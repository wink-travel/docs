Wink espone due server MCP autenticati. Entrambi utilizzano **login OAuth2 interattivo** (flusso di autorizzazione con codice PKCE) — il tuo agente AI apre una scheda del browser per effettuare l’accesso con il tuo account Wink. Nessun segreto client da gestire.

| Server | URL | Cosa fa |
|--------|-----|---------|
| **Inventory API** | `https://api.wink.travel/mcp` | Inventario, prenotazioni, tariffe, canali di vendita, analisi e tutte le operazioni della piattaforma |
| **Integrations** | `https://integrations.wink.travel/mcp` | Integrazioni channel manager — sincronizza proprietà, tariffe e disponibilità con OTA |

---

## Come funziona l’autenticazione

I server MCP di Wink utilizzano il flusso **OAuth2 Authorization Code + PKCE** e supportano la **Dynamic Client Registration (RFC 7591)**. Ecco cosa succede al primo collegamento:

1. Il client AI scopre il server di autorizzazione dai metadati `/.well-known/oauth-protected-resource` dell’endpoint MCP.
2. Il client si registra autonomamente tramite **Dynamic Client Registration** — nessuna configurazione manuale dell’applicazione richiesta.
3. Il client apre una **scheda del browser** su `https://iam.wink.travel`. Effettui l’accesso con il tuo account Wink e approvi le autorizzazioni richieste nella schermata di consenso.
4. Wink emette un **token di accesso** associato al tuo account e collegato alla tua identità.
5. Il client AI allega il token a ogni richiesta MCP. Tutti i risultati degli strumenti sono automaticamente limitati alla tua entità di gestione.
6. I token scadono dopo 3 ore. Il client AI aggiorna il token silenziosamente in background senza richiedere nuovamente l’accesso.

Ogni chiamata agli strumenti avviene **sotto la tua identità** — le stesse regole ACL che proteggono il portale web si applicano all’agente AI.

## Collega il tuo client AI

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Assicurati che Claude Code sia aggiornato:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Aggiungi il server MCP Inventory di Wink:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code contatta il server, scopre il server di autorizzazione e apre il browser predefinito.

4. **Accedi a Wink** e approva la richiesta di autorizzazione nella schermata di consenso.

5. Claude Code conferma la connessione. Digita `/mcp` per verificare che il server appaia e che gli strumenti siano caricati.
</Steps>

Per aggiungere anche il server Integrations:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Condividi con il tuo team]
Aggiungi `--scope project` a `claude mcp add` e Claude Code scriverà l’URL del server in `.mcp.json` nella radice del repository. Committa quel file — ogni membro del team completerà il proprio accesso browser la prima volta che si collega.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Modifica il file di configurazione di Claude Desktop:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. Aggiungi le voci dei server MCP:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **Chiudi completamente e riavvia** Claude Desktop (usa Esci dal menu — chiudere la finestra non basta).

4. Claude Desktop apre una scheda del browser per ogni nuovo server. Accedi a Wink e approva le autorizzazioni.

5. L’icona della spina nella barra inferiore mostra entrambi i server come connessi.
</Steps>

  </TabItem>
  <TabItem label="OpenAI Codex">

<Steps>
1. Assicurati che Codex CLI sia installato:

   ```bash
   npm install -g @openai/codex
   ```

2. Apri (o crea) il file di configurazione Codex:
   - **macOS / Linux:** `~/.codex/config.json`
   - **Windows:** `%USERPROFILE%\.codex\config.json`

3. Aggiungi le voci dei server MCP di Wink:

   ```json title="~/.codex/config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

4. Avvia Codex. Al primo utilizzo, Codex apre una scheda del browser su `https://iam.wink.travel`.

5. **Accedi a Wink** e approva le autorizzazioni richieste.

6. Codex conferma la connessione. Esegui `codex` e chiedi di elencare gli strumenti disponibili per verificare che i server Wink siano attivi.
</Steps>

:::note
Il supporto MCP di Codex CLI richiede la versione **1.0** o successiva. Esegui `codex --version` per controllare, e `npm install -g @openai/codex` per aggiornare.
:::

  </TabItem>
  <TabItem label="ChatGPT">

Il supporto ai server MCP è disponibile nell’**app desktop ChatGPT** per abbonati Plus, Pro, Team ed Enterprise.

<Steps>
1. Scarica e installa l’[app desktop ChatGPT](https://openai.com/chatgpt/download/) se non l’hai già fatto.

2. Apri l’app e clicca sull’**icona del profilo** in alto a destra, poi scegli **Impostazioni**.

3. Vai su **Connettori** (o **Server MCP** a seconda della versione dell’app) e clicca su **Aggiungi**.

4. Inserisci l’URL del server Inventory di Wink:
   ```
   https://api.wink.travel/mcp
   ```
   Poi clicca su **Connetti**.

5. ChatGPT apre una scheda del browser su `https://iam.wink.travel`. **Accedi a Wink** e approva le autorizzazioni.

6. Ripeti i passaggi 4–5 per il server Integrations:
   ```
   https://integrations.wink.travel/mcp
   ```

7. Entrambi i server appaiono nella lista Connettori. Avvia una nuova chat — gli strumenti Wink sono disponibili automaticamente.
</Steps>

:::note[Limitazione app web]
I server MCP sono configurabili solo nell’**app desktop**. L’interfaccia web di ChatGPT su chatgpt.com non supporta server MCP personalizzati.
:::

  </TabItem>

   - **Windows:** `%USERPROFILE%\.cursor\mcp.json`

2. Aggiungi le voci dei server MCP di Wink:

   ```json title="~/.cursor/mcp.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
   ```

3. Apri Cursor. Vai su **Impostazioni → Impostazioni Cursor → MCP** e verifica che entrambi i server appaiano con indicatore di stato verde. Se sono rossi, clicca su **Aggiorna**.

## Riferimento scope

Quando approvi la schermata di consenso vedrai un dettaglio di cosa l’agente sta richiedendo. Wink raggruppa le autorizzazioni per area funzionale:

| Gruppo scope | Scope | Cosa sbloccano |
|--------------|-------|----------------|
| **Trasporto MCP** | `mcp.read` `mcp.write` `mcp.remove` | Necessari per connettersi a uno dei server MCP |
| **Account** | `account.read` `account.write` `account.remove` | Entità di gestione, membri del team, impostazioni, applicazioni |
| **Prenotazione** | `booking.read` `booking.write` `booking.remove` | Ricerca, visualizzazione, creazione, cancellazione e rimborso prenotazioni |
| **Inventario** | `inventory.read` `inventory.write` `inventory.remove` | Proprietà, camere, tariffe, servizi, disponibilità |
| **Analisi** | `analytics.read` | Analisi prenotazioni, report ricavi, classifiche |
| **Marketing** | `marketing.read` `marketing.write` `marketing.remove` | Post social, campagne, canali di vendita, promozioni |
| **Contenuti** | `content.read` `content.write` `content.remove` | Multimedia, URL abbreviati, elementi sindacabili, mappe |
| **Pagamento** | `payment.read` `payment.write` | Libro mastro, pagamenti, dettagli finanziari, prelievi |

Il client AI richiede solo gli scope necessari. Puoi negare singole autorizzazioni nella schermata di consenso — gli strumenti che richiedono uno scope negato restituiranno un errore se invocati.

## Risoluzione problemi

**La scheda del browser non si apre**

Il tuo client AI potrebbe non supportare ancora il flusso PKCE interattivo. Verifica di usare una versione recente:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** aggiorna tramite l’updater integrato nell’app

**`401 Unauthorized` dopo l’accesso**

Il token memorizzato potrebbe essere scaduto. Rimuovi e riaggiungi il server per forzare un nuovo accesso:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

Per Claude Desktop e ChatGPT, rimuovi la voce server dalle impostazioni, riavvia l’app e aggiungila di nuovo.

**`403 Forbidden` chiamando uno strumento specifico**

Lo strumento richiede uno scope che non hai approvato nella schermata di consenso. Riconnetti il server — la schermata di consenso apparirà di nuovo e potrai approvare il permesso mancante.

**Il server appare ma le chiamate agli strumenti restituiscono "account non trovato"**

Sei connesso a un account Wink senza entità di gestione. Vai su [Wink Portal](https://app.wink.travel) e assicurati che il tuo account sia configurato prima di usare il server MCP.

**Il token scade durante la sessione**

I token sono validi per 3 ore. Claude Code e Claude Desktop aggiornano i token silenziosamente senza interrompere la sessione. Se vedi errori di autenticazione dopo un lungo periodo di inattività, invia un nuovo messaggio — il client si ri-autenticherà automaticamente.

**Codex CLI mostra "MCP server unreachable"**

Controlla che il file `~/.codex/config.json` sia un JSON valido (senza virgole finali) e che `"type": "http"` sia impostato. Codex richiede il trasporto HTTP per server remoti; il trasporto stdio è solo per binari locali.

**Menu "Connettori" di ChatGPT mancante**

Il supporto MCP richiede la versione **1.2024.352** o successiva dell’app desktop ChatGPT e un abbonamento attivo Plus, Pro, Team o Enterprise. Aggiorna l’app e verifica il piano in Impostazioni → Account.

**Server Cursor mostra rosso / "Connessione fallita"**

Verifica che `~/.cursor/mcp.json` sia un JSON valido e contenga `"type": "http"`. Poi vai su **Impostazioni → Impostazioni Cursor → MCP** e clicca su **Aggiorna**. Se l’errore persiste, riavvia completamente Cursor — le modifiche alla configurazione non sempre vengono rilevate senza un riavvio.

**Server MCP Windsurf non elencati nelle impostazioni**

Windsurf richiede un riavvio completo (non solo ricaricare la finestra) per rilevare le modifiche a `mcp_config.json`. Usa **File → Esci** e riapri. Se i server non appaiono ancora, conferma di usare Windsurf **1.4+** tramite **Aiuto → Informazioni su Windsurf**.

**Opzione "Aggiungi server" in Cline non visibile**

Il gestore server MCP richiede Cline **2.0** o successivo. Apri il pannello Estensioni di VS Code, trova Cline e clicca su **Aggiorna** se disponibile. Dopo l’aggiornamento, ricarica VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
