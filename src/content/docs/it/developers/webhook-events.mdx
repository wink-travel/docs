Questa pagina elenca tutti gli eventi webhook a cui puoi iscriverti su Wink. Per le istruzioni di configurazione, consulta la [Guida all'Integrazione Webhook](/it/developers/webhook-integration) o la [pagina di gestione Webhooks](/it/portal/settings/webhooks).

## Come iscriversi

1. Vai su **Applicazioni > Webhooks** nel tuo portale.
2. Crea un webhook e seleziona gli eventi che vuoi ricevere.
3. Wink invia una richiesta HTTP POST al tuo endpoint ogni volta che si verifica l'evento.

Per i passaggi completi di configurazione e le migliori pratiche, consulta [Integrazione Webhook](/it/developers/webhook-integration).

## Gestione degli eventi delle entità

Eventi per la gestione delle entità (proprietà, affiliati, aziende) e la loro amministrazione.

### Ciclo di vita

| Evento | Chiave | Descrizione |
|---|---|---|
| Entità creata | `managing_entity.created` | È stata creata una nuova entità di gestione. |
| Entità eliminata | `managing_entity.deleted` | Un'entità di gestione è stata eliminata. |
| Stato aggiornato | `managing_entity.status.updated` | Lo stato dell'entità è cambiato. |
| In revisione | `account.under_review` | L'account dell'entità è in attesa di revisione. |

### Abbonamento

| Evento | Chiave | Descrizione |
|---|---|---|
| Abbonamento fornito | `managing_entity.subscription.provisioned` | È stato fornito un nuovo abbonamento. |
| Abbonamento modificato | `managing_entity.subscription.changed` | Il piano di abbonamento è stato modificato. |
| Fattura abbonamento modificata | `managing_entity.subscription.invoice.changed` | La fattura dell'abbonamento è stata aggiornata. |

### Ciclo di vita del manager

| Evento | Chiave | Descrizione |
|---|---|---|
| Manager aggiunto | `managing_entity.manager.added` | È stato aggiunto un nuovo manager. |
| Manager invitato | `managing_entity.manager.invited` | È stato inviato un invito a un manager. |
| Manager rimosso | `managing_entity.manager.removed` | Un manager è stato rimosso. |
| Manager accettato | `managing_entity.manager.accepted` | Un invito a manager è stato accettato. |
| Manager rifiutato | `managing_entity.manager.rejected` | Un invito a manager è stato rifiutato. |
| Proprietario impostato | `managing_entity.manager.owner.set` | La proprietà dell'entità è stata trasferita. |
| Manager aggiornati | `account.managers.update` | La lista dei manager è cambiata. |

### Informazioni sull'entità

| Evento | Chiave | Descrizione |
|---|---|---|
| Informazioni aggiornate | `managing_entity.information.updated` | Le informazioni dell'entità sono state aggiornate. |
| Indirizzo aggiornato | `managing_entity.city.updated` | L'indirizzo/città dell'entità è stato modificato. |
| Nome aggiornato | `managing_entity.name.updated` | Il nome dell'entità è stato modificato. |
| Nome URL aggiornato | `managing_entity.url_name.updated` | L'URL personalizzato dell'entità è cambiato. |
| ID univoco aggiornato | `managing_entity.unique_id.updated` | L'identificatore univoco dell'entità è cambiato. |
| Gestito da aggiornato | `managing_entity.managed_by.updated` | La relazione di gestione/parentela dell'entità è cambiata. |
| Place ID aggiornato | `managing_entity.place_id.updated` | Il Google Place ID dell'entità è cambiato. |
| Rappresentante account aggiornato | `managing_entity.account_representative.updated` | Il rappresentante dell'account è stato modificato. |
| Foto profilo aggiornata | `managing_entity.profile_picture.updated` | La foto profilo dell'entità è stata aggiornata. |
| Logo aggiornato | `managing_entity.logo.updated` | Il logo dell'entità è stato aggiornato. |
| Dettagli aggiornati | `account.details.updated` | I campi dei dettagli dell'account sono cambiati. |
| Agente aggiornato | `managing_entity.agent.updated` | L'agente dell'entità è stato modificato. |

### Notifiche

## Eventi di prenotazione

| Evento | Chiave | Descrizione |
|---|---|---|

| Prenotazione annullata | `booking.cancelled` | Una prenotazione è stata annullata. |
| Prenotazione fallita | `booking.failed` | Un tentativo di prenotazione è fallito. |
| Prenotazione in elaborazione | `booking.processing` | Il pagamento della prenotazione è in elaborazione. |
| Inizializzazione richiesta | `booking.initialize.request` | È stata richiesta un'inizializzazione della prenotazione. |

| Rimborso parziale | `booking.refund.partial` | È stato emesso un rimborso parziale. |
| Rimborso completo | `booking.refund.full` | È stato emesso un rimborso completo. |

| Fondi registrati | `booking.funds.ledgered` | I fondi della prenotazione sono stati registrati nel libro contabile. |

### Recensioni

| Evento | Chiave | Descrizione |
|---|---|---|
