Booking Engine si integra ovunque. Scegli il tuo framework o CMS e segui la sua guida; i Web Components sottostanti sono gli stessi ovunque.

## Approcci principali

- [Web Components](/it/integrations/web-components/) — gli elementi incorporabili usati in ogni integrazione.
- [pacchetto npm](/it/integrations/npm/) — installa in un build JavaScript.
- [Headless CMS](/it/integrations/headless/) — rendi da qualsiasi backend di contenuti.
- [Partner API](/it/integrations/partner-api/) — integrazione programmatica completa.
