Booking Engine embeds anywhere. Pick your framework or CMS and follow its guide; the underlying Web Components are the same everywhere.

## Core approaches

- [Web Components](/integrations/web-components/) — the embeddable elements every integration uses.
- [npm package](/integrations/npm/) — install into a JavaScript build.
- [Headless CMS](/integrations/headless/) — render from any content backend.
- [Partner API](/integrations/partner-api/) — full programmatic integration.
