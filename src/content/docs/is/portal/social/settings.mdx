# Stillingar

Þegar þú byrjar fyrst með Social munum við spyrja þig hvernig þú vilt að við búum til efnið þitt. Þessar valkostir eru alltaf tiltækir svo þú getir auðveldlega breytt þeim síðar.

Farðu í `Settings` í hliðarstikunni til að stjórna stillingunum þínum.

Valkostir hluti inniheldur grunnstillingar fyrir efnisgerð:

1. **Valin sérsnið** Veldu hvaða sérsnið á að nota við gerð efnis. Sérsnið stjórna þemalitum, sjálfgefnu ferðalagi, gjaldmiðli, tungumáli og fleiru. Þú býrð til sérsnið undir reikningnum þínum á [app.wink.travel](https://app.wink.travel).
2. **Sjálfvirk samþykkt** Þegar þetta er virkjað eru búin innlegg birt sjálfkrafa án þess að þurfa samþykki þitt. Virkjaðu þetta þegar þú ert viss um gæði efnisins sem við framleiðum fyrir þig.
3. **Nafn samþykkjanda** Nafn einstaklings eða teymis sem fær beiðnir um samþykki í tölvupósti.
4. **Tölvupóstur samþykkjanda** Tölvupóstfang þar sem beiðnir um samþykki fyrir komandi innlegg verða sendar.

## Efnisgerðendur

<figure>
<CldImage
  src="academy/social_content_creators"

Social kemur með marga efnisgerðendur til að velja úr. Hver gerandi einbeitir sér að einum sérstökum hætti til að búa til einstakt efni fyrir eign þína með AI. Hver efnisgerðandi hefur **Þyngd** eiginleika — hærri þyngd eykur líkurnar á að sá gerandi verði valinn við gerð innleggja.

Hér eru allir tiltækir efnisgerðendur:

| Gerandi | Lýsing |
| -- | -- |
| **Áfangastaður** | Notar staðsetningu þína til að búa til gagnlegan texta um svæðið |
| **Herbergistegund** | Býr til bókanlegt innlegg með einni af herbergistegundum þínum með AI-búnum texta og myndum af herbergistegundinni |
| **Virkni** | Býr til bókanlegt innlegg með einni af virkni þinni |
| **Viðbót** | Býr til bókanlegt innlegg með einni af viðbótum þínum |
| **Aðdráttarafl** | Býr til bókanlegt innlegg með einni af aðdráttaraflum þínum |
| **Staður** | Býr til bókanlegt innlegg með einni af stöðum þínum |
| **Fundarherbergi** | Býr til bókanlegt innlegg með einu af fundarherbergjum þínum |
| **Veitingastaður** | Býr til bókanlegt innlegg með einum af veitingastöðum þínum |
| **Heilsulind** | Býr til bókanlegt innlegg með einni af heilsulindum þínum |
| **Eign** | Býr til bókanlegt innlegg með best verðlagða herbergi þínu með AI-búnum texta og myndum af eigninni þinni |
| **Notendatilfinning** | Safnar umsögnum gesta af netinu í innlegg sem byggir á tilfinningum og dregur fram hvað gestir elska við eignina þína |
| **Skemmtilegt** | Býr til létt og skemmtileg innlegg til að halda straumnum áhugaverðum |

:::tip[Pro tip]
Gakktu úr skugga um að þú hafir þann birgðaflokk sem þarf fyrir valda efnisgerðendur. Til dæmis, ef þú velur "Veitingastaður," þarftu að hafa að minnsta kosti einn veitingastað skráðan í eign þinni.
:::

## Rödd

Röddin setur tungumálastílinn sem AI notar við gerð efnis. Veldu þær raddir sem passa við persónuleika vörumerkisins þíns. Eins og með efnisgerðendur hefur hver rödd **Þyngd** til að stjórna hversu oft hún er notuð.

Hér eru tiltækar raddir:

| Rödd | Stíll |
| -- | -- |
| **Hlutlaus** | Róleg, áreiðanleg, staðreyndamiðuð. Engin yfirlýsing, engar brandarar — bara áreiðanleg og vel uppbyggð þekking |
| **Vinaleg** | Hlý, aðgengileg, brosandi í gegnum texta með afslöppuðum samdráttum og stundum emoji |
| **Lúxus** | Fínleg, fáguð. Orð eins og „glæsilegt“ og „sérsmíðað“ sem láta lesendur finna fyrir sérstöku |
| **Matgæðingur** | Ástríðufull, munnvatnandi lýsingar. Matarporno mál sem vekur matarlyst |
| **Ævintýragjörn** | Djarf, óhrædd, könnuður. Lýsingar sem vekja skynjun og gera allt epískt |
| **Fjölskylduvæn** | Hrein, barnvæn spenna. Hlý foreldraorku um öruggar og skemmtilegar upplifanir |
| **Rómantísk** | Ljóðræn, hugljúf, hjartsláttar. Sólsetur, mjúkt mál og ást |
| **Húmorísk** | Harkaleg, snöggar einlínum, snjall orðaleikur. Les eins og stand-up sýning |
| **Umhverfisvæn** | Heiðarleg og réttlát. Fagnar grænum valkostum og sjálfbærum ákvörðunum |
| **Staðbundinn innherji** | Mjög sértækar staðbundnar vísanir, varar við ferðamannagildrum, notar staðbundið slangur |
| **Innkynning** | Vinaleg, hátíðleg og staðfestandi. Lætur alla finna sig séða og metna |
| **Dularfull** | Himinrík, andleg, alheims sannindi. Mjúk boð um að líta inn á við |
| **Framtíðarsýn** | Fínleg, framúrskarandi. Elskar hugtök eins og „paradigm shift“ og bjartsýnar framtíðarsýn |
| **Sparsamur** | Hress, úrræðagóður, stoltur af sparnaði. Fagnar hagkvæmum fundum og ókeypis upplifunum |

## Tegundir innleggja

Tegundir innleggja ákvarða markmið og uppbyggingu efnisins sem búið er til. Hver tegund innleggja hefur **Þyngd** til að stjórna hversu oft hún er notuð.

| Tegund innleggja | Lýsing |
| -- | -- |
| **Viðskiptaleg** | Skýr, hnitmiðuð, með áherslu á umbreytingu. Hvetur til bókana og beinna aðgerða með staðreyndum, verðlagi og næstu skrefum |
| **Vitsmunaleg** | Vörumerkjabyggjandi efni sem er ætlað að kynna eignina þína og auka sýnileika meðal mögulegra gesta |
| **Tilfinningaleg** | Tilfinningalegt efni sem skapar jákvæð tengsl og byggir upp tilfinningalegt samband við áhorfendur þína |

## Tímabelti

  height="396"

/>
  <figcaption>*Mynd 4 - Tímabelti*</figcaption>

Þú gætir viljað beina markaðsstarfi þínu að ákveðnu tungumáli og svæði. Segðu okkur hvaða tungumál þú vilt búa til efni fyrir og hvaða tímabelti þú hefur áhuga á og við sjáum um restina. Innlegg eru birt á áætluðum tíma í valda tímabeltinu þínu.

*Flestar eignir nota eitt tungumál og sjálfgefið tungumál þeirra er staðbundið tungumál.*

Með því að tengja Google Business Profile þinn getum við sótt ríkulegri eignaupplýsingar fyrir áhrifaríkara efni. Eignin þín þarf að hafa staðfestan Google Business Profile svo við getum búið til efni úr skráningu þinni. Sumir efnisgerðendur okkar **krefjast** þess að þú hafir Google Business reikning.

:::tip[Pro tip]
Byrjaðu smátt

Vertu ekki of metnaðarfull/ur í fyrstu tilraun. Við mælum með að þú byrjir á að búa til efni fyrir eign þína á einu tungumáli.
:::
