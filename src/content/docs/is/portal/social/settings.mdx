# Stillingar

Þegar þú byrjar að nota Social munum við spyrja þig hvernig þú vilt að við búum til efnið þitt. Þessar valkostir eru alltaf tiltækir svo þú getir auðveldlega breytt þeim síðar.

Farðu í `Preferences` í hliðarstikunni til að stjórna stillingum þínum.

Kaflinn Preferences inniheldur grunnstillingar fyrir efnisgerð:

1. **Preferred customization** Veldu hvaða sérsnið þú vilt nota við gerð efnis. Sérsnið stjórna þemalitum, sjálfgefnu ferðalagi, gjaldmiðli, tungumáli og fleiru. Þú býrð til sérsnið undir reikningnum þínum á [app.wink.travel](https://app.wink.travel).
2. **Auto-approve** Þegar þetta er virkjað eru gerðar færslur birtar sjálfkrafa án þess að þurfa samþykki þitt. Virkjaðu þetta þegar þú ert viss um gæði efnisins sem við framleiðum fyrir þig.
3. **Approver name** Nafn þess eða þeirrar deildar sem mun fá beiðnir um samþykki í tölvupósti.
4. **Approver e-mail** Tölvupóstfang þar sem beiðnir um samþykki fyrir komandi færslur verða sendar.

## Content creators

Social býður upp á marga efnisgerðaraðila til að velja úr. Hver gerðaraðili einbeitir sér að einum sérstökum hætti við að búa til einstakt efni fyrir gististaðinn þinn með AI. Hver efnisgerðaraðili hefur **Weight** eiginleika — hærri þyngd eykur líkurnar á að sá gerðaraðili verði valinn þegar færslur eru gerðar.

Hér eru allir tiltækir efnisgerðaraðilar:

| Creator | Lýsing |
| -- | -- |
| **Destination** | Notar staðsetningu þína til að búa til gagnlegan texta um svæðið |
| **Room type** | Býr til bókanlega færslu með einni herbergistegund með AI-búnum texta og myndum af herbergistegundinni þinni |
| **Activity** | Býr til bókanlega færslu með einni af þínum afþreyingum |
| **Add-On** | Býr til bókanlega færslu með einu af þínum viðbótum |
| **Attraction** | Býr til bókanlega færslu með einni af þínum aðdráttaraflum |
| **Place** | Býr til bókanlega færslu með einum af þínum stöðum |
| **Meeting room** | Býr til bókanlega færslu með einu af þínum fundarherbergjum |
| **Restaurant** | Býr til bókanlega færslu með einu af þínum veitingastöðum |
| **Spa** | Býr til bókanlega færslu með einu af þínum heilsulindum |
| **Property** | Býr til bókanlega færslu með best verðlagða herberginu þínu með AI-búnum texta og myndum af gististaðnum þínum |
| **User sentiment** | Safnar saman umsögnum gesta af netinu í tilfinningadrifna færslu sem dregur fram hvað gestir elska við gististaðinn þinn |
| **Funny** | Býr til léttar, skemmtilegar færslur til að halda straumnum áhugaverðum |

:::tip[Pro tip]
Gakktu úr skugga um að þú hafir þann birgðutegund sem þarf fyrir valda efnisgerðaraðila. Til dæmis, ef þú velur „Restaurant,“ þarftu að hafa að minnsta kosti einn veitingastað skráðan á gististaðnum þínum.
:::

## Tone of voice

<figure>
<CldImage
  src="academy/social_personas"

  height="396"
  alt="Social tone of voice"
/>
  <figcaption>*Mynd 3 - Tone of voice*</figcaption>

Tónninn í máli setur tungumálastílinn sem AI notar við gerð efnis. Veldu þá tóna sem passa við persónuleika vörumerkisins þíns. Eins og með efnisgerðaraðila hefur hver tónn **Weight** til að stjórna hversu oft hann er notaður.

Hér eru tiltækir tónar:

| Tone | Stíll |
| -- | -- |
| **Neutral** | Rólegur, áreiðanlegur, staðreyndamiðaður. Engin yfirdrifin orð, engar brandarar — bara áreiðanleg og vel uppbyggð þekking |
| **Friendly** | Hlýlegur, aðgengilegur, brosandi í gegnum texta með afslöppuðum samdráttum og stundum emoji |
| **Luxury** | Fínn, fágaður. Orð eins og „glæsilegur“ og „sérsmíðaður“ sem láta lesendur finna fyrir sérstöku útliti |
| **Foodie** | Ástríðufullar, munnvatnandi lýsingar. Matur sem vekur löngun |
| **Adventurous** | Djarfur, óhræddur, könnuður. Lýsingar sem vekja sterkar skynjanir og gera allt epískt |
| **Family** | Hreinlæti, barnvænn spenningur. Hlýleg orka foreldra um öruggar og skemmtilegar upplifanir |
| **Romantic** | Ljóðrænn, hugljúfur, hjartsláttar. Sólsetur, mjúkt málfar og ást |
| **Humorous** | Hnyttinn, snöggar setningar, snjall orðaleikur. Les eins og stand-up sýning |
| **Eco** | Heiðarlegur og réttlátur. Fagnar grænum valkostum og sjálfbærum lausnum |
| **Local insider** | Mjög sértækar staðbundnar vísanir, varar við ferðamannagildrum, notar staðbundið slangur |
| **Inclusive** | Vinalegur, fagnaður og staðfesting. Lætur alla finna sig séða og metna |
| **Mystical** | Dularfullur, andlegur, alheimssannindi. Mjúk boð um að líta inn á við |
| **Futuristic** | Nútímalegur, framúrskarandi. Elskar hugtök eins og „paradigm shift“ og bjartsýnar framtíðarsýn |
| **Budget** | Hagrænn, úrræðagóður, stoltur af sparnaði. Fagnar hagkvæmum fundum og ókeypis upplifunum |

## Post types

Gerðir færslna ákvarða markmið og uppbyggingu efnisins sem er búið til. Hver gerð færslu hefur **Weight** til að stjórna hversu oft hún er notuð.

| Post type | Lýsing |
| -- | -- |
| **Transactional** | Skýr, hnitmiðuð, með áherslu á umbreytingu. Hvetur til bókana og beinna aðgerða með staðreyndum, verðlagi og næstu skrefum |
| **Awareness** | Vörumerkjabyggjandi efni sem er ætlað til að kynna gististaðinn þinn og auka sýnileika meðal mögulegra gesta |
| **Sentiment** | Tilfinningalegt efni sem skapar jákvæð tengsl og byggir upp tilfinningalegt samband við áhorfendur þína |

Þú gætir viljað beina markaðsátaki þínu að ákveðnu tungumáli og svæði. Segðu okkur hvaða tungumál þú vilt búa til efni fyrir og hvaða tímabelti þú hefur áhuga á og við sjáum um restina. Færslur eru birtar á áætluðum tíma í valda tímabeltinu þínu.

*Flestir gististaðir nota eitt tungumál og sjálfgefið er að nota þeirra staðbundna tungumál.*

Með því að tengja Google Business Profile þinn getum við sótt ríkulegri upplýsingar um gististaðinn til að búa til áhrifaríkara efni. Gististaðurinn þinn þarf að hafa staðfestan Google Business Profile svo við getum búið til efni úr skráningu þinni. Sumir af efnisgerðaraðilum okkar **krefjast** þess að þú hafir Google Business reikning.

Byrjaðu smátt

Ekki vera of metnaðarfullur í fyrstu tilraun. Við mælum með að þú byrjir á að búa til efni fyrir gististaðinn þinn á einu tungumáli.
:::
