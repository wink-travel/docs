Wink býður upp á tvo auðkennda MCP þjónar. Báðir nota **gagnvirka OAuth2 innskráningu** (PKCE heimildarkóðaflæði) — AI-umboðsmaður þinn opnar vafraglugga svo þú skráir þig inn með Wink reikningnum þínum. Engar viðskiptavinleyndarmál til að stjórna.

| Þjónn | URL | Hvað hann gerir |
|--------|-----|--------------|
| **Inventory API** | `https://api.wink.travel/mcp` | Birgðir, bókanir, verð, sölurásir, greiningar og allar aðgerðir á vettvangi |
| **Integrations** | `https://integrations.wink.travel/mcp` | Samþættingar rásarstjóra — samstilling eigna, verðs og framboðs með OTA-kerfum |

---

## Hvernig auðkenning virkar

Wink MCP þjónar nota **OAuth2 Heimildarkóða + PKCE** flæði og styðja **Dynamic Client Registration (RFC 7591)**. Þetta gerist þegar þú tengir í fyrsta sinn:

1. AI viðskiptavinurinn finnur auðkenningarþjóninn úr `/.well-known/oauth-protected-resource` metadata MCP endapunktsins.
2. Viðskiptavinurinn skráir sig sjálfur með **Dynamic Client Registration** — engin handvirk umsóknaruppsetning nauðsynleg.
3. Viðskiptavinurinn opnar **vafraglugga** á `https://iam.wink.travel`. Þú skráir þig inn með Wink reikningnum þínum og samþykkir beiðnar heimildir á samþykkisskjánum.
4. Wink gefur út **aðgangstákn** sem er bundið við reikninginn þinn og auðkenni.
5. AI viðskiptavinurinn festir táknið við hverja MCP beiðni. Öll niðurstaða tækja er sjálfkrafa bundin við þitt stjórnunareiningu.
6. Táknum rennur út eftir 3 klukkustundir. AI viðskiptavinurinn endurnýjar þau hljóðlaust í bakgrunni án frekari fyrirspurna.

Allar tækjakall keyra **undir þínu auðkenni** — sömu ACL reglur sem vernda vefsvæðið gilda um AI umboðsmanninn.

## Tengdu AI viðskiptavininn þinn

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Gakktu úr skugga um að Claude Code sé uppfærður:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Bættu við Wink Inventory MCP þjóninum:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code hefur samband við þjóninn, finnur auðkenningarþjóninn og opnar sjálfgefinn vafra.

4. **Skráðu þig inn í Wink** og samþykktu beiðnina um heimildir á samþykkisskjánum.

5. Claude Code staðfestir tenginguna. Sláðu inn `/mcp` til að staðfesta að þjónninn birtist og tól hafi hlaðist.
</Steps>

Til að bæta við Integrations þjóninum líka:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Deildu með teyminu þínu]
Bættu við `--scope project` í `claude mcp add` og Claude Code skrifar þjónnslóðina í `.mcp.json` í rót verkefnisins. Skráðu þá skrá — hver liðsfélagi klárar eigin innskráningu í vafra í fyrsta sinn sem hann tengist.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Breyttu stillingarskránni fyrir Claude Desktop:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. Bættu við MCP þjónnaskrám:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **Lokaðu Claude Desktop alveg og ræstu aftur** (notaðu Quit úr valmyndastikunni — að loka glugga dugar ekki).

4. Claude Desktop opnar vafraglugga fyrir hvern nýjan þjón. Skráðu þig inn í Wink og samþykktu heimildir.

5. Tengi-tákn í neðri tækjastikunni sýnir báða þjónana sem tengda.
</Steps>

  </TabItem>
  <TabItem label="OpenAI Codex">

<Steps>

   - **macOS / Linux:** `~/.codex/config.json`
   - **Windows:** `%USERPROFILE%\.codex\config.json`

3. Bættu við Wink MCP þjónnaskrám:

   ```json title="~/.codex/config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

4. Ræstu Codex. Í fyrsta skipti opnar Codex vafraglugga á `https://iam.wink.travel`.

5. **Skráðu þig inn í Wink** og samþykktu beiðnar heimildir.

6. Codex staðfestir tenginguna. Keyrðu `codex` og biððu um lista yfir tiltæk tól til að staðfesta að Wink þjónarnir séu virkir.
</Steps>

:::note
Codex CLI MCP stuðningur krefst útgáfu **1.0** eða nýrri. Keyrðu `codex --version` til að athuga og `npm install -g @openai/codex` til að uppfæra.
:::

  </TabItem>
  <TabItem label="ChatGPT">

Stuðningur við MCP þjónustu er í boði í **ChatGPT skjáborðsforritinu** fyrir Plus, Pro, Team og Enterprise áskrifendur.

<Steps>
1. Sæktu og settu upp [ChatGPT skjáborðsforritið](https://openai.com/chatgpt/download/) ef þú hefur ekki gert það.

2. Opnaðu forritið og smelltu á **prófílmyndina þína** efst til hægri, veldu svo **Stillingar**.

3. Farðu í **Tengla** (eða **MCP Servers** eftir útgáfu) og smelltu á **Bæta við**.

4. Sláðu inn Wink Inventory þjónnslóðina:
   ```
   https://api.wink.travel/mcp
   ```
   Smelltu svo á **Tengja**.

5. ChatGPT opnar vafraglugga á `https://iam.wink.travel`. **Skráðu þig inn í Wink** og samþykktu heimildir.

6. Endurtaktu skref 4–5 fyrir Integrations þjóninn:
   ```
   https://integrations.wink.travel/mcp
   ```

7. Báðir þjónar birtast í tenglalistanum þínum. Byrjaðu nýtt spjall — Wink tól eru sjálfkrafa tiltæk.
</Steps>

:::note[Takmörkun vefforrits]
MCP þjónar eru aðeins stillanlegir í **skjáborðsforriti**. ChatGPT vefviðmótið á chatgpt.com styður ekki sérsniðna MCP þjónustu.
:::

  </TabItem>

   - **macOS / Linux:** `~/.cursor/mcp.json`
   - **Windows:** `%USERPROFILE%\.cursor\mcp.json`

2. Bættu við Wink MCP þjónnaskrám:

   ```json title="~/.cursor/mcp.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. Opnaðu Cursor. Farðu í **Stillingar → Cursor Stillingar → MCP** og staðfestu að báðir þjónar birtist með grænum stöðutákni. Ef þeir eru rauðir, smelltu á **Endurnýja**.

4. Cursor opnar vafraglugga á `https://iam.wink.travel`. **Skráðu þig inn í Wink** og samþykktu heimildir.

</Steps>

:::tip[Verkefnastilling]
Þú getur líka sett `mcp.json` skrá í rót verkefnisins í staðinn fyrir í `~/.cursor/`. Verkefnastillingin hefur forgang og gerir þjónana aðgengilega fyrir alla liðsmenn sem opna verkefnið í Cursor.
:::

## Tilvísun í umfang

Þegar þú samþykkir samþykkisskjáinn sérðu sundurliðun á því sem umboðsmaðurinn biður um. Wink flokkar heimildir eftir virkni:

| Heimildarhópur | Heimildir | Hvað þær opna |
|-------------|--------|-----------------|
| **MCP flutningur** | `mcp.read` `mcp.write` `mcp.remove` | Nauðsynlegt til að tengjast MCP þjónninum |
| **Reikningur** | `account.read` `account.write` `account.remove` | Stjórnunareiningar, liðsmenn, stillingar, umsóknir |
| **Bókun** | `booking.read` `booking.write` `booking.remove` | Leita, skoða, búa til, hætta við og endurgreiða bókanir |
| **Birgðir** | `inventory.read` `inventory.write` `inventory.remove` | Eignir, herbergi, verð, þægindi, framboð |
| **Greiningar** | `analytics.read` | Bókunargreiningar, tekjuskýrslur, stigatöflur |
| **Markaðssetning** | `marketing.read` `marketing.write` `marketing.remove` | Færslur á samfélagsmiðlum, herferðir, sölurásir, kynningar |
| **Efni** | `content.read` `content.write` `content.remove` | Fjölmiðlar, styttar slóðir, dreifingarefni, kort |
| **Greiðsla** | `payment.read` `payment.write` | Reikningsbók, útborganir, fjármálayfirlit, úttektir |

AI viðskiptavinurinn biður aðeins um þær heimildir sem hann þarf. Þú getur neitað einstökum heimildum á samþykkisskjánum — tól sem krefjast neitaðrar heimildar skila villu þegar þau eru kölluð.

## Villuleit

**Vafragluggi opnast ekki**

AI viðskiptavinurinn þinn styður kannski ekki gagnvirka PKCE flæðið ennþá. Staðfestu að þú sért að keyra nýjustu útgáfu:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT skjáborð:** uppfærðu með innbyggðum uppfærslutæki appsins

**`401 Unauthorized` eftir innskráningu**

Táknið þitt í skyndiminni gæti verið úrelt. Fjarlægðu og bættu þjóninum aftur til að kveikja á nýrri innskráningu:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

Fyrir Claude Desktop og ChatGPT, fjarlægðu þjónninn úr stillingum, ræstu forritið aftur og bættu honum svo við.

**`403 Forbidden` þegar kallað er á ákveðið tól**

Tólið krefst heimildar sem þú samþykktir ekki á samþykkisskjánum. Tengdu þjóninn aftur — samþykkisskjárinn birtist á ný og þú getur samþykkt vantar heimild.

**Þjónninn birtist en tól skila "account not found"**

Þú ert skráður inn með Wink reikningi sem hefur enga stjórnunareiningu. Farðu á [Wink Portal](https://app.wink.travel) og tryggðu að reikningurinn þinn sé rétt stilltur áður en þú notar MCP þjóninn.

**Táknið rennur út á miðju tímabili**

Táknum gilda í 3 klukkustundir. Claude Code og Claude Desktop endurnýja tákn hljóðlaust án truflunar á fundinum. Ef þú sérð auðkennisvillur eftir langa kyrrsetu, sláðu inn nýja skilaboð — viðskiptavinurinn auðkennir sig sjálfkrafa aftur.

**Codex CLI sýnir "MCP server unreachable"**

Athugaðu að `~/.codex/config.json` sé gilt JSON (engin aukakomma) og að `"type": "http"` sé stillt. Codex krefst HTTP flutnings fyrir fjarþjóna; stdio flutningur er aðeins fyrir staðbundna keyrslu.

**ChatGPT "Connectors" valmynd vantar**

MCP stuðningur krefst ChatGPT skjáborðsforrits útgáfu **1.2024.352** eða nýrri og virks Plus, Pro, Team eða Enterprise áskriftar. Uppfærðu forritið og staðfestu áætlun í Stillingar → Reikningur.

**Cursor þjónn sýnir rauðan / "Failed to connect"**

Staðfestu að `~/.cursor/mcp.json` sé gilt JSON og innihaldi `"type": "http"`. Farðu svo í **Stillingar → Cursor Stillingar → MCP** og smelltu á **Endurnýja**. Ef villan heldur áfram, endurræstu Cursor alveg — breytingar á stillingum nást ekki alltaf án endurræsingar.

**Windsurf MCP þjónar birtast ekki í stillingum**

Windsurf krefst fullrar endurræsingar (ekki bara gluggahleðslu) til að taka breytingar á `mcp_config.json` gildar. Notaðu **Skrá → Hætta** og ræstu aftur. Ef þjónar birtast ekki, staðfestu að þú sért með Windsurf **1.4+** í **Hjálp → Um Windsurf**.

**Cline "Add Server" valkostur sést ekki**

MCP þjónastjóri krefst Cline **2.0** eða nýrri. Opnaðu VS Code Extensions gluggann, finndu Cline og smelltu á **Uppfæra** ef uppfærsla er í boði. Eftir uppfærslu, endurhlaða VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
