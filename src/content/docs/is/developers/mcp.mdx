MCP verkfæri Wink eru birt sem **verkfærasett** — sérhæfðir endapunktar, hver og einn fyrir eitt verkefni. Þú tengir AI viðskiptavininn þinn við einn eða tvo sem passa við vinnuna þína, ekki alla.

Hver endapunktur notar **gagnvirka OAuth2 innskráningu** (PKCE heimildarkóðaferli): AI-umboðsmaðurinn þinn opnar vafraglugga, þú skráir þig inn með Wink reikningnum þínum, og það er það. Engar viðskiptaleyndarmál til að stjórna.

```bash title="A channel manager integrator connects to one endpoint"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="A hotelier managing their own rates connects to another"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## Af hverju verkfærin eru skipt á milli endapunkta

Wink býður um 500 verkfæri. Að gefa öllum þeim til umboðsmanns í einu er tæknilega mögulegt — en slæm hugmynd.

**Verkfæra skilgreiningar kosta samhengi.** Hvert verkfæri sem MCP þjónn auglýsir er hlaðið inn í samhengi líkanins áður en það vinnur, ásamt lýsingu og fullri breytuskipan. Fimm hundruð þeirra taka stóran hluta af fjárhagsáætlun sem raunverulegt verkefni þitt þarf, í hverri beiðni.

**Gæði valkosta minnka þegar listinn stækkar.** Umboðsmaður sem velur úr 500 svipuðum verkfærum gerir verri val en sá sem velur úr 40. Ef þú samþættir channel manager eru um það bil tuttugu verkfæri viðeigandi fyrir þig; hin 480 eru hávaði sem gerir rétt verkfæri erfiðara að finna.

**Verkefnið er raunverulega aðskiljanlegt.** Sá sem samstillir framboð úr PMS og sá sem sér um samstarfsaðila lendingssíður deila næstum engum verkfærum. Að skipta eftir verkefni þýðir að hver tenging ber orðaforða eins verkefnis.

<Aside type="caution" title="Verkfærasett eru ekki aðgangsheimildir">
Að velja þröngt verkfærasett takmarkar **ekki** hvað reikningurinn þinn getur gert, og að velja vítt setti veitir ekki neitt aukalega. Hvert verkfæri framfylgir sömu aðgangsheimildum og vefsvæðið, undir þinni innskráðu auðkenni. Ef reikningurinn þinn getur ekki hætt við bókun í Wink Portal, getur umboðsmaðurinn það ekki heldur — óháð því hvaða endapunktur er tengdur.

Veldu verkfærasett fyrir **einbeitingu**, ekki öryggi.
</Aside>

## Endapunkta skrá

Tveir hýsingarþjónar þjónusta verkfærasett. Fjöldi verkfæra er áætlaður og vex með tímanum.

### `https://integrations.wink.travel` — samþættingar channel manager

Einn endapunktur, því þessi hýsing er fyrir eitt verkefni.

| Endapunktur | Verkfæri | Hvað það nær yfir |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | Tenging og staðfesting channel manager, PMS eða CRS samþættingar |

<Aside type="note" title="Samþætting channel manager vs. stjórnun eigin verðs">
Þetta eru mismunandi verkefni fyrir mismunandi aðila, og þau deila ekki endapunkti.

**Channel manager, PMS eða CRS söluaðili** samþættir einu sinni í gegnum `integrations.wink.travel/mcp/channel-manager`, og síðan skiptast eignir, verð, framboð og bókanir yfir þá samþættingu. Sá eini endapunktur er allt yfirborðið.

**Hótelstjóri sem breytir eigin verði handvirkt** notar extranet verkfærasettin á `api.wink.travel` — `/mcp/extranet/rates` og vinir. Þau eru ekki hluti af channel manager samþættingu og samþættari hefur enga ástæðu til að tengjast þeim.

Reikningsstjórnun er einnig á `api.wink.travel`, á `/mcp/settings`. Það er enginn `/mcp/settings` á samþættingarhýsingunni.
</Aside>

Hver endapunktur ber einnig með sér `ping` verkfæri, svo þú getir staðfest að tenging sé virk áður en þú biður um raunverulega vinnu.

## Hvaða verkfærasett þarf ég?

| Ef þú ert… | Tengdu við |
|---|---|
| **Samþættir channel manager, PMS eða CRS** | `integrations.wink.travel/mcp/channel-manager` — bara þennan |
| **Stjórnar innihaldi eignar** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **Stjórnar herbergjum og herbergistegundum** | `/mcp/extranet/facilities` |
| **Stjórnar verði og framboði** | `/mcp/extranet/rates` |
| **Rekur daglegar bókanir** | `/mcp/extranet/operations` |
| **Eykur dreifingu** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **Byggir samstarfsaðila síður** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **Rekur link-in-bio síður** | `/mcp/link-manager` + `/mcp/social` |
| **Bókar fyrir hönd ferðalanga** | `/mcp/travel-agent` |
| **Samræmir fjármál** | `/mcp/payment` |
| **Byggir bókunarupplifun** | `/mcp/booking-engine` + `/mcp/reference` |

Byrjaðu á einu. Bættu við öðru þegar þú finnur þig biðja um eitthvað sem það getur ekki gert — hver tenging er sjálfstæð og að bæta við einni hefur aldrei áhrif á aðrar.

<Aside type="tip" title="Viltu samt allt?">
`https://api.wink.travel/mcp` og `https://integrations.wink.travel/mcp` eru enn aðgengileg og þjónusta **öll** verkfæri á sínum hýsli. Þau eru gagnleg til að kanna hvað er til, en við mælum ekki með þeim fyrir daglega vinnu: verkfæralistinn er nógu stór til að trufla verkefnið þitt og rýra val umboðsmannsins. Veldu frekar verkfærasettin hér að ofan.
</Aside>

## Hvernig auðkenning virkar

Wink MCP þjónar nota **OAuth2 heimildarkóða + PKCE** ferlið og styðja **Dynamic Client Registration (RFC 7591)**. Þetta gerist þegar þú tengir í fyrsta sinn:

1. AI viðskiptavinurinn þinn finnur heimildarþjóninn úr MCP endapunktinum `/.well-known/oauth-protected-resource` metadata.
2. Viðskiptavinurinn skráir sig sjálfur með **Dynamic Client Registration** — engin handvirk umsóknaruppsetning nauðsynleg.
3. Viðskiptavinurinn opnar **vafraglugga** á `https://iam.wink.travel`. Þú skráir þig inn með Wink reikningnum þínum og samþykkir beiðnar heimildir á samþykkisskjánum.
4. Wink gefur út **aðgangslykil** bundinn við reikninginn þinn og auðkenni.
5. AI viðskiptavinurinn festir lykilinn við hverja MCP beiðni. Öll verkfæri eru sjálfkrafa bundin við stjórnunareiningu þína.
6. Lyklar renna út eftir 3 klukkustundir. AI viðskiptavinurinn endurnýjar þá hljóðlaust í bakgrunni án frekari beiðna.

Hver verkfæra kalla keyrir **undir þínu auðkenni** — sömu aðgangsreglur og verja vefsvæðið gilda um AI umboðsmanninn.

<Steps>
1. Gakktu úr skugga um að Claude Code sé uppfærður:

## Heimildir

Þegar þú samþykkir á samþykkisskjánum sérðu sundurliðun á því sem umboðsmaðurinn biður um. MCP
viðskiptavinir nota sama heimildamál og restin af vettvangnum — sjá fulla
[heimildaskráningu á Auðkenningarsíðu](/is/developers/authentication#scopes).

Tveir hlutir eru sértækir fyrir MCP:

- **`mcp.read` `mcp.write` `mcp.remove` heimildir eru aukalega nauðsynlegar** til að opna MCP
  flutningsrásina. Viðskiptavinur með `mcp.*` heimild fær aðgang að hvaða Wink MCP endapunkti sem er, en hvert
  verkfæri sem hann kallar fram framfylgir samt heimildum endapunktsins sem það umlykur (t.d. `booking.read`).
- **AI viðskiptavinurinn biður aðeins um þær heimildir sem hann þarf.** Þú getur neitað einstökum heimildum á
  samþykkisskjánum — verkfæri sem krefjast neitaðrar heimildar skila villu þegar þau eru kölluð.

**Verkfærasett breyta engu af þessu.** Endapunkturinn sem þú tengir við ákveður hvaða verkfæri eru *skráð*,
ekki hvað þeim er *heimilt að gera*. Að tengjast `/mcp/payment` veitir engar fjármálaheimildir sem þú hafðir ekki fyrir,
og að tengjast `/mcp/reference` hindrar ekki verkfæri þar í að framfylgja eigin heimildum. Heimildastýring er ákvörðuð fyrir hvert verkfæri út frá lykli þínum og heimildum reikningsins.

## Villuleit

**Vafragluggi opnast ekki**

AI viðskiptavinurinn þinn styður kannski ekki gagnvirka PKCE ferlið ennþá. Gakktu úr skugga um að þú sért með nýjustu útgáfu:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT skjáborð:** uppfærðu með innbyggðum uppfærslutæki appsins

**`401 Unauthorized` eftir innskráningu**

Geymdur lykill þinn gæti verið úreltur. Fjarlægðu og bættu þjóninum aftur til að kveikja á nýrri innskráningu:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

Fyrir Claude Desktop og ChatGPT, fjarlægðu þjóninn úr stillingum, ræstu forritið aftur og bættu honum við á ný.

**`403 Forbidden` þegar kallað er á ákveðið verkfæri**

Verkfærið krefst heimildar sem þú hafðir ekki samþykkt á samþykkisskjánum, eða heimildar sem reikningurinn þinn hefur ekki. Tengdu þjóninn aftur — samþykkisskjárinn birtist á ný og þú getur samþykkt vantar heimild. Ef það bilar enn, þarf verkfærið reikningsheimild sem þú hefur ekki; að tengjast öðru verkfærasetti hjálpar ekki, því verkfærasett veita ekki heimildir.

**Verkfærið sem ég þarf er ekki á listanum**

Þú ert líklega tengdur við verkfærasett sem nær ekki yfir það verkefni. Skoðaðu [endapunkta skrána](#endpoint-directory) og bættu við verkfærasetti sem nær yfir það — tengingar eru sjálfstæðar, svo að bæta við einu breytir engu um hin. Ef þú ert óviss um hvaða setti hefur það, tengdu tímabundið við `https://api.wink.travel/mcp`, finndu verkfærið og athugaðu hvaða verkfærasett skráir það.

**`404 Not Found` á endapunkti verkfærasets**

Athugaðu slóðina vel — innbyggðu verkfærasettin hafa tvö stig (`/mcp/extranet/rates`, ekki `/mcp/extranet-rates`), og þau einföldu hafa eitt (`/mcp/link-manager`). Athugaðu að *óauðkennd* beiðni á hvaða slóð undir `/mcp` sem er skilar `401`, ekki `404`, svo `401` segir ekki hvort endapunkturinn sé til.

**Ég tengdist `api.wink.travel/mcp/channel-manager` og fékk ekkert**

Sá endapunktur er ekki til. Channel manager samþætting er aðeins í boði á `https://integrations.wink.travel/mcp/channel-manager`. Ef þú þarft líka að lesa eða breyta eigin verðskrá handvirkt, er það annað verkefni á öðrum endapunkti — sjá `/mcp/extranet/rates`.

**Þjónninn birtist en verkfæri skila "account not found"**

Þú ert skráður inn með Wink reikningi sem hefur enga stjórnunareiningu. Farðu á [Wink Portal](https://app.wink.travel) og tryggðu að reikningurinn þinn sé rétt stilltur áður en þú notar MCP þjóninn.

**Lykill rennur út á miðju tímabili**

Lyklar gilda í 3 klukkustundir. Claude Code og Claude Desktop endurnýja lykla hljóðlaust án truflunar. Ef þú sérð auðkennisvillur eftir langa kyrrsetu, sláðu inn nýja skilaboð — viðskiptavinurinn auðkennir sig sjálfkrafa aftur.

**Codex CLI sýnir "MCP server unreachable"**

Athugaðu að `~/.codex/config.json` sé gilt JSON (engin aukakomma) og að `"type": "http"` sé stillt. Codex krefst HTTP flutnings fyrir fjarþjóna; stdio flutningur er aðeins fyrir staðbundna keyrslu.

**ChatGPT "Connectors" valmynd vantar**

MCP stuðningur krefst ChatGPT skjáborðsforrits útgáfu **1.2024.352** eða nýrri og virks Plus, Pro, Team eða Enterprise áskriftar. Uppfærðu forritið og staðfestu áskrift í Stillingar → Reikningur.

**Cursor þjónn sýnir rautt / "Failed to connect"**

Staðfestu að `~/.cursor/mcp.json` sé gilt JSON og innihaldi `"type": "http"`. Farðu svo í **Stillingar → Cursor Stillingar → MCP** og smelltu á **Endurnýja**. Ef villan heldur áfram, endurræstu Cursor alveg — stillingabreytingar eru ekki alltaf sóttar án endurræsingar.

**Windsurf MCP þjónar birtast ekki í stillingum**

Windsurf krefst fullrar endurræsingar (ekki bara gluggahleðslu) til að taka breytingar á `mcp_config.json` upp. Notaðu **Skrá → Hætta** og ræstu aftur. Ef þjónar birtast ekki, staðfestu að þú sért með Windsurf **1.4+** í **Hjálp → Um Windsurf**.

**Cline "Add Server" valkostur sést ekki**

MCP þjónastjóri krefst Cline **2.0** eða nýrri. Opnaðu VS Code Extensions gluggann, finndu Cline og smelltu á **Update** ef uppfærsla er í boði. Eftir uppfærslu, endurhleðslu VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
