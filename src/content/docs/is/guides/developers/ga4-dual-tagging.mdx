Með því að tengja Google Analytics 4 eign þína við Wink eru bókunaratburðir þínir — frá herbergisskoðunum til fullgertra bókana — sjálfkrafa sendir til þíns eigin GA4 mælaborðs ásamt eigin greiningum Wink. Engin kóðun, engin tæknileg uppsetning hjá þér.

<Aside type="tip">
Þú þarft tvö atriði frá GA4: **Measurement ID** og **Measurement Protocol API leyndarmál**. Measurement ID knýr vafraferlið í vafra gesta; API leyndarmálið leyfir Wink að skrá fullgerðar bókanir (`purchase`) **á þjóninum**, svo sala glatist aldrei þegar gestur er vísað til og frá greiðsluaðila.
</Aside>

---

## Hvernig þetta virkar

```
Þú slærð inn Measurement ID (G-XXXXXXXXXX) og API leyndarmálið í Wink vefinn
       ↓
Vafraatburðir (skoðanir, körfu, greiðsluferli) streyma til GA4 eignar þinnar frá vafranum
Fullgerðar bókanir (purchase) eru sendar á þjóninum — lifa af greiðsluvísun
       ↓
Þú skráir þig inn á analytics.google.com og sérð fulla bókunarferlið þitt
```

---

## Hvað þú þarft að gera

<Steps>

1. **Búðu til GA4 eign**

   Farðu á [analytics.google.com](https://analytics.google.com): Stjórnandi → Búa til eign. Stilltu tímabelti og gjaldmiðil til að passa við markaðinn þinn.

2. **Búðu til vefstraum gagna**

   Stjórnandi → Gagnastraumar → Bæta við straumi → Vefur. Sláðu inn `wink.travel` sem vefslóð. Þetta býr til þitt **Measurement ID** (`G-XXXXXXXXXX`). Afritaðu það.

3. **Búðu til Measurement Protocol API leyndarmál**

   Opnaðu sama vefstraum → flettu niður að **Measurement Protocol API secrets** → **Búa til**. Gefðu því viðurnefni (t.d. "Wink") og afritaðu myndaða **leyndarmálsgildið**. Þetta leyndarmál leyfir Wink að skrá fullgerðar bókanir á þjóninum, svo sala glatist aldrei við greiðsluvísun.

4. **Sláðu inn Measurement ID og API leyndarmálið í Wink vefinn**

   Skráðu þig inn á [app.wink.travel](https://app.wink.travel), veldu reikninginn þinn og farðu í **Sérsnið** flipann. Límdu Measurement ID og API leyndarmálið í **GA4** reitina og vistaðu. Það er allt — GA4 samþættingin þín er virk.

   <Aside type="note">
   API leyndarmálið er **aðeins til að skrifa**: þegar það er vistað er það aldrei sýnt aftur. Við framtíðarbreytingar skaltu skilja leyndarmálsreitinn auðan til að halda gildinu sem þú vistaðir.
   </Aside>

5. **Merkja `purchase` sem lykilatburð**

   Til baka í GA4 eigninni þinni: Stjórnandi → Atburðir → finndu `purchase` → kveiktu á **Merkja sem lykilatburð**. Þetta gerir fullgerðar bókanir sýnilegar í skýrslu um umbreytingar.

6. **Skoðaðu gögnin þín**

   Skráðu þig inn á [analytics.google.com](https://analytics.google.com) og þú munt sjá bókanir, tekjur og ferðalag gesta — allt sjálfvirkt fylgst með í gegnum Wink.

</Steps>

<Aside type="note">
Þú þarft ekki að setja upp neinn rekstrarkóða á þínum eigin vef fyrir þessa samþættingu. Wink sér um allt. Measurement ID þitt er áfangastaðurinn þar sem bókunargögnin þín eru send, og API leyndarmálið leyfir Wink að staðfesta fullgerðar bókanir á þjóninum.
</Aside>

<Aside type="tip">
**GA4 og GTM má nota saman.** Ef þú keyrir einnig Google Tag Manager gáminn (t.d. Sojern gáminn), getur þú stillt bæði samtímis — þau eru ekki lengur útilokuð hvort annað. Sjá [GTM Analytics Integration](/is/guides/developers/gtm-dual-tagging).
</Aside>

## Hvað þú getur fylgst með

Þegar tengt er fær GA4 eign þín fulla röð af Enhanced E-commerce atburðum fyrir eign þína:

### Uppgötvun

| Atburður | Hvað það þýðir |
|---|---|
| `view_item_list` | Gestur sá eign þína í leit eða flokkaskrá |
| `select_item` | Gestur smellti á eign þína úr skrá |
| `view_item` | Gestur skoðaði hóteldetaljasíðu þína |

### Íhugun

| Atburður | Hvað það þýðir |
|---|---|
| `view_promotion` | Gestur sá kynningartilboð fyrir eign þína |
| `select_promotion` | Gestur smellti á kynningartilboð |
| `add_to_wishlist` | Gestur vistaði eign þína á óskalista sinn |

### Bókunarferli

| Atburður | Hvað það þýðir |
|---|---|
| `add_to_cart` | Gestur valdi herbergi eða pakka |
| `view_cart` | Gestur skoðaði bókunaryfirlit sitt |
| `remove_from_cart` | Gestur fjarlægði herbergi eða pakka |
| `begin_checkout` | Gestur hóf greiðsluferlið |
| `add_payment_info` | Gestur sló inn greiðsluupplýsingar sínar |
| `add_shipping_info` | Gestur sló inn upplýsingar um gestinn |
| `purchase` | Gestur kláraði bókun |
| `refund` | Bókun var felld niður og endurgreidd |

Allir atburðir innihalda viðeigandi víddir eins og tekjur, gjaldmiðil, herbergistegund og bókunargildi — sem gefur þér fulla mynd af ferðalagi gesta frá fyrstu sýn til fullgertrar bókunar. Til að opna fleiri eignar- og herbergisvíddir eins og `city_name`, `cancellation_policy`, `bed_type` og fleira, sjá [Sérsniðnar víddir í GA4](/is/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4).

## Þversvæðis rekstur (Ítarlegt)

Venjuleg samþætting hér að ofan fylgist með öllu sem gerist innan Wink. En ef þú vilt fylgjast með gestum alla leið frá þínum eigin vef og til bókunar á Wink — og réttilega rekja upprunalegan umferðarkost (Google Ads, tölvupóstherferðir, lífræna leit o.s.frv.) — þarf eitt auka skref á hvorri hlið.

<Aside type="caution">
Þessi kafli á aðeins við ef þú ert með GA4 uppsett á þínum eigin vef. Ef þú keyrir ekki GA4 á síðunni þinni, þá er venjuleg samþætting hér að ofan allt sem þú þarft.
</Aside>

### Af hverju þetta skiptir máli

Án þversvæðis reksturs mun gestur sem heimsækir vefinn þinn fyrst og bókar svo á Wink birtast í GA4 sem **Bein** lota án tengingar við fyrri heimsókn. Allar Google Ads smellur, tölvupóstherferðir eða lífrænar leitir sem leiddu til bókunar fá enga viðurkenningu.

Með þversvæðis rekstri stilltum sérðu fulla ferðalag gesta:

```
google.com (greidd auglýsing)
       ↓
vefur þinn (gestur skoðar herbergi)
       ↓
wink.travel (gestur velur herbergi og bókar)
       ↓
kaup réttilega rakin til upprunalegu Google Ads smellunnar
```

### Aðgerð krafist: Þú

Stilltu GA4 eign þína til að þekkja `wink.travel` sem hluta af þínu eigin léni, ekki sem ytri tilvísun. Þetta segir GA4 að sauma saman tvær lotur í eina samfellu ferðalag gesta.

<Steps>
1. GA4 Stjórnandi → Gagnastraumar → þinn straumur
2. Stilltu merkjastillingar → **Stilltu lénið þitt**
3. Bættu við `wink.travel` sem tengdu léni
4. Vistaðu
</Steps>

### Aðgerð krafist: Wink

Hafðu samband við [Wink Support](https://app.wink.travel) og gefðu upp lénið á vefnum þínum (t.d. `yourhotel.com`). Wink bætir léni þínu við lista yfir tilvísunareyðingu í Wink GA4 eigninni. Þetta kemur í veg fyrir að vefurinn þinn sé skráður sem tilvísun, sem annars myndi skrifa yfir upprunalega tilvísun gesta og hefja nýja lotu.

<Aside type="tip">
Venjuleg samþætting hér að ofan dugar fyrir flestar eignir og gefur þér strax yfirsýn yfir bókanir og tekjur á Wink. Þversvæðis rekstur er ítarleg valkostur sem er þess virði að setja upp þegar þú ert öruggur með GA4 gögnin þín og vilt dýpri innsýn í tilvísanir.
</Aside>
