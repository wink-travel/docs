Wink **Partner API** er auðkennd, háhraða leið fyrir samþættara til að sækja bókanlegt ferðaframboð — sama framboð og knýr innbyggð viðmót og opinberar leitaraðgerðir, sem er aðgengilegt sem fyrsta flokks forritunarviðmót. Þar sem ókeypis Web Components og opinberar leitaraðgerðir eru ætlaðar léttum, mannlegum innbyggingum, er Partner API byggt fyrir kerfi sem leita, verðleggja og bóka í stórum stíl. Aðgangur er auðkenndur fyrir hvern samþættara og gjaldfærður eftir notkun, svo þú greiðir aðeins fyrir þann umferð sem þú sendir raunverulega.

## Áætlanir & verðlagning

Notkun er mæld í **hótelnóttum**: eitt hótel verðlagt fyrir eina nótt — *ekki* eitt API kall. Leit sem skilar 20 hótelum fyrir 3 nætur er 60 hótelnætur úr einni beiðni. Efni- og Leitarkall (áfangastaðaleit og sjálfvirk útfylling) eru undantekningar: hvert kostar eina einingu per kall, sama hvað það skilar. Reikningsendapunktar eru ókeypis. [Verðlagning](/is/pricing/) er heimild fyrir verðinu.

| | Ókeypis | Greitt | Fyrirtæki |
|---|---|---|---|
| **Verð** | 0 $ | Notkunarmiðað | Hafðu samband |
| **Best fyrir** | Mat & lágt magn samþættinga | Greiðsla eftir notkun í stórum stíl | Sérsniðið magn & samningsskilmálar |
| Einingar á mánuði | 10.000 | Ótakmarkað | Ótakmarkað |
| API svarstími (P95) | — | Undir 500 ms | Undir 500 ms |
| Verð per einingu (hótelnótt) | Ókeypis | 0,0001 $ | Sérsniðið |
| Svörun við mánaðarmörkum | 429 þar til 1. dag næsta mánaðar (UTC) | Gjaldtaka, ekki hindrun | Samkvæmt samningi |
| Þjónustustigssamningur | — | ✓ | ✓ |
| Forgangsþjónusta | — | ✓ | ✓ |

## API tilvísun

Tvö viðmót þjóna bókanlegu framboði og þau samsvara tveimur stigum hér að ofan:

- **Ókeypis — Consumer / Booking Engine API** (REST, `/api/public/**`): nafnlaust, fyrir vafra og viðmót. [Skoða Booking Engine tilvísun →](/is/api/booking-engine/)
- **Greitt — Partner Integrator API** (**gRPC**, `wink.partner.v1`): auðkennt, notkunarmælt, byggt fyrir þjónustu-til-þjónustu samþættingu í stórum stíl. [Skoða Integrator tilvísun →](/is/partner-api/partner/)

Partner Integrator API er gRPC, ekki REST. Þú kallar á það með framleiddum viðskiptavini yfir HTTP/2 á
`partner.wink.travel:443`, með berarauðkenni og reikningi sem þú ert að kalla fyrir:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

Tilvísunarsíðan hér að ofan skráir alla þjónustu, skilaboð og villustöðu, og skemað er einnig
aðgengilegt í keyrslutíma í gegnum þjónustuglugga, svo `grpcurl`, Postman og Insomnia finna það án niðurhals.

Ef þú vilt frekar búa til viðskiptavin fyrirfram, eru `.proto` upprunaskrár birtar á
[github.com/wink-travel/partner-api-proto](https://github.com/wink-travel/partner-api-proto).

## Hvernig notkun og takmarkanir virka

### Ókeypis stig

Ókeypis stigið er hannað til að leyfa þér að byggja, prófa og reka hóflega framleiðsluumferð án kostnaðar.

- **Engin birt takmörkun á mínútu.** Wink fylgist með beiðnahlutföllum og getur beitt sanngjörnum notkunartakmörkunum til að vernda þjónustuna. Ef þú færð **HTTP 429 (Of margar beiðnir)**, bíddu í þann tíma sem stendur í `Retry-After` hausnum áður en þú reynir aftur.
- **Mánaðarmörk — 10.000 einingar á mánuði.** Mörkin eru veitt fyrir hvern reikning og endurstilla á 1. degi hvers mánaðar (UTC). Þegar þú nærð þeim fær reikningur sem ekki er skráður í greiðslu eftir notkun **HTTP 429 þar til 1. dag næsta mánaðar** — harður stöðvunarpunktur með `Retry-After` haus og skilaboðum sem hvetja þig til að gerast áskrifandi að Greiddu stiginu. Skráður reikningur heldur áfram að virka og er gjaldfærður fyrir notkun umfram mörk.

Ókeypis stigið inniheldur ekki þjónustustigssamning né forgangsþjónustu.

### Greitt stig

Greidda stigið fjarlægir mánaðarmörk og þú greiðir aðeins fyrir það sem þú notar.

- **Mældar hótelnætur — 0,0001 $ per hótelnótt.** Engin mánaðarmörk; þú ert gjaldfærður eftir raunverulegu magni. Wink getur samt beitt sanngjörnum notkunartakmörkunum til að vernda þjónustuna. Leit- og framboðskall gjaldfærast per verðlagðri hótelnótt; Efni- og Leitarkall gjaldfærast sem ein eining hvert, svo hópun beiðna heldur kostnaði niðri.

Greidda stigið inniheldur þjónustustigssamninginn hér að neðan — 99,9% uppetutryggingu og P95 svarstímatakmark undir 500 ms — og forgangsþjónustu eftir alvarleika.

## Þjónustustigssamningur

_Gildistími: 5. júlí 2026 · Útgáfa 1.0_

Þessi þjónustustigssamningur (SLA) setur fram skuldbindingu um aðgengi, þjónustukredita og stuðningsmarkmið sem Wink ("Wink", "við", "okkur") veitir viðskiptavini ("Viðskiptavinur", "þú") fyrir auðkennda Wink Partner API (”Partner API” eða ”Þjónusta”) á þeim stigum þar sem SLA gildir. Þessi SLA er hluti af og stjórnað af samningi milli þín og Wink sem veitir þér aðgang að Partner API (”Samningurinn”) og gildir svo lengi sem þú ert með virka, greidda áskrift að Partner API í góðu standi. Skilgreind hugtök sem ekki eru útskýrð hér hafa merkingu samkvæmt Samningnum.

### 1. Skilgreiningar

1. **„Uppetími“** merkir tímabil þegar Partner API er tiltækt til að taka við og svara með árangri réttmætum, auðkenndum beiðnum.
2. **„Niðurtími“** merkir tímabil, mælt í mínútum, þegar Partner API bregst ekki við réttmætum, auðkenndum beiðnum, að undanskildum tímabilum sem falla undir undantekningar í kafla 4. Einangraðar villur sem hafa áhrif á óverulegan hluta beiðna teljast ekki sem niðurtími.
3. **„Mánaðarlegur uppetímaprósenta“** merkir fyrir tiltekinn kalendurmánuð heildarfjölda mínútna í mánuðinum að frádregnum niðurtímamínútum, deilt með heildarfjölda mínútna í mánuðinum, tjáð sem prósenta.
4. **„Áætluð viðhald“** merkir fyrirfram skipulagt viðhald þjónustunnar sem Wink hefur tilkynnt í samræmi við kafla 4.
5. **„Þjónustukredit“** merkir kredit, reiknað sem prósenta af gjöldum sem þú hefur greitt eða átt eftir að greiða fyrir Partner API í viðkomandi kalendurmánuði, sem er dregið frá framtíðar gjöldum fyrir Partner API sem eina og sérstöku úrræði vegna vanefnda á uppetímaskuldbindingu.
6. **„Svarstími“** merkir liðinn tími frá því að Wink móttekur réttmætar, auðkenndar beiðnir við þjónustumörk Wink þar til Wink byrjar að senda svar, að undanskildum netflutningi og tíma hjá viðskiptavini utan stjórnunar Wink.

### 2. Aðgengi & frammistöðuskuldbinding

Wink mun leggja fram viðskiptalega sanngjarnar viðleitni til að gera Partner API tiltækt með **mánaðarlegum uppetímaprósentu að minnsta kosti 99,9%** á hverjum kalendurmánuði (”Uppetímaskuldbinding”). Uppetímaskuldbindingin er mæld við þjónustumörk Wink og útilokar þætti utan sanngjarnrar stjórnunar Wink, þar með talda þá sem lýst er í kafla 4. Eftirlitskerfi Wink eru heimild fyrir mælingu mánaðarlegrar uppetímaprósentu og svarstíma.

Wink stefnir einnig að **95. prósentíl (P95) svarstíma undir 500 millisekúndum** fyrir árangursríkar, réttmætar, auðkenndar beiðnir, mælt við þjónustumörk Wink yfir hvern kalendurmánuð (”Frammistöðumarkmið”). Frammistöðumarkmiðið útilokar þætti í kafla 4, beiðnir sem skila forritastigs villum vegna beiðninnar sjálfrar, og óvenjulega stórar eða flóknar hópbeiðnir. Frammistöðumarkmiðið er þjónustuviðmið; þjónustukredit í kafla 3 gilda um vanefndir á **Uppetímaskuldbindingu** og eru eina og sérstöku úrræði vegna aðgengisbilana.

### 3. Þjónustukredit

Ef mánaðarleg uppetímaprósenta fellur undir uppetímaskuldbindingu í einhverjum kalendurmánuði gætir þú átt rétt á þjónustukrediti reiknuðum sem prósentu af Partner API gjöldum sem þú hefur greitt eða átt eftir að greiða fyrir þann mánuð, samkvæmt eftirfarandi stigveldi:

| Mánaðarleg uppetímaprósenta | Þjónustukredit |
|---|---|
| Undir 99,9% en 99,0% eða hærra | 10% |
| Undir 99,0% en 95,0% eða hærra | 25% |
| Undir 95,0% | 50% |

1. **Krafa um kredit.** Til að fá þjónustukredit verður þú að senda skriflega kröfu til Wink innan **þrjátíu (30) daga** frá lokum kalendurmánaðarins þar sem bilun átti sér stað. Krafa skal innihalda dagsetningar og tíma hvers niðurtímatilfellis sem þú krefst og öll tiltæk gögn eða rökstuðning. Kröfur sem berast eftir þennan tíma eru ekki gjaldgengar.
2. **Form kredit.** Samþykkt þjónustukredit eru dregin frá framtíðar Partner API gjöldum og hafa enga reiðufjárvirði. Þau eru ekki endurgreiðslur og verða ekki greidd út nema lög krefjist þess.
3. **Hámarks kredit.** Heildarþjónustukredit fyrir hvern kalendurmánuð mun ekki fara yfir 50% af Partner API gjöldum sem þú hefur greitt eða átt eftir að greiða fyrir þann mánuð.
4. **Eina og sérstöku úrræði.** Þjónustukredit eru þitt **eina og sérstöku úrræði** vegna vanefnda Wink á uppetímaskuldbindingu eða annarra aðgengisbilana Partner API.

### 4. Undantekningar

Uppetímaskuldbinding og þjónustukredit gilda ekki og niðurtími felur ekki í sér neina óaðgengi, stöðvun, skerðingu eða frammistöðuvandamál sem stafa af eða tengjast:

1. **Áætluðu viðhaldi** sem Wink hefur tilkynnt fyrirfram, að því gefnu að tilkynning hafi verið gefin með hæfilegum fyrirvara í gegnum venjulegan samskiptamáta Wink við viðskiptavini;
2. **Force majeure** atburðum eða öðrum orsökum utan sanngjarrar stjórnunar Wink, þar með talin náttúruhamfarir, stjórnvöld, net- eða rafmagnsbilun, og þjónustuneyðarárásir eða aðrar illgjarnar árásir;
3. vandamálum sem stafa af **þínum** aðgerðum eða vanrækslu, búnaði, hugbúnaði eða neti, eða þjónustu, vöru eða veitanda þriðja aðila sem er ekki undir beinni stjórn Wink;
4. þinni **misnotkun þjónustunnar** eða **brot á samningi**, þessum SLA, notkunarskilmálum eða gildandi takmörkunum, þar með talið umferð sem Wink metur sem of mikla, sjálfvirka misnotkun eða sviksemi; og
5. öllum **stöðvunum eða lokunum** aðgangs þíns sem eru réttilega framkvæmdar samkvæmt samningi, þar með talið stöðvun vegna greiðslumissis.

### 5. Stuðningur & svarmarkmið

Wink veitir stuðning fyrir Partner API á venjulegum opnunartíma, að undanskildum staðbundnum frídögum. Wink mun leggja fram viðskiptalega sanngjarna viðleitni til að staðfesta réttilega sendar stuðningsbeiðnir innan eftirfarandi svarmarkmiða, byggt á alvarleika sem þú gefur og Wink staðfestir sanngjarnt:

| Alvarleiki | Lýsing | Markmið um fyrstu svörun |
|---|---|---|
| **Alvarleiki 1 — Brýnt** | Partner API er niðri eða óvirkt í framleiðslu án lausnar. | 4 klukkustundir |
| **Alvarleiki 2 — Mikilvægt** | Mikilvæg virkni skerðist eða er skert; lausn er til staðar. | 1 virkur dagur |
| **Alvarleiki 3 — Minni háttar** | Almennar spurningar, minni vandamál eða óskir um virkni. | 2 virkir dagar |

Svarmarkmið lýsa hvenær Wink stefnir að gera **fyrstu tengingu**; þau eru ekki ábyrgð á lausnartíma. Forgangsþjónusta og alvarleikamiðuð markmið gilda á þeim stigum þar sem þau eru tilgreind.

### 6. Gögn & öryggi

Wink viðheldur viðskiptalega sanngjörnum stjórnunaraðgerðum, tæknilegum og skipulagslegum aðgerðum til að vernda trúnað, heilleika og aðgengi gagna sem unnin eru í gegnum Partner API og endurskoðar þær reglulega. Meðferð persónuupplýsinga hjá Wink er stjórnað af [Persónuverndarstefnu](/is/privacy) og öllum gagnavinnsluskilmálum í samningi. Þú berð ábyrgð á að tryggja þín eigin API auðkenni, lögmætri notkun gagna sem þú sækir og að tilkynna Wink tafarlaust um grun um misnotkun auðkenna.

### 7. Takmörkun ábyrgðar

Þjónustukredit eru **eina og sérstöku úrræði** vegna óaðgengis eða vanefnda á uppetímaskuldbindingu og eru veitt í stað annarrar ábyrgðar vegna slíkrar vanefndar. Fyrir utan það sem sérstaklega er tekið fram í SLA, er Partner API veitt „eins og hún er“. Að því marki sem lög leyfa, er heildarábyrgð Wink vegna þjónustunnar takmörkuð eins og kveðið er á um í samningi, og Wink ber ekki ábyrgð á óbeinum, tilviljanakenndum, sérstökum, afleiðingum eða refsiviðurlögum, né tapi á hagnaði, tekjum, gögnum eða góðu orðspori, jafnvel þótt það hafi verið tilkynnt um möguleika á slíkum skaða.

### 8. Gildistími, breytingar & uppsögn

Þessi SLA gildir svo lengi sem þú ert með virka Partner API áskrift á stigi þar sem SLA gildir. Wink getur uppfært SLA reglulega; verulegar breytingar verða tilkynntar í gegnum venjulegan samskiptamáta Wink við viðskiptavini, og áframhaldandi notkun Partner API eftir gildistöku uppfærslu telst samþykki á uppfærðu SLA. SLA rennur sjálfkrafa út við uppsögn eða lok samnings eða áskriftar þinnar að Partner API. Greinar sem eðlislægt eiga að lifa áfram eftir uppsögn — þar með taldar réttindi til þjónustukredita, takmörkun ábyrgðar og skilgreiningar — lifa áfram.
