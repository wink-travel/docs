Wink **Partner API** er auðkennd, hraðvirkari leið fyrir samþættara til að sækja bókanlegt ferðaframboð — sama framboð og knýr innbyggðu búnaðina okkar og opinbera vafraendapunkta, sem er aðgengilegt sem fyrsta flokks forritunarviðmót. Þar sem ókeypis Web Components og opinberir vafraendapunktar eru ætlaðir til létts, mannlegs innbyggingar, er Partner API byggt fyrir kerfi sem leita, verðleggja og bóka í stórum stíl. Aðgangur er auðkenndur fyrir hvern samþættara og gjaldfærður eftir notkun, svo þú greiðir aðeins fyrir þann umferð sem þú sendir raunverulega.

## Áætlanir & verðlagning

Ein API-fyrirspurn = ein beiðni. Mæld notkun er gjaldfærð á hverjar 1.000 beiðnir.

| | Ókeypis | Greidd | Fyrirtæki |
|---|---|---|---|
| **Verð** | 0 $ | Notkunartengd | Hafðu samband |
| **Best fyrir** | Mat og samþættingar með litla umferð | Greiðsla eftir notkun í stórum stíl | Sérsniðin magn og samningsskilmálar |
| Fyrirspurnir á mínútu | 30 (60 skyndibylgja) | Ótakmarkað | Ótakmarkað |
| Fyrirspurnir á mánuði | 10.000 | Ótakmarkað | Ótakmarkað |
| Svartími API (P95) | — | Undir 500 ms | Undir 500 ms |
| Verð á hverjar 1.000 fyrirspurnir | Ókeypis | 1,00 $ | Sérsniðið |

## API tilvísun

Tveir fletir þjónusta bókanlegt framboð, og þeir samsvara tveimur stigum hér að ofan:

- **Ókeypis — Consumer / Booking Engine API** (REST, `/api/public/**`): nafnlaus, fyrir vafra og búnað. [Skoðaðu Booking Engine tilvísun →](/is/api/booking-engine/)
- **Greidd — Partner Integrator API** (**gRPC**, `wink.partner.v1`): auðkennd, notkunarmæld, byggð fyrir þjónustu-til-þjónustu samþættingu í stórum stíl. [Skoðaðu Integrator tilvísun →](/is/partner-api/partner/)

Partner Integrator API er gRPC, ekki REST. Þú kallar á það með útbúnum viðskiptavini yfir HTTP/2 á
`partner.wink.travel:443`, með burðarlykli og reikningi sem þú ert að kalla fyrir:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

Tilvísunarsíðan hér að ofan skráir alla þjónustu, skilaboð og villustöðu, og skemað er einnig
aðgengilegt í keyrslutíma í gegnum þjónustuglugga, svo `grpcurl`, Postman og Insomnia finna það án þess að þurfa að hlaða niður neinu.

## Hvernig notkun og takmörk virka

### Ókeypis stig

Ókeypis stigið er hannað til að leyfa þér að byggja, prófa og reka hóflega framleiðsluumferð án kostnaðar.

- **Takmörkun hraða — 30 fyrirspurnir á mínútu, með 60-fyrirspurna skyndibylgju.** Stuttar toppar yfir viðvarandi hraða eru teknar af skyndibylgjunni. Ef þú fer yfir hana svarar API með **HTTP 429 (Of margar fyrirspurnir)** og beitir **5 mínútna hléi** áður en lykillinn þinn heldur áfram að þjóna umferð. Taktu hlé og reyndu aftur eftir hléið frekar en að áreita endapunktinn.
- **Mánaðarkvóti — 10.000 fyrirspurnir á mánuði.** Þegar þú nærð mánaðarmörkum skilar API **HTTP 429 fyrir restina af mánuðinum** — harður stöðvunarhnappur — ásamt skilaboðum sem hvetja þig til að gerast áskrifandi að Greidda stiginu til að halda áfram. Teljarinn endurstillist í byrjun næsta mánaðar.

Ókeypis stigið inniheldur ekki þjónustustigssamning né forgangsþjónustu.

### Greitt stig

Greidda stigið fjarlægir mánaðarmörkin og hlé á hraðatakmörkunum, og þú greiðir aðeins fyrir það sem þú notar.

- **Mældar fyrirspurnir — 1,00 $ á hverjar 1.000 fyrirspurnir.** Engin mánaðarmörk eru og engin hraðatakmörkun við eðlilega notkun; þú ert gjaldfærður eftir raunverulegu magni.
- **Yfirnotkun á hlutfalli leit að bókun — 2,00 $ á hverjar 1.000 umfram leitir.** Til að halda framboði heilbrigðu mælum við hlutfall leitanna ("leitir") miðað við staðfestar bókanir. Þú átt rétt á **5.000 leitir á bókun** áður en yfirnotkun tekur gildi. Umfram leitir eru reiknaðar sem:

  `umfram = max(0, leitir − bókanir × 5.000)`

  Yfirnotkun er svo gjaldfærð á **2,00 $ á hverjar 1.000 umfram leitir**. Samþættingar sem skila góðum viðskiptum þurfa sjaldan að greiða yfirnotkun; gjaldið á aðeins við um umferð sem leitar mun meira en hún bókar.

Greidda stigið inniheldur þjónustustigssamninginn sem lýst er hér að neðan — 99,9% uppetutryggingu og P95 svartíma markmið undir 500 ms — og forgangs- og alvarleikamiðaða þjónustu.

## Þjónustustigssamningur

_Gildistími: 5. júlí 2026 · Útgáfa 1.0_

Þessi þjónustustigssamningur (SLA) setur fram skuldbindingu um aðgengi, þjónustukredita og stuðningsmarkmið sem Wink ("Wink", "við", "okkur") veitir viðskiptavini ("Viðskiptavinur", "þú") fyrir auðkennda Wink Partner API (”Partner API” eða ”Þjónusta”) á þeim stigum þar sem SLA gildir. Þessi SLA er hluti af og stjórnað af samningi milli þín og Wink sem veitir þér aðgang að Partner API (”Samningurinn”) og gildir svo lengi sem þú ert með virka, greidda áskrift að Partner API í góðu standi. Skilgreind hugtök sem ekki eru útskýrð hér hafa þau merkingu sem gefin er í Samningnum.

### 1. Skilgreiningar

1. **„Uppetími“** merkir tímabil þar sem Partner API er tiltækt til að taka við og svara með góðum árangri réttmætum, auðkenndum fyrirspurnum.
2. **„Niðurtími“** merkir hvaða tímabil, mælt í mínútum, þar sem Partner API bregst ekki með góðum árangri við réttmætum, auðkenndum fyrirspurnum, að undanskildum tímabilum sem falla undir undanþágur í kafla 4. Einangraðar villur sem hafa áhrif á óverulegan hluta fyrirspurna teljast ekki sem niðurtími.
3. **„Mánaðarlegur uppetímaprósenta“** merkir, fyrir tiltekinn mánuð, heildarfjölda mínútna í þeim mánuði að frádregnum niðurtímamínútum, deilt með heildarfjölda mínútna í mánuðinum, tjáð sem prósenta.
4. **„Áætluð viðhaldsvinna“** merkir fyrirfram skipulagða viðhaldsvinnu á Þjónustunni sem Wink hefur tilkynnt fyrirfram í samræmi við kafla 4.
5. **„Þjónustukredit“** merkir kredit, reiknað sem prósenta af gjöldum sem þú hefur greitt eða átt eftir að greiða fyrir Partner API í viðkomandi mánuði, sem er dregið frá framtíðar gjöldum fyrir Partner API sem eina og sérstöku úrræði vegna vanefnda á uppetímaskuldbindingu.
6. **„Svartími“** merkir þann tíma sem líður frá því að Wink fær réttmæt, auðkennd fyrirspurn við þjónustumörk Wink þar til Wink byrjar að senda svar, að undanskildum netflutningi og tíma hjá viðskiptavini utan stjórnunar Wink.

### 2. Aðgengi & frammistöðuskuldbinding

Wink mun leggja sig fram við að gera Partner API tiltækt með **mánaðarlegum uppetímaprósentu að minnsta kosti 99,9%** á hverjum mánuði (”Uppetímaskuldbinding”). Uppetímaskuldbindingin er mæld við þjónustumörk Wink og undanskilur þætti utan sanngjarnrar stjórnunar Wink, þar með talda þá sem lýst er í kafla 4. Eftirlitskerfi Wink eru heimildarheimildin fyrir mælingu á mánaðarlegri uppetímaprósentu og svartíma.

Wink stefnir einnig að **95. prósentíl (P95) svartíma undir 500 millisekúndum** fyrir árangursríkar, réttmætar, auðkenndar fyrirspurnir, mælt við þjónustumörk Wink yfir hvern mánuð (”Frammistöðumarkmið”). Frammistöðumarkmiðið undanskilur þætti í kafla 4, fyrirspurnir sem skila villum á forritastigi vegna fyrirspurnarinnar sjálfrar, og óvenjulega stórar eða flóknar hópfyrirspurnir. Frammistöðumarkmiðið er þjónustuviðmið; Þjónustukredit í kafla 3 gilda um vanefndir á **Uppetímaskuldbindingu** og eru eina og sérstöku úrræði vegna aðgengisbilana.

### 3. Þjónustukredit

Ef mánaðarleg uppetímaprósenta fellur undir uppetímaskuldbindingu í einhverjum mánuði gætir þú átt rétt á þjónustukrediti reiknuðum sem prósentu af gjöldum fyrir Partner API sem þú hefur greitt eða átt eftir að greiða fyrir þann mánuð, samkvæmt eftirfarandi stigveldi:

| Mánaðarleg uppetímaprósenta | Þjónustukredit |
|---|---|
| Undir 99,9% en að minnsta kosti 99,0% | 10% |
| Undir 99,0% en að minnsta kosti 95,0% | 25% |
| Undir 95,0% | 50% |

1. **Krafa um kredit.** Til að fá þjónustukredit verður þú að senda skriflega kröfu til Wink innan **þrjátíu (30) daga** frá lokum mánaðarins þar sem bilun átti sér stað. Krafa þarf að innihalda dagsetningar og tíma hvers niðurtímatilfellis sem þú krefst fyrir og öll tiltæk gögn eða rökstuðning. Kröfur sem berast eftir þennan tíma eru ekki gjaldgengar.
2. **Form kredit.** Samþykkt þjónustukredit eru dregin frá framtíðar gjöldum fyrir Partner API og hafa enga reiðufjárvirði. Þau eru ekki endurgreiðslur og verða ekki greidd út nema lög krefjist þess.
3. **Hámarks kredit.** Heildarupphæð þjónustukredita fyrir hvern mánuð fer ekki yfir 50% af gjöldum fyrir Partner API sem þú hefur greitt eða átt eftir að greiða fyrir þann mánuð.
4. **Eina og sérstöku úrræði.** Þjónustukredit eru þitt **eina og sérstöku úrræði** vegna vanefnda Wink á uppetímaskuldbindingu eða annarri aðgengisbilun Partner API.

### 4. Undanþágur

Uppetímaskuldbinding og þjónustukredit gilda ekki og niðurtími felur ekki í sér neina óaðgengi, stöðvun, skerðingu eða frammistöðuvandamál sem stafa af eða tengjast:

1. **Áætluðu viðhaldi** sem Wink hefur tilkynnt fyrirfram, að því gefnu að tilkynning hafi verið gefin með hæfilegum fyrirvara í gegnum þann miðil sem Wink notar venjulega til að hafa samband við viðskiptavini;
2. **Force majeure** atburðum eða öðrum orsökum utan sanngjarrar stjórnunar Wink, þar með talin náttúruhamfarir, stjórnvöld, net- eða rafmagnsbilun, og þjónustuneyð eða aðrar illgjarnar árásir;
3. vandamálum sem stafa af **aðgerðum eða vanrækslu þinni**, búnaði, hugbúnaði eða neti, eða þjónustu, vöru eða veitanda þriðja aðila sem ekki er undir beinni stjórn Wink;
4. misnotkun þinni á Þjónustunni eða brotum á Samningnum, þessum SLA, notkunarskilmálum eða gildandi hraðatakmörkunum, þar með talin umferð sem Wink telur óhóflega, sjálfvirka misnotkun eða sviksemi; og
5. öllum **stöðvunum eða lokunum** á aðgangi þínum sem eru réttilega framkvæmdar samkvæmt Samningnum, þar með talin stöðvun vegna greiðslumissis.

### 5. Stuðningur & svarmarkmið

Wink veitir stuðning fyrir Partner API á venjulegum opnunartíma, að undanskildum opinberum frídögum. Wink mun leggja sig fram við að staðfesta réttilega sendar stuðningsbeiðnir innan eftirfarandi svarmarkmiða, byggt á alvarleika sem þú gefur og Wink staðfestir með sanngjörnum hætti:

| Alvarleiki | Lýsing | Markmið um fyrstu svörun |
|---|---|---|
| **Alvarleiki 1 — Brýnt** | Partner API er niðri eða ónothæft í framleiðslu án lausnar. | 4 klukkustundir |
| **Alvarleiki 2 — Mikilvægt** | Mikilvæg virkni skert eða skemmd; lausn er til staðar. | 1 virkur dagur |
| **Alvarleiki 3 — Minniháttar** | Almennar spurningar, smávægileg vandamál eða óskir um virkni. | 2 virkir dagar |

Svarmarkmiðin lýsa því hvenær Wink stefnir að því að hafa **fyrstu samskipti**; þau eru ekki ábyrgð á lausnartíma. Forgangsþjónusta og alvarleikamiðuð markmið gilda á þeim stigum þar sem þau eru tilgreind.

### 6. Gögn & öryggi

Wink viðheldur viðunandi stjórnunar-, tæknilegum og skipulagslegum aðgerðum til að vernda trúnað, heilleika og aðgengi gagna sem unnin eru í gegnum Partner API, og endurskoðar þessar aðgerðir reglulega. Meðferð persónuupplýsinga hjá Wink er stjórnað af [Persónuverndarstefnu](/is/privacy) og öllum gagnavinnsluskilmálum í Samningnum. Þú berð ábyrgð á að tryggja þín eigin API-auðkenni, lögmætri notkun gagna sem þú sækir og að tilkynna Wink tafarlaust um grun um misnotkun auðkenna.

### 7. Takmörkun ábyrgðar

Þjónustukredit eru **eina og sérstöku úrræði** vegna óaðgengis eða vanefnda á uppetímaskuldbindingu, og eru veitt í stað annarrar ábyrgðar vegna slíkrar vanefndar. Fyrir utan það sem sérstaklega er tekið fram í SLA, er Partner API veitt „eins og hún er“. Í mesta leyfi samkvæmt gildandi lögum er heildarábyrgð Wink vegna Þjónustunnar takmörkuð eins og kveðið er á um í Samningnum, og Wink ber ekki ábyrgð á óbeinum, tilviljanakenndum, sérstökum, afleiðingum eða refsiviðurlögum, né tapi á hagnaði, tekjum, gögnum eða góðu orðspori, jafnvel þótt það hafi verið upplýst um möguleika á slíkum skaða.

### 8. Gildistími, breytingar & uppsögn

Þessi SLA gildir svo lengi sem þú ert með virka Partner API áskrift á stigi þar sem SLA gildir. Wink getur uppfært SLA reglulega; verulegar breytingar verða tilkynntar í gegnum þann miðil sem Wink notar venjulega til að ná til viðskiptavina, og áframhaldandi notkun Partner API eftir gildistöku uppfærslu telst samþykki á uppfærðu SLA. Þessi SLA rennur sjálfkrafa út við uppsögn eða lok Samnings eða áskriftar þinnar að Partner API. Greinar sem eðlislægt er að þær haldi gildi eftir uppsögn — þar með taldar réttindi til þjónustukredita, takmörkun ábyrgðar og skilgreiningar — haldast í gildi.
