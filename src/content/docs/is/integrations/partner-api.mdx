Wink **Partner API** er auðkennd, hraðvirkari leið fyrir samþættara til að spyrja bókanlega ferðavöru — sama framboð og knýr innbyggð viðmót og opinberar skoðunarendapunkta, sem er aðgengilegt sem fyrsta flokks forritunarviðmót. Þar sem ókeypis Web Components og opinberir skoðunarendapunktar eru ætlaðir fyrir létta, mannlegu notendaviðmót, er Partner API byggt fyrir kerfi sem leita, verðleggja og bóka í stórum stíl. Aðgangur er auðkenndur fyrir hvern samþættara og gjaldfærður eftir notkun, svo þú greiðir aðeins fyrir þann umferð sem þú sendir raunverulega.

## Áætlanir & verðlagning

Ein API-fyrirspurn = ein beiðni. Mæld notkun er gjaldfærð á hverjar 1.000 beiðnir.

| | Ókeypis | Greidd | Fyrirtæki |
|---|---|---|---|
| **Verð** | 0 $ | Notkunartengd | Hafðu samband |
| **Best fyrir** | Mat og samþættingar með litla umferð | Greiðsla eftir notkun í stórum stíl | Sérsniðin magn og samningsskilmálar |
| Fyrirspurnir á mínútu | 30 (60 skyndibylgja) | Ótakmarkað | Ótakmarkað |
| Fyrirspurnir á mánuði | 10.000 | Ótakmarkað | Ótakmarkað |
| Svartími API (P95) | — | Undir 500 ms | Undir 500 ms |
| Verð á hverjar 1.000 fyrirspurnir | Ókeypis | 1,00 $ | Sérsniðið |
| Yfirnotkun á hlutfalli leit-bókunar (á hverjar 1.000 umfram leitir umfram 5.000:1) | — | 2,00 $ | Sérsniðið |
| Svörun við takmörkunum | 429 (hlé / mánaðarleg lokun) | Engin | Engin |

## API tilvísun

Tveir endapunktar þjónusta bókanlega vöru og þeir samsvara tveimur stigum hér að ofan:

- **Ókeypis — Consumer / Booking Engine API** (REST, `/api/public/**`): nafnlaus, fyrir vafra og viðmót. [Skoðaðu Booking Engine tilvísun →](/is/api/booking-engine/)
- **Greidd — Partner Integrator API** (**gRPC**, `wink.partner.v1`): auðkennd, notkunarmæld, byggð fyrir þjónustu-til-þjónustu samþættingu í stórum stíl. [Skoðaðu Integrator tilvísun →](/is/partner-api/partner/)

Partner Integrator API er gRPC, ekki REST. Þú kallar á það með útbúnum viðskiptavini yfir HTTP/2 á
`partner.wink.travel:443`, með burðarlykli og reikningi sem þú ert að kalla fyrir:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

Tilvísunarsíðan hér að ofan skráir alla þjónustu, skilaboð og villustöðu, og skemað er einnig
aðgengilegt í keyrslutíma í gegnum þjónustuglugga, svo `grpcurl`, Postman og Insomnia finna það án þess að þurfa að hlaða niður neinu.

Ef þú vilt frekar búa til viðskiptavin fyrirfram, eru `.proto` upprunaskrárnar birtar á
[github.com/wink-travel/partner-api-proto](https://github.com/wink-travel/partner-api-proto).

## Hvernig notkun og takmörk virka

### Ókeypis stig

Ókeypis stigið er hannað til að leyfa þér að byggja, prófa og reka hóflega framleiðsluumferð án kostnaðar.

- **Takmörkun á hraða — 30 fyrirspurnir á mínútu, með 60-fyrirspurna skyndibylgju.** Stuttar toppar yfir viðvarandi hraða eru teknar af skyndibylgjunni. Ef þú fer yfir hana svarar API með **HTTP 429 (Of margar fyrirspurnir)** og beitir **5 mínútna hléi** áður en lykillinn þinn heldur áfram að þjóna umferð. Taktu hlé og reyndu aftur eftir hléið í stað þess að áreita endapunktinn.
- **Mánaðarkvóti — 10.000 fyrirspurnir á mánuði.** Þegar þú nærð mánaðarmörkum skilar API **HTTP 429 fyrir restina af mánuðinum** — harður stöðvunarhnappur — ásamt skilaboðum sem hvetja þig til að gerast áskrifandi að Greidda stiginu til að halda áfram. Teljarinn endurstillist í byrjun næsta mánaðar.

Ókeypis stigið inniheldur ekki þjónustustigssamning né forgangsþjónustu.

### Greitt stig

Greidda stigið fjarlægir mánaðarmörkin og hlé á hraðatakmörkunum, og þú greiðir aðeins fyrir það sem þú notar.

- **Mældar fyrirspurnir — 1,00 $ á hverjar 1.000 fyrirspurnir.** Engin mánaðarmörk eru og engin hraðatakmörkun við eðlilega notkun; þú ert gjaldfærður eftir raunverulegu magni.
- **Yfirnotkun á leit-bókun hlutfalli — 2,00 $ á hverjar 1.000 umfram leitir.** Til að halda framboði heilbrigðu mælum við hlutfall leitanna ("looks") við staðfestar bókanir. Þú átt rétt á **5.000 leitunum á hverja bókun** áður en yfirnotkun tekur gildi. Umfram leitir eru reiknaðar sem:

  `umfram = max(0, leitir − bókanir × 5.000)`

  Yfirnotkun er þá gjaldfærð á **2,00 $ á hverjar 1.000 umfram leitir**. Samþættingar sem skila góðum viðskiptum þurfa sjaldan að greiða yfirnotkun; gjaldið á aðeins við um umferð sem leitar mun meira en hún bókar.

Greidda stigið inniheldur þjónustustigssamninginn sem lýst er hér að neðan — 99,9% uppetutryggingu og P95 svartíma markmið undir 500 ms — og forgangs- og alvarleikamiðaða þjónustu.

## Þjónustustigssamningur

_Gildistími: 5. júlí 2026 · Útgáfa 1.0_

Þessi þjónustustigssamningur (SLA) setur fram skuldbindingu um aðgengi, þjónustukredita og stuðningsmarkmið sem Wink ("Wink", "við", "okkur") veitir viðskiptavini ("Viðskiptavinur", "þú") fyrir auðkennda Wink Partner API (Partner API eða Þjónustan) á þeim stigum þar sem SLA gildir. Þessi SLA er hluti af og stjórnað af samningi milli þín og Wink sem veitir þér aðgang að Partner API (Samningurinn) og gildir svo lengi sem þú ert með virka, greidda áskrift að Partner API í góðu standi. Skilgreind hugtök sem ekki eru útskýrð hér hafa merkingu samkvæmt Samningnum.

### 1. Skilgreiningar

1. **"Uppetími"** merkir tímabil þegar Partner API er tiltækt til að taka við og svara með góðum árangri réttmætum, auðkenndum fyrirspurnum.
2. **"Niðurtími"** merkir tímabil, mælt í mínútum, þegar Partner API bregst ekki við réttmætum, auðkenndum fyrirspurnum, að undanskildum tímabilum sem falla undir undantekningar í kafla 4. Einangraðar villur sem hafa áhrif á óverulegan hluta fyrirspurna teljast ekki sem niðurtími.
3. **"Mánaðarlegur uppetímaprósenta"** merkir fyrir tiltekinn mánuð heildarfjölda mínútna í mánuðinum að frádregnum niðurtímamínútum, deilt með heildarfjölda mínútna í mánuðinum, gefið upp sem prósenta.
4. **"Áætluð viðhald"** merkir fyrirfram skipulagt viðhald á Þjónustunni sem Wink hefur tilkynnt fyrirfram samkvæmt kafla 4.
5. **"Þjónustukredit"** merkir kredit, reiknað sem prósenta af gjöldum sem þú hefur greitt eða átt að greiða fyrir Partner API í viðkomandi mánuði, sem er dregið frá framtíðar gjöldum fyrir Partner API sem eina og eina úrbót vegna vanefnda á uppetímasamningi.
6. **"Svartími"** merkir þann tíma sem líður frá því að Wink fær réttmæt, auðkennd fyrirspurn við þjónustumörk Wink þar til Wink byrjar að senda svar, að undanskildum netflutningi og tíma hjá viðskiptavini utan stjórn Wink.

### 2. Skuldbinding um aðgengi og frammistöðu

Wink mun leggja viðskiptalega sanngjörn áform í að gera Partner API tiltækt með **mánaðarlegum uppetímaprósentu að minnsta kosti 99,9%** á hverjum mánuði (Uppetímasamningurinn). Uppetímasamningurinn er mældur við þjónustumörk Wink og útilokar þætti utan sanngjarnrar stjórnunar Wink, þar með talda þá sem lýst er í kafla 4. Eftirlitskerfi Wink eru heimildarheimildin fyrir mælingu á mánaðarlegum uppetímaprósentu og svartíma.

Wink stefnir einnig að **95. prósentíl (P95) svartíma undir 500 millisekúndum** fyrir vel heppnaðar, réttmætar, auðkenndar fyrirspurnir, mælt við þjónustumörk Wink yfir hvern mánuð (Frammistöðumarkmiðið). Frammistöðumarkmiðið útilokar þætti sem lýst er í kafla 4, fyrirspurnir sem skila villum á forritastigi vegna fyrirspurnarinnar sjálfrar, og óvenjulega stórar eða flóknar hópfyrirspurnir. Frammistöðumarkmiðið er þjónustuviðmið; Þjónustukredit í kafla 3 gilda um vanefndir á **Uppetímasamningnum** og eru eina og eina úrbót vegna aðgengisbilana.

### 3. Þjónustukredit

Ef mánaðarlegur uppetímaprósenta fellur undir Uppetímasamninginn í einhverjum mánuði gætir þú átt rétt á Þjónustukrediti reiknuðum sem prósentu af gjöldum fyrir Partner API sem þú hefur greitt eða átt að greiða fyrir þann mánuð, samkvæmt eftirfarandi stigveldi:

| Mánaðarlegur uppetímaprósenta | Þjónustukredit |
|---|---|
| Undir 99,9% en að minnsta kosti 99,0% | 10% |
| Undir 99,0% en að minnsta kosti 95,0% | 25% |
| Undir 95,0% | 50% |

1. **Krafa um kredit.** Til að fá Þjónustukredit þarftu að senda skriflega kröfu til Wink innan **þrjátíu (30) daga** frá lokum mánaðarins þar sem bilunin átti sér stað. Krafa þarf að innihalda dagsetningar og tíma hvers niðurtímatilfellis sem þú krefst og öll tiltæk gögn eða rökstuðning. Kröfur sem berast eftir þennan tíma eru ekki gjaldgengar.
2. **Form kredit.** Samþykkt Þjónustukredit eru dregin frá framtíðar gjöldum fyrir Partner API og hafa enga peningalega virði. Þau eru ekki endurgreiðslur og verða ekki greidd út nema lög krefjist þess.
3. **Hámarks kredit.** Heildar Þjónustukredit sem veitt eru fyrir einn mánuð fara ekki yfir 50% af gjöldum fyrir Partner API sem þú hefur greitt eða átt að greiða fyrir þann mánuð.
4. **Eina og eina úrbót.** Þjónustukredit eru þín **eina og eina úrbót** vegna vanefnda Wink á Uppetímasamningnum eða annarra aðgengisbilana á Partner API.

### 4. Undantekningar

Uppetímasamningurinn og tilheyrandi Þjónustukredit gilda ekki og niðurtími felur ekki í sér neina óaðgengi, stöðvun, versnandi þjónustu eða frammistöðuvandamál sem stafa af eða tengjast:

1. **Áætluðu viðhaldi** sem Wink hefur tilkynnt fyrirfram, að því gefnu að tilkynning hafi verið gefin með hæfilegum fyrirvara í gegnum venjulegan samskiptamáta Wink við viðskiptavini;
2. **Force majeure** atburðum eða öðrum orsökum utan sanngjarrar stjórnunar Wink, þar með talin náttúruhamfarir, stjórnvöld, net- eða rafmagnsbilun og þjónustuníð eða aðrar illgjarnar árásir;
3. vandamálum sem stafa af **þínum** aðgerðum eða vanrækslu, búnaði, hugbúnaði eða neti, eða þjónustu, vöru eða veitanda þriðja aðila sem ekki er undir beinni stjórn Wink;
4. misnotkun þinni á Þjónustunni eða brotum á Samningnum, þessum SLA, notkunarskilmálum eða gildandi takmörkunum, þar með talin umferð sem Wink telur óhóflega, sjálfvirka misnotkun eða sviksemi; og
5. öllum **stöðvunum eða lokunum** á aðgangi þínum sem eru réttilega framkvæmdar samkvæmt Samningnum, þar með talin stöðvun vegna greiðslumissis.

### 5. Stuðningur & svörunarmarkmið

Wink veitir stuðning fyrir Partner API á venjulegum opnunartíma, að undanskildum opinberum frídögum. Wink mun leggja viðskiptalega sanngjörn áform í að staðfesta réttilega sendar stuðningsbeiðnir innan eftirfarandi markmiða um svörunartíma, byggt á alvarleika sem þú gefur og Wink staðfestir sanngjarnt:

| Alvarleiki | Lýsing | Markmið um fyrstu svörun |
|---|---|---|
| **Alvarleiki 1 — Brýnt** | Partner API er niðri eða ónothæft í framleiðslu án lausnar. | 4 klukkustundir |
| **Alvarleiki 2 — Mikilvægt** | Mikilvæg virkni er skert eða versnuð; lausn er til staðar. | 1 virkur dagur |
| **Alvarleiki 3 — Minniháttar** | Almennar spurningar, smávægileg vandamál eða óskir um virkni. | 2 virkir dagar |

Markmið um svörun lýsa því hvenær Wink stefnir að því að hafa **fyrstu samskipti**; þau eru ekki ábyrgð á lausnartíma. Forgangsþjónusta og alvarleikamiðuð markmið gilda á þeim stigum þar sem þau eru tilgreind.

### 6. Gögn & öryggi

Wink viðheldur viðskiptalega sanngjörnum stjórnunaraðgerðum, tæknilegum og skipulagslegum aðgerðum til að vernda trúnað, heilleika og aðgengi gagna sem unnin eru í gegnum Partner API, og endurskoðar þessar aðgerðir reglulega. Meðferð persónuupplýsinga hjá Wink er stjórnað af [Persónuverndarstefnu](/is/privacy) og öllum gagnavinnsluskilmálum í Samningnum. Þú berð ábyrgð á að tryggja þín eigin API-auðkenni, lögmætri notkun gagna sem þú sækir og að tilkynna Wink tafarlaust um grun um misnotkun auðkenna.

### 7. Takmörkun ábyrgðar

Þjónustukredit eru **eina og eina úrbótin** vegna óaðgengis eða vanefnda á Uppetímasamningnum, og eru veitt í stað annarrar ábyrgðar vegna slíkrar vanefndar. Fyrir utan það sem sérstaklega er tekið fram í SLA, er Partner API veitt "eins og hún er". Að því marki sem lög leyfa, er heildarábyrgð Wink vegna Þjónustunnar takmörkuð eins og kveðið er á um í Samningnum, og Wink ber ekki ábyrgð á óbeinum, tilviljanakenndum, sérstökum, afleiðingum eða refsiviðurlögum, né tapi á hagnaði, tekjum, gögnum eða góðu orðspori, jafnvel þótt það hafi verið tilkynnt um möguleika á slíkum skaða.

### 8. Gildistími, breytingar & uppsögn

Þessi SLA gildir svo lengi sem þú ert með virka Partner API áskrift á stigi þar sem SLA gildir. Wink getur uppfært SLA reglulega; verulegar breytingar verða tilkynntar í gegnum venjulegan samskiptamáta Wink við viðskiptavini, og áframhaldandi notkun Partner API eftir gildistöku uppfærslu þýðir samþykki á uppfærðu SLA. SLA rennur sjálfkrafa út við uppsögn eða lok Samnings eða áskriftar þinnar að Partner API. Greinar sem eðlislægt eiga að lifa áfram eftir uppsögn — þar með taldar réttindi til ókröfðra Þjónustukredita, takmörkun ábyrgðar og skilgreiningar — lifa áfram.
