Wink, iki kimlik doğrulamalı MCP sunucusu sunar. Her ikisi de **etkileşimli OAuth2 oturumu açma** (PKCE yetkilendirme kodu akışı) kullanır — AI ajanın, Wink hesabınızla oturum açmanız için bir tarayıcı sekmesi açar. Yönetilecek istemci gizli anahtarı yoktur.

| Sunucu | URL | Ne yapar |
|--------|-----|----------|
| **Inventory API** | `https://api.wink.travel/mcp` | Envanter, rezervasyonlar, fiyatlar, satış kanalları, analizler ve tüm platform işlemleri |
| **Integrations** | `https://integrations.wink.travel/mcp` | Kanal yöneticisi entegrasyonları — mülkleri, fiyatları ve müsaitliği OTA'larla senkronize eder |

---

## Kimlik doğrulama nasıl çalışır

Wink MCP sunucuları **OAuth2 Yetkilendirme Kodu + PKCE** akışını kullanır ve **Dinamik İstemci Kaydı (RFC 7591)** destekler. İlk bağlantı kurulduğunda şu adımlar gerçekleşir:

1. AI istemciniz, MCP uç noktasının `/.well-known/oauth-protected-resource` meta verisinden yetkilendirme sunucusunu keşfeder.
2. İstemci, **Dinamik İstemci Kaydı** yoluyla kendini kaydeder — manuel uygulama kurulumu gerekmez.
3. İstemci, `https://iam.wink.travel` adresinde bir **tarayıcı sekmesi** açar. Wink hesabınızla oturum açar ve izin ekranında istenen izinleri onaylarsınız.
4. Wink, hesabınıza özel ve kimliğinize bağlı bir **erişim belirteci** verir.
5. AI istemcisi, her MCP isteğine bu belirteci ekler. Tüm araç sonuçları otomatik olarak yönetici varlığınıza göre sınırlandırılır.
6. Belirteçler 3 saat sonra süresi dolar. AI istemciniz, arka planda sessizce yeniler, tekrar istemez.

Her araç çağrısı **kimliğiniz altında** çalışır — web portalını koruyan aynı ACL kuralları AI ajanı için de geçerlidir.

## AI istemcinizi bağlayın

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Claude Code'un güncel olduğundan emin olun:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Wink Inventory MCP sunucusunu ekleyin:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code sunucuya bağlanır, yetkilendirme sunucusunu keşfeder ve varsayılan tarayıcınızı açar.

4. **Wink'te oturum açın** ve izin ekranında izin isteğini onaylayın.

5. Claude Code bağlantıyı doğrular. Sunucunun göründüğünü ve araçların yüklendiğini kontrol etmek için `/mcp` yazın.
</Steps>

Integrations sunucusunu da eklemek için:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Ekibinizle paylaşın]
`claude mcp add` komutuna `--scope project` ekleyin, Claude Code sunucu URL'sini depo kökünde `.mcp.json` dosyasına yazar. Bu dosyayı commit edin — her ekip üyesi ilk bağlantıda kendi tarayıcı oturum açmasını tamamlar.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Claude Desktop yapılandırma dosyasını düzenleyin:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. MCP sunucu girdilerini ekleyin:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. Claude Desktop'u **tamamen kapatıp yeniden başlatın** (menü çubuğundan Çıkış yapın — pencereyi kapatmak yeterli değildir).

4. Claude Desktop her yeni sunucu için bir tarayıcı sekmesi açar. Wink'te oturum açın ve izinleri onaylayın.

5. Alt araç çubuğundaki fiş simgesi her iki sunucunun bağlı olduğunu gösterir.
</Steps>

  </TabItem>
  <TabItem label="OpenAI Codex">

<Steps>
1. Codex CLI'nin yüklü olduğundan emin olun:
   ```bash
   npm install -g @openai/codex
   ```

2. Codex yapılandırma dosyasını açın (veya oluşturun):
   - **macOS / Linux:** `~/.codex/config.json`
   - **Windows:** `%USERPROFILE%\.codex\config.json`

3. Wink MCP sunucu girdilerini ekleyin:

   ```json title="~/.codex/config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

4. Codex'i başlatın. İlk kullanımda Codex, `https://iam.wink.travel` adresinde bir tarayıcı sekmesi açar.

5. **Wink'te oturum açın** ve istenen izinleri onaylayın.

6. Codex bağlantıyı doğrular. `codex` komutunu çalıştırın ve Wink sunucularının aktif olduğunu doğrulamak için mevcut araçları listelemesini isteyin.
</Steps>

:::note
Codex CLI MCP desteği için **1.0** veya daha yeni sürüm gereklidir. Sürümü kontrol etmek için `codex --version` komutunu çalıştırın ve güncellemek için `npm install -g @openai/codex` komutunu kullanın.
:::

  </TabItem>
  <TabItem label="ChatGPT">

MCP sunucu desteği, Plus, Pro, Team ve Enterprise aboneleri için **ChatGPT masaüstü uygulamasında** mevcuttur.

<Steps>
1. Henüz yapmadıysanız [ChatGPT masaüstü uygulamasını](https://openai.com/chatgpt/download/) indirin ve kurun.

2. Uygulamayı açın ve sağ üst köşedeki **profil simgenize** tıklayın, ardından **Ayarlar**'ı seçin.

3. **Bağlayıcılar** (veya uygulama sürümünüze bağlı olarak **MCP Sunucuları**) bölümüne gidin ve **Ekle**'ye tıklayın.

4. Wink Inventory sunucu URL'sini girin:
   ```
   https://api.wink.travel/mcp
   ```
   Ardından **Bağlan**'a tıklayın.

5. ChatGPT, `https://iam.wink.travel` adresinde bir tarayıcı sekmesi açar. **Wink'te oturum açın** ve izinleri onaylayın.

6. Aynı işlemi Integrations sunucusu için tekrarlayın:
   ```
   https://integrations.wink.travel/mcp
   ```

7. Her iki sunucu Bağlayıcılar listenizde görünür. Yeni bir sohbet başlatın — Wink araçları otomatik olarak kullanılabilir.
</Steps>

:::note[Web uygulaması sınırlaması]
MCP sunucuları yalnızca **masaüstü uygulamada** yapılandırılabilir. chatgpt.com web arayüzü özel MCP sunucularını desteklemez.
:::

  </TabItem>
  <TabItem label="Cursor">

<Steps>
1. Cursor MCP yapılandırma dosyasını açın (veya oluşturun):
   - **macOS / Linux:** `~/.cursor/mcp.json`
   - **Windows:** `%USERPROFILE%\.cursor\mcp.json`

2. Wink MCP sunucu girdilerini ekleyin:

   ```json title="~/.cursor/mcp.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. Cursor'u açın. **Ayarlar → Cursor Ayarları → MCP** bölümüne gidin ve her iki sunucunun yeşil durum göstergesiyle göründüğünü doğrulayın. Kırmızı görünüyorsa **Yenile**'ye tıklayın.

4. Cursor, `https://iam.wink.travel` adresinde bir tarayıcı sekmesi açar. **Wink'te oturum açın** ve izinleri onaylayın.

5. Bir sohbet açın (`Ctrl+L` / `Cmd+L`) ve bağlantıyı doğrulamak için Cursor'dan mevcut Wink araçlarını listelemesini isteyin.
</Steps>

:::tip[Proje kapsamlı yapılandırma]
`~/.cursor/` yerine projenizin kök dizinine bir `mcp.json` dosyası da koyabilirsiniz. Proje düzeyindeki yapılandırma önceliklidir ve projeyi Cursor'da açan her ekip üyesi için sunucuları kullanılabilir yapar.
:::

## Kapsam referansı

İzin ekranını onayladığınızda, ajanın istediği izinlerin dökümünü görürsünüz. Wink izinleri işlevsel alanlara göre gruplar:

| Kapsam grubu | Kapsamlar | Neyi açar |
|-------------|-----------|-----------|
| **MCP transport** | `mcp.read` `mcp.write` `mcp.remove` | Her iki MCP sunucusuna bağlanmak için gereklidir |
| **Hesap** | `account.read` `account.write` `account.remove` | Yönetici varlıklar, ekip üyeleri, ayarlar, uygulamalar |
| **Rezervasyon** | `booking.read` `booking.write` `booking.remove` | Rezervasyon arama, görüntüleme, oluşturma, iptal ve iade |
| **Envanter** | `inventory.read` `inventory.write` `inventory.remove` | Mülkler, odalar, fiyatlar, olanaklar, müsaitlik |
| **Analitik** | `analytics.read` | Rezervasyon analizleri, gelir raporları, lider tabloları |
| **Pazarlama** | `marketing.read` `marketing.write` `marketing.remove` | Sosyal gönderiler, kampanyalar, satış kanalları, promosyonlar |
| **İçerik** | `content.read` `content.write` `content.remove` | Multimedya, kısaltılmış URL'ler, paylaşımlı öğeler, haritalar |
| **Ödeme** | `payment.read` `payment.write` | Defter, ödemeler, finansal döküm, çekimler |

AI istemcisi yalnızca ihtiyaç duyduğu kapsamları ister. İzin ekranında bireysel izinleri reddedebilirsiniz — reddedilen kapsam gerektiren araçlar çağrıldığında hata döner.

## Sorun giderme

**Tarayıcı sekmesi açılmıyor**

AI istemciniz henüz etkileşimli PKCE akışını desteklemiyor olabilir. Güncel sürüm kullandığınızdan emin olun:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT masaüstü:** uygulamanın yerleşik güncelleyicisinden güncelleyin

**Oturum açtıktan sonra `401 Unauthorized` hatası**

Önbelleğe alınan belirteciniz eski olabilir. Sunucuyu kaldırıp yeniden ekleyerek yeni oturum açmayı tetikleyin:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

Claude Desktop ve ChatGPT için ayarlardan sunucu girdisini kaldırın, uygulamayı yeniden başlatın ve tekrar ekleyin.

**Belirli bir araç çağrısında `403 Forbidden` hatası**

Araç, izin ekranında onaylamadığınız bir kapsam gerektiriyor. Sunucuyu yeniden bağlayın — izin ekranı tekrar açılır ve eksik izni onaylayabilirsiniz.

**Sunucu görünüyor ama araç çağrıları "hesap bulunamadı" hatası veriyor**

Wink hesabınızda yönetici varlık yok. MCP sunucusunu kullanmadan önce [Wink Portal](https://app.wink.travel) adresine gidip hesabınızın kurulu olduğundan emin olun.

**Oturum sırasında belirteç süresi doluyor**

Belirteçler 3 saat geçerlidir. Claude Code ve Claude Desktop belirteçleri arka planda sessizce yeniler. Uzun süre boş kaldıktan sonra kimlik doğrulama hatası alırsanız yeni bir mesaj yazın — istemci otomatik olarak yeniden kimlik doğrulaması yapar.

**Codex CLI "MCP sunucusuna ulaşılamıyor" hatası veriyor**

`~/.codex/config.json` dosyanızın geçerli JSON olduğundan (sonunda virgül yok) ve `"type": "http"` olarak ayarlandığından emin olun. Codex, uzak sunucular için HTTP taşıma gerektirir; stdio taşıma yalnızca yerel ikili dosyalar içindir.

**ChatGPT "Bağlayıcılar" menüsü eksik**

MCP desteği için ChatGPT masaüstü uygulaması sürüm **1.2024.352** veya daha yenisi ve aktif Plus, Pro, Team veya Enterprise aboneliği gerekir. Uygulamayı güncelleyin ve Ayarlar → Hesap bölümünden planınızı doğrulayın.

**Cursor sunucusu kırmızı gösteriyor / "Bağlantı başarısız"**

`~/.cursor/mcp.json` dosyanızın geçerli JSON ve `"type": "http"` içerdiğini doğrulayın. Sonra **Ayarlar → Cursor Ayarları → MCP** bölümüne gidip **Yenile**'ye tıklayın. Hata devam ederse Cursor'u tamamen yeniden başlatın — yapılandırma değişiklikleri bazen yeniden başlatma olmadan algılanmaz.

**Windsurf MCP sunucuları ayarlarda görünmüyor**

Windsurf, `mcp_config.json` değişikliklerini algılamak için tam yeniden başlatma (sadece pencere yenileme değil) gerektirir. **Dosya → Çıkış** yapıp yeniden açın. Sunucular hala görünmüyorsa, **Yardım → Windsurf Hakkında** bölümünden Windsurf sürümünüzün **1.4+** olduğundan emin olun.

**Cline "Sunucu Ekle" seçeneği görünmüyor**

MCP sunucu yöneticisi için Cline **2.0** veya daha yeni sürüm gerekir. VS Code Uzantılar panelini açın, Cline'ı bulun ve güncelleme varsa **Güncelle**'ye tıklayın. Güncellemeden sonra VS Code'u yeniden yükleyin (`Ctrl+Shift+P` → "Developer: Reload Window").
