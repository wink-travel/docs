Google Analytics 4 mülkünüzü Wink'e bağlayarak, oda görüntülemelerinden tamamlanan rezervasyonlara kadar olan rezervasyon etkinlikleriniz, Wink'in kendi analizleriyle birlikte otomatik olarak kendi GA4 kontrol panelinize iletilir. Kod yazmaya veya teknik kurulum yapmaya gerek yoktur.

<Aside type="tip">
GA4'ten iki şeye ihtiyacınız var: bir **Measurement ID** ve bir **Measurement Protocol API secret**. Measurement ID, misafirin tarayıcısındaki gezinme hunisini çalıştırır; API secret ise Wink'in tamamlanan rezervasyonları (`purchase`) **sunucu tarafında** kaydetmesini sağlar, böylece misafir ödeme sağlayıcısına yönlendirilirken satış asla kaybolmaz.
</Aside>

---

## Nasıl Çalışır

```
Measurement ID'nizi (G-XXXXXXXXXX) ve API secret'ınızı Wink portalına girersiniz
       ↓
Gezinme etkinlikleri (görüntülemeler, sepet, ödeme) tarayıcıdan GA4 mülkünüze akar
Tamamlanan rezervasyonlar (purchase) sunucu tarafında gönderilir — ödeme yönlendirmesinden etkilenmez
       ↓
analytics.google.com'a giriş yapar ve tam rezervasyon huninizi görürsünüz
```

## Yapmanız Gerekenler

<Steps>

1. **Bir GA4 Mülkü Oluşturun**

   [analytics.google.com](https://analytics.google.com) adresine gidin: Yönetici → Mülk Oluştur. Pazarınıza uygun saat dilimi ve para birimini ayarlayın.

2. **Bir Web Veri Akışı Oluşturun**

   Yönetici → Veri Akışları → Akış Ekle → Web. URL olarak `wink.travel` girin. Bu, size **Measurement ID** (`G-XXXXXXXXXX`) oluşturur. Kopyalayın.

3. **Bir Measurement Protocol API Secret Oluşturun**

   Aynı Web Veri Akışını açın → **Measurement Protocol API secrets** bölümüne gidin → **Oluştur**. Bir takma ad verin (örneğin "Wink") ve oluşturulan **secret değerini** kopyalayın. Bu secret, Wink'in tamamlanan rezervasyonları sunucu tarafında kaydetmesini sağlar, böylece ödeme yönlendirmesi sırasında satış kaybolmaz.

4. **Measurement ID ve API Secret'ınızı Wink Portalına Girin**

   [app.wink.travel](https://app.wink.travel) adresine giriş yapın, hesabınızı seçin ve **Özelleştirmeler** sekmesine gidin. Measurement ID ve API secret'ınızı **GA4** alanlarına yapıştırın ve kaydedin. Hepsi bu kadar — GA4 entegrasyonunuz artık aktif.

   <Aside type="note">
   API secret **yalnızca yazma amaçlıdır**: kaydedildikten sonra bir daha gösterilmez. Gelecekte düzenleme yaparken, secret alanını boş bırakın; böylece önceden kaydettiğiniz değer korunur.
   </Aside>

5. **`purchase` Etkinliğini Anahtar Olarak İşaretleyin**

   GA4 mülkünüzde: Yönetici → Etkinlikler → `purchase` etkinliğini bulun → **Anahtar etkinlik olarak işaretle** seçeneğini açın. Bu, tamamlanan rezervasyonların Dönüşümler raporunda görünmesini sağlar.

6. **Verilerinizi Görüntüleyin**

   [analytics.google.com](https://analytics.google.com) adresine giriş yapın; rezervasyonlarınızı, gelirlerinizi ve misafir huninizi otomatik olarak Wink üzerinden takip edebilirsiniz.

</Steps>

<Aside type="note">
Bu entegrasyon için kendi web sitenize herhangi bir takip kodu yüklemenize gerek yoktur. Wink her şeyi halleder. Measurement ID'niz, rezervasyon verilerinizin gönderildiği yerdir ve API secret, Wink'in tamamlanan rezervasyonları sunucu tarafında doğrulamasını sağlar.
</Aside>

<Aside type="tip">
**GA4 ve GTM birlikte kullanılabilir.** Eğer Google Tag Manager konteyneriniz varsa (örneğin Sojern konteyneri), her ikisini aynı anda yapılandırabilirsiniz — artık birbirini dışlamazlar. Detaylar için [GTM Analytics Entegrasyonu](/tr/guides/developers/gtm-dual-tagging) sayfasına bakın.
</Aside>

## Neleri Takip Edebilirsiniz

Bağlandıktan sonra, GA4 mülkünüz mülkünüz için Gelişmiş E-ticaret etkinliklerinin tam setini alır:

### Keşif

| Etkinlik | Anlamı |
|---|---|
| `view_item_list` | Misafir mülkünüzü arama veya kategori listesinde gördü |
| `select_item` | Misafir listeden mülkünüze tıkladı |
| `view_item` | Misafir otel detay sayfanızı görüntüledi |

### Değerlendirme

| Etkinlik | Anlamı |
|---|---|
| `view_promotion` | Misafir mülkünüz için bir promosyon teklifini gördü |
| `select_promotion` | Misafir bir promosyon teklifine tıkladı |
| `add_to_wishlist` | Misafir mülkünüzü istek listesine ekledi |

### Rezervasyon Hunisi

| Etkinlik | Anlamı |
|---|---|
| `add_to_cart` | Misafir bir oda veya paket seçti |
| `view_cart` | Misafir rezervasyon özetini görüntüledi |
| `remove_from_cart` | Misafir bir oda veya paketi sepetten çıkardı |
| `begin_checkout` | Misafir ödeme sürecini başlattı |
| `add_payment_info` | Misafir ödeme bilgilerini girdi |
| `add_shipping_info` | Misafir misafir bilgilerini girdi |
| `purchase` | Misafir rezervasyonu tamamladı |
| `refund` | Rezervasyon iptal edildi ve iade yapıldı |

Tüm etkinlikler, gelir, para birimi, oda tipi ve rezervasyon değeri gibi ilgili boyutları içerir — böylece misafir yolculuğunu ilk izlenimden tamamlanan rezervasyona kadar tam olarak görebilirsiniz. `city_name`, `cancellation_policy`, `bed_type` gibi ek mülk ve oda düzeyi boyutları açmak için [GA4'te Özel Boyutlar](/tr/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4) sayfasına bakın.

## Alanlar Arası Takip (Gelişmiş)

Yukarıdaki standart entegrasyon, Wink içindeki tüm etkinlikleri takip eder. Ancak, misafirlerin kendi web sitenizden başlayıp Wink'te rezervasyon tamamlamasına kadar olan süreci ve orijinal trafik kaynağını (Google Ads, e-posta kampanyaları, organik arama vb.) doğru şekilde izlemek istiyorsanız, her iki tarafta ek bir adım gereklidir.

<Aside type="caution">
Bu bölüm yalnızca kendi web sitenizde GA4 kuruluysa geçerlidir. Sitenizde GA4 kullanmıyorsanız, yukarıdaki standart entegrasyon yeterlidir.
</Aside>

### Neden Önemli?

Alanlar arası takip olmadan, önce web sitenizi ziyaret eden ve sonra Wink'te rezervasyon yapan misafir, GA4'te önceki ziyaretle bağlantısı olmayan **Doğrudan** oturum olarak görünür. Rezervasyona yol açan Google Ads tıklamaları, e-posta kampanyaları veya organik arama ziyaretleri kredi alamaz.

Alanlar arası takip yapılandırıldığında, tam misafir yolculuğunu görürsünüz:

```
google.com (ücretli reklam)
       ↓
web siteniz (misafir odalara göz atar)
       ↓
wink.travel (misafir oda seçer ve rezervasyon yapar)
       ↓
satın alma doğru şekilde orijinal Google Ads tıklamasına bağlanır
```

### Yapmanız Gerekenler: Siz

GA4 mülkünüzü, `wink.travel` adresini kendi alan adınızın bir parçası olarak tanıyacak şekilde yapılandırın, harici bir yönlendirme olarak değil. Bu, GA4'ün iki oturumu tek bir sürekli misafir yolculuğu olarak birleştirmesini sağlar.

<Steps>
1. GA4 Yönetici → Veri Akışları → akışınızı seçin
2. Etiket ayarlarını yapılandır → **Alan adlarınızı yapılandırın**
3. `wink.travel` adresini bağlı alan olarak ekleyin
4. Kaydedin
</Steps>

### Yapmanız Gerekenler: Wink

[Wink Destek](https://app.wink.travel) ile iletişime geçin ve web sitenizin alan adını (örneğin `yourhotel.com`) sağlayın. Wink, alan adınızı Wink GA4 mülkündeki yönlendirme hariç tutma listesine ekleyecektir. Bu, web sitenizin yönlendirme kaynağı olarak kaydedilmesini engeller; aksi takdirde misafirin orijinal ataması üzerine yazılır ve yeni bir oturum başlatılır.

<Aside type="tip">
Yukarıdaki standart entegrasyon çoğu mülk için yeterlidir ve Wink'teki rezervasyonlar ile gelirler hakkında anında görünürlük sağlar. Alanlar arası takip, GA4 verilerinizle rahat olduğunuzda ve daha derin atama içgörüsü istediğinizde kurulması gereken gelişmiş bir seçenektir.
</Aside>
