Šī rokasgrāmata ved ceļojumu aģentūru no reģistrācijas līdz pirmajai klienta rezervācijai. Tā arī izskaidro divus veidus, kā aģentūra var strādāt ar Wink, lai jūs varētu izvēlēties pareizo pirms darba uzsākšanas.

## Pirms sākat

Jums būs nepieciešams:

- Jūsu uzņēmuma dati.
- Jūsu ceļojumu aģentūras reģistrācijas numurs vai jūsu IATA kods, ja tāds ir.
- Bankas konts jūsu komisijas maksājumu saņemšanai.

## Izvēlieties, kā strādāsiet

| | Standarta (lielākā daļa aģentūru) | Aģenta iekasētais maksājums |
|---|---|---|
| Kā veicat rezervāciju | Wink portālā vai caur Partnera API | Caur [Partnera API](/lv/integrations/partner-api/), no sava pašu sistēmas |
| Kas saņem klienta maksājumu | Maksājums tiek iekasēts viesnīcai, kas paliek par reģistrēto tirgotāju. Jūs ievadāt klienta karti norēķinos. | Jūs to darāt kā reģistrētais tirgotājs. |
| Ko jūs pelnāt | **10% noklusējuma komisija** par katru rezervāciju | Komisija saskaņā ar jūsu pašu līgumu ar katru viesnīcu |
| Ko maksājat Wink | Nekas | **1,5%** rezervācijas maksa no katras rezervācijas vērtības, rēķināta mēneša beigās, plus Partnera API izmantošana virs bezmaksas limita |
| Maksājumi viesnīcai | Tiek nokārtoti jūsu vietā | Jūs maksājat katrai viesnīcai tieši, saskaņā ar jūsu pašu līgumu ar tām |
| Atmaksas, chargeback un maksājumu atbilstība | Tiek nokārtota jūsu vietā | Jūsu atbildība |
| Apstiprinājums | Jūsu reģistrācija tiek pārskatīta pirms rezervācijas veikšanas | Jūsu reģistrācija tiek pārskatīta, kā arī nepieciešama Wink rakstiska atļauja šim darbības veidam ar kredītlimitu |

Wink pārskata katras ceļojumu aģentūras reģistrāciju. Lielākā daļa aģentūru izmanto standarta ceļu. Aģenta iekasētais maksājums ir paredzēts **tikai API partneriem**: aģentūrām, kas rezervē caur Partnera API no savas sistēmas, jau iekasē klientu maksājumus pēc savas licences un tieši sadarbojas ar viesnīcām.

## 1. solis: Reģistrējiet savu aģentūru

<Steps>
1. Dodieties uz [app.wink.travel](https://app.wink.travel), noklikšķiniet uz `Sign-In / Register` un reģistrējieties.

2. Kreisajā sānjoslā noklikšķiniet uz `Accounts`, tad `Create` un izvēlieties **I am a Travel Agent**.

3. Aizpildiet aģentūras datus. Izvēlieties **Company** kā juridisko formu: tas nosaka, kā jūs saņemsiet maksājumus. Skatīt [Create Account](/lv/portal/create-account/).

4. Ja plānojat iekasēt maksājumus pats caur Partnera API, izvēlieties šo ceļu reģistrācijas laikā. Tas ir pieprasījums, nevis apstiprinājums. Skatīt [6. solis](#step-6-collect-payment-yourself-api-partners-only).

5. Wink pārskata katru ceļojumu aģentūras reģistrāciju. Mēs nosūtām e-pastu uz jūsu reģistrēto adresi un pieprasām dokumentus: uzņēmuma datus un jūsu ceļojumu aģentūras reģistrācijas numuru vai IATA kodu. Jūs varat veikt rezervācijas, kad reģistrācija ir apstiprināta.
</Steps>

## 2. solis: Pievienojiet bankas kontu

Dodieties uz `Account > Bank Accounts`, pievienojiet aģentūras kontu un atzīmējiet to kā **Primary**. Komisija tiek maksāta uz šo kontu ar bankas pārskaitījumu. Wink izmanto Revolut izmaksām, tāpēc Revolut biznesa konts ir visērtākais variants, bet der jebkurš bankas konts. Skatīt [Bank Accounts](/lv/portal/settings/payouts/).

## 3. solis: Atrodiet viesnīcas savam klientam

<Steps>
1. Noklikšķiniet uz `Browse > Hotels` galvenajā navigācijas joslā.

2. Meklējiet pēc galamērķa, datumiem un viesu skaita, un filtrējiet, līdz atrodat piemērotākās iespējas klientam.

3. Saglabājiet īsās sarakstus [kuriētajā sarakstā](/lv/portal/studio/curated-lists/), ja salīdzināt iespējas ar klientu.
</Steps>

Redzamās cenas ir viesnīcas pašu cenas. Wink tās nodod tādas, kādas ir, bez uzcenojuma: jūs pelnāt ar komisiju. Skatīt [Search](/lv/portal/studio/search/).

## 4. solis: Veiciet rezervāciju klientam

<Steps>
1. Izvēlieties numuru un cenu, ievadiet klienta vārdu un kontaktinformāciju kā ceļotāju.

2. Norēķinos ievadiet karti, ko klients jums deva šai rezervācijai. Maksājums tiek iekasēts viesnīcai, kas paliek par reģistrēto tirgotāju.

3. Apstipriniet. Jūs, ceļotājs un viesnīca saņems apstiprinājuma e-pastu. Rezervācijas kods sākas ar `WNK`.
</Steps>

:::caution[Rūpīgi apstrādājiet klienta karti]
Pieprasiet karti tikai rezervācijai, ko veicat, un ievadiet to tieši norēķinos. Nenorakstiet, nesūtiet e-pastā un neglabājiet savos ierakstos.
:::

## 5. solis: Pārvaldiet rezervācijas un saņemiet maksājumus

- **Rezervācijas:** noklikšķiniet uz `Bookings` galvenajā navigācijas joslā, lai redzētu visas rezervācijas, filtrētu tās, eksportētu CSV formātā, atkārtoti nosūtītu apstiprinājumu vai atceltu saskaņā ar viesnīcas atcelšanas politiku. Skatīt [Bookings](/lv/portal/travel-agent/bookings/).
- **Komisija:** noklusēti 10%. Kad regulāri sadarbojaties ar viesnīcu, varat pieprasīt [tiešu savienojumu](/lv/portal/studio/network/) un vienoties par citu komisiju.
- **Kad saņemat maksājumu:** komisija kļūst pieejama 24 stundu laikā pēc viesu reģistrēšanās un tiek pārskaitīta uz jūsu primāro bankas kontu. Pārskaitījuma maksas tiek segtas pēc faktiskajām izmaksām. Skatīt [Pricing](/lv/getting-started/pricing/).

## 6. solis: Saņemiet maksājumus paši (tikai API partneriem)

Izlaidiet šo soli, ja rezervējat portālā vai esat apmierināts ar standarta ceļu.

<Steps>
1. Integrējieties ar [Partnera API](/lv/integrations/partner-api/). Šis ceļš darbojas tikai caur API, no jūsu pašu rezervēšanas sistēmas, nevis portālā.

2. Izvēlieties šo ceļu reģistrācijas laikā (1. solis).

3. Wink izvērtē to kopā ar jūsu reģistrācijas dokumentiem, piemēram, jūsu finanšu stāvokli un regulatīvo statusu, un apstiprina rakstiski. Apstiprinājumam ir pievienots **kredītlimits**: maksimālā summa, ko varat turēt neapmaksātās rezervācijās jebkurā brīdī.

4. Kamēr neesat apstiprināts, varat turpināt rezervēt pa standarta ceļu.
</Steps>

Kad apstiprināts, jūs paši saņemat klienta maksājumu un maksājat katrai viesnīcai tieši. No katras rezervācijas vispirms atskaita 1,5% Wink maksu, tad jūsu komisiju; pārējais pienākas viesnīcai:

| Par USD 1 000,00 rezervāciju ar 10% komisiju | |
|---|---|
| Rezervācijas vērtība | USD 1 000,00 |
| Atlikums pēc Wink maksas (1,5% no rezervācijas vērtības) | USD 15,00 |
| Starpsumma | USD 985,00 |
| Atlikums pēc jūsu komisijas (10% no starpsumma) | USD 98,50 |
| **Jāizmaksā viesnīcai** | **USD 886,50** |

Wink rēķina 1,5% rezervācijas maksu mēneša beigās, USD, ar maksājuma termiņu 15 dienas, kā arī jebkuru Partnera API izmantošanu virs bezmaksas limita. Jūs esat atbildīgs par atmaksām, chargeback, maksājumu drošību (PCI-DSS) un jebkuru licenci, ko jūsu valsts prasa maksājumu iekasēšanai. Pilni noteikumi ir [Travel Agent Agreement](/lv/legal/platform-agreements/).

## Savienojiet savas sistēmas

Aģentūras ar saviem rezervēšanas rīkiem var meklēt un rezervēt caur [Partnera API](/lv/integrations/partner-api/). Ceļojumu aģentūru konti var veidot rezervācijas tieši ar to, un tas ir vienīgais veids, kā strādāt ar aģenta iekasēto maksājumu ceļu. Skatīt [Partnera API reference](/lv/partner-api/partner/).

## Jūsu kontrolsaraksts

- [ ] Aģentūra reģistrēta kā Travel Agent konts
- [ ] Dokumenti nosūtīti un reģistrācija apstiprināta
- [ ] Bankas konts pievienots un atzīmēts kā Primary
- [ ] Atrastas pirmās viesnīcas klientam
- [ ] Veikta pirmā rezervācija, karte ievadīta norēķinos
- [ ] Pēc izvēles, API partneri: izvēlējušies maksājumu iekasēt paši reģistrācijas laikā
