Booking Engine var iegult jebkur. Izvēlieties savu ietvaru vai CMS un sekojiet tā norādījumiem; pamatā esošie Web Components ir vienādi visur.

## Galvenās pieejas

- [Web Components](/lv/integrations/web-components/) — iegultie elementi, ko izmanto katra integrācija.
- [npm package](/lv/integrations/npm/) — instalējiet JavaScript izstrādē.
- [Headless CMS](/lv/integrations/headless/) — renderēšana no jebkuras satura aizmugures sistēmas.
- [Partner API](/lv/integrations/partner-api/) — pilnīga programmatiska integrācija.
