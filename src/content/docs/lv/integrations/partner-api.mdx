Wink **Partnera API** ir autentificēts, lielas caurlaidspējas veids, kā integrētāji var vaicāt rezervējamu ceļojumu inventāru — to pašu piegādi, kas darbina mūsu iegultos logrīkus un publiskos pārlūkošanas galapunktus, kas pieejami kā pirmās klases programmatiska saskarne. Kamēr bezmaksas Web Components un publiskie pārlūkošanas galapunkti ir paredzēti vieglai, cilvēkam draudzīgai iegulšanai, Partnera API ir veidots sistēmām, kas meklē, cenu nosaka un rezervē lielā apjomā. Piekļuve ir autentificēta katram integrētājam un tiek apmaksāta pēc lietošanas, tāpēc jūs maksājat tikai par trafiku, ko patiešām nosūtāt.

Lietošana tiek mērīta **viesnīcas naktīs**: viena viesnīca, novērtēta par vienu nakti — *ne* par vienu API izsaukumu. Meklējums, kas atgriež 20 viesnīcas 3 nakšu uzturēšanās periodam, ir 60 viesnīcas naktis no viena pieprasījuma. Saturs un Meklēšana (galamērķa meklēšana un automātiskā pabeigšana) ir izņēmums: katrs maksā vienu vienību par izsaukumu, neatkarīgi no tā, ko tas atgriež. Konta galapunkti ir bez maksas. ## API atsauce

Ir divas virsmas, kas apkalpo rezervējamo inventāru, un tās atbilst diviem iepriekš minētajiem līmeņiem:

- **Bezmaksas — Patērētāja / Rezervēšanas dzinēja API** (REST, `/api/public/**`): anonīms, pārlūkprogrammai un logrīkiem paredzēts. [Pārlūkojiet Rezervēšanas dzinēja atsauci →](/lv/api/booking-engine/)
- **Maksas — Partnera integratora API** (**gRPC**, `wink.partner.v1`): autentificēts, lietošanas mērīts, veidots servera-servera integrācijai lielā apjomā. [Pārlūkojiet Integratora atsauci →](/lv/partner-api/partner/)

Partnera integratora API ir gRPC, nevis REST. Jūs to izsaucat ar ģenerētu klientu pār HTTP/2 pie
`partner.wink.travel:443`, nododot nēsātāja tokenu un kontu, kuram izsaucat:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

Iepriekš minētā atsauces lapa dokumentē katru pakalpojumu, ziņojumu un kļūdas statusu, un shēma ir pieejama arī izpildes laikā caur servera atspoguļošanu, tāpēc `grpcurl`, Postman un Insomnia to atrod bez nepieciešamības kaut ko lejupielādēt.

Ja vēlaties ģenerēt klientu iepriekš, `.proto` avota faili ir publicēti vietnē
[github.com/wink-travel/partner-api-proto](https://github.com/wink-travel/partner-api-proto).

## Kā darbojas lietošana un ierobežojumi

### Bezmaksas līmenis

Bezmaksas līmenis ir paredzēts, lai ļautu jums izveidot, testēt un darbināt mērenu ražošanas trafiku bez maksas.

- **Nav publicēta minūtes limits.** Wink uzrauga pieprasījumu ātrumu un var piemērot godīgas lietošanas ierobežojumus, lai aizsargātu pakalpojumu. Ja saņemat **HTTP 429 (Pārāk daudz pieprasījumu)**, pagaidiet sekundes, kas norādītas `Retry-After` galvenē, pirms mēģināt vēlreiz.
- **Mēneša limits — 10 000 vienību kalendāra mēnesī.** Limits tiek piešķirts katram kontam un tiek atiestatīts katra mēneša 1. datumā (UTC). Kad tas ir sasniegts, konts, kas nav reģistrējies maksāšanas pēc patēriņa režīmā, saņem **HTTP 429 līdz nākamā mēneša 1. datumam** — stingru apturēšanu ar `Retry-After` galveni un ziņojumu, kas aicina abonēt Maksas līmeni. Reģistrēts konts turpina darboties un tiek apmaksāts par lietošanu virs limita.

Bezmaksas līmenī nav iekļauts Pakalpojuma līmeņa līgums vai prioritārs atbalsts.

### Maksas līmenis

Maksas līmenis noņem mēneša griestus un iekasē maksu tikai par to, ko izmantojat.

- **Mērītas viesnīcas naktis — 0,0001 $ par viesnīcas nakti.** Nav mēneša griestu; maksa tiek iekasēta pēc faktiskā apjoma. Wink joprojām var piemērot godīgas lietošanas ierobežojumus, lai aizsargātu pakalpojumu. Meklēšanas un inventāra izsaukumi tiek apmaksāti par katru novērtēto viesnīcas nakti; Saturs un Meklēšana maksā vienu vienību katrs, tāpēc pieprasījumu apvienošana samazina rēķinu.

Maksas līmenī ir iekļauts zemāk aprakstītais Pakalpojuma līmeņa līgums — 99,9% darbspējas solījums un P95 atbildes laika mērķis zem 500 ms — un prioritārs, pēc smaguma pakāpes balstīts atbalsts.

## Pakalpojuma līmeņa līgums

_Stāšanās spēkā datums: 2026. gada 5. jūlijs · Versija 1.0_

Šis Pakalpojuma līmeņa līgums (turpmāk — "SLA") nosaka pieejamības solījumu, pakalpojuma kredītus un atbalsta mērķus, ko Wink ("Wink", "mēs", "mums") sniedz klientam ("Klients", "jūs") autentificētajam Wink Partnera API (turpmāk — "Partnera API" vai "Pakalpojums") līmeņos, kuros ir norādīts SLA piemērojamība. Šis SLA ir iekļauts un regulēts ar līgumu starp jums un Wink, saskaņā ar kuru jūs piekļūstat Partnera API (turpmāk — "Līgums"), un tas attiecas tik ilgi, kamēr jums ir aktīvs, apmaksāts Partnera API abonements labā stāvoklī. Šeit nedefinētie ar lielo burtu rakstītie termini ir definēti Līgumā.

### 1. Definīcijas

1. **"Darbspēja"** nozīmē periodus, kuros Partnera API ir pieejams, lai pieņemtu un veiksmīgi atbildētu uz pareizi veidotiem, autentificētiem pieprasījumiem.
2. **"Nedarbspēja"** nozīmē jebkuru periodu minūtēs, kurā Partnera API neveiksmīgi atbild uz pareizi veidotiem, autentificētiem pieprasījumiem, izņemot periodus, kas ietverti 4. sadaļā minētajos izņēmumos. Atsevišķas kļūdas, kas ietekmē nenozīmīgu pieprasījumu daļu, pašas par sevi nav Nedarbspēja.
3. **"Mēneša darbspējas procents"** nozīmē, konkrētā kalendāra mēnesī, kopējo minūšu skaitu mēnesī mīnus kopējo Nedarbspējas minūšu skaitu, dalītu ar kopējo minūšu skaitu mēnesī, izteiktu procentos.
4. **"Ieplānota apkope"** nozīmē plānotu Pakalpojuma apkopi, par kuru Wink ir sniedzis iepriekšēju paziņojumu saskaņā ar 4. sadaļu.
5. **"Pakalpojuma kredīts"** nozīmē kredītu, kas aprēķināts kā procentuālā daļa no maksām, ko jūs esat samaksājis vai jāmaksā par Partnera API attiecīgajā kalendāra mēnesī, un kas tiek piemērots nākotnes Partnera API maksām kā vienīgais un ekskluzīvs līdzeklis, ja netiek izpildīts darbspējas solījums.
6. **"Atbildes laiks"** nozīmē laika periodu no brīža, kad Wink saņem pareizi veidotu, autentificētu pieprasījumu Wink pakalpojuma robežā, līdz brīdim, kad Wink sāk atgriezt atbildi, izņemot tīkla pārvades laiku un jebkādu klienta puses laiku ārpus Wink kontroles.

### 2. Pieejamības un veiktspējas solījums

Wink izmantos komerciāli pamatotus centienus, lai nodrošinātu Partnera API pieejamību ar **Mēneša darbspējas procentu vismaz 99,9%** katrā kalendāra mēnesī līguma termiņā (turpmāk — "Darbspējas solījums"). Darbspējas solījums tiek mērīts Wink pakalpojuma robežā un neietver faktorus, kas nav Wink saprātīgā kontrolē, tostarp tos, kas aprakstīti 4. sadaļā. Wink uzraudzības sistēmas ir autoritatīvs ieraksts Mēneša darbspējas procenta un Atbildes laika mērīšanai.

Wink tālāk mērķē uz **95. percentila (P95) atbildes laiku zem 500 milisekundēm** veiksmīgiem, pareizi veidotiem, autentificētiem pieprasījumiem, mērītu Wink pakalpojuma robežā katrā kalendāra mēnesī (turpmāk — "Veiktspējas mērķis"). Veiktspējas mērķis neietver 4. sadaļā aprakstītos faktorus, pieprasījumus, kas atgriež lietojumprogrammas līmeņa kļūdas, ko izraisījis pats pieprasījums, un neparasti lielus vai sarežģītus partiju pieprasījumus. Veiktspējas mērķis ir pakalpojuma mērķis; 3. sadaļā minētie Pakalpojuma kredīti attiecas uz neizpildītu **Darbspējas solījumu** un ir vienīgais un ekskluzīvs līdzeklis par pieejamības trūkumiem.

### 3. Pakalpojuma kredīti

Ja Mēneša darbspējas procents nokrītas zem Darbspējas solījuma jebkurā kalendāra mēnesī, jums var būt tiesības saņemt Pakalpojuma kredītu, kas aprēķināts kā procentuālā daļa no Partnera API maksām, ko esat samaksājis vai jāmaksā par šo mēnesi, saskaņā ar šādu tabulu:

| Mēneša darbspējas procents | Pakalpojuma kredīts |
|---|---|
| Zem 99,9%, bet ne zem 99,0% | 10% |
| Zem 99,0%, bet ne zem 95,0% | 25% |
| Zem 95,0% | 50% |

1. **Kredīta pieprasīšana.** Lai saņemtu Pakalpojuma kredītu, jums jāiesniedz rakstisks pieprasījums Wink iekš **trīsdesmit (30) dienām** pēc kalendāra mēneša beigām, kurā radās darbspējas trūkums. Pieprasījumā jāiekļauj katra Nedarbspējas incidenta datumi un laiki, kā arī jebkādi pieejamie atbalsta žurnāli vai pierādījumi. Pēc šī termiņa iesniegtie pieprasījumi netiek izskatīti.
2. **Kredīta forma.** Apstiprinātie Pakalpojuma kredīti tiek piemēroti nākotnes Partnera API maksām un tiem nav skaidras naudas vērtības. Tie nav atmaksas un netiks izmaksāti, izņemot gadījumus, kad to prasa piemērojamie likumi.
3. **Maksimālais kredīts.** Kopējais Pakalpojuma kredītu apjoms par jebkuru kalendāra mēnesi nepārsniegs 50% no Partnera API maksām, ko esat samaksājis vai jāmaksā par šo mēnesi.
4. **Vienīgais un ekskluzīvs līdzeklis.** Pakalpojuma kredīti ir jūsu **vienīgais un ekskluzīvs līdzeklis** par jebkādu Wink neizpildi Darbspējas solījumā vai citu Partnera API pieejamības trūkumu.

### 4. Izņēmumi

Darbspējas solījums un jebkādi Pakalpojuma kredīti neattiecas uz un Nedarbspēja neietver jebkādu nepieejamību, apturēšanu, pasliktināšanos vai veiktspējas problēmu, kas rodas no vai attiecas uz:

1. **Ieplānotu apkopi**, par kuru Wink ir sniedzis iepriekšēju paziņojumu, ja šāds paziņojums ir dots saprātīgā laika posmā iepriekš, izmantojot kanālu, ko Wink parasti izmanto saziņai ar klientiem;
2. **Force majeure** notikumiem vai citiem iemesliem ārpus Wink saprātīgās kontroles, tostarp dabas katastrofām, valdības rīkojumiem, tīkla vai komunālo pakalpojumu pārtraukumiem un pakalpojuma atteikuma vai citiem ļaunprātīgiem uzbrukumiem;
3. problēmām, ko izraisījuši **jūsu** rīcība vai bezdarbība, jūsu aprīkojums, programmatūra vai tīkls, vai jebkāds **trešās puses** pakalpojums, produkts vai nodrošinātājs, kas nav Wink tiešā kontrolē;
4. jūsu **Pakalpojuma ļaunprātīga izmantošana** vai **Līguma**, šī SLA, pieņemamas lietošanas noteikumu vai piemērojamo ātruma ierobežojumu pārkāpums, tostarp satiksme, ko Wink saprātīgi uzskata par pārmērīgu, automatizētu ļaunprātīgu izmantošanu vai krāpniecību; un
5. jebkādu jūsu piekļuves **apturēšanu vai pārtraukšanu**, kas pienācīgi veikta saskaņā ar Līgumu, tostarp apturēšanu par maksājumu neizpildi.

### 5. Atbalsts un atbildes mērķi

Wink nodrošina atbalstu Partnera API standarta darba laikā, izņemot vietējos svētkus. Wink izmantos komerciāli pamatotus centienus, lai atzītu pareizi iesniegtus atbalsta pieprasījumus šādos mērķa atbildes laikos, pamatojoties uz jūsu piešķirto smaguma pakāpi un Wink saprātīgu apstiprinājumu:

| Smagums | Apraksts | Mērķa sākotnējā atbilde |
|---|---|---|
| **Sev 1 — Kritisks** | Partnera API nedarbojas vai nav izmantojams ražošanā bez risinājuma. | 4 stundas |
| **Sev 2 — Lielāks** | Būtiska funkcija ir traucēta vai pasliktināta; pastāv risinājums. | 1 darba diena |
| **Sev 3 — Mazāks** | Vispārīgi jautājumi, nelielas problēmas vai funkciju pieprasījumi. | 2 darba dienas |

Mērķa atbildes laiki apraksta, kad Wink cenšas veikt **sākotnējo kontaktu**; tie nav risinājuma laika garantija. Prioritārais atbalsts un pēc smaguma pakāpes balstītie mērķi attiecas uz līmeņiem, kuros tie ir norādīti kā iekļauti.

### 6. Dati un drošība

Wink uztur komerciāli pamatotas administratīvās, tehniskās un organizatoriskās pasākumus, kas paredzēti, lai aizsargātu Partnera API apstrādāto datu konfidencialitāti, integritāti un pieejamību, un periodiski pārskata šos pasākumus. Wink personas datu apstrādi regulē [Privātuma politika](/lv/privacy) un jebkādi datu apstrādes noteikumi Līgumā. Jūs esat atbildīgs par savas API piekļuves datu drošību, par jebkādu iegūto datu likumīgu izmantošanu un par nekavējošu Wink informēšanu par jebkādu aizdomīgu piekļuves datu kompromitāciju.

### 7. Atbildības ierobežojums

Pakalpojuma kredīti ir **vienīgais un ekskluzīvs līdzeklis** par jebkādu nepieejamību vai neizpildi Darbspējas solījumā, un tiek nodrošināti kā aizvietojums jebkurai citai atbildībai, kas izriet no šādas neizpildes. Izņemot tieši šajā SLA norādīto, Partnera API tiek nodrošināts "kā pieejams". Cik vien tas ir atļauts ar piemērojamo likumu, Wink kopējā atbildība, kas izriet no vai saistīta ar Pakalpojumu, ir ierobežota saskaņā ar Līgumu, un Wink nav atbildīgs par jebkādiem netiešiem, nejaušiem, īpašiem, sekām vai soda zaudējumiem, vai par zaudētiem ienākumiem, ieņēmumiem, datiem vai labu gribu, pat ja ir brīdināts par šādu zaudējumu iespējamību.

### 8. Termiņš, izmaiņas un izbeigšana

Šis SLA attiecas tik ilgi, kamēr jums ir aktīvs Partnera API abonements līmenī, kurā ir norādīts SLA piemērojamība. Wink var laiku pa laikam atjaunināt šo SLA; būtiskas izmaiņas tiks paziņotas caur kanālu, ko Wink parasti izmanto, lai sasniegtu klientus, un turpmāka Partnera API izmantošana pēc atjauninājuma stāšanās spēkā nozīmē atjauninātā SLA pieņemšanu. Šis SLA automātiski beidzas līguma vai jūsu Partnera API abonementa izbeigšanās vai termiņa beigās. Sadaļas, kas pēc savas būtības jāglabā pēc izbeigšanas — tostarp uzkrātās, bet neizmantotās Pakalpojuma kredītu tiesības, atbildības ierobežojums un definīcijas — paliek spēkā.
