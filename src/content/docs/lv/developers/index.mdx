Katru platformas funkciju var izsaukt ārēji. Šī sadaļa aptver autentifikāciju, API virsmu, notikumu piegādi un atsauces datus aiz tās.

## Sāciet šeit

- [Ātrā sākšana](/lv/developers/quickstart/) — no nulles līdz dzīviem viesnīcu cenām un jūsu pirmajai testa rezervācijai testēšanas vidē.
- [Izveidojiet uz Wink bāzes](/lv/developers/build-on-wink/) — ko varat izveidot un kurš API ir piemērots.
- [Iestatīšana](/lv/developers/setup/) — izveidojiet lietotni un saņemiet akreditācijas datus.
- [Autentifikācija](/lv/developers/authentication/) — OAuth2 sesijas un piekļuves tiesības.

## API virsma

- [REST un gRPC](/lv/developers/rest-and-grpc/) — divi pārvades veidi un kad katru izmantot.
- [Ģeolokācija](/lv/developers/geolocation/) — telpiska meklēšana pār rezervējamo inventāru.
- [Taksonomija](/lv/developers/taxonomy/) — OTA kodi, atbalstītās valodas un valūtas.

## Notikumi un sinhronizācija

- [Webhook integrācija](/lv/developers/webhook-integration/) — abonējiet platformas notikumus.
- [Webhook notikumu katalogs](/lv/developers/webhook-events/) — katrs notikums, ko platforma izstaro.
- [Rezervāciju sinhronizācija](/lv/developers/booking-sync/) — uzturiet rezervācijas saskaņotas ar PMS vai kanālu pārvaldnieku.
