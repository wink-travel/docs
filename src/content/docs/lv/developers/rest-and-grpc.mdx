Wink piedāvā divus transporta veidus. Kuru izmantot, ir atkarīgs no tā, ar kuru API jūs integrējaties.

| | Transports | Shēma | Dokumentācija |
| --- | --- | --- | --- |
| Lielākā daļa Wink API | REST pār HTTPS | OpenAPI 3 | Jebkura grupa sadaļā **API** sānjoslā |
| Partneru integratora API | gRPC pār HTTP/2 | Protocol Buffers | [Partneris](/lv/partner-api/partner/) |

<Aside type="note" title="Mēs vairs nepublicējam valodu SDK">
  Rokas vadīti SDK atpalika no API, ko tie aptvēra, un nekad nepiedāvāja vajadzīgo valodu. Ģenerējiet klientu no shēmas — tā vienmēr ir aktuāla — vai ļaujiet mūsu MCP serverim uzrakstīt integrācijas kodu, kas pielāgots jūsu lietošanas gadījumam.
</Aside>

## Ģenerēt REST klientu

Katrs API grupas publicē OpenAPI 3 dokumentu. Norādiet jebkuru OpenAPI ģeneratoru uz to, un jūs saņemsiet tipizētu klientu jūsu valodā.

```bash
# Grupas specifikācija tiek pasniegta blakus tās atsauces lapai.
curl -o wink-extranet.json https://api.wink.travel/v3/api-docs/extranet

npx @openapitools/openapi-generator-cli generate \
  -i wink-extranet.json -g typescript-fetch -o ./wink-client
```

## Ģenerēt gRPC klientu

Partneru integratora API ir gRPC. Jūs ģenerējat klientu no `.proto` shēmas, ko Wink publicē divos veidos:

- **Servera atspoguļojums** — serveris apraksta sevi, tāpēc rīki kā `grpcurl`, Postman un Insomnia var atklāt shēmu izpildes laikā bez failu lejupielādes. Atspoguļojumam nepieciešams tas pats piekļuves tokens kā jebkuram citam izsaukumam.
- **`.proto` faili**, ja vēlaties shēmu saglabāt un ģenerēt iepriekš.

```bash
# Atklājiet shēmu no darbojoša servera (autentificēts).
grpcurl -H "authorization: Bearer $WINK_TOKEN" \
  partner.wink.travel:443 list

# Tad ģenerējiet klientu — šeit Go; katra atbalstītā valoda darbojas līdzīgi.
protoc --go_out=. --go-grpc_out=. partner_lookup.proto
```

Izsaukumi nes jūsu piekļuves tokenu `authorization` metadatu galvenē, tieši tāpat kā REST to nes `Authorization` galvenē. Kļūdas tiek saņemtas kā gRPC statusa kods atbildes pēcgabalos, nevis kā HTTP statusa kods — [Partneru atsauce](/lv/partner-api/partner/) uzskaita statusus, ko jāgaida.

## Vai ļaujiet MCP serverim to uzrakstīt

Ja izmantojat AI kodēšanas palīgu, mūsu MCP serveris ir ātrākais ceļš. Tas piedāvā Wink API kā rīkus, ko jūsu palīgs var izsaukt un analizēt, tāpēc, nevis ģenerējot pilnu klientu un meklējot galapunktus pats, jūs aprakstāt, ko veidojat, un saņemat integrācijas kodu, kas pielāgots tam.
