Wink piedāvā divus autentificētus MCP serverus. Abi izmanto **interaktīvu OAuth2 pieteikšanos** (PKCE autorizācijas koda plūsma) — jūsu AI aģents atver pārlūkprogrammas cilni, lai jūs varētu pieteikties ar savu Wink kontu. Nav jāuztur klienta noslēpumi.

| Serveris | URL | Ko tas dara |
|--------|-----|--------------|
| **Inventory API** | `https://api.wink.travel/mcp` | Inventārs, rezervācijas, cenas, pārdošanas kanāli, analītika un visas platformas operācijas |
| **Integrations** | `https://integrations.wink.travel/mcp` | Kanālu pārvaldnieku integrācijas — sinhronizē īpašumus, cenas un pieejamību ar OTA |

---

## Kā darbojas autentifikācija

Wink MCP serveri izmanto **OAuth2 autorizācijas koda + PKCE** plūsmu un atbalsta **dinamisko klienta reģistrāciju (RFC 7591)**. Šeit ir, kas notiek, kad pieslēdzaties pirmo reizi:

1. Jūsu AI klients atrod autorizācijas serveri no MCP gala punkta `/.well-known/oauth-protected-resource` metadatiem.
2. Klients pats reģistrējas, izmantojot **dinamisko klienta reģistrāciju** — nav nepieciešama manuāla lietotnes iestatīšana.
3. Klients atver **pārlūkprogrammas cilni** uz `https://iam.wink.travel`. Jūs piesakāties ar savu Wink kontu un apstiprināt pieprasītās atļaujas piekrišanas ekrānā.
4. Wink izsniedz **piekļuves tokenu**, kas ir saistīts ar jūsu kontu un identitāti.
5. AI klients pievieno tokenu katram MCP pieprasījumam. Visi rīku rezultāti automātiski tiek ierobežoti jūsu pārvaldības vienībai.
6. Tokeni beidzas pēc 3 stundām. Jūsu AI klients tos klusējot atjauno fonā bez atkārtotas prasības.

Katrs rīka izsaukums tiek veikts **jūsu identitātes vārdā** — tās pašas ACL tiesības, kas aizsargā tīmekļa portālu, attiecas arī uz AI aģentu.

## Savienojiet savu AI klientu

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Pārliecinieties, ka Claude Code ir atjaunināts:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Pievienojiet Wink Inventory MCP serveri:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code sazinās ar serveri, atrod autorizācijas serveri un atver jūsu noklusējuma pārlūkprogrammu.

4. **Piesakieties Wink** un apstipriniet atļauju pieprasījumu piekrišanas ekrānā.

5. Claude Code apstiprina savienojumu. Ierakstiet `/mcp`, lai pārbaudītu, vai serveris ir redzams un tā rīki ir ielādēti.
</Steps>

Lai pievienotu arī Integrations serveri:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Dalieties ar savu komandu]
Pievienojiet `--scope project` pie `claude mcp add`, un Claude Code ierakstīs servera URL `.mcp.json` failā projekta saknē. Apstipriniet šo failu — katrs komandas loceklis pirmo reizi pieslēdzoties veic savu pārlūkprogrammas pieteikšanos.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Rediģējiet Claude Desktop konfigurācijas failu:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. Pievienojiet MCP serveru ierakstus:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **Pilnībā aizveriet un restartējiet** Claude Desktop (izmantojiet Quit no izvēlnes joslas — loga aizvēršana nav pietiekama).

4. Claude Desktop atver pārlūkprogrammas cilni katram jaunajam serverim. Piesakieties Wink un apstipriniet atļaujas.

5. Apakšējā rīkjoslā spraudņa ikona rāda abus serverus kā pieslēgtus.
</Steps>

  </TabItem>

<Steps>


2. Atveriet (vai izveidojiet) Codex konfigurācijas failu:
   - **macOS / Linux:** `~/.codex/config.json`
   - **Windows:** `%USERPROFILE%\.codex\config.json`

3. Pievienojiet Wink MCP serveru ierakstus:

   ```json title="~/.codex/config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

4. Sāciet Codex. Pirmreizējā lietošanā Codex atver pārlūkprogrammas cilni uz `https://iam.wink.travel`.

5. **Piesakieties Wink** un apstipriniet pieprasītās atļaujas.

6. Codex apstiprina savienojumu. Izpildiet `codex` un lūdziet uzskaitīt pieejamos rīkus, lai pārbaudītu, vai Wink serveri darbojas.
</Steps>

:::note
Codex CLI MCP atbalsts prasa versiju **1.0** vai jaunāku. Pārbaudiet ar `codex --version` un atjauniniet ar `npm install -g @openai/codex`.
:::

  </TabItem>
  <TabItem label="ChatGPT">

MCP serveru atbalsts ir pieejams **ChatGPT darbvirsmas lietotnē** Plus, Pro, Team un Enterprise abonentiem.

<Steps>
1. Lejupielādējiet un instalējiet [ChatGPT darbvirsmas lietotni](https://openai.com/chatgpt/download/), ja vēl neesat to izdarījis.

2. Atveriet lietotni un noklikšķiniet uz **jūsu profila ikonas** augšējā labajā stūrī, pēc tam izvēlieties **Iestatījumi**.

3. Dodieties uz **Savienotāji** (vai **MCP serveri** atkarībā no lietotnes versijas) un noklikšķiniet **Pievienot**.

4. Ievadiet Wink Inventory servera URL:
   ```
   https://api.wink.travel/mcp
   ```
   Pēc tam noklikšķiniet **Savienot**.

5. ChatGPT atver pārlūkprogrammas cilni uz `https://iam.wink.travel`. **Piesakieties Wink** un apstipriniet atļaujas.

6. Atkārtojiet 4.–5. soli Integrations serverim:
   ```
   https://integrations.wink.travel/mcp
   ```

7. Abi serveri parādās jūsu Savienotāju sarakstā. Sāciet jaunu tērzēšanu — Wink rīki ir pieejami automātiski.
</Steps>

:::note[Web lietotnes ierobežojums]
MCP serverus var konfigurēt tikai **darbvirsmas lietotnē**. ChatGPT tīmekļa saskarne chatgpt.com neatbalsta pielāgotus MCP serverus.
:::

  </TabItem>

   - **macOS / Linux:** `~/.cursor/mcp.json`
   - **Windows:** `%USERPROFILE%\.cursor\mcp.json`

2. Pievienojiet Wink MCP serveru ierakstus:

   ```json title="~/.cursor/mcp.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }

   ```

3. Atveriet Cursor. Dodieties uz **Iestatījumi → Cursor iestatījumi → MCP** un pārliecinieties, ka abi serveri ir ar zaļu statusa indikatoru. Ja tie ir sarkani, noklikšķiniet **Atjaunot**.

## Tiesības

Apstiprinot piekrišanas ekrānu, redzēsiet, kādas tiesības aģents pieprasa. MCP klienti izmanto to pašu atļauju terminoloģiju kā pārējā platforma — skatiet pilnu
[atsauci par tiesībām autentifikācijas lapā](/lv/developers/authentication#scopes).

Divas lietas ir specifiskas MCP:

- **`mcp.read`, `mcp.write`, `mcp.remove` tiesības ir papildus nepieciešamas**, lai atvērtu MCP transportu. Klients ar `mcp.*` tiesībām tiek pieņemts `/mcp`, bet katrs rīks, ko tas izsauc, joprojām ievēro gala punkta sadaļas tiesības (piemēram, `booking.read`).
- **AI klients pieprasa tikai nepieciešamās tiesības.** Jūs varat noraidīt atsevišķas atļaujas piekrišanas ekrānā — rīki, kas prasa noraidītu tiesību, izsniegs kļūdu, kad tie tiks izsaukti.

## Problēmu novēršana

**Pārlūkprogrammas cilne neatveras**

Jūsu AI klients var vēl neatbalstīt interaktīvo PKCE plūsmu. Pārbaudiet, vai izmantojat jaunāko versiju:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT darbvirsmas lietotne:** atjauniniet, izmantojot lietotnes iebūvēto atjauninātāju

**`401 Unauthorized` pēc pieteikšanās**

Jūsu kešotais tokens var būt novecojis. Noņemiet un pievienojiet serveri atkārtoti, lai izraisītu jaunu pieteikšanos:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

Claude Desktop un ChatGPT gadījumā noņemiet servera ierakstu iestatījumos, restartējiet lietotni un pievienojiet to no jauna.

**`403 Forbidden` izsaucot konkrētu rīku**

Rīks prasa tiesības, kuras neapstiprinājāt piekrišanas ekrānā. Pieslēdziet serveri atkārtoti — piekrišanas ekrāns parādīsies vēlreiz, un jūs varēsiet apstiprināt trūkstošo atļauju.

**Serveris ir redzams, bet rīka izsaukumi atgriež "account not found"**

Jūs esat pieteicies Wink kontā, kuram nav pārvaldības vienības. Dodieties uz [Wink portālu](https://app.wink.travel) un pārliecinieties, ka jūsu konts ir iestatīts pirms MCP servera lietošanas.

**Tokens beidzas sesijas vidū**

Tokeni ir derīgi 3 stundas. Claude Code un Claude Desktop klusējot atjauno tokenus bez sesijas pārtraukuma. Ja pēc ilgas neaktivitātes redzat autentifikācijas kļūdas, ierakstiet jaunu ziņu — klients automātiski pārreģistrēsies.

**Codex CLI rāda "MCP server unreachable"**

Pārliecinieties, ka jūsu `~/.codex/config.json` ir derīgs JSON (bez pēdējām komatiem) un `"type": "http"` ir iestatīts. Codex prasa HTTP transportu attāliem serveriem; stdio transports ir paredzēts tikai lokāliem binārajiem failiem.

**ChatGPT "Savienotāji" izvēlne nav redzama**

MCP atbalsts prasa ChatGPT darbvirsmas lietotnes versiju **1.2024.352** vai jaunāku un aktīvu Plus, Pro, Team vai Enterprise abonementu. Atjauniniet lietotni un pārbaudiet plānu sadaļā Iestatījumi → Konts.

**Cursor serveris rāda sarkanu / "Neizdevās pieslēgties"**

Pārliecinieties, ka jūsu `~/.cursor/mcp.json` ir derīgs JSON un satur `"type": "http"`. Pēc tam dodieties uz **Iestatījumi → Cursor iestatījumi → MCP** un noklikšķiniet **Atjaunot**. Ja kļūda saglabājas, pilnībā restartējiet Cursor — konfigurācijas izmaiņas ne vienmēr tiek uzreiz nolasītas bez restartēšanas.

**Windsurf MCP serveri nav redzami iestatījumos**

Windsurf prasa pilnu restartu (ne tikai loga pārlādi), lai nolasītu izmaiņas `mcp_config.json`. Izmantojiet **Fails → Iziet** un palaidiet no jauna. Ja serveri joprojām nav redzami, pārliecinieties, ka izmantojat Windsurf versiju **1.4+** caur **Palīdzība → Par Windsurf**.

**Cline opcija "Pievienot serveri" nav redzama**

MCP serveru pārvaldnieks prasa Cline versiju **2.0** vai jaunāku. Atveriet VS Code paplašinājumu paneli, atrodiet Cline un noklikšķiniet **Atjaunināt**, ja ir pieejams atjauninājums. Pēc atjaunināšanas pārlādējiet VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
