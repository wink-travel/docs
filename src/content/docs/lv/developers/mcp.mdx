Wink MCP rīki tiek publicēti kā **rīku komplekti** — fokusēti galapunkti, katrs aptver vienu darba jomu. Jūs savienojat savu AI klientu ar vienu vai diviem, kas atbilst jūsu darbam, nevis ar visiem.

Katrs galapunkts izmanto **interaktīvu OAuth2 pieteikšanos** (PKCE autorizācijas koda plūsma): jūsu AI aģents atver pārlūkprogrammas cilni, jūs piesakāties ar savu Wink kontu, un tas arī viss. Nav klienta slepeno atslēgu pārvaldīšanas.

```bash title="Kanālu pārvaldnieka integrators savienojas ar vienu galapunktu"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="Viesnīcas pārvaldnieks, kas pārvalda savas cenas, savienojas ar citu"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## Kāpēc rīki ir sadalīti pa galapunktiem

Wink piedāvā apmēram 500 rīkus. Visus tos nodot aģentam uzreiz ir tehniski iespējams — bet slikta ideja.

**Rīku definīcijas izmanto kontekstu.** Katrs rīks, ko MCP serveris reklamē, tiek ielādēts modeļa konteksta logā pirms darba veikšanas, kopā ar tā aprakstu un pilnu parametru shēmu. Pieci simti no tiem patērē lielu daļu no budžeta, kas nepieciešams jūsu faktiskajam uzdevumam, katrā pieprasījumā.

**Izvēles kvalitāte samazinās, palielinoties sarakstam.** Aģents, kas izvēlas no 500 līdzīgi nosauktiem rīkiem, pieņem sliktākas izvēles nekā tas, kas izvēlas no 40. Ja integrējat kanālu pārvaldnieku, aptuveni divdesmit rīki jums ir nozīmīgi; pārējie 480 ir troksnis, kas apgrūtina pareizā rīka atrašanu.

**Darbs ir patiesi atdalāms.** Kāds, kas sinhronizē pieejamību no PMS, un kāds, kas veido filiāļu nolaišanās lapas, gandrīz nesadala rīkus. Darba sadalīšana nozīmē, ka katrs savienojums nes viena darba vārdu krājumu.

<Aside type="caution" title="Rīku komplekti nav atļaujas">
Šaura rīku komplekta izvēle **neierobežo** to, ko jūsu konts var darīt, un plaša komplekta izvēle nedod neko papildus. Katrs rīks ievēro tās pašas konta atļaujas kā tīmekļa portāls, jūsu pierakstītās identitātes ietvaros. Ja jūsu konts nevar atcelt rezervāciju Wink Portal, arī aģents to nevar — neatkarīgi no tā, pie kura galapunkta tas ir pieslēgts.

Izvēlieties rīku komplektus **fokusa dēļ**, nevis drošības.
</Aside>

### `https://integrations.wink.travel` — kanālu pārvaldnieku integrācijas

Viens galapunkts, jo šis saimniekdators pastāv vienam darbam.

| Galapunkts | Rīki | Ko tas aptver |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | Kanālu pārvaldnieka, PMS vai CRS integrācijas savienošana un pārbaude |

<Aside type="note" title="Kanālu pārvaldnieka integrācija pret savu cenu pārvaldību">
Tie ir dažādi darbi dažādiem cilvēkiem, un tiem nav kopīga galapunkta.

**Kanālu pārvaldnieks, PMS vai CRS pārdevējs** integrējas vienreiz caur `integrations.wink.travel/mcp/channel-manager`, un pēc tam apmainās ar īpašumiem, cenām, pieejamību un rezervācijām caur šo integrāciju. Šis vienīgais galapunkts ir visa virsma.

**Viesnīcas pārvaldnieks, kas maina savas cenas manuāli,** izmanto ekstraneta rīku komplektus `api.wink.travel` — `/mcp/extranet/rates` un līdzīgos. Tie nav daļa no kanālu pārvaldnieka integrācijas, un integratoram nav iemesla tos izmantot.

Konta administrēšana arī atrodas `api.wink.travel`, `/mcp/settings`. Integrācijas saimniekdatorā nav `/mcp/settings`.
</Aside>

Katrs galapunkts arī satur `ping` rīku, lai jūs varētu pārbaudīt, vai savienojums ir aktīvs, pirms lūgt tam veikt reālu darbu.

### Agentiskas maksāšanas iespējas

Pilnam ceļotāja rezervācijas plūsmas nodrošināšanai savienojiet **Wink Booking Engine** pie `https://api.wink.travel/mcp/booking-engine` un saderīgu **maksājumu maku**. Pievienojot Wink MCP, tiek atvērta pārlūkprogrammas pieteikšanās un atļauju izvēle; jūsu klients pēc tam apstrādā autentifikāciju.

Booking Engine ietver galamērķa meklēšanu, viesnīcu un numuru meklēšanu, `agentic_booking_quote`, `agentic_booking_pay`, `agentic_booking_book`, rezervāciju izgūšanu un kvītis, kad šajā vidē ir iespējota agentiska rezervēšana un maksāšana. Skatiet [Agentic Payments](/lv/developers/agentic-payments/) savienojuma iestatīšanai, izvēlētajām atļaujām un soļiem no meklēšanas līdz apstiprinājumam.

## Kuri rīku komplekti man ir nepieciešami?

| Ja jūs esat… | Savienojieties ar |
|---|---|
| **Integrējat kanālu pārvaldnieku, PMS vai CRS** | `integrations.wink.travel/mcp/channel-manager` — tikai šo |
| **Pārvaldāt īpašuma saturu** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **Pārvaldāt numurus un numuru tipus** | `/mcp/extranet/facilities` |
| **Pārvaldāt cenas un pieejamību** | `/mcp/extranet/rates` |
| **Vadāt ikdienas rezervācijas** | `/mcp/extranet/operations` |
| **Palielināt izplatīšanu** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **Veidojat filiāļu lapas** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **Vadāt link-in-bio lapas** | `/mcp/link-manager` + `/mcp/social` |
| **Veicat rezervācijas ceļotāju vārdā** | `/mcp/travel-agent` |
| **Saskaņojat naudu** | `/mcp/payment` |
| **Rezervējat numuru ar AI aģentu** | `/mcp/booking-engine` + saderīgs maksājumu maks — skatiet [Agentic Payments](/lv/developers/agentic-payments/) |
| **Veidojat rezervēšanas pieredzi** | `/mcp/booking-engine`; pēc izvēles `/mcp/reference` papildu meklēšanai |

**Booking Engine ietver galveno rezervēšanas darba plūsmu.** Tas nodrošina konta un pielāgošanas atklāšanu, galamērķa meklēšanu, viesnīcu pieejamību un numuru cenu detaļas, iepirkumu grozus, norēķinus un ceļotāju rezervāciju pārvaldību. Agentiskas rezervēšanas un maksāšanas rīki ir iekļauti, ja tie ir iespējoti šajā vidē.

Pilsētas viesnīcu meklēšanai izmantojiet `destination_lookup_search_suggestions`, lai noteiktu galamērķi, pēc tam `inventory_search_city`, lai atrastu pieejamās viesnīcas un cenas. Abi rīki ir `/mcp/booking-engine`, tāpēc šai plūsmai nav nepieciešams Reference savienojums.

Pievienojiet `/mcp/reference`, ja nepieciešamas atbalsta meklēšanas, piemēram, valstis, valūtas un valūtas kursi, atbalstītās valodas, laika joslas, plašākas ģeogrāfiskās meklēšanas, OTA klasifikācijas vai publiskās īpašuma zināšanas. Tie ir izvēles papildinājumi rezervēšanas plūsmai.

Sāciet ar vienu. Pievienojiet citu, kad atklājat, ka kaut ko nevar izdarīt — katrs savienojums ir neatkarīgs, un viena pievienošana nekad neietekmē pārējos.

<Aside type="tip" title="Vēlaties visu?">
`https://api.wink.travel/mcp` un `https://integrations.wink.travel/mcp` joprojām ir pieejami un apkalpo **visus** rīkus savā saimniekdatorā. Tie ir noderīgi, lai izpētītu, kas pastāv, bet mēs tos neiesakām ikdienas darbam: rīku saraksts ir pietiekami liels, lai aizēnotu jūsu uzdevumu un pasliktinātu aģenta rīku izvēli. Dodiet priekšroku iepriekš minētajiem rīku komplektiem.
</Aside>

## Kā darbojas autentifikācija

Wink MCP serveri izmanto **OAuth2 autorizācijas koda + PKCE** plūsmu un atbalsta **Dinamisko klienta reģistrāciju (RFC 7591)**. Šeit ir, kas notiek, kad pieslēdzaties pirmo reizi:

1. Jūsu AI klients atrod autorizācijas serveri no MCP galapunkta `/.well-known/oauth-protected-resource` metadatiem.
2. Klients pats reģistrējas, izmantojot **Dinamisko klienta reģistrāciju** — nav nepieciešama manuāla lietotnes iestatīšana.
3. Klients atver **pārlūkprogrammas cilni** uz `https://iam.wink.travel`. Jūs piesakāties ar savu Wink kontu un apstiprināt pieprasītās atļaujas piekrišanas ekrānā.
4. Wink izsniedz **piekļuves žetonu**, kas ir saistīts ar jūsu kontu un identitāti.
5. AI klients pievieno žetonu katram MCP pieprasījumam. Visi rīku rezultāti tiek automātiski ierobežoti jūsu pārvaldības vienībai.
6. Žetoni beidzas pēc 3 stundām. Jūsu AI klients klusējot atjauno žetonus fonā bez atkārtotas piekrišanas pieprasīšanas.

Katrs rīka izsaukums tiek veikts **jūsu identitātes vārdā** — tās pašas ACL noteikumi, kas aizsargā tīmekļa portālu, attiecas arī uz AI aģentu.

## Savienojiet savu AI klientu

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Pārliecinieties, ka Claude Code ir atjaunināts:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Izvēlieties rīku komplektu no [augstāk redzamā katalogā](#endpoint-directory) un pievienojiet to. Piemēram, cenas un pieejamība:
   ```bash
   claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
   ```

3. Claude Code sazinās ar serveri, atrod autorizācijas serveri un atver jūsu noklusējuma pārlūkprogrammu.

4. **Pierakstieties Wink** un apstipriniet atļauju pieprasījumu piekrišanas ekrānā.

5. Claude Code apstiprina savienojumu. Ierakstiet `/mcp`, lai pārbaudītu, vai serveris parādās un tā rīki ir ielādēti.
</Steps>

Pievienojiet tik daudz rīku komplektu, cik nepieciešams jūsu darbam — katrs ir atsevišķs servera ieraksts ar savu nosaukumu:
```bash
claude mcp add wink-operations https://api.wink.travel/mcp/extranet/operations --transport http
claude mcp add wink-analytics  https://api.wink.travel/mcp/analytics           --transport http
```

Jūs pierakstāties tikai vienreiz. Pēc pirmās pārlūkprogrammas apstiprināšanas Claude Code atkārtoti izmanto jūsu Wink sesiju papildu Wink galapunktiem.

:::tip[Dalieties ar savu komandu]
Pievienojiet `--scope project` pie `claude mcp add`, un Claude Code ieraksta servera URL `.mcp.json` failā repozitorija saknē. Apstipriniet šo failu — katrs komandas loceklis saņem tos pašus rīku komplektus, un katrs pirmo reizi pieslēdzoties veic savu pārlūkprogrammas pieteikšanos.
:::

## Atļauju jomas

Apstiprinot piekrišanas ekrānu, redzēsiet sadalījumu par to, ko aģents pieprasa. MCP klienti izmanto to pašu atļauju vārdu krājumu kā pārējā platforma — skatiet pilnu [jomu atsauci Autentifikācijas lapā](/lv/developers/authentication#scopes).

Divas lietas ir specifiskas MCP:

- **`mcp.read` `mcp.write` `mcp.remove` jomas ir papildus nepieciešamas**, lai atvērtu MCP transportu. Klients ar `mcp.*` jomu tiek pieņemts jebkurā Wink MCP galapunktā, bet katrs rīks, ko tas izsauc, joprojām ievēro galapunkta sadaļas jomu (piemēram, `booking.read`).
- **AI klients pieprasa tikai tās jomas, kas tam nepieciešamas.** Jūs varat noraidīt atsevišķas atļaujas piekrišanas ekrānā — rīki, kas prasa noraidītu jomu, izsniegs kļūdu, kad tiks izsaukti.

**Rīku komplekti neko no tā nemaina.** Galapunkts, pie kura pieslēdzaties, nosaka, kuri rīki ir *uzskaitīti*, nevis ko tie *drīkst darīt*. Savienojums ar `/mcp/payment` nedod nekādas finanšu atļaujas, kas jums jau nav, un savienojums ar `/mcp/reference` neaptur rīku tur ievērot savu jomu. Autorizācija tiek lemta katram rīka izsaukumam, no jūsu žetona un konta pilnvarām.

## Problēmu novēršana

**Pārlūkprogrammas cilne neatveras**

Jūsu AI klients var vēl neatbalstīt interaktīvo PKCE plūsmu. Pārbaudiet, vai izmantojat jaunāko versiju:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT darbvirsma:** atjauniniet no lietotnes iebūvētā atjauninātāja

**`401 Unauthorized` pēc pieteikšanās**

Jūsu kešotais žetons var būt novecojis. Noņemiet un pievienojiet serveri atkārtoti, lai izraisītu jaunu pieteikšanos:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

Claude Desktop un ChatGPT noņemiet servera ierakstu iestatījumos, restartējiet lietotni un pievienojiet to vēlreiz.

**`403 Forbidden` izsaucot konkrētu rīku**

Rīks prasa jomu, ko neapstiprinājāt piekrišanas ekrānā, vai atļauju, kas nav jūsu kontā. Pārslēdziet serveri — piekrišanas ekrāns parādīsies vēlreiz, un varēsiet apstiprināt trūkstošo atļauju. Ja tas joprojām neizdodas, rīks prasa konta atļauju, kas jums nav; savienojums ar citu rīku komplektu nepalīdzēs, jo rīku komplekti nedod atļaujas.

**Rīks, kas man vajadzīgs, nav sarakstā**

Iespējams, esat pieslēdzies rīku komplektam, kas neaptver šo darbu. Pārbaudiet [galapunkta katalogu](#endpoint-directory) un pievienojiet rīku komplektu, kas to aptver — savienojumi ir neatkarīgi, tāpēc viena pievienošana neko nemaina pārējos. Ja neesat pārliecināts, kurš to satur, īslaicīgi pieslēdzieties `https://api.wink.travel/mcp`, atrodiet rīku un tad noskaidrojiet, kurš rīku komplekts to uzskaita.

**`404 Not Found` uz rīku komplekta galapunkta**

Pārbaudiet ceļu uzmanīgi — ligzdotajiem rīku komplektiem ir divi segmenti (`/mcp/extranet/rates`, nevis `/mcp/extranet-rates`), bet plakanajiem ir viens (`/mcp/link-manager`). Ņemiet vērā, ka *neautentificēts* pieprasījums uz jebkuru ceļu zem `/mcp` atgriež `401`, nevis `404`, tāpēc tikai `401` nepasaka, vai galapunkts pastāv.

**Savienojos ar `api.wink.travel/mcp/channel-manager` un nesaņēmu neko**

Šāds galapunkts nepastāv. Kanālu pārvaldnieka integrācija tiek apkalpota tikai no `https://integrations.wink.travel/mcp/channel-manager`. Ja jums arī jālasa vai jāmaina īpašuma cenas manuāli, tas ir atsevišķs darbs atsevišķā galapunktā — skatiet `/mcp/extranet/rates`.

**Serveris parādās, bet rīku izsaukumi atgriež "account not found"**

Jūs esat pierakstījies Wink kontā, kam nav pārvaldības vienības. Dodieties uz [Wink Portal](https://app.wink.travel) un pārliecinieties, ka jūsu konts ir iestatīts, pirms lietojat MCP serveri.

**Žetons beidzas sesijas vidū**

Žetoni ir derīgi 3 stundas. Claude Code un Claude Desktop klusējot atjauno žetonus bez pārtraukuma. Ja pēc ilga dīkstāves perioda redzat autentifikācijas kļūdas, ierakstiet jaunu ziņojumu — klients automātiski pārreģistrēsies.

**Codex CLI rāda "MCP server unreachable"**

Pārbaudiet, vai jūsu `~/.codex/config.json` ir derīgs JSON (bez pēdējām komatiem) un `"type": "http"` ir iestatīts. Codex prasa HTTP transportu attāliem serveriem; stdio transports ir tikai lokāliem binārajiem failiem.

**ChatGPT "Connectors" izvēlne nav redzama**

MCP atbalsts prasa ChatGPT darbvirsmas lietotnes versiju **1.2024.352** vai jaunāku un aktīvu Plus, Pro, Team vai Enterprise abonementu. Atjauniniet lietotni un pārbaudiet plānu Iestatījumos → Konts.

**Cursor serveris rāda sarkanu / "Failed to connect"**

Pārbaudiet, vai jūsu `~/.cursor/mcp.json` ir derīgs JSON un satur `"type": "http"`. Tad dodieties uz **Iestatījumi → Cursor iestatījumi → MCP** un noklikšķiniet **Atsvaidzināt**. Ja kļūda saglabājas, pilnībā restartējiet Cursor — konfigurācijas izmaiņas ne vienmēr tiek ņemtas vērā bez restartēšanas.

**Windsurf MCP serveri nav redzami iestatījumos**

Windsurf prasa pilnu restartu (ne tikai loga pārlādi), lai ielādētu izmaiņas `mcp_config.json`. Izmantojiet **Fails → Iziet** un palaidiet atkārtoti. Ja serveri joprojām nav redzami, pārliecinieties, ka izmantojat Windsurf **1.4+** caur **Palīdzība → Par Windsurf**.

**Cline "Add Server" opcija nav redzama**

MCP serveru pārvaldnieks prasa Cline **2.0** vai jaunāku versiju. Atveriet VS Code paplašinājumu paneli, atrodiet Cline un noklikšķiniet **Atjaunināt**, ja ir pieejams atjauninājums. Pēc atjaunināšanas pārlādējiet VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
