Цей посібник проведе туристичну агенцію від реєстрації до першого бронювання клієнта. Також він пояснює два способи роботи агенції на Wink, щоб ви могли обрати правильний перед початком.

## Перед початком

Вам знадобиться:

- Дані вашої компанії.
- Номер реєстрації туристичної агенції або ваш код IATA, якщо він у вас є.
- Банківський рахунок для отримання комісії.

## Оберіть спосіб роботи

| | Стандартний (більшість агенцій) | Збір платежів агентом |
|---|---|---|
| Як ви бронюєте | У порталі Wink або через Partner API | Через [Partner API](/uk/integrations/partner-api/), зі своєї системи |
| Хто приймає платіж клієнта | Збирається для готелю, який залишається продавцем | Ви, як продавець. |
| Що ви заробляєте | **10% стандартна комісія** з кожного бронювання | Комісія за вашим договором з кожним готелем |
| Що ви платите Wink | Нічого | **1,5%** комісія за бронювання від вартості, виставляється щомісяця, плюс використання Partner API понад безкоштовний ліміт |
| Оплата готелю | Виконується за вас | Ви оплачуєте кожен готель напряму за власним договором |
| Повернення, чарджбеки, відповідність платежам | Виконується за вас | Ваша відповідальність |
| Затвердження | Ваша реєстрація перевіряється перед бронюванням | Ваша реєстрація перевіряється, плюс письмове схвалення Wink для цього способу з кредитним лімітом |

Wink перевіряє реєстрацію кожної туристичної агенції. Більшість агенцій використовують стандартний спосіб. Збір платежів агентом — для **партнерів API**: агенцій, які бронюють через Partner API зі своєї системи, вже збирають платежі клієнтів за власною ліцензією і укладають договори напряму з готелями.

## Крок 1: Зареєструйте агенцію

<Steps>
1. Перейдіть на [app.wink.travel](https://app.wink.travel), натисніть `Sign-In / Register` і зареєструйтесь.

2. Натисніть `Accounts` у лівій бічній панелі, потім `Create` і оберіть **I am a Travel Agent**.

3. Заповніть дані вашої агенції. Оберіть **Company** як тип організації: це визначає, як вам платитимуть. Див. [Create Account](/uk/portal/create-account/).

4. Якщо ви плануєте збирати платежі самостійно через Partner API, оберіть цей спосіб під час реєстрації. Це запит, а не затвердження. Див. [Крок 6](#step-6-collect-payment-yourself-api-partners-only).

5. Wink перевіряє кожну реєстрацію туристичної агенції. Ми надсилаємо листа на вашу зареєстровану адресу з проханням надати документи: дані компанії та номер реєстрації або код IATA. Ви зможете бронювати після затвердження реєстрації.
</Steps>

## Крок 2: Додайте банківський рахунок

Перейдіть у `Account > Bank Accounts`, додайте рахунок вашої агенції і позначте його як **Primary**. Комісія виплачується туди банківським переказом. Wink здійснює виплати через Revolut, тому бізнес-рахунок Revolut — найзручніший варіант, але підходить будь-який банківський рахунок. Див. [Bank Accounts](/uk/portal/settings/payouts/).

## Крок 3: Знайдіть готелі для клієнта

<Steps>
1. Натисніть `Browse > Hotels` у головному меню.

2. Шукайте за напрямком, датами та кількістю гостей, фільтруйте, доки не знайдете потрібні варіанти для клієнта.

3. Збережіть короткі списки у [curated list](/uk/portal/studio/curated-lists/), якщо порівнюєте варіанти з клієнтом.
</Steps>

Ціни, які ви бачите, — це ціни готелю. Wink передає їх без змін, без націнки: ваш заробіток — через комісію. Див. [Search](/uk/portal/studio/search/).

## Крок 4: Забронюйте для клієнта

<Steps>
1. Оберіть номер і тариф, введіть ім’я та контактні дані клієнта як мандрівника.

2. На оплаті введіть картку, яку клієнт надав для цього бронювання. Платіж збирається для готелю, який залишається продавцем.

3. Підтвердіть. Ви, мандрівник і готель отримують лист-підтвердження. Код бронювання починається з `WNK`.
</Steps>

:::caution[Обробляйте картку клієнта обережно]
Запитуйте картку лише для поточного бронювання і вводьте її безпосередньо на оплаті. Не записуйте, не надсилайте електронною поштою і не зберігайте у своїх записах.
:::

## Крок 5: Керуйте бронюваннями та отримуйте оплату

- **Бронювання:** натисніть `Bookings` у головному меню, щоб побачити всі бронювання, відфільтрувати, експортувати у CSV, повторно надіслати підтвердження або скасувати відповідно до політики скасування готелю. Див. [Bookings](/uk/portal/travel-agent/bookings/).
- **Комісія:** за замовчуванням 10%. Коли ви регулярно працюєте з готелем, можете попросити [пряме підключення](/uk/portal/studio/network/) і домовитись про іншу комісію.
- **Коли платять:** комісія стає доступною протягом 24 годин після заїзду гостя і надходить на ваш основний банківський рахунок. Плата за перекази стягується за собівартістю. Див. [Pricing](/uk/getting-started/pricing/).

## Крок 6: Збирайте оплату самостійно (тільки партнери API)

Пропустіть цей крок, якщо бронюєте у порталі або вас влаштовує стандартний спосіб.

<Steps>
1. Інтегруйтесь з [Partner API](/uk/integrations/partner-api/). Цей спосіб працює лише через API, зі своєї системи бронювання, не в порталі.

2. Оберіть цей спосіб під час реєстрації (Крок 1).

3. Wink оцінює це разом із вашими документами, наприклад, фінансовий стан і регуляторний статус, і підтверджує письмово. Затвердження супроводжується **кредитним лімітом**: максимальною сумою незавершених бронювань у будь-який момент.

4. Поки не затверджені, можете бронювати стандартним способом.
</Steps>

Після затвердження ви самі приймаєте платіж клієнта і оплачуєте кожен готель напряму. З кожного бронювання ви послідовно віднімаєте 1,5% комісію Wink, потім вашу комісію; решта належить готелю:

| За бронювання на 1 000,00 USD з комісією 10% | |
|---|---|
| Вартість бронювання | 1 000,00 USD |
| Мінус комісія Wink (1,5% від вартості) | 15,00 USD |
| Проміжна сума | 985,00 USD |
| Мінус ваша комісія (10% від проміжної суми) | 98,50 USD |
| **До сплати готелю** | **886,50 USD** |

Wink виставляє рахунок за 1,5% комісію щомісяця у USD, оплата протягом 15 днів, плюс використання Partner API понад безкоштовний ліміт. Ви відповідаєте за повернення, чарджбеки, безпеку платежів (PCI-DSS) і будь-яку ліцензію, яку вимагає ваша країна для збору платежів. Повні умови у [Travel Agent Agreement](/uk/legal/platform-agreements/).

## Підключіть власні системи

Агенції з власними інструментами бронювання можуть шукати і бронювати через [Partner API](/uk/integrations/partner-api/). Облікові записи туристичних агенцій можуть створювати бронювання напряму через API, і це єдиний спосіб працювати за схемою збору платежів агентом. Див. [Partner API reference](/uk/partner-api/partner/).
