Інструменти MCP Wink публікуються як **набори інструментів** — сфокусовані кінцеві точки, кожна з яких охоплює одну задачу. Ви підключаєте свій AI-клієнт до однієї або двох, що відповідають вашій роботі, а не до всіх одразу.

Кожна кінцева точка використовує **інтерактивний вхід OAuth2** (PKCE authorization code flow): ваш AI-агент відкриває вкладку браузера, ви входите у свій акаунт Wink, і все. Немає секретів клієнта для керування.

```bash title="Інтегратор channel manager підключається до однієї кінцевої точки"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="Готельєр, що керує власними тарифами, підключається до іншої"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## Чому інструменти розділені по кінцевих точках

Wink надає близько 500 інструментів. Передавати всі одразу агенту технічно можливо — але це погана ідея.

**Визначення інструментів коштують контексту.** Кожен інструмент, який рекламує сервер MCP, завантажується у контекстне вікно моделі перед виконанням роботи, разом із описом і повною схемою параметрів. П’ятсот таких інструментів споживають значну частину бюджету, який потрібен для вашого завдання, при кожному запиті.

**Якість вибору падає зі збільшенням списку.** Агент, що обирає з 500 інструментів із подібними назвами, робить гірші вибори, ніж той, хто обирає з 40. Якщо ви інтегруєте channel manager, приблизно двадцять інструментів релевантні для вас; інші 480 — це шум, що ускладнює пошук потрібного інструменту.

**Роботу справді можна розділити.** Хтось, хто синхронізує доступність із PMS, і хтось, хто курує афілійовані лендинг-сторінки, майже не мають спільних інструментів. Розділення за задачами означає, що кожне підключення несе словник однієї задачі.

<Aside type="caution" title="Набори інструментів — це не права доступу">
Вибір вузького набору інструментів **не обмежує** можливості вашого акаунта, а вибір широкого не надає нічого додаткового. Кожен інструмент застосовує ті ж права акаунта, що й веб-портал, під вашим увійденим ідентифікатором. Якщо ваш акаунт не може скасувати бронювання у Wink Portal, агент теж не зможе — незалежно від того, до якої кінцевої точки він підключений.

Обирайте набори інструментів для **фокусу**, а не для безпеки.
</Aside>

## Каталог кінцевих точок

Два хости обслуговують набори інструментів. Кількість інструментів приблизна і з часом зростає.

### `https://api.wink.travel` — платформа

| Кінцева точка | Інструменти | Що охоплює |
|---|---:|---|
| `/mcp/extranet/facilities` | ~64 | Бронювальний та onsite інвентар: гостьові кімнати та типи кімнат, спа, ресторани, конференц-зали, активності, атракції, місця, інші товари для продажу |
| `/mcp/extranet/property` | ~62 | Запис про об’єкт та його комерційні умови: профіль і контент, додаткові послуги, політики скасування, бонуси, оголошення |
| `/mcp/settings` | ~60 | Адміністрування акаунта: профіль і брендинг управляючої організації, менеджери та їх права, налаштування, вебхуки, налаштування сповіщень |
| `/mcp/studio/embeds` | ~48 | Публікація кураторського інвентарю: віджети, сітки та ранжовані сітки, картки, карти, глибокі посилання на інвентар і сторінки постачальників |
| `/mcp/extranet/rates` | ~44 | Ціни та доступність: періоди тарифів і алокації, тарифні плани, основні тарифи, спеціальні та промоційні тарифи |
| `/mcp/extranet/operations` | ~39 | Управління активним об’єктом: бронювання та їх життєвий цикл, відгуки гостей і відповіді, календарні стрічки, заплановані завдання |
| `/mcp/extranet/distribution` | ~37 | Канали продажу: канали продажу та модифікатори тарифів, запити на афілійовані та постачальницькі відносини, реєстрація, збір лідів |
| `/mcp/studio/curation` | ~35 | Створення комерційних колекцій: статичні та динамічні списки, ранжовані списки, збережені пошуки, агрегати об’єктів |
| `/mcp/link-manager` | ~28 | Колекції синдикованих посилань, їх дизайн, категорії та теги, а також скорочені URL |
| `/mcp/reference` | ~24 | Дані лише для читання: країни, валюти та курси обміну, мови, часові пояси, геолокації, IP-геолокація |
| `/mcp/analytics` | ~18 | Аналітика бронювань і доходів: огляди, лінійні графіки, рейтинги, ефективність афілійованих, метрики поширення |
| `/mcp/payment` | ~18 | Фінансові операції: бухгалтерія, зняття коштів і оцінки комісій, агрегати фондів бронювань |
| `/mcp/booking-engine` | ~17 | Шлях покупця: пошук і перегляд, кошик і оформлення замовлення, списки бажань, налаштування кампаній |
| `/mcp/social` | ~17 | Підключені соціальні акаунти, публікація і планування постів, перегляд аналітики постів |
| `/mcp/travel-agent` | ~8 | Бронювання через агента від імені мандрівників, звіти агента |

### `https://integrations.wink.travel` — інтеграції channel manager

Одна кінцева точка, бо цей хост існує для однієї задачі.

| Кінцева точка | Інструменти | Що охоплює |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | Підключення та перевірка інтеграції channel manager, PMS або CRS |

<Aside type="note" title="Інтеграція channel manager vs. керування власними тарифами">
Це різні задачі для різних людей, і вони не ділять кінцеву точку.

**Постачальник channel manager, PMS або CRS** інтегрується один раз через `integrations.wink.travel/mcp/channel-manager` і відтоді обмінюється об’єктами, тарифами, доступністю та бронюваннями через цю інтеграцію. Ця одна кінцева точка — це вся поверхня.

**Готельєр, що змінює власні тарифи вручну**, використовує набори інструментів екстранету на `api.wink.travel` — `/mcp/extranet/rates` та інші. Вони не є частиною інтеграції channel manager, і інтегратор не має причин підключатися до них.

Адміністрування акаунта також на `api.wink.travel`, за адресою `/mcp/settings`. На хості інтеграцій немає `/mcp/settings`.
</Aside>

Кожна кінцева точка також має інструмент `ping`, щоб ви могли підтвердити, що з’єднання активне, перш ніж просити виконати реальну роботу.

## Які набори інструментів мені потрібні?

| Якщо ви… | Підключайтеся до |
|---|---|
| **Інтегруєте channel manager, PMS або CRS** | `integrations.wink.travel/mcp/channel-manager` — лише ця |
| **Керуєте контентом об’єкта** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **Керуєте кімнатами та типами кімнат** | `/mcp/extranet/facilities` |
| **Керуєте цінами та доступністю** | `/mcp/extranet/rates` |
| **Ведете щоденне бронювання** | `/mcp/extranet/operations` |
| **Розвиваєте дистрибуцію** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **Створюєте афілійовані сторінки** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **Керуєте сторінками link-in-bio** | `/mcp/link-manager` + `/mcp/social` |
| **Бронюєте від імені мандрівників** | `/mcp/travel-agent` |
| **Здійснюєте фінансові звірки** | `/mcp/payment` |
| **Створюєте досвід бронювання** | `/mcp/booking-engine` + `/mcp/reference` |

Починайте з одного. Додавайте інший, коли вам знадобиться щось, що перший не може зробити — кожне підключення незалежне, і додавання не впливає на інші.

<Aside type="tip" title="Хочете все одразу?">
`https://api.wink.travel/mcp` і `https://integrations.wink.travel/mcp` залишаються доступними і надають **всі** інструменти на своєму хості. Вони корисні для ознайомлення з наявним, але ми не рекомендуємо їх для щоденної роботи: список інструментів занадто великий, щоб не заважати вашому завданню і погіршувати вибір інструментів агентом. Віддавайте перевагу наведеним вище наборам.
</Aside>

## Як працює автентифікація

Сервери MCP Wink використовують потік **OAuth2 Authorization Code + PKCE** і підтримують **Dynamic Client Registration (RFC 7591)**. Ось що відбувається при першому підключенні:

1. Ваш AI-клієнт знаходить сервер авторизації через метадані `/.well-known/oauth-protected-resource` кінцевої точки MCP.
2. Клієнт самостійно реєструється через **Dynamic Client Registration** — налаштування додатку вручну не потрібне.
3. Клієнт відкриває **вкладку браузера** на `https://iam.wink.travel`. Ви входите у свій акаунт Wink і погоджуєтеся з запитуваними правами на екрані згоди.
4. Wink видає **токен доступу**, прив’язаний до вашого акаунта і ідентичності.
5. AI-клієнт додає токен до кожного запиту MCP. Всі результати інструментів автоматично обмежені вашою управляючою організацією.
6. Токени діють 3 години. Ваш AI-клієнт оновлює їх у фоновому режимі без повторного запиту.

Кожен виклик інструменту виконується **під вашою ідентичністю** — ті ж правила ACL, що захищають веб-портал, застосовуються до AI-агента.

## Підключіть свій AI-клієнт

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Переконайтеся, що Claude Code оновлено:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Оберіть набір інструментів із [каталогу вище](#endpoint-directory) і додайте його. Наприклад, ціни та доступність:
   ```bash
   claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
   ```

3. Claude Code зв’язується з сервером, знаходить сервер авторизації і відкриває ваш браузер за замовчуванням.

4. **Увійдіть у Wink** і підтвердіть запит на дозвіл на екрані згоди.

5. Claude Code підтверджує підключення. Введіть `/mcp`, щоб перевірити, що сервер з’явився і інструменти завантажені.
</Steps>

Додавайте стільки наборів інструментів, скільки потрібно для вашої роботи — кожен це окремий запис сервера з власною назвою:
```bash
claude mcp add wink-operations https://api.wink.travel/mcp/extranet/operations --transport http
claude mcp add wink-analytics  https://api.wink.travel/mcp/analytics           --transport http
```

Ви входите лише один раз. Після першого підтвердження у браузері Claude Code повторно використовує вашу сесію Wink для додаткових кінцевих точок Wink.

:::tip[Поділіться з командою]
Додайте `--scope project` до `claude mcp add`, і Claude Code запише URL сервера у `.mcp.json` у корені репозиторію. Закомітьте цей файл — кожен член команди отримає ті ж набори інструментів, і кожен виконає власний вхід у браузері при першому підключенні.
:::

5. Іконка штекера на нижній панелі показує обидва сервери як підключені.

  <TabItem label="ChatGPT">

Підтримка серверів MCP доступна у **десктоп-додатку ChatGPT** для підписників Plus, Pro, Team та Enterprise.

<Steps>
1. Завантажте і встановіть [десктоп-додаток ChatGPT](https://openai.com/chatgpt/download/), якщо ще не зробили цього.

2. Відкрийте додаток і натисніть **іконку профілю** у верхньому правому куті, потім оберіть **Налаштування**.

3. Перейдіть до **Конекторів** (або **Серверів MCP** залежно від версії додатку) і натисніть **Додати**.

4. Введіть URL набору інструментів із [каталогу вище](#endpoint-directory), наприклад:
   ```
   https://api.wink.travel/mcp/extranet/rates
   ```
   Потім натисніть **Підключити**.

5. ChatGPT відкриває вкладку браузера на `https://iam.wink.travel`. **Увійдіть у Wink** і підтвердіть права.

6. Повторіть кроки 4–5 для інших наборів інструментів, які потрібні для вашої роботи, наприклад:
   ```
   https://api.wink.travel/mcp/extranet/operations
   ```

7. Кожен набір інструментів з’явиться у списку Конекторів. Почніть новий чат — інструменти Wink будуть доступні автоматично.
</Steps>

:::note[Обмеження веб-додатку]
Сервери MCP можна налаштовувати лише у **десктоп-додатку**. Веб-інтерфейс ChatGPT на chatgpt.com не підтримує кастомні сервери MCP.
:::

2. Додайте записи серверів MCP Wink:

   ```json title="~/.codeium/windsurf/mcp_config.json"
   {
     "mcpServers": {
       "wink-extranet-rates": {
         "type": "http",
         "url": "https://api.wink.travel/mcp/extranet/rates"
       },
       "wink-extranet-operations": {
         "type": "http",
         "url": "https://api.wink.travel/mcp/extranet/operations"
       }
     }
   }
   ```

3. **Повністю перезапустіть Windsurf** (Файл → Вийти, потім знову відкрийте).

4. Перейдіть у **Налаштування → Сервери MCP** і переконайтеся, що обидва сервери відображаються як підключені. Windsurf відкриває вкладку браузера на `https://iam.wink.travel` при першому запуску.

5. **Увійдіть у Wink** і підтвердіть права. Сервери стануть зеленими у панелі налаштувань після автентифікації.
</Steps>

## Обсяги доступу

Коли ви підтверджуєте екран згоди, ви побачите розподіл запитуваних агентом прав. Клієнти MCP використовують ту ж словникову базу дозволів, що й решта платформи — див. повний [довідник обсягів на сторінці автентифікації](/uk/developers/authentication#scopes).

Дві речі специфічні для MCP:

- **Обсяги `mcp.read`, `mcp.write`, `mcp.remove` додатково потрібні** для відкриття транспорту MCP. Клієнт із обсягом `mcp.*` допускається до будь-якої кінцевої точки Wink MCP, але кожен інструмент, який він викликає, все одно застосовує обсяг секції кінцевої точки, яку він обгортає (наприклад, `booking.read`).
- **AI-клієнт запитує лише ті обсяги, які йому потрібні.** Ви можете відмовити в окремих дозволах на екрані згоди — інструменти, що потребують відхиленого обсягу, повернуть помилку при виклику.

**Набори інструментів цього не змінюють.** Кінцева точка, до якої ви підключаєтеся, визначає, які інструменти *перелічені*, а не що їм *дозволено робити*. Підключення до `/mcp/payment` не надає жодних фінансових прав, яких у вас не було, а підключення до `/mcp/reference` не заважає інструменту там застосовувати власний обсяг. Авторизація визначається для кожного виклику інструменту, на основі вашого токена і прав акаунта.

## Вирішення проблем

**Вкладка браузера не відкривається**

Ваш AI-клієнт може ще не підтримувати інтерактивний потік PKCE. Перевірте, що у вас остання версія:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** оновіть через вбудований оновлювач додатку

**`401 Unauthorized` після входу**

Ваш кешований токен може бути застарілим. Видаліть і додайте сервер знову, щоб викликати новий вхід:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

Для Claude Desktop і ChatGPT видаліть запис сервера в налаштуваннях, перезапустіть додаток і додайте знову.

**`403 Forbidden` при виклику конкретного інструменту**

Інструмент потребує обсягу, який ви не підтвердили на екрані згоди, або права, яких немає у вашого акаунта. Підключіться знову — екран згоди з’явиться знову, і ви зможете підтвердити відсутній дозвіл. Якщо помилка не зникає, інструмент потребує права акаунта, якого у вас немає; підключення до іншого набору інструментів не допоможе, бо набори не надають права.

**Інструмент, який мені потрібен, відсутній у списку**

Ймовірно, ви підключені до набору інструментів, що не охоплює цю задачу. Перевірте [каталог кінцевих точок](#endpoint-directory) і додайте потрібний набір — підключення незалежні, тому додавання не змінює інші. Якщо не впевнені, де він є, тимчасово підключіться до `https://api.wink.travel/mcp`, знайдіть інструмент, а потім подивіться, який набір його містить.

**`404 Not Found` на кінцевій точці набору інструментів**

Уважно перевірте шлях — вкладені набори мають два сегменти (`/mcp/extranet/rates`, а не `/mcp/extranet-rates`), а плоскі — один (`/mcp/link-manager`). Зверніть увагу, що *неавторизований* запит до будь-якого шляху під `/mcp` повертає `401`, а не `404`, тому лише `401` не означає, що кінцева точка існує.

**Я підключився до `api.wink.travel/mcp/channel-manager` і нічого не отримав**

Такої кінцевої точки немає. Інтеграція channel manager обслуговується лише з `https://integrations.wink.travel/mcp/channel-manager`. Якщо вам також потрібно читати або змінювати власні тарифи об’єкта вручну, це окрема задача на окремій кінцевій точці — див. `/mcp/extranet/rates`.

**Сервер з’являється, але виклики інструментів повертають "акаунт не знайдено"**

Ви увійшли у Wink акаунт, який не має управляючої організації. Перейдіть на [Wink Portal](https://app.wink.travel) і переконайтеся, що ваш акаунт налаштований перед використанням сервера MCP.

**Токен закінчується під час сесії**

Токени дійсні 3 години. Claude Code і Claude Desktop оновлюють токени у фоновому режимі без переривання сесії. Якщо після тривалого простою з’являються помилки автентифікації, надішліть нове повідомлення — клієнт автоматично повторно автентифікується.

**Codex CLI показує "MCP server unreachable"**

Перевірте, що ваш `~/.codex/config.json` є валідним JSON (без зайвих ком) і що `"type": "http"` встановлено. Codex вимагає HTTP-транспорт для віддалених серверів; stdio-транспорт призначений лише для локальних бінарників.

**Меню "Connectors" у ChatGPT відсутнє**

Підтримка MCP вимагає версії десктоп-додатку ChatGPT **1.2024.352** або новішої та активної підписки Plus, Pro, Team або Enterprise. Оновіть додаток і перевірте план у Налаштуваннях → Акаунт.

**Сервер Cursor показує червоний / "Не вдалося підключитися"**

Перевірте, що ваш `~/.cursor/mcp.json` є валідним JSON і містить `"type": "http"`. Потім перейдіть у **Налаштування → Налаштування Cursor → MCP** і натисніть **Оновити**. Якщо помилка не зникає, повністю перезапустіть Cursor — зміни конфігурації не завжди застосовуються без перезапуску.

**Сервери MCP Windsurf не відображаються в налаштуваннях**

Windsurf вимагає повного перезапуску (не лише перезавантаження вікна), щоб застосувати зміни в `mcp_config.json`. Використовуйте **Файл → Вийти** і знову відкрийте. Якщо сервери все ще не з’являються, переконайтеся, що у вас Windsurf версії **1.4+** через **Довідка → Про Windsurf**.

**Опція "Додати сервер" у Cline не відображається**

Менеджер серверів MCP вимагає Cline версії **2.0** або новішої. Відкрийте панель розширень VS Code, знайдіть Cline і натисніть **Оновити**, якщо доступне оновлення. Після оновлення перезавантажте VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
