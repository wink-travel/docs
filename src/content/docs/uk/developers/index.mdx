Кожна функція платформи доступна для виклику зовні. У цьому розділі описано автентифікацію, API, доставку подій та довідкові дані, що стоять за цим.

## Почніть тут

- [Quickstart](/uk/developers/quickstart/) — від нуля до актуальних цін на готелі та вашого першого тестового бронювання в середовищі staging.
- [Build on Wink](/uk/developers/build-on-wink/) — що можна створити і який API підходить.
- [Setup](/uk/developers/setup/) — створіть додаток і отримайте облікові дані.
- [Authentication](/uk/developers/authentication/) — сесії OAuth2 та області доступу.

## API

- [REST and gRPC](/uk/developers/rest-and-grpc/) — два протоколи передачі та коли використовувати кожен.
- [Geolocation](/uk/developers/geolocation/) — просторовий пошук по доступному для бронювання інвентарю.
- [Taxonomy](/uk/developers/taxonomy/) — OTA-коди, підтримувані мови та валюти.

## Події та синхронізація

- [Webhook Integration](/uk/developers/webhook-integration/) — підписка на події платформи.
- [Webhook Events Catalog](/uk/developers/webhook-events/) — усі події, які генерує платформа.
- [Booking Sync](/uk/developers/booking-sync/) — підтримуйте бронювання у відповідності з PMS або канал-менеджером.

## AI агенти

- [MCP Servers](/uk/developers/mcp/) — читайте живі API-контракти від AI-клієнта.
- [Agentic Payments](/uk/developers/agentic-payments/) — підключіть свого агента, увійдіть, знайдіть кімнату та підтвердіть оплату.
- [AI Skills](/uk/developers/ai-skills/) — що може робити затверджений агент на платформі.
