# Налаштування

Коли ви вперше починаєте працювати з Social, ми запитаємо, як ви хочете, щоб ми створювали ваш контент. Ці опції доступні вам у будь-який час, тож ви можете легко змінити їх пізніше.

Перейдіть до `Settings` у бічному меню, щоб керувати своїми налаштуваннями.

## Переваги

Розділ переваг містить ваші базові налаштування генерації контенту:

1. **Улюблене налаштування** Виберіть, яке налаштування використовувати при генерації контенту. Налаштування контролюють кольори теми, стандартний маршрут, валюту, мову та інше. Ви створюєте налаштування у своєму акаунті на [app.wink.travel](https://app.wink.travel).
2. **Автоматичне затвердження** Якщо увімкнено, згенеровані пости публікуються автоматично без вашого затвердження. Увімкніть це, коли будете впевнені у якості контенту, який ми для вас створюємо.
3. **Ім’я затверджувача** Ім’я особи або команди, яка отримуватиме електронні листи з запитами на затвердження.
4. **Електронна пошта затверджувача** Адреса електронної пошти, на яку надсилатимуться запити на затвердження майбутніх постів.

## Творці контенту

Social пропонує багато творців контенту на вибір. Кожен творець зосереджений на одному конкретному способі створення унікального контенту для вашої власності за допомогою ШІ. Кожен творець контенту має атрибут **Вага** — більша вага збільшує ймовірність вибору цього творця при генерації постів.

Ось усі доступні творці контенту:

| Творець | Опис |
| -- | -- |
| **Destination** | Використовує ваше розташування для створення корисного тексту про місцевість |
| **Room type** | Створює бронюваний пост з одним із ваших типів номерів із текстом, згенерованим ШІ, та зображеннями типу номера |
| **Activity** | Створює бронюваний пост з однією з ваших активностей |
| **Add-On** | Створює бронюваний пост з одним із ваших додаткових сервісів |
| **Attraction** | Створює бронюваний пост з однією з ваших визначних пам’яток |
| **Place** | Створює бронюваний пост з одним із ваших місць |
| **Meeting room** | Створює бронюваний пост з однією з ваших конференц-залів |
| **Restaurant** | Створює бронюваний пост з одним із ваших ресторанів |
| **Spa** | Створює бронюваний пост з одним із ваших спа |
| **Property** | Створює бронюваний пост з вашим найкращим номером за ціною з текстом, згенерованим ШІ, та зображеннями власності |
| **User sentiment** | Агрегує відгуки гостей з усього інтернету у пост, що відображає позитивні враження гостей про вашу власність |
| **Funny** | Створює легкі, розважальні пости, щоб підтримувати цікавість вашої стрічки |

:::tip[Порада професіонала]
Переконайтеся, що у вас є тип інвентарю, необхідний для обраних творців контенту. Наприклад, якщо ви обираєте "Restaurant", у вашій власності має бути принаймні один ресторан.
:::

## Тон голосу

Тон голосу визначає стиль мови, який ШІ використовує при генерації контенту. Оберіть тони, що відповідають особистості вашого бренду. Як і у творців контенту, кожен тон має **Вагу**, щоб контролювати, як часто він використовується.

Ось доступні тони:

| Тон | Стиль |
| -- | -- |
| **Neutral** | Спокійний, авторитетний, фактичний. Без перебільшень і жартів — лише надійна, добре структурована інформація |
| **Friendly** | Теплий, доступний, енергія усмішки через текст із розмовними скороченнями та іноді емодзі |
| **Luxury** | Вишуканий, витончений. Слова на кшталт "вишуканий" і "індивідуальний", що створюють відчуття ексклюзивності |
| **Foodie** | Чуттєві, апетитні описи. Мова, що викликає апетит |
| **Adventurous** | Сміливий, відважний, енергія дослідника. Яскраві сенсорні описи, що роблять усе епічним |
| **Family** | Доброзичливий, дружній до дітей. Тепла батьківська енергія про безпечні та веселі враження |
| **Romantic** | Поетичний, мрійливий, що зворушує серце. Захід сонця, ніжна мова і любов |
| **Humorous** | Саркастичний, швидкі дотепні фрази, гра слів. Читається як стендап |
| **Eco** | Щирий і праведний. Підкреслює зелені альтернативи та сталий вибір |
| **Local insider** | Дуже конкретні місцеві посилання, попереджає про туристичні пастки, використовує місцевий сленг |
| **Inclusive** | Привітний, святковий і підтримуючий. Робить так, щоб кожен почувався поміченим і цінним |
| **Mystical** | Ефірний, духовний, космічні істини. Лагідні запрошення заглянути всередину себе |
| **Futuristic** | Стильний, орієнтований у майбутнє. Любить терміни на кшталт "зміна парадигми" та оптимістичні бачення майбутнього |
| **Budget** | Практичний, винахідливий, гордо ощадливий. Підкреслює доступні знахідки та безкоштовні враження |

## Типи постів

Типи постів визначають мету та структуру згенерованого контенту. Кожен тип поста має **Вагу**, щоб контролювати, як часто він використовується.

| Тип поста | Опис |
| -- | -- |
| **Transactional** | Чіткий, лаконічний, орієнтований на конверсію. Сприяє бронюванням і прямим діям за допомогою фактів, цін і наступних кроків |
| **Awareness** | Контент для побудови бренду, призначений для представлення вашої власності та підвищення видимості серед потенційних гостей |
| **Sentiment** | Емоційно резонуючий контент, що створює позитивні асоціації та будує емоційний зв’язок з аудиторією |

Підключивши свій профіль Google Business, ми можемо отримувати більш детальну інформацію про власність для ефективнішого контенту. Вашій власності потрібен підтверджений профіль Google Business, щоб ми могли генерувати контент із вашого оголошення. Деякі наші творці контенту **вимагають**, щоб у вас був акаунт Google Business.
