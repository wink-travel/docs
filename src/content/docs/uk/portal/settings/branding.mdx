Налаштування — це потужна функція, яку ви можете використовувати для контролю кожного аспекту інтеграції з Wink без необхідності писати код. Кожен елемент інвентарю, який ви продаєте, можна налаштувати. Додавайте або видаляйте функції, змінюйте кольорову схему та багато іншого.

Ось як почати:

<Steps>
 1. Виберіть обліковий запис, з яким хочете працювати, на сторінці [Accounts](https://app.wink.travel).
 2. Натисніть `Actions` у нижній частині картки облікового запису та оберіть `Manage account`.
 3. Натисніть вкладку `Customizations` на наступній сторінці.
 4. У цьому розділі буде перелік усіх ваших налаштувань.
 5. Виберіть редагування існуючого або створення нового.
 </Steps>

На сторінці `Customization` натисніть кнопку `Actions` під потрібним налаштуванням і виберіть `Update`.

:::note
У вас вже є доступна за замовчуванням запис, створена разом з вашим обліковим записом. Цю запис не можна видалити.
:::

Це перенесе вас до форми налаштування, де доступні такі функції.

## Загальні

Ось опції, доступні у вкладці `General`.

- **Назва** Дайте вашому налаштуванню ім’я для легшого запам’ятовування. *наприклад, Для мого тревел-блогу*
- **Валюта відображення** Виберіть початкову валюту, яку користувачі бачитимуть поруч із доступним для бронювання інвентарем. *наприклад, USD*
- **Мова відображення** Виберіть початкову мову, з якою користувачі зіткнуться. *наприклад, English*
- **Додати до заголовка сторінки** Ви можете контролювати, що додається до заголовка сторінки (*заголовок, який ви бачите на вкладці браузера*). Це головним чином використовується для нашого booking engine. *наприклад, якщо ви перейдете на https://book.wink.travel, за замовчуванням ви побачите `Home | Traveliko - Hotels with Benefits`*. Ви можете змінити все після символу '|'.

## Тема

Вкладка `Theme` дозволяє налаштувати вигляд і відчуття нашого вебсайту [booking engine](/uk/booking-engine/in-a-nutshell), вебсайту [WinkLinks](/uk/portal/link-manager/wink-links) та всіх наших [Web Components](/uk/integrations/web-components).

### Конфігурація

Цей розділ дозволяє налаштувати дизайн і макет карток. Наразі доступний лише один дизайн — Wink.

Макет картки контролює, чи хочете ви, щоб користувачі бачили горизонтально чи вертикально розташовані транзакційні картки. Інформація однакова.

:::note
Різниці в макеті карток при перегляді з мобільного пристрою немає. Однак різницю можна побачити на iPad mini та пристроях з більшим розділенням.
:::

:::tip[Порада професіонала]
Використовуйте горизонтальний макет, якщо у вас у списку менше 4 одиниць тревел-інвентарю (наприклад, типів номерів)... це виглядає краще.
:::

## Аналітика

Ми підтримуємо аналітику GA4 "з коробки". Якщо ви хочете відстежувати весь шлях конверсії розширеної електронної комерції від початку до кінця, підготуйте ваш ідентифікатор вимірювання і введіть його у поле на вкладці `Analytics`.

<Aside type="caution" title="Нагадування">
  Не забудьте додати `i.trvl.as` та `book.wink.travel` до потоків вашої властивості GA4.
</Aside>

## Карти

Щоб вбудувати наші карти на ваш сайт за допомогою [плагіна WordPress](/uk/integrations/wordpress) або [Web Components](/uk/integrations/web-components), вам потрібно надати власний ключ API Google Maps.

:::note
  [Створіть ключ API Google Maps тут](https://console.developers.google.com/projectselector2/apis/credentials?supportedpurview=project)
:::

Після генерації ключа та налаштування для вашого сайту введіть його на вкладці `Analytics`.

## Маршрут

Вкладка `Itinerary` є, мабуть, найцікавішою з точки зору забезпечення відображення цін для вибраного інвентарю.
Оскільки ціноутворення тревел-інвентарю досить складне, Wink повинен знати маршрут користувача, щоб показати точну ціну.

Цей розділ дозволяє встановити маршрут за замовчуванням для відображення цін на всіх наших цифрових майданчиках, таких як:

- Наші соціально-дружні зображення з накладенням ціни.
- Сітки, картки та посилання WinkLinks.
- Web Components
- Booking engine

### Дати

Ви можете вибрати, чи хочете встановити статичний діапазон дат або рухомий.

- Виберіть статичний діапазон дат, якщо налаштування використовується для конкретної події, що відбувається у визначену дату.
- Виберіть рухомий діапазон дат, якщо хочете:
    1. За замовчуванням встановити сьогодні + 1 ніч, як це роблять більшість OTA, АБО.
    2. За замовчуванням встановити дату в майбутньому, яка завжди має бути доступною.

### Конфігурація номерів

За замовчуванням маршрут встановлено на 2 дорослих, оскільки це найпоширеніша настройка для більшості мандрівників.
Це легко змінити, і ви можете додати кілька номерів з різною кількістю мешканців; як дорослих, так і дітей.

### Акції

Акції — це зручна функція, яка економить час вашим користувачам. Якщо власник має промокод, яким ви можете поділитися з друзями, ви можете ввести його тут.
Кожен, хто перейде за вашим посиланням або подібним, автоматично отримає цей промокод у своєму маршруті, і знижка буде застосована автоматично.

## Інтеграція

Вкладка `Integration` призначена для готелів, інтеграторів і турагентів, які хочуть мати більший контроль над тим, як бронювання на Wink розподіляються.

### Сповіщення

Ця опція дає готелю та інтегратору можливість дозволити Wink повідомляти всі зацікавлені сторони про бронювання.
Це включає повідомлення менеджера каналів.

За замовчуванням усі ці опції увімкнені. Випадки, коли інтегратор може захотіти вимкнути одну або кілька з цих функцій:

- Турагент інтегрований на рівні API і хоче надсилати власні підтверджувальні листи.
- Готель тестує інтеграцію і не хоче турбувати свій відділ продажів.
- Готель не цікавиться електронною поштою і хоче отримувати сповіщення лише через PMS.

### Логотип у листах

Для інтеграторів, які хочуть використовувати нашу службу сповіщень електронною поштою, є можливість налаштувати листи так, щоб вони виглядали, ніби надіслані від них.

:::note
  Рекомендовані розміри: 300px ширина x 75px висота
:::

## Специфічно для готелів

У вкладці `Hotel-specific` є опції, які дозволяють готелю контролювати, що відображається на їхній цільовій сторінці в нашому booking engine і що показувати, коли немає інвентарю для запитуваного маршруту.

- **Рейтинги**: Власник, який ще не отримав значущих рейтингів, може вибрати відключити цю функцію.

:::note
  Власник не може контролювати, як афілійований партнер відображає цільову сторінку готелю... Це дві різні конфігурації.
:::

- **Доступність**: Дозволяє власнику вибрати, чи продовжувати відображати інвентар, навіть якщо немає доступності.

:::note
  У більшості випадків власник хоче дати користувачам можливість натиснути кнопку `Book` і перейти на їхню цільову сторінку, де можна змінити маршрут і спробувати знайти доступну дату.
  Увімкніть цей перемикач, якщо хочете заблокувати користувача від продовження.
:::

## Як використовувати

У більшості випадків ви обираєте, яке `Customization` застосувати до ваших посилань, карток, карт і сіток.

Ось випадки, коли ви можете захотіти вручну застосувати вашу конфігурацію:

- **Ручне перевизначення** Ви хочете поділитися посиланням на наш booking engine безпосередньо, не використовуючи функцію [Shareable Links](/uk/portal/studio/shareable-links), з вашою кастомною конфігурацією.
- **Плагін WordPress** Додайте конфігурацію у налаштування вашого Wink [WordPress Plugin](/uk/integrations/wordpress).
- **Кастомна інтеграція** Вручну застосуйте її до вашого кастомного інтегратора за допомогою нашого Web Component [wink-app-loader](/uk/integrations/web-components/#application-loader).

### Ручне перевизначення

Ось простий приклад, як застосувати ваш ID конфігурації з усіма налаштуваннями до основних URL booking engine.

<h4 align="center"> [https://book.wink.travel?configurationId=MY-UNIQUE-ID](https://book.wink.travel?configurationId=MY-UNIQUE-ID) </h4>

:::note
  Коли користувач натисне на це посилання, також буде встановлено ваш cookie для афілійованого відстеження.
:::

### Плагін WordPress

Перейдіть до [Wink WordPress plugin](/uk/integrations/wordpress), щоб дізнатися більше.

### Кастомна інтеграція

Керуйте всіма вбудованими Wink Web Components на сторінці за допомогою Web Component [wink-app-loader](/uk/integrations/web-components/#application-loader).

Нижче приклад, який використовує `MY-UNIQUE-ID` як ID конфігурації.

```html {11}
<html>
  <head>
    <link rel="stylesheet" href="https://elements.wink.travel/styles.css"></link>
  </head>
  <body>

    <script src="https://elements.wink.travel/elements.js" type="module" defer></script>

    <wink-app-loader
      client-id="YOUR CLIENT ID GOES HERE"
      configuration-id="MY-UNIQUE-ID"
    ></wink-app-loader>
  </body>
</html>
```
