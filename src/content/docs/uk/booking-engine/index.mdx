Booking Engine — це транзакційний шар під кожним маршрутом Wink: власним сайтом готелю, партнерськими та креаторськими посиланнями, пошуком для споживачів і AI-агентами. Оплата збирається від імені готелю, як його агента, тому готель залишається торговцем запису.

## Процес бронювання

- [Пошук](/uk/booking-engine/search/) — знайти доступний інвентар.
- [Деталі об’єкта](/uk/booking-engine/property-detail/) — номери, тарифи, політики та додаткові послуги.
- [Оформлення](/uk/booking-engine/checkout/) — єдиний крок оплати під брендом готелю.
- [Підтвердження бронювання](/uk/booking-engine/confirmation/) — що отримує гість.
