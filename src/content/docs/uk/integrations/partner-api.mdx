Wink **Партнерський API** — це автентифікований, високопродуктивний спосіб для інтеграторів запитувати доступний для бронювання туристичний інвентар — той самий запас, що живить наші вбудовувані віджети та публічні кінцеві точки перегляду, представлений як інтерфейс програмування першого класу. Якщо безкоштовні Web Components і публічні кінцеві точки перегляду призначені для легкого вбудовування, орієнтованого на користувача, то Партнерський API створений для систем, які шукають, оцінюють і бронюють у великому масштабі. Доступ автентифікується для кожного інтегратора і оплачується за використання, тож ви платите лише за трафік, який фактично надсилаєте.

## Довідник API

Два OpenAPI інтерфейси обслуговують доступний для бронювання інвентар і відповідають двом вищезазначеним рівням:

- **Безкоштовний — API для споживача / бронювальної системи** (`/api/public/**`): анонімний, орієнтований на браузер і віджети. [Переглянути довідник Booking Engine →](/uk/api/booking-engine/)
- **Платний — Партнерський інтеграторський API** (`/api/partner/**`): автентифікований, з вимірюванням використання, створений для інтеграції сервер-сервер у великому масштабі. [Переглянути довідник інтегратора →](/uk/partner-api/partner/)

## Як працює використання та обмеження

### Безкоштовний рівень

Безкоштовний рівень призначений для того, щоб ви могли створювати, тестувати та запускати помірний продуктивний трафік безкоштовно.

- **Обмеження швидкості — 30 запитів за хвилину, з можливістю сплеску до 60 запитів.** Короткочасні піки понад сталу швидкість компенсуються сплеском. Якщо ви перевищуєте його, API відповідає **HTTP 429 (Забагато запитів)** і застосовує **5-хвилинну паузу**, перш ніж ваш ключ знову почне обробляти трафік. Зачекайте і повторіть спробу після паузи, не навантажуючи кінцеву точку.
- **Місячна квота — 10 000 запитів на календарний місяць.** Після досягнення місячного ліміту API повертає **HTTP 429 до кінця місяця** — жорстку зупинку — разом із повідомленням із пропозицією перейти на платний рівень для продовження. Лічильник скидається на початку наступного календарного місяця.

Безкоштовний рівень не включає Угоду про рівень обслуговування або пріоритетну підтримку.

### Платний рівень

Платний рівень знімає місячний ліміт і паузи обмеження швидкості, і ви сплачуєте лише за фактичне використання.

- **Виміряні запити — $1.00 за 1 000 запитів.** Обмежень на місячну кількість запитів і обмежень швидкості при нормальному використанні немає; оплата здійснюється за фактичний обсяг.
- **Перевищення співвідношення переглядів до бронювань — $2.00 за 1 000 зайвих переглядів.** Щоб підтримувати здоровий запас, ми вимірюємо співвідношення пошуків ("переглядів") до підтверджених бронювань. Ви маєте право на **5 000 переглядів на одне бронювання** до застосування перевищення. Зайві перегляди обчислюються так:

  `excess = max(0, looks − bookings × 5,000)`

  Потім перевищення оплачується за **$2.00 за 1 000 зайвих переглядів**. Інтеграції з хорошим коефіцієнтом конверсії рідко мають перевищення; плата застосовується лише до трафіку, який шукає значно більше, ніж бронює.

Платний рівень включає Угоду про рівень обслуговування, описану нижче — зобов’язання 99,9% часу безвідмовної роботи та цільовий час відповіді P95 менше 500 мс — а також пріоритетну підтримку з урахуванням ступеня важливості.

## Угода про рівень обслуговування

_Дата набрання чинності: 5 липня 2026 · Версія 1.0_

Ця Угода про рівень обслуговування (далі — "SLA") встановлює зобов’язання щодо доступності, сервісні кредити та цілі підтримки, які Wink ("Wink", "ми", "нас") надає клієнту ("Клієнт", "ви") для автентифікованого Партнерського API Wink (далі — "Партнерський API" або "Сервіс") на рівнях, де зазначено застосування SLA. Ця SLA є частиною та регулюється угодою між вами та Wink, за якою ви отримуєте доступ до Партнерського API (далі — "Угода"), і застосовується доти, доки у вас є активна, оплачена підписка на Партнерський API у доброму стані. Терміни з великої літери, не визначені тут, мають значення, надані їм в Угоді.

### 1. Визначення

1. **"Час безвідмовної роботи"** означає періоди, протягом яких Партнерський API доступний для прийому та успішної відповіді на правильно сформовані, автентифіковані запити.
2. **"Час простою"** означає будь-який період, виміряний у хвилинах, протягом якого Партнерський API не відповідає успішно на правильно сформовані, автентифіковані запити, за винятком періодів, що підпадають під виключення, описані в Розділі 4. Поодинокі помилки, що впливають на незначну частку запитів, самі по собі не вважаються часом простою.
3. **"Щомісячний відсоток часу безвідмовної роботи"** означає для певного календарного місяця загальну кількість хвилин у цьому місяці мінус загальну кількість хвилин простою, поділену на загальну кількість хвилин у цьому місяці, виражену у відсотках.
4. **"Заплановане обслуговування"** означає планове обслуговування Сервісу, про яке Wink заздалегідь повідомив відповідно до Розділу 4.
5. **"Сервісний кредит"** означає кредит, розрахований як відсоток від сплачених або підлягаючих сплаті вами за Партнерський API у відповідному календарному місяці, який застосовується до майбутніх платежів за Партнерський API як єдиний і виключний засіб відшкодування за невиконання зобов’язання щодо часу безвідмовної роботи.
6. **"Час відповіді"** означає час, що минув від отримання Wink правильно сформованого, автентифікованого запиту на межі сервісу Wink до моменту початку Wink надсилати відповідь, за винятком часу мережевого транзиту та будь-якого часу на стороні клієнта поза контролем Wink.

### 2. Зобов’язання щодо доступності та продуктивності

Wink докладатиме комерційно розумних зусиль, щоб забезпечити доступність Партнерського API на рівні **щомісячного відсотка часу безвідмовної роботи не менше 99,9%** протягом кожного календарного місяця терміну дії (далі — "Зобов’язання щодо часу безвідмовної роботи"). Зобов’язання вимірюється на межі сервісу Wink і виключає будь-які фактори поза розумним контролем Wink, включно з описаними в Розділі 4. Системи моніторингу Wink є авторитетним джерелом для вимірювання щомісячного відсотка часу безвідмовної роботи та часу відповіді.

Wink також орієнтується на **95-й процентиль (P95) часу відповіді менше 500 мілісекунд** для успішних, правильно сформованих, автентифікованих запитів, вимірюваного на межі сервісу Wink протягом кожного календарного місяця (далі — "Ціль продуктивності"). Ціль продуктивності виключає фактори, описані в Розділі 4, запити, що повертають помилки на рівні застосунку, спричинені самим запитом, а також незвично великі або складні пакетні запити. Ціль продуктивності є сервісною метою; сервісні кредити з Розділу 3 застосовуються до невиконання **Зобов’язання щодо часу безвідмовної роботи** і є єдиним і виключним засобом відшкодування за недоступність.

### 3. Сервісні кредити

Якщо щомісячний відсоток часу безвідмовної роботи опускається нижче Зобов’язання у будь-якому календарному місяці, ви можете претендувати на Сервісний кредит, розрахований як відсоток від сплачених або підлягаючих сплаті вами за Партнерський API у тому місяці, згідно з наступною шкалою:

| Щомісячний відсоток часу безвідмовної роботи | Сервісний кредит |
|---|---|
| Нижче 99,9%, але не менше 99,0% | 10% |
| Нижче 99,0%, але не менше 95,0% | 25% |
| Нижче 95,0% | 50% |

1. **Подання претензії.** Щоб отримати Сервісний кредит, ви повинні подати письмову претензію Wink протягом **тридцяти (30) днів** після закінчення календарного місяця, у якому сталася недоступність. Претензія має містити дати та час кожного інциденту простою, який ви заявляєте, а також будь-які доступні журнали або докази. Претензії, подані після цього терміну, не розглядаються.
2. **Форма кредиту.** Затверджені Сервісні кредити застосовуються до майбутніх платежів за Партнерський API і не мають грошової вартості. Вони не є поверненням коштів і не виплачуються готівкою, за винятком випадків, передбачених чинним законодавством.
3. **Максимальний кредит.** Загальна сума Сервісних кредитів за будь-який календарний місяць не перевищуватиме 50% від сплачених або підлягаючих сплаті вами за Партнерський API у тому місяці.
4. **Єдиний і виключний засіб.** Сервісні кредити є вашим **єдиним і виключним засобом** у разі невиконання Wink Зобов’язання щодо часу безвідмовної роботи або будь-яких інших проблем з доступністю Партнерського API.

### 4. Виключення

Зобов’язання щодо часу безвідмовної роботи та будь-які Сервісні кредити не застосовуються, а час простою не включає будь-яку недоступність, призупинення, погіршення або проблеми з продуктивністю, що виникають через або пов’язані з:

1. **Запланованим обслуговуванням**, про яке Wink заздалегідь повідомив, за умови, що таке повідомлення було надано за розумний період через канал, який Wink зазвичай використовує для спілкування з клієнтами;
2. **Форс-мажорними обставинами** або іншими причинами поза розумним контролем Wink, включно з природними катастрофами, діями уряду, збоями мережі або комунальних служб, а також атаками типу відмова в обслуговуванні чи іншими зловмисними атаками;
3. проблемами, спричиненими вашими діями або бездіяльністю, вашим обладнанням, програмним забезпеченням або мережею, або будь-яким сервісом, продуктом чи постачальником третьої сторони, що не перебуває під прямим контролем Wink;
4. вашим **зловживанням Сервісом** або **порушенням Угоди**, цієї SLA, правил прийнятного використання або застосовних обмежень швидкості, включно з трафіком, який Wink розумно вважає надмірним, автоматизованим зловживанням або шахрайством; та

### 5. Підтримка та цілі відповіді

Wink надає підтримку для Партнерського API у стандартні робочі години, за винятком місцевих державних свят. Wink докладатиме комерційно розумних зусиль, щоб підтвердити отримання правильно поданих запитів на підтримку у такі цільові терміни відповіді, залежно від ступеня важливості, який ви призначаєте і який Wink розумно підтверджує:

| Ступінь важливості | Опис | Цільова початкова відповідь |
|---|---|---|
| **Sev 1 — Критичний** | Партнерський API не працює або непридатний для використання в продуктиві без обхідного шляху. | 4 години |
| **Sev 2 — Важливий** | Значне погіршення або обмеження функції; існує обхідний шлях. | 1 робочий день |
| **Sev 3 — Незначний** | Загальні питання, незначні проблеми або запити на функції. | 2 робочі дні |

Цільові терміни відповіді описують, коли Wink прагне встановити **перший контакт**; це не гарантії часу вирішення. Пріоритетна підтримка та цілі за ступенем важливості застосовуються на рівнях, де вони заявлені.

Ви несете відповідальність за безпеку власних облікових даних API, за законне використання будь-яких отриманих даних і за своєчасне повідомлення Wink про будь-яке підозрюване порушення безпеки облікових даних.

### 7. Обмеження відповідальності

Сервісні кредити є **єдиним і виключним засобом** у разі недоступності або невиконання Зобов’язання щодо часу безвідмовної роботи і надаються замість будь-якої іншої відповідальності, що виникає з такого невиконання. За винятком випадків, прямо передбачених у цій SLA, Партнерський API надається "як є". У межах максимальної міри, дозволеної чинним законодавством, загальна відповідальність Wink, що виникає з або пов’язана з Сервісом, обмежується положеннями Угоди, і Wink не несе відповідальності за будь-які непрямі, випадкові, спеціальні, наслідкові або штрафні збитки, а також за втрату прибутку, доходу, даних або ділової репутації, навіть якщо було повідомлено про можливість таких збитків.

### 8. Термін дії, зміни та припинення

Ця SLA застосовується доти, доки у вас є активна підписка на Партнерський API на рівні, де заявлено застосування SLA. Wink може час від часу оновлювати цю SLA; суттєві зміни будуть повідомлені через канал, який Wink зазвичай використовує для зв’язку з клієнтами, а подальше використання Партнерського API після набрання чинності оновленням означає прийняття оновленої SLA. Ця SLA припиняє дію автоматично після припинення або закінчення Угоди або вашої підписки на Партнерський API. Розділи, які за своєю природою повинні зберігати чинність після припинення — включно з правом на нараховані, але не заявлені Сервісні кредити, обмеженням відповідальності та визначеннями — залишаються чинними.
