Booking Engine можна вбудувати будь-де. Оберіть свій фреймворк або CMS і дотримуйтесь його інструкцій; базові Web Components однакові скрізь.

## Основні підходи

- [Web Components](/uk/integrations/web-components/) — вбудовувані елементи, які використовує кожна інтеграція.
- [npm package](/uk/integrations/npm/) — встановлення у JavaScript-білд.
- [Headless CMS](/uk/integrations/headless/) — рендеринг з будь-якої бекенд-системи контенту.
- [Partner API](/uk/integrations/partner-api/) — повна програмна інтеграція.
