**BOOK NOW**（今すぐ予約）ボタンは、宿泊施設の空室状況や料金を把握し、旅行者が部屋を予約できるプロバイダーとホテル自身が連携することを指す、ホスピタリティ業界で広く使われている用語です。このボタンは、ホテルが自社のウェブサイト上で自分たちの条件で部屋を販売できる最もシンプルな方法です。

*多くのホテルはチャネルマネージャーが提供するバンドルされた予約エンジンを利用していますが、特定の予約エンジンに決める前に、ネイティブ予約エンジンを比較検討することをお勧めします。*

## 対象読者

この記事は主に、無料で高いコンバージョン率を誇る当社の予約エンジンを自社ウェブサイトに導入したいホテル向けです。
しかし、当社の技術を自社サイトで利用したいすべての方にも有益な内容です。

## リンク経由

最も簡単な連携方法として、[共有可能リンク](/ja/portal/studio/shareable-links)の利用を推奨します。

手順は以下の通りです：

<Steps>
1. https://app.wink.travel にアクセス
2. 右上の `Sign-In / Register` をクリックし、ユーザーアカウントでログイン
3. 左上のドロップダウンから操作したい物件を選択
4. ナビゲーションバーの `Booking engine` をクリック
5. ページにリンクが表示されます
6. このリンクをウェブマスターに渡し、**BOOK NOW** ボタンに使用してください
7. 完了 ✅
</Steps>

:::note
このリンクは自社ウェブサイトで使用でき、予約エンジンは自社ドメイン上でも動作可能です（詳細は[予約エンジンの機能](/ja/booking-engine/features/)をご覧ください）。Googleの無料予約リンクのトラフィックは異なり、常に book.wink.travel に着地します。[Googleでの掲載方法](/ja/guides/hoteliers/get-listed-on-google/#where-the-guest-lands)もご参照ください。
:::

### 高度な使い方

リンクには選択した `customization` に基づく旅程がURLに組み込まれています。
リンクをさらにカスタマイズするには：

- 選択したカスタマイズを変更するか
- 旅程を上書きする

この記事では後者に焦点を当てます。これにより、旅行者が自社サイト上で旅程を選択し、それをWinkの予約エンジンに渡す自由度が高まります。

URLに旅程を渡す方法は以下の通りです。

有効なリクエストパラメータ：

- **sd** チェックイン日を追加：*sd=2027-03-14*
- **n** 宿泊日数を追加：*n=1* または
- **ed** チェックアウト日を指定：*ed=2027-03-15*
- **rc** 宿泊人数：*rc=a2*（大人2名）
- **l** 表示言語の指定：*l=es*
- **c** 表示通貨の指定：*c=EUR*
- **p** プロモーションコードの追加：*p=ABC123*

URL例：

https://trvl.as/abc123?sd=2027-03-14&n=1&rc=a2&l=es&c=EUR

さらに高度なケースでは、`+` 記号を使って複数の部屋構成を指定できます：

例：

https://trvl.as/abc123?sd=2027-03-14&n=1&rc=a2-ca16q1-ca8q1+a2&l=es&c=EUR

- 部屋タイプ1 = 大人2名、子供2名（16歳＋8歳）
- 部屋タイプ2 = 大人2名

### 例

**BOOK NOW** ボタンのHTMLサンプル：

*このサンプルは、主要なCSSライブラリとして[Bootstrap](https://getbootstrap.com)を使用していることを想定しています。*

```html
<a
  href="https://trvl.as/abc123"
  target="_blank"
  class="btn btn-lg btn-primary"
  title="Book a room"
>
BOOK NOW
</a>
```

### その他の利点

当社のリンクを `book now` ボタンとして使う他の利点もあります。

- **ソーシャルフレンドリー** リンクはソーシャルメディアで簡単に共有でき、選択した画像の上に `動的価格表示` がされます。
- **短縮URL** URLが非常に共有しやすく、InstagramのプロフィールURLなどにも使えます。

## 埋め込み経由

より多機能で深い連携を望むホテル向けに、[カード](/ja/portal/studio/cards)を自社サイトに埋め込む例を紹介します。

手順は以下の通りです：

<Steps>
1. https://app.wink.travel にアクセス
2. 右上の `Sign-In / Register` をクリックし、ユーザーアカウントでログイン
3. 左上のドロップダウンから操作したい物件を選択
4. メインナビゲーションバーの `Search` をクリック
5. 物件名を入力し、検索ボタンをクリック
6. 検索結果カードの `Actions` リンクをクリックし、`Create > Make a Card` を選択
7. カードが作成されます
8. 右上にカードが準備できた旨のメッセージが表示され、さらにカスタマイズするか尋ねられます
9. メインナビゲーションバーの `Tools > Cards` をクリックし、新しいカードを確認
10. カードの `Actions` リンクをクリックし、`Embed` を選択
11. 新しいウィンドウが開き、コピー可能なHTMLコードが表示されます
12. `Client-ID` を取得するには [Applications](/ja/account/applications) にアクセス
13. `Configuration-ID` を取得するには [Customization](/ja/portal/settings/branding) にアクセス
14. 完了 ✅
</Steps>

埋め込みカードのHTMLサンプル：

```html
<wink-content-loader
  layout="GUEST_ROOM"
  id="09d7cca4-6ff6-11ef-949b-42004e494300"
></wink-content-loader>
```

*上記HTMLサンプルにはWinkのCSSおよびJavascriptは含まれていません。カードのみです。*
