Google Analytics 4 プロパティを Wink に接続すると、部屋の閲覧から予約完了までの予約イベントが、Wink 独自の分析と並んで自動的にご自身の GA4 ダッシュボードに転送されます。コード不要、技術的な設定も不要です。

<Aside type="tip">
GA4 からは **Measurement ID** と **Measurement Protocol API secret** の2つが必要です。Measurement ID はゲストのブラウザでの閲覧ファネルを動かし、API secret は Wink が予約完了（`purchase`）を **サーバー側で** 記録できるようにするため、ゲストが決済プロバイダーへリダイレクトされても売上が失われません。
</Aside>

---

## 仕組み

```
Measurement ID (G-XXXXXXXXXX) と API secret を Wink ポータルに入力
       ↓
閲覧イベント（閲覧、カート、チェックアウト）がブラウザから GA4 プロパティにストリーム送信される
予約完了（purchase）はサーバー側で送信され、決済リダイレクトを乗り越える
       ↓
analytics.google.com にログインして完全な予約ファネルを確認
```

---

## やること

<Steps>

1. **GA4 プロパティを作成する**

   [analytics.google.com](https://analytics.google.com) にアクセスし、管理 → プロパティを作成。タイムゾーンと通貨を市場に合わせて設定。

2. **ウェブデータストリームを作成する**

   管理 → データストリーム → ストリームを追加 → ウェブ。URL に `wink.travel` を入力。これで **Measurement ID** (`G-XXXXXXXXXX`) が生成されます。コピーしてください。

3. **Measurement Protocol API Secret を作成する**

   同じウェブデータストリームを開き、**Measurement Protocol API secrets** までスクロール → **作成**。ニックネーム（例：「Wink」）を付けて生成された **シークレット値** をコピー。このシークレットにより Wink は予約完了をサーバー側で記録でき、決済リダイレクト時に売上が失われません。

4. **Wink ポータルに Measurement ID と API Secret を入力する**

   [app.wink.travel](https://app.wink.travel) にログインし、アカウントを選択して **カスタマイズ** タブへ。GA4 フィールドに Measurement ID と API secret を貼り付けて保存。これで GA4 連携が有効になります。

   <Aside type="note">
   API secret は **書き込み専用** です：保存後は再表示されません。将来編集する際は、既存の値を保持したい場合はシークレット欄を空欄のままにしてください。
   </Aside>

5. **`purchase` を重要イベントとしてマークする**

   GA4 プロパティに戻り、管理 → イベント → `purchase` を探して **重要イベントとしてマーク** をオンにします。これで予約完了がコンバージョンレポートに表示されます。

6. **データを確認する**

   [analytics.google.com](https://analytics.google.com) にログインすると、予約、収益、ゲストファネルが自動的に Wink を通じて追跡されているのが見られます。

</Steps>

<Aside type="note">
この連携のためにご自身のウェブサイトにトラッキングコードを設置する必要はありません。Wink がすべて処理します。Measurement ID は予約データの送信先であり、API secret は Wink がサーバー側で予約完了を確認するためのものです。
</Aside>

<Aside type="tip">
**GA4 と GTM は併用可能です。** 例えば Sojern コンテナなどの Google タグマネージャーを運用している場合でも、両方を同時に設定できます。もはや排他的ではありません。[GTM Analytics Integration](/ja/guides/developers/gtm-dual-tagging) をご覧ください。
</Aside>

## 追跡できる内容

接続後、GA4 プロパティは物件向けの拡張eコマースイベントの全スイートを受信します：

### 発見段階

| イベント | 意味 |
|---|---|
| `view_item_list` | ゲストが検索やカテゴリ一覧で物件を見た |
| `select_item` | ゲストが一覧から物件をクリックした |
| `view_item` | ゲストがホテル詳細ページを閲覧した |

### 検討段階

| イベント | 意味 |
|---|---|
| `view_promotion` | ゲストが物件のプロモーションを見た |
| `select_promotion` | ゲストがプロモーションをクリックした |
| `add_to_wishlist` | ゲストが物件をウィッシュリストに保存した |

### 予約ファネル

| イベント | 意味 |
|---|---|
| `add_to_cart` | ゲストが部屋やパッケージを選択した |
| `view_cart` | ゲストが予約概要を見た |
| `remove_from_cart` | ゲストが部屋やパッケージをカートから削除した |
| `begin_checkout` | ゲストがチェックアウトを開始した |
| `add_payment_info` | ゲストが支払い情報を入力した |
| `add_shipping_info` | ゲストがゲスト情報を入力した |
| `purchase` | ゲストが予約を完了した |
| `refund` | 予約がキャンセルされ返金された |

すべてのイベントには収益、通貨、部屋タイプ、予約金額などの関連ディメンションが含まれ、最初の印象から予約完了までのゲストの行動を完全に把握できます。`city_name`、`cancellation_policy`、`bed_type` などの物件・部屋レベルの追加ディメンションを利用するには、[Custom Dimensions in GA4](/ja/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4) をご覧ください。

## クロスドメイントラッキング（上級）

上記の標準連携は Wink 内で起こるすべてを追跡します。しかし、ご自身のウェブサイトから Wink での予約完了までゲストの行動を追跡し、元のトラフィックソース（Google 広告、メールキャンペーン、オーガニック検索など）を正しく帰属させたい場合は、双方で追加の設定が必要です。

<Aside type="caution">
このセクションはご自身のウェブサイトに GA4 を導入している場合のみ該当します。サイトで GA4 を運用していない場合は、上記の標準連携だけで十分です。
</Aside>

### なぜ重要か

クロスドメイントラッキングがないと、最初にご自身のサイトを訪れてから Wink で予約したゲストは、GA4 上では元の訪問と切り離された **直接アクセス** としてカウントされます。Google 広告のクリックやメールキャンペーン、オーガニック検索の訪問が予約に結びついても、正しく評価されません。

クロスドメイントラッキングを設定すると、ゲストの行動が完全に追跡されます：

```
google.com（有料広告）
       ↓
ご自身のウェブサイト（ゲストが部屋を閲覧）
       ↓
wink.travel（ゲストが部屋を選択し予約）
       ↓
購入が元の Google 広告クリックに正しく帰属
```

### あなたがやること

GA4 プロパティで `wink.travel` を自分のドメインの一部として認識させ、外部リファラーとして扱わないように設定します。これにより GA4 は2つのセッションを1つの連続したゲストジャーニーとして結合します。

<Steps>
1. GA4 管理 → データストリーム → 対象のストリーム
2. タグ設定の構成 → **ドメインの構成**
3. `wink.travel` をリンクドメインとして追加
4. 保存
</Steps>

### Wink がやること

[Wink サポート](https://app.wink.travel) に連絡し、ご自身のウェブサイトドメイン（例：`yourhotel.com`）を伝えてください。Wink は Wink GA4 プロパティのリファラー除外リストにドメインを追加します。これにより、ご自身のサイトがリファラーとして記録されるのを防ぎ、ゲストの元の帰属情報が上書きされて新しいセッションが始まるのを防ぎます。

<Aside type="tip">
上記の標準連携はほとんどの物件に十分で、Wink 上の予約や収益を即座に可視化できます。クロスドメイントラッキングは上級オプションで、GA4 データに慣れてより詳細な帰属分析をしたい場合に設定を検討してください。
</Aside>
