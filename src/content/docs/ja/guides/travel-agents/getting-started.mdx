このガイドでは、旅行代理店が登録から最初のクライアント予約までの流れを説明します。また、Winkで代理店が利用できる2つの方法についても解説し、開始前に適切な方法を選べるようにします。

## はじめる前に

以下が必要です：

- 会社の詳細情報
- 旅行代理店登録番号、またはIATAコード（お持ちの場合）
- 手数料の振込先となる銀行口座

## 利用方法を選ぶ

| | 標準（ほとんどの代理店） | 代理店が支払いを回収する方法 |
|---|---|---|
| 予約方法 | WinkポータルまたはPartner API経由 | ご自身のシステムから[Partner API](/ja/integrations/partner-api/)経由 |
| クライアントの支払いを受け取るのは誰か | ホテルが受け取り、ホテルがマーチャント・オブ・レコードのまま。チェックアウト時にクライアントのカードを入力します。 | 代理店がマーチャント・オブ・レコードとして受け取ります。 |
| 収益 | 各予約に対して**10%の基本手数料** | 各ホテルとの独自契約に基づく手数料 |
| Winkへの支払い | なし | 各予約金額の**1.5%**の予約手数料（毎月請求）、および無料枠を超えたPartner API利用料 |
| ホテルへの支払い | Winkが代行 | 代理店が各ホテルに直接支払い（独自契約に基づく） |
| 返金、チャージバック、支払いコンプライアンス | Winkが代行 | 代理店の責任 |
| 承認 | 登録審査後に予約可能 | 登録審査に加え、Winkの書面による承認と与信枠設定あり |

Winkはすべての旅行代理店登録を審査します。ほとんどの代理店は標準ルートを利用します。代理店が支払いを回収する方法は**APIパートナーのみ**対象で、自社システムからPartner API経由で予約し、独自のライセンスと契約でクライアント支払いを回収し、ホテルと直接契約している代理店向けです。

## ステップ1：代理店を登録する

<Steps>
1. [app.wink.travel](https://app.wink.travel)にアクセスし、`Sign-In / Register`をクリックして登録します。

2. 左サイドバーの`Accounts`をクリックし、`Create`を選択して**I am a Travel Agent**を選びます。

3. 代理店の詳細を入力します。支払い方法を決めるため、法人形態は**Company**を選択してください。[アカウント作成](/ja/portal/create-account/)を参照。

4. Partner API経由で自分で支払いを回収する場合は、登録時にそのルートを選択します。これは申請であり承認ではありません。[ステップ6](#step-6-collect-payment-yourself-api-partners-only)を参照。

5. Winkはすべての旅行代理店登録を審査します。登録住所にメールを送り、会社情報と旅行代理店登録番号またはIATAコードの書類を求めます。承認されると予約が可能になります。
</Steps>

## ステップ2：銀行口座を追加する

`Account > Bank Accounts`に移動し、代理店の口座を追加して**Primary**に設定します。手数料は銀行振込で支払われます。WinkはRevolut経由で支払いを行うため、Revolutビジネスアカウントが最もスムーズですが、どの銀行口座でも利用可能です。[銀行口座](/ja/portal/settings/payouts/)を参照。

## ステップ3：クライアントのためにホテルを探す

<Steps>
1. メインナビゲーションバーの`Browse > Hotels`をクリック。

2. 目的地、日付、宿泊人数で検索し、クライアントに合った選択肢が見つかるまで絞り込みます。

3. クライアントと比較検討する場合は、[キュレーションリスト](/ja/portal/studio/curated-lists/)にショートリストを保存します。
</Steps>

表示される料金はホテルの公式料金です。Winkはマークアップなしでそのまま提供し、収益は手数料から得られます。[検索](/ja/portal/studio/search/)を参照。

## ステップ4：クライアントのために予約する

<Steps>
1. 部屋と料金を選び、旅行者としてクライアントの名前と連絡先を入力します。

2. チェックアウト時に、クライアントから受け取ったカード情報を入力します。支払いはホテルに対して行われ、ホテルがマーチャント・オブ・レコードのままです。

3. 確認します。代理店、旅行者、ホテルにそれぞれ確認メールが届きます。予約コードは`WNK`で始まります。
</Steps>

:::caution[クライアントのカード情報は慎重に扱う]
予約のためにカード情報を求めるのはその予約のみとし、すぐにチェックアウト画面に入力してください。カード情報をメモしたり、メールで送ったり、自分の記録に残したりしないでください。
:::

## ステップ5：予約管理と支払い受取

- **予約管理:** メインナビの`Bookings`をクリックするとすべての予約が表示され、フィルター、CSVエクスポート、確認メールの再送、ホテルのキャンセルポリシー内でのキャンセルが可能です。[予約管理](/ja/portal/travel-agent/bookings/)を参照。
- **手数料:** 基本は10%。特定のホテルと継続的に取引する場合は、[直接接続](/ja/portal/studio/network/)を依頼し、異なる手数料を合意できます。
- **支払いタイミング:** 手数料はゲストのチェックイン後24時間以内に利用可能となり、プライマリ銀行口座に振り込まれます。振込手数料は実費負担です。[料金](/ja/getting-started/pricing/)を参照。

## ステップ6：自分で支払いを回収する（APIパートナーのみ）

ポータルで予約する場合や標準ルートで問題なければ、このステップはスキップしてください。

<Steps>
1. [Partner API](/ja/integrations/partner-api/)と連携します。この方法はポータルではなく、自社の予約システムからAPI経由でのみ利用可能です。

2. 登録時にこのルートを選択します（ステップ1）。

3. Winkは登録書類とともに財務状況や規制状況を評価し、書面で承認します。承認には**与信枠**が設定され、未決済予約の最大保有額が決まります。

4. 承認されるまでは標準ルートで予約を続けられます。
</Steps>

承認後はクライアントの支払いを自分で受け取り、各ホテルに直接支払います。各予約で、まず1.5%のWink手数料を差し引き、その後に手数料を差し引きます。残額がホテルへの支払いとなります。

| USD 1,000.00の予約、手数料10%の場合 | |
|---|---|
| 予約金額 | USD 1,000.00 |
| Wink手数料（予約金額の1.5%） | USD 15.00 |
| 小計 | USD 985.00 |
| 手数料（小計の10%） | USD 98.50 |
| **ホテルへの支払い額** | **USD 886.50** |

Winkは1.5%の予約手数料を毎月USDで請求し、15日以内に支払う必要があります。無料枠を超えたPartner API利用料も請求されます。返金、チャージバック、支払いセキュリティ（PCI-DSS）、および支払い回収に必要な国のライセンスは代理店の責任です。詳細は[旅行代理店契約](/ja/legal/platform-agreements/)をご覧ください。

## 自社システムとの連携

独自の予約ツールを持つ代理店は[Partner API](/ja/integrations/partner-api/)を通じて検索・予約が可能です。旅行代理店アカウントは直接APIで予約を作成でき、代理店が支払いを回収するルートはAPI経由のみです。[Partner APIリファレンス](/ja/partner-api/partner/)を参照。
