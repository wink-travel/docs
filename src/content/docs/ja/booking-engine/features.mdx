予約エンジンは、在庫が予約可能になる場所です。施設は[Portal](/ja/portal/overview)で在庫をリストし、アフィリエイトもそこで共有可能なコンテンツに変換します — そして予約エンジンはそのコンテンツを旅行者に適切な言語、通貨、ブランディングで提供し、予約を受け付けます。

`https://book.wink.travel`というウェブサイトとして公開されており、同じ機能が[Web Components](/ja/integrations/web-components)、[WordPressプラグイン](/ja/integrations/wordpress)、[API](/ja/api)を通じてインテグレーターにも提供されています。

## 一つのエンジン、フィットする形で

予約エンジンは一つだけで、`https://book.wink.travel`にあります。

<LinkButton href="https://book.wink.travel/home" variant="secondary" icon="external" target="_blank">
  予約エンジンを開く
</LinkButton>

販売者に合わせて適応します。多くの施設を扱うアフィリエイトには閲覧・比較用のホームページが作られます。単一のホテルにはその施設の在庫に直接つながるページが用意されます。プロパティマネジメント会社には[代表する施設](/ja/portal/settings/agency-representation)が表示されます。これらは別のサイトや別製品ではなく、同じエンジンに対して[カスタマイズ](/ja/portal/settings/branding)がどのように表示するかを指示しているだけです。

## 旅行者ができること

### 予約したいものを見つける

- **目的地で検索。** 都市、島、国、または特定の施設、レストラン、スパ、会議室、アクティビティ、観光地、場所を調べる。
- **ランキングされたコレクションを閲覧。** 会員料金、価格、人気、エコ評価、体験、特典、ロイヤルティ、追加オプションで並べ替えられた在庫を、世界規模または都市・島・国単位で探検。
- **結果をフィルター** 名前、半径、ライフスタイル、星評価、直販のみの在庫で絞り込み。
- **旅程を設定** — チェックイン・チェックアウト日、大人・子供の人数と年齢、複数部屋、プロモコード。グリッドの価格はリアルタイムで更新。

詳細は[検索](/ja/booking-engine/search)をご覧ください。

### 施設を評価する

各施設には写真ギャラリー、ローカライズされた説明、地図、アメニティ、星評価とゲストスコア、Greendexエコ評価、ゲストレビュー、施設のレストラン、スパ、アクティビティ、観光地、会議室、旅行アドバイザリーが掲載された専用ランディングページがあります。

詳細は[施設詳細](/ja/booking-engine/property-detail)をご覧ください。

### 宿泊を組み立てて予約する

- **部屋と料金プランを選択**、返金可能・不可のオプションが明確に表示。
- **各料金に付随する特典を確認** — 保証されたものと空き状況によるもの。
- **複数部屋を一つの予約に追加**し、数量を調整。
- **ホテルの追加オプションやパッケージを追加**、日時指定の追加オプションも含む。
- **合計金額がリアルタイムで更新**、部屋ごとの価格内訳と公開料金との差額も表示。
- **埋め込みの安全な決済ウィジェットでチェックアウト・支払い**。カード、ウォレット、現地決済方法が施設の決済アカウントに応じて提供。

詳細は[チェックアウト](/ja/booking-engine/checkout)をご覧ください。

### 予約後の管理

- **予約確認を表示**、予約コードを即時およびメールで受け取る。
- **ログイン不要で予約を開く** — アカウントを作成していないゲストもメールの予約リンクでアクセス可能。
- **予約内容を確認**：キャンセルポリシー、支払い状況、支払方法、追加料金、施設の連絡先。
- **操作を行う**：予約コードのコピー、共有、カレンダーへの追加、印刷、領収書のダウンロード、理由付きキャンセル、キャンセル期限外の返金申請。
- **宿泊後にレビューを書く**。
- **複数予約がある場合は旅行ごとにグループ化して表示**。

詳細は[予約](/ja/booking-engine/bookings)と[予約確認](/ja/booking-engine/confirmation)をご覧ください。

### パーソナル化

- **ヘッダーからいつでも言語と通貨を切り替え** — 40以上の言語と160以上の通貨。
- **Winkのシングルサインオンで一度サインイン**。サインイン後はチェックアウト途中も含め、元の場所に戻る。
- **旅行プロフィールを保持** — ロケール設定、緊急連絡先、アレルギー、ペット、アクセシビリティ、ホテル・部屋・食事・個人の好みを管理し、予約した施設と共有するか選択可能。
- **リンクやQRコードで施設を共有**、15のソーシャル・メッセージングネットワークに対応。

詳細は[旅行設定](/ja/booking-engine/travel-preferences)をご覧ください。

## 旅行者が予約エンジンにたどり着く方法

ほとんどの場合、予約エンジンへの直接リンクは不要です。[Portal](/ja/portal/overview)で作成したリンク、カード、グリッド、地図、そして[WinkLinks](/ja/portal/link-manager/wink-links)で公開したものはすべて、クライアントID、アフィリエイトID、ブランディングを含み、旅行者を適切なページに適切な旅程をセットして誘導します。

| 共有するもの | 旅行者がたどり着く場所 |
| --- | --- |
| [共有可能リンク](/ja/portal/studio/shareable-links) | 短縮された`trvl.as` URLで、ブランド化された施設ランディングページに展開。旅程、通貨、言語が事前適用済み。Facebook、X、WhatsAppなどURLが使える場所で投稿可能。 |
| [カード](/ja/portal/studio/cards) | 単一の予約可能なサプライヤーや在庫アイテム — ホテル、部屋タイプ、スパ、レストラン。`予約`は予約フローを開き、`ベストディール`と`ホテル詳細`は施設ページへ。 |
| [グリッド](/ja/portal/studio/grids) | キュレーションリスト、保存検索、ライブランキング検索から作成されたページネーション付きカードセット。各カードは同じ方法で予約可能。 |
| [地図](/ja/portal/studio/maps) | マーカーが予約可能なカードを開くインタラクティブ地図。 |
| [WinkLinks](/ja/portal/link-manager/wink-links) | 上記の任意の組み合わせをホストするリンクインバイオページ。Instagramから2クリックで予約へ。 |
| [今すぐ予約ボタン](/ja/guides/hoteliers/the-book-now-button) | 自サイトのボタンで、自動生成された施設リンクに日付、部屋構成、言語、通貨、プロモコードをURLパラメータとして付加。 |
| [Web Components](/ja/integrations/web-components) | カード、グリッド、地図、検索、旅程ピッカーをページに直接埋め込み。予約はエンジンにフォワードするかモーダルで開くか選択可能。 |
| [WordPressプラグイン](/ja/integrations/wordpress) | 同じコンポーネントをWordPressショートコードとして、Gutenberg、Elementor、Avada、WPBakeryで利用可能。 |
| [API](/ja/api) | リモート旅行代理店システムやチャネルマネージャー向けの直接統合。 |

どのルートであっても、送客したアフィリエイトは帰属記録され、180日間保持されるため、後日の予約でも紹介したアフィリエイトにクレジットが入ります。

## ホワイトラベリング

予約エンジンはあなたのブランドの背後に消えるように設計されています。

最も軽いレベルでは、[カスタマイズ](/ja/portal/settings/branding)がエンジンのスタイルをあなたのものとして読み替えます：名前、ロゴ、色、タイポグラフィ。旅行者は依然として`book.wink.travel`にアクセスします。

最も深いレベルでは、**アフィリエイトが独自ドメインで予約エンジンを運用可能**です。ドメインを予約エンジンに向けると、ホスト名から自動的にカスタマイズが解決されます — URLにクライアントIDや設定IDは不要、アドレスバーにWinkドメインも表示されません。旅行者は検索から確認まで`book.yourbrand.com`を見ます。

:::note[独自ドメインの設定]
カスタムドメインはセルフサービスではなく弊社のサポートで設定します。[お問い合わせ](/ja/contact)から使用したいドメインをお知らせください。設定とカスタマイズへの接続を行います。
:::

## カスタマイズ

以下はすべてカスタマイズ単位で設定され、複数保持可能 — 市場別、キャンペーン別、施設別など。

**アイデンティティ**

- ページタイトルに付加される表示名とタグライン。
- ロゴ、予約メール用の別ロゴも含む。

**見た目と操作感**

- 11色のカラーパレット：プライマリ、セカンダリ、成功、危険、警告、情報、ライト、ダーク、本文、ミューテッド、ホワイト。
- 20種類の厳選フォントから選択可能なタイポグラフィ。
- ホームページ、ヘッダー、施設ページのレイアウト — 情報型または取引型。
- カードレイアウト — 縦グリッドまたは横リスト。
- 検索バー、ランキングバッジ、利用不可施設カードのトグル。

下記の開発者サンドボックスでテーマのカスタマイズを試せます。

<LinkButton href="https://developer.wink.travel/web-component" variant="secondary" icon="external" target="_blank">
  テーマ設定
</LinkButton>

**旅行者が最初に着地するデフォルト**

- デフォルトの言語と通貨。
- 事前設定された旅程 — 固定日付または「30日後、2泊」などのローリングウィンドウ。
- デフォルトの部屋構成とプロモコード。
- 目的地ピッカーのデフォルト都市。

**計測と連携**

- Winkと並行して動作する独自のGoogle Analytics 4測定ID、Google Tag Managerコンテナ、トラッキングピクセル。
- 独自のGoogle Maps APIキー。
- 予約通知メールの送信先制御（施設、予約者、チャネルマネージャー）。
- 埋め込みコンポーネントの`予約`ボタンが予約エンジンにフォワードするかモーダルで開くかの制御。

詳細な項目ごとの説明は[カスタマイズ](/ja/portal/settings/branding)と[予約体験のカスタマイズ](/ja/guides/general/customizing-your-booking-experience)をご覧ください。

## 直接リンク

予約エンジンに手動でリンクする場合は、URLにクライアントIDとカスタマイズIDをパラメータとして追加します。どちらも[Portal](/ja/portal/overview)の操作中のアカウント（施設、管理会社、アフィリエイトいずれか）に存在します。

### クライアントIDの見つけ方

<Steps>
1. [Accounts](https://app.wink.travel)から操作したいアカウントを選択。
2. アカウントカード下部の`Actions`をクリックし、`Manage account`を選択。
3. 次のページで`Applications`タブをクリック。
4. 使用したいアプリケーションのClient IDをコピーし、URLのリクエストパラメータとして貼り付け。例：?client-id=MY_CLIENT_ID
</Steps>

アプリケーションの作成・管理については[Applications](/ja/account/applications)をご覧ください。

### カスタマイズIDの見つけ方

<Steps>
1. [Accounts](https://app.wink.travel)から操作したいアカウントを選択。
2. アカウントカード下部の`Actions`をクリックし、`Manage account`を選択。
3. 次のページで`Customizations`タブをクリック。
4. 使用したいカスタマイズのCustomization IDをコピーし、URLのリクエストパラメータとして貼り付け。例：?configuration-id=MY_CUSTOMIZATION_ID
</Steps>

カスタマイズで制御される内容の全リストは[カスタマイズ](/ja/portal/settings/branding)をご覧ください。

### 組み合わせ例

ホームページへのリンクは以下のようになります：

https://book.wink.travel?client-id=MY_CLIENT_ID&configuration-id=MY_CUSTOMIZATION_ID

ホームページはあなたのブランディングを反映し、アカウントが代表する在庫 — 自施設、管理施設、またはアフィリエイトカタログ全体 — を表示します。

特定の施設に直接送る場合は、そのランディングページにリンクしてください：

https://book.wink.travel/hotel/hotel-x?client-id=MY_CLIENT_ID&configuration-id=MY_CUSTOMIZATION_ID

:::note
クライアントIDまたはカスタマイズIDを省略すると予約エンジンは読み込まれますが、デフォルト設定にフォールバックし、旅行者はデフォルトのブランディングを見て、予約はあなたに帰属しません。必ず両方を含めてください。
:::

## 例：施設ページ

Winkのすべての施設には固有のランディングページがあります。すべての外部リンクはこれらのランディングページに旅行者を誘導します。

ランディングページには、旅行者が宿泊を検討するために必要な情報がすべて含まれています。
