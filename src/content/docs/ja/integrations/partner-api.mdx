Winkの**パートナーAPI**は、認証された高スループットの方法で、統合者が予約可能な旅行在庫を照会できるものです。これは、埋め込み可能なウィジェットや公開ブラウズエンドポイントを支える同じ供給を、第一級のプログラムインターフェースとして公開しています。無料のWebコンポーネントや公開ブラウズエンドポイントは軽量で人間向けの埋め込みを目的としていますが、パートナーAPIは大規模に検索、価格設定、予約を行うシステム向けに構築されています。アクセスは統合者ごとに認証され、使用量に応じて課金されるため、実際に送信したトラフィック分だけ支払います。

## APIリファレンス

予約可能な在庫を提供する2つのOpenAPIインターフェースがあり、上記の2つの階層に対応しています：

- **無料 — コンシューマー / 予約エンジンAPI** (`/api/public/**`): 匿名、ブラウザおよびウィジェット向け。[予約エンジンリファレンスを見る →](/ja/api/booking-engine/)
- **有料 — パートナー統合API** (`/api/partner/**`): 認証済み、使用量計測、サーバー間統合向け。[統合者リファレンスを見る →](/ja/partner-api/partner/)

## 使用量と制限の仕組み

### 無料プラン

無料プランは、構築、テスト、控えめな本番トラフィックの運用を無償で可能にするために設計されています。

- **レート制限 — 1分あたり30リクエスト、バースト60リクエスト。** 持続的なレートを超える短期的なスパイクはバースト許容量で吸収されます。超過するとAPIは**HTTP 429（リクエスト過多）**で応答し、**5分間の停止**が適用され、その後キーがトラフィックの提供を再開します。停止期間後にリトライし、エンドポイントを叩き続けるのは避けてください。
- **月間クォータ — カレンダー月あたり10,000リクエスト。** 月間上限に達すると、APIは**月末までHTTP 429を返し**、継続利用には有料プランへの加入を促すメッセージを表示します。カウンターは翌月初めにリセットされます。

無料プランにはサービスレベル契約や優先サポートは含まれません。

### 有料プラン

有料プランは月間上限とレート制限の停止を解除し、使用量に応じてのみ課金されます。

- **従量課金 — 1,000リクエストあたり$1.00。** 月間リクエスト上限はなく、通常使用ではレート制限もありません。実際の使用量に基づいて課金されます。
- **ルック・トゥ・ブック超過料金 — 1,000ルック超過ごとに$2.00。** 供給の健全性を保つため、検索数（「ルック」）と確定予約数の比率を計測します。1予約あたり**5,000ルック**までは超過料金は発生しません。超過ルックは以下の式で計算されます：

  `excess = max(0, looks − bookings × 5,000)`

  超過分は**1,000ルックあたり$2.00**で課金されます。コンバージョン率の高い統合では超過料金はほとんど発生しません。超過料金は、予約よりもはるかに多く検索するトラフィックにのみ適用されます。

有料プランには以下に記載のサービスレベル契約（99.9%の稼働率保証とP95応答時間500ms未満の目標）および優先度・重大度に基づくサポートが含まれます。

## サービスレベル契約

_発効日：2026年7月5日 · バージョン1.0_

本サービスレベル契約（以下「SLA」）は、Wink（「Wink」、「当社」）が認証済みWinkパートナーAPI（「パートナーAPI」または「サービス」）に対して、SLAが適用される階層の顧客（「顧客」、「お客様」）に提供する可用性コミットメント、サービスクレジット、およびサポート目標を定めるものです。本SLAは、お客様とWink間のパートナーAPIアクセスに関する契約（「契約」）に組み込まれ、かつこれに準拠し、有効な有料パートナーAPIサブスクリプションを維持している限り適用されます。ここで定義されていない大文字用語は契約で定義された意味を持ちます。

### 1. 定義

1. **「稼働時間」**とは、パートナーAPIが適切に形成され認証されたリクエストを受け入れ、正常に応答できる期間を指します。
2. **「停止時間」**とは、パートナーAPIが適切に形成され認証されたリクエストに正常に応答できなかった期間（分単位）を指し、セクション4に記載の除外事項に該当する期間は含みません。影響がごく一部のリクエストに限られる単発のエラーは停止時間に含まれません。
3. **「月間稼働率」**とは、特定のカレンダー月におけるその月の総分数から停止時間の分数を差し引いたものを、その月の総分数で割った割合（パーセンテージ）を指します。
4. **「予定メンテナンス」**とは、Winkがセクション4に従い事前通知を行ったサービスの計画的メンテナンスを指します。
5. **「サービスクレジット」**とは、稼働率コミットメントを満たせなかった場合の唯一かつ排他的な救済措置として、該当月にお客様が支払ったまたは支払うべきパートナーAPI料金の一定割合として計算され、将来のパートナーAPI料金に充当されるクレジットを指します。
6. **「応答時間」**とは、Winkのサービス境界で適切に形成され認証されたリクエストを受信してから、Winkが応答の返送を開始するまでの経過時間を指し、ネットワーク遅延やクライアント側の時間は含みません。

### 2. 可用性およびパフォーマンスコミットメント

Winkは、契約期間中の各カレンダー月において、パートナーAPIの**月間稼働率を99.9%以上**に維持するよう商業的に合理的な努力を行います（「稼働率コミットメント」）。稼働率コミットメントはWinkのサービス境界で測定され、セクション4に記載のWinkの合理的な管理外の要因は除外されます。Winkの監視システムが月間稼働率および応答時間の公式な記録源です。

さらに、Winkは各カレンダー月において、正常で適切に形成され認証されたリクエストの**95パーセンタイル（P95）応答時間を500ミリ秒未満**にすることを目標とします（「パフォーマンス目標」）。パフォーマンス目標はセクション4に記載の要因、リクエスト自身の原因によるアプリケーションレベルのエラー、異常に大きいまたは複雑なバッチリクエストを除外します。パフォーマンス目標はサービス目標であり、セクション3のサービスクレジットは**稼働率コミットメント**の不達成に対する唯一かつ排他的な救済措置です。

### 3. サービスクレジット

月間稼働率が稼働率コミットメントを下回った場合、お客様は当該月に支払ったまたは支払うべきパートナーAPI料金の割合に応じたサービスクレジットを受ける資格があります。以下の表に従います：

| 月間稼働率 | サービスクレジット |
|---|---|
| 99.9%未満かつ99.0%以上 | 10% |
| 99.0%未満かつ95.0%以上 | 25% |
| 95.0%未満 | 50% |

1. **クレジット請求。** サービスクレジットを受けるには、停止が発生したカレンダー月の終了後**30日以内**にWinkに書面で請求を提出する必要があります。請求には、請求対象の停止事象の日時および合理的に入手可能なログや証拠を含めてください。この期間を過ぎた請求は対象外です。
2. **クレジットの形態。** 承認されたサービスクレジットは将来のパートナーAPI料金に充当され、現金価値はありません。返金ではなく、適用法令で要求される場合を除き現金支払いは行いません。
3. **最大クレジット。** 1カレンダー月あたりのサービスクレジットの合計は、その月にお客様が支払ったまたは支払うべきパートナーAPI料金の50%を超えません。
4. **唯一かつ排他的な救済。** サービスクレジットは、Winkが稼働率コミットメントを満たさなかった場合の**唯一かつ排他的な救済措置**です。

### 4. 除外事項

稼働率コミットメントおよびサービスクレジットは、以下に起因または関連するサービスの利用不可、停止、劣化、パフォーマンス問題には適用されず、停止時間にも含まれません：

1. Winkが事前通知を行った**予定メンテナンス**（合理的な期間前に通常の連絡チャネルを通じて通知されたもの）；
2. 自然災害、政府の行為、ネットワークやユーティリティの障害、サービス拒否攻撃やその他の悪意ある攻撃など、Winkの合理的管理外の**不可抗力**事象；
3. お客様の行為または不作為、お客様の機器、ソフトウェア、ネットワーク、またはWinkの直接管理下にない第三者サービス、製品、プロバイダーによる問題；
4. お客様の**サービスの乱用**または**契約、SLA、許容使用条件、適用レート制限の違反**、過剰なトラフィック、機械的乱用、不正行為とWinkが合理的に判断するもの；
5. 契約に基づき適切に実施されたお客様のアクセスの**停止または終了**（未払いによる停止を含む）。

### 5. サポートおよび応答目標

Winkは標準営業時間内（現地祝日を除く）にパートナーAPIのサポートを提供します。Winkは、お客様が割り当てた重大度に基づき、Winkが合理的に確認した場合、以下の目標応答時間内に適切に提出されたサポートリクエストに対して初回応答を行うよう商業的に合理的な努力をします：

| 重大度 | 説明 | 目標初回応答時間 |
|---|---|---|
| **Sev 1 — 重大** | パートナーAPIが本番環境でダウンまたは使用不能で、回避策なし。 | 4時間 |
| **Sev 2 — 主要** | 重要な機能が障害または劣化しているが回避策あり。 | 1営業日 |
| **Sev 3 — 軽微** | 一般的な質問、軽微な問題、機能要望。 | 2営業日 |

目標応答時間は**初回連絡**の目標であり、解決時間の保証ではありません。優先サポートおよび重大度に基づく目標は、該当階層で提供されます。

### 6. データおよびセキュリティ

Winkは、パートナーAPIを通じて処理されるデータの機密性、完全性、可用性を保護するために商業的に合理的な管理的、技術的、組織的措置を維持し、定期的に見直します。Winkの個人データ処理は[プライバシーポリシー](/ja/privacy)および契約のデータ処理条項に準拠します。お客様は自身のAPI認証情報の保護、取得したデータの合法的な使用、および認証情報の不正使用が疑われる場合の速やかなWinkへの通知に責任を負います。

### 7. 責任の制限

サービスクレジットは、稼働率コミットメントの不達成に対する**唯一かつ排他的な救済措置**であり、それに起因するその他の責任に代わるものです。本SLAに明示されている場合を除き、パートナーAPIは「現状有姿」で提供されます。適用法の最大限許容範囲内で、Winkのサービスに関する総責任は契約に定める範囲に限定され、間接的、偶発的、特別、結果的、懲罰的損害や利益、収益、データ、信用の損失については、たとえその可能性を知らされていても責任を負いません。

### 8. 期間、変更および終了

本SLAは、SLA適用階層の有効なパートナーAPIサブスクリプションを保持している限り適用されます。Winkは本SLAを随時更新することができ、重要な変更は通常の顧客連絡チャネルを通じて通知されます。更新後のパートナーAPIの継続利用は更新されたSLAの承諾を意味します。本SLAは契約またはパートナーAPIサブスクリプションの終了または満了により自動的に終了します。終了後も性質上存続すべき条項（未請求のサービスクレジット資格、責任制限、定義など）は存続します。
