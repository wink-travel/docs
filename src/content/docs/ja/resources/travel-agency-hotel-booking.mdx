## 直接供給と再販供給の違い

ほとんどの代理店向けホテルコンテンツは、ホテル → チャネルマネージャー → 卸売業者またはベッドバンク → 代理店というチェーンを経由して届きます。各段階で遅延、マージン、代理店が見る情報とホテルの実際の状況の乖離が生じます。

よくある問題は、顧客が決定する頃には料金が古くなっている、確認時に空室がなくなる、部屋の説明が合わない、予約していないホテルに質問できない、などです。

直接予約はこのチェーンを省きます。料金はホテルのもので、空室状況はリアルタイム、予約はホテルのシステムに代理店情報付きで入ります。

| | 卸売業者 / ベッドバンク | 直接ホテル供給 |
|---|---|---|
| 料金の起点 | 契約割当、しばしば静的 | ホテルのリアルタイム料金 |
| 空室状況 | キャッシュされ、確認時に失敗することも | ホテルからのリアルタイム |
| マージン構造 | 料金内のマークアップ | 透明な手数料 |
| 顧客所有権 | 共有または不透明 | 代理店が顧客を保持 |
| ホテルとの関係 | 間接的 | ホテルと直接 |
| 特別リクエスト | チェーンを通じて伝達 | 予約と共にホテルに届く |

## 代理店が直接予約に必要なもの

- **対象供給へのアクセス** — どのホテル、部屋、料金が代理店向けに利用可能か、ホテルが設定。
- **顧客向けに提示する方法** — 厳選されたホテルリスト、パッケージ、地図、提案や旅程のためのストアフロント。
- **ソースを保持する予約経路** — 手数料の帰属が追跡可能。
- **明確な支払い条件** — 誰が集金し、誰がマーチャント・オブ・レコードか、手数料の決済タイミング。
- **ホテルに確実に届く確認・変更処理。**

## 支払いの2つの方法

**ホテルが集金する場合。** 支払いはホテルのために集められ、ホテルがマーチャント・オブ・レコードとなります。代理店は帰属した予約に対して手数料を得て、マーチャント責任は負いません。これがデフォルトで、ライセンスは不要です。

**代理店が集金する場合。** 適切な地域の旅行代理店ライセンスを持つ代理店は、顧客から直接支払いを受けてホテルに支払うことができます。この場合、Winkは資金を扱わないため、**1.5%の処理手数料のみ**を月次請求します。どのライセンスが必要かは運営地域によるため、事前に現地で確認してください。

## 手数料と計算基準

デフォルトは**10%**で、ホテルの1.5%プラットフォーム手数料とカード処理費用を差し引いた後の金額に対して計算されます。2000ドルの予約では約**189ドル**です。帰属は**クリックから6ヶ月間**有効で、提案が数週間顧客に留まる場合に重要です。

## 団体、イベント、MICE予約

直接供給は、卸売業者が弱い分野で特に価値があります：結婚式、会議、リトリート、インセンティブのための部屋ブロック。これらは料金、確保、締切日についてホテルと話し合う必要があり、予約が代理店のものでホテルが代理店を認識している場合に可能です。

対象供給から作成されたストアフロントやイベントページは、参加者に予約可能なリンクを提供しつつ、ブロック、帰属、報告を代理店に保持します。

## よくある間違い

- **ネット卸売料金と手数料対象の直接料金を比較し、既に含まれるマークアップを調整しないこと。**
- **PDFを顧客に送ること。** 予約できない提案は、予約可能な提案に予約を奪われます。
- **すべての顧客に同じリンクを共有すること。** 帰属と報告が推測になってしまいます。
- **手数料を得るためにライセンスが必要だと誤解すること。** 支払いを自分で集金する場合のみ必要です。
- **顧客からの問い合わせがあるまで、ブロックのキャンセル条件を無視すること。**
