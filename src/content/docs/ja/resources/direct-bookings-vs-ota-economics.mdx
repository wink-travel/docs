## なぜ総予約価値だけでは不十分なのか

ホテルはしばしばチャネルを客室数、総予約価値、稼働率で比較します。これらの指標は有用ですが、経済全体を示すものではありません。チャネルは**純貢献度**で評価すべきです：

<div class="not-prose my-5 rounded-xl border border-border bg-muted/40 p-5 text-sm leading-relaxed text-foreground/90">
  <strong class="text-foreground">純予約価値</strong> = 総予約価値 − 手数料／獲得コスト − 支払いコスト − キャンペーンコスト − キャンセル＆ノーショーの影響 − 運用コスト <span class="text-primary">+ リピート予約価値 + アップセル＆付帯価値 + ゲスト関係の戦略的価値</span>
</div>

OTA予約は、空室を埋めたり、新しい市場にホテルを紹介したりする場合に有用です。ホテルがすでに需要を持ち、自社のウェブサイト、予約エンジン、ソーシャルルート、パートナールート、QRコード、AIハンドオフ、プラットフォーム統合を通じてコンバージョンできる場合、直接予約はより価値があります。すべての予約を同じとみなすのは誤りです。

## OTAの経済学

OTAは実際の問題を解決します：供給を集約し、旅行者を引き付け、広告に多大な投資をし、比較ツールを提供し、ホテルが直接リーチできないところに可視性を作り出します。そのリーチにはコストがかかります。Cloudbedsによると、多くの大手OTAの手数料はプラットフォーム、地域、物件タイプ、契約条件により**15%から30%以上**に及ぶことが一般的です。

OTAコストは基本手数料だけにとどまりません。ホテルはプロモーション参加、優先掲載プログラム、支払い・通貨手数料、接続コスト、キャンセル・代替リスク、レートパリティや在庫管理にかかる運用時間も考慮します。OTA経済学はOTAが*追加的な*需要を生み出す場合に意味があります。問題は過度の依存であり、ホテルが直接獲得できた予約に高い獲得コストを支払うことです。

## 直接予約の経済学

直接予約は自動的に無料ではありません。ホテルはウェブサイト、予約エンジン、コンテンツ、SEO、有料検索、メタサーチ、CRM、分析、決済処理、スタッフの時間を必要とするかもしれません。しかし、直接チャネルはうまく運用されると強力な経済性を生みます。ホテルはオファーとブランドストーリーをコントロールでき、客室、パッケージ、アドオン、飲食、スパ、体験を完全に提示でき、使えるゲストデータを保持し、到着前後のコミュニケーションを送り、リピート予約を促し、ソースとキャンペーンを追跡し、ソーシャル、パートナー、QR、AI、プラットフォームの需要を同じ予約エンジンに誘導できます。

SiteMinderのHotel Booking Trendsによると、ホテルのウェブサイトは2025年に平均予約価値が**516米ドル**で、OTAの**312米ドル**を上回りました。すべてのホテルが同じ結果を得るわけではありませんが、ホテルが直接予約を価値とコンバージョン品質で評価すべき理由を示しています。

## 直接予約 vs OTAの比較

| 項目 | 直接予約 | OTA予約 |
|---|---|---|
| 獲得コスト | 直接需要とコンバージョン基盤が整えば低い。 | 手数料ベースで、予約価値に対して一般的に大きい。 |
| ゲスト関係 | ホテルが直接コミュニケーションしリピート価値を構築。 | OTAがショッピングとコミュニケーション環境をよりコントロール。 |
| ブランドコントロール | ホテルがストーリー、イメージ、客室提示、アップセルをコントロール。 | OTAのテンプレートとランキングロジックに制約される。 |
| オファーの柔軟性 | パッケージ、アドオン、飲食、スパ、特典の販売が容易。 | OTAのマーチャンダイジングルールに依存。 |
| アトリビューション | リンク、QRコード、ソーシャル、パートナーを追跡すれば詳細。 | OTAソースは見えるが、上流の影響は測りにくい。 |
| 発見リーチ | ブランド、SEO、有料メディア、パートナー、オーディエンスに依存。 | 比較や未知物件需要に強いマーケットプレイスリーチ。 |
| リピート価値 | ホテルが同意を得て良好にコミュニケーションすれば高い。 | リピート関係はOTAに残る可能性がある。 |
| 最適な用途 | 既知の需要、所有オーディエンス、パートナールート、リピートゲスト。 | 追加リーチ、新市場、低需要期。 |

## キャンセルリスクの重要性

チャネル経済学は手数料だけではありません。PhocusWireが報じたCloudbedsの調査によると、2025年のデータではOTA予約は独立系ホテルの直接予約よりキャンセル率が高い傾向にあります。市場、ポリシー、リードタイム、料金タイプ、セグメントによって行動は異なるため、ベンチマークを盲目的にコピーしないでください。しかし原則として、**純価値にはキャンセルリスクを含めるべきです。** 総量は多いがキャンセル率が高くリピート価値が低いチャネルは、見かけほど利益的でないかもしれません。

## 具体例：同じ予約でも異なる純価値

これはあくまで例示であり、Winkの価格設定や料金表ではありません。

| 項目 | OTA予約 | 直接予約 |
|---|---:|---:|
| 総予約価値 | $1,000 | $1,000 |
| 手数料／獲得コスト | −$180 | −$60 |
| 支払い＆処理 | モデル依存 | −$30 |
| キャンセル・リピート前の純価値 | $820 | $910 |
| ゲスト関係 | 部分的にOTA管理 | ホテル管理 |
| アップセル機会 | チャネルに制約あり | アドオン＆パッケージ利用可能 |

数値は変動しますが、論理は同じです：直接予約の経済学はチャネルコスト、データ価値、アップセル価値、リピート可能性の組み合わせです。

## なぜOTAがまだ重要なのか

OTAを排除することが目標ではありません。多くのホテルにとってそれは賢明ではありません。OTAは新規または認知度の低いホテルの可視性を高め、低需要期を埋め、国際市場にリーチし、比較や直前需要に対応します。PhocuswrightはOTAが世界の宿泊流通の中心であり続けていると指摘し、2026年のCloudbeds調査では独立系ホテルのOTAシェアは**63.4%**で、2024年の61.3%から増加しています。戦略的な問いはOTAが有用かどうかではなく、ホテルがOTAを**意図的に使っているか、デフォルトで使っているか**です。

## パートナー需要の役割

直接予約 vs OTAはパートナーを無視すると狭すぎます。KOL代理店、DMC、イベント主催者、コミュニティ、銀行、ロイヤルティプログラム、プラットフォームなどのパートナー予約は、純粋な直接予約とOTA経済学の間に位置します。パートナーが需要を作り出し、ホテルが承認された供給、アトリビューション、予約エンジンの履行を維持する場合、構造が整っていれば（ホテルが在庫を管理し、パートナーが承認済み資産を使い、ルートがパートナーコンテキストを運ぶ）、パートナー需要は**直接予約スタイルの経済学**を生みます。

## チャネルミックスの監査方法

1. **すべての予約ソースをリストアップ** — ウェブサイト、ブランド・オーガニック検索、Googleホテルサーフェス、メール、ソーシャル、QR、直接販売、OTA、卸売業者、DMC、パートナー、イベント、Traveliko、開発者統合、AIルート。
2. **チャネルごとの純予約価値を計算** — 総価値、手数料、支払いコスト、キャンペーンコスト、キャンセル率、平均価値、滞在日数、アドオン支出、リピート率。
3. **リーチチャネルと関係チャネルを分ける** — 両方を意図的に使う。
4. **高い獲得コストを払うべきでない予約を見つける** — OTA経由のリピートゲスト、OTA広告に送られるブランド検索需要、一般的なOTAページに誘導されるソーシャルフォロワー、アトリビューションのないパートナー推薦。
5. **より良い直接経路を構築** — チャネルを責める前に経路を修正：モバイル対応予約、最新料金、明確なポリシー、信頼シグナル、関連オファー、支払いの安心感、迅速な読み込み。
