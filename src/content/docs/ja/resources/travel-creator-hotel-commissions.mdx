## ブランド契約はリーチに対して支払う。コミッションは成果に対して支払う。

スポンサー付き宿泊や有料投稿はコンテンツに対する一度きりの料金です。視聴者数に基づいて価格が決まり、毎回交渉が必要で、投稿が流れてしまうと収益は止まります。

コミッションは逆の仕組みです。コンテンツは残り、リンクは有効で、誰かが予約するたびに収益が発生します。小規模で特定のオーディエンスの方が、信頼されていて意図が明確なため、大規模な一般層よりも成果が出やすいことが多いです。

| | ブランド契約 | 予約コミッション |
|---|---|---|
| 支払い対象 | コンテンツ | 確定した予約 |
| 価格基準 | フォロワー数、リーチ | 予約金額 |
| 収益発生 | 一度きり | 帰属された予約ごとに |
| メディアキット必要 | 通常必要 | 不要 |
| フォロワー最低数 | 通常必要 | 不要 |
| 古い投稿で機能 | いいえ | はい、リンクが有効な間は |

両者は対立するものではありません。クリエイターはローンチ時にブランド料を受け取り、その下でコミッションを継続して稼ぐことがよくあります。

## 実際に稼げる額

Winkでは基本が**10%のコミッション**で、ホテルの1.5%のプラットフォーム手数料とカード決済手数料を差し引いた後の金額に対して計算されます。100ドルの予約なら約**9.45ドル**、5泊で1,200ドルの予約なら約**113ドル**です。

クリックは**6ヶ月間**あなたに帰属されます。これは見た目以上に重要です。3月にリールを見て保存し、パートナーと日程を確認して5月に予約する場合、7日や30日の期間ではその予約は無効になってしまいます。

## 稼ぐために必要なもの

- **予約可能な送客先。** 実際におすすめするホテルのストアフロントで、ホームページのリンクではありません。
- **ホテル管理の料金。** 表示する価格はホテル自身のもので、視聴者が他で安く見つけて信頼を失わないようにします。
- **コンテキストごとにリンクを分ける。** リール、ストーリー、ニュースレター、プロフィールごとに別のリンクを用意し、効果を測定できるようにします。
- **視聴から予約までのギャップをカバーするアトリビューション。**

## 実際に成果が出る投稿内容

- **一般的より具体的に。** 「このホテルでリクエストすべき部屋」は「バリのベスト10ホテル」より効果的。
- **実用的な疑問に答える。** 価格帯、徒歩圏内か、プールは静かか、朝食は価値があるか。
- **意図がある場所にリンクを置く。** 部屋の説明の瞬間にリンクを置き、プロフィールだけに置かない。
- **古いコンテンツも収益化。** まだ閲覧がある投稿のリンクを更新し、新しい投稿だけを追いかけない。
- **季節ごとの再利用。** 目的地コンテンツは毎年再浮上するため、ライブリンクが無料トラフィックを収益化可能にする。

## Winkでの仕組み

対象ホテルの供給を閲覧し、**Studio**や**WinkLinks**でリンク、カード、マップ、ストアフロントを作成して投稿します。誰かが予約すると、**Booking Engine**があなたのアトリビューション付きで予約を処理し、コミッションがあなたのアカウントに報告されます。ホテルは料金と空室管理を保持し、あなたはオーディエンスとの関係を維持します。

参加は無料です。手動投稿やWinkLinksの公開も無料で、SocialのAIコンテンツ生成のみ使用量に応じた課金で、コミッションを稼ぐために必須ではありません。

## よくある間違い

- **ホームページに送る。** 余計なクリックが予約を減らします。
- **自分で管理しない料金を宣伝する。** 視聴者が他で安く見つけると予約と信頼を失います。
- **すべて同じリンクを使う。** 帰属できなければ改善できません。
- **新しい投稿だけ投稿する。** 古い投稿のライブリンクが新規より稼ぐことも多いです。
- **フォロワー数の閾値を待つ。** コミッションに最低条件はなく、小さくても熱心なオーディエンスで始められます。
