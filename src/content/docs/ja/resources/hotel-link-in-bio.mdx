## ホテルにとって「Link in Bio」が重要な理由

ソーシャルプラットフォームはクリック可能なリンクを制限しています。Instagram、TikTokなどのプロフィールはブランドに実質的に**1つのリンク**しか与えません。だから「Link in Bio」はホテルのコンテンツとフォロワーが次に行うべきことの間の入り口になりました。同じ制約はQRコードの裏、短縮キャンペーンURL、パートナー推薦にも現れます：1つのリンクがその瞬間を担わなければなりません。

一般的なLink in Bioツールは問題の半分しか解決していません。リンクを整理しますが、人々を**離れた**ページに送り、ライブのホテル在庫を表示せず、予約もできません。ホテルにとってそれは漏れです：注目は来ますが、ホームページやOTAに消えてしまいます。

解決策は、その1つのリンクを**ディレクトリではなくストアフロント**として扱うことです。

## Link in Bioとトラベルストアフロントの違い

| | 一般的なLink in Bio | トラベルストアフロント |
|---|---|---|
| 内容 | URLのリスト | 予約可能なホテルカード、オファー、リスト、地図 |
| 役割 | 人を離れたページに送る | 予約へと導く |
| 在庫 | なし | ライブのホテル在庫と料金 |
| チェックアウト | なし | Booking Engineによる実現 |
| アトリビューション | なしまたは基本的なクリック | 予約を通じて保持 |
| 対象 | デスクトップの後付け | モバイルファースト |

トラベルストアフロントはLink in Bioページのように見えます — クリーンでモバイル対応、1つのリンク — しかし予約可能なショップフロントのように機能します。

## ホテルのトラベルストアフロントに含められるもの

1つの公開リンクで予約可能なコンテンツの全メニューを提示できます：

- **予約可能なホテルカードとオファー** — 部屋、パッケージ、季節限定の特典。
- **キュレーションリスト** — 「家族向けベスト」「ウェルネスエスケープ」「イベントホテル」など。
- **予約可能な供給の地図やグリッド**。
- **リッチコンテンツ、ファイル、メディア** — パンフレット、ウェルカム情報、ギャラリー。
- **QRコードの行き先** — 施設内コードの裏にあるストアフロント。
- **通常のリンク** — 予約以外のすべて。

これがトラベルストアフロントが物件のInstagramプロフィール、結婚式のルームブロック、デスティネーションキャンペーン、パートナーの推薦ページに同様に効果的な理由です。

## Winkでの仕組み

- **[Studio](/ja/products/studio/)が資産を作成。** 承認されたホテル供給から予約可能なカード、リンク、地図、グリッド、QRコードを作成。
- **[WinkLinks](/ja/products/winklinks/)がストアフロント。** それらの資産を1つのモバイルファーストの公開リンク`i.trvl.as/your-name`にまとめる — カードビューまたはリストビューで。**無料で利用可能**。
- **[Booking Engine](/ja/products/booking-engine/)が予約を実現。** タップでチェックアウトへ進み、支払い、確認、滞在全体を完了 — ソースとパートナーのアトリビューションを保持。

これは[ホテルソーシャルコマース](/ja/resources/hotel-social-commerce/)の締めくくりの場面です：コンテンツが注目を生み、ストアフロントが予約可能な選択肢を保持し、Booking Engineが変換します。

## 利用者

- **ホテル** — ソーシャルプロフィール、QRコード、メール、施設内資料用の1つのリンク。部屋、オファー、ダイニング、スパ、体験を表示。
- **パートナーとクリエイター** — ネットワークホテルから作られたデスティネーションページ、イベントコレクション、キャンペーンストアフロント。[10%のデフォルトコミッションと6ヶ月のアトリビューション](/ja/partners/)付き。
- **イベント** — 参加者が1つのリンクから予約できるルームブロックやデスティネーションストアフロント。

## 実践的なセットアップ

1. **リンクを取得** — `i.trvl.as/your-name`を設定。
2. **Studioで資産を作成** — 特集したい部屋、オファー、コレクション。
3. **ストアフロントを配置** — カードビューかリストビューを選び、最も強力な予約可能オファーを先頭に。
4. **リンクをあらゆる場所に配置** — ソーシャルプロフィール、QRコード、メール署名、キャンペーンURL、パートナーページ。
5. **常に最新に保つ** — 季節のオファーやイベントを入れ替え、ストアフロントが常に販売中の内容を反映。
6. **測定** — どの入口やソースがコンバージョンしているかを確認し、改善。

## よくある間違い

- **URLのリストだけの一般的なLink in Bioを使うこと。** フォロワーを予約へ導くのではなく離れたページに送ってしまう。
- **プロフィールリンクを直接ホームページにすること。** ランディングページではなく予約可能なオファーを先頭に。
- **ストアフロントを放置して古くすること。** オファーやイベントを更新し、クリックする価値を保つ。
- **パートナーを忘れること。** 同じストアフロントモデルでパートナーがホテルをアトリビューション付きで提示できる。
