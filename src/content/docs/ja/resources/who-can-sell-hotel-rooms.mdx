## 混同されやすい2つの活動

**予約の紹介。** ホテルを推薦し、旅行者が予約し、ホテルに支払いが行われ、あなたはコミッションを得ます。資金は一切保持しません。

**マーチャントとしての販売。** 旅行者の支払いを自分の口座で受け取り、ホテルに支払います。あなたが旅行者に宿泊を提供する責任者となります。

後者はほとんどの市場でライセンス取得のトリガーとなり、チャージバックのリスク、返金義務、税務処理も伴います。前者は一般的にそうではないため、法人格のないクリエイターでもコミッションを得られ、顧客資金を保持するツアーオペレーターはライセンスが必要となります。

## 2つのモデルの違い

| | ホテルのために支払いが回収される場合 | あなたが支払いを回収する場合 |
|---|---|---|
| マーチャント・オブ・レコード | ホテル | あなた |
| 旅行代理店ライセンス | 紹介には不要 | 通常は地域により必要 |
| チャージバック責任 | ホテルの責任 | あなたの責任 |
| 返金・キャンセル対応 | ホテルが対応 | あなたが対応 |
| 消費者保護義務 | ホテルの義務 | あなたの義務 |
| Wink手数料 | 予約ごとに1.5%のプラットフォーム手数料＋カード処理費用 | 月次請求の1.5%処理手数料のみ |
| 受け取るコミッション | デフォルト10% | 自分でマージン設定 |
| 必要な事業者資格 | 誰でも可 | ライセンス取得事業者 |

## ライセンスなしで収益を得られる人

最初のモデルでは、以下のすべてがホテル予約でコミッションを得られます：

- **クリエイターやKOL** がオーディエンスに推薦を投稿
- **出版社やニュースレター** が目的地やホテルの編集記事を運営
- **コミュニティやクラブ** が会員旅行を企画
- **イベント主催者** が参加者のために部屋を確保
- **代理店やDMC** が顧客の旅程を作成
- **銀行、ロイヤルティ、会員プログラム** が旅行特典を提供
- **アプリ、プラットフォーム、AIエージェント** が予約経路を組み込み

これらはいずれも旅行者の資金を保持しないため、マーチャントにはなりません。ホテルは従来通り、ゲストと契約し宿泊を提供します。

## 2番目のモデルが適切な場合

自分で支払いを回収するのは、すでにライセンスを持つ旅行事業者で、自社の顧客契約、支払い関係、返金ポリシーを持ち、ホテルを仕入先として扱いたい場合に限られます。航空券とホテルをパッケージにするツアーオペレーターが一般的な例です。

その場合、Winkは**1.5%の処理手数料のみ**を請求し、資金の流れには関与しません。そうでなければ、最初のモデルで同じコミッションをより少ない負担で得られます。

## 販売開始前に確認すべきこと

- **旅行者の所在地**（自分の所在地だけでなく）— 消費者保護規則は旅行者に従うことが多いです。
- **資金を保持するかどうか**、たとえ短時間でも。保持が重要な境界線です。
- **ホテルと交通をパッケージにするか** — 別のパッケージ旅行規則が適用される場合があります。
- **返金が旅行者にどう届くか**、宿泊に問題があった場合の対応者。
- **自社の利用規約で何を約束しているか** — モデルに関わらず義務が生じることがあります。

国ごとに規則は異なり変わります。マーチャントモデルを選ぶ前に必ず現地の専門家に確認してください。

## よくある間違い

- **コミッションを得るのにライセンスが必要と誤解すること。** 紹介の場合は通常不要です。
- **「便利だから」と自分の口座を経由して支払いを回すことで、意図せずマーチャント・オブ・レコードになること。**
- **ホテルが資金とポリシーを持つのに、自分で返金を約束してしまうこと。**
- **一国の規則をすべての地域に適用すること。** 義務は旅行者の所在地に従うことが多いです。
- **より良いレートを求めてマーチャントモデルを選ぶこと。** コミッションは増えず、責任が増えます。
