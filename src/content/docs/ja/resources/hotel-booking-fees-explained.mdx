## 予約に表示される3つの費用

ほとんどのホテルの商取引料金は一つの混合パーセンテージにまとめられています。これではどの部分がサービス料で、どの部分が実費の通過費用で、どの部分が販売コストなのかが隠れてしまいます。分けると：

1. **プラットフォーム料金 — 1.5%。** 確定予約を実現するために商取引層が請求する料金。
2. **カード処理 — 実費。** カードネットワークと決済代行業者が請求する料金で、マージンなしで通過されます。
3. **コミッション — デフォルトで10%、場合によって発生。** ゲストを紹介した者に支払われます。自社サイトからの予約ではゼロです。

自社サイトからの予約は1と2の費用のみ。パートナー、クリエイター、AIエージェント経由の予約は3つすべての費用がかかります。

## なぜカード処理費用は固定額ではないのか

カード処理費用はカードの種類、発行国、通貨、決済方法によって異なります。国内のデビットカードと海外のプレミアムクレジットカードでは受け入れコストが異なり、誠実な提供者は両者に対して一律の料金を約束できません。

実費で通過させることで、ホテルは予約ごとの実際の費用を把握できます。トレードオフとして、合計費用は単一の数字ではなく範囲として示されます。例として、カード手数料が4.0%の場合、直接予約の合計は約5.5%になります。実際の数字はゲストが提示するカードによって異なり、予約ごとに実際の手数料が表示されます。

## 具体例

ホテルの自社サイトからの100ドルの直接予約を、カード手数料4.0%で例示：

| 項目 | 金額 |
|---|---|
| 予約金額 | $100.00 |
| プラットフォーム料金 (1.5%) | −$1.50 |
| カード処理費用 (例示4.0%) | −$4.00 |
| **ホテルの手取り** | **約$94.50** |

同じ予約でパートナーやクリエイターが紹介した場合：

| 項目 | 金額 |
|---|---|
| 予約金額 | $100.00 |
| プラットフォーム料金＋カード処理費用 | −$5.50 |
| パートナーコミッション (10%、手数料後) | −$9.45 |
| **ホテルの手取り** | **約$85.05** |

パートナー経由の場合でも、OTA予約で一般的な15〜25%のコミッションより低く、ホテルはゲストとの関係、メールアドレス、次回予約を保持できます。

## 無料のサービス

- ホテル自社サイトの**予約エンジン**
- エクストラネットを通じた**物件管理**
- **WinkLinks**のストアフロント
- **アフィリエイト、パートナー、旅行代理店向けツール**
- **手動のSNS投稿、分析、リーダーボード**
- **消費者向けおよび予約エンジンAPI**

サブスクリプション、席数、初期設定費用は一切ありません。利用料金が発生するのは、SocialのAIコンテンツ生成とパートナーAPIの無料枠を超えたボリュームのみで、どちらも予約を受けるために必須ではありません。

## マーチャント・オブ・レコードは誰か

**ホテルがマーチャント・オブ・レコードです。** 支払いはホテルのために回収され、ホテルがゲストと契約する当事者のままです。これは税務、チャージバック、消費者保護義務に関わり、ホテルがゲストとの関係を保持する理由でもあります。

認可を受けた事業者（例：承認済み旅行代理店）が代わりに支払いを回収し、ホテルに直接支払うことも可能です。その場合、Winkは資金を扱わないため、**1.5%のカード処理手数料のみ**を月次請求します。

## どのプロバイダーにも確認すべき質問

- カード手数料は**実費通過かマークアップか**？
- プラットフォーム料金は**予約数に対してか、総収入に対してか**？
- コミッションは**総額か手数料控除後か**？
- **マーチャント・オブ・レコードは誰か**、チャージバック責任は誰が負うか？
- 追加の**サブスクリプション、席数、初期設定費用はあるか**？
- **キャンセルや返金時の料金の扱いはどうなるか**？

## よくある誤解

- **混合率と分割率を比較すること。** 同じ条件で比較しないと誤った結論になります。
- **ゲストの生涯価値を忘れること。** 直接メールできるゲストは、できないゲストより価値があります。
- **コミッションは避けられないものと考えること。** パートナー経由の予約にのみ適用され、自社サイトのトラフィックにはかかりません。
- **安い＝機能が少ないと考えること。** 無料プランに何が含まれているかを確認し、不要なプランにお金を払わないようにしましょう。
