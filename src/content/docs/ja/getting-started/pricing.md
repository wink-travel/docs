Winkにはサブスクリプション、席数制限、初期設定費用はありません。プラットフォームの大部分は無料で、支払うのは以下の2つだけです。

1. **予約ごとのプラットフォーム手数料とカード決済手数料（実費）** — 予約が成立したときのみ発生します。
2. **従量課金制の使用料** — 実行するたびにコストがかかる一部のプレミアム機能に対して、無料の月間利用枠があります。

## 無料の内容

以下は永続的に無料で、利用枠や計測もありません。

- **予約エンジン** — 自社サイト、WinkLinksページ、または埋め込み先のどこでも利用可能。
- **物件管理** — コンテンツ、写真、料金、料金プラン、空室状況、プロモーション、ポリシー。
- **アフィリエイトツール** — 共有可能なリンク、キュレーションリスト、グリッド、地図、カード、埋め込みウィジェット。
- **旅行代理店ツール** — 検索、特別料金、顧客代理予約。
- **WinkLinks** — 独自のバニティURLを取得し、ページを作成して何度でも公開可能。
- **手動のソーシャル投稿** — 接続されたネットワーク上で自分で書いた投稿。
- **分析、リーダーボード、クレーム、設定**およびアカウント管理。
- **ConsumerおよびBooking Engine API**、およびそれらのルックアップとオートコンプリートエンドポイント。**Partner API**では、LookupとContentの呼び出しはそれぞれ1ユニットとして計測されます（詳細は[Usage](#what-is-and-isnt-metered)参照）。

## 予約

Winkは2つのモデルをサポートしています：Winkがホテルの代わりに支払いを回収するモデルと、旅行代理店が加盟店として記録されるモデルです。

### モデル1 — Winkがホテルの代わりに回収

Winkはホテルの限定的な支払い回収代理人としてゲストの支払いを回収します。ホテルが加盟店として記録され、ゲストのカード明細にはホテル名が表示されます。
このモデルは全予約の95%に適用されます。

#### 内訳

:::note[プラットフォーム手数料]
Winkは予約ごとに1.5%のプラットフォーム手数料を請求します。これはプラットフォームの維持費用をカバーし、上記の無料サービスを提供可能にしています。キャンセルされた予約には課金されません。
:::

:::note[カード決済手数料]
ゲストの支払いを回収するための決済処理手数料は実費でホテルに転嫁され、マージンはありません。手数料はゲストのカードや支払い方法によって異なり、各予約の会計セクションに正確な金額が表示されます。予約がキャンセルまたは返金された場合でも、決済業者が保持する手数料は請求されます。手数料が発生しない場合は、Winkも請求しません。
:::

:::note[資金送金手数料]
資金をアカウントに送金する際に手数料が発生します。これは選択した送金方法によります。現在サポートしているのは：

- **銀行振込** — お住まいの国、送金元、途中で適用される通貨換算によって費用が異なります。送金手数料および換算コストは受取人が実費で負担します。アカウントに利用可能な資金がある場合に使える見積もり計算機を用意しています。

他の送金方法のサポートをご希望の場合はメールでご連絡ください。
:::

### モデル2 — 旅行代理店が加盟店として記録

このモデルは、地域の旅行代理店ライセンスを保有し、加盟店として記録されることを希望する旅行代理店のみが利用可能です。APIパートナー限定で、[Partner API](/ja/integrations/partner-api/)経由の予約に適用され、Winkの事前書面承認が必要です。登録済みの旅行代理店の中には、支払い処理とホテルへの資金送金を自ら管理したいという希望を持つところがあります。このモデルでは、資金の管理責任を負い、必要なライセンスを保有しています。

#### 内訳

:::note[プラットフォーム手数料]
Winkは予約ごとに1.5%のプラットフォーム手数料を請求します。これはプラットフォームの維持費用をカバーし、上記の無料サービスを提供可能にしています。
:::

このモデルでは、旅行代理店はWinkの1.5%手数料と無料枠を超えたPartner APIの使用料を月次で請求されます。

## パートナーの支払い

予約を送信するパートナー：クリエイター、アフィリエイト、プラットフォーム、開発者、旅行代理店。パートナーシップは非独占で、地域制限はありません。

|  | ホテルのために支払いを回収（ほとんどのパートナー） | あなたが加盟店（APIパートナーのみ） |
|---|---|---|
| ライセンスまたは地域手数料 | なし | なし |
| 初期設定費用 | なし | なし |
| サブスクリプションまたは月額料金 | なし | なし |
| 最低契約期間または条件 | なし | なし。クレジットリミット適用。 |
| Partner APIアクセス | 月間10,000ホテル泊まで無料、その後1ホテル泊あたり$0.0001。従量課金はデフォルトでオフ。無料枠超過時は`429`を返す。 | 同上 |
| 取引手数料 | なし。コミッション（デフォルト10%）を獲得。 | 予約金額の1.5%の予約手数料。月次USD請求、15日以内支払い。従量課金オン時はPartner API使用料が別途月次請求。 |
| サポート費用 | なし | なし |
| その他の料金 | 送金手数料（実費） | 承認時に前払いまたはデポジットの可能性あり。未払い請求書には月1.5%の遅延利息。 |
| 料金変更時期 | 30日前通知。変更後の予約にのみ適用。 | 同上。Winkは通知の上、クレジットリミットを変更可能。 |

加盟店モデルはWinkの事前書面承認が必要です。[モデル2](#model-2--travel-agent-as-merchant-of-record)および[Partner API](/ja/integrations/partner-api/)ページを参照してください。

## 使用料（従量課金制）

一部の機能は実行するたびにコストがかかります — 生成AI、サードパーティのソーシャルAPI、大規模なリアルタイム価格提供など。これらを月額プランにまとめる代わりに、実際に使った分だけ支払い、無料の月間利用枠を超えた分だけ課金されます。

| 機能 | 月間無料枠 | その後 | 課金単位 |
| -- | -- | -- | -- |
| ソーシャル投稿 — 画像 | 1 | $1.50 | 1件の公開投稿 |
| ソーシャル投稿 — AI生成画像 | 0 | $2.50 | 1件の公開投稿 |
| ソーシャル投稿 — AI強化動画 | 0 | $4.00 | 1件の公開投稿 |
| ソーシャル投稿 — AI生成動画 | 0 | $14.00 | 1件の公開投稿 |
| コメントやDMへのAI返信 | 5 | $0.05 | 1件の返信 |
| チャットボット回答 | 5 | $0.05 | 1件の回答 |
| Partner API | 10,000 | $0.0001 | 1ホテル泊 |

価格はUSDです。無料枠は**アカウント単位**で付与され、ユーザー単位ではありません。毎月1日（UTC）にリセットされます。

### 投稿の価格設定方法

投稿は中身の内容によって価格が決まります。画像は安価ですが、動画は高価です。AI生成メディアは自分で用意した写真よりもコストがかかります。

- **無料枠は標準画像投稿のみをカバーします。** アカウントごとに月1件の無料枠があります。動画投稿やAI生成メディアは最初の投稿から課金対象で、動画投稿を行う物件は初月から料金が発生します。
- **動画が優先されます。** 投稿に動画が含まれる場合、その投稿全体が動画料金で課金されます。画像と動画が混在する投稿は動画投稿とみなされます。
- **AI生成かどうかで料金が変わります。** 自分で提供した写真やWinkのコンテンツライブラリのメディアは標準料金で課金されます。Winkが生成したメディアはAI料金で課金されます。

### 計測されるものとされないもの

- **生成された投稿が第三者ネットワーク（Facebook、Instagramなど）に公開された場合のみ課金対象です。** 自分で書いた投稿はどこに公開しても無料です。
- **WinkLinksへの公開は常に無料**です。生成投稿でも手数料はかかりません。
- **課金は公開時に発生し、試行回数ではありません。** 下書きを何度も再生成しても課金は1回だけです。ただし、画像は約10回、動画は約3回の再生成制限があります。作業中に残り回数が表示されます。
- Partner APIでは、**ホテル泊数**が課金単位です。1回のAPI呼び出しで20軒のホテルを3泊検索すると、60ホテル泊分の課金となります。ContentおよびLookup（目的地検索とオートコンプリート）呼び出しは1ユニットずつ課金されます。アカウント関連のエンドポイントは無料です。

### 従量課金の有効化

従量課金はデフォルトでオフです。無料枠は誰でも利用可能です。

無料枠を超えて利用するには、**アカウントのオーナーが従量課金を有効化し、どのアカウントを計測対象にするか選択します。** 有効化されたすべてのアカウントの使用量は**1つの月次請求書**にまとめられ、カードで自動決済するか、自分で支払うための請求書を受け取れます。

有効化後は使用量が計測されますが、**決して制限されません。** Winkでの支出に対してレート制限に達することはありません。

:::note[有効化しない場合]
何も壊れず、料金も発生しません。その月は無料枠で止まり、生成投稿は公開されず、Partner API呼び出しは無料枠がリセットされるまで`429`を返します。
:::

### 請求状況

| 状態 | 意味 |
| -- | -- |
| 良好 | すべて正常に動作しています。 |
| 支払遅延 | 支払いが失敗し再試行中です。この期間中も機能は利用可能です。 |
| 停止中 | 請求書が未払いのまま期限を迎えました。課金対象の操作は停止されますが、無料機能は通常通り利用可能です。 |

:::tip[リアルタイム価格]
単価と無料枠は常にPortalに表示され、請求システムから直接取得されます。契約前に確認可能です。[Billing](/ja/portal/plan)で従量課金を有効化し、アカウントを選択、月間使用量と請求書を追跡できます。[Social](/ja/portal/social/what-is-social)では投稿数が支出に与える影響を確認できます。
:::

## プラットフォーム効果

最後に、Winkは規模と予約数の拡大に伴い、プラットフォーム効果の一部を皆さまと共有したいと考えています。予約数の増加は決済処理業者からのボリュームディスカウントの機会をもたらします。カード決済手数料は実費転嫁のため、交渉による節約はそのままホテルに還元されます。
