Winkにはサブスクリプション、席数制限、初期設定費用はありません。プラットフォームの大部分は無料で、支払うのは以下の2つだけです。

1. **予約ごとのプラットフォーム手数料とカード決済手数料（実費）** — 予約が成立した場合のみ発生します。
2. **従量課金制の使用料** — 実行するたびにコストがかかる一部のプレミアム機能に対して、無料の月間利用枠を超えた分のみ課金されます。

## 無料の内容

以下は永続的に無料で、利用枠や計測もありません。

- **予約エンジン** — ご自身のサイト、WinkLinksページ、または埋め込み先のどこでも利用可能です。
- **物件管理** — コンテンツ、写真、料金、料金プラン、空室状況、プロモーション、ポリシー。
- **アフィリエイトツール** — 共有可能なリンク、キュレーションリスト、グリッド、地図、カード、埋め込みウィジェット。
- **旅行代理店ツール** — 検索、特別料金、顧客代理予約。
- **WinkLinks** — 独自のURLを取得し、ページを作成して何度でも公開可能。
- **手動のソーシャル投稿** — ご自身で作成した投稿は、接続されたネットワーク上で無料。
- **分析、リーダーボード、クレーム、設定**およびアカウント管理。
- **ConsumerおよびBooking Engine API**、およびルックアップ・オートコンプリートのエンドポイント。

## 予約

Winkは2つのモデルをサポートしています：Winkがホテルの代わりに支払いを受け取るモデルと、ライセンスを持つ旅行代理店が加盟店として機能するモデルです。

### モデル1 — Winkがホテルの代わりに支払いを受け取る

Winkはホテルの限定的な支払い代行者としてゲストの支払いを受け取ります。ホテルが加盟店であり、ゲストのカード明細にはホテル名が表示されます。
このモデルは全予約の95%に適用されます。

#### 内訳

:::note[プラットフォーム手数料]
Winkは予約ごとに1.5%のプラットフォーム手数料を請求します。これはプラットフォームの維持費用をカバーし、上記の無料サービスを提供可能にしています。キャンセルされた予約には課金されません。
:::

:::note[カード決済手数料]
ゲストの支払いを受け取るための決済手数料は実費でホテルに転嫁され、マージンはありません。手数料はゲストのカードや支払い方法によって異なり、各予約の会計セクションに正確な金額が表示されます。予約がキャンセルまたは返金された場合でも、決済業者が保持する手数料は請求されます。手数料が発生しない場合は、当社も請求しません。
:::

:::note[資金送金手数料]
資金をアカウントに送金する際には手数料がかかります。これは選択した送金方法によります。現在サポートしているのは：

- **銀行振込** — 送金元の国、送金先の国、通貨換算の有無によって費用が異なります。送金手数料および換算コストは受取人が実費で負担します。アカウントに利用可能な資金がある場合に使える見積もり計算機を用意しています。

他の送金方法をご希望の場合はメールでご連絡ください。
:::

### モデル2 — 旅行代理店が加盟店となる場合

このモデルは、地域の旅行代理店ライセンスを持ち、加盟店としての責任を負いたい旅行代理店のみ利用可能です。登録済みの旅行代理店の中には、支払いの取り扱いやホテルへの資金送金を自ら行いたいという希望を持つところがあります。このモデルでは、代理店が資金の責任を負い、必要なライセンスを保有しています。

#### 内訳

:::note[プラットフォーム手数料]
Winkは予約ごとに1.5%のプラットフォーム手数料を請求します。これはプラットフォームの維持費用をカバーし、上記の無料サービスを提供可能にしています。
:::

このモデルを利用する場合、旅行代理店はWinkのプラットフォーム手数料のみを支払い、Winkは旅行代理店に対して月次で請求書を発行します。

## 使用料（従量課金制）

一部の機能は実行するたびにコストがかかります — 生成型AI、サードパーティのソーシャルAPI、大規模なリアルタイム価格提供など。これらを月額プランにまとめるのではなく、無料の月間利用枠を超えた分だけ支払う仕組みです。

| 機能 | 月間無料枠 | その後 | 課金単位 |
| -- | -- | -- | -- |
| ソーシャル投稿 — 画像 | 1 | $1.50 | 1件の公開投稿 |
| ソーシャル投稿 — AI生成画像 | 0 | $2.50 | 1件の公開投稿 |
| ソーシャル投稿 — AI強化動画 | 0 | $4.00 | 1件の公開投稿 |
| ソーシャル投稿 — AI生成動画 | 0 | $14.00 | 1件の公開投稿 |
| コメントやDMへのAI返信 | 5 | $0.05 | 1件の返信 |
| チャットボット回答 | 5 | $0.05 | 1件の回答 |
| パートナーAPI | 10,000 | $0.0001 | 1ホテル・1泊 |

価格はUSDです。無料枠は**アカウント単位**で付与され、ユーザー単位ではありません。毎月1日（UTC）にリセットされます。

### 投稿の価格設定

投稿は中身によって価格が決まります。静止画は安価ですが、動画は高価です。AI生成メディアは、ご自身で用意した写真よりもコストがかかります。

- **無料枠は標準の画像投稿のみをカバーします。** アカウントごとに月1件無料です。動画投稿やAI生成メディアは最初の投稿から課金対象で、無料枠はありません。動画投稿を行う物件は初月から料金が発生することを想定してください。
- **動画が優先されます。** 投稿に動画が含まれる場合、その投稿全体が動画料金で課金されます。画像と動画が混在する投稿は動画投稿とみなされます。
- **AI生成かどうかで料金が変わります。** ご自身で提供した写真や動画、またはWinkのコンテンツライブラリのメディアは標準料金で課金されます。Winkが生成したメディアはAI料金で課金されます。

### 計測対象と非対象

- **生成された投稿が第三者ネットワーク（Facebook、Instagramなど）に公開された場合のみ課金対象です。** ご自身で作成した投稿はどこに公開しても無料です。
- **WinkLinksへの公開は常に無料**です。生成投稿であっても無料です。
- **課金は公開時に発生し、試行回数ではありません。** 下書きを何度も再生成しても料金は増えません。実際に公開した投稿1件分の料金のみです。ただし、再生成の回数には制限があり、画像は約10回、動画は約3回まで可能です。作業中に残り回数が表示されます。
- パートナーAPIでは、**ホテル・泊数単位**で課金されます。1泊の宿泊料金が1ホテル・1泊です。例えば、20軒のホテルを3泊検索すると、1回のリクエストで60ホテル・泊となります。ルックアップやオートコンプリートのエンドポイントは無料で計測されません。

### 利用開始方法

従量課金制はデフォルトでオフです。誰でも無料枠は利用可能です。

無料枠を超えて利用するには、**アカウントのオーナー**が従量課金制を有効にし、どのアカウントを計測対象にするか選択します。選択したアカウントの利用状況は**1つの月次請求書**にまとめられ、カードで自動決済するか、ご自身で支払う請求書を受け取ることができます。

有効化後は利用状況が計測されますが、**利用制限はありません**。支払い限度額に達して利用が止まることはありません。

:::note[有効化しない場合]
何も壊れず、料金も発生しません。その月は無料枠で止まり、生成投稿は公開されず、パートナーAPIの呼び出しは無料枠がリセットされるまで`429`エラーが返されます。
:::

### 請求状況

| 状態 | 意味 |
| -- | -- |
| 良好 | すべて正常に動作しています。 |
| 支払い遅延 | 支払いが失敗し再試行中です。この期間中も機能は利用可能です。 |
| 停止中 | 請求書が未払いのまま期限を過ぎました。課金対象の操作は停止されますが、無料機能は通常通り利用可能です。 |

:::tip[リアルタイム価格]
単価や無料枠は常にPortalに表示され、請求システムから直接取得されます。契約前に確認可能です。[Billing](/ja/portal/plan)で従量課金制を有効化し、アカウントを選択、月間利用状況や請求書を確認できます。[Social](/ja/portal/social/what-is-social)では投稿数が費用に与える影響を説明しています。
:::

## プラットフォーム効果

最後に、Winkは規模と予約数の拡大に伴い、プラットフォーム効果を皆さまと共有したいと考えています。予約数が増えることで決済代行業者からのボリュームディスカウントの機会が増えます。カード決済手数料は実費転嫁のため、交渉による節約分はそのままホテルに還元されます。
