Winkにはサブスクリプション、席数制限、初期設定費用はありません。プラットフォームの大部分は無料で、支払うのは以下の2つだけです。

1. **予約ごとの小さな割合の手数料** — 実際に収益が発生したときのみ。
2. **従量課金の使用料** — 実行するたびにコストがかかる一部のプレミアム機能で、各機能には無料の月間利用枠があります。

## 無料の内容

以下は永続的に無料で、利用枠や計測もありません。

- **予約エンジン** — ご自身のサイト、WinkLinksページ、または埋め込み先のどこでも利用可能。
- **物件管理** — コンテンツ、写真、料金、料金プラン、空室状況、プロモーション、ポリシー。
- **アフィリエイトツール** — 共有可能なリンク、キュレーションリスト、グリッド、地図、カード、埋め込みウィジェット。
- **旅行代理店ツール** — 検索、特別料金、クライアント代理予約。
- **WinkLinks** — 独自のバニティURLを取得し、ページを作成して何度でも公開可能。
- **手動のソーシャル投稿** — ご自身で作成した投稿は、接続された任意のネットワークで無料。
- **分析、リーダーボード、クレーム、設定**およびアカウント管理。
- **コンシューマーおよび予約エンジンAPI**、およびルックアップ・オートコンプリートのエンドポイント。

## 予約

Winkはマーチャントモデルとエージェントモデルの両方をサポートしています。

### モデル1

予約時にWinkがマーチャント・オブ・レコードとなります。Winkが資金を管理し、旅行代理店運営に必要なすべてのライセンスを保有しています。
このモデルは全予約の95%に適用されます。

Winkはプラットフォーム維持のために`予約ごとに5.5%`の手数料を請求します。
その大部分は決済ゲートウェイ（Visa、MasterCardなど）に支払われます。平均的な予約の取得コストは`2.95%`で、時には`3.6%`に達することもあります。部分返金は決済ゲートウェイに新たなチャージとみなされ、さらにコストがかかります。
Winkを使う前に割引交渉に時間をかけるよりも、今ここで価格を完全に透明にすることで皆様の時間を節約したいと考えています。私たちの価格モデルは非常に公正であり、私たちも生活のために収益が必要です。

#### 内訳

:::note[処理手数料]
Winkは予約ごとに1.5%の処理手数料を請求します。これはプラットフォームの維持費用であり、上記の無料サービスを提供できる理由です。
:::

:::note[決済手数料]
TripPayは予約ごとに4.0%の決済手数料を請求します。これは旅行者からの支払いを取得するための費用です。
:::

:::note[資金送金手数料]
資金をあなたの口座に送金する際に手数料が発生します。これは選択した送金方法によって異なります。現在サポートしているのは：

- **銀行振込** あなたの所在地と送金元の国によって費用が異なります。口座に利用可能な資金がある場合に使える見積もり計算機を用意しています。

他の支払い方法のサポートをご希望の場合はメールでご連絡ください。
:::

### モデル2

このモデルは、地域で旅行代理店のライセンスを保有し、マーチャント・オブ・レコードとなることを希望する旅行代理店のみ利用可能です。登録済みの旅行代理店の中には、支払い処理とホテルへの資金送金を自ら行いたいという希望を持つところがあります。このモデルでは、彼らが資金の管理責任を負い、必要なライセンスを保有しています。

#### 内訳

:::note[処理手数料]
Winkは予約ごとに1.5%の処理手数料を請求します。これはプラットフォームの維持費用であり、上記の無料サービスを提供できる理由です。
:::

このモデルを利用する場合、旅行代理店はWinkの処理手数料のみを支払い、Winkは旅行代理店に対して月次で請求書を発行します。

## 使用料（従量課金）

一部の機能は実行するたびにコストがかかります — 生成型AI、サードパーティのソーシャルAPI、大規模なライブ価格提供など。これらを使わないかもしれない月額プランにまとめる代わりに、実際に使った分だけ支払い、無料の月間利用枠を超えた場合にのみ課金されます。

| 機能 | 月間無料枠 | その後 | 課金単位 |
| -- | -- | -- | -- |
| ソーシャル投稿 — 画像 | 1 | $1.50 | 1件の公開投稿 |
| ソーシャル投稿 — AI生成画像 | 0 | $2.50 | 1件の公開投稿 |
| ソーシャル投稿 — AI強化動画 | 0 | $4.00 | 1件の公開投稿 |
| ソーシャル投稿 — AI生成動画 | 0 | $14.00 | 1件の公開投稿 |
| コメントやDMへのAI返信 | 5 | $0.05 | 1件の返信 |
| チャットボット回答 | 5 | $0.05 | 1件の回答 |
| パートナーAPI | 10,000 | $0.0001 | 1ホテル・1泊 |

価格はUSDです。無料枠は**アカウント単位**で付与され、ユーザー単位ではなく、毎月1日（UTC）にリセットされます。

### 投稿の価格設定方法

投稿の価格は中身によって決まります。なぜなら、それが制作コストだからです。静止画像は安価ですが、動画は高価です。AIで生成したものは、ご自身で用意した写真よりもかなりコストがかかります。

- **無料枠は標準の画像投稿のみをカバーします。** アカウントごとに月1件の無料画像投稿が含まれます。動画投稿やAI生成メディアは最初の投稿から課金対象であり、動画投稿を行う物件は初月から料金が発生することを想定してください。
- **動画が優先されます。** 投稿に動画が含まれる場合、その投稿全体が動画料金で課金されます。画像と動画が混在する投稿は動画投稿とみなされます。
- **AI生成かどうかで料金が変わります。** ご自身で提供した写真や動画、またはWinkのコンテンツライブラリのメディアは標準料金で課金されます。Winkが生成したメディアはAI料金で課金されます。

### 計測されるものとされないもの

- **生成された投稿が第三者ネットワーク（Facebook、Instagramなど）に公開された場合のみ課金対象です。** ご自身で作成した投稿はどこに公開しても無料です。
- **WinkLinksへの公開は常に無料**です。生成投稿であっても無料です。
- **課金は公開時に発生し、試行回数ごとではありません。** 下書きを何度も再生成しても料金は増えません。実際に公開した投稿1件につき1回の課金です。ただし、再生成の回数には制限があり、画像は約10回、動画は3回まで可能です。作業中に残り回数が表示されます。
- パートナーAPIでは、**ホテル・泊数単位**で課金されます。1ホテルの1泊分の価格です。1回の検索で20ホテルの3泊分が返された場合、60ホテル泊分の課金となります。ルックアップやオートコンプリートのエンドポイントは無料で計測されません。

### 利用開始方法

従量課金はデフォルトでオフです。誰でも無料枠は利用可能です。

無料枠を超えて利用するには、**アカウントのオーナーが従量課金を有効化し、どのアカウントを計測対象にするか選択します。** 有効化したすべてのアカウントの利用状況は**1つの月次請求書**にまとめられ、カードで自動決済するか、ご自身で支払う請求書として受け取ることができます。

有効化後は利用状況が計測されますが、**決して制限されません。** Winkでの支出に対してレート制限に達することはありません。

:::note[有効化しない場合]
何も壊れず、料金も発生しません。その月は無料枠で止まり、生成投稿は公開されず、パートナーAPIの呼び出しは無料枠リセットまで`429`エラーが返されます。
:::

### 請求状況

| 状態 | 意味 |
| -- | -- |
| 良好 | すべて正常に動作しています。 |
| 支払い遅延 | 支払いが失敗し再試行中です。この期間中も機能は利用可能です。 |
| 停止中 | 請求書が未払いのまま期限を迎えました。課金対象の操作は停止されますが、無料機能は通常通り利用可能です。 |

:::tip[リアルタイム価格]
単価と無料枠は常にPortalに表示され、請求システムから直接取得されるため、契約前に確認できます。[Billing](/ja/portal/plan)で従量課金を有効化し、アカウントを選択し、月間利用状況や請求書を追跡できます。[Social](/ja/portal/social/what-is-social)では投稿数が支出に与える影響を確認できます。
:::

## プラットフォーム効果

最後に、規模と予約数が増加するにつれて、プラットフォーム効果の一部を皆様と共有したいと考えています。予約数の増加は決済ゲートウェイからのボリュームディスカウントの機会をもたらし、これによりすべてのユーザーの処理手数料を引き下げることが可能になります。
