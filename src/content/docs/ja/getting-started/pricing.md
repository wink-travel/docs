Winkにはサブスクリプション、席数制限、初期設定費用はありません。プラットフォームの大部分は無料で、支払うのは以下の2つだけです。

1. **予約ごとの小さな割合の手数料** — 実際に収益が発生したときのみ。
2. **使った分だけの従量課金** — 実行するたびにコストがかかる一部のプレミアム機能に対して、無料の月間利用枠付き。

## 無料の内容

以下は永続的に無料で、利用枠や計測もありません。

- **予約エンジン** — ご自身のサイト、WinkLinksページ、または埋め込み先のどこでも利用可能。
- **物件管理** — コンテンツ、写真、料金、料金プラン、空室状況、プロモーション、ポリシー。
- **アフィリエイトツール** — 共有可能なリンク、キュレーションリスト、グリッド、地図、カード、埋め込みウィジェット。
- **旅行代理店ツール** — 検索、特別料金、顧客代理予約。
- **WinkLinks** — 独自のURLを取得し、ページを作成して何度でも公開可能。
- **手動のソーシャル投稿** — ご自身で作成した投稿は、接続されたネットワーク上で無料。
- **分析、リーダーボード、クレーム、設定**、アカウント管理。
- **ConsumerおよびBooking Engine API**、およびルックアップ・オートコンプリートエンドポイント。

## 予約

Winkはマーチャントモデルとエージェントモデルの両方をサポートしています。

### モデル1

予約時点でWinkがマーチャントオブレコードとなります。Winkが資金を管理し、旅行代理店運営に必要なすべてのライセンスを保有しています。
このモデルは全予約の95%に適用されます。

Winkはプラットフォーム維持のために`予約ごとに5.5%`の手数料を請求します。
その大部分は決済ゲートウェイ（Visa、MasterCardなど）に支払われます。平均的な予約の取得コストは`2.95%`で、時には`3.6%`に達することもあります。部分返金は決済ゲートウェイに新たなチャージと見なされ、さらにコストがかかります。
Winkを使う前に割引交渉に時間をかけるよりも、価格を透明に示すことで皆様の時間を節約したいと考えています。私たちの価格モデルは非常に公正であり、私たちも生活のために収益が必要です。

#### 内訳

:::note[処理手数料]
Winkは予約ごとに1.5%の処理手数料を請求します。これはプラットフォーム維持費用であり、上記の無料機能を提供できる理由です。
:::

:::note[決済手数料]
TripPayは予約ごとに4.0%の決済手数料を請求します。これは旅行者からの支払い取得にかかる費用です。
:::

:::note[資金送金手数料]
資金をお客様の口座に送金する際に手数料が発生します。これは選択した送金方法によります。現在サポートしているのは：

- **銀行振込** お客様の所在地と送金元によって費用が異なります。口座に利用可能な資金がある場合に使える見積もり計算機を用意しています。

他の支払い方法のサポートをご希望の場合はメールでご連絡ください。
:::

### モデル2

このモデルは、地域の旅行代理店ライセンスを保有し、マーチャントオブレコードとなることを希望する旅行代理店のみ利用可能です。登録済みの旅行代理店の中には、支払い処理とホテルへの資金送金を自ら行いたいという希望があります。このモデルでは、資金管理と必要なライセンスは旅行代理店が負います。

#### 内訳

:::note[処理手数料]
Winkは予約ごとに1.5%の処理手数料を請求します。これはプラットフォーム維持費用であり、上記の無料機能を提供できる理由です。
:::

このモデルでは、旅行代理店はWinkの処理手数料のみを支払い、Winkは旅行代理店に月次で請求書を発行します。

## 利用（従量課金）

一部の機能は実行するたびにコストがかかります — 生成AI、サードパーティのソーシャルAPI、大規模なライブ価格提供など。これらを使わないかもしれない月額プランにまとめる代わりに、無料の月間利用枠を超えた分だけ支払います。

| 機能 | 月間無料枠 | その後 | 課金単位 |
| -- | -- | -- | -- |
| ソーシャル投稿 — 画像 | 1 | $1.50 | 1投稿公開ごと |
| ソーシャル投稿 — AI生成画像 | 0 | $2.50 | 1投稿公開ごと |
| ソーシャル投稿 — 動画 | 0 | $4.00 | 1投稿公開ごと |
| ソーシャル投稿 — AI生成動画 | 0 | $14.00 | 1投稿公開ごと |
| コメントやDMへのAI返信 | 5 | $0.05 | 1返信ごと |
| チャットボット回答 | 5 | $0.05 | 1回答ごと |
| パートナーAPI | 10,000 | $0.0001 | 1ホテル・1泊ごと |
| パートナーメディアAPI | 1,000 | $0.0005 | 1ホテルのメディアごと |

価格はUSDです。無料枠は**アカウント単位**で付与され、ユーザー単位ではなく、毎月1日（UTC）にリセットされます。

### 投稿の価格設定方法

投稿は中身の種類によって価格が決まります。静止画は安価ですが、動画は高価です。AI生成メディアは、ご自身で用意した写真よりもかなりコストがかかります。

- **無料枠は標準画像投稿のみをカバーします。** アカウントごとに月1投稿が無料です。動画投稿やAI生成メディアは最初の投稿から課金対象で、動画投稿を行う物件は初月から料金が発生します。
- **動画が優先されます。** 投稿に動画が含まれる場合、その投稿全体が動画料金で課金されます。画像と動画が混在する投稿は動画投稿扱いです。
- **AI生成かどうかで料金が変わります。** ご自身で提供した写真や動画、またはWinkのコンテンツライブラリのメディアは標準料金です。Winkが生成したメディアはAI料金が適用されます。

### 計測対象と非対象

- **生成された投稿が第三者ネットワーク（Facebook、Instagramなど）に公開された場合のみ課金対象です。** ご自身で作成した投稿はどこに公開しても無料です。
- **WinkLinksへの公開は常に無料**です。生成投稿でも同様です。
- **課金は公開時に発生し、試行回数ではありません。** 下書きを何度も再生成しても料金は増えません。実際に公開した投稿1件分だけ支払います。ただし、再生成は画像で約10回、動画で約3回まで可能で、これは制作コストに基づいています。残り回数は作業中に表示されます。
- パートナーAPIでは、**ホテル・泊数単位**が課金単位です。1回のAPI呼び出しで20軒のホテルを3泊分検索すると、60ホテル泊分の課金となります。ルックアップやオートコンプリートエンドポイントは無料で計測されません。
- **パートナーメディアAPI**では、1ホテルのメディア一式が1単位です。50軒のホテルを一括リクエストすると50単位課金されます。メディアが返されなかったホテル分は課金されません。

### 例：OTAが90日分の価格をキャッシュする場合

OTA、メタサーチサイト、ツアーオペレーターが、**1,000軒のホテル**の90日先までの価格を取得し、各ホテルが**4つのマスターレート**を公開しているとします。

**全てを一度に更新すると90,000ホテル泊分で、料金は$9.00です。**

1,000軒 × 90日です。4つのマスターレートは追加料金なしです。1回のリクエストでその期間の全料金プランが返るため、料金プラン数は課金に影響しません。リクエストの分割も課金に影響しません。期間リクエストは最大30日なので、1ホテルあたり3回のリクエストを行っても、3 × 30日分の料金は90日分の1回のリクエストと同じです。課金はリクエストした価格情報に対して発生し、経路の呼び出し回数ではありません。

つまり、月額料金は更新頻度によって決まります。

| 更新頻度 | ホテル泊数/月 | 無料枠超過分 | 月額料金 |
| -- | -- | -- | -- |
| 月1回 | 90,000 | 80,000 | **$8.00** |
| 週1回 | 360,000 | 350,000 | **$35.00** |
| 毎日 | 2,700,000 | 2,690,000 | **$269.00** |
| 1日2回 | 5,400,000 | 5,390,000 | **$539.00** |

1,000軒のホテルを毎日更新すると1日3,000リクエストで、1日あたり約$9.00です。無料枠の10,000ホテル泊分は、90日間で約110軒のホテルを価格付けできるか、統合の構築・テストに十分な量です。

#### 料金に影響する要素

- **料金プランを1つずつリクエストすること。** 期間リクエストは全料金プランの最安値を一度に返します。1つずつリクエストすると4倍のリクエスト数と料金になります。
- **追加の宿泊人数、通貨、言語。** 1名分の料金と2名分の料金は別のリクエストとして課金されます。表示通貨や言語の追加も同様です。
- **不要な更新頻度。** 90日すべてを同じ頻度で更新する必要はありません。直近14日を毎日更新し、15日目以降は週1回にすると、同じ1,000軒で月額**$71.40**に抑えられます。価格変動が多い直近日程だけを頻繁に更新するのが効率的です。

### 利用開始方法

従量課金はデフォルトでオフです。誰でも無料枠は自動で利用できます。

無料枠を超えて利用するには、**アカウントのオーナー**が従量課金を有効にし、どのアカウントを計測対象にするか選択します。選択したアカウントの利用状況は**1つの月次請求書**にまとめられ、カード自動決済か請求書払いを選べます。

有効化後は利用状況が計測されますが、**利用制限はありません**。料金を支払う限り、利用制限で止まることはありません。

:::note[有効化しない場合]
何も壊れず、料金も発生しません。その月は無料枠で止まり、生成投稿は公開されず、パートナーAPIは無料枠を超えると`429`エラーを返します。
:::

### 請求状況

| 状態 | 意味 |
| -- | -- |
| 良好 | すべて正常に動作しています。 |
| 支払い遅延 | 支払いが失敗し再試行中です。この期間中も機能は利用可能です。 |
| 停止中 | 請求書が未払いで期限切れです。課金対象の操作は停止されますが、無料機能は通常通り利用可能です。 |

:::tip[リアルタイム価格]
単価や無料枠は常にPortalで最新の請求システムから表示されます。契約前に確認可能です。[Billing](/ja/account/subscription)で従量課金を有効化し、アカウントを選択、月間利用状況や請求書を確認できます。[Social](/ja/portal/social/what-is-social)では投稿数が費用に与える影響を確認できます。
:::

## プラットフォーム効果

最後に、規模と予約数が増えるにつれて、プラットフォーム効果を皆様と共有したいと考えています。予約数の増加により決済ゲートウェイからのボリュームディスカウントが可能となり、全ユーザーの処理手数料を引き下げることができます。

今すぐWinkに参加して、ホスピタリティ業界で新しく収益性の高いビジネスを始めましょう！
