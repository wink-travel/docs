請求ページでは、従量課金をオンにし、どのアカウントに適用するかを決め、支出を監視できます。

開始するためにここに来る必要はありません。すべてのアカウントは、従量課金対象機能の無料月間利用枠が自動的に付与されます。このページは、その利用枠を超える場合のみ使用します。無料の内容、従量課金の対象、料金については[料金](/ja/getting-started/pricing)をご覧ください。

## 従量課金の有効化

従量課金をオンにして、請求方法を選択します：

- **カード** — 請求書発行時に保存されたカードから自動的に引き落とします。
- **請求書** — 請求書を送付し、ご自身でお支払いいただきます。

いつでもこの2つの間で切り替え可能です。

:::note
アカウントの**所有者**のみが従量課金を有効にできます。他人のアカウントの管理権限があっても十分ではありません。請求書は所有者に送られるため、他人があなたのカードに請求をかけることはできません。
:::

## アカウントの選択

複数のアカウントを所有している場合は、それぞれ個別に従量課金の対象を選べます。オフにしたアカウントは毎月無料利用枠で止まります。

有効にしたすべてのアカウントの利用は**月ごとに1つの請求書**にまとめられるため、物件ごとに請求書が分かれることはありません。

## 支払い方法

カードを追加すると、決済プロバイダーに安全に保存されます。ブランド名、下4桁、有効期限のみ表示され、Winkはカード番号の全桁を見たり保存したりしません。銀行がカードを更新した場合も自動で情報が更新されます。

## 利用状況

今月これまでの利用状況を、機能別・アカウント別に無料利用枠と並べて確認できます。支出を予測可能にしたい場合は、この数字を注視してください。特にSocialでは、月間投稿数が実質的な予算となります。

利用枠は毎月1日にリセットされます。

## 請求書

請求履歴には、各月の番号、請求期間、金額、通貨、ステータスが一覧表示され、オンラインで請求書を閲覧したりPDFでダウンロードしたりできます。

## 請求状況

| ステータス | 意味 |
| -- | -- |
| 良好 | すべて正常に動作しています。 |
| 支払い遅延 | 支払いが失敗し再試行中です。再試行中も機能は利用可能です。 |
| 停止中 | 請求書の未払いが続きました。従量課金機能は支払い完了まで利用できませんが、無料機能は通常通り利用可能です。 |
