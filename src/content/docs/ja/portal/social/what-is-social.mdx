# 概要

ソーシャルメディアはホテルにとって最も強力なマーケティングツールの一つですが、多くの施設は高品質で魅力的なコンテンツを継続的に投稿し、成果につなげるための時間、専門知識、リソースを持っていません。
私たちは、AI搭載の自動化を活用し、ホテル側の手間をかけずに動的でリアルタイムなコンテンツを生成・投稿することで、この問題を解決します。

- AIによるホテルごとの提供内容に合わせたソーシャルメディアコンテンツ。
- リアルタイムの在庫、プロモーション、ユーザー投稿コンテンツを活用。
- 完全な承認プロセスでホテルがブランドコントロールを維持。
- 手動作業ゼロで直接予約を最大化。

この機能は、ホテルが旅行者と関わる方法を変革し、一貫性があり最適化された収益重視のソーシャルメディアプレゼンスを大規模に維持するのを支援します。

一般的なAIソーシャルメディアツールとは異なり、当システムはホテル専用に設計されており、リアルタイムの在庫、料金、ホテルコンテンツと直接連携しています。

## 仕組み

あらゆる規模の施設向けに開発された高度なコンテンツ管理プラットフォームにAIを組み込み、ホテルが存在するあらゆる場所にコンテンツを配信できるスケジューリング機能で包み込むのは自然な進化でした。

ソーシャルメディア自動化エンジンは、AIとWinkの無料機能（共有可能なリンク、リアルタイム在庫アクセス、ホテル提供コンテンツなど）を活用し、直接予約に最適化された投稿を作成します。

1. AIがWinkのCDNからコンテンツをスキャン。
2. AIがソーシャルメディア投稿を作成。
3. コンテンツはホテルに承認のため送信。
4. 投稿は希望言語に翻訳。
5. 投稿は選択されたソーシャルネットワークにスケジュール配信。

### コンテンツソース

AIは以下を使って動的にソーシャルメディア投稿を生成します：

- ホテルエクストラネットデータ：客室説明、画像、アメニティ、料金。
- リアルタイム在庫：空室状況、期間限定プロモーション、フラッシュセール。
- ユーザーアップロードコンテンツ：カスタム画像、動画、テキスト。
- 公開されているホテルコンテンツ。

### AI生成投稿

投稿は以下の手順で生成されます：

1. 利用可能なコンテンツに対して感情分析を実施。
2. 既存の画像を活用。
3. 事前定義されたペルソナに基づき、キャプション、テキスト、ハッシュタグを強化。
4. リアルタイム価格オーバーレイ付きの画像プレビューを作成。

#### 投稿タイプ

生成された投稿は以下の3タイプのいずれかに分類されます：

- **トランザクショナル** — コンバージョン重視。事実、価格、次のステップで予約を促進。
- **アウェアネス** — ブランド構築。施設を紹介し認知度を向上。
- **センチメント** — 感情に訴える。ポジティブな印象を与える。

#### 例

- 「早期予約で節約！💰」（トランザクショナル）
- 「釣り🐟旅行も一緒に予約しよう！」（トランザクショナル）
- 「10人中9人が💕このホテルを支持」（センチメント）
- 「久しぶりに最高の場所。💥 --Dr. Shu」（センチメント）
- 「ディズニーランドからわずか200m💦」（アウェアネス）
- 「空港まで10分🛫」（アウェアネス）

### 承認プロセス

ホテルは常にコントロールを保持しつつ、ハンズフリーの自動化の恩恵を受けられます。すべてを自動化する「設定して忘れる」ポリシーを選択することも可能です。

ただし、ソーシャルチャネルの完全管理を任せる前に、翌月に配信予定の投稿ごとに通知を受けて承認することもできます。

以下が可能です：

- 承認：投稿の翻訳言語と配信するソーシャルネットワークを選択。
- 修正：AIに代替バージョンを生成させ、手動で変更。
- 拒否：投稿を破棄。

### スケジューラー

投稿のタイムゾーンと言語を選択でき、投稿はリーチとエンゲージメントが最大となるピークの曜日・時間にスケジュールされます。

### 分析

- すべてのチャネルでクリック数、コンバージョン、エンゲージメントをリアルタイムで追跡。
- 高パフォーマンス投稿はリサイクル・再利用され、リーチを拡大。
- AIは過去のパフォーマンスから学習し、将来の投稿を最適化。

## 自動DM＆返信

自動DM＆返信機能は、ホテルのソーシャルメディア上のコメントやダイレクトメッセージを効率的に管理します。AIを使い、施設内設備や近隣観光に関する問い合わせに迅速かつ正確に対応し、トラッキング可能な予約リンクを提供。会話を予約に変換しやすくします。

### 例

1. ユーザーが投稿に「美しい！！！ここにいたい😊」と返信。
2. 自動返信：「いいですよね！！4月の夕日は本当に素晴らしいです。ちなみに早期予約で30%オフになります。こちらをチェック https://trvl.as/AB76g」

## AIコンシェルジュ

AIコンシェルジュは自動返信＆DMと同じ技術を使い、ホテルのウェブサイト向けにカスタムチャットボットを提供します。リアルタイムで潜在顧客と対話し、質問に答え、パーソナライズされたおすすめを提供し、予約完了を支援。ウェブサイト訪問者をゲストに変えるのを簡単にします。

### 例

👤「こんにちは…質問があります。」

🤖「こんにちは！どうされましたか？」

👤「訪問に最適な時期はいつですか？」

🤖「良い質問です。12月から1月が最も混み合うピークシーズンです。2月に来られるなら、天気は同じですが料金が安く人も少ないです。」

👤「2月のプロモコードはありますか？」

🤖「ありませんが、30日前予約でツインルームの割引価格からさらに15%オフになります。」

🤖「こちらが部屋の写真です [Image]」

👤「それにします！」

🤖「素晴らしい、こちらのリンクを使ってください https://trvl.as/AB76g」

🤖「他にお手伝いできることはありますか？」

## 料金

プランや階層はありません。Socialは従量課金制で、生成・公開したコンテンツに対してのみ、無料の月間枠を超えた分だけ課金されます。

| ご利用内容 | 料金 |
| -- | -- |
| 自分で投稿作成・公開 | 無料、無制限、すべての接続ネットワークで |
| WinkLinksへの公開 | 無料、無制限、生成・非生成問わず |
| AIによるコメント・DM返信 | 月5件無料、その後1件あたり$0.05 |
| チャットボット回答 | 月5件無料、その後1件あたり$0.05 |

アカウント連携、翻訳、承認ワークフロー、エンゲージメント・予約分析はすべて無料で含まれます。

FacebookとInstagramへの生成投稿は内容によって料金が異なります：

| 投稿タイプ | 月間無料枠 | 以降料金 |
| -- | -- | -- |
| 画像 | 1件 | $1.50 |
| AI生成画像 | 0件 | $2.50 |
| AI強化動画 | 0件 | $4.00 |
| AI生成動画 | 0件 | $14.00 |

無料枠の投稿は標準画像投稿に適用されます。動画やAI生成メディアは最初の投稿から課金対象です。動画を含む投稿は全体が動画料金で請求されます。

### 支出はあなたがコントロール

公開された投稿ごとに課金されるため、生成依頼数がそのまま請求額となり、選択したメディアが料金を決定します。月1〜84件の生成投稿数を自分で設定でき、デフォルトは16件です。Social設定でいつでも変更可能です。

投稿が実際に公開された場合のみ課金されるため、ドラフトの修正は何度でも無料です。各投稿には再生成の試行回数が十分に用意されており（画像投稿は約10回、動画は3回）、残り回数も表示されます。

:::tip[プロのコツ]
少量から始めて徐々に増やす

関係構築と信頼は時間がかかります。月間投稿数を少なめに設定し、投稿ごとに手動承認を行いましょう。信頼が深まったら投稿数を増やし、1ヶ月間自動承認を試してみてください。
:::

詳細は[料金](/ja/getting-started/pricing)をご覧ください。従量課金の有効化や月間利用状況の確認は[請求](/ja/portal/plan)から行えます。

### Wink Agency

[Wink Agency](/ja/guides/hoteliers/creator-agency)は、施設とインフルエンサーやアフィリエイトのネットワークを結びつけ、彼らのオーディエンスに販売を支援します。プランの制限はなくなりましたので、お問い合わせいただければ設定いたします。
