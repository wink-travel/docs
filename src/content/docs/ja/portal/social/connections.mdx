すでにリンク管理ツールであるWinkLinksと連携しています。`Connect a social network`をクリックして、さらに多くのソーシャルネットワークと連携してください。
このプロセスでは、ソーシャルネットワークにリダイレクトされ、`Wink Social`アプリが代わりにコンテンツを投稿することを承認する必要があります。

連携が完了すると、次のスケジュールされた月に向けてそのネットワーク用のコンテンツの生成を開始します。

:::note
WinkLinksへの投稿は常に無料です。FacebookおよびInstagramへの生成された投稿には無料の月間割当があり、それを超えると投稿ごとに課金されます — 詳しくは[料金](/ja/getting-started/pricing)をご覧ください。
:::

## 対応プラットフォーム

| プラットフォーム | 説明 | 要件 |
| -- | -- | -- |
| **WinkLinks** | 高度なリンク管理ツールへの自動投稿 | 常に無料、割当なし |
| **Facebook** | 投稿の自動化、コメントやDMへの返信 | Facebookビジネスページが必要 |
| **Instagram** | 投稿の自動化、コメントやDMへの返信 | FacebookアカウントにリンクされたInstagramビジネスアカウントが必要 |

各連携は現在のステータスを表示します：**アクティブ**、**切断済み**、または**停止中**。

:::note
各ソーシャルネットワークに最適化されたコンテンツを作成し、公開します。
:::
