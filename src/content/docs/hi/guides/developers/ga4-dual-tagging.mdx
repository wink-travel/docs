अपने Google Analytics 4 प्रॉपर्टी को Wink से कनेक्ट करके, आपकी बुकिंग इवेंट्स — रूम व्यू से लेकर पूरी हुई बुकिंग तक — अपने GA4 डैशबोर्ड में Wink की अपनी एनालिटिक्स के साथ स्वचालित रूप से भेजी जाती हैं। कोई कोडिंग या तकनीकी सेटअप आपकी तरफ से आवश्यक नहीं है।

<Aside type="tip">
आपको GA4 से दो चीजें चाहिए: एक **Measurement ID** और एक **Measurement Protocol API secret**। Measurement ID अतिथि के ब्राउज़र में ब्राउज़िंग फनल को संचालित करता है; API secret Wink को पूरी हुई बुकिंग्स (`purchase`) **सर्वर-साइड** रिकॉर्ड करने देता है, ताकि भुगतान प्रदाता के रीडायरेक्ट के दौरान बिक्री कभी न खोए।
</Aside>

---

## यह कैसे काम करता है

```
आप Wink पोर्टल में अपना Measurement ID (G-XXXXXXXXXX) और API secret दर्ज करते हैं
       ↓
ब्राउज़िंग इवेंट्स (व्यू, कार्ट, चेकआउट) ब्राउज़र से आपके GA4 प्रॉपर्टी में स्ट्रीम होते हैं
पूरी हुई बुकिंग्स (purchase) सर्वर-साइड भेजी जाती हैं — भुगतान रीडायरेक्ट के बाद भी सुरक्षित रहती हैं
       ↓
आप analytics.google.com में लॉग इन करके अपनी पूरी बुकिंग फनल देखते हैं
```

---

## आपको क्या करना है

<Steps>

1. **GA4 प्रॉपर्टी बनाएं**

   [analytics.google.com](https://analytics.google.com) पर जाएं: Admin → Create Property। अपनी टाइमज़ोन और मुद्रा अपने मार्केट के अनुसार सेट करें।

2. **वेब डेटा स्ट्रीम बनाएं**

   Admin → Data Streams → Add Stream → Web। URL के रूप में `wink.travel` दर्ज करें। इससे आपका **Measurement ID** (`G-XXXXXXXXXX`) बनता है। इसे कॉपी करें।

3. **Measurement Protocol API Secret बनाएं**

   उसी वेब डेटा स्ट्रीम को खोलें → नीचे स्क्रॉल करें **Measurement Protocol API secrets** → **Create**। इसे एक उपनाम दें (जैसे "Wink") और उत्पन्न **secret value** को कॉपी करें। यह secret Wink को पूरी हुई बुकिंग्स सर्वर-साइड रिकॉर्ड करने देता है, ताकि भुगतान रीडायरेक्ट के दौरान बिक्री न खोए।

4. **Wink पोर्टल में अपना Measurement ID और API Secret दर्ज करें**

   [app.wink.travel](https://app.wink.travel) में लॉग इन करें, अपना अकाउंट चुनें, और **Customizations** टैब पर जाएं। अपने Measurement ID और API secret को **GA4** फील्ड्स में पेस्ट करें और सेव करें। बस इतना ही — आपकी GA4 इंटीग्रेशन अब सक्रिय है।

   <Aside type="note">
   API secret **write-only** है: एक बार सेव करने के बाद यह फिर कभी नहीं दिखाया जाता। भविष्य में संपादन करते समय, secret फील्ड खाली छोड़ें ताकि पहले से स्टोर किया गया मान बना रहे।
   </Aside>

5. **`purchase` को Key Event के रूप में मार्क करें**

   अपने GA4 प्रॉपर्टी में वापस जाएं: Admin → Events → `purchase` खोजें → **Mark as key event** टॉगल करें। इससे पूरी हुई बुकिंग्स आपके Conversions रिपोर्ट में दिखेंगी।

6. **अपने डेटा को देखें**

   [analytics.google.com](https://analytics.google.com) में लॉग इन करें और आप अपनी बुकिंग्स, राजस्व, और अतिथि फनल देखेंगे — सभी Wink के माध्यम से स्वचालित रूप से ट्रैक किए गए।

</Steps>

<Aside type="note">
इस इंटीग्रेशन के लिए आपको अपनी वेबसाइट पर कोई ट्रैकिंग कोड इंस्टॉल करने की आवश्यकता नहीं है। Wink सब कुछ संभालता है। आपका Measurement ID वह गंतव्य है जहां आपकी बुकिंग डेटा भेजी जाती है, और आपका API secret Wink को पूरी हुई बुकिंग्स सर्वर-साइड पुष्टि करने देता है।
</Aside>

<Aside type="tip">
**GA4 और GTM को एक साथ इस्तेमाल किया जा सकता है।** यदि आप Google Tag Manager कंटेनर (जैसे Sojern कंटेनर) भी चलाते हैं, तो आप दोनों को एक साथ कॉन्फ़िगर कर सकते हैं — अब वे परस्पर विरोधी नहीं हैं। देखें [GTM Analytics Integration](/hi/guides/developers/gtm-dual-tagging)।
</Aside>

## आप क्या ट्रैक कर सकते हैं

कनेक्ट होने के बाद, आपका GA4 प्रॉपर्टी आपकी प्रॉपर्टी के लिए Enhanced E-commerce इवेंट्स का पूरा सेट प्राप्त करता है:

### डिस्कवरी

| इवेंट | इसका मतलब क्या है |
|---|---|
| `view_item_list` | अतिथि ने आपकी प्रॉपर्टी को खोज या श्रेणी सूची में देखा |
| `select_item` | अतिथि ने सूची से आपकी प्रॉपर्टी पर क्लिक किया |
| `view_item` | अतिथि ने आपके होटल विवरण पृष्ठ को देखा |

### विचार-विमर्श

| इवेंट | इसका मतलब क्या है |
|---|---|
| `view_promotion` | अतिथि ने आपकी प्रॉपर्टी के लिए प्रचार प्रस्ताव देखा |
| `select_promotion` | अतिथि ने प्रचार प्रस्ताव पर क्लिक किया |
| `add_to_wishlist` | अतिथि ने अपनी विशलिस्ट में आपकी प्रॉपर्टी को जोड़ा |

### बुकिंग फनल

| इवेंट | इसका मतलब क्या है |
|---|---|
| `add_to_cart` | अतिथि ने एक कमरा या पैकेज चुना |
| `view_cart` | अतिथि ने अपनी बुकिंग सारांश देखा |
| `remove_from_cart` | अतिथि ने एक कमरा या पैकेज हटाया |
| `begin_checkout` | अतिथि ने चेकआउट प्रक्रिया शुरू की |
| `add_payment_info` | अतिथि ने अपनी भुगतान जानकारी दर्ज की |
| `add_shipping_info` | अतिथि ने अपनी अतिथि जानकारी दर्ज की |
| `purchase` | अतिथि ने बुकिंग पूरी की |
| `refund` | बुकिंग रद्द की गई और रिफंड किया गया |

सभी इवेंट्स में संबंधित आयाम शामिल हैं जैसे राजस्व, मुद्रा, कमरे का प्रकार, और बुकिंग मूल्य — जो आपको पहली छाप से पूरी हुई बुकिंग तक अतिथि यात्रा की पूरी तस्वीर देते हैं। अतिरिक्त प्रॉपर्टी और कमरे-स्तर के आयाम जैसे `city_name`, `cancellation_policy`, `bed_type` आदि अनलॉक करने के लिए देखें [Custom Dimensions in GA4](/hi/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4)।

## क्रॉस-डोमेन ट्रैकिंग (उन्नत)

ऊपर दिया गया मानक इंटीग्रेशन Wink के भीतर होने वाली सभी गतिविधियों को ट्रैक करता है। हालांकि, यदि आप चाहते हैं कि अतिथि आपकी अपनी वेबसाइट से लेकर Wink पर बुकिंग पूरी होने तक की पूरी यात्रा ट्रैक हो — और मूल ट्रैफिक स्रोत (Google Ads, ईमेल अभियान, ऑर्गेनिक सर्च आदि) को सही ढंग से मान्यता मिले — तो प्रत्येक पक्ष पर एक अतिरिक्त कदम आवश्यक है।

<Aside type="caution">
यह अनुभाग केवल तभी लागू होता है जब आपकी अपनी वेबसाइट पर GA4 इंस्टॉल हो। यदि आप अपनी साइट पर GA4 नहीं चलाते, तो ऊपर दिया गया मानक इंटीग्रेशन ही पर्याप्त है।
</Aside>

### यह क्यों महत्वपूर्ण है

क्रॉस-डोमेन ट्रैकिंग के बिना, जो अतिथि पहले आपकी वेबसाइट पर आता है और फिर Wink पर बुकिंग करता है, वह आपके GA4 में एक **Direct** सेशन के रूप में दिखाई देगा, जिसका उनके पहले के विजिट से कोई संबंध नहीं होगा। कोई भी Google Ads क्लिक, ईमेल अभियान, या ऑर्गेनिक सर्च विजिट जो बुकिंग तक ले गया, उसे कोई क्रेडिट नहीं मिलेगा।

क्रॉस-डोमेन ट्रैकिंग कॉन्फ़िगर होने पर, आप पूरी अतिथि यात्रा देखेंगे:

```
google.com (पेड एड)
       ↓
आपकी वेबसाइट (अतिथि कमरे ब्राउज़ करता है)
       ↓
wink.travel (अतिथि कमरे का चयन करता है और बुकिंग करता है)
       ↓
purchase सही ढंग से मूल Google Ads क्लिक को श्रेय दिया गया
```

### आवश्यक कार्रवाई: आप

अपने GA4 प्रॉपर्टी को कॉन्फ़िगर करें ताकि `wink.travel` को आपकी अपनी डोमेन का हिस्सा माना जाए, न कि बाहरी रेफरल के रूप में। यह GA4 को दोनों सेशन्स को एक निरंतर अतिथि यात्रा में जोड़ने के लिए कहता है।

<Steps>
1. GA4 Admin → Data Streams → अपनी स्ट्रीम चुनें
2. टैग सेटिंग्स कॉन्फ़िगर करें → **अपने डोमेन्स कॉन्फ़िगर करें**
3. `wink.travel` को लिंक्ड डोमेन के रूप में जोड़ें
4. सेव करें
</Steps>

### आवश्यक कार्रवाई: Wink

[Wink Support](https://app.wink.travel) से संपर्क करें और अपनी वेबसाइट डोमेन (जैसे `yourhotel.com`) प्रदान करें। Wink आपकी डोमेन को Wink GA4 प्रॉपर्टी में रेफरल एक्सक्लूजन सूची में जोड़ देगा। इससे आपकी वेबसाइट को रेफरल स्रोत के रूप में रिकॉर्ड होने से रोका जाएगा, जो अन्यथा अतिथि की मूल मान्यता को अधिलेखित कर नया सेशन शुरू कर सकता है।

<Aside type="tip">
ऊपर दिया गया मानक इंटीग्रेशन अधिकांश प्रॉपर्टीज के लिए पर्याप्त है और आपको Wink पर बुकिंग और राजस्व की त्वरित दृश्यता देता है। क्रॉस-डोमेन ट्रैकिंग एक उन्नत विकल्प है जिसे आप अपने GA4 डेटा के साथ सहज होने के बाद और गहरी मान्यता अंतर्दृष्टि के लिए सेट कर सकते हैं।
</Aside>
