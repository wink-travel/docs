Wink दो ट्रांसपोर्ट प्रदान करता है। आप किसे उपयोग करते हैं यह इस बात पर निर्भर करता है कि आप किस API के साथ एकीकृत हो रहे हैं।

| | ट्रांसपोर्ट | स्कीमा | दस्तावेज़ |
| --- | --- | --- | --- |
| अधिकांश Wink APIs | HTTPS पर REST | OpenAPI 3 | साइडबार में **API** के अंतर्गत कोई भी समूह |
| Partner Integrator API | HTTP/2 पर gRPC | Protocol Buffers | [Partner](/hi/partner-api/partner/) |

<Aside type="note" title="हम अब भाषा SDKs प्रकाशित नहीं करते">
  हाथ से बनाए गए SDKs उन APIs से पीछे रह जाते थे जिन्हें वे कवर करते थे, और कभी भी उस भाषा को कवर नहीं करते थे जिसकी आपको वास्तव में आवश्यकता थी। इसके बजाय स्कीमा से क्लाइंट जनरेट करें — यह हमेशा वर्तमान होता है — या हमारे MCP सर्वर को आपके उपयोग के मामले के अनुसार एकीकरण कोड लिखने दें।
</Aside>

## REST क्लाइंट जनरेट करें

प्रत्येक API समूह एक OpenAPI 3 दस्तावेज़ प्रकाशित करता है। किसी भी OpenAPI जनरेटर को इसे इंगित करें और आपको अपनी भाषा में एक टाइप्ड क्लाइंट मिलेगा।

```bash
# किसी समूह के लिए स्पेक उसके संदर्भ पृष्ठ के पास परोसा जाता है।
curl -o wink-extranet.json https://api.wink.travel/v3/api-docs/extranet

npx @openapitools/openapi-generator-cli generate \
  -i wink-extranet.json -g typescript-fetch -o ./wink-client
```

## gRPC क्लाइंट जनरेट करें

Partner Integrator API gRPC है। आप `.proto` स्कीमा से क्लाइंट जनरेट करते हैं, जिसे Wink दो तरीकों से प्रकाशित करता है:

- **सर्वर रिफ्लेक्शन** — सर्वर स्वयं का वर्णन करता है, इसलिए `grpcurl`, Postman और Insomnia जैसे टूल्स रनटाइम पर स्कीमा खोज सकते हैं बिना कोई फाइल डाउनलोड किए। रिफ्लेक्शन के लिए किसी भी अन्य कॉल की तरह समान बीयरर टोकन की आवश्यकता होती है।
- **`.proto` फाइलें**, यदि आप स्कीमा को वेंडर करना और पहले से जनरेट करना पसंद करते हैं।

```bash
# चल रहे सर्वर से स्कीमा खोजें (प्रमाणीकृत)।
grpcurl -H "authorization: Bearer $WINK_TOKEN" \
  partner.wink.travel:443 list

# फिर क्लाइंट जनरेट करें — यहाँ Go; हर समर्थित भाषा इसी तरह काम करती है।
protoc --go_out=. --go-grpc_out=. partner_lookup.proto
```

कॉल्स आपके बीयरर टोकन को `authorization` मेटाडेटा हेडर में ले जाते हैं, ठीक वैसे ही जैसे REST इसे `Authorization` हेडर में ले जाता है। त्रुटियाँ HTTP स्टेटस कोड के बजाय प्रतिक्रिया ट्रेलर्स में gRPC स्टेटस कोड के रूप में आती हैं — [Partner संदर्भ](/hi/partner-api/partner/) में वे स्टेटस सूचीबद्ध हैं जिनकी आपको उम्मीद करनी चाहिए।

## या MCP सर्वर को इसे लिखने दें

यदि आप AI कोडिंग सहायक का उपयोग करते हैं, तो हमारा MCP सर्वर सबसे तेज़ मार्ग है। यह Wink के APIs को ऐसे टूल्स के रूप में प्रस्तुत करता है जिन्हें आपका सहायक कॉल और समझ सकता है, इसलिए पूरे क्लाइंट को जनरेट करने और एंडपॉइंट्स खोजने के बजाय, आप जो बना रहे हैं उसका वर्णन करते हैं और उस के अनुसार एकीकरण कोड प्राप्त करते हैं।
