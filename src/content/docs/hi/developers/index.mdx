हर प्लेटफ़ॉर्म फीचर बाहरी रूप से कॉल किया जा सकता है। यह अनुभाग प्रमाणीकरण, API सतह, इवेंट डिलीवरी और इसके पीछे के संदर्भ डेटा को कवर करता है।

## यहाँ से शुरू करें

- [Quickstart](/hi/developers/quickstart/) — शून्य से लाइव होटल कीमतों और आपके पहले परीक्षण बुकिंग तक स्टेजिंग में।
- [Build on Wink](/hi/developers/build-on-wink/) — आप क्या बना सकते हैं और कौन सा API उपयुक्त है।
- [Setup](/hi/developers/setup/) — एक एप्लिकेशन बनाएं और क्रेडेंशियल प्राप्त करें।
- [Authentication](/hi/developers/authentication/) — OAuth2 सत्र और स्कोप।

## API सतह

- [REST and gRPC](/hi/developers/rest-and-grpc/) — दो ट्रांसपोर्ट और कब किसका उपयोग करें।
- [Geolocation](/hi/developers/geolocation/) — बुक करने योग्य इन्वेंट्री पर स्थानिक खोज।
- [Taxonomy](/hi/developers/taxonomy/) — OTA कोड, समर्थित भाषाएँ और मुद्राएँ।

## इवेंट और सिंक्रोनाइज़ेशन

- [Webhook Integration](/hi/developers/webhook-integration/) — प्लेटफ़ॉर्म इवेंट्स की सदस्यता लें।
- [Webhook Events Catalog](/hi/developers/webhook-events/) — प्लेटफ़ॉर्म द्वारा जारी हर इवेंट।
- [Booking Sync](/hi/developers/booking-sync/) — PMS या चैनल मैनेजर के साथ बुकिंग को संरेखित रखें।

## AI एजेंट

- [MCP Servers](/hi/developers/mcp/) — AI क्लाइंट से लाइव API कॉन्ट्रैक्ट पढ़ें।
- [Agentic Payments](/hi/developers/agentic-payments/) — अपने एजेंट को कनेक्ट करें, साइन इन करें, एक कमरा खोजें और भुगतान स्वीकृत करें।
- [AI Skills](/hi/developers/ai-skills/) — प्लेटफ़ॉर्म पर एक अनुमोदित एजेंट क्या कर सकता है।
