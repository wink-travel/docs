हर प्लेटफ़ॉर्म फीचर बाहरी रूप से कॉल किया जा सकता है। यह अनुभाग प्रमाणीकरण, API सतह, इवेंट डिलीवरी और इसके पीछे के संदर्भ डेटा को कवर करता है।

## यहाँ से शुरू करें

- [Wink पर निर्माण करें](/hi/developers/build-on-wink/) — आप क्या बना सकते हैं और कौन सा API उपयुक्त है।
- [सेटअप](/hi/developers/setup/) — एक एप्लिकेशन बनाएं और क्रेडेंशियल प्राप्त करें।
- [प्रमाणीकरण](/hi/developers/authentication/) — OAuth2 सत्र और स्कोप।

## API सतह

- [REST और gRPC](/hi/developers/rest-and-grpc/) — दो ट्रांसपोर्ट और कब किसका उपयोग करें।
- [जियोलोकेशन](/hi/developers/geolocation/) — बुक करने योग्य इन्वेंट्री पर स्थानिक खोज।
- [टैक्सोनॉमी](/hi/developers/taxonomy/) — OTA कोड, समर्थित भाषाएँ और मुद्राएँ।

## इवेंट और सिंक्रोनाइज़ेशन

- [Webhook इंटीग्रेशन](/hi/developers/webhook-integration/) — प्लेटफ़ॉर्म इवेंट्स की सदस्यता लें।
- [Webhook इवेंट्स कैटलॉग](/hi/developers/webhook-events/) — प्लेटफ़ॉर्म द्वारा जारी हर इवेंट।
- [बुकिंग सिंक](/hi/developers/booking-sync/) — बुकिंग को PMS या चैनल मैनेजर के साथ संरेखित रखें।

## AI एजेंट्स

- [MCP सर्वर](/hi/developers/mcp/) — AI क्लाइंट से लाइव API कॉन्ट्रैक्ट पढ़ें।
- [Agentic Payments](/hi/developers/agentic-payments/) — अपने एजेंट को कनेक्ट करें, साइन इन करें, एक कमरा खोजें और भुगतान स्वीकृत करें।
- [AI Skills](/hi/developers/ai-skills/) — प्लेटफ़ॉर्म पर एक अनुमोदित एजेंट क्या कर सकता है।
