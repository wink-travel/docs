Booking Engine कहीं भी एम्बेड करें। अपना फ्रेमवर्क या CMS चुनें और उसके गाइड का पालन करें; अंतर्निहित Web Components हर जगह समान हैं।

## मुख्य दृष्टिकोण

- [Web Components](/hi/integrations/web-components/) — एम्बेड करने योग्य तत्व जो हर एकीकरण उपयोग करता है।
- [npm package](/hi/integrations/npm/) — JavaScript बिल्ड में इंस्टॉल करें।
- [Headless CMS](/hi/integrations/headless/) — किसी भी कंटेंट बैकएंड से रेंडर करें।
- [Partner API](/hi/integrations/partner-api/) — पूर्ण प्रोग्रामेटिक एकीकरण।
