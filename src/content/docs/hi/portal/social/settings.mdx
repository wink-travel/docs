# सेटिंग्स

जब आप Social के साथ पहली बार शुरू करते हैं, तो हम आपसे पूछेंगे कि आप चाहते हैं कि हम आपकी सामग्री कैसे बनाएं। ये विकल्प हमेशा आपके लिए उपलब्ध होते हैं ताकि आप बाद में आसानी से उन्हें बदल सकें।

अपनी सेटिंग्स प्रबंधित करने के लिए साइडबार से `Preferences` पर जाएं।

प्राथमिकताएँ अनुभाग में आपकी मूल सामग्री निर्माण सेटिंग्स होती हैं:

1. **पसंदीदा अनुकूलन** सामग्री उत्पन्न करते समय उपयोग करने के लिए अनुकूलन चुनें। अनुकूलन थीम रंग, डिफ़ॉल्ट यात्रा कार्यक्रम, मुद्रा, भाषा, और अधिक को नियंत्रित करते हैं। आप [app.wink.travel](https://app.wink.travel) पर अपने खाते के तहत अनुकूलन बनाते हैं।
2. **स्वचालित अनुमोदन** सक्षम होने पर, उत्पन्न पोस्ट बिना आपकी मंजूरी के स्वचालित रूप से प्रकाशित हो जाते हैं। जब आप हमारे द्वारा बनाई गई सामग्री की गुणवत्ता पर भरोसा कर लें, तो इसे सक्षम करें।
3. **अनुमोदक का नाम** वह व्यक्ति या टीम का नाम जो अनुमोदन अनुरोध ईमेल प्राप्त करेगा।
4. **अनुमोदक ईमेल** वह ईमेल पता जहां आगामी पोस्ट के अनुमोदन अनुरोध भेजे जाएंगे।

Social के साथ चुनने के लिए कई सामग्री निर्माता आते हैं। प्रत्येक निर्माता आपके संपत्ति के लिए AI का उपयोग करके अद्वितीय सामग्री बनाने के एक विशिष्ट तरीके पर केंद्रित होता है। हर सामग्री निर्माता के पास एक **Weight** गुण होता है — उच्च वज़न उस निर्माता के चयन की संभावना बढ़ाता है जब पोस्ट उत्पन्न किए जाते हैं।

यहाँ सभी उपलब्ध सामग्री निर्माता हैं:

| निर्माता | विवरण |
| -- | -- |
| **गंतव्य** | आपके स्थान का उपयोग करके क्षेत्र के बारे में सहायक पाठ बनाता है |
| **कमरे का प्रकार** | AI-जनित पाठ और आपके कमरे के प्रकार की छवियों के साथ आपके कमरे के प्रकार में से एक को प्रदर्शित करता हुआ बुक करने योग्य पोस्ट बनाता है |
| **गतिविधि** | आपकी किसी गतिविधि को प्रदर्शित करता हुआ बुक करने योग्य पोस्ट बनाता है |
| **ऐड-ऑन** | आपके किसी ऐड-ऑन को प्रदर्शित करता हुआ बुक करने योग्य पोस्ट बनाता है |
| **आकर्षण** | आपके किसी आकर्षण को प्रदर्शित करता हुआ बुक करने योग्य पोस्ट बनाता है |
| **स्थान** | आपके किसी स्थान को प्रदर्शित करता हुआ बुक करने योग्य पोस्ट बनाता है |
| **मीटिंग रूम** | आपके किसी मीटिंग रूम को प्रदर्शित करता हुआ बुक करने योग्य पोस्ट बनाता है |
| **रेस्टोरेंट** | आपके किसी रेस्टोरेंट को प्रदर्शित करता हुआ बुक करने योग्य पोस्ट बनाता है |
| **स्पा** | आपके किसी स्पा को प्रदर्शित करता हुआ बुक करने योग्य पोस्ट बनाता है |
| **संपत्ति** | AI-जनित पाठ और आपकी संपत्ति की छवियों के साथ आपके सबसे अच्छी कीमत वाले कमरे को प्रदर्शित करता हुआ बुक करने योग्य पोस्ट बनाता है |
| **उपयोगकर्ता भावना** | वेब पर मेहमानों की समीक्षाओं को एकत्रित करके एक भावना-आधारित पोस्ट बनाता है जो दर्शाता है कि मेहमान आपकी संपत्ति के बारे में क्या पसंद करते हैं |
| **मज़ेदार** | हल्के-फुल्के, मनोरंजक पोस्ट बनाता है ताकि आपका फीड आकर्षक बना रहे |

:::tip[प्रो टिप]
सुनिश्चित करें कि आपके चुने हुए सामग्री निर्माताओं के लिए आवश्यक इन्वेंटरी प्रकार आपके पास हो। उदाहरण के लिए, यदि आप "रेस्टोरेंट" चुनते हैं, तो आपकी संपत्ति पर कम से कम एक रेस्टोरेंट सूचीबद्ध होना चाहिए।
:::

आवाज़ का लहजा वह भाषा शैली सेट करता है जिसका AI सामग्री उत्पन्न करते समय उपयोग करता है। उन लहजों को चुनें जो आपके ब्रांड की व्यक्तित्व से मेल खाते हैं। सामग्री निर्माताओं की तरह, प्रत्येक लहजे का एक **Weight** होता है जो नियंत्रित करता है कि इसे कितनी बार उपयोग किया जाता है।

यहाँ उपलब्ध लहजे हैं:

| लहजा | शैली |
| -- | -- |
| **तटस्थ** | शांत, अधिकारपूर्ण, तथ्यात्मक। कोई अतिशयोक्ति नहीं, कोई मज़ाक नहीं — बस विश्वसनीय, सुव्यवस्थित ज्ञान |
| **मित्रवत** | गर्मजोशी भरा, सुलभ, टेक्स्ट में मुस्कुराहट के साथ, आकस्मिक संक्षेप और कभी-कभी इमोजी के साथ |
| **लक्ज़री** | परिष्कृत, निखरा हुआ। "उत्कृष्ट" और "विशेष" जैसे शब्द जो पाठकों को विशिष्ट महसूस कराते हैं |
| **खाद्य प्रेमी** | कामुक, मुँह में पानी लाने वाले वर्णन। खाद्य प्रेमी भाषा जो पाठकों को भूखा कर देती है |
| **साहसी** | साहसी, निडर, खोजकर्ता ऊर्जा। जीवंत संवेदी वर्णन जो सब कुछ महाकाव्य बनाते हैं |
| **परिवार** | स्वस्थ, बच्चों के अनुकूल उत्साह। सुरक्षित और मज़ेदार अनुभवों के बारे में गर्म माता-पिता की ऊर्जा |
| **रोमांटिक** | काव्यात्मक, उदासीन, दिल को छू लेने वाला। सूर्यास्त, नरम भाषा, और प्रेम |
| **हास्यपूर्ण** | व्यंग्यात्मक, तेज़ एक-लाइनर, चतुर शब्दों का खेल। स्टैंड-अप सेट की तरह पढ़ता है |
| **इको** | गंभीर और धार्मिक। हरित विकल्पों और टिकाऊ विकल्पों का जश्न मनाता है |
| **स्थानीय अंदरूनी** | अत्यंत विशिष्ट स्थानीय संदर्भ, पर्यटक जाल से सावधान करता है, स्थानीय स्लैंग का उपयोग करता है |
| **समावेशी** | स्वागत योग्य, उत्सवपूर्ण, और पुष्टि करने वाला। हर किसी को देखा और मूल्यवान महसूस कराता है |
| **रहस्यमय** | अलौकिक, आध्यात्मिक, ब्रह्मांडीय सत्य। भीतर देखने के लिए कोमल निमंत्रण |
| **भविष्यवादी** | चिकना, भविष्य की सोच वाला। "पैराडाइम शिफ्ट" और आशावादी भविष्य दृष्टिकोण जैसे शब्द पसंद करता है |
| **बजट** | जुगाड़ू, संसाधनपूर्ण, गर्व से किफायती। किफायती खोजों और मुफ्त अनुभवों का जश्न मनाता है |

## पोस्ट प्रकार

पोस्ट प्रकार उत्पन्न सामग्री के लक्ष्य और संरचना को निर्धारित करते हैं। प्रत्येक पोस्ट प्रकार का एक **Weight** होता है जो नियंत्रित करता है कि इसे कितनी बार उपयोग किया जाता है।

| पोस्ट प्रकार | विवरण |
| -- | -- |
| **लेन-देन संबंधी** | स्पष्ट, संक्षिप्त, रूपांतरण-केंद्रित। तथ्यों, कीमतों, और अगले कदमों के साथ बुकिंग और सीधे क्रियाओं को बढ़ावा देता है |
| **जागरूकता** | ब्रांड-निर्माण सामग्री जो आपकी संपत्ति का परिचय देती है और संभावित मेहमानों के बीच दृश्यता बढ़ाती है |
| **भावना** | भावनात्मक रूप से प्रतिध्वनित सामग्री जो सकारात्मक संघ बनाती है और आपके दर्शकों के साथ भावनात्मक संबंध बनाती है |

आप अपनी मार्केटिंग कोशिशों को किसी विशेष भाषा और क्षेत्र पर केंद्रित करना चाह सकते हैं। हमें बताएं कि आप किन भाषाओं के लिए सामग्री बनाना चाहते हैं और आप किस समय क्षेत्र में रुचि रखते हैं, और हम बाकी काम करेंगे। पोस्ट आपके चयनित समय क्षेत्र में निर्धारित समय पर प्रकाशित होते हैं।

*अधिकांश संपत्तियाँ एक भाषा का उपयोग करती हैं और अपनी स्थानीय भाषा को डिफ़ॉल्ट मानती हैं।*
