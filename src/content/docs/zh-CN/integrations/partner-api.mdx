## 使用和限制说明

### 免费层

免费层旨在让您构建、测试并运行适度的生产流量，且无需付费。

- **速率限制 — 每分钟 30 次请求，允许 60 次突发。** 短时间内超过持续速率的请求由突发额度吸收。若超出，API 将返回 **HTTP 429（请求过多）** 并应用 **5 分钟暂停**，暂停结束后密钥恢复服务。请在暂停窗口后重试，避免频繁请求。
- **月度配额 — 每日历月 10,000 次请求。** 达到月度上限后，API 在当月剩余时间内返回 **HTTP 429**，即硬停止，并提示您订阅付费层以继续使用。计数器在下一个日历月初重置。

免费层不包含服务级别协议或优先支持。

### 付费层

付费层取消月度上限和速率限制暂停，仅按实际使用量计费。

- **计量请求 — 每 1,000 次请求 $1.00。** 无月度请求上限，正常使用下无速率限制节流，按实际流量计费。
- **预订转化超额 — 每 1,000 次超额搜索 $2.00。** 为保持供应健康，我们对搜索（“浏览”）与确认预订的比例进行计量。您享有 **每笔预订 5,000 次浏览** 的额度，超额浏览按以下公式计算：

  `excess = max(0, looks − bookings × 5,000)`

  超额部分按 **每 1,000 次超额浏览 $2.00** 计费。转化率高的集成很少产生超额费用；该费用仅适用于搜索远超预订的流量。

付费层包含下述服务级别协议——99.9% 正常运行时间承诺和 P95 响应时间目标低于 500 毫秒——以及优先、基于严重性的支持。

## 服务级别协议

_生效日期：2026 年 7 月 5 日 · 版本 1.0_

本服务级别协议（“SLA”）规定了 Wink（“Wink”、“我们”）向客户（“客户”、“您”）提供的经过身份验证的 Wink 合作伙伴 API（“合作伙伴 API”或“服务”）的可用性承诺、服务信用和支持目标，适用于声明适用 SLA 的层级。本 SLA 纳入您与 Wink 之间访问合作伙伴 API 的协议（“协议”）并受其约束，适用于您保持有效且良好状态的付费合作伙伴 API 订阅期间。未在此定义的术语含义以协议中定义为准。

### 1. 定义

1. **“正常运行时间”** 指合作伙伴 API 可接受并成功响应格式正确、经过身份验证请求的时间段。
2. **“停机时间”** 指合作伙伴 API 未能成功响应格式正确、经过身份验证请求的时间段（以分钟计），不包括第 4 节中列出的排除情况。影响极少请求的孤立错误本身不构成停机时间。
3. **“月度正常运行百分比”** 指某日历月内总分钟数减去停机分钟数，再除以该月总分钟数，结果以百分比表示。
4. **“计划维护”** 指 Wink 按第 4 节规定提前通知的服务计划维护。
5. **“服务信用”** 指按您当月为合作伙伴 API 支付或应付费用的百分比计算的信用额度，作为未达到正常运行时间承诺的唯一且排他性补救措施，抵扣未来合作伙伴 API 费用。
6. **“响应时间”** 指 Wink 在服务边界收到格式正确、经过身份验证请求到开始返回响应的时间，不包括网络传输和客户端控制之外的时间。

### 2. 可用性与性能承诺

Wink 将尽商业合理努力确保合作伙伴 API 在每个日历月的 **月度正常运行百分比至少为 99.9%**（“正常运行时间承诺”）。正常运行时间承诺在 Wink 服务边界测量，不包括第 4 节中描述的不可控因素。Wink 的监控系统为月度正常运行百分比和响应时间的权威记录。

Wink 还设定了成功、格式正确、经过身份验证请求的 **第 95 百分位（P95）响应时间低于 500 毫秒** 的目标（“性能目标”），在 Wink 服务边界按月测量。性能目标不包括第 4 节描述的因素、因请求本身导致的应用级错误以及异常大或复杂的批量请求。性能目标为服务目标；第 3 节的服务信用仅适用于未达到 **正常运行时间承诺** 的情况，是可用性不足的唯一且排他性补救。

### 3. 服务信用

若月度正常运行百分比低于正常运行时间承诺，您可根据以下阶梯获得按当月合作伙伴 API 费用计算的服务信用：

| 月度正常运行百分比 | 服务信用 |
|---|---|
| 低于 99.9% 但不低于 99.0% | 10% |
| 低于 99.0% 但不低于 95.0% | 25% |
| 低于 95.0% | 50% |

1. **申请信用。** 您必须在发生故障的日历月结束后 **30 天内** 向 Wink 提交书面申请，包含每次停机事件的日期和时间及您合理可提供的支持日志或证据。逾期申请不予受理。
2. **信用形式。** 经批准的服务信用用于抵扣未来合作伙伴 API 费用，无现金价值，不是退款，除非适用法律另有规定。
3. **最高额度。** 单个日历月累计服务信用不超过您当月为合作伙伴 API 支付或应付费用的 50%。
4. **唯一且排他性补救。** 服务信用是您因 Wink 未达到正常运行时间承诺或其他可用性不足而享有的 **唯一且排他性补救**。
