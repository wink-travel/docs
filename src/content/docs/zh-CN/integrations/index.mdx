Booking Engine 可嵌入任何地方。选择您的框架或 CMS 并按照其指南操作；底层的 Web Components 在任何地方都是相同的。

## 核心方法

- [Web Components](/zh-CN/integrations/web-components/) — 每个集成都使用的可嵌入元素。
- [npm package](/zh-CN/integrations/npm/) — 安装到 JavaScript 构建中。
- [Headless CMS](/zh-CN/integrations/headless/) — 从任何内容后端渲染。
- [Partner API](/zh-CN/integrations/partner-api/) — 完整的编程式集成。
