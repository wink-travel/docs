作为开发者，应用程序让您可以访问 Wink 的所有功能。您可以访问所有相同的数据，甚至扩展 Wink 自身的功能。
您可以选择使用 Wink 的 OAuth2 服务器来验证您的旅游网站，就像使用 Google 或 Facebook 一样。
这样，您就可以将 Wink 的功能扩展到您自己的网站或应用程序中。

:::note
当您[创建新账户](/zh-CN/portal/create-account)时，您的第一个应用程序已经创建。我们在某些预订场景中使用该应用程序。

您不能重复使用此应用程序。请根据需要创建新的应用程序。
:::

## 创建应用程序

由于您无法访问我们为您创建的应用程序的 `密钥`，您需要创建自己的应用程序。
您可以在此处创建应用程序，无需先设置物业或公司——它不绑定到任何特定账户。

### 客户端类型

创建应用程序时，您需要选择一个客户端类型，该类型决定了应用程序的身份验证方式。
此设置无法更改——如果需要不同类型，请创建新的应用程序。

- **Web 应用程序** — 服务器渲染的应用程序，可以安全地保存客户端密钥（授权码流程）。
- **单页应用程序 (SPA)** — 无后端的浏览器应用程序；使用 PKCE，无客户端密钥。
- **移动应用程序** — 原生 iOS/Android 应用程序；使用带旋转刷新令牌的 PKCE。
- **机器对机器** — 作为自身运行的后端服务（客户端凭据）；无用户登录。

以下是创建应用程序的步骤：

<Steps>
1. 在应用程序页面，点击 `创建新应用程序` 按钮。
2. ***名称*** 给您的应用程序命名。*例如 Cool App*
3. **客户端类型** 选择与您的应用程序身份验证方式匹配的类型——参见上文[客户端类型](#client-types)。
4. **重定向 URI** 至少需要一个重定向 URI。它用于在成功身份验证后验证重定向域。机器对机器应用程序不使用此项。*例如 https://www.cool-site.com*
5. **注销后重定向 URI** *(可选)* 用户注销后可重定向的 URL。留空则重用上述重定向 URI。
6. **权限范围** 选择此应用程序可以代表您访问的内容——参见下文[选择权限范围](#choosing-scopes)。
7. 点击 `创建应用程序` 按钮继续。
</Steps>

您将被重定向回应用程序列表，并显示一个一次性对话框，展示新的客户端 ID 和客户端密钥。请立即复制密钥并妥善保存——它不会再次显示，且无法找回（只能[旋转](#rotate-credentials)以获取新密钥）。

## 选择权限范围

每个应用程序始终包含 **登录（OpenID Connect）** 权限范围（`openid`、`profile`、`email`、`offline_access`）——这些确认用户身份并保持登录状态，因此它们被选中且锁定；不可更改。

其他权限范围均为可选。剩余权限范围按功能分组，详见[权限范围](/zh-CN/developers/authentication#scopes)——账户、库存与价格、预订、营销与促销、物业内容、分析与报告、渠道管理集成、支付以及会计与账本——每组均有通俗描述说明其解锁的功能。使用列表上方的 `全部` / `无` 链接可一次选择或清除所有可选权限范围。

:::note
**支付** 和 **会计与账本** 被标记为 **敏感**，因为它们涉及资金流动——仅授予确实需要访问支付或账本的应用程序。
:::

有两类权限范围故意**不在此表单中提供**：

- **`mcp.*`** — AI 代理访问[模型上下文协议](/zh-CN/developers/mcp)传输，该权限单独配置，仅供机器对机器客户端使用。
- **管理员级权限**（`administrator.*`）— 平台级访问权限，不按应用程序授予。

应用程序创建后，此标签页和[已授权应用](/zh-CN/account/apps)均会按功能分组显示其已授予的权限范围（例如“预订：`booking.read`”），方便您一目了然地查看应用程序权限，无需打开详情。

## 旋转凭据

如果客户端密钥可能泄露，或您想要更新凭据，请旋转凭据，而不是重新创建应用程序：

<Steps>
1. 在应用程序列表中找到该应用，点击 `旋转`。
2. 确认对话框——当前客户端 ID 和密钥立即失效。
3. 在关闭对话框前复制新的客户端 ID 和密钥。
</Steps>

旋转操作会保留应用名称、客户端类型、重定向 URI 和权限范围——仅凭据会更改。

## 删除应用程序

:::caution
请不要删除我们自动为您创建的应用程序，以确保您的账户所有功能正常。
:::

如果您不再需要某个应用程序，可以删除它。此操作不可逆——凭据会立即被撤销，且无法恢复。

<Steps>
1. 在应用程序列表中找到该应用，点击 `删除`。
2. 确认对话框以永久删除该应用程序。
</Steps>
