账单页面是您开启按需付费、决定适用哪些账户以及监控支出的地方。

您无需特意来到这里开始使用。每个账户在计费功能上都有免费的月度额度，无需任何操作。此页面仅用于超出该额度的情况。请参阅[定价](/zh-CN/getting-started/pricing)了解哪些是免费的、哪些是计费的以及费用详情。

## 启用按需付费

开启按需付费并选择您的结算方式：

- **卡片** — 当发票开出时，我们会自动从您保存的卡片中扣款。
- **发票** — 我们会向您发送发票，您自行付款。

您可以随时在两者之间切换。

:::note
只有账户的**所有者**才能为其启用按需付费。拥有他人账户的管理权限是不够的，因为发票会发送给所有者——我们不会允许其他人使用您的卡片扣费。
:::

## 选择您的账户

如果您拥有多个账户，可以单独选择哪些账户启用计费。关闭的账户每月仅享受免费额度。

所有启用账户的使用情况会合并为**每月一张发票**，因此您只需支付一张账单，而不是每个物业一张。

## 付款方式

添加卡片后，我们会与支付提供商安全存储。我们仅显示卡片品牌、后四位和有效期——Wink 从不查看或存储您的完整卡号。如果银行发放了替换卡，信息会自动更新。

## 使用情况

跟踪本月迄今为止的使用情况，按功能和账户分类，并显示每项的免费额度。如果您想控制支出，这个数字很重要——尤其是社交功能，您的月度发帖数实际上就是预算。

额度每月1日重置。

## 发票

您的发票历史列出每月的编号、计费周期、金额、货币和状态，并提供在线查看或下载 PDF 的链接。

## 账单状态

| 状态 | 含义 |
| -- | -- |
| 良好状态 | 一切正常运行。 |
| 逾期 | 付款尝试失败，正在重试。重试期间您的功能继续正常使用。 |
| 暂停 | 发票未支付至截止日期。计费功能被阻止，直到结清——免费功能照常使用。 |
