欢迎来到 Wink。无论您是经营酒店、向受众推广旅游、代表客户预订，还是为上述任何一方开发软件——您都来对地方了。

Wink 的创建旨在让销售旅游库存重新变得令人兴奋，并让更多人能够接触到它，而不仅仅是那些曾经控制市场的少数大型玩家。这些文档将引导您了解平台的每个部分，从创建第一个账户到通过深度 API 集成上线。您无需按顺序阅读；直接前往与您目标相符的部分——如果您已经知道自己想要什么，页面顶部的 AI 驱动搜索栏会直接带您到达。

Wink 账户让您能够：

- 创建和管理物业，并在潜在旅客所在的所有地方销售。
- 创建和管理联盟账户，并从您促成的预订中赚取佣金。
- 创建和管理旅行代理账户，代表您的客户进行预订。
- 获取您的 WinkLinks 个性化网址（*例如 https://i.trvl.as/bob*），并将其用作您的 `Link-in-Bio URL`。
- 预订您的下一次假期并节省开支。
- 作为开发者，通过与 Wink 集成完成以上所有操作。

## 关于 Wink

`Wink Travel Platform` 是一个开创性的全新旅游平台，从零开始设计，旨在赋能酒店、体验提供商、影响者和联盟。通过无缝集成创新工具与用户友好界面，Wink 改变了酒店业，使连接、成长和成功比以往任何时候都更容易。

您作为企业所做的一切现在都集中在一个地方——**Portal**。与之并列的是我们的**预订引擎**，所有预订最终都在这里完成，以及我们的**开发者工具**，供希望基于我们构建的团队使用。请选择下面适合您的部分并从那里开始。

## 费用说明

Wink 提供的大部分服务都是免费的。列出和管理您的物业、构建您的联盟网络、使用预订引擎、发布您的 WinkLinks 页面、撰写自己的社交帖子、分析数据——这些都不收费，也没有订阅费和设置费。

当发生预订时，Wink 会收取少量费用以维持运营。还有一些每次使用都会产生实际成本的高级功能——如 AI 生成的社交帖子、自动回复、高流量 API 访问——这些以**按使用付费**的方式计费，费率我们相信您会觉得非常合理。每项功能都附带免费月度额度，您可以先试用再决定是否付费。

## 核心概念

> 见一斑，知全豹

在熟悉 Wink 的所有功能时，您会发现许多操作方式相似。理解核心概念将帮助您更快上手并增强信心。

请看：

- 每个部分通常都有列出、添加、更新和删除条目的方式。
- 编辑条目时，表单字段上的红色星号 <Badge text="*" variant="danger" size="large" /> 表示必填项。
- 如果某个表单字段填写错误，该字段会显示红色边框，且下方会有红色文字说明问题。
- 只有当表单有效且有更改时，您才能点击 `保存`。
- 有些表单包含多个标签页，例如客房表单。
- 所有标签页都必须有效才能继续。
- 含有缺失或无效数据的标签页名称旁会显示黄色三角形 <Badge text="⚠️" variant="caution" size="large" />。
- 提交表单时，大多数表单会弹出 `确认` 对话框，询问您是否继续。

## Portal

[Portal](https://app.wink.travel) 是您作为企业进行所有操作的单一应用。无论您拥有哪种账户，这里都是您的起点：

- **物业** — 列出您的酒店，管理价格、内容和可用性，并拥有一支庞大的联盟销售团队。
- **联盟** — 变现您的受众，并从每笔您引导的预订中赚取佣金。
- **旅行代理** — 直接从供应商搜索定制价格和库存，为客户预订。
- **支付** — 跟踪您的收入并提现，支付由 TripPay 支持。
- **社交** — 让 AI 保持您的社交渠道活跃并转化。
- **链接管理** — 构建并发布您的 WinkLinks 页面。
- **设置** — 品牌、管理者、应用、Webhook 和支付，按账户区分。

您可以通过单一登录管理任意多个账户，企业版也在路上。
