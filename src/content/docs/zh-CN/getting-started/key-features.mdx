Wink 旅游平台的功能源于实际需求。人们不知道如何：

- 快速开始在线销售旅游库存。
- 轻松通过社交媒体或线上销售设施和体验。
- 在预订过程中向旅客进行追加销售。
- 找到专注于旅游且能赚取直接佣金的联盟网络。
- 利用联盟网络无额外努力地通过数千个销售渠道销售，从而降低成本和风险。
- 保留客户所有权以便重新定位。
- 利用他们的社交影响力实现变现。
- 集成一个不需要冗长保密协议和长时间等待的旅游平台。
- 在与联盟合作时正确跟踪投资回报率。
- ……以及更多

随着时间推移，新增了功能，扩展了现有功能，也移除了一些功能。如果你从事旅游行业，或者只是喜欢/需要旅行，我们有充分的理由让你加入 Wink。继续阅读，了解原因。

以下功能构成了 Wink 的核心。

## 预订引擎

Wink 的核心是一款强大、可白标且高度可定制的预订引擎。它具备你对预订引擎的所有期望功能，如实时定价、物业信息、设施、位置等。支持不同的排名类别，如环保、生活方式和评价。允许旅客创建详细的旅客档案并分享，告知酒店他们的偏好、过敏情况、紧急联系方式等。

我们的预订引擎通过精美设计的界面让每个物业和目的地看起来都很出色。但真正让它与众不同的是它能够向旅客推销任何与物业相关的服务。就像廉价航空鼓励乘客升级到更宽敞的座位、增加行李额度和餐食一样，Wink 让物业清晰了解追加销售的样貌。从客房附加服务、预订会议室或当地餐厅座位，到博物馆、自然徒步和水上乐园……Wink 赋能物业，让整个社区通过优惠和体验焕发生机，令旅客惊喜。

我们的重点是让旅客体验更丰富的整体体验，并在抵达前以更高价位连接物业与客人。

## 内容创作

Wink 既是内容工具，也是预订平台。Wink 上的每一件旅游库存——一个房间、一项水疗、一张邻近餐厅的桌子、一场日出徒步——都可以转化为你的受众可以实际消费和行动的内容。

选取任何物业、房间或体验，生成可分享的链接、卡片、网格、地图或精选列表，然后投放到你的受众所在之处。在线分享最广泛使用的方式是 `链接`，我们的链接带有动态预览，实时显示价格叠加在你选择的美图上。内容永不过时：价格、可用性和内容保持实时更新，因此几个月前分享的链接今天依然能卖出。

这缩短了从社交动态到确认预订的路径——旅客看到值得拥有的东西，价格合理且可用，无需离开动态去寻找。

## 自动化

制作内容是一回事，*每周持续制作，永远不断*才是真正让人崩溃的事。我们遇到的几乎每家酒店都有同样的故事：一阵热情，一个月的好帖子，然后沉默——因为负责的人被紧急事务拉走、去度假或离职。受众注意到沉默远早于内容。

所以我们实现了自动化。Wink 监控你的实时库存、价格、促销、照片和物业内容，并按你设定的时间表生成帖子——用你销售的语言，带有真实价格和预订链接。你决定参与程度：每条帖子发布前审批，或开启自动审批让它自动运行。

### 持续改进

每条帖子都会被衡量——曝光、互动、点击，最关键的是由此产生的预订。性能数据反馈到下一次生成内容：优先展示哪些房间和体验，哪些角度更受欢迎，何时发布，哪种语气更能转化。运行自动化六个月的物业发布的内容明显比第一周更精准，无需人工分析。

### 对酒店而言

这改变了销售和市场部门的运作方式。自动化为你提供了底线——一个持续、一致、符合品牌且始终最新的存在，不依赖任何人的日程。你的市场团队停止写标题，开始做只有他们能做的工作：活动、合作、定位。没有市场部门的小型物业首次拥有了市场团队。

### 对联盟而言

联盟使用同一引擎但目标不同。Wink 自动代表你发布可佣金内容——每条帖子都带有你的追踪代码，任何转化都会支付佣金，无论你发布时是否在线。你不必每次推广都手动生成链接，只需设定节奏，让持续的实时可预订库存触达你的受众。

自动发布到 WinkLinks 永远免费，发布到其他社交网络的帖子在超出免费月度额度前也免费——详见[价格](/zh-CN/getting-started/pricing)。

## 链接管理器

链接管理器让你保存和组织喜欢的网址以备后用。浏览器书签就是一种链接管理器。随着社交媒体的兴起，暴露和分享链接给朋友和受众的需求更大。你的 Facebook 动态就是一种社交友好的链接管理器。

我们的链接管理工具 WinkLinks 更进一步。

- 它为你提供一个个性化网址，如 https://i.trvl.as/bob，适用于 IG 等只允许分享单一 URL 的场景，并让你管理来自全网的链接。此外，如果网站支持 `丰富内容`，如 Spotify，WinkLinks 会让播放列表可播放，或让 Facebook 视频可观看。
- WinkLinks 允许你免费添加所有现有的联盟链接，如 CJ 和 Amazon。
- WinkLinks 也是任何人只需两次点击即可销售旅游库存的最简预订引擎，专注于将你的受众转化为预订。

WinkLinks 高度可定制，支持你的品牌需求。

## 联盟网络

预订引擎是我们的核心产品，但联盟网络让平台焕发生机。Wink 让物业与联盟互联。双方可协商交易、佣金和折扣。物业无需猜测合作是否合理，可查看联盟的过往表现及其带来的旅客细分。即使没有直接连接，联盟也能访问一般可用的价格和优惠。

Wink 向联盟提供多样化库存。我们跟踪每笔预订的分析数据、你的投资回报率，并负责支付所有相关方。你可以专注于你最擅长的事：向你的受众销售。

我们的 Extranet 是物业自助连接联盟并触达全球旅客的系统。

## 代理友好

大多数旅游平台先为人设计，再加上 API。Wink 则反其道而行之：**Portal 中你能做的每一件事，AI 代理也能做**——通过 [Model Context Protocol](/zh-CN/developers/mcp) 暴露的 500 多个工具，覆盖整个平台。没有代理无法触及的管理员专属区域，也没有需要人工点击的任务。

### 物业管理

给代理一个电子表格、PMS 导出或一组照片，让它完成入驻。它能注册物业，为每个房间、餐厅、水疗和活动撰写描述，设置设施和政策，加载主价和价格计划，开启销售渠道并推送可用性——人工需数天完成的工作，一次无人值守运行即可完成。

上线后的所有工作同样适用。价格和可用性更新、季节性调价、停用日期、内容刷新、声誉监控和月末报告都能按计划自动运行，无需登录。

### 联盟营销

代理也能管理商业端：搜索适合你受众的库存，向物业请求并协商佣金，构建可分享的链接、卡片、网格和精选列表，发布它们，然后读取转化分析并重新分配资源到有效内容。

对于规模运营者——代理、网络、大型创作者团队——这就是手动管理少量物业与程序化管理数千物业的区别。

### 代为预订

像 OpenClaw 这样的 AI 助手能在 Wink 上端到端规划整个行程——理解需求，搜索全球实时库存，比较价格、设施和评价，然后预订并付款。无需网站、无需表单、无需人工介入。

**AI 助手没有品牌忠诚度。** 它不在乎房间在哪个网站上架。它关心的是是否为最佳产品、最佳价格、最佳设施，满足用户需求。不是赞助位，不是多年 SEO，不是你的市场预算大小。

发现不再是品牌，而是产品——这奖励了诚实、完整的产品描述。这正是 Wink 为你打造的。
