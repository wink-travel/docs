Wink 无需订阅、无席位限制且无设置费。平台绝大部分功能免费，您只需支付以下两项费用：

1. **每笔预订的平台费用，加上按成本收取的卡片处理费** — 仅在完成预订时收取。
2. **按使用量付费** — 针对少数每次使用都会产生成本的高级功能，每项功能均有免费月度额度。

## 免费内容

以下功能永久免费，无额度限制，无需计量：

- **预订引擎** — 可嵌入您自己的网站、WinkLinks 页面或其他任何地方。
- **物业管理** — 内容、照片、价格、价格计划、可用性、促销和政策。
- **联盟工具** — 可分享链接、精选列表、网格、地图、卡片和可嵌入小部件。
- **旅行社工具** — 搜索、定制价格及代表客户预订。
- **WinkLinks** — 认领您的专属网址，构建页面并随时发布。
- **手动社交发布** — 您自己撰写的任何内容，发布到任何已连接的网络。
- **分析、排行榜、索赔、设置**及账户管理。
- **消费者和预订引擎 API**，以及查询和自动完成端点。

## 预订

Wink 支持两种模式：Wink 代酒店收款，或持牌旅行社作为商户。

### 模式 1 — Wink 代酒店收款

Wink 作为酒店的有限支付收款代理，代酒店收取客人付款。酒店为商户，酒店名称显示在客人信用卡账单上。
此模式适用于 95% 的预订。

#### 费用明细

:::note[平台费用]
Wink 对每笔预订收取 1.5% 的平台费用。此费用用于平台维护，支持我们免费提供上述所有功能。取消预订不收取此费用。
:::

:::note[卡片处理费]
收取客人付款的支付处理费按成本转嫁给酒店，无任何利润。费用因客人卡片和支付方式不同而异，具体金额显示在每笔预订的会计部分。若预订取消或退款，处理器保留的费用仍需支付；若无费用，则我们也不收取。
:::

:::note[资金发放]
将资金发送到您的账户会产生费用，具体取决于您选择的发放方式。我们目前支持：

- **银行转账** — 费用取决于您所在国家、资金来源地及任何货币转换。支付费用和转换成本由收款方按成本支付。账户中有可用资金时，我们提供报价计算器供您使用。

如需支持其他支付方式，请发送邮件联系我们。
:::

### 模式 2 — 旅行社作为商户

此模式仅适用于持有本地区旅行社执照且希望作为商户的旅行社。一些注册旅行社希望负责支付处理及向酒店发放资金。此模式下，旅行社负责资金并持有必要的运营执照。

#### 费用明细

:::note[平台费用]
Wink 对每笔预订收取 1.5% 的平台费用。此费用用于平台维护，支持我们免费提供上述所有功能。
:::

采用此模式，旅行社仅支付 Wink 平台费用，Wink 将按月向旅行社开具发票。

### 发布内容的计费方式

发布内容按其包含的内容计费，因为这决定了我们的成本。静态图片成本低，视频成本高；AI 生成的内容成本远高于您自己提供的照片。

- **免费额度仅涵盖标准图片发布。** 每账户每月可免费发布一条。视频发布和 AI 生成媒体从第一条开始计费——无免费额度，因此发布视频的物业首月即会产生费用。
- **视频优先计费。** 只要发布内容包含任何视频，整条内容按视频费率计费。图片和视频混合发布视为视频发布。
- **AI 来源决定计费等级。** 您提供的媒体（自有照片、视频或 Wink 内容库）按标准费率计费。我们为您生成的媒体按 AI 费率计费。

### 计量范围

- 仅对发布到第三方网络（Facebook、Instagram）的**生成内容**计费。您自己撰写的发布内容免费，无论发布到哪里。
- **发布到 WinkLinks 始终免费**，无论是否生成内容。
- 计费发生在**发布时**，而非尝试时。反复生成草稿直到满意不会增加费用——您只为最终发布的内容付费。尝试次数有限制：图片发布约允许 10 次重生成，视频发布约 3 次，反映了我们的制作成本。您在操作时会看到剩余次数。
- 合作伙伴 API 中，**酒店-天**指一间酒店一晚住宿的价格——*不是*一次 API 调用。一次返回 20 家酒店、3 晚住宿的搜索计为 60 酒店-天。查询和自动完成端点免费且不计量。

### 如何启用

按使用付费默认关闭。所有用户均可享受免费额度，无需操作。

要超出免费额度，**账户所有者**需启用按使用付费，并选择计量的账户。所有启用账户的使用量合并为**单一月度发票**，您可选择自动刷卡结算或自行支付发票。

启用后，您的使用量会被计量，但**绝不会限速**——您不会因消费而触发速率限制。

:::note[如果您不启用]
不会出现故障，也不会收费。您只会停留在当月免费额度：生成内容将无法发布，合作伙伴 API 调用会返回 `429`，直到额度重置。
:::
