Wink 无需订阅、无座位费且无设置费。平台绝大部分功能免费，您只需支付以下两项费用：

1. **每笔预订的平台费用，加上按成本收取的卡片处理费** — 仅在完成预订时收取。
2. **按使用量付费** — 针对少数每次使用都会产生成本的高级功能，每项功能均有免费月度额度。

## 免费内容

以下功能永久免费，无额度限制，无需计量：

- **预订引擎** — 可在您自己的网站、WinkLinks 页面或任何嵌入位置使用。
- **物业管理** — 内容、照片、价格、价格计划、可用性、促销和政策。
- **联盟工具** — 可分享的链接、精选列表、网格、地图、卡片和可嵌入的小部件。
- **旅行社工具** — 搜索、定制价格及代表客户预订。
- **WinkLinks** — 认领您的专属网址，构建页面并随时发布。
- **手动社交发布** — 您自己撰写的任何内容，发布到任何已连接的网络。
- **分析、排行榜、索赔、设置**及账户管理。
- **消费者和预订引擎 API**，以及查询和自动完成端点。

## 预订

Wink 支持两种模式：Wink 代酒店收款，或持牌旅行社作为商户。

### 模式 1 — Wink 代酒店收款

Wink 作为酒店的有限收款代理，代客人收取付款。酒店为商户，酒店名称显示在客人的信用卡账单上。
此模式适用于 95% 的预订。

#### 费用明细

:::note[平台费用]
Wink 对每笔预订收取 1.5% 的平台费用。此费用用于平台维护，支持我们免费提供上述所有功能。取消预订不收取此费用。
:::

:::note[卡片处理费]
收取客人付款的支付处理费按成本转嫁给酒店，无加价。费用因客人卡片和支付方式不同而异，具体金额显示在每笔预订的会计部分。若预订取消或退款，处理方保留的费用仍需支付；若无费用，则我们也不收取。
:::

:::note[资金发放]
将资金发送到您的账户会产生费用，具体取决于您选择的发放方式。我们目前支持：

- **银行转账** — 费用取决于您所在国家、资金来源地及途中是否有货币兑换。支付费用和兑换费用由收款方按成本支付。账户中有可用资金时，我们提供报价计算器供您使用。

如需支持其他支付方式，请发送邮件联系我们。
:::

### 模式 2 — 旅行社作为商户

此模式仅适用于持有本地区旅行社执照且希望作为商户的旅行社。一些注册旅行社希望负责付款处理及向酒店发放资金。此模式下，旅行社负责资金并持有必要的运营执照。

#### 费用明细

:::note[平台费用]
Wink 对每笔预订收取 1.5% 的平台费用。此费用用于平台维护，支持我们免费提供上述所有功能。
:::

采用此模式，旅行社仅支付 Wink 的平台费用，Wink 会按月向旅行社开具发票。

### 帖子计费方式

帖子按内容计费，因为内容制作成本不同。静态图片成本低，视频成本高，AI 生成的内容成本明显高于您自己提供的照片。

- **免费额度仅涵盖标准图片帖子。** 每账户每月可免费发布一条。视频帖子和 AI 生成媒体从第一条开始计费——无免费额度，因此发布视频的物业首月即会产生费用。
- **视频优先计费。** 帖子中包含任何视频内容，整条帖子按视频费率计费。图片和视频混合的帖子视为视频帖子。
- **AI 来源决定计费等级。** 您提供的媒体（自有照片、视频或 Wink 内容库）按标准费率计费。我们为您生成的媒体按 AI 费率计费。

### 计量范围

- 仅**发布到第三方网络（Facebook、Instagram）且由 AI 生成的帖子**计费。您自己撰写的帖子无论发布到哪里均免费。
- **发布到 WinkLinks 始终免费**，无论是否生成。
- 计费在**发布时**发生，不按尝试次数计费。反复生成草稿直到满意不会增加费用——您只为最终发布的帖子付费。尝试次数有限制：图片帖子约 10 次，视频帖子约 3 次，反映了我们的制作成本。您在操作时会看到剩余次数。
- 合作伙伴 API 中，**一晚酒店住宿**指一间酒店一晚的价格——*不是*一次 API 调用。一次搜索返回 20 家酒店、3 晚住宿即为 60 晚酒店住宿。内容和查询（目的地搜索和自动完成）调用各计一单位，无论返回多少。账户端点免费。

### 启用方式

按使用付费默认关闭。所有用户均可享受免费额度，无需操作。

若需超出免费额度，**账户所有者**需启用按使用付费并选择计费账户。所有启用账户的使用量合并为**单一月度发票**，可自动用卡结算或自行支付发票。

启用后，使用量会被计量但**绝不限制速度**——您不会因消费而遇到速率限制。

:::note[未启用时]
不会出现故障，也不会收费。您仅限于当月免费额度：生成的帖子无法发布，合作伙伴 API 调用返回 `429`，直到额度重置。
:::
