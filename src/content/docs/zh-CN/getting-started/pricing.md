Wink 无需订阅、无席位限制且无设置费。平台绝大部分功能永久免费，您只需为以下两项支付费用：

1. **每笔预订收取少量百分比费用** — 仅在您实际盈利时收取。
2. **按使用量付费** — 针对少数每次运行都会产生成本的高级功能，每项功能均有免费月度额度。

## 免费内容

以下功能永久免费，无额度限制，无计量：

- **预订引擎** — 可嵌入您自己的网站、WinkLinks 页面或其他任何地方。
- **物业管理** — 内容、照片、价格、价格计划、可用性、促销和政策。
- **联盟工具** — 可分享链接、精选列表、网格、地图、卡片和可嵌入小部件。
- **旅行社工具** — 搜索、定制价格及代表客户预订。
- **WinkLinks** — 认领您的专属网址，构建页面并随时发布。
- **手动社交发布** — 您自己撰写的任何内容，发布到任何已连接的网络。
- **分析、排行榜、索赔、设置**及账户管理。
- **消费者和预订引擎 API**，以及查询和自动完成端点。

## 预订

Wink 支持商户模式和代理模式。

### 模式 1

预订发生时，Wink 是商户记录方。Wink 负责资金并持有所有必要的旅行社经营许可证。
此模式适用于 95% 的所有预订。

Wink 收取 `每笔预订 5.5%` 的费用以维护平台。
其中大部分支付给支付网关（Visa、MasterCard 等）。平均每笔预订的收单成本为 `2.95%`，有时高达 `3.6%`。部分退款会进一步增加成本，因为支付网关将其视为新收费。
我们希望现在就完全透明地说明定价，以节省大家在使用 Wink 之前谈判折扣的时间。我们的定价模式非常公平，我们也需要维持运营。

#### 费用明细

:::note[处理费]
Wink 对每笔预订收取 1.5% 的处理费。此费用用于平台维护，也是我们能免费提供上述所有功能的原因。
:::

:::note[支付费]
TripPay 对每笔预订收取 4.0% 的支付费。此费用用于收取旅客的付款。
:::

:::note[资金发放]
将资金发送到您的账户会产生费用，具体取决于您选择的发放方式。我们目前支持：

- **银行转账** 费用取决于您所在国家及资金来源地。账户中有可用资金时，我们提供报价计算器供您使用。

如果您希望我们支持其他支付方式，请发送电子邮件联系我们。
:::

### 模式 2

此模式仅适用于持有本地区旅行社许可证且希望成为商户记录方的旅行社。部分注册旅行社希望负责付款处理及向酒店发放资金。在此模式下，他们负责资金并持有在其国家运营所需的许可证。

#### 费用明细

:::note[处理费]
Wink 对每笔预订收取 1.5% 的处理费。此费用用于平台维护，也是我们能免费提供上述所有功能的原因。

采用此模式，旅行社仅支付 Wink 的处理费，Wink 会按月向旅行社开具发票。

### 帖子计费方式

帖子按内容计费，因为制作成本不同。静态图片成本低；视频成本高；AI 生成的内容成本远高于您自己提供的照片。

- **免费额度仅涵盖标准图片帖子。** 每个账户每月可免费发布一条。视频帖子和 AI 生成媒体从第一条开始计费——因此发布视频的物业首月即会产生费用。
- **视频优先计费。** 只要帖子包含任何视频，整条帖子按视频费率计费。图片和视频混合的帖子按视频帖子计费。
- **AI 来源决定计费等级。** 您提供的媒体——您自己的照片和视频，或 Wink 内容库中的素材——按标准费率计费。我们为您生成的媒体按 AI 费率计费。

### 计量范围

- 只有**生成的**帖子发布到第三方网络（Facebook、Instagram）时才计费。您自己撰写的帖子无论发布到哪里均免费。
- **发布到 WinkLinks 始终免费**，无论是否生成。
- 计费发生在**发布时**，而非每次尝试。反复生成草稿直到满意不会增加费用——您只为实际发布的帖子付费。尝试次数有限制：每条帖子允许约 10 次图片重生成和 3 次视频重生成，反映了我们的制作成本。您在操作时会看到剩余次数。
- 合作伙伴 API 中，**酒店-天**指一酒店一晚住宿的价格——*不是*一次 API 调用。一次返回 20 家酒店、3 晚住宿的搜索即为 60 酒店-天。查询和自动完成端点免费且不计量。
- 合作伙伴媒体 API 中，单位是一家酒店返回的所有媒体，无论照片和视频数量。一次批量请求 50 家酒店即计 50 单位——如果部分酒店无可见媒体，您只为实际返回媒体的酒店计费。

### 示例：OTA 缓存 90 天价格

假设您是 OTA、元搜索网站或旅游运营商，想获取 **1,000 家酒店**未来 90 天的价格，每家酒店发布 **4 个主价格**。

**一次完整刷新共计 90,000 酒店-天 — $9.00。**

计算方式为 1,000 家酒店 × 90 天。4 个主价格不额外收费：一次请求返回该日期范围内酒店发布的所有价格计划，价格计划数量不影响计费。请求分段也不影响计费——一次周期请求最多覆盖 30 天，您会对每家酒店发起 3 次请求，3 × 30 天计费与一次 90 天请求相同。您为请求的价格付费，而非请求方式。

所以每月费用取决于刷新频率：

| 刷新频率 | 酒店-天/月 | 超出 10,000 免费额度 | 月费用 |
| -- | -- | -- | -- |
| 每月一次 | 90,000 | 80,000 | **$8.00** |
| 每周一次 | 360,000 | 350,000 | **$35.00** |
| 每日一次 | 2,700,000 | 2,690,000 | **$269.00** |
| 每天两次 | 5,400,000 | 5,390,000 | **$539.00** |

每天刷新 1,000 家酒店共 3,000 次请求，约合每天 $9.00。免费额度 10,000 酒店-天/月，足够为约 110 家酒店定价 90 天，或构建测试完整集成而无需付费。

#### 影响费用的因素

- **逐个请求价格计划。** 周期请求一次返回所有房型的最佳价格。如果您每次请求只看一个价格计划，需发四倍请求，费用也翻四倍。
- **额外入住人数、货币或语言。** 1 成人价格和 2 成人价格是两个不同请求，分别计费。第二种显示货币或语言同理。
- **不必要的刷新频率。** 并非所有 90 天都需同样刷新频率。对未来 14 天每日刷新，15–90 天每周刷新，1,000 家酒店月费用为 **$71.40**，远低于 $269.00——近期价格波动较大，保持新鲜。

### 启用方式

按使用付费默认关闭。所有用户均享有免费额度，无需操作。

超出免费额度时，**账户所有者**需启用按使用付费并选择计量账户。所有启用账户的使用量合并计入**单张月度发票**，可自动刷卡结算或自行支付发票。

启用后，使用量计量但**绝不限制速率**——您不会因消费而触发速率限制。

:::note[未启用时]
不会出现故障，也不会收费。您仅停留在当月免费额度：生成的帖子无法发布，合作伙伴 API 调用返回 `429`，直到额度重置。
:::
