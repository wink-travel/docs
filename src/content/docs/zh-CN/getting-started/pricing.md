Wink 无订阅费、无席位费、无设置费。平台绝大部分功能永久免费，您只需为以下两项支付费用：

1. **每笔预订收取少量百分比费用** — 仅在您实际赚钱时收取。
2. **按使用量付费** — 针对少数每次运行都会产生成本的高级功能，每项功能均有免费月度额度。

## 免费内容

以下功能永久免费，无额度限制，无计量：

- **预订引擎** — 可嵌入您自己的网站、WinkLinks 页面或其他任何地方。
- **物业管理** — 内容、照片、价格、价格计划、可用性、促销和政策。
- **联盟工具** — 可分享链接、精选列表、网格、地图、卡片和可嵌入小部件。
- **旅行社工具** — 搜索、定制价格及代表客户预订。
- **WinkLinks** — 认领您的专属网址，构建页面并随时发布。
- **手动社交发布** — 您自己撰写的任何内容，发布到任何已连接的网络。
- **分析、排行榜、索赔、设置**及账户管理。
- **消费者和预订引擎 API**，以及查询和自动完成端点。

## 预订

Wink 支持商户模式和代理模式。

### 模式 1

预订发生时，Wink 是商户记录方。Wink 负责资金并持有所有运营旅行社所需的许可证。
此模式适用于 95% 的所有预订。

Wink 收取 `每笔预订 5.5%` 费用以维护平台。
其中大部分支付给支付网关（Visa、MasterCard 等）。平均每笔预订的获取成本为 `2.95%`，有时高达 `3.6%`。部分退款会进一步增加成本，因为支付网关将其视为新收费。
我们希望现在就完全透明地说明定价，以节省大家在使用 Wink 之前谈判折扣的时间。我们的定价模式非常公平，我们也需要维持运营。

#### 费用明细

:::note[处理费]
Wink 对每笔预订收取 1.5% 的处理费。此费用用于平台维护，也是我们能免费提供上述所有功能的原因。
:::

:::note[支付费]
TripPay 对每笔预订收取 4.0% 的支付费。此费用用于从旅客处收款。
:::

:::note[资金发放]
将资金发送到您的账户会产生费用，具体取决于您选择的发放方式。我们目前支持：

- **银行转账** 费用取决于您所在国家及资金来源地。账户中有可用资金时，我们提供报价计算器供您使用。

如果您希望我们支持其他支付方式，请发送电子邮件联系我们。
:::

### 模式 2

此模式仅适用于持有本地区旅行社许可证且希望成为商户记录方的旅行社。部分注册旅行社希望负责支付处理及向酒店发放资金。在此模式下，他们负责资金并持有在其国家运营所需的许可证。

#### 费用明细

:::note[处理费]
Wink 对每笔预订收取 1.5% 的处理费。此费用用于平台维护，也是我们能免费提供上述所有功能的原因。
:::

采用此模式，旅行社仅支付 Wink 的处理费，Wink 会按月向旅行社开具发票。

## 使用量（按使用付费）

少数功能每次运行都会产生成本——生成式 AI、第三方社交 API 以及大规模实时价格服务。您无需订阅可能不使用的月度套餐，只需为实际使用的部分付费，且在用完免费月度额度之前不收费。

| 功能 | 每月免费额度 | 之后费用 | 计费单位 |
| -- | -- | -- | -- |
| 社交发布 — 图片 | 1 | $1.50 | 每发布一条 |
| 社交发布 — AI 生成图片 | 0 | $2.50 | 每发布一条 |
| 社交发布 — AI 增强视频 | 0 | $4.00 | 每发布一条 |
| 社交发布 — AI 生成视频 | 0 | $14.00 | 每发布一条 |

| 聊天机器人回答 | 5 | $0.05 | 每回答一次 |
| 合作伙伴 API | 10,000 | $0.0001 | 每酒店-天 |

价格均以美元计。免费额度按**账户**授予，不按用户计算，每月 1 日（UTC）重置。

### 发布内容的计费方式

发布内容按其包含的内容计费，因为这决定了我们的成本。静态图片成本低；视频成本高；任何 AI 生成的内容成本远高于您自己提供的照片。

- **免费额度仅涵盖标准图片发布。** 每个账户每月可免费发布一条。视频发布和 AI 生成媒体从第一条开始计费——这些类别无免费额度，因此发布视频的物业应预期首月即产生费用。
- **视频优先计费。** 如果发布内容包含任何视频，则整条内容按视频费率计费。图片和视频混合发布视为视频发布。
- **AI 来源决定计费等级。** 您提供的媒体——您自己的照片和视频，或任何来自 Wink 内容库的素材——按标准费率计费。我们为您生成的媒体按 AI 费率计费。

### 计量范围

- 仅**生成的**发布内容发布到第三方网络（Facebook、Instagram）时计费。您自己撰写的发布内容无论发布到哪里均免费。
- **发布到 WinkLinks 始终免费**，无论是否生成。
- 计费发生在**发布时**，而非每次尝试。反复生成草稿直到满意不会增加费用——您只为实际发布的内容付费。尝试次数有限制：每条图片发布约允许 10 次重新生成，视频发布约 3 次，这反映了我们的制作成本。您在操作时会看到剩余次数。
- 合作伙伴 API 中，**酒店-天**指一个酒店一晚的价格——*不是*一次 API 调用。一次搜索返回 20 家酒店、3 晚住宿即为 60 酒店-天。查询和自动完成端点免费且不计量。

### 启用方式

按使用付费默认关闭。所有用户均可享受免费额度，无需操作。

要超出免费额度，**账户所有者**需启用按使用付费并选择计量的账户。所有启用账户的使用量合并为**单一月度发票**，您可通过信用卡自动结算或自行支付发票。

启用后，您的使用量将被计量但**绝不限制速率**——您不会因消费而遇到速率限制。

:::note[如果您不启用]
不会出现故障，也不会收费。您只会停留在当月免费额度内：生成的发布内容将无法发布，合作伙伴 API 调用会返回 `429`，直到额度重置。
:::
