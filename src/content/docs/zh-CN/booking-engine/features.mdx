预订引擎是库存变为可预订的地方。酒店在[Portal](/zh-CN/portal/overview)中列出他们的库存，合作伙伴也在那里将其转化为可分享的内容——然后预订引擎以合适的语言、货币和品牌向旅客展示这些内容，并完成预订。

它以网站形式公开，地址为 `https://book.wink.travel`，同样的功能也通过我们的[Web Components](/zh-CN/integrations/web-components)、[WordPress 插件](/zh-CN/integrations/wordpress)和[API](/zh-CN/api)向集成商提供。

## 一个引擎，多样呈现

只有一个预订引擎，位于 `https://book.wink.travel`。

<LinkButton href="https://book.wink.travel/home" variant="secondary" icon="external" target="_blank">
  打开预订引擎
</LinkButton>

它会根据销售方的不同进行适配。拥有多家酒店的合作伙伴会获得一个用于浏览和比较的主页。单一酒店则获得直接进入其库存的页面。物业管理公司则获得[他们所代表的酒店](/zh-CN/portal/settings/agency-representation)。这些都不是独立的网站或产品——而是您的[定制](/zh-CN/portal/settings/branding)告诉同一个引擎如何展示自己。

## 旅客能做什么

### 寻找可预订内容

- **按目的地搜索。** 查找城市、岛屿、国家或特定的酒店、餐厅、水疗、会议室、活动、景点或地点。
- **浏览排名集合。** 探索按会员价、价格、受欢迎度、环保评级、体验、优惠、忠诚度或附加服务排序的库存——可全球或限定在某个城市、岛屿或国家。
- **筛选结果**，按名称、半径、生活方式、星级和仅限直销库存。
- **设置行程**——入住和退房日期、成人数、儿童及其年龄、多个房间同时预订，以及促销代码。价格表格实时更新。

详情请见[搜索](/zh-CN/booking-engine/search)。

### 评估酒店

每个酒店都有自己的落地页，包含照片画廊、本地化描述、地图、设施、星级和客人评分、我们的 Greendex 环保评级、客人评论，以及酒店的餐厅、水疗、活动、景点、会议室和旅行提醒。

详情请见[酒店详情](/zh-CN/booking-engine/property-detail)。

### 组合住宿并预订

- **选择房型和价格方案**，明确标注可退款和不可退款选项。
- **查看每个价格方案附带的优惠**——包括保证的和视供应情况而定的。
- **一次添加多个房间**并调整数量。
- **添加酒店附加服务和套餐**，包括按日期和时间安排的定时附加服务。
- **实时查看总价更新**，含每间房价格明细及相较公开价格的节省。
- **通过嵌入的安全支付组件结账付款**。根据酒店的支付账户支持，提供信用卡、钱包和本地支付方式。

详情请见[结账](/zh-CN/booking-engine/checkout)。

### 预订后管理

- **查看确认信息**，含预订代码，立即显示并通过邮件发送。
- **无需登录即可打开预订**——通过邮件发送的预订链接适用于未创建账户的客人。
- **查看完整预订信息**：取消政策、支付状态、已支付金额及方式、额外费用和酒店联系方式。
- **执行操作**：复制预订代码、分享预订、添加到日历、打印、下载收据、带理由取消或在取消期限外申请退款。
- **入住合格后撰写评价**。
- **查看分组的行程**，当一次旅行产生多个预订时。

详情请见[预订](/zh-CN/booking-engine/bookings)和[预订确认](/zh-CN/booking-engine/confirmation)。

### 个性化体验

- **随时切换语言和货币**，支持40多种语言和160多种货币。
- **通过 Wink 单点登录一次登录**。登录后返回时，旅客会回到之前所在的页面，包括结账中途。
- **保持旅行档案**——本地偏好、紧急联系人、过敏信息、宠物、无障碍需求，以及酒店、房型、饮食和个人偏好——并选择是否与预订的酒店共享。
- **通过链接或二维码分享酒店**，支持十五个社交和消息网络。

详情请见[旅行偏好](/zh-CN/booking-engine/travel-preferences)。

## 旅客如何进入预订引擎

大多数情况下无需直接链接到预订引擎。您在[Portal](/zh-CN/portal/overview)中构建的所有内容——链接、卡片、网格和地图——以及您在[WinkLinks](/zh-CN/portal/link-manager/wink-links)发布的任何内容，都已携带您的客户ID、合作伙伴ID和品牌，能将旅客引导到正确的页面，且行程已预填。

| 您分享的内容 | 旅客落地位置 |
| --- | --- |
| [可分享链接](/zh-CN/portal/studio/shareable-links) | 一个短的 `trvl.as` URL，展开后是带有品牌的酒店落地页，预先应用您的行程、货币和语言。适合作为 Facebook、X、WhatsApp 或其他任何支持 URL 的平台的帖子。 |
| [卡片](/zh-CN/portal/studio/cards) | 单个可预订的供应商或库存项——酒店、房型、水疗、餐厅。`预订`按钮打开预订流程；`最佳优惠`和`酒店详情`链接到酒店页面。 |
| [网格](/zh-CN/portal/studio/grids) | 由精选列表、保存的搜索或实时排名搜索构建的分页卡片集合。每张卡片的预订方式相同。 |
| [地图](/zh-CN/portal/studio/maps) | 交互式地图，标记点打开可预订卡片。 |
| [WinkLinks](/zh-CN/portal/link-manager/wink-links) | 您的链接主页，托管上述任意组合。Instagram 两步直达预订。 |
| [立即预订按钮](/zh-CN/guides/hoteliers/the-book-now-button) | 您自己网站的按钮，指向自动生成的酒店链接，URL 参数包含日期、房型配置、语言、货币和促销代码。 |
| [Web Components](/zh-CN/integrations/web-components) | 直接在您的页面嵌入卡片、网格、地图、搜索和行程选择器。预订要么跳转到引擎，要么在模态窗口中打开，由您选择。 |
| [WordPress 插件](/zh-CN/integrations/wordpress) | 以 WordPress 短代码形式提供相同组件，支持 Gutenberg、Elementor、Avada 和 WPBakery。 |
| [API](/zh-CN/api) | 远程旅行代理系统和渠道管理器的直接集成。 |

无论旅客通过哪条路径进入，发送他们的合作伙伴都会被记录以便归因——且归因持续180天，因此后续访问产生的预订仍会归功于介绍该旅客的合作伙伴。

## 白标化

预订引擎设计为隐形于您的品牌之下。

最轻度的定制是通过[定制](/zh-CN/portal/settings/branding)重新设计引擎，使其呈现为您的品牌：您的名称、标志、颜色、字体。旅客仍然访问 `book.wink.travel`。

最深度的定制是**合作伙伴可以在自己的域名上运行预订引擎**。将您的域名指向预订引擎，它会自动根据主机名解析您的定制——URL 中无客户ID或配置ID，地址栏无 Wink 域名。旅客从搜索到确认都看到 `book.yourbrand.com`。

:::note[设置您自己的域名]
自定义域名需我们协助设置，非自助服务。请[联系我们](/zh-CN/contact)提供您想使用的域名，我们将帮您配置并连接到您的定制。
:::

## 定制内容

以下所有内容均按定制设置，您可以保留多个定制——每个市场、每个活动或每个酒店一个。

**身份**

- 显示名称和标语，附加在页面标题后。
- 标志，包括预订邮件的独立标志。

**外观和感觉**

- 十一色调色板：主色、次色、成功色、危险色、警告色、信息色、浅色、深色、正文色、弱化色和白色。
- 字体，从二十种精选字体中选择。
- 页面布局——信息型或交易型——重塑主页、页眉和酒店页面。
- 卡片布局——垂直网格或水平列表。
- 搜索栏、排名徽章和不可用酒店卡片的开关。

在下面的开发者沙箱中试用主题定制。

<LinkButton href="https://developer.wink.travel/web-component" variant="secondary" icon="external" target="_blank">
  主题定制
</LinkButton>

**旅客默认落地**

- 默认语言和货币。
- 预设行程——固定日期或滚动窗口，如“30天后，2晚”。
- 默认房型配置和促销代码。
- 目的地选择器的默认城市。

**测量和集成**

- 您自己的 Google Analytics 4 测量ID、Google Tag Manager 容器和跟踪像素，与 Wink 并行运行。
- 您自己的 Google Maps API 密钥。
- 控制预订通知邮件是否发送给酒店、预订者和渠道经理。
- 控制嵌入组件的 `预订` 按钮是跳转到预订引擎还是在模态窗口中打开。

字段级详细说明，请参见[定制](/zh-CN/portal/settings/branding)和[定制您的预订体验](/zh-CN/guides/general/customizing-your-booking-experience)。

## 直接链接

如果您想手动链接到预订引擎，请在 URL 中添加您的客户ID和定制ID作为参数。两者均在您正在使用的[账户](/zh-CN/portal/overview)中——无论该账户是酒店、管理公司还是合作伙伴。

### 查找您的客户ID

<Steps>
1. 从[账户](https://app.wink.travel)中选择您要操作的账户。
2. 点击账户卡底部的 `操作`，选择 `管理账户`。
3. 在接下来的页面点击 `应用` 标签。
4. 复制您想使用的应用的客户ID，并作为请求参数粘贴到 URL 中。例如：?client-id=MY_CLIENT_ID
</Steps>

更多关于创建和管理应用的信息，请参见[应用](/zh-CN/account/applications)。

### 查找您的定制ID

<Steps>
1. 从[账户](https://app.wink.travel)中选择您要操作的账户。
2. 点击账户卡底部的 `操作`，选择 `管理账户`。
3. 在接下来的页面点击 `定制` 标签。
4. 复制您想使用的定制的定制ID，并作为请求参数粘贴到 URL 中。例如：?configuration-id=MY_CUSTOMIZATION_ID
</Steps>

完整的定制控制内容，请参见[定制](/zh-CN/portal/settings/branding)。

### 组合链接

链接到主页时，URL 形如：

https://book.wink.travel?client-id=MY_CLIENT_ID&configuration-id=MY_CUSTOMIZATION_ID

主页带有您的品牌，显示您账户所代表的库存——您自己的酒店、您管理的酒店，或您的完整合作伙伴目录。

若要直接发送旅客到特定酒店，请链接到其落地页：

https://book.wink.travel/hotel/hotel-x?client-id=MY_CLIENT_ID&configuration-id=MY_CUSTOMIZATION_ID

:::note
如果省略客户ID或定制ID，预订引擎仍会加载，但会回退到默认配置——旅客看到默认品牌，且预订不会归因于您。请务必同时包含两者。
:::
