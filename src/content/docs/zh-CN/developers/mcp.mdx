Wink 提供两个经过身份验证的 MCP 服务器。两者均使用**交互式 OAuth2 登录**（PKCE 授权码流程）— 您的 AI 代理会打开浏览器标签页，您使用 Wink 账户登录。无需管理客户端密钥。

| 服务器 | URL | 功能说明 |
|--------|-----|----------|
| **Inventory API** | `https://api.wink.travel/mcp` | 库存、预订、价格、销售渠道、分析及所有平台操作 |
| **Integrations** | `https://integrations.wink.travel/mcp` | 渠道管理集成 — 与 OTA 同步物业、价格和可用性 |

---

## 身份验证工作原理

Wink MCP 服务器使用**OAuth2 授权码 + PKCE**流程，并支持**动态客户端注册（RFC 7591）**。首次连接时发生以下步骤：

1. 您的 AI 客户端从 MCP 端点的 `/.well-known/oauth-protected-resource` 元数据中发现授权服务器。
2. 客户端通过**动态客户端注册**自助注册 — 无需手动设置应用。
3. 客户端打开一个指向 `https://iam.wink.travel` 的**浏览器标签页**。您使用 Wink 账户登录，并在同意屏幕上批准请求的权限。
4. Wink 签发一个与您的身份关联、作用域限定于您的账户的**访问令牌**。
5. AI 客户端将令牌附加到每个 MCP 请求。所有工具结果自动限定于您的管理实体。
6. 令牌在 3 小时后过期。您的 AI 客户端会在后台静默刷新，无需再次提示。

每个工具调用均**以您的身份运行** — 保护 Web 门户的相同访问控制规则同样适用于 AI 代理。

## 连接您的 AI 客户端

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. 确保 Claude Code 是最新版本：
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. 添加 Wink Inventory MCP 服务器：
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code 联系服务器，发现授权服务器，并打开默认浏览器。

4. **登录 Wink** 并在同意屏幕上批准权限请求。

5. Claude Code 确认连接。输入 `/mcp` 验证服务器是否出现且工具已加载。
</Steps>

要同时添加 Integrations 服务器：
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[与团队共享]
在 `claude mcp add` 命令中添加 `--scope project`，Claude Code 会将服务器 URL 写入仓库根目录的 `.mcp.json` 文件。提交该文件 — 每个团队成员首次连接时完成自己的浏览器登录。
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. 编辑 Claude Desktop 配置文件：
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. 添加 MCP 服务器条目：

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **完全退出并重启** Claude Desktop（使用菜单栏的退出，关闭窗口不够）。

4. Claude Desktop 会为每个新服务器打开浏览器标签页。登录 Wink 并批准权限。

5. 底部工具栏的插头图标显示两个服务器均已连接。
</Steps>

  </TabItem>
  <TabItem label="OpenAI Codex">

<Steps>
1. 确保已安装 Codex CLI：
   ```bash
   npm install -g @openai/codex
   ```

2. 打开（或创建）Codex 配置文件：
   - **macOS / Linux:** `~/.codex/config.json`
   - **Windows:** `%USERPROFILE%\.codex\config.json`

3. 添加 Wink MCP 服务器条目：

   ```json title="~/.codex/config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

4. 启动 Codex。首次使用时，Codex 会打开浏览器标签页指向 `https://iam.wink.travel`。

5. **登录 Wink** 并批准请求的权限。

6. Codex 确认连接。运行 `codex` 并请求列出可用工具，验证 Wink 服务器已激活。
</Steps>

:::note
Codex CLI MCP 支持需要版本 **1.0** 或更高。运行 `codex --version` 检查，使用 `npm install -g @openai/codex` 升级。
:::

  </TabItem>
  <TabItem label="ChatGPT">

MCP 服务器支持适用于 Plus、Pro、Team 和 Enterprise 订阅用户的**ChatGPT 桌面应用**。

<Steps>
1. 如果尚未安装，请下载并安装 [ChatGPT 桌面应用](https://openai.com/chatgpt/download/)。

2. 打开应用，点击右上角的**个人资料图标**，然后选择**设置**。

3. 进入**连接器**（或根据应用版本为**MCP 服务器**），点击**添加**。

4. 输入 Wink Inventory 服务器 URL：
   ```
   https://api.wink.travel/mcp
   ```
   然后点击**连接**。

5. ChatGPT 会打开浏览器标签页指向 `https://iam.wink.travel`。**登录 Wink** 并批准权限。

6. 对 Integrations 服务器重复步骤 4–5：
   ```
   https://integrations.wink.travel/mcp
   ```

7. 两个服务器都会出现在您的连接器列表中。开始新聊天 — Wink 工具会自动可用。
</Steps>

:::note[网页版限制]
MCP 服务器仅可在**桌面应用**中配置。ChatGPT 网站界面（chatgpt.com）不支持自定义 MCP 服务器。
:::

  </TabItem>

<Steps>
1. 打开（或创建）Cursor MCP 配置文件：
   - **macOS / Linux:** `~/.cursor/mcp.json`
   - **Windows:** `%USERPROFILE%\.cursor\mcp.json`

2. 添加 Wink MCP 服务器条目：

   ```json title="~/.cursor/mcp.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. 打开 Cursor。进入**设置 → Cursor 设置 → MCP**，确认两个服务器均显示绿色状态指示。如果显示红色，点击**刷新**。

4. Cursor 会打开浏览器标签页指向 `https://iam.wink.travel`。**登录 Wink** 并批准权限。

5. 打开聊天（`Ctrl+L` / `Cmd+L`），请求 Cursor 列出可用的 Wink 工具以确认连接。
</Steps>

:::tip[项目范围配置]
您也可以将 `mcp.json` 文件放置在项目根目录，而非 `~/.cursor/`。项目级配置优先，且使所有打开该项目的团队成员均可使用服务器。
:::

## 权限范围参考

在您批准同意屏幕时，会看到代理请求的权限细分。Wink 按功能区域分组权限：

| 权限组 | 权限范围 | 解锁功能 |
|-------------|--------|-----------------|
| **MCP 传输** | `mcp.read` `mcp.write` `mcp.remove` | 连接任一 MCP 服务器所需 |
| **账户** | `account.read` `account.write` `account.remove` | 管理实体、团队成员、设置、应用 |
| **预订** | `booking.read` `booking.write` `booking.remove` | 搜索、查看、创建、取消和退款预订 |
| **库存** | `inventory.read` `inventory.write` `inventory.remove` | 物业、房型、价格、设施、可用性 |
| **分析** | `analytics.read` | 预订分析、收入报告、排行榜 |
| **营销** | `marketing.read` `marketing.write` `marketing.remove` | 社交帖子、活动、销售渠道、促销 |
| **内容** | `content.read` `content.write` `content.remove` | 多媒体、短链接、可联合发布项目、地图 |
| **支付** | `payment.read` `payment.write` | 账本、支付、财务明细、提现 |

AI 客户端仅请求所需权限。您可以在同意屏幕上拒绝单个权限 — 需要被拒权限的工具调用时会返回错误。

## 故障排除

**浏览器标签页未打开**

您的 AI 客户端可能尚不支持交互式 PKCE 流程。请确认您使用的是最新版本：
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT 桌面:** 通过应用内置更新器更新

**登录后出现 `401 Unauthorized`**

您的缓存令牌可能已过期。删除并重新添加服务器以触发新的登录：

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

对于 Claude Desktop 和 ChatGPT，从设置中删除服务器条目，重启应用，然后重新添加。

**调用特定工具时出现 `403 Forbidden`**

该工具需要您在同意屏幕上未批准的权限。重新连接服务器 — 同意屏幕会再次出现，您可以批准缺失的权限。

**服务器出现但工具调用返回“账户未找到”**

您登录的 Wink 账户没有管理实体。请访问 [Wink Portal](https://app.wink.travel) 并确保账户已设置后再使用 MCP 服务器。

**令牌在会话中途过期**

令牌有效期为 3 小时。Claude Code 和 Claude Desktop 会静默刷新令牌，不会中断会话。如果长时间空闲后出现认证错误，输入新消息 — 客户端会自动重新认证。

**Codex CLI 显示“MCP 服务器无法访问”**

检查您的 `~/.codex/config.json` 是否为有效 JSON（无尾随逗号），且 `"type": "http"` 已设置。Codex 远程服务器需使用 HTTP 传输；stdio 传输仅限本地二进制。

**ChatGPT “连接器”菜单缺失**

MCP 支持需要 ChatGPT 桌面应用版本 **1.2024.352** 或更高，且需 Plus、Pro、Team 或 Enterprise 订阅。更新应用并在设置 → 账户中确认订阅状态。

**Cursor 服务器显示红色 / “连接失败”**

确认您的 `~/.cursor/mcp.json` 是有效 JSON 并包含 `"type": "http"`。然后进入**设置 → Cursor 设置 → MCP**，点击**刷新**。若错误持续，完全重启 Cursor — 配置更改有时需重启才能生效。

**Windsurf MCP 服务器未在设置中列出**

Windsurf 需完全重启（非仅重载窗口）以加载 `mcp_config.json` 的更改。使用**文件 → 退出**并重新启动。若服务器仍未出现，确认您使用的是 Windsurf **1.4+**，通过**帮助 → 关于 Windsurf**查看。

**Cline “添加服务器”选项不可见**

MCP 服务器管理器需要 Cline **2.0** 或更高版本。打开 VS Code 扩展面板，找到 Cline，若有更新，点击**更新**。更新后重载 VS Code（`Ctrl+Shift+P` → “开发者：重载窗口”）。
