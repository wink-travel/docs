Wink 的 MCP 工具以**工具集**形式发布——专注的端点，每个覆盖一个任务。您将 AI 客户端连接到与您的工作匹配的一两个端点，而非全部。

每个端点都使用**交互式 OAuth2 登录**（PKCE 授权码流程）：您的 AI 代理打开浏览器标签页，您使用 Wink 账户登录，仅此而已。无需管理客户端密钥。

```bash title="渠道管理集成商连接到一个端点"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="酒店业主管理自己的价格连接到另一个端点"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## 为什么工具分布在多个端点

Wink 公开了大约 500 个工具。一次性交给代理所有工具在技术上可行——但这是个坏主意。

**工具定义占用上下文。** MCP 服务器广告的每个工具都会在模型执行任何工作前加载到上下文窗口中，包括其描述和完整参数架构。五百个工具会占用您实际任务所需预算的大部分，每次请求都如此。

**列表越长，选择质量越差。** 代理从 500 个名称相似的工具中选择，做出的选择比从 40 个中选择要差。如果您集成渠道管理，大约二十个工具与您相关；其余 480 个是噪音，使正确工具更难找到。

**工作确实可以分离。** 同步 PMS 可用性的人和策划联盟落地页的人几乎不共享工具。按任务拆分意味着每个连接只携带一个任务的词汇。

<Aside type="caution" title="工具集不是权限">
选择狭窄的工具集**不会**限制您的账户权限，选择广泛的工具集也不会授予额外权限。每个工具都在您登录身份下执行与网页版门户相同的账户权限。如果您的账户无法在 Wink 门户取消预订，代理也无法——无论连接哪个端点。

选择工具集是为了**专注**，而非安全。
</Aside>

### `https://integrations.wink.travel` — 渠道管理集成

一个端点，因为该主机只为一个任务存在。

| 端点 | 工具数 | 覆盖内容 |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | 连接和验证渠道管理、PMS 或 CRS 集成 |

<Aside type="note" title="集成渠道管理与管理自有价格">
这些是不同人员的不同任务，且不共享端点。

**渠道管理、PMS 或 CRS 供应商** 通过 `integrations.wink.travel/mcp/channel-manager` 集成一次，之后通过该集成交换物业、价格、可用性和预订。该单一端点即为全部接口。

**酒店业主手动更改自有价格** 使用 `api.wink.travel` 上的外网工具集——`/mcp/extranet/rates` 等。这些不属于渠道管理集成，集成商无理由连接它们。

账户管理也在 `api.wink.travel`，路径为 `/mcp/settings`。集成主机上无 `/mcp/settings`。
</Aside>

每个端点还包含一个 `ping` 工具，您可以在请求实际工作前确认连接是否活跃。

## 我需要哪些工具集？

| 如果您是… | 连接到 |
|---|---|
| **集成渠道管理、PMS 或 CRS** | `integrations.wink.travel/mcp/channel-manager` — 仅此一个 |
| **管理物业内容** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **管理客房和房型** | `/mcp/extranet/facilities` |
| **管理价格和可用性** | `/mcp/extranet/rates` |
| **日常管理预订** | `/mcp/extranet/operations` |
| **拓展分销渠道** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **构建联盟页面** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **运营个人主页链接页** | `/mcp/link-manager` + `/mcp/social` |
| **代表旅客预订** | `/mcp/travel-agent` |
| **财务对账** | `/mcp/payment` |
| **构建预订体验** | `/mcp/booking-engine` + `/mcp/reference` |

从一个开始。当您发现它无法满足需求时，再添加另一个——每个连接独立，添加一个不会影响其他。

<Aside type="tip" title="仍想要全部工具？">
`https://api.wink.travel/mcp` 和 `https://integrations.wink.travel/mcp` 仍可用，提供其主机上的**所有**工具。它们适合探索现有工具，但不推荐日常使用：工具列表过大，会干扰任务并降低代理的工具选择质量。优先选择上述工具集。
</Aside>

## 认证工作原理

Wink MCP 服务器使用**OAuth2 授权码 + PKCE**流程，支持**动态客户端注册（RFC 7591）**。首次连接时发生：

1. 您的 AI 客户端从 MCP 端点的 `/.well-known/oauth-protected-resource` 元数据发现授权服务器。
2. 客户端通过**动态客户端注册**自助注册——无需手动申请。
3. 客户端打开浏览器标签页至 `https://iam.wink.travel`。您使用 Wink 账户登录并在同意屏幕批准请求权限。
4. Wink 签发与您的账户和身份关联的**访问令牌**。
5. AI 客户端将令牌附加到每个 MCP 请求。所有工具结果自动限定在您的管理实体范围内。
6. 令牌有效期为 3 小时。AI 客户端在后台静默刷新，无需再次提示。

每个工具调用均**以您的身份执行**——保护网页版门户的相同 ACL 规则适用于 AI 代理。

## 权限范围

在您批准同意屏幕时，会看到代理请求的权限细分。MCP
客户端使用与平台其他部分相同的权限词汇——详见
[认证页面的完整范围参考](/zh-CN/developers/authentication#scopes)。

MCP 特有两点：

- **`mcp.read`、`mcp.write`、`mcp.remove` 范围是打开 MCP 传输的额外必需权限。** 持有 `mcp.*` 范围的客户端可访问任何 Wink MCP 端点，但调用的每个工具仍执行其所属端点的分区权限（如 `booking.read`）。
- **AI 客户端仅请求所需权限。** 您可在同意屏幕拒绝单个权限——需要被拒权限的工具调用时会返回错误。

**工具集不改变这些。** 您连接的端点决定*列出*哪些工具，而非它们*被允许做什么*。连接 `/mcp/payment` 不会授予您未持有的财务权限，连接 `/mcp/reference` 也不会阻止该处工具执行自身权限。授权由每次工具调用基于您的令牌和账户权限决定。

## 故障排查

**浏览器标签页未打开**

您的 AI 客户端可能尚不支持交互式 PKCE 流程。确认您使用的是最新版本：
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT 桌面:** 通过应用内置更新器更新

**登录后出现 `401 Unauthorized`**

缓存的令牌可能已过期。删除并重新添加服务器以触发新登录：

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

对于 Claude Desktop 和 ChatGPT，从设置中删除服务器条目，重启应用，再次添加。

**调用特定工具时出现 `403 Forbidden`**

该工具需要您在同意屏幕未批准的权限范围，或账户缺少权限。重新连接服务器——同意屏幕会再次出现，您可批准缺失权限。若仍失败，说明工具需要您账户未持有的权限；连接其他工具集无效，因为工具集不授予权限。

**我需要的工具不在列表中**

您可能连接了不覆盖该任务的工具集。检查[端点目录](#endpoint-directory)，添加包含该工具的工具集——连接独立，添加一个不会影响其他。如果不确定哪个包含，临时连接 `https://api.wink.travel/mcp`，找到工具后查找其所属工具集。

**工具集端点返回 `404 Not Found`**

仔细检查路径——嵌套工具集有两个段（如 `/mcp/extranet/rates`，非 `/mcp/extranet-rates`），扁平工具集有一个段（如 `/mcp/link-manager`）。注意，未认证请求任何 `/mcp` 下路径返回 `401`，非 `404`，所以仅凭 `401` 无法判断端点是否存在。

**我连接了 `api.wink.travel/mcp/channel-manager` 但无响应**

该端点不存在。渠道管理集成仅由 `https://integrations.wink.travel/mcp/channel-manager` 提供。如果您还需手动读写物业自有价格，需连接另一个端点——见 `/mcp/extranet/rates`。

**服务器出现但工具调用返回“账户未找到”**

您登录的 Wink 账户无管理实体。请访问 [Wink Portal](https://app.wink.travel) 确认账户已设置后再使用 MCP 服务器。

**令牌在会话中期过期**

令牌有效期为 3 小时。Claude Code 和 Claude Desktop 会静默刷新令牌，不中断会话。长时间空闲后出现认证错误，输入新消息，客户端会自动重新认证。

**Codex CLI 显示“无法连接 MCP 服务器”**

检查 `~/.codex/config.json` 是否为有效 JSON（无尾随逗号），且 `"type": "http"` 已设置。Codex 远程服务器需 HTTP 传输，本地二进制用 stdio 传输。

**ChatGPT “连接器”菜单缺失**

MCP 支持需 ChatGPT 桌面应用版本 **1.2024.352** 或更高，且需 Plus、Pro、Team 或 Enterprise 订阅。更新应用并在设置 → 账户确认订阅。

**Cursor 服务器显示红色 / “连接失败”**

确认 `~/.cursor/mcp.json` 是有效 JSON 且含 `"type": "http"`。然后进入**设置 → Cursor 设置 → MCP**，点击**刷新**。若错误持续，完全重启 Cursor——配置更改有时需重启才能生效。

**Windsurf MCP 服务器未在设置中列出**

Windsurf 需完全重启（非仅重载窗口）以加载 `mcp_config.json` 变更。使用**文件 → 退出**后重新打开。若仍未显示，确认 Windsurf 版本为 **1.4+**，通过**帮助 → 关于 Windsurf** 检查。

**Cline “添加服务器”选项不可见**

MCP 服务器管理器需 Cline **2.0** 或更高版本。打开 VS Code 扩展面板，找到 Cline，若有更新，点击**更新**。更新后重载 VS Code（`Ctrl+Shift+P` → “开发者：重载窗口”）。
