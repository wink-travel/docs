本页列出了您可以在 Wink 上订阅的所有 webhook 事件。有关设置说明，请参见[Webhook 集成指南](/zh-CN/developers/webhook-integration)或[Webhook 管理页面](/zh-CN/portal/settings/webhooks)。

## 如何订阅

1. 在您的门户中导航至 **应用 > Webhooks**。
2. 创建一个 webhook 并选择您想接收的事件。
3. 每当事件发生时，Wink 会向您的端点发送 HTTP POST 请求。

有关完整的设置步骤和最佳实践，请参见[Webhook 集成](/zh-CN/developers/webhook-integration)。
