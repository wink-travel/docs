需求合作伙伴协议不允许将 Wink 供应的价格与“除明确允许外”的其他价格进行比较（第 11.3 条款）。本页说明 Wink 如何授予搜索展示权限，以及获得权限后您的展示必须遵守的规则。

## 什么是搜索展示

**搜索展示** 是指在响应用户搜索时，展示来自 Partner API 的酒店，与其他酒店优惠（包括来自其他来源的无偿替代选项）一起显示，并通过点击跳转打开所选酒店的 Wink 预订引擎，使用您的联盟账户。

它仅涵盖搜索、内容和点击跳转。通过 Partner API 创建、更改或取消预订需要 Wink 的单独书面批准。

## 每次展示的规则

- **实时价格。** 价格和可用性必须反映展示时的实时数据（第 8.2 条款）。
- **价格不变。** 按 Partner API 返回的价格原样展示，不得加价、附加费用或更改。酒店设定并控制其价格。
- **准确呈现。** 准确展示价格、包含内容和取消政策，不得改变其含义（第 6.1 条款）。
- **绝不将 Wink 作为卖方呈现。** 您的产品在视觉和结构上必须与 Wink 区分开，绝不自称为 Wink，也绝不将 Wink 呈现为独立的在线旅行社或卖方（第 7.4 条款）。住宿合同由旅客与酒店签订。
- **披露。** 在法律要求的情况下披露您与 Wink 的商业关系（第 6.2 条款）。
- **禁止转用。** 不得将 Wink 供应数据或内容转授权、转让或披露给任何其他人（第 11.3 条款）。

## 临时展示

Wink 不限制您持有搜索结果的时间，因为没人能预测价格何时变动：酒店可能五秒后或一年后更改价格。关键是您展示的价格和可用性必须与展示时的实时数据一致（第 8.2 条款）。每当行程变更时，或在展示您无法确定仍然有效的结果前，请再次从 Partner API 获取数据。

遵守这些规则的展示不属于第 7.5 条款中的“内容静态副本”，也不属于第 8.2 条款中的过期价格缓存。

## 缓存酒店内容

酒店内容（名称、描述、图片、设施和政策）缓存没有时间限制。使用 Partner API 中每个酒店的 `lastUpdate` 作为缓存键，内容变更时刷新缓存。

## 可保留的标识符

您可以保留以下标识符，仅限于此：

- Wink 酒店 ID 和酒店 `urlName`，
- 归属于您的预订参考号，
- 您自己的归属、客户和配置 ID，以及相关的点击和预订日期。

仅用于跨来源去重酒店列表，以及归属、报告和佣金核对。不得超出上述规则保留价格、可用性或酒店内容，也不得使用 Wink 的任何数据（包括这些标识符）来训练、微调或评估模型，或构建或改进供应数据库（第 7.5 和 10.6 条款）。

## 如何申请许可

搜索展示需要 Wink 的明确书面许可，以附函形式添加至您的需求合作伙伴协议。许可在附函和协议均被接受后生效，若违反上述规则，Wink 可提前通知或立即撤销许可。

申请时，请发送邮件至 [legal@wink.travel](mailto:legal@wink.travel)，内容包括：

- 您的产品名称，
- 如果已上线，请提供其 URL，
- 您计划如何使用 Wink 供应：展示内容、展示位置及与哪些内容一起展示。

我们将从此开始处理。
