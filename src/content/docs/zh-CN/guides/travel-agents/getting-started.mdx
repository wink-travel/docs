本指南带您从注册旅行社到完成首个客户预订。还将解释旅行社在 Wink 上的两种工作方式，帮助您在开始前选择合适的方式。

## 开始之前

您需要准备：

- 您的公司信息。
- 您的旅行社注册号，或如果有的话，IATA 代码。
- 用于收取佣金的银行账户。

## 选择您的工作方式

| | 标准方式（大多数旅行社） | 代理自行收款 |
|---|---|---|
| 预订方式 | 在 Wink 门户或通过 Partner API | 通过 [Partner API](/zh-CN/integrations/partner-api/)，从您自己的系统 |
| 谁收取客户付款 | 由酒店收取，酒店为商户。您在结账时输入客户的卡信息。 | 由您收取，您为商户。 |
| 您的收益 | 每笔预订的**默认 10% 佣金** | 您与每家酒店协议中的佣金比例 |
| 向 Wink 支付 | 无需支付 | 每笔预订金额的**1.5%**预订费，按月开票，另加超出免费额度的 Partner API 使用费 |
| 向酒店付款 | Wink 代为处理 | 您直接向每家酒店付款，依据您与酒店的协议 |
| 退款、拒付、支付合规 | Wink 代为处理 | 您负责 |
| 审核 | 注册审核通过后可预订 | 注册审核通过，且 Wink 书面批准此方式，并设有信用额度 |

Wink 会审核每个旅行社的注册信息。大多数旅行社采用标准方式。代理自行收款仅适用于**API 合作伙伴**：即通过 Partner API 从自有系统预订，且已根据自身许可收取客户付款并直接与酒店签约的旅行社。

## 第 1 步：注册您的旅行社

<Steps>
1. 访问 [app.wink.travel](https://app.wink.travel)，点击 `Sign-In / Register` 并注册。

2. 在左侧边栏点击 `Accounts`，然后点击 `Create`，选择 **I am a Travel Agent**。

3. 填写您的旅行社信息。选择 **Company** 作为实体类型，这决定您的付款方式。详见 [Create Account](/zh-CN/portal/create-account/)。

4. 如果您打算通过 Partner API 自行收款，请在注册时选择该方式。这是申请步骤，不是批准。详见[第 6 步](#step-6-collect-payment-yourself-api-partners-only)。

5. Wink 会审核每个旅行社注册。我们会发送邮件至您注册的地址，要求提供公司资料和旅行社注册号或 IATA 代码。注册审核通过后即可预订。
</Steps>

## 第 2 步：添加您的银行账户

进入 `Account > Bank Accounts`，添加您的旅行社账户并标记为**主要账户**。佣金将通过银行转账支付到该账户。Wink 通过 Revolut 发送付款，因此 Revolut 商业账户是最顺畅的选择，但任何银行账户均可。详见 [Bank Accounts](/zh-CN/portal/settings/payouts/)。

## 第 3 步：为客户寻找酒店

<Steps>
1. 在主导航栏点击 `Browse > Hotels`。

2. 按目的地、日期和入住人数搜索，并筛选出适合客户的选项。

3. 如果您与客户比较多个选项，可将短名单保存到[精选列表](/zh-CN/portal/studio/curated-lists/)。
</Steps>

您看到的价格是酒店自身价格。Wink 不做任何加价，您通过佣金获得收益。详见 [Search](/zh-CN/portal/studio/search/)。

## 第 4 步：为客户预订

<Steps>
1. 选择房型和价格，输入客户姓名和联系方式作为旅客信息。

2. 结账时，输入客户提供的用于本次预订的卡信息。付款由酒店收取，酒店为商户。

3. 确认预订。您、旅客和酒店都会收到确认邮件。预订代码以 `WNK` 开头。
</Steps>

:::caution[妥善保管客户的卡信息]
仅为当前预订索取卡信息，并直接输入结账页面。不要抄写、通过邮件发送或保存在您自己的记录中。
:::

## 第 5 步：管理预订并收取佣金

- **预订管理：** 点击主导航栏的 `Bookings` 查看所有预订，可筛选、导出 CSV、重新发送确认邮件或在酒店取消政策范围内取消。详见 [Bookings](/zh-CN/portal/travel-agent/bookings/)。
- **佣金：** 默认 10%。与酒店建立长期合作后，您可以申请[直接连接](/zh-CN/portal/studio/network/)并协商不同佣金比例。
- **付款时间：** 佣金在客人入住后 24 小时内到账，支付至您的主要银行账户。转账手续费按成本收取。详见 [Pricing](/zh-CN/getting-started/pricing/)。

## 第 6 步：自行收款（仅限 API 合作伙伴）

如果您在门户预订或满意标准方式，请跳过此步骤。

<Steps>
1. 集成 [Partner API](/zh-CN/integrations/partner-api/)。此方式仅通过 API，从您自己的预订系统操作，门户不支持。

2. 在注册时选择此方式（第 1 步）。

3. Wink 会结合您的注册资料（如财务状况和监管状态）进行评估，并书面确认。批准时会设定**信用额度**：您可持有的未结算预订最大金额。

4. 审批前，您可继续使用标准方式预订。
</Steps>

获批后，您自行收取客户付款，并直接向每家酒店付款。每笔预订按顺序扣除 1.5% Wink 费用和您的佣金，剩余金额支付给酒店：

| 以 1,000.00 美元预订，佣金 10% 为例 | |
|---|---|
| 预订金额 | 1,000.00 美元 |
| 扣除 Wink 费用（1.5% 预订金额） | 15.00 美元 |
| 小计 | 985.00 美元 |
| 扣除您的佣金（小计的 10%） | 98.50 美元 |
| **应付酒店金额** | **886.50 美元** |

Wink 每月开具 1.5% 预订费发票，美元计价，15 天内支付，另加超出免费额度的 Partner API 使用费。您负责退款、拒付、支付安全（PCI-DSS）及所在国收款所需的任何许可。完整条款见 [Travel Agent Agreement](/zh-CN/legal/platform-agreements/)。

## 连接您自己的系统

拥有自有预订工具的旅行社可通过 [Partner API](/zh-CN/integrations/partner-api/) 搜索和预订。旅行社账户可直接通过 API 创建预订，这是代理自行收款方式的唯一途径。详见 [Partner API 参考](/zh-CN/partner-api/partner/)。

## 您的检查清单

- [ ] 以旅行社账户注册
- [ ] 提交资料并通过注册审核
- [ ] 添加银行账户并标记为主要账户
- [ ] 为客户找到首批酒店
- [ ] 完成首笔预订，结账时输入卡信息
- [ ] 可选，API 合作伙伴：注册时选择自行收款
