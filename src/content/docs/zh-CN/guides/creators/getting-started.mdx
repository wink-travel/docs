本指南将带您从注册到创建第一个可预订的酒店链接。大约需要15分钟。完成后，您将拥有一个实时店面、您的第一个分享链接，并且了解如何以及何时获得佣金。

## 开始之前

您需要：

- 一个用于注册的电子邮件地址。
- 您的主要社交资料、频道或博客的链接。
- 银行账户信息。您可以等到赚到第一笔佣金后再填写。

## 您如何赚钱

- **每笔您带来的Wink网络酒店预订，默认佣金为10%。**
- **每次点击享有六个月的信用期。** 如果有人今天点击您的链接，三个月后预订，佣金仍归您所有。
- **无粉丝数量限制**，无需申请。Wink网络上所有活跃酒店从第一天起都对您开放。
- **无需处理客人服务。** 付款由酒店收取，酒店作为商户负责客人服务，您获得佣金。

完整详情请参见[旅行创作者如何赚取酒店预订佣金](/zh-CN/resources/travel-creator-hotel-commissions/)和[定价](/zh-CN/pricing/)。

## 第1步：创建您的Wink登录

<Steps>
1. 访问 [app.wink.travel](https://app.wink.travel)，点击右上角的`登录 / 注册`。

2. 点击登录表单下方的`注册`链接，填写表单并点击`注册`。

3. 登录后，您将进入Portal，准备创建您的账户。
</Steps>

## 第2步：创建您的创作者账户

您的登录是您本人。您的**账户**是您的创作者资料，您的观众和酒店将看到它。

  <figcaption>*选择您的账户类型*</figcaption>

<Steps>
1. 点击左侧边栏的`账户`，然后点击`创建`。

2. 选择**我是联盟会员**。在Wink中，创作者即为联盟会员：您通过带来的预订赚取佣金。

3. 填写表单：
   - **名称**：您的创作者名称，观众熟知的名字。
   - **实体类型**：选择`个人`，除非您通过公司操作。这决定您的付款方式。
   - **类型**：选择`影响者`。
   - **描述**：一两行介绍您发布的内容，显示在您的店面上。
   - **网站**：您的主要资料链接，例如Instagram、TikTok或YouTube网址。酒店在您直接联系时会查看这里。
   - **城市**：您的所在地。

4. 接受条款与条件及付款条款，然后点击`保存`。
</Steps>

:::tip[您的店面地址]
您的账户名称决定您的店面地址：名为*Queen Bee*的账户地址为`i.trvl.as/queen-bee`。您可以稍后编辑地址中的这部分，即slug。slug先到先得，请尽早认领。详见[认领您的URL](/zh-CN/portal/link-manager/claim-your-url/)。
:::

## 第3步：设置您的店面

您的店面是您的**WinkLinks**页面，一个链接聚合页，同时也销售酒店。它已存在于您的`i.trvl.as`地址。现在让它成为您的专属。

  <figcaption>*一个WinkLinks店面*</figcaption>

<Steps>
1. 上传头像并检查第2步中的描述。

2. 添加您已分享的链接：您的频道、博客，甚至其他联盟链接。它们都集中在一个页面。详见[内容](/zh-CN/portal/link-manager/content/)。

3. 在`WinkLinks > 设计`中，开启**智能**，让Instagram、Facebook、YouTube、X和Spotify链接显示为可播放的帖子，而非普通链接。选择布局和颜色。详见[设置](/zh-CN/portal/link-manager/settings/)。
</Steps>

想看一个实时示例？访问 [i.trvl.as/starringmay](https://i.trvl.as/starringmay)。

## 第4步：寻找值得推广的酒店

酒店信息在**Studio**，即Portal的创作者端。无需额外注册。

<Steps>
1. 点击主导航栏的`浏览 > 酒店`，或从仪表盘搜索。

2. 按目的地、日期和价格筛选，找到您真正愿意推荐的酒店。

3. 收藏优质酒店：添加到[精选列表](/zh-CN/portal/studio/curated-lists/)（每个账户默认有`收藏`列表），或[保存搜索](/zh-CN/portal/studio/saved-searches/)以便后续查看。
</Steps>

:::tip
推广您曾入住或愿意入住的酒店。您的观众能分辨真伪，这也是将点击转化为预订的关键。想法请参见[发现超值优惠](/zh-CN/guides/affiliates/discover-great-deals/)。
:::

<Steps>
1. 在搜索结果中的某个酒店，点击`制作链接`。

2. 给链接起一个您能识别的名称，添加标题和描述，选择分享时显示的图片。

3. 选择一个主题，在图片上方显示实时价格。

4. 点击`保存`。您将获得一个短链接，如`trvl.as/3xWCH`，带有您的信用信息。
</Steps>

完整选项请见[可分享链接](/zh-CN/portal/studio/shareable-links/)。

### 各格式适用场景

| 发布位置 | 使用 | 原因 |
|---|---|---|
| Stories、Reels、TikTok、评论、私信 | [可分享链接](/zh-CN/portal/studio/shareable-links/) | 单个酒店的短链接，带价格预览。 |
| 个人主页链接 | [WinkLinks](/zh-CN/portal/link-manager/wink-links/) | 一个地址涵盖您所有推荐。 |
| 主题旅行（“里斯本5家精品住宿”） | 以[精选列表](/zh-CN/portal/studio/curated-lists/)形式展示，配合[网格](/zh-CN/portal/studio/grids/)或[地图](/zh-CN/portal/studio/maps/) | 方便用户比较并从一个页面预订。 |
| 博客或网站 | [卡片](/zh-CN/portal/studio/cards/)、[网格](/zh-CN/portal/studio/grids/)或[地图](/zh-CN/portal/studio/maps/) | 在文章内直接展示可预订酒店。 |

## 第6步：分享链接

将您的链接放在观众常看的地方：个人简介、故事链接贴纸、YouTube描述、置顶评论、新闻通讯和博客文章。六个月的信用期意味着即使是常青视频或文章中的链接，发布后很久仍能持续带来收益。

:::note[标注您的合作链接]
大多数平台和许多国家要求您标明从链接中获利，例如使用*#ad*、*#affiliate*或平台的付费合作标签。请遵守您所在平台和国家的规定。这也有助于建立观众信任。
:::

## 第7步：追踪效果

点击右上角的个人头像，然后选择`分析`，查看点击和预订数据。放弃转化率低的内容，多发布效果好的。详见[分析](/zh-CN/account/analytics/)。

## 第8步：领取佣金

<Steps>
1. **添加您的银行账户**：进入`账户 > 银行账户`，添加账户并标记为**主要账户**。自动付款将汇入主要账户。详见[银行账户](/zh-CN/portal/settings/payouts/)。

2. **佣金在客人入住后24小时内可用。** 例如3月预订6月入住，佣金将在6月支付。

3. **付款通过银行转账。** Wink通过Revolut发放付款，如果您有Revolut账户，建议使用：体验最顺畅。其他银行账户同样支持。

4. **转账手续费按成本收取**，费用取决于您的国家和货币。提现前会显示费用估算。详见[定价](/zh-CN/getting-started/pricing/)和[提现资金](/zh-CN/portal/payment/withdraw-funds/)。
</Steps>

:::note
随着收入增长，我们可能会要求您在提款前进行身份验证。这是所有支付平台的标准流程。
:::

## 进阶提升

- **直接与酒店合作。** 当您在Wink有5笔预订后，可以向酒店申请直接合作，例如为您的观众争取特别优惠或团体价。通过直接合作，您和酒店可以协商不同于默认10%的佣金。详见[网络](/zh-CN/portal/studio/network/)。
- **更轻松地发布更多内容。** [社交](/zh-CN/portal/social/what-is-social/)功能为您创建并安排酒店帖子。手动发布始终免费；AI生成内容按使用付费。详见[定价](/zh-CN/pricing/)。

- [ ] 已保存首批酒店至列表
- [ ] 已制作首个可预订链接
- [ ] 链接已分享并标注为合作链接
- [ ] 已添加银行账户并标记为主要账户
