注册旅行代理商使用与其他用户相同的门户网站，即 [app.wink.travel](https://app.wink.travel)，使用旅行代理账户。代理商代表客户搜索和预订，并从每笔预订中赚取佣金。要设置账户，请参阅 [作为旅行社入门](/zh-CN/guides/travel-agents/getting-started/)。

获批自行收款的旅行社作为商户记录，并在 Wink 平台外处理付款。拥有自己系统的旅行社可以通过 [Partner API](/zh-CN/integrations/partner-api/) 进行集成。

旅行代理商拥有与 [Studio](/zh-CN/portal/studio/what-is-studio) 部分相同门户功能的子集，因此这里不再重复介绍。

## 搜索

访问 [搜索](/zh-CN/portal/studio/search) 了解如何搜索和预订酒店。

否则，请继续阅读下一部分。

## API

旅行社可以通过 [Partner API](/zh-CN/partner-api/partner/) 进行搜索和预订，该接口取代了旧的旅行代理 REST 端点。
