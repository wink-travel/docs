Extranet 是我们位于 [app.wink.travel](https://app.wink.travel) 的单一应用 [Portal](/zh-CN/portal/overview) 的物业端。它面向酒店、连锁、品牌和酒店管理公司，用于创建和管理其在 Wink 平台上的数字物业档案。

无需单独注册，也没有其他登录入口——只需在 Portal 中选择一个物业账户，本节描述的 Extranet 功能便会呈现。

Extranet 经过精心设计，力求尽可能简单，同时支持高级物业门户用户所期望的所有功能。举几个例子：

1. 简单：使用我们的智能入驻工作流程，在不到一小时内完成物业入驻并上线。
2. 高级：Wink 支持 8500 种不同的取消政策变体。
3. 酷炫：让地球上某个人享受 10% 折扣，用户无需登录或输入促销代码。

让我们的向导引导您完成整个流程。当您觉得足够熟悉时……就可以独立操作了。

Wink 是一个面向物业和体验提供商的高级内容管理系统。您在 Portal 中能做的所有操作，都可以通过 API 实现。这使您能够与 Wink 深度集成，甚至无需登录即可通过 Wink 销售。

:::tip[专业提示]
您是否正在通过 Leonardo International 支付昂贵的媒体资产托管费用？您可以通过 Wink 完全实现相同功能，并且获得更多选项来操作和微调您的图片和视频。
:::

所有这些功能对您都是免费的。只有在您完成预订时，我们才会收取少量费用。没有损失——只有收获。
