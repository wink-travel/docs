## 两种容易混淆的活动

**推荐预订。** 您推荐酒店，旅客预订，酒店收款，您赚取佣金。您从不持有资金。

**作为商户销售。** 您将旅客的付款收进自己的账户，并自行支付酒店。您现在是欠旅客住宿服务的一方。

第二种情况在大多数市场会触发许可要求，同时承担拒付风险、退款义务和税务处理。第一种通常不会，因此创作者即使没有公司结构也能赚取佣金，而持有客户资金的旅行社则需要许可证。

## 两种模式的区别

| | 为酒店收款 | 您自己收款 |
|---|---|---|
| 商户身份 | 酒店 | 您 |
| 旅行社许可证 | 推荐无需 | 通常需要，视地区而定 |
| 拒付责任 | 酒店承担 | 您承担 |
| 退款与取消 | 由酒店处理 | 由您处理 |
| 消费者保护义务 | 酒店承担 | 您承担 |
| Wink费用 | 每笔预订1.5%平台费加成本卡处理费 | 仅1.5%处理费，按月开票 |
| 佣金比例 | 默认10% | 您自行设定利润率 |
| 需要的身份 | 任何人 | 持证经营者 |

## 谁可以无证赚取佣金

在第一种模式下，以下各方都可以通过酒店预订赚取佣金：

- **创作者和关键意见领袖** 向受众发布推荐
- **出版商和新闻通讯** 运营目的地或酒店内容
- **社区和俱乐部** 组织会员旅行
- **活动组织者** 为代表团预订房间
- **代理和目的地管理公司** 制定客户行程
- **银行、忠诚度和会员计划** 提供旅行福利
- **应用、平台和AI代理** 嵌入预订路径

他们都不持有旅客资金，因此不成为商户。酒店继续履行与客人的合同并提供住宿。

## 何时选择第二种模式

自己收款适用于少数情况——当您已经是持证旅行企业，拥有自己的客户合同、支付关系和退款政策，并且需要酒店作为供应商而非商户时。打包机票和酒店的旅行社是常见例子。

如果是这种情况，Wink只收取**1.5%处理费**，不参与资金流。如果不是，第一种模式能让您获得相同佣金且负担更轻。

## 开始销售前需确认

- **旅客所在地**，不仅是您所在地——消费者保护规则通常跟随旅客所在地。
- **是否会持有资金**，即使是短暂持有。持有资金是关键界限。
- **是否打包**酒店和交通，这可能触发单独的打包旅游规则。
- **退款如何返还旅客**，以及住宿出现问题时谁负责。
- **您自己条款中的承诺**，因为这可能无论模式如何都产生义务。

各国规则不同且不断变化。选择商户模式前请咨询当地顾问确认您的立场。

## 常见错误

- **误以为赚取佣金需要许可证。** 推荐模式通常不需要。
- **因“方便”将支付路由至自己账户，意外成为商户。**
- **承诺无法控制的退款**，当酒店持有资金和退款政策时。
- **以一国规则套用所有地区。** 义务通常跟随旅客所在地。
- **为更高佣金选择商户模式。** 佣金不会更高，只会增加责任。
