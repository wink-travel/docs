## 直连供应与转售供应的区别

大多数代理酒店内容通过一条链路传递：酒店 → 渠道管理 → 批发商或床位银行 → 代理商。每经过一个环节都会增加延迟、加价，并导致代理商看到的内容与酒店实际库存不符。

常见的实际表现包括：客户决定时价格已过时、确认时无房、房型描述不符，以及无法向酒店咨询非直接预订的订单。

直接预订则省去中间环节。价格为酒店自身价格，库存实时，预订直接进入酒店系统并关联您的代理商。

| | 批发商 / 床位银行 | 直连酒店供应 |
|---|---|---|
| 价格来源 | 合同配额，通常是静态的 | 酒店实时价格 |
| 库存 | 缓存，确认时可能失败 | 酒店实时库存 |
| 利润结构 | 价格中包含加价 | 透明佣金 |
| 客户归属 | 共享或不明确 | 代理商保持客户关系 |
| 酒店关系 | 间接 | 直接与酒店 |
| 特殊请求 | 通过链路传递 | 直接与酒店沟通 |

## 代理商直接预订所需条件

- **访问符合条件的供应** — 酒店设定哪些酒店、房型和价格对您的代理开放。
- **面向客户的展示方式** — 精选酒店列表、套餐、地图或用于提案和行程的店面。
- **保留来源的预订路径**，确保佣金归属无需追踪。
- **明确的支付条款** — 谁收款，谁是交易商，佣金何时结算。
- **确认和修改处理**，确保信息真正传达给酒店。

## 两种支付方式

**酒店收款。** 由酒店收款，酒店为交易商。代理商从归属的预订中赚取佣金，无需承担交易商责任。这是默认方式，无需许可。

**代理商收款。** 持有相应地区旅行社许可的代理商可自行向客户收款并直接支付给酒店。Wink仅收取**1.5%处理费**，按月开票，因为不处理资金。具体许可要求视运营地区而定，选择此方式前请当地确认。

## 佣金及计算方式

默认佣金为**10%**，基于酒店1.5%平台费和刷卡手续费后计算，而非总价。以2000美元预订为例，约为**189美元**。归属有效期为**每次点击6个月**，这对提案可能与客户沟通数周的代理工作尤为重要。

## 团体、活动及MICE预订

直连供应在批发商最薄弱的环节最有价值：婚礼、会议、度假和奖励的房间包块。这些需要与酒店沟通价格、保留和截止日期——只有当预订属于您且酒店知道您身份时才可能实现。

基于符合条件供应构建的店面或活动页面为参与者提供可预订链接，同时保持包块、归属和报告归代理所有。

## 常见错误

- **将净批发价与可佣金直连价直接比较**，未调整净价中已含的加价。
- **向客户发送PDF。** 无法直接预订的提案会流失订单给能预订的竞争者。
- **所有客户共用一个链接。** 归属和报告变成猜测。
- **误以为赚取佣金需要许可。** 只有自行收款才需要许可。
- **忽视包块的取消条款**，直到客户询问。
