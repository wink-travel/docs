## 为什么连接性很重要

每条预订路径都依赖于准确的酒店供应。如果价格错误，客人会失去信任；如果可用性错误，酒店可能会导致预订失败；如果库存过时，任何路径都无法可靠运行。Wink 不仅支持网站预订按钮 — 同一酒店数据还支持网站路径、可分享链接、二维码、网页组件、WinkLinks 店面、合作伙伴链接、Traveliko 列表、社交预订路径、Agentic AI 交接和开发者流程。所有这些都需要同一个基础：准确的 **ARI** — 可用性、价格和库存。

## 两种设置路径

**路径 1 — 连接支持的提供商。** 当酒店已经在 Wink 支持的渠道管理器、PMS、CRS 或价格提供商中管理价格时使用。酒店在 Extranet 中选择提供商，在提供商仪表盘激活 Wink 作为渠道，映射房型和价格计划，提供商将 ARI 发送给 Wink — 自动填充主价格日历。适合多渠道酒店、频繁价格变动、实时库存需求和较低的手动工作量。

**路径 2 — 在 Extranet 中手动加载价格。** 当酒店不使用支持的提供商或希望通过 `Distribution > Master rate calendar` 手动操作 Wink 时使用 — 支持单日和批量日期范围更新。适合小库存、早期设置或测试。**这需要自律：** 如果运营中价格变动，必须有人更新 Wink。如果连接了提供商，手动更改可能会在提供商下一次发送相同日期更新时被覆盖。

## 连接提供商与手动加载对比

| 问题 | 连接提供商 | Extranet 手动加载 |
|---|---|---|
| 谁更新 ARI？ | 支持的提供商向 Wink 发送更新。 | 酒店手动更新价格和可用性。 |
| 适用场景 | 多渠道酒店、频繁变动、实时库存。 | 小库存、有限使用、无连接提供商。 |
| 工作量 | 设置后日常工作量较低。 | 持续手动维护。 |
| 实时表现 | ARI 自动从提供商更新。 | 仅与最后一次手动更新保持一致。 |
| 风险 | 映射或提供商设置必须正确。 | 若不维护，价格或可用性可能过时。 |
| 预订通知 | 在配置处通知渠道管理器/CRS/PMS。 | 酒店通过 Wink 接收预订通知。 |

## 支持的提供商

Wink 支持多种渠道管理器，以及直接或通过 Channex 作为代理连接的 PMS。上线前请与 Wink 团队确认您的具体提供商版本、设置路径和映射要求。

| 提供商 | 类型 | 备注 |
|---|---|---|
| SiteMinder | 渠道管理器 | 直接集成 |
| Cloudbeds | 渠道管理器 | 直接集成 |
| Travelclick | 渠道管理器 | 直接集成 |
| RateGain | 渠道管理器 | 直接集成 |
| D-EDGE | 渠道管理器 | 直接集成 |
| YieldPlanet | 渠道管理器 | 直接集成 |
| Rate Tiger | 渠道管理器 | 直接集成 |
| Hotel Link | 渠道管理器 | 直接集成 |
| Channex | 渠道管理器 + PMS 代理 | 直接连接，且为多种 PMS 提供代理 |
| SynXis | CRS | 可能需要通过 SynXis Channel Connect Express 额外设置 |

许多 PMS 系统 — 例如 Mews、Apaleo、Opera Cloud 和 OTA Sync — 可以通过 **Channex** 代理将 ARI 路由到 Wink。如果您的 PMS 连接到 Channex，就能接入 Wink；上线前请确认 PMS 版本和 Channex 设置。（此列表为代表性示例 — 请与 Wink 团队确认您的提供商。）

## 提供商设置简要说明

在 Extranet 中，进入 `Distribution > Channel manager`，选择您的价格提供商并保存。在提供商仪表盘添加 **Wink** 渠道，映射 Wink 中创建的房型和价格计划。如果提供商不自动推送价格，请发起完整价格推送，然后检查主价格日历 — 可能几分钟内更新（具体时间因提供商和映射而异）。使用 **Verifier** 模拟旅客价格请求，测试可用性、货币、折扣和价格显示，确认无误后再发送真实需求。团队了解通知行为后再创建测试预订。

## 预订通知

连接性不仅是将价格发送给 Wink — 还包括预订如何反馈。当预订完成时，渠道管理器、CRS 或 PMS 会在配置处收到通知；酒店和旅客收到确认邮件；合作伙伴在合作伙伴路径上收到预订和归因确认；开发者可监听 `booking.created` webhook 获取实时详情。

## Wink 的位置

连接性位于 Extranet 和预订引擎之间。[Extranet](/zh-CN/products/extranet/) 是酒店端的内容、房型、价格计划、限制、可用性、政策和预订引擎设置控制层；支持的提供商将 ARI 传入，或酒店手动维护主价格日历；[Booking Engine](/zh-CN/products/booking-engine/) 使用这些经批准的数据，完成来自直接、社交、WinkLinks、合作伙伴、Traveliko、Agentic AI 和开发者路径的预订。简单规则：**连接性越强，预订路径越可靠。**

## 常见错误

- **假设 Wink 可以在无当前可用性的情况下销售。** 它需要先从提供商或手动 Extranet 更新获取 ARI。
- **连接提供商但未映射房型和价格计划。** 映射正确前设置不完整。
- **连接提供商时手动编辑价格。** 手动更改可能被提供商下一次更新覆盖。
- **忘记验证。** 发送真实需求前测试价格显示、可用性和折扣逻辑。
- **将连接性仅视为技术任务。** 它影响收入、营销、合作伙伴路径、转化率和客人信任。
