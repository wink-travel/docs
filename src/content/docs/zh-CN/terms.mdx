## 2. 定义

- **平台** — 指上述 Wink 产品、网站、应用程序和接口。
- **Booking Engine** — Wink 的结账和履约层，完成预订、收款、发送确认并同步预订信息。
- **TripPay** — Wink 自有的预订支付网关。卡片处理由第三方支付处理商 Stripe 执行。
- **酒店**或**供应商** — 在平台上发布供应、价格和可用性的住宿提供者。
- **合作伙伴** — 分销酒店供应并可能赚取佣金的企业（如旅行社、DMC、出版商或忠诚度计划）。
- **创作者** — 通过个人店面或链接向其受众推广酒店供应并可能赚取佣金的个人。
- **开发者** — 通过 API、MCP 服务器或 SDK 与平台集成的个人或企业。
- **AI 代理** — 经批准的自动化或 AI 驱动客户端，代表用户发现供应并通过平台创建预订。
- **旅客**或**客人** — 通过平台预订或入住酒店的人。
- **内容** — 任何提交至平台或通过平台提供的文本、图片、价格、列表、链接、代码或其他材料。

## 3. Wink 平台及我们的角色

**Wink 提供技术和商务基础设施。** Wink 连接酒店供应与可销售渠道，并完成预订和支付。Wink **不是**住宿提供者，**不是**住宿的商户记录方，也**不**作为传统旅行社或旅游运营商。

任何住宿或相关服务的合同均由**旅客与酒店直接**签订。酒店独自负责其供应、价格、可用性、描述、政策（包括取消和退款政策），以及履行和交付预订。Wink 不是该合同方，对任何酒店、合作伙伴、创作者、开发者或旅客的行为或疏忽不承担责任。

Wink 不保证任何特定供应、价格、可用性或渠道的存在或不中断，且可随时添加、更改或移除平台功能。
