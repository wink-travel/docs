Pinapayagan ka ng Recognition na itampok ang mga parangal, sertipikasyon, at badge ng industriya ng iyong property upang makabuo ng tiwala sa mga potensyal na bisita.

Para pamahalaan ang pagkilala, i-click ang `Impact > Recognition` mula sa pangunahing nav bar.

## Pagdaragdag ng pagkilala

I-click ang `Create` upang magdagdag ng bagong entry ng pagkilala. Kasama sa bawat entry ang:

- **Kategorya** — Ang uri ng pagkilala (hal., parangal, sertipikasyon).
- **Uri** — Ang partikular na uri ng pagkilala.
- **Tagapagbigay** — Ang nag-isyu na organisasyon (hal., Michelin, TripAdvisor, AAA).
- **Rating** — Numerikong halaga ng rating, kung naaangkop.
- **Simbolo ng rating** — Ang icon o simbolo na ginagamit upang ipakita ang rating.
- **Petsa** — Kailan nakuha ang pagkilala.
- **Opisyal na pagtatalaga** — Kung ito ay isang opisyal na pagtatalaga.

## Pamamahala ng mga entry

Mula sa listahan ng pagkilala, maaari mong i-edit o alisin ang mga umiiral na entry. Ang mga entry ng pagkilala ay ipinapakita sa profile ng iyong property sa booking engine, na tumutulong sa mga manlalakbay na makita ang iyong mga parangal nang mabilis.
