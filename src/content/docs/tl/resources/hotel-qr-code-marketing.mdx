## Bakit mahalaga ang mga QR code para sa mga hotel

Puno ang hotel ng mga offline na sandali na may mataas na intensyon. Isang guest na nagbabasa ng spa menu, isang kumakain na tapos na sa pagkain, isang dumadalo sa kasal, isang biyahero na may hawak na key card — bawat isa ay pagkakataon para mag-drive ng booking, dagdag na serbisyo o pagbabalik na pananatili. Kinokonekta ng mga QR code ang mga sandaling iyon sa isang digital, bookable na susunod na hakbang.

Madali lang ang teknolohiya; bawat camera ng telepono ay nakakabasa ng code. Ang pagkakaiba ng isang gumaganang QR code at isang hindi pinapansin ay **kung saan ito patungo**. Maraming hotel QR code ang nagbubukas ng static na PDF, homepage, o menu na walang paraan para kumilos. Ang oportunidad ay gawing **bookable at nasusukat** ang pag-scan.

## Saan maaaring ilagay ng mga hotel ang mga QR code

| Lugar | Ang bookable na sandali |
|---|---|
| Mga kuwarto ng guest at key cards | Palawigin ang pananatili, mag-book ng pagbabalik, magdagdag ng spa o kainan. |
| Mga restawran at bar | Magpareserba ng mesa, mag-book ng karanasan sa chef, magplano ng susunod na pananatili. |
| Spa at wellness | Mag-book ng mga treatment at wellness packages. |
| Front desk at lobby | Mag-upsell ng mga upgrade, maagang check-in, late checkout, mga karanasan. |
| Mga kaganapan at kasal | Bigyan ang mga dumalo ng room block o destination storefront. |
| Mga nakaimprentang collateral | Mga brochure, flyer, signage, business card at welcome book. |
| Out-of-home at mga lokal na partner | Mga poster, partner venues at mga destination placement. |

Dapat ang bawat lugar ay tumutugma sa isang **tiyak na intensyon** — ang spa QR ay hindi dapat magdala sa guest sa room-only na proseso.

## Ano ang dapat puntahan ng QR code

Dapat ang pag-scan ay mapunta sa isang destinasyon na tumutugma sa sandali at maaaring kumpletuhin ang isang aksyon:

- Isang **bookable na alok** — ang eksaktong kuwarto, package, mesa, treatment o karanasan.
- Isang **storefront** — kapag ang isang code ay dapat magpakita ng ilang alok (mga event hotel, isang destination collection, buong menu ng bookable na nilalaman ng property).
- Isang **mobile-first** na pahina — halos lahat ng QR traffic ay nasa telepono.
- Isang **nasusukat** na ruta — para malaman ng hotel kung aling lugar ang nag-drive ng booking.

## Paano ito gumagana sa Wink

Ginagawang tunay na channel ng Wink ang QR code, hindi lang isang static na link.

- **[Studio](/tl/products/studio/) ang gumagawa ng mga code.** Gumawa ng bookable Shareable Link o asset at i-download ang branded na **QR code bilang PNG o SVG** para sa print, signage at mga in-property na lugar.
- **[WinkLinks](/tl/products/winklinks/) ang nagho-host ng destinasyon.** Kapag ang isang code ay dapat maglaman ng higit sa isang alok, ituro ito sa isang mobile-first Travel Storefront — mga bookable hotel card, alok, listahan at mapa sa ilalim ng isang `i.trvl.as/your-name` na link.
- **[Booking Engine](/tl/products/booking-engine/) ang nag-aasikaso ng booking.** Isang tap ang magdadala sa checkout — ang tamang kuwarto, rate at mga dagdag, bayad, kumpirmasyon — at ang buong pananatili, hindi lang ang kuwarto.
- **Nananatili ang attribution.** Ang booking ay nananatiling konektado sa kampanya, lugar o partner sa likod ng code, kaya nakikita ng hotel kung aling mga QR code ang talagang lumilikha ng demand.

Ito ang parehong closed loop sa likod ng [hotel social commerce](/tl/resources/hotel-social-commerce/) — ang QR code ay isang offline na entry point lamang dito.

## Isang praktikal na QR playbook

### 1 — Piliin ang sandali at intensyon

Magdesisyon kung ano ang dapat ibenta sa bawat lugar. Iba ang trabaho ng restaurant table tent at wedding banner.

### 2 — Gumawa muna ng destinasyon

Gumawa ng bookable na alok o storefront bago mag-print ng kahit ano. Ang destinasyon ang kampanya; ang code ay pintuan lang.

### 3 — Gumawa at i-brand ang code

Gamitin ang Studio para gumawa ng QR code at i-download ito bilang PNG o SVG para manatiling malinaw sa anumang laki ng print.

### 4 — Disenyuhin para sa pag-scan

Maglagay ng malinaw na call to action sa tabi ng code ("I-scan para mag-book ng spa package"), at siguraduhing mabilis mag-load ang landing page sa mobile.

### 5 — Sukatin at ulitin

Subaybayan ang scans-to-bookings ayon sa lugar. Ilipat ang mga code na hindi nagko-convert, at pagdoblehin ang mga gumagana.

## Mga karaniwang pagkakamali

- **Mga QR code na nagbubukas ng PDF o homepage.** Dapat ang pag-scan ay magtungo sa isang bookable na bagay.
- **Isang generic na code sa lahat ng lugar.** Itugma ang code sa sandali at intensyon.
- **Walang attribution.** Kung hindi mo malalaman kung aling lugar ang nag-drive ng booking, hindi mo ito mapapabuti.
- **Mga landing page na para sa desktop.** Mobile ang QR traffic — disenyuhin para dito.
- **Pagpi-print bago gumawa.** Gumawa muna ng destinasyon bago mag-commit sa print.
