Sa pamamagitan ng pagkonekta ng iyong Google Analytics 4 property sa Wink, ang iyong mga booking event — mula sa pagtingin ng mga kuwarto hanggang sa mga kumpletong booking — ay awtomatikong ipinapasa sa iyong sariling GA4 dashboard kasabay ng sariling analytics ng Wink. Walang code, walang teknikal na setup sa iyong panig.

<Aside type="tip">
Kailangan mo ng dalawang bagay mula sa GA4: isang **Measurement ID** at isang **Measurement Protocol API secret**. Ang Measurement ID ang nagpapatakbo ng browsing funnel sa browser ng bisita; ang API secret naman ang nagpapahintulot sa Wink na i-record ang mga kumpletong booking (`purchase`) **server-side**, kaya hindi mawawala ang isang benta kapag na-redirect ang bisita papunta at pabalik mula sa payment provider.
</Aside>

---

## Paano Ito Gumagana

```
Ilagay mo ang iyong Measurement ID (G-XXXXXXXXXX) at API secret sa Wink portal
       ↓
Ang mga browsing event (views, cart, checkout) ay dumadaloy sa iyong GA4 property mula sa browser
Ang mga kumpletong booking (purchase) ay ipinapadala server-side — nananatili kahit may payment redirect
       ↓
Mag-login ka sa analytics.google.com at makikita mo ang buong booking funnel mo
```

---

## Ano ang Kailangan Mong Gawin

<Steps>

1. **Gumawa ng GA4 Property**

   Pumunta sa [analytics.google.com](https://analytics.google.com): Admin → Create Property. Itakda ang iyong timezone at currency upang tumugma sa iyong merkado.

2. **Gumawa ng Web Data Stream**

   Admin → Data Streams → Add Stream → Web. Ilagay ang `wink.travel` bilang URL. Ito ay magbibigay sa iyo ng **Measurement ID** (`G-XXXXXXXXXX`). Kopyahin ito.

3. **Gumawa ng Measurement Protocol API Secret**

   Buksan ang parehong Web Data Stream → mag-scroll sa **Measurement Protocol API secrets** → **Create**. Bigyan ito ng palayaw (hal. "Wink") at kopyahin ang nabuo na **secret value**. Ang secret na ito ang nagpapahintulot sa Wink na i-record ang mga kumpletong booking server-side, kaya hindi mawawala ang benta sa panahon ng payment redirect.

4. **Ilagay ang Iyong Measurement ID at API Secret sa Wink Portal**

   Mag-login sa [app.wink.travel](https://app.wink.travel), piliin ang iyong account, at pumunta sa tab na **Customizations**. I-paste ang iyong Measurement ID at API secret sa mga **GA4** na field at i-save. Iyon lang — aktibo na ang iyong GA4 integration.

   <Aside type="note">
   Ang API secret ay **write-only**: kapag naisave na, hindi na ito ipapakita muli. Sa mga susunod na pag-edit, iwanang blangko ang secret field upang mapanatili ang naunang na-save na halaga.
   </Aside>

5. **Markahan ang `purchase` bilang Key Event**

   Bumalik sa iyong GA4 property: Admin → Events → hanapin ang `purchase` → i-toggle ang **Mark as key event**. Ginagawa nitong lumabas ang mga kumpletong booking sa iyong Conversions report.

6. **Tingnan ang Iyong Data**

   Mag-login sa [analytics.google.com](https://analytics.google.com) at makikita mo ang iyong mga booking, kita, at guest funnel — lahat ay awtomatikong nasusubaybayan sa pamamagitan ng Wink.

</Steps>

<Aside type="note">
Hindi mo kailangang mag-install ng anumang tracking code sa iyong sariling website para sa integration na ito. Ang Wink ang bahala sa lahat. Ang iyong Measurement ID ang destinasyon kung saan ipinapadala ang iyong booking data, at ang iyong API secret ang nagpapahintulot sa Wink na kumpirmahin ang mga kumpletong booking server-side.
</Aside>

<Aside type="tip">
**Maaaring gamitin nang sabay ang GA4 at GTM.** Kung nagpapatakbo ka rin ng Google Tag Manager container (halimbawa ay Sojern container), maaari mong i-configure ang pareho nang sabay — hindi na sila magkahiwalay. Tingnan ang [GTM Analytics Integration](/tl/guides/developers/gtm-dual-tagging).
</Aside>

## Ano ang Maaari Mong Subaybayan

Kapag nakakonekta na, matatanggap ng iyong GA4 property ang buong hanay ng Enhanced E-commerce events para sa iyong property:

### Discovery

| Event | Kahulugan |
|---|---|
| `view_item_list` | Nakita ng bisita ang iyong property sa isang search o category listing |
| `select_item` | Nag-click ang bisita sa iyong property mula sa isang listing |
| `view_item` | Tiningnan ng bisita ang detalye ng iyong hotel |

### Consideration

| Event | Kahulugan |
|---|---|
| `view_promotion` | Nakita ng bisita ang isang promotional offer para sa iyong property |
| `select_promotion` | Nag-click ang bisita sa isang promotional offer |
| `add_to_wishlist` | In-save ng bisita ang iyong property sa kanilang wishlist |

### Booking Funnel

| Event | Kahulugan |
|---|---|
| `add_to_cart` | Pumili ang bisita ng kuwarto o package |
| `view_cart` | Tiningnan ng bisita ang kanilang booking summary |
| `remove_from_cart` | Tinanggal ng bisita ang isang kuwarto o package |
| `begin_checkout` | Sinimulan ng bisita ang proseso ng checkout |
| `add_payment_info` | Inilagay ng bisita ang kanilang payment details |
| `add_shipping_info` | Inilagay ng bisita ang kanilang guest details |
| `purchase` | Nakumpleto ng bisita ang booking |
| `refund` | Kinansela at na-refund ang booking |

Lahat ng event ay may kasamang mga kaugnay na dimensyon tulad ng kita, pera, uri ng kuwarto, at halaga ng booking — na nagbibigay sa iyo ng buong larawan ng paglalakbay ng bisita mula sa unang impression hanggang sa kumpletong booking. Para ma-unlock ang karagdagang property- at room-level na dimensyon tulad ng `city_name`, `cancellation_policy`, `bed_type`, at iba pa, tingnan ang [Custom Dimensions in GA4](/tl/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4).

## Cross-Domain Tracking (Advanced)

Ang standard integration sa itaas ay sumusubaybay sa lahat ng nangyayari sa loob ng Wink. Gayunpaman, kung nais mong subaybayan ang mga bisita mula sa iyong sariling website hanggang sa kumpletong booking sa Wink — at tama ang pag-aatributo sa orihinal na pinagmulan ng trapiko (Google Ads, email campaigns, organic search, atbp.) — kailangan ng isang karagdagang hakbang sa bawat panig.

<Aside type="caution">
Ang seksyong ito ay para lamang sa mga may GA4 na naka-install sa kanilang sariling website. Kung hindi ka nagpapatakbo ng GA4 sa iyong site, sapat na ang standard integration sa itaas.
</Aside>

### Bakit Mahalaga Ito

Kung walang cross-domain tracking, ang bisitang bumisita muna sa iyong website at pagkatapos ay nag-book sa Wink ay lalabas sa iyong GA4 bilang isang **Direct** session na walang koneksyon sa kanilang naunang pagbisita. Anumang Google Ads clicks, email campaigns, o organic search visits na nagdala sa booking ay hindi makakakuha ng kredito.

Kapag naka-configure ang cross-domain tracking, makikita mo ang buong paglalakbay ng bisita:

```
google.com (bayad na ad)
       ↓
iyong website (nag-browse ang bisita ng mga kuwarto)
       ↓
wink.travel (pinili at nag-book ang bisita ng kuwarto)
       ↓
tamang naiaatributo ang purchase sa orihinal na Google Ads click
```

### Kailangan Mong Gawin: Ikaw

I-configure ang iyong GA4 property upang kilalanin ang `wink.travel` bilang bahagi ng iyong sariling domain, hindi bilang external referral. Sinasabi nito sa GA4 na pagdugtungin ang dalawang session bilang isang tuloy-tuloy na paglalakbay ng bisita.

<Steps>
1. GA4 Admin → Data Streams → iyong stream
2. Configure tag settings → **Configure your domains**
3. Idagdag ang `wink.travel` bilang linked domain
4. I-save
</Steps>

### Kailangan Gawin ng Wink

Makipag-ugnayan sa [Wink Support](https://app.wink.travel) at ibigay ang domain ng iyong website (hal. `yourhotel.com`). Idadagdag ng Wink ang iyong domain sa referral exclusion list sa Wink GA4 property. Pinipigilan nito ang iyong website na maitala bilang referral source, na kung hindi ay mag-o-overwrite sa orihinal na attribution ng bisita at magsisimula ng bagong session.

<Aside type="tip">
Sapat na ang standard integration sa itaas para sa karamihan ng mga property at nagbibigay ito ng agarang visibility sa mga booking at kita sa Wink. Ang cross-domain tracking ay isang advanced na opsyon na sulit i-setup kapag komportable ka na sa iyong GA4 data at nais ng mas malalim na insight sa attribution.
</Aside>
