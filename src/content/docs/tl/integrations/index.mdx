Maaaring i-embed ang Booking Engine kahit saan. Piliin ang iyong framework o CMS at sundin ang gabay nito; pareho ang mga underlying Web Components kahit saan.

## Pangunahing mga pamamaraan

- [Web Components](/tl/integrations/web-components/) — ang mga embeddable na elemento na ginagamit sa bawat integrasyon.
- [npm package](/tl/integrations/npm/) — i-install sa isang JavaScript build.
- [Headless CMS](/tl/integrations/headless/) — i-render mula sa anumang content backend.
- [Partner API](/tl/integrations/partner-api/) — buong programmatic na integrasyon.
