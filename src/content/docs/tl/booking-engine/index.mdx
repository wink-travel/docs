Ang Booking Engine ay ang layer ng transaksyon sa ilalim ng bawat ruta ng Wink: sariling website ng hotel, mga partner at creator links, consumer discovery at AI agents. Kinokolekta ang bayad para sa hotel bilang ahente nito, kaya ang hotel ang nananatiling merchant of record.

## Ang daloy ng booking

- [Search](/tl/booking-engine/search/) — hanapin ang magagamit na imbentaryo.
- [Property Detail](/tl/booking-engine/property-detail/) — mga kuwarto, presyo, patakaran at mga dagdag.
- [Checkout](/tl/booking-engine/checkout/) — isang hakbang ng pagbabayad na may tatak ng hotel.
- [Booking Confirmation](/tl/booking-engine/confirmation/) — ang natatanggap ng bisita.

## Para sa manlalakbay

- [Bookings](/tl/booking-engine/bookings/) — pamahalaan ang umiiral na reserbasyon.
- [Bucket List](/tl/booking-engine/bucket-list/) — i-save ang mga property para sa susunod.
- [Travel Preferences](/tl/booking-engine/travel-preferences/) — i-personalize ang mga resulta.
