Lahat ng tampok ng platform ay maaaring tawagin mula sa labas. Saklaw ng seksyong ito ang authentication, ang API surface, paghahatid ng mga kaganapan, at ang reference data sa likod nito.

## Magsimula dito

- [Quickstart](/tl/developers/quickstart/) — mula zero hanggang live na presyo ng hotel at ang iyong unang test booking sa staging.
- [Build on Wink](/tl/developers/build-on-wink/) — kung ano ang maaari mong gawin at aling API ang angkop.
- [Setup](/tl/developers/setup/) — gumawa ng application at kunin ang mga kredensyal.
- [Authentication](/tl/developers/authentication/) — OAuth2 sessions at scopes.

## Ang API surface

- [REST and gRPC](/tl/developers/rest-and-grpc/) — ang dalawang transport at kailan gagamitin ang bawat isa.
- [Geolocation](/tl/developers/geolocation/) — spatial search sa bookable inventory.
- [Taxonomy](/tl/developers/taxonomy/) — mga OTA code, suportadong mga wika at mga pera.

## Mga Kaganapan at pagsasabay

- [Webhook Integration](/tl/developers/webhook-integration/) — mag-subscribe sa mga kaganapan ng platform.
- [Webhook Events Catalog](/tl/developers/webhook-events/) — bawat kaganapan na inilalabas ng platform.
- [Booking Sync](/tl/developers/booking-sync/) — panatilihing naka-align ang mga booking sa isang PMS o channel manager.

## Mga AI agent

- [MCP Servers](/tl/developers/mcp/) — basahin ang live API contracts mula sa isang AI client.
- [Agentic Payments](/tl/developers/agentic-payments/) — ikonekta ang iyong agent, mag-sign in, maghanap ng kuwarto at aprubahan ang bayad.
- [AI Skills](/tl/developers/ai-skills/) — kung ano ang magagawa ng isang aprubadong agent sa platform.
