Ang bawat tampok ng platform ay maaaring tawagin mula sa labas. Saklaw ng seksyong ito ang authentication, ang API surface, paghahatid ng mga kaganapan, at ang reference data sa likod nito.

## Magsimula dito

- [Setup](/tl/developers/setup/) — gumawa ng aplikasyon at kunin ang mga kredensyal.
- [Authentication](/tl/developers/authentication/) — OAuth2 sessions at mga scope.

- [REST at gRPC](/tl/developers/rest-and-grpc/) — ang dalawang transport at kailan gagamitin ang bawat isa.
