Hindi pinapayagan ng Demand Partner Agreement ang paghahambing ng presyo gamit ang supply ng Wink "maliban kung hayagang pinahihintulutan" (clause 11.3). Ipinaliwanag sa pahinang ito kung paano nagbibigay ng pahintulot ang Wink para sa search display, at ang mga patakarang dapat sundin ng iyong pagpapakita kapag nakuha mo na ito.

## Ano ang ibig sabihin ng search display

**Search display** ay ang pagpapakita ng mga hotel mula sa Partner API bilang tugon sa paghahanap ng user, kasabay ng iba pang mga alok ng hotel, kabilang ang mga hindi bayad na alternatibo mula sa ibang mga pinagmulan, na may click-out na nagbubukas sa napiling hotel sa Wink Booking Engine sa ilalim ng iyong affiliate account.

Saklaw nito ang paghahanap, nilalaman, at click-out lamang. Ang paggawa, pagbabago, o pagkansela ng mga booking sa pamamagitan ng Partner API ay nangangailangan ng hiwalay na nakasulat na pahintulot mula sa Wink.

## Mga patakaran para sa bawat pagpapakita

- **Live rates.** Dapat ipakita ang mga rate at availability na tumutugma sa live na datos sa oras ng pagpapakita (clause 8.2).
- **Hindi binabago ang mga rate.** Ipakita ang bawat rate nang eksakto kung paano ito ibinibigay ng Partner API, walang markup, surcharge, o pagbabago. Ang hotel ang nagtatakda at kumokontrol ng kanilang rate.
- **Tumpak na presentasyon.** Ipakita nang tumpak ang mga presyo, mga kasama, at mga patakaran sa pagkansela nang hindi binabago ang kahulugan nito (clause 6.1).
- **Huwag ipakita ang Wink bilang nagbebenta.** Ang iyong produkto ay nananatiling malinaw at hiwalay sa Wink, hindi nagpapakita ng sarili bilang Wink, at hindi ipinapakita ang Wink bilang hiwalay na online travel agency o bilang nagbebenta (clause 7.4). Ang kontrata para sa pananatili ay nasa pagitan ng manlalakbay at ng hotel.
- **Pagbubunyag.** Ibinubunyag ang iyong komersyal na relasyon sa Wink kung kinakailangan ng batas (clause 6.2).
- **Walang karagdagang paggamit.** Huwag mag-sublicense, maglipat, o magbunyag ng data o nilalaman ng supply ng Wink sa iba pa (clause 11.3).

## Pansamantalang pagpapakita

Walang itinakdang limitasyon ng oras ang Wink kung gaano katagal mo maaaring hawakan ang resulta ng paghahanap, dahil walang nakakaalam kung kailan magbabago ang presyo: maaaring baguhin ito ng hotel limang segundo mula ngayon o isang taon mula ngayon. Ang mahalaga ay ang rate at availability na ipinapakita mo ay tumutugma sa live na datos sa oras ng pagpapakita (clause 8.2). Kunin muli mula sa Partner API tuwing nagbabago ang itinerary, at bago ipakita ang resulta na hindi ka sigurado kung ito ay kasalukuyan pa.

Ang pagpapakitang sumusunod sa mga patakarang ito ay hindi isang "static copy of content" sa ilalim ng clause 7.5, ni pag-cache ng lipas na mga rate sa ilalim ng clause 8.2.

## Pag-cache ng nilalaman ng property

Ang nilalaman ng property (mga pangalan, paglalarawan, mga larawan, amenities at mga patakaran) ay walang limitasyon sa oras ng pag-cache. Gamitin ang `lastUpdate` ng bawat property mula sa Partner API bilang iyong cache key, at i-refresh ang nilalaman ng property kapag ito ay nagbago.

## Mga identifier na maaari mong panatilihin

Maaari mong panatilihin ang mga ito, at ito lamang:

- ang Wink property ID at property `urlName`,
- mga booking reference number ng mga booking na naka-attribute sa iyo,
- ang iyong sariling attribution, client at configuration IDs, kasama ang kaugnay na mga petsa ng click at booking.

Gamitin lamang ang mga ito para i-de-duplicate ang mga listahan ng hotel mula sa iba't ibang pinagmulan, at para sa attribution, pag-uulat, at reconciliation ng komisyon. Huwag panatilihin ang mga rate, availability, o nilalaman ng property lampas sa mga patakarang nabanggit sa itaas, at huwag gamitin ang anumang data mula sa Wink, kabilang ang mga identifier na ito, para sanayin, i-fine-tune o suriin ang isang modelo, o para bumuo o pagbutihin ang isang supply database (clauses 7.5 at 10.6).

## Paano humiling ng pahintulot

Ang search display ay nangangailangan ng hayagang nakasulat na pahintulot mula sa Wink, na ibinibigay bilang side letter sa iyong Demand Partner Agreement. Nagkakabisa ito kapag parehong tinanggap ang liham at ang Kasunduan, at maaaring bawiin ng Wink ito sa pamamagitan ng abiso o agad-agad kung nilabag ang mga patakarang nabanggit.

Para humiling nito, mag-email sa [legal@wink.travel](mailto:legal@wink.travel) na may:

- pangalan ng iyong produkto,
- ang URL nito, kung ito ay live,
- kung paano mo planong gamitin ang supply ng Wink: kung ano ang ipapakita mo, saan, at kasabay ng ano.

Kami na ang bahala mula doon.
