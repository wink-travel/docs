Ipinapakita ng pahinang ito ang bawat kaganapan sa webhook na maaari mong i-subscribe sa Wink. Para sa mga tagubilin sa pagsasaayos, tingnan ang [Webhook Integration Guide](/tl/developers/webhook-integration) o ang [Webhooks management page](/tl/portal/settings/webhooks).

## Paano mag-subscribe

1. Pumunta sa **Applications > Webhooks** sa iyong portal.
2. Gumawa ng webhook at piliin ang mga kaganapan na nais mong matanggap.
3. Magpapadala ang Wink ng HTTP POST sa iyong endpoint sa tuwing magaganap ang kaganapan.

Para sa buong mga hakbang sa pagsasaayos at mga pinakamahusay na kasanayan, tingnan ang [Webhook Integration](/tl/developers/webhook-integration).

## Pamamahala ng mga kaganapan ng entity

Mga kaganapan para sa pamamahala ng mga entity (mga ari-arian, mga affiliate, mga kumpanya) at ang kanilang administrasyon.

### Lifecycle

| Kaganapan | Key | Paglalarawan |
|---|---|---|
| Entity created | `managing_entity.created` | Isang bagong managing entity ang nalikha. |
| Entity deleted | `managing_entity.deleted` | Isang managing entity ang natanggal. |
| Status updated | `managing_entity.status.updated` | Nagbago ang status ng entity. |
| Under review | `account.under_review` | Nakabinbing nire-review ang account ng entity. |

### Subscription

| Kaganapan | Key | Paglalarawan |
|---|---|---|
| Subscription provisioned | `managing_entity.subscription.provisioned` | Isang bagong subscription ang na-provision. |
| Subscription changed | `managing_entity.subscription.changed` | Nagbago ang plano ng subscription. |
| Subscription invoice changed | `managing_entity.subscription.invoice.changed` | Na-update ang invoice ng subscription. |

### Manager lifecycle

| Kaganapan | Key | Paglalarawan |
|---|---|---|
| Manager added | `managing_entity.manager.added` | Isang bagong manager ang naidagdag. |
| Manager invited | `managing_entity.manager.invited` | Naipadala ang imbitasyon sa manager. |
| Manager removed | `managing_entity.manager.removed` | Natanggal ang isang manager. |
| Manager accepted | `managing_entity.manager.accepted` | Tinanggap ang imbitasyon ng manager. |
| Manager rejected | `managing_entity.manager.rejected` | Tinanggihan ang imbitasyon ng manager. |
| Owner set | `managing_entity.manager.owner.set` | Nailipat ang pagmamay-ari ng entity. |
| Managers updated | `account.managers.update` | Nagbago ang listahan ng mga manager. |

### Impormasyon ng entity

| Kaganapan | Key | Paglalarawan |
|---|---|---|
| Information updated | `managing_entity.information.updated` | Na-update ang impormasyon ng entity. |
| Address updated | `managing_entity.city.updated` | Nagbago ang address/lungsod ng entity. |
| Name updated | `managing_entity.name.updated` | Nagbago ang pangalan ng entity. |
| URL name updated | `managing_entity.url_name.updated` | Nagbago ang vanity URL ng entity. |
| Unique ID updated | `managing_entity.unique_id.updated` | Nagbago ang natatanging identifier ng entity. |
| Managed-by updated | `managing_entity.managed_by.updated` | Nagbago ang relasyon ng parent/managed-by ng entity. |
| Place ID updated | `managing_entity.place_id.updated` | Nagbago ang Google Place ID ng entity. |
| Account representative updated | `managing_entity.account_representative.updated` | Nagbago ang kinatawan ng account. |
| Profile picture updated | `managing_entity.profile_picture.updated` | Na-update ang larawan ng profile ng entity. |
| Logo updated | `managing_entity.logo.updated` | Na-update ang logo ng entity. |
| Details updated | `account.details.updated` | Nagbago ang mga detalye ng account. |
| Agent updated | `managing_entity.agent.updated` | Nabago ang agent ng entity. |

### Mga notification

| Kaganapan | Key | Paglalarawan |
|---|---|---|
| Agent email notification | `managing_entity.agent.email.notification` | Naipadala ang email notification sa agent. |
| Manager email notification | `managing_entity.manager.email.notification` | Naipadala ang email notification sa isang manager. |
