Wink ponuja dva avtorizirana MCP strežnika. Oba uporabljata **interaktivno OAuth2 prijavo** (PKCE avtentikacijski tok s kodo za avtorizacijo) — vaš AI agent odpre zavihek brskalnika, kjer se prijavite z vašim Wink računom. Ni potrebe po upravljanju skrivnosti odjemalca.

| Strežnik | URL | Kaj počne |
|--------|-----|--------------|
| **Inventory API** | `https://api.wink.travel/mcp` | Inventar, rezervacije, cene, prodajni kanali, analitika in vse platformne operacije |
| **Integrations** | `https://integrations.wink.travel/mcp` | Integracije upravljalcev kanalov — sinhronizacija nastanitev, cen in razpoložljivosti z OTA |

---

## Kako deluje avtorizacija

Wink MCP strežniki uporabljajo **OAuth2 Authorization Code + PKCE** tok in podpirajo **Dynamic Client Registration (RFC 7591)**. Tako poteka povezava ob prvi uporabi:

1. Vaš AI odjemalec odkrije avtorizacijski strežnik iz metapodatkov MCP končne točke `/.well-known/oauth-protected-resource`.
2. Odjemalec se sam registrira prek **Dynamic Client Registration** — ni potrebe po ročni nastavitvi aplikacije.
3. Odjemalec odpre **zavihek brskalnika** na `https://iam.wink.travel`. Prijavite se z Wink računom in potrdite zahtevane pravice na zaslonu za soglasje.
4. Wink izda **dostopni žeton** z omejitvijo na vaš račun in povezan z vašo identiteto.
5. AI odjemalec priloži žeton vsakemu MCP zahtevku. Vsi rezultati orodij so samodejno omejeni na vašo upravljavsko entiteto.
6. Žetoni potečejo po 3 urah. Vaš AI odjemalec jih tiho osveži v ozadju brez ponovnega poziva.

Vsak klic orodja teče **v vaši identiteti** — enaka pravila ACL, ki varujejo spletni portal, veljajo tudi za AI agenta.

## Povežite svoj AI odjemalec

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Prepričajte se, da je Claude Code posodobljen:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Dodajte Wink Inventory MCP strežnik:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code kontaktira strežnik, odkrije avtorizacijski strežnik in odpre vaš privzeti brskalnik.

4. **Prijavite se v Wink** in potrdite zahtevo za dovoljenja na zaslonu za soglasje.

5. Claude Code potrdi povezavo. Vnesite `/mcp`, da preverite, ali se strežnik prikaže in so orodja naložena.
</Steps>

Za dodajanje tudi Integrations strežnika:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Delite s svojo ekipo]
Dodajte `--scope project` k `claude mcp add` in Claude Code zapiše URL strežnika v `.mcp.json` v korenu repozitorija. Potrdite to datoteko — vsak član ekipe opravi svojo prijavo v brskalniku ob prvi povezavi.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Uredite konfiguracijsko datoteko Claude Desktop:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. Dodajte vnose MCP strežnikov:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **Popolnoma zaprite in ponovno zaženite** Claude Desktop (uporabite Quit iz menijske vrstice — samo zapiranje okna ni dovolj).

4. Claude Desktop odpre zavihek brskalnika za vsak nov strežnik. Prijavite se v Wink in potrdite dovoljenja.

5. Ikona vtičnice v spodnji orodni vrstici pokaže oba strežnika kot povezana.
</Steps>

  </TabItem>

2. Odprite (ali ustvarite) konfiguracijsko datoteko Codex:
   - **macOS / Linux:** `~/.codex/config.json`
   - **Windows:** `%USERPROFILE%\.codex\config.json`

3. Dodajte vnose Wink MCP strežnikov:

   ```json title="~/.codex/config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

4. Zaženite Codex. Ob prvi uporabi Codex odpre zavihek brskalnika na `https://iam.wink.travel`.

5. **Prijavite se v Wink** in potrdite zahtevana dovoljenja.

6. Codex potrdi povezavo. Zaženite `codex` in ga prosite, naj izpiše razpoložljiva orodja, da preverite, ali so Wink strežniki aktivni.
</Steps>

:::note
Podpora MCP v Codex CLI zahteva različico **1.0** ali novejšo. Za preverjanje zaženite `codex --version` in za nadgradnjo `npm install -g @openai/codex`.
:::

  </TabItem>
  <TabItem label="ChatGPT">

Podpora MCP strežnikov je na voljo v **ChatGPT namizni aplikaciji** za naročnike Plus, Pro, Team in Enterprise.

<Steps>
1. Prenesite in namestite [ChatGPT namizno aplikacijo](https://openai.com/chatgpt/download/), če je še nimate.

2. Odprite aplikacijo in kliknite **ikono profila** v zgornjem desnem kotu, nato izberite **Nastavitve**.

3. Pojdite na **Povezovalnike** (ali **MCP strežniki** glede na različico aplikacije) in kliknite **Dodaj**.

4. Vnesite URL Wink Inventory strežnika:
   ```
   https://api.wink.travel/mcp
   ```
   Nato kliknite **Poveži**.

5. ChatGPT odpre zavihek brskalnika na `https://iam.wink.travel`. **Prijavite se v Wink** in potrdite dovoljenja.

6. Ponovite koraka 4–5 za Integrations strežnik:
   ```
   https://integrations.wink.travel/mcp
   ```

7. Oba strežnika se prikažeta na seznamu Povezovalnikov. Začnite nov klepet — Wink orodja so samodejno na voljo.
</Steps>

:::note[Omejitev spletne aplikacije]
MCP strežniki so konfigurabilni samo v **namizni aplikaciji**. Spletni vmesnik ChatGPT na chatgpt.com ne podpira prilagojenih MCP strežnikov.
:::

## Referenca obsegov

Ko potrdite zaslon za soglasje, boste videli razčlenitev, kaj agent zahteva. Wink združuje dovoljenja po funkcionalnih področjih:

| Skupina obsega | Obsegi | Kaj omogočajo |
|-------------|--------|-----------------|
| **MCP transport** | `mcp.read` `mcp.write` `mcp.remove` | Potrebno za povezavo z obema MCP strežnikoma |
| **Račun** | `account.read` `account.write` `account.remove` | Upravljanje entitet, članov ekipe, nastavitev, aplikacij |
| **Rezervacija** | `booking.read` `booking.write` `booking.remove` | Iskanje, ogled, ustvarjanje, preklic in vračilo rezervacij |
| **Inventar** | `inventory.read` `inventory.write` `inventory.remove` | Nastanitve, sobe, cene, dodatki, razpoložljivost |
| **Analitika** | `analytics.read` | Analitika rezervacij, poročila o prihodkih, lestvice |
| **Marketing** | `marketing.read` `marketing.write` `marketing.remove` | Objave na družbenih omrežjih, kampanje, prodajni kanali, promocije |
| **Vsebina** | `content.read` `content.write` `content.remove` | Multimedija, skrajšani URL-ji, sinhronizabilni elementi, zemljevidi |
| **Plačilo** | `payment.read` `payment.write` | Knjigovodstvo, izplačila, finančne razčlenitve, dvigi |

AI odjemalec zahteva samo obsege, ki jih potrebuje. Posamezna dovoljenja lahko zavrnete na zaslonu za soglasje — orodja, ki zahtevajo zavrnjeni obseg, bodo ob klicu vrnila napako.

## Odpravljanje težav

**Zavihek brskalnika se ne odpre**

Vaš AI odjemalec morda še ne podpira interaktivnega PKCE toka. Preverite, da uporabljate najnovejšo različico:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT namizna aplikacija:** posodobite prek vgrajenega posodabljalnika aplikacije

**`401 Unauthorized` po prijavi**

Vaš predpomnjeni žeton je lahko potekel. Odstranite in ponovno dodajte strežnik, da sprožite novo prijavo:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

Za Claude Desktop in ChatGPT odstranite vnos strežnika iz nastavitev, znova zaženite aplikacijo in ga dodajte znova.

**`403 Forbidden` pri klicu določenega orodja**

Orodje zahteva obseg, ki ga niste potrdili na zaslonu za soglasje. Ponovno povežite strežnik — zaslon za soglasje se bo prikazal znova in lahko potrdite manjkajoče dovoljenje.

**Strežnik se prikaže, a klici orodij vrnejo "račun ni najden"**

Prijavljeni ste v Wink račun, ki nima upravljavske entitete. Obiščite [Wink Portal](https://app.wink.travel) in poskrbite, da je vaš račun pravilno nastavljen pred uporabo MCP strežnika.

**Žeton poteče med sejo**

Žetoni veljajo 3 ure. Claude Code in Claude Desktop tiho osvežujeta žetone brez prekinitve seje. Če po dolgem mirovanju vidite napake pri avtorizaciji, vnesite novo sporočilo — odjemalec se bo samodejno ponovno avtoriziral.

**Codex CLI prikaže "MCP server unreachable"**

Preverite, da je vaša datoteka `~/.codex/config.json` veljaven JSON (brez odvečnih vejic) in da je `"type": "http"` nastavljeno. Codex zahteva HTTP transport za oddaljene strežnike; stdio transport je samo za lokalne binarne datoteke.

**V meniju ChatGPT manjka "Connectors"**

Podpora MCP zahteva različico ChatGPT namizne aplikacije **1.2024.352** ali novejšo in aktivno naročnino Plus, Pro, Team ali Enterprise. Posodobite aplikacijo in preverite svoj načrt v Nastavitve → Račun.

**Cursor strežnik kaže rdeče / "Failed to connect"**

Preverite, da je vaša datoteka `~/.cursor/mcp.json` veljaven JSON in vsebuje `"type": "http"`. Nato pojdite na **Nastavitve → Nastavitve Cursor → MCP** in kliknite **Osveži**. Če napaka ostaja, popolnoma znova zaženite Cursor — spremembe konfiguracije niso vedno zaznane brez ponovnega zagona.

**Windsurf MCP strežniki niso prikazani v nastavitvah**

Windsurf zahteva popoln ponovni zagon (ne samo osvežitev okna), da zazna spremembe v `mcp_config.json`. Uporabite **Datoteka → Izhod** in ponovno zaženite. Če strežniki še vedno niso prikazani, preverite, da imate Windsurf **1.4+** prek **Pomoč → O Windsurf**.

**V Cline ni vidna možnost "Add Server"**

Upravljalnik MCP strežnikov zahteva Cline **2.0** ali novejši. Odprite panel razširitev VS Code, poiščite Cline in kliknite **Posodobi**, če je na voljo posodobitev. Po posodobitvi znova naložite VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
