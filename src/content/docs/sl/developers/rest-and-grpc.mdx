Wink ponuja dva transporta. Kateri uporabite, je odvisno od tega, s katerim API-jem se integrirate.

| | Transport | Shema | Dokumentacija |
| --- | --- | --- | --- |
| Večina Wink API-jev | REST prek HTTPS | OpenAPI 3 | Katera koli skupina pod **API** v stranski vrstici |
| Partner Integrator API | gRPC prek HTTP/2 | Protocol Buffers | [Partner](/sl/partner-api/partner/) |

<Aside type="note" title="Jezikovni SDK-ji niso več objavljeni">
  Ročno vzdrževani SDK-ji so zaostajali za API-ji, ki so jih ovijali, in nikoli niso pokrivali jezika, ki ste ga dejansko potrebovali. Namesto tega generirajte odjemalca iz sheme — ta je vedno aktualna — ali pa naj naš MCP strežnik napiše integracijsko kodo, prilagojeno vašemu primeru uporabe.
</Aside>

## Generirajte REST odjemalca

Vsaka skupina API-jev objavi dokument OpenAPI 3. Usmerite kateri koli generator OpenAPI nanj in dobite tipiziranega odjemalca v vašem jeziku.

```bash
# Specifikacija za skupino je na voljo poleg njene referenčne strani.
curl -o wink-extranet.json https://api.wink.travel/v3/api-docs/extranet

npx @openapitools/openapi-generator-cli generate \
  -i wink-extranet.json -g typescript-fetch -o ./wink-client
```

## Generirajte gRPC odjemalca

Partner Integrator API je gRPC. Odjemalca generirate iz `.proto` sheme, ki jo Wink objavlja na dva načina:

- **Server reflection** — strežnik se sam opiše, tako da orodja, kot so `grpcurl`, Postman in Insomnia, lahko med izvajanjem odkrijejo shemo brez prenosa datotek. Reflection zahteva isti žeton nosilca kot kateri koli drug klic.
- **Datoteke `.proto`**, če raje vključite shemo in generirate vnaprej.

```bash
# Odkrijte shemo iz delujočega strežnika (avtenticirano).
grpcurl -H "authorization: Bearer $WINK_TOKEN" \
  partner.wink.travel:443 list

# Nato generirajte odjemalca — tukaj Go; vsak podprt jezik deluje enako.
protoc --go_out=. --go-grpc_out=. partner_lookup.proto
```

Klici nosijo vaš žeton nosilca v metapodatkovnem glavi `authorization`, enako kot REST v glavi `Authorization`. Napake pridejo kot gRPC statusna koda v odzivnih zaključkih namesto kot HTTP statusna koda — [Partnerjeva referenca](/sl/partner-api/partner/) navaja statuse, ki jih lahko pričakujete.

## Ali pa naj MCP strežnik napiše kodo

Če uporabljate AI pomočnika za kodiranje, je naš MCP strežnik najhitrejša pot.
