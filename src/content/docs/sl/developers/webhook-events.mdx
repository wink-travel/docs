Ta stran navaja vse dogodke webhook, na katere se lahko naročite na Wink. Za navodila za nastavitev si oglejte [Vodnik za integracijo Webhook](/sl/developers/webhook-integration) ali [Stran za upravljanje Webhookov](/sl/portal/settings/webhooks).

## Kako se naročiti

1. Pojdite na **Applications > Webhooks** v vašem portalu.
2. Ustvarite webhook in izberite dogodke, ki jih želite prejemati.
3. Wink pošlje HTTP POST na vašo končno točko vsakič, ko se dogodek zgodi.

Za celotne korake nastavitve in najboljše prakse si oglejte [Integracijo Webhook](/sl/developers/webhook-integration).

## Upravljanje dogodkov entitet

Dogodki za upravljanje entitet (lastnosti, podružnice, podjetja) in njihovo administracijo.

### Življenjski cikel

| Dogodek | Ključ | Opis |
|---|---|---|
| Entiteta ustvarjena | `managing_entity.created` | Ustvarjena je bila nova upravljalska entiteta. |
| Entiteta izbrisana | `managing_entity.deleted` | Upravljalska entiteta je bila izbrisana. |
| Status posodobljen | `managing_entity.status.updated` | Status entitete se je spremenil. |
| V pregledu | `account.under_review` | Račun entitete je v pregledu. |

### Naročnina

| Dogodek | Ključ | Opis |
|---|---|---|
| Naročnina zagotovljena | `managing_entity.subscription.provisioned` | Nova naročnina je bila zagotovljena. |
| Naročnina spremenjena | `managing_entity.subscription.changed` | Načrt naročnine je bil spremenjen. |
| Račun za naročnino spremenjen | `managing_entity.subscription.invoice.changed` | Račun za naročnino je bil posodobljen. |

### Življenjski cikel upravitelja

| Dogodek | Ključ | Opis |
|---|---|---|
| Upravitelj dodan | `managing_entity.manager.added` | Dodan je bil nov upravitelj. |
| Upravitelj povabljen | `managing_entity.manager.invited` | Poslano je bilo povabilo upravitelju. |
| Upravitelj odstranjen | `managing_entity.manager.removed` | Upravitelj je bil odstranjen. |
| Upravitelj sprejet | `managing_entity.manager.accepted` | Povabilo upravitelju je bilo sprejeto. |
| Upravitelj zavrnjen | `managing_entity.manager.rejected` | Povabilo upravitelju je bilo zavrnjeno. |
| Lastnik nastavljen | `managing_entity.manager.owner.set` | Lastništvo entitete je bilo preneseno. |
| Upravitelji posodobljeni | `account.managers.update` | Seznam upraviteljev se je spremenil. |

### Informacije o entiteti

| Dogodek | Ključ | Opis |
|---|---|---|
| Informacije posodobljene | `managing_entity.information.updated` | Informacije o entiteti so bile posodobljene. |

| Ime posodobljeno | `managing_entity.name.updated` | Ime entitete se je spremenilo. |

| Place ID posodobljen | `managing_entity.place_id.updated` | Google Place ID entitete se je spremenil. |
| Predstavnik računa posodobljen | `managing_entity.account_representative.updated` | Predstavnik računa je bil spremenjen. |
