Booking Engine se vgradi kjerkoli. Izberite svoj okvir ali CMS in sledite njegovemu vodniku; osnovni Web Components so povsod enaki.

## Osnovni pristopi

- [Web Components](/sl/integrations/web-components/) — vgradljivi elementi, ki jih uporablja vsaka integracija.
- [npm package](/sl/integrations/npm/) — namestitev v JavaScript gradnjo.
- [Headless CMS](/sl/integrations/headless/) — prikaz iz katerega koli vsebinskega backend-a.
- [Partner API](/sl/integrations/partner-api/) — popolna programska integracija.
