Denna guide tar en resebyrå från registrering till dess första kundbokning. Den förklarar också de två sätt en byrå kan arbeta på med Wink, så att du kan välja rätt innan du börjar.

## Innan du börjar

Du behöver:

- Dina företagsuppgifter.
- Ditt resebyråregistreringsnummer eller din IATA-kod om du har en sådan.
- Ett bankkonto för din provision.

## Välj hur du vill arbeta

| | Standard (de flesta byråer) | Agentinsamlad betalning |
|---|---|---|
| Hur du bokar | I Wink-portalen eller via Partner API | Via [Partner API](/sv/integrations/partner-api/), från ditt eget system |
| Vem tar emot kundens betalning | Betalningen samlas in för hotellet, som förblir betalningsmottagare. Du anger kundens kort vid utcheckning. | Du gör det, som betalningsmottagare. |
| Vad du tjänar | **10% standardprovision** på varje bokning | Provision enligt ditt eget avtal med varje hotell |
| Vad du betalar Wink | Ingenting | **1,5%** bokningsavgift på varje bokningsvärde, faktureras månadsvis, plus Partner API-användning över den fria gränsen |
| Betalning till hotellet | Hanteras åt dig | Du betalar varje hotell direkt, enligt ditt eget avtal med dem |
| Återbetalningar, chargebacks, betalningsöverensstämmelse | Hanteras åt dig | Ditt ansvar |
| Godkännande | Din registrering granskas innan du kan boka | Din registrering granskas, plus Winks skriftliga godkännande för denna väg, med en kreditgräns |

Wink granskar varje resebyrås registrering. De flesta byråer använder sedan standardvägen. Agentinsamlad betalning är endast för **API-partners**: byråer som bokar via Partner API från sitt eget system, redan samlar in kundbetalningar under egen licens och kontrakterar direkt med hotell.

## Steg 1: Registrera din byrå

<Steps>
1. Gå till [app.wink.travel](https://app.wink.travel), klicka på `Sign-In / Register` och registrera dig.

2. Klicka på `Accounts` i vänstra sidomenyn, sedan `Create`, och välj **I am a Travel Agent**.

3. Fyll i din byrås uppgifter. Välj **Company** som enhetstyp: det avgör hur du får betalt. Se [Create Account](/sv/portal/create-account/).

4. Om du ska samla in betalning själv via Partner API, välj den vägen vid registreringen. Detta är en förfrågan, inte ett godkännande. Se [Steg 6](#step-6-collect-payment-yourself-api-partners-only).

5. Wink granskar varje resebyråregistrering. Vi mejlar din registrerade adress och begär dina handlingar: företagsuppgifter och ditt resebyråregistreringsnummer eller IATA-kod. Du kan boka när din registrering är godkänd.
</Steps>

## Steg 2: Lägg till ditt bankkonto

Gå till `Account > Bank Accounts`, lägg till din byrås konto och markera det som **Primary**. Provision betalas ut dit via banköverföring. Wink skickar utbetalningar via Revolut, så ett Revolut företagskonto är det smidigaste alternativet, men vilket bankkonto som helst fungerar. Se [Bank Accounts](/sv/portal/settings/payouts/).

## Steg 3: Hitta hotell för din kund

<Steps>
1. Klicka på `Browse > Hotels` i huvudnavigeringsfältet.

2. Sök efter destination, datum och antal personer, och filtrera tills du har rätt alternativ för din kund.

3. Spara kortlistor till en [curated list](/sv/portal/studio/curated-lists/) om du jämför alternativ med kunden.
</Steps>

De priser du ser är hotellets egna. Wink vidarebefordrar dem oförändrade, utan påslag: du tjänar via provision. Se [Search](/sv/portal/studio/search/).

## Steg 4: Boka för din kund

<Steps>
1. Välj rum och pris, och ange din kunds namn och kontaktuppgifter som resenär.

2. Vid utcheckning, ange det kort din kund gav dig för denna bokning. Betalningen samlas in för hotellet, och hotellet förblir betalningsmottagare.

3. Bekräfta. Du, resenären och hotellet får varsin bekräftelse via e-post. Bokningskoden börjar med `WNK`.
</Steps>

:::caution[Hantera din kunds kort varsamt]
Be endast om kortet för den bokning du gör och ange det direkt i utcheckningen. Skriv inte ner det, mejla det eller spara det i dina egna register.
:::

## Steg 5: Hantera bokningar och få betalt

- **Bokningar:** klicka på `Bookings` i huvudnavigeringsfältet för att se alla bokningar, filtrera, exportera till CSV, skicka om en bekräftelse eller avboka inom hotellets avbokningspolicy. Se [Bookings](/sv/portal/travel-agent/bookings/).
- **Provision:** 10% som standard. När du arbetar regelbundet med ett hotell kan du be om en [direktkoppling](/sv/portal/studio/network/) och komma överens om en annan provision.
- **När du får betalt:** provisionen blir tillgänglig inom 24 timmar efter att gästen checkat in och går till ditt primära bankkonto. Överföringsavgifter betalas till självkostnadspris. Se [Pricing](/sv/getting-started/pricing/).

## Steg 6: Samla in betalning själv (endast API-partners)

Hoppa över detta steg om du bokar i portalen eller är nöjd med standardvägen.

<Steps>
1. Integrera med [Partner API](/sv/integrations/partner-api/). Denna väg fungerar endast via API, från ditt eget bokningssystem, inte i portalen.

2. Välj denna väg vid registreringen (Steg 1).

3. Wink bedömer detta tillsammans med dina registreringshandlingar, till exempel din ekonomiska status och regulatoriska status, och bekräftar skriftligen. Godkännandet kommer med en **kreditgräns**: det högsta belopp du kan ha i obetalda bokningar samtidigt.

4. Tills du är godkänd kan du fortsätta boka via standardvägen.
</Steps>

När du är godkänd tar du själv emot kundens betalning och betalar varje hotell direkt. För varje bokning drar du, i ordning, av 1,5% Wink-avgift och sedan din provision; resten betalas till hotellet:

| På en bokning på 1 000,00 USD med 10% provision | |
|---|---|
| Bokningsvärde | 1 000,00 USD |
| Minus Wink-avgift (1,5% av bokningsvärdet) | 15,00 USD |
| Delsumma | 985,00 USD |
| Minus din provision (10% av delsumma) | 98,50 USD |
| **Till hotellet** | **886,50 USD** |

Wink fakturerar 1,5% bokningsavgift månadsvis, i USD, med betalningsvillkor 15 dagar, plus eventuell Partner API-användning över den fria gränsen. Du ansvarar för återbetalningar, chargebacks, betalningssäkerhet (PCI-DSS) och eventuell licens som ditt land kräver för att samla in betalning. Fullständiga villkor finns i [Travel Agent Agreement](/sv/legal/platform-agreements/).

## Koppla dina egna system

Byråer med egna bokningsverktyg kan söka och boka via [Partner API](/sv/integrations/partner-api/). Resebyrakonton kan skapa bokningar direkt via det, och det är det enda sättet att arbeta på agentinsamlad väg. Se [Partner API reference](/sv/partner-api/partner/).

## Din checklista

- [ ] Byrå registrerad som Travel Agent-konto
- [ ] Handlingar skickade och registrering godkänd
- [ ] Bankkonto tillagt och markerat som Primary
- [ ] Första hotell hittade för en kund
- [ ] Första bokningen gjord, kort angivet vid utcheckning
- [ ] Valfritt, API-partners: valt att samla in betalning själv vid registrering
