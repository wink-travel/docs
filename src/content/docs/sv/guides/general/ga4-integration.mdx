Genom att koppla din Google Analytics 4-egendom till Wink skickas dina bokningsevent — från rumsvisningar till slutförda bokningar — automatiskt vidare till din egen GA4-instrumentpanel tillsammans med Winks egna analyser. Ingen kod, ingen teknisk installation från din sida.

<Aside type="tip">
Du behöver två saker från GA4: ett **Measurement ID** och en **Measurement Protocol API-hemlighet**. Measurement ID driver surftratten i gästens webbläsare; API-hemligheten låter Wink registrera slutförda bokningar (`purchase`) **server-side**, så att en försäljning aldrig går förlorad när gästen omdirigeras till och från betalningsleverantören.
</Aside>

---

## Så här fungerar det

```
Du anger ditt Measurement ID (G-XXXXXXXXXX) och API-hemlighet i Wink-portalen
       ↓
Surfevent (visningar, kundvagn, kassa) strömmas till din GA4-egendom från webbläsaren
Slutförda bokningar (purchase) skickas server-side — överlever betalningsomdirigeringen
       ↓
Du loggar in på analytics.google.com och ser din fullständiga bokningstratt
```

---

## Vad du behöver göra

<Steps>

1. **Skapa en GA4-egendom**

   Gå till [analytics.google.com](https://analytics.google.com): Admin → Skapa egendom. Ställ in din tidszon och valuta så att de matchar din marknad.

2. **Skapa en webbdatastream**

   Admin → Data Streams → Lägg till stream → Webb. Ange `wink.travel` som URL. Detta genererar ditt **Measurement ID** (`G-XXXXXXXXXX`). Kopiera det.

3. **Skapa en Measurement Protocol API-hemlighet**

   Öppna samma webbdatastream → scrolla till **Measurement Protocol API secrets** → **Skapa**. Ge den ett smeknamn (t.ex. "Wink") och kopiera det genererade **hemliga värdet**. Denna hemlighet gör det möjligt för Wink att registrera slutförda bokningar server-side, så att en försäljning aldrig går förlorad under betalningsomdirigeringen.

4. **Ange ditt Measurement ID och API-hemlighet i Wink-portalen**

   Logga in på [app.wink.travel](https://app.wink.travel), välj ditt konto och gå till fliken **Anpassningar**. Klistra in ditt Measurement ID och API-hemlighet i **GA4**-fälten och spara. Det är allt — din GA4-integration är nu aktiv.

   <Aside type="note">
   API-hemligheten är **skrivskyddad**: när den väl sparats visas den aldrig igen. Vid framtida redigeringar, lämna hemlighetsfältet tomt för att behålla det värde du redan sparat.
   </Aside>

5. **Markera `purchase` som ett nyckelevent**

   Tillbaka i din GA4-egendom: Admin → Events → hitta `purchase` → slå på **Markera som nyckelevent**. Detta gör att slutförda bokningar visas i din konverteringsrapport.

6. **Visa dina data**

   Logga in på [analytics.google.com](https://analytics.google.com) så ser du dina bokningar, intäkter och gästtratt — allt spåras automatiskt via Wink.

</Steps>

<Aside type="note">
Du behöver inte installera någon spårningskod på din egen webbplats för denna integration. Wink hanterar allt. Ditt Measurement ID är destinationen dit dina bokningsdata skickas, och din API-hemlighet låter Wink bekräfta slutförda bokningar server-side.
</Aside>

<Aside type="tip">
**GA4 och GTM kan användas tillsammans.** Om du även kör en Google Tag Manager-container (till exempel en Sojern-container) kan du konfigurera båda samtidigt — de är inte längre ömsesidigt uteslutande. Se [GTM Analytics Integration](/sv/guides/developers/gtm-dual-tagging).
</Aside>

## Vad du kan spåra

När du är ansluten tar din GA4-egendom emot hela sviten av Enhanced E-commerce-event för din egendom:

### Upptäckt

| Event | Vad det betyder |
|---|---|
| `view_item_list` | En gäst såg din egendom i en sökning eller kategorilista |
| `select_item` | En gäst klickade på din egendom från en lista |
| `view_item` | En gäst visade din hotells detaljsida |

### Övervägande

| Event | Vad det betyder |
|---|---|
| `view_promotion` | En gäst såg ett kampanjerbjudande för din egendom |
| `select_promotion` | En gäst klickade på ett kampanjerbjudande |
| `add_to_wishlist` | En gäst sparade din egendom i sin önskelista |

### Bokningstratt

| Event | Vad det betyder |
|---|---|
| `add_to_cart` | En gäst valde ett rum eller paket |
| `view_cart` | En gäst visade sin bokningsöversikt |
| `remove_from_cart` | En gäst tog bort ett rum eller paket |
| `begin_checkout` | En gäst påbörjade kassaprocessen |
| `add_payment_info` | En gäst angav sina betalningsuppgifter |
| `add_shipping_info` | En gäst angav sina gästuppgifter |
| `purchase` | En gäst slutförde en bokning |
| `refund` | En bokning avbokades och återbetalades |

Alla event inkluderar relevanta dimensioner som intäkter, valuta, rumstyp och bokningsvärde — vilket ger dig en fullständig bild av gästresan från första intryck till slutförd bokning. För att låsa upp ytterligare egendoms- och rumsspecifika dimensioner som `city_name`, `cancellation_policy`, `bed_type` med mera, se [Custom Dimensions in GA4](/sv/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4).

## Cross-Domain Tracking (Avancerat)

Standardintegration ovan spårar allt som händer inom Wink. Men om du vill spåra gäster hela vägen från din egen webbplats till bokningsslutförande på Wink — och korrekt tillskriva den ursprungliga trafik-källan (Google Ads, e-postkampanjer, organisk sökning etc.) — krävs ett extra steg på varje sida.

<Aside type="caution">
Denna sektion gäller endast om du har GA4 installerat på din egen webbplats. Om du inte kör GA4 på din sida räcker standardintegration ovan.
</Aside>

### Varför detta är viktigt

Utan cross-domain tracking kommer en gäst som först besöker din webbplats och sedan bokar på Wink att visas i din GA4 som en **Direkt** session utan koppling till deras tidigare besök. Eventuella Google Ads-klick, e-postkampanjer eller organiska sökbesök som ledde till bokningen får ingen kredit.

Med cross-domain tracking konfigurerad ser du hela gästresan:

```
google.com (betald annons)
       ↓
din webbplats (gästen bläddrar bland rum)
       ↓
wink.travel (gästen väljer rum och bokar)
       ↓
purchase tillskrivs korrekt till det ursprungliga Google Ads-klicket
```

### Åtgärd krävs: Du

Konfigurera din GA4-egendom för att känna igen `wink.travel` som en del av din egen domän, inte som en extern hänvisning. Detta talar om för GA4 att sammanfoga de två sessionerna till en kontinuerlig gästresa.

<Steps>
1. GA4 Admin → Data Streams → din stream
2. Konfigurera tagginställningar → **Konfigurera dina domäner**
3. Lägg till `wink.travel` som en länkad domän
4. Spara
</Steps>

### Åtgärd krävs: Wink

Kontakta [Wink Support](https://app.wink.travel) och ange din webbplatsdomän (t.ex. `yourhotel.com`). Wink lägger till din domän i exkluderingslistan för hänvisningar i Wink GA4-egendom. Detta förhindrar att din webbplats registreras som en hänvisningskälla, vilket annars skulle skriva över gästens ursprungliga tillskrivning och starta en ny session.

<Aside type="tip">
Standardintegration ovan räcker för de flesta egendomar och ger dig omedelbar insyn i bokningar och intäkter på Wink. Cross-domain tracking är ett avancerat alternativ som är värt att konfigurera när du är bekväm med dina GA4-data och vill ha djupare tillskrivningsinsikt.
</Aside>
