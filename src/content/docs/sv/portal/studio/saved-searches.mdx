Sparade sökningar gör precis vad namnet antyder. När du söker efter reseinventarier har du möjlighet att spara din sökfråga för senare användning.

## Spara din sökfråga

När du börjar söka efter inventarier (se [Search](/sv/portal/studio/search)) kan du finjustera dina sökfilter.
Längst ner i sökformuläret finns alternativet `Save search`.

Genom att klicka på denna länk får du möjlighet att ge sökningen ett namn (*t.ex. Min samling av magiska hotell*) som du kommer ihåg senare.

<figure>

      width="350"

    <figcaption>*Ge din sökning ett namn*</figcaption>
</figure>

Ge den ett namn och klicka på knappen `Save search`. Därefter kan du navigera till `Lists > Dynamic` från huvudmenyn för att se din nyss skapade post.

## Liståtgärder

Din sparade sökning kan användas för att visa reseinventarier för dina användare i form av ett rutnät eller en karta och göra så att dina sökresultat visas på det sätt du vill.

<figure>
<CloudinaryImage

    <figcaption>*Sparad sökfråga utan tillämpade filter*</figcaption>

Varje sparad sökfråga har åtgärder du kan utföra på den:

- Konvertera sökfrågan till en [karta](/sv/portal/studio/maps).
- Konvertera sökfrågan till ett [rutnät](/sv/portal/studio/grids).
- Ta bort den sparade sökningen.

## API

Utvecklare som vill hantera sparade sökningar kan gå till [Developers > API > Browse](/sv/api).
