För att hantera dina avbokningsregler, klicka på `Monetize > Cancellation policies` i huvudnavigeringsfältet.

Avbokningsregler bestämmer hur bokarens medel hanteras om gästen inte kan komma. Avbokningsregler finns i två olika varianter:

1. Återbetalningsbara
2. Icke återbetalningsbara

I de flesta fall räcker dessa två alternativ. Men båda ger dig stor möjlighet att anpassa din avbokningsregel ytterligare.

:::tip[Rolig fakta]
Wink stödjer totalt 8500 variationer av avbokningsregler.
:::

För att skapa en avbokningsregel, klicka på knappen `Create a new cancellation policy`.

## Icke återbetalningsbar

För att skapa en icke återbetalningsbar avbokningsregel, ställ in reglaget på 🛑 av när du blir tillfrågad om regeln är återbetalningsbar.

### Alternativ

Du kan valfritt konfigurera din `icke återbetalningsbara` regel ytterligare för större kontroll.

- **Hur mycket debiteras gästen vid en avbokning?** Som standard är en icke återbetalningsbar regel 100% icke återbetalningsbar. Du kan finjustera beloppet här. *t.ex. 50% av totalpriset*
- **Har debiteringen en tidsgräns?** Om du finjusterade beloppet kan du finjustera det ytterligare genom att ange hur länge det beloppet gäller. *t.ex. Fram till 3 dagar före ankomst*
- **Hur mycket debiteras gästen vid avbokning efter tidsgränsen?** Om gästen avbokar efter den angivna tidsgränsen kan du ange hur mycket gästen ska betala efter tidsgränsen. *t.ex. 70% av totalpriset*

## Återbetalningsbar

För att skapa en återbetalningsbar avbokningsregel, ställ in reglaget på ✅ på när du blir tillfrågad om regeln är återbetalningsbar.

### Alternativ

Du kan valfritt konfigurera din `återbetalningsbara` regel ytterligare för större kontroll.

- **Hur länge före ankomst kan gästen avboka utan kostnad?** Som standard är en återbetalningsbar regel alltid 100% återbetalningsbar. Du kan finjustera tidsgränsen här. *t.ex. 3 dagar före ankomst*
- **Vad ska gästen debiteras om avbokningen sker efter tidsgränsen ovan?** Om du finjusterade tidsgränsen kan du ange hur mycket gästen ska betala efter tidsgränsen. *t.ex. 50% av totalpriset*
- **Hur mycket ska gästen debiteras vid 'No show'?** Om gästen inte dyker upp kan du ange hur mycket gästen debiteras för en `No show`. *t.ex. 100% av totalpriset*
