# Inställningar

När du först börjar med Social kommer vi att fråga hur du vill att vi ska skapa ditt innehåll. Dessa alternativ är alltid tillgängliga för dig så att du enkelt kan ändra dem senare.

Navigera till `Settings` i sidomenyn för att hantera dina inställningar.

Sektionen för preferenser innehåller dina grundläggande inställningar för innehållsgenerering:

1. **Föredragen anpassning** Välj vilken anpassning som ska användas vid generering av innehåll. Anpassningar styr temafärger, standardresplan, valuta, språk med mera. Du skapar anpassningar under ditt konto på [app.wink.travel](https://app.wink.travel).
2. **Auto-godkänn** När detta är aktiverat publiceras genererade inlägg automatiskt utan att kräva ditt godkännande. Aktivera detta när du är säker på kvaliteten på det innehåll vi producerar åt dig.
3. **Godkännare namn** Namnet på personen eller teamet som kommer att få e-post om godkännande av inlägg.
4. **Godkännare e-post** E-postadressen dit godkännandeförfrågningar för kommande inlägg skickas.

## Innehållsskapare

  <figcaption>*Fig. 2 - Innehållsskapare*</figcaption>

Social har många innehållsskapare att välja mellan. Varje skapare fokuserar på ett specifikt sätt att skapa unikt innehåll för din anläggning med hjälp av AI. Varje innehållsskapare har en **Vikt** — en högre vikt ökar chansen att just den skaparen väljs vid generering av inlägg.

Här är alla tillgängliga innehållsskapare:

| Skapare | Beskrivning |
| -- | -- |
| **Destination** | Använder din plats för att skapa hjälpsam text om området |
| **Rumstyp** | Skapar ett bokningsbart inlägg med en av dina rumstyper med AI-genererad text och bilder på rumstypen |
| **Aktivitet** | Skapar ett bokningsbart inlägg med en av dina aktiviteter |
| **Tillägg** | Skapar ett bokningsbart inlägg med ett av dina tillägg |
| **Attraktion** | Skapar ett bokningsbart inlägg med en av dina attraktioner |
| **Plats** | Skapar ett bokningsbart inlägg med en av dina platser |
| **Mötesrum** | Skapar ett bokningsbart inlägg med ett av dina mötesrum |
| **Restaurang** | Skapar ett bokningsbart inlägg med en av dina restauranger |
| **Spa** | Skapar ett bokningsbart inlägg med ett av dina spa |
| **Anläggning** | Skapar ett bokningsbart inlägg med ditt bäst prissatta rum med AI-genererad text och bilder på anläggningen |
| **Användarsentiment** | Samlar gästrecensioner från hela webben till ett sentimentdrivet inlägg som lyfter fram vad gäster älskar med din anläggning |
| **Rolig** | Skapar lättsamma, underhållande inlägg för att hålla ditt flöde engagerande |

:::tip[Proffstips]
Se till att du har den inventarietyp som krävs för dina valda innehållsskapare. Om du till exempel väljer "Restaurang" måste du ha minst en restaurang listad på din anläggning.
:::

## Tonläge

Tonläget bestämmer språkstilen AI använder när innehåll genereras. Välj de toner som matchar din varumärkespersonlighet. Precis som med innehållsskapare har varje ton en **Vikt** för att styra hur ofta den används.

Här är de tillgängliga tonerna:

| Ton | Stil |
| -- | -- |
| **Neutral** | Lugnt, auktoritativt, faktabaserat. Ingen hype, inga skämt — bara pålitlig, välstrukturerad kunskap |
| **Vänlig** | Varm, tillgänglig, med ett leende i texten, avslappnade sammandragningar och ibland emojis |
| **Lyxig** | Sofistikerad, förfinad. Ord som "utsökt" och "skräddarsydd" som får läsaren att känna sig exklusiv |
| **Matälskare** | Sinnliga, aptitretande beskrivningar. Matporrspråk som gör läsaren hungrig |
| **Äventyrlig** | Djärv, orädd, upptäckarenergi. Levande sinnesbeskrivningar som får allt att låta episkt |
| **Familj** | Hälsosam, barnvänlig entusiasm. Varm föräldraenergi om säkra och roliga upplevelser |
| **Romantisk** | Poetisk, längtande, hjärtefladdrande. Solnedgångar, mjukt språk och kärlek |
| **Humoristisk** | Sarkastisk, snabba one-liners, smart ordlek. Låter som en stand-up-show |
| **Ekologisk** | Ärlig och rättfärdig. Hyllar gröna alternativ och hållbara val |
| **Lokal insider** | Mycket specifika lokala referenser, varnar för turistfällor, använder lokal slang |
| **Inkluderande** | Välkomnande, firande och bekräftande. Får alla att känna sig sedda och värderade |
| **Mystisk** | Eterisk, andlig, kosmiska sanningar. Mjuka inbjudningar att se inåt |
| **Futuristisk** | Snygg, framåtblickande. Älskar termer som "paradigmskifte" och optimistiska framtidsvisioner |
| **Budget** | Uppfinningsrik, resursstark, stolt sparsam. Hyllar prisvärda fynd och gratisupplevelser |

## Inläggstyper

Inläggstyper bestämmer målet och strukturen för det genererade innehållet. Varje inläggstyp har en **Vikt** för att styra hur ofta den används.

| Inläggstyp | Beskrivning |
| -- | -- |
| **Transaktionell** | Klar, koncis, konverteringsfokuserad. Driver bokningar och direkta åtgärder med fakta, priser och nästa steg |
| **Medvetenhet** | Varumärkesbyggande innehåll som är utformat för att introducera din anläggning och öka synligheten bland potentiella gäster |
| **Sentiment** | Känslomässigt resonant innehåll som skapar positiva associationer och bygger en emotionell koppling med din publik |

Du kanske vill rikta dina marknadsföringsinsatser mot ett särskilt språk och en region. Berätta vilka språk du vill skapa innehåll för och vilken tidszon du är intresserad av så sköter vi resten. Inlägg publiceras vid schemalagd tid i din valda tidszon.

*De flesta anläggningar använder ett enda språk och standardiserar till sitt lokala språk.*

## Google Business

<figure>
<CldImage
  src="academy/social_google_business"

  <figcaption>*Fig. 5 - Google Business*</figcaption>

Genom att koppla ditt Google Business Profile kan vi hämta rikare anläggningsdetaljer för mer effektivt innehåll. Din anläggning behöver en verifierad Google Business Profile för att vi ska kunna generera innehåll från din lista. Vissa av våra innehållsskapare **kräver** att du har ett Google Business-konto.

:::tip[Proffstips]
Börja smått

Var inte för ambitiös vid första försöket. Vi rekommenderar att du börjar med att skapa innehåll för din anläggning på ett enda språk.
:::
