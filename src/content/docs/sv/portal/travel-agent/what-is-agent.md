Registrerade resebyråer använder samma portal som alla andra, på [app.wink.travel](https://app.wink.travel), med ett Travel Agent-konto. Agenter söker och bokar åt sina kunder och tjänar en provision på varje bokning. För att skapa ett konto, följ [Kom igång som resebyrå](/sv/guides/travel-agents/getting-started/).

Byråer som är godkända att själva ta emot betalningar agerar som merchant of record och hanterar betalningar utanför Wink-plattformen. Byråer med egna system kan integrera via [Partner API](/sv/integrations/partner-api/).

Resebyråer har en delmängd av samma portalfunktioner som [Studio](/sv/portal/studio/what-is-studio) så vi kommer inte att gå igenom dem igen här.

## Sök

Gå till [Search](/sv/portal/studio/search) för att lära dig hur du söker efter och bokar hotell.

Annars, fortsätt till nästa avsnitt.

## API

Byråer kan söka och boka via [Partner API](/sv/partner-api/partner/), som ersätter de äldre Travel Agent REST-endpunkterna.
