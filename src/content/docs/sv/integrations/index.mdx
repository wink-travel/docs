Booking Engine kan bäddas in var som helst. Välj ditt ramverk eller CMS och följ dess guide; de underliggande Web Components är desamma överallt.

## Kärnmetoder

- [Web Components](/sv/integrations/web-components/) — de inbäddningsbara elementen som varje integration använder.
- [npm package](/sv/integrations/npm/) — installera i en JavaScript-bygge.
- [Headless CMS](/sv/integrations/headless/) — rendera från vilken innehållsbackend som helst.
- [Partner API](/sv/integrations/partner-api/) — fullständig programmatisk integration.
