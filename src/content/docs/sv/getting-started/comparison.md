## Wink vs Internet Booking Engine (IBE)

Vissa hotell försöker jämföra oss med deras internetbokningsmotor som följde med deras kanalhanterare och ber oss ge dem ett fast, månatligt pris baserat på antalet rum på deras anläggning.

Vi är inte en IBE och förhoppningsvis hjälper detta till att klargöra skillnaden. Det finns för- och nackdelar med alla tjänster. Om din IBE fungerar för din anläggning, fortsätt använda den.  
Wink finns för att fylla flera luckor i resebranschen och samla allt på ett ställe. 

:::tip
Du behöver inte byta ut din befintliga IBE. Vi rekommenderar dock att du provar vår sociala, användarvänliga bokningsmotor eller länkhanterare på ett av dina sociala mediekonton för att se hur de konverterar. Du betalar inget om det inte blir några bokningar – Vad har du att förlora? 😉
:::
