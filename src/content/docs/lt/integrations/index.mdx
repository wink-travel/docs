Booking Engine galima įterpti bet kur. Pasirinkite savo sistemą ar CMS ir sekite jos gidu; pagrindiniai Web Components yra vienodi visur.

## Pagrindiniai metodai

- [Web Components](/lt/integrations/web-components/) — įterpiami elementai, kuriuos naudoja kiekviena integracija.
- [npm package](/lt/integrations/npm/) — įdiekite į JavaScript projektą.
- [Headless CMS](/lt/integrations/headless/) — atvaizdavimas iš bet kokios turinio sistemos.
- [Partner API](/lt/integrations/partner-api/) — pilna programinė integracija.
