Wink **Partnerio API** yra autentifikuotas, didesnio pralaidumo būdas integratoriams užklausti rezervuojamą kelionių inventorių — tą patį tiekimą, kuris maitina mūsų įterpiamus valdiklius ir viešus naršymo galinius taškus, pateiktus kaip pirmos klasės programinis sąsajos sprendimas. Nemokami Web Components ir vieši naršymo galiniai taškai skirti lengvam, žmogui skirtam įterpimui, o Partnerio API sukurtas sistemoms, kurios ieško, kainuoja ir rezervuoja dideliu mastu. Prieiga yra autentifikuota pagal integratorių ir apmokestinama pagal naudojimą, todėl mokate tik už tikrą siunčiamą srautą.

## Planai ir kainodara

Naudojimas matuojamas **viešbučio nakvynėmis**: vienas viešbutis įkainojamas už vieną nakvynę — *ne* už vieną API užklausą. Paieška, kuri grąžina 20 viešbučių 3 nakvynių laikotarpiui, yra 60 viešbučio nakvynių iš vienos užklausos. Turinio ir paieškos (paskirties vietos paieška ir automatinis užbaigimas) užklausos yra išimtis: kiekviena kainuoja po vienetą už užklausą, nesvarbu, ką grąžina. Sąskaitos galiniai taškai yra nemokami. [Kainodara](/lt/pricing/) yra tiksliausias tarifų šaltinis.

## API nuoroda

Dvi sąsajos aptarnauja rezervuojamą inventorių ir atitinka aukščiau nurodytus du lygius:

- **Nemokamas — Vartotojo / Rezervavimo variklio API** (REST, `/api/public/**`): anoniminis, naršyklės ir valdiklio sąsajai. [Naršykite Rezervavimo variklio nuorodą →](/lt/api/booking-engine/)
- **Mokamas — Partnerio integratoriaus API** (**gRPC**, `wink.partner.v1`): autentifikuotas, matuojamas pagal naudojimą, sukurtas serverių integracijai dideliu mastu. [Naršykite Integratoriaus nuorodą →](/lt/partner-api/partner/)

Partnerio integratoriaus API yra gRPC, ne REST. Jį kviečiate sugeneruotu klientu per HTTP/2 adresu
`partner.wink.travel:443`, perduodant nešėjo žetoną ir paskyrą, už kurią kviečiate:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

Aukščiau pateikta nuorodų puslapis dokumentuoja kiekvieną paslaugą, žinutę ir klaidų būseną, o schema taip pat
yra prieinama vykdymo metu per serverio atspindį, todėl `grpcurl`, Postman ir Insomnia ją atranda be jokio atsisiuntimo.

Jei norite iš anksto sugeneruoti klientą, `.proto` šaltinio failai paskelbti
[github.com/wink-travel/partner-api-proto](https://github.com/wink-travel/partner-api-proto).

## Kaip veikia naudojimas ir ribos

### Nemokamas lygis

Nemokamas lygis skirtas leisti jums kurti, testuoti ir vykdyti nedidelį gamybinį srautą be papildomų išlaidų.

- **Nėra paskelbto užklausų per minutę limito.** Wink stebi užklausų dažnį ir gali taikyti sąžiningo naudojimo ribas paslaugos apsaugai. Jei gaunate **HTTP 429 (Per daug užklausų)**, palaukite tiek sekundžių, kiek nurodyta `Retry-After` antraštėje, prieš bandydami dar kartą.
- **Mėnesio limitas — 10 000 vienetų per kalendorinį mėnesį.** Limitas suteikiamas kiekvienai paskyrai ir atsinaujina kiekvieno mėnesio 1 d. (UTC). Pasiekus limitą, paskyra, kuri nėra užsiregistravusi mokėjimui pagal naudojimą, gauna **HTTP 429 iki kito mėnesio 1 d.** — griežtas sustabdymas su `Retry-After` antrašte ir žinute, kviečiančia prenumeruoti Mokamą lygį. Užsiregistravusi paskyra toliau veikia ir apmokestinama už viršytą naudojimą.

Nemokamas lygis neapima Paslaugų lygio susitarimo ar prioritetinės pagalbos.

### Mokamas lygis

Mokamas lygis pašalina mėnesio ribą ir apmokestina tik už tai, ką naudojate.

- **Matuojamos viešbučio nakvynės — 0,0001 USD už viešbučio nakvynę.** Nėra mėnesio limito; mokate pagal faktinį kiekį. Wink vis dar gali taikyti sąžiningo naudojimo ribas paslaugos apsaugai. Paieškos ir inventoriaus užklausos apmokestinamos už kiekvieną įkainotą viešbučio nakvynę; Turinio ir Paieškos užklausos apmokestinamos po vieną vienetą, todėl užklausų grupavimas sumažina sąskaitą.

Mokamas lygis apima žemiau aprašytą Paslaugų lygio susitarimą — 99,9 % veikimo laiko įsipareigojimą ir P95 atsakymo laiką mažiau nei 500 ms — bei prioritetinę, pagal rimtumą pagrįstą pagalbą.

## Paslaugų lygio susitarimas

_Galiojimo data: 2026 m. liepos 5 d. · Versija 1.0_

Šis Paslaugų lygio susitarimas („SLA“) nustato prieinamumo įsipareigojimą, paslaugų kreditus ir palaikymo tikslus, kuriuos Wink („Wink“, „mes“, „mums“) suteikia klientui („Klientas“, „jūs“) autentifikuotam Wink Partnerio API („Partnerio API“ arba „Paslauga“) lygiuose, kuriuose nurodoma, kad SLA taikomas. Šis SLA yra įtrauktas į ir reglamentuojamas susitarimo tarp jūsų ir Wink, pagal kurį jūs naudojatės Partnerio API („Susitarimas“), ir galioja tol, kol turite aktyvią, apmokamą Partnerio API prenumeratą. Didžiosios raidės nenaudojamos čia apibrėžtiems terminams reiškia terminus, nurodytus Susitarime.

### 1. Apibrėžimai

1. **„Veikimo laikas“** reiškia laikotarpius, kai Partnerio API yra prieinamas priimti ir sėkmingai atsakyti į tinkamai suformuotas, autentifikuotas užklausas.
2. **„Neveikimo laikas“** reiškia bet kurį laikotarpį, matuojamą minutėmis, kai Partnerio API nesugeba sėkmingai atsakyti į tinkamai suformuotas, autentifikuotas užklausas, išskyrus laikotarpius, nurodytus 4 skyriuje kaip išimtys. Atsitiktinės klaidos, paveikiančios nereikšmingą užklausų dalį, savaime nelaikomos Neveikimo laiku.
3. **„Mėnesio veikimo laiko procentas“** reiškia, tam tikram kalendoriniam mėnesiui, bendrą to mėnesio minučių skaičių atėmus Neveikimo laiko minutes, padalytą iš bendro to mėnesio minučių skaičiaus, išreikštą procentais.
4. **„Planuojama priežiūra“** reiškia suplanuotą Paslaugos priežiūrą, apie kurią Wink iš anksto pranešė pagal 4 skyrių.
5. **„Paslaugos kreditas“** reiškia kreditą, apskaičiuotą kaip procentą nuo jūsų už Partnerio API mokamų ar mokėtinų mokesčių paveiktame kalendoriniame mėnesyje, kuris taikomas būsimoms Partnerio API sąskaitoms kaip vienintelė ir išskirtinė priemonė dėl Veikimo laiko įsipareigojimo nevykdymo.
6. **„Atsakymo laikas“** reiškia laiką nuo Wink gavimo tinkamai suformuotos, autentifikuotos užklausos Wink paslaugos riboje iki momento, kai Wink pradeda grąžinti atsakymą, neįskaitant tinklo perdavimo ir kliento pusės laiko, kuris nėra Wink kontroliuojamas.

### 2. Prieinamumo ir našumo įsipareigojimas

Wink naudos komerciniu požiūriu pagrįstas pastangas, kad Partnerio API būtų prieinamas su **Mėnesio veikimo laiko procentu ne mažesniu kaip 99,9 %** kiekvieną kalendorinį mėnesį (toliau – „Veikimo laiko įsipareigojimas“). Veikimo laiko įsipareigojimas matuojamas Wink paslaugos riboje ir neapima veiksnių, kurie nėra Wink pagrįstos kontrolės srityje, įskaitant tuos, kurie aprašyti 4 skyriuje. Wink stebėjimo sistemos yra autoritetingas šaltinis Mėnesio veikimo laiko procento ir Atsakymo laiko matavimui.

Wink taip pat siekia **95-ojo procentilio (P95) atsakymo laiko mažiau nei 500 milisekundžių** sėkmingoms, tinkamai suformuotoms, autentifikuotoms užklausoms, matuojamoms Wink paslaugos riboje per kiekvieną kalendorinį mėnesį (toliau – „Našumo tikslas“). Našumo tikslas neapima 4 skyriuje aprašytų veiksnių, užklausų, kurios grąžina programos lygio klaidas dėl pačios užklausos, ir neįprastai didelių ar sudėtingų užklausų partijų. Našumo tikslas yra paslaugos tikslas; Paslaugos kreditai 3 skyriuje taikomi tik dėl Veikimo laiko įsipareigojimo nevykdymo ir yra vienintelė ir išskirtinė priemonė dėl prieinamumo trūkumų.

### 3. Paslaugos kreditai

Jei Mėnesio veikimo laiko procentas bet kuriame kalendoriniame mėnesyje nukrenta žemiau Veikimo laiko įsipareigojimo, galite būti tinkami gauti Paslaugos kreditą, apskaičiuotą kaip procentą nuo jūsų to mėnesio Partnerio API mokesčių, pagal šią skalę:

| Mėnesio veikimo laiko procentas | Paslaugos kreditas |
|---|---|
| Žemiau 99,9 %, bet ne mažiau kaip 99,0 % | 10 % |
| Žemiau 99,0 %, bet ne mažiau kaip 95,0 % | 25 % |
| Žemiau 95,0 % | 50 % |

1. **Kredito reikalavimas.** Norėdami gauti Paslaugos kreditą, turite pateikti raštišką pretenziją Wink per **trisdešimt (30) dienų** nuo kalendorinio mėnesio pabaigos, kuriame įvyko trūkumas. Pretenzijoje turi būti nurodytos kiekvieno Neveikimo laiko įvykio datos ir laikai bei visi pagrįsti žurnalai ar įrodymai, kurie jums yra prieinami. Pretenzijos, pateiktos po šio termino, nebus priimamos.
2. **Kredito forma.** Patvirtinti Paslaugos kreditai taikomi būsimoms Partnerio API sąskaitoms ir neturi piniginės vertės. Tai nėra grąžinimai ir nebus išmokami, išskyrus atvejus, kai tai reikalaujama taikomų įstatymų.
3. **Maksimalus kreditas.** Bendras Paslaugos kreditų kiekis už bet kurį kalendorinį mėnesį neviršys 50 % jūsų to mėnesio Partnerio API mokesčių.
4. **Vienintelė ir išskirtinė priemonė.** Paslaugos kreditai yra jūsų **vienintelė ir išskirtinė priemonė** dėl Wink nesugebėjimo įvykdyti Veikimo laiko įsipareigojimą ar bet kokio kito Partnerio API prieinamumo trūkumo.

### 4. Išimtys

Veikimo laiko įsipareigojimas ir bet kokie Paslaugos kreditai netaikomi, o Neveikimo laikas neįskaitomas, jei nepasiekiamumas, sustabdymas, pablogėjimas ar našumo problema kyla dėl arba susijusi su:

1. **Planuojama priežiūra**, apie kurią Wink iš anksto pranešė, jei toks pranešimas pateiktas protingu laiku per kanalą, kurį Wink paprastai naudoja bendraudamas su klientais;
2. **Force majeure** įvykiai ar kitos priežastys, kurios nėra Wink pagrįstos kontrolės srityje, įskaitant gamtos katastrofas, vyriausybės veiksmus, tinklo ar komunalinių paslaugų gedimus bei paslaugų atakų ar kitų kenkėjiškų veiksmų atvejus;
3. problemos, kurias sukėlė **jūsų** veiksmai ar neveikimas, jūsų įranga, programinė įranga ar tinklas, arba bet kuri **trečiosios šalies** paslauga, produktas ar tiekėjas, kuris nėra Wink tiesioginės kontrolės srityje;
4. jūsų **paslaugos piktnaudžiavimas** arba **Susitarimo**, šio SLA, priimtino naudojimo taisyklių ar taikomų užklausų ribojimų pažeidimas, įskaitant srautą, kurį Wink pagrįstai laiko pertekliniu, automatizuotą piktnaudžiavimą ar sukčiavimą; ir
5. bet koks jūsų prieigos **sustabdymas ar nutraukimas**, tinkamai įvykdytas pagal Susitarimą, įskaitant sustabdymą dėl neapmokėjimo.

### 5. Pagalba ir atsakymo tikslai

Wink teikia Partnerio API palaikymą įprastomis darbo valandomis, išskyrus vietines šventes. Wink naudos komerciniu požiūriu pagrįstas pastangas tinkamai pateiktas pagalbos užklausas pripažinti per šiuos tikslinius atsakymo laikus, remdamasis jūsų priskirtu rimtumu ir Wink pagrįstai patvirtindamas:

| Rimtumas | Aprašymas | Tikslinis pradinis atsakymas |
|---|---|---|
| **Sev 1 — Kritinis** | Partnerio API neveikia arba negalima naudoti gamyboje be sprendimo būdo. | 4 valandos |
| **Sev 2 — Svarbus** | Reikšminga funkcijos sutrikimas ar pablogėjimas; yra sprendimo būdas. | 1 darbo diena |
| **Sev 3 — Mažas** | Bendri klausimai, smulkios problemos ar funkcijų užklausos. | 2 darbo dienos |

Tiksliniai atsakymo laikai apibūdina, kada Wink siekia užmegzti **pradinį kontaktą**; tai nėra garantija dėl sprendimo laiko. Prioritetinė pagalba ir pagal rimtumą pagrįsti tikslai taikomi lygiuose, kuriuose nurodoma, kad jie įtraukti.

### 6. Duomenys ir saugumas

Wink palaiko komerciniu požiūriu pagrįstas administracines, technines ir organizacines priemones, skirtas apsaugoti per Partnerio API apdorojamus duomenis nuo konfidencialumo, vientisumo ir prieinamumo pažeidimų, ir periodiškai jas peržiūri. Wink asmens duomenų tvarkymą reglamentuoja [Privatumo politika](/lt/privacy) ir bet kokios duomenų tvarkymo sąlygos Susitarime. Jūs liekate atsakingi už savo API kredencialų saugumą, už bet kokių gautų duomenų teisėtą naudojimą ir už greitą Wink informavimą apie bet kokį įtariamą kredencialų pažeidimą.

### 7. Atsakomybės apribojimas

Paslaugos kreditai yra **vienintelė ir išskirtinė priemonė** dėl bet kokio nepasiekiamumo ar Veikimo laiko įsipareigojimo nevykdymo ir teikiami vietoje bet kokios kitos atsakomybės, kylančios dėl tokio nevykdymo. Išskyrus aiškiai nurodytus šio SLA atvejus, Partnerio API teikiamas „kaip yra“. Maksimali Wink atsakomybė, kylanti iš ar susijusi su Paslauga, yra ribojama pagal Susitarimą, ir Wink neatsako už jokius netiesioginius, atsitiktinius, specialius, pasekminius ar baudžiamuosius nuostolius, taip pat už prarastas pajamas, pajamas, duomenis ar gerą vardą, net jei buvo įspėta apie tokių nuostolių galimybę.

### 8. Terminas, pakeitimai ir nutraukimas

Šis SLA galioja tol, kol turite aktyvią Partnerio API prenumeratą lygyje, kuriame nurodoma, kad SLA taikomas. Wink gali laikas nuo laiko atnaujinti šį SLA; esminiai pakeitimai bus pranešti per kanalą, kurį Wink paprastai naudoja klientų pasiekiamumui, o tolesnis Partnerio API naudojimas po atnaujinimo įsigaliojimo reiškia atnaujinto SLA priėmimą. Šis SLA automatiškai nutraukiamas pasibaigus Susitarimui arba jūsų Partnerio API prenumeratai. Skyriai, kurie pagal savo pobūdį turi išlikti po nutraukimo — įskaitant sukauptą, bet nepareikalautą Paslaugos kreditų teisę, atsakomybės apribojimą ir apibrėžimus — išlieka galiojantys.
