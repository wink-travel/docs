Kiekviena platformos funkcija yra iškviečiama išorėje. Šiame skyriuje aptariama autentifikacija, API paviršius, įvykių pristatymas ir su tuo susiję atitinkami duomenys.

## Pradėkite čia

- [Kurkite su Wink](/lt/developers/build-on-wink/) — ką galite sukurti ir kuris API tinka.
- [Nustatymai](/lt/developers/setup/) — sukurkite programą ir gaukite prisijungimo duomenis.
- [Autentifikacija](/lt/developers/authentication/) — OAuth2 sesijos ir leidimai.

## API paviršius

- [REST ir gRPC](/lt/developers/rest-and-grpc/) — du perdavimo būdai ir kada naudoti kiekvieną.
- [Geolokacija](/lt/developers/geolocation/) — erdvinė paieška per užsakymams prieinamą inventorių.
- [Taksonomija](/lt/developers/taxonomy/) — OTA kodai, palaikomos kalbos ir valiutos.
