Wink suteikia du autentifikuotus MCP serverius. Abu naudoja **interaktyvų OAuth2 prisijungimą** (PKCE autorizacijos kodo srautas) — jūsų AI agentas atidaro naršyklės skirtuką, kad prisijungtumėte su savo Wink paskyra. Nereikia valdyti klientų slaptumo raktų.

| Serveris | URL | Ką atlieka |
|----------|-----|------------|
| **Inventory API** | `https://api.wink.travel/mcp` | Inventorius, užsakymai, kainos, pardavimo kanalai, analizė ir visi platformos veiksmai |
| **Integrations** | `https://integrations.wink.travel/mcp` | Kanalų valdymo integracijos — sinchronizuoja objektus, kainas ir prieinamumą su OTA |

---

## Kaip veikia autentifikacija

Wink MCP serveriai naudoja **OAuth2 autorizacijos kodo + PKCE** srautą ir palaiko **dinaminę kliento registraciją (RFC 7591)**. Štai kas vyksta, kai jungiatės pirmą kartą:

1. Jūsų AI klientas atranda autorizacijos serverį iš MCP galinio taško `/.well-known/oauth-protected-resource` metaduomenų.
2. Klientas pats užsiregistruoja per **dinaminę kliento registraciją** — nereikia rankinio programos nustatymo.
3. Klientas atidaro **naršyklės skirtuką** adresu `https://iam.wink.travel`. Prisijungiate su savo Wink paskyra ir patvirtinate prašomas teises sutikimo ekrane.
4. Wink išduoda **prieigos žetoną**, susietą su jūsų paskyra ir tapatybe.
5. AI klientas prideda žetoną prie kiekvieno MCP užklausos. Visi įrankių rezultatai automatiškai apribojami jūsų valdomai įmonei.
6. Žetonai galioja 3 valandas. Jūsų AI klientas tyliai atnaujina žetoną fone be papildomo prašymo.

Kiekvienas įrankio kvietimas vykdomas **jūsų tapatybe** — taikomos tos pačios ACL taisyklės, kurios saugo interneto portalą.

## Prijunkite savo AI klientą

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Įsitikinkite, kad Claude Code yra atnaujintas:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Pridėkite Wink Inventory MCP serverį:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code susisiekia su serveriu, atranda autorizacijos serverį ir atidaro numatytąją naršyklę.

4. **Prisijunkite prie Wink** ir patvirtinkite leidimų prašymą sutikimo ekrane.

5. Claude Code patvirtina ryšį. Įveskite `/mcp`, kad patikrintumėte, ar serveris rodomas ir įrankiai įkeliami.
</Steps>

Norėdami pridėti ir Integrations serverį:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Dalinkitės su savo komanda]
Pridėkite `--scope project` prie `claude mcp add`, ir Claude Code įrašys serverio URL į `.mcp.json` projekto šaknyje. Įtraukite šį failą į versijų valdymą — kiekvienas komandos narys pirmą kartą jungdamasis atliks savo naršyklės prisijungimą.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Redaguokite Claude Desktop konfigūracijos failą:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. Pridėkite MCP serverių įrašus:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **Pilnai uždarykite ir paleiskite iš naujo** Claude Desktop (naudokite Quit meniu juostoje — lango uždarymas nepakanka).

4. Claude Desktop atidaro naršyklės skirtuką kiekvienam naujam serveriui. Prisijunkite prie Wink ir patvirtinkite leidimus.

5. Apatinėje įrankių juostoje esanti kištuko piktograma rodo abu serverius kaip prijungtus.
</Steps>

  </TabItem>

   - **macOS / Linux:** `~/.codex/config.json`
   - **Windows:** `%USERPROFILE%\.codex\config.json`

   ```json title="~/.codex/config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },

         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

4. Paleiskite Codex. Pirmą kartą naudojant Codex atidaro naršyklės skirtuką adresu `https://iam.wink.travel`.

5. **Prisijunkite prie Wink** ir patvirtinkite prašomas teises.

6. Codex patvirtina ryšį. Paleiskite `codex` ir paprašykite išvardinti prieinamus įrankius, kad patikrintumėte, ar Wink serveriai veikia.

:::note
Codex CLI MCP palaikymui reikalinga versija **1.0** arba naujesnė. Patikrinkite komandą `codex --version` ir atnaujinkite su `npm install -g @openai/codex`.

  <TabItem label="ChatGPT">

MCP serverių palaikymas yra **ChatGPT darbalaukio programoje** Plus, Pro, Team ir Enterprise prenumeratoriams.

<Steps>
1. Atsisiųskite ir įdiekite [ChatGPT darbalaukio programą](https://openai.com/chatgpt/download/), jei dar to nepadarėte.

2. Atidarykite programą ir spustelėkite **savo profilio piktogramą** viršutiniame dešiniajame kampe, tada pasirinkite **Nustatymai**.

3. Eikite į **Jungikliai** (arba **MCP serveriai** priklausomai nuo programos versijos) ir spustelėkite **Pridėti**.

4. Įveskite Wink Inventory serverio URL:
   ```
   https://api.wink.travel/mcp
   ```
   Tada spustelėkite **Prisijungti**.

5. ChatGPT atidaro naršyklės skirtuką adresu `https://iam.wink.travel`. **Prisijunkite prie Wink** ir patvirtinkite leidimus.

6. Pakartokite 4–5 žingsnius Integrations serveriui:
   ```
   https://integrations.wink.travel/mcp
   ```

7. Abu serveriai bus matomi jūsų Jungiklių sąraše. Pradėkite naują pokalbį — Wink įrankiai bus automatiškai prieinami.
</Steps>

:::note[Žiniatinklio programos apribojimas]
MCP serveriai konfigūruojami tik **darbalaukio programoje**. ChatGPT žiniatinklio sąsaja chatgpt.com nepalaiko pasirinktinių MCP serverių.
:::

  </TabItem>

<Steps>

   - **macOS / Linux:** `~/.cursor/mcp.json`
   - **Windows:** `%USERPROFILE%\.cursor\mcp.json`

2. Pridėkite Wink MCP serverių įrašus:

   ```json title="~/.cursor/mcp.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. Atidarykite Cursor. Eikite į **Nustatymai → Cursor nustatymai → MCP** ir patvirtinkite, kad abu serveriai rodomi su žaliu statuso indikatoriumi. Jei rodomas raudonas, spustelėkite **Atnaujinti**.

## Leidimai

Patvirtindami sutikimo ekraną matysite, kokias teises agentas prašo. MCP klientai naudoja tą pačią leidimų žodyną kaip ir visa platforma — žr. pilną
[leidimų aprašymą Autentifikacijos puslapyje](/lt/developers/authentication#scopes).

Du dalykai yra specifiniai MCP:

- **`mcp.read`, `mcp.write`, `mcp.remove` leidimai papildomai reikalingi** MCP transportui atidaryti. Klientas, turintis `mcp.*` leidimą, gali jungtis prie `/mcp`, bet kiekvienas įrankis, kurį jis kviečia, vis tiek taiko atitinkamo galinio taško leidimą (pvz., `booking.read`).
- **AI klientas prašo tik reikalingų leidimų.** Galite atmesti atskirus leidimus sutikimo ekrane — įrankiai, kuriems reikalingas atmestas leidimas, grąžins klaidą kviečiant.

## Trikčių šalinimas

**Naršyklės skirtukas neatidaromas**

Jūsų AI klientas gali dar nepalaikyti interaktyvaus PKCE srauto. Patikrinkite, ar naudojate naujausią versiją:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT darbalaukio programa:** atnaujinkite per programos vidinį atnaujinimą

**`401 Unauthorized` po prisijungimo**

Jūsų talpykloje esantis žetonas gali būti pasenęs. Pašalinkite ir pridėkite serverį iš naujo, kad būtų inicijuotas naujas prisijungimas:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

Claude Desktop ir ChatGPT pašalinkite serverio įrašą nustatymuose, paleiskite programą iš naujo ir pridėkite serverį dar kartą.

**`403 Forbidden` kviečiant konkretų įrankį**

Įrankiui reikalingas leidimas, kurio nesutikote sutikimo ekrane. Prisijunkite prie serverio iš naujo — sutikimo ekranas pasirodys dar kartą ir galėsite patvirtinti trūkstamą leidimą.

**Serveris rodomas, bet įrankių kvietimai grąžina „paskyra nerasta“**

Esate prisijungę prie Wink paskyros, kuri neturi valdomos įmonės. Eikite į [Wink Portalą](https://app.wink.travel) ir įsitikinkite, kad jūsų paskyra yra tinkamai sukonfigūruota prieš naudojant MCP serverį.

**Žetonas pasibaigia sesijos viduryje**

Žetonai galioja 3 valandas. Claude Code ir Claude Desktop tyliai atnaujina žetonus be pertraukiančios sesijos. Jei po ilgo neveikimo matote autentifikacijos klaidų, įveskite naują žinutę — klientas automatiškai persijungs.

**Codex CLI rodo „MCP serveris nepasiekiamas“**

Patikrinkite, ar jūsų `~/.codex/config.json` yra galiojantis JSON (be užbaigiančių kablelių) ir ar `"type": "http"` yra nustatyta. Codex reikalauja HTTP transporto nuotoliniams serveriams; stdio transportas skirtas tik vietiniams binariniams failams.

**ChatGPT meniu „Jungikliai“ nerodomas**

MCP palaikymui reikalinga ChatGPT darbalaukio programos versija **1.2024.352** arba naujesnė ir aktyvi Plus, Pro, Team arba Enterprise prenumerata. Atnaujinkite programą ir patikrinkite planą Nustatymai → Paskyra.

**Cursor serveris rodo raudoną / „Nepavyko prisijungti“**

Patikrinkite, ar jūsų `~/.cursor/mcp.json` yra galiojantis JSON ir turi `"type": "http"`. Tada eikite į **Nustatymai → Cursor nustatymai → MCP** ir spustelėkite **Atnaujinti**. Jei klaida išlieka, pilnai paleiskite Cursor iš naujo — konfigūracijos pakeitimai ne visada įsigalioja be perkrovimo.

**Windsurf MCP serveriai nerodomi nustatymuose**

Windsurf reikalauja pilno paleidimo iš naujo (ne tik lango perkrovimo), kad įkeltų pakeitimus `mcp_config.json`. Naudokite **Failas → Išeiti** ir vėl paleiskite. Jei serveriai vis dar nerodomi, įsitikinkite, kad naudojate Windsurf **1.4+** per **Pagalba → Apie Windsurf**.

**Cline „Pridėti serverį“ parinktis nematoma**

MCP serverių valdymui reikalinga Cline versija **2.0** arba naujesnė. Atidarykite VS Code plėtinių panelę, suraskite Cline ir spustelėkite **Atnaujinti**, jei yra naujinimas. Po atnaujinimo perkraukite VS Code (`Ctrl+Shift+P` → „Developer: Reload Window“).
