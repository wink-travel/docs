Wink MCP įrankiai skelbiami kaip **įrankių rinkiniai** – specializuoti galiniai taškai, kiekvienas apimantis vieną užduotį. Jūs prijungiate savo AI klientą prie vieno ar dviejų, kurie atitinka jūsų darbą, o ne prie visų.

Kiekvienas galinis taškas naudoja **interaktyvų OAuth2 prisijungimą** (PKCE autorizacijos kodo srautas): jūsų AI agentas atidaro naršyklės skirtuką, jūs prisijungiate su savo Wink paskyra, ir viskas. Nereikia valdyti kliento slaptumo.

```bash title="Kanalo valdytojo integratorius jungiasi prie vieno galinio taško"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="Viešbučio savininkas, valdantis savo kainas, jungiasi prie kito"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## Kodėl įrankiai padalinti į galinius taškus

Wink siūlo apie 500 įrankių. Pateikti visus vienu metu agentui techniškai įmanoma – bet tai bloga idėja.

**Įrankių apibrėžimai kainuoja kontekstą.** Kiekvienas MCP serverio reklamuojamas įrankis įkeliamas į modelio konteksto langą prieš atliekant bet kokį darbą, kartu su aprašymu ir pilnu parametrų schemu. Penki šimtai tokių įrankių sunaudoja didelę dalį biudžeto, kurio reikia jūsų užduočiai, kiekviename užklausoje.

**Pasirinkimo kokybė mažėja didėjant sąrašui.** Agentas, renkantis iš 500 panašiai pavadintų įrankių, priima prastesnius sprendimus nei tas, kuris renkasi iš 40. Jei integruojate kanalo valdytoją, apie dvidešimt įrankių jums aktualūs; likę 480 yra triukšmas, kuris apsunkina tinkamo įrankio radimą.

**Darbas iš tiesų yra atskiriamas.** Kas nors, sinchronizuojantis prieinamumą iš PMS, ir kas nors, kuruojantis filialų nukreipimo puslapius, beveik nesidalija įrankiais. Darbo padalijimas reiškia, kad kiekvienas ryšys turi vienos užduoties žodyną.

<Aside type="caution" title="Įrankių rinkiniai nėra leidimai">
Pasirinkus siaurą įrankių rinkinį **neapriboja** jūsų paskyros galimybių, o pasirinkus platų – nieko papildomo nesuteikia. Kiekvienas įrankis taiko tas pačias paskyros teises kaip ir interneto portale, pagal jūsų prisijungusią tapatybę. Jei jūsų paskyra negali atšaukti užsakymo Wink portale, agentas taip pat negali – nepriklausomai nuo to, prie kurio galinio taško jis prijungtas.

Rinkitės įrankių rinkinius dėl **dėmesio**, o ne dėl saugumo.
</Aside>

### `https://integrations.wink.travel` — kanalo valdytojo integracijos

Vienas galinis taškas, nes šis serveris skirtas vienai užduočiai.

| Galinis taškas | Įrankiai | Apima |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | Kanalo valdytojo, PMS ar CRS integracijos prijungimas ir patvirtinimas |

<Aside type="note" title="Kanalo valdytojo integravimas vs. savo kainų valdymas">
Tai skirtingos užduotys skirtingiems žmonėms, ir jos nesidalija galiniu tašku.

**Kanalo valdytojo, PMS ar CRS tiekėjas** integruojasi vieną kartą per `integrations.wink.travel/mcp/channel-manager` ir nuo to laiko keičiasi objektais, kainomis, prieinamumu ir rezervacijomis per tą integraciją. Tas vienas galinis taškas yra visas paviršius.

**Viešbučio savininkas, keičiantis savo kainas rankiniu būdu**, naudoja extranet įrankių rinkinius `api.wink.travel` – `/mcp/extranet/rates` ir pan. Tai nėra kanalo valdytojo integracijos dalis ir integratorius neturi priežasties jungtis prie jų.

Paskyros administravimas taip pat yra `api.wink.travel`, adresu `/mcp/settings`. Integracijos serveryje nėra `/mcp/settings`.
</Aside>

Kiekvienas galinis taškas taip pat turi `ping` įrankį, kad galėtumėte patvirtinti, jog ryšys veikia prieš prašydami atlikti tikrą darbą.

## Kokius įrankių rinkinius man reikia?

| Jei jūs… | Prisijunkite prie |
|---|---|
| **Integruojate kanalo valdytoją, PMS ar CRS** | `integrations.wink.travel/mcp/channel-manager` – tik šio |
| **Valdote objekto turinį** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **Valdote kambarius ir kambarių tipus** | `/mcp/extranet/facilities` |
| **Valdote kainas ir prieinamumą** | `/mcp/extranet/rates` |
| **Vykdote kasdienes rezervacijas** | `/mcp/extranet/operations` |
| **Plečiate platinimą** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **Kuriate filialų puslapius** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **Vykdote link-in-bio puslapius** | `/mcp/link-manager` + `/mcp/social` |
| **Rezervuojate keliautojų vardu** | `/mcp/travel-agent` |
| **Tvarkote finansus** | `/mcp/payment` |
| **Kuriate rezervavimo patirtį** | `/mcp/booking-engine` + `/mcp/reference` |

Pradėkite nuo vieno. Pridėkite kitą, kai prireiks kažko, ko jis negali – kiekvienas ryšys yra nepriklausomas, ir pridėjus vieną kiti nebus paveikti.

<Aside type="tip" title="Vis dar norite visko?">
`https://api.wink.travel/mcp` ir `https://integrations.wink.travel/mcp` lieka prieinami ir teikia **visus** įrankius savo serveryje. Jie naudingi norint tyrinėti, kas yra, bet jų nerekomenduojame kasdieniam darbui: įrankių sąrašas yra pakankamai didelis, kad užgožtų jūsų užduotį ir pablogintų agento įrankių pasirinkimą. Rinkitės aukščiau pateiktus įrankių rinkinius.
</Aside>

## Kaip veikia autentifikacija

Wink MCP serveriai naudoja **OAuth2 autorizacijos kodo + PKCE** srautą ir palaiko **dinaminę kliento registraciją (RFC 7591)**. Štai kas vyksta, kai jungiatės pirmą kartą:

1. Jūsų AI klientas atranda autorizacijos serverį iš MCP galinio taško `/.well-known/oauth-protected-resource` metaduomenų.
2. Klientas pats užsiregistruoja per **dinaminę kliento registraciją** – nereikia rankinio programos nustatymo.
3. Klientas atidaro **naršyklės skirtuką** adresu `https://iam.wink.travel`. Jūs prisijungiate su savo Wink paskyra ir patvirtinate prašomas teises sutikimo ekrane.
4. Wink išduoda **prieigos žetoną**, susietą su jūsų paskyra ir tapatybe.
5. AI klientas prideda žetoną prie kiekvieno MCP užklausos. Visi įrankių rezultatai automatiškai taikomi jūsų valdymo subjektui.
6. Žetonai galioja 3 valandas. Jūsų AI klientas tyliai atnaujina žetoną fone be papildomo prašymo.

Kiekvienas įrankio kvietimas vykdomas **jūsų tapatybės vardu** – ta pati ACL taisyklė, sauganti interneto portalą, taikoma AI agentui.

## Prijunkite savo AI klientą

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Įsitikinkite, kad Claude Code yra atnaujintas:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Pasirinkite įrankių rinkinį iš [aukščiau pateikto katalogo](#endpoint-directory) ir pridėkite jį. Pavyzdžiui, kainas ir prieinamumą:
   ```bash
   claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
   ```

3. Claude Code susisiekia su serveriu, atranda autorizacijos serverį ir atidaro numatytąją naršyklę.

4. **Prisijunkite prie Wink** ir patvirtinkite leidimų prašymą sutikimo ekrane.

5. Claude Code patvirtina ryšį. Įveskite `/mcp`, kad patikrintumėte, ar serveris matomas ir įrankiai įkelti.
</Steps>

Pridėkite tiek įrankių rinkinių, kiek reikia jūsų darbui – kiekvienas yra atskiras serverio įrašas su savo pavadinimu:
```bash
claude mcp add wink-operations https://api.wink.travel/mcp/extranet/operations --transport http
claude mcp add wink-analytics  https://api.wink.travel/mcp/analytics           --transport http
```

Prisijungiate tik vieną kartą. Po pirmo naršyklės patvirtinimo Claude Code naudoja jūsų Wink sesiją papildomiems Wink galiniams taškams.

:::tip[Dalinkitės su savo komanda]
Pridėkite `--scope project` prie `claude mcp add` ir Claude Code įrašo serverio URL į `.mcp.json` projekto šaknyje. Įtraukite šį failą į versijų valdymą – kiekvienas komandos narys gaus tuos pačius įrankių rinkinius ir kiekvienas pirmą kartą prisijungdamas atliks savo naršyklės prisijungimą.
:::

## Leidimai

Patvirtindami sutikimo ekraną matysite, kokias teises agentas prašo. MCP klientai naudoja tą pačią leidimų žodyną kaip ir visa platforma – pilną
[leidimų aprašymą rasite Autentifikacijos puslapyje](/lt/developers/authentication#scopes).

Du dalykai yra specifiniai MCP:

- **`mcp.read`, `mcp.write`, `mcp.remove` leidimai papildomai reikalingi** atidaryti MCP transportą. Klientas, turintis `mcp.*` leidimą, gali jungtis prie bet kurio Wink MCP galinio taško, bet kiekvienas įrankis, kurį jis kviečia, vis tiek taiko to galinio taško skyriaus leidimą (pvz., `booking.read`).
- **AI klientas prašo tik reikalingų leidimų.** Galite atmesti atskirus leidimus sutikimo ekrane – įrankiai, kuriems reikalingas atmestas leidimas, grąžins klaidą kviečiant.

**Įrankių rinkiniai nieko nekeičia.** Galinis taškas, prie kurio jungiatės, nusprendžia, kurie įrankiai yra *pateikti sąraše*, o ne ką jie *gali daryti*. Prisijungimas prie `/mcp/payment` nesuteikia jokių finansinių teisių, kurių jau neturėjote, o prisijungimas prie `/mcp/reference` nesustabdo įrankio taikyti savo leidimą. Autorizacija sprendžiama kiekvieno įrankio kvietimo metu pagal jūsų žetoną ir paskyros teises.

## Trikčių šalinimas

**Naršyklės skirtukas neatidaromas**

Jūsų AI klientas gali dar nepalaikyti interaktyvaus PKCE srauto. Patikrinkite, ar naudojate naujausią versiją:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT darbalaukis:** atnaujinkite per programos vidinį atnaujinimą

**`401 Unauthorized` po prisijungimo**

Jūsų talpykloje esantis žetonas gali būti pasenęs. Pašalinkite ir pridėkite serverį iš naujo, kad suaktyvintumėte naują prisijungimą:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

Claude Desktop ir ChatGPT pašalinkite serverio įrašą iš nustatymų, paleiskite programą iš naujo ir pridėkite jį vėl.

**`403 Forbidden` kviečiant konkretų įrankį**

Įrankiui reikalingas leidimas, kurio nesutikote sutikimo ekrane, arba jūsų paskyra neturi reikiamos teisės. Prisijunkite prie serverio iš naujo – sutikimo ekranas pasirodys dar kartą ir galėsite patvirtinti trūkstamą leidimą. Jei vis tiek nepavyksta, įrankiui reikia paskyros leidimo, kurio neturite; jungimasis prie kito įrankių rinkinio nepadės, nes įrankių rinkiniai nesuteikia leidimų.

**Įrankis, kurio reikia, nėra sąraše**

Tikėtina, kad esate prisijungę prie įrankių rinkinio, kuris neapima tos užduoties. Patikrinkite [galinių taškų katalogą](#endpoint-directory) ir pridėkite tinkamą įrankių rinkinį – ryšiai yra nepriklausomi, todėl pridėjus vieną niekas kitas nesikeičia. Jei nesate tikri, kuris jį turi, laikinai prisijunkite prie `https://api.wink.travel/mcp`, raskite įrankį, tada pažiūrėkite, kuris įrankių rinkinys jį pateikia.

**`404 Not Found` įrankių rinkinio galiniame taške**

Atidžiai patikrinkite kelią – įrankių rinkiniai su dviem segmentais (`/mcp/extranet/rates`, o ne `/mcp/extranet-rates`), o plokšti turi vieną segmentą (`/mcp/link-manager`). Atkreipkite dėmesį, kad *neautentifikuota* užklausa bet kuriame `/mcp` kelyje grąžina `401`, o ne `404`, todėl vien `401` nepasako, ar galinis taškas egzistuoja.

**Prisijungiau prie `api.wink.travel/mcp/channel-manager` ir nieko negavau**

Toks galinis taškas neegzistuoja. Kanalo valdytojo integracija teikiama tik per `https://integrations.wink.travel/mcp/channel-manager`. Jei taip pat reikia rankiniu būdu skaityti ar rašyti objekto kainas, tai atskira užduotis atskirame galiniame taške – žr. `/mcp/extranet/rates`.

**Serveris matomas, bet įrankių kvietimai grąžina „account not found“**

Jūs esate prisijungę prie Wink paskyros, kuri neturi valdymo subjekto. Eikite į [Wink Portal](https://app.wink.travel) ir įsitikinkite, kad jūsų paskyra yra tinkamai sukonfigūruota prieš naudojant MCP serverį.

**Žetonas baigiasi sesijos viduryje**

Žetonai galioja 3 valandas. Claude Code ir Claude Desktop tyliai atnaujina žetonus be pertraukos jūsų sesijoje. Jei po ilgo neveikimo matote autentifikacijos klaidas, įveskite naują žinutę – klientas automatiškai persijungs.

**Codex CLI rodo „MCP server unreachable“**

Patikrinkite, ar jūsų `~/.codex/config.json` yra galiojantis JSON (be užbaigiančių kablelių) ir ar `"type": "http"` yra nustatytas. Codex reikalauja HTTP transporto nuotoliniams serveriams; stdio transportas skirtas tik vietiniams binariniams failams.

**ChatGPT „Connectors“ meniu nėra**

MCP palaikymas reikalauja ChatGPT darbalaukio programos versijos **1.2024.352** ar naujesnės ir aktyvios Plus, Pro, Team arba Enterprise prenumeratos. Atnaujinkite programą ir patikrinkite planą Nustatymai → Paskyra.

**Cursor serveris rodo raudoną / „Nepavyko prisijungti“**

Patikrinkite, ar jūsų `~/.cursor/mcp.json` yra galiojantis JSON ir turi `"type": "http"`. Tada eikite į **Nustatymai → Cursor nustatymai → MCP** ir spustelėkite **Atnaujinti**. Jei klaida išlieka, pilnai paleiskite Cursor iš naujo – konfigūracijos pakeitimai ne visada įsigalioja be perkrovimo.

**Windsurf MCP serveriai nerodomi nustatymuose**

Windsurf reikalauja pilno perkrovimo (ne tik lango perkrovimo), kad paimtų pakeitimus `mcp_config.json`. Naudokite **Failas → Išeiti** ir paleiskite iš naujo. Jei serveriai vis dar nerodomi, įsitikinkite, kad naudojate Windsurf **1.4+** per **Pagalba → Apie Windsurf**.

**Cline „Pridėti serverį“ parinktis nematoma**

MCP serverių valdymui reikalinga Cline versija **2.0** ar naujesnė. Atidarykite VS Code plėtinių panelę, suraskite Cline ir spustelėkite **Atnaujinti**, jei yra atnaujinimas. Po atnaujinimo perkraukite VS Code (`Ctrl+Shift+P` → „Developer: Reload Window“).
