Wink MCP įrankiai skelbiami kaip **įrankių rinkiniai** — specializuoti galiniai taškai, kiekvienas apimantis vieną užduotį. Jūs prijungiate savo AI klientą prie vieno ar dviejų, kurie atitinka jūsų darbą, o ne prie visų.

Kiekvienas galinis taškas naudoja **interaktyvų OAuth2 prisijungimą** (PKCE autorizacijos kodo srautas): jūsų AI agentas atidaro naršyklės skirtuką, jūs prisijungiate su savo Wink paskyra, ir viskas. Nereikia valdyti kliento slaptumo raktų.

```bash title="Kanalo valdytojo integratorius jungiasi prie vieno galinio taško"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="Viešbučio savininkas, valdantis savo kainas, jungiasi prie kito"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## Kodėl įrankiai padalinti į skirtingus galinius taškus

Wink turi apie 500 įrankių. Pateikti visus vienu metu agentui techniškai įmanoma — bet tai bloga idėja.

**Įrankių apibrėžimai kainuoja kontekstą.** Kiekvienas MCP serverio skelbiamas įrankis įkeliamas į modelio konteksto langą prieš pradedant darbą, kartu su aprašymu ir pilnu parametrų schemos aprašymu. Penki šimtai tokių įrankių sunaudoja didelę dalį biudžeto, kurio reikia jūsų užduočiai, kiekviename užklausoje.

**Pasirinkimo kokybė mažėja didėjant sąrašui.** Agentas, renkantis iš 500 panašiai pavadintų įrankių, priima prastesnius sprendimus nei tas, kuris renkasi iš 40. Jei integruojate kanalo valdytoją, apie dvidešimt įrankių jums aktualūs; likę 480 yra triukšmas, kuris apsunkina tinkamo įrankio radimą.

**Darbas iš tiesų yra atskiriamas.** Kas nors, sinchronizuojantis prieinamumą iš PMS, ir kas nors, kuruojantis filialų nukreipimo puslapius, beveik nesidalija įrankiais. Darbo padalijimas reiškia, kad kiekvienas ryšys turi vienos užduoties žodyną.

<Aside type="caution" title="Įrankių rinkiniai nėra leidimai">
Pasirinkus siaurą įrankių rinkinį **neapribojama** to, ką gali jūsų paskyra, o pasirinkus platų — nieko papildomo nesuteikiama. Kiekvienas įrankis taiko tas pačias paskyros teises kaip ir interneto portale, pagal jūsų prisijungusią tapatybę. Jei jūsų paskyra negali atšaukti užsakymo Wink portale, agentas taip pat negali — nepriklausomai nuo to, prie kurio galinio taško jis prijungtas.

Rinkitės įrankių rinkinius dėl **dėmesio**, o ne dėl saugumo.
</Aside>

### `https://integrations.wink.travel` — kanalo valdytojo integracijos

Vienas galinis taškas, nes šis serveris skirtas vienai užduočiai.

| Galinis taškas | Įrankiai | Apima |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | Kanalo valdytojo, PMS ar CRS integracijos prijungimas ir patikrinimas |

<Aside type="note" title="Kanalo valdytojo integravimas vs. savo kainų valdymas">
Tai skirtingos užduotys skirtingiems žmonėms, ir jos nesidalija galiniu tašku.

**Kanalo valdytojas, PMS ar CRS tiekėjas** integruojasi vieną kartą per `integrations.wink.travel/mcp/channel-manager` ir nuo to laiko keičiasi objektais, kainomis, prieinamumu ir rezervacijomis per tą integraciją. Tas vienas galinis taškas yra visas paviršius.

**Viešbučio savininkas, keičiantis savo kainas rankiniu būdu**, naudoja extranet įrankių rinkinius `api.wink.travel` — `/mcp/extranet/rates` ir pan. Tai nėra kanalo valdytojo integracijos dalis ir integratorius neturi priežasties jungtis prie jų.

Paskyros administravimas taip pat yra `api.wink.travel`, adresu `/mcp/settings`. Integracijų serveryje nėra `/mcp/settings`.
</Aside>

Kiekvienas galinis taškas taip pat turi `ping` įrankį, kad galėtumėte patvirtinti, jog ryšys veikia prieš pradedant tikrą darbą.

### Agentinės mokėjimo funkcijos

Pilnam keliautojo rezervacijos srautui prijunkite **Wink Booking Engine** adresu `https://api.wink.travel/mcp/booking-engine` ir suderinamą **mokėjimo piniginę**. Pridėjus Wink MCP atsidaro naršyklės prisijungimas ir leidimų pasirinkimas; jūsų klientas tada tvarko autentifikaciją.

Booking Engine apima kelionės tikslų paiešką, viešbučių ir kambarių paiešką, `agentic_booking_quote`, `agentic_booking_pay`, `agentic_booking_book`, rezervacijų gavimą ir kvitus, kai agentinė rezervacija ir mokėjimas įjungti tam aplinkai. Žr. [Agentic Payments](/lt/developers/agentic-payments/) dėl prijungimo nustatymų, pasirenkamų leidimų ir žingsnių nuo paieškos iki patvirtinimo.

## Kokius įrankių rinkinius man reikia?

| Jei jūs… | Prijunkite prie |
|---|---|
| **Integruojate kanalo valdytoją, PMS ar CRS** | `integrations.wink.travel/mcp/channel-manager` — tik šio |
| **Valdote objekto turinį** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **Valdote kambarius ir kambarių tipus** | `/mcp/extranet/facilities` |
| **Valdote kainas ir prieinamumą** | `/mcp/extranet/rates` |
| **Vykdote kasdienes rezervacijas** | `/mcp/extranet/operations` |
| **Plečiate platinimą** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **Kuriate filialų puslapius** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **Vykdote nuorodų puslapius** | `/mcp/link-manager` + `/mcp/social` |
| **Rezervuojate keliautojų vardu** | `/mcp/travel-agent` |
| **Suderinate pinigus** | `/mcp/payment` |
| **Rezervuojate kambarį su AI agentu** | `/mcp/booking-engine` + suderinama mokėjimo piniginė — žr. [Agentic Payments](/lt/developers/agentic-payments/) |
| **Kuriate rezervacijos patirtį** | `/mcp/booking-engine`; papildomai `/mcp/reference` papildomoms paieškoms |

**Booking Engine apima pagrindinį rezervacijos srautą.** Jis suteikia paskyros ir pritaikymo atradimą, kelionės tikslo paiešką, viešbučių prieinamumą ir kambarių kainų detales, pirkinių krepšelius, atsiskaitymą ir keliautojų rezervacijų valdymą. Agentinės rezervacijos ir mokėjimo įrankiai taip pat įtraukti, kai įjungti tam aplinkai.

Miestui skirtai viešbučių paieškai naudokite `destination_lookup_search_suggestions` kelionės tikslui nustatyti, tada `inventory_search_city` norint rasti prieinamus viešbučius ir kainas. Abu įrankiai yra `/mcp/booking-engine`, todėl šiam srautui nereikia Reference ryšio.

Pridėkite `/mcp/reference`, kai reikia papildomų paieškų, tokių kaip šalys, valiutos ir valiutų kursai, palaikomos kalbos, laiko juostos, platesnės geografinės paieškos, OTA klasifikacijos ar viešos objekto žinios. Tai yra neprivalomi papildymai rezervacijos srautui.

Pradėkite nuo vieno. Pridėkite kitą, kai pastebite, kad kažko trūksta — kiekvienas ryšys yra nepriklausomas, ir pridėjus vieną, kiti nesikeičia.

<Aside type="tip" title="Vis dar norite visko?">
`https://api.wink.travel/mcp` ir `https://integrations.wink.travel/mcp` lieka prieinami ir teikia **visus** savo serverio įrankius. Jie naudingi tyrinėjant, kas egzistuoja, bet jų nerekomenduojame kasdieniam darbui: įrankių sąrašas yra pakankamai didelis, kad užgožtų jūsų užduotį ir pablogintų agento įrankių pasirinkimą. Rinkitės aukščiau pateiktus įrankių rinkinius.
</Aside>

## Kaip veikia autentifikacija

Wink MCP serveriai naudoja **OAuth2 autorizacijos kodo + PKCE** srautą ir palaiko **dinaminę kliento registraciją (RFC 7591)**. Štai kas vyksta, kai jungiatės pirmą kartą:

1. Jūsų AI klientas atranda autorizacijos serverį iš MCP galinio taško `/.well-known/oauth-protected-resource` metaduomenų.
2. Klientas pats užsiregistruoja per **dinaminę kliento registraciją** — nereikia rankinio programos nustatymo.
3. Klientas atidaro **naršyklės skirtuką** adresu `https://iam.wink.travel`. Jūs prisijungiate su savo Wink paskyra ir patvirtinate prašomus leidimus sutikimo ekrane.
4. Wink išduoda **prieigos žetoną**, susietą su jūsų paskyra ir tapatybe.
5. AI klientas prideda žetoną prie kiekvieno MCP užklausos. Visi įrankių rezultatai automatiškai ribojami pagal jūsų valdomą subjektą.
6. Žetonai galioja 3 valandas. Jūsų AI klientas tyliai atnaujina žetoną fone be papildomo prašymo.

Kiekvienas įrankio kvietimas vykdomas **jūsų tapatybės vardu** — ta pati ACL taisyklė, sauganti interneto portalą, taikoma AI agentui.

## Prijunkite savo AI klientą

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Įsitikinkite, kad Claude Code yra atnaujintas:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Pasirinkite įrankių rinkinį iš [aukščiau pateikto katalogo](#endpoint-directory) ir pridėkite jį. Pavyzdžiui, kainos ir prieinamumas:
   ```bash
   claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
   ```

3. Claude Code susisiekia su serveriu, atranda autorizacijos serverį ir atidaro numatytąją naršyklę.

4. **Prisijunkite prie Wink** ir patvirtinkite leidimų prašymą sutikimo ekrane.

5. Claude Code patvirtina ryšį. Įveskite `/mcp`, kad patikrintumėte, ar serveris matomas ir įrankiai įkelti.
</Steps>

Pridėkite tiek įrankių rinkinių, kiek reikia jūsų darbui — kiekvienas yra atskiras serverio įrašas su savo pavadinimu:
```bash
claude mcp add wink-operations https://api.wink.travel/mcp/extranet/operations --transport http
claude mcp add wink-analytics  https://api.wink.travel/mcp/analytics           --transport http
```

Prisijungiate tik vieną kartą. Po pirmo naršyklės patvirtinimo Claude Code naudoja jūsų Wink sesiją papildomiems Wink galiniams taškams.

:::tip[Dalinkitės su savo komanda]
Pridėkite `--scope project` prie `claude mcp add` ir Claude Code įrašo serverio URL į `.mcp.json` projekto šaknyje. Įtraukite tą failą į versijų valdymą — kiekvienas komandos narys gaus tuos pačius įrankių rinkinius ir pirmą kartą prisijungdamas atliks savo naršyklės prisijungimą.
:::

1. Įdiekite Cline iš VS Code Marketplace:
   - Atidarykite VS Code ir paspauskite `Ctrl+Shift+X` / `Cmd+Shift+X`
   - Ieškokite **Cline** ir spustelėkite **Install**

2. Spustelėkite **Cline piktogramą** veiklos juostoje (kairėje šoninėje juostoje), kad atidarytumėte Cline panelę.

3. Spustelėkite **MCP Servers** piktogramą (kištuko piktogramą) Cline įrankių juostoje, tada pasirinkite **Edit MCP Settings**.

4. VS Code atidaro `cline_mcp_settings.json`. Pridėkite Wink įrašus:

   ```json title="cline_mcp_settings.json"
   {
     "mcpServers": {
       "wink-extranet-rates": {
         "type": "http",
         "url": "https://api.wink.travel/mcp/extranet/rates"
       },
       "wink-extranet-operations": {
         "type": "http",
         "url": "https://api.wink.travel/mcp/extranet/operations"
       }
     }
   }
   ```

5. **Išsaugokite failą.** Cline automatiškai perkrauna ir atidaro naršyklės skirtuką adresu `https://iam.wink.travel`.

6. **Prisijunkite prie Wink** ir patvirtinkite leidimus. Abu serveriai pasirodys kaip aktyvūs MCP Servers panelėje.
</Steps>

:::tip[Alternatyva: pridėti per URL]
MCP Servers panelėje spustelėkite **Add Server** ir įklijuokite įrankių rinkinio URL, pvz., `https://api.wink.travel/mcp/extranet/rates` tiesiogiai. Cline automatiškai užpildo konfigūraciją ir tvarko autentifikaciją be rankinio JSON redagavimo.
:::

  </TabItem>
</Tabs>

## Leidimų apimtys

Patvirtindami sutikimo ekraną matysite, kokius leidimus agentas prašo. MCP klientai naudoja tą pačią leidimų žodyną kaip ir visa platforma — žr. pilną
[apimtį Autentifikacijos puslapyje](/lt/developers/authentication#scopes).

Du dalykai yra specifiniai MCP:

- **`mcp.read` `mcp.write` `mcp.remove` apimtys papildomai reikalingos** atidaryti MCP transportą. Klientas, turintis `mcp.*` apimtį, gali prisijungti prie bet kurio Wink MCP galinio taško, bet kiekvienas įrankis, kurį jis kviečia, vis tiek taiko to galinio taško skyriaus apimtį (pvz., `booking.read`).
- **AI klientas prašo tik reikalingų apimčių.** Galite atmesti atskirus leidimus sutikimo ekrane — įrankiai, kuriems reikalinga atmesta apimtis, grąžins klaidą kvietimo metu.

**Įrankių rinkiniai nieko nekeičia.** Galinis taškas, prie kurio jungiatės, nusprendžia, kurie įrankiai yra *pateikti sąraše*, o ne ką jie *gali daryti*. Prisijungimas prie `/mcp/payment` nesuteikia jokių finansinių leidimų, kurių jau neturėjote, o prisijungimas prie `/mcp/reference` nesustabdo įrankio taikyti savo apimtį. Autorizacija sprendžiama pagal kiekvieną įrankio kvietimą, remiantis jūsų žetonu ir paskyros leidimais.

## Trikčių šalinimas

**Naršyklės skirtukas neatidaromas**

Jūsų AI klientas gali dar nepalaikyti interaktyvaus PKCE srauto. Patikrinkite, ar naudojate naujausią versiją:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT darbalaukis:** atnaujinkite per programos vidinį atnaujinimą

**`401 Unauthorized` po prisijungimo**

Jūsų talpykloje esantis žetonas gali būti pasenęs. Pašalinkite ir pridėkite serverį iš naujo, kad suaktyvintumėte naują prisijungimą:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

Claude Desktop ir ChatGPT pašalinkite serverio įrašą nustatymuose, paleiskite programą iš naujo ir pridėkite dar kartą.

**`403 Forbidden` kviečiant konkretų įrankį**

Įrankiui reikalinga apimtis, kurios nesutikote sutikimo ekrane, arba leidimas, kurio jūsų paskyra neturi. Prijunkite serverį iš naujo — sutikimo ekranas pasirodys dar kartą ir galėsite patvirtinti trūkstamą leidimą. Jei vis tiek nepavyksta, įrankiui reikia paskyros leidimo, kurio neturite; jungimasis prie kito įrankių rinkinio nepadės, nes įrankių rinkiniai nesuteikia leidimų.

**Reikalingo įrankio nėra sąraše**

Tikriausiai esate prijungę įrankių rinkinį, kuris neapima tos užduoties. Patikrinkite [galinio taško katalogą](#endpoint-directory) ir pridėkite tinkamą įrankių rinkinį — ryšiai yra nepriklausomi, todėl pridėjus vieną, kiti nesikeičia. Jei nesate tikri, kuris jį turi, laikinai prisijunkite prie `https://api.wink.travel/mcp`, raskite įrankį, tada pažiūrėkite, kuris įrankių rinkinys jį pateikia.

**`404 Not Found` galinio taško adresu**

Atidžiai patikrinkite kelią — įrankių rinkiniai turi du segmentus (`/mcp/extranet/rates`, o ne `/mcp/extranet-rates`), o plokšti turi vieną (`/mcp/link-manager`). Atkreipkite dėmesį, kad *neautentifikuota* užklausa bet kuriam `/mcp` keliui grąžina `401`, o ne `404`, todėl vien `401` nepasako, ar galinis taškas egzistuoja.

**Prisijungiau prie `api.wink.travel/mcp/channel-manager` ir nieko negavau**

Toks galinis taškas neegzistuoja. Kanalo valdytojo integracija teikiama tik per `https://integrations.wink.travel/mcp/channel-manager`. Jei taip pat reikia rankiniu būdu skaityti ar rašyti objekto kainas, tai yra atskira užduotis atskirame galiniame taške — žr. `/mcp/extranet/rates`.

**Serveris matomas, bet įrankių kvietimai grąžina „account not found“**

Esate prisijungę prie Wink paskyros, kuri neturi valdomo subjekto. Eikite į [Wink Portal](https://app.wink.travel) ir įsitikinkite, kad jūsų paskyra yra nustatyta prieš naudojant MCP serverį.

**Žetonas baigiasi sesijos viduryje**

Žetonai galioja 3 valandas. Claude Code ir Claude Desktop tyliai atnaujina žetonus be pertraukos jūsų sesijoje. Jei po ilgo neveikimo matote autentifikacijos klaidas, įveskite naują žinutę — klientas automatiškai persijungs.

**Codex CLI rodo „MCP server unreachable“**

Patikrinkite, ar jūsų `~/.codex/config.json` yra galiojantis JSON (be užbaigiančių kablelių) ir ar `"type": "http"` yra nustatyta. Codex reikalauja HTTP transporto nuotoliniams serveriams; stdio transportas skirtas tik vietiniams binariniams failams.

**ChatGPT meniu „Connectors“ nerodomas**

MCP palaikymas reikalauja ChatGPT darbalaukio programos versijos **1.2024.352** ar naujesnės ir aktyvios Plus, Pro, Team arba Enterprise prenumeratos. Atnaujinkite programą ir patikrinkite planą Nustatymai → Paskyra.

**Cursor serveris rodo raudonai / „Failed to connect“**

Patikrinkite, ar jūsų `~/.cursor/mcp.json` yra galiojantis JSON ir turi `"type": "http"`. Tada eikite į **Settings → Cursor Settings → MCP** ir spustelėkite **Refresh**. Jei klaida išlieka, pilnai paleiskite Cursor iš naujo — konfigūracijos pakeitimai ne visada įsigalioja be perkrovimo.

**Windsurf MCP serveriai nerodomi nustatymuose**

Windsurf reikalauja pilno perkrovimo (ne tik lango perkrovimo), kad įkeltų pakeitimus `mcp_config.json`. Naudokite **File → Quit** ir vėl paleiskite. Jei serveriai vis dar nerodomi, įsitikinkite, kad naudojate Windsurf **1.4+** per **Help → About Windsurf**.

**Cline „Add Server“ parinktis nematoma**

MCP serverių valdymas reikalauja Cline **2.0** ar naujesnės versijos. Atidarykite VS Code Extensions panelę, suraskite Cline ir spustelėkite **Update**, jei yra atnaujinimas. Po atnaujinimo perkraukite VS Code (`Ctrl+Shift+P` → „Developer: Reload Window“).
