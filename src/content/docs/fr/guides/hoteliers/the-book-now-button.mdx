Le bouton **RÉSERVER MAINTENANT** est un terme omniprésent dans l’industrie hôtelière qui désigne l’intégration propre à l’hôtel avec un fournisseur qui connaît la disponibilité et les tarifs de l’établissement et permet aux voyageurs de réserver une chambre. Ce bouton est la manière la plus simple pour les hôtels de pouvoir vendre des chambres sur leur propre site web et selon leurs propres conditions.

*Beaucoup d’hôtels utilisent le moteur de réservation intégré proposé par leur gestionnaire de canaux. Nous recommandons aux hôtels de faire des recherches et de comparer les moteurs de réservation natifs avant de s’engager avec un en particulier.*

## Public cible

Cet article s’adresse principalement aux hôtels qui souhaitent installer notre moteur de réservation gratuit et à fort taux de conversion sur leur site web.  
Mais... il est également utile pour toute personne souhaitant utiliser nos technologies sur leurs sites web.

## via un lien

Pour l’intégration la plus simple, nous recommandons d’utiliser un [lien partageable](/fr/portal/studio/shareable-links).

Voici les étapes à suivre :

<Steps>
1. Rendez-vous sur https://app.wink.travel
2. Cliquez sur `Sign-In / Register` en haut à droite et connectez-vous avec votre compte utilisateur.
3. Sélectionnez l’établissement avec lequel vous souhaitez travailler dans le menu déroulant en haut à gauche.
4. Cliquez sur `Booking engine` dans la barre de navigation.
5. La page vous affichera votre lien.
6. Donnez ce lien à votre webmaster et utilisez-le pour votre bouton **RÉSERVER MAINTENANT**.
7. Vous êtes ✅.
</Steps>

:::note
Vous pouvez utiliser ce lien sur votre propre site web, et le moteur de réservation peut également fonctionner sur votre propre domaine (voir [Fonctionnalités du moteur de réservation](/fr/booking-engine/features/)). Le trafic des liens de réservation gratuits Google est différent : il aboutit toujours sur book.wink.travel. Voir [Se référencer sur Google](/fr/guides/hoteliers/get-listed-on-google/#where-the-guest-lands).
:::

### Avancé

Le lien contient déjà un itinéraire intégré dans l’URL, qui provient de la `personnalisation` choisie.  
Vous pouvez personnaliser davantage votre lien en :

- Changeant la personnalisation sélectionnée OU
- En remplaçant l’itinéraire

Dans cet article, nous nous concentrerons sur la seconde option car elle vous donne plus de liberté pour laisser les voyageurs sélectionner un itinéraire sur votre site web et le transmettre au moteur de réservation Wink.

Voici comment transmettre votre propre itinéraire via l’URL.

Paramètres de requête valides :

- **sd** Pour ajouter une date de début : *sd=2027-03-14*
- **n** Pour ajouter un nombre de nuits : *n=1* OU
- **ed** Utiliser une date de fin : *ed=2027-03-15*
- **rc** Invités : *rc=a2* (Adultes : 2)
- **l** Demander une langue d’affichage : *l=es*
- **c** Demander une devise d’affichage : *c=EUR*
- **p** Ajouter une promotion : *p=ABC123*

L’URL ressemblerait à ceci :

https://trvl.as/abc123?sd=2027-03-14&n=1&rc=a2&l=es&c=EUR

Pour des cas d’utilisation plus avancés, vous pouvez aussi demander plusieurs configurations de chambres en utilisant le signe `+` :

Exemple :

https://trvl.as/abc123?sd=2027-03-14&n=1&rc=a2-ca16q1-ca8q1+a2&l=es&c=EUR

- Type de chambre 1 = Adultes : 2, Enfants : 2 = 16 ans + 8 ans.
- Type de chambre 2 = Adultes : 2.

### Exemple

Exemple de code HTML pour un bouton **RÉSERVER MAINTENANT** :

*Cet exemple suppose que vous utilisez [Bootstrap](https://getbootstrap.com) comme bibliothèque CSS principale.*

```html
<a
  href="https://trvl.as/abc123"
  target="_blank"
  class="btn btn-lg btn-primary"
  title="Réserver une chambre"
>
RÉSERVER MAINTENANT
</a>
```

### Autres avantages

Il y a d’autres avantages à utiliser un de nos liens comme bouton `réserver maintenant`.

- **Compatible réseaux sociaux** Le lien peut être facilement partagé sur les réseaux sociaux et affiche un `tarif dynamique` au-dessus de l’image que vous avez sélectionnée.
- **Court** L’URL est très partageable et vous pouvez l’utiliser dans des endroits comme l’URL de votre bio Instagram.

## via intégration

Certains hôtels souhaitent un peu plus de fonctionnalités et une intégration plus poussée pour leur site web. Cet exemple couvre l’intégration d’une [Carte](/fr/portal/studio/cards) dans leur site.

Voici les étapes à suivre :

<Steps>
1. Rendez-vous sur https://app.wink.travel
2. Cliquez sur `Sign-In / Register` en haut à droite et connectez-vous avec votre compte utilisateur.
3. Sélectionnez l’établissement avec lequel vous souhaitez travailler en haut à gauche.
4. Cliquez sur `Search` dans la barre de navigation principale.
5. Tapez le nom de votre établissement et cliquez sur le bouton de recherche.
6. Cliquez sur le lien `Actions` sur la carte de résultat de recherche et sélectionnez `Create > Make a Card`.
7. Cela créera une `Carte`.
8. Un message apparaîtra en haut à droite vous indiquant que votre carte est prête et si vous souhaitez la personnaliser davantage.
9. Cliquez sur `Tools > Cards` dans la barre de navigation principale et vous verrez votre nouvelle carte.
10. Cliquez sur le lien `Actions` sur votre carte et cliquez sur `Embed`.
11. Une nouvelle fenêtre s’ouvre avec un exemple de code HTML que vous pouvez copier.
12. Pour récupérer votre `Client-ID`, allez dans [Applications](/fr/account/applications).
13. Pour récupérer votre `Configuration-ID`, allez dans [Customization](/fr/portal/settings/branding).
14. Vous êtes ✅.
</Steps>

Exemple de code HTML pour une carte intégrée :

```html
<wink-content-loader
  layout="GUEST_ROOM"
  id="09d7cca4-6ff6-11ef-949b-42004e494300"
></wink-content-loader>
```

*L’exemple HTML ci-dessus n’inclut pas le CSS et Javascript Wink requis ; uniquement la carte.*

Un client voit maintenant les tarifs dynamiques, peut modifier l’itinéraire et cliquer pour réserver directement sur votre site. Le bouton de réservation vous conduit à la page d’accueil de votre établissement Wink pour finaliser le paiement.
