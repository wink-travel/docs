Ce guide accompagne une agence de voyage depuis son enregistrement jusqu’à sa première réservation client. Il explique également les deux modes de fonctionnement possibles sur Wink, afin que vous puissiez choisir celui qui vous convient avant de commencer.

## Avant de commencer

Vous aurez besoin de :

- Vos informations d’entreprise.
- Votre numéro d’enregistrement d’agence de voyage, ou votre code IATA si vous en avez un.
- Un compte bancaire pour recevoir votre commission.

## Choisissez votre mode de fonctionnement

| | Standard (la plupart des agences) | Paiement collecté par l’agent |
|---|---|---|
| Comment vous réservez | Dans le portail Wink, ou via l’API Partenaire | Via la [Partner API](/fr/integrations/partner-api/), depuis votre propre système |
| Qui encaisse le paiement du client | Collecté pour l’hôtel, qui reste commerçant enregistré. Vous saisissez la carte de votre client lors du paiement. | C’est vous, en tant que commerçant enregistré. |
| Ce que vous gagnez | **10 % de commission par défaut** sur chaque réservation | La commission définie dans votre propre accord avec chaque hôtel |
| Ce que vous payez à Wink | Rien | **1,5 %** de frais de réservation sur la valeur de chaque réservation, facturés mensuellement, plus l’utilisation de la Partner API au-delà du quota gratuit |
| Paiement à l’hôtel | Pris en charge pour vous | Vous payez chaque hôtel directement, selon votre propre accord avec eux |
| Remboursements, rétrofacturations, conformité des paiements | Pris en charge pour vous | Votre responsabilité |
| Approbation | Votre enregistrement est examiné avant que vous puissiez réserver | Votre enregistrement est examiné, plus l’approbation écrite de Wink pour cette voie, avec une limite de crédit |

Wink examine chaque enregistrement d’agence de voyage. La plupart des agences utilisent ensuite la voie standard. Le paiement collecté par l’agent est réservé aux **partenaires API uniquement** : agences qui réservent via la Partner API depuis leur propre système, collectent déjà les paiements clients sous leur propre licence et contractent directement avec les hôtels.

## Étape 1 : Enregistrez votre agence

<Steps>
1. Rendez-vous sur [app.wink.travel](https://app.wink.travel), cliquez sur `Sign-In / Register` et inscrivez-vous.

2. Cliquez sur `Accounts` dans la barre latérale gauche, puis sur `Create`, et choisissez **I am a Travel Agent**.

3. Remplissez les informations de votre agence. Choisissez **Company** comme type d’entité : cela détermine comment vous êtes payé. Voir [Create Account](/fr/portal/create-account/).

4. Si vous souhaitez collecter vous-même les paiements via la Partner API, choisissez cette option lors de l’enregistrement. Il s’agit d’une demande, pas d’une approbation. Voir [Étape 6](#step-6-collect-payment-yourself-api-partners-only).

5. Wink examine chaque enregistrement d’agence de voyage. Nous envoyons un e-mail à votre adresse enregistrée et demandons vos documents : informations sur l’entreprise et votre numéro d’enregistrement d’agence de voyage ou code IATA. Vous pouvez réserver une fois votre enregistrement approuvé.
</Steps>

## Étape 2 : Ajoutez votre compte bancaire

Allez dans `Account > Bank Accounts`, ajoutez le compte de votre agence et marquez-le **Primary**. La commission est versée par virement bancaire sur ce compte. Wink effectue les paiements via Revolut, donc un compte business Revolut est la solution la plus fluide, mais tout compte bancaire fonctionne. Voir [Bank Accounts](/fr/portal/settings/payouts/).

## Étape 3 : Trouvez des hôtels pour votre client

<Steps>
1. Cliquez sur `Browse > Hotels` dans la barre de navigation principale.

2. Recherchez par destination, dates et occupation, et filtrez jusqu’à obtenir les bonnes options pour votre client.

3. Enregistrez des listes courtes dans une [liste sélectionnée](/fr/portal/studio/curated-lists/) si vous comparez des options avec le client.
</Steps>

Les tarifs affichés sont ceux de l’hôtel. Wink les transmet tels quels, sans majoration : vous gagnez via la commission. Voir [Search](/fr/portal/studio/search/).

## Étape 4 : Réservez pour votre client

<Steps>
1. Choisissez la chambre et le tarif, et saisissez le nom et les coordonnées de votre client en tant que voyageur.

2. Au paiement, saisissez la carte que votre client vous a donnée pour cette réservation. Le paiement est collecté pour l’hôtel, qui reste commerçant enregistré.

3. Confirmez. Vous, le voyageur et l’hôtel recevez chacun un e-mail de confirmation. Le code de réservation commence par `WNK`.
</Steps>

:::caution[Manipulez la carte de votre client avec précaution]
Demandez la carte uniquement pour la réservation en cours et saisissez-la directement dans le paiement. Ne la notez pas, ne l’envoyez pas par e-mail et ne la conservez pas dans vos propres dossiers.
:::

## Étape 5 : Gérez les réservations et soyez payé

- **Réservations :** cliquez sur `Bookings` dans la barre de navigation principale pour voir toutes les réservations, les filtrer, les exporter en CSV, renvoyer une confirmation ou annuler dans le respect de la politique d’annulation de l’hôtel. Voir [Bookings](/fr/portal/travel-agent/bookings/).
- **Commission :** 10 % par défaut. Une fois que vous travaillez régulièrement avec un hôtel, vous pouvez lui demander une [connexion directe](/fr/portal/studio/network/) et convenir d’une commission différente.
- **Paiement :** la commission devient disponible dans les 24 heures suivant l’enregistrement du client, et est versée sur votre compte bancaire principal. Les frais de transfert sont facturés au coût. Voir [Pricing](/fr/getting-started/pricing/).

## Étape 6 : Collectez vous-même les paiements (partenaires API uniquement)

Passez cette étape si vous réservez dans le portail ou si vous êtes satisfait de la voie standard.

<Steps>
1. Intégrez la [Partner API](/fr/integrations/partner-api/). Cette voie fonctionne uniquement via l’API, depuis votre propre système de réservation, pas dans le portail.

2. Choisissez cette voie lors de l’enregistrement (Étape 1).

3. Wink l’évalue avec vos documents d’enregistrement, par exemple votre situation financière et votre statut réglementaire, et confirme par écrit. L’approbation inclut une **limite de crédit** : le montant maximal que vous pouvez avoir en réservations non réglées à tout moment.

4. Tant que vous n’êtes pas approuvé, vous pouvez continuer à réserver via la voie standard.
</Steps>

Une fois approuvé, vous encaissez vous-même le paiement du client et payez chaque hôtel directement. Pour chaque réservation, vous déduisez, dans l’ordre, les 1,5 % de frais Wink puis votre commission ; le reste est dû à l’hôtel :

| Sur une réservation de 1 000,00 USD avec une commission de 10 % | |
|---|---|
| Valeur de la réservation | 1 000,00 USD |
| Moins les frais Wink (1,5 % de la valeur) | 15,00 USD |
| Sous-total | 985,00 USD |
| Moins votre commission (10 % du sous-total) | 98,50 USD |
| **Montant dû à l’hôtel** | **886,50 USD** |

Wink facture les frais de réservation de 1,5 % mensuellement, en USD, payables sous 15 jours, plus toute utilisation de la Partner API au-delà du quota gratuit. Vous êtes responsable des remboursements, rétrofacturations, sécurité des paiements (PCI-DSS) et de toute licence requise dans votre pays pour collecter les paiements. Les conditions complètes sont dans le [Travel Agent Agreement](/fr/legal/platform-agreements/).

## Connectez vos propres systèmes

Les agences disposant de leurs propres outils de réservation peuvent rechercher et réserver via la [Partner API](/fr/integrations/partner-api/). Les comptes agences de voyage peuvent créer des réservations directement avec elle, et c’est la seule façon de travailler sur la voie de paiement collecté par l’agent. Voir la [référence Partner API](/fr/partner-api/partner/).
