Le moteur de réservation s’intègre partout. Choisissez votre framework ou CMS et suivez son guide ; les Web Components sous-jacents sont les mêmes partout.

## Approches principales

- [Web Components](/fr/integrations/web-components/) — les éléments embarquables utilisés par toutes les intégrations.
- [npm package](/fr/integrations/npm/) — installation dans une build JavaScript.
- [Headless CMS](/fr/integrations/headless/) — rendu depuis n’importe quel backend de contenu.
- [Partner API](/fr/integrations/partner-api/) — intégration programmatique complète.
