Le Moteur de Réservation est la couche transactionnelle sous-jacente à chaque parcours Wink : le site web propre à l'hôtel, les liens partenaires et créateurs, la découverte par les consommateurs et les agents IA. Le paiement est collecté pour le compte de l'hôtel, en tant que son agent, ce qui permet à l'hôtel de rester le commerçant de référence.

## Le parcours de réservation

- [Recherche](/fr/booking-engine/search/) — trouver les disponibilités.
- [Détail de l'établissement](/fr/booking-engine/property-detail/) — chambres, tarifs, politiques et options supplémentaires.
- [Paiement](/fr/booking-engine/checkout/) — une étape de paiement unique à l'image de l'hôtel.
- [Confirmation de réservation](/fr/booking-engine/confirmation/) — ce que reçoit le client.
