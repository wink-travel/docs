Il vous sera demandé de définir l’emplacement de votre établissement lors de la configuration.

Pour gérer l’emplacement de votre établissement sur la carte, cliquez sur `Property > Position` dans l’onglet de navigation principal.

Vous pouvez définir l’emplacement sur la carte de deux façons :

1. Recherchez votre établissement par nom dans le champ de recherche au-dessus de la carte et sélectionnez-le.
2. Utilisez la carte, zoomez et déplacez-vous jusqu’à l’emplacement de votre établissement, puis cliquez sur la carte lorsque vous l’avez trouvé.

Un marqueur apparaîtra avec vos coordonnées mises à jour.

:::note
Votre établissement doit être enregistré sur Google Pages pour apparaître dans le champ de recherche.
:::

Mettez à jour le formulaire et cliquez sur le bouton `Save` pour continuer.
