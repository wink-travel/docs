Le tableau de bord est la première chose que vous voyez lorsque vous ouvrez [Portal](https://app.wink.travel) — le centre de commande de votre compte. Tous les types de compte voient les mêmes deux sections ; seules les données sous-jacentes diffèrent selon que vous gérez une propriété ou un compte de type affilié (Studio, Agent de voyage, Corporate).

## Activité

Un aperçu rapide de la santé de vos réservations, avec des cartes affichant :

- Nombre total de réservations
- Valeur moyenne des ventes
- Montant total des ventes

Un lien vous emmène directement à votre liste complète de réservations pour plus de détails.

## Analyses

Un graphique suivant vos ventes dans le temps, avec un lien vers vos analyses complètes pour un filtrage plus approfondi et des plages de dates.
