Avant toute chose, vous devez créer un compte utilisateur sur Wink.

<Aside type="note" title="Vous réservez un voyage ?">
Ce guide s'adresse aux professionnels souhaitant travailler avec l'inventaire de voyages de Wink — hôteliers, agents de voyage, affiliés et autres partenaires gérant les réservations, les établissements et la distribution. Si vous êtes un voyageur, vous n'avez pas besoin de compte au préalable : vous en créerez un lors du processus de paiement lorsque vous effectuerez une réservation.
</Aside>

Suivez ces étapes :

<Steps>
1. Rendez-vous sur [app.wink.travel](https://app.wink.travel)
2. Cliquez sur `Sign-In / Register` en haut à droite
3. Vous serez dirigé vers un formulaire de connexion. Cliquez sur le lien `Register` sous les champs du formulaire.
4. Remplissez le formulaire d'inscription et cliquez sur `Register`. Vous êtes redirigé vers la page de connexion.
5. Une fois connecté, vous serez redirigé vers notre [Portail](/fr/portal/create-account) où vous pourrez créer votre premier compte.
</Steps>

Créer un compte utilisateur Wink vous donne accès à toutes les fonctionnalités de la plateforme. Vous pouvez créer un nombre illimité d’établissements et de comptes affiliés.
