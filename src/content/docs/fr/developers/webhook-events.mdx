Cette page liste tous les événements webhook auxquels vous pouvez vous abonner sur Wink. Pour les instructions de configuration, consultez le [Guide d'intégration Webhook](/fr/guides/developers/webhook-integration) ou la [page de gestion des Webhooks](/fr/portal/settings/webhooks).

## Comment s'abonner

1. Accédez à **Applications > Webhooks** dans votre portail.
2. Créez un webhook et sélectionnez les événements que vous souhaitez recevoir.
3. Wink envoie un HTTP POST à votre point de terminaison chaque fois que l'événement se produit.

Pour les étapes complètes de configuration et les bonnes pratiques, consultez [Intégration Webhook](/fr/guides/developers/webhook-integration).

## Gestion des événements d'entité

Événements pour la gestion des entités (propriétés, affiliés, entreprises) et leur administration.

### Cycle de vie

| Événement | Clé | Description |
|---|---|---|
| Entité créée | `managing_entity.created` | Une nouvelle entité de gestion a été créée. |
| Entité supprimée | `managing_entity.deleted` | Une entité de gestion a été supprimée. |
| Statut mis à jour | `managing_entity.status.updated` | Le statut de l'entité a changé. |
| En cours de révision | `account.under_review` | Le compte de l'entité est en attente de révision. |

### Abonnement

| Événement | Clé | Description |
|---|---|---|
| Abonnement provisionné | `managing_entity.subscription.provisioned` | Un nouvel abonnement a été provisionné. |
| Abonnement modifié | `managing_entity.subscription.changed` | Le plan d'abonnement a été modifié. |
| Facture d'abonnement modifiée | `managing_entity.subscription.invoice.changed` | La facture d'abonnement a été mise à jour. |

### Cycle de vie du gestionnaire

| Événement | Clé | Description |
|---|---|---|
| Gestionnaire ajouté | `managing_entity.manager.added` | Un nouveau gestionnaire a été ajouté. |
| Gestionnaire invité | `managing_entity.manager.invited` | Une invitation a été envoyée à un gestionnaire. |
| Gestionnaire supprimé | `managing_entity.manager.removed` | Un gestionnaire a été supprimé. |
| Gestionnaire accepté | `managing_entity.manager.accepted` | Une invitation de gestionnaire a été acceptée. |
| Gestionnaire rejeté | `managing_entity.manager.rejected` | Une invitation de gestionnaire a été rejetée. |
| Propriétaire défini | `managing_entity.manager.owner.set` | La propriété de l'entité a été transférée. |
| Gestionnaires mis à jour | `account.managers.update` | La liste des gestionnaires a changé. |

### Informations sur l'entité

| Événement | Clé | Description |
|---|---|---|
| Informations mises à jour | `managing_entity.information.updated` | Les informations de l'entité ont été mises à jour. |
| Adresse mise à jour | `managing_entity.city.updated` | L'adresse/la ville de l'entité a été modifiée. |
| Nom mis à jour | `managing_entity.name.updated` | Le nom de l'entité a été modifié. |
| Nom d'URL mis à jour | `managing_entity.url_name.updated` | L'URL personnalisée de l'entité a changé. |
| Identifiant unique mis à jour | `managing_entity.unique_id.updated` | L'identifiant unique de l'entité a changé. |
| Gestionnaire mis à jour | `managing_entity.managed_by.updated` | La relation parent/gestionnaire de l'entité a changé. |
| ID de lieu mis à jour | `managing_entity.place_id.updated` | L'ID Google Place de l'entité a changé. |
| Représentant du compte mis à jour | `managing_entity.account_representative.updated` | Le représentant du compte a été modifié. |
| Photo de profil mise à jour | `managing_entity.profile_picture.updated` | La photo de profil de l'entité a été mise à jour. |
| Logo mis à jour | `managing_entity.logo.updated` | Le logo de l'entité a été mis à jour. |
| Détails mis à jour | `account.details.updated` | Les champs de détails du compte ont changé. |
| Agent mis à jour | `managing_entity.agent.updated` | L'agent de l'entité a été modifié. |
