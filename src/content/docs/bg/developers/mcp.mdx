Wink предоставя два автентикирани MCP сървъра. И двата използват **интерактивно OAuth2 влизане** (PKCE authorization code flow) — вашият AI агент отваря браузър таб, за да влезете с вашия Wink акаунт. Няма нужда от управление на client secrets.

| Сървър | URL | Какво прави |
|--------|-----|--------------|
| **Inventory API** | `https://api.wink.travel/mcp` | Инвентар, резервации, цени, канали за продажба, аналитика и всички операции на платформата |
| **Integrations** | `https://integrations.wink.travel/mcp` | Интеграции с channel manager — синхронизиране на имоти, цени и наличности с OTAs |

---

## Как работи автентикацията

Wink MCP сървърите използват **OAuth2 Authorization Code + PKCE** поток и поддържат **Dynamic Client Registration (RFC 7591)**. Ето какво се случва при първото свързване:

1. Вашият AI клиент открива authorization сървъра от метаданните на MCP endpoint `/.well-known/oauth-protected-resource`.
2. Клиентът се регистрира автоматично чрез **Dynamic Client Registration** — не е необходима ръчна настройка на приложението.
3. Клиентът отваря **браузър таб** към `https://iam.wink.travel`. Влизате с вашия Wink акаунт и одобрявате заявените разрешения на екрана за съгласие.
4. Wink издава **access token**, обвързан с вашата идентичност и обхвата на акаунта ви.
5. AI клиентът прикача токена към всяка MCP заявка. Всички резултати от инструментите автоматично са ограничени до управляващата ви единица.
6. Токените изтичат след 3 часа. Вашият AI клиент обновява токена тихо на заден план без повторно искане за влизане.

Всяко повикване на инструмент се изпълнява **под вашата идентичност** — същите ACL правила, които защитават уеб портала, важат и за AI агента.

## Свържете вашия AI клиент

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Уверете се, че Claude Code е актуален:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Добавете Wink Inventory MCP сървъра:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code се свързва със сървъра, открива authorization сървъра и отваря вашия браузър по подразбиране.

4. **Влезте в Wink** и одобрете заявката за разрешения на екрана за съгласие.

5. Claude Code потвърждава връзката. Въведете `/mcp`, за да проверите дали сървърът се появява и инструментите са заредени.
</Steps>

За да добавите и Integrations сървъра:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Споделете с вашия екип]
Добавете `--scope project` към `claude mcp add` и Claude Code записва URL на сървъра в `.mcp.json` в корена на репото. Качете този файл — всеки член на екипа ще завърши собственото си влизане в браузъра при първото свързване.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Редактирайте конфигурационния файл на Claude Desktop:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. Добавете записите за MCP сървърите:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **Затворете напълно и рестартирайте** Claude Desktop (използвайте Quit от менюто — затварянето на прозореца не е достатъчно).

4. Claude Desktop отваря браузър таб за всеки нов сървър. Влезте в Wink и одобрете разрешенията.

5. Иконата на щепсела в долната лента показва и двата сървъра като свързани.
</Steps>

  </TabItem>
  <TabItem label="OpenAI Codex">

<Steps>
1. Уверете се, че Codex CLI е инсталиран:
   ```bash
   npm install -g @openai/codex
   ```

2. Отворете (или създайте) конфигурационния файл на Codex:
   - **macOS / Linux:** `~/.codex/config.json`
   - **Windows:** `%USERPROFILE%\.codex\config.json`

3. Добавете записите за Wink MCP сървърите:

   ```json title="~/.codex/config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

4. Стартирайте Codex. При първото използване Codex отваря браузър таб към `https://iam.wink.travel`.

5. **Влезте в Wink** и одобрете заявените разрешения.

6. Codex потвърждава връзката. Стартирайте `codex` и го помолете да изброи наличните инструменти, за да проверите дали Wink сървърите са активни.
</Steps>

:::note
Поддръжката на MCP в Codex CLI изисква версия **1.0** или по-нова. Изпълнете `codex --version`, за да проверите, и `npm install -g @openai/codex`, за да обновите.
:::

  </TabItem>
  <TabItem label="ChatGPT">

Поддръжката на MCP сървъри е налична в **ChatGPT desktop app** за абонати Plus, Pro, Team и Enterprise.

<Steps>
1. Изтеглете и инсталирайте [ChatGPT desktop app](https://openai.com/chatgpt/download/), ако още не сте го направили.

2. Отворете приложението и кликнете върху **вашия профилен икон** в горния десен ъгъл, след което изберете **Settings**.

3. Отидете на **Connectors** (или **MCP Servers** в зависимост от версията на приложението) и кликнете **Add**.

4. Въведете URL на Wink Inventory сървъра:
   ```
   https://api.wink.travel/mcp
   ```
   След това кликнете **Connect**.

5. ChatGPT отваря браузър таб към `https://iam.wink.travel`. **Влезте в Wink** и одобрете разрешенията.

6. Повторете стъпки 4–5 за Integrations сървъра:
   ```
   https://integrations.wink.travel/mcp
   ```

7. И двата сървъра се появяват в списъка с Connectors. Започнете нов чат — Wink инструментите са налични автоматично.
</Steps>

:::note[Ограничение на уеб приложението]
MCP сървърите могат да се конфигурират само в **desktop app**. Уеб интерфейсът на ChatGPT на chatgpt.com не поддържа персонализирани MCP сървъри.
:::

<Steps>
1. Отворете (или създайте) конфигурационния файл за Cursor MCP:
   - **macOS / Linux:** `~/.cursor/mcp.json`
   - **Windows:** `%USERPROFILE%\.cursor\mcp.json`

2. Добавете записите за Wink MCP сървърите:

   ```json title="~/.cursor/mcp.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. Отворете Cursor. Отидете на **Settings → Cursor Settings → MCP** и потвърдете, че и двата сървъра се показват със зелен индикатор за статус. Ако са червени, кликнете **Refresh**.

4. Cursor отваря браузър таб към `https://iam.wink.travel`. **Влезте в Wink** и одобрете разрешенията.

5. Отворете чат (`Ctrl+L` / `Cmd+L`) и помолете Cursor да изброи наличните Wink инструменти, за да потвърдите връзката.
</Steps>

:::

## Референция на обхватите

Когато одобрите екрана за съгласие, ще видите разбивка на заявените от агента разрешения. Wink групира разрешенията по функционални области:

| Група обхват | Обхвати | Какво отключват |
|-------------|--------|-----------------|
| **MCP транспорт** | `mcp.read` `mcp.write` `mcp.remove` | Необходими за свързване към който и да е MCP сървър |
| **Акаунт** | `account.read` `account.write` `account.remove` | Управляващи единици, членове на екипа, настройки, приложения |
| **Резервация** | `booking.read` `booking.write` `booking.remove` | Търсене, преглед, създаване, анулиране и възстановяване на резервации |
| **Инвентар** | `inventory.read` `inventory.write` `inventory.remove` | Имоти, стаи, цени, удобства, наличности |
| **Аналитика** | `analytics.read` | Аналитика на резервации, отчети за приходи, класации |
| **Маркетинг** | `marketing.read` `marketing.write` `marketing.remove` | Социални публикации, кампании, канали за продажба, промоции |
| **Съдържание** | `content.read` `content.write` `content.remove` | Мултимедия, съкратени URL, синдикирани елементи, карти |
| **Плащане** | `payment.read` `payment.write` | Главна книга, плащания, финансови разбивки, тегления |

AI клиентът иска само необходимите му обхвати. Можете да откажете отделни разрешения на екрана за съгласие — инструментите, които изискват отказан обхват, ще върнат грешка при извикване.

## Отстраняване на проблеми

**Браузър таб не се отваря**

Вашият AI клиент може да не поддържа още интерактивния PKCE поток. Проверете дали използвате последна версия:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** обновете чрез вградения ъпдейтър на приложението

**`401 Unauthorized` след влизане**

Кешираният ви токен може да е изтекъл. Премахнете и добавете отново сървъра, за да задействате ново влизане:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

За Claude Desktop и ChatGPT, премахнете сървъра от настройките, рестартирайте приложението и го добавете отново.

**`403 Forbidden` при извикване на конкретен инструмент**

Инструментът изисква обхват, който не сте одобрили на екрана за съгласие. Свържете отново сървъра — екранът за съгласие ще се появи и можете да одобрите липсващото разрешение.

**Сървърът се появява, но повикванията към инструменти връщат "account not found"**

Влезли сте с Wink акаунт, който няма управляваща единица. Отидете на [Wink Portal](https://app.wink.travel) и се уверете, че акаунтът ви е настроен преди да използвате MCP сървъра.

**Токенът изтича по време на сесия**

Токените са валидни 3 часа. Claude Code и Claude Desktop обновяват токените тихо без прекъсване на сесията. Ако получите грешки при автентикация след дълго бездействие, изпратете ново съобщение — клиентът ще се автентикира автоматично.

**Codex CLI показва "MCP server unreachable"**

Проверете дали `~/.codex/config.json` е валиден JSON (без запетаи накрая) и че `"type": "http"` е зададено. Codex изисква HTTP транспорт за отдалечени сървъри; stdio транспорт е само за локални бинарни файлове.

**Менюто "Connectors" в ChatGPT липсва**

Поддръжката на MCP изисква версия на ChatGPT desktop app **1.2024.352** или по-нова и активен абонамент Plus, Pro, Team или Enterprise. Обновете приложението и проверете плана си в Settings → Account.

**Сървърът в Cursor показва червено / "Failed to connect"**

Проверете дали `~/.cursor/mcp.json` е валиден JSON и съдържа `"type": "http"`. След това отидете на **Settings → Cursor Settings → MCP** и кликнете **Refresh**. Ако грешката продължава, рестартирайте напълно Cursor — промените в конфигурацията не винаги се засичат без рестарт.

**Windsurf MCP сървърите не се показват в настройките**

Windsurf изисква пълен рестарт (не само презареждане на прозореца), за да засече промените в `mcp_config.json`. Използвайте **File → Quit** и стартирайте отново. Ако сървърите все още не се появяват, уверете се, че сте на Windsurf **1.4+** чрез **Help → About Windsurf**.

**Опцията "Add Server" в Cline не е видима**

Мениджърът на MCP сървъри изисква Cline **2.0** или по-нова версия. Отворете панела с разширения на VS Code, намерете Cline и кликнете **Update**, ако има налична актуализация. След обновяване презаредете VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
