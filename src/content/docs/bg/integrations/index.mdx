Booking Engine може да се вгражда навсякъде. Изберете своя фреймуърк или CMS и следвайте неговото ръководство; основните Web Components са еднакви навсякъде.

## Основни подходи

- [Web Components](/bg/integrations/web-components/) — вградимите елементи, които използва всяка интеграция.
- [npm package](/bg/integrations/npm/) — инсталиране в JavaScript билд.
- [Headless CMS](/bg/integrations/headless/) — рендиране от всякакъв бекенд за съдържание.
- [Partner API](/bg/integrations/partner-api/) — пълна програмна интеграция.
