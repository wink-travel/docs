Booking Engine embutido em qualquer lugar. Escolha o seu framework ou CMS e siga o seu guia; os Web Components subjacentes são os mesmos em todo lado.

## Abordagens principais

- [Web Components](/pt-PT/integrations/web-components/) — os elementos embutíveis que todas as integrações usam.
- [pacote npm](/pt-PT/integrations/npm/) — instale numa build JavaScript.
- [Headless CMS](/pt-PT/integrations/headless/) — renderize a partir de qualquer backend de conteúdo.
- [Partner API](/pt-PT/integrations/partner-api/) — integração programática completa.
