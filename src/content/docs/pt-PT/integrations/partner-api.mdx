A **API Parceiro** da Wink é a forma autenticada e de maior capacidade para integradores consultarem inventário de viagens reservável — o mesmo fornecimento que alimenta os nossos widgets incorporáveis e endpoints públicos de navegação, exposto como uma interface programática de primeira classe. Enquanto os Web Components gratuitos e os endpoints públicos de navegação são destinados a incorporações leves e orientadas para o utilizador, a API Parceiro é construída para sistemas que pesquisam, precificam e reservam em grande escala. O acesso é autenticado por integrador e faturado por uso, para que pague apenas pelo tráfego que realmente enviar.

## Planos e preços

O uso é medido em **noites de hotel**: um hotel precificado para uma noite de estadia — *não* uma chamada API. Uma pesquisa que retorna 20 hotéis para uma estadia de 3 noites corresponde a 60 noites de hotel numa única requisição. Chamadas de Conteúdo e Pesquisa (busca de destino e autocompletar) são exceção: cada uma custa uma unidade por chamada, independentemente do que retorna. Endpoints de conta são gratuitos. [Preços](/pt-PT/pricing/) são a fonte de verdade para a tarifa.

## Referência da API

Duas interfaces servem o inventário reservável, correspondendo aos dois níveis acima:

- **Gratuito — API Consumidor / Motor de Reservas** (REST, `/api/public/**`): anónimo, orientado para browser e widgets. [Navegar pela referência do Motor de Reservas →](/pt-PT/api/booking-engine/)
- **Pago — API Integrador Parceiro** (**gRPC**, `wink.partner.v1`): autenticado, medido por uso, construído para integração servidor a servidor em escala. [Navegar pela referência do Integrador →](/pt-PT/partner-api/partner/)

A API Integrador Parceiro é gRPC, não REST. Chama-se com um cliente gerado sobre HTTP/2 em
`partner.wink.travel:443`, passando um token bearer e a conta para a qual está a chamar:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

A página de referência acima documenta todos os serviços, mensagens e estados de erro, e o esquema está também
disponível em tempo de execução através de reflexão do servidor, pelo que `grpcurl`, Postman e Insomnia o descobrem sem
necessidade de download.

Se preferir gerar um cliente antecipadamente, os ficheiros fonte `.proto` estão publicados em
[github.com/wink-travel/partner-api-proto](https://github.com/wink-travel/partner-api-proto).

## Como funcionam o uso e os limites

### Nível gratuito

O nível gratuito foi concebido para permitir que construa, teste e execute tráfego de produção modesto sem custos.

- **Sem limite por minuto publicado.** A Wink monitoriza as taxas de pedidos e pode aplicar limites de uso justo para proteger o serviço. Se receber um **HTTP 429 (Too Many Requests)**, aguarde o número de segundos indicado no cabeçalho `Retry-After` antes de tentar novamente.
- **Franquia mensal — 10.000 unidades por mês civil.** A franquia é concedida por conta e reinicia no dia 1 de cada mês (UTC). Quando a atingir, uma conta que não tenha aderido à faturação paga conforme uso recebe **HTTP 429 até ao dia 1 do mês seguinte** — uma paragem rígida, com cabeçalho `Retry-After` e uma mensagem a convidar a subscrever o nível Pago. Uma conta aderida continua a funcionar e é faturada pelo uso além da franquia.

O nível gratuito não inclui Acordo de Nível de Serviço nem suporte prioritário.

### Nível pago

O nível pago remove o teto mensal e cobra apenas pelo que usar.

- **Noites de hotel medidas — 0,0001 $ por noite de hotel.** Não há teto mensal; é faturado pelo volume real. A Wink pode ainda aplicar limites de uso justo para proteger o serviço. Chamadas de pesquisa e inventário são faturadas por noite de hotel precificada; chamadas de Conteúdo e Pesquisa são faturadas uma unidade cada, pelo que agrupar pedidos mantém a fatura baixa.

O nível pago inclui o Acordo de Nível de Serviço descrito abaixo — compromisso de 99,9% de uptime e objetivo de tempo de resposta P95 inferior a 500 ms — e suporte prioritário baseado na severidade.

## Acordo de Nível de Serviço

_Data de vigência: 5 de julho de 2026 · Versão 1.0_

Este Acordo de Nível de Serviço (o "SLA") estabelece o compromisso de disponibilidade, créditos de serviço e metas de suporte que a Wink ("Wink", "nós", "nos") fornece a um cliente ("Cliente", "você") para a API Parceiro autenticada da Wink (a "API Parceiro" ou "Serviço") nos níveis em que um SLA é declarado aplicável. Este SLA está incorporado e é regido pelo acordo entre você e a Wink sob o qual acede à API Parceiro (o "Acordo"), e aplica-se enquanto mantiver uma subscrição ativa e paga da API Parceiro em boa situação. Termos em maiúsculas não definidos aqui têm o significado atribuído no Acordo.

### 1. Definições

1. **"Uptime"** significa os períodos durante os quais a API Parceiro está disponível para aceitar e responder com sucesso a pedidos autenticados e corretamente formados.
2. **"Downtime"** significa qualquer período, medido em minutos, durante o qual a API Parceiro não responde com sucesso a pedidos autenticados e corretamente formados, excluindo qualquer período que se enquadre nas Exclusões definidas na Secção 4. Erros isolados que afetam uma fração imaterial de pedidos não são, por si só, Downtime.
3. **"Percentagem Mensal de Uptime"** significa, para um dado mês civil, o total de minutos nesse mês menos os minutos totais de Downtime, dividido pelo total de minutos nesse mês, expresso em percentagem.
4. **"Manutenção Programada"** significa manutenção planeada do Serviço para a qual a Wink forneceu aviso prévio conforme a Secção 4.
5. **"Crédito de Serviço"** significa um crédito, calculado como uma percentagem das taxas pagas ou pagáveis por si pela API Parceiro no mês civil afetado, que é aplicado contra futuras taxas da API Parceiro como o único e exclusivo recurso por falha em cumprir o Compromisso de Uptime.
6. **"Tempo de Resposta"** significa o tempo decorrido entre a receção pela Wink de um pedido autenticado e corretamente formado na fronteira do serviço da Wink e o ponto em que a Wink começa a devolver a resposta, excluindo o trânsito de rede e qualquer tempo do lado do cliente fora do controlo da Wink.

### 2. Compromisso de Disponibilidade e Desempenho

A Wink usará esforços comercialmente razoáveis para tornar a API Parceiro disponível com uma **Percentagem Mensal de Uptime de pelo menos 99,9%** durante cada mês civil do prazo (o "Compromisso de Uptime"). O Compromisso de Uptime é medido na fronteira do serviço da Wink e exclui quaisquer fatores fora do controlo razoável da Wink, incluindo os descritos na Secção 4. Os sistemas de monitorização da Wink são a fonte autoritativa para medir a Percentagem Mensal de Uptime e o Tempo de Resposta.

A Wink visa ainda um **Tempo de Resposta no 95.º percentil (P95) inferior a 500 milissegundos** para pedidos autenticados e corretamente formados bem-sucedidos, medido na fronteira do serviço da Wink ao longo de cada mês civil (o "Objetivo de Desempenho"). O Objetivo de Desempenho exclui os fatores descritos na Secção 4, pedidos que retornem erros a nível de aplicação causados pelo próprio pedido, e pedidos em lote incomumente grandes ou complexos. O Objetivo de Desempenho é um objetivo de serviço; os Créditos de Serviço na Secção 3 aplicam-se a falhas no cumprimento do **Compromisso de Uptime** e são o único e exclusivo recurso para insuficiências de disponibilidade.

### 3. Créditos de Serviço

Se a Percentagem Mensal de Uptime ficar abaixo do Compromisso de Uptime em qualquer mês civil, poderá ser elegível para um Crédito de Serviço calculado como uma percentagem das taxas da API Parceiro pagas ou pagáveis por si nesse mês, conforme a seguinte escala:

| Percentagem Mensal de Uptime | Crédito de Serviço |
|---|---|
| Abaixo de 99,9% mas igual ou superior a 99,0% | 10% |
| Abaixo de 99,0% mas igual ou superior a 95,0% | 25% |
| Abaixo de 95,0% | 50% |

1. **Reivindicação de crédito.** Para receber um Crédito de Serviço deve submeter uma reclamação por escrito à Wink dentro de **trinta (30) dias** após o final do mês civil em que ocorreu a insuficiência. A reclamação deve incluir as datas e horas de cada incidente de Downtime que está a reclamar e quaisquer registos ou evidências razoavelmente disponíveis. Reclamações submetidas após este prazo não são elegíveis.
2. **Forma do crédito.** Créditos de Serviço aprovados são aplicados contra futuras taxas da API Parceiro e não têm valor monetário. Não são reembolsos e não serão pagos exceto quando exigido por lei aplicável.
3. **Crédito máximo.** O total de Créditos de Serviço concedidos para qualquer mês civil não excederá 50% das taxas da API Parceiro pagas ou pagáveis por si nesse mês.
4. **Recurso único e exclusivo.** Os Créditos de Serviço são o seu **único e exclusivo recurso** por qualquer falha da Wink em cumprir o Compromisso de Uptime ou qualquer outra insuficiência de disponibilidade da API Parceiro.

### 4. Exclusões

O Compromisso de Uptime e quaisquer Créditos de Serviço resultantes não se aplicam, e Downtime não inclui, qualquer indisponibilidade, suspensão, degradação ou problema de desempenho que surja ou esteja relacionado com:

1. **Manutenção Programada** para a qual a Wink tenha dado aviso prévio, desde que tal aviso seja dado com antecedência razoável através de um canal que a Wink normalmente usa para comunicar com clientes;
2. eventos de **força maior** ou outras causas fora do controlo razoável da Wink, incluindo desastres naturais, atos governamentais, falhas de rede ou utilidades, e ataques de negação de serviço ou outros ataques maliciosos;
3. problemas causados por **seus** atos ou omissões, seu equipamento, software ou rede, ou por qualquer serviço, produto ou fornecedor **terceiro** não sob controlo direto da Wink;
4. seu **abuso do Serviço** ou **violação do Acordo**, deste SLA, dos termos de uso aceitável, ou dos limites de taxa aplicáveis, incluindo tráfego que a Wink razoavelmente determine ser excessivo, abuso automatizado ou fraudulento; e
5. qualquer **suspensão ou rescisão** do seu acesso devidamente efetuada ao abrigo do Acordo, incluindo suspensão por falta de pagamento.

### 5. Suporte e Metas de Resposta

A Wink fornece suporte para a API Parceiro durante o horário comercial padrão, excluindo feriados públicos locais. A Wink usará esforços comercialmente razoáveis para reconhecer pedidos de suporte devidamente submetidos dentro dos seguintes tempos-alvo de resposta, com base na severidade que atribuir e que a Wink confirmar razoavelmente:

| Severidade | Descrição | Resposta inicial alvo |
|---|---|---|
| **Sev 1 — Crítico** | API Parceiro está indisponível ou inutilizável em produção sem solução alternativa. | 4 horas |
| **Sev 2 — Maior** | Funcionalidade significativa prejudicada ou degradada; existe solução alternativa. | 1 dia útil |
| **Sev 3 — Menor** | Questões gerais, problemas menores ou pedidos de funcionalidade. | 2 dias úteis |

Os tempos-alvo de resposta descrevem quando a Wink pretende fazer o **contacto inicial**; não são garantias de tempo de resolução. Suporte prioritário e metas baseadas em severidade aplicam-se nos níveis onde estão indicados como incluídos.

### 6. Dados e Segurança

A Wink mantém medidas administrativas, técnicas e organizacionais comercialmente razoáveis destinadas a proteger a confidencialidade, integridade e disponibilidade dos dados processados através da API Parceiro, e revê essas medidas periodicamente. O processamento de dados pessoais pela Wink é regido pela [Política de Privacidade](/pt-PT/privacy) e quaisquer termos de processamento de dados no Acordo. Você continua responsável por proteger as suas credenciais API, pelo uso legal de quaisquer dados que recupere, e por notificar prontamente a Wink de qualquer suspeita de comprometimento das credenciais.

### 7. Limitação de Responsabilidade

Os Créditos de Serviço são o **único e exclusivo recurso** por qualquer indisponibilidade ou falha em cumprir o Compromisso de Uptime, e são fornecidos em substituição a qualquer outra responsabilidade decorrente dessa falha. Exceto conforme expressamente declarado neste SLA, a API Parceiro é fornecida "tal como está". Na máxima extensão permitida pela lei aplicável, a responsabilidade agregada da Wink decorrente ou relacionada com o Serviço é limitada conforme estabelecido no Acordo, e a Wink não é responsável por quaisquer danos indiretos, incidentais, especiais, consequenciais ou punitivos, ou por lucros cessantes, receitas, dados ou boa vontade, mesmo que avisada da possibilidade de tais danos.

### 8. Prazo, Alterações e Rescisão

Este SLA aplica-se enquanto mantiver uma subscrição ativa da API Parceiro num nível onde o SLA é declarado aplicável. A Wink pode atualizar este SLA ocasionalmente; alterações materiais serão comunicadas através de um canal que a Wink normalmente usa para alcançar clientes, e o uso continuado da API Parceiro após a atualização entrar em vigor constitui aceitação do SLA atualizado. Este SLA termina automaticamente com a rescisão ou expiração do Acordo ou da sua subscrição da API Parceiro. Secções que por sua natureza devem sobreviver à rescisão — incluindo elegibilidade a Créditos de Serviço acumulados mas não reclamados, limitação de responsabilidade e definições — permanecem em vigor.
