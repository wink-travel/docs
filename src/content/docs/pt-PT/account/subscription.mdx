A página de faturação é onde ativa o pagamento conforme o uso, decide a que contas se aplica e acompanha o que está a gastar.

Não precisa de vir aqui para começar. Cada conta tem uma franquia mensal gratuita nas funcionalidades medidas sem fazer nada. Esta página é apenas para ultrapassar essa franquia. Veja [Preços](/pt-PT/getting-started/pricing) para saber o que é gratuito, o que é medido e quanto custa.

## Ativar o pagamento conforme o uso

Ative o pagamento conforme o uso e escolha como quer liquidar a sua fatura:

- **Cartão** — cobramos automaticamente o seu cartão guardado quando a fatura é emitida.
- **Fatura** — enviamos-lhe uma fatura e paga-a você mesmo.

Pode alternar entre os dois a qualquer momento.

:::note
Só o **proprietário** de uma conta pode ativar o pagamento conforme o uso para essa conta. Ter acesso de gestão a uma conta de outra pessoa não é suficiente, porque a fatura é enviada ao proprietário — não vamos permitir que mais ninguém faça cobranças no seu cartão.
:::

## Escolher as suas contas

Se for proprietário de mais do que uma conta, escolhe individualmente quais são medidas. Uma conta que deixar desativada simplesmente para na sua franquia gratuita mensal.

O uso de todas as contas ativadas é consolidado numa **única fatura por mês**, para que receba uma só conta em vez de uma por propriedade.

## Método de pagamento

Adicione um cartão e guardamo-lo de forma segura com o nosso fornecedor de pagamentos. Mostramos apenas a marca, os últimos quatro dígitos e a data de validade — a Wink nunca vê nem armazena o número completo do seu cartão. Se o seu banco emitir um cartão de substituição, os dados atualizam-se automaticamente.

## Uso

Acompanhe o que usou até agora este mês, discriminado por funcionalidade e por conta, juntamente com a franquia gratuita para cada uma. Este é o número a vigiar se quiser manter o seu gasto previsível — para o Social em particular, o seu número mensal de publicações é efetivamente o seu orçamento.

As franquias são repostas no dia 1 de cada mês.

## Faturas

O seu histórico de faturas lista o número de cada mês, o período de faturação, o montante, a moeda e o estado, com ligações para ver a fatura online ou descarregá-la em PDF.

## Estado da faturação

| Estado | O que significa |
| -- | -- |
| Em dia | Tudo está a funcionar normalmente. |
| Em atraso | Uma tentativa de pagamento falhou e está a ser repetida. As suas funcionalidades continuam a funcionar enquanto tentamos novamente. |
| Suspenso | Uma fatura ficou por pagar até ao fim. As funcionalidades medidas ficam bloqueadas até ser liquidada — as funcionalidades gratuitas continuam normalmente. |
