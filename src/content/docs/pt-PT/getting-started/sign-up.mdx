Antes de mais, precisa de criar uma conta de utilizador na Wink.

<Aside type="note" title="Está a reservar uma viagem?">
Este guia é para profissionais que querem trabalhar com o inventário de viagens da Wink — hoteleiros, agentes de viagens, afiliados e outros parceiros que gerem reservas, propriedades e distribuição. Se é um viajante, não precisa de uma conta desde o início: irá criar uma durante o processo de checkout quando fizer uma reserva.
</Aside>

Siga estes passos:

<Steps>
1. Aceda a [app.wink.travel](https://app.wink.travel)
2. Clique em `Sign-In / Register` no canto superior direito
3. Será direcionado para um formulário de login. Clique no link `Register` abaixo dos campos do formulário.
4. Preencha o formulário de registo e clique em `Register`. Será redirecionado para a página de login.
5. Após iniciar sessão, será redirecionado para o nosso [Portal](/pt-PT/portal/create-account) onde pode criar a sua primeira conta.
</Steps>

Criar uma conta de utilizador Wink dá-lhe acesso a todas as funcionalidades da plataforma. Pode criar propriedades e contas de afiliados ilimitadas.
