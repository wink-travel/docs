Esta página lista todos os eventos webhook aos quais pode subscrever na Wink. Para instruções de configuração, consulte o [Guia de Integração Webhook](/pt-PT/developers/webhook-integration) ou a [página de gestão de Webhooks](/pt-PT/portal/settings/webhooks).

## Como subscrever

1. Navegue até **Aplicações > Webhooks** no seu portal.
2. Crie um webhook e selecione os eventos que deseja receber.
3. A Wink envia um HTTP POST para o seu endpoint cada vez que o evento ocorre.

Para passos completos de configuração e melhores práticas, consulte [Integração Webhook](/pt-PT/developers/webhook-integration).
