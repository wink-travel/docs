Esta página lista todos os eventos webhook aos quais pode subscrever na Wink. Para instruções de configuração, consulte o [Guia de Integração Webhook](/pt-PT/developers/webhook-integration) ou a [página de gestão de Webhooks](/pt-PT/portal/settings/webhooks).

## Como subscrever

1. Navegue até **Aplicações > Webhooks** no seu portal.
2. Crie um webhook e selecione os eventos que deseja receber — ou deixe a lista vazia para receber todos os eventos.
3. A Wink envia um HTTP POST assinado para o seu endpoint cada vez que o evento ocorre. Veja [Integração Webhook](/pt-PT/developers/webhook-integration) para o envelope, cabeçalhos, verificação de assinatura e tentativas.

## Todos os tipos de evento

Esta tabela é gerada a partir do catálogo de eventos da plataforma em tempo de construção, por isso está sempre atualizada com a API.
Os tipos de evento marcados como entregues ligam para a sua página de referência na [API Webhooks](/pt-PT/api/webhooks/), que
documenta o corpo JSON exato (`WebhookEnvelope` com um `object` específico do evento), os cabeçalhos `Wink-*` e
a política de tentativas. Tipos de evento que não são entregues existem internamente (pagamentos, livro razão, sincronização do channel-manager, …) mas não são atualmente enviados aos subscritores webhook.

**Destinatários** indica quem recebe um evento: `SUPPLIER` (o hotel), `AFFILIATE` (um revendedor com um canal de vendas ativo para o hotel), `AGENT` (a agência de viagens que fez a reserva) ou `SELF` (a entidade gestora sobre a qual o evento incide). Cada destinatário recebe o mesmo formato de payload; detalhes específicos do papel estão por trás do URL `links.self` do payload.

:::tip
Comece por subscrever todos os eventos durante o desenvolvimento. Assim que perceber quais os payloads que o seu sistema necessita, reduza as subscrições para diminuir o ruído. Envie para si próprio um evento de teste a partir de **Aplicações > Webhooks** (ou `POST …/webhook/{id}/test`) para confirmar o seu endpoint e a verificação da assinatura antes de entrar em produção.
:::
