A Wink descreve o inventário usando vocabulários controlados — conjuntos fixos de códigos com significados acordados. Quando
envia `"5"` como uma comodidade de hotel, a plataforma interpreta como *Ar condicionado*, e todos os consumidores
dessas informações também.

Esta página é a referência publicada para os três vocabulários:

- **Códigos OTA** — {taxonomy.ota.codeCount} códigos em {taxonomy.ota.categoryCount} categorias, abrangendo
  comodidades, tipos de cama, vistas dos quartos, características de acessibilidade, culinária e mais.
- **Línguas** — as {taxonomy.languages.list.length} línguas em que o conteúdo pode ser criado e servido.
- **Moedas** — as {taxonomy.currencies.list.length} moedas em que as tarifas podem ser cotadas e liquidadas.

Os códigos são estáveis. Os nomes podem ser reformulados para maior clareza, por isso faça a correspondência pelo **código**, nunca pelo nome.

## Códigos OTA

A Wink segue as listas de códigos da [OpenTravel Alliance](https://opentravel.org/). Cada categoria tem um
identificador de três letras — `HAC` para comodidades de hotel, `BED` para tipos de cama — e cada código dentro de uma
categoria é único para ela. O mesmo valor numérico significa coisas diferentes em categorias diferentes, por isso um
código só é significativo junto com a categoria a que pertence: `BED` `1` é *Casal / Full*, enquanto `HAC`
`1` é *Receção 24 horas*.

Selecione uma categoria para ver os seus códigos.

## Línguas

O conteúdo — descrições da propriedade, nomes dos quartos, políticas — pode ser criado em qualquer uma destas línguas.
Os códigos são etiquetas [IETF BCP 47](https://www.rfc-editor.org/info/bcp47): uma língua de duas letras
[ISO 639-1](https://www.iso.org/iso-639-language-code), opcionalmente seguida por uma
[ISO 3166-1](https://www.iso.org/iso-3166-country-codes.html) região onde a plataforma distingue
variantes regionais — `pt-BR` e `pt-PT` são tratados separadamente, assim como `es`, `es-AR` e `es-MX`.

O padrão da plataforma é `{taxonomy.languages.default}`, usado quando um pedido não especifica língua e
quando uma tradução não está disponível.

## Moedas

As tarifas podem ser cotadas e liquidadas em qualquer uma destas moedas. Os códigos são
identificadores de três letras [ISO 4217](https://www.iso.org/iso-4217-currency-codes.html).

O padrão da plataforma é `{taxonomy.currencies.default}`. É a moeda de exibição de reserva e a
unidade para a qual os valores a nível de plataforma são normalizados; **não** é a moeda em que uma reserva é liquidada — os hotéis
liquidam na sua própria moeda, por isso uma tarifa cotada numa moeda e paga noutra inclui uma margem de câmbio.

Algumas entradas não são moedas nacionais: `XAU` e `XAG` são ouro e prata, `XDR` é o Direito Especial de Saque do FMI, e `BTC` é Bitcoin. Estas são usadas para avaliação e relatórios, e geralmente não são utilizáveis como moeda de liquidação.
