De MCP-tools van Wink worden gepubliceerd als **toolsets** — gerichte eindpunten, elk gericht op één taak. Je verbindt je AI-client met de één of twee die bij je werk passen, niet met ze allemaal.

Elk eindpunt gebruikt **interactieve OAuth2-login** (PKCE autorisatiecode-flow): je AI-agent opent een browsertab, je logt in met je Wink-account, en dat is het. Geen client secrets om te beheren.

```bash title="Een channel manager-integrator verbindt met één eindpunt"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="Een hotelier die zijn eigen tarieven beheert, verbindt met een ander"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## Waarom de tools zijn verdeeld over eindpunten

Wink biedt ongeveer 500 tools aan. Ze allemaal tegelijk aan een agent geven is technisch mogelijk — maar geen goed idee.

**Tooldefinities kosten context.** Elke tool die een MCP-server adverteert, wordt geladen in het contextvenster van het model voordat het werk begint, samen met de beschrijving en het volledige parameterschema. Vijfhonderd van die tools verbruiken een groot deel van het budget dat je daadwerkelijke taak nodig heeft, bij elke aanvraag.

**De kwaliteit van keuzes neemt af naarmate de lijst groeit.** Een agent die uit 500 vergelijkbaar genaamde tools kiest, maakt slechtere keuzes dan een agent die uit 40 kiest. Als je een channel manager integreert, zijn ongeveer twintig tools relevant voor jou; de andere 480 zijn ruis die het moeilijker maakt om de juiste tool te vinden.

**Het werk is echt te scheiden.** Iemand die beschikbaarheid synchroniseert vanuit een PMS en iemand die affiliate landingspagina’s samenstelt, delen bijna geen tools. Splitsen per taak betekent dat elke verbinding het vocabulaire van één taak draagt.

<Aside type="caution" title="Toolsets zijn geen permissies">
Het kiezen van een smalle toolset beperkt **niet** wat je account kan doen, en het kiezen van een brede toolset geeft ook niets extra’s. Elke tool handhaaft dezelfde accountpermissies als het webportaal, onder jouw ingelogde identiteit. Als je account geen boeking kan annuleren in Wink Portal, kan de agent dat ook niet — ongeacht met welk eindpunt hij verbonden is.

Kies toolsets voor **focus**, niet voor beveiliging.
</Aside>

### `https://integrations.wink.travel` — channel manager-integraties

Eén eindpunt, omdat deze host voor één taak bestaat.

| Eindpunt | Tools | Wat het dekt |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | Verbinden en verifiëren van een channel manager-, PMS- of CRS-integratie |

<Aside type="note" title="Channel manager integreren vs. eigen tarieven beheren">
Dit zijn verschillende taken voor verschillende mensen, en ze delen geen eindpunt.

Een **channel manager-, PMS- of CRS-leverancier** integreert één keer via `integrations.wink.travel/mcp/channel-manager`, en wisselt daarna eigendommen, tarieven, beschikbaarheid en reserveringen uit via die integratie. Dat enkele eindpunt is het hele oppervlak.

Een **hotelier die zijn eigen tarieven handmatig wijzigt** gebruikt de extranet-toolsets op `api.wink.travel` — `/mcp/extranet/rates` en aanverwanten. Die maken geen deel uit van een channel manager-integratie en een integrator heeft geen reden om ermee te verbinden.

Accountbeheer is ook op `api.wink.travel`, bij `/mcp/settings`. Er is geen `/mcp/settings` op de integrations-host.
</Aside>

Elk eindpunt heeft ook een `ping`-tool, zodat je kunt bevestigen dat een verbinding live is voordat je echt werk vraagt.

## Welke toolsets heb ik nodig?

| Als je… | Verbind met |
|---|---|
| **Een channel manager, PMS of CRS integreert** | `integrations.wink.travel/mcp/channel-manager` — alleen deze |
| **De inhoud van een eigendom beheert** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **Kamers en kamertypes beheert** | `/mcp/extranet/facilities` |
| **Prijzen en beschikbaarheid beheert** | `/mcp/extranet/rates` |
| **Dagelijkse reserveringen runt** | `/mcp/extranet/operations` |
| **Distributie uitbreidt** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **Affiliate-pagina’s bouwt** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **Link-in-bio-pagina’s runt** | `/mcp/link-manager` + `/mcp/social` |
| **Boekingen namens reizigers doet** | `/mcp/travel-agent` |
| **Geld afstemt** | `/mcp/payment` |
| **Een boekingservaring bouwt** | `/mcp/booking-engine` + `/mcp/reference` |

Begin met één. Voeg er een toe als je merkt dat je iets vraagt wat het niet kan — elke verbinding is onafhankelijk, en toevoegen beïnvloedt de anderen nooit.

<Aside type="tip" title="Wil je toch alles?">
`https://api.wink.travel/mcp` en `https://integrations.wink.travel/mcp` blijven beschikbaar en serveren **elke** tool op hun host. Ze zijn handig om te verkennen wat er bestaat, maar we raden ze niet aan voor dagelijks werk: de lijst met tools is groot genoeg om je taak te verdringen en de toolselectie van de agent te verslechteren. Geef de voorkeur aan de bovenstaande toolsets.
</Aside>

## Hoe authenticatie werkt

Wink MCP-servers gebruiken de **OAuth2 Authorization Code + PKCE** flow en ondersteunen **Dynamic Client Registration (RFC 7591)**. Dit gebeurt als je voor het eerst verbinding maakt:

1. Je AI-client ontdekt de autorisatieserver via de `/.well-known/oauth-protected-resource` metadata van het MCP-eindpunt.
2. De client registreert zichzelf via **Dynamic Client Registration** — geen handmatige applicatie-instelling nodig.
3. De client opent een **browsertab** naar `https://iam.wink.travel`. Je logt in met je Wink-account en keurt de gevraagde permissies goed op het toestemmingsscherm.
4. Wink geeft een **toegangstoken** uit dat is gescopeerd op je account en gekoppeld aan je identiteit.
5. De AI-client voegt het token toe aan elke MCP-aanvraag. Alle toolresultaten zijn automatisch gescopeerd op jouw beheersentiteit.
6. Tokens verlopen na 3 uur. Je AI-client vernieuwt ze stilletjes op de achtergrond zonder opnieuw te vragen.

Elke toolaanroep draait **onder jouw identiteit** — dezelfde ACL-regels die het webportaal beschermen, gelden voor de AI-agent.

## Scopes

Wanneer je het toestemmingsscherm goedkeurt, zie je een overzicht van wat de agent aanvraagt. MCP-clients gebruiken hetzelfde permissievocabulaire als de rest van het platform — zie de volledige
[scope-referentie op de Authenticatiepagina](/nl/developers/authentication#scopes).

Twee dingen zijn specifiek voor MCP:

- **De `mcp.read` `mcp.write` `mcp.remove` scopes zijn daarnaast vereist** om de MCP-transport te openen. Een client met een `mcp.*` scope krijgt toegang tot elk Wink MCP-eindpunt, maar elke tool die het aanroept handhaaft nog steeds de sectiescope van het eindpunt dat het omsluit (bijv. `booking.read`).
- **De AI-client vraagt alleen de scopes aan die het nodig heeft.** Je kunt individuele permissies weigeren op het toestemmingsscherm — tools die een geweigerde scope vereisen, geven een foutmelding bij aanroep.

**Toolsets veranderen hier niets aan.** Het eindpunt waar je verbinding mee maakt bepaalt welke tools *vermeld* worden, niet wat ze *mogen doen*. Verbinden met `/mcp/payment` geeft geen financiële permissie die je nog niet had, en verbinden met `/mcp/reference` voorkomt niet dat een tool daar zijn eigen scope afdwingt. Autorisatie wordt per toolaanroep beslist, op basis van je token en de machtigingen van je account.

## Problemen oplossen

**Browsertab opent niet**

Je AI-client ondersteunt mogelijk de interactieve PKCE-flow nog niet. Controleer of je een recente versie gebruikt:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** update via de ingebouwde updater van de app

**`401 Unauthorized` na inloggen**

Je gecachte token is mogelijk verlopen. Verwijder en voeg de server opnieuw toe om een verse login te forceren:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

Voor Claude Desktop en ChatGPT, verwijder de serververmelding uit de instellingen, herstart de app en voeg hem opnieuw toe.

**`403 Forbidden` bij aanroepen van een specifieke tool**

De tool vereist een scope die je niet hebt goedgekeurd op het toestemmingsscherm, of een permissie die je account niet heeft. Verbind de server opnieuw — het toestemmingsscherm verschijnt weer en je kunt de ontbrekende permissie goedkeuren. Als het nog steeds mislukt, heeft de tool een accountpermissie nodig die je niet hebt; verbinden met een andere toolset helpt niet, want toolsets verlenen geen permissies.

**De tool die ik nodig heb staat niet in de lijst**

Je bent waarschijnlijk verbonden met een toolset die die taak niet dekt. Controleer de [endpointdirectory](#endpoint-directory) en voeg de toolset toe die dat wel doet — verbindingen zijn onafhankelijk, dus toevoegen verandert niets aan de anderen. Als je niet zeker weet welke het is, verbind tijdelijk met `https://api.wink.travel/mcp`, vind de tool, en zoek dan op welke toolset die vermeldt.

**`404 Not Found` op een toolset-eindpunt**

Controleer het pad goed — de geneste toolsets hebben twee segmenten (`/mcp/extranet/rates`, niet `/mcp/extranet-rates`), en de platte hebben er één (`/mcp/link-manager`). Let op dat een *niet-geauthenticeerde* aanvraag naar een pad onder `/mcp` een `401` teruggeeft, niet `404`, dus alleen een `401` zegt niet of het eindpunt bestaat.

**Ik verbond met `api.wink.travel/mcp/channel-manager` en kreeg niets**

Dat eindpunt bestaat niet. Channel manager-integratie wordt alleen bediend vanaf `https://integrations.wink.travel/mcp/channel-manager`. Als je ook handmatig de eigen tarieven van een eigendom moet lezen of schrijven, is dat een aparte taak op een apart eindpunt — zie `/mcp/extranet/rates`.

**De server verschijnt maar toolaanroepen geven "account niet gevonden"**

Je bent ingelogd met een Wink-account zonder beheersentiteit. Ga naar [Wink Portal](https://app.wink.travel) en zorg dat je account is ingesteld voordat je de MCP-server gebruikt.

**Token verloopt midden in een sessie**

Tokens zijn 3 uur geldig. Claude Code en Claude Desktop vernieuwen tokens stilletjes zonder je sessie te onderbreken. Als je na een lange inactiviteit authenticatiefouten ziet, typ dan een nieuw bericht — de client herauthenticeert automatisch.

**Codex CLI toont "MCP server unreachable"**

Controleer of je `~/.codex/config.json` geldige JSON is (geen trailing commas) en dat `"type": "http"` is ingesteld. Codex vereist HTTP-transport voor externe servers; stdio-transport is alleen voor lokale binaries.

**ChatGPT "Connectors"-menu ontbreekt**

MCP-ondersteuning vereist ChatGPT desktop-app versie **1.2024.352** of later en een actief Plus-, Pro-, Team- of Enterprise-abonnement. Update de app en controleer je abonnement in Instellingen → Account.

**Cursor-server toont rood / "Failed to connect"**

Controleer of je `~/.cursor/mcp.json` geldige JSON is en `"type": "http"` bevat. Ga dan naar **Instellingen → Cursor-instellingen → MCP** en klik op **Vernieuwen**. Als de fout blijft, start Cursor volledig opnieuw op — configuratiewijzigingen worden niet altijd opgepikt zonder herstart.

**Windsurf MCP-servers niet zichtbaar in instellingen**

Windsurf vereist een volledige herstart (niet alleen venster herladen) om wijzigingen in `mcp_config.json` op te pikken. Gebruik **Bestand → Afsluiten** en start opnieuw. Als servers nog steeds niet verschijnen, controleer of je Windsurf **1.4+** gebruikt via **Help → Over Windsurf**.

**Cline "Server toevoegen"-optie niet zichtbaar**

De MCP-servermanager vereist Cline **2.0** of later. Open het VS Code Extensies-paneel, zoek Cline en klik op **Bijwerken** als er een update is. Na bijwerken, herlaad VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
