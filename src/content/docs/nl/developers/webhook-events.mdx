Deze pagina toont elk webhook event waarop je je kunt abonneren op Wink. Voor installatie-instructies, zie de [Webhook Integratie Gids](/nl/developers/webhook-integration) of de [Webhook beheerpagina](/nl/portal/settings/webhooks).

## Hoe te abonneren

1. Navigeer naar **Applicaties > Webhooks** in je portal.
2. Maak een webhook aan en selecteer de events die je wilt ontvangen.
3. Wink stuurt een HTTP POST naar je endpoint telkens wanneer het event plaatsvindt.

Voor volledige installatie-stappen en best practices, zie [Webhook Integratie](/nl/developers/webhook-integration).
