Een Wink-gebruiker kan ervoor kiezen om jou een van hun accommodatie-, partner- of reisagentaccounts te laten beheren. Wanneer dat gebeurt, ontvang je een e-mail met een uitnodigingsverzoek.

import { Steps } from '@astrojs/starlight/components';

Om je huidige Wink-uitnodigingen te bekijken, volg je deze stappen:

<Steps>
 1. Log in op [app.wink.travel](https://app.wink.travel).
 2. Klik op `Uitnodigingen` in de linkerzijbalk.
 3. Je ziet een lijst met alle huidige uitnodigingen.
 4. Deze sectie toont al je aanvragen.
 5. Kies om de uitnodiging te `Accepteren` of `Weigeren`.
 6. Als je de uitnodiging hebt geaccepteerd, verschijnt het account in de sectie `Accounts`.
</Steps>
