Je inhoud is beschikbaar onder het tabblad `Entries`.

We ondersteunen drie hoofdtypen inhoud:

- Openbaar beschikbare URL's die linken naar webpagina's.
- Bestanden die via WinkLinks zijn geüpload.
- Tekstinhoud gemaakt via onze `Quotes`-functie.

## Inhoud toevoegen

Zo voeg je inhoud toe aan WinkLinks. Ga onder het tabblad `Entries` eerst naar de knop `Add entry`.

### Normale link

:::tip
De link moet naar een webpagina leiden. Je kunt bijvoorbeeld niet direct linken naar een PDF. Als je een PDF wilt delen, moet je de functie `Upload file` gebruiken.
:::

Hier zijn de stappen om een normale link toe te voegen:

<Steps>
1. Voer de link in die je wilt delen. *bijv. https://trvl.as/3xWCH*
2. Zodra je de link invoert, zoekt Wink de details van deze website op en vult het formulier dat je daarna ziet in.
3. Je kunt ervoor kiezen om sommige gegevens aan te passen, zoals de sitenaam, titel en beschrijving.
4. Je kunt ook een aangepaste afbeelding uploaden.
5. Klik op de knop `Save` wanneer je klaar bent om door te gaan.
</Steps>

### Bestand uploaden

:::caution[Vereisten]
- Afbeeldingen mogen niet groter zijn dan 10Mb.
- Video's mogen niet groter zijn dan 50Mb.
- We ondersteunen alle erkende beeld- en videoformaten, inclusief PDF.
:::

:::note[Aanbevelingen]
- 2560w x 1440h (16x9 beeldverhouding) voor je uitgelichte afbeelding.
- 2560w x 1920h (4:3 beeldverhouding) voor alle andere afbeeldingen.
- De afbeeldingsgrootte mag niet groter zijn dan 5Mb. Comprimeer je afbeeldingen voordat je ze uploadt naar Wink.
:::

Hier zijn de stappen om een bestand toe te voegen:

<Steps>
1. Media kan worden toegevoegd:
    - Door afbeeldingen van je computer naar het venster te slepen of klik op `Browse`.
    - Door een externe URL te plakken die naar een afbeelding verwijst.
    - Door je laptopcamera te gebruiken.
    - Vanuit je Google Drive-account.
    - Vanuit je Dropbox-account.
    - Vanuit Shutterstock
    - Vanuit gettyimages
    - Vanuit iStock
    - Vanuit Unsplash
2. Zodra het bestand is geüpload, kun je meer metadata toevoegen om je bestand te beschrijven, zoals titel en beschrijving.
3. Klik op de knop `Save` wanneer je klaar bent om door te gaan.
</Steps>

### Een quote schrijven

:::tip
Een quote is een geweldige manier om een scheiding aan te brengen in een lange lijst [...en het laat je ook slim en deskundig klinken 😉].
:::

Hier zijn de stappen om een quote te schrijven:

<Steps>
1. Typ de quote *bijv. Rozen zijn rood. Viooltjes zijn blauw...*.
2. Voer de naam in van de oorspronkelijke auteur. *bijv. Edmund Spenser*
3. Voer de naam in van de site waar je de quote vandaan hebt. *bijv. Daily Quotes*
4. Klik op de knop `Save` wanneer je klaar bent om door te gaan.
</Steps>

## Inhoud bijwerken

Alle inhoud kan eenvoudig worden aangepast door te klikken op de link `Actions` en `Update` te selecteren. Je kunt inhoud op een vergelijkbare manier verwijderen door op de knop `Remove` te klikken.

## Inhoud verwijderen

Alle inhoud kan eenvoudig worden aangepast door `Update` te selecteren. Je kunt inhoud op een vergelijkbare manier verwijderen door eerst op de link `Actions` te klikken en vervolgens op de knop `Remove`.

## Inhoud sorteren

Je kunt je inhoud ordenen door te klikken op het pictogram linksonder in elke entry en deze naar de gewenste positie te slepen.

## Inhoud groeperen

:::tip
Maak je tags aan voordat je je entries maakt. Anders verlies je je voortgang en moet je opnieuw beginnen.
:::

Wanneer je een entry bewerkt, heb je de optie om een of meer tags toe te voegen voor groeperingsdoeleinden. Scroll naar beneden in het formulier om het veld `Tags` te vinden.

Gebruikers die je WinkLinks-pagina bekijken, kunnen kiezen hoe ze je inhoud willen bekijken (lijst of raster) en kunnen een of meer tags selecteren om je inhoud verder te filteren.

## API

Ontwikkelaars die `WinkLinks` willen beheren, kunnen terecht bij [Developers > API > WinkLinks](/nl/api).
