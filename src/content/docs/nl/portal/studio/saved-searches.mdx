Opgeslagen zoekopdrachten doen wat de naam al zegt. Tijdens het zoeken naar reisinventaris heb je de optie om je zoekopdracht op te slaan voor later gebruik.

## Je zoekopdracht opslaan

Wanneer je begint met zoeken naar inventaris (zie [Search](/nl/portal/studio/search) ), kun je je zoekfilters verfijnen.
Onderaan het zoekformulier staat de optie `Save search`.

Door op deze link te klikken krijg je de mogelijkheid om deze zoekopdracht een naam te geven (*bijv. Mijn Bibliotheek van Magische Hotels*), iets wat je later zult onthouden.

<figure>
<CloudinaryImage

    <figcaption>*Geef je zoekopdracht een naam*</figcaption>
</figure>

Geef het een naam en klik op de knop `Save search`. Daarna kun je via `Lists > Dynamic` in de hoofd navigatiebalk je nieuw aangemaakte record bekijken.

## Lijstacties

Je opgeslagen zoekopdracht kan worden gebruikt om reisinventaris aan je gebruikers te tonen in de vorm van een raster of een kaart en je zoekresultaten op de gewenste manier weer te geven.

<figure>
<CloudinaryImage
      width="700"
      height="939"
      resize="scale"
      quality="best"
      alt="Saved search actions"
      src="academy/saved-search-actions"

    />
    <figcaption>*Opgeslagen zoekopdracht zonder toegepaste filters*</figcaption>
</figure>

Elke opgeslagen zoekopdracht heeft acties die je erop kunt uitvoeren:

- Zet de zoekopdracht om in een [kaart](/nl/portal/studio/maps).
- Zet de zoekopdracht om in een [raster](/nl/portal/studio/grids).
- Verwijder de opgeslagen zoekopdracht.

## API

Ontwikkelaars die opgeslagen zoekopdrachten willen beheren kunnen terecht bij [Developers > API > Browse](/nl/api).
