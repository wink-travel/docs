Cada funcionalitat de la plataforma es pot cridar externament. Aquesta secció cobreix l'autenticació, la superfície de l'API, la entrega d'esdeveniments i les dades de referència que hi ha darrere.

## Comença aquí

- [Construeix sobre Wink](/ca/developers/build-on-wink/) — què pots construir i quina API s'adapta.
- [Configuració](/ca/developers/setup/) — crea una aplicació i obté credencials.
- [Autenticació](/ca/developers/authentication/) — sessions OAuth2 i àmbits.

## La superfície de l'API

- [REST i gRPC](/ca/developers/rest-and-grpc/) — els dos transports i quan utilitzar cada un.
- [Geolocalització](/ca/developers/geolocation/) — cerca espacial sobre inventari reservable.
- [Taxonomia](/ca/developers/taxonomy/) — codis OTA, idiomes i monedes compatibles.

- [Integració Webhook](/ca/developers/webhook-integration/) — subscriu-te als esdeveniments de la plataforma.
- [Catàleg d'Esdeveniments Webhook](/ca/developers/webhook-events/) — cada esdeveniment que emet la plataforma.
- [Sincronització de Reserves](/ca/developers/booking-sync/) — mantén les reserves alineades amb un PMS o gestor de canals.
