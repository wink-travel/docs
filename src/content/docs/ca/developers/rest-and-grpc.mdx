Wink exposa dos transports. Quin utilitzeu depèn de quina API esteu integrant.

| | Transport | Esquema | Docs |
| --- | --- | --- | --- |
| La majoria d’APIs de Wink | REST sobre HTTPS | OpenAPI 3 | Qualsevol grup sota **API** a la barra lateral |
| Partner Integrator API | gRPC sobre HTTP/2 | Protocol Buffers | [Partner](/ca/partner-api/partner/) |

<Aside type="note" title="Ja no publiquem SDKs per a llenguatges">
  Els SDKs mantinguts manualment anaven per darrere de les APIs que encapsulaven, i mai cobrien el llenguatge que realment necessitaveu. Genereu un client a partir de l’esquema en comptes d’això — sempre està actualitzat — o deixeu que el nostre servidor MCP escrigui codi d’integració adaptat al vostre cas d’ús.
</Aside>

## Generar un client REST

Cada grup d’API publica un document OpenAPI 3. Apunteu qualsevol generador OpenAPI a aquest document i obtindreu un client tipat en el vostre llenguatge.

```bash
# L’especificació de cada grup es pot descarregar en aquest lloc: /api/downloads/<group>.json
curl -o wink-extranet.json https://wink.travel/api/downloads/extranet.json

npx @openapitools/openapi-generator-cli generate \
  -i wink-extranet.json -g typescript-fetch -o ./wink-client
```

## Generar un client gRPC

La Partner Integrator API és gRPC. Genereu un client a partir de l’esquema `.proto`, que Wink publica de dues maneres:

- **Server reflection** — el servidor es descriu a si mateix, de manera que eines com `grpcurl`, Postman i Insomnia poden descobrir l’esquema en temps d’execució sense fitxers per descarregar. La reflexió requereix el mateix token bearer que qualsevol altra crida.
- **Els fitxers `.proto`**, si preferiu incorporar l’esquema i generar-lo prèviament.

```bash
# Descobrir l’esquema des d’un servidor en execució (autenticat).
grpcurl -H "authorization: Bearer $WINK_TOKEN" \
  partner.wink.travel:443 list

# Després genereu un client — aquí Go; cada llenguatge compatible funciona igual.
protoc --go_out=. --go-grpc_out=. partner_lookup.proto
```

Les crides porten el vostre token bearer a la capçalera de metadades `authorization`, exactament com REST el porta a la capçalera `Authorization`. Els errors arriben com un codi d’estat gRPC als tràilers de la resposta en lloc d’un codi d’estat HTTP — la [referència Partner](/ca/partner-api/partner/) enumera els estats que hauríeu d’esperar.

## O deixeu que el servidor MCP ho escrigui

Si utilitzeu un assistent de codificació AI, el nostre servidor MCP és la ruta més ràpida. Exposa les APIs de Wink com a eines que el vostre assistent pot cridar i raonar, així que en comptes de generar un client complet i trobar els punts finals vosaltres mateixos, descriviu què esteu construint i obtindreu codi d’integració adaptat a això.
