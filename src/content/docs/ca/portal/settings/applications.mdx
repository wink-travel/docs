Les aplicacions et donen accés a totes les funcionalitats de Wink com a desenvolupador. Pots accedir a totes les mateixes dades i fins i tot ampliar les funcionalitats pròpies de Wink.
Pots triar utilitzar el servidor OAuth2 de Wink per autenticar el teu lloc de viatges de la mateixa manera que faries servir Google o Facebook.
D’aquesta manera, pots ampliar les funcionalitats de Wink al teu propi lloc web o aplicació.

:::note
La teva primera aplicació ja està creada quan [crees un compte nou](/ca/portal/create-account). Fem servir aquesta aplicació per a alguns escenaris de reserva.

No pots reutilitzar aquesta aplicació. Si us plau, crea noves aplicacions segons les necessitis.
:::

## Crea una aplicació

Com que no pots accedir a la `clau secreta` de l’aplicació que vam crear per a tu, hauràs de crear la teva pròpia.

:::caution
Has de crear un compte d’afiliat a Wink o un compte a TripPay abans de crear una aplicació, ja que vincularàs la teva aplicació a un compte específic.
:::

### Tipus de client

Quan crees una aplicació, tries un tipus de client que determina com s’autentica l’aplicació:

- **SPA** (Single Page Application) — Per a aplicacions frontend basades en navegador que utilitzen el flux d’autorització OAuth2 amb codi i PKCE. Aquest és el tipus més comú per a aplicacions web.
- **MACHINE_2_MACHINE** — Per a integracions servidor a servidor que s’autentiquen directament amb credencials de client. Utilitza-ho quan el teu servei backend necessiti cridar les API de Wink sense que hi hagi un usuari present.

Aquí tens els passos per crear una aplicació:

<Steps>
1. A la pàgina d’aplicacions, fes clic al botó `Crea una aplicació nova`.
2. ***Nom*** Dona un nom a la teva aplicació. *ex. Aplicació Cool*
3. **Tipus de client** Tria `SPA` per a aplicacions web o `MACHINE_2_MACHINE` per a integracions servidor.
4. **Nom de l’entitat** Enllaça la teva aplicació amb un dels teus comptes existents. *ex. Compte Cool*
5. **URIs de redirecció** Es requereix almenys una URI de redirecció. S’utilitza per validar el domini de redirecció després d’una autenticació exitosa. *ex. https://www.cool-site.com*
6. **URIs de redirecció post-tancament de sessió** *(Opcional)* URLs on es pot redirigir els usuaris després de tancar la sessió. Això assegura que els usuaris aterrin en una pàgina coneguda després que la seva sessió acabi.
7. Fes clic al botó `Desa` per continuar.
</Steps>

Seràs redirigit de nou a la teva llista d’aplicacions. Veureu la teva nova aplicació a la llista i tindràs accés a la clau secreta de l’aplicació només aquesta vegada. Assegura’t de copiar-la i guardar-la en un lloc segur.

## Actualitza una aplicació

Hauràs d’actualitzar la teva aplicació si canvia alguna de les teves URIs de redirecció o vols afegir o eliminar una URI.

Per actualitzar una aplicació existent, fes el següent:

<Steps>
1. Fes clic a l’enllaç `Accions` de l’aplicació que vols actualitzar.
2. Fes clic al botó `Actualitza` sota Accions.
3. Fes els canvis a l’aplicació.
4. Fes clic al botó `Desa` per continuar.
</Steps>

Seràs redirigit de nou a la teva llista d’aplicacions.

## Elimina una aplicació

:::caution
Si us plau, no eliminis l’aplicació que vam crear automàticament per a tu per assegurar que totes les funcionalitats funcionin per al teu compte.
:::

Si no necessites més una aplicació, pots eliminar-la.

Per eliminar una aplicació, fes el següent:

<Steps>
1. Fes clic a l’enllaç `Accions` de l’aplicació que vols actualitzar.
2. Fes clic al botó `Elimina` sota Accions.
3. Fes clic al botó `D’acord` per confirmar l’eliminació.
</Steps>

Seràs redirigit de nou a la teva llista d’aplicacions.
