Els agents de viatge registrats utilitzen el mateix portal que tothom, a [app.wink.travel](https://app.wink.travel), amb un compte d'Agent de Viatge. Els agents cerquen i reserven en nom dels seus clients i guanyen una comissió per cada reserva. Per configurar-ne un, segueix [Com començar com a agència de viatges](/ca/guides/travel-agents/getting-started/).

Les agències aprovades per cobrar el pagament elles mateixes actuen com a comerciant registrat i gestionen el pagament fora de la plataforma Wink. Les agències amb els seus propis sistemes poden integrar-se a través de la [Partner API](/ca/integrations/partner-api/).

Els agents de viatge disposen d’un subconjunt de les mateixes funcions del portal que [Studio](/ca/portal/studio/what-is-studio), així que no les tornarem a cobrir aquí.

## API

Les agències poden cercar i reservar a través de la [Partner API](/ca/partner-api/partner/), que substitueix els antics endpoints REST per a agents de viatge.
