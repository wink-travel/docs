Booking Engine s'integra a qualsevol lloc. Tria el teu framework o CMS i segueix la seva guia; els Web Components subjacents són els mateixos a tot arreu.

## Enfocaments principals

- [Web Components](/ca/integrations/web-components/) — els elements integrables que utilitza cada integració.
- [npm package](/ca/integrations/npm/) — instal·la-ho en una compilació JavaScript.
- [Headless CMS](/ca/integrations/headless/) — renderitza des de qualsevol backend de contingut.
- [Partner API](/ca/integrations/partner-api/) — integració programàtica completa.
