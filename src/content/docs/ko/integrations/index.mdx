Booking Engine은 어디에나 임베드할 수 있습니다. 원하는 프레임워크나 CMS를 선택하고 가이드를 따르세요; 기본 Web Components는 어디서나 동일합니다.

## 핵심 접근법

- [Web Components](/ko/integrations/web-components/) — 모든 통합에서 사용하는 임베드 가능한 요소입니다.
- [npm package](/ko/integrations/npm/) — JavaScript 빌드에 설치합니다.
- [Headless CMS](/ko/integrations/headless/) — 모든 콘텐츠 백엔드에서 렌더링합니다.
- [Partner API](/ko/integrations/partner-api/) — 완전한 프로그래밍 통합입니다.
