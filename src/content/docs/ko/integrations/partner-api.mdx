Wink **파트너 API**는 통합자가 예약 가능한 여행 인벤토리를 조회할 수 있는 인증된 고처리량 방식입니다 — 임베디드 위젯과 공개 탐색 엔드포인트에 동력을 공급하는 동일한 공급을 1급 프로그래밍 인터페이스로 노출합니다. 무료 웹 컴포넌트와 공개 탐색 엔드포인트가 경량의 사용자 대상 임베딩용인 반면, 파트너 API는 대규모로 검색, 가격 책정 및 예약하는 시스템을 위해 구축되었습니다. 접근은 통합자별로 인증되며 사용량에 따라 청구되므로 실제로 전송하는 트래픽에 대해서만 비용을 지불합니다.

## 요금제 및 가격

API 호출 1회 = 요청 1회. 사용량은 1,000 요청 단위로 청구됩니다.

| | 무료 | 유료 | 엔터프라이즈 |
|---|---|---|---|
| **가격** | $0 | 사용량 기반 | 문의하기 |
| **적합 대상** | 평가 및 저용량 통합 | 대규모 사용량 기반 지불 | 맞춤형 용량 및 협상 조건 |
| 분당 요청 수 | 30 (60 버스트) | 무제한 | 무제한 |
| 월별 요청 수 | 10,000 | 무제한 | 무제한 |
| API 응답 시간 (P95) | — | 500ms 미만 | 500ms 미만 |
| 1,000 요청당 가격 | 무료 | $1.00 | 맞춤형 |
| 예약 대비 조회 초과 요금 (5,000:1 초과 조회 1,000건당) | — | $2.00 | 맞춤형 |
| 요율 제한 응답 | 429 (일시 중지 / 월별 강제 중단) | 없음 | 없음 |

## 사용량 및 제한 작동 방식

### 무료 요금제

무료 요금제는 비용 없이 적당한 프로덕션 트래픽을 구축, 테스트 및 운영할 수 있도록 설계되었습니다.

- **요율 제한 — 분당 30 요청, 60 요청 버스트 허용.** 지속적인 속도를 초과하는 짧은 급증은 버스트 허용량으로 흡수됩니다. 이를 초과하면 API가 **HTTP 429 (요청 과다)** 응답을 반환하고 키가 트래픽을 다시 제공하기 전까지 **5분간 일시 중지**됩니다. 일시 중지 후 재시도하며 엔드포인트를 과도하게 호출하지 마십시오.
- **월별 할당량 — 달력 월당 10,000 요청.** 월별 한도에 도달하면 API가 해당 월 나머지 기간 동안 **HTTP 429**를 반환하며, 계속 사용하려면 유료 요금제로 구독하라는 메시지를 표시합니다. 카운터는 다음 달 초에 초기화됩니다.

무료 요금제에는 서비스 수준 계약이나 우선 지원이 포함되어 있지 않습니다.

### 유료 요금제

유료 요금제는 월별 한도와 요율 제한 일시 중지를 제거하고 실제 사용량에 대해서만 청구합니다.

- **사용량 기반 요청 — 1,000 요청당 $1.00.** 월별 요청 한도나 정상 사용 시 요율 제한이 없으며, 실제 사용량에 따라 청구됩니다.
- **예약 대비 조회 초과 요금 — 1,000 초과 조회당 $2.00.** 공급을 건강하게 유지하기 위해 검색("조회") 대비 확정 예약 비율을 측정합니다. 예약 1건당 **5,000 조회**가 허용되며 초과 조회는 다음과 같이 계산됩니다:

  `초과 = max(0, 조회 − 예약 × 5,000)`

  초과 조회에 대해 **1,000건당 $2.00**가 청구됩니다. 전환율이 좋은 통합은 거의 초과 요금을 발생시키지 않으며, 이 요금은 예약 대비 검색이 훨씬 많은 트래픽에만 적용됩니다.

유료 요금제에는 아래 설명된 서비스 수준 계약 — 99.9% 가동 시간 보장 및 500ms 미만 P95 응답 시간 목표 — 및 우선 순위, 심각도 기반 지원이 포함됩니다.

## 서비스 수준 계약

_발효일: 2026년 7월 5일 · 버전 1.0_

본 서비스 수준 계약("SLA")은 Wink("Wink", "당사")가 고객("고객", "귀하")에게 인증된 Wink 파트너 API("파트너 API" 또는 "서비스")에 대해 제공하는 가용성 약속, 서비스 크레딧 및 지원 목표를 규정합니다. 본 SLA는 귀하와 Wink 간 파트너 API 접근에 관한 계약("계약")에 통합되어 계약에 따라 적용되며, 귀하가 유효한 유료 파트너 API 구독을 유지하는 한 적용됩니다. 본 문서에서 정의되지 않은 대문자 용어는 계약에서 정의된 의미를 갖습니다.

### 1. 정의

1. **"가동 시간"**은 파트너 API가 적절히 형식화되고 인증된 요청을 수락하고 성공적으로 응답할 수 있는 기간을 의미합니다.
2. **"다운타임"**은 파트너 API가 적절히 형식화되고 인증된 요청에 성공적으로 응답하지 못하는 분 단위 기간을 의미하며, 4절에 명시된 제외 기간은 포함하지 않습니다. 미미한 요청 일부에만 영향을 미치는 단발성 오류는 다운타임으로 간주하지 않습니다.
3. **"월별 가동 시간 비율"**은 해당 달의 총 분 수에서 다운타임 분 수를 뺀 값을 해당 달 총 분 수로 나눈 백분율입니다.
4. **"예정된 유지보수"**는 Wink가 4절에 따라 사전 통지를 제공한 서비스의 계획된 유지보수를 의미합니다.
5. **"서비스 크레딧"**은 가동 시간 약속 미달 시 해당 달에 귀하가 지불했거나 지불할 파트너 API 요금의 일정 비율로 계산되어 향후 파트너 API 요금에 적용되는 크레딧으로, 유일하고 배타적인 구제 수단입니다.
6. **"응답 시간"**은 Wink가 적절히 형식화되고 인증된 요청을 서비스 경계에서 수신한 시점부터 응답 반환을 시작하는 시점까지 경과한 시간으로, 네트워크 전송 및 Wink가 통제하지 않는 클라이언트 측 시간을 제외합니다.

### 2. 가용성 및 성능 약속

Wink는 계약 기간 동안 매 달 파트너 API의 **월별 가동 시간 비율을 최소 99.9% 이상**으로 유지하기 위해 상업적으로 합리적인 노력을 기울입니다("가동 시간 약속"). 가동 시간 약속은 Wink 서비스 경계에서 측정하며, 4절에 명시된 Wink의 합리적 통제를 벗어난 요인은 제외됩니다. Wink의 모니터링 시스템이 월별 가동 시간 비율 및 응답 시간 측정의 권위 있는 기록 소스입니다.

또한 Wink는 매 달 서비스 경계에서 성공적이고 적절히 형식화된 인증 요청에 대해 **95번째 백분위수(P95) 응답 시간을 500밀리초 미만**으로 유지하는 것을 목표로 합니다("성능 목표"). 성능 목표는 4절에 명시된 요인, 요청 자체로 인한 애플리케이션 수준 오류, 비정상적으로 크거나 복잡한 배치 요청을 제외합니다. 성능 목표는 서비스 목표이며, 3절의 서비스 크레딧은 **가동 시간 약속** 미달에 대한 유일하고 배타적인 구제 수단입니다.

### 3. 서비스 크레딧

월별 가동 시간 비율이 가동 시간 약속 미만일 경우, 해당 월에 귀하가 지불했거나 지불할 파트너 API 요금의 일정 비율로 서비스 크레딧을 받을 수 있습니다. 비율은 다음과 같습니다:

| 월별 가동 시간 비율 | 서비스 크레딧 |
|---|---|
| 99.9% 미만, 99.0% 이상 | 10% |
| 99.0% 미만, 95.0% 이상 | 25% |
| 95.0% 미만 | 50% |

1. **크레딧 청구.** 서비스 크레딧을 받으려면 다운타임이 발생한 달 종료 후 **30일 이내**에 Wink에 서면 청구서를 제출해야 합니다. 청구서에는 각 다운타임 사건의 날짜 및 시간과 합리적으로 제공 가능한 로그 또는 증거가 포함되어야 합니다. 이 기간 이후 제출된 청구는 인정되지 않습니다.
2. **크레딧 형태.** 승인된 서비스 크레딧은 향후 파트너 API 요금에 적용되며 현금 가치는 없습니다. 환불이 아니며 관련 법률에 따라 요구되는 경우를 제외하고 지급되지 않습니다.
3. **최대 크레딧.** 단일 달에 지급되는 서비스 크레딧 총액은 해당 달에 귀하가 지불했거나 지불할 파트너 API 요금의 50%를 초과하지 않습니다.
4. **유일하고 배타적인 구제 수단.** 서비스 크레딧은 Wink가 가동 시간 약속을 준수하지 못하거나 파트너 API의 가용성 부족에 대해 귀하가 받을 수 있는 **유일하고 배타적인 구제 수단**입니다.

### 4. 제외 사항

가동 시간 약속 및 서비스 크레딧은 다음과 같은 경우 적용되지 않으며, 다운타임에 포함되지 않습니다:

1. Wink가 사전에 합리적인 기간 동안 고객과 소통하는 채널을 통해 통지한 **예정된 유지보수**;
2. 천재지변, 정부 행위, 네트워크 또는 유틸리티 장애, 서비스 거부 공격 등 Wink의 합리적 통제를 벗어난 **불가항력** 사건;
3. 귀하의 행위 또는 부작위, 귀하의 장비, 소프트웨어, 네트워크, 또는 Wink가 직접 통제하지 않는 제3자 서비스, 제품, 공급자에 의해 발생한 문제;
4. 귀하의 **서비스 남용** 또는 **계약, 본 SLA, 허용 사용 조건, 적용 요율 제한 위반**, 과도한 트래픽, 자동화된 남용, 사기성 트래픽 등 Wink가 합리적으로 판단하는 경우;
5. 계약에 따라 적법하게 이루어진 귀하의 접근 **일시 중지 또는 종료**, 미납에 따른 중지 포함.

### 5. 지원 및 응답 목표

Wink는 현지 공휴일을 제외한 표준 영업 시간 동안 파트너 API 지원을 제공합니다. Wink는 귀하가 지정하고 Wink가 합리적으로 확인한 심각도에 따라 적절히 제출된 지원 요청에 대해 다음 목표 응답 시간 내에 초기 응답을 제공하기 위해 상업적으로 합리적인 노력을 기울입니다:

| 심각도 | 설명 | 목표 초기 응답 |
|---|---|---|
| **심각도 1 — 치명적** | 파트너 API가 프로덕션에서 다운되었거나 우회 방법 없이 사용 불가. | 4시간 |
| **심각도 2 — 주요** | 주요 기능이 손상되었으나 우회 방법 존재. | 1영업일 |
| **심각도 3 — 경미** | 일반 질문, 경미한 문제, 기능 요청. | 2영업일 |

목표 응답 시간은 Wink가 **초기 연락**을 시도하는 시점을 의미하며 해결 시간을 보장하지 않습니다. 우선 지원 및 심각도 기반 목표는 포함된 요금제에서 적용됩니다.

### 6. 데이터 및 보안

Wink는 파트너 API를 통해 처리되는 데이터의 기밀성, 무결성 및 가용성을 보호하기 위해 상업적으로 합리적인 관리적, 기술적, 조직적 조치를 유지하며 주기적으로 검토합니다. Wink의 개인정보 처리 방식은 [개인정보 보호정책](/ko/privacy) 및 계약 내 데이터 처리 조건에 따릅니다. 귀하는 API 자격 증명을 안전하게 관리하고, 검색한 데이터의 합법적 사용에 책임을 지며, 자격 증명 유출 의심 시 즉시 Wink에 통지해야 합니다.

### 7. 책임 제한

서비스 크레딧은 가용성 부족 또는 가동 시간 약속 미달에 대한 **유일하고 배타적인 구제 수단**이며, 해당 실패로 인한 기타 책임을 대체합니다. 본 SLA에 명시된 경우를 제외하고, 파트너 API는 "있는 그대로" 제공됩니다. 적용 법률이 허용하는 최대 범위 내에서 Wink의 서비스 관련 총 책임은 계약에 명시된 대로 제한되며, Wink는 간접적, 부수적, 특별, 결과적 또는 징벌적 손해, 이익, 수익, 데이터, 영업권 손실에 대해 책임지지 않습니다.

### 8. 기간, 변경 및 종료

본 SLA는 귀하가 SLA가 적용되는 요금제의 활성 파트너 API 구독을 유지하는 동안 적용됩니다. Wink는 본 SLA를 수시로 업데이트할 수 있으며, 중요한 변경 사항은 고객과 소통하는 일반 채널을 통해 안내됩니다. 업데이트 발효 후 파트너 API를 계속 사용하면 업데이트된 SLA에 동의하는 것으로 간주됩니다. 본 SLA는 계약 또는 귀하의 파트너 API 구독 종료 또는 만료 시 자동 종료됩니다. 종료 후에도 본질상 존속해야 하는 조항 — 미청구 서비스 크레딧 자격, 책임 제한, 정의 등 — 은 계속 유효합니다.
