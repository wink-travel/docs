## 직접 공급과 재판매 공급의 차이

대부분의 여행사 호텔 콘텐츠는 호텔 → 채널 매니저 → 도매업자 또는 베드뱅크 → 여행사라는 체인을 통해 도착합니다. 각 단계마다 지연, 마진, 여행사가 보는 정보와 호텔 실제 상황 간의 차이가 발생합니다.

실제 증상은 익숙합니다: 고객이 결정할 때쯤이면 요금이 오래되었고, 예약 확인 시 객실 가능이 실패하며, 객실 설명이 맞지 않고, 호텔에 직접 예약하지 않은 건에 대해 문의할 방법이 없습니다.

직접 예약은 이 단계를 제거합니다. 요금은 호텔의 것이고, 객실 가능 현황은 실시간이며, 예약은 여행사가 연결된 상태로 호텔 자체 시스템에 기록됩니다.

| | 도매업자 / 베드뱅크 | 직접 호텔 공급 |
|---|---|---|
| 요금 출처 | 계약된 할당량, 종종 고정 | 호텔의 실시간 요금 |
| 객실 가능 현황 | 캐시되어 확인 시 실패 가능 | 호텔에서 실시간 제공 |
| 마진 구조 | 요금 내 마진 포함 | 투명한 수수료 |
| 고객 소유권 | 공유 또는 불투명 | 여행사가 고객 유지 |
| 호텔 관계 | 간접적 | 호텔과 직접적 |
| 특별 요청 | 체인을 통해 전달 | 예약과 함께 호텔에 도달 |

## 여행사가 직접 예약하려면 필요한 것

- **적격 공급에 대한 접근 권한** — 호텔이 설정한 여행사별 이용 가능한 호텔, 객실 및 요금.
- **고객에게 제시할 수 있는 방법** — 엄선된 호텔 목록, 패키지, 지도 또는 제안서나 일정용 스토어프론트.
- **출처를 보존하는 예약 경로** — 수수료가 추적 가능하도록.
- **명확한 결제 조건** — 누가 수금하며, 누가 상인 기록을 유지하고, 언제 수수료가 정산되는지.
- **호텔에 실제로 전달되는 확인 및 수정 처리**.

## 결제가 작동하는 두 가지 방식

**호텔이 수금하는 경우.** 결제는 호텔을 위해 수금되며 호텔이 상인 기록을 유지합니다. 여행사는 수수료를 받고 상인 책임은 없습니다. 기본 방식이며 라이선스가 필요 없습니다.

**여행사가 수금하는 경우.** 적절한 지역 여행사 라이선스를 보유한 여행사는 고객으로부터 직접 결제를 받고 호텔에 지불할 수 있습니다. 이 경우 Wink는 자금을 처리하지 않으므로 **1.5% 처리 수수료만** 월별 청구합니다. 적용되는 라이선스는 운영 지역에 따라 다르므로 현지에서 확인 후 선택하세요.

## 수수료 및 계산 기준

기본 수수료는 **10%**이며, 호텔의 1.5% 플랫폼 수수료와 카드 처리 비용을 제외한 후 계산됩니다. $2,000 예약 시 약 **$189**입니다. 수수료 귀속은 **클릭 후 6개월간** 유지되며, 제안서가 고객과 몇 주간 머무는 경우 중요합니다.

## 단체, 이벤트 및 MICE 예약

직접 공급은 도매업자가 약한 부분에서 가장 가치가 있습니다: 결혼식, 회의, 리트릿, 인센티브를 위한 객실 블록. 요금, 보류 및 마감일에 대해 호텔과 대화가 필요하며, 예약과 호텔이 여행사를 알기 때문에 가능합니다.

적격 공급으로 만든 스토어프론트나 이벤트 페이지는 참가자에게 예약 가능한 링크를 제공하면서 블록, 귀속 및 보고를 여행사가 유지할 수 있게 합니다.

## 흔한 실수

- **순도매 요금과 수수료 적용 가능한 직접 요금을 비교**할 때 이미 순도매 요금에 포함된 마진을 조정하지 않음.
- **고객에게 PDF를 보내는 것.** 예약할 수 없는 제안서는 예약 가능한 제안을 만든 쪽에 예약을 빼앗깁니다.
- **모든 고객에게 하나의 공유 링크 사용.** 귀속과 보고가 추측에 의존하게 됩니다.
- **수수료를 받기 위해 라이선스가 필요하다고 가정.** 수수료를 받는 데는 필요 없으며, 직접 결제 수금 시에만 필요합니다.
- **고객이 요청할 때까지 블록 취소 조건을 무시.**
