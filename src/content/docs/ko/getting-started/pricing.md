Wink는 구독, 좌석 수 제한, 초기 설정 비용이 없습니다. 플랫폼의 대부분 기능은 무료이며, 비용이 발생하는 항목은 두 가지뿐입니다:

1. **예약당 플랫폼 수수료 및 카드 결제 수수료(실비)** — 예약이 이루어질 때만 부과됩니다.
2. **사용량 기반 요금** — 실행할 때마다 비용이 발생하는 일부 프리미엄 기능에 대해, 매월 무료 할당량이 제공됩니다.

## 무료로 제공되는 기능

다음 기능들은 할당량이나 측정 없이 영구적으로 무료입니다:

- **예약 엔진** — 자체 사이트, WinkLinks 페이지 또는 임베드한 모든 곳에서 사용 가능.
- **숙소 관리** — 콘텐츠, 사진, 요금, 요금제, 가용성, 프로모션 및 정책 관리.
- **제휴 도구** — 공유 가능한 링크, 큐레이션 리스트, 그리드, 지도, 카드 및 임베드 위젯.
- **여행사 도구** — 검색, 맞춤 요금 및 고객을 대신한 예약.
- **WinkLinks** — 원하는 URL을 등록하고 페이지를 만들어 원하는 만큼 게시 가능.
- **수동 소셜 게시물** — 직접 작성한 모든 게시물, 연결된 네트워크 어디서든 무료.
- **분석, 리더보드, 클레임, 설정** 및 계정 관리.
- **소비자 및 예약 엔진 API**, 조회 및 자동완성 엔드포인트.

## 예약

Wink는 두 가지 모델을 지원합니다: Wink가 호텔 결제를 수집하는 경우와 여행사가 상인으로서 결제를 처리하는 경우입니다.

### 모델 1 — Wink가 호텔 결제 수집 대행

Wink는 호텔의 제한된 결제 수집 대행자로서 고객 결제를 수집합니다. 호텔이 상인으로 등록되며, 고객 카드 명세서에 호텔 이름이 표시됩니다. 이 모델은 전체 예약의 95%에 해당합니다.

#### 세부 내용

:::note[플랫폼 수수료]
Wink는 예약당 1.5% 플랫폼 수수료를 부과합니다. 이는 플랫폼 유지비용을 충당하며 위에 나열된 모든 무료 기능을 제공할 수 있게 합니다. 취소된 예약에는 부과되지 않습니다.
:::

:::note[카드 결제 수수료]
고객 결제 수집을 위한 결제 처리 수수료는 실비로 호텔에 전가되며, 마진은 없습니다. 수수료는 고객 카드 및 결제 방식에 따라 다르며, 각 예약의 회계 섹션에 정확한 금액이 표시됩니다. 예약이 취소되거나 환불될 경우, 결제 처리사가 유지하는 수수료는 여전히 부과됩니다; 수수료가 없으면 Wink도 부과하지 않습니다.
:::

:::note[자금 송금 수수료]
계좌로 자금을 송금할 때 수수료가 발생합니다. 이는 선택한 송금 방식에 따라 다릅니다. 현재 지원하는 방식은 다음과 같습니다:

- **은행 송금** — 거주 국가, 자금 출처, 환전 여부에 따라 비용이 달라집니다. 송금 수수료 및 환전 비용은 수취인이 실비로 부담합니다. 계정에 사용 가능한 자금이 있을 때 견적 계산기를 제공합니다.

다른 송금 방식을 원하시면 이메일로 문의해 주세요.
:::

### 모델 2 — 여행사가 상인으로서 결제 처리

이 모델은 해당 지역에서 여행사 라이선스를 보유하고 상인으로서 결제를 처리하고자 하는 여행사에만 제공됩니다. 일부 등록된 여행사는 결제 처리 및 호텔로의 자금 송금 책임을 지고, 해당 국가에서 필요한 라이선스를 보유합니다.

#### 세부 내용

:::note[플랫폼 수수료]
Wink는 예약당 1.5% 플랫폼 수수료를 부과합니다. 이는 플랫폼 유지비용을 충당하며 위에 나열된 모든 무료 기능을 제공할 수 있게 합니다.
:::

이 모델을 사용하는 여행사는 Wink의 플랫폼 수수료만 지불하며, Wink는 매월 여행사에 청구서를 발행합니다.

## 사용량 기반 요금 (pay-as-you-go)

일부 기능은 실행할 때마다 비용이 발생합니다 — 생성형 AI, 타사 소셜 API, 대규모 실시간 가격 제공 등. 월별 요금제에 묶지 않고, 실제 사용량에 대해서만 요금을 부과하며, 매월 무료 할당량이 제공됩니다.

| 기능 | 월별 무료 할당량 | 이후 요금 | 청구 단위 |
| -- | -- | -- | -- |
| 소셜 게시물 — 이미지 | 1 | $1.50 | 게시물 1건 |
| 소셜 게시물 — AI 생성 이미지 | 0 | $2.50 | 게시물 1건 |
| 소셜 게시물 — AI 향상 비디오 | 0 | $4.00 | 게시물 1건 |
| 소셜 게시물 — AI 생성 비디오 | 0 | $14.00 | 게시물 1건 |
| AI 댓글 또는 DM 답변 | 5 | $0.05 | 답변 1건 |
| 챗봇 답변 | 5 | $0.05 | 답변 1건 |
| 파트너 API | 10,000 | $0.0001 | 호텔-일 1건 |

가격은 USD 기준입니다. 무료 할당량은 **계정별**로 제공되며, 사용자별이 아니고 매월 1일(UTC)에 초기화됩니다.

### 게시물 요금 산정 방식

게시물 내 포함된 콘텐츠에 따라 요금이 부과됩니다. 정지 이미지는 저렴하지만, 비디오는 비용이 더 높으며, AI로 생성된 콘텐츠는 직접 제공한 사진보다 훨씬 더 비용이 듭니다.

- **무료 할당량은 표준 이미지 게시물에만 적용됩니다.** 계정당 월 1건이 무료입니다. 비디오 게시물과 AI 생성 미디어는 첫 게시물부터 요금이 부과됩니다 — 따라서 비디오 게시물을 게시하는 숙소는 첫 달부터 요금이 발생할 수 있습니다.
- **비디오가 우선합니다.** 게시물에 비디오가 포함되면 전체 게시물이 비디오 요율로 청구됩니다. 이미지와 비디오가 혼합된 게시물은 비디오 게시물로 간주됩니다.
- **AI 생성 여부가 요율을 결정합니다.** 직접 제공한 사진 및 비디오, 또는 Wink 콘텐츠 라이브러리의 미디어는 표준 요율이 적용됩니다. Wink가 생성한 미디어는 AI 요율이 적용됩니다.

### 측정되는 항목과 그렇지 않은 항목

- **생성된 게시물이 제3자 네트워크(Facebook, Instagram 등)에 게시될 때만 요금이 부과됩니다.** 직접 작성한 게시물은 어디에 게시하든 무료입니다.
- **WinkLinks에 게시하는 것은 항상 무료입니다**, 생성 여부와 관계없이.
- 게시 시점에 요금이 부과되며, 시도 횟수별로 부과되지 않습니다. 초안 재생성은 요금에 포함되지 않으며, 실제 게시한 게시물에 대해서만 한 번 요금이 부과됩니다. 다만, 각 게시물은 이미지 10회, 비디오 3회 정도의 재생성 제한이 있습니다. 작업 중 남은 횟수를 확인할 수 있습니다.
- 파트너 API에서 **호텔-일**은 1박 숙박에 대한 1개 호텔 단위입니다 — *API 호출 1회가 아닙니다*. 예를 들어, 20개 호텔을 3박 검색하면 60 호텔-일이 한 번의 요청으로 계산됩니다. 조회 및 자동완성 엔드포인트는 무료이며 측정되지 않습니다.

### 사용량 기반 요금 활성화

기본적으로 사용량 기반 요금은 비활성화되어 있습니다. 모든 사용자는 아무 조치 없이 무료 할당량을 받습니다.

무료 할당량을 초과하려면, **계정 소유자**가 사용량 기반 요금을 활성화하고 측정할 계정을 선택해야 합니다. 활성화된 모든 계정의 사용량은 **단일 월별 청구서**로 합산되며, 카드 자동 결제 또는 직접 결제 청구서 수령이 가능합니다.

활성화 후에는 사용량이 측정되지만 **절대 제한되지 않습니다** — 요금 지출에 따른 속도 제한이 없습니다.

:::note[활성화하지 않으면]
문제가 발생하거나 요금이 부과되지 않습니다. 해당 월의 무료 할당량까지만 사용 가능하며, 생성된 게시물은 게시되지 않고 파트너 API 호출은 `429` 오류를 반환합니다. 할당량이 초기화되면 다시 사용 가능합니다.
:::

### 청구 상태

| 상태 | 의미 |
| -- | -- |
| 정상 | 모든 기능이 정상 작동 중입니다. |
| 연체 | 결제 실패 후 재시도 중입니다. 이 기간 동안 기능은 계속 작동합니다. |
| 정지 | 청구서 미납 상태가 지속되었습니다. 청구 대상 작업은 결제 완료 시까지 차단되며, 무료 기능은 정상 작동합니다. |

:::tip[실시간 가격]
단가 및 무료 할당량은 항상 포털에서 실시간으로 확인할 수 있어, 사용 전에 요금을 확인할 수 있습니다. [Billing](/ko/portal/plan)에서 사용량 기반 요금을 활성화하고 계정을 선택하며, 월별 사용량과 청구서를 추적하세요. 게시물 수량이 지출에 미치는 영향은 [Social](/ko/portal/social/what-is-social)에서 확인할 수 있습니다.
:::

## 플랫폼 효과

마지막으로, Wink가 규모와 예약 수가 증가함에 따라 플랫폼 효과를 공유하고자 합니다. 예약이 많아질수록 결제 처리사로부터 대량 할인 기회를 얻을 수 있습니다. 카드 결제 수수료는 실비로 호텔에 전가되므로, 협상된 절감액은 호텔에 직접 돌아갑니다.

오늘 Wink에 가입하여 호스피탈리티 산업에서 새롭고 수익성 높은 비즈니스 방식을 경험해 보세요!
