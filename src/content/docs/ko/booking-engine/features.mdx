예약 엔진은 재고가 예약 가능해지는 곳입니다. 숙소는 [Portal](/ko/portal/overview)에서 재고를 등록하고 제휴사는 이를 공유 가능한 콘텐츠로 전환합니다 — 그런 다음 예약 엔진은 해당 콘텐츠를 여행자에게 적절한 언어, 통화, 브랜딩으로 제공하고 예약을 처리합니다.

웹사이트 `https://book.wink.travel`에서 제공되며, 동일한 기능이 [Web Components](/ko/integrations/web-components), [WordPress plugin](/ko/integrations/wordpress), [APIs](/ko/api)를 통해 통합자에게도 제공됩니다.

## 하나의 엔진, 맞춤형

예약 엔진은 하나이며, `https://book.wink.travel`에 있습니다.

<LinkButton href="https://book.wink.travel/home" variant="secondary" icon="external" target="_blank">
  예약 엔진 열기
</LinkButton>

판매하는 주체에 맞게 적응합니다. 여러 숙소를 보유한 제휴사는 탐색 및 비교용 홈 페이지를 받습니다. 단일 호텔은 자체 재고로 바로 연결되는 페이지를 받습니다. 숙소 관리 회사는 [대표하는 숙소들](/ko/portal/settings/agency-representation)을 받습니다. 이 모든 것은 별도의 사이트나 제품이 아니라, 동일한 엔진이 어떻게 자신을 보여줄지 알려주는 [맞춤 설정](/ko/portal/settings/branding)입니다.

## 여행자가 할 수 있는 일

### 예약할 숙소 찾기

- **목적지로 검색하기.** 도시, 섬, 국가 또는 특정 숙소, 레스토랑, 스파, 회의실, 액티비티, 명소, 장소를 찾아보세요.
- **순위별 컬렉션 탐색.** 회원 요금, 가격, 인기, 친환경 등급, 경험, 혜택, 로열티, 추가 옵션별로 정렬된 재고를 전 세계 또는 특정 도시, 섬, 국가별로 탐색하세요.
- **결과 필터링** 이름, 반경, 라이프스타일, 별점, 직영 재고로 필터링하세요.
- **일정 설정** — 체크인 및 체크아웃 날짜, 성인 수, 어린이 및 나이, 여러 객실, 프로모션 코드 입력. 그리드 내 가격이 실시간으로 업데이트됩니다.

자세한 내용은 [검색](/ko/booking-engine/search)에서 확인하세요.

### 숙소 평가하기

각 숙소는 사진 갤러리, 현지화된 설명, 지도, 편의시설, 별점 및 고객 점수, Greendex 친환경 등급, 고객 리뷰, 숙소 내 레스토랑, 스파, 액티비티, 명소, 회의실, 여행 주의사항이 포함된 고유 랜딩 페이지를 가집니다.

자세한 내용은 [숙소 상세](/ko/booking-engine/property-detail)에서 확인하세요.

### 숙박 구성 및 예약하기

- **객실 및 요금제 선택**, 환불 가능 및 불가 옵션이 명확히 표시됩니다.
- **각 요금에 포함된 혜택 확인** — 보장된 혜택과 가능 시 제공되는 혜택 모두.
- **여러 객실 추가** 및 수량 조정.
- **호텔 추가 옵션 및 패키지 추가**, 날짜와 시간에 맞춘 예약형 추가 옵션 포함.
- **총액 실시간 업데이트 확인**, 객실별 가격 내역과 공개 요금 대비 절감액 표시.
- **내장된 안전 결제 위젯으로 결제 및 체크아웃**. 카드, 지갑, 현지 결제 수단은 숙소의 결제 계정 지원에 따라 제공됩니다.

자세한 내용은 [체크아웃](/ko/booking-engine/checkout)에서 확인하세요.

### 예약 후 관리

- **예약 확인서 보기** — 예약 코드와 함께 즉시 및 이메일로 제공.
- **로그인 없이 예약 열기** — 계정을 만들지 않은 고객도 이메일로 받은 예약 링크로 접근 가능.
- **전체 예약 내역 검토**: 취소 정책, 결제 상태, 결제 방법, 추가 요금, 숙소 연락처.
- **조치하기**: 예약 코드 복사, 공유, 캘린더에 추가, 인쇄, 영수증 다운로드, 사유와 함께 취소, 취소 기간 외 환불 요청.
- **숙박 후 리뷰 작성** 가능.
- **여러 예약이 하나의 여행으로 그룹화되어 표시**.

자세한 내용은 [예약](/ko/booking-engine/bookings) 및 [예약 확인](/ko/booking-engine/confirmation)에서 확인하세요.

### 개인화하기

- **언어 및 통화 언제든지 변경** — 40개 이상의 언어와 160개 이상의 통화 지원.
- **Wink 싱글 사인온으로 한 번 로그인**. 로그인 후에는 체크아웃 중간 등 정확히 이전 위치로 돌아갑니다.
- **여행 프로필 유지** — 지역 선호, 비상 연락처, 알레르기, 반려동물, 접근성 요구, 호텔, 객실, 음식, 개인 선호 설정 및 예약한 숙소와 공유 여부 선택.
- **숙소를 링크 또는 QR 코드로 15개 소셜 및 메시징 네트워크에 공유**.

자세한 내용은 [여행 선호](/ko/booking-engine/travel-preferences)에서 확인하세요.

## 여행자가 예약 엔진에 도달하는 방법

대부분의 경우 예약 엔진에 직접 링크할 필요가 없습니다. [Portal](/ko/portal/overview)에서 구축한 모든 것 — 링크, 카드, 그리드, 지도 — 및 [WinkLinks](/ko/portal/link-manager/wink-links)에 게시한 모든 콘텐츠는 이미 고객 ID, 제휴사 ID, 브랜딩을 포함하며, 여행자를 적절한 페이지와 일정이 미리 채워진 상태로 안내합니다.

| 공유하는 것 | 여행자가 도착하는 위치 |
| --- | --- |
| [공유 가능한 링크](/ko/portal/studio/shareable-links) | 짧은 `trvl.as` URL로, 브랜딩된 숙소 랜딩 페이지로 확장되며 일정, 통화, 언어가 미리 적용됩니다. Facebook, X, WhatsApp 등 URL이 사용되는 곳 어디서나 게시물로 작동합니다. |
| [카드](/ko/portal/studio/cards) | 단일 예약 가능한 공급자 또는 재고 항목 — 호텔, 객실 유형, 스파, 레스토랑. `예약`은 예약 흐름을 열고, `최고 혜택`과 `호텔 상세`는 숙소 페이지로 이동합니다. |
| [그리드](/ko/portal/studio/grids) | 선별된 목록, 저장된 검색 또는 실시간 순위 검색에서 생성된 페이지네이션 카드 세트. 각 카드는 동일한 방식으로 예약됩니다. |
| [지도](/ko/portal/studio/maps) | 마커가 예약 가능한 카드로 열리는 인터랙티브 지도. |
| [WinkLinks](/ko/portal/link-manager/wink-links) | 위의 모든 조합을 호스팅하는 링크 인 바이오 페이지. 인스타그램에서 두 번의 클릭으로 예약까지. |
| [지금 예약 버튼](/ko/guides/hoteliers/the-book-now-button) | 날짜, 객실 구성, 언어, 통화, 프로모션 코드가 URL 매개변수로 포함된 자동 생성 숙소 링크를 가리키는 자체 사이트 버튼. |
| [Web Components](/ko/integrations/web-components) | 카드, 그리드, 지도, 검색, 일정 선택기를 페이지에 직접 삽입. 예약은 엔진으로 전달하거나 모달로 열 수 있습니다. |
| [WordPress plugin](/ko/integrations/wordpress) | Gutenberg, Elementor, Avada, WPBakery용 WordPress 숏코드로 동일한 컴포넌트 제공. |
| [APIs](/ko/api) | 원격 여행사 시스템 및 채널 매니저를 위한 직접 통합. |

여행자가 어떤 경로를 택하든, 그들을 보낸 제휴사는 귀속 기록되며 — 이 귀속은 180일간 유지되어 나중 방문 시 예약도 해당 제휴사에 크레딧이 부여됩니다.

## 화이트라벨링

예약 엔진은 귀하의 브랜드 뒤에 숨도록 설계되었습니다.

가장 기본적으로, [맞춤 설정](/ko/portal/settings/branding)은 엔진을 귀하의 이름, 로고, 색상, 타이포그래피로 재스타일링하여 귀하의 것으로 보이게 합니다. 여행자는 여전히 `book.wink.travel`에 도착합니다.

가장 깊은 수준에서는, **제휴사가 자체 도메인 이름에서 예약 엔진을 운영할 수 있습니다**. 도메인을 예약 엔진에 연결하면 호스트명에서 자동으로 맞춤 설정을 불러옵니다 — URL에 클라이언트 ID나 구성 ID가 없고, 주소 표시줄에 Wink 도메인이 없습니다. 여행자는 검색부터 확인까지 `book.yourbrand.com`을 봅니다.

:::note[자체 도메인 설정]
맞춤 도메인은 셀프 서비스가 아닌 당사의 지원으로 설정됩니다. 사용하려는 도메인과 함께 [문의하기](/ko/contact)로 연락 주시면 설정 및 맞춤 연결을 도와드립니다.
:::

## 맞춤 설정

아래 모든 항목은 맞춤 설정별로 설정되며, 여러 개를 유지할 수 있습니다 — 시장별, 캠페인별, 숙소별로 하나씩.

**정체성**

- 페이지 제목에 추가되는 표시 이름과 태그라인.
- 로고, 예약 이메일용 별도 로고 포함.

**외관 및 느낌**

- 11가지 토큰 색상 팔레트: 기본, 보조, 성공, 위험, 경고, 정보, 밝음, 어두움, 본문, 음소거, 흰색.
- 20가지 엄선된 서체 중 선택한 타이포그래피.
- 홈 페이지, 헤더, 숙소 페이지를 재구성하는 정보형 또는 거래형 페이지 레이아웃.
- 카드 레이아웃 — 세로 그리드 또는 가로 리스트.
- 검색 바, 순위 배지, 예약 불가 숙소 카드 토글.

아래 개발자 샌드박스에서 테마 맞춤 설정을 테스트해 보세요.

<LinkButton href="https://developer.wink.travel/web-component" variant="secondary" icon="external" target="_blank">
  테마 설정
</LinkButton>

**여행자가 도착하는 기본값**

- 기본 언어 및 통화.
- 미리 설정된 일정 — 고정 날짜 또는 "30일 후, 2박"과 같은 롤링 윈도우.
- 기본 객실 구성 및 프로모션 코드.
- 목적지 선택기의 기본 도시.

**측정 및 통합**

- Wink와 함께 작동하는 자체 Google Analytics 4 측정 ID, Google Tag Manager 컨테이너, 추적 픽셀.
- 자체 Google Maps API 키.
- 예약 알림 이메일을 숙소, 예약자, 채널 매니저에게 보낼지 여부 제어.
- 내장 컴포넌트의 `예약` 버튼이 예약 엔진으로 전달할지 모달로 열지 선택.

필드별 안내는 [맞춤 설정](/ko/portal/settings/branding) 및 [예약 경험 맞춤 설정](/ko/guides/general/customizing-your-booking-experience)을 참조하세요.

## 직접 링크하기

예약 엔진에 직접 링크하려면 URL에 클라이언트 ID와 맞춤 설정 ID를 매개변수로 추가하세요. 두 ID 모두 [Portal](/ko/portal/overview)에서 작업 중인 계정에 있습니다 — 숙소, 관리 회사, 제휴사 계정 중 어느 것이든 상관없습니다.

### 클라이언트 ID 찾기

<Steps>
1. [계정](https://app.wink.travel)에서 작업할 계정을 선택하세요.
2. 계정 카드 하단의 `작업`을 클릭하고 `계정 관리`를 선택하세요.
3. 다음 페이지에서 `애플리케이션` 탭을 클릭하세요.
4. 사용하려는 애플리케이션의 클라이언트 ID를 복사하여 URL 요청 매개변수로 붙여넣으세요. 예: ?client-id=MY_CLIENT_ID
</Steps>

애플리케이션 생성 및 관리는 [애플리케이션](/ko/account/applications)을 참조하세요.

### 맞춤 설정 ID 찾기

<Steps>
1. [계정](https://app.wink.travel)에서 작업할 계정을 선택하세요.
2. 계정 카드 하단의 `작업`을 클릭하고 `계정 관리`를 선택하세요.
3. 다음 페이지에서 `맞춤 설정` 탭을 클릭하세요.
4. 사용하려는 맞춤 설정의 ID를 복사하여 URL 요청 매개변수로 붙여넣으세요. 예: ?configuration-id=MY_CUSTOMIZATION_ID
</Steps>

맞춤 설정이 제어하는 전체 목록은 [맞춤 설정](/ko/portal/settings/branding)을 참조하세요.

### 조합하기

홈 페이지로 링크하려면 다음과 같은 URL이 됩니다:

https://book.wink.travel?client-id=MY_CLIENT_ID&configuration-id=MY_CUSTOMIZATION_ID

홈 페이지는 귀하의 브랜딩을 적용하고 귀하 계정이 대표하는 재고 — 자체 숙소, 관리하는 숙소, 전체 제휴 카탈로그 — 를 보여줍니다.

특정 숙소로 바로 보내려면 해당 랜딩 페이지로 링크하세요:

https://book.wink.travel/hotel/hotel-x?client-id=MY_CLIENT_ID&configuration-id=MY_CUSTOMIZATION_ID

:::note
클라이언트 ID나 구성 ID를 생략하면 예약 엔진은 기본 구성으로 로드되어 기본 브랜딩이 표시되고 예약은 귀속되지 않습니다. 항상 두 ID를 모두 포함하세요.
:::
