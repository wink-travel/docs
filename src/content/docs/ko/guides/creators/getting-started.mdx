이 가이드는 회원가입부터 첫 예약 가능한 호텔 링크 생성까지 안내합니다. 약 15분 정도 소요됩니다. 완료하면 라이브 스토어프론트, 공유할 첫 링크를 갖게 되며, 수익 지급 방식과 시기를 알게 됩니다.

## 시작하기 전에

다음이 필요합니다:

- 등록할 이메일 주소
- 주요 소셜 프로필, 채널 또는 블로그 링크
- 은행 정보 (첫 커미션을 벌기 전까지는 나중에 입력해도 됩니다)

## 수익 구조

- Wink 네트워크 내 호텔 예약 시 **기본 10% 커미션** 지급
- **클릭 후 6개월간 유효한 크레딧**: 오늘 링크를 클릭하고 3개월 후 예약해도 커미션은 당신에게 지급됩니다.
- **팔로워 최소 조건 없음** 및 별도 신청 절차 없음. Wink 네트워크에 등록된 모든 호텔을 바로 이용할 수 있습니다.
- **고객 서비스 처리 불필요**: 결제는 호텔에서 직접 수령하며, 호텔이 고객을 관리합니다. 당신은 커미션만 받습니다.

전체 내용을 보려면 [여행 크리에이터 호텔 예약 커미션 받는 방법](/ko/resources/travel-creator-hotel-commissions/)과 [가격 정책](/ko/pricing/)을 참고하세요.

## 1단계: Wink 로그인 생성

<Steps>
1. [app.wink.travel](https://app.wink.travel)로 이동해 우측 상단의 `Sign-In / Register`를 클릭하세요.

2. 로그인 폼 아래의 `Register` 링크를 클릭하고 양식을 작성한 후 `Register`를 클릭하세요.

3. 로그인하면 포털에 접속되어 계정 생성 준비가 완료됩니다.
</Steps>

## 2단계: 크리에이터 계정 생성

로그인은 본인 계정이고, **계정**은 청중과 호텔이 보는 크리에이터 프로필입니다.

  alt="Wink에서 계정 유형 선택"

  <figcaption>*계정 유형 선택*</figcaption>

<Steps>
1. 왼쪽 사이드바에서 `Accounts`를 클릭한 후 `Create`를 클릭하세요.

2. **I am an Affiliate**를 선택하세요. Wink에서 크리에이터는 제휴사로, 보낸 예약에 대해 커미션을 받습니다.

3. 양식을 작성하세요:
   - **이름**: 청중이 아는 크리에이터 이름
   - **법인 유형**: 회사가 아닌 경우 `Individual` 선택. 지급 방식에 영향을 줍니다.
   - **유형**: `Influencer`
   - **설명**: 게시하는 내용에 대한 한두 줄 설명. 스토어프론트에 표시됩니다.
   - **웹사이트**: 주요 프로필 URL (예: Instagram, TikTok, YouTube). 호텔과 직접 협업 요청 시 참고됩니다.
   - **도시**: 거주지

4. 약관 및 결제 조건에 동의하고 `Save`를 클릭하세요.
</Steps>

:::tip[스토어프론트 주소]
계정 이름이 스토어프론트 주소를 결정합니다: *Queen Bee*라는 계정은 `i.trvl.as/queen-bee`가 됩니다. 주소의 슬러그 부분은 나중에 수정할 수 있습니다. 슬러그는 선착순이므로 빨리 확보하세요. [URL 확보하기](/ko/portal/link-manager/claim-your-url/)를 참고하세요.
:::

## 3단계: 스토어프론트 설정

스토어프론트는 **WinkLinks** 페이지로, 링크 인 바이오 페이지이자 호텔 판매 페이지입니다. 이미 `i.trvl.as` 주소에 존재합니다. 이제 나만의 페이지로 만드세요.

<figure>
<CldImage

  alt="WinkLinks 스토어프론트"
/>
  <figcaption>*WinkLinks 스토어프론트*</figcaption>
</figure>

<Steps>
1. 프로필 사진을 업로드하고 2단계에서 작성한 설명을 확인하세요.

2. 이미 공유 중인 링크(채널, 블로그, 다른 제휴 링크 등)를 추가하세요. 모두 한 페이지에 모입니다. [콘텐츠](/ko/portal/link-manager/content/)를 참고하세요.

3. `WinkLinks > Design`에서 **Intelligent**를 켜면 Instagram, Facebook, YouTube, X, Spotify 링크가 일반 링크 대신 재생 가능한 게시물로 표시됩니다. 레이아웃과 색상을 선택하세요. [설정](/ko/portal/link-manager/settings/)을 참고하세요.
</Steps>

실제 예시를 보고 싶다면 [i.trvl.as/starringmay](https://i.trvl.as/starringmay)를 방문하세요.

## 4단계: 홍보할 호텔 찾기

호텔은 포털의 크리에이터 전용 공간인 **Studio**에 있습니다. 별도 가입 절차는 없습니다.

<Steps>
1. 메인 내비게이션 바에서 `Browse > Hotels`를 클릭하거나 대시보드에서 검색하세요.

2. 목적지, 날짜, 가격으로 필터링해 추천할 만한 호텔을 찾으세요.

3. 좋은 호텔은 [큐레이션 리스트](/ko/portal/studio/curated-lists/)에 추가하거나 (모든 계정은 기본적으로 `Favorites` 리스트가 있음), [검색 저장](/ko/portal/studio/saved-searches/) 기능을 이용해 나중에 다시 방문하세요.
</Steps>

:::tip
직접 머물렀거나 머물고 싶은 곳을 홍보하세요. 청중은 이를 구분할 수 있으며, 클릭을 예약으로 전환시키는 핵심입니다. 아이디어가 필요하면 [좋은 딜 발견하기](/ko/guides/affiliates/discover-great-deals/)를 참고하세요.
:::

<Steps>
1. 검색 결과에서 호텔을 선택하고 `Make a link`를 클릭하세요.

2. 알아보기 쉬운 링크 이름을 정하고, 제목과 설명을 추가하며, 공유 시 보여질 이미지를 선택하세요.

3. 이미지 위에 실시간 가격을 표시할 테마를 선택하세요.

4. `Save`를 클릭하면 `trvl.as/3xWCH` 같은 짧은 링크가 생성되며, 크레딧이 포함됩니다.
</Steps>

전체 옵션은 [공유 가능한 링크](/ko/portal/studio/shareable-links/)에서 확인하세요.

### 용도별 링크 형식

| 게시 위치 | 사용 형식 | 이유 |
|---|---|---|
| 스토리, 릴, TikTok, 댓글, DM | [공유 가능한 링크](/ko/portal/studio/shareable-links/) | 호텔 하나당 짧은 링크, 가격 미리보기 포함 |
| 링크 인 바이오 | [WinkLinks](/ko/portal/link-manager/wink-links/) | 추천하는 모든 것을 한 주소에 모음 |
| 테마 여행 ("리스본의 5개 부티크 숙소") | [큐레이션 리스트](/ko/portal/studio/curated-lists/)를 [그리드](/ko/portal/studio/grids/) 또는 [지도](/ko/portal/studio/maps/)로 표시 | 한 곳에서 비교하고 예약 가능 |
| 블로그나 웹사이트 | [카드](/ko/portal/studio/cards/), [그리드](/ko/portal/studio/grids/), [지도](/ko/portal/studio/maps/) | 기사 내에서 바로 예약 가능한 호텔 표시 |

## 6단계: 공유하기

청중이 이미 보는 곳에 링크를 넣으세요: 바이오, 스토리 링크 스티커, YouTube 설명, 고정 댓글, 뉴스레터, 블로그 게시물 등. 6개월 크레딧 덕분에 오래된 영상이나 글에도 계속 수익이 발생합니다.

:::note[파트너 링크 표시하기]
대부분 플랫폼과 여러 국가에서는 링크에서 수익을 얻는다는 사실을 *#ad*, *#affiliate* 또는 플랫폼의 유료 파트너십 라벨 등으로 표시해야 합니다. 해당 플랫폼과 국가의 규정을 따르세요. 이는 청중과의 신뢰를 쌓는 데도 도움이 됩니다.
:::

## 7단계: 성과 추적하기

우측 상단 프로필 아이콘을 클릭한 후 `Analytics`를 선택해 클릭과 예약 현황을 확인하세요. 전환이 안 되는 콘텐츠는 줄이고, 효과 좋은 콘텐츠를 더 게시하세요. [분석](/ko/account/analytics/)을 참고하세요.

## 8단계: 수익 받기

<Steps>
1. **은행 계좌 추가**: `Account > Bank Accounts`로 가서 계좌를 추가하고 **Primary**로 표시하세요. 자동 지급은 기본 계좌로 이루어집니다. [은행 계좌](/ko/portal/settings/payouts/)를 참고하세요.

2. **커미션은 고객 체크인 후 24시간 이내에 지급 가능 상태가 됩니다.** 예를 들어 3월에 예약하고 6월에 숙박하면 6월에 지급됩니다.

3. **지급은 은행 송금으로 이루어집니다.** Wink는 Revolut을 통해 지급하므로 Revolut 계좌가 있으면 가장 원활합니다. 다른 은행 계좌도 사용 가능합니다.

4. **송금 수수료는 실비로 청구되며 국가와 통화에 따라 다릅니다.** 출금 전에 비용 계산기를 통해 수수료를 확인할 수 있습니다. [가격 정책](/ko/getting-started/pricing/)과 [출금](/ko/portal/payment/withdraw-funds/)을 참고하세요.
</Steps>

:::note
수익이 증가하면 자금 지급 전에 신원 확인을 요청할 수 있습니다. 이는 수익 지급 플랫폼에서 일반적인 절차입니다.
:::

## 레벨 업

- **호텔과 직접 협업하기.** Wink에서 5건의 예약이 있으면 호텔에 직접 연결을 요청할 수 있습니다. 예를 들어 청중 전용 특별 할인이나 단체 요금 등입니다. 직접 연결 시 기본 10% 커미션 외에 별도 협의가 가능합니다. [네트워크](/ko/portal/studio/network/)를 참고하세요.
- **더 적은 노력으로 더 많이 게시하기.** [Social](/ko/portal/social/what-is-social/)은 호텔 게시물을 자동 생성 및 예약합니다. 수동 게시물은 항상 무료이며, AI 제작 콘텐츠는 사용량 기반 과금입니다. [가격 정책](/ko/pricing/)을 참고하세요.
