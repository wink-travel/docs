이 가이드는 여행사를 등록부터 첫 고객 예약까지 안내합니다. 또한 Wink에서 여행사가 작업할 수 있는 두 가지 방식을 설명하여 시작 전에 적합한 방식을 선택할 수 있도록 도와줍니다.

## 시작하기 전에

다음이 필요합니다:

- 회사 정보
- 여행사 등록 번호 또는 IATA 코드(있는 경우)
- 수수료 입금을 위한 은행 계좌

## 작업 방식을 선택하세요

| | 표준 (대부분의 여행사) | 에이전트 직접 결제 |
|---|---|---|
| 예약 방법 | Wink 포털 또는 Partner API를 통해 | 자체 시스템에서 [Partner API](/ko/integrations/partner-api/)를 통해 |
| 고객 결제 수령자 | 호텔이 수집하며, 호텔이 상인으로 남음. 체크아웃 시 고객 카드 입력 | 여행사가 상인으로서 직접 수령 |
| 수익 | 각 예약에 대해 **기본 10% 수수료** | 각 호텔과의 개별 계약에 따른 수수료 |
| Wink에 지불하는 비용 | 없음 | 각 예약 금액의 **1.5%** 예약 수수료(월별 청구) 및 무료 한도 초과 Partner API 사용료 |
| 호텔 결제 | Wink가 처리 | 여행사가 각 호텔에 직접 결제, 자체 계약에 따름 |
| 환불, 차지백, 결제 준수 | Wink가 처리 | 여행사 책임 |
| 승인 | 예약 전 등록 심사 | 등록 심사 및 Wink의 서면 승인, 신용 한도 포함 |

Wink는 모든 여행사 등록을 검토합니다. 대부분의 여행사는 표준 방식을 사용합니다. 에이전트 직접 결제는 **API 파트너 전용**으로, 자체 시스템에서 Partner API를 통해 예약하고, 자체 라이선스와 계약으로 고객 결제를 수집하며 호텔과 직접 계약하는 여행사에 해당합니다.

## 1단계: 여행사 등록

<Steps>
1. [app.wink.travel](https://app.wink.travel)로 이동하여 `Sign-In / Register`를 클릭하고 등록하세요.

2. 왼쪽 사이드바에서 `Accounts`를 클릭한 후 `Create`를 선택하고 **I am a Travel Agent**를 선택하세요.

3. 여행사 정보를 입력하세요. 지급 방식을 결정하는 법인 유형으로 **Company**를 선택하세요. 자세한 내용은 [계정 생성](/ko/portal/create-account/)을 참조하세요.

4. Partner API를 통해 직접 결제 수집을 할 경우 등록 시 해당 방식을 선택하세요. 이는 요청이며 승인 절차는 아닙니다. [6단계](#step-6-collect-payment-yourself-api-partners-only)를 참고하세요.

5. Wink는 모든 여행사 등록을 검토합니다. 등록된 이메일로 서류 제출 요청(회사 정보 및 여행사 등록 번호 또는 IATA 코드)을 보내며, 승인 후 예약이 가능합니다.
</Steps>

## 2단계: 은행 계좌 추가

`Account > Bank Accounts`로 이동하여 여행사 계좌를 추가하고 **Primary**로 표시하세요. 수수료는 은행 송금으로 지급됩니다. Wink는 Revolut를 통해 지급하므로 Revolut 비즈니스 계좌가 가장 원활하지만, 다른 은행 계좌도 가능합니다. 자세한 내용은 [은행 계좌](/ko/portal/settings/payouts/)를 참조하세요.

## 3단계: 고객을 위한 호텔 찾기

<Steps>
1. 상단 내비게이션 바에서 `Browse > Hotels`를 클릭하세요.

2. 목적지, 날짜, 인원 수로 검색하고 필터를 적용해 고객에게 적합한 옵션을 찾으세요.

3. 고객과 옵션을 비교할 때는 [큐레이션 리스트](/ko/portal/studio/curated-lists/)에 단축 목록을 저장하세요.
</Steps>

표시되는 요금은 호텔 자체 요금입니다. Wink는 요금을 변경하지 않고 그대로 전달하며, 수익은 수수료를 통해 발생합니다. 자세한 내용은 [검색](/ko/portal/studio/search/)을 참조하세요.

## 4단계: 고객을 위한 예약

<Steps>
1. 객실과 요금을 선택하고 여행자로서 고객 이름과 연락처를 입력하세요.

2. 체크아웃 시 고객이 제공한 카드를 입력하세요. 결제는 호텔을 위해 수집되며, 호텔이 상인으로 남습니다.

3. 확인하세요. 여행사, 여행자, 호텔 모두 확인 이메일을 받으며 예약 코드는 `WNK`로 시작합니다.
</Steps>

:::caution[고객 카드 취급 주의]
예약에 필요한 카드만 요청하고 바로 체크아웃에 입력하세요. 카드 정보를 기록하거나 이메일로 보내거나 별도로 보관하지 마세요.
:::

## 5단계: 예약 관리 및 수익 지급

- **예약:** 상단 내비게이션 바에서 `Bookings`를 클릭해 모든 예약을 확인하고 필터링, CSV 내보내기, 확인서 재전송 또는 호텔 취소 정책 내에서 취소할 수 있습니다. 자세한 내용은 [예약](/ko/portal/travel-agent/bookings/)을 참조하세요.
- **수수료:** 기본 10%. 호텔과 정기적으로 거래하면 [직접 연결](/ko/portal/studio/network/)을 요청해 다른 수수료를 협의할 수 있습니다.
- **지급 시기:** 수수료는 고객 체크인 후 24시간 이내에 사용 가능해지며, 기본 은행 계좌로 지급됩니다. 송금 수수료는 실비로 부담합니다. 자세한 내용은 [가격 정책](/ko/getting-started/pricing/)을 참조하세요.

## 6단계: 직접 결제 수집 (API 파트너 전용)

포털에서 예약하거나 표준 방식에 만족한다면 이 단계를 건너뛰세요.

<Steps>
1. [Partner API](/ko/integrations/partner-api/)와 통합하세요. 이 방식은 포털이 아닌 자체 예약 시스템에서 API를 통해서만 작동합니다.

2. 등록 시(1단계) 이 방식을 선택하세요.

3. Wink는 등록 서류와 함께 재무 상태, 규제 상태 등을 평가하고 서면으로 승인합니다. 승인 시 **신용 한도**가 부여되며, 미정산 예약에 보유할 수 있는 최대 금액입니다.

4. 승인 전까지는 표준 방식으로 계속 예약할 수 있습니다.
</Steps>

승인 후에는 고객 결제를 직접 수집하고 각 호텔에 직접 결제합니다. 각 예약에서 순서대로 1.5% Wink 수수료와 수수료를 공제한 후 나머지 금액을 호텔에 지급합니다:

| 10% 수수료가 적용된 미화 1,000.00달러 예약 예시 | |
|---|---|
| 예약 금액 | USD 1,000.00 |
| Wink 수수료 (예약 금액의 1.5%) | USD 15.00 |
| 소계 | USD 985.00 |
| 수수료 (소계의 10%) | USD 98.50 |
| **호텔에 지급할 금액** | **USD 886.50** |

Wink는 1.5% 예약 수수료를 월별로 USD로 청구하며, 15일 이내에 지급해야 합니다. 무료 한도 초과 Partner API 사용료도 청구됩니다. 환불, 차지백, 결제 보안(PCI-DSS) 및 결제 수집에 필요한 국가별 라이선스는 여행사 책임입니다. 전체 약관은 [여행사 계약서](/ko/legal/platform-agreements/)에서 확인하세요.

## 자체 시스템 연결

자체 예약 도구가 있는 여행사는 [Partner API](/ko/integrations/partner-api/)를 통해 검색 및 예약할 수 있습니다. 여행사 계정은 API를 통해 직접 예약을 생성할 수 있으며, 에이전트 직접 결제 방식은 이 방법만 지원합니다. 자세한 내용은 [Partner API 참조](/ko/partner-api/partner/)를 확인하세요.
