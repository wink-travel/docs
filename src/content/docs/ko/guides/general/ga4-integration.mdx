Google Analytics 4 속성을 Wink에 연결하면 객실 조회부터 완료된 예약까지의 예약 이벤트가 Wink 자체 애널리틱스와 함께 자동으로 자신의 GA4 대시보드로 전송됩니다. 코딩이나 기술적 설정이 필요 없습니다.

<Aside type="tip">
GA4에서 필요한 것은 **측정 ID**(`G-XXXXXXXXXX`) 하나뿐입니다. Wink는 이를 게스트의 브라우저에 로드하여 완료된 예약(`purchase`)을 포함한 전체 예약 퍼널을 귀하의 GA4 속성으로 실시간 스트리밍합니다. API 비밀키를 생성하거나 웹사이트에 설치할 것도 없습니다.
</Aside>

---

## 작동 방식

```
Wink 포털에 측정 ID(G-XXXXXXXXXX)를 입력합니다
       ↓
Wink가 게스트 브라우저에 GA4를 로드하고 예약 이벤트
(조회, 장바구니, 결제)를 실시간으로 GA4 속성에 스트리밍합니다
       ↓
감사 페이지에서 완료된 예약(purchase) 이벤트가 브라우저에서 발생하며 —
결제 리디렉션으로 끊긴 GA4 세션을 Wink가 다시 연결하여
판매가 원래 방문에 정확히 집계됩니다
       ↓
analytics.google.com에 로그인하여 전체 예약 퍼널을 확인합니다
```

---

## 해야 할 일

<Steps>

1. **GA4 속성 생성**

   [analytics.google.com](https://analytics.google.com)으로 이동: 관리자 → 속성 생성. 시간대와 통화를 시장에 맞게 설정하세요.

2. **웹 데이터 스트림 생성**

   관리자 → 데이터 스트림 → 스트림 추가 → 웹. URL에 `wink.travel`을 입력합니다. 그러면 **측정 ID**(`G-XXXXXXXXXX`)가 생성됩니다. 복사하세요.

3. **Wink 포털에 측정 ID 입력**

   [app.wink.travel](https://app.wink.travel)에 로그인하여 계정을 선택하고 맞춤 설정 설정을 엽니다. **Analytics & integrations** 섹션에서 **GA4 측정 ID** 필드에 측정 ID를 붙여넣고 저장하세요. 이제 GA4 통합이 활성화됩니다.

4. **`purchase`를 주요 이벤트로 표시**

   GA4 속성에서: 관리자 → 이벤트 → `purchase` 찾기 → **주요 이벤트로 표시** 토글. 완료된 예약이 전환 보고서에 나타납니다.

5. **데이터 확인**

   [analytics.google.com](https://analytics.google.com)에 로그인하면 Wink를 통해 자동으로 추적된 예약, 수익, 고객 퍼널을 볼 수 있습니다.

</Steps>

<Aside type="note">
이 통합을 위해 웹사이트에 추적 코드를 설치할 필요가 없습니다. Wink가 모든 것을 처리하며, 측정 ID는 예약 데이터가 전송되는 목적지일 뿐입니다.
</Aside>

<Aside type="tip">
**GA4와 GTM은 함께 사용할 수 있습니다.** Google 태그 관리자 컨테이너(예: Sojern 컨테이너)를 운영 중이라면 두 가지를 동시에 구성할 수 있습니다. 상호 배타적이지 않습니다. 자세한 내용은 [GTM 애널리틱스 통합](/ko/guides/general/gtm-integration)을 참조하세요.
</Aside>

## Wink가 예약 엔진에서 측정 ID를 사용하는 방법

모든 작업은 **게스트의 브라우저에서** 이루어지며, 서버 간 데이터 전송이나 API 비밀키는 없습니다.

- **예약 페이지에서 귀하의 GA4가 로드됩니다.** 게스트가 Wink 예약 엔진에서 귀하의 숙소를 볼 때, Wink는 게스트 브라우저에 귀하의 측정 ID를 Wink 자체 애널리틱스와 함께 로드하여 동일한 공유 데이터를 읽습니다. 검색, 객실 조회, 장바구니, 결제 등 탐색 이벤트가 실시간으로 귀하의 GA4 속성에 스트리밍됩니다.
- **완료된 예약은 감사 페이지에서 발생합니다.** 게스트가 결제를 마치고 확인 페이지에 도착하면 `purchase` 이벤트가 클라이언트 측에서 발생하며, 전체 예약 금액, 통화, 객실 세부 정보가 포함됩니다.
- **결제 리디렉션으로 인한 판매 손실이 없습니다.** 카드 결제 시 게스트 브라우저가 결제 제공자 페이지로 이동했다가 돌아오는데, 이 과정에서 일반적으로 GA4 세션이 끊겨 예약이 새 "직접" 방문으로 기록됩니다. 이를 방지하기 위해 Wink는 리턴 URL에 GA4 세션 식별자를 전달하고 감사 페이지에서 `purchase` 이벤트 발생 전에 **원래 세션을 다시 연결**합니다. 따라서 완료된 예약은 게스트가 시작한 동일한 방문에 귀속됩니다.

<Aside type="note">
Wink는 예약당 `purchase` 이벤트 중복 집계를 방지하므로 페이지 새로고침이나 예약 상세 자동 리디렉션 시에도 판매가 중복 집계되지 않습니다.
</Aside>

## 추적 가능한 항목

연결 후 귀하의 GA4 속성은 숙소에 대한 향상된 전자상거래 이벤트 전체를 수신합니다:

### 발견

| 이벤트 | 의미 |
|---|---|
| `view_item_list` | 게스트가 검색 또는 카테고리 목록에서 숙소를 봄 |
| `select_item` | 게스트가 목록에서 숙소를 클릭함 |
| `view_item` | 게스트가 호텔 상세 페이지를 조회함 |

### 고려

| 이벤트 | 의미 |
|---|---|
| `view_promotion` | 게스트가 숙소 프로모션을 봄 |
| `select_promotion` | 게스트가 프로모션을 클릭함 |
| `add_to_wishlist` | 게스트가 숙소를 위시리스트에 저장함 |

### 예약 퍼널

| 이벤트 | 의미 |
|---|---|
| `add_to_cart` | 게스트가 객실 또는 패키지를 선택함 |
| `view_cart` | 게스트가 예약 요약을 봄 |
| `remove_from_cart` | 게스트가 객실 또는 패키지를 장바구니에서 제거함 |
| `begin_checkout` | 게스트가 결제 과정을 시작함 |
| `add_payment_info` | 게스트가 결제 정보를 입력함 |
| `add_shipping_info` | 게스트가 고객 정보를 입력함 |
| `purchase` | 게스트가 예약을 완료함 |
| `refund` | 예약이 취소되고 환불됨 |

모든 이벤트에는 수익, 통화, 객실 유형, 예약 금액 등 관련 차원이 포함되어 있어 첫 인상부터 완료된 예약까지 고객 여정을 완벽하게 파악할 수 있습니다. `city_name`, `cancellation_policy`, `bed_type` 등 추가 숙소 및 객실 수준 차원을 활성화하려면 [GA4의 맞춤 차원](/ko/guides/general/gtm-integration#custom-dimensions-in-ga4)을 참조하세요.

## 교차 도메인 추적 (고급)

위의 표준 통합은 Wink 내에서 발생하는 모든 것을 추적합니다. 그러나 자신의 웹사이트에서 Wink 예약 완료까지 고객 여정을 추적하고 원래 트래픽 출처(구글 광고, 이메일 캠페인, 유기적 검색 등)를 정확히 귀속하려면 양쪽에서 추가 설정이 필요합니다.

<Aside type="caution">
이 섹션은 귀하의 웹사이트에 GA4가 설치된 경우에만 해당합니다. 웹사이트에 GA4를 운영하지 않는다면 위의 표준 통합만으로 충분합니다.
</Aside>

### 왜 중요한가요

교차 도메인 추적이 없으면, 웹사이트를 먼저 방문한 후 Wink에서 예약한 게스트가 GA4에서 **직접 방문** 세션으로 나타나 이전 방문과 연결되지 않습니다. 예약으로 이어진 구글 광고 클릭, 이메일 캠페인, 유기적 검색 방문에 대한 크레딧이 부여되지 않습니다.

교차 도메인 추적을 구성하면 전체 고객 여정을 볼 수 있습니다:

```
google.com (유료 광고)
       ↓
귀하의 웹사이트 (게스트가 객실 탐색)
       ↓
wink.travel (게스트가 객실 선택 및 예약)
       ↓
구매가 원래 구글 광고 클릭에 정확히 귀속됨
```

### 귀하가 해야 할 일

GA4 속성에서 `wink.travel`을 외부 추천이 아닌 자신의 도메인 일부로 인식하도록 구성하세요. 이렇게 하면 GA4가 두 세션을 하나의 연속된 고객 여정으로 연결합니다.

<Steps>
1. GA4 관리자 → 데이터 스트림 → 해당 스트림 선택
2. 태그 설정 구성 → **도메인 구성**
3. `wink.travel`을 연결된 도메인으로 추가
4. 저장
</Steps>

### Wink가 해야 할 일

[Wink 지원](https://app.wink.travel)에 연락하여 귀하의 웹사이트 도메인(예: `yourhotel.com`)을 알려주세요. Wink가 Wink GA4 속성의 추천 제외 목록에 귀하의 도메인을 추가합니다. 이렇게 하면 귀하의 웹사이트가 추천 출처로 기록되지 않아 원래 귀속 정보가 덮어쓰여지거나 새 세션이 시작되는 것을 방지합니다.

<Aside type="tip">
대부분 숙소에는 위의 표준 통합만으로 충분하며 Wink에서 예약 및 수익을 즉시 확인할 수 있습니다. 교차 도메인 추적은 GA4 데이터를 충분히 이해하고 더 깊은 귀속 인사이트가 필요할 때 설정할 가치가 있는 고급 옵션입니다.
</Aside>
