이 페이지는 Wink에서 구독할 수 있는 모든 웹훅 이벤트를 나열합니다. 설정 방법은 [Webhook Integration Guide](/ko/developers/webhook-integration) 또는 [Webhooks 관리 페이지](/ko/portal/settings/webhooks)를 참조하세요.

## 구독 방법

1. 포털에서 **Applications > Webhooks**로 이동합니다.
2. 웹훅을 생성하고 수신할 이벤트를 선택하세요 — 또는 모든 이벤트를 수신하려면 목록을 비워두세요.
3. 이벤트가 발생할 때마다 Wink가 서명된 HTTP POST를 귀하의 엔드포인트로 전송합니다. 봉투, 헤더, 서명 검증 및 재시도에 대해서는 [Webhook Integration](/ko/developers/webhook-integration)을 참조하세요.

## 모든 이벤트 유형

이 표는 빌드 시 플랫폼의 이벤트 카탈로그에서 생성되므로 항상 API와 일치합니다.
전달된 것으로 표시된 이벤트 유형은 [Webhooks API](/ko/api/webhooks/)의 참조 페이지에 링크되어 있으며,
정확한 JSON 본문(`WebhookEnvelope`과 이벤트별 `object`), `Wink-*` 헤더 및
재시도 정책을 문서화합니다. 전달되지 않는 이벤트 유형은 내부적으로 존재하지만(결제, 원장, 채널 관리자
동기화 등) 현재 웹훅 구독자에게 전송되지 않습니다.

**수신자**는 이벤트를 받는 대상을 나타냅니다: `SUPPLIER` (호텔), `AFFILIATE` (호텔에 활성 판매 채널이 있는 리셀러), `AGENT` (예약을 한 여행사) 또는 `SELF` (이벤트 대상 관리 주체). 모든 수신자는 동일한 페이로드 형식을 받으며, 역할별 세부 정보는
페이로드의 `links.self` URL 뒤에 있습니다.

:::tip
개발 중에는 모든 이벤트를 구독하는 것부터 시작하세요. 시스템에 필요한 페이로드를 이해한 후에는 구독을 좁혀 노이즈를 줄이세요. **Applications > Webhooks**에서 테스트 이벤트를 보내거나 (`POST …/webhook/{id}/test`) 엔드포인트와 서명 검증을 확인한 후 라이브로 전환하세요.
:::
