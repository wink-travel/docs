[iam.wink.travel/my-account/apps](https://iam.wink.travel/my-account/apps)의 **Apps** 탭에서는 Wink 계정에 접근 권한을 부여한 모든 OAuth2 애플리케이션을 확인할 수 있으며, 해당 접근 권한을 취소할 수 있습니다.

## 앱이 여기에 표시되는 방법

Wink와 통합된 서드파티 도구(또는 Wink 자체 앱)에서 `Authorize`를 클릭하면 동의 절차가 권한 부여를 기록합니다. 이후 해당 앱은 승인한 범위 내에서 사용자를 대신해 동작할 수 있습니다.

## 접근 권한 검토하기

각 항목에는 다음이 표시됩니다:

- **앱 이름**과 간단한 설명
- 앱이 접근할 수 있는 **범위** (예: 재고 조회, 예약 관리)
- **마지막 사용 시점** — 앱이 가장 최근에 Wink API를 호출한 시간

## 앱 접근 권한 취소하기

각 항목 옆의 `Revoke`를 클릭하세요. 앱의 토큰이 즉시 무효화되며, 해당 앱이 사용자 계정에 대해 실행하는 백그라운드 작업은 401 오류로 실패하기 시작합니다.

:::tip
접근 권한 취소는 비파괴적입니다 — 언제든지 동의 절차를 다시 거쳐 앱을 재승인할 수 있습니다. 앱이 오작동할 때, 자격 증명을 교체할 때, 또는 더 이상 통합을 사용하지 않을 때 이 기능을 사용하세요.
:::

## 직접 개발한 OAuth 앱

OAuth 앱을 *생성*하려면(단순 승인만 하는 것이 아니라) 조직 계정 기능이 필요합니다 — [설정 → 애플리케이션](/ko/account/applications)을 참조하세요.
