Prin conectarea proprietății Google Analytics 4 la Wink, evenimentele de rezervare — de la vizualizările camerelor până la rezervările finalizate — sunt transmise automat către propriul tablou de bord GA4, alături de analizele proprii Wink. Fără cod, fără configurare tehnică din partea ta.

<Aside type="tip">
Ai nevoie de două lucruri din GA4: un **ID de măsurare** și un **secret API pentru Measurement Protocol**. ID-ul de măsurare alimentează fluxul de navigare în browserul oaspetelui; secretul API permite Wink să înregistreze rezervările finalizate (`purchase`) **server-side**, astfel încât o vânzare să nu se piardă niciodată când oaspetele este redirecționat către și dinspre furnizorul de plată.
</Aside>

---

## Cum Funcționează

```
Introduci ID-ul de măsurare (G-XXXXXXXXXX) și secretul API în portalul Wink
       ↓
Evenimentele de navigare (vizualizări, coș, finalizare comandă) sunt transmise către proprietatea ta GA4 din browser
Rezervările finalizate (purchase) sunt trimise server-side — supraviețuind redirecționării de plată
       ↓
Te conectezi la analytics.google.com și vezi întregul flux de rezervare
```

---

## Ce Trebuie Să Faci

<Steps>

1. **Creează o Proprietate GA4**

   Accesează [analytics.google.com](https://analytics.google.com): Admin → Creează Proprietate. Setează fusul orar și moneda pentru a corespunde pieței tale.

2. **Creează un Flux de Date Web**

   Admin → Fluxuri de date → Adaugă flux → Web. Introdu `wink.travel` ca URL. Acest lucru generează **ID-ul de măsurare** (`G-XXXXXXXXXX`). Copiază-l.

3. **Creează un Secret API pentru Measurement Protocol**

   Deschide același Flux de Date Web → derulează la **Secrete API pentru Measurement Protocol** → **Creează**. Dă-i un nume (ex. "Wink") și copiază **valoarea secretă** generată. Acest secret permite Wink să înregistreze rezervările finalizate server-side, astfel încât o vânzare să nu se piardă în timpul redirecționării de plată.

4. **Introdu ID-ul de Măsurare și Secretul API în Portalul Wink**

   Conectează-te la [app.wink.travel](https://app.wink.travel), selectează contul tău și accesează fila **Personalizări**. Lipește ID-ul de măsurare și secretul API în câmpurile **GA4** și salvează. Gata — integrarea GA4 este acum activă.

   <Aside type="note">
   Secretul API este **doar pentru scriere**: odată salvat, nu mai este afișat. La editările viitoare, lasă câmpul secret gol pentru a păstra valoarea deja stocată.
   </Aside>

5. **Marchează `purchase` ca Eveniment Cheie**

   Înapoi în proprietatea ta GA4: Admin → Evenimente → găsește `purchase` → activează **Marchează ca eveniment cheie**. Astfel, rezervările finalizate vor apărea în raportul tău de Conversii.

6. **Vizualizează Datele Tale**

   Conectează-te la [analytics.google.com](https://analytics.google.com) și vei vedea rezervările, veniturile și fluxul oaspeților — toate urmărite automat prin Wink.

</Steps>

<Aside type="note">
Nu este nevoie să instalezi niciun cod de urmărire pe propriul site pentru această integrare. Wink se ocupă de tot. ID-ul tău de măsurare este destinația unde sunt trimise datele de rezervare, iar secretul API permite lui Wink să confirme rezervările finalizate server-side.
</Aside>

<Aside type="tip">
**GA4 și GTM pot fi folosite împreună.** Dacă folosești și un container Google Tag Manager (de exemplu un container Sojern), poți configura ambele simultan — nu mai sunt excluzive reciproc. Vezi [Integrarea GTM Analytics](/ro/guides/developers/gtm-dual-tagging).
</Aside>

## Ce Poți Urmări

Odată conectată, proprietatea ta GA4 primește întregul set de evenimente Enhanced E-commerce pentru proprietatea ta:

### Descoperire

| Eveniment | Ce Înseamnă |
|---|---|
| `view_item_list` | Un oaspete a văzut proprietatea ta într-o căutare sau listă de categorii |
| `select_item` | Un oaspete a făcut clic pe proprietatea ta dintr-o listă |
| `view_item` | Un oaspete a vizualizat pagina detaliată a hotelului tău |

### Considerare

| Eveniment | Ce Înseamnă |
|---|---|
| `view_promotion` | Un oaspete a văzut o ofertă promoțională pentru proprietatea ta |
| `select_promotion` | Un oaspete a făcut clic pe o ofertă promoțională |
| `add_to_wishlist` | Un oaspete a salvat proprietatea ta în lista de dorințe |

### Fluxul de Rezervare

| Eveniment | Ce Înseamnă |
|---|---|
| `add_to_cart` | Un oaspete a selectat o cameră sau un pachet |
| `view_cart` | Un oaspete a vizualizat sumarul rezervării |
| `remove_from_cart` | Un oaspete a eliminat o cameră sau un pachet |
| `begin_checkout` | Un oaspete a început procesul de finalizare comandă |
| `add_payment_info` | Un oaspete a introdus detaliile de plată |
| `add_shipping_info` | Un oaspete a introdus detaliile personale |
| `purchase` | Un oaspete a finalizat o rezervare |
| `refund` | O rezervare a fost anulată și rambursată |

Toate evenimentele includ dimensiuni relevante precum venituri, monedă, tip cameră și valoarea rezervării — oferindu-ți o imagine completă a parcursului oaspetelui de la prima impresie până la rezervarea finalizată. Pentru a debloca dimensiuni suplimentare la nivel de proprietate și cameră, cum ar fi `city_name`, `cancellation_policy`, `bed_type` și altele, vezi [Dimensiuni Personalizate în GA4](/ro/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4).

## Urmărirea Cross-Domain (Avansat)

Integrarea standard de mai sus urmărește tot ce se întâmplă în Wink. Totuși, dacă dorești să urmărești oaspeții de pe propriul site până la finalizarea rezervării pe Wink — și să atribui corect sursa originală de trafic (Google Ads, campanii email, căutare organică etc.) — este necesar un pas suplimentar pe fiecare parte.

<Aside type="caution">
Această secțiune se aplică doar dacă ai GA4 instalat pe propriul site. Dacă nu folosești GA4 pe site-ul tău, integrarea standard de mai sus este tot ce ai nevoie.
</Aside>

### De Ce Este Important

Fără urmărirea cross-domain, un oaspete care vizitează mai întâi site-ul tău și apoi face o rezervare pe Wink va apărea în GA4 ca o sesiune **Directă**, fără legătură cu vizita anterioară. Orice clicuri Google Ads, campanii email sau vizite din căutare organică care au condus la rezervare nu vor primi credit.

Cu urmărirea cross-domain configurată, vezi întregul parcurs al oaspetelui:

```
google.com (reclamă plătită)
       ↓
site-ul tău (oaspetelui îi navighează camerele)
       ↓
wink.travel (oaspetelui selectează camera și rezervă)
       ↓
purchase atribuit corect clicului original Google Ads
```

### Acțiune Necesara: Tu

Configurează proprietatea GA4 să recunoască `wink.travel` ca parte din propriul tău domeniu, nu ca o referință externă. Astfel GA4 va uni cele două sesiuni într-un singur parcurs continuu al oaspetelui.

<Steps>
1. GA4 Admin → Fluxuri de date → fluxul tău
2. Configurează setările tagului → **Configurează domeniile tale**
3. Adaugă `wink.travel` ca domeniu legat
4. Salvează
</Steps>

### Acțiune Necesara: Wink

Contactează [Wink Support](https://app.wink.travel) și furnizează domeniul site-ului tău (ex. `hotelultau.com`). Wink va adăuga domeniul tău pe lista de excludere a referințelor în proprietatea GA4 Wink. Astfel se previne înregistrarea site-ului tău ca sursă de referință, care altfel ar suprascrie atribuirea originală a oaspetelui și ar începe o sesiune nouă.

<Aside type="tip">
Integrarea standard de mai sus este suficientă pentru majoritatea proprietăților și îți oferă vizibilitate imediată asupra rezervărilor și veniturilor pe Wink. Urmărirea cross-domain este o opțiune avansată, recomandată după ce te familiarizezi cu datele GA4 și dorești o perspectivă mai profundă asupra atribuirii.
</Aside>
