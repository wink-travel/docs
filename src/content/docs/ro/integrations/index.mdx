Booking Engine se încorporează oriunde. Alege framework-ul sau CMS-ul tău și urmează ghidul său; componentele Web de bază sunt aceleași peste tot.

## Abordări principale

- [Web Components](/ro/integrations/web-components/) — elementele încorporabile pe care le folosește fiecare integrare.
- [npm package](/ro/integrations/npm/) — instalare într-un build JavaScript.
- [Headless CMS](/ro/integrations/headless/) — redare din orice backend de conținut.
- [Partner API](/ro/integrations/partner-api/) — integrare programatică completă.
