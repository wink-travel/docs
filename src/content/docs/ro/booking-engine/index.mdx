Motorul de rezervări este stratul de tranzacție de sub fiecare rută Wink: site-ul propriu al hotelului, linkuri partener și creator, descoperirea consumatorului și agenți AI. Plata este colectată în numele hotelului, ca agent al acestuia, astfel încât hotelul rămâne comerciantul înregistrat.

## Fluxul de rezervare

- [Căutare](/ro/booking-engine/search/) — găsește inventarul disponibil.
- [Detalii proprietate](/ro/booking-engine/property-detail/) — camere, tarife, politici și opțiuni suplimentare.
- [Checkout](/ro/booking-engine/checkout/) — un singur pas de plată cu brandul hotelului.
- [Confirmare rezervare](/ro/booking-engine/confirmation/) — ce primește oaspetele.

## Pentru călător

- [Rezervări](/ro/booking-engine/bookings/) — gestionează o rezervare existentă.
- [Lista de dorințe](/ro/booking-engine/bucket-list/) — salvează proprietăți pentru mai târziu.
- [Preferințe de călătorie](/ro/booking-engine/travel-preferences/) — personalizează rezultatele.
