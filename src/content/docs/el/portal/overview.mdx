[Portal](https://app.wink.travel) είναι η βάση σας. Ένας λογαριασμός, μία εφαρμογή και όλα όσα χρειάζεστε για να μετατρέψετε τα ταξίδια σε επιχείρηση — είτε αυτό σημαίνει να γεμίζετε δωμάτια, να χτίζετε κοινό, να συνδέεστε με channel manager ή απλώς να αφήνετε έναν σύνδεσμο στο βιογραφικό σας.

## Τι σας επιτρέπει να κάνετε το Portal

- **Καταλύματα** — Καταχωρήστε τα δωμάτιά σας, ρυθμίστε τιμές και διαθεσιμότητα, συγχρονίστε τα ημερολόγιά σας και παρακολουθήστε τις κρατήσεις να έρχονται. Ξενοδοχεία, αλυσίδες, μάρκες, εταιρείες διαχείρισης — αυτό είναι το κέντρο ελέγχου σας.
- **Συνεργάτες** — Μετατρέψτε το κοινό σας σε εισόδημα. Προωθήστε το ταξιδιωτικό απόθεμα της Wink και κερδίστε προμήθεια για κάθε κράτηση, είτε είστε γενικός συνεργάτης, ταξιδιωτικός πράκτορας που κάνει κρατήσεις για πελάτες, δημιουργός περιεχομένου στα social media ή εταιρικός/ομαδικός λογαριασμός.
- **Ενσωματωτές** — Συνδεθείτε και συγχρονιστείτε. Channel managers, PMS και CRS providers συνδέονται μέσω του Portal για να διατηρούν τις τιμές και τη διαθεσιμότητα σε πραγματικό χρόνο, χωρίς χειροκίνητες ενημερώσεις.
- **Δημιουργοί περιεχομένου** — Δεν θέλετε λογαριασμό; Πάρτε μια δωρεάν σελίδα WinkLinks — μια vanity URL, οργανωμένους συνδέσμους και έναν χώρο για ό,τι θέλετε να μοιραστείτε.

Επιλέξτε το πεδίο σας παραπάνω και ξεκινήστε — το Portal αναπτύσσεται μαζί σας καθώς κάνετε περισσότερα.
