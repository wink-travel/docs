Οι Ειδοποιήσεις είναι μια παγκόσμια λειτουργία — δεν συνδέεται με καμία συγκεκριμένη ενότητα. Κάντε κλικ στο εικονίδιο του κουδουνιού στην πάνω δεξιά γωνία, δίπλα στις Ρυθμίσεις, για να ανοίξετε ένα πάνελ με κάθε ειδοποίηση από όλους τους λογαριασμούς που διαχειρίζεστε.

## Χρήση του πάνελ

- Μια ένδειξη στο κουδούνι δείχνει τον αριθμό των μη αναγνωσμένων σας (με ανώτατο όριο το `99+`).
- Εναλλάξτε μεταξύ `Μη αναγνωσμένα` και `Όλα` για να φιλτράρετε τη λίστα.
- Κάντε κλικ σε μια ειδοποίηση για να μεταβείτε απευθείας σε αυτό που αφορά.
- Απορρίψτε μεμονωμένες ειδοποιήσεις που δεν χρειάζεστε πλέον.

Όταν δεν έχετε καμία, το πάνελ εμφανίζει μια κενή κατάσταση αντί για λίστα.
