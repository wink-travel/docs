Οι εγγεγραμμένοι ταξιδιωτικοί πράκτορες χρησιμοποιούν την ίδια πύλη με όλους τους άλλους, στο [app.wink.travel](https://app.wink.travel), με λογαριασμό Travel Agent. Οι πράκτορες αναζητούν και κάνουν κρατήσεις εκ μέρους των πελατών τους και κερδίζουν προμήθεια για κάθε κράτηση. Για να δημιουργήσετε έναν, ακολουθήστε το [Ξεκινώντας ως Ταξιδιωτικό Πρακτορείο](/el/guides/travel-agents/getting-started/).

Τα πρακτορεία που έχουν εγκριθεί να συλλέγουν οι ίδιοι την πληρωμή λειτουργούν ως merchant of record και διαχειρίζονται την πληρωμή εκτός της πλατφόρμας Wink. Τα πρακτορεία με δικά τους συστήματα μπορούν να ενσωματωθούν μέσω του [Partner API](/el/integrations/partner-api/).

Οι ταξιδιωτικοί πράκτορες έχουν ένα υποσύνολο των ίδιων λειτουργιών της πύλης με το [Studio](/el/portal/studio/what-is-studio), οπότε δεν θα τις καλύψουμε ξανά εδώ.

## Αναζήτηση

Μεταβείτε στο [Search](/el/portal/studio/search) για να μάθετε πώς να αναζητάτε και να κάνετε κρατήσεις ξενοδοχείων.

Αλλιώς, συνεχίστε στο επόμενο τμήμα.

## API

Τα πρακτορεία μπορούν να αναζητούν και να κάνουν κρατήσεις μέσω του [Partner API](/el/partner-api/partner/), που αντικαθιστά τα παλαιότερα Travel Agent REST endpoints.
