Η σελίδα τιμολόγησης είναι όπου ενεργοποιείτε την πληρωμή ανά χρήση, αποφασίζετε σε ποιους από τους λογαριασμούς σας εφαρμόζεται και παρακολουθείτε τα έξοδά σας.

Δεν χρειάζεται να έρθετε εδώ για να ξεκινήσετε. Κάθε λογαριασμός λαμβάνει μια δωρεάν μηνιαία επιδότηση για τις μετρημένες λειτουργίες χωρίς να κάνετε τίποτα. Αυτή η σελίδα είναι μόνο για να ξεπεράσετε αυτή την επιδότηση. Δείτε [Τιμολόγηση](/el/getting-started/pricing) για το τι είναι δωρεάν, τι μετριέται και πόσο κοστίζει.

## Ενεργοποίηση πληρωμής ανά χρήση

Ενεργοποιήστε την πληρωμή ανά χρήση και επιλέξτε πώς θέλετε να εξοφλείτε το λογαριασμό σας:

- **Κάρτα** — χρεώνουμε αυτόματα την αποθηκευμένη κάρτα σας όταν εκδίδεται το τιμολόγιο.
- **Τιμολόγιο** — σας στέλνουμε τιμολόγιο και το πληρώνετε εσείς.

Μπορείτε να αλλάξετε μεταξύ των δύο οποιαδήποτε στιγμή.

:::note
Μόνο ο **ιδιοκτήτης** ενός λογαριασμού μπορεί να ενεργοποιήσει την πληρωμή ανά χρήση για αυτόν. Η διαχειριστική πρόσβαση σε λογαριασμό άλλου δεν αρκεί, γιατί το τιμολόγιο πηγαίνει στον ιδιοκτήτη — δεν θα επιτρέψουμε σε κανέναν άλλον να χρεώσει την κάρτα σας.
:::

## Επιλογή λογαριασμών

Αν έχετε περισσότερους από έναν λογαριασμούς, επιλέγετε ξεχωριστά ποιοι θα είναι μετρημένοι. Ένας λογαριασμός που αφήνετε απενεργοποιημένος απλώς σταματά στην δωρεάν επιδότηση κάθε μήνα.

Η χρήση από κάθε ενεργοποιημένο λογαριασμό συγκεντρώνεται σε **ένα τιμολόγιο ανά μήνα**, ώστε να λαμβάνετε έναν μόνο λογαριασμό αντί για έναν ανά ακίνητο.

## Τρόπος πληρωμής

Προσθέστε μια κάρτα και θα την αποθηκεύσουμε με ασφάλεια στον πάροχο πληρωμών μας. Εμφανίζουμε μόνο το brand, τα τελευταία τέσσερα ψηφία και την ημερομηνία λήξης — η Wink δεν βλέπει ούτε αποθηκεύει ποτέ τον πλήρη αριθμό της κάρτας σας. Αν η τράπεζά σας εκδώσει νέα κάρτα αντικατάστασης, τα στοιχεία ενημερώνονται αυτόματα.

## Χρήση

Παρακολουθήστε τι έχετε χρησιμοποιήσει μέχρι στιγμής αυτόν τον μήνα, αναλυμένο ανά λειτουργία και ανά λογαριασμό, μαζί με τη δωρεάν επιδότηση για κάθε έναν. Αυτός είναι ο αριθμός που πρέπει να προσέχετε αν θέλετε να κρατήσετε τα έξοδά σας προβλέψιμα — ειδικά για το Social, ο μηνιαίος αριθμός αναρτήσεών σας είναι ουσιαστικά ο προϋπολογισμός σας.

Οι επιδοτήσεις μηδενίζονται την 1η κάθε μήνα.

## Τιμολόγια

Το ιστορικό τιμολογίων σας εμφανίζει τον αριθμό κάθε μήνα, την περίοδο χρέωσης, το ποσό, το νόμισμα και την κατάσταση, με συνδέσμους για να δείτε το τιμολόγιο online ή να το κατεβάσετε σε PDF.

## Κατάσταση τιμολόγησης

| Κατάσταση | Τι σημαίνει |
| -- | -- |
| Καλή κατάσταση | Όλα λειτουργούν κανονικά. |
| Εκκρεμεί πληρωμή | Μια προσπάθεια πληρωμής απέτυχε και επαναλαμβάνεται. Οι λειτουργίες σας συνεχίζουν να λειτουργούν όσο προσπαθούμε ξανά. |
| Αναστολή | Ένα τιμολόγιο έμεινε απλήρωτο μέχρι το τέλος. Οι μετρημένες λειτουργίες μπλοκάρονται μέχρι να εξοφληθεί — οι δωρεάν λειτουργίες συνεχίζονται κανονικά. |
