Το Extranet είναι η πλευρά του ακινήτου στο [Portal](/el/portal/overview), την ενιαία μας εφαρμογή στο [app.wink.travel](https://app.wink.travel). Απευθύνεται σε ξενοδοχεία, αλυσίδες, μάρκες και εταιρείες διαχείρισης ξενοδοχείων για να δημιουργήσουν και να διαχειριστούν το ψηφιακό προφίλ των ακινήτων τους στην πλατφόρμα Wink.

Δεν υπάρχει κάτι ξεχωριστό για εγγραφή και πουθενά αλλού για σύνδεση — επιλέξτε έναν λογαριασμό ακινήτου στο Portal και οι λειτουργίες του Extranet που περιγράφονται σε αυτήν την ενότητα είναι αμέσως διαθέσιμες.

Το Extranet έχει σχεδιαστεί με προσοχή ώστε να είναι όσο το δυνατόν πιο απλό, αλλά ταυτόχρονα να υποστηρίζει όλες τις λειτουργίες που οι προχωρημένοι χρήστες περιμένουν από μια προηγμένη πύλη ακινήτου. Για να σας δώσουμε μερικά παραδείγματα:

1. Απλότητα: Χρησιμοποιήστε τη έξυπνη ροή εισαγωγής μας για να εισάγετε το ακίνητό σας και να πάτε LIVE σε λιγότερο από μία ώρα.
2. Προχωρημένο: Το Wink υποστηρίζει 8500 διαφορετικές παραλλαγές πολιτικών ακύρωσης.
3. Κουλ: Δώστε σε ένα μόνο άτομο στον πλανήτη έκπτωση 10% χωρίς να χρειάζεται να συνδεθεί ή να πληκτρολογήσει κωδικό προσφοράς.

Αφήστε τους οδηγούς μας να σας καθοδηγήσουν σε όλη τη διαδικασία. Όταν νιώσετε αρκετά άνετα... προχωρήστε μόνοι σας.

Το Wink είναι ένα προηγμένο σύστημα διαχείρισης περιεχομένου για ακίνητα και παρόχους εμπειριών. Ό,τι μπορείτε να κάνετε στο Portal, μπορείτε να το κάνετε και μέσω API. Αυτό σας επιτρέπει να κάνετε μια βαθιά ενσωμάτωση με το Wink σε τέτοιο βαθμό ώστε να μπορείτε να πουλάτε μέσω Wink χωρίς ποτέ να χρειαστεί να συνδεθείτε.

:::tip[Επαγγελματική Συμβουλή]
Πληρώνετε για ακριβή φιλοξενία μέσων μέσω της Leonardo International; Μπορείτε να κάνετε ακριβώς το ίδιο μέσω του Wink ΚΑΙ έχετε πολλές περισσότερες επιλογές για να χειριστείτε και να βελτιστοποιήσετε τις εικόνες και τα βίντεό σας.
:::

Όλες αυτές οι λειτουργίες παρέχονται χωρίς κόστος για εσάς. Μόνο όταν κάνετε μια κράτηση παίρνουμε μια μικρή προμήθεια. Δεν έχετε τίποτα να χάσετε - Τα πάντα να κερδίσετε.
