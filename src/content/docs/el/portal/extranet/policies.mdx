Θα σας ζητηθεί να ολοκληρώσετε τις πολιτικές της ιδιοκτησίας σας κατά τη ρύθμιση.

Για να διαχειριστείτε τις πολιτικές της ιδιοκτησίας σας, κάντε κλικ στο `Property > Property Policy` στην κύρια καρτέλα πλοήγησης.

Ενημερώστε τους επισκέπτες σας για:

- Ώρες check-in/check-out.
- Αν επιτρέπονται κατοικίδια και παιδιά στον χώρο.
- Αν προσφέρετε ίντερνετ και χώρο στάθμευσης στον χώρο.

Ενημερώστε τη φόρμα και κάντε κλικ στο κουμπί `Save` για να συνεχίσετε.
