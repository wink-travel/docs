Ο πράσινος δείκτης σας μετράται με βάση τον αντίκτυπο που έχει το κατάλυμά σας στο τοπικό περιβάλλον και στις αγοραστικές σας αποφάσεις.

Για να διαχειριστείτε το σκορ του Πράσινου Δείκτη, κάντε κλικ στο `Impact > Green Index` στην κύρια καρτέλα πλοήγησης.

Το ερωτηματολόγιο του Πράσινου Δείκτη παρουσιάζεται ως ένας οδηγός βήμα προς βήμα που σας καθοδηγεί σε κάθε κατηγορία μία προς μία. Ολοκληρώστε κάθε βήμα και κάντε κλικ στο `Next` για να προχωρήσετε στην επόμενη ενότητα.
