Οι παροχές της ιδιοκτησίας είναι υπηρεσίες και εγκαταστάσεις που είναι διαθέσιμες στην ιδιοκτησία σας.

Για να διαχειριστείτε τις παροχές της ιδιοκτησίας σας, κάντε κλικ στο `Property > Services` στην κύρια καρτέλα πλοήγησης.

Επιλέξτε όλα τα κουτιά που ισχύουν για την ιδιοκτησία σας.

Κάντε κλικ στο κουμπί `Save` για να συνεχίσετε.
