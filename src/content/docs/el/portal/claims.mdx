*Περίπου χρόνος ολοκλήρωσης: ~2 λεπτά*

Άλλα μέλη μπορούν επίσης να [καλέσουν το ακίνητό σας](/el/portal/studio/search) να ενταχθεί στο Wink. Θα λάβετε από εμάς μια πρόσκληση μέσω email με ένα αίτημα `lead` που μπορείτε να διεκδικήσετε και να χρησιμοποιήσετε για να ολοκληρώσετε τη δημιουργία του ακινήτου.

Για να δείτε τις τρέχουσες αιτήσεις σας στο Wink, ακολουθήστε τα παρακάτω βήματα:

<Steps>
 1. Συνδεθείτε στο [app.wink.travel](https://app.wink.travel).
 2. Κάντε κλικ στο `Claims` από το αριστερό μενού.
 3. Θα δείτε μια λίστα με όλες τις τρέχουσες αιτήσεις.
 4. Επιλέξτε την αίτηση που θέλετε να επεξεργαστείτε και συμπληρώστε τα ελλιπή πεδία της φόρμας για να δημιουργήσετε τον λογαριασμό σας.
</Steps>
