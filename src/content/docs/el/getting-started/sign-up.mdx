Πριν από οτιδήποτε, πρέπει να δημιουργήσετε έναν λογαριασμό χρήστη στο Wink.

<Aside type="note" title="Κάνετε κράτηση για ταξίδι;">
Αυτός ο οδηγός απευθύνεται σε επαγγελματίες που θέλουν να συνεργαστούν με το ταξιδιωτικό απόθεμα του Wink — ξενοδόχους, ταξιδιωτικούς πράκτορες, συνεργάτες και άλλους εταίρους που διαχειρίζονται κρατήσεις, καταλύματα και διανομή. Αν είστε ταξιδιώτης, δεν χρειάζεστε λογαριασμό εκ των προτέρων: θα δημιουργήσετε έναν κατά τη διαδικασία ολοκλήρωσης της κράτησης.
</Aside>

Ακολουθήστε αυτά τα βήματα:

<Steps>
1. Μεταβείτε στο [app.wink.travel](https://app.wink.travel)
2. Κάντε κλικ στο `Sign-In / Register` στην πάνω δεξιά γωνία
3. Θα μεταφερθείτε σε μια φόρμα σύνδεσης. Κάντε κλικ στον σύνδεσμο `Register` κάτω από τα πεδία της φόρμας.
4. Συμπληρώστε τη φόρμα εγγραφής και κάντε κλικ στο `Register`. Θα ανακατευθυνθείτε στη σελίδα σύνδεσης.
5. Μετά τη σύνδεση, θα ανακατευθυνθείτε στο [Portal](/el/portal/create-account) όπου μπορείτε να δημιουργήσετε τον πρώτο σας λογαριασμό.
</Steps>

Η δημιουργία λογαριασμού χρήστη στο Wink σας δίνει πρόσβαση σε όλες τις λειτουργίες της πλατφόρμας. Μπορείτε να δημιουργήσετε απεριόριστα καταλύματα και λογαριασμούς συνεργατών.
