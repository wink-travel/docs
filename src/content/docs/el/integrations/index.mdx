Το Booking Engine ενσωματώνεται οπουδήποτε. Επιλέξτε το framework ή CMS σας και ακολουθήστε τον οδηγό του· τα υποκείμενα Web Components είναι τα ίδια παντού.

## Βασικές προσεγγίσεις

- [Web Components](/el/integrations/web-components/) — τα ενσωματώσιμα στοιχεία που χρησιμοποιεί κάθε ενσωμάτωση.
- [npm package](/el/integrations/npm/) — εγκατάσταση σε ένα JavaScript build.
- [Headless CMS](/el/integrations/headless/) — απόδοση από οποιοδήποτε backend περιεχομένου.
- [Partner API](/el/integrations/partner-api/) — πλήρης προγραμματιστική ενσωμάτωση.
