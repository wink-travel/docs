Το Wink **Partner API** είναι ο αυθεντικοποιημένος, υψηλότερης απόδοσης τρόπος για τους ενσωματωτές να ερωτούν διαθέσιμο ταξιδιωτικό απόθεμα — την ίδια προσφορά που τροφοδοτεί τα ενσωματώσιμα widgets και τα δημόσια endpoints περιήγησης, εκτεθειμένη ως μια πρωτοκλασάτη προγραμματιστική διεπαφή. Ενώ τα δωρεάν Web Components και τα δημόσια endpoints περιήγησης προορίζονται για ελαφριά, ανθρώπινη ενσωμάτωση, το Partner API είναι σχεδιασμένο για συστήματα που αναζητούν, τιμολογούν και κάνουν κρατήσεις σε μεγάλη κλίμακα. Η πρόσβαση είναι αυθεντικοποιημένη ανά ενσωματωτή και χρεώνεται ανά χρήση, οπότε πληρώνετε μόνο για την κίνηση που πραγματικά στέλνετε.

## Σχέδια & τιμολόγηση

Μία κλήση API = ένα αίτημα. Η μετρημένη χρήση χρεώνεται ανά 1.000 αιτήματα.

| | Δωρεάν | Επί πληρωμή | Επιχειρηματικό |
|---|---|---|---|
| **Τιμή** | 0 $ | Με βάση τη χρήση | Επικοινωνήστε μαζί μας |
| **Καλύτερο για** | Αξιολόγηση & ενσωματώσεις χαμηλού όγκου | Πληρωμή ανά χρήση σε μεγάλη κλίμακα | Προσαρμοσμένος όγκος & διαπραγματευμένοι όροι |
| Αιτήματα ανά λεπτό | 30 (έκρηξη 60) | Απεριόριστα | Απεριόριστα |
| Αιτήματα ανά μήνα | 10.000 | Απεριόριστα | Απεριόριστα |
| Χρόνος απόκρισης API (P95) | — | Κάτω από 500 ms | Κάτω από 500 ms |
| Τιμή ανά 1.000 αιτήματα | Δωρεάν | 1,00 $ | Προσαρμοσμένη |
| Υπέρβαση look-to-book (ανά 1.000 επιπλέον αναζητήσεις πέραν του 5.000:1) | — | 2,00 $ | Προσαρμοσμένη |
| Απόκριση ορίου ρυθμού | 429 (παύση / μηνιαία οριστική διακοπή) | Καμία | Καμία |
| Συμφωνία Επιπέδου Υπηρεσίας | — | ✓ | ✓ |
| Προτεραιότητα υποστήριξης | — | ✓ | ✓ |
| Αφιερωμένη εισαγωγή | — | — | ✓ |

[Αποκτήστε ένα κλειδί API](https://app.wink.travel/account/applications) · [Ξεκινήστε τη μετρημένη χρέωση](https://app.wink.travel/account/applications) · [Επικοινωνήστε με τις πωλήσεις](https://cal.com/wink-ws36dy)

## Αναφορά API

Δύο επιφάνειες OpenAPI εξυπηρετούν διαθέσιμο απόθεμα, και αντιστοιχούν στα δύο παραπάνω επίπεδα:

- **Δωρεάν — Consumer / Booking Engine API** (`/api/public/**`): ανώνυμο, προσανατολισμένο σε browser και widget. [Περιηγηθείτε στην αναφορά Booking Engine →](/el/api/booking-engine/)
- **Επί πληρωμή — Partner Integrator API** (`/api/partner/**`): αυθεντικοποιημένο, μετρημένης χρήσης, σχεδιασμένο για ενσωμάτωση server-to-server σε μεγάλη κλίμακα. [Περιηγηθείτε στην αναφορά Integrator →](/el/integrations-api/integrator/)

## Πώς λειτουργεί η χρήση και τα όρια

### Δωρεάν επίπεδο

Το Δωρεάν επίπεδο έχει σχεδιαστεί για να σας επιτρέπει να δημιουργείτε, να δοκιμάζετε και να εκτελείτε μέτρια παραγωγική κίνηση χωρίς κόστος.

- **Όριο ρυθμού — 30 αιτήματα ανά λεπτό, με έκρηξη 60 αιτημάτων.** Οι σύντομες αιχμές πάνω από τον διατηρούμενο ρυθμό απορροφώνται από το όριο έκρηξης. Αν το υπερβείτε, το API απαντά με **HTTP 429 (Πολύ Πολλά Αιτήματα)** και εφαρμόζει **παύση 5 λεπτών** πριν το κλειδί σας συνεχίσει να εξυπηρετεί κίνηση. Απομακρυνθείτε και δοκιμάστε ξανά μετά την παύση αντί να κατακλύζετε το endpoint.
- **Μηνιαίο όριο — 10.000 αιτήματα ανά ημερολογιακό μήνα.** Μόλις φτάσετε το μηνιαίο όριο, το API επιστρέφει **HTTP 429 για το υπόλοιπο του μήνα** — οριστική διακοπή — μαζί με μήνυμα που σας προσκαλεί να εγγραφείτε στο Επί πληρωμή επίπεδο για να συνεχίσετε. Ο μετρητής μηδενίζεται στην αρχή του επόμενου μήνα.

Το Δωρεάν επίπεδο δεν περιλαμβάνει Συμφωνία Επιπέδου Υπηρεσίας ή προτεραιότητα υποστήριξης.

### Επί πληρωμή επίπεδο

Το Επί πληρωμή επίπεδο αφαιρεί το μηνιαίο όριο και τις παύσεις ορίου ρυθμού, και σας χρεώνει μόνο για ό,τι χρησιμοποιείτε.

- **Μετρημένα αιτήματα — 1,00 $ ανά 1.000 αιτήματα.** Δεν υπάρχει μηνιακό όριο αιτημάτων και δεν υπάρχει περιορισμός ρυθμού υπό κανονική χρήση· χρεώνεστε με βάση τον πραγματικό όγκο.
- **Υπέρβαση look-to-book — 2,00 $ ανά 1.000 επιπλέον αναζητήσεις.** Για να διατηρήσουμε υγιή την προσφορά, μετράμε την αναλογία αναζητήσεων ("looks") προς επιβεβαιωμένες κρατήσεις. Δικαιούστε **5.000 αναζητήσεις ανά κράτηση** πριν εφαρμοστεί υπέρβαση. Οι επιπλέον αναζητήσεις υπολογίζονται ως:

  `excess = max(0, looks − bookings × 5,000)`

  Η υπέρβαση χρεώνεται στη συνέχεια με **2,00 $ ανά 1.000 επιπλέον αναζητήσεις**. Οι ενσωματώσεις που μετατρέπουν καλά σπάνια επιβαρύνονται με υπέρβαση· η χρέωση ισχύει μόνο για κίνηση που αναζητά πολύ περισσότερο από ό,τι κάνει κρατήσεις.

Το Επί πληρωμή επίπεδο περιλαμβάνει τη Συμφωνία Επιπέδου Υπηρεσίας που περιγράφεται παρακάτω — δέσμευση 99,9% χρόνου λειτουργίας και στόχο χρόνου απόκρισης P95 κάτω από 500 ms — και προτεραιότητα υποστήριξης με βάση τη σοβαρότητα.

## Συμφωνία Επιπέδου Υπηρεσίας

_Ημερομηνία ισχύος: 5 Ιουλίου 2026 · Έκδοση 1.0_

Αυτή η Συμφωνία Επιπέδου Υπηρεσίας (η "SLA") καθορίζει τη δέσμευση διαθεσιμότητας, τις πιστώσεις υπηρεσίας και τους στόχους υποστήριξης που παρέχει η Wink ("Wink", "εμείς") σε έναν πελάτη ("Πελάτης", "εσείς") για το αυθεντικοποιημένο Wink Partner API (το "Partner API" ή "Υπηρεσία") σε επίπεδα όπου αναφέρεται ότι ισχύει SLA. Αυτή η SLA ενσωματώνεται και διέπεται από τη συμφωνία μεταξύ σας και της Wink με βάση την οποία έχετε πρόσβαση στο Partner API (η "Συμφωνία"), και ισχύει όσο διατηρείτε ενεργή, επί πληρωμή συνδρομή Partner API σε καλή κατάσταση. Οι κεφαλαιοποιημένοι όροι που δεν ορίζονται εδώ έχουν την έννοια που τους αποδίδεται στη Συμφωνία.

### 1. Ορισμοί

1. **"Χρόνος λειτουργίας"** σημαίνει τις περιόδους κατά τις οποίες το Partner API είναι διαθέσιμο να δεχτεί και να απαντήσει επιτυχώς σε σωστά διαμορφωμένα, αυθεντικοποιημένα αιτήματα.
2. **"Χρόνος διακοπής"** σημαίνει οποιαδήποτε περίοδος, μετρημένη σε λεπτά, κατά την οποία το Partner API αποτυγχάνει να απαντήσει επιτυχώς σε σωστά διαμορφωμένα, αυθεντικοποιημένα αιτήματα, εξαιρουμένων των περιόδων που εμπίπτουν στις Εξαιρέσεις που ορίζονται στην Ενότητα 4. Απομονωμένα σφάλματα που επηρεάζουν ένα ασήμαντο ποσοστό αιτημάτων δεν θεωρούνται από μόνα τους Χρόνος διακοπής.
3. **"Μηνιαίο Ποσοστό Χρόνου Λειτουργίας"** σημαίνει, για έναν δεδομένο ημερολογιακό μήνα, το συνολικό πλήθος λεπτών του μήνα μείον τα συνολικά λεπτά Χρόνου διακοπής, διαιρεμένο με το συνολικό πλήθος λεπτών του μήνα, εκφρασμένο ως ποσοστό.
4. **"Προγραμματισμένη Συντήρηση"** σημαίνει προγραμματισμένη συντήρηση της Υπηρεσίας για την οποία η Wink έχει παράσχει προηγούμενη ειδοποίηση σύμφωνα με την Ενότητα 4.
5. **"Πίστωση Υπηρεσίας"** σημαίνει πίστωση, υπολογιζόμενη ως ποσοστό των τελών που έχετε πληρώσει ή οφείλετε για το Partner API στον επηρεαζόμενο ημερολογιακό μήνα, που εφαρμόζεται έναντι μελλοντικών τελών Partner API ως η αποκλειστική και μόνη αποζημίωση για αποτυχία εκπλήρωσης της Δέσμευσης Χρόνου Λειτουργίας.
6. **"Χρόνος Απόκρισης"** σημαίνει τον χρόνο που μεσολαβεί από τη λήψη από τη Wink ενός σωστά διαμορφωμένου, αυθεντικοποιημένου αιτήματος στα όρια υπηρεσίας της Wink μέχρι το σημείο που η Wink αρχίζει να επιστρέφει την απόκριση, εξαιρουμένων των χρόνων δικτύου και οποιουδήποτε χρόνου στην πλευρά του πελάτη εκτός ελέγχου της Wink.

### 2. Δέσμευση Διαθεσιμότητας & Απόδοσης

Η Wink θα καταβάλει εμπορικά εύλογες προσπάθειες να κάνει το Partner API διαθέσιμο με **Μηνιαίο Ποσοστό Χρόνου Λειτουργίας τουλάχιστον 99,9%** κατά τη διάρκεια κάθε ημερολογιακού μήνα της διάρκειας (η "Δέσμευση Χρόνου Λειτουργίας"). Η Δέσμευση Χρόνου Λειτουργίας μετράται στα όρια υπηρεσίας της Wink και εξαιρεί παράγοντες εκτός εύλογου ελέγχου της Wink, συμπεριλαμβανομένων αυτών που περιγράφονται στην Ενότητα 4. Τα συστήματα παρακολούθησης της Wink είναι η επίσημη πηγή μέτρησης του Μηνιαίου Ποσοστού Χρόνου Λειτουργίας και του Χρόνου Απόκρισης.

Επιπλέον, η Wink στοχεύει σε **χρόνο απόκρισης 95ου εκατοστημορίου (P95) κάτω από 500 χιλιοστά του δευτερολέπτου** για επιτυχημένα, σωστά διαμορφωμένα, αυθεντικοποιημένα αιτήματα, μετρημένο στα όρια υπηρεσίας της Wink σε κάθε ημερολογιακό μήνα (ο "Στόχος Απόδοσης"). Ο Στόχος Απόδοσης εξαιρεί τους παράγοντες της Ενότητας 4, αιτήματα που επιστρέφουν σφάλματα επιπέδου εφαρμογής που προκαλούνται από το ίδιο το αίτημα, και ασυνήθιστα μεγάλα ή πολύπλοκα πακέτα αιτημάτων. Ο Στόχος Απόδοσης είναι στόχος υπηρεσίας· οι Πιστώσεις Υπηρεσίας στην Ενότητα 3 εφαρμόζονται σε αποτυχίες εκπλήρωσης της **Δέσμευσης Χρόνου Λειτουργίας** και είναι η αποκλειστική και μόνη αποζημίωση για ελλείψεις διαθεσιμότητας.

### 3. Πιστώσεις Υπηρεσίας

Εάν το Μηνιαίο Ποσοστό Χρόνου Λειτουργίας πέσει κάτω από τη Δέσμευση Χρόνου Λειτουργίας σε οποιονδήποτε ημερολογιακό μήνα, μπορεί να δικαιούστε Πίστωση Υπηρεσίας υπολογιζόμενη ως ποσοστό των τελών Partner API που έχετε πληρώσει ή οφείλετε για εκείνον τον μήνα, σύμφωνα με την παρακάτω κλίμακα:

| Μηνιαίο Ποσοστό Χρόνου Λειτουργίας | Πίστωση Υπηρεσίας |
|---|---|
| Κάτω από 99,9% αλλά ίσο ή πάνω από 99,0% | 10% |
| Κάτω από 99,0% αλλά ίσο ή πάνω από 95,0% | 25% |
| Κάτω από 95,0% | 50% |

1. **Αίτηση πίστωσης.** Για να λάβετε Πίστωση Υπηρεσίας πρέπει να υποβάλετε γραπτό αίτημα στη Wink εντός **τριάντα (30) ημερών** από το τέλος του ημερολογιακού μήνα κατά τον οποίο συνέβη η ελλειμματικότητα. Το αίτημα πρέπει να περιλαμβάνει τις ημερομηνίες και ώρες κάθε περιστατικού Χρόνου διακοπής που διεκδικείτε και τυχόν υποστηρικτικά αρχεία ή αποδείξεις που είναι εύλογα διαθέσιμες σε εσάς. Αιτήματα που υποβάλλονται μετά το διάστημα αυτό δεν είναι επιλέξιμα.
2. **Μορφή πίστωσης.** Οι εγκεκριμένες Πιστώσεις Υπηρεσίας εφαρμόζονται έναντι μελλοντικών τελών Partner API και δεν έχουν χρηματική αξία. Δεν είναι επιστροφές χρημάτων και δεν θα καταβληθούν εκτός αν απαιτείται από την ισχύουσα νομοθεσία.
3. **Μέγιστη πίστωση.** Το συνολικό ποσό Πιστώσεων Υπηρεσίας που απονέμεται για οποιονδήποτε ημερολογιακό μήνα δεν θα υπερβαίνει το 50% των τελών Partner API που έχετε πληρώσει ή οφείλετε για εκείνον τον μήνα.
4. **Αποκλειστική αποζημίωση.** Οι Πιστώσεις Υπηρεσίας είναι η **αποκλειστική και μόνη αποζημίωση** για οποιαδήποτε αποτυχία της Wink να εκπληρώσει τη Δέσμευση Χρόνου Λειτουργίας ή οποιαδήποτε άλλη έλλειψη διαθεσιμότητας του Partner API.

### 4. Εξαιρέσεις

Η Δέσμευση Χρόνου Λειτουργίας και τυχόν Πιστώσεις Υπηρεσίας δεν ισχύουν, και ο Χρόνος διακοπής δεν περιλαμβάνει, οποιαδήποτε μη διαθεσιμότητα, αναστολή, υποβάθμιση ή πρόβλημα απόδοσης που προκύπτει από ή σχετίζεται με:

1. **Προγραμματισμένη Συντήρηση** για την οποία η Wink έχει δώσει προηγούμενη ειδοποίηση, εφόσον η ειδοποίηση δίνεται με εύλογο χρονικό διάστημα εκ των προτέρων μέσω καναλιού που η Wink χρησιμοποιεί κανονικά για επικοινωνία με πελάτες·
2. **Γεγονότα ανωτέρας βίας** ή άλλες αιτίες πέραν του εύλογου ελέγχου της Wink, συμπεριλαμβανομένων φυσικών καταστροφών, κυβερνητικών ενεργειών, διακοπών δικτύου ή υπηρεσιών κοινής ωφέλειας, και επιθέσεων άρνησης υπηρεσίας ή άλλων κακόβουλων ενεργειών·
3. ζητήματα που προκαλούνται από τις **ενέργειες ή παραλείψεις σας**, τον εξοπλισμό, το λογισμικό ή το δίκτυό σας, ή από οποιαδήποτε **υπηρεσία, προϊόν ή πάροχο τρίτου μέρους** που δεν βρίσκεται υπό άμεσο έλεγχο της Wink·
4. την **κακή χρήση της Υπηρεσίας** ή **παραβίαση της Συμφωνίας**, αυτής της SLA, των όρων αποδεκτής χρήσης ή των ισχυόντων ορίων ρυθμού, συμπεριλαμβανομένης της κίνησης που η Wink λογικά θεωρεί υπερβολική, αυτοματοποιημένη κατάχρηση ή απάτη· και
5. οποιαδήποτε **αναστολή ή τερματισμό** της πρόσβασής σας που πραγματοποιείται σωστά βάσει της Συμφωνίας, συμπεριλαμβανομένης της αναστολής για μη πληρωμή.

### 5. Υποστήριξη & Στόχοι Απόκρισης

Η Wink παρέχει υποστήριξη για το Partner API κατά τις κανονικές εργάσιμες ώρες, εξαιρουμένων των τοπικών αργιών. Η Wink θα καταβάλει εμπορικά εύλογες προσπάθειες να αναγνωρίσει σωστά υποβλημένα αιτήματα υποστήριξης εντός των ακόλουθων στόχων χρόνου απόκρισης, βάσει της σοβαρότητας που αναθέτετε και που η Wink λογικά επιβεβαιώνει:

| Σοβαρότητα | Περιγραφή | Στόχος αρχικής απόκρισης |
|---|---|---|
| **Sev 1 — Κρίσιμη** | Το Partner API είναι εκτός λειτουργίας ή μη χρησιμοποιήσιμο σε παραγωγή χωρίς λύση παράκαμψης. | 4 ώρες |
| **Sev 2 — Σημαντική** | Σημαντική λειτουργία υποβαθμισμένη ή περιορισμένη· υπάρχει λύση παράκαμψης. | 1 εργάσιμη ημέρα |
| **Sev 3 — Μικρή** | Γενικές ερωτήσεις, μικρά ζητήματα ή αιτήματα λειτουργιών. | 2 εργάσιμες ημέρες |

Οι στόχοι χρόνου απόκρισης περιγράφουν πότε η Wink στοχεύει να κάνει **αρχική επαφή**· δεν είναι εγγυήσεις χρόνου επίλυσης. Η προτεραιότητα υποστήριξης και οι στόχοι βάσει σοβαρότητας ισχύουν στα επίπεδα όπου αναφέρεται ότι περιλαμβάνονται.

### 6. Δεδομένα & Ασφάλεια

Η Wink διατηρεί εμπορικά εύλογα διοικητικά, τεχνικά και οργανωτικά μέτρα σχεδιασμένα να προστατεύουν την εμπιστευτικότητα, ακεραιότητα και διαθεσιμότητα των δεδομένων που επεξεργάζονται μέσω του Partner API, και αναθεωρεί αυτά τα μέτρα περιοδικά. Η επεξεργασία προσωπικών δεδομένων από τη Wink διέπεται από την [Πολιτική Απορρήτου](/el/privacy) και τυχόν όρους επεξεργασίας δεδομένων στη Συμφωνία. Παραμένετε υπεύθυνοι για την ασφάλεια των δικών σας διαπιστευτηρίων API, για τη νόμιμη χρήση οποιωνδήποτε δεδομένων ανακτάτε, και για την άμεση ενημέρωση της Wink για οποιαδήποτε υποψία παραβίασης διαπιστευτηρίων.

### 7. Περιορισμός Ευθύνης

Οι Πιστώσεις Υπηρεσίας είναι η **αποκλειστική και μόνη αποζημίωση** για οποιαδήποτε μη διαθεσιμότητα ή αποτυχία εκπλήρωσης της Δέσμευσης Χρόνου Λειτουργίας, και παρέχονται αντί οποιασδήποτε άλλης ευθύνης που προκύπτει από τέτοια αποτυχία. Εκτός αν ρητά αναφέρεται σε αυτή τη SLA, το Partner API παρέχεται "ως έχει". Στο μέγιστο βαθμό που επιτρέπεται από το ισχύον δίκαιο, η συνολική ευθύνη της Wink που προκύπτει από ή σχετίζεται με την Υπηρεσία περιορίζεται όπως ορίζεται στη Συμφωνία, και η Wink δεν ευθύνεται για έμμεσα, τυχαία, ειδικά, επακόλουθα ή ποινικά ζημίες, ή για απώλεια κερδών, εσόδων, δεδομένων ή φήμης, ακόμη και αν έχει ενημερωθεί για την πιθανότητα τέτοιων ζημιών.

### 8. Διάρκεια, Αλλαγές & Τερματισμός

Αυτή η SLA ισχύει όσο έχετε ενεργή συνδρομή Partner API σε επίπεδο όπου αναφέρεται ότι ισχύει SLA. Η Wink μπορεί να ενημερώνει αυτή τη SLA περιοδικά· σημαντικές αλλαγές θα κοινοποιούνται μέσω καναλιού που η Wink χρησιμοποιεί κανονικά για επικοινωνία με πελάτες, και η συνεχιζόμενη χρήση του Partner API μετά την εφαρμογή ενημέρωσης συνιστά αποδοχή της ενημερωμένης SLA. Αυτή η SLA τερματίζεται αυτόματα με τον τερματισμό ή τη λήξη της Συμφωνίας ή της συνδρομής σας στο Partner API.
