Το Wink **Partner API** είναι ο αυθεντικοποιημένος, υψηλότερης απόδοσης τρόπος για τους ενσωματωτές να ερωτούν διαθέσιμο ταξιδιωτικό απόθεμα προς κράτηση — την ίδια προσφορά που τροφοδοτεί τα ενσωματώσιμα widgets μας και τα δημόσια endpoints περιήγησης, εκτεθειμένη ως μια πρωτοκλασάτη προγραμματιστική διεπαφή. Ενώ τα δωρεάν Web Components και τα δημόσια endpoints περιήγησης προορίζονται για ελαφριά, ανθρώπινη ενσωμάτωση, το Partner API είναι σχεδιασμένο για συστήματα που αναζητούν, τιμολογούν και κάνουν κρατήσεις σε μεγάλη κλίμακα. Η πρόσβαση αυθεντικοποιείται ανά ενσωματωτή και χρεώνεται ανά χρήση, οπότε πληρώνετε μόνο για την κίνηση που πραγματικά στέλνετε.

## Σχέδια & τιμολόγηση

Η χρήση μετριέται σε **διανυκτερεύσεις ξενοδοχείου**: ένα ξενοδοχείο τιμολογημένο για μία νύχτα διαμονής — *όχι* μία κλήση API. Μια αναζήτηση που επιστρέφει 20 ξενοδοχεία για 3 νύχτες είναι 60 διανυκτερεύσεις ξενοδοχείου από ένα μόνο αίτημα. Οι κλήσεις Περιεχομένου και Αναζήτησης (αναζήτηση προορισμού και αυτόματη συμπλήρωση) αποτελούν εξαίρεση: κάθε μία κοστίζει μία μονάδα ανά κλήση, ό,τι και αν επιστρέφει. Τα endpoints λογαριασμού είναι δωρεάν. Η [Τιμολόγηση](/el/pricing/) είναι η πηγή αλήθειας για την τιμή.

| | Δωρεάν | Επί πληρωμή | Επιχειρησιακό |
|---|---|---|---|
| **Τιμή** | 0 $ | Με βάση τη χρήση | Επικοινωνήστε μαζί μας |
| **Καλύτερο για** | Αξιολόγηση & ενσωματώσεις χαμηλού όγκου | Πληρωμή ανά χρήση σε μεγάλη κλίμακα | Προσαρμοσμένος όγκος & διαπραγματευμένοι όροι |
| Μονάδες ανά μήνα | 10.000 | Απεριόριστο | Απεριόριστο |
| Χρόνος απόκρισης API (P95) | — | Κάτω από 500 ms | Κάτω από 500 ms |
| Τιμή ανά μονάδα (διανυκτέρευση ξενοδοχείου) | Δωρεάν | 0,0001 $ | Προσαρμοσμένη |
| Απόκριση στο μηνιαίο όριο | 429 μέχρι την 1η του επόμενου μήνα (UTC) | Χρεώνεται, δεν μπλοκάρεται | Σύμφωνα με συμφωνία |
| Συμφωνία Επιπέδου Υπηρεσίας | — | ✓ | ✓ |
| Υποστήριξη προτεραιότητας | — | ✓ | ✓ |
| Αφιερωμένη εισαγωγή | — | — | ✓ |

[Αποκτήστε κλειδί API](https://app.wink.travel/account/applications) · [Ξεκινήστε χρέωση μετρημένης χρήσης](https://app.wink.travel/account/applications) · [Επικοινωνήστε με πωλήσεις](/el/demo/)

## Αναφορά API

Δύο επιφάνειες εξυπηρετούν το διαθέσιμο προς κράτηση απόθεμα, και αντιστοιχούν στα δύο παραπάνω επίπεδα:

- **Δωρεάν — Consumer / Booking Engine API** (REST, `/api/public/**`): ανώνυμο, προσανατολισμένο σε browser και widget. [Περιηγηθείτε στην αναφορά Booking Engine →](/el/api/booking-engine/)
- **Επί πληρωμή — Partner Integrator API** (**gRPC**, `wink.partner.v1`): αυθεντικοποιημένο, μετρημένης χρήσης, σχεδιασμένο για ενσωμάτωση server-to-server σε μεγάλη κλίμακα. [Περιηγηθείτε στην αναφορά Integrator →](/el/partner-api/partner/)

Το Partner Integrator API είναι gRPC, όχι REST. Το καλείτε με έναν παραγόμενο client μέσω HTTP/2 στο
`partner.wink.travel:443`, περνώντας ένα bearer token και τον λογαριασμό για τον οποίο καλείτε:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

Η παραπάνω σελίδα αναφοράς τεκμηριώνει κάθε υπηρεσία, μήνυμα και κατάσταση σφάλματος, και το σχήμα είναι επίσης
διαθέσιμο κατά το runtime μέσω server reflection, οπότε το `grpcurl`, Postman και Insomnia το ανακαλύπτουν χωρίς
να χρειάζεται να κατεβάσετε τίποτα.

Αν προτιμάτε να δημιουργήσετε client εκ των προτέρων, τα αρχεία πηγής `.proto` δημοσιεύονται στο
[github.com/wink-travel/partner-api-proto](https://github.com/wink-travel/partner-api-proto).

## Πώς λειτουργεί η χρήση και τα όρια

### Δωρεάν επίπεδο

Το Δωρεάν επίπεδο έχει σχεδιαστεί για να σας επιτρέπει να δημιουργείτε, να δοκιμάζετε και να λειτουργείτε με μέτρια παραγωγική κίνηση χωρίς κόστος.

- **Δεν υπάρχει δημοσιευμένο όριο ανά λεπτό.** Η Wink παρακολουθεί τα ποσοστά αιτημάτων και μπορεί να εφαρμόσει όρια δίκαιης χρήσης για την προστασία της υπηρεσίας. Αν λάβετε **HTTP 429 (Too Many Requests)**, περιμένετε τον αριθμό δευτερολέπτων που αναγράφεται στην κεφαλίδα `Retry-After` πριν ξαναδοκιμάσετε.
- **Μηνιαίο όριο — 10.000 μονάδες ανά ημερολογιακό μήνα.** Το όριο χορηγείται ανά λογαριασμό και επαναφέρεται την 1η κάθε μήνα (UTC). Μόλις το φτάσετε, ένας λογαριασμός που δεν έχει εγγραφεί στη χρέωση pay-as-you-go λαμβάνει **HTTP 429 μέχρι την 1η του επόμενου μήνα** — ένα σκληρό μπλοκάρισμα, με κεφαλίδα `Retry-After` και μήνυμα που σας προσκαλεί να εγγραφείτε στο Επί πληρωμή επίπεδο. Ένας εγγεγραμμένος λογαριασμός συνεχίζει να λειτουργεί και χρεώνεται για χρήση πέραν του ορίου.

Το Δωρεάν επίπεδο δεν περιλαμβάνει Συμφωνία Επιπέδου Υπηρεσίας ή υποστήριξη προτεραιότητας.

### Επί πληρωμή επίπεδο

Το Επί πληρωμή επίπεδο αφαιρεί το μηνιαίο όριο και σας χρεώνει μόνο για ό,τι χρησιμοποιείτε.

- **Μετρημένες διανυκτερεύσεις ξενοδοχείου — 0,0001 $ ανά διανυκτέρευση.** Δεν υπάρχει μηνιαίο όριο· χρεώνεστε με βάση τον πραγματικό όγκο. Η Wink μπορεί να εφαρμόσει όρια δίκαιης χρήσης για την προστασία της υπηρεσίας. Οι κλήσεις αναζήτησης και αποθέματος χρεώνονται ανά διανυκτέρευση τιμολογημένη· οι κλήσεις Περιεχομένου και Αναζήτησης χρεώνονται μία μονάδα η κάθε μία, οπότε η ομαδοποίηση των αιτημάτων σας κρατάει το κόστος χαμηλά.

Το Επί πληρωμή επίπεδο περιλαμβάνει τη Συμφωνία Επιπέδου Υπηρεσίας που περιγράφεται παρακάτω — δέσμευση διαθεσιμότητας 99,9% και στόχο χρόνου απόκρισης P95 κάτω από 500 ms — και υποστήριξη προτεραιότητας με βάση τη σοβαρότητα.

## Συμφωνία Επιπέδου Υπηρεσίας

_Ημερομηνία ισχύος: 5 Ιουλίου 2026 · Έκδοση 1.0_

Αυτή η Συμφωνία Επιπέδου Υπηρεσίας (η "SLA") καθορίζει τη δέσμευση διαθεσιμότητας, τις πιστώσεις υπηρεσίας και τους στόχους υποστήριξης που παρέχει η Wink ("Wink", "εμείς") σε έναν πελάτη ("Πελάτης", "εσείς") για το αυθεντικοποιημένο Wink Partner API (το "Partner API" ή "Υπηρεσία") σε επίπεδα όπου αναφέρεται ότι ισχύει SLA. Αυτή η SLA ενσωματώνεται και διέπεται από τη συμφωνία μεταξύ εσάς και της Wink με βάση την οποία έχετε πρόσβαση στο Partner API (η "Συμφωνία"), και ισχύει όσο διατηρείτε ενεργή, επί πληρωμή συνδρομή Partner API σε καλή κατάσταση. Οι κεφαλαιοποιημένοι όροι που δεν ορίζονται εδώ έχουν την έννοια που τους αποδίδεται στη Συμφωνία.

### 1. Ορισμοί

1. **"Διαθεσιμότητα"** σημαίνει τις περιόδους κατά τις οποίες το Partner API είναι διαθέσιμο να δεχτεί και να απαντήσει επιτυχώς σε σωστά διαμορφωμένα, αυθεντικοποιημένα αιτήματα.
2. **"Μη Διαθεσιμότητα"** σημαίνει οποιαδήποτε περίοδος, μετρημένη σε λεπτά, κατά την οποία το Partner API αποτυγχάνει να απαντήσει επιτυχώς σε σωστά διαμορφωμένα, αυθεντικοποιημένα αιτήματα, εξαιρουμένων των περιόδων που εμπίπτουν στις Εξαιρέσεις που ορίζονται στην Ενότητα 4. Απομονωμένα σφάλματα που επηρεάζουν ασήμαντο ποσοστό αιτημάτων δεν θεωρούνται από μόνα τους Μη Διαθεσιμότητα.
3. **"Μηνιαίο Ποσοστό Διαθεσιμότητας"** σημαίνει, για έναν δεδομένο ημερολογιακό μήνα, το συνολικό αριθμό λεπτών του μήνα μείον τα συνολικά λεπτά Μη Διαθεσιμότητας, διαιρεμένο με το συνολικό αριθμό λεπτών του μήνα, εκφρασμένο ως ποσοστό.
4. **"Προγραμματισμένη Συντήρηση"** σημαίνει προγραμματισμένη συντήρηση της Υπηρεσίας για την οποία η Wink έχει παράσχει προηγούμενη ειδοποίηση σύμφωνα με την Ενότητα 4.
5. **"Πίστωση Υπηρεσίας"** σημαίνει μια πίστωση, υπολογιζόμενη ως ποσοστό των τελών που έχετε πληρώσει ή οφείλετε για το Partner API στον επηρεαζόμενο ημερολογιακό μήνα, η οποία εφαρμόζεται έναντι μελλοντικών τελών Partner API ως η μόνη και αποκλειστική αποζημίωση για αποτυχία εκπλήρωσης της Δέσμευσης Διαθεσιμότητας.
6. **"Χρόνος Απόκρισης"** σημαίνει τον χρόνο που μεσολαβεί από τη λήψη από τη Wink ενός σωστά διαμορφωμένου, αυθεντικοποιημένου αιτήματος στα όρια της υπηρεσίας της Wink μέχρι το σημείο που η Wink αρχίζει να επιστρέφει την απόκριση, εξαιρουμένων των χρόνων μεταφοράς δικτύου και οποιουδήποτε χρόνου στην πλευρά του πελάτη εκτός ελέγχου της Wink.

### 2. Δέσμευση Διαθεσιμότητας & Απόδοσης

Η Wink θα καταβάλει εμπορικά εύλογες προσπάθειες να κάνει το Partner API διαθέσιμο με **Μηνιαίο Ποσοστό Διαθεσιμότητας τουλάχιστον 99,9%** κατά τη διάρκεια κάθε ημερολογιακού μήνα της διάρκειας (η "Δέσμευση Διαθεσιμότητας"). Η Δέσμευση Διαθεσιμότητας μετράται στα όρια της υπηρεσίας της Wink και εξαιρεί παράγοντες εκτός εύλογου ελέγχου της Wink, συμπεριλαμβανομένων αυτών που περιγράφονται στην Ενότητα 4. Τα συστήματα παρακολούθησης της Wink είναι η επίσημη πηγή μέτρησης του Μηνιαίου Ποσοστού Διαθεσιμότητας και του Χρόνου Απόκρισης.

Επιπλέον, η Wink στοχεύει σε **Χρόνο Απόκρισης 95ου εκατοστημορίου (P95) κάτω από 500 χιλιοστά του δευτερολέπτου** για επιτυχημένα, σωστά διαμορφωμένα, αυθεντικοποιημένα αιτήματα, μετρημένο στα όρια της υπηρεσίας της Wink σε κάθε ημερολογιακό μήνα (ο "Στόχος Απόδοσης"). Ο Στόχος Απόδοσης εξαιρεί τους παράγοντες της Ενότητας 4, αιτήματα που επιστρέφουν σφάλματα επιπέδου εφαρμογής που προκαλούνται από το ίδιο το αίτημα, και ασυνήθιστα μεγάλα ή πολύπλοκα ομαδικά αιτήματα. Ο Στόχος Απόδοσης είναι στόχος υπηρεσίας· οι Πιστώσεις Υπηρεσίας στην Ενότητα 3 εφαρμόζονται σε αποτυχίες εκπλήρωσης της **Δέσμευσης Διαθεσιμότητας** και αποτελούν τη μόνη και αποκλειστική αποζημίωση για ελλείψεις διαθεσιμότητας.

### 3. Πιστώσεις Υπηρεσίας

Εάν το Μηνιαίο Ποσοστό Διαθεσιμότητας πέσει κάτω από τη Δέσμευση Διαθεσιμότητας σε οποιονδήποτε ημερολογιακό μήνα, μπορεί να δικαιούστε Πίστωση Υπηρεσίας υπολογιζόμενη ως ποσοστό των τελών Partner API που έχετε πληρώσει ή οφείλετε για εκείνον τον μήνα, σύμφωνα με την παρακάτω κλίμακα:

| Μηνιαίο Ποσοστό Διαθεσιμότητας | Πίστωση Υπηρεσίας |
|---|---|
| Κάτω από 99,9% αλλά ίσο ή πάνω από 99,0% | 10% |
| Κάτω από 99,0% αλλά ίσο ή πάνω από 95,0% | 25% |
| Κάτω από 95,0% | 50% |

1. **Αίτηση πίστωσης.** Για να λάβετε Πίστωση Υπηρεσίας πρέπει να υποβάλετε γραπτό αίτημα στη Wink εντός **τριάντα (30) ημερών** από το τέλος του ημερολογιακού μήνα κατά τον οποίο συνέβη η ελλειμματική διαθεσιμότητα. Το αίτημα πρέπει να περιλαμβάνει τις ημερομηνίες και ώρες κάθε περιστατικού Μη Διαθεσιμότητας που διεκδικείτε και τυχόν υποστηρικτικά αρχεία καταγραφής ή αποδεικτικά στοιχεία που είναι εύλογα διαθέσιμα σε εσάς. Αιτήματα που υποβάλλονται μετά το διάστημα αυτό δεν είναι επιλέξιμα.
2. **Μορφή πίστωσης.** Οι εγκεκριμένες Πιστώσεις Υπηρεσίας εφαρμόζονται έναντι μελλοντικών τελών Partner API και δεν έχουν χρηματική αξία. Δεν είναι επιστροφές χρημάτων και δεν θα καταβληθούν εκτός αν απαιτείται από την ισχύουσα νομοθεσία.
3. **Μέγιστη πίστωση.** Το συνολικό ποσό Πιστώσεων Υπηρεσίας που απονέμεται για οποιονδήποτε ημερολογιακό μήνα δεν θα υπερβαίνει το 50% των τελών Partner API που έχετε πληρώσει ή οφείλετε για εκείνον τον μήνα.
4. **Μόνη και αποκλειστική αποζημίωση.** Οι Πιστώσεις Υπηρεσίας είναι η **μόνη και αποκλειστική αποζημίωσή σας** για οποιαδήποτε αποτυχία της Wink να εκπληρώσει τη Δέσμευση Διαθεσιμότητας ή οποιαδήποτε άλλη έλλειψη διαθεσιμότητας του Partner API.

### 4. Εξαιρέσεις

Η Δέσμευση Διαθεσιμότητας και τυχόν Πιστώσεις Υπηρεσίας δεν ισχύουν, και η Μη Διαθεσιμότητα δεν περιλαμβάνει, οποιαδήποτε μη διαθεσιμότητα, αναστολή, υποβάθμιση ή πρόβλημα απόδοσης που προκύπτει από ή σχετίζεται με:

1. **Προγραμματισμένη Συντήρηση** για την οποία η Wink έχει δώσει προηγούμενη ειδοποίηση, εφόσον η ειδοποίηση έχει δοθεί με εύλογο χρονικό διάστημα εκ των προτέρων μέσω καναλιού που η Wink χρησιμοποιεί κανονικά για επικοινωνία με πελάτες·
2. **Γεγονότα ανωτέρας βίας** ή άλλες αιτίες εκτός εύλογου ελέγχου της Wink, συμπεριλαμβανομένων φυσικών καταστροφών, κυβερνητικών ενεργειών, διακοπών δικτύου ή υπηρεσιών κοινής ωφέλειας, και επιθέσεων άρνησης υπηρεσίας ή άλλων κακόβουλων επιθέσεων·
3. προβλήματα που προκαλούνται από τις **ενέργειες ή παραλείψεις σας**, τον εξοπλισμό, το λογισμικό ή το δίκτυό σας, ή από οποιαδήποτε **υπηρεσία, προϊόν ή πάροχο τρίτου μέρους** που δεν βρίσκεται υπό τον άμεσο έλεγχο της Wink·
4. την **κακή χρήση της Υπηρεσίας** ή **παραβίαση της Συμφωνίας**, αυτής της SLA, των όρων αποδεκτής χρήσης ή των ισχυόντων ορίων ρυθμού, συμπεριλαμβανομένης της κίνησης που η Wink λογικά θεωρεί υπερβολική, αυτοματοποιημένη κατάχρηση ή απάτη· και
5. οποιαδήποτε **αναστολή ή τερματισμό** της πρόσβασής σας που έχει πραγματοποιηθεί σωστά βάσει της Συμφωνίας, συμπεριλαμβανομένης της αναστολής για μη πληρωμή.

### 5. Υποστήριξη & Στόχοι Απόκρισης

Η Wink παρέχει υποστήριξη για το Partner API κατά τις κανονικές εργάσιμες ώρες, εξαιρουμένων των τοπικών αργιών. Η Wink θα καταβάλει εμπορικά εύλογες προσπάθειες να αναγνωρίσει σωστά υποβλημένα αιτήματα υποστήριξης εντός των ακόλουθων στοχευμένων χρόνων απόκρισης, βάσει της σοβαρότητας που αναθέτετε και που η Wink λογικά επιβεβαιώνει:

| Σοβαρότητα | Περιγραφή | Στόχος αρχικής απόκρισης |
|---|---|---|
| **Sev 1 — Κρίσιμη** | Το Partner API είναι εκτός λειτουργίας ή μη χρησιμοποιήσιμο σε παραγωγή χωρίς λύση παράκαμψης. | 4 ώρες |
| **Sev 2 — Σημαντική** | Σημαντική λειτουργία υποβαθμισμένη ή περιορισμένη· υπάρχει λύση παράκαμψης. | 1 εργάσιμη ημέρα |
| **Sev 3 — Μικρή** | Γενικές ερωτήσεις, μικρά ζητήματα ή αιτήματα λειτουργιών. | 2 εργάσιμες ημέρες |

Οι στοχευμένοι χρόνοι απόκρισης περιγράφουν πότε η Wink στοχεύει να κάνει **την αρχική επαφή**· δεν είναι εγγυήσεις χρόνου επίλυσης. Η υποστήριξη προτεραιότητας και οι στόχοι βάσει σοβαρότητας ισχύουν στα επίπεδα όπου αναφέρεται ότι περιλαμβάνονται.

### 6. Δεδομένα & Ασφάλεια

Η Wink διατηρεί εμπορικά εύλογα διοικητικά, τεχνικά και οργανωτικά μέτρα σχεδιασμένα να προστατεύουν την εμπιστευτικότητα, ακεραιότητα και διαθεσιμότητα των δεδομένων που επεξεργάζονται μέσω του Partner API, και αναθεωρεί αυτά τα μέτρα περιοδικά. Η επεξεργασία προσωπικών δεδομένων από τη Wink διέπεται από την [Πολιτική Απορρήτου](/el/privacy) και τυχόν όρους επεξεργασίας δεδομένων στη Συμφωνία. Εσείς παραμένετε υπεύθυνοι για την ασφάλεια των δικών σας διαπιστευτηρίων API, για τη νόμιμη χρήση οποιωνδήποτε δεδομένων ανακτάτε, και για την άμεση ενημέρωση της Wink για οποιαδήποτε υποψία παραβίασης διαπιστευτηρίων.

### 7. Περιορισμός Ευθύνης

Οι Πιστώσεις Υπηρεσίας είναι η **μόνη και αποκλειστική αποζημίωση** για οποιαδήποτε μη διαθεσιμότητα ή αποτυχία εκπλήρωσης της Δέσμευσης Διαθεσιμότητας, και παρέχονται αντί οποιασδήποτε άλλης ευθύνης που προκύπτει από τέτοια αποτυχία. Εκτός αν ρητά αναφέρεται σε αυτή τη SLA, το Partner API παρέχεται "ως έχει". Στο μέγιστο βαθμό που επιτρέπει ο ισχύων νόμος, η συνολική ευθύνη της Wink που προκύπτει από ή σχετίζεται με την Υπηρεσία περιορίζεται όπως ορίζεται στη Συμφωνία, και η Wink δεν ευθύνεται για οποιεσδήποτε έμμεσες, τυχαίες, ειδικές, επακόλουθες ή ποινικές ζημίες, ή για απώλεια κερδών, εσόδων, δεδομένων ή φήμης, ακόμη και αν έχει ενημερωθεί για την πιθανότητα τέτοιων ζημιών.

### 8. Διάρκεια, Αλλαγές & Τερματισμός

Αυτή η SLA ισχύει όσο έχετε ενεργή συνδρομή Partner API σε επίπεδο όπου αναφέρεται ότι ισχύει SLA. Η Wink μπορεί να ενημερώνει αυτή τη SLA περιοδικά· σημαντικές αλλαγές θα κοινοποιούνται μέσω καναλιού που η Wink χρησιμοποιεί κανονικά για επικοινωνία με πελάτες, και η συνεχιζόμενη χρήση του Partner API μετά την εφαρμογή ενημέρωσης συνιστά αποδοχή της ενημερωμένης SLA. Αυτή η SLA τερματίζεται αυτόματα με τον τερματισμό ή τη λήξη της Συμφωνίας ή της συνδρομής σας στο Partner API. Ενότητες που λόγω της φύσης τους πρέπει να επιβιώσουν μετά τον τερματισμό — συμπεριλαμβανομένης της επιλεξιμότητας για αχρησιμοποίητες Πιστώσεις Υπηρεσίας, του περιορισμού ευθύνης και των ορισμών — επιβιώνουν.
