Συνδέοντας το Google Analytics 4 property σας με το Wink, τα γεγονότα κρατήσεων — από τις προβολές δωματίων μέχρι τις ολοκληρωμένες κρατήσεις — προωθούνται αυτόματα στον δικό σας πίνακα ελέγχου GA4 παράλληλα με τα δικά του analytics του Wink. Χωρίς κώδικα, χωρίς τεχνική ρύθμιση από εσάς.

<Aside type="tip">
Χρειάζεστε ένα μόνο πράγμα από το GA4: ένα **Measurement ID** (`G-XXXXXXXXXX`). Το Wink το φορτώνει στον browser του επισκέπτη και μεταδίδει ολόκληρο το funnel κρατήσεων — συμπεριλαμβανομένης της ολοκληρωμένης κράτησης (`purchase`) — απευθείας στο GA4 property σας. Δεν υπάρχει API secret για δημιουργία και δεν χρειάζεται να εγκαταστήσετε τίποτα στον δικό σας ιστότοπο.
</Aside>

---

## Πώς Λειτουργεί

```
Εισάγετε το Measurement ID σας (G-XXXXXXXXXX) στο portal του Wink
       ↓
Το Wink φορτώνει το GA4 σας στον browser του επισκέπτη και μεταδίδει τα γεγονότα κρατήσεων
(προβολές, καλάθι, ολοκλήρωση αγοράς) στο GA4 property σας σε πραγματικό χρόνο
       ↓
Στη σελίδα ευχαριστίας ενεργοποιείται η ολοκληρωμένη κράτηση (purchase) στον browser —
Το Wink επανασυνδέει τη συνεδρία GA4 που διακόπηκε από την ανακατεύθυνση πληρωμής, ώστε
η πώληση να μετράει στην αρχική επίσκεψη του επισκέπτη
       ↓
Συνδέεστε στο analytics.google.com και βλέπετε ολόκληρο το funnel κρατήσεων
```

---

## Τι Πρέπει να Κάνετε

<Steps>

1. **Δημιουργήστε ένα GA4 Property**

   Μεταβείτε στο [analytics.google.com](https://analytics.google.com): Admin → Create Property. Ορίστε τη ζώνη ώρας και το νόμισμα ώστε να ταιριάζουν με την αγορά σας.

2. **Δημιουργήστε ένα Web Data Stream**

   Admin → Data Streams → Add Stream → Web. Εισάγετε `wink.travel` ως URL. Αυτό δημιουργεί το **Measurement ID** σας (`G-XXXXXXXXXX`). Αντιγράψτε το.

3. **Εισάγετε το Measurement ID στο Portal του Wink**

   Συνδεθείτε στο [app.wink.travel](https://app.wink.travel), επιλέξτε τον λογαριασμό σας και ανοίξτε τις ρυθμίσεις προσαρμογής. Στην ενότητα **Analytics & integrations**, επικολλήστε το Measurement ID στο πεδίο **GA4 Measurement ID** και αποθηκεύστε. Αυτό ήταν — η ενσωμάτωση GA4 είναι πλέον ενεργή.

4. **Ορίστε το `purchase` ως Κύριο Γεγονός**

   Επιστρέψτε στο GA4 property σας: Admin → Events → βρείτε το `purchase` → ενεργοποιήστε το **Mark as key event**. Αυτό κάνει τις ολοκληρωμένες κρατήσεις να εμφανίζονται στην αναφορά Μετατροπών.

5. **Δείτε τα Δεδομένα σας**

   Συνδεθείτε στο [analytics.google.com](https://analytics.google.com) και θα δείτε τις κρατήσεις, τα έσοδα και το funnel επισκεπτών — όλα παρακολουθούνται αυτόματα μέσω του Wink.

</Steps>

<Aside type="note">
Δεν χρειάζεται να εγκαταστήσετε κανέναν κώδικα παρακολούθησης στον δικό σας ιστότοπο για αυτήν την ενσωμάτωση. Το Wink αναλαμβάνει τα πάντα — το Measurement ID σας είναι απλώς ο προορισμός όπου αποστέλλονται τα δεδομένα κρατήσεων.
</Aside>

<Aside type="tip">
**Το GA4 και το GTM μπορούν να χρησιμοποιηθούν μαζί.** Αν τρέχετε και container Google Tag Manager (π.χ. container Sojern), μπορείτε να ρυθμίσετε και τα δύο ταυτόχρονα — δεν αποκλείονται μεταξύ τους. Δείτε [GTM Analytics Integration](/el/guides/general/gtm-integration).
</Aside>

## Πώς Χρησιμοποιεί το Wink το Measurement ID σας στη Μηχανή Κρατήσεων

Όλα συμβαίνουν **στον browser του επισκέπτη** — δεν υπάρχει εξαγωγή δεδομένων server-to-server και δεν εμπλέκεται API secret.

- **Το GA4 σας φορτώνει στις σελίδες κρατήσεων.** Όποτε ένας επισκέπτης βλέπει το ακίνητό σας στη μηχανή κρατήσεων Wink, το Wink φορτώνει το Measurement ID σας στον browser του παράλληλα με τα δικά του analytics, διαβάζοντας από τα ίδια κοινά δεδομένα. Τα γεγονότα περιήγησης — αναζητήσεις, προβολές δωματίων, καλάθι, ολοκλήρωση αγοράς — μεταδίδονται στο GA4 property σας σε πραγματικό χρόνο.
- **Η ολοκληρωμένη κράτηση ενεργοποιείται στη σελίδα ευχαριστίας.** Όταν ο επισκέπτης ολοκληρώνει την πληρωμή και προσγειώνεται στη σελίδα επιβεβαίωσης, το γεγονός `purchase` ενεργοποιείται client-side, μεταφέροντας την πλήρη αξία κράτησης, νόμισμα και λεπτομέρειες δωματίου.
- **Η ανακατεύθυνση πληρωμής δεν χάνει πλέον την πώληση.** Οι πληρωμές με κάρτα στέλνουν τον browser του επισκέπτη στον πάροχο πληρωμών και πίσω, κάτι που κανονικά θα διέκοπτε τη συνεδρία GA4 στον browser και θα έκανε την κράτηση να φαίνεται ως νέα "Direct" επίσκεψη. Για να το αποτρέψει, το Wink μεταφέρει τους αναγνωριστικούς κωδικούς συνεδρίας GA4 μέσω του URL επιστροφής και **επανασυνδέει την αρχική συνεδρία** στη σελίδα ευχαριστίας *πριν* ενεργοποιηθεί το `purchase`. Η ολοκληρωμένη κράτηση αποδίδεται έτσι στην ίδια επίσκεψη που ξεκίνησε ο επισκέπτης — δεν μετράται ως ξεχωριστή συνεδρία.

<Aside type="note">
Το Wink αποφεύγει διπλοεγγραφές του `purchase` ανά κράτηση, οπότε η ανανέωση σελίδας ή η αυτόματη ανακατεύθυνση στις λεπτομέρειες κράτησης δεν μετράει διπλή πώληση.
</Aside>

## Τι Μπορείτε να Παρακολουθείτε

Μόλις συνδεθεί, το GA4 property σας λαμβάνει το πλήρες σύνολο γεγονότων Enhanced E-commerce για το ακίνητό σας:

### Ανακάλυψη

| Γεγονός | Τι Σημαίνει |
|---|---|
| `view_item_list` | Ένας επισκέπτης είδε το ακίνητό σας σε αναζήτηση ή λίστα κατηγορίας |
| `select_item` | Ένας επισκέπτης έκανε κλικ στο ακίνητό σας από λίστα |
| `view_item` | Ένας επισκέπτης είδε τη σελίδα λεπτομερειών του ξενοδοχείου σας |

### Εξέταση

| Γεγονός | Τι Σημαίνει |
|---|---|
| `view_promotion` | Ένας επισκέπτης είδε μια προωθητική προσφορά για το ακίνητό σας |
| `select_promotion` | Ένας επισκέπτης έκανε κλικ σε προωθητική προσφορά |
| `add_to_wishlist` | Ένας επισκέπτης αποθήκευσε το ακίνητό σας στη λίστα επιθυμιών του |

### Funnel Κρατήσεων

| Γεγονός | Τι Σημαίνει |
|---|---|
| `add_to_cart` | Ένας επισκέπτης επέλεξε δωμάτιο ή πακέτο |
| `view_cart` | Ένας επισκέπτης είδε την περίληψη της κράτησής του |
| `remove_from_cart` | Ένας επισκέπτης αφαίρεσε δωμάτιο ή πακέτο |
| `begin_checkout` | Ένας επισκέπτης ξεκίνησε τη διαδικασία ολοκλήρωσης αγοράς |
| `add_payment_info` | Ένας επισκέπτης εισήγαγε τα στοιχεία πληρωμής του |
| `add_shipping_info` | Ένας επισκέπτης εισήγαγε τα στοιχεία του επισκέπτη |
| `purchase` | Ένας επισκέπτης ολοκλήρωσε κράτηση |
| `refund` | Μια κράτηση ακυρώθηκε και επιστράφηκε το ποσό |

Όλα τα γεγονότα περιλαμβάνουν σχετικές διαστάσεις όπως έσοδα, νόμισμα, τύπο δωματίου και αξία κράτησης — δίνοντάς σας πλήρη εικόνα του ταξιδιού του επισκέπτη από την πρώτη εντύπωση μέχρι την ολοκληρωμένη κράτηση. Για να ξεκλειδώσετε επιπλέον διαστάσεις σε επίπεδο ακινήτου και δωματίου όπως `city_name`, `cancellation_policy`, `bed_type` και άλλες, δείτε [Custom Dimensions in GA4](/el/guides/general/gtm-integration#custom-dimensions-in-ga4).

## Παρακολούθηση Διατομεακά (Προχωρημένο)

Η βασική ενσωμάτωση παραπάνω παρακολουθεί ό,τι συμβαίνει μέσα στο Wink. Ωστόσο, αν θέλετε να παρακολουθείτε τους επισκέπτες από τον δικό σας ιστότοπο μέχρι την ολοκλήρωση κράτησης στο Wink — και να αποδίδετε σωστά την αρχική πηγή κίνησης (Google Ads, email καμπάνιες, οργανική αναζήτηση κ.ά.) — απαιτείται ένα επιπλέον βήμα σε κάθε πλευρά.

<Aside type="caution">
Αυτή η ενότητα ισχύει μόνο αν έχετε εγκατεστημένο το GA4 στον δικό σας ιστότοπο. Αν δεν τρέχετε GA4 στον ιστότοπό σας, η βασική ενσωμάτωση παραπάνω είναι ό,τι χρειάζεστε.
</Aside>

### Γιατί Είναι Σημαντικό

Χωρίς διατομεακή παρακολούθηση, ένας επισκέπτης που επισκέπτεται πρώτα τον ιστότοπό σας και μετά κάνει κράτηση στο Wink θα εμφανίζεται στο GA4 ως **Direct** συνεδρία χωρίς σύνδεση με την προηγούμενη επίσκεψη. Κάθε κλικ από Google Ads, email καμπάνιες ή οργανική αναζήτηση που οδήγησε στην κράτηση δεν θα λαμβάνει πίστωση.

Με ρυθμισμένη τη διατομεακή παρακολούθηση, βλέπετε ολόκληρο το ταξίδι του επισκέπτη:

```
google.com (πληρωμένη διαφήμιση)
       ↓
ο ιστότοπός σας (ο επισκέπτης περιηγείται σε δωμάτια)
       ↓
wink.travel (ο επισκέπτης επιλέγει δωμάτιο και κάνει κράτηση)
       ↓
η αγορά αποδίδεται σωστά στο αρχικό κλικ Google Ads
```

### Ενέργεια Απαιτείται: Εσείς

Ρυθμίστε το GA4 property σας ώστε να αναγνωρίζει το `wink.travel` ως μέρος του δικού σας domain, όχι ως εξωτερική παραπομπή. Αυτό λέει στο GA4 να συνδέσει τις δύο συνεδρίες σε ένα συνεχές ταξίδι επισκέπτη.

<Steps>
1. GA4 Admin → Data Streams → το stream σας
2. Configure tag settings → **Configure your domains**
3. Προσθέστε το `wink.travel` ως συνδεδεμένο domain
4. Αποθηκεύστε
</Steps>

### Ενέργεια Απαιτείται: Wink

Επικοινωνήστε με το [Wink Support](https://app.wink.travel) και δώστε το domain του ιστότοπού σας (π.χ. `yourhotel.com`). Το Wink θα προσθέσει το domain σας στη λίστα αποκλεισμού παραπομπών στο GA4 property του Wink. Αυτό αποτρέπει τον ιστότοπό σας από το να καταγράφεται ως πηγή παραπομπής, που διαφορετικά θα αντικαθιστούσε την αρχική απόδοση του επισκέπτη και θα ξεκινούσε νέα συνεδρία.

<Aside type="tip">
Η βασική ενσωμάτωση παραπάνω είναι επαρκής για τα περισσότερα ακίνητα και σας δίνει άμεση ορατότητα σε κρατήσεις και έσοδα στο Wink. Η διατομεακή παρακολούθηση είναι μια προχωρημένη επιλογή που αξίζει να ρυθμίσετε όταν είστε άνετοι με τα δεδομένα GA4 και θέλετε βαθύτερη ανάλυση απόδοσης.
</Aside>
