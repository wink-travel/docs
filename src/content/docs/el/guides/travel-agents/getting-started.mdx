Αυτός ο οδηγός οδηγεί ένα ταξιδιωτικό πρακτορείο από την εγγραφή μέχρι την πρώτη κράτηση πελάτη. Εξηγεί επίσης τους δύο τρόπους με τους οποίους ένα πρακτορείο μπορεί να λειτουργήσει στο Wink, ώστε να επιλέξετε τον κατάλληλο πριν ξεκινήσετε.

## Πριν ξεκινήσετε

Θα χρειαστείτε:

- Τα στοιχεία της εταιρείας σας.
- Τον αριθμό εγγραφής του ταξιδιωτικού πρακτορείου σας ή τον κωδικό IATA αν έχετε.
- Έναν τραπεζικό λογαριασμό για την προμήθειά σας.

## Επιλέξτε πώς θα λειτουργήσετε

| | Πρότυπο (τα περισσότερα πρακτορεία) | Πληρωμή που συλλέγει ο πράκτορας |
|---|---|---|
| Πώς κάνετε την κράτηση | Στο portal του Wink ή μέσω του Partner API | Μέσω του [Partner API](/el/integrations/partner-api/), από το δικό σας σύστημα |
| Ποιος εισπράττει την πληρωμή του πελάτη | Συλλέγεται για το ξενοδοχείο, που παραμένει έμπορος καταγραφής. Εισάγετε την κάρτα του πελάτη κατά το ταμείο. | Εσείς, ως έμπορος καταγραφής. |
| Τι κερδίζετε | **10% προεπιλεγμένη προμήθεια** σε κάθε κράτηση | Την προμήθεια που έχετε συμφωνήσει με κάθε ξενοδοχείο |
| Τι πληρώνετε στο Wink | Τίποτα | **1,5%** Τέλος Κράτησης επί της αξίας κάθε κράτησης, τιμολογείται μηνιαίως, συν χρήση Partner API πάνω από το δωρεάν όριο |
| Πληρωμή στο ξενοδοχείο | Διαχειρίζεται για εσάς | Πληρώνετε κάθε ξενοδοχείο απευθείας, σύμφωνα με τη δική σας συμφωνία |
| Επιστροφές, χρεώσεις, συμμόρφωση πληρωμών | Διαχειρίζεται για εσάς | Δική σας ευθύνη |
| Έγκριση | Η εγγραφή σας ελέγχεται πριν μπορέσετε να κάνετε κράτηση | Η εγγραφή σας ελέγχεται, συν η γραπτή έγκριση του Wink για αυτή τη διαδρομή, με πιστωτικό όριο |

Το Wink ελέγχει κάθε εγγραφή ταξιδιωτικού πρακτορείου. Τα περισσότερα πρακτορεία χρησιμοποιούν τη στάνταρ διαδρομή. Η πληρωμή που συλλέγει ο πράκτορας προορίζεται για **API συνεργάτες μόνο**: πρακτορεία που κλείνουν μέσω του Partner API από το δικό τους σύστημα, ήδη συλλέγουν πληρωμές πελατών με τη δική τους άδεια και συμβάλλονται απευθείας με ξενοδοχεία.

## Βήμα 1: Εγγραφείτε το πρακτορείο σας

<Steps>
1. Μεταβείτε στο [app.wink.travel](https://app.wink.travel), κάντε κλικ στο `Sign-In / Register` και εγγραφείτε.

2. Κάντε κλικ στο `Accounts` στην αριστερή πλαϊνή μπάρα, μετά στο `Create`, και επιλέξτε **Είμαι Ταξιδιωτικός Πράκτορας**.

3. Συμπληρώστε τα στοιχεία του πρακτορείου σας. Επιλέξτε **Εταιρεία** ως τύπο οντότητας: αυτό καθορίζει πώς θα πληρωθείτε. Δείτε [Create Account](/el/portal/create-account/).

4. Αν θα συλλέγετε εσείς την πληρωμή μέσω του Partner API, επιλέξτε αυτή τη διαδρομή κατά την εγγραφή. Πρόκειται για αίτηση, όχι έγκριση. Δείτε [Βήμα 6](#step-6-collect-payment-yourself-api-partners-only).

5. Το Wink ελέγχει κάθε εγγραφή ταξιδιωτικού πρακτορείου. Στέλνουμε email στη δηλωμένη διεύθυνση και ζητάμε τα έγγραφά σας: στοιχεία εταιρείας και αριθμό εγγραφής ή κωδικό IATA. Μπορείτε να κάνετε κράτηση μόλις εγκριθεί η εγγραφή σας.
</Steps>

## Βήμα 2: Προσθέστε τον τραπεζικό σας λογαριασμό

Μεταβείτε στο `Account > Bank Accounts`, προσθέστε τον λογαριασμό του πρακτορείου σας και επισημάνετέ τον ως **Κύριο**. Η προμήθεια καταβάλλεται εκεί μέσω τραπεζικής μεταφοράς. Το Wink στέλνει πληρωμές μέσω Revolut, οπότε ένας επαγγελματικός λογαριασμός Revolut είναι η πιο ομαλή επιλογή, αλλά οποιοσδήποτε τραπεζικός λογαριασμός λειτουργεί. Δείτε [Bank Accounts](/el/portal/settings/payouts/).

## Βήμα 3: Βρείτε ξενοδοχεία για τον πελάτη σας

<Steps>
1. Κάντε κλικ στο `Browse > Hotels` στην κύρια γραμμή πλοήγησης.

2. Αναζητήστε προορισμό, ημερομηνίες και πληρότητα, και φιλτράρετε μέχρι να βρείτε τις κατάλληλες επιλογές για τον πελάτη σας.

3. Αποθηκεύστε σύντομες λίστες σε μια [επιμελημένη λίστα](/el/portal/studio/curated-lists/) αν συγκρίνετε επιλογές με τον πελάτη.
</Steps>

Οι τιμές που βλέπετε είναι οι ίδιες του ξενοδοχείου. Το Wink τις προωθεί χωρίς καμία επιβάρυνση: κερδίζετε μέσω προμήθειας. Δείτε [Search](/el/portal/studio/search/).

## Βήμα 4: Κλείστε για τον πελάτη σας

<Steps>
1. Επιλέξτε το δωμάτιο και την τιμή, και εισάγετε το όνομα και τα στοιχεία επικοινωνίας του πελάτη σας ως ταξιδιώτη.

2. Στο ταμείο, εισάγετε την κάρτα που σας έδωσε ο πελάτης για αυτή την κράτηση. Η πληρωμή συλλέγεται για το ξενοδοχείο, που παραμένει έμπορος καταγραφής.

3. Επιβεβαιώστε. Εσείς, ο ταξιδιώτης και το ξενοδοχείο λαμβάνετε επιβεβαίωση μέσω email. Ο κωδικός κράτησης ξεκινά με `WNK`.
</Steps>

:::caution[Χειριστείτε την κάρτα του πελάτη σας με προσοχή]
Ζητήστε την κάρτα μόνο για την κράτηση που κάνετε και εισάγετέ την απευθείας στο ταμείο. Μην την γράφετε, μην την στέλνετε με email ή κρατάτε αντίγραφα στα αρχεία σας.
:::

## Βήμα 5: Διαχειριστείτε τις κρατήσεις και πληρωθείτε

- **Κρατήσεις:** κάντε κλικ στο `Bookings` στην κύρια γραμμή πλοήγησης για να δείτε κάθε κράτηση, να τη φιλτράρετε, να την εξάγετε σε CSV, να ξαναστείλετε επιβεβαίωση ή να ακυρώσετε εντός της πολιτικής ακύρωσης του ξενοδοχείου. Δείτε [Bookings](/el/portal/travel-agent/bookings/).
- **Προμήθεια:** 10% προεπιλεγμένα. Μόλις συνεργαστείτε τακτικά με ένα ξενοδοχείο, μπορείτε να ζητήσετε [άμεση σύνδεση](/el/portal/studio/network/) και να συμφωνήσετε διαφορετική προμήθεια.
- **Πότε πληρώνεστε:** η προμήθεια γίνεται διαθέσιμη εντός 24 ωρών από το check-in του επισκέπτη και κατατίθεται στον κύριο τραπεζικό σας λογαριασμό. Τα τέλη μεταφοράς πληρώνονται στο κόστος. Δείτε [Pricing](/el/getting-started/pricing/).

## Βήμα 6: Συλλέξτε την πληρωμή μόνοι σας (μόνο για API συνεργάτες)

Παραλείψτε αυτό το βήμα αν κάνετε κράτηση στο portal ή είστε ικανοποιημένοι με τη στάνταρ διαδρομή.

<Steps>
1. Ενσωματωθείτε με το [Partner API](/el/integrations/partner-api/). Αυτή η διαδρομή λειτουργεί μόνο μέσω API, από το δικό σας σύστημα κρατήσεων, όχι στο portal.

2. Επιλέξτε τη διαδρομή κατά την εγγραφή (Βήμα 1).

3. Το Wink το αξιολογεί μαζί με τα έγγραφα εγγραφής σας, π.χ. τη χρηματοοικονομική σας κατάσταση και τη ρυθμιστική σας κατάσταση, και επιβεβαιώνει γραπτώς. Η έγκριση συνοδεύεται από **πιστωτικό όριο**: το μέγιστο ποσό που μπορείτε να έχετε σε μη διακανονισμένες κρατήσεις ανά πάσα στιγμή.

4. Μέχρι να εγκριθείτε, μπορείτε να συνεχίσετε να κάνετε κράτηση μέσω της στάνταρ διαδρομής.
</Steps>

Μόλις εγκριθείτε, εισπράττετε εσείς την πληρωμή του πελάτη και πληρώνετε κάθε ξενοδοχείο απευθείας. Για κάθε κράτηση αφαιρείτε, με αυτή τη σειρά, το 1,5% τέλος Wink και μετά την προμήθειά σας· το υπόλοιπο οφείλεται στο ξενοδοχείο:

| Σε κράτηση USD 1.000,00 με προμήθεια 10% | |
|---|---|
| Αξία κράτησης | USD 1.000,00 |
| Μείον τέλος Wink (1,5% της αξίας κράτησης) | USD 15,00 |
| Υπόλοιπο | USD 985,00 |
| Μείον προμήθειά σας (10% του υπολοίπου) | USD 98,50 |
| **Οφείλεται στο ξενοδοχείο** | **USD 886,50** |

Το Wink τιμολογεί το 1,5% Τέλος Κράτησης μηνιαίως, σε USD, πληρωτέο εντός 15 ημερών, συν οποιαδήποτε χρήση Partner API πάνω από το δωρεάν όριο. Εσείς είστε υπεύθυνοι για επιστροφές, χρεώσεις, ασφάλεια πληρωμών (PCI-DSS) και οποιαδήποτε άδεια απαιτεί η χώρα σας για τη συλλογή πληρωμών. Οι πλήρεις όροι βρίσκονται στη [Συμφωνία Ταξιδιωτικού Πράκτορα](/el/legal/platform-agreements/).

## Συνδέστε τα δικά σας συστήματα

Τα πρακτορεία με δικά τους εργαλεία κρατήσεων μπορούν να αναζητούν και να κλείνουν μέσω του [Partner API](/el/integrations/partner-api/). Οι λογαριασμοί ταξιδιωτικών πρακτορείων μπορούν να δημιουργούν κρατήσεις απευθείας μέσω αυτού, και είναι ο μόνος τρόπος να λειτουργήσετε στη διαδρομή πληρωμής που συλλέγει ο πράκτορας. Δείτε την [αναφορά Partner API](/el/partner-api/partner/).

## Η λίστα ελέγχου σας

- [ ] Πρακτορείο εγγεγραμμένο ως λογαριασμός Ταξιδιωτικού Πράκτορα
- [ ] Έγγραφα αποσταλμένα και εγγραφή εγκεκριμένη
- [ ] Προστέθηκε τραπεζικός λογαριασμός και επισημάνθηκε ως Κύριος
- [ ] Βρέθηκαν τα πρώτα ξενοδοχεία για πελάτη
- [ ] Πραγματοποιήθηκε η πρώτη κράτηση, εισήχθη κάρτα στο ταμείο
- [ ] Προαιρετικό, API συνεργάτες: επιλέξατε να συλλέγετε εσείς την πληρωμή κατά την εγγραφή
