Η γνώση είναι η ζωτική δύναμη της Wink. Σας δείχνει πώς αποδίδει ο καθένας και τα πάντα στην Wink, μέχρι και την ώρα. Πριν από την Wink, τα ξενοδοχεία συνδρομοποιούνταν σε τρίτους παρόχους και πλήρωναν πολλά χρήματα για να έχουν πρόσβαση σε αυτό που η ομάδα διαχείρισης εσόδων αναφέρεται ως `το comp set`, που μεταφράζεται σε: `Πώς συγκρίνεται το ακίνητό μου με ένα άλλο ακίνητο;`.

Στην Wink, έχετε δωρεάν πρόσβαση σε αναλύσεις σε επίπεδο πλατφόρμας. Αυτό σας επιτρέπει να παρακολουθείτε την απόδοση οποιουδήποτε συνεργάτη, ταξιδιωτικού πράκτορα ή ακινήτου σε οποιοδήποτε μετρικό θέλετε... όσο θέλετε. Μπορείτε επίσης να έχετε πρόσβαση σε ευρύτερες τάσεις ανά περιοχή για να δείτε τι είδους προϊόν πωλείται πού και πότε. Στα σωστά χέρια, αυτή η γνώση μπορεί να βελτιώσει τις πωλησιακές δεξιότητες κάθε χρήστη της Wink.

## Πρόσβαση σε γραφήματα

Μπορείτε να έχετε πρόσβαση στα γραφήματά σας από οποιαδήποτε από τις ιστοσελίδες μας. Για να αποκτήσετε πρόσβαση στα αναλυτικά σας γραφήματα, ακολουθήστε τα παρακάτω βήματα:

<Steps>
1. Πρέπει να έχετε συνδεθεί σε μία από τις ιστοσελίδες μας.
2. Κάντε κλικ στο εικονίδιο προφίλ σας, στην πάνω δεξιά γωνία, και θα εμφανιστεί ένα μενού.
3. Κάντε κλικ στον σύνδεσμο `Analytics`.
4. Θα ανακατευθυνθείτε στα γραφήματά σας.
</Steps>

:::note
Κατά προεπιλογή, δημιουργούμε απλά γραφήματα για κάθε ακίνητο, ταξιδιωτικό πράκτορα και λογαριασμό συνεργάτη που δημιουργείτε, ώστε να μπορείτε εύκολα να παρακολουθείτε πώς αποδίδουν οι δικοί σας λογαριασμοί.
:::

## Δημιουργία γραφήματος

Όταν θέλετε να ξεκινήσετε να δημιουργείτε τα δικά σας γραφήματα, πηγαίνετε στα γραφήματά σας, όπως περιγράφεται παραπάνω, και κάντε κλικ στο κουμπί `Create chart`.

Παρακάτω ακολουθούν τα απλά βήματα για τη δημιουργία ενός αναλυτικού γραφήματος, ακολουθούμενα από πιο λεπτομερείς οδηγίες.

<Steps>
1. **Χρονική σειρά** Επιλέξτε μια χρονική σειρά για το γράφημά σας. *π.χ. Καθημερινά*.
2. **Τύπος παρακολούθησης** Επιλέξτε αν θα παρακολουθείτε ένα σταθερό χρονικό διάστημα ή συνεχώς. *π.χ. `Continuous`*.
    - Συνεχής: Επιλέξτε μονάδες χρόνου. *π.χ. 7 ημέρες*
    - Σταθερό: Εισάγετε χρονικό διάστημα ημερομηνίας/ώρας *π.χ. 22 Σεπτεμβρίου 2023 16:00 - 29 Σεπτεμβρίου 2023 16:00*.
3. **Νόμισμα εμφάνισης** Αν χειρίζεστε ποσά στο γράφημά σας, επιλέξτε σε ποια νομίσματα θέλετε να τα βλέπετε. *π.χ. USD*.
4. **Παρακολούθηση ακινήτου** Παρακολουθήστε ένα συγκεκριμένο ακίνητο. *Προαιρετικό*
5. **Παρακολούθηση καναλιού πωλήσεων** Παρακολουθήστε την τοποθεσία καναλιού πωλήσεων ανά ήπειρο, χώρα ή πόλη. *Προαιρετικό*
6. **Φιλτράρισμα τύπου καναλιού πωλήσεων** Φιλτράρετε σε συγκεκριμένο τύπο καναλιού πωλήσεων. *π.χ. Influencer*. *Προαιρετικό*
7. **Παρακολούθηση συγκεκριμένου καναλιού πωλήσεων** Παρακολουθήστε ένα συγκεκριμένο κανάλι πωλήσεων. *Προαιρετικό*
8. **Παρακολούθηση ταξιδιώτη** Παρακολουθήστε την τοποθεσία ταξιδιώτη ανά ήπειρο, χώρα ή πόλη. *Προαιρετικό*
9. **Επιλογή δεδομένων** Επιλέξτε τα δεδομένα που θέλετε να παρακολουθείτε. *π.χ. Κρατήσεις & Ακυρώσεις*
10. **Ομαδοποίηση δεδομένων** Αντί να φιλτράρετε ακίνητα ή κανάλια πωλήσεων, μπορείτε επίσης να ομαδοποιήσετε για να συγκεντρώσετε δεδομένα. *π.χ. Ομαδοποίηση ανά κανάλια πωλήσεων*
11. **Όνομα γραφήματος** Δώστε στο γράφημά σας ένα περιγραφικό όνομα. *π.χ. Κρατήσεις Travelbug ανά ώρα*
12. Κάντε κλικ στο κουμπί `Save`.
</Steps>

## Πώς λειτουργεί

Τα γραφήματα επεξεργάζονται με 4 βήματα. Αυτά τα βήματα περιγράφονται παρακάτω.

### Τύπος χρονικής σειράς

Επιλέγοντας ένα σταθερό χρονικό διάστημα ή μια συνεχή χρονική τομή, αρχίζετε να εστιάζετε στο ΠΟΤΕ θέλετε να δείτε δεδομένα.

### Παρακολούθηση / Φιλτράρισμα

Επιλέγοντας ακίνητο, κανάλι πωλήσεων κ.λπ., αρχίζετε να εστιάζετε στο ΠΟΙΟΣ θέλετε να δείτε δεδομένα. Ουσιαστικά φιλτράρετε όλα όσα δεν θέλετε να δείτε.

### Δεδομένα

Επιλέγοντας δεδομένα, αρχίζετε να εστιάζετε στο ΤΙ θέλετε να δείτε.

:::note
Τα δεδομένα πρέπει να είναι 'συνεργιστικά' με τέτοιο τρόπο ώστε να ταιριάζουν σε ένα γράφημα μαζί. Για παράδειγμα, δεν θα συμπεριλαμβάνατε 'Προβολές Σελίδας' και 'Συνολικά Καθαρά Έσοδα' στο ίδιο γράφημα.
:::

### Ομαδοποίηση <Badge text="Νέο" variant="note" />

Η ομαδοποίηση είναι ένας ισχυρός τρόπος για να συγκεντρώσετε και να εστιάσετε σε δεδομένα.

:::tip
Για παράδειγμα, αν είστε ακίνητο και θέλετε να παρακολουθήσετε πόσες κρατήσεις έκανε κάθε κανάλι πωλήσεών σας, θα φιλτράρετε στο ακίνητό σας (παραπάνω), θα επιλέξετε να παρακολουθείτε 'Κρατήσεις' (παραπάνω) και θα ομαδοποιήσετε κατά 'Κανάλι πωλήσεων' στην ενότητα Ομαδοποίηση.
:::

## Αφαίρεση γραφήματος

Για να αφαιρέσετε ένα γράφημα, ακολουθήστε τα παρακάτω βήματα:

<Steps>
1. Κάντε κλικ στον σύνδεσμο `Actions` που υπάρχει κάτω από κάθε γράφημα.
2. Κάντε κλικ στο κουμπί `Remove`.
</Steps>

Το γράφημά σας έχει διαγραφεί.
