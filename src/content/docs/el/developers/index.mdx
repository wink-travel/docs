Κάθε λειτουργία της πλατφόρμας είναι προσβάσιμη εξωτερικά. Αυτή η ενότητα καλύπτει την αυθεντικοποίηση, την επιφάνεια του API, την παράδοση γεγονότων και τα αναφορικά δεδομένα που τη στηρίζουν.

## Ξεκινήστε εδώ

- [Αναπτύξτε στο Wink](/el/developers/build-on-wink/) — τι μπορείτε να δημιουργήσετε και ποιο API ταιριάζει.
- [Ρύθμιση](/el/developers/setup/) — δημιουργήστε μια εφαρμογή και αποκτήστε διαπιστευτήρια.
- [Αυθεντικοποίηση](/el/developers/authentication/) — συνεδρίες OAuth2 και δικαιώματα.

## Η επιφάνεια του API

- [REST και gRPC](/el/developers/rest-and-grpc/) — οι δύο μεταφορές και πότε να χρησιμοποιήσετε κάθε μία.
- [Γεωεντοπισμός](/el/developers/geolocation/) — χωρική αναζήτηση σε διαθέσιμο προς κράτηση απόθεμα.
- [Ταξινομία](/el/developers/taxonomy/) — κωδικοί OTA, υποστηριζόμενες γλώσσες και νομίσματα.
