Κάθε λειτουργία της πλατφόρμας είναι προσβάσιμη εξωτερικά. Αυτή η ενότητα καλύπτει την αυθεντικοποίηση, την επιφάνεια της API, την παράδοση γεγονότων και τα αναφορικά δεδομένα πίσω από αυτή.

## Ξεκινήστε εδώ

- [Γρήγορη εκκίνηση](/el/developers/quickstart/) — από το μηδέν έως τις ζωντανές τιμές ξενοδοχείων και την πρώτη σας δοκιμαστική κράτηση σε περιβάλλον staging.
- [Ανάπτυξη στο Wink](/el/developers/build-on-wink/) — τι μπορείτε να δημιουργήσετε και ποια API ταιριάζει.
- [Ρύθμιση](/el/developers/setup/) — δημιουργήστε μια εφαρμογή και αποκτήστε διαπιστευτήρια.
- [Αυθεντικοποίηση](/el/developers/authentication/) — συνεδρίες OAuth2 και δικαιώματα.

## Η επιφάνεια της API

- [REST και gRPC](/el/developers/rest-and-grpc/) — οι δύο μεταφορές και πότε να χρησιμοποιείτε κάθε μία.
- [Γεωτοποθεσία](/el/developers/geolocation/) — χωρική αναζήτηση σε διαθέσιμο προς κράτηση απόθεμα.
- [Ταξινομία](/el/developers/taxonomy/) — κωδικοί OTA, υποστηριζόμενες γλώσσες και νομίσματα.

## Γεγονότα και συγχρονισμός

- [Ενσωμάτωση Webhook](/el/developers/webhook-integration/) — εγγραφείτε σε γεγονότα της πλατφόρμας.
- [Κατάλογος Γεγονότων Webhook](/el/developers/webhook-events/) — κάθε γεγονός που εκπέμπει η πλατφόρμα.
- [Συγχρονισμός Κρατήσεων](/el/developers/booking-sync/) — διατηρήστε τις κρατήσεις ευθυγραμμισμένες με PMS ή channel manager.

## Πράκτορες AI

- [MCP Servers](/el/developers/mcp/) — διαβάστε τα ζωντανά συμβόλαια API από έναν AI client.
- [Agentic Payments](/el/developers/agentic-payments/) — συνδέστε τον πράκτορά σας, συνδεθείτε, βρείτε δωμάτιο και εγκρίνετε πληρωμή.
- [AI Skills](/el/developers/ai-skills/) — τι μπορεί να κάνει ένας εγκεκριμένος πράκτορας στην πλατφόρμα.
