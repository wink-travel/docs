Αυτός ο οδηγός σας μεταφέρει από το τίποτα σε μια λειτουργική ενσωμάτωση σε περίπου 30 λεπτά. Στο τέλος θα έχετε:

- ζωντανές τιμές για ξενοδοχεία σε μια πόλη, από το Partner API,
- έναν σύνδεσμο κράτησης που πιστώνει τις κρατήσεις στον λογαριασμό σας,
- μια δοκιμαστική κράτηση και ένα webhook που σας ενημερώνει ότι έγινε.

Όλα συμβαίνουν στο **staging**, το περιβάλλον δοκιμών μας. Δεν χρειάζεται να ζητήσετε πρόσβαση από εμάς και η μετάβαση σε παραγωγή αργότερα δεν απαιτεί έγκριση.

## Είναι αυτός ο σωστός οδηγός για εσάς;

| Θέλετε να… | Ξεκινήστε εδώ |
|---|---|
| Εμφανίσετε ξενοδοχεία στην εφαρμογή, στον ιστότοπο ή στο προϊόν AI σας και να στείλετε ταξιδιώτες να κάνουν κράτηση, κερδίζοντας προμήθεια | **Αυτός ο οδηγός** |
| Κάνετε κρατήσεις εκ μέρους των πελατών σας ως αδειοδοτημένο ταξιδιωτικό πρακτορείο | Αυτός ο οδηγός μέχρι το Βήμα 5, μετά [Κράτηση ως ταξιδιωτικό πρακτορείο](#booking-as-a-travel-agency) |
| Ενσωματώσετε ξενοδοχεία με δυνατότητα κράτησης χωρίς να γράψετε ενσωμάτωση | [Web Components](/el/integrations/web-components/) |
| Επιτρέψετε σε έναν πράκτορα AI να αναζητήσει και να κάνει κράτηση | [MCP Servers](/el/developers/mcp/) και [Agentic Payments](/el/developers/agentic-payments/) |
| Συνδέσετε έναν channel manager ή PMS | [Προσθέστε τον Channel Manager σας](/el/guides/integrators/add-your-channel-manager/) |

## Πώς λειτουργεί

Χρησιμοποιείτε το **Partner API** για να βρείτε ξενοδοχεία και τις ζωντανές τιμές τους. Κάθε ξενοδοχείο έχει ένα σταθερό `urlName`. Το μετατρέπετε σε σύνδεσμο προς το Wink Booking Engine, `book.wink.travel`, που μεταφέρει τα IDs σας. Ο ταξιδιώτης κάνει κράτηση και πληρώνει εκεί, και η κράτηση πιστώνεται στον λογαριασμό σας.

## Πριν ξεκινήσετε

Θα χρειαστείτε:

- [`grpcurl`](https://github.com/fullstorydev/grpcurl), ή Postman ή Insomnia. Το Partner API είναι gRPC, όχι REST.
- `curl`.

:::note
Το staging μπαίνει σε αδράνεια όταν δεν το χρησιμοποιεί κανείς. Η πρώτη κλήση μετά από περίοδο ησυχίας μπορεί να διαρκέσει περίπου ένα λεπτό ενώ οι διακομιστές ξυπνούν.
:::

## Βήμα 1: Δημιουργήστε λογαριασμό στο staging

Το staging είναι εντελώς ξεχωριστό από την παραγωγή, με δικά του στοιχεία σύνδεσης και λογαριασμούς.

<Steps>
1. Μεταβείτε στο [staging-app.wink.travel](https://staging-app.wink.travel), κάντε κλικ στο `Sign-In / Register` και εγγραφείτε.

2. Κάντε κλικ στο `Accounts` στην αριστερή πλαϊνή μπάρα, μετά `Create`, και επιλέξτε **I am an Affiliate**. Οι κρατήσεις που στέλνετε πιστώνονται σε αυτόν τον λογαριασμό. Δείτε [Create Account](/el/portal/create-account/).
</Steps>

## Βήμα 2: Δημιουργήστε μια εφαρμογή

Η εφαρμογή δίνει στον κώδικά σας τα διαπιστευτήρια.

<Steps>
1. Στην κάρτα του λογαριασμού σας, κάντε κλικ στο `Actions` > `Manage account`, μετά στην καρτέλα `Applications`.

2. Κάντε κλικ στο `Create new application`, δώστε ένα όνομα και επιλέξτε **Machine-to-machine** ως τύπο πελάτη.

3. Στις scopes, επιλέξτε **Inventory & rates** (read). Το Partner API ελέγχει για `inventory.read`.

4. Κάντε κλικ στο `Create application` και αντιγράψτε το **Client ID** και το **Client secret**. Το μυστικό εμφανίζεται μία φορά και δεν μπορεί να ανακτηθεί αργότερα.
</Steps>

Δείτε [Applications](/el/account/applications/) για τους άλλους τύπους πελατών και scopes.

## Βήμα 3: Πάρτε ένα access token

```bash
curl -X POST https://staging-iam.wink.travel/oauth2/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials" \
  -d "client_id=<YOUR_CLIENT_ID>" \
  -d "client_secret=<YOUR_CLIENT_SECRET>" \
  -d "scope=inventory.read"
```

Αποθηκεύστε το `access_token` από την απάντηση:

```bash
export WINK_TOKEN=<access_token>
```

Τα tokens λήγουν. Στον δικό σας κώδικα, αφήστε μια βιβλιοθήκη OAuth2 να τα ανακτά και να τα ανανεώνει. Δείτε [Authentication](/el/developers/authentication/).

## Βήμα 4: Βρείτε το ID του λογαριασμού σας

Κάθε κλήση στο Partner API ορίζει τον λογαριασμό για τον οποίο ενεργείτε με την κεφαλίδα `managing-entity-id`. Λίστα με τους λογαριασμούς που μπορεί να ενεργεί το token σας:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" \
  -d '{}' \
  staging-partner.wink.travel:443 wink.partner.v1.Accounts/ListAccounts
```

Αντιγράψτε το `accountId` του affiliate λογαριασμού από το Βήμα 1:

```bash
export WINK_ACCOUNT_ID=<accountId>
```

## Βήμα 5: Αναζητήστε ξενοδοχεία σε μια πόλη

{/* TODO(Yann): επιβεβαιώστε την πόλη staging του δοκιμαστικού ξενοδοχείου με διαθεσιμότητα και χρησιμοποιήστε την εδώ. */}

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" \
  -H "managing-entity-id: $WINK_ACCOUNT_ID" \
  -d '{
    "urlName": "bangkok-thailand",
    "userSession": {
      "itinerary": {
        "startDate": "2026-12-01",
        "nights": 2,
        "room": { "adults": 2 }
      },
      "currencyCode": "USD",
      "languageCode": "en"
    }
  }' \
  staging-partner.wink.travel:443 wink.partner.v1.Search/SearchByCity
```

Χρησιμοποιήστε ημερομηνία check-in στο μέλλον· μια παρελθούσα ημερομηνία απορρίπτεται. Κάθε αποτέλεσμα περιλαμβάνει:

- `name`, `starRating` και `heroImageUrl`, αρκετά για να εμφανίσετε μια σειρά αποτελέσματος,
- `roomTypes`, τις ζωντανές προσφορές, το φθηνότερο δωμάτιο πρώτο,
- `urlName`, το slug που χρειάζεστε για τον σύνδεσμο κράτησης.

Οι τιμές είναι ακέραιοι σε μικρές μονάδες: διαιρέστε με 10 στη δύναμη του `currencyExponent` από την απάντηση (2 για USD, οπότε το `12500` είναι $125.00).

Δεν ξέρετε το slug μιας πόλης; Εντοπίστε το με `wink.partner.v1.Lookup/Search`. Για το πλήρες περιεχόμενο ενός ακινήτου, χρησιμοποιήστε την υπηρεσία `Content`. Η [αναφορά Partner API](/el/partner-api/partner/) τεκμηριώνει κάθε κλήση.

## Βήμα 6: Δημιουργήστε τον σύνδεσμο κράτησης

```text
https://staging-book.wink.travel/hotel/<urlName>?client-id=<YOUR_CLIENT_ID>&configuration-id=<YOUR_CUSTOMIZATION_ID>
```

- Το `<urlName>` είναι το `urlName` του ξενοδοχείου από το Βήμα 5.
- Το `client-id` είναι το Client ID της εφαρμογής σας από το Βήμα 2.
- Το `configuration-id` είναι το ID προσαρμογής σας: `Manage account` > `Customizations`. Μια προσαρμογή ορίζει επίσης το branding, την προεπιλεγμένη γλώσσα και το νόμισμα στη σελίδα κράτησης.

:::caution
Συμπεριλάβετε και τα δύο IDs. Χωρίς αυτά η σελίδα φορτώνει, αλλά με προεπιλεγμένο branding, και **η κράτηση δεν πιστώνεται σε εσάς**. Ποτέ μην βάζετε το client secret σε σύνδεσμο.
:::

Δείτε [Linking directly](/el/booking-engine/features/#linking-directly) για σύνδεση στην αρχική σελίδα του booking engine αντί για μεμονωμένο ξενοδοχείο.

## Βήμα 7: Κάντε μια δοκιμαστική κράτηση

Ανοίξτε τον σύνδεσμό σας, επιλέξτε ημερομηνίες και δωμάτιο, και ολοκληρώστε την πληρωμή με μια [δοκιμαστική κάρτα Stripe](https://docs.stripe.com/testing), για παράδειγμα `4242 4242 4242 4242` με οποιαδήποτε μελλοντική ημερομηνία λήξης και οποιοδήποτε CVC. Δεν χρεώνεται πραγματική κάρτα στο staging. Σημειώστε τον κωδικό κράτησης στη σελίδα επιβεβαίωσης· ξεκινά με `WNK`.

## Βήμα 8: Λάβετε ειδοποιήσεις για κρατήσεις

<Steps>
1. Στο Portal, μεταβείτε σε `Applications > Webhooks` και προσθέστε ένα endpoint που δέχεται αιτήματα `POST`.

2. Εγγραφείτε στο `booking.create`, ή αφήστε τη λίστα συμβάντων κενή για να λαμβάνετε τα πάντα όσο αναπτύσσετε.

3. Στείλτε στον εαυτό σας ένα δοκιμαστικό συμβάν, μετά κάντε άλλη μια δοκιμαστική κράτηση και παρακολουθήστε την άφιξή του.
</Steps>

Επαληθεύστε την υπογραφή κάθε παράδοσης πριν την εμπιστευτείτε. Δείτε [Webhook Integration](/el/developers/webhook-integration/) και τον [Κατάλογο Webhook Events](/el/developers/webhook-events/).

## Βήμα 9: Μεταβείτε σε παραγωγή

Δεν υπάρχει βήμα έγκρισης για προγραμματιστές. (Οι λογαριασμοί ταξιδιωτικών πρακτορείων πιστοποιούνται πρώτα· δείτε [παρακάτω](#booking-as-a-travel-agency).) Όταν η ενσωμάτωσή σας λειτουργεί στο staging:

<Steps>
1. Δημιουργήστε λογαριασμό και εφαρμογή στο [app.wink.travel](https://app.wink.travel), όπως στα Βήματα 1 και 2. Τα διαπιστευτήρια δεν μεταφέρονται μεταξύ περιβαλλόντων.

2. Αφαιρέστε το `staging-` από κάθε host:

   | Staging | Παραγωγή |
   |---|---|
   | `https://staging-iam.wink.travel` | `https://iam.wink.travel` |
   | `staging-partner.wink.travel:443` | `partner.wink.travel:443` |
   | `https://staging-book.wink.travel` | `https://book.wink.travel` |

3. Αναζητήστε ξανά το ID του λογαριασμού παραγωγής (Βήμα 4) και το ID προσαρμογής (Βήμα 6). Διαφέρουν από το staging.
</Steps>

Η χρήση του Partner API μετράται σε διανυκτερεύσεις ξενοδοχείων, με δωρεάν μηνιαίο όριο. Δείτε [Partner API](/el/integrations/partner-api/) για τιμολόγηση και όρια.

## Κράτηση ως ταξιδιωτικό πρακτορείο

Αν ο λογαριασμός σας είναι αδειοδοτημένο ταξιδιωτικό πρακτορείο, δεν χρειάζεται να στέλνετε ταξιδιώτες στο `book.wink.travel`: μπορείτε να δημιουργείτε κρατήσεις απευθείας με το `wink.partner.v1.Booking/CreateBooking` και να τις διαχειρίζεστε με τις άλλες κλήσεις `Booking`. Άλλοι λογαριασμοί στέλνουν τους ταξιδιώτες στον σύνδεσμο κράτησης.

Οι λογαριασμοί ταξιδιωτικών πρακτορείων πιστοποιούνται: η Wink ελέγχει κάθε εγγραφή πρακτορείου πριν μπορέσει να κάνει κράτηση. Τα πρακτορεία που θέλουν να εισπράττουν οι ίδιοι την πληρωμή από τους πελάτες τους, ως έμποροι καταγραφής, πρέπει να κάνουν κράτηση μέσω του Partner API και να λάβουν γραπτή έγκριση από τη Wink. Δείτε [Ξεκινώντας ως ταξιδιωτικό πρακτορείο](/el/guides/travel-agents/getting-started/) και την [αναφορά Partner API](/el/partner-api/partner/).
