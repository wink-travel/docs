Η Wink παρέχει δύο πιστοποιημένους διακομιστές MCP. Και οι δύο χρησιμοποιούν **διαδραστική σύνδεση OAuth2** (ροή κωδικού εξουσιοδότησης PKCE) — ο πράκτορας AI σας ανοίγει μια καρτέλα προγράμματος περιήγησης ώστε να συνδεθείτε με τον λογαριασμό σας Wink. Δεν χρειάζεται να διαχειρίζεστε μυστικά πελάτη.

| Διακομιστής | URL | Τι κάνει |
|-------------|-----|----------|
| **Inventory API** | `https://api.wink.travel/mcp` | Απόθεμα, κρατήσεις, τιμές, κανάλια πωλήσεων, αναλύσεις και όλες οι λειτουργίες της πλατφόρμας |
| **Integrations** | `https://integrations.wink.travel/mcp` | Ενσωματώσεις διαχειριστή καναλιών — συγχρονισμός ακινήτων, τιμών και διαθεσιμότητας με OTAs |

## Πώς λειτουργεί η πιστοποίηση

Οι διακομιστές MCP της Wink χρησιμοποιούν τη ροή **OAuth2 Authorization Code + PKCE** και υποστηρίζουν **Dynamic Client Registration (RFC 7591)**. Αυτό συμβαίνει όταν συνδέεστε για πρώτη φορά:

1. Ο πελάτης AI ανακαλύπτει τον διακομιστή εξουσιοδότησης από τα μεταδεδομένα `/.well-known/oauth-protected-resource` του endpoint MCP.
2. Ο πελάτης αυτοεγγράφεται μέσω **Dynamic Client Registration** — δεν απαιτείται χειροκίνητη ρύθμιση εφαρμογής.
3. Ο πελάτης ανοίγει μια **καρτέλα προγράμματος περιήγησης** στο `https://iam.wink.travel`. Συνδέεστε με τον λογαριασμό Wink και εγκρίνετε τα αιτούμενα δικαιώματα στην οθόνη συγκατάθεσης.
4. Η Wink εκδίδει ένα **access token** που σχετίζεται με τον λογαριασμό και την ταυτότητά σας.
5. Ο πελάτης AI επισυνάπτει το token σε κάθε αίτημα MCP. Όλα τα αποτελέσματα εργαλείων περιορίζονται αυτόματα στη διαχειριζόμενη οντότητά σας.
6. Τα tokens λήγουν μετά από 3 ώρες. Ο πελάτης AI ανανεώνει αθόρυβα στο παρασκήνιο χωρίς να ζητήσει ξανά σύνδεση.

Κάθε κλήση εργαλείου εκτελείται **υπό την ταυτότητά σας** — οι ίδιες κανόνες ACL που προστατεύουν την πύλη ισχύουν και για τον πράκτορα AI.

## Συνδέστε τον πελάτη AI σας

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Βεβαιωθείτε ότι το Claude Code είναι ενημερωμένο:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Προσθέστε τον διακομιστή Wink Inventory MCP:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Το Claude Code επικοινωνεί με τον διακομιστή, ανακαλύπτει τον διακομιστή εξουσιοδότησης και ανοίγει το προεπιλεγμένο πρόγραμμα περιήγησής σας.

4. **Συνδεθείτε στη Wink** και εγκρίνετε το αίτημα δικαιωμάτων στην οθόνη συγκατάθεσης.

5. Το Claude Code επιβεβαιώνει τη σύνδεση. Πληκτρολογήστε `/mcp` για να ελέγξετε ότι ο διακομιστής εμφανίζεται και τα εργαλεία έχουν φορτωθεί.
</Steps>

Για να προσθέσετε και τον διακομιστή Integrations:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Μοιραστείτε με την ομάδα σας]
Προσθέστε `--scope project` στο `claude mcp add` και το Claude Code θα γράψει το URL του διακομιστή στο `.mcp.json` στη ρίζα του αποθετηρίου. Κάντε commit αυτό το αρχείο — κάθε μέλος της ομάδας ολοκληρώνει τη δική του σύνδεση μέσω προγράμματος περιήγησης την πρώτη φορά που συνδέεται.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. Προσθέστε τις εγγραφές διακομιστών MCP:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **Κλείστε πλήρως και επανεκκινήστε** το Claude Desktop (χρησιμοποιήστε Quit από τη γραμμή μενού — το κλείσιμο του παραθύρου δεν αρκεί).

4. Το Claude Desktop ανοίγει μια καρτέλα προγράμματος περιήγησης για κάθε νέο διακομιστή. Συνδεθείτε στη Wink και εγκρίνετε τα δικαιώματα.

5. Το εικονίδιο φις στη γραμμή εργαλείων στο κάτω μέρος δείχνει και τους δύο διακομιστές ως συνδεδεμένους.
</Steps>

## Αναφορά δικαιωμάτων (scope)

Όταν εγκρίνετε την οθόνη συγκατάθεσης, θα δείτε ανάλυση των αιτούμενων δικαιωμάτων από τον πράκτορα. Η Wink ομαδοποιεί τα δικαιώματα ανά λειτουργική περιοχή:

| Ομάδα δικαιωμάτων | Δικαιώματα | Τι ξεκλειδώνουν |
|--------------------|------------|------------------|
| **MCP transport** | `mcp.read` `mcp.write` `mcp.remove` | Απαραίτητα για σύνδεση σε οποιονδήποτε διακομιστή MCP |
| **Account** | `account.read` `account.write` `account.remove` | Διαχειριζόμενες οντότητες, μέλη ομάδας, ρυθμίσεις, εφαρμογές |
| **Booking** | `booking.read` `booking.write` `booking.remove` | Αναζήτηση, προβολή, δημιουργία, ακύρωση και επιστροφή κρατήσεων |
| **Inventory** | `inventory.read` `inventory.write` `inventory.remove` | Ακίνητα, δωμάτια, τιμές, παροχές, διαθεσιμότητα |
| **Analytics** | `analytics.read` | Αναλύσεις κρατήσεων, αναφορές εσόδων, πίνακες κατάταξης |
| **Marketing** | `marketing.read` `marketing.write` `marketing.remove` | Κοινωνικές αναρτήσεις, καμπάνιες, κανάλια πωλήσεων, προωθήσεις |
| **Content** | `content.read` `content.write` `content.remove` | Πολυμέσα, συντομευμένα URLs, αντικείμενα για syndication, χάρτες |
| **Payment** | `payment.read` `payment.write` | Λογιστικό βιβλίο, πληρωμές, οικονομικές αναλύσεις, αναλήψεις |

Ο πελάτης AI ζητά μόνο τα δικαιώματα που χρειάζεται. Μπορείτε να αρνηθείτε μεμονωμένα δικαιώματα στην οθόνη συγκατάθεσης — τα εργαλεία που απαιτούν αρνημένο δικαίωμα θα επιστρέψουν σφάλμα κατά την κλήση.

## Αντιμετώπιση προβλημάτων

**Δεν ανοίγει καρτέλα προγράμματος περιήγησης**

Ο πελάτης AI σας μπορεί να μην υποστηρίζει ακόμα τη διαδραστική ροή PKCE. Ελέγξτε ότι τρέχετε πρόσφατη έκδοση:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** αναβαθμίστε μέσω του ενσωματωμένου updater της εφαρμογής

**`401 Unauthorized` μετά τη σύνδεση**

Το αποθηκευμένο token μπορεί να είναι παλιό. Αφαιρέστε και προσθέστε ξανά τον διακομιστή για να ξεκινήσει νέα σύνδεση:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

Για Claude Desktop και ChatGPT, αφαιρέστε την εγγραφή διακομιστή από τις ρυθμίσεις, επανεκκινήστε την εφαρμογή και προσθέστε τον ξανά.

**`403 Forbidden` κατά την κλήση συγκεκριμένου εργαλείου**

Το εργαλείο απαιτεί δικαίωμα που δεν εγκρίθηκε στην οθόνη συγκατάθεσης. Επανασυνδέστε τον διακομιστή — η οθόνη συγκατάθεσης θα εμφανιστεί ξανά και μπορείτε να εγκρίνετε το ελλείπον δικαίωμα.

**Ο διακομιστής εμφανίζεται αλλά οι κλήσεις εργαλείων επιστρέφουν "account not found"**

Έχετε συνδεθεί σε λογαριασμό Wink που δεν έχει διαχειριζόμενη οντότητα. Μεταβείτε στο [Wink Portal](https://app.wink.travel) και βεβαιωθείτε ότι ο λογαριασμός σας έχει ρυθμιστεί πριν χρησιμοποιήσετε τον διακομιστή MCP.

**Το token λήγει κατά τη διάρκεια της συνεδρίας**

Τα tokens ισχύουν για 3 ώρες. Το Claude Code και το Claude Desktop ανανεώνουν τα tokens αθόρυβα χωρίς να διακόπτουν τη συνεδρία σας. Αν δείτε σφάλματα πιστοποίησης μετά από μεγάλη αδράνεια, πληκτρολογήστε νέο μήνυμα — ο πελάτης θα επαληθευτεί αυτόματα ξανά.

**Το Codex CLI εμφανίζει "MCP server unreachable"**

Ελέγξτε ότι το `~/.codex/config.json` είναι έγκυρο JSON (χωρίς κόμματα στο τέλος) και ότι το `"type": "http"` έχει οριστεί. Το Codex απαιτεί HTTP μεταφορά για απομακρυσμένους διακομιστές· η μεταφορά stdio είναι μόνο για τοπικά binaries.

**Το μενού "Connectors" του ChatGPT λείπει**

Η υποστήριξη MCP απαιτεί έκδοση εφαρμογής ChatGPT για υπολογιστές **1.2024.352** ή νεότερη και ενεργή συνδρομή Plus, Pro, Team ή Enterprise. Αναβαθμίστε την εφαρμογή και ελέγξτε το πλάνο σας στις Ρυθμίσεις → Λογαριασμός.

**Ο διακομιστής Cursor εμφανίζει κόκκινο / "Failed to connect"**

Επιβεβαιώστε ότι το `~/.cursor/mcp.json` είναι έγκυρο JSON και περιέχει `"type": "http"`. Μεταβείτε στις **Ρυθμίσεις → Ρυθμίσεις Cursor → MCP** και κάντε κλικ στο **Ανανέωση**. Αν το σφάλμα παραμένει, επανεκκινήστε πλήρως το Cursor — οι αλλαγές ρυθμίσεων δεν εφαρμόζονται πάντα χωρίς επανεκκίνηση.

**Οι διακομιστές MCP του Windsurf δεν εμφανίζονται στις ρυθμίσεις**

Το Windsurf απαιτεί πλήρη επανεκκίνηση (όχι μόνο ανανέωση παραθύρου) για να φορτώσει αλλαγές στο `mcp_config.json`. Χρησιμοποιήστε **Αρχείο → Έξοδος** και ξανανοίξτε. Αν οι διακομιστές δεν εμφανίζονται, βεβαιωθείτε ότι έχετε το Windsurf **1.4+** μέσω **Βοήθεια → Σχετικά με το Windsurf**.

**Η επιλογή "Add Server" στο Cline δεν είναι ορατή**

Ο διαχειριστής διακομιστών MCP απαιτεί Cline **2.0** ή νεότερο. Ανοίξτε το πάνελ Επεκτάσεων VS Code, βρείτε το Cline και κάντε κλικ στο **Ενημέρωση** αν υπάρχει διαθέσιμη. Μετά την ενημέρωση, φορτώστε ξανά το VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
