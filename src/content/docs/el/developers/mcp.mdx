Τα εργαλεία MCP της Wink δημοσιεύονται ως **σύνολα εργαλείων** — εστιασμένα endpoints, το καθένα καλύπτοντας μία εργασία. Συνδέετε τον πελάτη AI σας σε ένα ή δύο που ταιριάζουν με την εργασία σας, όχι σε όλα.

Κάθε endpoint χρησιμοποιεί **διαδραστική σύνδεση OAuth2** (ροή κωδικού εξουσιοδότησης PKCE): ο πράκτορας AI ανοίγει μια καρτέλα προγράμματος περιήγησης, συνδέεστε με τον λογαριασμό Wink σας, και αυτό ήταν. Δεν χρειάζεται να διαχειρίζεστε μυστικά πελάτη.

```bash title="Ένας ενσωματωτής διαχειριστή καναλιών συνδέεται σε ένα endpoint"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="Ένας ξενοδόχος που διαχειρίζεται τις δικές του τιμές συνδέεται σε άλλο"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## Γιατί τα εργαλεία χωρίζονται σε endpoints

Η Wink εκθέτει περίπου 500 εργαλεία. Η παράδοση όλων μαζί σε έναν πράκτορα είναι τεχνικά εφικτή — αλλά κακή ιδέα.

**Οι ορισμοί εργαλείων κοστίζουν πλαίσιο.** Κάθε εργαλείο που διαφημίζει ένας διακομιστής MCP φορτώνεται στο παράθυρο πλαισίου του μοντέλου πριν κάνει οποιαδήποτε εργασία, μαζί με την περιγραφή και το πλήρες σχήμα παραμέτρων του. Πεντακόσια από αυτά καταναλώνουν μεγάλο μέρος του προϋπολογισμού που χρειάζεται η πραγματική σας εργασία, σε κάθε αίτημα.

**Η ποιότητα επιλογής μειώνεται καθώς η λίστα μεγαλώνει.** Ένας πράκτορας που επιλέγει από 500 εργαλεία με παρόμοια ονόματα κάνει χειρότερες επιλογές από έναν που επιλέγει από 40. Αν ενσωματώσετε έναν διαχειριστή καναλιών, περίπου είκοσι εργαλεία είναι σχετικά για εσάς· τα υπόλοιπα 480 είναι θόρυβος που δυσκολεύει την εύρεση του σωστού εργαλείου.

**Η εργασία είναι πραγματικά διαχωρίσιμη.** Κάποιος που συγχρονίζει διαθεσιμότητα από PMS και κάποιος που επιμελείται σελίδες συνεργατών μοιράζονται σχεδόν κανένα εργαλείο. Ο διαχωρισμός κατά εργασία σημαίνει ότι κάθε σύνδεση φέρει το λεξιλόγιο μιας εργασίας.

<Aside type="caution" title="Τα σύνολα εργαλείων δεν είναι δικαιώματα">
Η επιλογή ενός στενού συνόλου εργαλείων **δεν** περιορίζει το τι μπορεί να κάνει ο λογαριασμός σας, και η επιλογή ενός ευρέος δεν παρέχει κάτι επιπλέον. Κάθε εργαλείο εφαρμόζει τα ίδια δικαιώματα λογαριασμού με την πύλη ιστού, υπό την ταυτότητά σας που έχετε συνδεθεί. Αν ο λογαριασμός σας δεν μπορεί να ακυρώσει μια κράτηση στην Πύλη Wink, ούτε ο πράκτορας μπορεί — ανεξάρτητα από το σε ποιο endpoint είναι συνδεδεμένος.

Επιλέξτε σύνολα εργαλείων για **εστίαση**, όχι για ασφάλεια.
</Aside>

## Κατάλογος endpoints

Δύο hosts εξυπηρετούν σύνολα εργαλείων. Οι μετρήσεις εργαλείων είναι κατά προσέγγιση και αυξάνονται με τον χρόνο.

### `https://api.wink.travel` — η πλατφόρμα

| Endpoint | Εργαλεία | Τι καλύπτει |
|---|---:|---|
| `/mcp/extranet/facilities` | ~64 | Το διαθέσιμο και επιτόπιο απόθεμα: δωμάτια και τύποι δωματίων, spa, εστιατόρια, αίθουσες συνεδριάσεων, δραστηριότητες, αξιοθέατα, μέρη, άλλα προς πώληση είδη |
| `/mcp/extranet/property` | ~62 | Το αρχείο ιδιοκτησίας και οι εμπορικοί όροι: προφίλ και περιεχόμενο, πρόσθετα, πολιτικές ακύρωσης, προνόμια, ανακοινώσεις |
| `/mcp/settings` | ~60 | Διαχείριση λογαριασμού: προφίλ και branding διαχειριζόμενης οντότητας, διαχειριστές και δικαιώματα, προσαρμογές, webhooks, προτιμήσεις ειδοποιήσεων |
| `/mcp/studio/embeds` | ~48 | Δημοσίευση επιμελημένου αποθέματος: widgets, πλέγματα και ταξινομημένα πλέγματα, κάρτες, χάρτες, σύνδεσμοι σε βάθος προς απόθεμα και σελίδες προμηθευτών |
| `/mcp/extranet/rates` | ~44 | Τιμές και διαθεσιμότητα: περίοδοι τιμών και ποσοστώσεις αποθέματος, σχέδια τιμών, κύριες τιμές, ειδικές και προωθητικές τιμές |
| `/mcp/extranet/operations` | ~39 | Λειτουργία ζωντανής ιδιοκτησίας: κρατήσεις και ο κύκλος ζωής τους, κριτικές επισκεπτών και απαντήσεις, ροές ημερολογίου, προγραμματισμένες εργασίες |
| `/mcp/extranet/distribution` | ~37 | Πού πωλείται το απόθεμα: κανάλια πωλήσεων και τροποποιητές τιμών, αιτήματα συνεργασίας και προμηθευτών, εγγραφή, συλλογή leads |
| `/mcp/studio/curation` | ~35 | Δημιουργία συλλογών προς εμπορία: στατικές και δυναμικές λίστες, ταξινομημένες λίστες, αποθηκευμένες αναζητήσεις, συγκεντρωτικά στοιχεία ιδιοκτησίας |
| `/mcp/link-manager` | ~28 | Συλλογές συνδέσμων syndication, ο σχεδιασμός τους, κατηγορίες και ετικέτες, συντομευμένα URLs |
| `/mcp/reference` | ~24 | Δεδομένα μόνο για ανάγνωση: χώρες, νομίσματα και συναλλαγματικές ισοτιμίες, γλώσσες, ζώνες ώρας, γεωγραφικές αναζητήσεις, γεωτοποθεσία IP |
| `/mcp/analytics` | ~18 | Αναλύσεις κρατήσεων και εσόδων: επισκοπήσεις, γραφήματα, πίνακες κατάταξης, απόδοση συνεργατών, μετρικές μεριδίου |
| `/mcp/payment` | ~18 | Χρηματοοικονομικές λειτουργίες: καθολικό, αναλήψεις και εκτιμήσεις τελών, συγκεντρωτικά ποσά κρατήσεων |
| `/mcp/booking-engine` | ~17 | Η διαδρομή αγορών για τον ταξιδιώτη: αναζήτηση και αναζήτηση, καλάθι αγορών και ολοκλήρωση, λίστες επιθυμιών, προσαρμογή καμπάνιας |
| `/mcp/social` | ~17 | Συνδεδεμένοι κοινωνικοί λογαριασμοί, δημοσίευση και προγραμματισμός αναρτήσεων, ανάγνωση στατιστικών αναρτήσεων |
| `/mcp/travel-agent` | ~8 | Κρατήσεις που διευκολύνονται από πράκτορα για λογαριασμό ταξιδιωτών, και αναφορές πρακτόρων |

### `https://integrations.wink.travel` — ενσωματώσεις διαχειριστή καναλιών

Ένα endpoint, επειδή αυτός ο host υπάρχει για μία εργασία.

| Endpoint | Εργαλεία | Τι καλύπτει |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | Σύνδεση και επαλήθευση ενσωμάτωσης διαχειριστή καναλιών, PMS ή CRS |

<Aside type="note" title="Ενσωμάτωση διαχειριστή καναλιών έναντι διαχείρισης δικών σας τιμών">
Αυτές είναι διαφορετικές εργασίες για διαφορετικούς ανθρώπους, και δεν μοιράζονται endpoint.

Ένας **πωλητής διαχειριστή καναλιών, PMS ή CRS** ενσωματώνεται μία φορά μέσω `integrations.wink.travel/mcp/channel-manager`, και από τότε ανταλλάσσει ιδιοκτησίες, τιμές, διαθεσιμότητα και κρατήσεις μέσω αυτής της ενσωμάτωσης. Αυτό το μοναδικό endpoint είναι όλη η επιφάνεια.

Ένας **ξενοδόχος που αλλάζει τις δικές του τιμές χειροκίνητα** χρησιμοποιεί τα σύνολα εργαλείων extranet στο `api.wink.travel` — `/mcp/extranet/rates` και φίλους. Αυτά δεν είναι μέρος ενσωμάτωσης διαχειριστή καναλιών και ένας ενσωματωτής δεν έχει λόγο να συνδεθεί σε αυτά.

Η διαχείριση λογαριασμού είναι επίσης στο `api.wink.travel`, στο `/mcp/settings`. Δεν υπάρχει `/mcp/settings` στον host ενσωματώσεων.
</Aside>

Κάθε endpoint φέρει επίσης ένα εργαλείο `ping`, ώστε να μπορείτε να επιβεβαιώσετε ότι η σύνδεση είναι ενεργή πριν ζητήσετε πραγματική εργασία.

## Ποια σύνολα εργαλείων χρειάζομαι;

| Αν είστε… | Συνδεθείτε σε |
|---|---|
| **Ενσωματώνετε διαχειριστή καναλιών, PMS ή CRS** | `integrations.wink.travel/mcp/channel-manager` — μόνο αυτό |
| **Διαχειρίζεστε το περιεχόμενο μιας ιδιοκτησίας** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **Διαχειρίζεστε δωμάτια και τύπους δωματίων** | `/mcp/extranet/facilities` |
| **Διαχειρίζεστε τιμές και διαθεσιμότητα** | `/mcp/extranet/rates` |
| **Διαχειρίζεστε καθημερινές κρατήσεις** | `/mcp/extranet/operations` |
| **Αναπτύσσετε τη διανομή** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **Δημιουργείτε σελίδες συνεργατών** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **Διαχειρίζεστε σελίδες link-in-bio** | `/mcp/link-manager` + `/mcp/social` |
| **Κάνετε κρατήσεις για λογαριασμό ταξιδιωτών** | `/mcp/travel-agent` |
| **Εξοφλείτε χρήματα** | `/mcp/payment` |
| **Δημιουργείτε εμπειρία κράτησης** | `/mcp/booking-engine` + `/mcp/reference` |

Ξεκινήστε με ένα. Προσθέστε άλλο όταν βρείτε ότι ζητάτε κάτι που δεν μπορεί να κάνει — κάθε σύνδεση είναι ανεξάρτητη και η προσθήκη ενός δεν επηρεάζει τα άλλα.

<Aside type="tip" title="Θέλετε ακόμα τα πάντα;">
`https://api.wink.travel/mcp` και `https://integrations.wink.travel/mcp` παραμένουν διαθέσιμα και εξυπηρετούν **όλα** τα εργαλεία στον host τους. Είναι χρήσιμα για εξερεύνηση του τι υπάρχει, αλλά δεν τα προτείνουμε για καθημερινή εργασία: η λίστα εργαλείων είναι αρκετά μεγάλη ώστε να επισκιάζει την εργασία σας και να υποβαθμίζει την επιλογή εργαλείων του πράκτορα. Προτιμήστε τα παραπάνω σύνολα εργαλείων.
</Aside>

## Πώς λειτουργεί η αυθεντικοποίηση

Οι διακομιστές MCP της Wink χρησιμοποιούν τη ροή **OAuth2 Authorization Code + PKCE** και υποστηρίζουν **Δυναμική Εγγραφή Πελάτη (RFC 7591)**. Αυτό συμβαίνει όταν συνδέεστε για πρώτη φορά:

1. Ο πελάτης AI ανακαλύπτει τον διακομιστή εξουσιοδότησης από τα μεταδεδομένα `/.well-known/oauth-protected-resource` του endpoint MCP.
2. Ο πελάτης αυτοεγγράφεται μέσω **Δυναμικής Εγγραφής Πελάτη** — δεν απαιτείται χειροκίνητη ρύθμιση εφαρμογής.
3. Ο πελάτης ανοίγει μια **καρτέλα προγράμματος περιήγησης** στο `https://iam.wink.travel`. Συνδέεστε με τον λογαριασμό Wink και εγκρίνετε τα αιτούμενα δικαιώματα στην οθόνη συγκατάθεσης.
4. Η Wink εκδίδει ένα **token πρόσβασης** που σχετίζεται με τον λογαριασμό σας και την ταυτότητά σας.
5. Ο πελάτης AI επισυνάπτει το token σε κάθε αίτημα MCP. Όλα τα αποτελέσματα εργαλείων περιορίζονται αυτόματα στη διαχειριζόμενη οντότητα σας.
6. Τα tokens λήγουν μετά από 3 ώρες. Ο πελάτης AI ανανεώνει αθόρυβα στο παρασκήνιο χωρίς να ζητά ξανά.

Κάθε κλήση εργαλείου εκτελείται **υπό την ταυτότητά σας** — οι ίδιες κανόνες ACL που προστατεύουν την πύλη ιστού εφαρμόζονται και στον πράκτορα AI.

  <TabItem label="Claude Code">

<Steps>
1. Βεβαιωθείτε ότι το Claude Code είναι ενημερωμένο:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Επιλέξτε ένα σύνολο εργαλείων από τον [κατάλογο παραπάνω](#endpoint-directory) και προσθέστε το. Για παράδειγμα, τιμές και διαθεσιμότητα:
   ```bash
   claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
   ```

3. Το Claude Code επικοινωνεί με τον διακομιστή, ανακαλύπτει τον διακομιστή εξουσιοδότησης και ανοίγει το προεπιλεγμένο πρόγραμμα περιήγησής σας.

4. **Συνδεθείτε στη Wink** και εγκρίνετε το αίτημα δικαιωμάτων στην οθόνη συγκατάθεσης.

5. Το Claude Code επιβεβαιώνει τη σύνδεση. Πληκτρολογήστε `/mcp` για να επαληθεύσετε ότι ο διακομιστής εμφανίζεται και τα εργαλεία του έχουν φορτωθεί.
</Steps>

Προσθέστε όσα σύνολα εργαλείων χρειάζεται η εργασία σας — το καθένα είναι ξεχωριστή εγγραφή διακομιστή με το δικό του όνομα:
```bash
claude mcp add wink-operations https://api.wink.travel/mcp/extranet/operations --transport http
claude mcp add wink-analytics  https://api.wink.travel/mcp/analytics           --transport http
```

Συνδέεστε μόνο μία φορά. Μετά την πρώτη έγκριση στο πρόγραμμα περιήγησης, το Claude Code επαναχρησιμοποιεί τη συνεδρία Wink σας για επιπλέον endpoints Wink.

:::tip[Μοιραστείτε με την ομάδα σας]
Προσθέστε `--scope project` στο `claude mcp add` και το Claude Code γράφει το URL του διακομιστή στο `.mcp.json` στη ρίζα του αποθετηρίου. Κάντε commit αυτό το αρχείο — κάθε μέλος της ομάδας λαμβάνει τα ίδια σύνολα εργαλείων, και ο καθένας ολοκληρώνει τη δική του σύνδεση στο πρόγραμμα περιήγησης την πρώτη φορά που συνδέεται.
:::

<Steps>

7. Κάθε σύνολο εργαλείων εμφανίζεται στη λίστα Connectors σας. Ξεκινήστε μια νέα συνομιλία — τα εργαλεία Wink είναι διαθέσιμα αυτόματα.

## Δικαιώματα (Scopes)

Όταν εγκρίνετε την οθόνη συγκατάθεσης, θα δείτε ανάλυση των αιτημάτων του πράκτορα. Οι πελάτες MCP χρησιμοποιούν το ίδιο λεξιλόγιο δικαιωμάτων με την υπόλοιπη πλατφόρμα — δείτε την πλήρη
[αναφορά δικαιωμάτων στη σελίδα Αυθεντικοποίησης](/el/developers/authentication#scopes).

Δύο πράγματα είναι ειδικά για MCP:

- **Τα δικαιώματα `mcp.read`, `mcp.write`, `mcp.remove` απαιτούνται επιπλέον** για να ανοίξει η μεταφορά MCP. Ένας πελάτης που κατέχει δικαίωμα `mcp.*` επιτρέπεται σε οποιοδήποτε endpoint MCP της Wink, αλλά κάθε εργαλείο που καλεί εφαρμόζει ακόμα το δικαίωμα της ενότητας του endpoint που περιβάλλει (π.χ. `booking.read`).
- **Ο πελάτης AI ζητά μόνο τα δικαιώματα που χρειάζεται.** Μπορείτε να αρνηθείτε μεμονωμένα δικαιώματα στην οθόνη συγκατάθεσης — εργαλεία που απαιτούν αρνηθέν δικαίωμα θα επιστρέψουν σφάλμα όταν κληθούν.

**Τα σύνολα εργαλείων δεν αλλάζουν τίποτα από αυτά.** Το endpoint που συνδέεστε αποφασίζει ποια εργαλεία *εμφανίζονται*, όχι τι *επιτρέπεται* να κάνουν. Η σύνδεση σε `/mcp/payment` δεν παρέχει κανένα χρηματοοικονομικό δικαίωμα που δεν είχατε ήδη, και η σύνδεση σε `/mcp/reference` δεν εμποδίζει ένα εργαλείο εκεί να εφαρμόσει το δικό του δικαίωμα. Η εξουσιοδότηση αποφασίζεται ανά κλήση εργαλείου, από το token σας και τα δικαιώματα του λογαριασμού σας.

## Αντιμετώπιση προβλημάτων

**Δεν ανοίγει καρτέλα προγράμματος περιήγησης**

Ο πελάτης AI σας μπορεί να μην υποστηρίζει ακόμα τη διαδραστική ροή PKCE. Επαληθεύστε ότι τρέχετε πρόσφατη έκδοση:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** αναβαθμίστε από τον ενσωματωμένο updater της εφαρμογής

**`401 Unauthorized` μετά τη σύνδεση**

Το αποθηκευμένο token μπορεί να είναι παλιό. Αφαιρέστε και προσθέστε ξανά τον διακομιστή για να ενεργοποιήσετε νέα σύνδεση:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

Για Claude Desktop και ChatGPT, αφαιρέστε την εγγραφή διακομιστή από τις ρυθμίσεις, επανεκκινήστε την εφαρμογή και προσθέστε τον ξανά.

**`403 Forbidden` κατά την κλήση συγκεκριμένου εργαλείου**

Το εργαλείο απαιτεί δικαίωμα που δεν εγκρίνατε στην οθόνη συγκατάθεσης, ή δικαίωμα που δεν έχει ο λογαριασμός σας. Επανασυνδέστε τον διακομιστή — η οθόνη συγκατάθεσης θα εμφανιστεί ξανά και μπορείτε να εγκρίνετε το ελλείπον δικαίωμα. Αν αποτύχει ξανά, το εργαλείο χρειάζεται δικαίωμα λογαριασμού που δεν έχετε· η σύνδεση σε διαφορετικό σύνολο εργαλείων δεν βοηθά, γιατί τα σύνολα εργαλείων δεν παρέχουν δικαιώματα.

**Το εργαλείο που χρειάζομαι δεν είναι στη λίστα**

Πιθανώς είστε συνδεδεμένοι σε σύνολο εργαλείων που δεν καλύπτει αυτή την εργασία. Ελέγξτε τον [κατάλογο endpoints](#endpoint-directory) και προσθέστε το σύνολο εργαλείων που την καλύπτει — οι συνδέσεις είναι ανεξάρτητες, οπότε η προσθήκη ενός δεν αλλάζει τίποτα στα άλλα. Αν δεν είστε σίγουροι ποιο το έχει, συνδεθείτε προσωρινά στο `https://api.wink.travel/mcp`, βρείτε το εργαλείο, και μετά δείτε ποιο σύνολο εργαλείων το περιλαμβάνει.

**`404 Not Found` σε endpoint συνόλου εργαλείων**

Ελέγξτε προσεκτικά τη διαδρομή — τα nested σύνολα εργαλείων έχουν δύο τμήματα (`/mcp/extranet/rates`, όχι `/mcp/extranet-rates`), και τα flat έχουν ένα (`/mcp/link-manager`). Σημειώστε ότι ένα *μη αυθεντικοποιημένο* αίτημα σε οποιαδήποτε διαδρομή κάτω από `/mcp` επιστρέφει `401`, όχι `404`, οπότε μόνο το `401` δεν δείχνει αν το endpoint υπάρχει.

**Συνδέθηκα στο `api.wink.travel/mcp/channel-manager` και δεν πήρα τίποτα**

Αυτό το endpoint δεν υπάρχει. Η ενσωμάτωση διαχειριστή καναλιών εξυπηρετείται μόνο από το `https://integrations.wink.travel/mcp/channel-manager`. Αν χρειάζεστε επίσης να διαβάζετε ή να γράφετε τις δικές σας τιμές ιδιοκτησίας χειροκίνητα, αυτή είναι ξεχωριστή εργασία σε ξεχωριστό endpoint — δείτε `/mcp/extranet/rates`.

**Ο διακομιστής εμφανίζεται αλλά οι κλήσεις εργαλείων επιστρέφουν "account not found"**

Έχετε συνδεθεί σε λογαριασμό Wink που δεν έχει διαχειριζόμενη οντότητα. Μεταβείτε στο [Wink Portal](https://app.wink.travel) και βεβαιωθείτε ότι ο λογαριασμός σας έχει ρυθμιστεί πριν χρησιμοποιήσετε τον διακομιστή MCP.

**Το token λήγει κατά τη διάρκεια της συνεδρίας**

Τα tokens ισχύουν για 3 ώρες. Το Claude Code και το Claude Desktop ανανεώνουν τα tokens αθόρυβα χωρίς να διακόπτουν τη συνεδρία σας. Αν δείτε σφάλματα αυθεντικοποίησης μετά από μεγάλη αδράνεια, πληκτρολογήστε νέο μήνυμα — ο πελάτης θα επαναπιστοποιηθεί αυτόματα.

**Το Codex CLI δείχνει "MCP server unreachable"**

Ελέγξτε ότι το `~/.codex/config.json` είναι έγκυρο JSON (χωρίς κόμματα στο τέλος) και ότι το `"type": "http"` είναι ρυθμισμένο. Το Codex απαιτεί HTTP μεταφορά για απομακρυσμένους διακομιστές· η μεταφορά stdio είναι μόνο για τοπικά binaries.

**Το μενού "Connectors" του ChatGPT λείπει**

Η υποστήριξη MCP απαιτεί έκδοση εφαρμογής ChatGPT για υπολογιστές **1.2024.352** ή νεότερη και ενεργή συνδρομή Plus, Pro, Team ή Enterprise. Αναβαθμίστε την εφαρμογή και ελέγξτε το πλάνο σας στις Ρυθμίσεις → Λογαριασμός.

**Ο διακομιστής Cursor εμφανίζει κόκκινο / "Failed to connect"**

Επαληθεύστε ότι το `~/.cursor/mcp.json` είναι έγκυρο JSON και περιέχει `"type": "http"`. Μεταβείτε σε **Settings → Cursor Settings → MCP** και κάντε κλικ στο **Refresh**. Αν το σφάλμα παραμένει, επανεκκινήστε πλήρως το Cursor — οι αλλαγές ρυθμίσεων δεν αναγνωρίζονται πάντα χωρίς επανεκκίνηση.

**Οι διακομιστές MCP του Windsurf δεν εμφανίζονται στις ρυθμίσεις**

Το Windsurf απαιτεί πλήρη επανεκκίνηση (όχι μόνο ανανέωση παραθύρου) για να αναγνωρίσει αλλαγές στο `mcp_config.json`. Χρησιμοποιήστε **File → Quit** και ξανανοίξτε. Αν οι διακομιστές δεν εμφανίζονται, βεβαιωθείτε ότι έχετε Windsurf **1.4+** μέσω **Help → About Windsurf**.

**Η επιλογή "Add Server" του Cline δεν είναι ορατή**

Ο διαχειριστής διακομιστών MCP απαιτεί Cline **2.0** ή νεότερο. Ανοίξτε το πάνελ Επεκτάσεων του VS Code, βρείτε το Cline και κάντε κλικ στο **Update** αν υπάρχει διαθέσιμη ενημέρωση. Μετά την ενημέρωση, φορτώστε ξανά το VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
