Αυτή η σελίδα απαριθμεί κάθε γεγονός webhook στο οποίο μπορείτε να εγγραφείτε στο Wink. Για οδηγίες ρύθμισης, δείτε τον [Οδηγό Ενσωμάτωσης Webhook](/el/developers/webhook-integration) ή τη [σελίδα διαχείρισης Webhooks](/el/portal/settings/webhooks).

## Πώς να εγγραφείτε

1. Μεταβείτε στο **Εφαρμογές > Webhooks** στο portal σας.
2. Δημιουργήστε ένα webhook και επιλέξτε τα γεγονότα που θέλετε να λαμβάνετε — ή αφήστε τη λίστα κενή για να λαμβάνετε κάθε γεγονός.
3. Το Wink στέλνει ένα υπογεγραμμένο HTTP POST στο endpoint σας κάθε φορά που συμβαίνει το γεγονός. Δείτε τον [Οδηγό Ενσωμάτωσης Webhook](/el/developers/webhook-integration) για το φάκελο, τις κεφαλίδες, την επαλήθευση υπογραφής και τις επαναλήψεις.

## Κάθε τύπος γεγονότος

Αυτός ο πίνακας δημιουργείται από τον κατάλογο γεγονότων της πλατφόρμας κατά το χρόνο κατασκευής, ώστε να ταιριάζει πάντα με το API.
Οι τύποι γεγονότων που σημειώνονται ως παραδοθέντες συνδέονται με τη σελίδα αναφοράς τους στο [Webhooks API](/el/api/webhooks/), που
τεκμηριώνει το ακριβές σώμα JSON (`WebhookEnvelope` με ένα γεγονός-ειδικό `object`), τις κεφαλίδες `Wink-*` και
την πολιτική επαναλήψεων. Τύποι γεγονότων που δεν παραδίδονται υπάρχουν εσωτερικά (πληρωμές, καθολικό, συγχρονισμός διαχειριστή καναλιών, …) αλλά δεν αποστέλλονται προς το παρόν στους συνδρομητές webhook.

**Παραλήπτες** αναφέρει ποιος λαμβάνει ένα γεγονός: `SUPPLIER` (το ξενοδοχείο), `AFFILIATE` (ένας μεταπωλητής με ενεργό
κανάλι πωλήσεων προς το ξενοδοχείο), `AGENT` (το ταξιδιωτικό πρακτορείο που έκανε την κράτηση) ή `SELF` (η διαχειριστική οντότητα
για την οποία αφορά το γεγονός). Κάθε παραλήπτης λαμβάνει το ίδιο σχήμα payload· οι λεπτομέρειες ανά ρόλο βρίσκονται πίσω από το
URL `links.self` του payload.

:::tip
Ξεκινήστε εγγραφόμενοι σε όλα τα γεγονότα κατά την ανάπτυξη. Μόλις κατανοήσετε ποια payload χρειάζεται το σύστημά σας, περιορίστε τις εγγραφές σας για να μειώσετε τον θόρυβο. Στείλτε στον εαυτό σας ένα δοκιμαστικό γεγονός από **Εφαρμογές > Webhooks** (ή `POST …/webhook/{id}/test`) για να επιβεβαιώσετε το endpoint και τον έλεγχο υπογραφής πριν την ενεργοποίηση.
:::
