Αυτή η σελίδα απαριθμεί κάθε γεγονός webhook στο οποίο μπορείτε να εγγραφείτε στο Wink. Για οδηγίες ρύθμισης, δείτε τον [Οδηγό Ενσωμάτωσης Webhook](/el/guides/developers/webhook-integration) ή τη [σελίδα διαχείρισης Webhooks](/el/portal/settings/webhooks).

## Πώς να εγγραφείτε

1. Μεταβείτε στο **Εφαρμογές > Webhooks** στο portal σας.
2. Δημιουργήστε ένα webhook και επιλέξτε τα γεγονότα που θέλετε να λαμβάνετε.
3. Το Wink στέλνει ένα HTTP POST στο endpoint σας κάθε φορά που συμβαίνει το γεγονός.

Για πλήρη βήματα ρύθμισης και βέλτιστες πρακτικές, δείτε το [Webhook Integration](/el/guides/developers/webhook-integration).

## Διαχείριση γεγονότων οντοτήτων

Γεγονότα για τη διαχείριση οντοτήτων (ιδιοκτησίες, συνεργάτες, εταιρείες) και τη διοίκησή τους.

### Κύκλος ζωής

| Γεγονός | Κλειδί | Περιγραφή |
|---|---|---|
| Δημιουργία οντότητας | `managing_entity.created` | Μια νέα οντότητα διαχείρισης έχει δημιουργηθεί. |
| Διαγραφή οντότητας | `managing_entity.deleted` | Μια οντότητα διαχείρισης έχει διαγραφεί. |
| Ενημέρωση κατάστασης | `managing_entity.status.updated` | Η κατάσταση της οντότητας έχει αλλάξει. |
| Υπό αξιολόγηση | `account.under_review` | Ο λογαριασμός της οντότητας είναι υπό αξιολόγηση. |

### Συνδρομή

| Γεγονός | Κλειδί | Περιγραφή |
|---|---|---|
| Παροχή συνδρομής | `managing_entity.subscription.provisioned` | Μια νέα συνδρομή έχει παρασχεθεί. |
| Αλλαγή συνδρομής | `managing_entity.subscription.changed` | Το πρόγραμμα συνδρομής έχει αλλάξει. |
| Αλλαγή τιμολογίου συνδρομής | `managing_entity.subscription.invoice.changed` | Το τιμολόγιο της συνδρομής έχει ενημερωθεί. |

### Κύκλος ζωής διαχειριστή

| Πρόσκληση διαχειριστή | `managing_entity.manager.invited` | Έχει σταλεί πρόσκληση σε διαχειριστή. |
| Αφαίρεση διαχειριστή | `managing_entity.manager.removed` | Ένας διαχειριστής έχει αφαιρεθεί. |
