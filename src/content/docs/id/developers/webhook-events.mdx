Halaman ini mencantumkan setiap event webhook yang dapat Anda langgani di Wink. Untuk instruksi pengaturan, lihat [Panduan Integrasi Webhook](/id/developers/webhook-integration) atau [halaman pengelolaan Webhooks](/id/portal/settings/webhooks).

## Cara berlangganan

1. Navigasikan ke **Applications > Webhooks** di portal Anda.
2. Buat webhook dan pilih event yang ingin Anda terima.
3. Wink mengirim HTTP POST ke endpoint Anda setiap kali event terjadi.

Untuk langkah pengaturan lengkap dan praktik terbaik, lihat [Integrasi Webhook](/id/developers/webhook-integration).
