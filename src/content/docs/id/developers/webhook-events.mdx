Halaman ini mencantumkan setiap event webhook yang dapat Anda langgani di Wink. Untuk petunjuk pengaturan, lihat [Panduan Integrasi Webhook](/id/developers/webhook-integration) atau [halaman pengelolaan Webhooks](/id/portal/settings/webhooks).

## Cara berlangganan

1. Buka **Applications > Webhooks** di portal Anda.
2. Buat webhook dan pilih event yang ingin Anda terima — atau biarkan daftar kosong untuk menerima semua event.
3. Wink mengirimkan HTTP POST yang ditandatangani ke endpoint Anda setiap kali event terjadi. Lihat [Integrasi Webhook](/id/developers/webhook-integration) untuk informasi tentang amplop, header, verifikasi tanda tangan, dan pengulangan.

## Setiap jenis event

Tabel ini dihasilkan dari katalog event platform saat build, sehingga selalu sesuai dengan API.
Jenis event yang ditandai sebagai delivered terhubung ke halaman referensinya di [Webhooks API](/id/api/webhooks/), yang
mendokumentasikan body JSON tepatnya (`WebhookEnvelope` dengan `object` spesifik event), header `Wink-*` dan
kebijakan pengulangan. Jenis event yang tidak dikirim ada secara internal (pembayaran, ledger, sinkronisasi channel-manager, …) tetapi saat ini tidak dikirim ke pelanggan webhook.

**Penerima** menunjukkan siapa yang menerima event: `SUPPLIER` (hotel), `AFFILIATE` (reseller dengan saluran penjualan aktif ke hotel), `AGENT` (agen perjalanan yang membuat pemesanan) atau `SELF` (entitas pengelola yang menjadi subjek event). Setiap penerima menerima bentuk payload yang sama; detail spesifik per peran ada di URL `links.self` payload.

:::tip
Mulailah dengan berlangganan semua event selama pengembangan. Setelah Anda memahami payload mana yang dibutuhkan sistem Anda, batasi langganan untuk mengurangi kebisingan. Kirimkan event uji dari **Applications > Webhooks** (atau `POST …/webhook/{id}/test`) untuk memastikan endpoint dan pemeriksaan tanda tangan Anda sebelum live.
:::
