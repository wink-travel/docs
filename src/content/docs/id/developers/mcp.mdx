Alat MCP Wink diterbitkan sebagai **toolset** — endpoint terfokus, masing-masing mencakup satu tugas. Anda menghubungkan klien AI Anda ke satu atau dua yang sesuai dengan pekerjaan Anda, bukan ke semuanya.

Setiap endpoint menggunakan **login OAuth2 interaktif** (alur kode otorisasi PKCE): agen AI Anda membuka tab browser, Anda masuk dengan akun Wink Anda, dan selesai. Tidak ada rahasia klien yang perlu dikelola.

```bash title="Integrator manajer saluran menghubungkan ke satu endpoint"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="Seorang hotelier yang mengelola tarifnya sendiri menghubungkan ke endpoint lain"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## Mengapa alat dibagi ke beberapa endpoint

Wink menyediakan sekitar 500 alat. Memberikan semuanya sekaligus ke agen secara teknis mungkin — dan itu ide yang buruk.

**Definisi alat memakan konteks.** Setiap alat yang diiklankan oleh server MCP dimuat ke dalam jendela konteks model sebelum melakukan pekerjaan apa pun, bersama dengan deskripsi dan skema parameter lengkapnya. Lima ratus alat tersebut menghabiskan sebagian besar anggaran yang dibutuhkan tugas Anda, pada setiap permintaan.

**Kualitas pilihan menurun seiring daftar bertambah.** Agen yang memilih dari 500 alat dengan nama serupa membuat pilihan yang lebih buruk dibandingkan yang memilih dari 40. Jika Anda mengintegrasikan manajer saluran, sekitar dua puluh alat relevan untuk Anda; 480 lainnya adalah gangguan yang membuat alat yang tepat sulit ditemukan.

**Pekerjaan benar-benar dapat dipisahkan.** Seseorang yang menyinkronkan ketersediaan dari PMS dan seseorang yang mengkurasi halaman afiliasi hampir tidak berbagi alat. Memisahkan berdasarkan tugas berarti setiap koneksi membawa kosakata satu tugas.

<Aside type="caution" title="Toolset bukanlah izin">
Memilih toolset yang sempit **tidak** membatasi apa yang dapat dilakukan akun Anda, dan memilih yang luas tidak memberikan hak tambahan. Setiap alat menegakkan izin akun yang sama seperti portal web, di bawah identitas Anda yang masuk. Jika akun Anda tidak dapat membatalkan pemesanan di Wink Portal, agen juga tidak bisa — terlepas dari endpoint mana yang terhubung.

Pilih toolset untuk **fokus**, bukan untuk keamanan.
</Aside>

## Direktori endpoint

Dua host melayani toolset. Jumlah alat adalah perkiraan dan bertambah seiring waktu.

### `https://api.wink.travel` — platform

| Endpoint | Alat | Cakupan |
|---|---:|---|
| `/mcp/extranet/facilities` | ~64 | Inventaris yang dapat dipesan dan di lokasi: kamar tamu dan tipe kamar, spa, restoran, ruang rapat, aktivitas, atraksi, tempat, barang jual lainnya |
| `/mcp/extranet/property` | ~62 | Rekam properti dan ketentuan komersialnya: profil dan konten, tambahan, kebijakan pembatalan, keuntungan, pengumuman |
| `/mcp/settings` | ~60 | Administrasi akun: profil dan branding entitas pengelola, manajer dan haknya, kustomisasi, webhook, preferensi notifikasi |
| `/mcp/studio/embeds` | ~48 | Menerbitkan inventaris yang dikurasi: widget, grid dan grid berperingkat, kartu, peta, tautan dalam ke inventaris dan halaman pemasok |
| `/mcp/extranet/rates` | ~44 | Harga dan ketersediaan: periode tarif inventaris dan alokasi, rencana tarif, tarif utama, tarif khusus dan promosi |
| `/mcp/extranet/operations` | ~39 | Menjalankan properti secara langsung: reservasi dan siklus hidupnya, ulasan tamu dan tanggapan, feed kalender, tugas terjadwal |
| `/mcp/extranet/distribution` | ~37 | Tempat inventaris dijual: saluran penjualan dan pengubah tarif, permintaan hubungan afiliasi dan pemasok, pendaftaran, penangkapan prospek |
| `/mcp/studio/curation` | ~35 | Membangun koleksi yang dapat dipasarkan: daftar statis dan dinamis, daftar berperingkat, pencarian tersimpan, agregat properti |
| `/mcp/link-manager` | ~28 | Koleksi tautan sindikasi, desainnya, kategori dan tag, plus URL yang dipersingkat |
| `/mcp/reference` | ~24 | Data lookup hanya baca: negara, mata uang dan nilai tukar, bahasa, zona waktu, lookup geo, geolokasi IP |
| `/mcp/analytics` | ~18 | Analitik pemesanan dan pendapatan: gambaran umum, grafik garis, papan peringkat, kinerja afiliasi, metrik berbagi |
| `/mcp/payment` | ~18 | Operasi keuangan: buku besar, penarikan dan estimasi biaya, agregat dana pemesanan |
| `/mcp/booking-engine` | ~17 | Jalur belanja untuk pelancong: pencarian dan lookup, keranjang belanja dan checkout, daftar bucket, kustomisasi kampanye |
| `/mcp/social` | ~17 | Akun sosial terhubung, penerbitan dan penjadwalan posting, membaca wawasan posting |
| `/mcp/travel-agent` | ~8 | Pemesanan yang difasilitasi agen atas nama pelancong, dan laporan agen |

### `https://integrations.wink.travel` — integrasi manajer saluran

Satu endpoint, karena host ini ada untuk satu tugas.

| Endpoint | Alat | Cakupan |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | Menghubungkan dan memverifikasi integrasi manajer saluran, PMS, atau CRS |

<Aside type="note" title="Mengintegrasikan manajer saluran vs. mengelola tarif sendiri">
Ini adalah tugas berbeda untuk orang yang berbeda, dan mereka tidak berbagi endpoint.

**Vendor manajer saluran, PMS, atau CRS** mengintegrasikan sekali melalui `integrations.wink.travel/mcp/channel-manager`, dan sejak itu bertukar properti, tarif, ketersediaan, dan reservasi melalui integrasi itu. Endpoint tunggal itu adalah seluruh permukaan.

**Hotelier yang mengubah tarif sendiri secara manual** menggunakan toolset extranet di `api.wink.travel` — `/mcp/extranet/rates` dan kawan-kawannya. Itu bukan bagian dari integrasi manajer saluran dan integrator tidak perlu menghubungkannya.

Administrasi akun juga ada di `api.wink.travel`, di `/mcp/settings`. Tidak ada `/mcp/settings` di host integrasi.
</Aside>

Setiap endpoint juga membawa alat `ping`, sehingga Anda dapat memastikan koneksi aktif sebelum memintanya melakukan pekerjaan nyata.

## Toolset mana yang saya butuhkan?

| Jika Anda… | Hubungkan ke |
|---|---|
| **Mengintegrasikan manajer saluran, PMS, atau CRS** | `integrations.wink.travel/mcp/channel-manager` — hanya ini saja |
| **Mengelola konten properti** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **Mengelola kamar dan tipe kamar** | `/mcp/extranet/facilities` |
| **Mengelola harga dan ketersediaan** | `/mcp/extranet/rates` |
| **Menjalankan reservasi sehari-hari** | `/mcp/extranet/operations` |
| **Mengembangkan distribusi** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **Membangun halaman afiliasi** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **Menjalankan halaman link-in-bio** | `/mcp/link-manager` + `/mcp/social` |
| **Memesan atas nama pelancong** | `/mcp/travel-agent` |
| **Menyelesaikan keuangan** | `/mcp/payment` |
| **Membangun pengalaman pemesanan** | `/mcp/booking-engine` + `/mcp/reference` |

Mulailah dengan satu. Tambahkan yang lain saat Anda menemukan sesuatu yang tidak bisa dilakukan — setiap koneksi independen, dan menambah satu tidak memengaruhi yang lain.

<Aside type="tip" title="Masih ingin semuanya?">
`https://api.wink.travel/mcp` dan `https://integrations.wink.travel/mcp` tetap tersedia dan melayani **semua** alat di host mereka. Mereka berguna untuk menjelajahi apa yang ada, tapi kami tidak menyarankan untuk pekerjaan sehari-hari: daftar alat terlalu besar sehingga mengganggu tugas Anda dan menurunkan kualitas pemilihan alat agen. Lebih baik gunakan toolset di atas.
</Aside>

## Cara kerja autentikasi

Server MCP Wink menggunakan alur **OAuth2 Authorization Code + PKCE** dan mendukung **Dynamic Client Registration (RFC 7591)**. Berikut yang terjadi saat Anda menghubungkan untuk pertama kali:

1. Klien AI Anda menemukan server otorisasi dari metadata `/.well-known/oauth-protected-resource` endpoint MCP.
2. Klien mendaftar sendiri melalui **Dynamic Client Registration** — tidak perlu pengaturan aplikasi manual.
3. Klien membuka **tab browser** ke `https://iam.wink.travel`. Anda masuk dengan akun Wink dan menyetujui izin yang diminta di layar persetujuan.
4. Wink mengeluarkan **token akses** yang dibatasi ke akun Anda dan terhubung ke identitas Anda.
5. Klien AI melampirkan token ke setiap permintaan MCP. Semua hasil alat otomatis dibatasi ke entitas pengelola Anda.
6. Token kedaluwarsa setelah 3 jam. Klien AI Anda menyegarkan secara diam-diam di latar belakang tanpa meminta lagi.

Setiap panggilan alat berjalan **di bawah identitas Anda** — aturan ACL yang sama yang melindungi portal web berlaku untuk agen AI.

## Scope

Saat Anda menyetujui layar persetujuan, Anda akan melihat rincian apa yang diminta agen. Klien MCP menggunakan kosakata izin yang sama dengan platform — lihat referensi lengkap [scope di halaman Autentikasi](/id/developers/authentication#scopes).

Dua hal spesifik untuk MCP:

- **Scope `mcp.read` `mcp.write` `mcp.remove` juga diperlukan** untuk membuka transport MCP. Klien yang memegang scope `mcp.*` diizinkan ke endpoint MCP Wink mana pun, tapi setiap alat yang dipanggil tetap menegakkan scope bagian dari endpoint yang dibungkusnya (misal `booking.read`).
- **Klien AI hanya meminta scope yang dibutuhkan.** Anda dapat menolak izin individu di layar persetujuan — alat yang memerlukan scope yang ditolak akan mengembalikan error saat dipanggil.

**Toolset tidak mengubah ini.** Endpoint yang Anda hubungkan menentukan alat mana yang *terdaftar*, bukan apa yang *diizinkan dilakukan*. Menghubungkan ke `/mcp/payment` tidak memberikan izin keuangan yang belum Anda miliki, dan menghubungkan ke `/mcp/reference` tidak menghentikan alat di sana menegakkan scope-nya sendiri. Otorisasi diputuskan per panggilan alat, dari token dan hak akun Anda.

## Pemecahan masalah

**Tab browser tidak terbuka**

Klien AI Anda mungkin belum mendukung alur PKCE interaktif. Pastikan Anda menjalankan versi terbaru:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** perbarui dari updater bawaan aplikasi

**`401 Unauthorized` setelah masuk**

Token cache Anda mungkin sudah kadaluwarsa. Hapus dan tambahkan kembali server untuk memicu masuk baru:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

Untuk Claude Desktop dan ChatGPT, hapus entri server dari pengaturan, mulai ulang aplikasi, dan tambahkan lagi.

**`403 Forbidden` saat memanggil alat tertentu**

Alat memerlukan scope yang tidak Anda setujui di layar persetujuan, atau izin yang tidak dimiliki akun Anda. Sambungkan kembali server — layar persetujuan akan muncul lagi dan Anda dapat menyetujui izin yang kurang. Jika masih gagal, alat memerlukan izin akun yang tidak Anda miliki; menghubungkan ke toolset lain tidak akan membantu, karena toolset tidak memberikan izin.

**Alat yang saya butuhkan tidak ada di daftar**

Anda mungkin terhubung ke toolset yang tidak mencakup tugas itu. Periksa [direktori endpoint](#endpoint-directory) dan tambahkan toolset yang mencakupnya — koneksi independen, jadi menambah satu tidak mengubah yang lain. Jika ragu, sambungkan sementara ke `https://api.wink.travel/mcp`, temukan alatnya, lalu cari toolset yang mencantumkannya.

**`404 Not Found` pada endpoint toolset**

Periksa jalur dengan teliti — toolset bertingkat memiliki dua segmen (`/mcp/extranet/rates`, bukan `/mcp/extranet-rates`), dan yang datar satu segmen (`/mcp/link-manager`). Perlu dicatat bahwa permintaan *tanpa autentikasi* ke jalur mana pun di bawah `/mcp` mengembalikan `401`, bukan `404`, jadi `401` saja tidak menunjukkan apakah endpoint ada.

**Saya menghubungkan ke `api.wink.travel/mcp/channel-manager` dan tidak ada apa-apa**

Endpoint itu tidak ada. Integrasi manajer saluran hanya dilayani dari `https://integrations.wink.travel/mcp/channel-manager`. Jika Anda juga perlu membaca atau menulis tarif properti sendiri secara manual, itu tugas terpisah di endpoint terpisah — lihat `/mcp/extranet/rates`.

**Server muncul tapi panggilan alat mengembalikan "account not found"**

Anda masuk ke akun Wink yang tidak memiliki entitas pengelola. Pergi ke [Wink Portal](https://app.wink.travel) dan pastikan akun Anda sudah disiapkan sebelum menggunakan server MCP.

**Token kedaluwarsa di tengah sesi**

Token berlaku selama 3 jam. Claude Code dan Claude Desktop menyegarkan token secara diam-diam tanpa mengganggu sesi Anda. Jika Anda melihat error autentikasi setelah lama tidak aktif, ketik pesan baru — klien akan mengautentikasi ulang otomatis.

**Codex CLI menunjukkan "MCP server unreachable"**

Periksa bahwa `~/.codex/config.json` adalah JSON valid (tanpa koma di akhir) dan `"type": "http"` sudah disetel. Codex memerlukan transport HTTP untuk server jarak jauh; transport stdio hanya untuk binary lokal.

**Menu "Connectors" ChatGPT hilang**

Dukungan MCP memerlukan versi aplikasi desktop ChatGPT **1.2024.352** atau lebih baru dan langganan Plus, Pro, Team, atau Enterprise aktif. Perbarui aplikasi dan periksa paket Anda di Settings → Account.

**Server Cursor menunjukkan merah / "Failed to connect"**

Pastikan `~/.cursor/mcp.json` adalah JSON valid dan berisi `"type": "http"`. Lalu pergi ke **Settings → Cursor Settings → MCP** dan klik **Refresh**. Jika error berlanjut, mulai ulang Cursor sepenuhnya — perubahan konfigurasi tidak selalu terdeteksi tanpa restart.

**Server MCP Windsurf tidak muncul di pengaturan**

Windsurf memerlukan restart penuh (bukan hanya reload jendela) untuk memuat perubahan `mcp_config.json`. Gunakan **File → Quit** dan buka kembali. Jika server masih tidak muncul, pastikan Anda menggunakan Windsurf **1.4+** melalui **Help → About Windsurf**.

**Opsi "Add Server" Cline tidak terlihat**

Pengelola server MCP memerlukan Cline **2.0** atau lebih baru. Buka panel Extensions VS Code, cari Cline, dan klik **Update** jika tersedia. Setelah memperbarui, muat ulang VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
