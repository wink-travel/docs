Booking Engine dapat disematkan di mana saja. Pilih framework atau CMS Anda dan ikuti panduannya; Web Components yang mendasari sama di mana-mana.

## Pendekatan inti

- [Web Components](/id/integrations/web-components/) — elemen yang dapat disematkan yang digunakan setiap integrasi.
- [npm package](/id/integrations/npm/) — pasang ke dalam build JavaScript.
- [Headless CMS](/id/integrations/headless/) — render dari backend konten mana pun.
- [Partner API](/id/integrations/partner-api/) — integrasi programatik penuh.
