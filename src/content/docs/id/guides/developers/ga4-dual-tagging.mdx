Dengan menghubungkan properti Google Analytics 4 Anda ke Wink, event pemesanan Anda — mulai dari tampilan kamar hingga pemesanan yang selesai — secara otomatis diteruskan ke dashboard GA4 Anda sendiri bersamaan dengan analitik Wink. Tanpa kode, tanpa pengaturan teknis dari pihak Anda.

<Aside type="tip">
Anda memerlukan dua hal dari GA4: **Measurement ID** dan **Measurement Protocol API secret**. Measurement ID menggerakkan funnel penelusuran di browser tamu; API secret memungkinkan Wink merekam pemesanan yang selesai (`purchase`) **di sisi server**, sehingga penjualan tidak pernah hilang saat tamu dialihkan ke dan dari penyedia pembayaran.
</Aside>

---

## Cara Kerjanya

```
Anda memasukkan Measurement ID (G-XXXXXXXXXX) dan API secret di portal Wink
       ↓
Event penelusuran (tampilan, keranjang, checkout) mengalir ke properti GA4 Anda dari browser
Pemesanan yang selesai (purchase) dikirim dari sisi server — bertahan dari pengalihan pembayaran
       ↓
Anda masuk ke analytics.google.com dan melihat funnel pemesanan lengkap Anda
```

---

## Yang Perlu Anda Lakukan

<Steps>

1. **Buat Properti GA4**

   Buka [analytics.google.com](https://analytics.google.com): Admin → Buat Properti. Atur zona waktu dan mata uang sesuai pasar Anda.

2. **Buat Web Data Stream**

   Admin → Data Streams → Tambah Stream → Web. Masukkan `wink.travel` sebagai URL. Ini menghasilkan **Measurement ID** (`G-XXXXXXXXXX`). Salin ID tersebut.

3. **Buat Measurement Protocol API Secret**

   Buka Web Data Stream yang sama → gulir ke **Measurement Protocol API secrets** → **Buat**. Beri nama panggilan (misal "Wink") dan salin **nilai rahasia** yang dihasilkan. Rahasia ini memungkinkan Wink merekam pemesanan yang selesai di sisi server, sehingga penjualan tidak hilang selama pengalihan pembayaran.

4. **Masukkan Measurement ID dan API Secret Anda di Portal Wink**

   Masuk ke [app.wink.travel](https://app.wink.travel), pilih akun Anda, dan buka tab **Customizations**. Tempel Measurement ID dan API secret Anda ke kolom **GA4** dan simpan. Selesai — integrasi GA4 Anda sekarang aktif.

   <Aside type="note">
   API secret bersifat **write-only**: setelah disimpan tidak akan ditampilkan lagi. Saat mengedit nanti, biarkan kolom rahasia kosong untuk mempertahankan nilai yang sudah tersimpan.
   </Aside>

5. **Tandai `purchase` sebagai Event Kunci**

   Kembali ke properti GA4 Anda: Admin → Events → cari `purchase` → aktifkan **Mark as key event**. Ini membuat pemesanan yang selesai muncul di laporan Konversi Anda.

6. **Lihat Data Anda**

   Masuk ke [analytics.google.com](https://analytics.google.com) dan Anda akan melihat pemesanan, pendapatan, dan funnel tamu — semua dilacak otomatis melalui Wink.

</Steps>

<Aside type="note">
Anda tidak perlu memasang kode pelacakan apa pun di situs web Anda untuk integrasi ini. Wink menangani semuanya. Measurement ID Anda adalah tujuan pengiriman data pemesanan, dan API secret memungkinkan Wink mengonfirmasi pemesanan yang selesai di sisi server.
</Aside>

<Aside type="tip">
**GA4 dan GTM dapat digunakan bersamaan.** Jika Anda juga menjalankan container Google Tag Manager (misalnya container Sojern), Anda dapat mengonfigurasi keduanya sekaligus — mereka tidak lagi saling eksklusif. Lihat [Integrasi GTM Analytics](/id/guides/developers/gtm-dual-tagging).
</Aside>

## Apa yang Bisa Anda Lacak

Setelah terhubung, properti GA4 Anda menerima rangkaian lengkap event Enhanced E-commerce untuk properti Anda:

### Penemuan

| Event | Artinya |
|---|---|
| `view_item_list` | Tamu melihat properti Anda dalam pencarian atau daftar kategori |
| `select_item` | Tamu mengklik properti Anda dari daftar |
| `view_item` | Tamu melihat halaman detail hotel Anda |

### Pertimbangan

| Event | Artinya |
|---|---|
| `view_promotion` | Tamu melihat penawaran promosi untuk properti Anda |
| `select_promotion` | Tamu mengklik penawaran promosi |
| `add_to_wishlist` | Tamu menyimpan properti Anda ke daftar keinginan mereka |

### Funnel Pemesanan

| Event | Artinya |
|---|---|
| `add_to_cart` | Tamu memilih kamar atau paket |
| `view_cart` | Tamu melihat ringkasan pemesanan mereka |
| `remove_from_cart` | Tamu menghapus kamar atau paket |
| `begin_checkout` | Tamu memulai proses checkout |
| `add_payment_info` | Tamu memasukkan detail pembayaran mereka |
| `add_shipping_info` | Tamu memasukkan detail tamu mereka |
| `purchase` | Tamu menyelesaikan pemesanan |
| `refund` | Pemesanan dibatalkan dan dikembalikan dana |

Semua event mencakup dimensi relevan seperti pendapatan, mata uang, tipe kamar, dan nilai pemesanan — memberi Anda gambaran lengkap perjalanan tamu dari kesan pertama hingga pemesanan selesai. Untuk membuka dimensi tambahan tingkat properti dan kamar seperti `city_name`, `cancellation_policy`, `bed_type`, dan lainnya, lihat [Dimensi Kustom di GA4](/id/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4).

## Pelacakan Lintas Domain (Lanjutan)

Integrasi standar di atas melacak semua yang terjadi di dalam Wink. Namun, jika Anda ingin melacak tamu dari situs web Anda sendiri hingga pemesanan selesai di Wink — dan mengatribusikan sumber lalu lintas asli dengan benar (Google Ads, kampanye email, pencarian organik, dll.) — satu langkah tambahan diperlukan di masing-masing sisi.

<Aside type="caution">
Bagian ini hanya berlaku jika Anda memasang GA4 di situs web Anda sendiri. Jika Anda tidak menjalankan GA4 di situs Anda, integrasi standar di atas sudah cukup.
</Aside>

### Mengapa Ini Penting

Tanpa pelacakan lintas domain, tamu yang mengunjungi situs web Anda terlebih dahulu lalu memesan di Wink akan muncul di GA4 Anda sebagai sesi **Direct** tanpa kaitan dengan kunjungan sebelumnya. Klik Google Ads, kampanye email, atau kunjungan pencarian organik yang mengarah ke pemesanan tidak akan mendapatkan kredit.

Dengan pelacakan lintas domain dikonfigurasi, Anda melihat perjalanan tamu secara lengkap:

```
google.com (iklan berbayar)
       ↓
situs web Anda (tamu menelusuri kamar)
       ↓
wink.travel (tamu memilih kamar dan memesan)
       ↓
purchase diatribusikan dengan benar ke klik Google Ads asli
```

### Tindakan yang Diperlukan: Anda

Konfigurasikan properti GA4 Anda untuk mengenali `wink.travel` sebagai bagian dari domain Anda sendiri, bukan sebagai rujukan eksternal. Ini memberi tahu GA4 untuk menggabungkan dua sesi menjadi satu perjalanan tamu yang berkelanjutan.

<Steps>
1. GA4 Admin → Data Streams → stream Anda
2. Konfigurasikan pengaturan tag → **Konfigurasikan domain Anda**
3. Tambahkan `wink.travel` sebagai domain yang terhubung
4. Simpan
</Steps>

### Tindakan yang Diperlukan: Wink

Hubungi [Wink Support](https://app.wink.travel) dan berikan domain situs web Anda (misal `yourhotel.com`). Wink akan menambahkan domain Anda ke daftar pengecualian rujukan di properti GA4 Wink. Ini mencegah situs web Anda tercatat sebagai sumber rujukan, yang jika tidak akan menimpa atribusi asli tamu dan memulai sesi baru.

<Aside type="tip">
Integrasi standar di atas sudah cukup untuk sebagian besar properti dan memberi Anda visibilitas langsung ke pemesanan dan pendapatan di Wink. Pelacakan lintas domain adalah opsi lanjutan yang layak disiapkan setelah Anda nyaman dengan data GA4 Anda dan menginginkan wawasan atribusi yang lebih mendalam.
</Aside>
