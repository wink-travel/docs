Booking Engine kan integreres overalt. Vælg dit framework eller CMS og følg dets guide; de underliggende Web Components er de samme overalt.

## Kernemetoder

- [Web Components](/da/integrations/web-components/) — de indlejrede elementer, som alle integrationer bruger.
- [npm package](/da/integrations/npm/) — installer i et JavaScript-build.
- [Headless CMS](/da/integrations/headless/) — gengiv fra enhver indholdsbackend.
- [Partner API](/da/integrations/partner-api/) — fuld programmatisk integration.
