Wink udstiller to godkendte MCP-servere. Begge bruger **interaktiv OAuth2-login** (PKCE autorisationskode-flow) — din AI-agent åbner en browsertab, så du kan logge ind med din Wink-konto. Ingen klienthemmeligheder at administrere.

| Server | URL | Hvad den gør |
|--------|-----|--------------|
| **Inventory API** | `https://api.wink.travel/mcp` | Lager, bookinger, priser, salgskanaler, analyser og alle platformoperationer |
| **Integrations** | `https://integrations.wink.travel/mcp` | Channel manager-integrationer — synkroniser ejendomme, priser og tilgængelighed med OTA'er |

---

## Sådan fungerer autentificering

Wink MCP-servere bruger **OAuth2 Authorization Code + PKCE** flow og understøtter **Dynamic Client Registration (RFC 7591)**. Sådan foregår det, når du forbinder første gang:

1. Din AI-klient finder autorisationsserveren via MCP-endpointets `/.well-known/oauth-protected-resource` metadata.
2. Klienten registrerer sig selv via **Dynamic Client Registration** — ingen manuel applikationsopsætning nødvendig.
3. Klienten åbner en **browsertab** til `https://iam.wink.travel`. Du logger ind med din Wink-konto og godkender de ønskede tilladelser på samtykkeskærmen.
4. Wink udsteder et **access token** knyttet til din konto og identitet.
5. AI-klienten vedhæfter token til alle MCP-forespørgsler. Alle værktøjsresultater er automatisk begrænset til din administrerende enhed.
6. Tokens udløber efter 3 timer. Din AI-klient opdaterer stille i baggrunden uden at bede om login igen.

Hver værktøjsanmodning kører **under din identitet** — de samme ACL-regler, der beskytter webportalen, gælder for AI-agenten.

## Forbind din AI-klient

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Sørg for, at Claude Code er opdateret:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Tilføj Wink Inventory MCP-serveren:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code kontakter serveren, finder autorisationsserveren og åbner din standardbrowser.

4. **Log ind på Wink** og godkend tilladelsesforespørgslen på samtykkeskærmen.

5. Claude Code bekræfter forbindelsen. Skriv `/mcp` for at kontrollere, at serveren vises, og at dens værktøjer er indlæst.
</Steps>

For også at tilføje Integrations-serveren:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Del med dit team]
Tilføj `--scope project` til `claude mcp add`, og Claude Code skriver server-URL'en til `.mcp.json` i rodmappen af dit repo. Commit den fil — hver teammedlem gennemfører deres egen browser-login første gang, de forbinder.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Rediger Claude Desktop konfigurationsfil:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. Tilføj MCP-serveroplysningerne:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **Afslut helt og genstart** Claude Desktop (brug Quit i menulinjen — det er ikke nok at lukke vinduet).

4. Claude Desktop åbner en browsertab for hver ny server. Log ind på Wink og godkend tilladelser.

5. Stik-ikonet i bundværktøjslinjen viser begge servere som forbundet.
</Steps>

  </TabItem>
  <TabItem label="OpenAI Codex">

<Steps>

   ```bash
   npm install -g @openai/codex
   ```

2. Åbn (eller opret) Codex konfigurationsfil:
   - **macOS / Linux:** `~/.codex/config.json`
   - **Windows:** `%USERPROFILE%\.codex\config.json`

3. Tilføj Wink MCP-serveroplysningerne:

   ```json title="~/.codex/config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

4. Start Codex. Ved første brug åbner Codex en browsertab til `https://iam.wink.travel`.

5. **Log ind på Wink** og godkend de ønskede tilladelser.

6. Codex bekræfter forbindelsen. Kør `codex` og bed den liste tilgængelige værktøjer for at bekræfte, at Wink-serverne er aktive.
</Steps>

:::note
Codex CLI MCP-support kræver version **1.0** eller nyere. Kør `codex --version` for at tjekke, og `npm install -g @openai/codex` for at opgradere.
:::

  </TabItem>
  <TabItem label="ChatGPT">

MCP-serverunderstøttelse findes i **ChatGPT desktop-appen** for Plus, Pro, Team og Enterprise-abonnenter.

<Steps>
1. Download og installer [ChatGPT desktop-appen](https://openai.com/chatgpt/download/), hvis du ikke allerede har den.

2. Åbn appen og klik på **din profilikon** øverst til højre, vælg derefter **Indstillinger**.

3. Gå til **Connectors** (eller **MCP Servers** afhængigt af din app-version) og klik på **Tilføj**.

4. Indtast Wink Inventory-serverens URL:
   ```
   https://api.wink.travel/mcp
   ```
   Klik derefter på **Forbind**.

5. ChatGPT åbner en browsertab til `https://iam.wink.travel`. **Log ind på Wink** og godkend tilladelser.

6. Gentag trin 4–5 for Integrations-serveren:
   ```
   https://integrations.wink.travel/mcp
   ```

7. Begge servere vises i din Connectors-liste. Start en ny chat — Wink-værktøjer er tilgængelige automatisk.
</Steps>

:::note[Begrænsning i webappen]
MCP-servere kan kun konfigureres i **desktop-appen**. ChatGPT-webgrænsefladen på chatgpt.com understøtter ikke brugerdefinerede MCP-servere.
:::

2. Tilføj Wink MCP-serveroplysningerne:

   ```json title="~/.cursor/mcp.json"
   {
     "mcpServers": {
   ```

## Scope-reference

Når du godkender samtykkeskærmen, vil du se en oversigt over, hvad agenten anmoder om. Wink grupperer tilladelser efter funktionelt område:

| Scope-gruppe | Scopes | Hvad de åbner op for |
|-------------|--------|---------------------|
| **MCP transport** | `mcp.read` `mcp.write` `mcp.remove` | Kræves for at forbinde til en af MCP-serverne |
| **Konto** | `account.read` `account.write` `account.remove` | Administrerende enheder, teammedlemmer, indstillinger, applikationer |
| **Booking** | `booking.read` `booking.write` `booking.remove` | Søg, vis, opret, annuller og refunder bookinger |
| **Lager** | `inventory.read` `inventory.write` `inventory.remove` | Ejendomme, værelser, priser, faciliteter, tilgængelighed |
| **Analyser** | `analytics.read` | Bookinganalyser, indtægtsrapporter, top-lister |
| **Marketing** | `marketing.read` `marketing.write` `marketing.remove` | Sociale opslag, kampagner, salgskanaler, kampagner |
| **Indhold** | `content.read` `content.write` `content.remove` | Multimedia, forkortede URL'er, syndikerbare elementer, kort |
| **Betaling** | `payment.read` `payment.write` | Regnskab, udbetalinger, finansielle opgørelser, udbetalinger |

AI-klienten anmoder kun om de scopes, den har brug for. Du kan afvise individuelle tilladelser på samtykkeskærmen — værktøjer, der kræver en afvist scope, returnerer en fejl ved kald.

## Fejlfinding

**Browsertab åbner ikke**

Din AI-klient understøtter muligvis ikke det interaktive PKCE-flow endnu. Tjek, at du kører en nyere version:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** opdater via appens indbyggede opdatering

**`401 Unauthorized` efter login**

Dit cachede token kan være udløbet. Fjern og tilføj serveren igen for at udløse et nyt login:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

For Claude Desktop og ChatGPT, fjern serveren i indstillinger, genstart appen og tilføj den igen.

**`403 Forbidden` ved kald til et specifikt værktøj**

Værktøjet kræver en scope, du ikke godkendte på samtykkeskærmen. Forbind serveren igen — samtykkeskærmen vises igen, og du kan godkende den manglende tilladelse.

**Serveren vises, men værktøjskald returnerer "account not found"**

Du er logget ind på en Wink-konto uden en administrerende enhed. Gå til [Wink Portal](https://app.wink.travel) og sørg for, at din konto er opsat, før du bruger MCP-serveren.

**Token udløber midt i sessionen**

Tokens er gyldige i 3 timer. Claude Code og Claude Desktop opdaterer tokens stille uden at afbryde din session. Hvis du ser autentificeringsfejl efter lang inaktivitet, skriv en ny besked — klienten genautentificerer automatisk.

**Codex CLI viser "MCP server unreachable"**

Tjek, at din `~/.codex/config.json` er gyldig JSON (ingen afsluttende kommaer) og at `"type": "http"` er sat. Codex kræver HTTP-transport for fjernservere; stdio-transport er kun til lokale binære filer.

**ChatGPT "Connectors"-menu mangler**

MCP-support kræver ChatGPT desktop-app version **1.2024.352** eller nyere og et aktivt Plus-, Pro-, Team- eller Enterprise-abonnement. Opdater appen og tjek din plan under Indstillinger → Konto.

**Cursor-server viser rød / "Failed to connect"**

Tjek, at din `~/.cursor/mcp.json` er gyldig JSON og indeholder `"type": "http"`. Gå derefter til **Indstillinger → Cursor Settings → MCP** og klik på **Opdater**. Hvis fejlen fortsætter, genstart Cursor helt — konfigurationsændringer opfanges ikke altid uden genstart.

**Windsurf MCP-servere vises ikke i indstillinger**

Windsurf kræver fuld genstart (ikke kun genindlæsning af vindue) for at opfange ændringer i `mcp_config.json`. Brug **Fil → Afslut** og genstart. Hvis serverne stadig ikke vises, bekræft at du kører Windsurf **1.4+** via **Hjælp → Om Windsurf**.

**Cline "Add Server"-mulighed er ikke synlig**

MCP-servermanageren kræver Cline **2.0** eller nyere. Åbn VS Code Extensions-panelet, find Cline, og klik på **Opdater**, hvis en opdatering er tilgængelig. Efter opdatering, genindlæs VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
