Wink tilbyder to transportmetoder. Hvilken du bruger, afhænger af hvilken API du integrerer med.

| | Transport | Skema | Dokumentation |
| --- | --- | --- | --- |
| De fleste Wink API'er | REST over HTTPS | OpenAPI 3 | Enhver gruppe under **API** i sidebaren |
| Partner Integrator API | gRPC over HTTP/2 | Protocol Buffers | [Partner](/da/partner-api/partner/) |

<Aside type="note" title="Vi udgiver ikke længere sprog-SDK'er">
  Håndvedligeholdte SDK'er kom bagud i forhold til de API'er, de omsluttede, og dækkede aldrig det sprog, du faktisk havde brug for. Generer i stedet en klient fra skemaet — det er altid opdateret — eller lad vores MCP-server skrive integrationskode, der er tilpasset dit brugsscenarie.
</Aside>

## Generer en REST-klient

Hver API-gruppe udgiver et OpenAPI 3-dokument. Peg en hvilken som helst OpenAPI-generator på det, og du får en typet klient i dit sprog.

```bash
# Specifikationen for en gruppe serveres ved siden af dens referenceside.
curl -o wink-extranet.json https://api.wink.travel/v3/api-docs/extranet

npx @openapitools/openapi-generator-cli generate \
  -i wink-extranet.json -g typescript-fetch -o ./wink-client
```

## Generer en gRPC-klient

Partner Integrator API er gRPC. Du genererer en klient fra `.proto`-skemaet, som Wink udgiver på to måder:

- **Server reflection** — serveren beskriver sig selv, så værktøjer som `grpcurl`, Postman og Insomnia kan finde skemaet ved kørsel uden filer, der skal downloades. Reflection kræver det samme bearer-token som ethvert andet kald.
- **`.proto`-filerne**, hvis du foretrækker at inkludere skemaet og generere på forhånd.

```bash
# Find skemaet fra en kørende server (autentificeret).
grpcurl -H "authorization: Bearer $WINK_TOKEN" \
  partner.wink.travel:443 list

# Generer derefter en klient — her Go; alle understøttede sprog fungerer på samme måde.
protoc --go_out=. --go-grpc_out=. partner_lookup.proto
```

Kald bærer dit bearer-token i `authorization` metadata-headeren, præcis som REST bærer det i `Authorization` headeren. Fejl ankommer som en gRPC statuskode i responsens trailers i stedet for som en HTTP statuskode — [Partner-referencen](/da/partner-api/partner/) viser de statusser, du kan forvente.

## Eller lad MCP-serveren skrive det

Hvis du bruger en AI-kodeassistent, er vores MCP-server den hurtigste vej. Den eksponerer Winks API'er som værktøjer, din assistent kan kalde og forstå, så i stedet for at generere en hel klient og finde endpoints selv, beskriver du, hvad du bygger, og får integrationskode, der er tilpasset det.
