Nástroje MCP od Wink jsou publikovány jako **toolsety** — zaměřené koncové body, z nichž každý pokrývá jednu práci. Připojíte svého AI klienta k jednomu nebo dvěma, které odpovídají vaší práci, ne ke všem.

Každý koncový bod používá **interaktivní přihlášení OAuth2** (PKCE autorizační kódový tok): váš AI agent otevře záložku v prohlížeči, přihlásíte se pomocí svého účtu Wink a je to. Žádné spravování klientských tajemství.

```bash title="Integrátor channel manageru se připojuje k jednomu koncovému bodu"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="Hotelier spravující své vlastní ceny se připojuje k jinému"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## Proč jsou nástroje rozděleny do koncových bodů

Wink zpřístupňuje přibližně 500 nástrojů. Předat je všechny agentovi najednou je technicky možné — a špatný nápad.

**Definice nástrojů stojí kontext.** Každý nástroj, který MCP server inzeruje, je načten do kontextového okna modelu před tím, než začne pracovat, spolu s jeho popisem a kompletním schématem parametrů. Pět set takových nástrojů spotřebuje velkou část rozpočtu, který vaše skutečné úkoly potřebují, při každém požadavku.

**Kvalita výběru klesá s rostoucím seznamem.** Agent vybírající z 500 podobně pojmenovaných nástrojů dělá horší volby než ten, kdo vybírá z 40. Pokud integrujete channel manager, přibližně dvacet nástrojů je pro vás relevantních; ostatních 480 je šum, který ztěžuje nalezení správného nástroje.

**Práce je skutečně oddělitelná.** Někdo, kdo synchronizuje dostupnost z PMS, a někdo, kdo spravuje affiliate vstupní stránky, sdílí téměř žádné nástroje. Rozdělení podle práce znamená, že každé připojení nese slovník jedné práce.

<Aside type="caution" title="Toolsety nejsou oprávnění">
Výběr úzkého toolsetu **neomezuje** to, co váš účet může dělat, a výběr širokého toolsetu nic navíc nedává. Každý nástroj vynucuje stejná oprávnění účtu jako webové rozhraní, pod vaší přihlášenou identitou. Pokud váš účet nemůže zrušit rezervaci ve Wink Portálu, agent to také nemůže — bez ohledu na to, ke kterému koncovému bodu je připojen.

Vyberte toolsety pro **zaměření**, ne pro bezpečnost.
</Aside>

## Adresář koncových bodů

Dva hostitelé poskytují toolsety. Počty nástrojů jsou přibližné a časem rostou.

### `https://api.wink.travel` — platforma

| Koncový bod | Nástroje | Co pokrývá |
|---|---:|---|
| `/mcp/extranet/facilities` | ~64 | Rezervovatelný a na místě dostupný inventář: hostovské pokoje a typy pokojů, spa, restaurace, zasedací místnosti, aktivity, atrakce, místa, další prodejné položky |
| `/mcp/extranet/property` | ~62 | Záznam o nemovitosti a její obchodní podmínky: profil a obsah, doplňky, storno podmínky, výhody, oznámení |
| `/mcp/settings` | ~60 | Správa účtu: profil a branding spravující entity, manažeři a jejich oprávnění, přizpůsobení, webhooky, nastavení notifikací |
| `/mcp/studio/embeds` | ~48 | Publikování kurátorského inventáře: widgety, mřížky a řazené mřížky, karty, mapy, hluboké odkazy na inventář a stránky dodavatelů |
| `/mcp/extranet/rates` | ~44 | Ceny a dostupnost: období sazeb a alokace inventáře, sazební plány, hlavní sazby, speciální a promo sazby |
| `/mcp/extranet/operations` | ~39 | Provoz živé nemovitosti: rezervace a jejich životní cyklus, recenze hostů a odpovědi, kalendářové zdroje, plánované úkoly |
| `/mcp/extranet/distribution` | ~37 | Kde se inventář prodává: prodejní kanály a modifikátory sazeb, žádosti o vztahy s affiliate a dodavateli, registrace, zachytávání leadů |
| `/mcp/studio/curation` | ~35 | Budování obchodovatelných kolekcí: statické a dynamické seznamy, řazené seznamy, uložené vyhledávání, agregáty nemovitostí |
| `/mcp/link-manager` | ~28 | Syndikované kolekce odkazů, jejich design, kategorie a štítky, plus zkrácené URL |
| `/mcp/reference` | ~24 | Data pouze pro čtení: země, měny a směnné kurzy, jazyky, časová pásma, geo vyhledávání, geolokace IP |
| `/mcp/analytics` | ~18 | Analytika rezervací a příjmů: přehledy, čárové grafy, žebříčky, výkon affiliate, metriky sdílení |
| `/mcp/payment` | ~18 | Finanční operace: účetní kniha, výběry a odhady poplatků, agregáty rezervovaných fondů |
| `/mcp/booking-engine` | ~17 | Cesta nakupujícího cestovatele: vyhledávání a dohledávání, nákupní košík a pokladna, seznamy přání, přizpůsobení kampaní |
| `/mcp/social` | ~17 | Připojené sociální účty, publikování a plánování příspěvků, čtení statistik příspěvků |
| `/mcp/travel-agent` | ~8 | Rezervace zprostředkované agentem jménem cestovatelů a agenturní reporty |

### `https://integrations.wink.travel` — integrace channel managerů

Jeden koncový bod, protože tento host existuje pro jednu práci.

| Koncový bod | Nástroje | Co pokrývá |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | Připojení a ověření integrace channel manageru, PMS nebo CRS |

<Aside type="note" title="Integrace channel manageru vs. správa vlastních sazeb">
Jedná se o různé práce pro různé osoby a nesdílí koncový bod.

**Dodavatel channel manageru, PMS nebo CRS** integruje jednou přes `integrations.wink.travel/mcp/channel-manager` a od té doby vyměňuje nemovitosti, sazby, dostupnost a rezervace přes tuto integraci. Ten jediný koncový bod je celé rozhraní.

**Hotelier měnící své vlastní sazby ručně** používá extranetové toolsety na `api.wink.travel` — `/mcp/extranet/rates` a přidružené. Ty nejsou součástí integrace channel manageru a integrátor je nemá důvod připojovat.

Správa účtu je také na `api.wink.travel`, na `/mcp/settings`. Na hostiteli integrací `/mcp/settings` není.
</Aside>

Každý koncový bod také obsahuje nástroj `ping`, takže můžete ověřit, že je připojení aktivní, než požádáte o skutečnou práci.

## Jaké toolsety potřebuji?

| Pokud jste… | Připojte se k |
|---|---|
| **Integrujete channel manager, PMS nebo CRS** | `integrations.wink.travel/mcp/channel-manager` — pouze tento |
| **Spravujete obsah nemovitosti** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **Spravujete pokoje a typy pokojů** | `/mcp/extranet/facilities` |
| **Spravujete ceny a dostupnost** | `/mcp/extranet/rates` |
| **Řídíte každodenní rezervace** | `/mcp/extranet/operations` |
| **Rozšiřujete distribuci** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **Budujete affiliate stránky** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **Provozujete link-in-bio stránky** | `/mcp/link-manager` + `/mcp/social` |
| **Rezervujete jménem cestovatelů** | `/mcp/travel-agent` |
| **Vyrovnáváte finance** | `/mcp/payment` |
| **Budujete rezervační zážitek** | `/mcp/booking-engine` + `/mcp/reference` |

Začněte jedním. Přidejte další, když zjistíte, že něco, co potřebujete, nemůže ten první udělat — každé připojení je nezávislé a přidání jednoho neovlivní ostatní.

<Aside type="tip" title="Chcete stále všechno?">
`https://api.wink.travel/mcp` a `https://integrations.wink.travel/mcp` zůstávají dostupné a poskytují **všechny** nástroje na svém hostiteli. Jsou užitečné pro průzkum, co existuje, ale nedoporučujeme je pro každodenní práci: seznam nástrojů je dostatečně velký, aby zatlačil vaši práci do pozadí a zhoršil výběr nástrojů agenta. Preferujte výše uvedené toolsety.
</Aside>

## Jak funguje autentizace

Wink MCP servery používají **OAuth2 Authorization Code + PKCE** tok a podporují **Dynamic Client Registration (RFC 7591)**. Zde je, co se stane při prvním připojení:

1. Váš AI klient zjistí autorizační server z metadat MCP koncového bodu `/.well-known/oauth-protected-resource`.
2. Klient se sám zaregistruje přes **Dynamic Client Registration** — není potřeba manuální nastavení aplikace.
3. Klient otevře **záložku v prohlížeči** na `https://iam.wink.travel`. Přihlásíte se pomocí účtu Wink a schválíte požadovaná oprávnění na obrazovce souhlasu.
4. Wink vydá **přístupový token** vázaný na váš účet a identitu.
5. AI klient připojuje token ke každému MCP požadavku. Všechny výsledky nástrojů jsou automaticky omezeny na vaši spravující entitu.
6. Tokeny expirují po 3 hodinách. Váš AI klient je tichounce obnovuje na pozadí bez dalšího vyžádání.

Každé volání nástroje běží **pod vaší identitou** — stejná pravidla ACL, která chrání webové rozhraní, platí i pro AI agenta.

## Scopes

Při schvalování na obrazovce souhlasu uvidíte rozpis toho, co agent požaduje. MCP klienti používají stejný slovník oprávnění jako zbytek platformy — viz kompletní
[referenční seznam scope na stránce Autentizace](/cs/developers/authentication#scopes).

Dvě věci jsou specifické pro MCP:

- **Scope `mcp.read`, `mcp.write`, `mcp.remove` jsou navíc vyžadovány** k otevření MCP transportu. Klient s `mcp.*` scope má přístup ke kterémukoli Wink MCP koncovému bodu, ale každý nástroj, který vyvolá, stále vynucuje scope sekce koncového bodu, který obaluje (např. `booking.read`).
- **AI klient žádá pouze o scope, které potřebuje.** Na obrazovce souhlasu můžete jednotlivá oprávnění odmítnout — nástroje vyžadující odmítnutý scope vrátí chybu při volání.

**Toolsety nic z toho nemění.** Koncový bod, ke kterému se připojíte, rozhoduje, které nástroje jsou *zobrazeny*, ne co *smí dělat*. Připojení k `/mcp/payment` nedává žádné finanční oprávnění, které jste již neměli, a připojení k `/mcp/reference` nezabrání nástroji tam vynucovat vlastní scope. Autorizace se rozhoduje při každém volání nástroje podle vašeho tokenu a oprávnění vašeho účtu.

## Řešení problémů

**Neotevře se záložka v prohlížeči**

Váš AI klient možná ještě nepodporuje interaktivní PKCE tok. Ověřte, že používáte aktuální verzi:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** aktualizujte přes vestavěný updater aplikace

**`401 Unauthorized` po přihlášení**

Váš uložený token může být neplatný. Odstraňte a znovu přidejte server, aby se spustilo nové přihlášení:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

U Claude Desktop a ChatGPT odeberte server v nastavení, restartujte aplikaci a přidejte ho znovu.

**`403 Forbidden` při volání konkrétního nástroje**

Nástroj vyžaduje scope, které jste na obrazovce souhlasu neschválili, nebo oprávnění, které váš účet nemá. Znovu připojte server — obrazovka souhlasu se znovu objeví a můžete chybějící oprávnění schválit. Pokud to stále selhává, nástroj potřebuje oprávnění účtu, které nemáte; připojení k jinému toolsetu nepomůže, protože toolsety nedávají oprávnění.

**Nástroj, který potřebuji, není v seznamu**

Pravděpodobně jste připojeni k toolsetu, který tu práci nepokrývá. Zkontrolujte [adresář koncových bodů](#endpoint-directory) a přidejte toolset, který ano — připojení jsou nezávislá, takže přidání jednoho nic nemění na ostatních. Pokud si nejste jisti, který toolset ho má, dočasně se připojte k `https://api.wink.travel/mcp`, najděte nástroj a pak zjistěte, který toolset ho obsahuje.

**`404 Not Found` na koncovém bodu toolsetu**

Pečlivě zkontrolujte cestu — vnořené toolsety mají dvě části (`/mcp/extranet/rates`, ne `/mcp/extranet-rates`), ploché mají jednu (`/mcp/link-manager`). Neautentizovaný požadavek na jakoukoli cestu pod `/mcp` vrací `401`, ne `404`, takže samotné `401` neznamená, zda koncový bod existuje.

**Připojil jsem se k `api.wink.travel/mcp/channel-manager` a nic**

Tento koncový bod neexistuje. Integrace channel manageru je dostupná pouze z `https://integrations.wink.travel/mcp/channel-manager`. Pokud také potřebujete ručně číst nebo zapisovat vlastní sazby nemovitosti, je to samostatná práce na samostatném koncovém bodu — viz `/mcp/extranet/rates`.

**Server se zobrazuje, ale volání nástrojů vrací "account not found"**

Jste přihlášeni do Wink účtu, který nemá spravující entitu. Přejděte na [Wink Portal](https://app.wink.travel) a ujistěte se, že je váš účet nastaven před použitím MCP serveru.

**Token vyprší během relace**

Tokeny platí 3 hodiny. Claude Code a Claude Desktop obnovují tokeny tiše bez přerušení relace. Pokud po dlouhém nečinném období vidíte chyby autentizace, napište novou zprávu — klient se automaticky znovu autentizuje.

**Codex CLI hlásí "MCP server unreachable"**

Zkontrolujte, že váš `~/.codex/config.json` je platný JSON (bez koncových čárek) a že `"type": "http"` je nastaveno. Codex vyžaduje HTTP transport pro vzdálené servery; stdio transport je pouze pro lokální binárky.

**Menu "Connectors" v ChatGPT chybí**

Podpora MCP vyžaduje desktopovou aplikaci ChatGPT verze **1.2024.352** nebo novější a aktivní předplatné Plus, Pro, Team nebo Enterprise. Aktualizujte aplikaci a ověřte svůj plán v Nastavení → Účet.

**Cursor server ukazuje červeně / "Failed to connect"**

Ověřte, že váš `~/.cursor/mcp.json` je platný JSON a obsahuje `"type": "http"`. Pak přejděte na **Nastavení → Nastavení Cursor → MCP** a klikněte na **Obnovit**. Pokud chyba přetrvává, úplně restartujte Cursor — změny konfigurace se nemusí vždy načíst bez restartu.

**Windsurf MCP servery nejsou v nastavení**

Windsurf vyžaduje úplný restart (nejen reload okna) pro načtení změn v `mcp_config.json`. Použijte **Soubor → Ukončit** a znovu spusťte. Pokud servery stále nejsou vidět, ověřte, že máte Windsurf **1.4+** přes **Nápověda → O Windsurf**.

**V Cline není viditelná volba "Add Server"**

Správce MCP serverů vyžaduje Cline **2.0** nebo novější. Otevřete panel rozšíření VS Code, najděte Cline a klikněte na **Aktualizovat**, pokud je dostupná aktualizace. Po aktualizaci restartujte VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
