# Nastavení

Když začnete používat Social, zeptáme se vás, jak chcete, abychom vytvářeli váš obsah. Tyto možnosti máte k dispozici kdykoli, takže je můžete snadno později změnit.

Přejděte do `Nastavení` v postranním panelu pro správu vašich nastavení.

Sekce preferencí obsahuje základní nastavení generování obsahu:

1. **Preferovaná přizpůsobení** Vyberte, které přizpůsobení chcete použít při generování obsahu. Přizpůsobení ovlivňují barvy tématu, výchozí itinerář, měnu, jazyk a další. Přizpůsobení vytváříte ve svém účtu na [app.wink.travel](https://app.wink.travel).
2. **Automatické schválení** Pokud je povoleno, generované příspěvky jsou automaticky publikovány bez nutnosti vašeho schválení. Aktivujte toto, až budete mít jistotu v kvalitě obsahu, který pro vás vytváříme.
3. **Jméno schvalovatele** Jméno osoby nebo týmu, který bude dostávat e-maily se žádostmi o schválení.
4. **E-mail schvalovatele** E-mailová adresa, kam budou zasílány žádosti o schválení nadcházejících příspěvků.

## Tvůrci obsahu

Social nabízí mnoho tvůrců obsahu, ze kterých si můžete vybrat. Každý tvůrce se zaměřuje na specifický způsob vytváření unikátního obsahu pro vaši nemovitost pomocí AI. Každý tvůrce má atribut **Váha** — vyšší váha zvyšuje pravděpodobnost, že bude vybrán při generování příspěvků.

Zde jsou všichni dostupní tvůrci obsahu:

| Tvůrce | Popis |
| -- | -- |
| **Destinace** | Využívá vaši lokalitu k vytvoření užitečného textu o oblasti |
| **Typ pokoje** | Vytváří rezervovatelný příspěvek s jedním z vašich typů pokojů s AI generovaným textem a obrázky vašeho typu pokoje |
| **Aktivita** | Vytváří rezervovatelný příspěvek s jednou z vašich aktivit |
| **Doplňková služba** | Vytváří rezervovatelný příspěvek s jednou z vašich doplňkových služeb |
| **Atraktivita** | Vytváří rezervovatelný příspěvek s jednou z vašich atrakcí |
| **Místo** | Vytváří rezervovatelný příspěvek s jedním z vašich míst |
| **Zasedací místnost** | Vytváří rezervovatelný příspěvek s jednou z vašich zasedacích místností |
| **Restaurace** | Vytváří rezervovatelný příspěvek s jednou z vašich restaurací |
| **Spa** | Vytváří rezervovatelný příspěvek s jedním z vašich spa |
| **Nemovitost** | Vytváří rezervovatelný příspěvek s vaším nejlépe naceněným pokojem s AI generovaným textem a obrázky vaší nemovitosti |
| **Názory uživatelů** | Shromažďuje recenze hostů z celého webu do příspěvku založeného na sentimentu, který zdůrazňuje, co hosté na vaší nemovitosti milují |
| **Vtipný** | Vytváří lehké, zábavné příspěvky, které udržují váš feed zajímavý |

:::tip[Profesionální tip]
Ujistěte se, že máte typ inventáře potřebný pro vybrané tvůrce obsahu. Například pokud vyberete „Restaurace“, musíte mít na své nemovitosti alespoň jednu restauraci.
:::

## Tón hlasu

Tón hlasu určuje jazykový styl, který AI používá při generování obsahu. Vyberte tóny, které odpovídají osobnosti vaší značky. Stejně jako u tvůrců obsahu má každý tón atribut **Váha**, který ovládá, jak často je používán.

Zde jsou dostupné tóny:

| Tón | Styl |
| -- | -- |
| **Neutrální** | Klidný, autoritativní, faktický. Žádný přehnaný nadšení, žádné vtipy — jen spolehlivé, dobře strukturované informace |
| **Přátelský** | Teplý, přístupný, s energií úsměvu v textu, s neformálními zkratkami a občasnými emoji |
| **Luxusní** | Sofistikovaný, vytříbený. Slova jako „vynikající“ a „na míru“, která čtenáře činí exkluzivními |
| **Gurmánský** | Smyslné, chutné popisy. Jazyk „food porn“, který čtenáře hladově přitahuje |
| **Dobrodružný** | Odvážný, neohrožený, průzkumnická energie. Živé smyslové popisy, které vše znějí epicky |
| **Rodinný** | Celistvý, přátelský k dětem. Teplá rodičovská energie o bezpečných a zábavných zážitcích |
| **Romantický** | Poetický, zasněný, srdce rozechvívající. Západy slunce, jemný jazyk a láska |
| **Humorný** | Sarkastický, rychlé hlášky, chytré slovní hříčky. Čte se jako stand-up vystoupení |
| **Eko** | Upřímný a spravedlivý. Oslavuje zelené alternativy a udržitelné volby |
| **Místní znalec** | Velmi specifické místní odkazy, varuje před turistickými pastmi, používá místní slang |
| **Inkluzivní** | Vítající, oslavující a potvrzující. Dává všem pocit, že jsou viděni a ceněni |
| **Mystický** | Éterický, duchovní, kosmické pravdy. Jemné pozvání k nahlédnutí dovnitř |
| **Futuristický** | Elegantní, zaměřený na budoucnost. Miluje termíny jako „paradigmatický posun“ a optimistické vize budoucnosti |
| **Úsporný** | Šikovný, vynalézavý, hrdě spořivý. Oslavuje dostupné objevy a bezplatné zážitky |

## Typy příspěvků

Typy příspěvků určují cíl a strukturu generovaného obsahu. Každý typ příspěvku má atribut **Váha**, který ovládá, jak často je používán.

| Typ příspěvku | Popis |
| -- | -- |
| **Transakční** | Jasný, stručný, zaměřený na konverzi. Podporuje rezervace a přímé akce pomocí faktů, cen a dalších kroků |
| **Povědomí** | Obsah budující značku, navržený k představení vaší nemovitosti a zvýšení viditelnosti mezi potenciálními hosty |
| **Sentiment** | Emočně rezonující obsah, který vytváří pozitivní asociace a buduje emocionální spojení s vaším publikem |

Možná budete chtít zaměřit své marketingové úsilí na konkrétní jazyk a region. Řekněte nám jazyky, pro které chcete vytvářet obsah, a časové pásmo, o které máte zájem, a my uděláme zbytek. Příspěvky jsou publikovány ve stanovený čas ve vámi vybraném časovém pásmu.

*Většina nemovitostí používá jeden jazyk a výchozí nastavení na svůj místní jazyk.*
