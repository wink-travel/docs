Booking Engine lze vložit kamkoli. Vyberte si svůj framework nebo CMS a postupujte podle jeho návodu; základní Web Components jsou všude stejné.

## Základní přístupy

- [Web Components](/cs/integrations/web-components/) — vkládatelné prvky, které používá každá integrace.
- [npm package](/cs/integrations/npm/) — instalace do JavaScriptového buildu.
- [Headless CMS](/cs/integrations/headless/) — vykreslování z jakéhokoli obsahového backendu.
- [Partner API](/cs/integrations/partner-api/) — plná programová integrace.
