Wink **Partner API** je autentizovaný způsob s vyšší propustností pro integrátory, jak dotazovat rezervovatelný cestovní inventář — stejný zdroj, který pohání naše vkládatelné widgety a veřejné prohlížecí koncové body, vystavený jako plnohodnotné programové rozhraní. Zatímco bezplatné Web Components a veřejné prohlížecí koncové body jsou určeny pro lehké, uživatelsky orientované vkládání, Partner API je postaveno pro systémy, které vyhledávají, nacenění a rezervují ve velkém měřítku. Přístup je autentizován pro každého integrátora a účtován podle využití, takže platíte pouze za provoz, který skutečně odešlete.

## Plány a ceny

Využití se měří v **hotelových nocích**: jeden hotel oceněný za jednu noc pobytu — *nikoli* jeden API požadavek. Vyhledávání, které vrátí 20 hotelů na 3 noci, znamená 60 hotelových nocí z jednoho požadavku. Výjimkou jsou volání Content a Lookup (vyhledávání destinace a automatické doplňování): každé stojí jednu jednotku za volání, bez ohledu na výsledek. Koncové body účtu jsou zdarma. ## API reference

Dvě rozhraní slouží k rezervovatelnému inventáři a odpovídají dvěma výše uvedeným úrovním:

- **Zdarma — Consumer / Booking Engine API** (REST, `/api/public/**`): anonymní, určené pro prohlížeče a widgety. [Prohlédněte si referenci Booking Engine →](/cs/api/booking-engine/)
- **Placené — Partner Integrator API** (**gRPC**, `wink.partner.v1`): autentizované, měřené podle využití, postavené pro integraci server-server ve velkém měřítku. [Prohlédněte si referenci Integrator →](/cs/partner-api/partner/)

Partner Integrator API je gRPC, nikoli REST. Voláte ho pomocí generovaného klienta přes HTTP/2 na
`partner.wink.travel:443`, předávajíc bearer token a účet, pro který voláte:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

Výše uvedená referenční stránka dokumentuje každou službu, zprávu a stav chyby a schéma je také
k dispozici za běhu prostřednictvím serverové reflexe, takže `grpcurl`, Postman a Insomnia jej objeví bez nutnosti stahování.

Pokud raději generujete klienta předem, zdrojové soubory `.proto` jsou publikovány na
[github.com/wink-travel/partner-api-proto](https://github.com/wink-travel/partner-api-proto).

## Jak funguje využití a limity

### Zdarma úroveň

Zdarma úroveň je navržena tak, aby vám umožnila vyvíjet, testovat a provozovat mírný produkční provoz bez nákladů.

- **Žádný zveřejněný limit za minutu.** Wink monitoruje rychlost požadavků a může uplatnit limity spravedlivého užívání k ochraně služby. Pokud obdržíte **HTTP 429 (Příliš mnoho požadavků)**, počkejte počet sekund uvedený v hlavičce `Retry-After` před opakováním.
- **Měsíční limit — 10 000 jednotek za kalendářní měsíc.** Limit je přidělen na účet a resetuje se 1. dne každého měsíce (UTC). Jakmile jej dosáhnete, účet, který není zapsán do platby podle využití, obdrží **HTTP 429 až do 1. dne dalšího měsíce** — tvrdé zastavení s hlavičkou `Retry-After` a zprávou vyzývající k přechodu na placenou úroveň. Zapsaný účet pokračuje v práci a je účtován za využití nad rámec limitu.

Zdarma úroveň nezahrnuje smlouvu o úrovni služeb ani prioritní podporu.

### Placená úroveň

Placená úroveň odstraňuje měsíční strop a účtuje vás pouze za to, co skutečně využijete.

- **Měřené hotelové noci — 0,0001 $ za hotelovou noc.** Neexistuje žádný měsíční strop; platíte podle skutečného objemu. Wink může stále uplatnit limity spravedlivého užívání k ochraně služby. Vyhledávací a inventární volání se účtují za oceněné hotelové noci; volání Content a Lookup účtují jednu jednotku za každé volání, takže dávkování požadavků snižuje účet.

Placená úroveň zahrnuje smlouvu o úrovni služeb popsanou níže — závazek dostupnosti 99,9 % a cíl doby odezvy P95 pod 500 ms — a prioritní podporu založenou na závažnosti.

## Smlouva o úrovni služeb

_Učinné od: 5. července 2026 · Verze 1.0_

Tato smlouva o úrovni služeb (dále jen „SLA“) stanovuje závazek dostupnosti, servisní kredity a cíle podpory, které Wink („Wink“, „my“, „nás“) poskytuje zákazníkovi („Zákazník“, „vy“) pro autentizované Wink Partner API (dále jen „Partner API“ nebo „Služba“) na úrovních, kde je uvedeno, že se SLA vztahuje. Tato SLA je začleněna do a řídí se dohodou mezi vámi a Wink, na jejímž základě přistupujete k Partner API (dále jen „Dohoda“), a platí po dobu, kdy máte aktivní, placené předplatné Partner API v dobrém stavu. Velká písmena neuvedená zde mají význam uvedený v Dohodě.

### 1. Definice

1. **„Dostupnost“** znamená období, během kterých je Partner API dostupné k přijímání a úspěšnému zpracování správně vytvořených, autentizovaných požadavků.
2. **„Výpadek“** znamená jakékoli období, měřené v minutách, během kterého Partner API neodpovídá úspěšně na správně vytvořené, autentizované požadavky, s výjimkou období uvedených v sekci 4. Izolované chyby ovlivňující nevýznamnou část požadavků samy o sobě nejsou Výpadkem.
3. **„Měsíční procento dostupnosti“** znamená pro daný kalendářní měsíc celkový počet minut v tomto měsíci minus celkový počet minut výpadku, děleno celkovým počtem minut v měsíci, vyjádřeno v procentech.
4. **„Plánovaná údržba“** znamená plánovanou údržbu Služby, o které Wink poskytl předchozí oznámení v souladu s oddílem 4.
5. **„Servisní kredit“** znamená kredit vypočtený jako procento poplatků zaplacených nebo splatných vámi za Partner API v dotčeném kalendářním měsíci, který se uplatňuje proti budoucím poplatkům za Partner API jako jediný a výhradní nástroj nápravy za nesplnění závazku dostupnosti.
6. **„Doba odezvy“** znamená uplynulý čas mezi přijetím správně vytvořeného, autentizovaného požadavku na hranici služby Wink a okamžikem, kdy Wink začne vracet odpověď, bez zahrnutí přenosu v síti a jakéhokoli času na straně klienta mimo kontrolu Wink.

### 2. Závazek dostupnosti a výkonu

Wink použije obchodně rozumné úsilí, aby zajistil, že Partner API bude dostupné s **měsíčním procentem dostupnosti alespoň 99,9 %** během každého kalendářního měsíce trvání smlouvy (dále jen „Závazek dostupnosti“). Závazek dostupnosti se měří na hranici služby Wink a nezahrnuje faktory mimo rozumnou kontrolu Wink, včetně těch popsaných v sekci 4. Monitorovací systémy Wink jsou autoritativním zdrojem pro měření měsíčního procenta dostupnosti a doby odezvy.

Wink dále cílí na **95. percentil (P95) doby odezvy pod 500 milisekund** pro úspěšné, správně vytvořené, autentizované požadavky, měřeno na hranici služby Wink za každý kalendářní měsíc (dále jen „Cíl výkonu“). Cíl výkonu nezahrnuje faktory popsané v sekci 4, požadavky vracející aplikační chyby způsobené samotným požadavkem a neobvykle velké nebo složité dávkové požadavky. Cíl výkonu je cílem služby; servisní kredity v sekci 3 se vztahují na nesplnění **Závazku dostupnosti** a jsou jediným a výhradním nástrojem nápravy za nedostupnost.

### 3. Servisní kredity

Pokud měsíční procento dostupnosti klesne pod Závazek dostupnosti v jakémkoli kalendářním měsíci, můžete mít nárok na servisní kredit vypočtený jako procento poplatků za Partner API zaplacených nebo splatných vámi za tento měsíc podle následující tabulky:

| Měsíční procento dostupnosti | Servisní kredit |
|---|---|
| Pod 99,9 % ale alespoň 99,0 % | 10 % |
| Pod 99,0 % ale alespoň 95,0 % | 25 % |
| Pod 95,0 % | 50 % |

1. **Uplatnění kreditu.** Pro získání servisního kreditu musíte do **třiceti (30) dnů** od konce kalendářního měsíce, ve kterém k nedostatku došlo, podat Wink písemnou žádost. Žádost musí obsahovat data a časy každého incidentu výpadku, na který se vztahuje, a jakékoli dostupné podpůrné záznamy nebo důkazy. Žádosti podané po této lhůtě nejsou způsobilé.
2. **Forma kreditu.** Schválené servisní kredity se uplatňují proti budoucím poplatkům za Partner API a nemají hotovostní hodnotu. Nejsou refundacemi a nebudou vyplaceny, pokud to nevyžaduje platný zákon.
3. **Maximální kredit.** Celkové servisní kredity přiznané za jeden kalendářní měsíc nepřesáhnou 50 % poplatků za Partner API zaplacených nebo splatných vámi za tento měsíc.
4. **Jediný a výhradní nástroj nápravy.** Servisní kredity jsou vaším **jediným a výhradním nástrojem nápravy** za jakékoli nesplnění Závazku dostupnosti nebo jiný nedostatek dostupnosti Partner API.

4. vaše **zneužití služby** nebo **porušení dohody**, této SLA, podmínek přijatelných použití nebo platných limitů rychlosti, včetně provozu, který Wink rozumně považuje za nadměrný, automatizované zneužití nebo podvodné jednání; a

### 5. Podpora a cíle odezvy

Wink poskytuje podporu pro Partner API během standardní pracovní doby, s výjimkou místních státních svátků. Wink použije obchodně rozumné úsilí, aby potvrdil správně podané požadavky na podporu v následujících cílových dobách odezvy, založených na závažnosti, kterou přiřadíte a kterou Wink rozumně potvrdí:

| Závažnost | Popis | Cílová počáteční odezva |
|---|---|---|
| **Sev 1 — Kritická** | Partner API je nedostupné nebo nepoužitelné v produkci bez náhradního řešení. | 4 hodiny |
| **Sev 2 — Významná** | Významná funkce je omezená nebo degradovaná; existuje náhradní řešení. | 1 pracovní den |
| **Sev 3 — Menší** | Obecné dotazy, drobné problémy nebo požadavky na funkce. | 2 pracovní dny |

Cílové doby odezvy popisují, kdy Wink usiluje o **počáteční kontakt**; nejsou to záruky doby vyřešení. Prioritní podpora a cíle založené na závažnosti platí na úrovních, kde je uvedeno, že jsou zahrnuty.

Wink udržuje obchodně rozumná administrativní, technická a organizační opatření navržená k ochraně důvěrnosti, integrity a dostupnosti dat zpracovávaných prostřednictvím Partner API a tato opatření pravidelně přezkoumává. Zpracování osobních údajů společností Wink se řídí [Zásadami ochrany osobních údajů](/cs/privacy) a jakýmikoli podmínkami zpracování dat v Dohodě. Vy zůstáváte odpovědní za zabezpečení svých vlastních API přihlašovacích údajů, za zákonné použití jakýchkoli získaných dat a za okamžité oznámení Wink o jakémkoli podezření na kompromitaci přihlašovacích údajů.

### 7. Omezení odpovědnosti

Servisní kredity jsou **jediným a výhradním nástrojem nápravy** za jakoukoli nedostupnost nebo nesplnění Závazku dostupnosti a jsou poskytovány místo jakékoli jiné odpovědnosti vyplývající z takového nesplnění. S výjimkou výslovně uvedenou v této SLA je Partner API poskytováno „tak, jak je dostupné“. V maximálním rozsahu povoleném platným právem je celková odpovědnost Wink vyplývající ze služby omezena, jak je uvedeno v Dohodě, a Wink nenese odpovědnost za žádné nepřímé, náhodné, zvláštní, následné nebo trestní škody, ani za ztrátu zisku, příjmů, dat nebo dobré pověsti, i kdyby byl upozorněn na možnost takových škod.

### 8. Doba platnosti, změny a ukončení

Tato SLA platí po dobu, kdy máte aktivní předplatné Partner API na úrovni, kde je uvedeno, že se SLA vztahuje. Wink může tuto SLA čas od času aktualizovat; podstatné změny budou komunikovány prostřednictvím kanálu, který Wink běžně používá ke kontaktu se zákazníky, a pokračování v používání Partner API po účinnosti aktualizace znamená přijetí aktualizované SLA. Tato SLA automaticky zaniká při ukončení nebo vypršení Dohody nebo vašeho předplatného Partner API. Oddíly, které podle své povahy mají přežít ukončení — včetně nároku na servisní kredit, omezení odpovědnosti a definic — zůstávají v platnosti.
