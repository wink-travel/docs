Rezervační engine je transakční vrstva pod každou cestou Wink: vlastní web hotelu, partnerské a tvůrčí odkazy, objevování spotřebitelem a AI agenti. Platba je vybírána jménem hotelu, jako jeho agent, takže hotel zůstává obchodníkem záznamu.

## Rezervační proces

- [Vyhledávání](/cs/booking-engine/search/) — najít dostupný inventář.
- [Detail nemovitosti](/cs/booking-engine/property-detail/) — pokoje, ceny, podmínky a doplňky.
- [Pokladna](/cs/booking-engine/checkout/) — jediný krok platby s hotelovou značkou.
- [Potvrzení rezervace](/cs/booking-engine/confirmation/) — co host obdrží.
