Připojením svého Google Analytics 4 účtu k Wink se vaše události rezervací — od zobrazení pokojů až po dokončené rezervace — automaticky přeposílají do vašeho vlastního GA4 dashboardu vedle vlastních analytik Wink. Žádný kód, žádné technické nastavení na vaší straně.

<Aside type="tip">
Potřebujete dvě věci z GA4: **Measurement ID** a **Measurement Protocol API secret**. Measurement ID pohání prohlížecí trychtýř v prohlížeči hosta; API secret umožňuje Wink zaznamenávat dokončené rezervace (`purchase`) **na straně serveru**, takže se prodej nikdy neztratí při přesměrování k a od platebního poskytovatele.
</Aside>

---

## Jak to funguje

```
Zadáte své Measurement ID (G-XXXXXXXXXX) a API secret do portálu Wink
       ↓
Události prohlížení (zobrazení, košík, pokladna) se přenášejí do vaší GA4 vlastnosti z prohlížeče
Dokončené rezervace (purchase) jsou odesílány na straně serveru — přežijí přesměrování platby
       ↓
Přihlásíte se na analytics.google.com a uvidíte celý svůj rezervační trychtýř
```

---

## Co musíte udělat

<Steps>

1. **Vytvořte GA4 vlastnost**

   Přejděte na [analytics.google.com](https://analytics.google.com): Admin → Vytvořit vlastnost. Nastavte svůj časový pásmo a měnu tak, aby odpovídaly vašemu trhu.

2. **Vytvořte Web Data Stream**

   Admin → Data Streams → Přidat stream → Web. Zadejte `wink.travel` jako URL. Tím se vygeneruje vaše **Measurement ID** (`G-XXXXXXXXXX`). Zkopírujte ho.

3. **Vytvořte Measurement Protocol API Secret**

   Otevřete stejný Web Data Stream → sjeďte dolů na **Measurement Protocol API secrets** → **Vytvořit**. Dejte mu přezdívku (např. "Wink") a zkopírujte vygenerovanou **tajnou hodnotu**. Tento secret umožňuje Wink zaznamenávat dokončené rezervace na straně serveru, takže se prodej nikdy neztratí během přesměrování platby.

4. **Zadejte své Measurement ID a API Secret do portálu Wink**

   Přihlaste se na [app.wink.travel](https://app.wink.travel), vyberte svůj účet a přejděte na záložku **Customizations**. Vložte své Measurement ID a API secret do polí **GA4** a uložte. To je vše — vaše integrace GA4 je nyní aktivní.

   <Aside type="note">
   API secret je **pouze pro zápis**: po uložení již nikdy není znovu zobrazen. Při budoucích úpravách nechte pole secret prázdné, aby se zachovala hodnota, kterou jste již uložili.
   </Aside>

5. **Označte `purchase` jako klíčovou událost**

   Vraťte se do své GA4 vlastnosti: Admin → Události → najděte `purchase` → přepněte **Označit jako klíčovou událost**. Tím se dokončené rezervace zobrazí ve vašem přehledu Konverzí.

6. **Prohlédněte si svá data**

   Přihlaste se na [analytics.google.com](https://analytics.google.com) a uvidíte své rezervace, příjmy a trychtýř hosta — vše automaticky sledované přes Wink.

</Steps>

<Aside type="note">
Pro tuto integraci nemusíte na svých webových stránkách instalovat žádný sledovací kód. O vše se postará Wink. Vaše Measurement ID je cílové místo, kam se odesílají data o rezervacích, a váš API secret umožňuje Wink potvrdit dokončené rezervace na straně serveru.
</Aside>

<Aside type="tip">
**GA4 a GTM lze používat společně.** Pokud také provozujete kontejner Google Tag Manager (například kontejner Sojern), můžete oba nastavit současně — již nejsou vzájemně vylučující. Viz [GTM Analytics Integration](/cs/guides/developers/gtm-dual-tagging).
</Aside>

## Co můžete sledovat

Po připojení vaše GA4 vlastnost přijímá kompletní sadu Enhanced E-commerce událostí pro vaši nemovitost:

### Objevování

| Událost | Co znamená |
|---|---|
| `view_item_list` | Host viděl vaši nemovitost ve vyhledávání nebo v seznamu kategorií |
| `select_item` | Host klikl na vaši nemovitost ze seznamu |
| `view_item` | Host si prohlédl detailní stránku hotelu |

### Zvažování

| Událost | Co znamená |
|---|---|
| `view_promotion` | Host viděl propagační nabídku vaší nemovitosti |
| `select_promotion` | Host klikl na propagační nabídku |
| `add_to_wishlist` | Host si uložil vaši nemovitost do seznamu přání |

### Rezervační trychtýř

| Událost | Co znamená |
|---|---|
| `add_to_cart` | Host vybral pokoj nebo balíček |
| `view_cart` | Host si prohlédl shrnutí rezervace |
| `remove_from_cart` | Host odstranil pokoj nebo balíček |
| `begin_checkout` | Host zahájil proces pokladny |
| `add_payment_info` | Host zadal platební údaje |
| `add_shipping_info` | Host zadal údaje o hostu |
| `purchase` | Host dokončil rezervaci |
| `refund` | Rezervace byla zrušena a refundována |

Všechny události zahrnují relevantní dimenze jako příjmy, měnu, typ pokoje a hodnotu rezervace — což vám poskytuje kompletní přehled o cestě hosta od prvního dojmu až po dokončenou rezervaci. Pro odemknutí dalších dimenzí na úrovni nemovitosti a pokoje, jako jsou `city_name`, `cancellation_policy`, `bed_type` a další, viz [Custom Dimensions in GA4](/cs/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4).

## Cross-Domain Tracking (Pokročilé)

Standardní integrace výše sleduje vše, co se děje v rámci Wink. Pokud však chcete sledovat hosty od vašeho vlastního webu až po dokončení rezervace na Wink — a správně přiřadit původní zdroj návštěvnosti (Google Ads, e-mailové kampaně, organické vyhledávání atd.) — je potřeba provést ještě jeden krok na obou stranách.

<Aside type="caution">
Tato sekce platí pouze pokud máte GA4 nainstalované na svém vlastním webu. Pokud GA4 na svém webu nepoužíváte, standardní integrace výše je vše, co potřebujete.
</Aside>

### Proč je to důležité

Bez cross-domain trackingu se host, který nejprve navštíví váš web a poté provede rezervaci na Wink, zobrazí v GA4 jako **Direct** relace bez spojení s jeho předchozí návštěvou. Jakékoliv kliknutí z Google Ads, e-mailové kampaně nebo organické vyhledávání, které vedly k rezervaci, tak nezískají žádné uznání.

S nastaveným cross-domain trackingem vidíte kompletní cestu hosta:

```
google.com (placená reklama)
       ↓
váš web (host prohlíží pokoje)
       ↓
wink.travel (host vybere pokoj a rezervuje)
       ↓
purchase správně přiřazeno k původnímu kliknutí Google Ads
```

### Co musíte udělat: Vy

Nastavte svou GA4 vlastnost tak, aby rozpoznala `wink.travel` jako součást vaší vlastní domény, nikoli jako externí odkaz. To říká GA4, aby spojila obě relace do jedné kontinuální cesty hosta.

<Steps>
1. GA4 Admin → Data Streams → váš stream
2. Nastavení tagu → **Nastavte své domény**
3. Přidejte `wink.travel` jako propojenou doménu
4. Uložte
</Steps>

### Co musí udělat Wink

Kontaktujte [Wink Support](https://app.wink.travel) a poskytněte svou doménu webu (např. `yourhotel.com`). Wink přidá vaši doménu do seznamu vyloučení odkazů v GA4 vlastnosti Wink. Tím se zabrání tomu, aby váš web byl zaznamenán jako zdroj odkazu, což by jinak přepsalo původní atribuci hosta a zahájilo novou relaci.

<Aside type="tip">
Standardní integrace výše je dostačující pro většinu nemovitostí a poskytuje okamžitý přehled o rezervacích a příjmech na Wink. Cross-domain tracking je pokročilá možnost, kterou stojí za to nastavit, jakmile budete mít s daty GA4 větší zkušenosti a budete chtít hlubší přehled o atribuci.
</Aside>
