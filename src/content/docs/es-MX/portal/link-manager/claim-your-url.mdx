Al crear una [cuenta de afiliado](/es-MX/portal/studio/what-is-studio), ya tienes una URL personalizada de WinkLinks. Las funciones para editores de WinkLinks están disponibles en nuestra aplicación Studio, junto con otras funciones para afiliados.

### Ejemplo

Si el nombre de tu cuenta es Queen Bee, tu URL personalizada de WinkLinks será:

<h4 align="center">https://i.trvl.as/queen-bee</h4>

La parte después de `i.trvl.as/` se llama slug. Comienza siendo el nombre de tu cuenta, y puedes editarlo después. Los slugs están disponibles bajo el principio de `el que primero llega, primero se sirve` - ¡Obtén tu URL única mientras puedas!
