## 為什麼 QR Code 對飯店很重要

飯店充滿高意圖的線下時刻。旅客閱讀水療菜單、用餐完畢、參加婚禮、持有房卡 — 每個時刻都是推動訂房、加購或回訪的機會。QR Code 將這些時刻連結到數位且可預訂的下一步。

技術很簡單；每支手機相機都能掃描 QR Code。能否成功的關鍵在於 **QR Code 導向的內容**。太多飯店的 QR Code 只打開靜態 PDF、首頁或無法行動的菜單。機會在於讓掃描 **可預訂且可衡量**。

## 飯店可放置 QR Code 的位置

| 擺放位置 | 可預訂的時刻 |
|---|---|
| 客房與房卡 | 延長住宿、預訂回訪、加購水療或餐飲。 |
| 餐廳與酒吧 | 預約座位、預訂主廚體驗、規劃未來住宿。 |
| 水療與健康 | 預訂療程與健康套裝。 |
| 櫃檯與大廳 | 推銷升等、提前入住、延遲退房、體驗活動。 |
| 活動與婚禮 | 提供與會者房間團體優惠或目的地商店頁面。 |
| 印刷宣傳品 | 手冊、傳單、標示、名片與迎賓手冊。 |
| 戶外與當地合作夥伴 | 海報、合作場地與目的地擺放。 |

每個擺放位置應對應 **特定意圖** — 水療的 QR Code 不應該導向只有客房的流程。

## QR Code 應該導向什麼

掃描應該落在符合當下時刻且能完成動作的目的地：

- **可預訂的優惠** — 精確的客房、套裝、座位、療程或體驗。
- **商店頁面** — 當一個 QR Code 需呈現多個優惠（活動飯店、目的地集合、飯店完整可預訂內容）。
- **行動優先頁面** — QR 流量幾乎全來自手機。
- **可衡量的路徑** — 讓飯店知道哪個擺放位置帶來訂房。

## Wink 上的運作方式

Wink 將 QR Code 變成真正的通路，而非靜態連結。

- **[Studio](/zh-TW/products/studio/) 產生 QR Code。** 建立可預訂的 Shareable Link 或資產，並下載品牌化的 **QR Code PNG 或 SVG**，用於印刷、標示及館內擺放。
- **[WinkLinks](/zh-TW/products/winklinks/) 托管目的地。** 當一個 QR Code 需呈現多個優惠時，指向行動優先的 Travel Storefront — 可預訂的飯店卡片、優惠、清單與地圖，統一在 `i.trvl.as/your-name` 連結下。
- **[Booking Engine](/zh-TW/products/booking-engine/) 完成訂房。** 點擊後進入結帳 — 選擇正確的客房、價格與加購，付款並確認 — 銷售整個住宿，不只是客房。
- **保留歸因。** 訂房會連結回該 QR Code 背後的活動、擺放位置或合作夥伴，讓飯店能看到哪些 QR Code 真正創造需求。

這是與 [飯店社群商務](/zh-TW/resources/hotel-social-commerce/) 相同的閉環 — QR Code 只是線下的入口。

## 實用 QR 行動指南

### 1 — 選擇時刻與意圖

決定每個擺放位置要販售什麼。餐廳桌立牌與婚禮橫幅是不同的任務。

### 2 — 先建立目的地

在印刷前先建立可預訂優惠或商店頁面。目的地就是活動，QR Code 只是入口。

### 3 — 產生並品牌化 QR Code

使用 Studio 產生 QR Code，並下載 PNG 或 SVG，確保印刷尺寸下依然清晰。

### 4 — 設計掃描體驗

在 QR Code 旁加上明確行動呼籲（「掃描預訂水療套裝」），並確保落地頁在手機上快速載入。

### 5 — 衡量並優化

追蹤各擺放位置的掃描轉訂房率。移除無效 QR Code，加強有效的。

## 常見錯誤

- **QR Code 只打開 PDF 或首頁。** 掃描必須導向可預訂內容。
- **一個通用 QR Code 用在所有地方。** QR Code 要符合當下時刻與意圖。
- **沒有歸因。** 無法知道哪個擺放位置帶來訂房，就無法優化。
- **桌面版設計的落地頁。** QR 流量是行動裝置，設計要符合行動優先。
- **先印刷後建立目的地。** 先建立目的地，再決定印刷。
