## 訂房可能出現的三項費用

大多數飯店商務定價會合併成一個混合百分比，這會隱藏哪些是服務費、哪些是轉嫁費用、哪些是銷售成本。拆開來看：

1. **平台費 — 1.5%。** 商務層為完成確認訂房所收取的費用。
2. **卡片處理費 — 依成本計算。** 卡片網路及處理商收取的費用，無加價轉嫁。
3. **佣金 — 預設為 10%，但只在特定情況下收取。** 支付給帶來客人的人。自家網站的訂房則為零。

自家網站的訂房只需支付項目 1 和 2。由合作夥伴、創作者或 AI 代理帶來的訂房則需支付全部三項。

## 為什麼卡片處理費不是固定數字

卡片處理費取決於卡片類型、發卡國家、貨幣及付款方式。國內借記卡與國外高級信用卡的接受成本不同，沒有誠實的服務商會承諾兩者皆為同一固定費用。

依成本轉嫁意味著飯店能看到每筆訂房的真實費用，而非加價後的平均值。這樣的折衷是總費用會呈現一個範圍，而非單一數字。僅供參考：以 4.0% 卡片費為例，直接訂房總費用約為 5.5%。實際數字取決於客人使用的卡片，且每筆訂房會顯示真實費用。

## 實例說明

以飯店自家網站的一筆 100 美元直接訂房為例，卡片費用以 4.0% 為示範：

| 項目 | 金額 |
|---|---|
| 訂房價值 | $100.00 |
| 平台費 (1.5%) | −$1.50 |
| 卡片處理費 (示範為 4.0%) | −$4.00 |
| **飯店淨收** | **約 $94.50** |

若該訂房由合作夥伴或創作者帶來：

| 項目 | 金額 |
|---|---|
| 訂房價值 | $100.00 |
| 平台費 + 卡片處理費 | −$5.50 |
| 合作夥伴佣金 (10%，扣除費用後計算) | −$9.45 |
| **飯店淨收** | **約 $85.05** |

即使是合作夥伴帶來的訂房，費用仍低於 OTA 訂房常見的 15–25% 佣金，且飯店保有客戶關係、電子郵件地址及後續訂房機會。

## 哪些是免費的

- 飯店自家網站的 **訂房引擎**
- 透過後台的 **物業管理**
- **WinkLinks** 商店
- **聯盟、合作夥伴及旅行社工具**
- **手動社群發文**、分析及排行榜
- **消費者及訂房引擎 API**

無訂閱費、座位費或設定費。唯一按使用量計費的是社群的 AI 內容生成及超出免費月額的合作夥伴 API 流量 — 這兩者皆非訂房所必需。

## 誰是交易商

**飯店是交易商**。款項為飯店收取，飯店仍是與客人簽約的主體。這對稅務、拒付及消費者保護義務很重要，也是飯店保有客戶關係而非租借的原因。

持牌營運者（例如核准的旅行社）可自行收款並直接支付給飯店。此時 Wink 僅收取 **1.5% 的處理費**，每月開立發票，因為 Wink 不處理資金。

## 值得向任何服務商詢問的問題

- 卡片費用是 **轉嫁成本還是加價**？
- 平台費是針對 **訂房數量還是總營收** 收取？
- 佣金是基於 **總額還是扣除費用後的淨額** 計算？
- 誰是 **交易商**，誰負擔拒付責任？
- 是否有額外的 **訂閱費、座位費或設定費**？
- 取消或退款時，費用如何處理？

## 常見錯誤

- **將混合費率與拆分費率比較。** 請先對應相同類型再做結論。
- **忽略客戶終身價值。** 可再次聯絡的直接客戶比無法聯絡的更有價值。
- **誤以為佣金是不可避免。** 佣金只適用於合作夥伴帶來的訂房，不適用於自家網站流量。
- **以為便宜就代表功能少。** 付費前請先了解免費方案包含哪些功能。
