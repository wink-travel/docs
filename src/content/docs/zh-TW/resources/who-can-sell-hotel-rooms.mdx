## 兩種常被混淆的活動

**推薦訂房。** 您推薦飯店，旅客訂房，飯店收款，您賺取佣金。您從不持有款項。

**作為商戶銷售。** 您將旅客的付款收進自己的帳戶，並自行支付給飯店。您現在是欠旅客住宿服務的一方。

第二種情況在大多數市場會觸發執照要求，並伴隨拒付風險、退款義務及稅務處理。第一種通常不會，因此創作者無需公司架構也能賺取佣金，而持有客戶款項的旅行社則需要執照。

## 兩種模式的差異

| | 為飯店收款 | 您自行收款 |
|---|---|---|
| 商戶身份 | 飯店 | 您 |
| 旅行社執照 | 推薦不需 | 通常依地區需 |
| 拒付責任 | 飯店 | 您 |
| 退款與取消 | 飯店處理 | 您處理 |
| 消費者保護義務 | 飯店 | 您 |
| Wink 費用 | 每筆訂單 1.5% 平台費加卡片手續費成本 | 僅 1.5% 處理費，月結 |
| 佣金比例 | 預設 10% | 您自行設定利潤 |
| 需要的身份 | 任何人 | 持牌營運者 |

## 誰可以無需執照賺取佣金

在第一種模式下，以下各方都可以從飯店訂房賺取佣金：

- **創作者與意見領袖** 向觀眾發布推薦
- **出版商與電子報** 發布目的地或飯店相關內容
- **社群與俱樂部** 組織會員旅遊
- **活動主辦方** 為與會者安排房間
- **代理商與目的地管理公司** 規劃客戶行程
- **銀行、忠誠與會員計劃** 提供旅遊福利
- **應用程式、平台與 AI 代理** 嵌入訂房流程

他們都不持有旅客款項，因此不成為商戶。飯店依舊與旅客簽約並提供住宿。

## 何時第二種模式合理

自行收款適用於少數情況 — 當您已是持牌旅行業者，擁有自己的客戶合約、付款關係及退款政策，且需要飯店成為您的供應商而非商戶。常見例子是將機票與飯店打包的旅行社。

若是您，Wink 僅收取**1.5% 的處理費**，且不參與資金流。若非您，第一種模式能以更少負擔獲得相同佣金。

## 開始銷售前應確認

- **旅客所在地**，不僅是您所在地 — 消費者保護規定通常依旅客所在地而定。
- **是否會持有款項**，即使是短暫持有。持有款項是關鍵界線。
- **是否打包** 飯店與交通，可能觸發額外的套裝旅遊規定。
- **退款如何返還旅客**，以及住宿出問題時誰負責。
- **您自己條款中承諾的內容**，因為這可能無論模式都會產生義務。

各國規定不同且會變動。選擇成為商戶前，請先諮詢當地顧問確認您的立場。

## 常見錯誤

- **誤以為賺取佣金需要執照。** 推薦模式通常不需。
- **不小心成為商戶**，因為「方便起見」將付款導入自己帳戶。
- **承諾無法控制的退款**，當飯店持有款項及退款政策時。
- **以一國規定套用全球。** 義務通常依旅客所在地而定。
- **為了更好費率選擇商戶模式。** 佣金不會更高，反而增加責任。
