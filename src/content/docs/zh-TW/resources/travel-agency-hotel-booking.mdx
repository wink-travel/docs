## 直接供應與轉售供應的差異

大多數代理商飯店內容是透過一條鏈條傳遞：飯店 → 通路管理系統 → 批發商或床位銀行 → 代理商。每一環節都增加延遲、利潤空間，並造成代理商看到的資訊與飯店實際狀況不一致。

常見的問題包括：客戶決定時房價已過時、確認時無法訂到房、房型描述不符，以及無法向飯店詢問非自己訂的訂單問題。

直接訂房則省略中間環節。房價是飯店的，即時可訂房況，訂單直接進入飯店系統並附加您的代理商資訊。

| | 批發商 / 床位銀行 | 直接飯店供應 |
|---|---|---|
| 房價來源 | 合約配額，通常為靜態 | 飯店即時房價 |
| 可訂房況 | 快取，確認時可能失敗 | 飯店即時提供 |
| 利潤結構 | 房價內含加價 | 透明佣金 |
| 客戶擁有權 | 共享或不明確 | 代理商保有客戶 |
| 飯店關係 | 間接 | 直接與飯店 |
| 特殊需求 | 經由多層傳遞 | 訂房時直接聯繫飯店 |

## 代理商直接訂房所需條件

- **取得符合資格的供應** — 飯店設定哪些飯店、房型與房價可供您的代理商使用。
- **客戶友善的呈現方式** — 精選飯店清單、套裝行程、地圖或提案/行程的展示頁面。
- **保留來源的訂房流程**，確保佣金能正確歸屬，無需追蹤。
- **明確的付款條款** — 誰收款、誰是交易記錄商家、佣金何時結算。
- **訂單確認與修改流程**，確保訊息能送達飯店。

## 付款方式的兩種可能

**飯店收款。** 付款由飯店收取，飯店為交易記錄商家。代理商從歸屬訂單中賺取佣金，無需承擔商家責任。這是預設方式，無需執照。

**代理商收款。** 持有適當區域旅遊代理執照的代理商可自行向客戶收款，並直接支付飯店。Wink只收取**1.5%處理費**，每月開立發票，因為不處理資金。適用執照依營運地點而定，選擇此方式前請先確認當地規定。

## 佣金及計算方式

預設佣金為**10%**，計算基礎是扣除飯店1.5%平台費與刷卡手續費後的淨額，而非總額。以2000美元訂單為例，約為**189美元**。佣金歸屬期限為**每次點擊6個月**，對於提案可能與客戶持續數週的代理工作非常重要。

## 團體、活動與MICE訂房

直接供應在批發商較弱的領域最有價值：婚禮、會議、靜修與獎勵旅遊的房間包區。這些需要與飯店討論房價、保留與截止日期，只有當訂單屬於您且飯店知道您身份時才可能。

由符合資格供應建立的展示頁或活動頁，讓參與者有可訂房連結，同時保留包區、歸屬與報告給代理商。

## 常見錯誤

- **將淨批發價與可抽佣的直接房價比較**，卻未調整淨價中已含的加價。
- **寄送PDF給客戶。** 無法直接訂房的提案會流失訂單給能訂房的競爭者。
- **所有客戶共用一個連結。** 佣金歸屬與報告變成猜測。
- **誤以為賺取佣金需要執照。** 只有自行收款才需要執照。
- **忽略包區取消條款**，直到客戶詢問才發現。
