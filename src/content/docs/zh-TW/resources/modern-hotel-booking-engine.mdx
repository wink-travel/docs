## 訂房引擎的功能

飯店訂房引擎將訂房意圖轉化為預訂。SiteMinder 將其描述為讓飯店接受直接線上預訂的軟體 — 這仍然正確，但現代的期待更廣泛。如今訂房引擎應顯示準確的房價與可用性；讓客人選擇日期、房型、房價方案及細節；清楚顯示政策；支援付款或詢問；向客人與飯店確認；適用於行動與桌面裝置；支援額外服務與加購項目；並將來源、活動與合作夥伴資訊帶入報告。

對 Wink 而言，訂房引擎也服務**多重需求路徑。**訂房可能從網站、可分享連結、QR 碼、網頁元件、社群貼文、WinkLinks 商店、合作夥伴連結、Traveliko 列表、Agentic AI 交接或開發者整合開始 — 引擎應載入正確的飯店資料並完成每個路徑背後的交易。

## 為何只支援房型結帳已不夠

許多舊有引擎建構於單一流程：選房、選價、輸入資料、付款。這仍然重要 — 但住宿範圍比房晚更廣。客人可能想要早餐、延遲退房、提前入住、接送、停車、升等、水療療程、餐飲體驗、健康套裝、當地導覽、活動票券、會議室，或家庭及長期住宿優惠。

SiteMinder 與 Cloudbeds 都將加購項目視為訂房流程的一部分，反映更廣泛的期待：訂房路徑應幫助客人**圍繞房型預訂塑造住宿體驗。**對飯店而言，加購與套裝行程提升訂單價值，創造更明確的直接訂房理由，使社群與合作夥伴活動更具針對性，並將需求連結至完整飯店產品。

## 房型預訂周邊應支援的項目

| 產品或優惠 | 重要性 | 範例路徑 |
|---|---|---|
| 房型與套房 | 核心住宿庫存。 | 網站、直接連結、Traveliko、合作夥伴商店。 |
| 房價方案 | 選擇取消政策、餐飲方案或價值權衡。 | 訂房引擎房價方案頁面。 |
| 套裝行程 | 提供明確的訂房理由。 | 週末、家庭、浪漫、健康、長期住宿。 |
| 加購項目 | 提升價值並個人化住宿。 | 早餐、接送、停車、升等、提前/延遲退房。 |
| 餐飲 | 為房型預訂增加餐飲價值。 | 住宿加餐套裝、早餐加購。 |
| 水療與健康 | 為住宿增加健康價值。 | 水療套裝、健康住宿、療程加購。 |
| 體驗 | 將目的地內容轉化為住宿價值。 | 導覽加購、課程、飯店主導體驗。 |
| 活動與團體 | 捕捉活動房型需求與詢問。 | 詢問路徑、房間區塊、活動套裝。 |
| 合作夥伴專屬優惠 | 讓合作夥伴推廣核准優惠。 | 合作夥伴連結、QR 碼、商店、活動卡。 |

答案因飯店而異 — 都市飯店可能以房型、早餐與延遲退房為主；度假村可能優先水療與餐飲套裝；活動飯店可能需要詢問與房間區塊。引擎應支援房型*周邊*策略，而非強迫所有飯店採用相同模式。

## 結帳摩擦很重要

訂房引擎同時也是結帳系統。Baymard 研究報告平均購物車放棄率超過 70% — 飯店訂房不完全等同電商購物車，但教訓相同：當客人準備購買時，每個不必要欄位、混淆錯誤、不清楚政策或意外費用都會造成流失。注意過多必填欄位、非行動優先設計、不明稅費或包含項目、後期出現的政策文字、與活動不符的房型頁面、強制加購、低信任付款步驟、錯誤清除已輸入資料，以及緩慢載入或版面跳動。強大的引擎讓下一步明確：**選擇、檢視、付款或詢問。**

## 行動裝置與效能期待

許多飯店需求現今從行動裝置開始 — 搜尋、地圖、社群、QR 掃描、合作夥伴活動、電子郵件或 AI 交接。Google 的 Core Web Vitals 衡量真實世界的載入速度、互動性與視覺穩定性（以 75 百分位數跨裝置評估）。實務上，訂房引擎應感覺載入快速、內容出現穩定、選擇日期與加購反應靈敏、小螢幕清晰，且驗證錯誤後可靠。**效能不只是 SEO 問題 — 它是營收問題。**緩慢或不穩定的流程會將需求流失回 OTA。

## 每個路徑都需要正確的飯店資料

現代引擎不應將每次點擊視為相同。網站按鈕載入直接路徑；可分享連結載入相關優惠；QR 碼保留來源追蹤；網頁元件保留嵌入上下文；合作夥伴連結保留合作夥伴與活動歸因；WinkLinks 卡片載入選定飯店與優惠；Traveliko 列表使用有效庫存；Agentic AI 交接保留合格意圖；開發者應用保留平台上下文。**這是通用訂房表單與商務履約層的差異。**

## Wink 的定位

在 Wink 中，[Extranet](/zh-TW/products/extranet/) 是供應控制層 — 物業內容、房型、房價、可用性、政策、套裝行程、加購項目與訂房引擎設定（連接支援供應商或手動維護房價）。[Booking Engine](/zh-TW/products/booking-engine/) 將核准供應轉換為可預訂路徑，涵蓋飯店網站、連結、QR 碼、網頁元件與 WinkLinks — 以及合作夥伴路徑、[Traveliko](/zh-TW/products/traveliko/)、[Agentic AI](/zh-TW/agentic-ai/) 與開發者整合 — 載入飯店專屬資料並在適當時向客人、飯店與合作夥伴確認。[Studio](/zh-TW/products/studio/) 創建指向它的連結、卡片、QR 碼與元件。價格細節則在[價格](/zh-TW/pricing/)頁面。
