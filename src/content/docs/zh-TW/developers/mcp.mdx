Wink 的 MCP 工具以 **工具集** 形式發布 — 專注的端點，每個端點涵蓋一項工作。您將 AI 用戶端連接到符合您工作的一兩個端點，而非全部。

每個端點都使用 **互動式 OAuth2 登入**（PKCE 授權碼流程）：您的 AI 代理會開啟瀏覽器分頁，您使用 Wink 帳號登入，完成後即完成設定。無需管理用戶端密鑰。

```bash title="頻道管理整合者連接到一個端點"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="飯店業者管理自己的價格連接到另一個端點"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

---

## 為什麼工具分散在多個端點

Wink 提供約 500 個工具。一次交給代理全部使用技術上可行，但並不理想。

**工具定義會佔用上下文。** MCP 伺服器廣告的每個工具都會在模型執行工作前載入到上下文視窗中，包含其描述與完整參數結構。五百個工具會佔用大量預算，影響您實際任務的執行，每次請求皆是如此。

**選擇品質隨列表增長而下降。** 從 500 個名稱相似的工具中挑選，代理做出較差的選擇；從 40 個中挑選則較佳。若您整合頻道管理器，約有二十個工具與您相關；其餘 480 個是噪音，讓正確工具更難找到。

**工作本質上是可分離的。** 同步 PMS 可用性的人與策劃聯盟登陸頁的人幾乎不共用工具。依工作拆分，讓每個連線只帶有該工作的詞彙。

<Aside type="caution" title="工具集不是權限">
選擇狹窄的工具集**不會**限制您的帳號權限，選擇廣泛的工具集也不會授予額外權限。每個工具都依照您登入身份執行與網頁入口相同的帳號權限。如果您的帳號無法在 Wink Portal 取消訂單，代理也無法 — 不論連接哪個端點。

選擇工具集是為了**專注**，不是為了安全。
</Aside>

### `https://integrations.wink.travel` — 頻道管理整合

一個端點，因為此主機只服務一項工作。

| 端點 | 工具數 | 涵蓋範圍 |
|---|---:|---|
| `/mcp/channel-manager` | 約 9 | 連接與驗證頻道管理器、PMS 或 CRS 整合 |

<Aside type="note" title="整合頻道管理器 vs. 自行管理價格">
這是不同工作，針對不同人，且不共用端點。

**頻道管理器、PMS 或 CRS 供應商** 透過 `integrations.wink.travel/mcp/channel-manager` 整合一次，之後透過該整合交換物業、價格、可用性與訂房。該單一端點即為整個介面。

**飯店業者手動更改價格** 使用 `api.wink.travel` 上的外部網工具集 — `/mcp/extranet/rates` 等。這些不屬於頻道管理器整合，整合者無需連接。

帳號管理也在 `api.wink.travel`，位於 `/mcp/settings`。整合主機上沒有 `/mcp/settings`。
</Aside>

每個端點也包含一個 `ping` 工具，讓您在要求執行實際工作前確認連線是否活躍。

## 我需要哪些工具集？

| 如果您是… | 連接到 |
|---|---|
| **整合頻道管理器、PMS 或 CRS** | `integrations.wink.travel/mcp/channel-manager` — 只有這個 |
| **管理物業內容** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **管理客房與房型** | `/mcp/extranet/facilities` |
| **管理價格與可用性** | `/mcp/extranet/rates` |
| **執行日常訂房** | `/mcp/extranet/operations` |
| **擴展銷售通路** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **建立聯盟頁面** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **經營連結頁面** | `/mcp/link-manager` + `/mcp/social` |
| **代旅客訂房** | `/mcp/travel-agent` |
| **對帳** | `/mcp/payment` |
| **建立訂房體驗** | `/mcp/booking-engine` + `/mcp/reference` |

從一個開始。當您發現它無法完成某項工作時，再新增另一個 — 每個連線獨立，新增不會影響其他。

<Aside type="tip" title="還是想要全部？">
`https://api.wink.travel/mcp` 和 `https://integrations.wink.travel/mcp` 仍可使用，並提供其主機上的**所有**工具。它們適合探索現有工具，但不建議用於日常工作：工具列表過大會擠壓您的任務並降低代理的工具選擇品質。建議使用上述工具集。
</Aside>

## 認證運作方式

Wink MCP 伺服器使用 **OAuth2 授權碼 + PKCE** 流程，並支援 **動態用戶端註冊 (RFC 7591)**。首次連接時流程如下：

1. 您的 AI 用戶端從 MCP 端點的 `/.well-known/oauth-protected-resource` 元資料發現授權伺服器。
2. 用戶端透過 **動態用戶端註冊** 自行註冊 — 無需手動設定應用程式。
3. 用戶端開啟瀏覽器分頁至 `https://iam.wink.travel`。您使用 Wink 帳號登入並在同意畫面批准權限。
4. Wink 發行一個與您的帳號及身份綁定的 **存取權杖**。
5. AI 用戶端將權杖附加於每個 MCP 請求。所有工具結果自動依管理實體範圍限制。
6. 權杖有效期為 3 小時。AI 用戶端會在背景靜默刷新，無需再次提示。

每次工具呼叫皆**以您的身份執行** — 保護網頁入口的 ACL 規則同樣適用於 AI 代理。

## 權限範圍

當您批准同意畫面時，會看到代理請求的權限細項。MCP 用戶端使用與平台其他部分相同的權限詞彙 — 詳見認證頁的完整[權限範圍參考](/zh-TW/developers/authentication#scopes)。

MCP 特有兩點：

- **`mcp.read`、`mcp.write`、`mcp.remove` 權限範圍是開啟 MCP 傳輸的額外要求。** 持有 `mcp.*` 權限的用戶端可存取任何 Wink MCP 端點，但每個工具仍會執行其所屬端點的區段權限（例如 `booking.read`）。
- **AI 用戶端只請求所需權限。** 您可在同意畫面拒絕個別權限 — 需要被拒絕權限的工具呼叫會回傳錯誤。

**工具集不改變這些規則。** 您連接的端點決定哪些工具*列出*，而非它們*被允許做什麼*。連接 `/mcp/payment` 不會授予您未持有的財務權限，連接 `/mcp/reference` 也不會阻止該處工具執行其權限。授權由每次工具呼叫根據您的權杖與帳號授權決定。

## 疑難排解

**瀏覽器分頁未開啟**

您的 AI 用戶端可能尚未支援互動式 PKCE 流程。請確認您使用的是新版：
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT 桌面:** 從應用程式內建更新器更新

**登入後出現 `401 Unauthorized`**

您的快取權杖可能已過期。移除並重新新增伺服器以觸發重新登入：

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

Claude Desktop 和 ChatGPT 請從設定移除伺服器條目，重啟應用程式後再新增。

**呼叫特定工具時出現 `403 Forbidden`**

該工具需要您在同意畫面未批准的權限範圍，或您的帳號未持有該權限。重新連接伺服器 — 同意畫面會再次出現，您可批准缺少的權限。若仍失敗，表示工具需要您未持有的帳號權限；更換工具集無法解決，因為工具集不授權權限。

**我需要的工具不在列表中**

您可能連接了不涵蓋該工作的工具集。檢查[端點目錄](#endpoint-directory)，新增涵蓋該工作的工具集 — 連線獨立，新增不會影響其他。若不確定工具在哪個工具集，暫時連接 `https://api.wink.travel/mcp`，找到工具後查詢其所屬工具集。

**工具集端點出現 `404 Not Found`**

請仔細檢查路徑 — 嵌套工具集有兩段（如 `/mcp/extranet/rates`，非 `/mcp/extranet-rates`），平面工具集有一段（如 `/mcp/link-manager`）。未認證請求至 `/mcp` 下任何路徑會回傳 `401`，非 `404`，因此僅憑 `401` 無法判斷端點是否存在。

**我連接 `api.wink.travel/mcp/channel-manager` 但沒反應**

該端點不存在。頻道管理整合僅由 `https://integrations.wink.travel/mcp/channel-manager` 提供。若您還需手動讀寫物業價格，請使用另一個端點 — 參見 `/mcp/extranet/rates`。

**伺服器出現但工具呼叫回傳「找不到帳號」**

您登入的 Wink 帳號尚未設定管理實體。請前往 [Wink Portal](https://app.wink.travel) 確認帳號設定後再使用 MCP 伺服器。

**權杖在會話中期過期**

權杖有效期為 3 小時。Claude Code 和 Claude Desktop 會靜默刷新權杖，不會中斷會話。若長時間閒置後出現認證錯誤，輸入新訊息 — 用戶端會自動重新認證。

**Codex CLI 顯示「MCP server unreachable」**

確認您的 `~/.codex/config.json` 是有效 JSON（無尾逗號），且 `"type": "http"` 已設定。Codex 遠端伺服器需 HTTP 傳輸；stdio 傳輸僅用於本地二進位檔。

**ChatGPT「連接器」選單消失**

MCP 支援需 ChatGPT 桌面應用程式版本 **1.2024.352** 或以上，且需 Plus、Pro、Team 或 Enterprise 訂閱。請更新應用程式並在設定 → 帳號確認方案。

**Cursor 伺服器顯示紅色 / 「連線失敗」**

確認 `~/.cursor/mcp.json` 是有效 JSON 且包含 `"type": "http"`。前往 **設定 → Cursor 設定 → MCP** 點擊 **重新整理**。若錯誤持續，請完全重新啟動 Cursor — 設定變更有時需重啟才能生效。

**Windsurf MCP 伺服器未出現在設定中**

Windsurf 需完全重新啟動（非僅重新載入視窗）才能讀取 `mcp_config.json` 變更。使用 **檔案 → 退出** 並重新啟動。若仍未出現，請確認 Windsurf 版本為 **1.4+**，可透過 **說明 → 關於 Windsurf** 檢查。

**Cline 無法看到「新增伺服器」選項**

MCP 伺服器管理器需 Cline 版本 **2.0** 或以上。開啟 VS Code 擴充套件面板，找到 Cline，若有更新按鈕請點擊更新。更新後重新載入 VS Code（`Ctrl+Shift+P` →「Developer: Reload Window」）。
