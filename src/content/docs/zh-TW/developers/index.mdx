每個平台功能皆可外部調用。本節涵蓋身份驗證、API 介面、事件傳遞及其背後的參考資料。

## 從這裡開始

- [在 Wink 上開發](/zh-TW/developers/build-on-wink/) — 你可以開發什麼以及適合使用哪個 API。
- [設定](/zh-TW/developers/setup/) — 建立應用程式並取得憑證。
- [身份驗證](/zh-TW/developers/authentication/) — OAuth2 會話與權限範圍。

## API 介面

- [REST 和 gRPC](/zh-TW/developers/rest-and-grpc/) — 兩種傳輸方式及何時使用。
- [地理定位](/zh-TW/developers/geolocation/) — 可預訂庫存的空間搜尋。
- [分類法](/zh-TW/developers/taxonomy/) — OTA 代碼、支援語言與貨幣。

## 事件與同步

- [Webhook 整合](/zh-TW/developers/webhook-integration/) — 訂閱平台事件。
- [Webhook 事件目錄](/zh-TW/developers/webhook-events/) — 平台發出的所有事件。
- [訂單同步](/zh-TW/developers/booking-sync/) — 與 PMS 或渠道管理器保持訂單一致。

## AI 代理

- [MCP 伺服器](/zh-TW/developers/mcp/) — 從 AI 用戶端讀取即時 API 合約。
- [Agentic 付款](/zh-TW/developers/agentic-payments/) — 連接你的代理，登入、尋找房間並批准付款。
- [AI 技能](/zh-TW/developers/ai-skills/) — 核准代理在平台上能執行的功能。
