需求合作夥伴協議不允許與 Wink 供應進行價格比較，除非「明確允許」（條款 11.3）。本頁說明 Wink 如何授權搜尋顯示的權限，以及您取得該權限後，顯示必須遵守的規則。

## 什麼是搜尋顯示

**搜尋顯示** 是指在使用者搜尋時，從 Partner API 顯示飯店，並與其他飯店優惠（包括來自其他來源的免費替代方案）一起呈現，點擊後會在您的聯盟帳戶下開啟該飯店的 Wink 訂房引擎。

它僅涵蓋搜尋、內容與點擊導向。透過 Partner API 建立、更改或取消訂單，需另獲 Wink 書面批准。

## 每次顯示的規則

- **即時價格。** 價格與可訂房狀態必須反映顯示當下的即時資料（條款 8.2）。
- **價格不變。** 顯示的每個價格必須與 Partner API 回傳完全相同，不得加價、加收費用或更改。飯店設定並控制其價格。
- **準確呈現。** 價格、包含項目及取消政策必須準確呈現，且不得改變其意義（條款 6.1）。
- **絕不將 Wink 呈現為賣方。** 您的產品在視覺與結構上必須與 Wink 明顯區隔，絕不自稱為 Wink，也不得將 Wink 呈現為獨立的線上旅行社或賣方（條款 7.4）。住宿合約是旅客與飯店間的合約。
- **揭露。** 法律要求時，必須揭露您與 Wink 的商業關係（條款 6.2）。
- **禁止轉用。** 不得將 Wink 供應的資料或內容轉授權、轉讓或透露給任何其他人（條款 11.3）。

## 暫時顯示

Wink 不限制您持有搜尋結果的時間，因為沒有人知道價格何時會變動：飯店可能五秒後或一年後改價。重要的是您顯示的價格與可訂房狀態必須與顯示當下的即時資料相符（條款 8.2）。每當行程變更，或在顯示您無法確定仍為最新的結果前，請再次從 Partner API 取得資料。

遵守這些規則的顯示不屬於條款 7.5 所稱的「內容靜態複製」，也不屬於條款 8.2 所稱的過期價格快取。

## 內容快取

飯店內容（名稱、描述、圖片、設施與政策）無快取時間限制。請使用 Partner API 中每個飯店的 `lastUpdate` 作為快取鍵，並在內容變更時更新。

## 您可保留的識別碼

您僅可保留以下識別碼：

- Wink 飯店 ID 與飯店 `urlName`，
- 歸屬於您的訂單參考號碼，
- 您自己的歸屬、客戶與設定 ID，以及相關的點擊與訂單日期。

僅用於跨來源去重飯店列表，以及歸屬、報告與佣金對帳。請勿保留價格、可訂房狀態或飯店內容超出上述規則，且不得使用 Wink 的任何資料（包括這些識別碼）來訓練、微調或評估模型，或用於建立或改進供應資料庫（條款 7.5 與 10.6）。

## 如何申請權限

搜尋顯示需 Wink 明確書面授權，作為您需求合作夥伴協議的附函。該授權在附函與協議雙方接受後生效，若違反上述規則，Wink 可提前通知或立即撤銷。

申請時，請寄信至 [legal@wink.travel](mailto:legal@wink.travel)，並提供：

- 您的產品名稱，
- 若已上線，請附上網址，
- 您計畫如何使用 Wink 供應：將顯示什麼、在哪裡，以及與哪些內容並列。
