# 設定

當您首次使用 Social 時，我們會詢問您希望如何建立內容。這些選項隨時可用，讓您輕鬆在之後更改。

請從側邊欄導覽至 `Settings` 以管理您的設定。

偏好設定區包含您的基本內容產生設定：

1. **偏好自訂** 選擇產生內容時要使用的自訂設定。自訂設定控制主題色彩、預設行程、貨幣、語言等。您可在 [app.wink.travel](https://app.wink.travel) 帳戶中建立自訂設定。
2. **自動核准** 啟用後，產生的貼文會自動發布，無需您的核准。當您對我們產出的內容品質有信心時，請啟用此功能。
3. **核准者名稱** 將收到核准請求電子郵件的人員或團隊名稱。
4. **核准者電子郵件** 將寄送即將發布貼文核准請求的電子郵件地址。

Social 提供多種內容創作者可供選擇。每位創作者專注於使用 AI 為您的物業創造獨特內容的特定方式。每位內容創作者都有一個 **權重** 屬性 — 權重越高，該創作者在產生貼文時被選中的機率越大。

以下是所有可用的內容創作者：

| 創作者 | 說明 |
| -- | -- |
| **目的地** | 利用您的地點創造有用的區域介紹文字 |
| **房型** | 以 AI 產生文字及您的房型圖片，創建可預訂的房型貼文 |
| **活動** | 創建以您的活動為主題的可預訂貼文 |
| **加購項目** | 創建以您的加購項目為主題的可預訂貼文 |
| **景點** | 創建以您的景點為主題的可預訂貼文 |
| **地點** | 創建以您的地點為主題的可預訂貼文 |
| **會議室** | 創建以您的會議室為主題的可預訂貼文 |
| **餐廳** | 創建以您的餐廳為主題的可預訂貼文 |
| **水療** | 創建以您的水療為主題的可預訂貼文 |
| **物業** | 以 AI 產生文字及您的物業圖片，創建以最佳價格房型為主題的可預訂貼文 |
| **用戶情感** | 彙整網路上的旅客評論，產生情感導向貼文，突顯旅客喜愛您的物業的原因 |
| **幽默** | 創建輕鬆有趣的貼文，讓您的動態保持吸引力 |

:::tip[專家提示]
請確保您擁有所選內容創作者所需的庫存類型。例如，若選擇「餐廳」，您的物業需至少有一家餐廳。
:::

## 語氣風格

<CldImage

  <figcaption>*圖 3 - 語氣風格*</figcaption>

語氣風格設定 AI 產生內容時使用的語言風格。選擇符合您品牌個性的語氣。與內容創作者一樣，每種語氣都有一個 **權重**，用以控制使用頻率。

以下是可用的語氣：

| 語氣 | 風格 |
| -- | -- |
| **中性** | 冷靜、權威、事實性。無誇張、無笑話 — 只有可靠且結構良好的知識 |
| **親切** | 溫暖、親近、文字中帶笑容，使用口語縮寫及偶爾表情符號 |
| **奢華** | 精緻、優雅。使用「精美」和「訂製」等詞彙，讓讀者感受尊貴 |
| **美食家** | 感官豐富、令人垂涎的描述。美食誘惑語言讓讀者食指大動 |
| **冒險** | 大膽、無畏、探險家氣息。生動感官描述讓一切聽起來壯闊 |
| **家庭** | 健康、適合兒童的興奮感。溫暖的父母氣息，關於安全且有趣的體驗 |
| **浪漫** | 詩意、憧憬、心動。夕陽、柔和語言與愛情 |
| **幽默** | 諷刺、快速一語雙關、巧妙文字遊戲。讀起來像單口喜劇表演 |
| **環保** | 誠懇且正義感強。讚揚綠色替代方案與永續選擇 |
| **在地達人** | 極具地方特色的參考，提醒避開觀光陷阱，使用在地俚語 |
| **包容** | 歡迎、慶祝且肯定。讓每個人都感受到被看見與重視 |
| **神秘** | 空靈、靈性、宇宙真理。溫柔邀請內省 |
| **未來感** | 流暢、前瞻。喜愛「範式轉移」等詞彙與樂觀未來願景 |
| **經濟實惠** | 精明、足智多謀、驕傲地節儉。讚揚實惠發現與免費體驗 |

## 貼文類型

貼文類型決定產生內容的目標與結構。每種貼文類型都有一個 **權重**，用以控制使用頻率。

| 貼文類型 | 說明 |
| -- | -- |
| **交易型** | 清晰、簡潔、以轉換為目標。以事實、價格及後續步驟推動訂房與直接行動 |
| **認知型** | 品牌建立內容，旨在介紹您的物業並提升潛在旅客的能見度 |
| **情感型** | 具情感共鳴的內容，創造正面聯想並與受眾建立情感連結 |

您可能想將行銷重點放在特定語言與區域。告訴我們您想為哪些語言創建內容及您關注的時區，我們會負責其餘工作。貼文會在您選擇的時區預定時間發布。

*大多數物業使用單一語言，並預設為當地語言。*
