您已經連結到 WinkLinks，我們的連結管理工具。點擊 `Connect a social network` 以連結更多您的社交網路。
此流程會將您導向您的社交網路，批准 `Wink Social` 應用程式代表您發布內容。

連結完成後，我們會開始為該網路產生下個排程月份的內容。

:::note
發布到 WinkLinks 永遠免費。產生的 Facebook 和 Instagram 貼文有免費的每月額度，超出後將依發布貼文數量計費 — 請參閱 [價格](/zh-TW/getting-started/pricing)。
:::

## 支援的平台

| 平台 | 說明 | 要求 |
| -- | -- | -- |
| **WinkLinks** | 自動發布至我們的進階連結管理器 | 永遠免費，無額度限制 |
| **Facebook** | 自動發布貼文，回覆留言和私訊 | 需要 Facebook 商業專頁 |
| **Instagram** | 自動發布貼文，回覆留言和私訊 | 需要連結 Facebook 帳號的 Instagram 商業帳號 |

每個連結會顯示目前狀態：**啟用中**、**已斷開** 或 **已暫停**。

:::note
我們會為每個社交網路建立並發布最佳化的內容。
:::
