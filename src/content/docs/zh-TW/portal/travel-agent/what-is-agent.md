註冊的旅行社使用與其他人相同的入口網站 [app.wink.travel](https://app.wink.travel)，並使用旅行社帳號。代理人代表其客戶搜尋並預訂，並從每筆訂單中賺取佣金。要設定帳號，請參考 [成為旅行社入門指南](/zh-TW/guides/travel-agents/getting-started/)。

獲批准自行收款的旅行社，將作為商戶記錄並在 Wink 平台外處理付款。有自己系統的旅行社可透過 [Partner API](/zh-TW/integrations/partner-api/) 進行整合。

旅行社擁有與 [Studio](/zh-TW/portal/studio/what-is-studio) 部分相同的入口網站功能，因此此處不再重複說明。

## 搜尋

請前往 [搜尋](/zh-TW/portal/studio/search) 了解如何搜尋及預訂飯店。

否則，請繼續閱讀下一節。

## API

旅行社可透過 [Partner API](/zh-TW/partner-api/partner/) 進行搜尋及預訂，此 API 取代舊有的旅行社 REST 端點。
