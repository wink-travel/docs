Extranet 是我們位於 [app.wink.travel](https://app.wink.travel) 的單一應用程式 [Portal](/zh-TW/portal/overview) 中的物業端。它專為飯店、連鎖、品牌及飯店管理公司設計，用以建立及管理其在 Wink 平台上的數位物業檔案。

您不需要另外註冊，也沒有其他地方需要登入 — 在 Portal 中選擇一個物業帳號，這裡描述的 Extranet 功能就會立即呈現。

Extranet 經過精心設計，盡可能簡單，但仍支援進階使用者期望的所有高級物業入口網站功能。舉幾個例子：

1. 簡單：使用我們智慧的上線流程，讓您的物業在不到一小時內完成上線。
2. 進階：Wink 支援 8500 種不同的取消政策變化。
3. 酷炫：讓地球上某個人享有 10% 折扣，且使用者無需登入或輸入促銷代碼。

讓我們的嚮導引導您完成整個流程。當您感到足夠熟悉後……就可以自行操作。

Wink 是一個先進的內容管理系統，適用於物業及體驗提供者。您在 Portal 中能做的事，都可以透過 API 完成。這讓您能與 Wink 深度整合，甚至完全不需登入即可透過 Wink 銷售。

:::tip[專家提示]
您是否正在透過 Leonardo International 支付昂貴的媒體資產託管費用？您可以透過 Wink 做完全相同的事，且還能獲得更多操作及微調圖片和影片的選項。
:::

所有這些功能對您完全免費。只有在您完成訂房時，我們才會收取少量費用。沒有損失，只有收穫。
