本文說明如何在 Wink 上與積極的聯盟合作夥伴連結，並管理現有的合作夥伴。

## 銷售通路

要管理您的銷售通路，請從主選單點選 `Distribution > Sales channels`。

銷售通路是您現有的聯盟合作關係，並以他們可存取的庫存、優惠和折扣加以規範。

要更新現有的銷售通路，請點選您想更新的銷售通路下方的 `Actions` 連結。

- **會員折扣** 透過此銷售通路預訂的旅客可享有會員價格。
- **佣金** 每筆成功預訂，該銷售通路會獲得佣金。
- **單一促銷** 新增您希望此銷售通路擁有的促銷活動。
- **組合促銷** 新增您希望此銷售通路擁有的組合促銷活動。
- **啟用** 切換啟用開關以完全啟用或停用該銷售通路。
- **黑名單** 將銷售通路標記為黑名單，將無法透過該通路進行預訂。

設定完成後，點選 `Save` 按鈕繼續。

:::tip
將銷售通路列入黑名單後，該通路將無法取得您的任何價格，甚至包括您的 Wink Network 價格。
:::

## 探索網路

要在 Wink 上尋找新的聯盟合作夥伴，請從主選單點選 `Distribution > Explore network`。

在此區域，您可以在頁面上方看到聯盟合作夥伴的待處理請求，下方則列出可連結的聯盟合作夥伴清單。

### 回應請求

您可以選擇拒絕聯盟合作夥伴的請求。若想繼續處理該請求，系統會帶您前往 `affiliate details` 頁面，您可在此取得該聯盟的更多資訊及 Wink 上的過往績效指標。

### 搜尋聯盟合作夥伴

在聯盟合作夥伴列表中，您可以依名稱、類型和地點搜尋。看到喜歡的對象時，點選即可前往 `affiliate details` 頁面。

### 與聯盟合作夥伴連結

若您選擇與某聯盟建立直接關係，系統會要求您以管理銷售通路的方式來規範此關係。

儲存新的銷售通路後，系統會帶您回到銷售通路清單。

## API
