Wink 沒有訂閱費、沒有座位費，也沒有設定費用。平台絕大多數功能都是免費的，您只會為以下兩項付費：

1. **每筆訂單收取少量百分比費用** — 僅在您實際賺錢時收取。
2. **按使用量付費的使用費** — 針對少數每次執行都會產生成本的高級功能，每項功能都有免費的月度額度。

## 免費項目

以下功能永遠免費，無額度限制，也不計量：

- **訂房引擎** — 可用於您的網站、WinkLinks 頁面或任何嵌入位置。
- **物業管理** — 內容、照片、價格、價格方案、可用性、促銷和政策。
- **聯盟工具** — 可分享的連結、精選清單、格狀圖、地圖、卡片和可嵌入小工具。
- **旅行社工具** — 搜尋、專屬價格及代表客戶訂房。
- **WinkLinks** — 申請您的專屬網址，建立頁面並隨時發布。
- **手動社群貼文** — 您自行撰寫的任何內容，發佈於任何連接的社群網路。
- **分析、排行榜、索賠、設定**及帳戶管理。
- **消費者與訂房引擎 API**，以及查詢和自動完成端點。

## 訂單

Wink 支援商戶模式和代理模式。

### 模式 1

訂單發生時，Wink 為商戶。Wink 負責資金並持有所有必要的旅行社營業執照。
此模式適用於 95% 的訂單。

Wink 對每筆訂單收取 `5.5%` 費用以維護平台。
大部分費用支付給支付閘道（Visa、MasterCard 等）。平均每筆訂單的取得成本為 `2.95%`，有時高達 `3.6%`。部分退款會進一步增加成本，因為支付閘道視為新交易。
我們希望現在就完全透明地說明價格，節省大家在使用 Wink 前談判折扣的時間。我們的定價模式非常公平，我們也需要維持營運。

#### 費用明細

:::note[處理費]
Wink 對每筆訂單收取 1.5% 的處理費。此費用涵蓋平台維護，讓我們能免費提供上述所有功能。
:::

:::note[支付費]
TripPay 對每筆訂單收取 4.0% 的支付費。此費用涵蓋從旅客取得付款的成本。
:::

:::note[資金撥付]
將資金匯入您的帳戶會產生費用，視您選擇的撥付方式而定。我們目前支援：

- **銀行轉帳** 費用依您所在地及資金來源國家而異。我們提供報價計算器，當您帳戶有可用資金時可使用。

若您希望我們支援其他撥付方式，請寄信告知。
:::

### 模式 2

此模式僅提供給持有當地旅行社執照且希望成為商戶的旅行社。部分註冊旅行社希望自行負責付款及資金撥付給飯店。此模式下，他們負責資金並持有必要的營業執照。

#### 費用明細

:::note[處理費]
Wink 對每筆訂單收取 1.5% 的處理費。此費用涵蓋平台維護，讓我們能免費提供上述所有功能。
:::

使用此模式，旅行社只需支付 Wink 的處理費，Wink 將每月向旅行社開立發票。

## 使用量（按使用付費）

少數功能每次執行都會產生成本 — 生成式 AI、第三方社群 API，以及大規模即時價格服務。您不需訂閱月費方案，而是只為實際使用量付費，且在用完免費月度額度後才開始計費。

| 功能 | 每月免費額度 | 之後費用 | 計費單位 |
| -- | -- | -- | -- |
| 社群貼文 — 圖片 | 1 | $1.50 | 一則已發布貼文 |
| 社群貼文 — AI 生成圖片 | 0 | $2.50 | 一則已發布貼文 |
| 社群貼文 — AI 強化影片 | 0 | $4.00 | 一則已發布貼文 |
| 社群貼文 — AI 生成影片 | 0 | $14.00 | 一則已發布貼文 |
| AI 回覆評論或私訊 | 5 | $0.05 | 一則回覆 |
| 聊天機器人回答 | 5 | $0.05 | 一則回答 |
| 合作夥伴 API | 10,000 | $0.0001 | 一個飯店-天 |

價格以美元計。免費額度**以帳戶為單位**，非以使用者計算，並於每月 1 日（UTC）重置。

### 貼文如何計價

貼文依內容計價，因為這是我們的成本。靜態圖片成本低；影片成本高；任何 AI 生成的媒體成本遠高於您自行提供的照片。

- **免費額度僅涵蓋標準圖片貼文。** 每帳戶每月可免費發布一則。影片貼文及 AI 生成媒體從第一則貼文起即計費 — 這些類別沒有免費額度，因此發布影片的物業在第一個月就會產生費用。
- **影片優先計價。** 若貼文包含任何影片，整則貼文皆以影片費率計費。混合圖片與影片的貼文視為影片貼文。
- **AI 來源決定費率。** 您自行提供的媒體（自有照片、影片或 Wink 內容庫）以標準費率計費。由我們生成的媒體則以 AI 費率計費。

### 什麼會計量，什麼不會

- 只有**發佈到第三方網路（Facebook、Instagram）的生成貼文**會計費。您自行撰寫的貼文無論發佈到哪裡皆免費。
- **發佈到 WinkLinks 永遠免費**，無論是否生成。
- 計費在**發佈時**產生，不是每次嘗試。反覆生成草稿直到滿意不會增加費用 — 您只為實際發佈的貼文付費。嘗試次數有限制：每則貼文約可重生成 10 次圖片、3 次影片，反映我們的製作成本。您在操作時會看到剩餘次數。
- 合作夥伴 API 中，**飯店-天**指一間飯店一晚住宿的價格 — *非* 一次 API 呼叫。一次搜尋回傳 20 間飯店、3 晚住宿即為 60 個飯店-天。查詢與自動完成端點免費且不計量。

### 如何啟用

按使用付費預設關閉。每個人都可無需操作享有免費額度。

若要超出免費額度，**帳戶擁有者**需啟用按使用付費並選擇要計量的帳戶。所有啟用帳戶的使用量會合併成**單一月度發票**，您可自動以信用卡付款或自行支付發票。

啟用後，您的使用量會被計量但**絕不會被限制速率** — 您不會因花費而遇到速率限制。

:::note[若您不啟用]
不會有任何功能中斷，也不會產生費用。您只會停留在當月免費額度：生成貼文無法發佈，合作夥伴 API 呼叫會回傳 `429`，直到額度重置。
:::

### 帳單狀態

| 狀態 | 意義 |
| -- | -- |
| 良好 | 一切正常運作。 |
| 逾期 | 付款失敗，系統正在重試。此期間功能仍可使用。 |
| 暫停 | 發票未付款至截止日。計費行為被封鎖；免費功能照常。 |

:::tip[即時價格]
單價與免費額度會在 Portal 中即時顯示，直接來自我們的帳單系統，讓您在承諾前可先查詢。請參閱 [Billing](/zh-TW/portal/plan) 以啟用按使用付費、選擇帳戶並追蹤本月使用量與發票。請參閱 [Social](/zh-TW/portal/social/what-is-social) 了解貼文量如何影響花費。
:::
