Wink 沒有訂閱費、沒有座位費，也沒有設定費用。平台絕大多數功能免費，您只需支付兩項費用：

1. **每筆訂單的平臺費用，加上成本價的信用卡處理費** — 僅在訂單成立時收取。
2. **按使用量付費的使用費** — 針對少數每次使用都會產生成本的高級功能，每項功能均有免費月度額度。

## 免費項目

以下功能永遠免費，無需額度限制或計量：

- **訂房引擎** — 可用於您的網站、WinkLinks 頁面或任何嵌入位置。
- **物業管理** — 內容、照片、價格、價格方案、可用性、促銷和政策。
- **聯盟工具** — 可分享連結、精選清單、格狀圖、地圖、卡片和可嵌入小工具。
- **旅行社工具** — 搜尋、客製化價格及代表客戶訂房。
- **WinkLinks** — 申請您的專屬網址，建立頁面並隨時發布。
- **手動社群貼文** — 您自行撰寫的任何貼文，於任何連結的社群網路。
- **分析、排行榜、索賠、設定**及帳戶管理。
- **消費者與訂房引擎 API**，以及查詢和自動完成功能端點。

## 訂單

Wink 支援兩種模式：Wink 代酒店收款，以及持牌旅行社作為商戶。

### 模式一 — Wink 代酒店收款

Wink 作為酒店的有限收款代理，代收旅客付款。酒店為商戶，旅客信用卡帳單上顯示酒店名稱。
此模式適用於 95% 的訂單。

#### 費用明細

:::note[平台費用]
Wink 對每筆訂單收取 1.5% 平台費。此費用涵蓋平台維護，讓我們能免費提供上述所有功能。取消訂單不收取此費。
:::

:::note[信用卡處理費]
收取旅客付款的支付處理費用以成本價轉嫁給酒店，無加價。費用依旅客信用卡及付款方式而異，具體金額顯示於每筆訂單的會計部分。若訂單取消或退款，處理商保留的費用仍需支付；若無費用，則不收取。
:::

:::note[資金撥付]
將資金匯入您的帳戶會產生費用，視您選擇的撥付方式而定。目前支援：

- **銀行轉帳** — 費用依您所在地國家、資金來源地及匯率轉換而異。撥付費用及匯率轉換費用由收款方支付，均為成本價。我們提供報價計算器，供您在帳戶有可用資金時使用。

若您希望我們支援其他撥付方式，請寄信告知。
:::

### 模式二 — 旅行社作為商戶

此模式僅限持有當地旅行社執照且希望成為商戶的旅行社使用。有些註冊旅行社希望自行負責付款處理及資金撥付給酒店。此模式下，旅行社負責資金並持有必要營運執照。

#### 費用明細

:::note[平台費用]
Wink 對每筆訂單收取 1.5% 平台費。此費用涵蓋平台維護，讓我們能免費提供上述所有功能。
:::

使用此模式，旅行社僅支付 Wink 平台費，Wink 將每月向旅行社開立發票。

## 使用量（按使用付費）

少數功能每次使用都會產生成本 — 生成式 AI、第三方社群 API，以及大規模即時價格服務。您不需訂閱月費方案，而是只為實際使用量付費，且先享有免費月度額度。

| 功能 | 每月免費額度 | 之後費用 | 計費單位 |
| -- | -- | -- | -- |
| 社群貼文 — 圖片 | 1 | $1.50 | 一則已發布貼文 |
| 社群貼文 — AI 生成圖片 | 0 | $2.50 | 一則已發布貼文 |
| 社群貼文 — AI 強化影片 | 0 | $4.00 | 一則已發布貼文 |
| 社群貼文 — AI 生成影片 | 0 | $14.00 | 一則已發布貼文 |
| AI 回覆留言或私訊 | 5 | $0.05 | 一則回覆 |
| 聊天機器人回答 | 5 | $0.05 | 一則回答 |
| 合作夥伴 API | 10,000 | $0.0001 | 一個飯店-天 |

價格以美元計。免費額度**以帳戶為單位**，非以使用者計算，並於每月 1 日（UTC）重置。

### 貼文如何計價

貼文依內容計價，因為製作成本不同。靜態圖片成本低；影片成本高；AI 生成內容成本遠高於您自行提供的照片。

- **免費額度僅涵蓋標準圖片貼文。** 每帳戶每月可免費發布一則。影片貼文及 AI 生成媒體從第一則貼文起即收費 — 這些類別無免費額度，因此發布影片的物業首月即會產生費用。
- **影片優先計價。** 若貼文包含任何影片，整則貼文以影片費率計價。圖片與影片混合貼文視為影片貼文。
- **AI 來源決定費率。** 您自行提供的媒體（自有照片、影片或 Wink 內容庫）以標準費率計費。由我們生成的媒體則以 AI 費率計費。

### 什麼會計量，什麼不會

- 只有**發布到第三方社群網路（Facebook、Instagram）的生成貼文**會計費。您自行撰寫的貼文無論發布到哪裡皆免費。
- **發布到 WinkLinks 永遠免費**，無論是否生成。
- 計費於**發布時**產生，不是每次嘗試。反覆生成草稿直到滿意不會增加費用 — 您只付一次實際發布的貼文費用。嘗試次數有限制：圖片貼文約可重生成 10 次，影片貼文約 3 次，反映我們的製作成本。系統會顯示剩餘次數。
- 合作夥伴 API 中，**飯店-天**指一間飯店一晚住宿的價格 — *非* 一次 API 呼叫。一次搜尋回傳 20 間飯店、3 晚住宿即為 60 個飯店-天。查詢與自動完成端點免費且不計量。

### 如何啟用

按使用付費預設關閉。所有人均享有免費額度。

若要超出免費額度，**帳戶擁有者**需啟用按使用付費，並選擇要計量的帳戶。所有啟用帳戶的使用量會合併成**單一月度發票**，您可自動以信用卡付款或自行支付發票。

啟用後，使用量會被計量但**絕不會限速** — 您不會因花費而遭遇速率限制。

:::note[若您不啟用]
不會有任何功能中斷，也不會產生費用。您只會停留在當月免費額度：生成貼文無法發布，合作夥伴 API 呼叫會回傳 `429`，直到額度重置。
:::
