歡迎來到 Wink。無論您是經營飯店、向觀眾推廣旅遊、代表客戶訂房，或是為上述任何一方開發軟體 — 您都來對地方了。

Wink 的誕生是為了讓銷售旅遊庫存再次變得令人興奮，並讓更多人能夠接觸到，而不再只是少數大型業者的專利。這些文件將帶您了解平台的每個部分，從建立第一個帳號到透過深度 API 整合上線。您不需要按順序閱讀；直接前往符合您需求的章節 — 如果您已經知道要找什麼，頁面頂端的 AI 智能搜尋欄會直接帶您到目標。

擁有 Wink 帳號，您可以：

- 建立並管理物業，並在潛在旅客所在的各處銷售。
- 建立並管理聯盟帳號，並從您促成的訂單中賺取佣金。
- 建立並管理旅行社帳號，代表您的客戶進行訂房。
- 取得您的 WinkLinks 專屬網址（*例如 https://i.trvl.as/bob*），並用作您的 `Link-in-Bio URL`。
- 預訂您的下一次假期並享有折扣。
- 作為開發者，透過整合 Wink 完成上述所有操作。

## 關於 Wink

`The Wink Travel Platform` 是一個全新且具突破性的旅遊平台，從零開始設計，旨在賦能飯店、體驗提供者、意見領袖及聯盟行銷者。透過無縫整合創新工具與使用者友善介面，Wink 改變了旅宿產業，使連結、成長與成功變得前所未有的簡單。

您作為企業所做的一切現在都集中在一個地方 — **Portal**。旁邊還有我們的 **訂房引擎**，所有訂單最終都在這裡完成，以及為想要在我們平台上開發的團隊準備的 **開發者工具**。請選擇下方最適合您的章節，從那裡開始。

## 費用說明

Wink 提供的大部分服務都是免費的。刊登及管理您的物業、建立聯盟網絡、使用訂房引擎、發布您的 WinkLinks 頁面、撰寫社群貼文、分析數據 — 這些都不收費，且無訂閱費或設定費。

當訂單完成時，Wink 會收取少量比例作為營運費用。而少數高階功能，如 AI 生成社群貼文、自動回覆、高流量 API 存取等，會以 **按使用量付費** 的方式計費，我們相信您會覺得費率相當合理。每項功能都附有免費月額額度，讓您在付費前先試用。

## 核心概念

> 你看過一個... 就看過全部

當您熟悉 Wink 的所有功能時，會發現許多操作方式相似。了解核心概念能讓您更熟悉並更有信心地使用我們的功能。

以下是重點：

- 每個區塊通常都有列出、添加、更新及刪除項目的功能。
- 編輯項目時，表單欄位旁的紅色星號 <Badge text="*" variant="danger" size="large" /> 表示該欄位為必填。
- 若某欄位資料錯誤，該欄位會出現紅色邊框，並在欄位下方以紅字說明問題。
- 只有當表單有效且有變更時，您才能 `儲存` 表單。
- 有些表單包含多個分頁，例如客房表單。
- 所有分頁都必須有效才能繼續。
- 含有缺失或無效資料的分頁，名稱旁會顯示黃色三角形 <Badge text="⚠️" variant="caution" size="large" />。
- 提交表單時，大多數表單會顯示 `確認` 對話框，詢問您是否要繼續。

## Portal

[Portal](https://app.wink.travel) 是您作為企業所做一切的單一應用程式。無論您擁有何種帳號，這裡都是您的起點：

- **物業** — 刊登您的飯店，管理價格、內容與可用性，並擁有一支聯盟行銷軍團為您銷售。
- **聯盟** — 將您的觀眾變現，並從每筆您帶來的訂單中賺取佣金。
- **旅行社** — 直接從供應商搜尋專屬價格與庫存，並為您的客戶訂房。
- **付款** — 追蹤您的收入並提領資金，由 TripPay 支援。
- **社群** — 讓 AI 幫您維持社群頻道活躍並提升轉換率。
- **連結管理** — 建立並發布您的 WinkLinks 頁面。
- **設定** — 品牌設定、管理者、應用程式、Webhook 及付款設定，依帳號區分。

您可以從單一登入管理多個帳號，企業版即將推出。
