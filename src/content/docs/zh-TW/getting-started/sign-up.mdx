在開始之前，您需要先在 Wink 建立使用者帳號。

<Aside type="note" title="您正在預訂行程嗎？">
本指南適用於想要使用 Wink 旅遊庫存的專業人士——飯店業者、旅行社、聯盟夥伴及其他管理訂房、物業和分銷的合作夥伴。如果您是旅客，則不需要事先建立帳號：您會在預訂結帳流程中建立帳號。
</Aside>

請依照以下步驟操作：

<Steps>
1. 前往 [app.wink.travel](https://app.wink.travel)
2. 點擊右上角的 `登入 / 註冊`
3. 您將看到登入表單，點擊表單欄位下方的 `註冊` 連結。
4. 填寫註冊表單並點擊 `註冊`。系統會將您導向登入頁面。
5. 登入後，您會被導向我們的 [Portal](/zh-TW/portal/create-account)，在那裡您可以建立您的第一個帳號。
</Steps>

建立 Wink 使用者帳號可讓您使用平台上的所有功能。您可以建立無限數量的物業和聯盟帳號。
