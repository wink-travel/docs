Wink 旅遊平台擁有源自需求而生的功能。人們不知道如何：

- 快速開始在線銷售旅遊庫存。
- 輕鬆透過社群媒體或線上銷售設施和體驗。
- 在訂房過程中向旅客進行加購銷售。
- 找到專門針對旅遊且能直接賺取佣金的聯盟網絡。
- 利用聯盟網絡無需額外努力即可跨越數千個銷售渠道銷售；從而降低成本和風險。
- 保留客戶所有權以便重新行銷。
- 利用社交影響力獲利。
- 整合不需冗長 NDA 和長時間等待的旅遊平台。
- 與聯盟合作時正確追蹤投資報酬率。
- …以及更多

隨著時間推移，新增了新功能，擴展了現有功能，也移除了一些功能。如果你在旅遊領域工作，或只是喜歡／需要旅遊，我們有充分理由讓你加入 Wink。繼續閱讀，了解原因。

以下功能構成 Wink 的核心。

## 訂房引擎

Wink 的核心是一個強大、白標且高度可自訂的訂房引擎。它具備你對訂房引擎的所有期待功能，如即時價格、物業資訊、設施、位置等。它支援不同的排名類別，如環保、生活風格和評論。它允許旅客建立詳細的旅客檔案，並分享給飯店，告知他們偏好、過敏資訊、緊急聯絡號碼等。

我們的訂房引擎以美觀的介面讓每個物業和目的地看起來令人驚豔。但真正讓它與眾不同的是能夠向旅客加售任何物品，無論是在物業內或周邊。就像廉價航空鼓勵乘客升級到更寬敞的座位、增加行李額度和餐點一樣，Wink 讓物業清楚知道加售應該是什麼樣子。從房內附加服務、會議室預訂、當地餐廳訂位，到博物館、自然健行和水上樂園… Wink 讓物業有能力讓整個社區因優惠和體驗而活躍起來，讓旅客驚喜連連。

我們的重點是讓旅客體驗更完整的旅遊體驗，並在抵達前以更高價格點連結物業與客人。

## 內容創作

Wink 不僅是訂房平台，更是內容工具。Wink 上的每一項旅遊庫存——一間房、一項水療、一張隔壁餐廳的桌子、一場日出健行——都能轉化成你的受眾能實際消費並採取行動的內容。

選擇任何物業、房型或體驗，製作可分享的連結、卡片、網格、地圖或精選清單，然後放到你的受眾所在之處。網路上最廣泛使用的分享方式是 `連結`，我們的連結附帶動態預覽，顯示即時價格，覆蓋在你選擇的美麗圖片上。內容永不過時：價格、可用性和內容保持即時更新，因此你幾個月前分享的連結今天仍能銷售。

這縮短了從社群動態到確認訂房的路徑——旅客看到值得擁有的東西，價格合理且可用，無需離開動態去搜尋。

## 自動化

製作內容是一回事。*每週持續製作，永遠不間斷* 才是真正讓人崩潰的事。我們遇過幾乎每家飯店都有同樣故事：一開始熱情高漲，發了好幾篇貼文，然後就沉默了——因為負責的人被拉去處理緊急事務、去度假或離職。觀眾比內容更早注意到沉默。

所以我們自動化了。Wink 監控你的即時庫存、價格、促銷、照片和物業內容，並依你設定的排程產生貼文——用你銷售的語言，帶有真實價格和訂房連結。你決定參與程度：每篇貼文都需你核准，或開啟自動核准讓它自動運行。

### 持續改進

每篇貼文都會被衡量——曝光、互動、點擊，最重要的是由此產生的訂房。這些績效數據反饋到下一次產生的內容：哪些房型和體驗要優先推，哪些角度能打動受眾，何時發文，哪種語氣能轉換。持續使用自動化六個月的物業，發佈的內容明顯比第一週更銳利，且沒有人特別坐下來分析。

### 對飯店而言

這改變了銷售與行銷部門的運作方式。自動化給你一個底線——一個一致、符合品牌、永遠最新的存在，不依賴任何人的行事曆。你的行銷團隊不再寫說明文字，而是專注做只有他們能做的事：活動、合作、定位。沒有行銷部門的小型物業，第一次擁有了行銷團隊。

### 對聯盟而言

聯盟使用同一引擎，但目標不同。Wink 自動代表你發佈可賺取佣金的內容——每篇貼文都帶有你的追蹤碼，任何轉換都會付給你，無論你發文時是否在線。你不必每次推廣都手動建立連結，只需設定節奏，讓一連串即時可訂的庫存觸及你的受眾。

自動發佈到 WinkLinks 永遠免費，發佈到其他社群網路則有免費月額配額，超出後按貼文計費——詳見 [價格](/zh-TW/getting-started/pricing)。

## 連結管理器

連結管理器讓你保存並組織喜歡的 URL 以便日後使用。瀏覽器書籤就是一種連結管理器。隨著社群媒體興起，讓連結能被朋友和受眾輕鬆取得的需求更大。你的 Facebook 動態就是一種社群友善的連結管理器。

我們的連結管理工具 WinkLinks 更進一步。

- 它給你一個專屬網址，例如 https://i.trvl.as/bob，適合像 IG 這類只允許分享單一 URL 的平台，並讓你管理來自網路各處的連結。此外，如果網站支援 `豐富內容`，像 Spotify，WinkLinks 會讓播放清單可播放，或讓 Facebook 影片可觀看。
- WinkLinks 讓你免費加入所有現有的聯盟連結，如 CJ 和 Amazon。
- WinkLinks 也是任何人只需兩次點擊就能銷售旅遊庫存的最簡單方式。它是一個精簡版訂房引擎，專注於將你的受眾轉換成訂房。

WinkLinks 高度可自訂，支援你的品牌需求。

## 聯盟網絡

訂房引擎是我們的核心產品，但聯盟網絡讓我們的平台活起來。Wink 讓物業與聯盟互相連結。雙方可協商交易、佣金和折扣。物業不必猜測合作是否合理，能看到聯盟過去的表現及其帶來的旅客族群。即使沒有直接連結，聯盟也能取得一般可用的價格和優惠。

Wink 以多種方式向聯盟提供庫存。我們追蹤每筆訂房的分析、你的投資報酬率，並負責支付所有相關方。你可以專注於你最擅長的事：銷售給你的受眾。

## 物業後台

Wink 的 Extranet 是最先進的內容管理系統，讓物業能在線銷售房型、設施、體驗和各種附加服務。我們設計此系統時，首重易用性，其次是飯店比以往更需要銷售更多。我們在整個使用旅程中運用 AI，協助並加速物業的 `上市時間`。過去需要數週的工作，現在不到一小時即可完成。

我們的 Extranet 是物業自助系統，讓他們能連結聯盟並觸及全球旅客。

## 代理友善

大多數旅遊平台是先為人設計，後來才加上 API。Wink 則相反：**Portal 中你能做的每件事，AI 代理也能做**——超過 500 種工具透過 [Model Context Protocol](/zh-TW/developers/mcp) 暴露，涵蓋整個平台。沒有代理無法觸及的管理區域，也沒有需要人手點擊的任務。

### 物業管理

給代理一份試算表、PMS 匯出或一個照片資料夾，讓它完成上架。它能註冊物業，為每間房、餐廳、水療和活動撰寫描述，設定設施和政策，載入主價和價格方案，開啟銷售渠道並推送可用性——人力需數天完成的工作，代理一鍵無人值守完成。

上線後的所有工作同理。價格和可用性更新、季節性調價、停賣日期、內容更新、聲譽監控和月結報告都能排程自動執行，無需登入。

### 聯盟行銷

代理也能操作商務面：搜尋符合你受眾的庫存，向物業請求並協商佣金，建立可分享的連結、卡片、網格和精選清單，發佈它們，然後讀取轉換分析並重新分配資源到有效的項目。

對於規模經營者——代理商、網絡、大型創作者名單——這是手動管理少數物業與程式化管理數千物業的差異。

### 代你訂房

像 OpenClaw 這樣的 AI 助理能在 Wink 上端到端規劃整趟旅程——理解需求、搜尋全球即時庫存、比較價格、設施和評論，然後完成訂房和付款。無需網站、無需表單、無需人工介入。

**而且 AI 助理沒有品牌忠誠度。** 它不在乎房間掛在哪個網站。它在乎的是這是否是最佳產品、最佳價格、最佳設施，符合使用者需求。不是贊助名額，不是十年的 SEO，不是你的行銷預算大小。

搜尋不再是品牌，而是產品——這獎勵誠實、完整描述你實際銷售的內容。這正是 Wink 為你打造的。

## 付款

訂房過程中可能有多方參與——物業、銷售該訂房的聯盟、旅行社、代表他們的代理商。我們確保每個人都能自動且準時收到款項。

無需佣金報表、無需企業間發票、無需追款。你會收到匯入你自己的銀行帳戶、以你的貨幣支付，無論你身處世界何處。
