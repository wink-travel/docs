訂房引擎是讓庫存可被預訂的地方。飯店會在 [Portal](/zh-TW/portal/overview) 列出他們的庫存，合作夥伴也會在那裡將其轉換成可分享的內容 — 然後訂房引擎會以正確的語言、貨幣和品牌呈現該內容給旅客，並完成訂房。

它以網站形式呈現於 `https://book.wink.travel`，同樣的功能也透過我們的 [Web Components](/zh-TW/integrations/web-components)、[WordPress 外掛](/zh-TW/integrations/wordpress) 和 [API](/zh-TW/api) 提供給整合者使用。

## 一個引擎，多種形態

只有一個訂房引擎，位於 `https://book.wink.travel`。

<LinkButton href="https://book.wink.travel/home" variant="secondary" icon="external" target="_blank">
  開啟訂房引擎
</LinkButton>

它會根據銷售者的身份調整。擁有多家飯店的合作夥伴會有一個用於瀏覽和比較的首頁。單一飯店則有直接進入其庫存的頁面。物業管理公司則會看到他們所代表的 [物業](/zh-TW/portal/settings/agency-representation)。這些都不是獨立網站或獨立產品 — 而是您的 [自訂設定](/zh-TW/portal/settings/branding) 告訴同一個引擎如何呈現自己。

## 旅客能做什麼

### 找到想訂的項目

- **依目的地搜尋。** 查找城市、島嶼、國家或特定的物業、餐廳、水療中心、會議室、活動、景點或地點。
- **瀏覽排名集合。** 探索依會員價格、價格、人氣、生態評分、體驗、優惠、忠誠度或附加服務排序的庫存 — 可全球或限定於某城市、島嶼或國家。
- **篩選結果** 依名稱、半徑、生活風格、星級評等及僅限直接庫存。
- **設定行程** — 入住和退房日期、成人數、兒童及其年齡、同時多間房間，以及促銷代碼。價格表格會即時更新。

詳見 [搜尋](/zh-TW/booking-engine/search)。

### 評估物業

每個物業都有自己的登陸頁面，包含相片庫、本地化描述、地圖、設施、星級評等和旅客評分、我們的 Greendex 生態評分、旅客評論，以及該物業的餐廳、水療、活動、景點、會議室和旅遊公告。

詳見 [物業詳情](/zh-TW/booking-engine/property-detail)。

### 建立住宿並完成訂房

- **選擇房型和價格方案**，明確標示可退款與不可退款選項。
- **查看每個價格方案附帶的優惠** — 包括保證和視供應情況而定的優惠。
- **一次加入多間房間** 並調整數量。
- **加入飯店附加服務和套裝行程**，包含可指定日期和時間的定時附加服務。
- **即時觀看總價更新**，並有每間房價格明細及相較公開價格的節省金額。
- **透過嵌入的安全付款元件結帳付款**。根據物業的付款帳戶支援，提供信用卡、電子錢包和本地付款方式。

詳見 [結帳](/zh-TW/booking-engine/checkout)。

### 事後管理訂房

- **查看訂房確認**，含訂房代碼，立即顯示並透過電子郵件發送。
- **無需登入即可開啟訂房** — 透過電子郵件發送的訂房連結適用於未建立帳戶的旅客。
- **檢視完整訂房資訊**：取消政策、付款狀態、已付款項目及方式、額外費用及物業聯絡資訊。
- **執行操作**：複製訂房代碼、分享訂房、加入行事曆、列印、下載收據、取消並說明原因，或在取消期限外申請退款。
- **入住後撰寫評論**。
- **查看多筆訂房合併的行程**。

詳見 [訂房](/zh-TW/booking-engine/bookings) 和 [訂房確認](/zh-TW/booking-engine/confirmation)。

### 個人化體驗

- **隨時切換語言和貨幣**，超過 40 種語言和 160 種貨幣。
- **透過 Wink 單一登入一次登入**。登入後返回旅客離開的頁面，包含結帳中途。
- **維護旅遊個人檔案** — 地區偏好、緊急聯絡人、過敏、寵物、無障礙需求，以及飯店、房型、餐飲和個人偏好 — 並選擇是否與訂房物業分享。
- **透過連結或 QR 碼分享物業** 至十五個社群和通訊網路。

詳見 [旅遊偏好](/zh-TW/booking-engine/travel-preferences)。

## 旅客如何進入訂房引擎

大多數情況下，無需直接連結到訂房引擎。您在 [Portal](/zh-TW/portal/overview) 建立的所有內容 — 連結、卡片、格子和地圖 — 以及您在 [WinkLinks](/zh-TW/portal/link-manager/wink-links) 發佈的任何內容，都已包含您的客戶 ID、合作夥伴 ID 和品牌，並將旅客導向正確頁面，且行程已預先填入。

| 您分享的內容 | 旅客抵達的位置 |
| --- | --- |
| [可分享連結](/zh-TW/portal/studio/shareable-links) | 短網址 `trvl.as`，展開後為品牌化的物業登陸頁，預先套用您的行程、貨幣和語言。可用於 Facebook、X、WhatsApp 或任何可放網址的地方。 |
| [卡片](/zh-TW/portal/studio/cards) | 單一可訂房的供應商或庫存項目 — 飯店、房型、水療、餐廳。`訂房` 開啟訂房流程；`最佳優惠` 和 `飯店詳情` 導向物業頁面。 |
| [格子](/zh-TW/portal/studio/grids) | 由策劃清單、已保存搜尋或即時排名搜尋建立的分頁卡片集合。每張卡片的訂房方式相同。 |
| [地圖](/zh-TW/portal/studio/maps) | 互動地圖，標記點可開啟可訂房卡片。 |
| [WinkLinks](/zh-TW/portal/link-manager/wink-links) | 您的個人連結頁，包含上述任意組合。從 Instagram 兩步驟完成訂房。 |
| [立即訂房按鈕](/zh-TW/guides/hoteliers/the-book-now-button) | 您自己網站的按鈕，指向自動產生的物業連結，並以日期、房型配置、語言、貨幣和促銷代碼作為 URL 參數。 |
| [Web Components](/zh-TW/integrations/web-components) | 直接在您的頁面嵌入卡片、格子、地圖、搜尋和行程選擇器。訂房可轉至引擎或在模態視窗中開啟，由您選擇。 |
| [WordPress 外掛](/zh-TW/integrations/wordpress) | 同樣的元件以 WordPress 短代碼形式提供，支援 Gutenberg、Elementor、Avada 和 WPBakery。 |
| [API](/zh-TW/api) | 供遠端旅行社系統和渠道管理者直接整合。 |

無論旅客走哪條路徑，送出旅客的合作夥伴都會被記錄以便歸因 — 且此歸因持續 180 天，因此後續訪問所產生的訂房仍會歸功於介紹該旅客的合作夥伴。

## 白標化

訂房引擎設計為隱藏於您的品牌之下。

最輕度的層級是透過 [自訂設定](/zh-TW/portal/settings/branding) 重新設計引擎，使其呈現為您的品牌：您的名稱、標誌、色彩、字體。旅客仍會抵達 `book.wink.travel`。

最深度的層級是 **合作夥伴可以在自己的網域名稱上運行訂房引擎**。將您的網域指向訂房引擎，並自動從主機名稱解析您的自訂設定 — URL 中不含客戶 ID 或設定 ID，地址欄也不會出現 Wink 網域。旅客從搜尋到確認都會看到 `book.yourbrand.com`。

:::note[設定您自己的網域]
自訂網域需由我們協助設定，非自助服務。請 [聯絡我們](/zh-TW/contact) 並提供您想使用的網域，我們將協助配置並連接您的自訂設定。
:::

## 自訂設定

以下所有項目均依自訂設定設定，您可以維持多個自訂設定 — 依市場、活動或物業分別設定。

**識別**

- 顯示名稱和標語附加於頁面標題。
- 標誌，包括訂房電子郵件專用標誌。

**外觀與感受**

- 十一色調色盤：主色、次色、成功、危險、警告、資訊、淺色、深色、正文、淡化和白色。
- 字體，從二十種精選字型中選擇。
- 頁面佈局 — 資訊型或交易型 — 重新塑造首頁、標頭和物業頁面。
- 卡片佈局 — 垂直格子或水平列表。
- 搜尋列、排名徽章和無法預訂物業卡片的切換開關。

在我們的開發者沙盒中試試自訂主題。

<LinkButton href="https://developer.wink.travel/web-component" variant="secondary" icon="external" target="_blank">
  主題設定
</LinkButton>

**旅客預設抵達**

- 預設語言和貨幣。
- 預設行程 — 固定日期或滾動視窗，如「30 天後，2 晚」。
- 預設房型配置和促銷代碼。
- 目的地選擇器的預設城市。

**測量與整合**

- 您自己的 Google Analytics 4 測量 ID、Google Tag Manager 容器和追蹤像素，與 Wink 並行運作。
- 您自己的 Google Maps API 金鑰。
- 控制訂房通知電子郵件是否寄給物業、訂房者和渠道管理者。
- 控制嵌入元件的 `訂房` 按鈕是轉至訂房引擎還是在模態視窗中開啟。

逐欄說明請參閱 [自訂設定](/zh-TW/portal/settings/branding) 和 [自訂您的訂房體驗](/zh-TW/guides/general/customizing-your-booking-experience)。

## 直接連結

如果您想手動連結到訂房引擎，請在 URL 中加入您的客戶 ID 和自訂設定 ID 作為參數。兩者皆可在 [Portal](/zh-TW/portal/overview) 中找到，無論該帳戶是物業、管理公司或合作夥伴。

### 找出您的客戶 ID

<Steps>
1. 從 [帳戶](https://app.wink.travel) 選擇您要操作的帳戶。
2. 點擊帳戶卡片底部的 `操作`，選擇 `管理帳戶`。
3. 在接下來的頁面點擊 `應用程式` 分頁。
4. 複製您要使用的應用程式的客戶 ID，並將其作為請求參數貼到 URL 中。範例：?client-id=MY_CLIENT_ID
</Steps>

更多關於建立和管理應用程式，請參閱 [應用程式](/zh-TW/account/applications)。

### 找出您的自訂設定 ID

<Steps>
1. 從 [帳戶](https://app.wink.travel) 選擇您要操作的帳戶。
2. 點擊帳戶卡片底部的 `操作`，選擇 `管理帳戶`。
3. 在接下來的頁面點擊 `自訂設定` 分頁。
4. 複製您要使用的自訂設定的 ID，並將其作為請求參數貼到 URL 中。範例：?configuration-id=MY_CUSTOMIZATION_ID
</Steps>

完整自訂設定控制項目請參閱 [自訂設定](/zh-TW/portal/settings/branding)。

### 組合起來

連結到首頁的 URL 會像這樣：

https://book.wink.travel?client-id=MY_CLIENT_ID&configuration-id=MY_CUSTOMIZATION_ID

首頁會帶有您的品牌，並顯示您帳戶所代表的庫存 — 您自己的物業、您管理的物業，或您完整的合作夥伴目錄。

若要直接送旅客到特定物業，請連結到該物業的登陸頁：

https://book.wink.travel/hotel/hotel-x?client-id=MY_CLIENT_ID&configuration-id=MY_CUSTOMIZATION_ID

:::note
若省略客戶 ID 或自訂設定 ID，訂房引擎仍會載入，但會回退到預設設定 — 旅客會看到預設品牌，且訂房不會歸功於您。請務必同時包含兩者。
:::
