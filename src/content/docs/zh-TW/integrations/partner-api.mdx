Wink **合作夥伴 API** 是供整合者以較高吞吐量查詢可預訂旅遊庫存的已驗證方式 — 同樣的供應來源驅動我們的可嵌入小工具和公開瀏覽端點，並以一級程式化介面呈現。免費的 Web Components 和公開瀏覽端點適合輕量且面向使用者的嵌入，而合作夥伴 API 則為大規模搜尋、定價和預訂系統打造。存取依整合者驗證，並依使用量計費，因此您只需支付實際傳送的流量費用。

## API 參考

兩個介面提供可預訂庫存，對應上述兩個層級：

- **免費 — 消費者 / 預訂引擎 API**（REST，`/api/public/**`）：匿名，面向瀏覽器與小工具。[瀏覽預訂引擎參考 →](/zh-TW/api/booking-engine/)
- **付費 — 合作夥伴整合者 API**（**gRPC**，`wink.partner.v1`）：已驗證、計量使用量，為大規模伺服器對伺服器整合打造。[瀏覽整合者參考 →](/zh-TW/partner-api/partner/)

合作夥伴整合者 API 採用 gRPC 而非 REST。您可使用產生的客戶端透過 HTTP/2 呼叫
`partner.wink.travel:443`，並傳遞 Bearer Token 及您所呼叫的帳戶：

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

上述參考頁面記錄了所有服務、訊息與錯誤狀態，且架構在執行時可透過伺服器反射取得，因此 `grpcurl`、Postman 和 Insomnia 可自動發現，無需下載任何檔案。

若您想事先產生客戶端，`.proto` 原始檔案已發布於
[github.com/wink-travel/partner-api-proto](https://github.com/wink-travel/partner-api-proto)。

## 使用量與限制說明

### 免費層級

免費層級設計讓您能免費建置、測試並執行適度的生產流量。

- **速率限制 — 每分鐘 30 次請求，突發可達 60 次。** 短暫超過持續速率的峰值由突發配額吸收。若超出，API 將回應 **HTTP 429（請求過多）**，並對您的金鑰施加 **5 分鐘暫停**，暫停期間請勿持續重試，請在暫停結束後再嘗試。
- **每月配額 — 每日曆月 10,000 次請求。** 達到月度上限後，API 將於該月剩餘期間回應 **HTTP 429** — 硬性停止，並附上訊息邀請您升級付費層級繼續使用。計數器於下一個月初重置。

免費層級不包含服務等級協議或優先支援。

### 付費層級

付費層級取消月度上限與速率限制暫停，並僅依實際使用量計費。

- **計量請求 — 每 1,000 次請求 $1.00。** 無月度請求上限，正常使用下無速率限制節流，依實際流量計費。
- **查詢與預訂比率超額 — 每 1,000 次超額查詢 $2.00。** 為維持供應健康，我們會計量搜尋（「查詢」）與確認預訂的比例。您享有 **每筆預訂 5,000 次查詢** 的免費額度。超額查詢計算方式為：

  `excess = max(0, 查詢數 − 預訂數 × 5,000)`

  超額部分將以 **每 1,000 次超額查詢 $2.00** 計費。轉換率良好的整合通常不會產生超額費用；此費用僅適用於搜尋遠多於預訂的流量。

付費層級包含下述服務等級協議 — 99.9% 正常運作承諾及 P95 回應時間目標低於 500 毫秒 — 以及優先且依嚴重性分級的支援。

## 服務等級協議

_生效日期：2026 年 7 月 5 日 · 版本 1.0_

本服務等級協議（以下簡稱「SLA」）訂定 Wink（「Wink」、「我們」）對客戶（「客戶」、「您」）於已標示適用 SLA 層級的已驗證 Wink 合作夥伴 API（「合作夥伴 API」或「服務」）所提供的可用性承諾、服務抵免及支援目標。此 SLA 納入並受您與 Wink 間用於存取合作夥伴 API 的協議（「協議」）約束，且僅於您維持有效且付費的合作夥伴 API 訂閱時適用。未定義之專有名詞，依協議定義為準。

### 1. 定義

1. **「正常運作時間」** 指合作夥伴 API 可接受並成功回應格式正確且已驗證請求的期間。
2. **「停機時間」** 指合作夥伴 API 未能成功回應格式正確且已驗證請求的分鐘數，排除第 4 節所列之排除情況。影響極少數請求的孤立錯誤不視為停機時間。
3. **「月度正常運作百分比」** 指特定日曆月內，該月總分鐘數扣除停機分鐘數後除以該月總分鐘數，並以百分比表示。
4. **「預定維護」** 指 Wink 依第 4 節規定提前通知的計劃性服務維護。
5. **「服務抵免」** 指依受影響日曆月您支付或應付的合作夥伴 API 費用百分比計算的抵免額，作為未達正常運作承諾的唯一且排他性補償，將用於抵扣未來合作夥伴 API 費用。
6. **「回應時間」** 指 Wink 於服務邊界收到格式正確且已驗證請求起，至開始回傳回應的時間，排除網路傳輸及 Wink 無法控制的用戶端時間。

### 2. 可用性與效能承諾

Wink 將以商業合理努力確保合作夥伴 API 在每個日曆月達成 **月度正常運作百分比至少 99.9%**（「正常運作承諾」）。正常運作承諾於 Wink 服務邊界測量，排除第 4 節所述 Wink 合理無法控制之因素。Wink 監控系統為測量月度正常運作百分比與回應時間的權威紀錄來源。

Wink 進一步目標為成功、格式正確且已驗證請求達成 **第 95 百分位（P95）回應時間低於 500 毫秒**（「效能目標」），於每日曆月在 Wink 服務邊界測量。效能目標排除第 4 節所述因素、因請求本身造成的應用層錯誤，以及異常大型或複雜的批次請求。效能目標為服務目標；第 3 節服務抵免僅適用於未達 **正常運作承諾**，且為唯一且排他性補償。

| 低於 99.9% 但不低於 99.0% | 10% |
| 低於 99.0% 但不低於 95.0% | 25% |
| 低於 95.0% | 50% |

1. **申請抵免。** 您必須於停機事件發生的日曆月結束後 **三十（30）天內** 向 Wink 提出書面申請。申請需包含您主張的每次停機日期與時間，以及您合理可取得的任何支援日誌或證據。逾期申請不予受理。
2. **抵免形式。** 核准的服務抵免將用於抵扣未來合作夥伴 API 費用，無現金價值。非退款，除非適用法律另有規定。

4. **唯一且排他性補償。** 服務抵免為您因 Wink 未達正常運作承諾或其他可用性不足所享有的 **唯一且排他性補償**。
