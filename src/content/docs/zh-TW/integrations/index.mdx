Booking Engine 可嵌入任何地方。選擇您的框架或 CMS 並遵循其指南；底層的 Web Components 在各處皆相同。

## 核心方式

- [Web Components](/zh-TW/integrations/web-components/) — 每個整合方案都使用的可嵌入元素。
- [npm package](/zh-TW/integrations/npm/) — 安裝到 JavaScript 建構中。
- [Headless CMS](/zh-TW/integrations/headless/) — 從任何內容後端渲染。
- [Partner API](/zh-TW/integrations/partner-api/) — 完整的程式化整合。
