計費頁面是您啟用隨用隨付、決定適用帳戶範圍，以及監控支出的地方。

您不需要特地來這裡開始使用。每個帳戶在計量功能上都會自動獲得免費的每月額度，完全不需任何操作。此頁面僅用於超出該額度的情況。請參閱[價格](/zh-TW/getting-started/pricing)了解哪些是免費、哪些是計量，以及費用是多少。

## 啟用隨用隨付

開啟隨用隨付並選擇您想要的付款方式：

- **信用卡** — 發票開立時，我們會自動從您儲存的卡片扣款。
- **發票** — 我們會寄送發票給您，您自行付款。

您可以隨時在兩者之間切換。

:::note
只有帳戶的**擁有者**才能啟用該帳戶的隨用隨付。擁有他人帳戶的管理權限並不足夠，因為發票會寄給擁有者 — 我們不會允許其他人使用您的卡片付費。
:::

## 選擇您的帳戶

如果您擁有多個帳戶，可以個別選擇哪些帳戶啟用計量。未啟用的帳戶每月只會使用免費額度。

所有啟用帳戶的使用量會合併成**每月一張發票**，因此您只會收到一張帳單，而非每個物業一張。

## 付款方式

新增信用卡後，我們會安全地將卡片資料儲存在付款服務提供商。系統只會顯示卡片品牌、後四碼和有效期限 — Wink 永遠不會看到或儲存您的完整卡號。若銀行發行替換卡，資料會自動更新。

## 使用量

追蹤本月迄今的使用量，依功能和帳戶分類，並顯示每項的免費額度。若想控制支出，這是您要關注的數字 — 尤其是社群功能，您的每月貼文數即是預算。

額度會在每月 1 號重置。

## 發票

您的發票紀錄會列出每月的編號、計費期間、金額、貨幣和狀態，並附有線上檢視或下載 PDF 的連結。

## 計費狀態

| 狀態 | 意義 |
| -- | -- |
| 良好狀態 | 一切運作正常。 |
| 逾期未付 | 付款嘗試失敗，系統正在重試。重試期間您的功能仍可使用。 |
| 暫停服務 | 發票長期未付。計量功能將被封鎖，直到結清為止 — 免費功能則照常使用。 |
