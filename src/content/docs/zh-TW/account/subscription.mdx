帳單頁面是您啟用隨用隨付、決定適用帳戶，以及監控支出的地方。

您不需要特地來這裡開始使用。每個帳戶在計費功能上都有免費的每月額度，完全不需任何操作。此頁面僅用於超出該額度的情況。請參閱[價格](/zh-TW/getting-started/pricing)了解哪些是免費、哪些是計費項目及其費用。

## 啟用隨用隨付

開啟隨用隨付並選擇您想要的付款方式：

- **信用卡** — 發票開立時，我們會自動從您儲存的信用卡扣款。
- **發票** — 我們會寄送發票給您，您自行付款。

您可以隨時在兩者之間切換。

:::note
只有帳戶的**擁有者**才能啟用該帳戶的隨用隨付。擁有他人帳戶的管理權限並不足夠，因為發票會寄給擁有者 — 我們不會允許其他人使用您的信用卡付費。
:::

## 選擇您的帳戶

如果您擁有多個帳戶，可以個別選擇哪些帳戶啟用計費。未啟用的帳戶每月僅享有免費額度。

所有啟用帳戶的使用量會合併成**每月一張發票**，因此您會收到單一帳單，而非每個物業一張。

## 付款方式

新增信用卡後，我們會安全地將卡片資料儲存在付款服務商。系統只會顯示卡片品牌、末四碼及有效期限 — Wink 永遠不會看到或儲存您的完整卡號。若銀行發行替換卡，資料會自動更新。

## 使用量

追蹤本月迄今的使用量，依功能及帳戶分類，並顯示每項的免費額度。若想控制支出，這是您應該關注的數字 — 尤其是 Social 功能，您的每月貼文數即是預算。

額度會在每月 1 日重置。

## 發票

您的發票紀錄會列出每月的發票號碼、計費期間、金額、貨幣及狀態，並附有線上檢視或下載 PDF 的連結。

## 帳單狀態

| 狀態 | 意義 |
| -- | -- |
| 良好 | 一切運作正常。 |
| 逾期 | 付款嘗試失敗，系統正在重試。重試期間您的功能仍可使用。 |
| 暫停 | 發票未付款至截止日。計費功能將被封鎖，直到付款完成 — 免費功能則照常使用。 |
