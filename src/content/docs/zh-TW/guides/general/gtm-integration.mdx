您可以透過在 Wink 入口網站輸入 **GTM 容器 ID**，將 **任何** Google Tag Manager (GTM) 容器連接到 Wink。連接後，您的容器會自動為您的物業載入，並直接讀取 Wink 的預訂事件 — 涵蓋從搜尋到完成預訂的完整客人旅程。常見的使用案例是用於再行銷和廣告的 **Sojern** 容器，但任何 GTM 容器的運作方式都相同。

<Aside type="tip">
這假設您已擁有 GTM 容器 ID（格式為 `GTM-XXXXXXX`）。如果您的容器來自像 Sojern 這樣的合作夥伴，請向您的客戶經理索取 **GTM 容器 ID** — 它與像素或標籤 ID 不同。第一次使用 Sojern？請造訪 [sojern.com/contact](https://www.sojern.com/contact) 開始使用。
</Aside>

---

## 您需要做的事

<Steps>

1. **取得您的 GTM 容器 ID**

   取得您的 **GTM 容器 ID**（格式為 `GTM-XXXXXXX`）。如果來自像 Sojern 這樣的合作夥伴，請特別索取 GTM 容器 ID — 它與像素或標籤 ID 不同。

2. **在 Wink 入口網站輸入**

   登入 [app.wink.travel](https://app.wink.travel)，選擇您的帳戶，並開啟自訂設定。在 **Analytics & integrations** 區段，將您的 GTM 容器 ID 貼入 **GTM Container ID** 欄位並儲存。您的整合現在已啟用。

3. **與您的供應商確認**

   如果您的容器來自像 Sojern 這樣的合作夥伴，請告知您的客戶經理整合已啟用。他們可以從他們端確認標籤是否在 `wink.travel` 上正確觸發，並且資料是否流入您的帳戶。

</Steps>

<Aside type="note">
此整合不需要您在自己的網站上放置任何像素代碼。Wink 會自動在所有您的物業啟用頁面載入您的 GTM 容器。

此方法適用於 **任何** GTM 容器 ID — Sojern 只是常見範例。
</Aside>

## Wink 端的作法

為了透明度，以下是 Wink 為使此整合運作所做的設定：

- **在自訂設定的 Analytics & integrations 區段** 提供一個 GTM 容器 ID 欄位。當您輸入容器 ID 時，Wink 會驗證格式（`GTM-XXXXXXX`）並安全地將其儲存於您的物業資料中。
- **在 Wink 上您的物業啟用的每個頁面**，您的容器會直接注入頁面 — 與 Wink 自身的 `window.dataLayer` 共享 — 因此它會與 Wink 自身的容器一起載入，無需任何額外設定。這是自動完成的，Wink 團隊無需為每個物業額外作業。
- **您的容器以非同步方式載入**，不會影響客人的頁面載入效能。
- **Wink 自身的追蹤與您的容器並行運作**，兩者共用同一個 `dataLayer`。Wink 追蹤的每個預訂事件同時可供您的容器使用。
- **當您的物業未被瀏覽時** — 例如客人在 Wink 瀏覽其他飯店時 — 您的容器不會被載入，因此只接收與您的物業相關的資料。
- **完成預訂（`purchase`）事件會在感謝頁的瀏覽器端觸發。** GTM 容器 ID 是黑盒子 — Wink 無法假設裡面有什麼標籤 — 因此 Wink 不會從伺服器端代表您呼叫 Google。相反地，容器中任何 GA4 或轉換標籤會在客戶端接收 `purchase` 事件，就像其他預訂事件一樣。因為付款供應商會將客人的瀏覽器導向離開再返回，Wink 會在觸發 `purchase` 前重新連接被導向中斷的分析會話，確保銷售歸因於客人的原始訪問，而非計為新會話。

## DataLayer 參考

Wink 在整個客人旅程中推送 GA4 相容事件到 `dataLayer`。您的 GTM 容器會從同一共享的 `dataLayer` 讀取，因此您配置的任何觸發器或變數都能存取下述所有屬性。

每個事件遵循標準 GA4 強化電子商務結構：頂層的 `event` 字串與 `ecommerce` 物件。每次推送前，Wink 會清除先前的 ecommerce 載荷，以防止舊資料影響新觸發器。

<Aside type="note">
**dataLayer 重置模式**

Wink 在每次事件推送前重置 ecommerce 物件：

```js
dataLayer.push({ ecommerce: null });   // 清除先前事件
dataLayer.push({ event: '...', ecommerce: { ... } });
```

請勿依賴 ecommerce 屬性在事件間持續存在。請在觸發時於同一事件中讀取。
</Aside>

### 預訂旅程事件

這些事件會在客人通過預訂漏斗時自動觸發。請將您的 GTM 觸發器設定為符合下列事件名稱的 **自訂事件** 觸發器。

| 步驟 | 事件 | 觸發時機 |
|------|-------|---------------|
| 1 | `view_item_list` | 飯店庫存格或列表載入 |
| 2 | `view_item` | 客人瀏覽特定物業頁面 |
| 3 | `add_to_cart` | 客人將房型加入購物車 |
| 4 | `begin_checkout` | 結帳／付款頁面載入 |
| 5 | `add_payment_info` | 客人選擇付款方式 |
| 6 | `login` | 客人透過單一登入認證 |
| 7 | `purchase` | 預訂確認 |
| 8 | `refund` | 預訂取消 |

### 物品屬性

所有包含 `items` 陣列的事件共用相同的物品結構。除非標示為必填，否則所有屬性皆為選填。

#### 標準 GA4 欄位

這些欄位為 GA4 原生識別，且在標準電子商務報告中無需額外設定即會顯示。

| 屬性 | 類型 | 必填 | 說明 |
|----------|------|----------|-------------|
| `item_id` | string | 是 | 房型或產品的唯一識別碼 |
| `item_name` | string | — | 房型或產品名稱 |
| `affiliation` | string | — | 聯盟或賣方名稱 |
| `coupon` | string | — | 套用於物品的折扣碼 |

| `creative_slot` | string | — | 推廣創意的版位位置 |
| `discount` | number | — | 套用的折扣金額 |
| `index` | number | — | 列表中的位置（從 1 開始） |
| `item_brand` | string | — | 飯店或品牌名稱 |
| `item_category` | string | — | 產品類型 — 例如 `GUEST_ROOM`、`ACTIVITY`、`ATTRACTION`、`MEETING_ROOM`、`RESTAURANT`、`SPA` |

這些參數攜帶 Wink 特定的預訂上下文。GA4 不會自動在報告中顯示它們 — 您必須先在 GA4 物業中將每個參數註冊為 **物品範圍自訂維度**，它們才會出現在探索或標準報告中。請參閱下方 [GA4 中的自訂維度](#custom-dimensions-in-ga4) 了解設定說明。

| 屬性 | 類型 | 說明 |
|----------|------|-------------|

| `property_name` | string | 物業顯示名稱 |
| `property_brand` | string | 物業所屬品牌 |
| `property_chain` | string | 物業所屬連鎖 |
| `property_url_name` | string | 物業的 URL 友好別名 |
| `city_name` | string | 物業所在城市 |
| `country_code` | string | ISO 3166-1 alpha-2 國家代碼 |
| `start_date` | string | 入住日期，格式為 `YYYY-MM-DD` |
| `end_date` | string | 退房日期，格式為 `YYYY-MM-DD` |
| `num_adults` | number | 預訂中的成人數量 |
| `num_children` | number | 預訂中的兒童數量 |
| `cancellation_policy` | string | 下列之一：`Refundable`、`Non-Refundable`、`Refundable-With-Restrictions`、`Non-Refundable-With-Restrictions` |
| `rate_plan_id` | string | 價格方案識別碼 |
| `room_rate_id` | string | 特定房價識別碼 |
| `room_rate_name` | string | 房價顯示名稱 |
| `num_perks` | number | 價格方案包含的優惠數量 |
| `room_location` | string | 房型位置描述（例如 `Overwater`、`Garden`） |
| `room_view` | string | 房型景觀描述（例如 `Ocean`、`City`） |
| `room_classification` | string | 房型分類或等級（例如 `Suite`、`Standard`） |
| `bed_type` | string | 房型床型配置（例如 `King`、`Twin`） |

### GA4 中的自訂維度

GA4 在報告中會忽略自訂物品參數，除非您明確將它們註冊為物品範圍的自訂維度。您只需註冊打算在報告中使用的參數 — 不必註冊全部 20 個。

<Steps>

1. **開啟自訂定義**

   在 GA4 中，前往 **管理**（左下齒輪圖示）→ 選擇您的物業 → **資料顯示** → **自訂定義**。

2. **建立新的自訂維度**

   點擊 **建立自訂維度**。

3. **填寫維度詳細資料**

   - **維度名稱** — GA4 報告中顯示的人類可讀標籤（請參考下表）
   - **範圍** — 選擇 **物品**
   - **事件參數** — 與 dataLayer 中參數名稱完全相符（請參考下表）
   - **說明** — 選填但建議填寫

4. **儲存並重複**

   點擊 **儲存**，然後對每個想追蹤的參數重複此步驟。

</Steps>

<Aside type="note">
自訂維度註冊後，GA4 報告中可能需要最多 24 小時才會開始顯示。註冊前收集的歷史資料不會回填。

GA4 標準物業最多允許 50 個物品範圍自訂維度（360 物業允許更多）。
</Aside>

建立自訂維度時，請參考下表。**事件參數** 必須完全匹配 — GA4 對大小寫敏感。

| 維度名稱 | 事件參數 | 類型 |
|----------------|-----------------|------|
| 物業 ID | `property_id` | 文字 |
| 物業名稱 | `property_name` | 文字 |
| 物業品牌 | `property_brand` | 文字 |
| 物業連鎖 | `property_chain` | 文字 |
| 物業 URL 名稱 | `property_url_name` | 文字 |
| 城市名稱 | `city_name` | 文字 |
| 國家代碼 | `country_code` | 文字 |
| 入住日期 | `start_date` | 文字 |
| 退房日期 | `end_date` | 文字 |
| 成人數量 | `num_adults` | 數字 |
| 兒童數量 | `num_children` | 數字 |
| 取消政策 | `cancellation_policy` | 文字 |
| 價格方案 ID | `rate_plan_id` | 文字 |
| 房價 ID | `room_rate_id` | 文字 |
| 房價名稱 | `room_rate_name` | 文字 |
| 優惠數量 | `num_perks` | 數字 |
| 房型位置 | `room_location` | 文字 |
| 房型景觀 | `room_view` | 文字 |
| 房型分類 | `room_classification` | 文字 |
| 床型 | `bed_type` | 文字 |

### `virtualPageView`

這是 Wink 的自訂事件 — 不屬於標準 GA4 事件集。它會在每次頁面導航時推送，攜帶裝置與會話上下文。它不包含 `ecommerce` 物件。

```json
{

  "device": "Desktop",
  "deviceAgent": "Mozilla/5.0 ...",
  "os": "MacOS",
  "path": "/hotels/grand-resort",
  "title": "Grand Resort — Wink",
  "userId": "user_abc123",
  "startDate": "2026-06-01",
  "endDate": "2026-06-05",
  "guests": "2",
  "rooms": "1"
}
```

| 屬性 | 說明 |
|----------|-------------|
| `device` | 偵測到的裝置類型 — `Desktop`、`Android`、`iPhone`、`iPad` 或類似 |
| `deviceAgent` | 原始使用者代理字串 |
| `os` | 偵測到的作業系統 — `Windows`、`MacOS`、`Linux`、`UNIX` |
| `path` | 目前頁面路徑 |
| `title` | 目前頁面標題 |
| `userId` | 已認證使用者識別碼（未登入時省略） |
| `startDate` | 目前搜尋會話的入住日期 |
| `endDate` | 目前搜尋會話的退房日期 |
| `guests` | 目前搜尋會話的客人人數 |
| `rooms` | 目前搜尋會話的房間數量 |
