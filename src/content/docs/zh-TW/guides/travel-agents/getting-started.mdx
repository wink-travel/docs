本指南帶領旅行社從註冊到完成第一筆客戶訂房。並說明旅行社在 Wink 上的兩種合作方式，讓您在開始前能選擇最適合的方案。

## 開始前準備

您需要：

- 您的公司資料。
- 您的旅行社註冊號碼，或若有，您的 IATA 代碼。
- 用於收取佣金的銀行帳戶。

## 選擇您的合作方式

| | 標準方案（大多數旅行社） | 代理自行收款 |
|---|---|---|
| 預訂方式 | 在 Wink 入口網站或透過 Partner API | 透過 [Partner API](/zh-TW/integrations/partner-api/)，從您自己的系統 |
| 誰收取客戶付款 | 為飯店收款，飯店為商戶。您在結帳時輸入客戶的卡片。 | 您自行收款，為商戶。 |
| 您的收益 | 每筆訂單的 **10% 預設佣金** | 您與每家飯店協議的佣金 |
| 向 Wink 支付 | 無 | 每筆訂單價值的 **1.5%** 預訂費，按月開立發票，另加超出免費額度的 Partner API 使用費 |
| 付款給飯店 | Wink 代為處理 | 您直接依協議付款給各飯店 |
| 退款、拒付、支付合規 | Wink 代為處理 | 您負責 |
| 審核 | 註冊審核通過後可預訂 | 註冊審核通過，且需 Wink 書面核准此路徑，並有信用額度限制 |

Wink 會審核每家旅行社的註冊資料。大多數旅行社使用標準方案。代理自行收款僅限 **API 合作夥伴**：即透過 Partner API 從自有系統預訂，且已依自身執照收款並直接與飯店簽約的旅行社。

## 第 1 步：註冊您的旅行社

<Steps>
1. 前往 [app.wink.travel](https://app.wink.travel)，點擊 `Sign-In / Register` 並註冊。

2. 點擊左側邊欄的 `Accounts`，再點 `Create`，選擇 **I am a Travel Agent**。

3. 填寫您的旅行社資料。選擇 **Company** 作為實體類型：這會決定您的付款方式。詳見 [Create Account](/zh-TW/portal/create-account/)。

4. 若您打算透過 Partner API 自行收款，請在註冊時選擇此路徑。這是申請，非核准。詳見 [第 6 步](#step-6-collect-payment-yourself-api-partners-only)。

5. Wink 會審核每筆旅行社註冊。我們會寄信至您註冊的電子郵件，要求提供公司資料及旅行社註冊號碼或 IATA 代碼。註冊核准後即可預訂。
</Steps>

## 第 2 步：新增銀行帳戶

前往 `Account > Bank Accounts`，新增您的旅行社帳戶並標記為 **Primary**。佣金將以銀行轉帳方式支付。Wink 透過 Revolut 發放款項，因此 Revolut 商業帳戶是最順暢的選擇，但任何銀行帳戶皆可。詳見 [Bank Accounts](/zh-TW/portal/settings/payouts/)。

## 第 3 步：為客戶尋找飯店

<Steps>
1. 點擊主選單的 `Browse > Hotels`。

2. 依目的地、日期和入住人數搜尋，並篩選出適合客戶的選項。

3. 若與客戶比較多個選項，可將短名單儲存至 [精選清單](/zh-TW/portal/studio/curated-lists/)。
</Steps>

您看到的價格為飯店原價。Wink 不加價，您透過佣金獲利。詳見 [Search](/zh-TW/portal/studio/search/)。

## 第 4 步：為客戶預訂

<Steps>
1. 選擇房型與價格，並輸入客戶姓名及聯絡資料作為旅客。

2. 結帳時輸入客戶提供的卡片。付款由飯店收取，飯店為商戶。

3. 確認訂單。您、旅客及飯店皆會收到確認郵件。訂單代碼以 `WNK` 開頭。
</Steps>

:::caution[妥善保管客戶卡片資訊]
僅為當次訂單索取卡片，並直接輸入結帳頁面。請勿抄寫、以電子郵件傳送或保留於個人紀錄中。
:::

## 第 5 步：管理訂單並收款

- **訂單管理：** 點擊主選單的 `Bookings`，查看所有訂單，可篩選、匯出 CSV、重寄確認信或在飯店取消政策內取消。詳見 [Bookings](/zh-TW/portal/travel-agent/bookings/)。
- **佣金：** 預設為 10%。與飯店長期合作後，可申請 [直接連結](/zh-TW/portal/studio/network/) 並協議不同佣金。
- **付款時間：** 佣金於旅客入住後 24 小時內可用，匯入您的主要銀行帳戶。轉帳手續費照實收取。詳見 [Pricing](/zh-TW/getting-started/pricing/)。

## 第 6 步：自行收款（僅限 API 合作夥伴）

若您在入口網站預訂，或滿意標準方案，請跳過此步驟。

<Steps>
1. 整合 [Partner API](/zh-TW/integrations/partner-api/)。此路徑僅能透過 API，從您自有的訂房系統操作，無法在入口網站使用。

2. 在註冊時選擇此路徑（第 1 步）。

3. Wink 會連同您的註冊資料一併評估，例如財務狀況及法規資格，並以書面確認。核准時會設定 **信用額度**：您可同時持有的未結訂單最高金額。

4. 核准前，您可繼續使用標準方案預訂。
</Steps>

核准後，您自行收取客戶付款並直接付給各飯店。每筆訂單依序扣除 1.5% Wink 費用及您的佣金，剩餘款項付給飯店：

| 以 USD 1,000.00 訂單，10% 佣金為例 | |
|---|---|
| 訂單價值 | USD 1,000.00 |
| 扣除 Wink 費用（訂單價值 1.5%） | USD 15.00 |
| 小計 | USD 985.00 |
| 扣除您的佣金（小計 10%） | USD 98.50 |
| **應付飯店款項** | **USD 886.50** |

Wink 每月以美元開立 1.5% 預訂費發票，15 天內付款，另加超出免費額度的 Partner API 使用費。退款、拒付、支付安全（PCI-DSS）及收款所需的國家執照由您負責。完整條款見 [Travel Agent Agreement](/zh-TW/legal/platform-agreements/)。

## 連接您自己的系統

擁有自有訂房工具的旅行社可透過 [Partner API](/zh-TW/integrations/partner-api/) 搜尋與預訂。旅行社帳戶可直接使用 API 建立訂單，且代理自行收款路徑僅能透過此方式。詳見 [Partner API 參考](/zh-TW/partner-api/partner/)。

## 您的檢查清單

- [ ] 以旅行社帳戶註冊
- [ ] 文件寄出並註冊核准
- [ ] 新增銀行帳戶並標記為主要
- [ ] 為客戶找到第一批飯店
- [ ] 完成第一筆訂單，結帳時輸入卡片
- [ ] 選擇自行收款（API 合作夥伴選項）
