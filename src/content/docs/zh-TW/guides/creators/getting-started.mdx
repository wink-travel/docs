本指南將帶您從註冊到建立第一個可預訂的飯店連結。大約需要 15 分鐘。結束時，您將擁有一個線上店面、第一個可分享的連結，並且了解如何及何時獲得報酬。

## 開始之前

您需要：

- 一個用於註冊的電子郵件地址。
- 您主要社群資料、頻道或部落格的連結。
- 銀行帳戶資料。這可以等到您賺到第一筆佣金後再提供。

## 您如何賺錢

- **每筆您帶來的訂單，預設佣金為 10%**，適用於 Wink Network 上的所有飯店。
- **每次點擊享有六個月的信用期限。** 如果有人今天點擊您的連結，三個月後預訂，該訂單仍屬於您。
- **無需最低追蹤者數量**，也無需申請。Wink Network 上所有活躍飯店從第一天起皆可使用。
- **無需處理客戶服務。** 付款由飯店收取，飯店為商戶並負責照顧客人。您則獲得佣金。

完整說明請參閱 [旅遊創作者如何從飯店訂單賺取佣金](/zh-TW/resources/travel-creator-hotel-commissions/) 及 [價格說明](/zh-TW/pricing/)。

## 第一步：建立您的 Wink 登入帳號

<Steps>
1. 前往 [app.wink.travel](https://app.wink.travel) 並點擊右上角的 `Sign-In / Register`。

2. 點擊登入表單下方的 `Register` 連結，填寫表單後點擊 `Register`。

3. 登入後，您將進入 Portal，準備建立您的帳號。
</Steps>

## 第二步：建立您的創作者帳號

您的登入帳號是您本人。您的 **帳號** 是觀眾和飯店看到的創作者檔案。

<figure>
<CldImage
  src="academy/create_account"
  width="700"
  height="318"
  alt="在 Wink 中選擇帳號類型"
/>
  <figcaption>*選擇您的帳號類型*</figcaption>
</figure>

<Steps>
1. 點擊左側邊欄的 `Accounts`，然後點擊 `Create`。

2. 選擇 **我是聯盟行銷者**。在 Wink，創作者即為聯盟行銷者：您可從您帶來的訂單中賺取佣金。

3. 填寫表單：
   - **名稱**：您的創作者名稱，觀眾認識您的名稱。
   - **實體類型**：`個人`，除非您是透過公司操作。此項決定您的付款方式。
   - **類型**：`影響者`。
   - **描述**：一至兩行關於您發佈內容的介紹，會顯示在您的店面。
   - **網站**：您的主要社群資料，例如 Instagram、TikTok 或 YouTube 的網址。飯店在您直接洽談合作時會查看此處。
   - **城市**：您所在的城市。

4. 接受條款與條件及付款條款，然後點擊 `Save`。
</Steps>

:::tip[您的店面網址]
您的帳號名稱決定您的店面網址：名為 *Queen Bee* 的帳號會有 `i.trvl.as/queen-bee`。您可以稍後編輯網址中的這部分（slug）。slug 採先到先得，請盡早申請。詳見 [申請您的網址](/zh-TW/portal/link-manager/claim-your-url/)。
:::

## 第三步：設定您的店面

您的店面即是您的 **WinkLinks** 頁面，一個連結聚合頁，同時也能銷售飯店。它已存在於您的 `i.trvl.as` 網址。現在讓它成為您的專屬。

  <figcaption>*一個 WinkLinks 店面*</figcaption>

<Steps>
1. 上傳個人頭像並檢查第二步的描述。

2. 新增您已分享的連結：您的頻道、部落格，甚至其他聯盟連結。它們都會集中在同一頁面。詳見 [內容](/zh-TW/portal/link-manager/content/)。

3. 在 `WinkLinks > Design` 中，啟用 **智能**，讓 Instagram、Facebook、YouTube、X 和 Spotify 連結顯示為可播放的貼文，而非純文字連結。選擇版面配置和顏色。詳見 [設定](/zh-TW/portal/link-manager/settings/)。
</Steps>

想看實例？請造訪 [i.trvl.as/starringmay](https://i.trvl.as/starringmay)。

## 第四步：尋找值得推廣的飯店

飯店資料在 **Studio**，即 Portal 的創作者端。無需額外註冊。

<Steps>
1. 點擊主導航列的 `Browse > Hotels`，或從您的儀表板搜尋。

2. 依目的地、日期和價格篩選，直到找到您願意推薦的飯店。

3. 收藏優質飯店：加入 [精選清單](/zh-TW/portal/studio/curated-lists/)（每個帳號預設有 `Favorites`），或 [儲存搜尋](/zh-TW/portal/studio/saved-searches/) 以便日後回訪。
</Steps>

:::tip
推廣您曾入住或願意入住的地方。您的觀眾能分辨真偽，這也是將點擊轉換為訂單的關鍵。想法請參考 [發掘超值優惠](/zh-TW/guides/affiliates/discover-great-deals/)。
:::

<Steps>
1. 在搜尋結果中的飯店上，點擊 `Make a link`。

2. 為連結命名以便識別，新增標題和描述，並選擇分享時顯示的圖片。

3. 選擇主題，讓即時價格顯示在圖片上方。

4. 點擊 `Save`。您會得到一個短連結，如 `trvl.as/3xWCH`，帶有您的信用。
</Steps>

完整功能請參閱 [可分享連結](/zh-TW/portal/studio/shareable-links/)。

### 各種格式的使用場合

| 發佈位置 | 使用 | 原因 |
|---|---|---|
| 限時動態、Reels、TikTok、留言、私訊 | [可分享連結](/zh-TW/portal/studio/shareable-links/) | 一個短連結對應一間飯店，並帶有價格預覽。 |
| 個人簡介連結 | [WinkLinks](/zh-TW/portal/link-manager/wink-links/) | 一個網址涵蓋您所有推薦。 |
| 主題旅遊（如「里斯本五家精品住宿」） | 以 [精選清單](/zh-TW/portal/studio/curated-lists/) 形式呈現，搭配 [格狀](/zh-TW/portal/studio/grids/) 或 [地圖](/zh-TW/portal/studio/maps/) | 讓人們能比較並從同一處預訂。 |
| 您的部落格或網站 | [卡片](/zh-TW/portal/studio/cards/)、[格狀](/zh-TW/portal/studio/grids/) 或 [地圖](/zh-TW/portal/studio/maps/) | 在文章中直接展示可預訂飯店。 |

## 第六步：分享連結

將您的連結放在觀眾常看的地方：個人簡介、限時動態連結貼紙、YouTube 影片說明、置頂留言、電子報和部落格文章。六個月的信用期限意味著，常青影片或文章中的連結能長期帶來收益。

:::note[標示您的合作連結]
多數平台及許多國家要求您標示您從連結中獲利，例如使用 *#ad*、*#affiliate* 或平台的付費合作標籤。請遵守您所在平台及國家的規定，也能建立觀眾信任。
:::

## 第七步：追蹤成效

點擊右上角的個人圖示，然後選擇 `Analytics`，查看點擊和訂單數據。放棄無效的內容，多發有效的。詳見 [分析](/zh-TW/account/analytics/)。

## 第八步：領取報酬

<Steps>
1. **新增銀行帳戶**：前往 `Account > Bank Accounts`，新增帳戶並標記為 **主要帳戶**。自動付款會匯入主要帳戶。詳見 [銀行帳戶](/zh-TW/portal/settings/payouts/)。

2. **佣金在客人入住後 24 小時內可用。** 例如三月訂單入住六月，六月才會付款。

3. **付款以銀行轉帳方式進行。** Wink 透過 Revolut 發放款項，若您有 Revolut 帳戶，建議使用，流程最順暢。其他銀行帳戶也可使用。

4. **轉帳手續費依國家與貨幣而異，按成本收取。** 提款前會顯示費用估算。詳見 [價格說明](/zh-TW/getting-started/pricing/) 及 [提款](/zh-TW/portal/payment/withdraw-funds/)。
</Steps>

:::note
隨著收入增加，我們可能會要求您在提款前驗證身份。這是所有支付平台的標準程序。
:::

## 進階提升

- **直接與飯店合作。** 當您在 Wink 有 5 筆訂單後，可以向飯店申請直接連結，例如為您的觀眾爭取特別優惠或團體價。直接連結可協商不同於預設 10% 的佣金。詳見 [Network](/zh-TW/portal/studio/network/)。
- **更輕鬆地多發內容。** [Social](/zh-TW/portal/social/what-is-social/) 可為您建立並排程飯店貼文。手動貼文永遠免費；AI 生成內容則按使用付費。詳見 [價格說明](/zh-TW/pricing/)。

## 您的檢查清單

- [ ] Wink 登入帳號已建立
- [ ] 創作者帳號已建立，名稱正確
- [ ] 店面已設定：頭像、描述、連結、啟用智能
- [ ] 已將首批飯店加入清單
- [ ] 已製作第一個可預訂連結
- [ ] 連結已分享並標示為合作連結
- [ ] 銀行帳戶已新增並標記為主要帳戶
