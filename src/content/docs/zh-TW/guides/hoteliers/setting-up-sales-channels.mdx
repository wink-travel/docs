銷售通路是您控制庫存分銷的方式。銷售通路定義了誰可以銷售您的房間、他們賺取的佣金以及可用的價格方案。

## 銷售通路類型

在 Wink 上有三種主要的物業分銷方式：

- **Wink Network** — 您的物業對平台上的所有合作夥伴可見。這是最廣泛的分銷方式。
- **直接通路** — 您為特定合作夥伴或代理建立私人通路，並設定自訂的佣金比例。
- **您自己的網站** — 使用可分享連結或嵌入卡片，直接從您的網站銷售，無需中介。

## 建立銷售通路

<Steps>
1. 前往 https://app.wink.travel 並選擇您的物業。
2. 導航至銷售通路區域。
3. 點擊 `建立新的銷售通路`。
4. 為通路命名（例如：「網站直銷」、「合作夥伴 - Kim Travel」）。
5. 設定**佣金百分比** — 合作夥伴每筆訂單可獲得的佣金比例。
6. 選擇此通路可用的**價格方案**。
7. 可選擇限制特定的**房型**或**庫存**。
8. 點擊 `儲存`。
</Steps>

## Wink Network

Wink Network 是預設的分銷通路。啟用後，您的物業會出現在 [Studio](/zh-TW/portal/studio/search)，任何合作夥伴都能找到並銷售您的物業。

啟用方式：

<Steps>
1. 前往您的物業網路設定。
2. 啟用 `Wink Network`。
3. 設定網路合作夥伴的預設佣金比例。
</Steps>

:::tip
Wink Network 是獲得廣泛曝光的最簡單方式。您也可以稍後為表現最佳的合作夥伴建立不同佣金比例的直接通路。
:::

## 直接合作夥伴通路

對於您想密切合作的合作夥伴，建立具有自訂佣金的直接通路。

<Steps>
1. 透過網路區找到該合作夥伴。詳見 [Network](/zh-TW/portal/extranet/network)。
2. 為該合作夥伴建立直接銷售通路。
3. 設定自訂佣金比例（可高於或低於網路預設）。
4. 選擇此通路可用的庫存。
</Steps>

當您想為網紅或旅行社提供優惠價格或專屬房間時，這非常有用。

## 佣金結構

佣金是以扣除 Wink 1.5% 平台費用及實際收取的信用卡手續費後的訂單價值百分比計算，而非毛額。例如，一筆 $100 訂單，信用卡手續費為 4.0%（實際費用依卡別而異，會顯示於每筆訂單），扣除 $1.50 平台費和 $4.00 手續費後，剩餘 $94.50，10% 佣金即為 $9.45。

訂單價值在各方之間分配：

- **合作夥伴佣金** — 銷售者（合作夥伴、旅行社、網紅）所賺取的部分。
- **平台費用** — Wink 對已確認訂單收取的 1.5% 費用。
- **物業收入** — 剩餘部分歸您所有。

您可控制合作夥伴佣金，平台費用則會自動扣除。

## 監控績效

通路啟用後，使用 [Analytics](/zh-TW/account/analytics) 追蹤哪些通路帶來最多訂單和收入。這有助於您優化佣金比例並決定投資哪些合作夥伴關係。
