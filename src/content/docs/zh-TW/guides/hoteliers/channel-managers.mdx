Wink 與領先的頻道管理系統、物業管理系統（PMS）及中央訂房系統（CRS）整合，確保您的價格與可用性在所有銷售渠道中保持同步。

## 運作方式

頻道管理整合使您的物業管理系統與 Wink 之間能雙向傳輸資料：

1. **價格推送** — 您的頻道管理系統將價格更新發送至 Wink。當您在 PMS 中更新價格時，這些變更會自動反映在 Wink 上。
2. **可用性同步** — 您的頻道管理系統將可用性更新發送至 Wink。當房間在 PMS 中被預訂或釋出時，Wink 的庫存會即時更新。
3. **訂單通知** — 當在 Wink 上完成訂單時，您的頻道管理系統會收到通知，讓訂單顯示在您的 PMS 中。

## 支援的頻道管理系統

Wink 目前整合以下系統：

| 頻道管理系統 | 說明 |
|---|---|
| **Channex** | 全球分銷與頻道管理平台。 |
| **TravelClick** | 酒店解決方案與頻道管理（Amadeus）。 |
| **Omnibees** | 酒店分銷與收益管理。 |
| **D-Edge** | 旅宿科技與中央訂房解決方案。 |
| **Allotz** | 庫存分配與頻道管理。 |
| **Ezee / Yanolja** | 以亞洲市場為主的雲端 PMS 與頻道管理。 |
| **RateGain** | 價格情報與分銷技術。 |
| **RateTiger** | 即時價格與可用性分銷。 |
| **CloudBeds** | 雲端 PMS、頻道管理與訂房引擎。 |
| **SiteMinder** | 領先的酒店頻道管理與分銷平台。 |
| **Exely** | 酒店價格與可用性同步。 |

:::note
如果您的頻道管理系統不在列表中，請聯繫 Wink 團隊。可根據 Wink 支援的 OTA（Open Travel Alliance）協議標準新增整合。
:::
