**立即預訂** 按鈕是飯店業界常見的術語，指的是飯店與能掌握物業可用性與價格的供應商整合，讓旅客能直接預訂房間。此按鈕是飯店在自家網站上以自訂條件銷售房間的最簡單方式。

*許多飯店使用其通路管理系統所附帶的預訂引擎。我們建議飯店在決定使用特定預訂引擎前，先做一些研究並比較原生預訂引擎。*

## 目標讀者

本文主要針對想在自家網站安裝我們免費且高轉換率預訂引擎的飯店。
但…對於任何想在網站上使用我們技術的人，也同樣有幫助。

## 透過連結

為了最簡單的整合，我們建議使用[可分享連結](/zh-TW/portal/studio/shareable-links)。

操作步驟如下：

<Steps>
1. 前往 https://app.wink.travel
2. 點擊右上角的 `登入 / 註冊`，使用您的帳號登入。
3. 從左上角下拉選單選擇您要操作的物業。
4. 點擊導覽列中的 `預訂引擎`。
5. 頁面會顯示您的連結。
6. 將此連結提供給您的網站管理員，並用於您的 **立即預訂** 按鈕。
7. 完成 ✅。
</Steps>

:::note
您可以在自家網站使用此連結，且預訂引擎也能在您自己的網域上運行（詳見[預訂引擎功能](/zh-TW/booking-engine/features/)）。Google 免費預訂連結流量則不同：它總是導向 book.wink.travel。詳見[在 Google 上架](/zh-TW/guides/hoteliers/get-listed-on-google/#where-the-guest-lands)。
:::

### 進階

該連結已內嵌來自您所選 `customization` 的行程資訊。
您可以進一步自訂連結：

- 更換所選的 customization 或
- 覆寫行程

本文將著重於後者，因為它讓您更自由地讓旅客在網站上選擇行程，並轉送至 Wink 的預訂引擎。

以下說明如何將自訂行程隨 URL 一起傳遞。

有效的請求參數：

- **sd** 新增起始日期：*sd=2027-03-14*
- **n** 新增住宿晚數：*n=1* 或
- **ed** 使用結束日期：*ed=2027-03-15*
- **rc** 旅客人數：*rc=a2*（成人：2）
- **l** 請求顯示語言：*l=es*
- **c** 請求顯示貨幣：*c=EUR*
- **p** 新增促銷代碼：*p=ABC123*

URL 範例如下：

https://trvl.as/abc123?sd=2027-03-14&n=1&rc=a2&l=es&c=EUR

對於更進階的使用情境，您也可以用 `+` 號請求多組房型配置：

範例：

https://trvl.as/abc123?sd=2027-03-14&n=1&rc=a2-ca16q1-ca8q1+a2&l=es&c=EUR

- 房型 1 = 成人：2，兒童：2（16 歲 + 8 歲）
- 房型 2 = 成人：2

### 範例

**立即預訂** 按鈕 HTML 範例：

*此範例假設您使用 [Bootstrap](https://getbootstrap.com) 作為主要 CSS 函式庫。*

```html
<a
  href="https://trvl.as/abc123"
  target="_blank"
  class="btn btn-lg btn-primary"
  title="Book a room"
>
立即預訂
</a>
```

### 其他優點

使用我們的連結作為您的 `立即預訂` 按鈕還有其他好處：

- **社群友善** 連結易於在社群媒體分享，且會在您選擇的圖片上顯示 `動態價格`。
- **短網址** URL 非常適合分享，您也可以用於 Instagram 個人簡介網址等。

## 透過嵌入

有些飯店希望網站功能更完整，整合更深入。此範例將說明如何將[卡片](/zh-TW/portal/studio/cards)嵌入網站。

操作步驟如下：

<Steps>
1. 前往 https://app.wink.travel
2. 點擊右上角的 `登入 / 註冊`，使用您的帳號登入。
3. 從左上角選擇您要操作的物業。
4. 點擊主導覽列的 `搜尋`。
5. 輸入您的物業名稱並點擊搜尋按鈕。
6. 在搜尋結果卡片上點擊 `操作` 連結，選擇 `建立 > 製作卡片`。
7. 系統會建立一張 `卡片`。
8. 右上角會出現訊息，告知卡片已準備好，並詢問是否要進一步自訂。
9. 點擊主導覽列的 `工具 > 卡片`，即可看到您的新卡片。
10. 在卡片的 `操作` 連結點擊 `嵌入`。
11. 會開啟新視窗，提供可複製的 HTML 範例程式碼。
12. 若要取得您的 `Client-ID`，請前往[應用程式](/zh-TW/account/applications)。
13. 若要取得您的 `Configuration-ID`，請前往[自訂設定](/zh-TW/portal/settings/branding)。
14. 完成 ✅。
</Steps>

嵌入卡片 HTML 範例：

```html
<wink-content-loader
  layout="GUEST_ROOM"
  id="09d7cca4-6ff6-11ef-949b-42004e494300"
></wink-content-loader>
```

*上述 HTML 範例未包含 Wink 所需的 CSS 與 Javascript，僅為卡片本體。*
