Задачи — это место, где Wink отображает подсказки о том, что вы можете улучшить в своем аккаунте — всегда видимый список необязательных, но важных шагов с индикатором выполнения, показывающим ваш прогресс.

В настоящее время доступно для аккаунтов объектов, доступ через `Tasks` в разделе Extranet главного навигационного меню.

## Что отображается

Подсказки сгруппированы по темам и появляются только тогда, когда есть что сделать — после выполнения группы она исчезает из списка:

- **Удобства** — Конференц-залы, рестораны, спа.
- **Район** — Активности, достопримечательности, интересные места.
- **Новости** — Награды, публикации, отзывы третьих лиц.
- **Осведомленность** — Социальные связи, рейтинг Green Index.
- **Дополнительные продажи** — Акции, дополнительные услуги.

Нажмите на любую подсказку, чтобы перейти прямо к форме для её выполнения.
