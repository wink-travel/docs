Создавая [партнёрский аккаунт](/ru/portal/studio/what-is-studio), вы уже получаете персональный URL WinkLinks. Функции издателя WinkLinks доступны в нашем приложении Studio вместе с другими партнёрскими функциями.

### Пример

Если имя вашего аккаунта Queen Bee, ваш персональный URL WinkLinks будет:

<h4 align="center">https://i.trvl.as/queen-bee</h4>

Часть после `i.trvl.as/` называется slug. Изначально это имя вашего аккаунта, которое вы можете изменить позже. Slug выдаются по принципу «кто первый пришёл — того и URL» — получите свой уникальный URL, пока он доступен!
