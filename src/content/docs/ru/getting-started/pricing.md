Wink не требует подписок, не ограничивает количество пользователей и не взимает плату за настройку. Большая часть платформы бесплатна, и есть только две вещи, за которые вы когда-либо будете платить:

1. **Комиссия платформы за бронирование плюс комиссия за обработку карт по себестоимости** — только при совершении бронирования.
2. **Плата по факту использования** — за несколько премиальных функций, которые требуют затрат при каждом запуске, каждая с бесплатным ежемесячным лимитом.

## Что бесплатно

Эти функции не требуют оплаты, навсегда, без лимитов и учёта использования:

- **Бронирование** — на вашем сайте, на странице WinkLinks или в любом другом месте, где вы его встроите.
- **Управление объектами** — контент, фотографии, тарифы, тарифные планы, доступность, акции и правила.
- **Партнёрские инструменты** — ссылки для распространения, кураторские списки, сетки, карты, карточки и виджеты для встраивания.
- **Инструменты для турагентов** — поиск, индивидуальные тарифы и бронирование от имени ваших клиентов.
- **WinkLinks** — зарегистрируйте свой vanity URL, создайте страницу и публикуйте на ней сколько угодно.
- **Ручные публикации в соцсетях** — всё, что вы пишете сами, в любой подключённой сети.
- **Аналитика, таблицы лидеров, заявки, настройки** и управление аккаунтом.
- **API для потребителей и бронирования**, включая их endpoints для поиска и автозаполнения. В **Partner API** вызовы Lookup и Content учитываются по одной единице каждый (см. [Использование](#what-is-and-isnt-metered) ниже).

## Бронирования

Wink поддерживает две модели: Wink собирает оплату для отеля, либо лицензированный турагент выступает как продавец.

### Модель 1 — Wink собирает оплату для отеля

Wink выступает ограниченным агентом по сбору платежей от имени отеля. Отель является продавцом, и его имя отображается в выписке по карте гостя. Эта модель применяется к 95% всех бронирований.

#### Разбивка

:::note[Комиссия платформы]
Wink взимает комиссию платформы в размере 1,5% с каждого бронирования. Это покрывает обслуживание платформы и позволяет нам предоставлять всё перечисленное выше бесплатно. Комиссия не взимается за отменённые бронирования.
:::

:::note[Обработка карт]
Комиссия за обработку платежа, взимаемая для сбора оплаты гостя, передаётся отелю по себестоимости без наценки. Она зависит от карты гостя и способа оплаты, точная сумма отображается в разделе бухгалтерии каждого бронирования. Если бронирование отменяется или возвращается, комиссия процессора, которую он удерживает, всё равно взимается; если комиссия отсутствует, мы тоже не взимаем.
:::

:::note[Выплата средств]
Существуют комиссии за перевод средств на ваш счёт. Они зависят от выбранного вами способа выплаты. В настоящее время мы поддерживаем:

- **Банковский перевод** — стоимость зависит от страны вашего местоположения, страны отправления средств и возможной конвертации валюты. Комиссия за выплату и любые расходы на конвертацию оплачиваются получателем по себестоимости. Мы предоставляем калькулятор расчёта, который можно использовать при наличии доступных средств на счёте.

Если вы хотите, чтобы мы поддержали другой способ выплаты, напишите нам на e-mail.
:::

### Модель 2 — Турагент как продавец

Эта модель доступна только для турагентств с лицензией в их регионе, желающих выступать продавцом. Она доступна только партнёрам API, бронирующим через [Partner API](/ru/integrations/partner-api/), и требует предварительного письменного одобрения Wink. Некоторые наши зарегистрированные турагенты хотят самостоятельно обрабатывать платежи и распределять средства отелям. В этой модели они несут ответственность за средства и имеют необходимые лицензии для работы в своей стране.

#### Разбивка

:::note[Комиссия платформы]
Wink взимает комиссию платформы в размере 1,5% с каждого бронирования. Это покрывает обслуживание платформы и позволяет нам предоставлять всё перечисленное выше бесплатно.
:::

В этой модели турагенты платят Wink комиссию 1,5% плюс любые расходы на использование Partner API сверх бесплатного лимита, выставляемые ежемесячно.

## Что платят партнёры

Для партнёров, которые отправляют бронирования: создатели, аффилиаты, платформы, разработчики и турагенты. Партнёрства не эксклюзивны и не ограничены территориями.

| | Оплата собирается для отеля (большинство партнёров) | Вы — продавец (только партнёры API) |
|---|---|---|
| Лицензионный или территориальный сбор | Нет | Нет |
| Плата за настройку | Нет | Нет |
| Подписка или ежемесячная плата | Нет | Нет |
| Минимальные обязательства или срок | Нет | Нет. Применяется кредитный лимит. |
| Доступ к Partner API | 10 000 ночей в отеле в месяц бесплатно, затем $0.0001 за ночь. Плата по факту использования отключена по умолчанию; при превышении лимита вызовы возвращают `429`. | То же |
| Транзакционная комиссия | Нет. Вы зарабатываете комиссию (по умолчанию 10%). | 1,5% комиссия за бронирование от стоимости, выставляется ежемесячно в USD, оплата в течение 15 дней. При включённой плате по факту использования Partner API выставляется отдельный счёт. |
| Плата за поддержку | Нет | Нет |
| Другие сборы | Комиссии за перевод выплат по себестоимости | Возможна предоплата или депозит при одобрении. Проценты 1,5% в месяц на просроченные счета. |
| Изменение тарифов | Уведомление за 30 дней; применяется только к бронированиям после изменения | То же. Wink может изменять ваш кредитный лимит с уведомлением. |

Маршрут с продавцом требует предварительного письменного одобрения Wink. См. [Модель 2](#model-2--travel-agent-as-merchant-of-record) выше и страницу [Partner API](/ru/integrations/partner-api/).

## Использование (плата по факту)

Некоторые функции требуют затрат при каждом запуске — генеративный ИИ, сторонние социальные API и предоставление актуальных цен в масштабе. Вместо включения их в ежемесячный план, который вы можете не использовать, вы платите только за фактическое потребление и только после использования бесплатного ежемесячного лимита.

| Функция | Бесплатно в месяц | Затем | Единица оплаты |
| -- | -- | -- | -- |
| Публикация в соцсетях — изображение | 1 | $1.50 | Одна опубликованная публикация |
| Публикация в соцсетях — изображение, сгенерированное ИИ | 0 | $2.50 | Одна опубликованная публикация |
| Публикация в соцсетях — видео, улучшенное ИИ | 0 | $4.00 | Одна опубликованная публикация |
| Публикация в соцсетях — видео, сгенерированное ИИ | 0 | $14.00 | Одна опубликованная публикация |
| Ответ ИИ на комментарий или личное сообщение | 5 | $0.05 | Один ответ |
| Ответ чатбота | 5 | $0.05 | Один ответ |
| Partner API | 10 000 | $0.0001 | Одна ночь в отеле |

Цены указаны в USD. Бесплатный лимит предоставляется **на аккаунт**, а не на пользователя, и сбрасывается 1-го числа каждого месяца (UTC).

### Как рассчитывается стоимость публикаций

Стоимость публикаций зависит от их содержимого, так как именно это влияет на наши затраты. Статичное изображение стоит дешево; видео — дороже; всё, что мы генерируем с помощью ИИ, стоит значительно дороже, чем фото, предоставленное вами.

- **Бесплатный лимит покрывает только стандартные публикации с изображениями.** Вы получаете одну такую публикацию на аккаунт в месяц. Видео и медиа, сгенерированные ИИ, оплачиваются с первой публикации — для этих категорий бесплатного лимита нет, поэтому объект, публикующий видео, должен ожидать плату уже в первый месяц.
- **Видео имеет приоритет.** Если публикация содержит хоть одно видео, вся публикация тарифицируется по видео-тарифу. Публикация с изображением и видео считается видео-публикацией.
- **Происхождение ИИ определяет тариф.** Медиа, предоставленные вами — ваши собственные фото и видео или материалы из библиотеки Wink — тарифицируются по стандартной ставке. Медиа, сгенерированные нами для вас, тарифицируются по ставке ИИ.

### Что учитывается и что нет

- Платится только за **сгенерированную** публикацию, опубликованную в сторонней сети (Facebook, Instagram). Публикация, написанная вами самостоятельно, бесплатна, куда бы она ни была опубликована.
- **Публикация в WinkLinks всегда бесплатна**, сгенерированная или нет.
- Оплата взимается **при публикации**, а не за попытки. Повторное создание черновика до удовлетворения не увеличивает счёт — вы платите один раз за опубликованную публикацию. Попытки не бесконечны: для изображений доступно около 10 повторных генераций, для видео — 3, что отражает наши затраты на их создание. Вы увидите, сколько осталось, в процессе работы.
- В Partner API **ночь в отеле** — это одна ночь проживания в одном отеле, *а не* один вызов API. Поиск, возвращающий 20 отелей на 3 ночи, считается 60 ночами отеля за один запрос. Вызовы Content и Lookup (поиск по направлениям и автозаполнение) стоят по одной единице каждый, независимо от результата. Вызовы к аккаунту бесплатны.

### Включение

Плата по факту использования отключена по умолчанию. Все получают бесплатный лимит без дополнительных действий.

Чтобы превысить лимит, **владелец** аккаунта включает плату по факту использования и выбирает, какие из его аккаунтов будут учитываться. Использование всех включённых аккаунтов объединяется в **один ежемесячный счёт**, который можно оплачивать автоматически картой или получать счёт для самостоятельной оплаты.

После включения использование учитывается, но **никогда не ограничивается** — вы не столкнётесь с лимитом скорости при оплате.

:::note[Если вы не включите]
Ничего не сломается и ничего не будет списано. Вы просто остановитесь на бесплатном лимите за этот месяц: сгенерированные публикации не будут опубликованы, а вызовы Partner API будут возвращать `429` до сброса лимита.
:::

### Статус оплаты

| Статус | Что означает |
| -- | -- |
| В хорошем состоянии | Всё работает нормально. |
| Просрочено | Платёж не прошёл, повторная попытка. Функции продолжают работать в этот период. |
| Приостановлено | Счёт не оплачен до конца. Платные действия заблокированы до оплаты; бесплатные функции работают как обычно. |

:::tip[Актуальные цены]
Цены за единицу и бесплатные лимиты всегда отображаются в Портале, напрямую из нашей системы биллинга, чтобы вы могли проверить их перед использованием. См. [Биллинг](/ru/portal/plan) для включения платы по факту, выбора аккаунтов и отслеживания использования и счетов за месяц. См. [Соцсети](/ru/portal/social/what-is-social) для информации о том, как объём публикаций влияет на ваши расходы.
:::

Поскольку комиссия за обработку карт передаётся по себестоимости, любая сэкономленная сумма напрямую идёт отелям.
