На этой странице перечислены все события webhook, на которые вы можете подписаться в Wink. Для инструкций по настройке смотрите [Руководство по интеграции Webhook](/ru/guides/developers/webhook-integration) или [страницу управления Webhook](/ru/portal/settings/webhooks).

## Как подписаться

1. Перейдите в **Приложения > Webhook** в вашем портале.
2. Создайте webhook и выберите события, которые хотите получать.
3. Wink отправляет HTTP POST на ваш endpoint каждый раз, когда происходит событие.

Для полного описания шагов настройки и лучших практик смотрите [Интеграция Webhook](/ru/guides/developers/webhook-integration).
