Инструменты MCP Wink публикуются как **наборы инструментов** — специализированные конечные точки, каждая из которых охватывает одну задачу. Вы подключаете ваш AI-клиент к одной или двум, которые соответствуют вашей работе, а не ко всем сразу.

Каждая конечная точка использует **интерактивный вход OAuth2** (PKCE authorization code flow): ваш AI-агент открывает вкладку браузера, вы входите в систему с учётной записью Wink, и всё. Нет необходимости управлять секретами клиента.

```bash title="Интегратор channel manager подключается к одной конечной точке"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="Отельер, управляющий своими тарифами, подключается к другой"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## Почему инструменты разделены по конечным точкам

Wink предоставляет около 500 инструментов. Передавать все сразу агенту технически возможно — но это плохая идея.

**Определения инструментов занимают контекст.** Каждый инструмент, который сервер MCP рекламирует, загружается в контекстное окно модели перед выполнением работы, вместе с описанием и полной схемой параметров. Пятьсот таких инструментов занимают значительную часть бюджета, необходимого для вашей задачи, при каждом запросе.

**Качество выбора падает с ростом списка.** Агент, выбирающий из 500 инструментов с похожими названиями, делает худший выбор, чем агент, выбирающий из 40. Если вы интегрируете channel manager, примерно двадцать инструментов релевантны для вас; остальные 480 — это шум, который затрудняет поиск нужного инструмента.

**Работа действительно разделима.** Кто-то синхронизирует доступность из PMS, а кто-то курирует страницы партнёрских программ — у них почти нет общих инструментов. Разделение по задачам означает, что каждое подключение содержит словарь одной задачи.

<Aside type="caution" title="Наборы инструментов — это не права доступа">
Выбор узкого набора инструментов **не ограничивает** возможности вашей учётной записи, а выбор широкого не даёт дополнительных прав. Каждый инструмент применяет те же права учётной записи, что и веб-портал, под вашей авторизованной личностью. Если ваша учётная запись не может отменить бронирование в Wink Portal, агент тоже не сможет — независимо от того, к какой конечной точке он подключён.

Выбирайте наборы инструментов для **фокуса**, а не для безопасности.
</Aside>

## Каталог конечных точек

Два хоста обслуживают наборы инструментов. Количество инструментов приблизительное и со временем растёт.

### `https://api.wink.travel` — платформа

| Конечная точка | Инструменты | Что охватывает |
|---|---:|---|
| `/mcp/extranet/facilities` | ~64 | Бронирование и инвентарь на месте: гостевые комнаты и типы комнат, спа, рестораны, конференц-залы, активности, достопримечательности, места, другие продаваемые позиции |
| `/mcp/extranet/property` | ~62 | Запись объекта и его коммерческие условия: профиль и контент, доп. услуги, политики отмены, бонусы, объявления |
| `/mcp/settings` | ~60 | Администрирование учётной записи: профиль управляющей организации и брендинг, менеджеры и их полномочия, кастомизация, вебхуки, настройки уведомлений |
| `/mcp/studio/embeds` | ~48 | Публикация курируемого инвентаря: виджеты, сетки и ранжированные сетки, карточки, карты, глубокие ссылки на инвентарь и страницы поставщиков |
| `/mcp/extranet/rates` | ~44 | Цены и доступность: периоды тарифов и квоты, тарифные планы, основные тарифы, специальные и промо-тарифы |
| `/mcp/extranet/operations` | ~39 | Управление объектом в реальном времени: бронирования и их жизненный цикл, отзывы гостей и ответы, календари, запланированные задачи |
| `/mcp/extranet/distribution` | ~37 | Каналы продаж: каналы продаж и модификаторы тарифов, запросы партнёрских и поставщицких отношений, регистрация, сбор лидов |
| `/mcp/studio/curation` | ~35 | Создание коллекций для мерчандайзинга: статические и динамические списки, ранжированные списки, сохранённые поиски, агрегаты объектов |
| `/mcp/link-manager` | ~28 | Коллекции синдицированных ссылок, их дизайн, категории и теги, а также сокращённые URL |
| `/mcp/reference` | ~24 | Данные только для чтения: страны, валюты и курсы обмена, языки, часовые пояса, геолокация, IP-геолокация |
| `/mcp/analytics` | ~18 | Аналитика бронирований и доходов: обзоры, линейные графики, рейтинги, эффективность партнёров, метрики доли |
| `/mcp/payment` | ~18 | Финансовые операции: бухгалтерская книга, выводы и оценки комиссий, агрегаты средств бронирования |
| `/mcp/booking-engine` | ~17 | Путь покупателя: поиск и просмотр, корзина и оформление заказа, списки желаний, кастомизация кампаний |
| `/mcp/social` | ~17 | Подключённые социальные аккаунты, публикация и планирование постов, чтение аналитики постов |
| `/mcp/travel-agent` | ~8 | Бронирования через агента от имени путешественников и отчёты агентов |

### `https://integrations.wink.travel` — интеграции channel manager

Одна конечная точка, так как этот хост существует для одной задачи.

| Конечная точка | Инструменты | Что охватывает |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | Подключение и проверка интеграции channel manager, PMS или CRS |

<Aside type="note" title="Интеграция channel manager и управление собственными тарифами">
Это разные задачи для разных людей, и они не используют одну конечную точку.

**Поставщик channel manager, PMS или CRS** интегрируется один раз через `integrations.wink.travel/mcp/channel-manager` и с этого момента обменивается данными об объектах, тарифах, доступности и бронированиях через эту интеграцию. Эта единственная конечная точка — вся поверхность взаимодействия.

**Отельер, меняющий свои тарифы вручную**, использует наборы инструментов extranet на `api.wink.travel` — `/mcp/extranet/rates` и другие. Они не входят в интеграцию channel manager, и интегратор не имеет причин подключаться к ним.

Администрирование учётной записи также находится на `api.wink.travel`, по адресу `/mcp/settings`. На хосте интеграций `/mcp/settings` нет.
</Aside>

Каждая конечная точка также содержит инструмент `ping`, чтобы вы могли проверить, что соединение активно, прежде чем отправлять реальные запросы.

## Какие наборы инструментов мне нужны?

| Если вы… | Подключайтесь к |
|---|---|
| **Интегрируете channel manager, PMS или CRS** | `integrations.wink.travel/mcp/channel-manager` — только к этой |
| **Управляете контентом объекта** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **Управляете комнатами и типами комнат** | `/mcp/extranet/facilities` |
| **Управляете ценами и доступностью** | `/mcp/extranet/rates` |
| **Ведёте ежедневные бронирования** | `/mcp/extranet/operations` |
| **Расширяете каналы продаж** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **Создаёте партнёрские страницы** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **Ведёте страницы с ссылками в био** | `/mcp/link-manager` + `/mcp/social` |
| **Бронируете от имени путешественников** | `/mcp/travel-agent` |
| **Ведёте финансовую сверку** | `/mcp/payment` |
| **Создаёте опыт бронирования** | `/mcp/booking-engine` + `/mcp/reference` |

Начните с одного. Добавляйте другой, когда обнаружите, что первый не может выполнить нужную задачу — каждое подключение независимо, и добавление одного не влияет на другие.

<Aside type="tip" title="Хотите всё сразу?">
`https://api.wink.travel/mcp` и `https://integrations.wink.travel/mcp` остаются доступными и предоставляют **все** инструменты на своём хосте. Они полезны для изучения доступных возможностей, но мы не рекомендуем их для повседневной работы: список инструментов слишком большой, что мешает вашей задаче и ухудшает выбор инструментов агентом. Предпочитайте наборы инструментов, перечисленные выше.
</Aside>

## Как работает аутентификация

Серверы MCP Wink используют поток **OAuth2 Authorization Code + PKCE** и поддерживают **Dynamic Client Registration (RFC 7591)**. Вот что происходит при первом подключении:

1. Ваш AI-клиент обнаруживает сервер авторизации из метаданных `/.well-known/oauth-protected-resource` конечной точки MCP.
2. Клиент регистрируется самостоятельно через **Dynamic Client Registration** — ручная настройка приложения не требуется.
3. Клиент открывает **вкладку браузера** на `https://iam.wink.travel`. Вы входите в систему с учётной записью Wink и подтверждаете запрошенные разрешения на экране согласия.
4. Wink выдаёт **токен доступа**, привязанный к вашей учётной записи и идентичности.
5. AI-клиент прикрепляет токен к каждому запросу MCP. Все результаты инструментов автоматически ограничены вашей управляющей организацией.
6. Токены действуют 3 часа. Ваш AI-клиент обновляет их в фоновом режиме без повторного запроса.

Каждый вызов инструмента выполняется **от вашего имени** — те же правила контроля доступа, что и в веб-портале, применяются к AI-агенту.

## Подключите ваш AI-клиент

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Убедитесь, что Claude Code обновлён:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Выберите набор инструментов из [каталога выше](#endpoint-directory) и добавьте его. Например, цены и доступность:
   ```bash
   claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
   ```

3. Claude Code связывается с сервером, обнаруживает сервер авторизации и открывает ваш браузер по умолчанию.

4. **Войдите в Wink** и подтвердите запрос разрешений на экране согласия.

5. Claude Code подтверждает подключение. Введите `/mcp`, чтобы проверить, что сервер появился и инструменты загружены.
</Steps>

Добавляйте столько наборов инструментов, сколько нужно для вашей работы — каждый это отдельная запись сервера с собственным именем:
```bash
claude mcp add wink-operations https://api.wink.travel/mcp/extranet/operations --transport http
claude mcp add wink-analytics  https://api.wink.travel/mcp/analytics           --transport http
```

Вход выполняется один раз. После первого подтверждения в браузере Claude Code повторно использует вашу сессию Wink для дополнительных конечных точек Wink.

:::tip[Поделитесь с командой]
Добавьте `--scope project` к `claude mcp add`, и Claude Code запишет URL сервера в `.mcp.json` в корне репозитория. Зафиксируйте этот файл — каждый член команды получит те же наборы инструментов, и каждый выполнит собственный вход в браузере при первом подключении.
:::

1. Отредактируйте конфигурационный файл Claude Desktop:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`

5. Значок вилки в нижней панели показывает оба сервера как подключённые.
</Steps>

:::

Cline — расширение VS Code с встроенным менеджером серверов MCP. Ручное редактирование JSON не требуется.

<Steps>
1. Установите Cline из Marketplace VS Code:
   - Откройте VS Code и нажмите `Ctrl+Shift+X` / `Cmd+Shift+X`
   - Найдите **Cline** и нажмите **Установить**

## Области доступа

При подтверждении экрана согласия вы увидите разбивку запрашиваемых агентом разрешений. Клиенты MCP используют тот же словарь разрешений, что и остальная платформа — смотрите полный
[справочник областей доступа на странице аутентификации](/ru/developers/authentication#scopes).

Два момента специфичны для MCP:

- **Области `mcp.read`, `mcp.write`, `mcp.remove` дополнительно требуются** для открытия транспорта MCP. Клиент с областью `mcp.*` допускается к любой конечной точке Wink MCP, но каждый вызываемый инструмент всё равно применяет область раздела конечной точки, которую он оборачивает (например, `booking.read`).
- **AI-клиент запрашивает только необходимые области.** Вы можете отказать в отдельных разрешениях на экране согласия — инструменты, требующие отказанной области, вернут ошибку при вызове.

**Наборы инструментов этого не меняют.** Конечная точка, к которой вы подключаетесь, решает, какие инструменты *перечислены*, а не что им *разрешено делать*. Подключение к `/mcp/payment` не даёт финансовых прав, которых у вас не было, а подключение к `/mcp/reference` не мешает инструменту там применять собственную область. Авторизация решается для каждого вызова инструмента на основе вашего токена и прав учётной записи.

## Устранение неполадок

**Вкладка браузера не открывается**

Ваш AI-клиент может ещё не поддерживать интерактивный поток PKCE. Проверьте, что у вас последняя версия:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** обновитесь через встроенный обновлятор приложения

**`401 Unauthorized` после входа**

Ваш кэшированный токен мог устареть. Удалите и добавьте сервер заново, чтобы инициировать новый вход:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

Для Claude Desktop и ChatGPT удалите запись сервера в настройках, перезапустите приложение и добавьте снова.

**`403 Forbidden` при вызове конкретного инструмента**

Инструмент требует область, которую вы не одобрили на экране согласия, или разрешение, которого нет у вашей учётной записи. Переподключите сервер — экран согласия появится снова, и вы сможете одобрить недостающие разрешения. Если ошибка сохраняется, инструмент требует прав учётной записи, которых у вас нет; подключение к другому набору инструментов не поможет, так как наборы не предоставляют права.

**Инструмент, который мне нужен, отсутствует в списке**

Вероятно, вы подключены к набору инструментов, который не охватывает эту задачу. Проверьте [каталог конечных точек](#endpoint-directory) и добавьте нужный набор — подключения независимы, добавление одного не влияет на другие. Если не уверены, где он есть, временно подключитесь к `https://api.wink.travel/mcp`, найдите инструмент и посмотрите, в каком наборе он есть.

**`404 Not Found` на конечной точке набора инструментов**

Проверьте путь внимательно — вложенные наборы имеют два сегмента (`/mcp/extranet/rates`, а не `/mcp/extranet-rates`), а плоские — один (`/mcp/link-manager`). Обратите внимание, что *неавторизованный* запрос к любому пути под `/mcp` возвращает `401`, а не `404`, поэтому один только `401` не говорит, существует ли конечная точка.

**Я подключился к `api.wink.travel/mcp/channel-manager` и ничего не получил**

Такой конечной точки нет. Интеграция channel manager обслуживается только с `https://integrations.wink.travel/mcp/channel-manager`. Если вам также нужно читать или изменять собственные тарифы объекта вручную, это отдельная задача на отдельной конечной точке — смотрите `/mcp/extranet/rates`.

**Сервер отображается, но вызовы инструментов возвращают "account not found"**

Вы вошли в Wink с учётной записью, у которой нет управляющей организации. Перейдите в [Wink Portal](https://app.wink.travel) и убедитесь, что ваша учётная запись настроена перед использованием сервера MCP.

**Токен истекает в середине сессии**

Токены действуют 3 часа. Claude Code и Claude Desktop обновляют токены в фоне без прерывания сессии. Если после длительного простоя появляются ошибки аутентификации, отправьте новое сообщение — клиент автоматически повторно аутентифицируется.

**Codex CLI показывает "MCP server unreachable"**

Проверьте, что ваш `~/.codex/config.json` — валидный JSON (без завершающих запятых) и что `"type": "http"` установлен. Codex требует HTTP-транспорт для удалённых серверов; stdio-транспорт предназначен только для локальных бинарников.

**В меню ChatGPT отсутствует пункт "Connectors"**

Поддержка MCP требует версии настольного приложения ChatGPT **1.2024.352** или выше и активной подписки Plus, Pro, Team или Enterprise. Обновите приложение и проверьте план в Настройках → Учётная запись.

**Сервер Cursor показывает красный / "Failed to connect"**

Проверьте, что ваш `~/.cursor/mcp.json` — валидный JSON и содержит `"type": "http"`. Затем перейдите в **Настройки → Настройки Cursor → MCP** и нажмите **Обновить**. Если ошибка сохраняется, полностью перезапустите Cursor — изменения конфигурации не всегда применяются без перезапуска.

**Серверы MCP Windsurf не отображаются в настройках**

Windsurf требует полного перезапуска (не просто перезагрузки окна) для применения изменений в `mcp_config.json`. Используйте **Файл → Выход** и запустите снова. Если серверы всё ещё не отображаются, убедитесь, что у вас версия Windsurf **1.4+** через **Справка → О Windsurf**.

**В Cline отсутствует опция "Add Server"**

Менеджер серверов MCP требует Cline версии **2.0** или выше. Откройте панель расширений VS Code, найдите Cline и нажмите **Обновить**, если доступно обновление. После обновления перезагрузите VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
