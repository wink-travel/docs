Это руководство проведет туристическое агентство от регистрации до первой брони клиента. Также объясняются два способа работы агентства на Wink, чтобы вы могли выбрать подходящий перед началом.

## Перед началом

Вам понадобятся:

- Данные вашей компании.
- Регистрационный номер туристического агентства или ваш код IATA, если он есть.
- Банковский счет для получения комиссии.

## Выберите способ работы

| | Стандартный (большинство агентств) | Самостоятельный сбор платежей агентом |
|---|---|---|
| Как вы бронируете | В портале Wink или через Partner API | Через [Partner API](/ru/integrations/partner-api/), из вашей собственной системы |
| Кто принимает оплату клиента | Оплата собирается для отеля, который остается торговцем. Вы вводите карту клиента при оформлении. | Вы, как торговец. |
| Ваш заработок | **10% стандартная комиссия** с каждой брони | Комиссия по вашему собственному соглашению с каждым отелем |
| Что вы платите Wink | Ничего | **1,5%** комиссия за бронирование от стоимости брони, выставляется ежемесячно, плюс использование Partner API сверх бесплатного лимита |
| Оплата отелю | Выполняется за вас | Вы платите каждому отелю напрямую по вашему соглашению с ними |
| Возвраты, возвраты платежей, соответствие требованиям оплаты | Выполняется за вас | Ваша ответственность |
| Одобрение | Ваша регистрация проверяется перед бронированием | Ваша регистрация проверяется, плюс письменное одобрение Wink для этого способа с кредитным лимитом |

Wink проверяет регистрацию каждого туристического агентства. Большинство агентств используют стандартный способ. Самостоятельный сбор платежей предназначен только для **API-партнеров**: агентств, которые бронируют через Partner API из своей системы, уже собирают платежи клиентов по своей лицензии и заключают прямые договоры с отелями.

## Шаг 1: Зарегистрируйте агентство

<Steps>
1. Перейдите на [app.wink.travel](https://app.wink.travel), нажмите `Sign-In / Register` и зарегистрируйтесь.

2. В левом боковом меню выберите `Accounts`, затем `Create` и выберите **I am a Travel Agent**.

3. Заполните данные вашего агентства. Выберите тип организации **Company**: это определит, как вы будете получать оплату. Подробнее см. [Create Account](/ru/portal/create-account/).

4. Если вы планируете самостоятельно собирать платежи через Partner API, выберите этот способ при регистрации. Это запрос, а не одобрение. См. [Шаг 6](#step-6-collect-payment-yourself-api-partners-only).

5. Wink проверяет каждую регистрацию туристического агентства. Мы отправляем письмо на ваш зарегистрированный адрес с запросом документов: данные компании и регистрационный номер агентства или код IATA. Вы сможете бронировать после одобрения регистрации.
</Steps>

## Шаг 2: Добавьте банковский счет

Перейдите в `Account > Bank Accounts`, добавьте счет вашего агентства и отметьте его как **Primary**. Комиссия выплачивается туда банковским переводом. Wink отправляет выплаты через Revolut, поэтому бизнес-счет Revolut — самый удобный вариант, но подойдет любой банковский счет. Подробнее см. [Bank Accounts](/ru/portal/settings/payouts/).

## Шаг 3: Найдите отели для клиента

<Steps>
1. В главном меню нажмите `Browse > Hotels`.

2. Выполните поиск по направлению, датам и количеству гостей, отфильтруйте результаты, пока не найдете подходящие варианты для клиента.

3. Сохраняйте короткие списки в [курируемый список](/ru/portal/studio/curated-lists/), если сравниваете варианты с клиентом.
</Steps>

Цены, которые вы видите, — это цены отеля. Wink передает их без изменений, без наценки: ваш заработок — через комиссию. Подробнее см. [Search](/ru/portal/studio/search/).

## Шаг 4: Забронируйте для клиента

<Steps>
1. Выберите номер и тариф, введите имя и контактные данные клиента как путешественника.

2. При оформлении введите карту, которую клиент предоставил для этой брони. Оплата собирается для отеля, который остается торговцем.

3. Подтвердите. Вы, путешественник и отель получите подтверждение по электронной почте. Код брони начинается с `WNK`.
</Steps>

:::caution[Обращайтесь с картой клиента внимательно]
Запрашивайте карту только для текущей брони и вводите ее сразу при оформлении. Не записывайте, не отправляйте по электронной почте и не храните в своих записях.
:::

## Шаг 5: Управляйте бронированиями и получайте оплату

- **Бронирования:** нажмите `Bookings` в главном меню, чтобы увидеть все брони, отфильтровать их, экспортировать в CSV, повторно отправить подтверждение или отменить в рамках политики отмены отеля. Подробнее см. [Bookings](/ru/portal/travel-agent/bookings/).
- **Комиссия:** по умолчанию 10%. Если вы регулярно работаете с отелем, можете запросить у него [прямое подключение](/ru/portal/studio/network/) и согласовать другую комиссию.
- **Когда платят:** комиссия становится доступна в течение 24 часов после заезда гостя и переводится на ваш основной банковский счет. Комиссия за переводы оплачивается по себестоимости. Подробнее см. [Pricing](/ru/getting-started/pricing/).

## Шаг 6: Собирайте оплату самостоятельно (только для API-партнеров)

Пропустите этот шаг, если бронируете в портале или вас устраивает стандартный способ.

<Steps>
1. Интегрируйтесь с [Partner API](/ru/integrations/partner-api/). Этот способ работает только через API из вашей собственной системы бронирования, не в портале.

2. Выберите этот способ при регистрации (Шаг 1).

3. Wink оценивает заявку вместе с регистрационными документами, например, финансовое состояние и статус по регуляциям, и подтверждает письменно. Одобрение включает **кредитный лимит** — максимальную сумму незавершенных бронирований в любой момент.

4. Пока не одобрены, вы можете продолжать бронировать по стандартному способу.
</Steps>

После одобрения вы сами принимаете оплату клиента и платите каждому отелю напрямую. С каждой брони вы вычитаете в порядке: 1,5% комиссию Wink, затем вашу комиссию; остальное идет отелю:

| По брони на 1 000,00 USD с комиссией 10% | |
|---|---|
| Стоимость брони | 1 000,00 USD |
| Минус комиссия Wink (1,5% от стоимости) | 15,00 USD |
| Промежуточный итог | 985,00 USD |
| Минус ваша комиссия (10% от промежуточного итога) | 98,50 USD |
| **Сумма к оплате отелю** | **886,50 USD** |

Wink выставляет счет за 1,5% комиссию ежемесячно в USD, оплата в течение 15 дней, плюс любые расходы на Partner API сверх бесплатного лимита. Вы отвечаете за возвраты, возвраты платежей, безопасность платежей (PCI-DSS) и любые лицензии, требуемые в вашей стране для сбора платежей. Полные условия в [Travel Agent Agreement](/ru/legal/platform-agreements/).

## Подключите свои системы

Агентства с собственными инструментами бронирования могут искать и бронировать через [Partner API](/ru/integrations/partner-api/). Аккаунты туристических агентств могут создавать брони напрямую через API, и это единственный способ работать по самостоятельному сбору платежей. Подробнее см. [Partner API reference](/ru/partner-api/partner/).
