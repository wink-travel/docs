Кнопка **ЗАБРОНИРОВАТЬ СЕЙЧАС** — это повсеместный термин в гостиничной индустрии, который обозначает собственную интеграцию отеля с провайдером, знающим о доступности и ценах объекта размещения и позволяющим путешественникам забронировать номер. Эта кнопка — самый простой способ для отелей продавать номера на собственном сайте и на своих условиях.

*Многие отели используют встроенный движок бронирования, предлагаемый их канал-менеджером. Мы рекомендуем отелям провести исследование и сравнить нативные движки бронирования перед выбором конкретного решения.*

## Аудитория

Эта статья предназначена в первую очередь для отелей, которые хотят установить наш бесплатный, с высокой конверсией, движок бронирования на свой сайт.
Но... она также будет полезна всем, кто хочет использовать наши технологии на своих сайтах.

## через Ссылку

Для самой простой интеграции мы рекомендуем использовать [Shareable Link](/ru/portal/studio/shareable-links).

Вот шаги для этого:

<Steps>
1. Перейдите на https://app.wink.travel
2. Нажмите `Sign-In / Register` в правом верхнем углу и войдите в свой аккаунт.
3. Выберите объект размещения, с которым хотите работать, из выпадающего списка в левом верхнем углу.
4. Нажмите на `Booking engine` в навигационной панели.
5. На странице вы увидите вашу ссылку.
6. Передайте эту ссылку вашему вебмастеру и используйте её для кнопки **ЗАБРОНИРОВАТЬ СЕЙЧАС**.
7. Готово ✅.
</Steps>

:::note
Вы можете использовать эту ссылку на своём сайте, а движок бронирования также может работать на вашем собственном домене (см. [Функции движка бронирования](/ru/booking-engine/features/)). Трафик по бесплатной ссылке бронирования из Google отличается: он всегда ведёт на book.wink.travel. Подробнее см. [Как попасть в Google](/ru/guides/hoteliers/get-listed-on-google/#where-the-guest-lands).
:::

### Расширенные возможности

Ссылка уже содержит маршрут, встроенный в URL, который исходит из выбранной вами `customization`.
Вы можете дополнительно настроить ссылку, изменяя:

- Выбранную кастомизацию ИЛИ
- Переопределяя маршрут

В этой статье мы сосредоточимся на втором варианте, так как он даёт больше свободы, позволяя путешественникам выбирать маршрут на вашем сайте и передавать его в движок бронирования Wink.

Вот как передать свой маршрут вместе с URL.

Допустимые параметры запроса:

- **sd** Добавить дату начала: *sd=2027-03-14*
- **n** Добавить количество ночей: *n=1* ИЛИ
- **ed** Использовать дату окончания: *ed=2027-03-15*
- **rc** Гости: *rc=a2* (Взрослые: 2)
- **l** Запросить язык отображения: *l=es*
- **c** Запросить валюту отображения: *c=EUR*
- **p** Добавить промоакцию: *p=ABC123*

URL будет выглядеть так:

https://trvl.as/abc123?sd=2027-03-14&n=1&rc=a2&l=es&c=EUR

Для более сложных случаев вы также можете запросить несколько конфигураций номеров, используя знак `+`:

Пример:

https://trvl.as/abc123?sd=2027-03-14&n=1&rc=a2-ca16q1-ca8q1+a2&l=es&c=EUR

- Тип номера 1 = Взрослые: 2, Дети: 2 = 16 лет + 8 лет.
- Тип номера 2 = Взрослые: 2.

### Другие преимущества

Есть и другие преимущества использования одной из наших ссылок в качестве кнопки `book now`.

- **Социальная доступность** Ссылку легко делиться в социальных сетях, и она отображает `динамическое ценообразование` поверх выбранного вами изображения.
- **Короткая** URL очень удобно распространять, например, использовать в вашем Instagram Bio URL.

## через Встраивание

Некоторые отели хотят получить больше функционала и более глубокую интеграцию для своего сайта. Этот пример покажет, как встроить [Card](/ru/portal/studio/cards) на их сайт.

Вот шаги для этого:

<Steps>
1. Перейдите на https://app.wink.travel
2. Нажмите `Sign-In / Register` в правом верхнем углу и войдите в свой аккаунт.
3. Выберите объект размещения, с которым хотите работать, в левом верхнем углу.
4. Нажмите на `Search` в главной навигационной панели.
5. Введите название вашего объекта и нажмите кнопку поиска.
6. Нажмите ссылку `Actions` на карточке результата поиска и выберите `Create > Make a Card`.
7. Это создаст `Card`.
8. В правом верхнем углу появится сообщение о готовности карточки и предложении её дальнейшей настройки.
9. Нажмите на `Tools > Cards` в главной навигационной панели, чтобы увидеть вашу новую карточку.
10. Нажмите на ссылку `Actions` на вашей карточке и выберите `Embed`.
11. Откроется новое окно с примером HTML-кода, который вы можете скопировать.
12. Чтобы получить ваш `Client-ID`, перейдите в [Applications](/ru/account/applications).
13. Чтобы получить ваш `Configuration-ID`, перейдите в [Customization](/ru/portal/settings/branding).
14. Готово ✅.
</Steps>

Пример HTML встроенной карточки:

```html
<wink-content-loader
  layout="GUEST_ROOM"
  id="09d7cca4-6ff6-11ef-949b-42004e494300"
></wink-content-loader>
```

*Пример HTML выше не включает необходимые CSS и Javascript Wink; только карточка.*

Пользователь теперь видит динамическое ценообразование, может изменить маршрут и нажать, чтобы забронировать прямо на вашем сайте. Кнопка бронирования ведёт на лендинг вашей собственности в Wink для завершения оплаты.
