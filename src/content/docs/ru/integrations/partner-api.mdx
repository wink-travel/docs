Партнёрский API Wink — это аутентифицированный, высокопроизводительный способ для интеграторов запрашивать бронируемый туристический инвентарь — тот же самый ассортимент, который используется в наших встраиваемых виджетах и публичных эндпоинтах для просмотра, представленный как полноценный программный интерфейс. В то время как бесплатные Web Components и публичные эндпоинты для просмотра предназначены для лёгкого встраивания, ориентированного на пользователя, Партнёрский API создан для систем, которые выполняют поиск, ценообразование и бронирование в большом объёме. Доступ аутентифицируется для каждого интегратора и тарифицируется по использованию, поэтому вы платите только за тот трафик, который действительно отправляете.

## Тарифы и цены

Использование измеряется в **ночах в отеле**: одна ночь проживания в одном отеле — *не* один вызов API. Поиск, возвращающий 20 отелей на 3 ночи, считается 60 ночами в отеле за один запрос. Вызовы Content и Lookup (поиск и автозаполнение по направлениям) — исключение: каждый стоит одну единицу за вызов, независимо от результата. Эндпоинты аккаунта бесплатны. ## Справочник API

Два интерфейса обслуживают бронируемый инвентарь и соответствуют двум вышеуказанным уровням:

- **Бесплатный — Consumer / Booking Engine API** (REST, `/api/public/**`): анонимный, ориентирован на браузер и виджеты. [Просмотреть справочник Booking Engine →](/ru/api/booking-engine/)
- **Платный — Partner Integrator API** (**gRPC**, `wink.partner.v1`): аутентифицированный, с учётом использования, создан для интеграции сервер-сервер в большом объёме. [Просмотреть справочник Integrator →](/ru/partner-api/partner/)

Partner Integrator API использует gRPC, а не REST. Вы вызываете его с помощью сгенерированного клиента по HTTP/2 на
`partner.wink.travel:443`, передавая токен Bearer и аккаунт, для которого выполняется вызов:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

Вышеуказанная страница справочника документирует каждый сервис, сообщение и статус ошибки, а схема также доступна во время выполнения через серверное отражение, поэтому `grpcurl`, Postman и Insomnia обнаруживают её без необходимости скачивания.

Если вы хотите сгенерировать клиента заранее, исходные файлы `.proto` опубликованы на
[github.com/wink-travel/partner-api-proto](https://github.com/wink-travel/partner-api-proto).

## Как работают использование и лимиты

### Бесплатный уровень

Бесплатный уровень предназначен для того, чтобы вы могли создавать, тестировать и запускать умеренный производственный трафик без затрат.

- **Нет опубликованного лимита запросов в минуту.** Wink отслеживает скорость запросов и может применять ограничения справедливого использования для защиты сервиса. Если вы получаете **HTTP 429 (Слишком много запросов)**, подождите количество секунд, указанное в заголовке `Retry-After`, прежде чем повторить попытку.
- **Месячный лимит — 10,000 единиц в календарный месяц.** Лимит предоставляется на аккаунт и сбрасывается 1-го числа каждого месяца (UTC). После достижения лимита аккаунт, не подключённый к оплате по факту, получает **HTTP 429 до 1-го числа следующего месяца** — жёсткая блокировка с заголовком `Retry-After` и сообщением с приглашением перейти на платный уровень. Аккаунт с подключённой оплатой продолжает работать и оплачивает использование сверх лимита.

Бесплатный уровень не включает Соглашение об уровне обслуживания и приоритетную поддержку.

### Платный уровень

Платный уровень снимает месячный потолок и выставляет счёт только за фактическое использование.

- **Оплата за ночи в отеле — $0.0001 за ночь.** Нет месячного потолка; вы оплачиваете фактический объём. Wink может применять ограничения справедливого использования для защиты сервиса. Вызовы поиска и инвентаря тарифицируются за каждую ночь в отеле; вызовы Content и Lookup — по одной единице за вызов, поэтому группировка запросов помогает снизить счёт.

Платный уровень включает Соглашение об уровне обслуживания, описанное ниже — обязательство 99.9% времени безотказной работы и целевое время отклика P95 менее 500 мс — а также приоритетную поддержку с учётом степени серьёзности.

## Соглашение об уровне обслуживания

_Дата вступления в силу: 5 июля 2026 · Версия 1.0_

Это Соглашение об уровне обслуживания (далее «SLA») устанавливает обязательства по доступности, сервисные кредиты и цели поддержки, которые Wink («Wink», «мы», «нас») предоставляет клиенту («Клиент», «вы») для аутентифицированного Партнёрского API Wink (далее «Партнёрский API» или «Сервис») на уровнях, для которых указано применение SLA. Это SLA включено в и регулируется соглашением между вами и Wink, в рамках которого вы получаете доступ к Партнёрскому API (далее «Соглашение»), и действует до тех пор, пока у вас есть активная, оплаченная подписка на Партнёрский API в хорошем статусе. Термины с заглавной буквы, не определённые здесь, имеют значения, указанные в Соглашении.

### 1. Определения

1. **«Время безотказной работы»** означает периоды, в течение которых Партнёрский API доступен для приёма и успешного ответа на корректно сформированные, аутентифицированные запросы.
2. **«Время простоя»** означает любой период, измеряемый в минутах, в течение которого Партнёрский API не отвечает успешно на корректно сформированные, аутентифицированные запросы, за исключением периодов, указанных в разделе 4. Изолированные ошибки, затрагивающие незначительную часть запросов, сами по себе не считаются временем простоя.
3. **«Процент времени безотказной работы за месяц»** означает для данного календарного месяца общее количество минут в этом месяце минус общее количество минут времени простоя, делённое на общее количество минут в месяце, выраженное в процентах.
4. **«Плановое обслуживание»** означает запланированное обслуживание Сервиса, о котором Wink заранее уведомил в соответствии с разделом 4.
5. **«Сервисный кредит»** означает кредит, рассчитанный как процент от платы, уплаченной или подлежащей уплате вами за Партнёрский API в затронутом календарном месяце, который применяется к будущим платежам за Партнёрский API как единственное и исключительное средство возмещения за несоблюдение обязательств по времени безотказной работы.
6. **«Время отклика»** означает время, прошедшее с момента получения Wink корректно сформированного, аутентифицированного запроса на границе сервиса Wink до момента начала возврата ответа, исключая время сетевой передачи и любое время на стороне клиента вне контроля Wink.

### 2. Обязательства по доступности и производительности

Wink приложит коммерчески разумные усилия, чтобы обеспечить доступность Партнёрского API с **процентом времени безотказной работы за месяц не менее 99.9%** в течение каждого календарного месяца срока действия (далее «Обязательство по времени безотказной работы»). Обязательство измеряется на границе сервиса Wink и исключает факторы вне разумного контроля Wink, включая описанные в разделе 4. Системы мониторинга Wink являются авторитетным источником для измерения процента времени безотказной работы и времени отклика.

Wink также ставит цель обеспечить **95-й перцентиль (P95) времени отклика менее 500 миллисекунд** для успешных, корректно сформированных, аутентифицированных запросов, измеряемого на границе сервиса Wink за каждый календарный месяц (далее «Цель производительности»). Цель производительности исключает факторы, описанные в разделе 4, запросы, возвращающие ошибки на уровне приложения, вызванные самим запросом, и необычно большие или сложные пакетные запросы. Цель производительности является сервисной задачей; сервисные кредиты из раздела 3 применяются к несоблюдению **Обязательства по времени безотказной работы** и являются единственным и исключительным средством возмещения за недостатки доступности.

### 3. Сервисные кредиты

Если процент времени безотказной работы за месяц опускается ниже Обязательства в любом календарном месяце, вы можете претендовать на Сервисный кредит, рассчитанный как процент от платы за Партнёрский API, уплаченной или подлежащей уплате вами за этот месяц, согласно следующей шкале:

| Процент времени безотказной работы за месяц | Сервисный кредит |
|---|---|
| Ниже 99.9%, но не ниже 99.0% | 10% |
| Ниже 99.0%, но не ниже 95.0% | 25% |
| Ниже 95.0% | 50% |

1. **Запрос кредита.** Чтобы получить Сервисный кредит, вы должны подать письменный запрос в Wink в течение **тридцати (30) дней** после окончания календарного месяца, в котором произошёл сбой. Запрос должен содержать даты и время каждого инцидента времени простоя, на который вы претендуете, а также любые доступные вам подтверждающие логи или доказательства. Запросы, поданные после этого срока, не рассматриваются.
2. **Форма кредита.** Одобренные Сервисные кредиты применяются к будущим платежам за Партнёрский API и не имеют денежной стоимости. Они не являются возвратом средств и не выплачиваются наличными, за исключением случаев, предусмотренных применимым законодательством.
3. **Максимальный кредит.** Общая сумма Сервисных кредитов за любой календарный месяц не превысит 50% платы за Партнёрский API, уплаченной или подлежащей уплате вами за этот месяц.
4. **Единственное и исключительное средство.** Сервисные кредиты являются вашим **единственным и исключительным средством** возмещения за любое несоблюдение Wink Обязательства по времени безотказной работы или иные недостатки доступности Партнёрского API.

### 5. Поддержка и цели по времени отклика

Wink предоставляет поддержку Партнёрского API в стандартные рабочие часы, за исключением местных государственных праздников. Wink приложит коммерчески разумные усилия, чтобы подтвердить получение корректно поданных запросов в поддержку в следующие целевые сроки отклика, в зависимости от присвоенной вами степени серьёзности и её разумного подтверждения Wink:

| Степень серьёзности | Описание | Целевое время первого ответа |
|---|---|---|
| **Sev 1 — Критическая** | Партнёрский API недоступен или неработоспособен в продакшене без обходных путей. | 4 часа |
| **Sev 2 — Значительная** | Значительное ухудшение или нарушение функции; существует обходной путь. | 1 рабочий день |
| **Sev 3 — Незначительная** | Общие вопросы, мелкие проблемы или запросы на функции. | 2 рабочих дня |

Целевые сроки отклика описывают, когда Wink стремится установить **первичный контакт**; они не гарантируют время решения. Приоритетная поддержка и цели по степени серьёзности применяются на уровнях, где они включены.
