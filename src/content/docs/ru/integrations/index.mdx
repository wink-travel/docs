Booking Engine можно встроить куда угодно. Выберите ваш фреймворк или CMS и следуйте его руководству; базовые Web Components везде одинаковы.

## Основные подходы

- [Web Components](/ru/integrations/web-components/) — встраиваемые элементы, используемые во всех интеграциях.
- [npm package](/ru/integrations/npm/) — установка в JavaScript-сборку.
- [Headless CMS](/ru/integrations/headless/) — рендеринг из любого контент-бэкенда.
- [Partner API](/ru/integrations/partner-api/) — полная программная интеграция.
