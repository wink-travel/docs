Booking Engine se može ugrađivati bilo gde. Izaberite svoj framework ili CMS i pratite njegov vodič; osnovni Web Components su isti svuda.

## Osnovni pristupi

- [Web Components](/sr/integrations/web-components/) — ugrađivi elementi koje koristi svaka integracija.
- [npm paket](/sr/integrations/npm/) — instalirajte u JavaScript build.
- [Headless CMS](/sr/integrations/headless/) — renderovanje sa bilo kog content backend-a.
- [Partner API](/sr/integrations/partner-api/) — potpuna programska integracija.
