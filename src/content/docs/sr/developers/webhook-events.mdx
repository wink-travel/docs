Ova stranica prikazuje sve webhook događaje na koje se možete pretplatiti na Wink-u. Za uputstva o podešavanju, pogledajte [Webhook Integration Guide](/sr/developers/webhook-integration) ili [Webhooks management page](/sr/portal/settings/webhooks).

## Kako se pretplatiti

1. Idite na **Applications > Webhooks** u vašem portalu.
2. Kreirajte webhook i izaberite događaje koje želite da primate.
3. Wink šalje HTTP POST na vaš endpoint svaki put kada se dogodi događaj.

Za kompletne korake podešavanja i najbolje prakse, pogledajte [Webhook Integration](/sr/developers/webhook-integration).

## Događaji upravljanja entitetima

Događaji za upravljanje entitetima (objekti, partneri, kompanije) i njihovu administraciju.

### Životni ciklus

| Događaj | Ključ | Opis |
|---|---|---|
| Entitet kreiran | `managing_entity.created` | Novi entitet za upravljanje je kreiran. |
| Entitet obrisan | `managing_entity.deleted` | Entitet za upravljanje je obrisan. |
| Status ažuriran | `managing_entity.status.updated` | Status entiteta je promenjen. |
| Na pregledu | `account.under_review` | Nalog entiteta je na pregledu. |

### Pretplata

| Događaj | Ključ | Opis |
|---|---|---|
| Pretplata obezbeđena | `managing_entity.subscription.provisioned` | Nova pretplata je obezbeđena. |
| Pretplata promenjena | `managing_entity.subscription.changed` | Plan pretplate je promenjen. |
| Faktura pretplate promenjena | `managing_entity.subscription.invoice.changed` | Faktura pretplate je ažurirana. |

### Životni ciklus menadžera

| Događaj | Ključ | Opis |
|---|---|---|
| Menadžer dodat | `managing_entity.manager.added` | Novi menadžer je dodat. |
| Menadžer pozvan | `managing_entity.manager.invited` | Pozivnica za menadžera je poslata. |
| Menadžer uklonjen | `managing_entity.manager.removed` | Menadžer je uklonjen. |
| Menadžer prihvatio | `managing_entity.manager.accepted` | Pozivnica menadžera je prihvaćena. |
| Menadžer odbio | `managing_entity.manager.rejected` | Pozivnica menadžera je odbijena. |
| Vlasnik postavljen | `managing_entity.manager.owner.set` | Vlasništvo entiteta je preneto. |
| Menadžeri ažurirani | `account.managers.update` | Lista menadžera je promenjena. |

### Informacije o entitetu

| Događaj | Ključ | Opis |
|---|---|---|
| Informacije ažurirane | `managing_entity.information.updated` | Informacije o entitetu su ažurirane. |
| Adresa ažurirana | `managing_entity.city.updated` | Adresa/grad entiteta je promenjen. |
| Ime ažurirano | `managing_entity.name.updated` | Ime entiteta je promenjeno. |
| URL ime ažurirano | `managing_entity.url_name.updated` | Vanity URL entiteta je promenjen. |
| Jedinstveni ID ažuriran | `managing_entity.unique_id.updated` | Jedinstveni identifikator entiteta je promenjen. |
| Ažuriran nadređeni entitet | `managing_entity.managed_by.updated` | Odnos entiteta sa nadređenim je promenjen. |
| Place ID ažuriran | `managing_entity.place_id.updated` | Google Place ID entiteta je promenjen. |
| Predstavnik naloga ažuriran | `managing_entity.account_representative.updated` | Predstavnik naloga je promenjen. |
| Profilna slika ažurirana | `managing_entity.profile_picture.updated` | Profilna slika entiteta je ažurirana. |
| Logo ažuriran | `managing_entity.logo.updated` | Logo entiteta je ažuriran. |
| Detalji ažurirani | `account.details.updated` | Polja detalja naloga su promenjena. |
| Agent ažuriran | `managing_entity.agent.updated` | Agent entiteta je izmenjen. |

### Obaveštenja

| Događaj | Ključ | Opis |
|---|---|---|
| Email obaveštenje agentu | `managing_entity.agent.email.notification` | Email obaveštenje je poslato agentu. |
| Email obaveštenje menadžeru | `managing_entity.manager.email.notification` | Email obaveštenje je poslato menadžeru. |

### Zadaci naloga

| Događaj | Ključ | Opis |
|---|---|---|
| Zadatak kreiran | `account.task.create` | Novi zadatak je dodat nalogu. |
| Zadatak ažuriran | `account.task.update` | Zadatak naloga je izmenjen. |
| Zadatak uklonjen | `account.task.remove` | Zadatak naloga je uklonjen. |
| Zadatak završen | `account.task.complete` | Zadatak naloga je završen. |
| Zadatak verifikacije poreskog ID-a završen | `account.task.tax_id.complete` | Zadatak verifikacije poreskog ID-a je završen. |

## Događaji rezervacija

Događaji za životni ciklus rezervacije na Wink-u, od kreiranja do refundacija i isplata.

### Osnovna rezervacija

|---|---|---|

| Inicijalizacija zatražena | `booking.initialize.request` | Zatražena je inicijalizacija rezervacije. |
| Inicijalizacija završena | `booking.initialize.complete` | Inicijalizacija rezervacije je završena. |

| Potpuna refundacija | `booking.refund.full` | Izdata je potpuna refundacija. |

### Isplate

|---|---|---|

### Recenzije

| Događaj | Ključ | Opis |
|---|---|---|
| Recenzija poslata | `booking.review.created` | Gost je poslao recenziju za rezervaciju. |
| Odgovor na recenziju | `booking.review.responded` | Objekat je odgovorio na recenziju rezervacije. |
