אפליקציות מעניקות לך גישה לכל התכונות של Wink כמפתח. תוכל לגשת לכל אותם נתונים ואפילו להרחיב את התכונות של Wink.
אתה יכול לבחור להשתמש בשרת OAuth2 של Wink כדי לאמת את אתר הנסיעות שלך באותו אופן שבו היית משתמש בגוגל או בפייסבוק.
כך תוכל להרחיב את תכונות Wink לאתר או לאפליקציה שלך.

:::note
האפליקציה הראשונה שלך כבר נוצרה כאשר [יצרת חשבון חדש](/he/portal/create-account). אנו משתמשים באפליקציה זו בכמה תרחישי הזמנה.

אין באפשרותך להשתמש שוב באפליקציה זו. אנא צור אפליקציות חדשות לפי הצורך.
:::

## יצירת אפליקציה

מכיוון שאינך יכול לגשת ל`secret key` של האפליקציה שיצרנו עבורך, תצטרך ליצור אחת משלך.
ניתן ליצור אפליקציה כאן מבלי להגדיר קודם נכס או חברה — היא אינה קשורה
לחשבון ספציפי כלשהו.

### סוגי לקוחות

בעת יצירת אפליקציה, בוחרים סוג לקוח שקובע כיצד האפליקציה מאמתת את עצמה.
לא ניתן לשנות זאת מאוחר יותר — אם אתה צריך סוג אחר, צור אפליקציה חדשה.

- **אפליקציית ווב** — אפליקציה שמופעלת בשרת ויכולה לשמור סוד לקוח בבטחה (authorization code flow).
- **אפליקציית דף יחיד (SPA)** — אפליקציה בדפדפן ללא backend; משתמשת ב-PKCE, ללא סוד לקוח.
- **אפליקציית מובייל** — אפליקציה מקומית ל-iOS/Android; משתמשת ב-PKCE עם טוקני רענון מסתובבים.
- **מכונה למכונה** — שירות backend הפועל כעצמו (client credentials); ללא התחברות משתמש.

הנה השלבים ליצירת אפליקציה:

<Steps>
1. בדף האפליקציות, לחץ על כפתור `Create new application`.
2. ***שם*** תן שם לאפליקציה שלך. *למשל Cool App*
3. **סוג לקוח** בחר את הסוג שמתאים לאופן האימות של האפליקציה — ראה [סוגי לקוחות](#client-types) למעלה.
4. **Redirect URIs** נדרש לפחות URI הפניה אחד. הוא משמש לאימות דומיין ההפניה לאחר אימות מוצלח. לא בשימוש באפליקציות מכונה למכונה. *למשל https://www.cool-site.com*
5. **Post-logout redirect URIs** *(אופציונלי)* כתובות URL שאליהן המשתמשים יופנו לאחר התנתקות. השאר ריק כדי להשתמש שוב ב-redirect URIs שלמעלה.
6. **Scopes** בחר מה האפליקציה הזו יכולה לגשת בשמך — ראה [בחירת scopes](#choosing-scopes) למטה.
7. לחץ על כפתור `Create application` כדי להמשיך.
</Steps>

אתה מנותב חזרה לרשימת האפליקציות שלך, ותיבת דו-שיח חד-פעמית מציגה את ה-Client ID
וה-Client secret החדשים. העתק את הסוד עכשיו ושמור אותו במקום בטוח — הוא לעולם לא יוצג שוב,
ואין דרך לשחזר אותו מאוחר יותר (רק [לסובב](#rotate-credentials) אותו לחדש).

## בחירת scopes

כל אפליקציה תמיד נושאת את ה-scopes של **Sign-in (OpenID Connect)** (`openid`, `profile`,
`email`, `offline_access`) — אלה מאשרים את זהות המשתמש ושומרים אותו מחובר, ולכן הם
מסומנים ומנעולים; הם אינם בחירה.

כל השאר הוא אופציונלי. ה-scopes הנותרים מקובצים לאותם חלקים פונקציונליים
שמתועדים ב-[Scopes](/he/developers/authentication#scopes) — חשבון, מלאי ותעריפים, הזמנות,
שיווק וקידומים, תוכן נכס, אנליטיקה ודוחות, אינטגרציות מנהל ערוצים,
תשלומים, וחשבונאות וספרים — כל אחד עם תיאור בשפה פשוטה של מה שהוא מפעיל. השתמש
בקישורי `All` / `None` מעל הרשימה כדי לבחור או לנקות כל scope אופציונלי בבת אחת.

:::note
**תשלומים** ו**חשבונאות וספרים** מסומנים כ**רגישים** כי הם מגנים על תנועות כספים — הענק אותם רק לאפליקציות שזקוקות במפורש לגשת לתשלומים או לספרים.
:::

שתי משפחות scopes אינן מוצעות בכוונה בטופס זה:

- **`mcp.*`** — גישה של סוכן AI ל[Model Context Protocol](/he/developers/mcp), שמסופק בנפרד ורק ללקוחות מכונה למכונה.
- **Scopes ברמת מנהל** (`administrator.*`) — גישה ברמת הפלטפורמה שאינה ניתנת לאפליקציה ספציפית.

לאחר יצירת אפליקציה, גם לשונית זו וגם [אפליקציות עם הסכמה](/he/account/apps) מציגות את ה-scopes שהוענקו לה
מקובצים לפי חלק (למשל "הזמנות: `booking.read`"), כך שתוכל לראות במהירות מה האפליקציה יכולה לעשות
מבלי לפתוח אותה.

## סיבוב אישורים

אם סוד הלקוח עלול היה להיחשף, או אם אתה רוצה אישורים חדשים, סובב אותם במקום
ליצור אפליקציה חדשה:

<Steps>
1. מצא את האפליקציה ברשימת האפליקציות שלך ולחץ על `Rotate`.
2. אשר את תיבת הדו-שיח — ה-Client ID והסוד הנוכחיים מפסיקים לעבוד מיד.
3. העתק את ה-Client ID והסוד החדשים מתיבת הדו-שיח החד-פעמית לפני סגירתה.
</Steps>

סיבוב שומר על שם האפליקציה, סוג הלקוח, ה-redirect URIs וה-scopes — רק האישורים משתנים.

## הסרת אפליקציה

:::caution
אנא אל תמחק את האפליקציה שיצרנו אוטומטית עבורך כדי לוודא שכל התכונות פועלות בחשבונך.
:::

אם אין לך צורך נוסף באפליקציה, תוכל להסיר אותה. זהו צעד קבוע — האישורים מבוטלים מיד ואינם ניתנים לשחזור.

<Steps>
1. מצא את האפליקציה ברשימת האפליקציות שלך ולחץ על `Delete`.
2. אשר את תיבת הדו-שיח כדי למחוק את האפליקציה לצמיתות.
</Steps>
