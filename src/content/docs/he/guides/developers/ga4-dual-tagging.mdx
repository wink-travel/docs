על ידי חיבור נכס Google Analytics 4 שלך ל-Wink, אירועי ההזמנה שלך — מצפיות בחדרים ועד להזמנות שהושלמו — מועברים אוטומטית ללוח הבקרה של GA4 שלך לצד האנליטיקה של Wink. ללא קוד, ללא הגדרות טכניות מצדך.

<Aside type="tip">
אתה צריך שני דברים מ-GA4: **Measurement ID** ו-**Measurement Protocol API secret**. ה-Measurement ID מפעיל את משפך הגלישה בדפדפן האורח; ה-API secret מאפשר ל-Wink לרשום הזמנות שהושלמו (`purchase`) **בצד השרת**, כך שמכירה לא תאבד כאשר האורח מנותב אל ומחברת ספק התשלום.
</Aside>

---

## איך זה עובד

```
אתה מזין את ה-Measurement ID (G-XXXXXXXXXX) ואת ה-API secret בפורטל של Wink
       ↓
אירועי גלישה (צפיות, עגלה, תשלום) זורמים לנכס GA4 שלך מהדפדפן
הזמנות שהושלמו (purchase) נשלחות בצד השרת — שורדות את ניתוב התשלום
       ↓
אתה נכנס ל-analytics.google.com ורואה את משפך ההזמנות המלא שלך
```

---

## מה עליך לעשות

<Steps>

1. **צור נכס GA4**

   עבור אל [analytics.google.com](https://analytics.google.com): מנהל → צור נכס. הגדר את אזור הזמן והמטבע שלך כך שיתאימו לשוק שלך.

2. **צור זרם נתונים לאינטרנט**

   מנהל → זרמי נתונים → הוסף זרם → אינטרנט. הזן `wink.travel` ככתובת URL. זה יוצר את **Measurement ID** שלך (`G-XXXXXXXXXX`). העתק אותו.

3. **צור Measurement Protocol API Secret**

   פתח את אותו זרם נתונים לאינטרנט → גלול אל **Measurement Protocol API secrets** → **צור**. תן לו כינוי (למשל "Wink") והעתק את **ערך הסוד** שנוצר. סוד זה מאפשר ל-Wink לרשום הזמנות שהושלמו בצד השרת, כך שמכירה לא תאבד במהלך ניתוב התשלום.

4. **הזן את ה-Measurement ID וה-API Secret בפורטל של Wink**

   היכנס ל-[app.wink.travel](https://app.wink.travel), בחר את החשבון שלך ועבור ללשונית **התאמות אישיות**. הדבק את ה-Measurement ID ואת ה-API secret בשדות **GA4** ושמור. זהו — האינטגרציה של GA4 שלך פעילה כעת.

   <Aside type="note">
   ה-API secret הוא **לכתיבה בלבד**: לאחר שמירתו הוא לעולם לא יוצג שוב. בעריכות עתידיות, השאר את שדה הסוד ריק כדי לשמור על הערך שכבר שמרת.
   </Aside>

5. **סמן את `purchase` כאירוע מפתח**

   חזור לנכס GA4 שלך: מנהל → אירועים → מצא את `purchase` → הפעל **סמן כאירוע מפתח**. זה גורם להזמנות שהושלמו להופיע בדוח ההמרות שלך.

6. **צפה בנתונים שלך**

   היכנס ל-[analytics.google.com](https://analytics.google.com) ותראה את ההזמנות, ההכנסות ומשפך האורחים שלך — הכל מתועד אוטומטית דרך Wink.

</Steps>

<Aside type="note">
אין צורך להתקין קוד מעקב באתר שלך עבור אינטגרציה זו. Wink מטפל בכל. ה-Measurement ID שלך הוא היעד שאליו נשלחים נתוני ההזמנות, וה-API secret מאפשר ל-Wink לאשר הזמנות שהושלמו בצד השרת.
</Aside>

<Aside type="tip">
**ניתן להשתמש ב-GA4 ו-GTM יחד.** אם אתה מפעיל גם מכולת Google Tag Manager (למשל מכולת Sojern), תוכל להגדיר את שניהם בו זמנית — הם כבר לא בלעדיים זה לזה. ראה [אינטגרציית GTM Analytics](/he/guides/developers/gtm-dual-tagging).
</Aside>

## מה ניתן לעקוב

לאחר החיבור, נכס GA4 שלך מקבל את כל אירועי Enhanced E-commerce עבור הנכס שלך:

### גילוי

| אירוע | משמעותו |
|---|---|
| `view_item_list` | אורח ראה את הנכס שלך בחיפוש או ברשימת קטגוריה |
| `select_item` | אורח לחץ על הנכס שלך מתוך רשימה |
| `view_item` | אורח צפה בדף הפרטים של המלון שלך |

### שקילה

| אירוע | משמעותו |
|---|---|
| `view_promotion` | אורח ראה הצעת קידום לנכס שלך |
| `select_promotion` | אורח לחץ על הצעת קידום |
| `add_to_wishlist` | אורח שמר את הנכס שלך ברשימת המשאלות שלו |

### משפך ההזמנה

| אירוע | משמעותו |
|---|---|
| `add_to_cart` | אורח בחר חדר או חבילה |
| `view_cart` | אורח צפה בסיכום ההזמנה שלו |
| `remove_from_cart` | אורח הסיר חדר או חבילה |
| `begin_checkout` | אורח התחיל את תהליך התשלום |
| `add_payment_info` | אורח הזין את פרטי התשלום שלו |
| `add_shipping_info` | אורח הזין את פרטי האורח שלו |
| `purchase` | אורח השלים הזמנה |
| `refund` | הזמנה בוטלה והוחזרו כספים |

כל האירועים כוללים ממדים רלוונטיים כגון הכנסות, מטבע, סוג חדר, וערך ההזמנה — ומספקים תמונה מלאה של מסלול האורח מהרושם הראשון ועד להזמנה שהושלמה. כדי לפתוח ממדים נוספים ברמת הנכס והחדר כגון `city_name`, `cancellation_policy`, `bed_type` ועוד, ראה [ממדים מותאמים אישית ב-GA4](/he/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4).

## מעקב בין-דומיינים (מתקדם)

האינטגרציה הסטנדרטית שלמעלה עוקבת אחרי כל מה שקורה בתוך Wink. עם זאת, אם ברצונך לעקוב אחר אורחים מהאתר שלך ועד להשלמת ההזמנה ב-Wink — ולייחס נכון את מקור התנועה המקורי (Google Ads, קמפיינים בדוא"ל, חיפוש אורגני וכו') — נדרש שלב נוסף בכל צד.

<Aside type="caution">
סעיף זה חל רק אם התקנת GA4 באתר שלך. אם אינך מפעיל GA4 באתר, האינטגרציה הסטנדרטית שלמעלה מספיקה.
</Aside>

### למה זה חשוב

ללא מעקב בין-דומיינים, אורח שמבקר באתר שלך תחילה ואז מזמין ב-Wink יופיע ב-GA4 שלך כישיבה **ישירה** ללא קשר לביקור הקודם שלו. כל לחיצות Google Ads, קמפיינים בדוא"ל או ביקורי חיפוש אורגני שהובילו להזמנה לא יקבלו קרדיט.

עם מעקב בין-דומיינים מוגדר, תראה את מסלול האורח המלא:

```
google.com (פרסומת בתשלום)
       ↓
האתר שלך (האורח גולש בחדרים)
       ↓
wink.travel (האורח בוחר חדר ומבצע הזמנה)
       ↓
purchase מיוחס נכון ללחיצת Google Ads המקורית
```

### פעולה נדרשת: אתה

הגדר את נכס GA4 שלך כך שיזהה את `wink.travel` כחלק מהדומיין שלך, לא כהפניה חיצונית. זה אומר ל-GA4 לתפור את שתי הישיבות יחד למסלול אורח רציף אחד.

<Steps>
1. מנהל GA4 → זרמי נתונים → הזרם שלך
2. הגדרות תג → **הגדר את הדומיינים שלך**
3. הוסף את `wink.travel` כדומיין מקושר
4. שמור
</Steps>

### פעולה נדרשת: Wink

צור קשר עם [תמיכת Wink](https://app.wink.travel) וספק את דומיין האתר שלך (למשל `yourhotel.com`). Wink תוסיף את הדומיין שלך לרשימת החריגים להפניות בנכס GA4 של Wink. זה מונע מהרשומות באתר שלך להירשם כמקור הפניה, מה שהיה משנה את ייחוס האורח ומתחיל ישיבה חדשה.

<Aside type="tip">
האינטגרציה הסטנדרטית שלמעלה מספיקה לרוב הנכסים ומספקת לך נראות מיידית להזמנות והכנסות ב-Wink. מעקב בין-דומיינים הוא אפשרות מתקדמת שכדאי להגדיר כאשר אתה מרגיש בנוח עם נתוני GA4 שלך ורוצה תובנות ייחוס עמוקות יותר.
</Aside>
