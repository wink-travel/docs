מדריך זה מלווה סוכנות נסיעות מהרישום ועד ההזמנה הראשונה ללקוח. הוא גם מסביר את שתי הדרכים בהן סוכנות יכולה לפעול ב-Wink, כדי שתוכל לבחור את המתאימה לך לפני שתתחיל.

## לפני שמתחילים

תזדקק ל:

- פרטי החברה שלך.
- מספר רישום סוכנות הנסיעות שלך, או קוד IATA אם יש לך.
- חשבון בנק עבור העמלה שלך.

## בחר כיצד תעבוד

| | סטנדרטי (רוב הסוכנויות) | תשלום שנאסף על ידי הסוכן |
|---|---|---|
| כיצד אתה מזמין | בפורטל Wink, או דרך ה-Partner API | דרך [Partner API](/he/integrations/partner-api/), מהמערכת שלך |
| מי מקבל את תשלום הלקוח | נאסף עבור המלון, שהוא נשאר הסוחר הרשום. אתה מזין את כרטיס הלקוח בעת התשלום. | אתה, כסוחר הרשום. |
| מה אתה מרוויח | **עמלה ברירת מחדל של 10%** על כל הזמנה | העמלה בהסכם שלך עם כל מלון |
| מה אתה משלם ל-Wink | כלום | **1.5%** דמי הזמנה על ערך כל הזמנה, מחויבים חודשית, בנוסף לשימוש ב-Partner API מעל המנוי החינמי |
| תשלום למלון | מטופל עבורך | אתה משלם לכל מלון ישירות, תחת ההסכם שלך איתם |
| החזרים, ביטולים, תאימות לתשלום | מטופל עבורך | באחריותך |
| אישור | הרישום שלך נבדק לפני שתוכל להזמין | הרישום שלך נבדק, בנוסף לאישור בכתב מ-Wink לדרך זו, עם מגבלת אשראי |

Wink בודקת כל רישום סוכנות נסיעות. רוב הסוכנויות משתמשות בדרך הסטנדרטית. תשלום שנאסף על ידי הסוכן מיועד ל**שותפי API בלבד**: סוכנויות שמזמינות דרך Partner API מהמערכת שלהם, כבר אוספות תשלומים תחת הרישיון והחוזה שלהם ומתקשרות ישירות עם המלונות.

## שלב 1: רישום הסוכנות שלך

<Steps>
1. עבור ל-[app.wink.travel](https://app.wink.travel), לחץ על `Sign-In / Register` והרשם.

2. לחץ על `Accounts` בסרגל הצד השמאלי, ואז על `Create`, ובחר **I am a Travel Agent**.

3. מלא את פרטי הסוכנות שלך. בחר **Company** כסוג הישות: זה קובע כיצד תקבל תשלום. ראה [Create Account](/he/portal/create-account/).

4. אם תאסוף תשלום בעצמך דרך Partner API, בחר בדרך זו במהלך הרישום. זו בקשה, לא אישור. ראה [שלב 6](#step-6-collect-payment-yourself-api-partners-only).

5. Wink בודקת כל רישום סוכנות נסיעות. אנו שולחים דוא"ל לכתובת הרשומה שלך ומבקשים את המסמכים: פרטי החברה ומספר רישום סוכנות הנסיעות או קוד IATA. תוכל להזמין לאחר שהרישום יאושר.
</Steps>

## שלב 2: הוסף את חשבון הבנק שלך

עבור ל-`Account > Bank Accounts`, הוסף את חשבון הסוכנות שלך וסמן אותו כ**ראשי**. העמלה משולמת שם בהעברה בנקאית. Wink שולחת תשלומים דרך Revolut, לכן חשבון עסקי ב-Revolut הוא האופציה החלקה ביותר, אך כל חשבון בנק יעבוד. ראה [Bank Accounts](/he/portal/settings/payouts/).

## שלב 3: מצא מלונות ללקוח שלך

<Steps>
1. לחץ על `Browse > Hotels` בסרגל הניווט הראשי.

2. חפש לפי יעד, תאריכים ותפוסה, וסנן עד שתמצא את האפשרויות המתאימות ללקוח שלך.

3. שמור רשימות קצרות ל[רשימה מובחרת](/he/portal/studio/curated-lists/) אם אתה משווה אפשרויות עם הלקוח.
</Steps>

המחירים שאתה רואה הם של המלון עצמו. Wink מעבירה אותם כפי שהם, ללא תוספת מחיר: אתה מרוויח דרך העמלה. ראה [Search](/he/portal/studio/search/).

## שלב 4: הזמנה עבור הלקוח שלך

<Steps>
1. בחר את החדר והמחיר, והזן את שם הלקוח ופרטי הקשר שלו כנוסע.

2. בעת התשלום, הזן את הכרטיס שהלקוח נתן לך להזמנה זו. התשלום נאסף עבור המלון, והמלון נשאר הסוחר הרשום.

3. אשר. אתה, הנוסע והמלון תקבלו כל אחד דוא"ל אישור. קוד ההזמנה מתחיל ב-`WNK`.
</Steps>

:::caution[טפל בכרטיס הלקוח בזהירות]
בקש את הכרטיס רק להזמנה שאתה מבצע והזן אותו ישירות בתשלום. אל תרשום אותו, תשלח בדוא"ל או תשמור ברשומות שלך.
:::

## שלב 5: נהל הזמנות וקבל תשלום

- **הזמנות:** לחץ על `Bookings` בסרגל הניווט הראשי כדי לראות כל הזמנה, לסנן, לייצא ל-CSV, לשלוח אישור מחדש או לבטל בהתאם למדיניות הביטול של המלון. ראה [Bookings](/he/portal/travel-agent/bookings/).
- **עמלה:** 10% כברירת מחדל. ברגע שתעבוד עם מלון באופן קבוע, תוכל לבקש ממנו [חיבור ישיר](/he/portal/studio/network/) ולהסכים על עמלה שונה.
- **מתי אתה מקבל תשלום:** העמלה זמינה תוך 24 שעות מהצ'ק-אין של האורח, ומועברת לחשבון הבנק הראשי שלך. דמי העברה משולמים בעלות. ראה [Pricing](/he/getting-started/pricing/).

## שלב 6: אסוף תשלום בעצמך (לשותפי API בלבד)

דלג על שלב זה אם אתה מזמין בפורטל, או מרוצה מהדרך הסטנדרטית.

<Steps>
1. שלב עם [Partner API](/he/integrations/partner-api/). דרך זו פועלת רק דרך ה-API, מהמערכת שלך, לא בפורטל.

2. בחר בדרך זו במהלך הרישום (שלב 1).

3. Wink מעריכה זאת לצד מסמכי הרישום שלך, למשל המצב הפיננסי והסטטוס הרגולטורי, ומאשרת בכתב. האישור כולל **מגבלת אשראי**: הסכום המקסימלי שתוכל להחזיק בהזמנות לא סגורות בכל רגע.

4. עד לאישור, תוכל להמשיך להזמין בדרך הסטנדרטית.
</Steps>

לאחר האישור, אתה אוסף את תשלום הלקוח בעצמך ומשלם לכל מלון ישירות. עבור כל הזמנה אתה מנכה, לפי הסדר, את דמי ה-Wink של 1.5% ואז את העמלה שלך; השאר מיועד למלון:

| בהזמנה של 1,000.00 דולר עם עמלה של 10% | |
|---|---|
| ערך ההזמנה | 1,000.00 דולר |
| פחות דמי Wink (1.5% מערך ההזמנה) | 15.00 דולר |
| סך ביניים | 985.00 דולר |
| פחות העמלה שלך (10% מסך הביניים) | 98.50 דולר |
| **מגיע למלון** | **886.50 דולר** |

Wink מחייבת את דמי ההזמנה של 1.5% חודשית, בדולרים, לתשלום תוך 15 יום, בנוסף לכל שימוש ב-Partner API מעל המנוי החינמי. אתה אחראי להחזרים, ביטולים, אבטחת תשלום (PCI-DSS) וכל רישיון שנדרש במדינתך לאיסוף תשלום. התנאים המלאים נמצאים ב-[Travel Agent Agreement](/he/legal/platform-agreements/).

## חבר את המערכות שלך

סוכנויות עם כלי הזמנה משלהן יכולות לחפש ולהזמין דרך [Partner API](/he/integrations/partner-api/). חשבונות סוכנויות נסיעות יכולים ליצור הזמנות ישירות דרכו, והוא הדרך היחידה לעבוד בדרך של תשלום שנאסף על ידי הסוכן. ראה את [Partner API reference](/he/partner-api/partner/).
