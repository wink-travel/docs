ממשק ה-API של Wink **לשותפים** הוא הדרך המאומתת, בעלת קצב העברה גבוה יותר, עבור אינטגרטורים לשאול מלאי נסיעות שניתן להזמין — אותו מלאי שמניע את הווידג'טים הניתנים להטמעה ואת נקודות הגלישה הציבוריות, החשוף כממשק תכנותי ברמה ראשונה. בעוד שה-Web Components החינמיים ונקודות הגלישה הציבוריות מיועדים להטמעה קלה ופונה לאדם, ממשק ה-API לשותפים בנוי למערכות שמחפשות, מחשבות מחירים ומבצעות הזמנות בקנה מידה גדול. הגישה מאומתת לפי אינטגרטור ומחושבת לפי שימוש, כך שתשלמו רק על התעבורה שאתם אכן שולחים.

## תוכניות ותמחור

השימוש נמדד ב**לילות במלון**: מלון אחד במחיר עבור לילה אחד של שהייה — *לא* קריאת API אחת. חיפוש שמחזיר 20 מלונות עבור שהייה של 3 לילות הוא 60 לילות במלון מבקשה אחת. שיחות תוכן וחיפוש (חיפוש יעד והשלמה אוטומטית) הן יוצא מן הכלל: כל אחת עולה יחידה אחת לכל קריאה, לא משנה מה היא מחזירה. נקודות קצה של חשבון הן חינמיות. [התמחור](/he/pricing/) הוא המקור האמין למחיר.

## הפניה ל-API

שני ממשקים משרתים את המלאי הניתן להזמנה, והם מתאימים לשני הרמות שלמעלה:

- **חינמי — API לצרכן / מנוע הזמנות** (REST, `/api/public/**`): אנונימי, פונה לדפדפן ולווידג'טים. [עיין במדריך מנוע ההזמנות →](/he/api/booking-engine/)
- **בתשלום — API אינטגרטור שותף** (**gRPC**, `wink.partner.v1`): מאומת, מחושב לפי שימוש, בנוי לאינטגרציה בין שרתים בקנה מידה גדול. [עיין במדריך האינטגרטור →](/he/partner-api/partner/)

ממשק ה-API של האינטגרטור השותף הוא gRPC, לא REST. קוראים לו עם לקוח שנוצר מראש דרך HTTP/2 בכתובת
`partner.wink.travel:443`, עם טוקן נושא והחשבון עבורו אתם קוראים:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

דף ההפניה לעיל מתעד כל שירות, הודעה ומצב שגיאה, והסכימה זמינה גם בזמן ריצה דרך רפלקציה של השרת, כך ש-`grpcurl`, Postman ו-Insomnia מגלים אותה ללא צורך בהורדה.

אם אתם מעדיפים ליצור לקוח מראש, קבצי המקור `.proto` מפורסמים בכתובת
[github.com/wink-travel/partner-api-proto](https://github.com/wink-travel/partner-api-proto).

## כיצד פועל השימוש והמגבלות

### רמת חינמי

רמת החינמי מיועדת לאפשר לכם לבנות, לבדוק ולהפעיל תעבורה יצרנית מתונה ללא עלות.

- **אין מגבלת דקות מפורסמת.** Wink עוקבת אחרי קצב הבקשות ועלולה להחיל מגבלות שימוש הוגן להגנת השירות. אם תקבלו **HTTP 429 (יותר מדי בקשות)**, המתינו את מספר השניות בכותרת `Retry-After` לפני שתנסו שוב.
- **מנוי חודשי — 10,000 יחידות לחודש קלנדרי.** המנוי ניתן לכל חשבון ומאופס ב-1 לכל חודש (UTC). ברגע שתגיעו אליו, חשבון שלא נרשם לחיוב לפי שימוש יקבל **HTTP 429 עד ל-1 לחודש הבא** — עצירה מוחלטת, עם כותרת `Retry-After` והודעה שמזמינה אתכם להירשם לרמת התשלום. חשבון רשום ממשיך לעבוד ומחויב על שימוש מעבר למנוי.

רמת החינמי אינה כוללת הסכם רמת שירות או תמיכה בעדיפות.

### רמת בתשלום

רמת התשלום מסירה את התקרה החודשית ומחייבת אתכם רק על מה שאתם משתמשים.

- **לילות במלון מחושבים — 0.0001$ ללילה במלון.** אין תקרה חודשית; אתם מחויבים על נפח אמיתי. Wink עשויה עדיין להחיל מגבלות שימוש הוגן להגנת השירות. שיחות חיפוש ומלאי מחויבות לפי לילות במלון במחיר; שיחות תוכן וחיפוש מחויבות יחידה אחת כל אחת, כך שאיחוד הבקשות שומר על החשבון נמוך.

רמת התשלום כוללת את הסכם רמת השירות המתואר למטה — התחייבות לזמינות של 99.9% ומטרת זמן תגובה P95 מתחת ל-500 מ"ש — ותמיכה בעדיפות, מבוססת חומרת הבעיה.

## הסכם רמת שירות

_תאריך תחולה: 5 ביולי 2026 · גרסה 1.0_

הסכם רמת השירות הזה ("SLA") מגדיר את התחייבות הזמינות, קרדיטים לשירות, ויעדי התמיכה ש-Wink ("Wink", "אנחנו", "לנו") מספק ללקוח ("לקוח", "אתה") עבור ממשק ה-API המאומת של Wink Partner ("Partner API" או "השירות") ברמות שבהן מצוין כי ה-SLA חל. הסכם זה משולב ומנוהל על ידי ההסכם בינך לבין Wink שבמסגרתו אתה ניגש ל-Partner API ("ההסכם"), ותקף כל עוד אתה שומר על מנוי Partner API פעיל בתשלום במצב תקין. מונחים עם אותיות גדולות שלא הוגדרו כאן מקבלים את המשמעות שניתנה להם בהסכם.

### 1. הגדרות

1. **"זמינות"** פירושה התקופות שבהן Partner API זמין לקבל ולהגיב בהצלחה לבקשות מאומתות ומעוצבות כראוי.
2. **"אי זמינות"** פירושה כל תקופה, הנמדדת בדקות, שבה Partner API נכשל להגיב בהצלחה לבקשות מאומתות ומעוצבות כראוי, למעט כל תקופה הנופלת תחת החריגים המפורטים בסעיף 4. שגיאות מבודדות המשפיעות על חלק זניח מהבקשות אינן, בפני עצמן, אי זמינות.
3. **"אחוז זמינות חודשי"** פירושו, עבור חודש קלנדרי נתון, סך כל הדקות בחודש פחות סך דקות אי הזמינות, חלקי סך כל הדקות בחודש, מבוטא באחוזים.
4. **"תחזוקה מתוזמנת"** פירושה תחזוקה מתוכננת של השירות שעליה Wink הודיעה מראש בהתאם לסעיף 4.
5. **"קרדיט שירות"** פירושו זיכוי, המחושב כאחוז מהתשלומים ששולמו או שיש לשלם על Partner API בחודש הקלנדרי המושפע, המיושם כנגד תשלומים עתידיים עבור Partner API כפתרון הבלעדי והיחיד לכישלון לעמוד בהתחייבות הזמינות.
6. **"זמן תגובה"** פירושו הזמן שחלף בין קבלת Wink בקשה מאומתת ומעוצבת כראוי בגבול השירות של Wink לבין הנקודה שבה Wink מתחיל להחזיר את התגובה, ללא זמן העברה ברשת וכל זמן בצד הלקוח שאינו בשליטת Wink.

### 2. התחייבות לזמינות וביצועים

Wink תשתמש במאמצים סבירים מסחרית כדי להבטיח ש-Partner API יהיה זמין ב**אחוז זמינות חודשי של לפחות 99.9%** במהלך כל חודש קלנדרי בתקופת ההסכם ("התחייבות הזמינות"). התחייבות הזמינות נמדדת בגבול השירות של Wink ומוצאת מחוץ לגורמים שאינם בשליטת Wink באופן סביר, כולל אלה המתוארים בסעיף 4. מערכות הניטור של Wink הן המקור הרשמי למדידת אחוז הזמינות החודשי וזמן התגובה.

Wink מכוונת גם ל**זמן תגובה ברבעון ה-95 (P95) של פחות מ-500 מילישניות** לבקשות מאומתות ומעוצבות כראוי, שנמדד בגבול השירות של Wink במהלך כל חודש קלנדרי ("מטרת הביצועים"). מטרת הביצועים אינה כוללת את הגורמים המתוארים בסעיף 4, בקשות שמחזירות שגיאות ברמת היישום שנגרמו על ידי הבקשה עצמה, ובקשות אצווה גדולות או מורכבות במיוחד. מטרת הביצועים היא יעד שירות; קרדיטי השירות בסעיף 3 חלים על כישלונות לעמוד ב**התחייבות הזמינות** והם הפתרון הבלעדי והיחיד למחסור בזמינות.

### 3. קרדיטי שירות

אם אחוז הזמינות החודשי יורד מתחת להתחייבות הזמינות בכל חודש קלנדרי, ייתכן שתהיה זכאי לקרדיט שירות המחושב כאחוז מתשלומי Partner API ששולמו או שיש לשלם עבורך באותו חודש, לפי הטבלה הבאה:

| אחוז זמינות חודשי | קרדיט שירות |
|---|---|
| מתחת ל-99.9% אך לפחות 99.0% | 10% |
| מתחת ל-99.0% אך לפחות 95.0% | 25% |
| מתחת ל-95.0% | 50% |

1. **תביעה לקרדיט.** כדי לקבל קרדיט שירות עליך להגיש תביעה בכתב ל-Wink בתוך **שלושים (30) ימים** מסוף החודש הקלנדרי שבו אירע הקיצור. התביעה חייבת לכלול את התאריכים והשעות של כל אירוע אי הזמינות שאתה תובע וכל לוגים או ראיות תומכות הזמינות לך סבירות. תביעות המוגשות לאחר חלון זה אינן זכאיות.
2. **צורת הקרדיט.** קרדיטי שירות מאושרים מיושמים כנגד תשלומים עתידיים עבור Partner API ואינם בעלי ערך כספי. הם אינם החזרים ולא ישולמו אלא אם כן נדרש על פי חוק.
3. **קרדיט מקסימלי.** סך כל קרדיטי השירות שיינתנו עבור חודש קלנדרי יחיד לא יעלה על 50% מתשלומי Partner API ששולמו או שיש לשלם עבורך באותו חודש.
4. **פתרון בלעדי ויחיד.** קרדיטי השירות הם ה**פתרון הבלעדי והיחיד** שלך לכל כישלון של Wink לעמוד בהתחייבות הזמינות או כל מחסור אחר בזמינות Partner API.

### 4. חריגים

התחייבות הזמינות וכל קרדיטי השירות הנובעים ממנה אינם חלים, ואי הזמינות אינה כוללת, כל אי זמינות, השעיה, ירידה באיכות או בעיית ביצועים הנובעים מ-או קשורים ל:

1. **תחזוקה מתוזמנת** שעליה Wink הודיעה מראש, בתנאי שההודעה ניתנה בזמן סביר מראש דרך ערוץ ש-Wink משתמשת בו בדרך כלל לתקשורת עם לקוחות;
2. אירועי **כוח עליון** או סיבות אחרות שאינן בשליטת Wink באופן סביר, כולל אסונות טבע, פעולות ממשלה, כשלי רשת או שירותים, ותקיפות מניעת שירות או תקיפות זדוניות אחרות;
3. בעיות שנגרמו על ידי **פעולות או מחדלים שלך**, הציוד, התוכנה או הרשת שלך, או על ידי כל שירות, מוצר או ספק **של צד שלישי** שאינו בשליטת Wink ישירה;
4. **שימוש לרעה בשירות** או **הפרת ההסכם**, ה-SLA הזה, תנאי שימוש מקובלים, או מגבלות קצב חלות, כולל תעבורה ש-Wink סבירה קובעת כמופרזת, שימוש אוטומטי לרעה, או הונאה; ו
5. כל **השעיה או סיום** של הגישה שלך שבוצעו כדין לפי ההסכם, כולל השעיה בגין אי תשלום.

### 5. יעדי תמיכה ותגובה

Wink מספקת תמיכה עבור Partner API בשעות עבודה רגילות, למעט חגים מקומיים. Wink תשתמש במאמצים סבירים מסחרית להכיר בבקשות תמיכה שהוגשו כראוי בתוך זמני תגובה יעד הבאים, בהתבסס על חומרת הבעיה שאתה מגדיר ו-Wink מאשרת סבירות:

| חומרה | תיאור | זמן תגובה ראשוני יעד |
|---|---|---|
| **חומרה 1 — קריטי** | Partner API לא פעיל או בלתי שמיש בייצור ללא פתרון חלופי. | 4 שעות |
| **חומרה 2 — משמעותי** | תכונה משמעותית נפגמת או מתדרדרת; קיים פתרון חלופי. | יום עסקים אחד |
| **חומרה 3 — מינורי** | שאלות כלליות, בעיות קטנות, או בקשות תכונה. | יומיים עסקים |

זמני התגובה היעדיים מתארים מתי Wink שואפת ליצור **מגע ראשוני**; הם אינם הבטחות לזמן פתרון. תמיכה בעדיפות ויעדי חומרה חלים ברמות שבהן מצוין שהם כלולים.

### 6. נתונים ואבטחה

Wink שומרת על אמצעים מנהליים, טכניים וארגוניים סבירים מסחרית שנועדו להגן על סודיות, שלמות וזמינות הנתונים המעובדים דרך Partner API, ובוחנת אמצעים אלה מעת לעת. עיבוד הנתונים האישיים של Wink מנוהל על ידי [מדיניות הפרטיות](/he/privacy) וכל תנאי עיבוד נתונים בהסכם. אתה נשאר אחראי לאבטחת אישורי ה-API שלך, לשימוש חוקי בכל נתון שאתה מושך, ולהודיע ל-Wink במהירות על כל חשד לפגיעה באישורים.

### 7. הגבלת אחריות

קרדיטי השירות הם ה**פתרון הבלעדי והיחיד** לכל אי זמינות או כישלון לעמוד בהתחייבות הזמינות, ומסופקים במקום כל אחריות אחרת הנובעת מכישלון כזה. למעט כפי שמוצהר במפורש ב-SLA זה, Partner API מסופק "כפי שהוא". במידה המרבית המותרת על פי חוק, האחריות הכוללת של Wink הנובעת או הקשורה לשירות מוגבלת כפי שמפורט בהסכם, ו-Wink אינה אחראית לנזקים עקיפים, מקריים, מיוחדים, תוצאתיים או עונשיים, או לאובדן רווחים, הכנסות, נתונים או מוניטין, גם אם הונחה על אפשרות נזקים כאלה.

### 8. תקופה, שינויים וסיום

SLA זה תקף כל עוד יש לך מנוי Partner API פעיל ברמה שבה מצוין כי ה-SLA חל. Wink רשאית לעדכן SLA זה מעת לעת; שינויים מהותיים יועברו דרך ערוץ ש-Wink משתמשת בו בדרך כלל לתקשורת עם לקוחות, והשימוש המתמשך ב-Partner API לאחר כניסת העדכון לתוקף מהווה הסכמה ל-SLA המעודכן. SLA זה מסתיים אוטומטית עם סיום או פקיעת ההסכם או מנוי Partner API שלך. סעיפים שבאופיים צריכים לשרוד את הסיום — כולל זכאות לקרדיט שירות שנצבר אך לא תבע, הגבלת אחריות והגדרות — יישארו בתוקף.
