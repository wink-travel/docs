האפליקציה **Wink Wix App** מוסיפה רכיבי רשת של Wink לאתר ה-Wix שלך כווידג'טים מקומיים שניתן לגרור ולשחרר בעורך ה-Wix. אין צורך בקידוד לבעלי האתר.

<LinkCard
  title="wink-travel/wink-wix-app on GitHub"
  href="https://github.com/wink-travel/wink-wix-app"
  description="קוד מקור, מדריך הגדרת מפתחים והוראות לתרומה."
/>

## התקנה

<Steps>
1. עבור ל-[שוק האפליקציות של Wix](https://www.wix.com/app-market) וחפש את **Wink Travel**.
2. לחץ על **הוסף לאתר** ופעל לפי ההנחיות לאישור האפליקציה.
3. לאחר ההתקנה, פתח את **לוח בקרה → הגדרות Wink** והזן את **Client ID** ו-**Client Secret** שלך.
   עבור אל [יישומים](/he/account/applications) כדי לקבל את האישורים שלך.
4. לחץ על **שמור** ואז על **בדוק חיבור** כדי לאשר ש-Wink מחובר.
</Steps>

## הוספת רכיב לעמוד

<Steps>
1. פתח את **עורך Wix** ועבור לעמוד שבו ברצונך להוסיף תוכן של Wink.
2. לחץ על **הוסף (+) → אפליקציות → Wink Travel** כדי לראות את כל הווידג'טים הזמינים.
3. גרור ווידג'ט אל העמוד — לדוגמה, **Wink Content** להצגת רשת מלונות.
4. בלוח הגדרות הווידג'ט, בחר את **סוג הפריסה** והדבק את **מזהה הפריסה** מפורטל.
5. לחץ על **פרסם** כדי להפוך את השינויים לזמינים.
</Steps>

## ווידג'טים זמינים

| ווידג'ט | מטרה |
|---|---|
| **Wink Content** | מציג כרטיסי מלונות, רשתות מדורגות, מפות ועוד |
| **Wink Lookup** | שורת חיפוש ליעדים ומלונות |
| **Wink Search** | כפתור אייקון שפותח את בורר המסלול |
| **Wink Account** | כפתור התחברות / חשבון משתמש |
| **Wink Itinerary** | כפתור מסלול המציג את הטיול הנוכחי |
| **Wink Cart** | כפתור סיכום עגלת קניות |
