Wink מציגה שני פרוטוקולים. באיזה מהם תשתמש תלוי באיזו API אתה משתלב.

| | פרוטוקול | סכימה | תיעוד |
| --- | --- | --- | --- |
| רוב ה-APIs של Wink | REST על HTTPS | OpenAPI 3 | כל קבוצה תחת **API** בסרגל הצדדי |
| Partner Integrator API | gRPC על HTTP/2 | Protocol Buffers | [Partner](/he/partner-api/partner/) |

<Aside type="note" title="איננו מפרסמים יותר SDKs לשפות">
  SDKs שנוהלו ידנית התעדכנו באיחור ביחס ל-APIs שהם עטפו, ולעולם לא כללו את השפה שהייתה לך באמת דרושה. במקום זאת, צור לקוח מתוך הסכימה — היא תמיד עדכנית — או תן לשרת MCP שלנו לכתוב קוד אינטגרציה המותאם למקרה השימוש שלך.
</Aside>

## יצירת לקוח REST

כל קבוצת API מפרסמת מסמך OpenAPI 3. הפנה כל מחולל OpenAPI אליו ותקבל לקוח טיפוסי בשפתך.

```bash
# המפרט של כל קבוצה זמין להורדה באתר זה: /api/downloads/<group>.json
curl -o wink-extranet.json https://wink.travel/api/downloads/extranet.json

npx @openapitools/openapi-generator-cli generate \
  -i wink-extranet.json -g typescript-fetch -o ./wink-client
```

## יצירת לקוח gRPC

Partner Integrator API הוא gRPC. אתה יוצר לקוח מתוך סכימת `.proto`, ש-Wink מפרסמת בשתי דרכים:

- **Server reflection** — השרת מתאר את עצמו, כך שכלים כמו `grpcurl`, Postman ו-Insomnia יכולים לגלות את הסכימה בזמן ריצה ללא צורך בקבצים להורדה. Reflection דורש את אותו אסימון bearer כמו כל קריאה אחרת.
- **קבצי `.proto`**, אם אתה מעדיף לכלול את הסכימה וליצור את הלקוח מראש.

```bash
# גלה את הסכימה משרת פעיל (מאומת).
grpcurl -H "authorization: Bearer $WINK_TOKEN" \
  partner.wink.travel:443 list

# לאחר מכן צור לקוח — כאן Go; כל שפה נתמכת עובדת באותה צורה.
protoc --go_out=. --go-grpc_out=. partner_lookup.proto
```

הקריאות נושאות את אסימון ה-bearer שלך בכותרת המטא-דאטה `authorization`, בדיוק כמו ש-REST נושא אותו בכותרת `Authorization`. שגיאות מגיעות כקוד סטטוס gRPC בטריילרים של התגובה במקום כקוד סטטוס HTTP — [הפניה ל-Partner](/he/partner-api/partner/) מפרטת את הסטטוסים שעליך לצפות להם.

## או תן לשרת MCP לכתוב את זה

אם אתה משתמש בעוזר קידוד מבוסס AI, שרת MCP שלנו הוא הדרך המהירה ביותר. הוא מציג את APIs של Wink ככלים שהעוזר שלך יכול לקרוא ולהבין, כך שבמקום ליצור לקוח שלם ולמצוא את נקודות הקצה בעצמך, אתה מתאר מה אתה בונה ומקבל קוד אינטגרציה המותאם לכך.
