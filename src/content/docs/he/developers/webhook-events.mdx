דף זה מפרט כל אירוע webhook שניתן להירשם אליו ב-Wink. להוראות הגדרה, ראה את [מדריך אינטגרציית Webhook](/he/developers/webhook-integration) או את [דף ניהול ה-Webhooks](/he/portal/settings/webhooks).

## כיצד להירשם

1. עבור אל **Applications > Webhooks** בפורטל שלך.
2. צור webhook ובחר את האירועים שברצונך לקבל.
3. Wink ישלח HTTP POST לנקודת הקצה שלך בכל פעם שהאירוע מתרחש.

לשלבים מלאים של ההגדרה והנחיות מומלצות, ראה [Webhook Integration](/he/developers/webhook-integration).

## ניהול אירועי ישות

אירועים לניהול ישויות (נכסים, שותפים, חברות) והניהול שלהן.

### מחזור חיים

| אירוע | מפתח | תיאור |
|---|---|---|
| ישות נוצרה | `managing_entity.created` | ישות ניהול חדשה נוצרה. |
| ישות נמחקה | `managing_entity.deleted` | ישות ניהול נמחקה. |
| סטטוס עודכן | `managing_entity.status.updated` | סטטוס הישות השתנה. |
| בבדיקה | `account.under_review` | חשבון הישות ממתין לבדיקה. |

| אירוע | מפתח | תיאור |
|---|---|---|
