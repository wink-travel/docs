Wink מציעה שני שרתי MCP מאומתים. שניהם משתמשים ב**כניסה אינטראקטיבית ב-OAuth2** (זרימת קוד הרשאה PKCE) — סוכן ה-AI שלכם פותח לשונית דפדפן כדי שתתחברו עם חשבון Wink שלכם. אין צורך לנהל סודות לקוח.

| שרת | URL | מה הוא עושה |
|--------|-----|--------------|
| **Inventory API** | `https://api.wink.travel/mcp` | מלאי, הזמנות, מחירים, ערוצי מכירה, אנליטיקה וכל פעולות הפלטפורמה |
| **Integrations** | `https://integrations.wink.travel/mcp` | אינטגרציות עם מנהל ערוצים — סינכרון נכסים, מחירים וזמינות עם OTAs |

---

## איך האימות עובד

שרתי MCP של Wink משתמשים בזרימת **OAuth2 Authorization Code + PKCE** ותומכים ב**רישום דינמי של לקוח (RFC 7591)**. כך זה עובד כשאתם מתחברים בפעם הראשונה:

1. לקוח ה-AI שלכם מגלה את שרת ההרשאה מתוך מטא-דאטה של נקודת הקצה MCP ב-`/.well-known/oauth-protected-resource`.
2. הלקוח נרשם בעצמו דרך **רישום דינמי של לקוח** — אין צורך בהגדרת אפליקציה ידנית.
3. הלקוח פותח **לשונית דפדפן** ל-`https://iam.wink.travel`. אתם מתחברים עם חשבון Wink ומאשרים את ההרשאות המבוקשות במסך ההסכמה.
4. Wink מנפיקה **אסימון גישה** המוגבל לחשבונכם ומקושר לזהותכם.
5. לקוח ה-AI מצרף את האסימון לכל בקשה ל-MCP. כל תוצאות הכלים מוגבלות אוטומטית לישות הניהול שלכם.
6. האסימונים פוקעים לאחר 3 שעות. לקוח ה-AI מרענן אותם ברקע ללא בקשה חוזרת.

כל קריאת כלי מתבצעת **מתחת לזהות שלכם** — אותם כללי ACL שמגנים על פורטל האינטרנט חלים גם על סוכן ה-AI.

## חברו את לקוח ה-AI שלכם

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. ודאו ש-Claude Code מעודכן:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. הוסיפו את שרת MCP של Wink Inventory:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code ייצור קשר עם השרת, יגלה את שרת ההרשאה ויפתח את הדפדפן המוגדר כברירת מחדל.

4. **התחברו ל-Wink** ואשרו את בקשת ההרשאות במסך ההסכמה.

5. Claude Code יאשר את החיבור. הקלידו `/mcp` כדי לוודא שהשרת מופיע ושהכלים נטענו.
</Steps>

להוספת שרת Integrations גם כן:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[שתפו עם הצוות שלכם]
הוסיפו `--scope project` ל-`claude mcp add` ו-Claude Code יכתוב את כתובת השרת ל-`.mcp.json` בשורש הריפוזיטורי. התחייבו לקובץ זה — כל חבר צוות ישלים את כניסת הדפדפן שלו בפעם הראשונה שהוא מתחבר.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. ערכו את קובץ הקונפיגורציה של Claude Desktop:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. הוסיפו את רשומות שרתי MCP:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **סגרו והפעילו מחדש לחלוטין** את Claude Desktop (השתמשו ב-Quit מהסרגל — סגירת החלון לא מספיקה).

4. Claude Desktop יפתח לשונית דפדפן עבור כל שרת חדש. התחברו ל-Wink ואשרו הרשאות.

5. סמל התקע בסרגל התחתון יציג את שני השרתים כמחוברים.
</Steps>

  </TabItem>
  <TabItem label="OpenAI Codex">

<Steps>
1. ודאו ש-Codex CLI מותקן:
   ```bash

   ```

2. פתחו (או צרו) את קובץ הקונפיגורציה של Codex:
   - **macOS / Linux:** `~/.codex/config.json`
   - **Windows:** `%USERPROFILE%\.codex\config.json`

3. הוסיפו את רשומות שרתי MCP של Wink:

   ```json title="~/.codex/config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

4. הפעלו את Codex. בשימוש הראשון, Codex יפתח לשונית דפדפן ל-`https://iam.wink.travel`.

5. **התחברו ל-Wink** ואשרו את ההרשאות המבוקשות.

6. Codex יאשר את החיבור. הריצו `codex` ובקשו ממנו לרשום את הכלים הזמינים כדי לוודא ששרתי Wink פעילים.
</Steps>

:::note
תמיכת MCP ב-Codex CLI דורשת גרסה **1.0** ומעלה. הריצו `codex --version` לבדיקה, ו-`npm install -g @openai/codex` לעדכון.
:::

תמיכת שרתי MCP זמינה ב**אפליקציית ChatGPT למחשב** למנויים Plus, Pro, Team ו-Enterprise.

<Steps>
1. הורידו והתקינו את [אפליקציית ChatGPT למחשב](https://openai.com/chatgpt/download/) אם עדיין לא עשיתם זאת.

2. פתחו את האפליקציה ולחצו על **סמל הפרופיל שלכם** בפינה הימנית העליונה, ואז בחרו **הגדרות**.

3. עברו ל**מחברים** (או **שרתי MCP** בהתאם לגרסת האפליקציה) ולחצו על **הוסף**.

4. הזינו את כתובת שרת Wink Inventory:
   ```
   https://api.wink.travel/mcp
   ```
   ואז לחצו **חבר**.

5. ChatGPT יפתח לשונית דפדפן ל-`https://iam.wink.travel`. **התחברו ל-Wink** ואשרו הרשאות.

6. חזרו על שלבים 4–5 עבור שרת Integrations:
   ```
   https://integrations.wink.travel/mcp
   ```

7. שני השרתים יופיעו ברשימת המחברים שלכם. התחילו שיחה חדשה — כלים של Wink זמינים אוטומטית.
</Steps>

:::note[מגבלת אפליקציית ווב]
שרתי MCP ניתנים להגדרה רק ב**אפליקציית המחשב**. ממשק הווב של ChatGPT ב-chatgpt.com אינו תומך בשרתי MCP מותאמים.
:::

## תחומי הרשאה

כשאתם מאשרים את מסך ההסכמה תראו פירוט של מה שהסוכן מבקש. לקוחות MCP משתמשים באותה אוצר מילים של הרשאות כמו שאר הפלטפורמה — ראו את כל
[ההפניה לתחומי הרשאה בדף האימות](/he/developers/authentication#scopes).

שני דברים ספציפיים ל-MCP:

- **תחומי ההרשאה `mcp.read` `mcp.write` `mcp.remove` נדרשים בנוסף** כדי לפתוח את תחום ה-MCP. לקוח שמחזיק ב-`mcp.*` מורשה ל-`/mcp`, אך כל כלי שהוא מפעיל עדיין מאכף את תחום ההרשאה של נקודת הקצה שהוא עוטף (למשל `booking.read`).
- **לקוח ה-AI מבקש רק את התחומים שהוא צריך.** ניתן לסרב להרשאות בודדות במסך ההסכמה — כלים שדורשים תחום שסורב יחזירו שגיאה בעת הפעלה.

## פתרון בעיות

**לשונית דפדפן לא נפתחת**

ייתכן שללקוח ה-AI שלכם אין תמיכה בזרימת PKCE אינטראקטיבית עדיין. ודאו שאתם מריצים גרסה עדכנית:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** עדכנו דרך העדכון המובנה באפליקציה

**`401 Unauthorized` לאחר התחברות**

ייתכן שהאסימון במטמון שלכם פג תוקף. הסירו והוסיפו מחדש את השרת כדי להפעיל כניסה חדשה:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

ל-Claude Desktop ו-ChatGPT, הסירו את רשומת השרת מההגדרות, אתחלו את האפליקציה והוסיפו שוב.

**`403 Forbidden` בעת קריאה לכלי מסוים**

הכלי דורש תחום הרשאה שסורב במסך ההסכמה. התחברו מחדש לשרת — מסך ההסכמה יופיע שוב ותוכלו לאשר את ההרשאה החסרה.

**השרת מופיע אך קריאות לכלי מחזירות "חשבון לא נמצא"**

אתם מחוברים לחשבון Wink שאין לו ישות ניהול. עברו ל-[פורטל Wink](https://app.wink.travel) וודאו שהחשבון מוגדר לפני השימוש בשרת MCP.

**אסימון פג באמצע סשן**

אסימונים תקפים ל-3 שעות. Claude Code ו-Claude Desktop מרעננים אסימונים בשקט ללא הפרעה. אם אתם רואים שגיאות אימות לאחר תקופת חוסר פעילות ארוכה, הקלידו הודעה חדשה — הלקוח יאמת מחדש אוטומטית.

**Codex CLI מציג "MCP server unreachable"**

בדקו ש-`~/.codex/config.json` הוא JSON תקין (ללא פסיקים מיותרים) ושהשדה `"type": "http"` מוגדר. Codex דורש תחבורה HTTP לשרתים מרוחקים; תחבורה stdio מיועדת לבינאריים מקומיים בלבד.

**תפריט "Connectors" ב-ChatGPT חסר**

תמיכת MCP דורשת גרסת אפליקציית ChatGPT למחשב **1.2024.352** ומעלה ומנוי Plus, Pro, Team או Enterprise פעיל. עדכנו את האפליקציה ואשרו את התכנית בהגדרות → חשבון.

**שרת Cursor מופיע באדום / "Failed to connect"**

ודאו ש-`~/.cursor/mcp.json` הוא JSON תקין וכולל `"type": "http"`. עברו ל**הגדרות → הגדרות Cursor → MCP** ולחצו על **רענן**. אם השגיאה נמשכת, אתחלו את Cursor לחלוטין — שינויים בקונפיגורציה לא תמיד נטענים ללא אתחול.

**שרתי MCP של Windsurf לא מופיעים בהגדרות**

Windsurf דורש אתחול מלא (לא רק רענון חלון) כדי לטעון שינויים ב-`mcp_config.json`. השתמשו ב**קובץ → יציאה** ופתחו מחדש. אם השרתים עדיין לא מופיעים, ודאו שאתם בגרסה **1.4+** דרך **עזרה → אודות Windsurf**.

**אפשרות "Add Server" ב-Cline לא נראית**

מנהל שרתי MCP דורש Cline בגרסה **2.0** ומעלה. פתחו את פאנל התוספים ב-VS Code, מצאו את Cline ולחצו על **עדכן** אם יש עדכון זמין. לאחר העדכון, טענו מחדש את VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
