כלי MCP של Wink מפורסמים כ**ערכות כלים** — נקודות קצה ממוקדות, כל אחת מכסה משימה אחת. אתם מחברים את לקוח ה-AI שלכם לאחת או שתיים שמתאימות לעבודה שלכם, לא לכולן.

כל נקודת קצה משתמשת ב**התחברות אינטראקטיבית ב-OAuth2** (זרימת קוד הרשאה PKCE): סוכן ה-AI שלכם פותח לשונית דפדפן, אתם נכנסים עם חשבון Wink שלכם, וזהו. אין צורך לנהל סודות לקוח.

```bash title="אינטגרטור מנהל ערוצים מתחבר לנקודת קצה אחת"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="מלונאי שמנהל את המחירים שלו מתחבר לנקודת קצה אחרת"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## למה הכלים מחולקים לנקודות קצה

Wink מציגה כ-500 כלים. להעביר את כולם לסוכן בבת אחת אפשרי טכנית — אבל רעיון לא טוב.

**הגדרות הכלים צורכות הקשר.** כל כלי ששרת MCP מפרסם נטען לחלון ההקשר של המודל לפני שהוא מבצע עבודה, יחד עם תיאורו ומבנה הפרמטרים המלא. חמש מאות כאלה צורכים חלק גדול מתקציב המשימה שלכם, בכל בקשה.

**איכות הבחירה יורדת ככל שהרשימה גדלה.** סוכן שבוחר מתוך 500 כלים עם שמות דומים עושה בחירות גרועות יותר מאשר סוכן שבוחר מתוך 40. אם אתם משתלבים עם מנהל ערוצים, כעשרים כלים רלוונטיים לכם; ה-480 הנותרים הם רעש שמקשה למצוא את הכלי הנכון.

**העבודה ניתנת להפרדה אמיתית.** מישהו שמסנכרן זמינות מ-PMS ומישהו שמנהל דפי שותפים כמעט ולא חולקים כלים. חלוקה לפי משימה אומרת שכל חיבור נושא את אוצר המילים של משימה אחת.

<Aside type="caution" title="ערכות כלים אינן הרשאות">
בחירת ערכת כלים צרה **אינה** מגבילה את מה שהחשבון שלכם יכול לעשות, ובחירת ערכה רחבה אינה מעניקה שום דבר נוסף. כל כלי מאכף את אותן הרשאות חשבון כמו פורטל האינטרנט, תחת הזהות שלכם שנכנסתם איתה. אם החשבון שלכם אינו יכול לבטל הזמנה בפורטל Wink, גם הסוכן לא יכול — ללא קשר לאיזו נקודת קצה הוא מחובר.

בחרו ערכות כלים ל**מיקוד**, לא לאבטחה.
</Aside>

## מדריך נקודות קצה

שני מארחים משרתים ערכות כלים. מספר הכלים משוער וגדל עם הזמן.

### `https://api.wink.travel` — הפלטפורמה

| נקודת קצה | כלים | מה היא מכסה |
|---|---:|---|
| `/mcp/extranet/facilities` | ~64 | מלאי שניתן להזמין ובמקום: חדרי אורחים וסוגי חדרים, ספא, מסעדות, חדרי ישיבות, פעילויות, אטרקציות, מקומות, פריטים נוספים למכירה |
| `/mcp/extranet/property` | ~62 | רשומת הנכס ותנאים מסחריים: פרופיל ותוכן, תוספות, מדיניות ביטול, הטבות, הודעות |
| `/mcp/settings` | ~60 | ניהול חשבון: פרופיל ישות ניהול ומיתוג, מנהלים והענקות שלהם, התאמה אישית, וובוקים, העדפות התראות |
| `/mcp/studio/embeds` | ~48 | פרסום מלאי שנבחר: ווידג'טים, רשתות ורשתות מדורגות, כרטיסים, מפות, קישורים עמוקים למלאי ודפי ספקים |
| `/mcp/extranet/rates` | ~44 | מחירים וזמינות: תקופות ותשלומים של מחירי מלאי, תוכניות מחירים, מחירי אב, מחירים מיוחדים וקידומיים |
| `/mcp/extranet/operations` | ~39 | ניהול נכס חי: הזמנות ומחזור חייהן, ביקורות אורחים ותגובות, פידים של לוח שנה, משימות מתוזמנות |
| `/mcp/extranet/distribution` | ~37 | היכן נמכר המלאי: ערוצי מכירה ומודיפיקטורים למחירים, בקשות לשותפים ולקשרים עם ספקים, רישום, לכידת לידים |
| `/mcp/studio/curation` | ~35 | בניית אוספים למכירה: רשימות סטטיות ודינמיות, רשימות מדורגות, חיפושים שמורים, אגרגטים של נכס |
| `/mcp/link-manager` | ~28 | אוספי קישורים מסונכרנים, העיצוב שלהם, קטגוריות ותוויות, בנוסף כתובות מקוצרות |
| `/mcp/reference` | ~24 | נתוני עיון לקריאה בלבד: מדינות, מטבעות ושערי חליפין, שפות, אזורי זמן, עיוני גיאוגרפיה, מיקום IP |
| `/mcp/analytics` | ~18 | ניתוח הזמנות והכנסות: סקירות, גרפים, לוחות מובילים, ביצועי שותפים, מדדי שיתוף |
| `/mcp/payment` | ~18 | פעולות פיננסיות: ספר חשבונות, משיכות והערכות עמלות, אגרגטים של כספי הזמנות |
| `/mcp/booking-engine` | ~17 | מסלול קניות למטייל: חיפוש ועיון, עגלת קניות ותשלום, רשימות דלי, התאמת קמפיינים |
| `/mcp/social` | ~17 | חשבונות חברתיים מחוברים, פרסום ותזמון פוסטים, קריאת תובנות פוסטים |
| `/mcp/travel-agent` | ~8 | הזמנות שמבוצעות על ידי סוכן מטיילים ודוחות סוכן |

### `https://integrations.wink.travel` — אינטגרציות מנהל ערוצים

נקודת קצה אחת, כי מארח זה קיים למשימה אחת.

| נקודת קצה | כלים | מה היא מכסה |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | חיבור ואימות מנהל ערוצים, PMS או אינטגרציית CRS |

<Aside type="note" title="אינטגרציה של מנהל ערוצים לעומת ניהול מחירים עצמאי">
אלו משימות שונות לאנשים שונים, והן אינן חולקות נקודת קצה.

**מנהל ערוצים, PMS או ספק CRS** משתלב פעם אחת דרך `integrations.wink.travel/mcp/channel-manager`, ומאז מחליף נכסים, מחירים, זמינות והזמנות דרך האינטגרציה הזו. נקודת הקצה היחידה היא כל הממשק.

**מלונאי שמשנה את המחירים שלו ידנית** משתמש בערכות הכלים של האקסטרנאט ב-`api.wink.travel` — `/mcp/extranet/rates` וחברים. אלו אינם חלק מאינטגרציית מנהל ערוצים ואין למשתלב סיבה להתחבר אליהם.

ניהול חשבון גם הוא ב-`api.wink.travel`, ב-`/mcp/settings`. אין `/mcp/settings` במארח האינטגרציות.
</Aside>

כל נקודת קצה כוללת גם כלי `ping`, כך שתוכלו לוודא שהחיבור חי לפני שתבקשו עבודה אמיתית.

| **מנהל הזמנות יומיות** | `/mcp/extranet/operations` |
| **מגדיל הפצה** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **בונה דפי שותפים** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **מנהל דפי קישורים ביו** | `/mcp/link-manager` + `/mcp/social` |
| **מבצע הזמנות מטעם מטיילים** | `/mcp/travel-agent` |
| **מתאם כספים** | `/mcp/payment` |
| **בונה חווית הזמנה** | `/mcp/booking-engine` + `/mcp/reference` |

התחילו עם אחת. הוסיפו נוספת כשאתם מוצאים שאתם מבקשים משהו שהיא לא יכולה לעשות — כל חיבור עצמאי, והוספת אחת לא משפיעה על האחרות.

<Aside type="tip" title="עדיין רוצים הכל?">
`https://api.wink.travel/mcp` ו-`https://integrations.wink.travel/mcp` נשארים זמינים ומשרתים **את כל** הכלים במארח שלהם. הם שימושיים לחקירת מה קיים, אבל איננו ממליצים עליהם לעבודה יומיומית: רשימת הכלים גדולה מדי ומסיטה את המשימה שלכם ופוגמת בבחירת הכלים של הסוכן. העדיפו את ערכות הכלים שלמעלה.
</Aside>

## איך האימות עובד

שרתי MCP של Wink משתמשים בזרימת **OAuth2 Authorization Code + PKCE** ותומכים ב**רישום דינמי של לקוח (RFC 7591)**. כך זה קורה כשאתם מתחברים בפעם הראשונה:

1. לקוח ה-AI שלכם מגלה את שרת ההרשאה מתוך מטא-דאטה של נקודת הקצה MCP ב-`/.well-known/oauth-protected-resource`.
2. הלקוח נרשם בעצמו דרך **רישום דינמי של לקוח** — אין צורך בהגדרת אפליקציה ידנית.
3. הלקוח פותח **לשונית דפדפן** ל-`https://iam.wink.travel`. אתם נכנסים עם חשבון Wink שלכם ומאשרים את ההרשאות המבוקשות במסך ההסכמה.
4. Wink מוציאה **אסימון גישה** שמוגבל לחשבון שלכם ומקושר לזהות שלכם.
5. לקוח ה-AI מצרף את האסימון לכל בקשת MCP. כל תוצאות הכלים מוגבלות אוטומטית לישות הניהול שלכם.
6. האסימונים פוקעים אחרי 3 שעות. לקוח ה-AI מרענן אותם בשקט ברקע ללא בקשה חוזרת.

כל קריאת כלי מתבצעת **תחת הזהות שלכם** — אותם כללי ACL שמגנים על פורטל האינטרנט חלים על סוכן ה-AI.

## חברו את לקוח ה-AI שלכם

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. ודאו ש-Claude Code מעודכן:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. בחרו ערכת כלים מה-[המדריך למעלה](#endpoint-directory) והוסיפו אותה. לדוגמה, מחירים וזמינות:
   ```bash
   claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
   ```

3. Claude Code יוצר קשר עם השרת, מגלה את שרת ההרשאה, ופותח את הדפדפן המוגדר כברירת מחדל.

4. **התחברו ל-Wink** ואשרו את בקשת ההרשאות במסך ההסכמה.

5. Claude Code מאשר את החיבור. הקלידו `/mcp` כדי לוודא שהשרת מופיע וכליו נטענו.
</Steps>

הוסיפו כמה ערכות כלים שהעבודה שלכם דורשת — כל אחת היא כניסה נפרדת עם שם משלה:
```bash
claude mcp add wink-operations https://api.wink.travel/mcp/extranet/operations --transport http
claude mcp add wink-analytics  https://api.wink.travel/mcp/analytics           --transport http
```

אתם נכנסים פעם אחת בלבד. לאחר האישור בדפדפן הראשון, Claude Code משתמש במפגש Wink שלכם לנקודות קצה נוספות.

:::tip[שתפו עם הצוות שלכם]
הוסיפו `--scope project` ל-`claude mcp add` ו-Claude Code יכתוב את כתובת השרת ל-`.mcp.json` בשורש הריפוזיטורי. התחייבו לקובץ הזה — כל חבר צוות יקבל את אותן ערכות כלים, וכל אחד יסיים את ההתחברות בדפדפן בפעם הראשונה שהוא מתחבר.
:::

תמיכת שרתי MCP זמינה ב**אפליקציית ChatGPT למחשב** למנויים Plus, Pro, Team ו-Enterprise.

<Steps>
1. הורידו והתקינו את [אפליקציית ChatGPT למחשב](https://openai.com/chatgpt/download/) אם עדיין לא עשיתם זאת.

2. פתחו את האפליקציה ולחצו על **אייקון הפרופיל שלכם** בפינה הימנית העליונה, ואז בחרו **הגדרות**.

3. עברו ל**מחברים** (או **שרתי MCP** בהתאם לגרסת האפליקציה) ולחצו על **הוסף**.

4. הזינו את כתובת ה-URL של ערכת כלים מה-[המדריך למעלה](#endpoint-directory), לדוגמה:
   ```
   https://api.wink.travel/mcp/extranet/rates
   ```
   ואז לחצו **התחבר**.

5. ChatGPT פותח לשונית דפדפן ל-`https://iam.wink.travel`. **התחברו ל-Wink** ואשרו הרשאות.

6. חזרו על שלבים 4–5 עבור כל ערכת כלים נוספת שהעבודה שלכם דורשת, לדוגמה:
   ```
   https://api.wink.travel/mcp/extranet/operations
   ```

7. כל ערכת כלים מופיעה ברשימת המחברים שלכם. התחילו שיחה חדשה — כלי Wink זמינים אוטומטית.
</Steps>

:::note[מגבלת אפליקציית רשת]
שרתי MCP ניתנים להגדרה רק ב**אפליקציית המחשב**. ממשק האינטרנט של ChatGPT ב-chatgpt.com אינו תומך בשרתי MCP מותאמים.
:::

## תחומי הרשאה

כשאתם מאשרים את מסך ההסכמה תראו פירוט של מה שהסוכן מבקש. לקוחות MCP משתמשים באוצר מילים של הרשאות זהה לשאר הפלטפורמה — ראו את ה[הפניה המלאה לתחומים בדף האימות](/he/developers/authentication#scopes).

שתי נקודות ספציפיות ל-MCP:

- **תחומי `mcp.read` `mcp.write` `mcp.remove` נדרשים בנוסף** לפתיחת תחבורה MCP. לקוח שמחזיק תחום `mcp.*` מתקבל לכל נקודת קצה MCP של Wink, אבל כל כלי שהוא מפעיל עדיין מאכף את תחום הסקשן של נקודת הקצה שהוא עוטף (למשל `booking.read`).
- **לקוח ה-AI מבקש רק את התחומים שהוא צריך.** ניתן לסרב להרשאות בודדות במסך ההסכמה — כלים שדורשים תחום שנדחה יחזירו שגיאה כשיפעילו אותם.

**ערכות כלים אינן משנות את זה.** נקודת הקצה שאליה אתם מתחברים מחליטה אילו כלים *מופיעים*, לא מה הם *מורשים לעשות*. התחברות ל-`/mcp/payment` אינה מעניקה הרשאה פיננסית שלא הייתה לכם, והתחברות ל-`/mcp/reference` אינה מונעת מכלי שם לאכוף את התחום שלו. האישור נקבע לפי קריאת כלי, מהאסימון שלכם ומההענקות של החשבון.

## פתרון בעיות

**לשונית דפדפן לא נפתחת**

יתכן שלקוח ה-AI שלכם עדיין לא תומך בזרימת PKCE אינטראקטיבית. ודאו שאתם מריצים גרסה עדכנית:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** עדכנו דרך העדכון המובנה באפליקציה

**`401 Unauthorized` לאחר התחברות**

יתכן שהאסימון במטמון פג תוקף. הסירו והוסיפו מחדש את השרת כדי להפעיל התחברות חדשה:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

ל-Claude Desktop ו-ChatGPT, הסירו את כניסת השרת מההגדרות, אתחלו את האפליקציה והוסיפו שוב.

**`403 Forbidden` בעת קריאה לכלי מסוים**

הכלי דורש תחום שלא אישרתם במסך ההסכמה, או הרשאה שהחשבון שלכם אינו מחזיק. התחברו מחדש לשרת — מסך ההסכמה יופיע שוב ותוכלו לאשר את ההרשאה החסרה. אם זה עדיין נכשל, הכלי דורש הרשאת חשבון שאין לכם; התחברות לערכת כלים אחרת לא תעזור, כי ערכות כלים אינן מעניקות הרשאות.

**הכלי שאני צריך לא מופיע ברשימה**

כנראה שאתם מחוברים לערכת כלים שאינה מכסה את המשימה הזו. בדקו את [מדריך נקודות הקצה](#endpoint-directory) והוסיפו את ערכת הכלים המתאימה — החיבורים עצמאים, כך שהוספת אחת לא משנה את האחרות. אם אינכם בטוחים מי מחזיק את הכלי, התחברו זמנית ל-`https://api.wink.travel/mcp`, מצאו את הכלי, ואז בדקו איזו ערכת כלים כוללת אותו.

**`404 Not Found` בנקודת קצה של ערכת כלים**

בדקו את הנתיב בקפידה — ערכות הכלים המורכבות כוללות שני מקטעים (`/mcp/extranet/rates`, לא `/mcp/extranet-rates`), והפשוטות כוללות אחד (`/mcp/link-manager`). שימו לב שבקשה *ללא אימות* לכל נתיב תחת `/mcp` מחזירה `401`, לא `404`, כך ש-`401` לבדו אינו אומר אם נקודת הקצה קיימת.

**התחברתי ל-`api.wink.travel/mcp/channel-manager` ולא קיבלתי כלום**

נקודת קצה זו אינה קיימת. אינטגרציית מנהל ערוצים מתבצעת רק מ-`https://integrations.wink.travel/mcp/channel-manager`. אם אתם צריכים גם לקרוא או לכתוב מחירים של נכס ידנית, זו משימה נפרדת בנקודת קצה נפרדת — ראו `/mcp/extranet/rates`.

**השרת מופיע אבל קריאות כלים מחזירות "חשבון לא נמצא"**

אתם מחוברים לחשבון Wink שאין לו ישות ניהול. עברו ל-[Wink Portal](https://app.wink.travel) וודאו שהחשבון שלכם מוגדר לפני השימוש בשרת MCP.

**האסימון פג באמצע מושב**

האסימונים תקפים ל-3 שעות. Claude Code ו-Claude Desktop מרעננים אסימונים בשקט ללא הפרעה למושב. אם אתם רואים שגיאות אימות לאחר תקופת חוסר פעילות ארוכה, הקלידו הודעה חדשה — הלקוח יאמת מחדש אוטומטית.

**Codex CLI מציג "MCP server unreachable"**

בדקו ש-`~/.codex/config.json` הוא JSON תקין (ללא פסיקים מיותרים) ושהשדה `"type": "http"` מוגדר. Codex דורש תחבורה HTTP לשרתים מרוחקים; תחבורה stdio מיועדת לבינאריים מקומיים בלבד.

**תפריט "מחברים" ב-ChatGPT חסר**

תמיכת MCP דורשת גרסת אפליקציית ChatGPT למחשב **1.2024.352** ומעלה ומנוי Plus, Pro, Team או Enterprise פעיל. עדכנו את האפליקציה ואשרו את התוכנית בהגדרות → חשבון.

**שרת Cursor מציג אדום / "Failed to connect"**

ודאו ש-`~/.cursor/mcp.json` הוא JSON תקין וכולל `"type": "http"`. עברו ל**הגדרות → הגדרות Cursor → MCP** ולחצו על **רענן**. אם השגיאה נמשכת, אתחלו את Cursor לחלוטין — שינויים בקונפיגורציה לא תמיד נטענים ללא אתחול.

**שרתי MCP של Windsurf לא מופיעים בהגדרות**

Windsurf דורש אתחול מלא (לא רק רענון חלון) כדי לטעון שינויים ב-`mcp_config.json`. השתמשו ב**קובץ → יציאה** ופתחו מחדש. אם השרתים עדיין לא מופיעים, ודאו שאתם בגרסה **1.4+** דרך **עזרה → אודות Windsurf**.

**אפשרות "הוסף שרת" ב-Cline לא נראית**

מנהל שרתי MCP דורש Cline **2.0** ומעלה. פתחו את פאנל התוספים ב-VS Code, מצאו את Cline ולחצו על **עדכן** אם יש עדכון זמין. לאחר העדכון, טענו מחדש את VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
