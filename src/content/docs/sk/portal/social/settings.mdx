# Nastavenia

Keď začnete používať Social, opýtame sa vás, ako chcete, aby sme vytvárali váš obsah. Tieto možnosti máte k dispozícii kedykoľvek, takže ich môžete neskôr jednoducho zmeniť.

Prejdite do `Nastavenia` v bočnom paneli, aby ste spravovali svoje nastavenia.

Sekcia preferencií obsahuje základné nastavenia generovania obsahu:

1. **Preferovaná prispôsobiteľnosť** Vyberte, ktorú prispôsobiteľnosť chcete použiť pri generovaní obsahu. Prispôsobenia ovládajú farby témy, predvolený itinerár, menu, jazyk a ďalšie. Prispôsobenia vytvárate vo svojom účte na [app.wink.travel](https://app.wink.travel).
2. **Automatické schvaľovanie** Po zapnutí sa generované príspevky automaticky publikujú bez potreby vášho schválenia. Zapnite to, keď budete mať dôveru v kvalitu obsahu, ktorý pre vás vytvárame.
3. **Meno schvaľovateľa** Meno osoby alebo tímu, ktorý bude dostávať e-maily so žiadosťou o schválenie.
4. **E-mail schvaľovateľa** E-mailová adresa, na ktorú budú zasielané žiadosti o schválenie nadchádzajúcich príspevkov.

## Tvorcovia obsahu

Social ponúka mnoho tvorcov obsahu na výber. Každý tvorca sa zameriava na špecifický spôsob vytvárania jedinečného obsahu pre vašu nehnuteľnosť pomocou AI. Každý tvorca obsahu má atribút **Váha** — vyššia váha zvyšuje pravdepodobnosť, že bude vybraný pri generovaní príspevkov.

Tu sú všetci dostupní tvorcovia obsahu:

| Tvorca | Popis |
| -- | -- |
| **Destinácia** | Používa vašu lokalitu na vytvorenie užitočného textu o oblasti |
| **Typ izby** | Vytvára rezervovateľný príspevok s jedným z vašich typov izieb s AI-generovaným textom a obrázkami izby |
| **Aktivita** | Vytvára rezervovateľný príspevok s jednou z vašich aktivít |
| **Doplnok** | Vytvára rezervovateľný príspevok s jedným z vašich doplnkov |
| **Atrakcia** | Vytvára rezervovateľný príspevok s jednou z vašich atrakcií |
| **Miesto** | Vytvára rezervovateľný príspevok s jedným z vašich miest |
| **Konferenčná miestnosť** | Vytvára rezervovateľný príspevok s jednou z vašich konferenčných miestností |
| **Reštaurácia** | Vytvára rezervovateľný príspevok s jednou z vašich reštaurácií |
| **Spa** | Vytvára rezervovateľný príspevok s jedným z vašich spa |
| **Nehnuteľnosť** | Vytvára rezervovateľný príspevok s vašou najlepšie ocenenou izbou s AI-generovaným textom a obrázkami nehnuteľnosti |
| **Názor používateľa** | Zhrňuje recenzie hostí z celého webu do príspevku založeného na sentimentoch, ktorý zdôrazňuje, čo hostia na vašej nehnuteľnosti milujú |
| **Zábavný** | Vytvára ľahké, zábavné príspevky, ktoré udržujú váš feed zaujímavý |

:::tip[Profesionálny tip]
Uistite sa, že máte typ inventára potrebný pre vybraných tvorcov obsahu. Napríklad, ak vyberiete "Reštaurácia", musíte mať vo svojej nehnuteľnosti aspoň jednu reštauráciu.
:::

## Tón hlasu

Tón hlasu určuje štýl jazyka, ktorý AI používa pri generovaní obsahu. Vyberte tóny, ktoré zodpovedajú osobnosti vašej značky. Rovnako ako pri tvorcoch obsahu, každý tón má **Váhu**, ktorá ovláda, ako často sa používa.

Tu sú dostupné tóny:

| Tón | Štýl |
| -- | -- |
| **Neutrálny** | Pokojný, autoritatívny, faktický. Žiadny prehnaný nadšenie, žiadne vtipy — len spoľahlivé, dobre štruktúrované informácie |
| **Priateľský** | Teplý, prístupný, s úsmevom v texte, s bežnými skrátenými tvarmi a občasnými emotikonmi |
| **Luxusný** | Sofistikovaný, vytvorený. Slová ako "výnimočný" a "na mieru", ktoré čitateľom dodávajú pocit exkluzivity |
| **Gurmánsky** | Zmyselné, chutné opisy. Jazyk jedla, ktorý čitateľov hladí |
| **Dobrodružný** | Odvážny, nebojácny, energický prieskumník. Živé zmyslové opisy, ktoré robia všetko epickým |
| **Rodinný** | Príjemný, vhodný pre deti, s nadšením. Teplá rodičovská energia o bezpečných a zábavných zážitkoch |
| **Romantický** | Poetický, nostalgický, srdce rozbúchajúci. Západy slnka, jemný jazyk a láska |
| **Humorný** | Sarkastický, rýchle vtipné poznámky, šikovné slovné hry. Číta sa ako stand-up vystúpenie |
| **Eko** | Úprimný a spravodlivý. Oslavuje zelené alternatívy a udržateľné voľby |
| **Miestny znalec** | Veľmi špecifické miestne odkazy, varuje pred turistickými pascami, používa miestny slang |
| **Inkluzívny** | Vítajúci, oslavujúci a potvrdzujúci. Robí, že sa každý cíti viditeľný a cenený |
| **Mystický** | Éterický, duchovný, kozmické pravdy. Jemné pozvania na hľadanie vnútra |
| **Futuristický** | Elegantný, s pohľadom do budúcnosti. Miluje výrazy ako "paradigmatický posun" a optimistické vízie budúcnosti |
| **Šetriaci** | Šikovný, vynaliezavý, hrdý na úspornosť. Oslavuje cenovo dostupné nálezy a bezplatné zážitky |

## Typy príspevkov

Typy príspevkov určujú cieľ a štruktúru generovaného obsahu. Každý typ príspevku má **Váhu**, ktorá ovláda, ako často sa používa.

| Typ príspevku | Popis |
| -- | -- |
| **Transakčný** | Jasný, stručný, zameraný na konverziu. Podporuje rezervácie a priame akcie s faktami, cenami a ďalšími krokmi |
| **Povedomie** | Obsah budujúci značku, navrhnutý na predstavenie vašej nehnuteľnosti a zvýšenie viditeľnosti medzi potenciálnymi hosťami |
| **Sentimentálny** | Emocionálne rezonujúci obsah, ktorý vytvára pozitívne asociácie a buduje emocionálne spojenie s vaším publikom |

## Časové pásma

Možno chcete zamerať svoje marketingové úsilie na konkrétny jazyk a región. Povedzte nám jazyky, pre ktoré chcete vytvárať obsah, a časové pásmo, o ktoré máte záujem, a my urobíme zvyšok. Príspevky sa publikujú v plánovanom čase vo vybranom časovom pásme.

*Väčšina nehnuteľností používa jeden jazyk a predvolene svoj miestny jazyk.*

:::tip[Profesionálny tip]
Začnite pomaly

Nebuďte príliš ambiciózni pri prvom pokuse. Odporúčame začať vytvárať obsah pre vašu nehnuteľnosť v jednom jazyku.
:::
