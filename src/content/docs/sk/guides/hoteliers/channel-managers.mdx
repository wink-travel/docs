Wink integruje s poprednými channel managermi, systémami na správu nehnuteľností (PMS) a centrálnymi rezervačnými systémami (CRS), aby boli vaše ceny a dostupnosť synchronizované vo všetkých vašich predajných kanáloch.

## Ako to funguje

Integrácie channel managerov umožňujú obojsmerný tok dát medzi vaším systémom na správu nehnuteľností a Wink:

1. **Odosielanie cien** — Váš channel manager posiela aktualizácie cien do Wink. Keď aktualizujete ceny vo vašom PMS, tieto zmeny sa automaticky prejavia vo Wink.
2. **Synchronizácia dostupnosti** — Váš channel manager posiela aktualizácie dostupnosti do Wink. Keď sú izby rezervované alebo uvoľnené vo vašom PMS, inventár vo Wink sa aktualizuje v reálnom čase.
3. **Upozornenia o rezerváciách** — Keď je vo Wink vytvorená rezervácia, váš channel manager je o tom informovaný, aby sa rezervácia zobrazila vo vašom PMS.

## Podporovaní channel manageri

Wink momentálne integruje nasledujúce systémy:

| Channel Manager | Popis |
|---|---|
| **Channex** | Globálna platforma pre distribúciu a správu kanálov. |
| **TravelClick** | Hotelové riešenia a správa kanálov (Amadeus). |
| **Omnibees** | Distribúcia a riadenie príjmov pre hotely. |
| **D-Edge** | Technológie pre pohostinstvo a riešenia centrálnej rezervácie. |
| **Allotz** | Alokácia inventára a správa kanálov. |
| **Ezee / Yanolja** | Cloudové PMS a správa kanálov zameraná na ázijský trh. |
| **RateGain** | Technológia pre inteligenciu cien a distribúciu. |
| **RateTiger** | Distribúcia cien a dostupnosti v reálnom čase. |
| **CloudBeds** | Cloudové PMS, channel manager a rezervačný engine. |
| **SiteMinder** | Vedúci hotelový channel manager a distribučná platforma. |
| **Exely** | Synchronizácia cien a dostupnosti pre hotely. |

:::note
Ak váš channel manager nie je na zozname, kontaktujte tím Wink. Nové integrácie môžu byť pridané na základe štandardov protokolu OTA (Open Travel Alliance), ktoré Wink podporuje.
:::
