Prepojením svojej služby Google Analytics 4 s Wink sa vaše udalosti rezervácií — od zobrazení izieb až po dokončené rezervácie — automaticky odosielajú do vášho vlastného GA4 panela spolu s vlastnou analytikou Wink. Žiadny kód, žiadne technické nastavenie na vašej strane.

<Aside type="tip">
Potrebujete dve veci z GA4: **Measurement ID** a **Measurement Protocol API secret**. Measurement ID poháňa prehliadací funnel v prehliadači hosťa; API secret umožňuje Wink zaznamenávať dokončené rezervácie (`purchase`) **na strane servera**, takže sa predaj nikdy nestratí, keď je hosť presmerovaný k poskytovateľovi platby a späť.
</Aside>

---

## Ako to funguje

```
Zadáte svoje Measurement ID (G-XXXXXXXXXX) a API secret do portálu Wink
       ↓
Prehliadacie udalosti (zobrazenia, košík, pokladňa) sa z prehliadača odosielajú do vašej GA4 služby
Dokončené rezervácie (purchase) sa odosielajú na strane servera — prežijú presmerovanie platby
       ↓
Prihlásite sa na analytics.google.com a vidíte celý svoj funnel rezervácií
```

---

## Čo musíte urobiť

<Steps>

1. **Vytvorte GA4 službu**

   Prejdite na [analytics.google.com](https://analytics.google.com): Admin → Vytvoriť službu. Nastavte svoj časový pásmo a menu podľa svojho trhu.

2. **Vytvorte Web Data Stream**

   Admin → Data Streams → Pridať stream → Web. Zadajte `wink.travel` ako URL. Tým sa vygeneruje vaše **Measurement ID** (`G-XXXXXXXXXX`). Skopírujte ho.

3. **Vytvorte Measurement Protocol API Secret**

   Otvorte ten istý Web Data Stream → posuňte sa na **Measurement Protocol API secrets** → **Vytvoriť**. Pomenujte ho (napr. "Wink") a skopírujte vygenerovanú **hodnotu secret**. Tento secret umožňuje Wink zaznamenávať dokončené rezervácie na strane servera, takže sa predaj nikdy nestratí počas presmerovania platby.

4. **Zadajte svoje Measurement ID a API Secret do portálu Wink**

   Prihláste sa na [app.wink.travel](https://app.wink.travel), vyberte svoj účet a prejdite na kartu **Customizations**. Vložte svoje Measurement ID a API secret do polí **GA4** a uložte. To je všetko — vaša integrácia GA4 je teraz aktívna.

   <Aside type="note">
   API secret je **len na zápis**: po uložení sa už nikdy nezobrazí. Pri ďalších úpravách nechajte pole secret prázdne, aby ste zachovali už uloženú hodnotu.
   </Aside>

5. **Označte `purchase` ako kľúčovú udalosť**

   Vráťte sa do svojej GA4 služby: Admin → Udalosti → nájdite `purchase` → zapnite **Označiť ako kľúčovú udalosť**. Tým sa dokončené rezervácie zobrazia vo vašej správe Konverzie.

6. **Prezrite si svoje dáta**

   Prihláste sa na [analytics.google.com](https://analytics.google.com) a uvidíte svoje rezervácie, príjmy a funnel hosťa — všetko automaticky sledované cez Wink.

</Steps>

<Aside type="note">
Na túto integráciu nemusíte inštalovať žiadny sledovací kód na svojej webovej stránke. O všetko sa postará Wink. Vaše Measurement ID je cieľ, kam sa odosielajú dáta o rezerváciách, a váš API secret umožňuje Wink potvrdiť dokončené rezervácie na strane servera.
</Aside>

<Aside type="tip">
**GA4 a GTM môžu byť použité spolu.** Ak prevádzkujete aj Google Tag Manager kontajner (napríklad Sojern kontajner), môžete ich konfigurovať súčasne — už nie sú vzájomne vylučujúce. Pozrite si [GTM Analytics Integration](/sk/guides/developers/gtm-dual-tagging).
</Aside>

## Čo môžete sledovať

Po prepojení vaša GA4 služba prijíma kompletnú sadu udalostí Enhanced E-commerce pre vašu nehnuteľnosť:

### Objavovanie

| Udalosť | Význam |
|---|---|
| `view_item_list` | Hosť videl vašu nehnuteľnosť vo vyhľadávaní alebo kategórii |
| `select_item` | Hosť klikol na vašu nehnuteľnosť zo zoznamu |
| `view_item` | Hosť si pozrel detailnú stránku hotela |

### Zvažovanie

| Udalosť | Význam |
|---|---|
| `view_promotion` | Hosť videl propagačnú ponuku vašej nehnuteľnosti |
| `select_promotion` | Hosť klikol na propagačnú ponuku |
| `add_to_wishlist` | Hosť si uložil vašu nehnuteľnosť do zoznamu želaní |

### Funnel rezervácie

| Udalosť | Význam |
|---|---|
| `add_to_cart` | Hosť vybral izbu alebo balík |
| `view_cart` | Hosť si pozrel súhrn rezervácie |
| `remove_from_cart` | Hosť odstránil izbu alebo balík |
| `begin_checkout` | Hosť začal proces pokladne |
| `add_payment_info` | Hosť zadal platobné údaje |
| `add_shipping_info` | Hosť zadal svoje údaje |
| `purchase` | Hosť dokončil rezerváciu |
| `refund` | Rezervácia bola zrušená a vrátená |

Všetky udalosti obsahujú relevantné dimenzie ako príjmy, menu, typ izby a hodnotu rezervácie — čo vám poskytuje kompletný obraz cesty hosťa od prvého dojmu až po dokončenú rezerváciu. Pre odomknutie ďalších dimenzií na úrovni nehnuteľnosti a izby, ako sú `city_name`, `cancellation_policy`, `bed_type` a ďalšie, pozrite si [Custom Dimensions in GA4](/sk/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4).

## Sledovanie cez viaceré domény (pokročilé)

Štandardná integrácia vyššie sleduje všetko, čo sa deje v rámci Wink. Ak však chcete sledovať hostí od vašej vlastnej webovej stránky až po dokončenie rezervácie na Wink — a správne pripísať pôvodný zdroj návštevnosti (Google Ads, e-mailové kampane, organické vyhľadávanie atď.) — je potrebný ešte jeden krok na každej strane.

<Aside type="caution">
Táto časť platí len v prípade, že máte GA4 nainštalované na svojej vlastnej webovej stránke. Ak GA4 na svojej stránke nepoužívate, štandardná integrácia vyššie vám stačí.
</Aside>

### Prečo je to dôležité

Bez sledovania cez viaceré domény sa hosť, ktorý najprv navštívi vašu webovú stránku a potom rezervuje cez Wink, v GA4 zobrazí ako **Direct** relácia bez spojenia s jeho predchádzajúcou návštevou. Žiadne kliknutia z Google Ads, e-mailové kampane ani organické vyhľadávanie, ktoré viedli k rezervácii, nebudú pripísané.

So správne nastaveným sledovaním cez viaceré domény vidíte kompletnú cestu hosťa:

```
google.com (platená reklama)
       ↓
vaša webová stránka (hosť prehliada izby)
       ↓
wink.travel (hosť vyberá izbu a rezervuje)
       ↓
purchase správne pripísané pôvodnému kliknutiu Google Ads
```

### Čo musíte urobiť: Vy

Nakonfigurujte svoju GA4 službu tak, aby rozpoznala `wink.travel` ako súčasť vašej vlastnej domény, nie ako externý odkaz. To povie GA4, aby spojila dve relácie do jednej kontinuálnej cesty hosťa.

<Steps>
1. GA4 Admin → Data Streams → váš stream
2. Konfigurácia nastavení tagu → **Konfigurujte svoje domény**
3. Pridajte `wink.travel` ako prepojenú doménu
4. Uložte
</Steps>

### Čo musí urobiť Wink

Kontaktujte [Wink Support](https://app.wink.travel) a poskytnite svoju doménu webovej stránky (napr. `yourhotel.com`). Wink pridá vašu doménu do zoznamu vylúčených odkazov v GA4 službe Wink. Tým sa zabráni tomu, aby sa vaša webová stránka zaznamenávala ako zdroj odkazu, čo by inak prepísalo pôvodnú atribúciu hosťa a spustilo novú reláciu.

<Aside type="tip">
Štandardná integrácia vyššie je pre väčšinu nehnuteľností dostatočná a poskytuje okamžitý prehľad o rezerváciách a príjmoch na Wink. Sledovanie cez viaceré domény je pokročilá možnosť, ktorú stojí za to nastaviť, keď budete mať s GA4 dáta pohodlne a chcete hlbší prehľad o atribúcii.
</Aside>
