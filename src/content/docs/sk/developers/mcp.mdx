Wink poskytuje dva overené MCP servery. Oba používajú **interaktívne prihlásenie OAuth2** (PKCE autorizačný kódový tok) — váš AI agent otvorí kartu prehliadača, kde sa prihlásite pomocou svojho Wink účtu. Nie je potrebné spravovať žiadne klientské tajomstvá.

| Server | URL | Čo robí |
|--------|-----|---------|
| **Inventory API** | `https://api.wink.travel/mcp` | Inventár, rezervácie, ceny, predajné kanály, analytika a všetky operácie platformy |
| **Integrations** | `https://integrations.wink.travel/mcp` | Integrácie správcu kanálov — synchronizácia nehnuteľností, cien a dostupnosti s OTA |

---

## Ako funguje overenie

Wink MCP servery používajú **OAuth2 Authorization Code + PKCE** tok a podporujú **Dynamic Client Registration (RFC 7591)**. Takto to prebieha pri prvom pripojení:

1. Váš AI klient zistí autorizačný server z metadát MCP endpointu `/.well-known/oauth-protected-resource`.
2. Klient sa sám zaregistruje cez **Dynamic Client Registration** — nie je potrebné manuálne nastavovať aplikáciu.
3. Klient otvorí **kartu prehliadača** na `https://iam.wink.travel`. Prihlásite sa pomocou Wink účtu a schválite požadované povolenia na obrazovke súhlasu.
4. Wink vydá **prístupový token** viazaný na váš účet a identitu.
5. AI klient pripojí token ku každej MCP požiadavke. Všetky výsledky nástrojov sú automaticky viazané na vašu spravovanú entitu.
6. Tokeny vypršia po 3 hodinách. Váš AI klient ich ticho obnovuje na pozadí bez ďalšieho vyzvania.

Každé volanie nástroja prebieha **pod vašou identitou** — rovnaké pravidlá ACL, ktoré chránia webové rozhranie, platia aj pre AI agenta.

## Pripojte svoj AI klient

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Uistite sa, že máte najnovšiu verziu Claude Code:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Pridajte Wink Inventory MCP server:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code kontaktuje server, zistí autorizačný server a otvorí váš predvolený prehliadač.

4. **Prihláste sa do Wink** a schváľte požiadavku na povolenia na obrazovke súhlasu.

5. Claude Code potvrdí pripojenie. Zadajte `/mcp` pre overenie, že server sa zobrazuje a jeho nástroje sú načítané.
</Steps>

Ak chcete pridať aj Integrations server:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Zdieľajte s tímom]
Pridajte `--scope project` k príkazu `claude mcp add` a Claude Code zapíše URL servera do `.mcp.json` v koreňovom adresári repozitára. Commitnite tento súbor — každý člen tímu sa pri prvom pripojení prihlási cez vlastný prehliadač.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Upravte konfiguračný súbor Claude Desktop:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. Pridajte záznamy MCP serverov:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **Úplne ukončite a reštartujte** Claude Desktop (použite Quit z menu — zatvorenie okna nestačí).

4. Claude Desktop otvorí kartu prehliadača pre každý nový server. Prihláste sa do Wink a schváľte povolenia.

5. Ikona zástrčky v spodnom paneli zobrazuje oba servery ako pripojené.
</Steps>

  </TabItem>
  <TabItem label="OpenAI Codex">

<Steps>
1. Uistite sa, že máte nainštalovaný Codex CLI:
   ```bash
   npm install -g @openai/codex
   ```

2. Otvorte (alebo vytvorte) konfiguračný súbor Codex:
   - **macOS / Linux:** `~/.codex/config.json`
   - **Windows:** `%USERPROFILE%\.codex\config.json`

3. Pridajte záznamy MCP serverov Wink:

   ```json title="~/.codex/config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

4. Spustite Codex. Pri prvom použití Codex otvorí kartu prehliadača na `https://iam.wink.travel`.

5. **Prihláste sa do Wink** a schváľte požadované povolenia.

6. Codex potvrdí pripojenie. Spustite `codex` a požiadajte o zoznam dostupných nástrojov, aby ste overili, že Wink servery sú aktívne.
</Steps>

:::note
Podpora MCP v Codex CLI vyžaduje verziu **1.0** alebo novšiu. Skontrolujte pomocou `codex --version` a aktualizujte príkazom `npm install -g @openai/codex`.
:::

  </TabItem>
  <TabItem label="ChatGPT">

Podpora MCP serverov je dostupná v **ChatGPT desktop aplikácii** pre predplatiteľov Plus, Pro, Team a Enterprise.

<Steps>
1. Stiahnite a nainštalujte [ChatGPT desktop aplikáciu](https://openai.com/chatgpt/download/), ak ju ešte nemáte.

2. Otvorte aplikáciu a kliknite na **ikonu svojho profilu** v pravom hornom rohu, potom vyberte **Nastavenia**.

3. Prejdite na **Konektory** (alebo **MCP Servery** podľa verzie aplikácie) a kliknite na **Pridať**.

4. Zadajte URL Wink Inventory servera:
   ```
   https://api.wink.travel/mcp
   ```
   Potom kliknite na **Pripojiť**.

5. ChatGPT otvorí kartu prehliadača na `https://iam.wink.travel`. **Prihláste sa do Wink** a schváľte povolenia.

6. Opakujte kroky 4–5 pre Integrations server:
   ```
   https://integrations.wink.travel/mcp
   ```

7. Oba servery sa zobrazia v zozname Konektorov. Začnite nový chat — Wink nástroje sú automaticky dostupné.
</Steps>

:::note[Obmedzenie webovej aplikácie]
MCP servery je možné konfigurovať iba v **desktop aplikácii**. Webové rozhranie ChatGPT na chatgpt.com nepodporuje vlastné MCP servery.
:::

  </TabItem>
  <TabItem label="Cursor">

<Steps>
1. Otvorte (alebo vytvorte) konfiguračný súbor Cursor MCP:
   - **macOS / Linux:** `~/.cursor/mcp.json`
   - **Windows:** `%USERPROFILE%\.cursor\mcp.json`

2. Pridajte záznamy MCP serverov Wink:

   ```json title="~/.cursor/mcp.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. Otvorte Cursor. Prejdite na **Nastavenia → Nastavenia Cursor → MCP** a overte, či sa oba servery zobrazujú so zeleným indikátorom stavu. Ak sú červené, kliknite na **Obnoviť**.

4. Cursor otvorí kartu prehliadača na `https://iam.wink.travel`. **Prihláste sa do Wink** a schváľte povolenia.

5. Otvorte chat (`Ctrl+L` / `Cmd+L`) a požiadajte Cursor o zoznam dostupných Wink nástrojov na potvrdenie pripojenia.
</Steps>

:::tip[Konfigurácia viazaná na projekt]
Môžete tiež umiestniť súbor `mcp.json` do koreňa svojho projektu namiesto `~/.cursor/`. Konfigurácia na úrovni projektu má prednosť a sprístupní servery každému členovi tímu, ktorý projekt otvorí v Cursor.
:::

## Referencia rozsahov

Keď schválite obrazovku súhlasu, uvidíte rozpis požiadaviek agenta. Wink zoskupuje povolenia podľa funkčných oblastí:

| Skupina rozsahov | Rozsahy | Čo odomykajú |
|------------------|---------|--------------|
| **MCP transport** | `mcp.read` `mcp.write` `mcp.remove` | Povinné pre pripojenie k MCP serveru |
| **Účet** | `account.read` `account.write` `account.remove` | Správa entít, členov tímu, nastavení, aplikácií |
| **Rezervácia** | `booking.read` `booking.write` `booking.remove` | Vyhľadávanie, zobrazenie, vytvorenie, zrušenie a vrátenie rezervácií |
| **Inventár** | `inventory.read` `inventory.write` `inventory.remove` | Nehnuteľnosti, izby, ceny, vybavenie, dostupnosť |
| **Analytika** | `analytics.read` | Analytika rezervácií, výkaz príjmov, rebríčky |
| **Marketing** | `marketing.read` `marketing.write` `marketing.remove` | Príspevky na sociálnych sieťach, kampane, predajné kanály, promo akcie |
| **Obsah** | `content.read` `content.write` `content.remove` | Multimédiá, skrátené URL, syndikované položky, mapy |
| **Platba** | `payment.read` `payment.write` | Kniha účtov, výplaty, finančné prehľady, výbery |

AI klient žiada iba o rozsahy, ktoré potrebuje. Môžete zamietnuť jednotlivé povolenia na obrazovke súhlasu — nástroje, ktoré vyžadujú zamietnutý rozsah, vrátia chybu pri volaní.

## Riešenie problémov

**Karta prehliadača sa neotvorí**

Váš AI klient možno ešte nepodporuje interaktívny PKCE tok. Overte, či používate aktuálnu verziu:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** aktualizujte cez vstavaný updater aplikácie

**`401 Unauthorized` po prihlásení**

Váš uložený token môže byť neplatný. Odstráňte a znova pridajte server, aby ste spustili nové prihlásenie:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

Pre Claude Desktop a ChatGPT odstráňte server zo nastavení, reštartujte aplikáciu a pridajte ho znova.

**`403 Forbidden` pri volaní konkrétneho nástroja**

Nástroj vyžaduje rozsah, ktorý ste na obrazovke súhlasu neschválili. Znovu pripojte server — obrazovka súhlasu sa zobrazí znova a môžete schváliť chýbajúce povolenie.

**Server sa zobrazuje, ale volania nástrojov vracajú "account not found"**

Ste prihlásení do Wink účtu, ktorý nemá spravovanú entitu. Prejdite na [Wink Portal](https://app.wink.travel) a uistite sa, že váš účet je správne nastavený pred použitím MCP servera.

**Token vyprší počas relácie**

Tokeny sú platné 3 hodiny. Claude Code a Claude Desktop ticho obnovujú tokeny bez prerušenia relácie. Ak sa po dlhšom nečinnom období objavia chyby autentifikácie, zadajte novú správu — klient sa automaticky znovu autentifikuje.

**Codex CLI hlási "MCP server unreachable"**

Skontrolujte, či je váš `~/.codex/config.json` platný JSON (bez záverečných čiark) a či je nastavené `"type": "http"`. Codex vyžaduje HTTP transport pre vzdialené servery; stdio transport je len pre lokálne binárky.

**Menu "Connectors" v ChatGPT chýba**

Podpora MCP vyžaduje verziu ChatGPT desktop aplikácie **1.2024.352** alebo novšiu a aktívne predplatné Plus, Pro, Team alebo Enterprise. Aktualizujte aplikáciu a overte svoj plán v Nastaveniach → Účet.

**Cursor server zobrazuje červenú / "Failed to connect"**

Overte, či je váš `~/.cursor/mcp.json` platný JSON a obsahuje `"type": "http"`. Potom prejdite na **Nastavenia → Nastavenia Cursor → MCP** a kliknite na **Obnoviť**. Ak chyba pretrváva, úplne reštartujte Cursor — zmeny konfigurácie sa nie vždy prejavia bez reštartu.

**Windsurf MCP servery sa nezobrazujú v nastaveniach**

Windsurf vyžaduje úplný reštart (nie len obnovenie okna) na načítanie zmien v `mcp_config.json`. Použite **Súbor → Ukončiť** a znova spustite. Ak servery stále nie sú viditeľné, overte, že máte Windsurf **1.4+** cez **Pomocník → O Windsurf**.

**V Cline nie je viditeľná možnosť "Add Server"**

Správca MCP serverov vyžaduje Cline **2.0** alebo novšiu verziu. Otvorte panel rozšírení VS Code, nájdite Cline a kliknite na **Aktualizovať**, ak je dostupná aktualizácia. Po aktualizácii reštartujte VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
