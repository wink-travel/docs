Nástroje MCP od Wink sú zverejnené ako **toolsety** — zamerané endpointy, z ktorých každý pokrýva jednu úlohu. Pripojíte svoj AI klient k jednému alebo dvom, ktoré zodpovedajú vašej práci, nie ku všetkým.

Každý endpoint používa **interaktívne OAuth2 prihlásenie** (PKCE authorization code flow): váš AI agent otvorí záložku prehliadača, prihlásite sa cez svoj Wink účet a je to. Žiadne spravovanie klientskych tajomstiev.

```bash title="Integrator channel managera sa pripája k jednému endpointu"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="Hotelier spravujúci vlastné ceny sa pripája k inému endpointu"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## Prečo sú nástroje rozdelené do viacerých endpointov

Wink sprístupňuje približne 500 nástrojov. Odovzdať ich všetky agentovi naraz je technicky možné — ale zlý nápad.

**Definície nástrojov stoja kontext.** Každý nástroj, ktorý MCP server ponúka, sa načíta do kontextového okna modelu pred tým, než vykoná akúkoľvek prácu, spolu s jeho popisom a kompletnou schémou parametrov. Päťsto takýchto nástrojov spotrebuje veľkú časť rozpočtu, ktorý vaša skutočná úloha potrebuje, pri každom jednom požiadavku.

**Kvalita výberu klesá so zväčšujúcim sa zoznamom.** Agent vyberajúci z 500 podobne nazvaných nástrojov robí horšie rozhodnutia než agent vyberajúci z 40. Ak integrujete channel manager, približne dvadsať nástrojov je pre vás relevantných; ostatných 480 je šum, ktorý sťažuje nájdenie správneho nástroja.

**Práca je skutočne oddeliteľná.** Niekto, kto synchronizuje dostupnosť z PMS, a niekto, kto spravuje affiliate landing pages, zdieľajú takmer žiadne nástroje. Rozdelenie podľa úlohy znamená, že každé pripojenie nesie slovník jednej úlohy.

<Aside type="caution" title="Toolsety nie sú oprávnenia">
Výber úzkeho toolsetu **neobmedzuje** to, čo váš účet môže robiť, a výber širokého toolsetu neudelí nič navyše. Každý nástroj vynucuje rovnaké oprávnenia účtu ako webové rozhranie, pod vašou prihlásenou identitou. Ak váš účet nemôže zrušiť rezerváciu vo Wink Portáli, agent to tiež nemôže — bez ohľadu na to, ku ktorému endpointu je pripojený.

Vyberajte toolsety pre **zameranie**, nie pre bezpečnosť.
</Aside>

## Adresár endpointov

Dva hostitelia poskytujú toolsety. Počty nástrojov sú približné a časom rastú.

|---|---:|---|

| `/mcp/extranet/rates` | ~44 | Ceny a dostupnosť: obdobia a alokácie cien inventára, cenové plány, hlavné ceny, špeciálne a promo ceny |
| `/mcp/extranet/operations` | ~39 | Prevádzka živej nehnuteľnosti: rezervácie a ich životný cyklus, recenzie hostí a odpovede, kalendárové feedy, plánované úlohy |

### `https://integrations.wink.travel` — integrácie channel managera

Jeden endpoint, pretože tento hostiteľ existuje pre jednu úlohu.

| Endpoint | Nástroje | Čo pokrýva |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | Pripojenie a overenie integrácie channel managera, PMS alebo CRS |

<Aside type="note" title="Integrácia channel managera vs. správa vlastných cien">
Ide o rôzne úlohy pre rôznych ľudí a nezdieľajú endpoint.

**Dodávateľ channel managera, PMS alebo CRS** integruje raz cez `integrations.wink.travel/mcp/channel-manager` a od tej doby vymieňa nehnuteľnosti, ceny, dostupnosť a rezervácie cez túto integráciu. Ten jediný endpoint je celá plocha.

**Hotelier, ktorý mení vlastné ceny ručne**, používa extranetové toolsety na `api.wink.travel` — `/mcp/extranet/rates` a príbuzné. Tie nie sú súčasťou integrácie channel managera a integrátor nemá dôvod sa k nim pripájať.

Správa účtu je tiež na `api.wink.travel`, na `/mcp/settings`. Na hostiteľovi integrácií nie je `/mcp/settings`.
</Aside>

Každý endpoint tiež nesie nástroj `ping`, takže môžete potvrdiť, že spojenie je aktívne pred tým, než požiadate o skutočnú prácu.

## Ktoré toolsety potrebujem?

| Ak ste… | Pripojte sa k |
|---|---|
| **Integrujete channel managera, PMS alebo CRS** | `integrations.wink.travel/mcp/channel-manager` — len tento jeden |
| **Spravujete obsah nehnuteľnosti** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **Spravujete izby a typy izieb** | `/mcp/extranet/facilities` |
| **Spravujete ceny a dostupnosť** | `/mcp/extranet/rates` |
| **Prevádzkujete každodenné rezervácie** | `/mcp/extranet/operations` |
| **Rozširujete distribúciu** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **Budujete affiliate stránky** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **Prevádzkujete link-in-bio stránky** | `/mcp/link-manager` + `/mcp/social` |
| **Rezervujete v mene cestujúcich** | `/mcp/travel-agent` |
| **Zúčtovávate peniaze** | `/mcp/payment` |
| **Budujete rezervačný zážitok** | `/mcp/booking-engine` + `/mcp/reference` |

Začnite s jedným. Pridajte ďalší, keď zistíte, že potrebujete niečo, čo ten prvý nedokáže — každé pripojenie je nezávislé a pridanie jedného nikdy neovplyvní ostatné.

<Aside type="tip" title="Chcete stále všetko?">
`https://api.wink.travel/mcp` a `https://integrations.wink.travel/mcp` zostávajú dostupné a poskytujú **všetky** nástroje na svojom hostiteľovi. Sú užitočné na preskúmanie existujúceho obsahu, ale neodporúčame ich na každodennú prácu: zoznam nástrojov je dostatočne veľký na to, aby zatienil vašu úlohu a zhoršil výber nástrojov agenta. Uprednostnite vyššie uvedené toolsety.
</Aside>

## Ako funguje autentifikácia

Wink MCP servery používajú **OAuth2 Authorization Code + PKCE** flow a podporujú **Dynamic Client Registration (RFC 7591)**. Takto to prebieha pri prvom pripojení:

1. Váš AI klient zistí autorizačný server z metadát MCP endpointu `/.well-known/oauth-protected-resource`.
2. Klient sa sám zaregistruje cez **Dynamic Client Registration** — nie je potrebné manuálne nastavovanie aplikácie.
3. Klient otvorí **záložku prehliadača** na `https://iam.wink.travel`. Prihlásite sa cez svoj Wink účet a schválite požadované oprávnenia na obrazovke súhlasu.
4. Wink vydá **access token** viazaný na váš účet a identitu.
5. AI klient pripojí token ku každému MCP požiadavku. Všetky výsledky nástrojov sú automaticky viazané na vašu spravujúcu entitu.
6. Tokeny expirovali po 3 hodinách. Váš AI klient ich ticho obnovuje na pozadí bez ďalšieho výzvy.

Každé volanie nástroja beží **pod vašou identitou** — rovnaké pravidlá ACL, ktoré chránia webové rozhranie, platia aj pre AI agenta.

## Scopes

Keď schválite obrazovku súhlasu, uvidíte rozpis toho, čo agent žiada. MCP klienti používajú rovnaký slovník oprávnení ako zvyšok platformy — pozrite si kompletný
[referenčný zoznam scope na stránke Autentifikácia](/sk/developers/authentication#scopes).

Dve veci sú špecifické pre MCP:

- **Scopes `mcp.read`, `mcp.write`, `mcp.remove` sú navyše potrebné** na otvorenie MCP transportu. Klient s `mcp.*` scope má prístup ku ktorémukoľvek Wink MCP endpointu, ale každý nástroj, ktorý vyvolá, stále vynucuje scope sekcie endpointu, ktorý obalí (napr. `booking.read`).
- **AI klient žiada len o scopes, ktoré potrebuje.** Môžete na obrazovke súhlasu zamietnuť jednotlivé oprávnenia — nástroje, ktoré vyžadujú zamietnutý scope, vrátia chybu pri vyvolaní.

**Toolsety nič z toho nemenia.** Endpoint, ku ktorému sa pripojíte, rozhoduje, ktoré nástroje sú *zobrazované*, nie čo môžu *robiť*. Pripojenie k `/mcp/payment` neudelí žiadne finančné oprávnenie, ktoré ste už nemali, a pripojenie k `/mcp/reference` nezastaví nástroj, aby vynucoval vlastný scope. Autorizácia sa rozhoduje pri každom volaní nástroja na základe vášho tokenu a oprávnení účtu.

## Riešenie problémov

**Neotvorí sa záložka prehliadača**

Váš AI klient možno ešte nepodporuje interaktívny PKCE flow. Overte, že používate aktuálnu verziu:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** aktualizujte cez vstavaný updater aplikácie

**`401 Unauthorized` po prihlásení**

Váš uložený token môže byť neplatný. Odstráňte a znova pridajte server, aby ste spustili nové prihlásenie:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

Pre Claude Desktop a ChatGPT odstráňte server zo settings, reštartujte aplikáciu a pridajte ho znova.

**`403 Forbidden` pri volaní konkrétneho nástroja**

Nástroj vyžaduje scope, ktorý ste na obrazovke súhlasu neschválili, alebo oprávnenie, ktoré váš účet nemá. Znovu pripojte server — obrazovka súhlasu sa zobrazí znova a môžete schváliť chýbajúce oprávnenie. Ak to stále zlyháva, nástroj potrebuje oprávnenie účtu, ktoré nemáte; pripojenie k inému toolsetu nepomôže, pretože toolsety neudelujú oprávnenia.

**Nástroj, ktorý potrebujem, nie je v zozname**

Pravdepodobne ste pripojení k toolsetu, ktorý túto úlohu nepokrýva. Skontrolujte [adresár endpointov](#endpoint-directory) a pridajte toolset, ktorý ju pokrýva — pripojenia sú nezávislé, takže pridanie jedného nič nemení na ostatných. Ak si nie ste istí, ktorý toolset ho má, dočasne sa pripojte k `https://api.wink.travel/mcp`, nájdite nástroj a potom zistite, ktorý toolset ho obsahuje.

**`404 Not Found` na endpoint toolsetu**

Dôkladne skontrolujte cestu — vnorené toolsety majú dva segmenty (`/mcp/extranet/rates`, nie `/mcp/extranet-rates`), a ploché majú jeden (`/mcp/link-manager`). Neautentifikovaný požiadavok na akúkoľvek cestu pod `/mcp` vráti `401`, nie `404`, takže samotné `401` neznamená, či endpoint existuje.

**Pripojil som sa k `api.wink.travel/mcp/channel-manager` a nič**

Tento endpoint neexistuje. Integrácia channel managera je dostupná iba na `https://integrations.wink.travel/mcp/channel-manager`. Ak potrebujete aj ručne čítať alebo zapisovať vlastné ceny nehnuteľnosti, je to samostatná úloha na samostatnom endpointu — pozrite `/mcp/extranet/rates`.

**Server sa zobrazuje, ale volania nástrojov vracajú "account not found"**

Ste prihlásení do Wink účtu, ktorý nemá spravujúcu entitu. Prejdite na [Wink Portal](https://app.wink.travel) a uistite sa, že váš účet je nastavený pred použitím MCP servera.

**Token vyprší počas relácie**

Tokeny sú platné 3 hodiny. Claude Code a Claude Desktop ticho obnovujú tokeny bez prerušenia relácie. Ak po dlhšom nečinnom období vidíte chyby autentifikácie, napíšte novú správu — klient sa automaticky znovu autentifikuje.

**Codex CLI hlási "MCP server unreachable"**

Skontrolujte, či je váš `~/.codex/config.json` platný JSON (bez záverečných čiark) a či je nastavené `"type": "http"`. Codex vyžaduje HTTP transport pre vzdialené servery; stdio transport je len pre lokálne binárky.

**Menu "Connectors" v ChatGPT chýba**

Podpora MCP vyžaduje verziu desktop aplikácie ChatGPT **1.2024.352** alebo novšiu a aktívne predplatné Plus, Pro, Team alebo Enterprise. Aktualizujte aplikáciu a overte svoj plán v Nastaveniach → Účet.

**Cursor server zobrazuje červenú / "Failed to connect"**

Overte, že váš `~/.cursor/mcp.json` je platný JSON a obsahuje `"type": "http"`. Potom prejdite na **Nastavenia → Nastavenia Cursor → MCP** a kliknite na **Obnoviť**. Ak chyba pretrváva, úplne reštartujte Cursor — zmeny konfigurácie sa nie vždy načítajú bez reštartu.

**Windsurf MCP servery nie sú v nastaveniach**

Windsurf vyžaduje úplný reštart (nie len reload okna) na načítanie zmien v `mcp_config.json`. Použite **Súbor → Ukončiť** a znovu spustite. Ak servery stále nie sú viditeľné, overte, že máte Windsurf **1.4+** cez **Pomocník → O Windsurf**.

**Možnosť "Add Server" v Cline nie je viditeľná**

Manažér MCP serverov vyžaduje Cline **2.0** alebo novší. Otvorte panel rozšírení VS Code, nájdite Cline a kliknite na **Aktualizovať**, ak je dostupná aktualizácia. Po aktualizácii reštartujte VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
