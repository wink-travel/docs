Booking Engine je možné vložiť kamkoľvek. Vyberte si svoj framework alebo CMS a riaďte sa jeho návodom; základné Web Components sú všade rovnaké.

## Hlavné prístupy

- [Web Components](/sk/integrations/web-components/) — vložiteľné prvky, ktoré používa každá integrácia.
- [npm package](/sk/integrations/npm/) — inštalácia do JavaScript build-u.
- [Headless CMS](/sk/integrations/headless/) — renderovanie z akéhokoľvek obsahového backendu.
- [Partner API](/sk/integrations/partner-api/) — plná programová integrácia.
