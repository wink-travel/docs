Alat MCP Wink diterbitkan sebagai **set alat** — titik akhir berfokus, setiap satu merangkumi satu tugasan. Anda menyambungkan klien AI anda ke satu atau dua yang sesuai dengan kerja anda, bukan ke semua.

Setiap titik akhir menggunakan **log masuk OAuth2 interaktif** (aliran kod kebenaran PKCE): ejen AI anda membuka tab pelayar, anda log masuk dengan akaun Wink anda, dan itu sahaja. Tiada rahsia klien untuk diuruskan.

```bash title="Integrator pengurus saluran menyambung ke satu titik akhir"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="Seorang pengurus hotel yang mengurus kadar mereka sendiri menyambung ke titik akhir lain"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## Kenapa alat dibahagikan merentasi titik akhir

Wink mendedahkan kira-kira 500 alat. Memberi semua alat itu kepada ejen sekaligus secara teknikal boleh dilakukan — dan ia adalah idea yang buruk.

**Definisi alat memerlukan konteks.** Setiap alat yang diiklankan oleh pelayan MCP dimuatkan ke dalam tetingkap konteks model sebelum ia melakukan sebarang kerja, bersama dengan penerangan dan skema parameter penuh. Lima ratus alat tersebut menggunakan sebahagian besar bajet yang diperlukan oleh tugasan sebenar anda, pada setiap permintaan.

**Kualiti pilihan menurun apabila senarai bertambah.** Ejen yang memilih dari 500 alat dengan nama yang serupa membuat pilihan yang lebih buruk berbanding yang memilih dari 40. Jika anda mengintegrasi pengurus saluran, kira-kira dua puluh alat relevan untuk anda; baki 480 adalah gangguan yang menyukarkan pencarian alat yang betul.

**Kerja itu benar-benar boleh dipisahkan.** Seseorang yang menyelaraskan ketersediaan dari PMS dan seseorang yang mengurus halaman pendaratan afiliasi hampir tidak berkongsi alat. Pembahagian mengikut tugasan bermakna setiap sambungan membawa kosa kata satu tugasan.

<Aside type="caution" title="Set alat bukan kebenaran">
Memilih set alat yang sempit **tidak** mengehadkan apa yang akaun anda boleh lakukan, dan memilih set yang luas tidak memberikan apa-apa tambahan. Setiap alat menguatkuasakan kebenaran akaun yang sama seperti portal web, di bawah identiti anda yang telah log masuk. Jika akaun anda tidak boleh membatalkan tempahan di Wink Portal, ejen juga tidak boleh — tanpa mengira titik akhir yang disambungkan.

Pilih set alat untuk **fokus**, bukan untuk keselamatan.
</Aside>

## Direktori titik akhir

Dua hos menyediakan set alat. Bilangan alat adalah anggaran dan bertambah dari masa ke masa.

### `https://api.wink.travel` — platform

| Titik Akhir | Alat | Apa yang diliputi |
|---|---:|---|
| `/mcp/extranet/facilities` | ~64 | Inventori boleh ditempah dan di lokasi: bilik tetamu dan jenis bilik, spa, restoran, bilik mesyuarat, aktiviti, tarikan, tempat, barangan lain yang boleh dijual |

| `/mcp/studio/embeds` | ~48 | Menerbitkan inventori terpilih: widget, grid dan grid berperingkat, kad, peta, pautan mendalam ke inventori dan halaman pembekal |

### `https://integrations.wink.travel` — integrasi pengurus saluran

Satu titik akhir, kerana hos ini wujud untuk satu tugasan.

| Titik Akhir | Alat | Apa yang diliputi |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | Menyambung dan mengesahkan integrasi pengurus saluran, PMS atau CRS |

<Aside type="note" title="Mengintegrasi pengurus saluran vs. mengurus kadar sendiri">
Ini adalah tugasan berbeza untuk orang yang berbeza, dan mereka tidak berkongsi titik akhir.

**Vendor pengurus saluran, PMS atau CRS** mengintegrasi sekali melalui `integrations.wink.travel/mcp/channel-manager`, dan selepas itu bertukar hartanah, kadar, ketersediaan dan tempahan melalui integrasi itu. Titik akhir tunggal itu adalah keseluruhan permukaan.

**Pengurus hotel yang mengubah kadar sendiri secara manual** menggunakan set alat extranet di `api.wink.travel` — `/mcp/extranet/rates` dan rakan-rakannya. Ini bukan sebahagian daripada integrasi pengurus saluran dan integrator tidak perlu menyambung ke situ.

Pentadbiran akaun juga di `api.wink.travel`, di `/mcp/settings`. Tiada `/mcp/settings` di hos integrasi.
</Aside>

Setiap titik akhir juga membawa alat `ping`, supaya anda boleh mengesahkan sambungan hidup sebelum memintanya melakukan kerja sebenar.

## Set alat mana yang saya perlukan?

| Jika anda… | Sambungkan ke |
|---|---|
| **Mengintegrasi pengurus saluran, PMS atau CRS** | `integrations.wink.travel/mcp/channel-manager` — hanya ini sahaja |
| **Mengurus kandungan hartanah** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **Mengurus bilik dan jenis bilik** | `/mcp/extranet/facilities` |
| **Mengurus harga dan ketersediaan** | `/mcp/extranet/rates` |
| **Mengendalikan tempahan harian** | `/mcp/extranet/operations` |
| **Mengembangkan pengedaran** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **Membina halaman afiliasi** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **Mengendalikan halaman pautan dalam bio** | `/mcp/link-manager` + `/mcp/social` |
| **Menempah bagi pihak pelancong** | `/mcp/travel-agent` |
| **Menyelaraskan wang** | `/mcp/payment` |
| **Membina pengalaman tempahan** | `/mcp/booking-engine` + `/mcp/reference` |

Mulakan dengan satu. Tambah satu lagi apabila anda mendapati sesuatu yang tidak boleh dilakukan — setiap sambungan adalah bebas, dan menambah satu tidak pernah menjejaskan yang lain.

<Aside type="tip" title="Masih mahu semuanya?">
`https://api.wink.travel/mcp` dan `https://integrations.wink.travel/mcp` kekal tersedia dan menyediakan **semua** alat di hos mereka. Ia berguna untuk meneroka apa yang wujud, tetapi kami tidak mengesyorkannya untuk kerja harian: senarai alat terlalu besar sehingga mengganggu tugasan anda dan menurunkan pemilihan alat ejen. Pilih set alat di atas.
</Aside>

## Cara pengesahan berfungsi

Pelayan MCP Wink menggunakan aliran **OAuth2 Authorization Code + PKCE** dan menyokong **Pendaftaran Klien Dinamik (RFC 7591)**. Berikut adalah apa yang berlaku apabila anda menyambung buat kali pertama:

1. Klien AI anda menemui pelayan kebenaran dari metadata titik akhir MCP `/.well-known/oauth-protected-resource`.
2. Klien mendaftar sendiri melalui **Pendaftaran Klien Dinamik** — tiada persediaan aplikasi manual diperlukan.
3. Klien membuka **tab pelayar** ke `https://iam.wink.travel`. Anda log masuk dengan akaun Wink anda dan meluluskan kebenaran yang diminta pada skrin persetujuan.
4. Wink mengeluarkan **token akses** yang dihadkan kepada akaun anda dan dipautkan kepada identiti anda.
5. Klien AI melampirkan token ke setiap permintaan MCP. Semua hasil alat secara automatik dihadkan kepada entiti pengurusan anda.
6. Token tamat tempoh selepas 3 jam. Klien AI anda menyegarkan secara senyap di latar belakang tanpa perlu meminta lagi.

Setiap panggilan alat dijalankan **di bawah identiti anda** — peraturan ACL yang sama yang melindungi portal web juga terpakai kepada ejen AI.

## Skop

Apabila anda meluluskan skrin persetujuan, anda akan melihat pecahan apa yang ejen minta. Klien MCP menggunakan kosa kata kebenaran yang sama seperti platform lain — lihat rujukan penuh [skop di halaman Pengesahan](/ms/developers/authentication#scopes).

Dua perkara khusus untuk MCP:

- **Skop `mcp.read` `mcp.write` `mcp.remove` juga diperlukan** untuk membuka pengangkutan MCP. Klien yang memegang skop `mcp.*` dibenarkan ke mana-mana titik akhir MCP Wink, tetapi setiap alat yang dipanggil masih menguatkuasakan skop bahagian titik akhir yang dibalutnya (contoh `booking.read`).
- **Klien AI hanya meminta skop yang diperlukan.** Anda boleh menolak kebenaran individu pada skrin persetujuan — alat yang memerlukan skop yang ditolak akan mengembalikan ralat apabila dipanggil.

**Set alat tidak mengubah apa-apa ini.** Titik akhir yang anda sambungkan menentukan alat mana yang *disenaraikan*, bukan apa yang *dibenarkan dilakukan*. Menyambung ke `/mcp/payment` tidak memberikan kebenaran kewangan yang anda tidak ada, dan menyambung ke `/mcp/reference` tidak menghalang alat di situ menguatkuasakan skopnya sendiri. Kebenaran ditentukan setiap panggilan alat, dari token anda dan pemberian akaun anda.

## Penyelesaian Masalah

**Tab pelayar tidak terbuka**

Klien AI anda mungkin belum menyokong aliran PKCE interaktif. Sahkan anda menjalankan versi terkini:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** kemas kini dari pengemas kini terbina dalam aplikasi

**`401 Unauthorized` selepas log masuk**

Token cache anda mungkin sudah lapuk. Buang dan tambah semula pelayan untuk mencetuskan log masuk baru:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

Untuk Claude Desktop dan ChatGPT, buang entri pelayan dari tetapan, mulakan semula aplikasi, dan tambah semula.

**`403 Forbidden` apabila memanggil alat tertentu**

Alat memerlukan skop yang anda tidak luluskan pada skrin persetujuan, atau kebenaran yang akaun anda tidak miliki. Sambung semula pelayan — skrin persetujuan akan muncul semula dan anda boleh luluskan kebenaran yang hilang. Jika masih gagal, alat memerlukan kebenaran akaun yang anda tidak ada; menyambung ke set alat lain tidak membantu, kerana set alat tidak memberikan kebenaran.

**Alat yang saya perlukan tiada dalam senarai**

Anda mungkin disambungkan ke set alat yang tidak meliputi tugasan itu. Semak [direktori titik akhir](#endpoint-directory) dan tambah set alat yang meliputi — sambungan adalah bebas, jadi menambah satu tidak mengubah yang lain. Jika tidak pasti yang mana ada alat itu, sambung sementara ke `https://api.wink.travel/mcp`, cari alat, kemudian lihat set alat mana yang menyenaraikannya.

**`404 Not Found` pada titik akhir set alat**

Periksa laluan dengan teliti — set alat bertingkat mempunyai dua segmen (`/mcp/extranet/rates`, bukan `/mcp/extranet-rates`), dan yang rata satu segmen (`/mcp/link-manager`). Perhatikan bahawa permintaan *tidak diautentikasi* ke mana-mana laluan di bawah `/mcp` mengembalikan `401`, bukan `404`, jadi `401` sahaja tidak memberitahu sama ada titik akhir wujud.

**Saya sambung ke `api.wink.travel/mcp/channel-manager` dan tiada apa**

Titik akhir itu tidak wujud. Integrasi pengurus saluran hanya disediakan dari `https://integrations.wink.travel/mcp/channel-manager`. Jika anda juga perlu baca atau tulis kadar hartanah sendiri secara manual, itu tugasan berasingan pada titik akhir berasingan — lihat `/mcp/extranet/rates`.

**Pelayan muncul tetapi panggilan alat mengembalikan "akaun tidak ditemui"**

Anda log masuk ke akaun Wink yang tiada entiti pengurusan. Pergi ke [Wink Portal](https://app.wink.travel) dan pastikan akaun anda disediakan sebelum menggunakan pelayan MCP.

**Token tamat tempoh semasa sesi**

Token sah selama 3 jam. Claude Code dan Claude Desktop menyegarkan token secara senyap tanpa mengganggu sesi anda. Jika anda lihat ralat pengesahan selepas tempoh tidak aktif lama, taip mesej baru — klien akan mengesahkan semula secara automatik.

**Codex CLI menunjukkan "MCP server unreachable"**

Periksa bahawa `~/.codex/config.json` adalah JSON sah (tiada koma bertindih) dan `"type": "http"` ditetapkan. Codex memerlukan pengangkutan HTTP untuk pelayan jauh; pengangkutan stdio untuk binari tempatan sahaja.

**Menu "Connectors" ChatGPT tiada**

Sokongan MCP memerlukan versi aplikasi desktop ChatGPT **1.2024.352** atau lebih baru dan langganan Plus, Pro, Team, atau Enterprise aktif. Kemas kini aplikasi dan sahkan pelan anda di Settings → Account.

**Pelayan Cursor menunjukkan merah / "Gagal sambung"**

Sahkan `~/.cursor/mcp.json` adalah JSON sah dan mengandungi `"type": "http"`. Kemudian pergi ke **Settings → Cursor Settings → MCP** dan klik **Refresh**. Jika ralat berterusan, mulakan semula Cursor sepenuhnya — perubahan konfigurasi tidak selalu diambil tanpa mulakan semula.

**Pelayan MCP Windsurf tidak disenaraikan dalam tetapan**

Windsurf memerlukan mulakan semula penuh (bukan hanya muat semula tetingkap) untuk mengambil perubahan pada `mcp_config.json`. Gunakan **File → Quit** dan buka semula. Jika pelayan masih tidak muncul, sahkan anda menggunakan Windsurf **1.4+** melalui **Help → About Windsurf**.

**Pilihan "Add Server" Cline tidak kelihatan**

Pengurus pelayan MCP memerlukan Cline **2.0** atau lebih baru. Buka panel Sambungan VS Code, cari Cline, dan klik **Update** jika ada kemas kini. Selepas kemas kini, muat semula VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
