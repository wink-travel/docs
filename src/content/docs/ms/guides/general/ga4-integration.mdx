Dengan menghubungkan properti Google Analytics 4 anda ke Wink, acara tempahan anda — dari paparan bilik hingga tempahan selesai — secara automatik dihantar ke papan pemuka GA4 anda sendiri bersama-sama dengan analitik Wink. Tiada kod, tiada persediaan teknikal di pihak anda.

<Aside type="tip">
Anda memerlukan dua perkara dari GA4: **Measurement ID** dan **Measurement Protocol API secret**. Measurement ID menggerakkan corong pelayaran dalam pelayar tetamu; API secret membolehkan Wink merekod tempahan selesai (`purchase`) **di sisi pelayan**, supaya jualan tidak hilang apabila tetamu dialihkan ke dan dari penyedia pembayaran.
</Aside>

---

## Cara Ia Berfungsi

```
Anda masukkan Measurement ID (G-XXXXXXXXXX) dan API secret dalam portal Wink
       ↓
Acara pelayaran (paparan, troli, pembayaran) dihantar ke properti GA4 anda dari pelayar
Tempahan selesai (purchase) dihantar di sisi pelayan — kekal walaupun selepas pengalihan pembayaran
       ↓
Anda log masuk ke analytics.google.com dan melihat corong tempahan penuh anda
```

---

## Apa Yang Perlu Anda Lakukan

<Steps>

1. **Cipta Properti GA4**

   Pergi ke [analytics.google.com](https://analytics.google.com): Admin → Create Property. Tetapkan zon waktu dan mata wang anda mengikut pasaran anda.

2. **Cipta Aliran Data Web**

   Admin → Data Streams → Add Stream → Web. Masukkan `wink.travel` sebagai URL. Ini akan menjana **Measurement ID** (`G-XXXXXXXXXX`). Salin ia.

3. **Cipta Measurement Protocol API Secret**

   Buka Aliran Data Web yang sama → skrol ke **Measurement Protocol API secrets** → **Create**. Beri nama panggilan (contoh: "Wink") dan salin **nilai rahsia** yang dijana. Rahsia ini membolehkan Wink merekod tempahan selesai di sisi pelayan, supaya jualan tidak hilang semasa pengalihan pembayaran.

4. **Masukkan Measurement ID dan API Secret Anda dalam Portal Wink**

   Log masuk ke [app.wink.travel](https://app.wink.travel), pilih akaun anda, dan pergi ke tab **Customizations**. Tampal Measurement ID dan API secret anda ke dalam medan **GA4** dan simpan. Itu sahaja — integrasi GA4 anda kini aktif.

   <Aside type="note">
   API secret adalah **tulis sahaja**: selepas disimpan ia tidak akan dipaparkan lagi. Untuk suntingan akan datang, biarkan medan rahsia kosong untuk mengekalkan nilai yang sudah disimpan.
   </Aside>

5. **Tandakan `purchase` sebagai Acara Utama**

   Kembali ke properti GA4 anda: Admin → Events → cari `purchase` → togol **Mark as key event**. Ini menjadikan tempahan selesai muncul dalam laporan Penukaran anda.

6. **Lihat Data Anda**

   Log masuk ke [analytics.google.com](https://analytics.google.com) dan anda akan melihat tempahan, pendapatan, dan corong tetamu anda — semua dijejak secara automatik melalui Wink.

</Steps>

<Aside type="note">
Anda tidak perlu memasang sebarang kod penjejakan di laman web anda sendiri untuk integrasi ini. Wink mengendalikan semuanya. Measurement ID anda adalah destinasi di mana data tempahan anda dihantar, dan API secret membolehkan Wink mengesahkan tempahan selesai di sisi pelayan.
</Aside>

<Aside type="tip">
**GA4 dan GTM boleh digunakan bersama.** Jika anda juga menjalankan bekas Google Tag Manager (contohnya bekas Sojern), anda boleh konfigurasikan kedua-duanya serentak — ia tidak lagi saling eksklusif. Lihat [Integrasi GTM Analytics](/ms/guides/developers/gtm-dual-tagging).
</Aside>

## Apa Yang Boleh Anda Jejak

Setelah disambungkan, properti GA4 anda menerima suite penuh acara Enhanced E-commerce untuk properti anda:

### Penemuan

| Acara | Maksudnya |
|---|---|
| `view_item_list` | Tetamu melihat properti anda dalam carian atau senarai kategori |
| `select_item` | Tetamu klik pada properti anda dari senarai |
| `view_item` | Tetamu melihat halaman butiran hotel anda |

### Pertimbangan

| Acara | Maksudnya |
|---|---|
| `view_promotion` | Tetamu melihat tawaran promosi untuk properti anda |
| `select_promotion` | Tetamu klik pada tawaran promosi |
| `add_to_wishlist` | Tetamu menyimpan properti anda ke senarai keinginan mereka |

### Corong Tempahan

| Acara | Maksudnya |
|---|---|
| `add_to_cart` | Tetamu memilih bilik atau pakej |
| `view_cart` | Tetamu melihat ringkasan tempahan mereka |
| `remove_from_cart` | Tetamu membuang bilik atau pakej |
| `begin_checkout` | Tetamu memulakan proses pembayaran |
| `add_payment_info` | Tetamu memasukkan butiran pembayaran mereka |
| `add_shipping_info` | Tetamu memasukkan butiran tetamu mereka |
| `purchase` | Tetamu menyelesaikan tempahan |
| `refund` | Tempahan dibatalkan dan dikembalikan wang |

Semua acara termasuk dimensi berkaitan seperti pendapatan, mata wang, jenis bilik, dan nilai tempahan — memberikan anda gambaran penuh perjalanan tetamu dari impresi pertama hingga tempahan selesai. Untuk membuka dimensi tambahan pada tahap properti dan bilik seperti `city_name`, `cancellation_policy`, `bed_type`, dan lain-lain, lihat [Dimensi Tersuai dalam GA4](/ms/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4).

## Penjejakan Rentas-Domain (Lanjutan)

Integrasi standard di atas menjejak segala yang berlaku dalam Wink. Namun, jika anda mahu menjejak tetamu dari laman web anda sendiri hingga ke penyelesaian tempahan di Wink — dan mengaitkan dengan betul sumber trafik asal (Google Ads, kempen e-mel, carian organik, dll.) — satu langkah tambahan diperlukan di setiap pihak.

<Aside type="caution">
Bahagian ini hanya terpakai jika anda memasang GA4 di laman web anda sendiri. Jika anda tidak menjalankan GA4 di laman anda, integrasi standard di atas sudah mencukupi.
</Aside>

### Kenapa Ini Penting

Tanpa penjejakan rentas-domain, tetamu yang melawat laman web anda dahulu dan kemudian menempah di Wink akan muncul dalam GA4 anda sebagai sesi **Direct** tanpa kaitan dengan lawatan mereka sebelum ini. Sebarang klik Google Ads, kempen e-mel, atau lawatan carian organik yang membawa kepada tempahan tidak akan mendapat kredit.

Dengan penjejakan rentas-domain dikonfigurasikan, anda melihat perjalanan tetamu sepenuhnya:

```
google.com (iklan berbayar)
       ↓
laman web anda (tetamu melayari bilik)
       ↓
wink.travel (tetamu memilih bilik dan menempah)
       ↓
purchase dikaitkan dengan betul kepada klik Google Ads asal
```

### Tindakan Diperlukan: Anda

Konfigurasikan properti GA4 anda untuk mengenal pasti `wink.travel` sebagai sebahagian daripada domain anda sendiri, bukan sebagai rujukan luaran. Ini memberitahu GA4 untuk menggabungkan dua sesi tersebut menjadi satu perjalanan tetamu yang berterusan.

<Steps>
1. GA4 Admin → Data Streams → aliran anda
2. Konfigurasikan tetapan tag → **Configure your domains**
3. Tambah `wink.travel` sebagai domain yang dipautkan
4. Simpan
</Steps>

### Tindakan Diperlukan: Wink

Hubungi [Sokongan Wink](https://app.wink.travel) dan berikan domain laman web anda (contoh: `yourhotel.com`). Wink akan menambah domain anda ke senarai pengecualian rujukan dalam properti GA4 Wink. Ini menghalang laman web anda direkod sebagai sumber rujukan, yang jika tidak akan menulis semula atribusi asal tetamu dan memulakan sesi baru.

<Aside type="tip">
Integrasi standard di atas sudah mencukupi untuk kebanyakan properti dan memberikan anda visibiliti segera ke atas tempahan dan pendapatan di Wink. Penjejakan rentas-domain adalah pilihan lanjutan yang patut disediakan apabila anda sudah selesa dengan data GA4 anda dan mahukan wawasan atribusi yang lebih mendalam.
</Aside>
