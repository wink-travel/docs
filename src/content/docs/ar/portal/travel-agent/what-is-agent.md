الحل الخاص بنا لوكلاء السفر المسجلين هو [Wink Agent](https://agent.wink.travel). إنه بوابة خدمة ذاتية يمكن للوكلاء استخدامها للبحث والحجز نيابةً عن عملائهم وكسب عمولة لأنفسهم على كل حجز.

يمكن لوكلاء السفر الأكثر تقدمًا اختيار التكامل على مستوى API لأغراض معالجة الدفع والمدفوعات خارج منصة Wink.

لدى وكلاء السفر مجموعة فرعية من نفس ميزات البوابة مثل [Studio](/ar/portal/studio/what-is-studio) لذلك لن نغطيها مرة أخرى هنا.

## البحث

اذهب إلى [Search](/ar/portal/studio/search) لتتعلم كيفية البحث عن الفنادق وحجزها.

وإلا، تابع إلى القسم التالي.

## API

يمكن للمطورين الذين يرغبون في إدارة `Travel Agent` التوجه إلى [Developers > API > Travel Agent](/ar/api).
