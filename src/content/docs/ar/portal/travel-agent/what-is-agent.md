يستخدم وكلاء السفر المسجلون نفس البوابة التي يستخدمها الجميع، على [app.wink.travel](https://app.wink.travel)، بحساب وكيل سفر. يقوم الوكلاء بالبحث والحجز نيابةً عن عملائهم ويحصلون على عمولة عن كل حجز. لإعداد حساب، اتبع [البدء كوكالة سفر](/ar/guides/travel-agents/getting-started/).

تعمل الوكالات المعتمدة لتحصيل المدفوعات بنفسها كتاجر مسجل وتتولى معالجة الدفع خارج منصة Wink. يمكن للوكالات التي لديها أنظمتها الخاصة التكامل عبر [Partner API](/ar/integrations/partner-api/).

يمتلك وكلاء السفر مجموعة فرعية من نفس ميزات البوابة مثل [Studio](/ar/portal/studio/what-is-studio) لذلك لن نغطيها مرة أخرى هنا.

## البحث

اذهب إلى [Search](/ar/portal/studio/search) لتتعلم كيفية البحث عن الفنادق وحجزها.

وإلا، تابع إلى القسم التالي.

## API

يمكن للوكالات البحث والحجز عبر [Partner API](/ar/partner-api/partner/)، الذي يحل محل نقاط نهاية REST لوكلاء السفر القديمة.
