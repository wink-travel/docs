## 1. من ينطبق عليه هذا

تنطبق سياسة الاستخدام المقبول ("**AUP**") على كل من يستخدم منصة Wink — المسافرون، الفنادق، الشركاء، المبدعون، المطورون ووكلاء الذكاء الاصطناعي — وتشكل جزءًا من [شروط الخدمة](/ar/terms/). المصطلحات المكتوبة بحروف كبيرة لها المعنى المعطى في الشروط.

## 2. المحتوى المحظور

يجب ألا تقوم بتقديم أو نشر أو نقل أي محتوى:

- غير قانوني، احتيالي، خادع أو مضلل؛
- ينتهك حقوق الملكية الفكرية أو الخصوصية أو الحقوق الأخرى لأي شخص؛
- تشهيري، تحرّضي، كريه، أو يروّج للعنف أو التمييز؛
- فاحش، يستغل أو يعرض القاصرين للخطر، أو ضار أو مرفوض بأي شكل آخر؛
- يحتوي على برمجيات خبيثة، أو روابط لمواد ضارة أو خادعة؛ أو
- يضلل بشأن فندق، سعر، توافر، عرض، أو هويتك أو انتمائك.

## 3. السلوك المحظور

يجب ألا:

- تنتهك أي قانون أو لائحة أو حق طرف ثالث معمول به؛
- تنتحل شخصية أي شخص أو كيان، أو تضلل بشأن انتمائك إلى Wink أو فندق أو أي جهة أخرى؛
- تستخدم المنصة لإرسال رسائل غير مرغوب فيها أو اتصالات غير مرغوبة؛
- تجمع أو تحصد بيانات شخصية عن الآخرين بدون أساس قانوني وموافقة حيثما يلزم؛
- تعيق استخدام مستخدم آخر للمنصة؛ أو
- تستخدم المنصة للمنافسة بشكل غير عادل، بما في ذلك بناء قاعدة بيانات عرض منافسة من بياناتنا.

## 4. سلامة وأمان المنصة

يجب ألا:

- تصل أو تفحص أو تمسح المنصة أو الحسابات أو الأنظمة بدون تفويض، أو تحاول تجاوز المصادقة أو حدود المعدل أو ضوابط الوصول التقنية الأخرى؛
- تدخل برمجيات خبيثة، أو تحاول تعطيل أو تحميل زائد أو إضعاف المنصة (بما في ذلك هجمات حجب الخدمة)؛
- تعكس الهندسة أو تحاول استخراج شفرة المصدر، إلا بالقدر الذي يحظره القانون؛ أو
- تصل إلى بيانات أو حسابات أو حجوزات ليست ملكك.

إذا اكتشفت ثغرة أمنية، أبلغ عنها بمسؤولية إلى **[تأكيد جهة الاتصال الأمنية — مثل security@wink.travel]** ولا تستغلها أو تكشف عنها علنًا قبل أن نعالجها.

## 5. استخدام API وMCP ووكلاء الذكاء الاصطناعي

إذا كنت تستخدم REST API، خادم MCP، SDKs أو تدير وكيل ذكاء اصطناعي، يجب عليك:

- المصادقة حسب المطلوب والحفاظ على سرية بيانات الاعتماد والرموز؛
- استخدام الوصول، النطاقات والموافقات الممنوحة فقط، واحترام حدود المعدل والاستخدام الموثقة؛
- عدم جمع أو تخزين أو حصاد بيانات تتجاوز الوصول الممنوح، وعدم استخدام بيانات المنصة لبناء أو تدريب قاعدة بيانات عرض أو تسعير منافسة **[تأكيد موقفك بشأن تدريب النماذج / إعادة استخدام البيانات وذكره صراحة]**؛
- التأكد من أن وكيل الذكاء الاصطناعي ينشئ الحجوزات ويأخذ الدفع **فقط** بتفويض المسافر المعني، وتظل مسؤولاً عن أفعال الوكيل؛
- عدم تحريف التوافر أو التسعير الحي، أو عرض بيانات قديمة على أنها حالية؛ و
- عدم تجاوز الضوابط التقنية أو الحصص أو النسب.

قد نغير أو نوقف أو نحد أو نلغي وصول API أو MCP أو الوكيل في أي وقت لحماية المنصة أو الفنادق أو المسافرين.

## 6. سلامة الحجوزات والسوق

للحفاظ على سوق عادل وموثوق، يجب ألا:

- تنشئ حجوزات مزيفة أو احتيالية أو تجريبية على النظام الحي، أو تلاعب بالحجوزات لكسب أو تضخيم العمولة؛
- تشارك في حشو الكوكيز، الإحالة الذاتية، النقرات القسرية، أو تنسب أو تصنع النسب بشكل خاطئ؛
- تضلل بشأن فندق، عرضه، أسعاره، المزايا أو التوافر؛ أو
- (كفندق) تنشر عرضًا لا يمكنك الوفاء به، أو تفشل في الوفاء بالحجوزات المؤكدة حسب الشروط المعروضة عند الحجز.

## 7. سلوك الشركاء والمبدعين

إذا كنت تروّج لعروض الفنادق كشريك أو مبدع، يجب عليك:

- الترويج بأمانة وتجنب الادعاءات الكاذبة أو المضللة أو غير المثبتة؛
- الإفصاح بوضوح وبشكل بارز عن العلاقات التجارية والتابعة حسب ما يقتضيه القانون (مثل إرشادات لجنة التجارة الفيدرالية الأمريكية والقواعد المماثلة)؛
- عدم المزايدة على أو استخدام علامات Wink أو الفنادق التجارية في البحث المدفوع أو النطاقات حيثما يُحظر ذلك؛ و
- عدم استخدام البريد المزعج، التحويلات الخادعة، النقرات المحفزة، أو ممارسات أخرى تقلل الثقة أو تنسب الحجوزات بشكل خاطئ.

## 8. البيانات والخصوصية

يجب أن تتعامل مع أي بيانات شخصية تصل إليها عبر المنصة — بما في ذلك بيانات المسافرين أو الضيوف — فقط كما يسمح به [الشروط](/ar/terms/)، و[سياسة الخصوصية](/ar/privacy/) والقانون المعمول به، وأن تستخدمها فقط للغرض الذي شاركت من أجله، وتحافظ على أمانها، ولا تبيعها أو تستخدمها للتسويق غير المرتبط بدون أساس قانوني وأي موافقة مطلوبة.

## 9. التنفيذ

قد نحقق في الانتهاكات المشتبه بها ونتخذ أي إجراء نراه مناسبًا، بما في ذلك إزالة أو تعطيل المحتوى، تقييد أو إلغاء الوصول، حجب أو عكس العمولات، تعليق أو إنهاء الحسابات، والإبلاغ عن الأنشطة غير القانونية للسلطات. قد نتصرف فورًا إذا كان السلوك يشكل خطرًا على المنصة أو الفنادق أو المسافرين أو الآخرين. لا يحد هذا من الحقوق أو العلاجات الأخرى المتاحة لنا بموجب الشروط أو القانون.

## 10. الإبلاغ عن سوء الاستخدام

للإبلاغ عن انتهاك لهذه السياسة، أو محتوى ينتهكها، أو احتيال مشتبه به أو مشكلات أمنية، اتصل بنا على **[تأكيد عنوان الاتصال بسوء الاستخدام — مثل abuse@wink.travel أو legal@wink.travel]**.

## 11. التغييرات على هذه السياسة

قد نقوم بتحديث هذه السياسة من وقت لآخر. سننشر النسخة المحدثة مع تاريخ "آخر تحديث" جديد، ويعتبر استمرارك في استخدام المنصة بعد سريان التغييرات قبولًا لها.
