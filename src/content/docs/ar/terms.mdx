## 2. التعريفات

- **المنصة** — منتجات Wink، المواقع الإلكترونية، التطبيقات والواجهات الموضحة أعلاه.
- **Booking Engine** — طبقة إتمام الحجز والدفع في Wink التي تكمل الحجز، وتأخذ الدفع، وترسل التأكيد وتزامن الحجز.
- **TripPay** — بوابة الدفع والحجز المملوكة لـ Wink. تتم معالجة البطاقات من قبل معالج الدفع الخارجي لدينا، Stripe.
- **الفندق** أو **المورد** — مزود الإقامة الذي يعرض العرض، الأسعار والتوافر على المنصة.
- **الشريك** — عمل تجاري (مثل وكالة سفر، DMC، ناشر أو برنامج ولاء) يوزع العرض الفندقي وقد يكسب عمولة.
- **المبدع** — فرد يروّج للعرض الفندقي لجمهوره من خلال واجهة متجر شخصية أو رابط وقد يكسب عمولة.
- **المطور** — شخص أو عمل يدمج مع المنصة عبر API، خادم MCP أو SDKs.
- **وكيل الذكاء الاصطناعي** — عميل آلي أو مدفوع بالذكاء الاصطناعي معتمد يكتشف العرض ويُنشئ الحجوزات عبر المنصة نيابة عن المستخدم.
- **المسافر** أو **الضيف** — شخص يحجز أو يقيم في فندق عبر المنصة.
- **المحتوى** — أي نصوص، صور، أسعار، قوائم، روابط، أكواد أو مواد أخرى يتم تقديمها أو إتاحتها عبر المنصة.

**توفر Wink التكنولوجيا والبنية التحتية للتجارة.** تربط Wink عرض الفندق بالقنوات التي يمكنها بيعه وتنفذ الحجز والدفع. Wink **ليست** مزود الإقامة، و**ليست** التاجر المسجل للإقامة، و**لا** تعمل كوكالة سفر تقليدية أو منظّم جولات.

يتم إبرام العقد لأي إقامة أو خدمة ذات صلة مباشرة بين **المسافر والفندق**. الفندق مسؤول وحده عن عرضه، وأسعاره، وتوافره، ووصفه، وسياساته (بما في ذلك سياسات الإلغاء والاسترداد)، وعن احترام وتنفيذ الحجوزات. Wink ليست طرفًا في ذلك العقد وليست مسؤولة عن أفعال أو إغفالات أي فندق أو شريك أو مبدع أو مطور أو مسافر.
