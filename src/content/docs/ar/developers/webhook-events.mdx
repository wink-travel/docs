تدرج هذه الصفحة كل حدث ويب هوك يمكنك الاشتراك فيه على Wink. للحصول على تعليمات الإعداد، راجع [دليل تكامل الويب هوك](/ar/developers/webhook-integration) أو [صفحة إدارة الويب هوك](/ar/portal/settings/webhooks).

## كيفية الاشتراك

1. انتقل إلى **التطبيقات > الويب هوك** في بوابتك.
2. أنشئ ويب هوك واختر الأحداث التي تريد استلامها.
3. ترسل Wink طلب HTTP POST إلى نقطة النهاية الخاصة بك في كل مرة يحدث فيها الحدث.

للحصول على خطوات الإعداد الكاملة وأفضل الممارسات، راجع [تكامل الويب هوك](/ar/developers/webhook-integration).

## إدارة أحداث الكيانات

أحداث لإدارة الكيانات (العقارات، الشركات التابعة، الشركات) وإدارتها.

### دورة الحياة

| الحدث | المفتاح | الوصف |
|---|---|---|
| تم إنشاء الكيان | `managing_entity.created` | تم إنشاء كيان إداري جديد. |
| تم حذف الكيان | `managing_entity.deleted` | تم حذف كيان إداري. |
| تم تحديث الحالة | `managing_entity.status.updated` | تغيرت حالة الكيان. |
| قيد المراجعة | `account.under_review` | حساب الكيان قيد المراجعة. |

### الاشتراك

| الحدث | المفتاح | الوصف |
|---|---|---|
| تم توفير الاشتراك | `managing_entity.subscription.provisioned` | تم توفير اشتراك جديد. |
| تم تغيير الاشتراك | `managing_entity.subscription.changed` | تم تغيير خطة الاشتراك. |
| تم تغيير فاتورة الاشتراك | `managing_entity.subscription.invoice.changed` | تم تحديث فاتورة الاشتراك. |

### دورة حياة المدير

| الحدث | المفتاح | الوصف |
|---|---|---|
| تم إضافة مدير | `managing_entity.manager.added` | تم إضافة مدير جديد. |
| تم دعوة مدير | `managing_entity.manager.invited` | تم إرسال دعوة لمدير. |
| تم إزالة مدير | `managing_entity.manager.removed` | تم إزالة مدير. |
| تم قبول المدير | `managing_entity.manager.accepted` | تم قبول دعوة المدير. |
| تم رفض المدير | `managing_entity.manager.rejected` | تم رفض دعوة المدير. |
| تم تعيين المالك | `managing_entity.manager.owner.set` | تم نقل ملكية الكيان. |
| تم تحديث المديرين | `account.managers.update` | تغيرت قائمة المديرين. |

### معلومات الكيان

| تم إنشاء الحجز | `booking.create` | تم إنشاء حجز جديد. |

| طلب التهيئة | `booking.initialize.request` | تم طلب تهيئة الحجز. |
| اكتمال التهيئة | `booking.initialize.complete` | تم الانتهاء من تهيئة الحجز. |

| تم تسجيل الأموال | `booking.funds.ledgered` | تم تسجيل أموال الحجز في الدفتر. |
