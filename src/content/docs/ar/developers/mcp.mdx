أدوات MCP الخاصة بـ Wink منشورة كـ **مجموعات أدوات** — نقاط نهاية مركزة، كل منها يغطي وظيفة واحدة. تقوم بربط عميل الذكاء الاصطناعي الخاص بك بالنقطة أو النقطتين اللتين تتطابقان مع عملك، وليس بكلها.

كل نقطة نهاية تستخدم **تسجيل دخول OAuth2 تفاعلي** (تدفق رمز التفويض PKCE): يفتح وكيل الذكاء الاصطناعي لديك تبويب متصفح، تقوم بتسجيل الدخول بحساب Wink الخاص بك، وهذا كل شيء. لا حاجة لإدارة أسرار العميل.

```bash title="موصل مدير القنوات يتصل بنقطة نهاية واحدة"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="مدير فندق يدير أسعاره الخاصة يتصل بنقطة نهاية أخرى"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## لماذا تم تقسيم الأدوات عبر نقاط نهاية

تكشف Wink عن حوالي 500 أداة. تسليم كل هذه الأدوات لوكيل دفعة واحدة ممكن تقنيًا — ولكنه فكرة سيئة.

**تعريفات الأدوات تستهلك السياق.** كل أداة يعلن عنها خادم MCP تُحمّل في نافذة سياق النموذج قبل أن يقوم بأي عمل، مع وصفها ومخطط المعلمات الكامل. خمسمائة من هذه تستهلك حصة كبيرة من الميزانية التي يحتاجها مهمتك الفعلية، في كل طلب.

**جودة الاختيار تنخفض مع زيادة القائمة.** وكيل يختار من بين 500 أداة ذات أسماء متشابهة يتخذ قرارات أسوأ من وكيل يختار من 40 أداة. إذا قمت بدمج مدير قنوات، فحوالي عشرين أداة ذات صلة بك؛ والباقي 480 أداة هي ضوضاء تجعل العثور على الأداة الصحيحة أصعب.

**العمل قابل للفصل فعليًا.** شخص يزامن التوافر من نظام إدارة الممتلكات (PMS) وشخص آخر ينشئ صفحات هبوط تابعة لا يشتركان تقريبًا في أي أدوات. التقسيم حسب الوظيفة يعني أن كل اتصال يحمل مفردات وظيفة واحدة.

<Aside type="caution" title="مجموعات الأدوات ليست أذونات">
اختيار مجموعة أدوات ضيقة **لا** يقيّد ما يمكن لحسابك القيام به، واختيار مجموعة واسعة لا يمنح أي شيء إضافي. كل أداة تفرض نفس أذونات الحساب كما في بوابة الويب، تحت هويتك المسجلة. إذا لم يكن بإمكان حسابك إلغاء حجز في بوابة Wink، فلن يستطيع الوكيل ذلك أيضًا — بغض النظر عن نقطة النهاية المتصل بها.

اختر مجموعات الأدوات من أجل **التركيز**، وليس من أجل الأمان.
</Aside>

## دليل نقاط النهاية

يخدم مضيفان مجموعات الأدوات. أعداد الأدوات تقريبية وتنمو مع الوقت.

### `https://api.wink.travel` — المنصة

| نقطة النهاية | الأدوات | ما تغطيه |
|---|---:|---|
| `/mcp/extranet/facilities` | ~64 | الجرد القابل للحجز والموجود في الموقع: غرف الضيوف وأنواع الغرف، المنتجعات الصحية، المطاعم، غرف الاجتماعات، الأنشطة، المعالم، الأماكن، عناصر أخرى قابلة للبيع |
| `/mcp/extranet/property` | ~62 | سجل العقار وشروطه التجارية: الملف التعريفي والمحتوى، الإضافات، سياسات الإلغاء، المزايا، الإعلانات |
| `/mcp/settings` | ~60 | إدارة الحساب: ملف تعريف الكيان الإداري والعلامة التجارية، المديرون ومنحهم، التخصيص، الويب هوكس، تفضيلات الإشعارات |
| `/mcp/studio/embeds` | ~48 | نشر الجرد المنسق: الأدوات، الشبكات والشبكات المرتبة، البطاقات، الخرائط، الروابط العميقة إلى الجرد وصفحات الموردين |
| `/mcp/extranet/rates` | ~44 | الأسعار والتوافر: فترات وأسهم أسعار الجرد، خطط الأسعار، الأسعار الرئيسية، الأسعار الخاصة والترويجية |
| `/mcp/extranet/operations` | ~39 | تشغيل عقار حي: الحجوزات ودورة حياتها، مراجعات الضيوف وردودهم، خلاصات التقويم، المهام المجدولة |
| `/mcp/extranet/distribution` | ~37 | أماكن بيع الجرد: قنوات البيع ومعدلات الأسعار، طلبات العلاقة مع التابعين والموردين، التسجيل، التقاط العملاء المحتملين |
| `/mcp/studio/curation` | ~35 | بناء مجموعات قابلة للتسويق: القوائم الثابتة والديناميكية، القوائم المرتبة، عمليات البحث المحفوظة، تجميعات العقارات |
| `/mcp/link-manager` | ~28 | مجموعات الروابط الموزعة، تصميمها، الفئات والوسوم، بالإضافة إلى عناوين URL المختصرة |
| `/mcp/reference` | ~24 | بيانات البحث للقراءة فقط: الدول، العملات وأسعار الصرف، اللغات، المناطق الزمنية، عمليات البحث الجغرافية، تحديد الموقع عبر IP |
| `/mcp/analytics` | ~18 | تحليلات الحجز والإيرادات: نظرات عامة، مخططات خطية، لوحات المتصدرين، أداء التابعين، مقاييس المشاركة |
| `/mcp/payment` | ~18 | العمليات المالية: دفتر الأستاذ، السحوبات وتقديرات الرسوم، تجميعات أموال الحجز |
| `/mcp/booking-engine` | ~17 | مسار التسوق الموجه للمسافر: البحث والبحث المرجعي، عربة التسوق والدفع، قوائم الرغبات، تخصيص الحملات |
| `/mcp/social` | ~17 | الحسابات الاجتماعية المتصلة، النشر والجدولة، قراءة تحليلات المنشورات |
| `/mcp/travel-agent` | ~8 | الحجوزات التي يسهلها الوكيل نيابة عن المسافرين، وتقارير الوكيل |

### `https://integrations.wink.travel` — تكاملات مدير القنوات

نقطة نهاية واحدة، لأن هذا المضيف موجود لوظيفة واحدة.

| نقطة النهاية | الأدوات | ما تغطيه |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | ربط والتحقق من تكامل مدير القنوات، PMS أو CRS |

<Aside type="note" title="تكامل مدير القنوات مقابل إدارة الأسعار الخاصة بك">
هذه وظائف مختلفة لأشخاص مختلفين، ولا يشتركون في نقطة نهاية واحدة.

يقوم **بائع مدير القنوات، PMS أو CRS** بالتكامل مرة واحدة عبر `integrations.wink.travel/mcp/channel-manager`، ومن ثم يتبادل الخصائص، الأسعار، التوافر والحجوزات عبر هذا التكامل. تلك النقطة الوحيدة هي السطح الكامل.

يستخدم **مدير الفندق الذي يغير أسعاره يدويًا** مجموعات أدوات الواجهة الخارجية على `api.wink.travel` — `/mcp/extranet/rates` وما شابه. هذه ليست جزءًا من تكامل مدير القنوات ولا يوجد سبب للموصل للاتصال بها.

إدارة الحساب أيضًا على `api.wink.travel`، في `/mcp/settings`. لا يوجد `/mcp/settings` على مضيف التكاملات.
</Aside>

كل نقطة نهاية تحمل أيضًا أداة `ping`، بحيث يمكنك التأكد من أن الاتصال مباشر قبل طلب عمل حقيقي.

## ما مجموعات الأدوات التي أحتاجها؟

| إذا كنت… | اتصل بـ |
|---|---|
| **تدمج مدير قنوات، PMS أو CRS** | `integrations.wink.travel/mcp/channel-manager` — فقط هذه |
| **تدير محتوى عقار** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **تدير الغرف وأنواع الغرف** | `/mcp/extranet/facilities` |
| **تدير الأسعار والتوافر** | `/mcp/extranet/rates` |
| **تشغل الحجوزات اليومية** | `/mcp/extranet/operations` |
| **تنمي التوزيع** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **تبني صفحات تابعة** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **تشغل صفحات الروابط في السيرة الذاتية** | `/mcp/link-manager` + `/mcp/social` |
| **تحجز نيابة عن المسافرين** | `/mcp/travel-agent` |
| **تسوي الأموال** | `/mcp/payment` |
| **تبني تجربة الحجز** | `/mcp/booking-engine` + `/mcp/reference` |

ابدأ بواحدة. أضف أخرى عندما تجد نفسك تطلب شيئًا لا تستطيع القيام به — كل اتصال مستقل، وإضافة واحدة لا تؤثر على الأخرى.

<Aside type="tip" title="هل تريد كل شيء؟">
`https://api.wink.travel/mcp` و `https://integrations.wink.travel/mcp` تبقيان متاحتين وتخدمان **كل** أداة على مضيفهما. هما مفيدان لاستكشاف الموجود، لكننا لا نوصي بهما للعمل اليومي: قائمة الأدوات كبيرة بما يكفي لتطغى على مهمتك وتقلل من اختيار الأدوات للوكيل. فضّل مجموعات الأدوات أعلاه.
</Aside>

## كيف يعمل التوثيق

تستخدم خوادم MCP الخاصة بـ Wink تدفق **رمز تفويض OAuth2 + PKCE** وتدعم **التسجيل الديناميكي للعميل (RFC 7591)**. هذا ما يحدث عند الاتصال لأول مرة:

1. يكتشف عميل الذكاء الاصطناعي خادم التفويض من بيانات التعريف `/.well-known/oauth-protected-resource` لنقطة نهاية MCP.
2. يقوم العميل بالتسجيل الذاتي عبر **التسجيل الديناميكي للعميل** — لا حاجة لإعداد يدوي للتطبيق.
3. يفتح العميل **تبويب متصفح** إلى `https://iam.wink.travel`. تقوم بتسجيل الدخول بحساب Wink الخاص بك وتوافق على الأذونات المطلوبة في شاشة الموافقة.
4. تصدر Wink **رمز وصول** مرتبط بحسابك وهويتك.
5. يرفق عميل الذكاء الاصطناعي الرمز بكل طلب MCP. كل نتائج الأدوات تُقيّد تلقائيًا بكيان الإدارة الخاص بك.
6. تنتهي صلاحية الرموز بعد 3 ساعات. يقوم عميل الذكاء الاصطناعي بتحديثها بصمت في الخلفية دون طلب منك مرة أخرى.

كل استدعاء أداة يعمل **تحت هويتك** — نفس قواعد ACL التي تحمي بوابة الويب تنطبق على وكيل الذكاء الاصطناعي.

## اربط عميل الذكاء الاصطناعي الخاص بك

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. تأكد من تحديث Claude Code:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. اختر مجموعة أدوات من [الدليل أعلاه](#endpoint-directory) وأضفها. على سبيل المثال، الأسعار والتوافر:
   ```bash
   claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
   ```

3. يتصل Claude Code بالخادم، يكتشف خادم التفويض، ويفتح متصفحك الافتراضي.

4. **سجّل الدخول إلى Wink** ووافق على طلب الأذونات في شاشة الموافقة.

5. يؤكد Claude Code الاتصال. اكتب `/mcp` للتحقق من ظهور الخادم وتحميل أدواته.
</Steps>

أضف عددًا من مجموعات الأدوات حسب حاجة عملك — كل منها إدخال خادم منفصل باسمه الخاص:
```bash
claude mcp add wink-operations https://api.wink.travel/mcp/extranet/operations --transport http
claude mcp add wink-analytics  https://api.wink.travel/mcp/analytics           --transport http
```

تسجل الدخول مرة واحدة فقط. بعد الموافقة الأولى في المتصفح، يعيد Claude Code استخدام جلسة Wink الخاصة بك لنقاط نهاية Wink الإضافية.

:::tip[شارك مع فريقك]
أضف `--scope project` إلى `claude mcp add` ويكتب Claude Code عنوان URL للخادم في `.mcp.json` في جذر المستودع. قم بعمل commit لذلك الملف — يحصل كل عضو في الفريق على نفس مجموعات الأدوات، ويكمل كل منهم تسجيل الدخول في المتصفح عند الاتصال لأول مرة.
:::

دعم خوادم MCP متاح في **تطبيق ChatGPT لسطح المكتب** لمشتركي Plus وPro وTeam وEnterprise.

<Steps>
1. حمّل وثبّت [تطبيق ChatGPT لسطح المكتب](https://openai.com/chatgpt/download/) إذا لم تكن قد فعلت ذلك.

2. افتح التطبيق وانقر على **أيقونة ملفك الشخصي** في الزاوية العلوية اليمنى، ثم اختر **الإعدادات**.

3. اذهب إلى **الموصلات** (أو **خوادم MCP** حسب إصدار التطبيق) وانقر **إضافة**.

4. أدخل عنوان URL لمجموعة أدوات من [الدليل أعلاه](#endpoint-directory)، على سبيل المثال:
   ```
   https://api.wink.travel/mcp/extranet/rates
   ```
   ثم انقر **اتصال**.

5. يفتح ChatGPT تبويب متصفح إلى `https://iam.wink.travel`. **سجّل الدخول إلى Wink** ووافق على الأذونات.

6. كرر الخطوتين 4–5 لأي مجموعة أدوات أخرى يحتاجها عملك، على سبيل المثال:
   ```
   https://api.wink.travel/mcp/extranet/operations
   ```

7. تظهر كل مجموعة أدوات في قائمة الموصلات الخاصة بك. ابدأ محادثة جديدة — أدوات Wink متاحة تلقائيًا.
</Steps>

:::note[قيود تطبيق الويب]
خوادم MCP قابلة للتكوين فقط في **تطبيق سطح المكتب**. واجهة الويب ChatGPT على chatgpt.com لا تدعم خوادم MCP المخصصة.
:::

   ```json title="~/.codeium/windsurf/mcp_config.json"
       },
       "wink-extranet-operations": {
         "type": "http",
         "url": "https://api.wink.travel/mcp/extranet/operations"
       }
     }
   }
   ```

3. **أعد تشغيل Windsurf بالكامل** (ملف → خروج، ثم أعد الفتح).

4. اذهب إلى **الإعدادات → خوادم MCP** وتحقق من ظهور كلا الخادمين متصلين. يفتح Windsurf تبويب متصفح إلى `https://iam.wink.travel` عند الاستخدام الأول.

5. **سجّل الدخول إلى Wink** ووافق على الأذونات. تتحول الخوادم إلى اللون الأخضر في لوحة الإعدادات بمجرد التوثيق.
</Steps>

:::note
يتطلب دعم MCP في Windsurf الإصدار **1.4** أو أحدث. تحقق عبر **مساعدة → حول Windsurf** وقم بالتحديث من موقع Windsurf إذا لزم الأمر.
:::

  </TabItem>

## الصلاحيات

عند الموافقة على شاشة الموافقة سترى تفصيلًا لما يطلبه الوكيل. يستخدم عملاء MCP نفس مفردات الأذونات كباقي المنصة — راجع المرجع الكامل
[للنطاقات في صفحة التوثيق](/ar/developers/authentication#scopes).

هناك أمران خاصان بـ MCP:

- **النطاقات `mcp.read` و `mcp.write` و `mcp.remove` مطلوبة أيضًا** لفتح نقل MCP. العميل الذي يحمل نطاق `mcp.*` يُسمح له بالوصول إلى أي نقطة نهاية MCP في Wink، لكن كل أداة يستدعيها تفرض نطاق القسم الخاص بنقطة النهاية التي تغلفها (مثل `booking.read`).
- **يطلب عميل الذكاء الاصطناعي فقط النطاقات التي يحتاجها.** يمكنك رفض أذونات فردية في شاشة الموافقة — الأدوات التي تتطلب نطاقًا مرفوضًا سترجع خطأ عند استدعائها.

**مجموعات الأدوات لا تغير أيًا من هذا.** نقطة النهاية التي تتصل بها تحدد الأدوات *المدرجة*، وليس ما يُسمح لها *بفعله*. الاتصال بـ `/mcp/payment` لا يمنح أي إذن مالي لم تكن تملكه، والاتصال بـ `/mcp/reference` لا يمنع أداة هناك من فرض نطاقها الخاص. يتم تحديد التفويض لكل استدعاء أداة، من رمزك ومنح حسابك.

## استكشاف الأخطاء وإصلاحها

**لا يفتح تبويب المتصفح**

قد لا يدعم عميل الذكاء الاصطناعي لديك تدفق PKCE التفاعلي بعد. تحقق من أنك تستخدم إصدارًا حديثًا:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT لسطح المكتب:** حدّث من أداة التحديث المدمجة في التطبيق

**`401 Unauthorized` بعد تسجيل الدخول**

قد يكون رمزك المخزن مؤقتًا قديمًا. قم بإزالة الخادم وإضافته مجددًا لتحفيز تسجيل دخول جديد:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

بالنسبة لـ Claude Desktop وChatGPT، أزل إدخال الخادم من الإعدادات، أعد تشغيل التطبيق، وأضفه مجددًا.

**`403 Forbidden` عند استدعاء أداة معينة**

تتطلب الأداة نطاقًا لم توافق عليه في شاشة الموافقة، أو إذنًا لا يملكه حسابك. أعد الاتصال بالخادم — ستظهر شاشة الموافقة مجددًا ويمكنك الموافقة على الإذن المفقود. إذا استمر الفشل، تحتاج الأداة إلى إذن حساب لا تملكه؛ الاتصال بمجموعة أدوات مختلفة لن يساعد، لأن مجموعات الأدوات لا تمنح أذونات.

**الأداة التي أحتاجها غير موجودة في القائمة**

ربما تكون متصلًا بمجموعة أدوات لا تغطي تلك الوظيفة. تحقق من [دليل نقاط النهاية](#endpoint-directory) وأضف مجموعة الأدوات التي تغطيها — الاتصالات مستقلة، لذا إضافة واحدة لا تغير شيئًا في الأخرى. إذا لم تكن متأكدًا من أيها تحتويها، اتصل مؤقتًا بـ `https://api.wink.travel/mcp`، ابحث عن الأداة، ثم تحقق من مجموعة الأدوات التي تدرجها.

**`404 Not Found` على نقطة نهاية مجموعة أدوات**

تحقق من المسار بعناية — مجموعات الأدوات المتداخلة لها مقطعين (`/mcp/extranet/rates`، وليس `/mcp/extranet-rates`)، والمجموعات المسطحة لها مقطع واحد (`/mcp/link-manager`). لاحظ أن الطلب *غير الموثق* لأي مسار تحت `/mcp` يرجع `401` وليس `404`، لذا `401` وحده لا يخبرك ما إذا كانت نقطة النهاية موجودة.

**اتصلت بـ `api.wink.travel/mcp/channel-manager` ولم أحصل على شيء**

نقطة النهاية هذه غير موجودة. تكامل مدير القنوات يُخدم فقط من `https://integrations.wink.travel/mcp/channel-manager`. إذا كنت تحتاج أيضًا لقراءة أو كتابة أسعار عقار يدويًا، فهذه وظيفة منفصلة على نقطة نهاية منفصلة — انظر `/mcp/extranet/rates`.

**يظهر الخادم لكن استدعاءات الأدوات ترجع "الحساب غير موجود"**

أنت مسجل دخول بحساب Wink لا يملك كيان إدارة. اذهب إلى [بوابة Wink](https://app.wink.travel) وتأكد من إعداد حسابك قبل استخدام خادم MCP.

**تنتهي صلاحية الرمز أثناء الجلسة**

الرموز صالحة لمدة 3 ساعات. يقوم Claude Code وClaude Desktop بتحديث الرموز بصمت دون مقاطعة جلستك. إذا رأيت أخطاء توثيق بعد فترة طويلة من الخمول، اكتب رسالة جديدة — سيعيد العميل التوثيق تلقائيًا.

**Codex CLI يظهر "خادم MCP غير متاح"**

تحقق من أن `~/.codex/config.json` هو JSON صالح (بدون فواصل زائدة) وأن `"type": "http"` مضبوط. يتطلب Codex نقل HTTP للخوادم البعيدة؛ نقل stdio مخصص للبرامج المحلية فقط.

**قائمة "الموصلات" في ChatGPT مفقودة**

يتطلب دعم MCP إصدار تطبيق ChatGPT لسطح المكتب **1.2024.352** أو أحدث واشتراك Plus أو Pro أو Team أو Enterprise نشط. حدّث التطبيق وتحقق من خطتك في الإعدادات → الحساب.

**خادم Cursor يظهر باللون الأحمر / "فشل الاتصال"**

تحقق من أن `~/.cursor/mcp.json` هو JSON صالح ويحتوي على `"type": "http"`. ثم اذهب إلى **الإعدادات → إعدادات Cursor → MCP** وانقر **تحديث**. إذا استمر الخطأ، أعد تشغيل Cursor بالكامل — التغييرات في الإعدادات لا تُلتقط دائمًا بدون إعادة تشغيل.

**خوادم MCP في Windsurf غير مدرجة في الإعدادات**

يتطلب Windsurf إعادة تشغيل كاملة (ليس مجرد إعادة تحميل النافذة) لالتقاط تغييرات `mcp_config.json`. استخدم **ملف → خروج** ثم أعد التشغيل. إذا لم تظهر الخوادم، تأكد من أنك تستخدم Windsurf **1.4+** عبر **مساعدة → حول Windsurf**.

**خيار "إضافة خادم" في Cline غير مرئي**

يتطلب مدير خوادم MCP في Cline الإصدار **2.0** أو أحدث. افتح لوحة امتدادات VS Code، ابحث عن Cline، وانقر **تحديث** إذا كان متاحًا. بعد التحديث، أعد تحميل VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
