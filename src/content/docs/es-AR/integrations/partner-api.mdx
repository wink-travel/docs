La **Partner API** de Wink es la forma autenticada y de mayor rendimiento para que los integradores consulten inventario de viajes reservable — el mismo suministro que alimenta nuestros widgets embebibles y los endpoints públicos de navegación, expuesto como una interfaz programática de primera clase. Mientras que los Web Components gratuitos y los endpoints públicos de navegación están pensados para integraciones ligeras y orientadas a usuarios, la Partner API está diseñada para sistemas que buscan, cotizan y reservan a gran escala. El acceso es autenticado por integrador y facturado según uso, por lo que solo pagás por el tráfico que realmente enviás.

## Planes y precios

El uso se mide en **noches de hotel**: un hotel cotizado para una noche de estadía — *no* una llamada a la API. Una búsqueda que devuelve 20 hoteles para una estadía de 3 noches equivale a 60 noches de hotel en una sola solicitud. Las llamadas de Contenido y Búsqueda (búsqueda de destino y autocompletado) son la excepción: cada una cuesta una unidad por llamada, sin importar lo que devuelva. Los endpoints de cuenta son gratuitos. Los [Precios](/es-AR/pricing/) son la fuente oficial para las tarifas.

## Referencia de la API

Dos interfaces sirven inventario reservable, y corresponden a los dos niveles mencionados:

- **Gratis — API de Consumidor / Motor de Reservas** (REST, `/api/public/**`): anónima, orientada a navegador y widgets. [Explorar la referencia del Motor de Reservas →](/es-AR/api/booking-engine/)
- **Pago — API para Integradores Partners** (**gRPC**, `wink.partner.v1`): autenticada, con medición de uso, diseñada para integración servidor a servidor a gran escala. [Explorar la referencia para Integradores →](/es-AR/partner-api/partner/)

La API para Integradores Partners es gRPC, no REST. Se llama con un cliente generado sobre HTTP/2 en
`partner.wink.travel:443`, pasando un token bearer y la cuenta para la que se realiza la llamada:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

La página de referencia arriba documenta cada servicio, mensaje y estado de error, y el esquema también está
disponible en tiempo de ejecución mediante reflexión del servidor, por lo que `grpcurl`, Postman e Insomnia lo descubren sin
necesidad de descargar nada.

Si preferís generar un cliente con anticipación, los archivos fuente `.proto` están publicados en
[github.com/wink-travel/partner-api-proto](https://github.com/wink-travel/partner-api-proto).

## Cómo funcionan el uso y los límites

### Nivel gratuito

El nivel gratuito está diseñado para que puedas construir, probar y operar con un tráfico de producción modesto sin costo.

- **No hay límite por minuto publicado.** Wink monitorea las tasas de solicitud y puede aplicar límites de uso justo para proteger el servicio. Si recibís un **HTTP 429 (Demasiadas solicitudes)**, esperá la cantidad de segundos indicada en el encabezado `Retry-After` antes de reintentar.
- **Asignación mensual — 10.000 unidades por mes calendario.** La asignación se otorga por cuenta y se reinicia el 1° de cada mes (UTC). Una vez alcanzada, una cuenta que no se haya registrado en la facturación por uso recibe **HTTP 429 hasta el 1° del mes siguiente** — un bloqueo estricto, con encabezado `Retry-After` y un mensaje invitándote a suscribirte al nivel Pago. Una cuenta registrada sigue funcionando y se factura por el uso que exceda la asignación.

El nivel gratuito no incluye Acuerdo de Nivel de Servicio ni soporte prioritario.

### Nivel pago

El nivel pago elimina el techo mensual y te factura solo por lo que usás.

- **Noches de hotel medidas — $0.0001 por noche de hotel.** No hay límite mensual; se factura por volumen real. Wink puede seguir aplicando límites de uso justo para proteger el servicio. Las llamadas de búsqueda e inventario se facturan por noches de hotel cotizadas; las llamadas de Contenido y Búsqueda se facturan una unidad cada una, por lo que agrupar tus solicitudes mantiene la factura baja.

El nivel pago incluye el Acuerdo de Nivel de Servicio descrito abajo — un compromiso de disponibilidad del 99,9% y un objetivo de tiempo de respuesta P95 menor a 500 ms — y soporte prioritario basado en severidad.

## Acuerdo de Nivel de Servicio

_Fecha de vigencia: 5 de julio de 2026 · Versión 1.0_

Este Acuerdo de Nivel de Servicio (el "SLA") establece el compromiso de disponibilidad, créditos de servicio y objetivos de soporte que Wink ("Wink", "nosotros") provee a un cliente ("Cliente", "vos") para la API autenticada Wink Partner (la "Partner API" o "Servicio") en los niveles donde se indica que aplica un SLA. Este SLA está incorporado y regido por el acuerdo entre vos y Wink bajo el cual accedés a la Partner API (el "Acuerdo"), y aplica mientras mantengas una suscripción activa y paga a la Partner API en buen estado. Los términos en mayúscula no definidos aquí tienen el significado que se les da en el Acuerdo.

### 1. Definiciones

1. **"Disponibilidad"** significa los períodos durante los cuales la Partner API está disponible para aceptar y responder exitosamente a solicitudes correctamente formadas y autenticadas.
2. **"Indisponibilidad"** significa cualquier período, medido en minutos, durante el cual la Partner API no responde exitosamente a solicitudes correctamente formadas y autenticadas, excluyendo cualquier período que caiga dentro de las Exclusiones establecidas en la Sección 4. Errores aislados que afectan una fracción insignificante de solicitudes no constituyen, por sí solos, Indisponibilidad.
3. **"Porcentaje de Disponibilidad Mensual"** significa, para un mes calendario dado, el total de minutos en ese mes menos los minutos totales de Indisponibilidad, dividido por el total de minutos en ese mes, expresado como porcentaje.
4. **"Mantenimiento Programado"** significa mantenimiento planificado del Servicio para el cual Wink ha proporcionado aviso previo conforme a la Sección 4.
5. **"Crédito de Servicio"** significa un crédito, calculado como un porcentaje de las tarifas pagadas o pagaderas por vos para la Partner API en el mes calendario afectado, que se aplica contra futuras tarifas de la Partner API como el único y exclusivo remedio por el incumplimiento del Compromiso de Disponibilidad.
6. **"Tiempo de Respuesta"** significa el tiempo transcurrido entre la recepción por parte de Wink de una solicitud correctamente formada y autenticada en el límite del servicio de Wink y el momento en que Wink comienza a devolver la respuesta, excluyendo el tránsito de red y cualquier tiempo del lado del cliente fuera del control de Wink.

### 2. Compromiso de Disponibilidad y Rendimiento

Wink hará esfuerzos comercialmente razonables para mantener la Partner API disponible con un **Porcentaje de Disponibilidad Mensual de al menos 99,9%** durante cada mes calendario del plazo (el "Compromiso de Disponibilidad"). El Compromiso de Disponibilidad se mide en el límite del servicio de Wink y excluye cualquier factor fuera del control razonable de Wink, incluyendo los descritos en la Sección 4. Los sistemas de monitoreo de Wink son la fuente autorizada para medir el Porcentaje de Disponibilidad Mensual y el Tiempo de Respuesta.

Además, Wink apunta a un **Tiempo de Respuesta en el percentil 95 (P95) menor a 500 milisegundos** para solicitudes exitosas, correctamente formadas y autenticadas, medido en el límite del servicio de Wink durante cada mes calendario (el "Objetivo de Rendimiento"). El Objetivo de Rendimiento excluye los factores descritos en la Sección 4, solicitudes que devuelven errores a nivel de aplicación causados por la propia solicitud, y solicitudes por lotes inusualmente grandes o complejas. El Objetivo de Rendimiento es un objetivo de servicio; los Créditos de Servicio en la Sección 3 aplican a incumplimientos del **Compromiso de Disponibilidad** y son el único y exclusivo remedio por deficiencias de disponibilidad.

### 3. Créditos de Servicio

Si el Porcentaje de Disponibilidad Mensual cae por debajo del Compromiso de Disponibilidad en cualquier mes calendario, podés ser elegible para un Crédito de Servicio calculado como un porcentaje de las tarifas de la Partner API pagadas o pagaderas por vos para ese mes, según la siguiente escala:

| Porcentaje de Disponibilidad Mensual | Crédito de Servicio |
|---|---|
| Por debajo de 99,9% pero igual o superior a 99,0% | 10% |
| Por debajo de 99,0% pero igual o superior a 95,0% | 25% |
| Por debajo de 95,0% | 50% |

1. **Reclamar un crédito.** Para recibir un Crédito de Servicio debés presentar un reclamo por escrito a Wink dentro de los **treinta (30) días** posteriores al fin del mes calendario en que ocurrió la deficiencia. El reclamo debe incluir las fechas y horas de cada incidente de Indisponibilidad que estés reclamando y cualquier registro o evidencia razonablemente disponible. Reclamos presentados fuera de este plazo no serán elegibles.
2. **Forma del crédito.** Los Créditos de Servicio aprobados se aplican contra futuras tarifas de la Partner API y no tienen valor en efectivo. No son reembolsos y no se pagarán excepto cuando lo exija la ley aplicable.
3. **Crédito máximo.** El total de Créditos de Servicio otorgados para cualquier mes calendario no excederá el 50% de las tarifas de la Partner API pagadas o pagaderas por vos para ese mes.
4. **Remedio único y exclusivo.** Los Créditos de Servicio son tu **único y exclusivo remedio** por cualquier incumplimiento de Wink al Compromiso de Disponibilidad o cualquier otra deficiencia de disponibilidad de la Partner API.

### 4. Exclusiones

El Compromiso de Disponibilidad y cualquier Crédito de Servicio resultante no aplican, y la Indisponibilidad no incluye, ninguna indisponibilidad, suspensión, degradación o problema de rendimiento que surja o esté relacionado con:

1. **Mantenimiento Programado** para el cual Wink haya dado aviso previo, siempre que dicho aviso se haya dado con un plazo razonable a través de un canal que Wink normalmente usa para comunicarse con los clientes;
2. eventos de **fuerza mayor** u otras causas fuera del control razonable de Wink, incluyendo desastres naturales, actos gubernamentales, fallas de red o servicios públicos, y ataques de denegación de servicio u otros ataques maliciosos;
3. problemas causados por **tus** actos u omisiones, tu equipo, software o red, o por cualquier servicio, producto o proveedor **tercero** que no esté bajo el control directo de Wink;
4. tu **uso indebido del Servicio** o **incumplimiento del Acuerdo**, este SLA, los términos de uso aceptable o los límites de tasa aplicables, incluyendo tráfico que Wink determine razonablemente como excesivo, abuso automatizado o fraudulento; y
5. cualquier **suspensión o terminación** de tu acceso debidamente efectuada bajo el Acuerdo, incluyendo suspensión por falta de pago.

### 5. Soporte y Objetivos de Respuesta

Wink provee soporte para la Partner API durante el horario comercial estándar, excluyendo feriados locales. Wink hará esfuerzos comercialmente razonables para reconocer solicitudes de soporte correctamente enviadas dentro de los siguientes tiempos objetivo de respuesta, basados en la severidad que asignes y que Wink confirme razonablemente:

| Severidad | Descripción | Respuesta inicial objetivo |
|---|---|---|
| **Sev 1 — Crítico** | La Partner API está caída o inutilizable en producción sin solución alternativa. | 4 horas |
| **Sev 2 — Mayor** | Funcionalidad significativa afectada o degradada; existe solución alternativa. | 1 día hábil |
| **Sev 3 — Menor** | Preguntas generales, problemas menores o solicitudes de funciones. | 2 días hábiles |

Los tiempos objetivo de respuesta describen cuándo Wink apunta a hacer **contacto inicial**; no garantizan tiempos de resolución. El soporte prioritario y los objetivos basados en severidad aplican en los niveles donde se indica que están incluidos.

### 6. Datos y Seguridad

Wink mantiene medidas administrativas, técnicas y organizativas comercialmente razonables diseñadas para proteger la confidencialidad, integridad y disponibilidad de los datos procesados a través de la Partner API, y revisa esas medidas periódicamente. El procesamiento de datos personales por parte de Wink está regido por la [Política de Privacidad](/es-AR/privacy) y cualquier término de procesamiento de datos en el Acuerdo. Vos seguís siendo responsable de asegurar tus propias credenciales API, del uso legal de cualquier dato que recuperes y de notificar rápidamente a Wink cualquier sospecha de compromiso de credenciales.

### 7. Limitación de Responsabilidad

Los Créditos de Servicio son el **único y exclusivo remedio** por cualquier indisponibilidad o incumplimiento del Compromiso de Disponibilidad, y se proveen en lugar de cualquier otra responsabilidad derivada de tal incumplimiento. Salvo lo expresamente indicado en este SLA, la Partner API se provee "tal cual está disponible". En la máxima medida permitida por la ley aplicable, la responsabilidad agregada de Wink derivada o relacionada con el Servicio está limitada según lo establecido en el Acuerdo, y Wink no es responsable por daños indirectos, incidentales, especiales, consecuentes o punitivos, ni por pérdida de ganancias, ingresos, datos o buena voluntad, incluso si se le ha advertido de la posibilidad de tales daños.

### 8. Plazo, Cambios y Terminación

Este SLA aplica mientras tengas una suscripción activa a la Partner API en un nivel donde se indique que aplica el SLA. Wink puede actualizar este SLA ocasionalmente; los cambios materiales se comunicarán a través de un canal que Wink normalmente usa para llegar a los clientes, y el uso continuado de la Partner API después de que una actualización entre en vigencia constituye aceptación del SLA actualizado. Este SLA termina automáticamente al terminar o expirar el Acuerdo o tu suscripción a la Partner API. Las secciones que por su naturaleza deben sobrevivir a la terminación — incluyendo la elegibilidad acumulada pero no reclamada para Créditos de Servicio, limitación de responsabilidad y definiciones — sobreviven.
