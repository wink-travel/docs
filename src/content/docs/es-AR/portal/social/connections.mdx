Ya estás conectado a WinkLinks, nuestra herramienta de gestión de enlaces. Conéctate a más de tus redes sociales haciendo clic en `Conectar una red social`.
El proceso te redirigirá a tu red social para aprobar la app `Wink Social` y que pueda publicar contenido en tu nombre.

Una vez conectado, comenzamos a generar contenido para esa red para el próximo mes programado.

:::note
Publicar en WinkLinks siempre es gratis. Las publicaciones generadas para Facebook e Instagram incluyen una cuota mensual gratuita, luego se facturan por publicación realizada — consulta [Precios](/es-AR/getting-started/pricing).
:::

## Plataformas compatibles

| Plataforma | Descripción | Requisitos |
| -- | -- | -- |
| **WinkLinks** | Publicación automática en nuestro avanzado gestor de enlaces | Siempre gratis, sin cuota |
| **Facebook** | Automatiza publicaciones, respuestas a comentarios y mensajes directos | Requiere una Página de Facebook para Empresas |
| **Instagram** | Automatiza publicaciones, respuestas a comentarios y mensajes directos | Requiere una Cuenta Comercial de Instagram vinculada a una cuenta de Facebook |

Cada conexión muestra su estado actual: **Activa**, **Desconectada** o **Suspendida**.

:::note
Creamos y publicamos contenido optimizado para cada red social.
:::
