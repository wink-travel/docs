Wink expone dos servidores MCP autenticados. Ambos usan **inicio de sesión interactivo OAuth2** (flujo de código de autorización PKCE): tu agente de IA abre una pestaña del navegador para que inicies sesión con tu cuenta Wink. No hay secretos de cliente para gestionar.

| Servidor | URL | Qué hace |
|--------|-----|--------------|
| **Inventory API** | `https://api.wink.travel/mcp` | Inventario, reservas, tarifas, canales de venta, analíticas y todas las operaciones de la plataforma |
| **Integrations** | `https://integrations.wink.travel/mcp` | Integraciones con channel manager — sincronizá propiedades, tarifas y disponibilidad con OTAs |

---

## Cómo funciona la autenticación

Los servidores MCP de Wink usan el flujo **OAuth2 Authorization Code + PKCE** y soportan **Dynamic Client Registration (RFC 7591)**. Esto es lo que sucede cuando te conectás por primera vez:

1. Tu cliente de IA descubre el servidor de autorización desde los metadatos `/.well-known/oauth-protected-resource` del endpoint MCP.
2. El cliente se registra automáticamente mediante **Dynamic Client Registration** — no se requiere configuración manual de la aplicación.
3. El cliente abre una **pestaña del navegador** en `https://iam.wink.travel`. Iniciás sesión con tu cuenta Wink y aprobás los permisos solicitados en la pantalla de consentimiento.
4. Wink emite un **token de acceso** vinculado a tu cuenta y a tu identidad.
5. El cliente de IA adjunta el token a cada solicitud MCP. Todos los resultados de las herramientas se limitan automáticamente a tu entidad gestora.
6. Los tokens expiran después de 3 horas. Tu cliente de IA los renueva silenciosamente en segundo plano sin pedir que vuelvas a iniciar sesión.

Cada llamada a una herramienta se ejecuta **bajo tu identidad** — se aplican las mismas reglas de ACL que protegen el portal web para el agente de IA.

## Conectá tu cliente de IA

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Asegurate de que Claude Code esté actualizado:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Agregá el servidor MCP de Wink Inventory:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code contacta al servidor, descubre el servidor de autorización y abre tu navegador predeterminado.

4. **Iniciá sesión en Wink** y aprobá la solicitud de permisos en la pantalla de consentimiento.

5. Claude Code confirma la conexión. Escribí `/mcp` para verificar que el servidor aparece y sus herramientas se hayan cargado.
</Steps>

Para agregar también el servidor Integrations:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Compartí con tu equipo]
Agregá `--scope project` a `claude mcp add` y Claude Code escribirá la URL del servidor en `.mcp.json` en la raíz del repositorio. Commiteá ese archivo — cada miembro del equipo completará su propio inicio de sesión en el navegador la primera vez que se conecte.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Editá el archivo de configuración de Claude Desktop:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. Agregá las entradas de los servidores MCP:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **Cerrá completamente y reiniciá** Claude Desktop (usá la opción Salir del menú — cerrar la ventana no alcanza).

4. Claude Desktop abre una pestaña del navegador para cada servidor nuevo. Iniciá sesión en Wink y aprobá los permisos.

5. El ícono de enchufe en la barra inferior muestra ambos servidores como conectados.
</Steps>

  </TabItem>

2. Abrí (o creá) el archivo de configuración de Codex:
   - **macOS / Linux:** `~/.codex/config.json`
   - **Windows:** `%USERPROFILE%\.codex\config.json`

3. Agregá las entradas de los servidores MCP de Wink:

   ```json title="~/.codex/config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

4. Iniciá Codex. En el primer uso, Codex abre una pestaña del navegador en `https://iam.wink.travel`.

5. **Iniciá sesión en Wink** y aprobá los permisos solicitados.

6. Codex confirma la conexión. Ejecutá `codex` y pedile que liste las herramientas disponibles para verificar que los servidores Wink están activos.
</Steps>

:::note
El soporte MCP de Codex CLI requiere la versión **1.0** o superior. Ejecutá `codex --version` para verificar y `npm install -g @openai/codex` para actualizar.
:::

  </TabItem>
  <TabItem label="ChatGPT">

El soporte para servidores MCP está disponible en la **app de escritorio ChatGPT** para suscriptores Plus, Pro, Team y Enterprise.

<Steps>
1. Descargá e instalá la [app de escritorio ChatGPT](https://openai.com/chatgpt/download/) si aún no lo hiciste.

2. Abrí la app y hacé clic en **tu ícono de perfil** en la esquina superior derecha, luego elegí **Configuración**.

3. Andá a **Conectores** (o **Servidores MCP** según la versión de la app) y hacé clic en **Agregar**.

4. Ingresá la URL del servidor Wink Inventory:
   ```
   https://api.wink.travel/mcp
   ```
   Luego hacé clic en **Conectar**.

5. ChatGPT abre una pestaña del navegador en `https://iam.wink.travel`. **Iniciá sesión en Wink** y aprobá los permisos.

6. Repetí los pasos 4 y 5 para el servidor Integrations:
   ```
   https://integrations.wink.travel/mcp
   ```

7. Ambos servidores aparecen en tu lista de Conectores. Iniciá un chat nuevo — las herramientas Wink estarán disponibles automáticamente.
</Steps>

:::note[Limitación en la app web]
Los servidores MCP solo se pueden configurar en la **app de escritorio**. La interfaz web de ChatGPT en chatgpt.com no soporta servidores MCP personalizados.
:::

  </TabItem>

<Steps>
1. Abrí (o creá) el archivo de configuración MCP de Cursor:
   - **macOS / Linux:** `~/.cursor/mcp.json`
   - **Windows:** `%USERPROFILE%\.cursor\mcp.json`

2. Agregá las entradas de los servidores MCP de Wink:

   ```json title="~/.cursor/mcp.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. Abrí Cursor. Andá a **Configuración → Configuración de Cursor → MCP** y confirmá que ambos servidores aparezcan con indicador de estado verde. Si están en rojo, hacé clic en **Actualizar**.

4. Cursor abre una pestaña del navegador en `https://iam.wink.travel`. **Iniciá sesión en Wink** y aprobá los permisos.

5. Abrí un chat (`Ctrl+L` / `Cmd+L`) y pedile a Cursor que liste las herramientas Wink disponibles para confirmar la conexión.
</Steps>

:::tip[Configuración con alcance de proyecto]
También podés colocar un archivo `mcp.json` en la raíz de tu proyecto en lugar de en `~/.cursor/`. La configuración a nivel proyecto tiene prioridad y hace que los servidores estén disponibles para cada miembro del equipo que abra el proyecto en Cursor.
:::

## Referencia de scopes

Cuando aprobás la pantalla de consentimiento verás un desglose de lo que el agente está solicitando. Wink agrupa los permisos por área funcional:

| Grupo de scopes | Scopes | Qué desbloquean |
|-------------|--------|-----------------|
| **Transporte MCP** | `mcp.read` `mcp.write` `mcp.remove` | Requerido para conectarse a cualquiera de los servidores MCP |
| **Cuenta** | `account.read` `account.write` `account.remove` | Entidades gestoras, miembros del equipo, configuraciones, aplicaciones |
| **Reserva** | `booking.read` `booking.write` `booking.remove` | Buscar, ver, crear, cancelar y reembolsar reservas |
| **Inventario** | `inventory.read` `inventory.write` `inventory.remove` | Propiedades, habitaciones, tarifas, servicios, disponibilidad |
| **Analíticas** | `analytics.read` | Analíticas de reservas, reportes de ingresos, rankings |
| **Marketing** | `marketing.read` `marketing.write` `marketing.remove` | Publicaciones sociales, campañas, canales de venta, promociones |
| **Contenido** | `content.read` `content.write` `content.remove` | Multimedia, URLs acortadas, elementos sindicables, mapas |
| **Pago** | `payment.read` `payment.write` | Libro mayor, pagos, desglose financiero, retiros |

El cliente de IA solicita solo los scopes que necesita. Podés negar permisos individuales en la pantalla de consentimiento — las herramientas que requieran un scope denegado devolverán un error al invocarlas.

## Solución de problemas

**No se abre la pestaña del navegador**

Tu cliente de IA puede no soportar aún el flujo interactivo PKCE. Verificá que estés usando una versión reciente:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** actualizá desde el actualizador incorporado en la app

**`401 Unauthorized` después de iniciar sesión**

Tu token en caché puede estar obsoleto. Eliminá y agregá nuevamente el servidor para forzar un nuevo inicio de sesión:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

Para Claude Desktop y ChatGPT, eliminá la entrada del servidor en la configuración, reiniciá la app y agregala de nuevo.

**`403 Forbidden` al llamar a una herramienta específica**

La herramienta requiere un scope que no aprobaste en la pantalla de consentimiento. Reconectá el servidor — la pantalla de consentimiento aparecerá de nuevo y podrás aprobar el permiso faltante.

**El servidor aparece pero las llamadas a herramientas devuelven "account not found"**

Estás conectado a una cuenta Wink que no tiene una entidad gestora. Entrá a [Wink Portal](https://app.wink.travel) y asegurate de que tu cuenta esté configurada antes de usar el servidor MCP.

**El token expira durante la sesión**

Los tokens son válidos por 3 horas. Claude Code y Claude Desktop renuevan los tokens silenciosamente sin interrumpir tu sesión. Si ves errores de autenticación tras un período largo de inactividad, escribí un nuevo mensaje — el cliente se reautenticará automáticamente.

**Codex CLI muestra "MCP server unreachable"**

Verificá que tu `~/.codex/config.json` sea JSON válido (sin comas finales) y que `"type": "http"` esté configurado. Codex requiere transporte HTTP para servidores remotos; el transporte stdio es solo para binarios locales.

**El menú "Conectores" de ChatGPT no aparece**

El soporte MCP requiere la versión **1.2024.352** o superior de la app de escritorio ChatGPT y una suscripción activa Plus, Pro, Team o Enterprise. Actualizá la app y verificá tu plan en Configuración → Cuenta.

**El servidor Cursor muestra rojo / "Failed to connect"**

Verificá que tu `~/.cursor/mcp.json` sea JSON válido y contenga `"type": "http"`. Luego andá a **Configuración → Configuración de Cursor → MCP** y hacé clic en **Actualizar**. Si el error persiste, reiniciá completamente Cursor — los cambios en la configuración no siempre se detectan sin reiniciar.

**Los servidores MCP de Windsurf no aparecen en la configuración**

Windsurf requiere un reinicio completo (no solo recargar la ventana) para detectar cambios en `mcp_config.json`. Usá **Archivo → Salir** y relanzá. Si los servidores siguen sin aparecer, confirmá que estás en Windsurf **1.4+** vía **Ayuda → Acerca de Windsurf**.

**La opción "Agregar servidor" en Cline no está visible**

El gestor de servidores MCP requiere Cline **2.0** o superior. Abrí el panel de Extensiones de VS Code, buscá Cline y hacé clic en **Actualizar** si hay una actualización disponible. Después de actualizar, recargá VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
