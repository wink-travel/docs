Esta guía te lleva de no tener nada a una integración funcional en unos 30 minutos. Al final tendrás:

- precios en vivo para hoteles en una ciudad, desde la Partner API,
- un enlace de reserva que acredita las reservas a tu cuenta,
- una reserva de prueba y un webhook que te avisa cuando sucede.

Todo sucede en **staging**, nuestro entorno de pruebas. No necesitas pedirnos acceso, y pasar a producción después tampoco requiere aprobación.

## ¿Es esta la guía adecuada para vos?

| Querés… | Empezá acá |
|---|---|
| Mostrar hoteles en tu app, sitio o producto de IA y enviar viajeros a reservar, ganando comisión | **Esta guía** |

## Cómo funciona

Usás la **Partner API** para encontrar hoteles y sus precios en vivo. Cada hotel tiene un `urlName` estable. Lo convertís en un enlace al Wink Booking Engine, `book.wink.travel`, que lleva tus IDs. El viajero reserva y paga ahí, y la reserva se acredita a tu cuenta.

## Antes de empezar

Vas a necesitar:

- [`grpcurl`](https://github.com/fullstorydev/grpcurl), o Postman o Insomnia. La Partner API es gRPC, no REST.
- `curl`.

:::note
Staging se pone en modo suspensión cuando nadie lo usa. La primera llamada después de un período de inactividad puede tardar alrededor de un minuto mientras los servidores se activan.
:::

## Paso 1: Crear una cuenta en staging

Staging es completamente separado de producción, con sus propios inicios de sesión y cuentas.

<Steps>
1. Entrá a [staging-app.wink.travel](https://staging-app.wink.travel), hacé clic en `Sign-In / Register` y registrate.

2. Hacé clic en `Accounts` en la barra lateral izquierda, luego en `Create`, y elegí **I am an Affiliate**. Las reservas que envíes se acreditan a esta cuenta. Mirá [Crear cuenta](/es-AR/portal/create-account/).
</Steps>

## Paso 2: Crear una aplicación

La aplicación le da a tu código sus credenciales.

<Steps>
1. En la tarjeta de tu cuenta, hacé clic en `Actions` > `Manage account`, luego en la pestaña `Applications`.

2. Hacé clic en `Create new application`, poné un nombre y elegí **Machine-to-machine** como tipo de cliente.

3. En scopes, seleccioná **Inventory & rates** (lectura). La Partner API verifica `inventory.read`.

4. Hacé clic en `Create application` y copiá el **Client ID** y el **Client secret**. El secreto se muestra una vez y no se puede recuperar después.
</Steps>

Mirá [Applications](/es-AR/account/applications/) para otros tipos de cliente y scopes.

## Paso 3: Obtener un token de acceso

```bash
curl -X POST https://staging-iam.wink.travel/oauth2/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials" \
  -d "client_id=<YOUR_CLIENT_ID>" \
  -d "client_secret=<YOUR_CLIENT_SECRET>" \
  -d "scope=inventory.read"
```

Guardá el `access_token` de la respuesta:

```bash
export WINK_TOKEN=<access_token>
```

Los tokens expiran. En tu propio código, usá una librería OAuth2 para obtenerlos y renovarlos. Mirá [Autenticación](/es-AR/developers/authentication/).

## Paso 4: Encontrar tu ID de cuenta

Cada llamada a la Partner API indica la cuenta para la que actuás en un encabezado `managing-entity-id`. Listá las cuentas para las que tu token puede actuar:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" \
  -d '{}' \
  staging-partner.wink.travel:443 wink.partner.v1.Accounts/ListAccounts
```

Copiá el `accountId` de la cuenta afiliada del Paso 1:

```bash
export WINK_ACCOUNT_ID=<accountId>
```

## Paso 5: Buscar hoteles en una ciudad

{/* TODO(Yann): confirmar la ciudad de staging del hotel de prueba con disponibilidad, y usarla acá. */}

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" \
  -H "managing-entity-id: $WINK_ACCOUNT_ID" \
  -d '{
    "urlName": "bangkok-thailand",
    "userSession": {
      "itinerary": {
        "startDate": "2026-12-01",
        "nights": 2,
        "room": { "adults": 2 }
      },
      "currencyCode": "USD",
      "languageCode": "en"
    }
  }' \
  staging-partner.wink.travel:443 wink.partner.v1.Search/SearchByCity
```

Usá una fecha de check-in en el futuro; una fecha pasada es rechazada. Cada resultado incluye:

- `name`, `starRating` y `heroImageUrl`, suficiente para mostrar una fila de resultados,
- `roomTypes`, las ofertas en vivo, la habitación más barata primero,
- `urlName`, el slug que necesitás para el enlace de reserva.

Los precios son enteros en unidades menores: dividí por 10 elevado a la `currencyExponent` de la respuesta (2 para USD, así `12500` es $125.00).

¿No conocés el slug de una ciudad? Resolvélos con `wink.partner.v1.Lookup/Search`. Para el contenido completo de una propiedad, usá el servicio `Content`. La [referencia de la Partner API](/es-AR/partner-api/partner/) documenta cada llamada.

## Paso 6: Construir el enlace de reserva

```text
https://staging-book.wink.travel/hotel/<urlName>?client-id=<YOUR_CLIENT_ID>&configuration-id=<YOUR_CUSTOMIZATION_ID>
```

- `<urlName>` es el `urlName` del hotel del Paso 5.
- `client-id` es el Client ID de tu aplicación del Paso 2.
- `configuration-id` es tu ID de personalización: `Manage account` > `Customizations`. Una personalización también define tu branding, idioma y moneda por defecto en la página de reserva.

:::caution
Incluí ambos IDs. Sin ellos la página carga igual, pero con branding por defecto, y **la reserva no se acredita a vos**. Nunca pongas tu client secret en un enlace.
:::

Mirá [Enlazar directamente](/es-AR/booking-engine/features/#linking-directly) para enlazar a la página principal del motor de reservas en lugar de a un solo hotel.

## Paso 7: Hacer una reserva de prueba

Abrí tu enlace, elegí fechas y habitación, y pagá con una [tarjeta de prueba de Stripe](https://docs.stripe.com/testing), por ejemplo `4242 4242 4242 4242` con cualquier fecha de vencimiento futura y cualquier CVC. No se cobra ninguna tarjeta real en staging. Anotá el código de reserva en la página de confirmación; empieza con `WNK`.

## Paso 8: Recibir notificaciones sobre reservas

<Steps>
1. En Portal, andá a `Applications > Webhooks` y agregá un endpoint que acepte solicitudes `POST`.

2. Suscribite a `booking.create`, o dejá la lista de eventos vacía para recibir todo mientras desarrollás.

3. Enviate un evento de prueba, luego hacé otra reserva de prueba y mirá que llegue.
</Steps>

Verificá la firma de cada entrega antes de confiar en ella. Mirá [Integración de Webhooks](/es-AR/developers/webhook-integration/) y el [Catálogo de eventos de Webhook](/es-AR/developers/webhook-events/).

## Paso 9: Pasar a producción

No hay un paso de aprobación para desarrolladores. (Las cuentas de agencias de viajes se certifican primero; ver [más abajo](#booking-as-a-travel-agency).) Cuando tu integración funcione en staging:

<Steps>
1. Creá una cuenta y una aplicación en [app.wink.travel](https://app.wink.travel), como en los Pasos 1 y 2. Las credenciales no se transfieren entre entornos.

2. Quitá `staging-` de cada host:

   | Staging | Producción |
   |---|---|
   | `https://staging-iam.wink.travel` | `https://iam.wink.travel` |
   | `staging-partner.wink.travel:443` | `partner.wink.travel:443` |
   | `https://staging-book.wink.travel` | `https://book.wink.travel` |

3. Buscá nuevamente tu ID de cuenta de producción (Paso 4) y tu ID de personalización (Paso 6). Son diferentes a los de staging.
</Steps>

El uso de la Partner API se mide en noches de hotel, con un cupo mensual gratuito. Mirá [Partner API](/es-AR/integrations/partner-api/) para precios y límites.

## Reservar como agencia de viajes

Si tu cuenta es una agencia de viajes autorizada, no necesitás enviar viajeros a `book.wink.travel`: podés crear reservas directamente con `wink.partner.v1.Booking/CreateBooking` y gestionarlas con las otras llamadas `Booking`. Las demás cuentas envían viajeros al enlace de reserva.

Las cuentas de agencias de viajes están certificadas: Wink revisa el registro de cada agencia antes de que pueda reservar. Las agencias que quieran cobrar a sus clientes directamente, como comerciante registrado, deben reservar a través de la Partner API y obtener la aprobación escrita de Wink. Mirá [Comenzar como agencia de viajes](/es-AR/guides/travel-agents/getting-started/) y la [referencia de la Partner API](/es-AR/partner-api/partner/).
