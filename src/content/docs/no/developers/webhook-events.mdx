Denne siden viser alle webhook-hendelser du kan abonnere på i Wink. For oppsettsinstruksjoner, se [Webhook Integration Guide](/no/developers/webhook-integration) eller [Webhooks management page](/no/portal/settings/webhooks).

## Hvordan abonnere

1. Gå til **Applications > Webhooks** i portalen din.
2. Opprett en webhook og velg hvilke hendelser du vil motta.
3. Wink sender en HTTP POST til endepunktet ditt hver gang hendelsen inntreffer.

For fullstendige oppsettstrinn og beste praksis, se [Webhook Integration](/no/developers/webhook-integration).
