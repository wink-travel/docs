Booking Engine kan legges inn hvor som helst. Velg ditt rammeverk eller CMS og følg veiledningen; de underliggende Web Components er de samme overalt.

## Kjerne-tilnærminger

- [Web Components](/no/integrations/web-components/) — de innebygde elementene som alle integrasjoner bruker.
- [npm package](/no/integrations/npm/) — installer i en JavaScript-build.
- [Headless CMS](/no/integrations/headless/) — gjengi fra hvilken som helst innholds-backend.
- [Partner API](/no/integrations/partner-api/) — full programmatisk integrasjon.
