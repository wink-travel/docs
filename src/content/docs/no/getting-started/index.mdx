Wink er infrastruktur for reiselivshandel. Hoteller kontrollerer sitt eget tilbud og selger direkte via sine nettsider, partner- og skaperkanaler, forbrukeroppdagelse og AI-agenter — og beholder gjesterelasjonen.

Denne seksjonen er orienteringen. Les den i rekkefølge hvis du er ny, eller hopp til det du trenger.

## Start her

- [Intro til Wink](/no/getting-started/how-to-use/) — hva plattformen gjør og hvordan delene henger sammen.
- [Nøkkelfunksjoner](/no/getting-started/key-features/) — funksjonene som er tilgjengelige for hoteller, tilknyttede partnere og utviklere.
- [Registrer deg](/no/getting-started/sign-up/) — opprett en konto og velg riktig kontotype.
- [Prising](/no/getting-started/pricing/) — hva Wink tar betalt for, og hva som er gratis.
