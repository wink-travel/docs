Wink integreres med ledende kanaladministratorer, eiendomsadministrasjonssystemer (PMS) og sentrale reservasjonsystemer (CRS) for å holde prisene og tilgjengeligheten synkronisert på tvers av alle dine salgskanaler.

## Slik fungerer det

Kanaladministrasjonsintegrasjoner muliggjør en toveis dataflyt mellom ditt eiendomsadministrasjonssystem og Wink:

1. **Prisoppdatering** — Din kanaladministrator sender prisoppdateringer til Wink. Når du oppdaterer prisene i ditt PMS, reflekteres disse endringene automatisk på Wink.
2. **Synkronisering av tilgjengelighet** — Din kanaladministrator sender tilgjengelighetsoppdateringer til Wink. Når rom blir booket eller frigjort i ditt PMS, oppdateres Winks inventar i sanntid.
3. **Bookingvarsler** — Når en booking gjøres på Wink, blir din kanaladministrator varslet slik at reservasjonen vises i ditt PMS.

## Støttede kanaladministratorer

Wink integreres for øyeblikket med følgende systemer:

| Kanaladministrator | Beskrivelse |
|---|---|
| **Channex** | Global distribusjons- og kanaladministrasjonsplattform. |
| **TravelClick** | Hotelløsninger og kanaladministrasjon (Amadeus). |
| **Omnibees** | Distribusjon og inntektsstyring for hoteller. |
| **D-Edge** | Teknologi for gjestfrihet og sentrale reservasjonsløsninger. |
| **Allotz** | Inventartildeling og kanaladministrasjon. |
| **Ezee / Yanolja** | Skybasert PMS og kanaladministrasjon med fokus på det asiatiske markedet. |
| **RateGain** | Prisintelligens og distribusjonsteknologi. |
| **RateTiger** | Distribusjon av priser og tilgjengelighet i sanntid. |
| **CloudBeds** | Skybasert PMS, kanaladministrator og bookingsystem. |
| **SiteMinder** | Ledende hotellkanaladministrator og distribusjonsplattform. |
| **Exely** | Synkronisering av priser og tilgjengelighet for hoteller. |

:::note
Hvis din kanaladministrator ikke er oppført, ta kontakt med Wink-teamet. Nye integrasjoner kan legges til basert på OTA (Open Travel Alliance)-protokollstandardene som Wink støtter.
:::
