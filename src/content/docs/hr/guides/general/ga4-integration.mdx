Povezivanjem svoje Google Analytics 4 imovine s Winkom, vaši događaji rezervacija — od pregleda soba do dovršenih rezervacija — automatski se prosljeđuju na vašu vlastitu GA4 nadzornu ploču uz Winkove vlastite analitike. Nema koda, nema tehničkog postavljanja s vaše strane.

<Aside type="tip">
Potrebne su vam dvije stvari iz GA4: **Measurement ID** i **Measurement Protocol API secret**. Measurement ID pokreće pregledni tok u pregledniku gosta; API secret omogućuje Winku da bilježi dovršene rezervacije (`purchase`) **na strani poslužitelja**, tako da se prodaja nikada ne izgubi kada je gost preusmjeren na i s pružatelja plaćanja.
</Aside>

---

## Kako To Radi

```
Unesete svoj Measurement ID (G-XXXXXXXXXX) i API secret u Wink portal
       ↓
Pregledni događaji (pregledi, košarica, naplata) šalju se u vašu GA4 imovinu iz preglednika
Dovršene rezervacije (purchase) šalju se na strani poslužitelja — preživljavajući preusmjeravanje plaćanja
       ↓
Prijavite se na analytics.google.com i vidite cijeli tok rezervacija
```

---

## Što Trebate Učiniti

<Steps>

1. **Napravite GA4 Imovinu**

   Idite na [analytics.google.com](https://analytics.google.com): Admin → Create Property. Postavite svoju vremensku zonu i valutu da odgovaraju vašem tržištu.

2. **Napravite Web Data Stream**

   Admin → Data Streams → Add Stream → Web. Unesite `wink.travel` kao URL. Ovo generira vaš **Measurement ID** (`G-XXXXXXXXXX`). Kopirajte ga.

3. **Napravite Measurement Protocol API Secret**

   Otvorite isti Web Data Stream → skrolajte do **Measurement Protocol API secrets** → **Create**. Dajte mu nadimak (npr. "Wink") i kopirajte generiranu **tajnu vrijednost**. Ova tajna omogućuje Winku da bilježi dovršene rezervacije na strani poslužitelja, tako da se prodaja nikada ne izgubi tijekom preusmjeravanja plaćanja.

4. **Unesite Svoj Measurement ID i API Secret u Wink Portal**

   Prijavite se na [app.wink.travel](https://app.wink.travel), odaberite svoj račun i idite na karticu **Customizations**. Zalijepite svoj Measurement ID i API secret u **GA4** polja i spremite. To je sve — vaša GA4 integracija je sada aktivna.

   <Aside type="note">
   API secret je **samo za pisanje**: jednom spremljen, nikada se više ne prikazuje. Prilikom budućih izmjena, ostavite polje za tajnu prazno da biste zadržali već spremljenu vrijednost.
   </Aside>

5. **Označite `purchase` kao Ključni Događaj**

   Vratite se u svoju GA4 imovinu: Admin → Events → pronađite `purchase` → uključite **Mark as key event**. Time dovršene rezervacije postaju vidljive u vašem izvještaju o konverzijama.

6. **Pogledajte Svoje Podatke**

   Prijavite se na [analytics.google.com](https://analytics.google.com) i vidjet ćete svoje rezervacije, prihode i tok gostiju — sve automatski praćeno putem Winka.

</Steps>

<Aside type="note">
Ne trebate instalirati nikakav kod za praćenje na vlastitoj web stranici za ovu integraciju. Wink se brine o svemu. Vaš Measurement ID je odredište na koje se šalju podaci o rezervacijama, a vaš API secret omogućuje Winku potvrdu dovršenih rezervacija na strani poslužitelja.
</Aside>

<Aside type="tip">
**GA4 i GTM se mogu koristiti zajedno.** Ako također koristite Google Tag Manager kontejner (na primjer Sojern kontejner), možete konfigurirati oba istovremeno — više nisu međusobno isključivi. Pogledajte [GTM Analytics Integration](/hr/guides/developers/gtm-dual-tagging).
</Aside>

## Što Možete Pratiti

Nakon povezivanja, vaša GA4 imovina prima puni paket Enhanced E-commerce događaja za vašu imovinu:

### Otkriće

| Događaj | Što Znači |
|---|---|
| `view_item_list` | Gost je vidio vašu imovinu u pretraživanju ili kategoriji |
| `select_item` | Gost je kliknuo na vašu imovinu s liste |
| `view_item` | Gost je pogledao detaljnu stranicu vašeg hotela |

### Razmatranje

| Događaj | Što Znači |
|---|---|
| `view_promotion` | Gost je vidio promotivnu ponudu za vašu imovinu |
| `select_promotion` | Gost je kliknuo na promotivnu ponudu |
| `add_to_wishlist` | Gost je spremio vašu imovinu na listu želja |

### Tok Rezervacije

| Događaj | Što Znači |
|---|---|
| `add_to_cart` | Gost je odabrao sobu ili paket |
| `view_cart` | Gost je pogledao sažetak rezervacije |
| `remove_from_cart` | Gost je uklonio sobu ili paket |
| `begin_checkout` | Gost je započeo proces naplate |
| `add_payment_info` | Gost je unio podatke o plaćanju |
| `add_shipping_info` | Gost je unio podatke o gostu |
| `purchase` | Gost je dovršio rezervaciju |
| `refund` | Rezervacija je otkazana i vraćen je novac |

Svi događaji uključuju relevantne dimenzije poput prihoda, valute, vrste sobe i vrijednosti rezervacije — dajući vam potpunu sliku putovanja gosta od prvog dojma do dovršene rezervacije. Za otključavanje dodatnih dimenzija na razini imovine i sobe poput `city_name`, `cancellation_policy`, `bed_type` i drugih, pogledajte [Custom Dimensions in GA4](/hr/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4).

## Praćenje Preko Više Domenā (Napredno)

Standardna integracija gore prati sve što se događa unutar Winka. Međutim, ako želite pratiti goste od vaše vlastite web stranice do dovršetka rezervacije na Winku — i ispravno pripisati izvor izvornog prometa (Google Ads, email kampanje, organsko pretraživanje itd.) — potreban je još jedan korak na svakoj strani.

<Aside type="caution">
Ovaj odjeljak vrijedi samo ako imate instaliran GA4 na svojoj web stranici. Ako ne koristite GA4 na svojoj stranici, standardna integracija gore je sve što vam treba.
</Aside>

### Zašto je Ovo Važno

Bez praćenja preko više domena, gost koji prvo posjeti vašu web stranicu, a zatim rezervira na Winku, pojavit će se u vašem GA4 kao **Direct** sesija bez veze s njihovom ranijom posjetom. Bilo koji klikovi na Google Ads, email kampanje ili organska pretraživanja koji su doveli do rezervacije neće dobiti zasluge.

S konfiguriranim praćenjem preko više domena, vidite kompletno putovanje gosta:

```
google.com (plaćeni oglas)
       ↓
vaša web stranica (gost pregledava sobe)
       ↓
wink.travel (gost odabire sobu i rezervira)
       ↓
purchase ispravno pripisan izvornom Google Ads kliku
```

### Potrebna Akcija: Vi

Konfigurirajte svoju GA4 imovinu da prepozna `wink.travel` kao dio vaše vlastite domene, a ne kao vanjski referral. To govori GA4 da spoji dvije sesije u jedno kontinuirano putovanje gosta.

<Steps>
1. GA4 Admin → Data Streams → vaš stream
2. Konfigurirajte postavke oznaka → **Configure your domains**
3. Dodajte `wink.travel` kao povezanu domenu
4. Spremi
</Steps>

### Potrebna Akcija: Wink

Kontaktirajte [Wink Support](https://app.wink.travel) i dostavite svoju domenu web stranice (npr. `yourhotel.com`). Wink će dodati vašu domenu na listu isključenja referala u Wink GA4 imovini. To sprječava da vaša web stranica bude zabilježena kao izvor referala, što bi inače prebrisalo izvornu atribuciju gosta i započelo novu sesiju.

<Aside type="tip">
Standardna integracija gore dovoljna je za većinu imovina i odmah vam daje uvid u rezervacije i prihode na Winku. Praćenje preko više domena je napredna opcija koju vrijedi postaviti kad ste upoznati sa svojim GA4 podacima i želite dublji uvid u atribuciju.
</Aside>
