Možete povezati **bilo koji** Google Tag Manager (GTM) kontejner s Winkom unošenjem njegovog **GTM Container ID** u Wink portal. Nakon povezivanja, vaš kontejner se automatski učitava za vašu nekretninu i izravno čita Winkove događaje rezervacije — pokrivajući cijelo putovanje gosta od pretraživanja do završene rezervacije. Čest slučaj upotrebe je **Sojern** kontejner za retargeting i oglašavanje, ali bilo koji GTM kontejner funkcionira na isti način.

<Aside type="tip">
Ovo pretpostavlja da već imate GTM Container ID (format `GTM-XXXXXXX`). Ako vaš kontejner dolazi od partnera poput Sojerna, zatražite od svog voditelja računa **GTM Container ID** — on se razlikuje od pixel ili tag ID-a. Novi ste u Sojernu? Posjetite [sojern.com/contact](https://www.sojern.com/contact) za početak.
</Aside>

---

## Što trebate učiniti

<Steps>

1. **Nabavite svoj GTM Container ID**

   Nabavite svoj **GTM Container ID** (format `GTM-XXXXXXX`). Ako dolazi od partnera poput Sojerna, zatražite specifično GTM Container ID — on se razlikuje od pixel ili tag ID-a.

2. **Unesite ga u Wink portal**

   Prijavite se na [app.wink.travel](https://app.wink.travel), odaberite svoj račun i idite na karticu **Customizations**. Zalijepite svoj GTM Container ID u polje **GTM** i spremite. Vaša integracija je sada aktivna.

3. **(Opcionalno) Dodajte GA4 Measurement ID + API Secret za server-side kupnju**

   GTM kontejneri se u potpunosti izvršavaju u pregledniku gosta, pa se završena rezervacija može propustiti ako gost zatvori karticu tijekom preusmjeravanja na plaćanje. Ako vaš kontejner učitava **GA4 property** i želite pouzdano bilježiti završene rezervacije, unesite i GA4 **Measurement ID** i **Measurement Protocol API secret** u GTM sekciju. Wink će tada poslati `purchase` za tu property **server-side**, točno kao što je opisano u vodiču [GA4 Analytics Integration](/hr/guides/developers/ga4-dual-tagging). Ostavite prazno ako vam treba samo praćenje u pregledniku.

4. **Potvrdite s vašim pružateljem usluge**

   Ako vaš kontejner dolazi od partnera poput Sojerna, obavijestite svog voditelja računa da je integracija aktivna. Oni mogu provjeriti s njihove strane da se tagovi ispravno aktiviraju na `wink.travel` za vašu nekretninu i da podaci teku u vaš račun.

</Steps>

<Aside type="note">
Ne morate postavljati nikakav pixel kod na vlastitu web stranicu za ovu integraciju. Wink automatski učitava vaš GTM kontejner na svim stranicama gdje je vaša nekretnina aktivna.

Ovo radi za **bilo koji** GTM Container ID — Sojern je samo čest primjer.
</Aside>

## Što Wink radi s naše strane

Za transparentnost, evo što Wink konfigurira da bi ova integracija funkcionirala:

- **Polje za GTM Container ID** dostupno je u kartici Customizations vašeg Wink portala. Kada unesete Container ID, Wink provjerava format (`GTM-XXXXXXX`) i sigurno ga pohranjuje za vašu nekretninu.
- **Na svakoj stranici gdje je vaša nekretnina aktivna** na Wink-u, vaš kontejner se izravno ubacuje u stranicu — dijeleći Winkov vlastiti `window.dataLayer` — tako da se učitava paralelno s Winkovim kontejnerom bez potrebe za dodatnom konfiguracijom. Ovo se događa automatski, bez dodatnog rada Wink tima po nekretnini.
- **Vaš kontejner se učitava asinkrono**, tako da ne utječe na performanse učitavanja stranice za vaše goste.
- **Winkovo vlastito praćenje i vaš kontejner rade paralelno**, čitajući iz istog zajedničkog `dataLayer`. Svaki događaj rezervacije koji Wink prati istovremeno je dostupan vašem kontejneru.
- **Kada vaša nekretnina nije pregledavana** — na primjer, kada gost pregledava drugi hotel na Wink-u — vaš kontejner se ne učitava, pa prima samo podatke relevantne za vašu nekretninu.
- **Ako ste unijeli GA4 Measurement ID + API secret** (korak 3 gore), `purchase` za završene rezervacije se dodatno šalje **server-side** putem GA4 Measurement Protocola, tako da se prodaja bilježi čak i ako gost nikada ne vrati na stranicu potvrde.

## Referenca DataLayer-a

Wink šalje GA4-kompatibilne događaje u `dataLayer` tijekom cijelog putovanja gosta. Vaš GTM kontejner čita iz istog zajedničkog `dataLayer`, tako da svaki okidač ili varijabla koju konfigurirate ima pristup svim svojstvima opisanima u nastavku.

Svaki događaj slijedi standardnu GA4 Enhanced Ecommerce strukturu: string `event` na vrhu i objekt `ecommerce`. Prije svakog push-a, Wink briše prethodni ecommerce payload kako bi spriječio da zastarjeli podaci utječu na nove okidače.

<Aside type="note">
**Obrazac resetiranja dataLayer-a**

Wink resetira ecommerce objekt prije svakog push-a događaja:

```js
dataLayer.push({ ecommerce: null });   // briše prethodni događaj
dataLayer.push({ event: '...', ecommerce: { ... } });
```

Nemojte se oslanjati na to da ecommerce svojstva ostaju između događaja. Uvijek ih čitajte u trenutku okidača unutar istog događaja.
</Aside>

### Događaji putovanja rezervacije

Ovi događaji se automatski aktiviraju dok se gost kreće kroz lijevak rezervacije. Konfigurirajte svoje GTM okidače kao **Custom Event** okidače koji odgovaraju imenima događaja u nastavku.

| Korak | Događaj | Kada se aktivira |
|-------|---------|------------------|
| 1 | `view_item_list` | Učitava se mreža ili lista hotela |
| 2 | `view_item` | Gost pregledava stranicu određene nekretnine |
| 3 | `add_to_cart` | Gost dodaje sobu u košaricu |
| 4 | `begin_checkout` | Učitava se stranica za plaćanje / naplatu |
| 5 | `add_payment_info` | Gost odabire način plaćanja |
| 6 | `login` | Gost se autentificira putem SSO-a |
| 7 | `purchase` | Rezervacija je potvrđena |
| 8 | `refund` | Rezervacija je otkazana |

  }
}

### Prilagođene dimenzije u GA4

GA4 ignorira prilagođene parametre stavke u izvještajima dok ih eksplicitno ne registrirate kao item-scoped custom dimensions. Trebate registrirati samo one parametre koje namjeravate koristiti u izvještajima — nije potrebno registrirati svih 20.

<Steps>

1. **Otvorite Custom Definitions**

   U GA4 idite na **Admin** (ikona zupčanika dolje lijevo) → odaberite svoju property → **Data display** → **Custom definitions**.

2. **Kreirajte novu prilagođenu dimenziju**

   Kliknite **Create custom dimensions**.

3. **Ispunite detalje dimenzije**

   - **Dimension name** — čitljiv naziv koji se pojavljuje u GA4 izvještajima (vidi tablicu dolje)
   - **Scope** — odaberite **Item**
   - **Event parameter** — točan naziv parametra kako se pojavljuje u dataLayer-u (vidi tablicu dolje)
   - **Description** — opcionalno, ali preporučeno

4. **Spremite i ponovite**

   Kliknite **Save**, zatim ponovite za svaki parametar koji želite pratiti.

</Steps>

<Aside type="note">
Prilagođene dimenzije mogu potrajati do 24 sata da se počnu prikazivati u GA4 izvještajima nakon registracije. Povijesni podaci prikupljeni prije registracije se ne nadopunjuju.

GA4 dopušta do 50 item-scoped custom dimensions po property na standardnim propertyjima (360 propertyji dopuštaju više).
</Aside>

Koristite sljedeću tablicu kao referencu pri kreiranju prilagođenih dimenzija. Vrijednost **Event parameter** mora biti točna — GA4 razlikuje velika i mala slova.

### `virtualPageView`

Ovo je prilagođeni Wink događaj — nije dio standardnog GA4 seta događaja. Pritiskuje se pri svakoj navigaciji stranice i nosi kontekst uređaja i sesije. Ne uključuje `ecommerce` objekt.

```json
{
  "event": "virtualPageView",
  "device": "Desktop",
  "deviceAgent": "Mozilla/5.0 ...",
  "os": "MacOS",
  "path": "/hotels/grand-resort",
  "title": "Grand Resort — Wink",
  "userId": "user_abc123",
  "startDate": "2026-06-01",
  "endDate": "2026-06-05",
  "guests": "2",
  "rooms": "1"
}
```

| Svojstvo | Opis |
|----------|------|
| `device` | Detektirani tip uređaja — `Desktop`, `Android`, `iPhone`, `iPad` ili slično |
| `deviceAgent` | Izvorni user agent string |
| `os` | Detektirani operativni sustav — `Windows`, `MacOS`, `Linux`, `UNIX` |
| `path` | Trenutna putanja stranice |
| `title` | Trenutni naslov stranice |
| `userId` | Identifikator autentificiranog korisnika (izostavljen ako nije prijavljen) |
| `startDate` | Datum prijave iz trenutne sesije pretraživanja |
| `endDate` | Datum odjave iz trenutne sesije pretraživanja |
| `guests` | Broj gostiju iz trenutne sesije pretraživanja |
| `rooms` | Broj soba iz trenutne sesije pretraživanja |
