Ova stranica prikazuje svaki webhook događaj na koji se možete pretplatiti na Wink-u. Za upute o postavljanju, pogledajte [Vodič za integraciju webhooka](/hr/guides/developers/webhook-integration) ili [stranicu za upravljanje webhookovima](/hr/portal/settings/webhooks).

## Kako se pretplatiti

1. Idite na **Applications > Webhooks** u vašem portalu.
2. Kreirajte webhook i odaberite događaje koje želite primati.
3. Wink šalje HTTP POST na vašu krajnju točku svaki put kada se događaj dogodi.

Za potpune korake postavljanja i najbolje prakse, pogledajte [Webhook integraciju](/hr/guides/developers/webhook-integration).

## Upravljanje događajima entiteta

Događaji za upravljanje entitetima (nekretnine, partneri, tvrtke) i njihovu administraciju.

### Životni ciklus

| Događaj | Ključ | Opis |
|---|---|---|
| Entitet kreiran | `managing_entity.created` | Novi entitet za upravljanje je kreiran. |
| Entitet obrisan | `managing_entity.deleted` | Entitet za upravljanje je obrisan. |
| Status ažuriran | `managing_entity.status.updated` | Status entiteta je promijenjen. |
| U pregledu | `account.under_review` | Račun entiteta je na pregledu. |

### Pretplata

| Događaj | Ključ | Opis |
|---|---|---|
| Pretplata osigurana | `managing_entity.subscription.provisioned` | Nova pretplata je osigurana. |
| Pretplata promijenjena | `managing_entity.subscription.changed` | Plan pretplate je promijenjen. |
| Račun pretplate promijenjen | `managing_entity.subscription.invoice.changed` | Račun pretplate je ažuriran. |

### Životni ciklus menadžera

| Događaj | Ključ | Opis |
|---|---|---|
| Menadžer dodan | `managing_entity.manager.added` | Novi menadžer je dodan. |
| Menadžer pozvan | `managing_entity.manager.invited` | Poslana je pozivnica menadžeru. |
| Menadžer uklonjen | `managing_entity.manager.removed` | Menadžer je uklonjen. |
| Menadžer prihvaćen | `managing_entity.manager.accepted` | Pozivnica menadžeru je prihvaćena. |
| Menadžer odbijen | `managing_entity.manager.rejected` | Pozivnica menadžeru je odbijena. |
| Vlasnik postavljen | `managing_entity.manager.owner.set` | Vlasništvo entiteta je preneseno. |
| Menadžeri ažurirani | `account.managers.update` | Popis menadžera je promijenjen. |

### Informacije o entitetu

| Događaj | Ključ | Opis |
|---|---|---|
| Informacije ažurirane | `managing_entity.information.updated` | Informacije o entitetu su ažurirane. |
| Adresa ažurirana | `managing_entity.city.updated` | Adresa/grad entiteta je promijenjen. |
| Ime ažurirano | `managing_entity.name.updated` | Ime entiteta je promijenjeno. |
| URL ime ažurirano | `managing_entity.url_name.updated` | Vanity URL entiteta je promijenjen. |
| Jedinstveni ID ažuriran | `managing_entity.unique_id.updated` | Jedinstveni identifikator entiteta je promijenjen. |
| Upravljano od ažurirano | `managing_entity.managed_by.updated` | Odnos roditelj/entitet koji upravlja je promijenjen. |
| Place ID ažuriran | `managing_entity.place_id.updated` | Google Place ID entiteta je promijenjen. |
| Predstavnik računa ažuriran | `managing_entity.account_representative.updated` | Predstavnik računa je promijenjen. |
| Profilna slika ažurirana | `managing_entity.profile_picture.updated` | Profilna slika entiteta je ažurirana. |
| Logo ažuriran | `managing_entity.logo.updated` | Logo entiteta je ažuriran. |
| Detalji ažurirani | `account.details.updated` | Polja detalja računa su promijenjena. |
| Agent ažuriran | `managing_entity.agent.updated` | Agent entiteta je izmijenjen. |

### Obavijesti

| Događaj | Ključ | Opis |
|---|---|---|
| Email obavijest agentu | `managing_entity.agent.email.notification` | Poslana je email obavijest agentu. |
| Email obavijest menadžeru | `managing_entity.manager.email.notification` | Poslana je email obavijest menadžeru. |

### Zadaci računa

| Događaj | Ključ | Opis |
|---|---|---|
| Zadatak kreiran | `account.task.create` | Novi zadatak je dodan na račun. |
| Zadatak ažuriran | `account.task.update` | Zadatak na računu je izmijenjen. |
| Zadatak uklonjen | `account.task.remove` | Zadatak na računu je uklonjen. |
| Zadatak dovršen | `account.task.complete` | Zadatak na računu je dovršen. |
| Zadatak verifikacije poreznog ID-a dovršen | `account.task.tax_id.complete` | Zadatak verifikacije poreznog ID-a je dovršen. |

## Događaji rezervacija

Događaji za životni ciklus rezervacije na Wink-u, od kreiranja do povrata i isplata.

### Osnovna rezervacija

| Događaj | Ključ | Opis |
|---|---|---|
| Rezervacija kreirana | `booking.create` | Nova rezervacija je kreirana. |
| Rezervacija otkazana | `booking.cancelled` | Rezervacija je otkazana. |
| Rezervacija nije uspjela | `booking.failed` | Pokušaj rezervacije nije uspio. |
| Obrada rezervacije | `booking.processing` | Plaćanje rezervacije se obrađuje. |
| Zahtjev za inicijalizaciju | `booking.initialize.request` | Zahtjev za inicijalizaciju rezervacije je poslan. |
| Inicijalizacija dovršena | `booking.initialize.complete` | Inicijalizacija rezervacije je dovršena. |

### Povrati

| Događaj | Ključ | Opis |
|---|---|---|

| Pogreška pri povratu | `booking.refund.error` | Došlo je do pogreške pri obradi povrata. |
| Djelomični povrat | `booking.refund.partial` | Izdana je djelomična povratna uplata. |
| Potpuni povrat | `booking.refund.full` | Izdana je potpuna povratna uplata. |

### Isplate

| Događaj | Ključ | Opis |
|---|---|---|
| Isplata kreirana | `booking.payout.create` | Isplata za rezervaciju je kreirana. |
| Isplata dovršena | `booking.payout.complete` | Isplata je uspješno dovršena. |
| Sredstva dostupna | `booking.funds.available` | Sredstva rezervacije su dostupna za poravnanje. |
| Sredstva evidentirana | `booking.funds.ledgered` | Sredstva rezervacije su evidentirana u knjigama. |

### Recenzije

| Događaj | Ključ | Opis |
|---|---|---|
| Recenzija poslana | `booking.review.created` | Gost je poslao recenziju za rezervaciju. |
| Odgovor na recenziju | `booking.review.responded` | Nekretnina je odgovorila na recenziju rezervacije. |
