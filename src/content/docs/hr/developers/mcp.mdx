Wink izlaže dva autentificirana MCP poslužitelja. Oba koriste **interaktivnu OAuth2 prijavu** (PKCE authorization code flow) — vaš AI agent otvara karticu preglednika kako biste se prijavili sa svojim Wink računom. Nema potrebe za upravljanjem klijentskim tajnama.

| Poslužitelj | URL | Što radi |
|-------------|-----|----------|
| **Inventory API** | `https://api.wink.travel/mcp` | Inventar, rezervacije, cijene, prodajni kanali, analitika i sve platformske operacije |
| **Integrations** | `https://integrations.wink.travel/mcp` | Integracije channel managera — sinkronizacija objekata, cijena i dostupnosti s OTA-ima |

---

## Kako funkcionira autentifikacija

Wink MCP poslužitelji koriste **OAuth2 Authorization Code + PKCE** protokol i podržavaju **Dynamic Client Registration (RFC 7591)**. Evo što se događa kada se prvi put povežete:

1. Vaš AI klijent otkriva authorization server iz MCP endpointa `/.well-known/oauth-protected-resource` metapodataka.
2. Klijent se samoregistrira putem **Dynamic Client Registration** — nije potrebna ručna konfiguracija aplikacije.
3. Klijent otvara **karticu preglednika** na `https://iam.wink.travel`. Prijavite se sa svojim Wink računom i odobrite tražene dozvole na zaslonu za suglasnost.
4. Wink izdaje **access token** vezan uz vaš račun i povezanu identitet.
5. AI klijent prilaže token svakom MCP zahtjevu. Svi rezultati alata automatski su ograničeni na vašu upravljačku jedinicu.
6. Tokeni istječu nakon 3 sata. Vaš AI klijent ih tiho osvježava u pozadini bez ponovnog zahtjeva za prijavom.

Svaki poziv alata izvršava se **pod vašim identitetom** — ista ACL pravila koja štite web portal vrijede i za AI agenta.

## Povežite svoj AI klijent

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Provjerite je li Claude Code ažuriran:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Dodajte Wink Inventory MCP poslužitelj:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code kontaktira poslužitelj, otkriva authorization server i otvara vaš zadani preglednik.

4. **Prijavite se u Wink** i odobrite zahtjev za dozvolama na zaslonu za suglasnost.

5. Claude Code potvrđuje vezu. Upisom `/mcp` provjerite pojavljuje li se poslužitelj i jesu li alati učitani.
</Steps>

Za dodavanje i Integrations poslužitelja:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Podijelite s timom]
Dodajte `--scope project` uz `claude mcp add` i Claude Code će zapisati URL poslužitelja u `.mcp.json` u korijenu repozitorija. Pošaljite tu datoteku u repozitorij — svaki član tima će prvi put prilikom povezivanja dovršiti vlastitu prijavu u pregledniku.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Uredite konfiguracijsku datoteku Claude Desktopa:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. Dodajte unose MCP poslužitelja:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **Potpuno izađite i ponovno pokrenite** Claude Desktop (koristite Quit iz izbornika — zatvaranje prozora nije dovoljno).

4. Claude Desktop otvara karticu preglednika za svaki novi poslužitelj. Prijavite se u Wink i odobrite dozvole.

5. Ikona utikača u donjoj alatnoj traci pokazuje oba poslužitelja kao povezana.
</Steps>

  </TabItem>

     "mcpServers": {
       "wink-inventory": {
         "type": "http",

6. Codex potvrđuje vezu. Pokrenite `codex` i zatražite popis dostupnih alata da provjerite jesu li Wink poslužitelji aktivni.

:::note

  <TabItem label="ChatGPT">

Podrška za MCP poslužitelje dostupna je u **ChatGPT desktop aplikaciji** za Plus, Pro, Team i Enterprise pretplatnike.

<Steps>
1. Preuzmite i instalirajte [ChatGPT desktop aplikaciju](https://openai.com/chatgpt/download/) ako je već nemate.

2. Otvorite aplikaciju i kliknite **ikonu svog profila** u gornjem desnom kutu, zatim odaberite **Settings**.

3. Idite na **Connectors** (ili **MCP Servers** ovisno o verziji aplikacije) i kliknite **Add**.

4. Unesite URL Wink Inventory poslužitelja:
   ```
   https://api.wink.travel/mcp
   ```
   Zatim kliknite **Connect**.

5. ChatGPT otvara karticu preglednika na `https://iam.wink.travel`. **Prijavite se u Wink** i odobrite dozvole.

6. Ponovite korake 4–5 za Integrations poslužitelj:
   ```
   https://integrations.wink.travel/mcp
   ```

7. Oba poslužitelja pojavljuju se na vašem popisu Connectors. Pokrenite novi chat — Wink alati su automatski dostupni.
</Steps>

:::note[Ograničenje web aplikacije]
MCP poslužitelji se mogu konfigurirati samo u **desktop aplikaciji**. Web sučelje ChatGPT-a na chatgpt.com ne podržava prilagođene MCP poslužitelje.
:::

   - **macOS / Linux:** `~/.cursor/mcp.json`
   - **Windows:** `%USERPROFILE%\.cursor\mcp.json`

2. Dodajte unose Wink MCP poslužitelja:

   ```json title="~/.cursor/mcp.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. Otvorite Cursor. Idite na **Settings → Cursor Settings → MCP** i provjerite pojavljuju li se oba poslužitelja sa zelenim indikatorom statusa. Ako su crveni, kliknite **Refresh**.

## Opsezi (Scopes)

Kada odobrite zaslon za suglasnost, vidjet ćete detaljan prikaz što agent traži. MCP
klijenti koriste isti vokabular dozvola kao i ostatak platforme — pogledajte puni
[referentni popis opsega na stranici Autentifikacije](/hr/developers/authentication#scopes).

Dva su specifična za MCP:

- **Opsezi `mcp.read`, `mcp.write` i `mcp.remove` su dodatno potrebni** za otvaranje MCP
  transporta. Klijent koji ima `mcp.*` opseg ima pristup `/mcp`, ali svaki alat koji pozove
  i dalje provjerava opseg sekcije endpointa koji obuhvaća (npr. `booking.read`).
- **AI klijent traži samo opsege koje treba.** Možete odbiti pojedinačne dozvole na
  zaslonu za suglasnost — alati koji zahtijevaju odbijeni opseg vratit će grešku pri pozivu.

## Rješavanje problema

**Kartica preglednika se ne otvara**

Vaš AI klijent možda još ne podržava interaktivni PKCE protokol. Provjerite koristite li najnoviju verziju:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** ažurirajte putem ugrađenog updatera aplikacije

**`401 Unauthorized` nakon prijave**

Vaš spremljeni token može biti zastario. Uklonite i ponovno dodajte poslužitelj da pokrenete novu prijavu:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

Za Claude Desktop i ChatGPT uklonite unos poslužitelja iz postavki, ponovno pokrenite aplikaciju i dodajte ga ponovno.

**`403 Forbidden` pri pozivu određenog alata**

Alat zahtijeva opseg koji niste odobrili na zaslonu za suglasnost. Ponovno povežite poslužitelj — zaslon za suglasnost će se ponovno pojaviti i moći ćete odobriti nedostajuću dozvolu.

**Poslužitelj se pojavljuje, ali pozivi alata vraćaju "account not found"**

Prijavljeni ste u Wink račun koji nema upravljačku jedinicu. Posjetite [Wink Portal](https://app.wink.travel) i provjerite je li vaš račun pravilno postavljen prije korištenja MCP poslužitelja.

**Token istječe tijekom sesije**

Tokeni vrijede 3 sata. Claude Code i Claude Desktop tiho osvježavaju tokene bez prekida sesije. Ako vidite greške autentifikacije nakon dužeg mirovanja, pošaljite novu poruku — klijent će se automatski ponovno autentificirati.

**Codex CLI prikazuje "MCP server unreachable"**

Provjerite je li vaš `~/.codex/config.json` valjani JSON (bez zarez na kraju) i da je `"type": "http"` postavljeno. Codex zahtijeva HTTP transport za udaljene poslužitelje; stdio transport je samo za lokalne binarne datoteke.

**ChatGPT meni "Connectors" nedostaje**

Podrška za MCP zahtijeva verziju ChatGPT desktop aplikacije **1.2024.352** ili noviju i aktivnu Plus, Pro, Team ili Enterprise pretplatu. Ažurirajte aplikaciju i provjerite svoj plan u Settings → Account.

**Cursor poslužitelj pokazuje crveno / "Failed to connect"**

Provjerite je li vaš `~/.cursor/mcp.json` valjani JSON i sadrži `"type": "http"`. Zatim idite na **Settings → Cursor Settings → MCP** i kliknite **Refresh**. Ako greška ostane, potpuno ponovno pokrenite Cursor — promjene konfiguracije se ne preuzimaju uvijek bez ponovnog pokretanja.

**Windsurf MCP poslužitelji nisu prikazani u postavkama**

Windsurf zahtijeva potpuno ponovno pokretanje (ne samo ponovno učitavanje prozora) da prepozna promjene u `mcp_config.json`. Koristite **File → Quit** i ponovno pokrenite. Ako poslužitelji i dalje nisu vidljivi, provjerite koristite li Windsurf **1.4+** putem **Help → About Windsurf**.

**Opcija "Add Server" u Cline nije vidljiva**

Upravitelj MCP poslužitelja zahtijeva Cline **2.0** ili noviji. Otvorite VS Code Extensions panel, pronađite Cline i kliknite **Update** ako je dostupna nadogradnja. Nakon ažuriranja ponovno učitajte VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
