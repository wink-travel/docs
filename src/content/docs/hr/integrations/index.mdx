Booking Engine se može ugrađivati bilo gdje. Odaberite svoj framework ili CMS i slijedite njegov vodič; temeljni Web Components su isti svugdje.

## Osnovni pristupi

- [Web Components](/hr/integrations/web-components/) — ugrađivi elementi koje koristi svaka integracija.
- [npm package](/hr/integrations/npm/) — instalirajte u JavaScript build.
- [Headless CMS](/hr/integrations/headless/) — renderirajte iz bilo kojeg content backenda.
- [Partner API](/hr/integrations/partner-api/) — potpuna programska integracija.
