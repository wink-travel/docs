Esta página lista todos os eventos webhook aos quais você pode se inscrever na Wink. Para instruções de configuração, veja o [Guia de Integração Webhook](/pt-BR/guides/developers/webhook-integration) ou a [página de gerenciamento de Webhooks](/pt-BR/portal/settings/webhooks).

## Como se inscrever

1. Navegue até **Aplicações > Webhooks** no seu portal.
2. Crie um webhook e selecione os eventos que deseja receber.
3. A Wink envia um HTTP POST para seu endpoint toda vez que o evento ocorre.

Para passos completos de configuração e melhores práticas, veja [Integração Webhook](/pt-BR/guides/developers/webhook-integration).
