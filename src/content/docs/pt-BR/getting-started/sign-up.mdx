Antes de tudo, você precisa criar uma conta de usuário na Wink.

<Aside type="note" title="Está reservando uma viagem?">
Este guia é para profissionais que desejam trabalhar com o inventário de viagens da Wink — hoteleiros, agentes de viagem, afiliados e outros parceiros que gerenciam reservas, propriedades e distribuição. Se você é um viajante, não precisa de uma conta antecipadamente: você criará uma durante o processo de checkout ao fazer uma reserva.
</Aside>

Siga estes passos:

<Steps>
1. Acesse [app.wink.travel](https://app.wink.travel)
2. Clique em `Sign-In / Register` no canto superior direito
3. Você será direcionado para um formulário de login. Clique no link `Register` abaixo dos campos do formulário.
4. Preencha o formulário de registro e clique em `Register`. Você será redirecionado para a página de login.
5. Após o login, você será redirecionado para o nosso [Portal](/pt-BR/portal/create-account) onde poderá criar sua primeira conta.
</Steps>

Criar uma conta de usuário na Wink dá acesso a todos os recursos da plataforma. Você pode criar propriedades e contas de afiliados ilimitadas.
