A página de cobrança é onde você ativa o pagamento conforme o uso, decide a quais contas isso se aplica e acompanha seus gastos.

Você não precisa vir aqui para começar. Cada conta recebe uma cota mensal gratuita nos recursos medidos sem precisar fazer nada. Esta página é apenas para ultrapassar essa cota. Veja [Preços](/pt-BR/getting-started/pricing) para saber o que é gratuito, o que é medido e quanto custa.

## Ativando o pagamento conforme o uso

Ative o pagamento conforme o uso e escolha como deseja pagar sua fatura:

- **Cartão** — cobramos automaticamente seu cartão salvo quando a fatura for emitida.
- **Fatura** — enviamos uma fatura para você pagar por conta própria.

Você pode alternar entre os dois a qualquer momento.

:::note
Apenas o **proprietário** de uma conta pode ativar o pagamento conforme o uso para ela. Ter acesso de gerenciamento à conta de outra pessoa não é suficiente, pois a fatura é enviada ao proprietário — não vamos permitir que outra pessoa coloque cobranças no seu cartão.
:::

## Escolhendo suas contas

Se você possui mais de uma conta, pode escolher individualmente quais serão medidas. Uma conta que você deixar desativada simplesmente para no limite gratuito a cada mês.

O uso de todas as contas ativadas é consolidado em **uma única fatura por mês**, para que você receba uma única cobrança em vez de uma por propriedade.

## Método de pagamento

Adicione um cartão e nós o armazenaremos com segurança junto ao nosso provedor de pagamento. Exibimos apenas a bandeira, os últimos quatro dígitos e a data de validade — a Wink nunca vê ou armazena o número completo do seu cartão. Se seu banco emitir um cartão substituto, os dados são atualizados automaticamente.

## Uso

Acompanhe o que você usou até agora neste mês, detalhado por recurso e por conta, junto com a cota gratuita para cada uma. Este é o número para observar se você quer manter seus gastos previsíveis — para Social em particular, sua contagem mensal de publicações é efetivamente seu orçamento.

As cotas são resetadas no dia 1º de cada mês.

## Faturas

Seu histórico de faturas lista o número de cada mês, período de cobrança, valor, moeda e status, com links para visualizar a fatura online ou baixá-la em PDF.

## Status da cobrança

| Status | O que significa |
| -- | -- |
| Em dia | Tudo está funcionando normalmente. |
| Atrasado | Uma tentativa de pagamento falhou e está sendo refeita. Seus recursos continuam funcionando enquanto tentamos novamente. |
| Suspenso | Uma fatura ficou sem pagamento até o final. Os recursos medidos são bloqueados até que seja quitada — os recursos gratuitos continuam normalmente. |
