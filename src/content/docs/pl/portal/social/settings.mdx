# Ustawienia

Kiedy zaczynasz korzystać z Social, zapytamy Cię, jak chcesz, abyśmy tworzyli Twoje treści. Opcje te są dostępne przez cały czas, dzięki czemu możesz je łatwo zmieniać później.

Przejdź do `Preferences` z paska bocznego, aby zarządzać swoimi ustawieniami.

Sekcja preferencji zawiera podstawowe ustawienia generowania treści:

1. **Preferowana personalizacja** Wybierz, której personalizacji używać podczas generowania treści. Personalizacje kontrolują kolory motywu, domyślny plan podróży, walutę, język i więcej. Personalizacje tworzysz na swoim koncie na [app.wink.travel](https://app.wink.travel).
2. **Automatyczna akceptacja** Po włączeniu, wygenerowane posty są publikowane automatycznie bez konieczności Twojej akceptacji. Włącz tę opcję, gdy będziesz pewny jakości tworzonych przez nas treści.
3. **Nazwa osoby zatwierdzającej** Nazwa osoby lub zespołu, który będzie otrzymywał e-maile z prośbą o zatwierdzenie.
4. **E-mail osoby zatwierdzającej** Adres e-mail, na który będą wysyłane prośby o zatwierdzenie nadchodzących postów.

## Twórcy treści

Social oferuje wiele twórców treści do wyboru. Każdy twórca skupia się na jednym specyficznym sposobie tworzenia unikalnych treści dla Twojej nieruchomości za pomocą AI. Każdy twórca treści ma atrybut **Waga** — wyższa waga zwiększa szansę, że dany twórca zostanie wybrany podczas generowania postów.

Oto wszyscy dostępni twórcy treści:

| Twórca | Opis |
| -- | -- |
| **Destination** | Wykorzystuje Twoją lokalizację do tworzenia pomocnych tekstów o okolicy |
| **Room type** | Tworzy rezerwowalny post z jednym z Twoich typów pokoi z tekstem generowanym przez AI i zdjęciami pokoju |
| **Activity** | Tworzy rezerwowalny post z jedną z Twoich aktywności |
| **Add-On** | Tworzy rezerwowalny post z jednym z Twoich dodatków |
| **Attraction** | Tworzy rezerwowalny post z jedną z Twoich atrakcji |
| **Place** | Tworzy rezerwowalny post z jednym z Twoich miejsc |
| **Meeting room** | Tworzy rezerwowalny post z jedną z Twoich sal konferencyjnych |
| **Restaurant** | Tworzy rezerwowalny post z jedną z Twoich restauracji |
| **Spa** | Tworzy rezerwowalny post z jednym z Twoich spa |
| **Property** | Tworzy rezerwowalny post z Twoim najlepiej wycenionym pokojem z tekstem generowanym przez AI i zdjęciami nieruchomości |
| **User sentiment** | Agreguje opinie gości z całego internetu w post oparte na sentymencie, który podkreśla, co goście kochają w Twojej nieruchomości |
| **Funny** | Tworzy lekkie, zabawne posty, które utrzymują zaangażowanie na Twoim profilu |

:::tip[Pro tip]
Upewnij się, że masz odpowiedni typ inwentarza wymagany przez wybranych twórców treści. Na przykład, jeśli wybierzesz "Restaurant", musisz mieć przynajmniej jedną restaurację na swojej nieruchomości.
:::

## Ton głosu

Ton głosu ustala styl języka, którego AI używa podczas generowania treści. Wybierz tony, które pasują do osobowości Twojej marki. Podobnie jak w przypadku twórców treści, każdy ton ma **Wagę**, która kontroluje, jak często jest używany.

Oto dostępne tony:

| Ton | Styl |
| -- | -- |
| **Neutralny** | Spokojny, autorytatywny, rzeczowy. Bez przesady, bez żartów — po prostu wiarygodna, dobrze ustrukturyzowana wiedza |
| **Przyjazny** | Ciepły, przystępny, z energią uśmiechu w tekście, z potocznymi skrótami i okazjonalnymi emoji |
| **Luksusowy** | Wyrafinowany, elegancki. Słowa takie jak "wykwintny" i "szyty na miarę", które sprawiają, że czytelnicy czują się wyjątkowo |
| **Smakosz** | Zmysłowe, apetyczne opisy. Język kulinarnego pornografii, który sprawia, że czytelnicy robią się głodni |
| **Przygodowy** | Śmiały, nieustraszony, z energią odkrywcy. Żywe opisy sensoryczne, które sprawiają, że wszystko brzmi epicko |
| **Rodzinny** | Pełen ciepła, przyjazny dzieciom entuzjazm. Ciepła energia rodzicielska o bezpiecznych i zabawnych doświadczeniach |
| **Romantyczny** | Poetycki, tęskny, poruszający serce. Zachody słońca, miękki język i miłość |
| **Humorystyczny** | Sarkastyczny, szybkie riposty, sprytne gry słów. Czyta się jak stand-up |
| **Eko** | Szczery i prawy. Celebruje zielone alternatywy i zrównoważone wybory |
| **Lokalny znawca** | Bardzo specyficzne lokalne odniesienia, ostrzega przed pułapkami turystycznymi, używa lokalnego slangu |
| **Inkluzywny** | Gościnny, celebrujący i afirmujący. Sprawia, że każdy czuje się zauważony i doceniony |
| **Mistyczny** | Eteryczny, duchowy, kosmiczne prawdy. Delikatne zaproszenia do spojrzenia w głąb siebie |
| **Futurystyczny** | Elegancki, myślący przyszłościowo. Uwielbia terminy takie jak "zmiana paradygmatu" i optymistyczne wizje przyszłości |
| **Budżetowy** | Zaradny, oszczędny, dumnie oszczędny. Celebruje przystępne cenowo znaleziska i darmowe doświadczenia |

## Typy postów

Typy postów określają cel i strukturę generowanych treści. Każdy typ postu ma **Wagę**, która kontroluje, jak często jest używany.

| Typ postu | Opis |
| -- | -- |
| **Transakcyjny** | Jasny, zwięzły, nastawiony na konwersję. Napędza rezerwacje i bezpośrednie działania za pomocą faktów, cen i kolejnych kroków |
| **Świadomość** | Treści budujące markę, zaprojektowane, aby przedstawić Twoją nieruchomość i zwiększyć widoczność wśród potencjalnych gości |
| **Sentiment** | Emocjonalnie rezonujące treści, które tworzą pozytywne skojarzenia i budują emocjonalną więź z Twoją publicznością |

Możesz chcieć skupić swoje działania marketingowe na konkretnym języku i regionie. Powiedz nam, dla jakich języków chcesz tworzyć treści oraz jaka strefa czasowa Cię interesuje, a my zajmiemy się resztą. Posty są publikowane o zaplanowanej godzinie w wybranej strefie czasowej.

*Większość nieruchomości używa jednego języka i domyślnie korzysta z lokalnego języka.*

Łącząc swój profil Google Business, możemy pobierać bogatsze szczegóły nieruchomości dla skuteczniejszego tworzenia treści. Twoja nieruchomość musi mieć zweryfikowany profil Google Business, abyśmy mogli generować treści na podstawie Twojej wizytówki. Niektórzy z naszych twórców treści **wymagają**, abyś miał konto Google Business.

:::tip[Pro tip]
Zacznij od małych kroków

Nie bądź zbyt ambitny przy pierwszej próbie. Zalecamy, abyś zaczął od tworzenia treści dla swojej nieruchomości w jednym języku.
:::
