Booking Engine można osadzić wszędzie. Wybierz swój framework lub CMS i postępuj zgodnie z jego przewodnikiem; bazowe Web Components są takie same wszędzie.

## Główne podejścia

- [Web Components](/pl/integrations/web-components/) — osadzalne elementy używane w każdej integracji.
- [npm package](/pl/integrations/npm/) — instalacja w środowisku JavaScript.
- [Headless CMS](/pl/integrations/headless/) — renderowanie z dowolnego backendu treści.
- [Partner API](/pl/integrations/partner-api/) — pełna integracja programistyczna.
