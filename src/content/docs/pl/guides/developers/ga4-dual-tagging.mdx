Łącząc swoją usługę Google Analytics 4 z Wink, Twoje zdarzenia rezerwacji — od przeglądania pokoi aż po zakończone rezerwacje — są automatycznie przesyłane do Twojego własnego pulpitu GA4 obok własnych analiz Wink. Bez kodu, bez technicznej konfiguracji z Twojej strony.

<Aside type="tip">
Potrzebujesz dwóch rzeczy z GA4: **ID pomiaru** oraz **sekretu API protokołu pomiarowego**. ID pomiaru napędza lejek przeglądania w przeglądarce gościa; sekret API pozwala Wink rejestrować zakończone rezerwacje (`purchase`) **po stronie serwera**, dzięki czemu sprzedaż nigdy nie zostaje utracona podczas przekierowania do i z dostawcy płatności.
</Aside>

---

## Jak to działa

```
Wprowadzasz swoje ID pomiaru (G-XXXXXXXXXX) i sekret API w portalu Wink
       ↓
Zdarzenia przeglądania (wyświetlenia, koszyk, realizacja zamówienia) przesyłane są do Twojej usługi GA4 z przeglądarki
Zakończone rezerwacje (purchase) są wysyłane po stronie serwera — przetrwają przekierowanie płatności
       ↓
Logujesz się na analytics.google.com i widzisz pełny lejek rezerwacji
```

---

## Co musisz zrobić

<Steps>

1. **Utwórz usługę GA4**

   Przejdź do [analytics.google.com](https://analytics.google.com): Administrator → Utwórz usługę. Ustaw swoją strefę czasową i walutę zgodnie z rynkiem.

2. **Utwórz strumień danych internetowych**

   Administrator → Strumienie danych → Dodaj strumień → Internet. Wprowadź `wink.travel` jako URL. To wygeneruje Twoje **ID pomiaru** (`G-XXXXXXXXXX`). Skopiuj je.

3. **Utwórz sekret API protokołu pomiarowego**

   Otwórz ten sam strumień danych internetowych → przewiń do **Sekrety API protokołu pomiarowego** → **Utwórz**. Nadaj mu nazwę (np. "Wink") i skopiuj wygenerowaną **wartość sekretu**. Ten sekret pozwala Wink rejestrować zakończone rezerwacje po stronie serwera, dzięki czemu sprzedaż nigdy nie zostaje utracona podczas przekierowania płatności.

4. **Wprowadź swoje ID pomiaru i sekret API w portalu Wink**

   Zaloguj się na [app.wink.travel](https://app.wink.travel), wybierz swoje konto i przejdź do zakładki **Dostosowania**. Wklej swoje ID pomiaru i sekret API w pola **GA4** i zapisz. To wszystko — integracja GA4 jest teraz aktywna.

   <Aside type="note">
   Sekret API jest **tylko do zapisu**: po zapisaniu nie jest już nigdy pokazywany. Przy kolejnych edycjach pozostaw pole sekretu puste, aby zachować już zapisany sekret.
   </Aside>

5. **Oznacz `purchase` jako zdarzenie kluczowe**

   Wróć do swojej usługi GA4: Administrator → Zdarzenia → znajdź `purchase` → włącz **Oznacz jako zdarzenie kluczowe**. Dzięki temu zakończone rezerwacje pojawią się w raporcie Konwersji.

6. **Przeglądaj swoje dane**

   Zaloguj się na [analytics.google.com](https://analytics.google.com), aby zobaczyć swoje rezerwacje, przychody i lejek gościa — wszystko śledzone automatycznie przez Wink.

</Steps>

<Aside type="note">
Nie musisz instalować żadnego kodu śledzącego na swojej stronie internetowej dla tej integracji. Wink zajmuje się wszystkim. Twoje ID pomiaru to miejsce docelowe, do którego wysyłane są dane rezerwacji, a sekret API pozwala Wink potwierdzać zakończone rezerwacje po stronie serwera.
</Aside>

<Aside type="tip">
**GA4 i GTM mogą być używane razem.** Jeśli korzystasz również z kontenera Google Tag Manager (np. kontenera Sojern), możesz skonfigurować oba jednocześnie — nie wykluczają się już wzajemnie. Zobacz [Integracja GTM Analytics](/pl/guides/developers/gtm-dual-tagging).
</Aside>

## Co możesz śledzić

Po połączeniu Twoja usługa GA4 otrzymuje pełen zestaw zdarzeń Enhanced E-commerce dla Twojej nieruchomości:

### Odkrywanie

| Zdarzenie | Co oznacza |
|---|---|
| `view_item_list` | Gość zobaczył Twoją nieruchomość w wynikach wyszukiwania lub w kategorii |
| `select_item` | Gość kliknął na Twoją nieruchomość z listy |
| `view_item` | Gość obejrzał stronę szczegółów hotelu |

### Rozważanie

| Zdarzenie | Co oznacza |
|---|---|
| `view_promotion` | Gość zobaczył ofertę promocyjną Twojej nieruchomości |
| `select_promotion` | Gość kliknął na ofertę promocyjną |
| `add_to_wishlist` | Gość dodał Twoją nieruchomość do listy życzeń |

### Lejek rezerwacji

| Zdarzenie | Co oznacza |
|---|---|
| `add_to_cart` | Gość wybrał pokój lub pakiet |
| `view_cart` | Gość obejrzał podsumowanie rezerwacji |
| `remove_from_cart` | Gość usunął pokój lub pakiet |
| `begin_checkout` | Gość rozpoczął proces realizacji zamówienia |
| `add_payment_info` | Gość wprowadził dane płatności |
| `add_shipping_info` | Gość wprowadził dane gościa |
| `purchase` | Gość zakończył rezerwację |
| `refund` | Rezerwacja została anulowana i zwrócona |

Wszystkie zdarzenia zawierają odpowiednie wymiary, takie jak przychód, waluta, typ pokoju i wartość rezerwacji — dając pełny obraz ścieżki gościa od pierwszego kontaktu do zakończonej rezerwacji. Aby odblokować dodatkowe wymiary na poziomie nieruchomości i pokoju, takie jak `city_name`, `cancellation_policy`, `bed_type` i inne, zobacz [Wymiary niestandardowe w GA4](/pl/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4).

## Śledzenie międzydomenowe (zaawansowane)

Standardowa integracja powyżej śledzi wszystko, co dzieje się w Wink. Jednak jeśli chcesz śledzić gości od Twojej własnej strony internetowej aż do zakończenia rezerwacji w Wink — i poprawnie przypisać oryginalne źródło ruchu (Google Ads, kampanie e-mailowe, wyszukiwanie organiczne itd.) — wymagana jest dodatkowa konfiguracja po obu stronach.

<Aside type="caution">
Ta sekcja dotyczy tylko, jeśli masz zainstalowane GA4 na swojej własnej stronie internetowej. Jeśli nie korzystasz z GA4 na swojej stronie, standardowa integracja powyżej jest wystarczająca.
</Aside>

### Dlaczego to ważne

Bez śledzenia międzydomenowego gość, który najpierw odwiedzi Twoją stronę, a potem dokona rezerwacji w Wink, pojawi się w GA4 jako sesja **Direct** bez powiązania z wcześniejszą wizytą. Kliknięcia Google Ads, kampanie e-mailowe czy wizyty z wyszukiwania organicznego, które doprowadziły do rezerwacji, nie zostaną uwzględnione.

Po skonfigurowaniu śledzenia międzydomenowego widzisz pełną ścieżkę gościa:

```
google.com (reklama płatna)
       ↓
Twoja strona (gość przegląda pokoje)
       ↓
wink.travel (gość wybiera pokój i rezerwuje)
       ↓
purchase poprawnie przypisane do oryginalnego kliknięcia Google Ads
```

### Działanie wymagane: Ty

Skonfiguruj swoją usługę GA4, aby rozpoznawała `wink.travel` jako część Twojej własnej domeny, a nie jako zewnętrzne odwołanie. To pozwala GA4 połączyć dwie sesje w jedną ciągłą ścieżkę gościa.

<Steps>
1. GA4 Administrator → Strumienie danych → Twój strumień
2. Konfiguracja ustawień tagów → **Skonfiguruj swoje domeny**
3. Dodaj `wink.travel` jako domenę powiązaną
4. Zapisz
</Steps>

### Działanie wymagane: Wink

Skontaktuj się z [Wink Support](https://app.wink.travel) i podaj domenę swojej strony (np. `twojhotel.com`). Wink doda Twoją domenę do listy wykluczeń odwołań w usłudze GA4 Wink. Zapobiega to rejestrowaniu Twojej strony jako źródła odwołania, co w przeciwnym razie nadpisałoby oryginalne przypisanie gościa i rozpoczęło nową sesję.

<Aside type="tip">
Standardowa integracja powyżej jest wystarczająca dla większości nieruchomości i daje natychmiastowy wgląd w rezerwacje i przychody w Wink. Śledzenie międzydomenowe to zaawansowana opcja, którą warto skonfigurować, gdy już dobrze znasz swoje dane GA4 i chcesz uzyskać głębsze informacje o przypisaniu.
</Aside>
