Narzędzia MCP Wink są udostępniane jako **zestawy narzędzi** — wyspecjalizowane endpointy, z których każdy obejmuje jedno zadanie. Łączysz swojego klienta AI z jednym lub dwoma, które odpowiadają Twojej pracy, a nie ze wszystkimi.

Każdy endpoint korzysta z **interaktywnego logowania OAuth2** (PKCE authorization code flow): Twój agent AI otwiera kartę przeglądarki, logujesz się na swoje konto Wink i to wszystko. Nie ma potrzeby zarządzania sekretami klienta.

```bash title="Integrator channel managera łączy się z jednym endpointem"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="Hotelarz zarządzający własnymi cenami łączy się z innym"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## Dlaczego narzędzia są podzielone na endpointy

Wink udostępnia około 500 narzędzi. Przekazanie ich wszystkich agentowi naraz jest technicznie możliwe — ale złym pomysłem.

**Definicje narzędzi zajmują kontekst.** Każde narzędzie, które serwer MCP reklamuje, jest ładowane do okna kontekstowego modelu przed wykonaniem jakiejkolwiek pracy, wraz z jego opisem i pełnym schematem parametrów. Pięćset takich narzędzi zużywa dużą część budżetu, którego potrzebuje Twoje faktyczne zadanie, przy każdym żądaniu.

**Jakość wyboru spada wraz z długością listy.** Agent wybierający spośród 500 podobnie nazwanych narzędzi podejmuje gorsze decyzje niż ten wybierający spośród 40. Jeśli integrujesz channel managera, około dwadzieścia narzędzi jest dla Ciebie istotnych; pozostałe 480 to szum utrudniający znalezienie właściwego narzędzia.

**Praca jest faktycznie podzielna.** Ktoś synchronizujący dostępność z PMS i ktoś tworzący strony afiliacyjne prawie nie dzielą narzędzi. Podział według zadania oznacza, że każde połączenie zawiera słownictwo jednego zadania.

<Aside type="caution" title="Zestawy narzędzi to nie uprawnienia">
Wybór wąskiego zestawu narzędzi **nie** ogranicza możliwości Twojego konta, a wybór szerokiego nie daje nic dodatkowego. Każde narzędzie wymusza te same uprawnienia konta co portal internetowy, pod Twoją zalogowaną tożsamością. Jeśli Twoje konto nie może anulować rezerwacji w Wink Portal, agent też nie może — bez względu na to, do którego endpointu jest podłączony.

Wybieraj zestawy narzędzi dla **skupienia**, nie dla bezpieczeństwa.
</Aside>

## Katalog endpointów

Dwa hosty obsługują zestawy narzędzi. Liczby narzędzi są przybliżone i rosną z czasem.

### `https://api.wink.travel` — platforma

| Endpoint | Narzędzia | Co obejmuje |
|---|---:|---|
| `/mcp/extranet/facilities` | ~64 | Rezerwowane i na miejscu zasoby: pokoje gościnne i typy pokoi, spa, restauracje, sale konferencyjne, atrakcje, miejsca, inne sprzedawalne elementy |
| `/mcp/extranet/property` | ~62 | Rekord nieruchomości i jej warunki handlowe: profil i zawartość, dodatki, polityki anulacji, korzyści, ogłoszenia |
| `/mcp/settings` | ~60 | Administracja kontem: profil i branding jednostki zarządzającej, menedżerowie i ich uprawnienia, personalizacja, webhooki, preferencje powiadomień |
| `/mcp/studio/embeds` | ~48 | Publikowanie wyselekcjonowanego zasobu: widgety, siatki i siatki rankingowe, karty, mapy, głębokie linki do zasobów i stron dostawców |
| `/mcp/extranet/rates` | ~44 | Ceny i dostępność: okresy i limity stawek, plany taryfowe, stawki główne, stawki specjalne i promocyjne |
| `/mcp/extranet/operations` | ~39 | Zarządzanie działającą nieruchomością: rezerwacje i ich cykl życia, opinie gości i odpowiedzi, kalendarze, zaplanowane zadania |
| `/mcp/extranet/distribution` | ~37 | Gdzie sprzedawany jest zasób: kanały sprzedaży i modyfikatory stawek, prośby o relacje afiliacyjne i dostawców, rejestracja, pozyskiwanie leadów |
| `/mcp/studio/curation` | ~35 | Tworzenie kolekcji handlowych: listy statyczne i dynamiczne, listy rankingowe, zapisane wyszukiwania, agregaty nieruchomości |
| `/mcp/link-manager` | ~28 | Kolekcje linków syndykowanych, ich projekt, kategorie i tagi, oraz skrócone URL-e |
| `/mcp/reference` | ~24 | Dane do odczytu: kraje, waluty i kursy wymiany, języki, strefy czasowe, geolokalizacje, geolokalizacja IP |
| `/mcp/analytics` | ~18 | Analizy rezerwacji i przychodów: przeglądy, wykresy liniowe, rankingi, wyniki afiliacji, metryki udziału |
| `/mcp/payment` | ~18 | Operacje finansowe: księga, wypłaty i szacunki opłat, agregaty środków rezerwacyjnych |
| `/mcp/booking-engine` | ~17 | Ścieżka zakupowa dla podróżnych: wyszukiwanie i odczyt, koszyk i finalizacja, listy życzeń, personalizacja kampanii |
| `/mcp/social` | ~17 | Połączone konta społecznościowe, publikowanie i planowanie postów, odczyt statystyk postów |
| `/mcp/travel-agent` | ~8 | Rezerwacje realizowane przez agentów w imieniu podróżnych oraz raporty agentów |

### `https://integrations.wink.travel` — integracje channel managerów

Jeden endpoint, ponieważ ten host istnieje dla jednego zadania.

| Endpoint | Narzędzia | Co obejmuje |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | Łączenie i weryfikacja integracji channel managera, PMS lub CRS |

<Aside type="note" title="Integracja channel managera a zarządzanie własnymi cenami">
To różne zadania dla różnych osób i nie dzielą endpointu.

**Dostawca channel managera, PMS lub CRS** integruje się raz przez `integrations.wink.travel/mcp/channel-manager`, a następnie wymienia nieruchomości, ceny, dostępność i rezerwacje przez tę integrację. Ten pojedynczy endpoint to cała powierzchnia.

**Hotelarz zmieniający własne ceny ręcznie** korzysta z zestawów narzędzi extranet na `api.wink.travel` — `/mcp/extranet/rates` i pokrewnych. Nie są one częścią integracji channel managera i integrator nie ma powodu, by się z nimi łączyć.

Administracja kontem jest również na `api.wink.travel`, pod `/mcp/settings`. Na hoście integracji nie ma `/mcp/settings`.
</Aside>

Każdy endpoint ma też narzędzie `ping`, aby potwierdzić, że połączenie jest aktywne przed wykonaniem prawdziwej pracy.

## Jakie zestawy narzędzi są mi potrzebne?

| Jeśli jesteś… | Połącz się z |
|---|---|
| **Integrujesz channel managera, PMS lub CRS** | `integrations.wink.travel/mcp/channel-manager` — tylko ten |
| **Zarządzasz zawartością nieruchomości** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **Zarządzasz pokojami i typami pokoi** | `/mcp/extranet/facilities` |
| **Zarządzasz cenami i dostępnością** | `/mcp/extranet/rates` |
| **Prowadzisz codzienne rezerwacje** | `/mcp/extranet/operations` |
| **Rozwijasz dystrybucję** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **Tworzysz strony afiliacyjne** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **Prowadzisz strony link-in-bio** | `/mcp/link-manager` + `/mcp/social` |
| **Rezerwujesz w imieniu podróżnych** | `/mcp/travel-agent` |
| **Rozliczasz pieniądze** | `/mcp/payment` |
| **Budujesz doświadczenie rezerwacji** | `/mcp/booking-engine` + `/mcp/reference` |

Zacznij od jednego. Dodaj kolejny, gdy zauważysz, że czegoś brakuje — każde połączenie jest niezależne i dodanie jednego nie wpływa na pozostałe.

<Aside type="tip" title="Chcesz mieć wszystko?">
`https://api.wink.travel/mcp` i `https://integrations.wink.travel/mcp` pozostają dostępne i obsługują **wszystkie** narzędzia na swoim hoście. Są przydatne do eksploracji dostępnych narzędzi, ale nie zalecamy ich do codziennej pracy: lista narzędzi jest na tyle duża, że przytłacza Twoje zadanie i pogarsza wybór narzędzi przez agenta. Preferuj powyższe zestawy narzędzi.
</Aside>

## Jak działa uwierzytelnianie

Serwery MCP Wink używają przepływu **OAuth2 Authorization Code + PKCE** i wspierają **Dynamic Client Registration (RFC 7591)**. Oto co się dzieje przy pierwszym połączeniu:

1. Twój klient AI odkrywa serwer autoryzacji z metadanych endpointu MCP `/.well-known/oauth-protected-resource`.
2. Klient sam się rejestruje przez **Dynamic Client Registration** — nie jest potrzebna ręczna konfiguracja aplikacji.
3. Klient otwiera **kartę przeglądarki** do `https://iam.wink.travel`. Logujesz się na konto Wink i zatwierdzasz wymagane uprawnienia na ekranie zgody.
4. Wink wydaje **token dostępu** powiązany z Twoim kontem i tożsamością.
5. Klient AI dołącza token do każdego żądania MCP. Wszystkie wyniki narzędzi są automatycznie ograniczone do Twojej jednostki zarządzającej.
6. Tokeny wygasają po 3 godzinach. Twój klient AI odświeża je cicho w tle bez ponownego pytania.

Każde wywołanie narzędzia działa **pod Twoją tożsamością** — te same zasady ACL, które chronią portal internetowy, obowiązują agenta AI.

## Zakresy uprawnień

Po zatwierdzeniu ekranu zgody zobaczysz podział żądanych uprawnień. Klienci MCP używają tego samego słownictwa uprawnień co reszta platformy — zobacz pełny
[referencyjny zakres na stronie Uwierzytelniania](/pl/developers/authentication#scopes).

Dwie rzeczy są specyficzne dla MCP:

- **Zakresy `mcp.read`, `mcp.write`, `mcp.remove` są dodatkowo wymagane** do otwarcia transportu MCP. Klient posiadający zakres `mcp.*` ma dostęp do dowolnego endpointu MCP Wink, ale każde wywołanie narzędzia nadal wymusza zakres sekcji endpointu, który opakowuje (np. `booking.read`).
- **Klient AI żąda tylko potrzebnych zakresów.** Możesz odmówić pojedynczych uprawnień na ekranie zgody — narzędzia wymagające odmówionego zakresu zwrócą błąd przy wywołaniu.

**Zestawy narzędzi tego nie zmieniają.** To, do którego endpointu się łączysz, decyduje, które narzędzia są *wymienione*, a nie co im wolno robić. Połączenie z `/mcp/payment` nie daje żadnych dodatkowych uprawnień finansowych, a połączenie z `/mcp/reference` nie powstrzymuje narzędzia od wymuszania własnego zakresu. Autoryzacja jest decydowana przy wywołaniu narzędzia, na podstawie Twojego tokena i uprawnień konta.

## Rozwiązywanie problemów

**Karta przeglądarki się nie otwiera**

Twój klient AI może jeszcze nie wspierać interaktywnego przepływu PKCE. Sprawdź, czy masz najnowszą wersję:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** zaktualizuj przez wbudowany updater aplikacji

**`401 Unauthorized` po zalogowaniu**

Twój zapisany token może być nieaktualny. Usuń i dodaj ponownie serwer, aby wymusić nowe logowanie:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

Dla Claude Desktop i ChatGPT usuń wpis serwera w ustawieniach, zrestartuj aplikację i dodaj go ponownie.

**`403 Forbidden` przy wywołaniu konkretnego narzędzia**

Narzędzie wymaga zakresu, którego nie zatwierdziłeś na ekranie zgody, lub uprawnienia, którego Twoje konto nie posiada. Połącz serwer ponownie — ekran zgody pojawi się ponownie i możesz zatwierdzić brakujące uprawnienie. Jeśli nadal nie działa, narzędzie wymaga uprawnienia konta, którego nie masz; połączenie z innym zestawem narzędzi nie pomoże, bo zestawy nie nadają uprawnień.

**Narzędzie, którego potrzebuję, nie jest na liście**

Prawdopodobnie jesteś połączony z zestawem narzędzi, który nie obejmuje tego zadania. Sprawdź [katalog endpointów](#endpoint-directory) i dodaj odpowiedni zestaw — połączenia są niezależne, więc dodanie jednego nie zmienia innych. Jeśli nie wiesz, który ma to narzędzie, połącz się tymczasowo z `https://api.wink.travel/mcp`, znajdź narzędzie, a potem sprawdź, który zestaw je zawiera.

**`404 Not Found` na endpointzie zestawu narzędzi**

Sprawdź dokładnie ścieżkę — zagnieżdżone zestawy mają dwa segmenty (`/mcp/extranet/rates`, nie `/mcp/extranet-rates`), a płaskie mają jeden (`/mcp/link-manager`). Uwaga, że *niezalogowane* żądanie do dowolnej ścieżki pod `/mcp` zwraca `401`, nie `404`, więc sam `401` nie mówi, czy endpoint istnieje.

**Połączyłem się z `api.wink.travel/mcp/channel-manager` i nic nie dostałem**

Taki endpoint nie istnieje. Integracja channel managera jest obsługiwana tylko z `https://integrations.wink.travel/mcp/channel-manager`. Jeśli potrzebujesz też ręcznie czytać lub pisać własne ceny nieruchomości, to osobne zadanie na osobnym endpointcie — patrz `/mcp/extranet/rates`.

**Serwer się pojawia, ale wywołania narzędzi zwracają "konto nie znalezione"**

Jesteś zalogowany na konto Wink, które nie ma jednostki zarządzającej. Wejdź na [Wink Portal](https://app.wink.travel) i upewnij się, że Twoje konto jest poprawnie skonfigurowane przed użyciem serwera MCP.

**Token wygasa w trakcie sesji**

Tokeny są ważne przez 3 godziny. Claude Code i Claude Desktop odświeżają tokeny cicho bez przerywania sesji. Jeśli po długim bezczynności pojawią się błędy uwierzytelniania, wpisz nową wiadomość — klient automatycznie się ponownie uwierzytelni.

**Codex CLI pokazuje "MCP server unreachable"**

Sprawdź, czy Twój `~/.codex/config.json` jest poprawnym JSON-em (bez przecinków na końcu) i czy `"type": "http"` jest ustawione. Codex wymaga transportu HTTP dla serwerów zdalnych; transport stdio jest tylko dla lokalnych binariów.

**Menu "Connectors" w ChatGPT nie jest widoczne**

Wsparcie MCP wymaga wersji desktopowej ChatGPT **1.2024.352** lub nowszej oraz aktywnej subskrypcji Plus, Pro, Team lub Enterprise. Zaktualizuj aplikację i sprawdź plan w Ustawienia → Konto.

**Serwer Cursor pokazuje czerwony / "Failed to connect"**

Sprawdź, czy Twój `~/.cursor/mcp.json` jest poprawnym JSON-em i zawiera `"type": "http"`. Następnie przejdź do **Settings → Cursor Settings → MCP** i kliknij **Refresh**. Jeśli błąd się utrzymuje, całkowicie zrestartuj Cursor — zmiany konfiguracji nie zawsze są wykrywane bez restartu.

**Serwery MCP Windsurf nie pojawiają się w ustawieniach**

Windsurf wymaga pełnego restartu (nie tylko przeładowania okna), aby wykryć zmiany w `mcp_config.json`. Użyj **Plik → Zakończ** i uruchom ponownie. Jeśli serwery nadal się nie pojawiają, upewnij się, że masz Windsurf w wersji **1.4+** (Pomoc → O Windsurf).

**Opcja "Add Server" w Cline nie jest widoczna**

Menedżer serwerów MCP wymaga Cline w wersji **2.0** lub nowszej. Otwórz panel rozszerzeń VS Code, znajdź Cline i kliknij **Aktualizuj**, jeśli jest dostępna aktualizacja. Po aktualizacji przeładuj VS Code (`Ctrl+Shift+P` → "Developer: Reload Window").
