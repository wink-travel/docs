# Overview

Shows the releases that have been made for our Apps, our Platform and the Partner API contracts.

- [Applications](/changelog/application) are front-end releases.
- [Platform](/changelog/platform) are back-end releases.
- [Partner API](/changelog/partner-api) are versioned releases of the Partner
  Integrator API's protobuf wire contracts. Each one is a tagged contract that a
  generated client can be pinned to; the sources live in the public
  [partner-api-proto](https://github.com/wink-travel/partner-api-proto) mirror.
