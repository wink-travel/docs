Booking Engine upotetaan minne tahansa. Valitse kehys tai CMS ja seuraa sen ohjeita; taustalla olevat Web Components -komponentit ovat samat kaikkialla.

## Keskeiset lähestymistavat

- [Web Components](/fi/integrations/web-components/) — upotettavat elementit, joita jokainen integraatio käyttää.
- [npm package](/fi/integrations/npm/) — asenna JavaScript-rakennukseen.
- [Headless CMS](/fi/integrations/headless/) — renderöi mistä tahansa sisältötaustasta.
- [Partner API](/fi/integrations/partner-api/) — täydellinen ohjelmallinen integraatio.
