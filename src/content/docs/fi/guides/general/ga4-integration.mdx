Yhdistämällä Google Analytics 4 -omaisuutesi Winkiin, varaus tapahtumat — huoneen katseluista aina valmiisiin varauksiin asti — välittyvät automaattisesti omaan GA4-hallintapaneeliisi yhdessä Winkin oman analytiikan kanssa. Ei koodia, ei teknistä asetusta sinun puoleltasi.

<Aside type="tip">
Tarvitset GA4:stä kaksi asiaa: **Measurement ID** ja **Measurement Protocol API -salaisuuden**. Measurement ID ohjaa selaimen vierailupolkua vieraan selaimessa; API-salaisuus mahdollistaa Winkin tallentaa valmiit varaukset (`purchase`) **palvelinpuolella**, joten myyntiä ei koskaan menetetä, kun vieras ohjataan maksupalveluntarjoajan sivuille ja takaisin.
</Aside>

---

## Kuinka se toimii

```
Syötät Measurement ID:n (G-XXXXXXXXXX) ja API-salaisuuden Wink-portaaliin
       ↓
Selaustapahtumat (katselut, ostoskori, kassalle siirtyminen) virtaavat GA4-omaisuuteesi selaimesta
Valmiit varaukset (purchase) lähetetään palvelinpuolella — säilyvät maksun uudelleenohjauksen yli
       ↓
Kirjaudut analytics.google.com ja näet koko varausputkesi
```

---

## Mitä sinun tulee tehdä

<Steps>

1. **Luo GA4-omaisuus**

   Mene osoitteeseen [analytics.google.com](https://analytics.google.com): Hallinta → Luo omaisuus. Aseta aikavyöhyke ja valuutta vastaamaan markkinaasi.

2. **Luo verkkotietovirta**

   Hallinta → Tietovirrat → Lisää virta → Verkko. Syötä URL-osoitteeksi `wink.travel`. Tämä luo **Measurement ID:n** (`G-XXXXXXXXXX`). Kopioi se.

3. **Luo Measurement Protocol API -salaisuus**

   Avaa sama verkkotietovirta → vieritä kohtaan **Measurement Protocol API secrets** → **Luo**. Anna sille lempinimi (esim. "Wink") ja kopioi luotu **salainen arvo**. Tämä salaisuus mahdollistaa Winkin tallentaa valmiit varaukset palvelinpuolella, jotta myyntiä ei koskaan menetetä maksun uudelleenohjauksen aikana.

4. **Syötä Measurement ID ja API-salaisuus Wink-portaaliin**

   Kirjaudu sisään osoitteessa [app.wink.travel](https://app.wink.travel), valitse tilisi ja siirry **Mukautukset**-välilehdelle. Liitä Measurement ID ja API-salaisuus **GA4**-kenttiin ja tallenna. Siinä kaikki — GA4-integraatiosi on nyt aktiivinen.

   <Aside type="note">
   API-salaisuus on **vain kirjoitusoikeudella**: tallennuksen jälkeen sitä ei enää näytetä. Tulevissa muokkauksissa jätä salaisuus tyhjäksi, jotta aiemmin tallennettu arvo säilyy.
   </Aside>

5. **Merkitse `purchase` avaintapahtumaksi**

   Palaa GA4-omaisuuteesi: Hallinta → Tapahtumat → etsi `purchase` → kytke päälle **Merkitse avaintapahtumaksi**. Tämä saa valmiit varaukset näkymään Muunnokset-raportissasi.

6. **Tarkastele tietojasi**

   Kirjaudu osoitteeseen [analytics.google.com](https://analytics.google.com) ja näet varauksesi, tulosi ja vieraan polun — kaikki seurataan automaattisesti Winkin kautta.

</Steps>

<Aside type="note">
Tätä integraatiota varten sinun ei tarvitse asentaa seurantakoodia omalle verkkosivustollesi. Wink hoitaa kaiken. Measurement ID on kohde, johon varausdata lähetetään, ja API-salaisuus antaa Winkille mahdollisuuden vahvistaa valmiit varaukset palvelinpuolella.
</Aside>

<Aside type="tip">
**GA4:ää ja GTM:ää voi käyttää yhdessä.** Jos käytät myös Google Tag Manager -säiliötä (esim. Sojern-säiliötä), voit konfiguroida molemmat samanaikaisesti — ne eivät enää ole toisensa poissulkevia. Katso [GTM Analytics Integration](/fi/guides/developers/gtm-dual-tagging).
</Aside>

## Mitä voit seurata

Kun yhteys on muodostettu, GA4-omaisuutesi vastaanottaa koko Enhanced E-commerce -tapahtumakokoelman:

### Löytövaihe

| Tapahtuma | Mitä se tarkoittaa |
|---|---|
| `view_item_list` | Vieras näki omaisuutesi haussa tai kategorian listauksessa |
| `select_item` | Vieras klikkasi omaisuuttasi listauksesta |
| `view_item` | Vieras katsoi hotellisi yksityiskohtasivua |

### Harkintavaihe

| Tapahtuma | Mitä se tarkoittaa |
|---|---|
| `view_promotion` | Vieras näki omaisuutesi kampanjatarjouksen |
| `select_promotion` | Vieras klikkasi kampanjatarjousta |
| `add_to_wishlist` | Vieras tallensi omaisuutesi toivelistalleen |

### Varausputki

| Tapahtuma | Mitä se tarkoittaa |
|---|---|
| `add_to_cart` | Vieras valitsi huoneen tai paketin |
| `view_cart` | Vieras katsoi varausyhteenvedon |
| `remove_from_cart` | Vieras poisti huoneen tai paketin |
| `begin_checkout` | Vieras aloitti kassaprosessin |
| `add_payment_info` | Vieras syötti maksutietonsa |
| `add_shipping_info` | Vieras syötti vieraansa tiedot |
| `purchase` | Vieras teki varauksen loppuun |
| `refund` | Varaus peruttiin ja hyvitettiin |

Kaikki tapahtumat sisältävät asiaankuuluvat ulottuvuudet, kuten tulot, valuutan, huonetyypin ja varauksen arvon — tarjoten täydellisen kuvan vieraan matkasta ensimmäisestä kosketuksesta valmiiseen varaukseen. Lisäominaisuuksien ja huonetasojen ulottuvuuksien, kuten `city_name`, `cancellation_policy`, `bed_type` ja muiden avaamiseksi katso [Custom Dimensions in GA4](/fi/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4).

## Ristiin-domain-seuranta (edistynyt)

Yllä oleva perusintegraatio seuraa kaikkea, mitä Winkissä tapahtuu. Jos kuitenkin haluat seurata vieraita koko matkan omalta verkkosivustoltasi varauksen loppuun Winkissä — ja oikein kohdistaa alkuperäisen liikenteen lähteen (Google Ads, sähköpostikampanjat, orgaaninen haku jne.) — tarvitaan yksi lisätoimenpide molemmilla puolilla.

<Aside type="caution">
Tämä osio koskee vain, jos sinulla on GA4 asennettuna omalle verkkosivustollesi. Jos et käytä GA4:ää sivustollasi, yllä oleva perusintegraatio riittää.
</Aside>

### Miksi tämä on tärkeää

Ilman ristiin-domain-seurantaa vieras, joka ensin vierailee sivustollasi ja sitten tekee varauksen Winkissä, näkyy GA4:ssäsi **Suorana** istuntona ilman yhteyttä aiempaan vierailuun. Kaikki Google Ads -klikkaukset, sähköpostikampanjat tai orgaaniset haut, jotka johtivat varaukseen, eivät saa tunnustusta.

Kun ristiin-domain-seuranta on konfiguroitu, näet vieraan koko matkan:

```
google.com (maksettu mainos)
       ↓
verkkosivustosi (vieras selaa huoneita)
       ↓
wink.travel (vieras valitsee huoneen ja varaa)
       ↓
purchase kohdistetaan oikein alkuperäiseen Google Ads -klikkaukseen
```

### Toimenpide: Sinä

Konfiguroi GA4-omaisuutesi tunnistamaan `wink.travel` osana omaa domainiasi, ei ulkoisena viittauksena. Tämä kertoo GA4:lle yhdistää kaksi istuntoa yhdeksi jatkuvaksi vieraan matkaksi.

<Steps>
1. GA4 Hallinta → Tietovirrat → oma virta
2. Määritä tagiasetukset → **Määritä domainisi**
3. Lisää `wink.travel` linkitetyksi domainiksi
4. Tallenna
</Steps>

### Toimenpide: Wink

Ota yhteyttä [Wink Supportiin](https://app.wink.travel) ja anna verkkosivustosi domain (esim. `yourhotel.com`). Wink lisää domainisi viittauspoissulkulistalle Wink GA4 -omaisuudessa. Tämä estää verkkosivustoasi tallentumasta viittauslähteeksi, mikä muuten ylikirjoittaisi vieraan alkuperäisen attribuution ja aloittaisi uuden istunnon.

<Aside type="tip">
Yllä oleva perusintegraatio riittää useimmille omaisuuksille ja antaa välittömän näkyvyyden varauksiin ja tuloihin Winkissä. Ristiin-domain-seuranta on edistynyt vaihtoehto, jonka kannattaa ottaa käyttöön, kun tunnet GA4-datasi hyvin ja haluat syvempää attribuution ymmärrystä.
</Aside>
