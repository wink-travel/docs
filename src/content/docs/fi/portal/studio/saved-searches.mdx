Tallennetut haut tekevät juuri sen, mitä nimi lupaa. Matkavarastoa etsiessäsi sinulla on mahdollisuus tallentaa hakukysely myöhempää käyttöä varten.

## Hakukyselyn tallentaminen

Kun aloitat varaston etsimisen (katso [Haku](/fi/portal/studio/search) ), voit hienosäätää hakusuodattimiasi.
Hakulomakkeen alareunassa on vaihtoehto `Tallenna haku`.

Tämän linkin klikkaaminen antaa sinulle mahdollisuuden nimetä tämä haku (*esim. Taikahotellien kirjastoni*), jotta muistat sen myöhemmin.

Anna nimi ja klikkaa `Tallenna haku` -painiketta. Tämän jälkeen voit siirtyä päävalikosta kohtaan `Listat > Dynaamiset` nähdäksesi juuri luomasi tallenteen.

## Listatoiminnot

Tallennettua hakua voi käyttää matkavaraston näyttämiseen käyttäjillesi ruudukko- tai karttanäkymässä ja voit määrittää hakutulosten esitystavan haluamallasi tavalla.

Jokaisella tallennetulla hakukyselyllä on toimintoja, joita voit suorittaa:

- Muunna hakukysely [kartaksi](/fi/portal/studio/maps).
- Muunna hakukysely [ruudukoksi](/fi/portal/studio/grids).
- Poista tallennettu haku.

## API

Kehittäjät, jotka haluavat hallita tallennettuja hakuja, voivat siirtyä kohtaan [Kehittäjät > API > Selaa](/fi/api).

## Lisälukemista

- Lue lisää [Kartta](/fi/portal/studio/maps) -ominaisuuksistamme.
- Lue lisää [Ruudukko](/fi/portal/studio/grids) -ominaisuuksistamme.
