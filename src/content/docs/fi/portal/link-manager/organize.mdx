Hallinnoidaksesi WinkLinks-tagejasi, siirry päävalikosta kohtaan `WinkLinks`, klikkaa `Design`-välilehteä ja selaa alas kohtaan `Manage categories`.

Sisällön kasvaessa haluat alkaa järjestää sitä. Tätä varten loimme `tagit`. Voit ryhmitellä sisältöä niin monella tagilla kuin haluat.

## Luo tagi

<Steps>
1. Luo uusi tagi klikkaamalla `Add a new tag` -painiketta.
2. Syötä uuden tagisi nimi. *esim. Berliinin parhaat kahvilat*
3. Klikkaa `Save`-linkkiä.
</Steps>

## Päivitä tagi

<Steps>
1. Aloita klikkaamalla `Edit`-linkkiä tagin vieressä, jota haluat muokata.
2. Päivitä tagisi nimi. *esim. Berliinin parhaat kahvilat*
3. Klikkaa `Save`-linkkiä.
</Steps>

## Poista tagi

:::note
Tagin poistaminen poistaa sen myös kaikesta siihen liitetyistä sisällöistä.
:::

<Steps>
1. Klikkaa `Remove`-linkkiä tagin vieressä, jonka haluat poistaa.
</Steps>

## API

Kehittäjät, jotka haluavat hallinnoida `WinkLinks`-tageja, voivat siirtyä kohtaan [Developers > API > WinkLinks](/fi/api).
