Tällä sivulla on luettelo kaikista webhook-tapahtumista, joihin voit tilata Winkissä. Asennusohjeita varten katso [Webhook Integration Guide](/fi/developers/webhook-integration) tai [Webhooks management page](/fi/portal/settings/webhooks).

## Kuinka tilata

1. Siirry portaalissasi kohtaan **Applications > Webhooks**.
2. Luo webhook ja valitse vastaanotettavat tapahtumat.
3. Wink lähettää HTTP POST -pyynnön päätepisteeseesi aina, kun tapahtuma tapahtuu.

Täydelliset asennusohjeet ja parhaat käytännöt löytyvät kohdasta [Webhook Integration](/fi/developers/webhook-integration).
