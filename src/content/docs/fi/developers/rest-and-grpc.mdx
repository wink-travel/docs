Wink tarjoaa kaksi siirtotapaa. Kumpaa käytät, riippuu siitä, minkä API:n kanssa integroidut.

| | Siirtotapa | Skeema | Dokumentaatio |
| --- | --- | --- | --- |
| Useimmat Wink API:t | REST HTTPS:n yli | OpenAPI 3 | Mikä tahansa ryhmä **API**-kohdan alla sivupalkissa |
| Partner Integrator API | gRPC HTTP/2:n yli | Protocol Buffers | [Partner](/fi/partner-api/partner/) |

<Aside type="note" title="Emme enää julkaise kielikohtaisia SDK:ita">
  Käsin ylläpidetyt SDK:t jäivät jälkeen niiden API:iden kehityksestä, joita ne käärittivät, eivätkä koskaan kattaneet juuri tarvitsemaasi kieltä. Generoi asiakas skeemasta sen sijaan — se on aina ajan tasalla — tai anna MCP-palvelimemme kirjoittaa integraatiokoodi käyttötapauksesi mukaan.
</Aside>

## Generoi REST-asiakas

Jokainen API-ryhmä julkaisee OpenAPI 3 -dokumentin. Suuntaa mikä tahansa OpenAPI-generaattori siihen, niin saat tyypitetyn asiakkaan omalla kielelläsi.

```bash
# Jokaisen ryhmän spesifikaatio on ladattavissa tältä sivustolta: /api/downloads/<group>.json
curl -o wink-extranet.json https://wink.travel/api/downloads/extranet.json

npx @openapitools/openapi-generator-cli generate \
  -i wink-extranet.json -g typescript-fetch -o ./wink-client
```

## Generoi gRPC-asiakas

Partner Integrator API on gRPC. Generoit asiakkaan `.proto`-skeemasta, jonka Wink julkaisee kahdella tavalla:

- **Palvelimen heijastus** — palvelin kuvaa itsensä, joten työkalut kuten `grpcurl`, Postman ja Insomnia voivat löytää skeeman ajon aikana ilman tiedostojen lataamista. Heijastus vaatii saman bearer-tokenin kuin muutkin kutsut.
- **`.proto`-tiedostot**, jos haluat mieluummin sisällyttää skeeman ja generoida etukäteen.

```bash
# Löydä skeema käynnissä olevalta palvelimelta (autentikoitu).
grpcurl -H "authorization: Bearer $WINK_TOKEN" \
  partner.wink.travel:443 list

# Sitten generoi asiakas — tässä Go; kaikki tuetut kielet toimivat samalla tavalla.
protoc --go_out=. --go-grpc_out=. partner_lookup.proto
```

Kutsut kuljettavat bearer-tokenisi `authorization`-metadataotsikossa, aivan kuten REST kuljettaa sen `Authorization`-otsikossa. Virheet saapuvat gRPC-tilakoodina vastauksen trailer-osassa HTTP-tilakoodin sijaan — [Partnerin referenssi](/fi/partner-api/partner/) listaa odotettavissa olevat tilakoodit.

## Tai anna MCP-palvelimen kirjoittaa se

Jos käytät tekoälypohjaista koodausavustajaa, MCP-palvelimemme on nopein reitti. Se tarjoaa Wink API:t työkaluina, joita avustajasi voi kutsua ja joiden perusteella se voi tehdä päätelmiä, joten sen sijaan, että generoit koko asiakkaan ja etsisit päätepisteet itse, kuvailet mitä rakennat ja saat integraatiokoodin, joka on muokattu käyttötapaukseesi.
