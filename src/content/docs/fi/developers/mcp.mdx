Wink tarjoaa kaksi todennettua MCP-palvelinta. Molemmat käyttävät **interaktiivista OAuth2-kirjautumista** (PKCE-valtuutuskoodivirta) — tekoälyagenttisi avaa selaimen välilehden, jossa kirjaudut sisään Wink-tililläsi. Asiakassalaisuuksia ei tarvitse hallita.

| Palvelin | URL | Mitä se tekee |
|--------|-----|--------------|
| **Inventory API** | `https://api.wink.travel/mcp` | Varastot, varaukset, hinnat, myyntikanavat, analytiikka ja kaikki alustan toiminnot |
| **Integrations** | `https://integrations.wink.travel/mcp` | Kanavahallinnan integraatiot — synkronoi kohteet, hinnat ja saatavuus OTA-kanavien kanssa |

---

## Miten todennus toimii

Wink MCP -palvelimet käyttävät **OAuth2 Authorization Code + PKCE** -virtaa ja tukevat **Dynamic Client Registration (RFC 7591)** -rekisteröintiä. Näin tapahtuu, kun yhdistät ensimmäistä kertaa:

1. Tekoälyasiakas löytää valtuutuspalvelimen MCP-päätepisteen `/.well-known/oauth-protected-resource` -metatietojen avulla.
2. Asiakas rekisteröityy itse **Dynamic Client Registration** -menetelmällä — manuaalista sovelluksen asetusta ei tarvita.
3. Asiakas avaa **selaimen välilehden** osoitteeseen `https://iam.wink.travel`. Kirjaudut sisään Wink-tililläsi ja hyväksyt pyydetyt käyttöoikeudet suostumusnäytöllä.
4. Wink myöntää **access tokenin**, joka on rajattu tilillesi ja linkitetty identiteettiisi.
5. Tekoälyasiakas liittää tokenin jokaiseen MCP-pyyntöön. Kaikki työkalujen tulokset rajataan automaattisesti hallinnoivaan yksikköösi.
6. Tokenit vanhenevat 3 tunnin kuluttua. Tekoälyasiakas päivittää ne hiljaisesti taustalla ilman uutta kehotetta.

Jokainen työkalukutsu suoritetaan **identiteettisi alla** — samat ACL-säännöt, jotka suojaavat verkkosivustoa, pätevät myös tekoälyagenttiin.

## Yhdistä tekoälyasiakkaasi

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Varmista, että Claude Code on ajan tasalla:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Lisää Wink Inventory MCP -palvelin:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code ottaa yhteyden palvelimeen, löytää valtuutuspalvelimen ja avaa oletusselaimesi.

4. **Kirjaudu sisään Wink-tililläsi** ja hyväksy käyttöoikeuspyyntö suostumusnäytöllä.

5. Claude Code vahvistaa yhteyden. Kirjoita `/mcp` varmistaaksesi, että palvelin näkyy ja sen työkalut ovat ladattu.
</Steps>

Jos haluat lisätä myös Integrations-palvelimen:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Jaa tiimisi kanssa]
Lisää `--scope project` komentoon `claude mcp add`, jolloin Claude Code tallentaa palvelimen URL-osoitteen `.mcp.json` -tiedostoon projektin juureen. Tee commit tästä tiedostosta — jokainen tiimin jäsen suorittaa oman selaimen kirjautumisen ensimmäisellä kerralla.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Muokkaa Claude Desktopin konfiguraatiotiedostoa:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. Lisää MCP-palvelinmerkinnät:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **Sulje Claude Desktop kokonaan ja käynnistä uudelleen** (käytä valikkorivin Quit-toimintoa — pelkkä ikkunan sulkeminen ei riitä).

4. Claude Desktop avaa selaimen välilehden jokaiselle uudelle palvelimelle. Kirjaudu sisään Wink-tililläsi ja hyväksy käyttöoikeudet.

5. Alapalkin pistokekuvake näyttää molemmat palvelimet yhdistettyinä.
</Steps>

  </TabItem>

   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",

       },

         "type": "http",

4. Käynnistä Codex. Ensimmäisellä käyttökerralla Codex avaa selaimen välilehden osoitteeseen `https://iam.wink.travel`.

5. **Kirjaudu sisään Wink-tililläsi** ja hyväksy pyydetyt käyttöoikeudet.

6. Codex vahvistaa yhteyden. Suorita `codex` ja pyydä listaamaan käytettävissä olevat työkalut varmistaaksesi, että Wink-palvelimet ovat aktiivisia.

  <TabItem label="ChatGPT">

MCP-palvelintuki on saatavilla **ChatGPT-työpöytäsovelluksessa** Plus-, Pro-, Team- ja Enterprise-tilaajille.

<Steps>
1. Lataa ja asenna [ChatGPT-työpöytäsovellus](https://openai.com/chatgpt/download/), jos et ole vielä tehnyt niin.

2. Avaa sovellus ja klikkaa **profiilikuvakettasi** oikeassa yläkulmassa, valitse sitten **Asetukset**.

3. Mene kohtaan **Liittimet** (tai **MCP-palvelimet** sovellusversiostasi riippuen) ja klikkaa **Lisää**.

4. Syötä Wink Inventory -palvelimen URL:
   ```
   https://api.wink.travel/mcp
   ```
   Klikkaa sitten **Yhdistä**.

5. ChatGPT avaa selaimen välilehden osoitteeseen `https://iam.wink.travel`. **Kirjaudu sisään Wink-tililläsi** ja hyväksy käyttöoikeudet.

6. Toista vaiheet 4–5 Integrations-palvelimelle:
   ```
   https://integrations.wink.travel/mcp
   ```

7. Molemmat palvelimet näkyvät liittimissäsi. Aloita uusi keskustelu — Wink-työkalut ovat automaattisesti käytettävissä.
</Steps>

:::note[Verkkosovelluksen rajoitus]
MCP-palvelimia voi määrittää vain **työpöytäsovelluksessa**. ChatGPT:n verkkokäyttöliittymä chatgpt.com ei tue mukautettuja MCP-palvelimia.
:::

## Oikeudet (Scopes)

Kun hyväksyt suostumusnäytön, näet erittelyn siitä, mitä agentti pyytää. MCP-asiakkaat käyttävät samaa käyttöoikeussanastoa kuin muu alusta — katso täydellinen
[käyttöoikeusviite Todennus-sivulla](/fi/developers/authentication#scopes).

Kaksi asiaa on erityisiä MCP:lle:

- **`mcp.read`, `mcp.write` ja `mcp.remove` -oikeudet vaaditaan lisäksi** MCP-yhteyden avaamiseen. Asiakas, jolla on `mcp.*` -oikeus, pääsee `/mcp`-päätepisteeseen, mutta jokainen kutsuma työkalu tarkistaa edelleen oman päätepisteensä osio-oikeudet (esim. `booking.read`).
- **Tekoälyasiakas pyytää vain tarvitsemansa oikeudet.** Voit kieltää yksittäisiä oikeuksia suostumusnäytöllä — työkalut, jotka vaativat kiellettyä oikeutta, palauttavat virheen kutsuttaessa.

## Vianmääritys

**Selaimen välilehti ei avaudu**

Tekoälyasiakkaasi ei ehkä vielä tue interaktiivista PKCE-virtaa. Varmista, että käytössäsi on uusin versio:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** päivitä sovelluksen sisäisellä päivitystyökalulla

**`401 Unauthorized` kirjautumisen jälkeen**

Välimuistissa oleva token voi olla vanhentunut. Poista ja lisää palvelin uudelleen, jolloin kirjautuminen käynnistyy uudestaan:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

Claude Desktopissa ja ChatGPT:ssä poista palvelin asetuksista, käynnistä sovellus uudelleen ja lisää palvelin uudestaan.

**`403 Forbidden` tiettyä työkalua kutsuttaessa**

Työkalu vaatii oikeuden, jota et hyväksynyt suostumusnäytöllä. Yhdistä palvelin uudelleen — suostumusnäyttö tulee uudestaan ja voit hyväksyä puuttuvan oikeuden.

**Palvelin näkyy, mutta työkalukutsut palauttavat "account not found"**

Olet kirjautunut Wink-tilille, jolla ei ole hallinnoivaa yksikköä. Mene [Wink Portaliin](https://app.wink.travel) ja varmista, että tilisi on asetettu oikein ennen MCP-palvelimen käyttöä.

**Token vanhenee istunnon aikana**

Tokenit ovat voimassa 3 tuntia. Claude Code ja Claude Desktop päivittävät tokenit hiljaisesti ilman keskeytystä. Jos näet todennusvirheitä pitkän käyttämättömyyden jälkeen, kirjoita uusi viesti — asiakas todennus uudelleen automaattisesti.

**Codex CLI näyttää "MCP server unreachable"**

Tarkista, että `~/.codex/config.json` on kelvollinen JSON (ei ylimääräisiä pilkkuja) ja että `"type": "http"` on asetettu. Codex vaatii HTTP-siirron etäpalvelimille; stdio-siirto on tarkoitettu vain paikallisille binääreille.

**ChatGPT:n "Connectors" -valikko puuttuu**

MCP-tuki vaatii ChatGPT-työpöytäsovelluksen version **1.2024.352** tai uudemman sekä aktiivisen Plus-, Pro-, Team- tai Enterprise-tilauksen. Päivitä sovellus ja tarkista tilausasetuksista.

**Cursor-palvelin näyttää punaisena / "Failed to connect"**

Varmista, että `~/.cursor/mcp.json` on kelvollinen JSON ja sisältää `"type": "http"`. Mene sitten **Asetukset → Cursor-asetukset → MCP** ja klikkaa **Päivitä**. Jos virhe jatkuu, käynnistä Cursor kokonaan uudelleen — konfiguraatiomuutokset eivät aina päivity ilman uudelleenkäynnistystä.

**Windsurf MCP -palvelimia ei näy asetuksissa**

Windsurf vaatii täydellisen uudelleenkäynnistyksen (ei pelkkää ikkunan uudelleenlatausta) `mcp_config.json` -muutosten havaitsemiseksi. Käytä **Tiedosto → Lopeta** ja käynnistä uudelleen. Jos palvelimet eivät vieläkään näy, varmista, että käytössäsi on Windsurf **1.4+** kohdasta **Ohje → Tietoja Windsurfista**.

**Cline "Lisää palvelin" -vaihtoehto ei näy**

MCP-palvelinhallinta vaatii Cline-version **2.0** tai uudemman. Avaa VS Code -laajennukset, etsi Cline ja klikkaa **Päivitä**, jos päivitys on saatavilla. Päivityksen jälkeen lataa VS Code uudelleen (`Ctrl+Shift+P` → "Developer: Reload Window").
