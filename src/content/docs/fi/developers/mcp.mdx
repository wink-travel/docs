Winkin MCP-työkalut julkaistaan **työkalusarjoina** — kohdennettuina päätepisteinä, joista kukin kattaa yhden tehtävän. Yhdistät tekoälyasiakkaasi yhteen tai kahteen, jotka vastaavat työsi tarpeita, et kaikkiin.

Jokainen päätepiste käyttää **interaktiivista OAuth2-kirjautumista** (PKCE-valtuutuskoodivirta): tekoälyagenttisi avaa selaimen välilehden, kirjaudut sisään Wink-tililläsi, ja se on siinä. Asiakassalaisuuksia ei tarvitse hallita.

```bash title="Kanavahallinnan integroija yhdistää yhteen päätepisteeseen"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="Hotelliyrittäjä, joka hallinnoi omia hintojaan, yhdistää toiseen"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

---

## Miksi työkalut on jaettu päätepisteisiin

Wink tarjoaa noin 500 työkalua. Kaikkien antaminen agentille kerralla on teknisesti mahdollista — mutta huono idea.

**Työkalumääritelmät kuluttavat kontekstia.** Jokainen MCP-palvelimen mainostama työkalu ladataan mallin konteksti-ikkunaan ennen työn aloittamista, mukaan lukien sen kuvaus ja täydellinen parametrikaavio. Viisisataa työkalua vie suuren osan budjetista, jota varsinaiseen tehtävääsi tarvitaan, jokaisella pyynnöllä.

**Valinnan laatu heikkenee listan kasvaessa.** Agentti, joka valitsee 500 samankaltaisesti nimetyistä työkaluista, tekee huonompia valintoja kuin agentti, joka valitsee 40:stä. Jos integroit kanavahallinnan, noin kaksikymmentä työkalua on sinulle relevantteja; loput 480 ovat melua, joka vaikeuttaa oikean työkalun löytämistä.

**Työ on aidosti erotettavissa.** Henkilö, joka synkronoi saatavuutta PMS:stä, ja henkilö, joka kuratoi affiliate-laskeutumissivuja, jakavat lähes nolla työkalua. Tehtäväkohtainen jako tarkoittaa, että jokainen yhteys kantaa yhden tehtävän sanaston.

<Aside type="caution" title="Työkalusarjat eivät ole käyttöoikeuksia">
Kapean työkalusarjan valinta **ei** rajoita tilisi toimintoja, eikä laajan valinta anna mitään ylimääräistä. Jokainen työkalu noudattaa samoja tilin käyttöoikeuksia kuin verkkosivusto, kirjautuneen identiteettisi alla. Jos tilisi ei voi perua varausta Wink Portalissa, agenttikaan ei voi — riippumatta siitä, mihin päätepisteeseen se on yhdistetty.

Valitse työkalusarjat **keskittymisen** vuoksi, ei turvallisuuden.
</Aside>

## Päätepistehakemisto

Kaksi isäntää palvelee työkalusarjoja. Työkalujen määrät ovat likimääräisiä ja kasvavat ajan myötä.

### `https://api.wink.travel` — alusta

| Päätepiste | Työkalut | Mitä se kattaa |
|---|---:|---|
| `/mcp/extranet/facilities` | ~64 | Varattava ja paikan päällä oleva inventaario: vierashuoneet ja huonetyypit, kylpylät, ravintolat, kokoustilat, aktiviteetit, nähtävyydet, paikat, muut myytävät kohteet |
| `/mcp/extranet/property` | ~62 | Kiinteistötiedot ja kaupalliset ehdot: profiili ja sisältö, lisäpalvelut, peruutusehdot, edut, ilmoitukset |
| `/mcp/settings` | ~60 | Tilin hallinta: hallinnoivan yksikön profiili ja brändäys, johtajat ja heidän valtuutuksensa, räätälöinti, webhookit, ilmoitusasetukset |
| `/mcp/studio/embeds` | ~48 | Kuratoidun inventaarion julkaisu: widgetit, ruudukot ja järjestetyt ruudukot, kortit, kartat, syvät linkit inventaarioon ja toimittajasivuille |
| `/mcp/extranet/rates` | ~44 | Hinnat ja saatavuus: inventaarion hintakaudet ja allokaatiot, hintasuunnitelmat, päähinnat, erikois- ja kampanjahinnat |
| `/mcp/extranet/operations` | ~39 | Kiinteistön päivittäinen hallinta: varaukset ja niiden elinkaari, vieraspalautteet ja vastaukset, kalenterisyötteet, aikataulutetut tehtävät |
| `/mcp/extranet/distribution` | ~37 | Missä inventaario myydään: myyntikanavat ja hintamuokkaajat, affiliate- ja toimittajasuhdepyynnöt, rekisteröinti, liidien keruu |
| `/mcp/studio/curation` | ~35 | Kaupallistettavien kokoelmien rakentaminen: staattiset ja dynaamiset listat, järjestetyt listat, tallennetut haut, kiinteistökokonaisuudet |
| `/mcp/link-manager` | ~28 | Syndikoidut linkkikokoelmat, niiden suunnittelu, kategoriat ja tagit, sekä lyhennetyt URL-osoitteet |
| `/mcp/reference` | ~24 | Vain luku -hakutiedot: maat, valuutat ja valuuttakurssit, kielet, aikavyöhykkeet, maantieteelliset haut, IP-sijainti |
| `/mcp/analytics` | ~18 | Varaus- ja tulosanalyytiikka: yleiskatsaukset, viivakaaviot, tulostaulut, affiliate-suorituskyky, jakomittarit |
| `/mcp/payment` | ~18 | Taloudelliset toiminnot: kirjanpito, nostot ja kuluarviot, varausrahastojen yhteenvedot |
| `/mcp/booking-engine` | ~17 | Matkustajalle suunnattu ostopolku: haku ja haku, ostoskori ja kassalle siirtyminen, bucket-listat, kampanjan räätälöinti |
| `/mcp/social` | ~17 | Yhdistetyt sosiaalitilit, julkaisujen ja aikataulutuksen hallinta, julkaisujen analytiikan lukeminen |
| `/mcp/travel-agent` | ~8 | Agentin avustamat varaukset matkustajien puolesta ja agenttiraportit |

### `https://integrations.wink.travel` — kanavahallinnan integraatiot

Yksi päätepiste, koska tämä isäntä on olemassa yhtä tehtävää varten.

| Päätepiste | Työkalut | Mitä se kattaa |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | Kanavahallinnan, PMS:n tai CRS:n yhdistäminen ja vahvistaminen |

<Aside type="note" title="Kanavahallinnan integrointi vs. omien hintojen hallinta">
Nämä ovat eri tehtäviä eri ihmisille, eikä niillä ole yhteistä päätepistettä.

**Kanavahallinnan, PMS:n tai CRS:n toimittaja** integroituu kerran osoitteessa `integrations.wink.travel/mcp/channel-manager` ja vaihtaa sen jälkeen kiinteistöt, hinnat, saatavuuden ja varaukset tämän integraation kautta. Tämä yksittäinen päätepiste kattaa kaiken.

**Hotelliyrittäjä, joka muuttaa omia hintojaan käsin**, käyttää extranet-työkalusarjoja osoitteessa `api.wink.travel` — `/mcp/extranet/rates` ja kumppanit. Nämä eivät kuulu kanavahallinnan integraatioon, eikä integraattorilla ole syytä yhdistää niihin.

Tilinhallinta on myös `api.wink.travel`-osoitteessa, `/mcp/settings`. Integraatioisännällä ei ole `/mcp/settings`-päätepistettä.
</Aside>

Jokainen päätepiste sisältää myös `ping`-työkalun, jolla voit varmistaa yhteyden olevan elossa ennen varsinaista työtä.

## Mitä työkalusarjoja tarvitsen?

| Jos olet… | Yhdistä |
|---|---|
| **Integroimassa kanavahallintaa, PMS:ää tai CRS:ää** | `integrations.wink.travel/mcp/channel-manager` — vain tämä |
| **Hallinnoimassa kiinteistön sisältöä** | `/mcp/extranet/property` + `/mcp/extranet/facilities` |
| **Hallinnoimassa huoneita ja huonetyyppejä** | `/mcp/extranet/facilities` |
| **Hallinnoimassa hintoja ja saatavuutta** | `/mcp/extranet/rates` |
| **Hoitaessa päivittäisiä varauksia** | `/mcp/extranet/operations` |
| **Kasvattamassa jakelua** | `/mcp/extranet/distribution` + `/mcp/analytics` |
| **Rakentamassa affiliate-sivuja** | `/mcp/studio/curation` + `/mcp/studio/embeds` |
| **Hoitaessa link-in-bio -sivuja** | `/mcp/link-manager` + `/mcp/social` |
| **Varaamassa matkustajien puolesta** | `/mcp/travel-agent` |
| **Sovittamassa rahaliikennettä** | `/mcp/payment` |
| **Rakentamassa varauskokemusta** | `/mcp/booking-engine` + `/mcp/reference` |

Aloita yhdellä. Lisää toinen, kun huomaat tarvitsevasi jotain, mitä se ei osaa — jokainen yhteys on itsenäinen, eikä yhden lisääminen vaikuta muihin.

<Aside type="tip" title="Haluatko silti kaiken?">
`https://api.wink.travel/mcp` ja `https://integrations.wink.travel/mcp` ovat edelleen saatavilla ja tarjoavat **kaikki** työkalut isäntänsä kautta. Ne ovat hyödyllisiä tutustumiseen, mutta emme suosittele niitä päivittäiseen käyttöön: työkalulista on niin suuri, että se häiritsee tehtävääsi ja heikentää agentin työkalujen valintaa. Suosi yllä olevia työkalusarjoja.
</Aside>

## Miten todennus toimii

Wink MCP -palvelimet käyttävät **OAuth2 Authorization Code + PKCE** -virtaa ja tukevat **Dynamic Client Registration (RFC 7591)** -toimintoa. Näin tapahtuu, kun yhdistät ensimmäistä kertaa:

1. Tekoälyasiakkaasi löytää valtuutuspalvelimen MCP-päätepisteen `/.well-known/oauth-protected-resource` -metadatasta.
2. Asiakas rekisteröityy itse **Dynamic Client Registration** -menetelmällä — manuaalista sovelluksen asetusta ei tarvita.
3. Asiakas avaa **selaimen välilehden** osoitteeseen `https://iam.wink.travel`. Kirjaudut sisään Wink-tililläsi ja hyväksyt pyydetyt käyttöoikeudet suostumusnäytöllä.
4. Wink myöntää **käyttöoikeustunnuksen**, joka on sidottu tiliisi ja identiteettiisi.
5. Tekoälyasiakas liittää tunnuksen jokaiseen MCP-pyyntöön. Kaikki työkalujen tulokset rajataan automaattisesti hallinnoivan yksikön mukaan.
6. Tunnukset vanhenevat 3 tunnin kuluttua. Tekoälyasiakas päivittää ne hiljaisesti taustalla ilman uutta kehotetta.

Jokainen työkalukutsu suoritetaan **identiteettisi alla** — samat käyttöoikeussäännöt, jotka suojaavat verkkosivustoa, koskevat myös tekoälyagenttia.

## Käyttöoikeudet

Kun hyväksyt suostumusnäytön, näet erittelyn agentin pyytämistä oikeuksista. MCP-asiakkaat käyttävät samaa käyttöoikeussanastoa kuin muu alusta — katso täydellinen [käyttöoikeusviite Todennus-sivulta](/fi/developers/authentication#scopes).

Kaksi asiaa on erityisiä MCP:lle:

- **`mcp.read` `mcp.write` `mcp.remove` -oikeudet vaaditaan lisäksi** MCP-yhteyden avaamiseen. Asiakas, jolla on `mcp.*`-oikeus, pääsee mihin tahansa Wink MCP -päätepisteeseen, mutta jokainen kutsuttu työkalu noudattaa edelleen päätepisteen osio-oikeuksia (esim. `booking.read`).
- **Tekoälyasiakas pyytää vain tarvitsemansa oikeudet.** Voit kieltää yksittäiset oikeudet suostumusnäytöllä — työkalut, jotka vaativat kiellettyä oikeutta, palauttavat virheen kutsuttaessa.

**Työkalusarjat eivät muuta tätä.** Päätepiste, johon yhdistät, päättää, mitkä työkalut *listataan*, ei mitä ne *saavat tehdä*. Yhdistäminen `/mcp/payment`-päätepisteeseen ei anna taloudellisia oikeuksia, joita sinulla ei jo ole, eikä yhdistäminen `/mcp/reference`-päätepisteeseen estä siellä olevaa työkalua noudattamasta omia oikeuksiaan. Valtuutus päätetään jokaisessa työkalukutsussa tokenin ja tilisi valtuuksien perusteella.

## Vianmääritys

**Selaimen välilehti ei avaudu**

Tekoälyasiakkaasi ei ehkä vielä tue interaktiivista PKCE-virtaa. Varmista, että käytät uusinta versiota:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT työpöytä:** päivitä sovelluksen sisäisellä päivitystyökalulla

**`401 Unauthorized` kirjautumisen jälkeen**

Välimuistissa oleva token voi olla vanhentunut. Poista palvelin ja lisää se uudelleen, jolloin kirjautuminen käynnistyy uudestaan:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

Claude Desktopissa ja ChatGPT:ssä poista palvelin asetuksista, käynnistä sovellus uudelleen ja lisää palvelin uudelleen.

**`403 Forbidden` tiettyä työkalua kutsuttaessa**

Työkalu vaatii oikeuden, jota et hyväksynyt suostumusnäytöllä, tai tililläsi ei ole tarvittavaa oikeutta. Yhdistä palvelin uudelleen — suostumusnäyttö tulee uudestaan ja voit hyväksyä puuttuvan oikeuden. Jos virhe jatkuu, työkalu tarvitsee tilioikeuden, jota sinulla ei ole; eri työkalusarjaan yhdistäminen ei auta, koska työkalusarjat eivät myönnä oikeuksia.

**Tarvittava työkalu ei ole listassa**

Olet todennäköisesti yhdistänyt työkalusarjaan, joka ei kata kyseistä tehtävää. Tarkista [päätepistehakemisto](#endpoint-directory) ja lisää oikea työkalusarja — yhteydet ovat itsenäisiä, joten yhden lisääminen ei vaikuta muihin. Jos et ole varma, mikä sarja sisältää työkalun, yhdistä väliaikaisesti `https://api.wink.travel/mcp`, etsi työkalu ja katso, missä työkalusarjassa se on.

**`404 Not Found` työkalusarjan päätepisteessä**

Tarkista polku huolellisesti — sisäkkäisillä työkalusarjoilla on kaksi segmenttiä (`/mcp/extranet/rates`, ei `/mcp/extranet-rates`), ja tasaisilla yksi (`/mcp/link-manager`). Huomaa, että *tunnistamaton* pyyntö mihin tahansa `/mcp`-polun alle palauttaa `401`, ei `404`, joten pelkkä `401` ei kerro, onko päätepistettä olemassa.

**Yhdistin `api.wink.travel/mcp/channel-manager` eikä mitään tapahtunut**

Tätä päätepistettä ei ole olemassa. Kanavahallinnan integraatio palvellaan vain osoitteessa `https://integrations.wink.travel/mcp/channel-manager`. Jos sinun täytyy myös lukea tai kirjoittaa kiinteistön omia hintoja käsin, se on eri tehtävä eri päätepisteessä — katso `/mcp/extranet/rates`.

**Palvelin näkyy, mutta työkalukutsut palauttavat "account not found"**

Olet kirjautunut Wink-tilille, jolla ei ole hallinnoivaa yksikköä. Mene [Wink Portaliin](https://app.wink.travel) ja varmista, että tilisi on asetettu oikein ennen MCP-palvelimen käyttöä.

**Token vanhenee istunnon aikana**

Tokenit ovat voimassa 3 tuntia. Claude Code ja Claude Desktop päivittävät tokenit hiljaisesti ilman keskeytystä. Jos näet todennusvirheitä pitkän käyttämättömyyden jälkeen, kirjoita uusi viesti — asiakas todennus uudelleen automaattisesti.

**Codex CLI näyttää "MCP server unreachable"**

Tarkista, että `~/.codex/config.json` on kelvollinen JSON (ei loppupisteitä) ja että `"type": "http"` on asetettu. Codex vaatii HTTP-siirron etäpalvelimille; stdio-siirto on vain paikallisille binääreille.

**ChatGPT:n "Connectors" -valikko puuttuu**

MCP-tuki vaatii ChatGPT:n työpöytäsovelluksen version **1.2024.352** tai uudemman ja aktiivisen Plus-, Pro-, Team- tai Enterprise-tilauksen. Päivitä sovellus ja tarkista tilisi tiedot kohdasta Asetukset → Tili.

**Cursor-palvelin näyttää punaisena / "Failed to connect"**

Varmista, että `~/.cursor/mcp.json` on kelvollinen JSON ja sisältää `"type": "http"`. Mene sitten kohtaan **Asetukset → Cursor-asetukset → MCP** ja klikkaa **Päivitä**. Jos virhe jatkuu, käynnistä Cursor kokonaan uudelleen — asetusten muutokset eivät aina päivity ilman uudelleenkäynnistystä.

**Windsurf MCP -palvelimia ei näy asetuksissa**

Windsurf vaatii täydellisen uudelleenkäynnistyksen (ei pelkkää ikkunan uudelleenlatausta) `mcp_config.json` -muutosten havaitsemiseksi. Käytä **Tiedosto → Lopeta** ja käynnistä uudelleen. Jos palvelimia ei vieläkään näy, varmista, että käytössäsi on Windsurfin versio **1.4+** kohdasta **Ohje → Tietoja Windsurfista**.

**Cline "Lisää palvelin" -vaihtoehto ei näy**

MCP-palvelinhallinta vaatii Cline-version **2.0** tai uudemman. Avaa VS Code -laajennukset-paneeli, etsi Cline ja klikkaa **Päivitä**, jos päivitys on saatavilla. Päivityksen jälkeen lataa VS Code uudelleen (`Ctrl+Shift+P` → "Developer: Reload Window").
