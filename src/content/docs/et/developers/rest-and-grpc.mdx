Wink pakub kahte transpordimeetodit. Millist kasutada, sõltub sellest, millise API-ga te integreerite.

| | Transport | Skeem | Dokumentatsioon |
| --- | --- | --- | --- |
| Enamik Wink API-sid | REST üle HTTPS | OpenAPI 3 | Kõik grupid, mis on külgribal **API** all |
| Partner Integrator API | gRPC üle HTTP/2 | Protocol Buffers | [Partner](/et/partner-api/partner/) |

<Aside type="note" title="Me ei avalda enam keele SDK-sid">
  Käsitsi hooldatud SDK-d jäid API-dele, mida nad katavad, maha ega toetanud kunagi teie tegelikult vajaminevat keelt. Genereerige klient skeemist — see on alati ajakohane — või laske meie MCP serveril kirjutada integratsioonikood, mis on kohandatud teie kasutusjuhtumile.
</Aside>

## Genereeri REST klient

Iga API grupp avaldab OpenAPI 3 dokumendi. Suunake mis tahes OpenAPI generaator sellele ja saate oma keeles tüübistatud kliendi.

```bash
# Grupi spetsifikatsioon on saadaval selle viite lehe kõrval.
curl -o wink-extranet.json https://api.wink.travel/v3/api-docs/extranet

npx @openapitools/openapi-generator-cli generate \
  -i wink-extranet.json -g typescript-fetch -o ./wink-client
```

## Genereeri gRPC klient

Partner Integrator API on gRPC. Genereerite kliendi `.proto` skeemist, mida Wink avaldab kahel viisil:

- **Serveri peegeldus** — server kirjeldab ennast, nii et tööriistad nagu `grpcurl`, Postman ja Insomnia saavad skeemi jooksvalt avastada ilma faile alla laadimata. Peegeldus nõuab sama bearer tokenit nagu iga teinegi päring.
- **`.proto` failid**, kui soovite skeemi eelnevalt hankida ja genereerida.

```bash
# Avasta skeem töötavast serverist (autentitud).
grpcurl -H "authorization: Bearer $WINK_TOKEN" \
  partner.wink.travel:443 list

# Seejärel genereeri klient — siin Go; iga toetatud keel töötab samamoodi.
protoc --go_out=. --go-grpc_out=. partner_lookup.proto
```

Päringud kannavad teie bearer tokenit `authorization` metaandmete päises, täpselt nagu REST kannab seda `Authorization` päises. Veateated tulevad gRPC staatusekoodina vastuse jaluses, mitte HTTP staatusekoodina — [Partneri viide](/et/partner-api/partner/) loetleb oodatavad staatused.

## Või lase MCP serveril see kirjutada

Kui kasutate AI koodiassistenti, on meie MCP server kiireim tee. See pakub Wink API-sid tööriistadena, mida teie assistent saab kutsuda ja mille üle mõelda, nii et selle asemel, et genereerida terve klient ja ise lõpp-punktid leida, kirjeldage, mida ehitate, ja saate integratsioonikoodi, mis on kohandatud teie vajadustele.
