Wink pakub kahte autentitud MCP serverit. Mõlemad kasutavad **interaktiivset OAuth2 sisselogimist** (PKCE autoriseerimiskoodi voog) — sinu AI agent avab brauseri vahelehe, et saaksid sisse logida oma Wink kontoga. Klientide saladusi ei ole vaja hallata.

| Server | URL | Mida see teeb |
|--------|-----|---------------|
| **Inventory API** | `https://api.wink.travel/mcp` | Inventar, broneeringud, hinnad, müügikanalid, analüütika ja kõik platvormi toimingud |
| **Integrations** | `https://integrations.wink.travel/mcp` | Kanalihalduri integratsioonid — sünkroniseeri majutusasutused, hinnad ja saadavus OTA-dega |

---

## Kuidas autentimine töötab

Wink MCP serverid kasutavad **OAuth2 autoriseerimiskoodi + PKCE** voogu ja toetavad **dünaamilist kliendiregistreerimist (RFC 7591)**. Esmakordsel ühendamisel toimub järgnev:

1. Sinu AI klient leiab autoriseerimisserveri MCP lõpp-punkti `/.well-known/oauth-protected-resource` metaandmete kaudu.
2. Klient registreerib end ise läbi **dünaamilise kliendiregistreerimise** — käsitsi rakenduse seadistust pole vaja.
3. Klient avab **brauseri vahelehe** aadressil `https://iam.wink.travel`. Sa logid sisse oma Wink kontoga ja kinnitad nõutud õigused nõusoleku ekraanil.
4. Wink väljastab sinu kontole ja identiteediga seotud **juurdepääsutokeni**.
5. AI klient lisab tokeni igale MCP päringule. Kõik tööriistade tulemused on automaatselt seotud sinu haldusüksusega.
6. Tokenid aeguvad 3 tunni pärast. Sinu AI klient uuendab neid vaikselt taustal ilma uuesti sisselogimist nõudmata.

Iga tööriista päring käib **sinu identiteedi all** — samad ACL reeglid, mis kaitsevad veebipaneeli, kehtivad ka AI agendi puhul.

## Ühenda oma AI klient

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Veendu, et Claude Code on ajakohane:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Lisa Wink Inventory MCP server:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code võtab serveriga ühendust, leiab autoriseerimisserveri ja avab sinu vaikimisi brauseri.

4. **Logi sisse Wink kontoga** ja kinnita nõusoleku ekraanil õigused.

5. Claude Code kinnitab ühenduse. Kontrollimiseks kirjuta `/mcp`, et näha, kas server on lisatud ja tööriistad laetud.
</Steps>

Integratsioonide serveri lisamiseks:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Jaga oma meeskonnaga]
Lisa `--scope project` käsule `claude mcp add` ja Claude Code kirjutab serveri URL-i `.mcp.json` faili projekti juurkausta. Kommiteeri see fail — iga meeskonnaliige teeb esimesel ühendamisel oma brauseri sisselogimise.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Muuda Claude Desktop konfiguratsioonifaili:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. Lisa MCP serveri kirjed:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **Sulge täielikult ja käivita uuesti** Claude Desktop (kasuta menüüriba Quit valikut — akna sulgemine ei ole piisav).

4. Claude Desktop avab iga uue serveri jaoks brauseri vahelehe. Logi sisse Wink kontoga ja kinnita õigused.

5. Alumise tööriistariba pistiku ikoon näitab mõlema serveri ühendatuna.
</Steps>

  </TabItem>

       "wink-inventory": {
         "type": "http",

       "wink-integrations": {
         "type": "http",

4. Käivita Codex. Esmakordsel kasutamisel avab Codex brauseri vahelehe aadressil `https://iam.wink.travel`.

6. Codex kinnitab ühenduse. Käivita `codex` ja palu näidata saadaolevaid tööriistu, et kontrollida Wink serverite aktiivsust.

  <TabItem label="ChatGPT">

MCP serveri tugi on saadaval **ChatGPT töölauarakenduses** Plus, Pro, Team ja Enterprise tellijatele.

<Steps>
1. Laadi alla ja paigalda [ChatGPT töölauarakendus](https://openai.com/chatgpt/download/), kui seda veel pole.

2. Ava rakendus ja klõpsa **oma profiili ikoonil** paremas ülanurgas, seejärel vali **Seaded**.

3. Mine **Ühendused** (või **MCP serverid** sõltuvalt rakenduse versioonist) ja klõpsa **Lisa**.

4. Sisesta Wink Inventory serveri URL:
   ```
   https://api.wink.travel/mcp
   ```
   Seejärel klõpsa **Ühenda**.

5. ChatGPT avab brauseri vahelehe aadressil `https://iam.wink.travel`. **Logi sisse Wink kontoga** ja kinnita õigused.

6. Korda samme 4–5 Integratsioonide serveri jaoks:
   ```
   https://integrations.wink.travel/mcp
   ```

7. Mõlemad serverid kuvatakse sinu Ühenduste nimekirjas. Alusta uut vestlust — Wink tööriistad on automaatselt saadaval.
</Steps>

:::note[Veebirakenduse piirang]
MCP servereid saab seadistada ainult **töölauarakenduses**. ChatGPT veebiliides chatgpt.com ei toeta kohandatud MCP servereid.
:::

## Õiguste viited

Nõusoleku ekraanil näed, milliseid õigusi agent küsib. Wink grupeerib õigused funktsionaalse ala järgi:

| Õiguste grupp | Õigused | Mida need avavad |
|---------------|---------|------------------|
| **MCP transport** | `mcp.read` `mcp.write` `mcp.remove` | Nõutud, et ühendada mõne MCP serveriga |
| **Konto** | `account.read` `account.write` `account.remove` | Haldusüksused, meeskonnaliikmed, seaded, rakendused |
| **Broneering** | `booking.read` `booking.write` `booking.remove` | Otsing, vaatamine, loomine, tühistamine ja tagasimaksed |
| **Inventar** | `inventory.read` `inventory.write` `inventory.remove` | Majutusasutused, toad, hinnad, mugavused, saadavus |
| **Analüütika** | `analytics.read` | Broneeringute analüütika, tulude aruanded, edetabelid |
| **Turundus** | `marketing.read` `marketing.write` `marketing.remove` | Sotsiaalmeedia postitused, kampaaniad, müügikanalid, soodustused |
| **Sisu** | `content.read` `content.write` `content.remove` | Multimeedia, lühendatud URL-id, levitatavad üksused, kaardid |
| **Makse** | `payment.read` `payment.write` | Raamatupidamine, väljamaksed, finantsülevaated, väljavõtmised |

AI klient küsib ainult vajalikke õigusi. Sa võid nõusoleku ekraanil üksikuid õigusi keelata — tööriistad, mis vajavad keelatud õigust, annavad vea, kui neid kutsutakse.

## Tõrkeotsing

**Brauseri vaheleht ei avane**

Sinu AI klient ei pruugi veel toetada interaktiivset PKCE voogu. Kontrolli, et kasutad värsket versiooni:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT töölauarakendus:** uuenda rakenduse sisseehitatud uuendajaga

**`401 Unauthorized` pärast sisselogimist**

Sinu vahemällu salvestatud token võib olla aegunud. Eemalda ja lisa server uuesti, et käivitada värske sisselogimine:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

Claude Desktopi ja ChatGPT puhul eemalda server seadete alt, taaskäivita rakendus ja lisa server uuesti.

**`403 Forbidden` konkreetse tööriista kutsumisel**

Tööriist vajab õigust, mida sa nõusoleku ekraanil ei kinnitanud. Ühenda server uuesti — nõusoleku ekraan ilmub uuesti ja saad puuduvat õigust kinnitada.

**Server on nähtav, kuid tööriistade päringud tagastavad "account not found"**

Oled sisse logitud Wink kontoga, millel puudub haldusüksus. Mine [Wink Portaal](https://app.wink.travel) ja veendu, et sinu konto on õigesti seadistatud enne MCP serveri kasutamist.

**Token aegub sessiooni keskel**

Tokenid kehtivad 3 tundi. Claude Code ja Claude Desktop uuendavad tokenid vaikselt ilma sessiooni katkestamata. Kui pärast pikka pausi ilmnevad autentimisvead, kirjuta uus sõnum — klient autentib end automaatselt uuesti.

**Codex CLI kuvab "MCP server unreachable"**

Kontrolli, et sinu `~/.codex/config.json` on korrektne JSON (ilma lõppkomadeta) ja et `"type": "http"` on määratud. Codex nõuab kaugserverite puhul HTTP transporti; stdio transport on mõeldud ainult kohalikeks binaarideks.

**ChatGPT menüüs "Connectors" puudub**

MCP tugi nõuab ChatGPT töölauarakenduse versiooni **1.2024.352** või uuemat ning aktiivset Plus, Pro, Team või Enterprise tellimust. Uuenda rakendus ja kontrolli plaani Seaded → Konto alt.

**Cursor server näitab punast / "Failed to connect"**

Kontrolli, et sinu `~/.cursor/mcp.json` on korrektne JSON ja sisaldab `"type": "http"`. Seejärel mine **Seaded → Cursori seaded → MCP** ja klõpsa **Värskenda**. Kui viga püsib, taaskäivita Cursor täielikult — konfiguratsiooni muudatused ei pruugi ilma taaskäivitamiseta rakenduda.

**Windsurf MCP serverid ei ilmu seadetes**

Windsurf vajab täielikku taaskäivitust (mitte ainult akna värskendust), et `mcp_config.json` muudatused jõustuksid. Kasuta **Fail → Quit** ja ava uuesti. Kui serverid ikka ei ilmu, veendu, et kasutad Windsurf versiooni **1.4+** (kontrolli Abi → Teave Windsurfist).

**Cline "Add Server" valik ei ole nähtav**

MCP serveri haldur nõuab Cline versiooni **2.0** või uuemat. Ava VS Code laienduste paneel, leia Cline ja klõpsa **Uuenda**, kui uuendus on saadaval. Pärast uuendust laadi VS Code uuesti (`Ctrl+Shift+P` → "Developer: Reload Window").
