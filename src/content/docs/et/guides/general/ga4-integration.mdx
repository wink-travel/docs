Ühendades oma Google Analytics 4 konto Winkiga, edastatakse teie broneeringusündmused — alates toa vaatamistest kuni lõpetatud broneeringuteni — automaatselt teie GA4 juhtpaneelile koos Winki enda analüütikaga. Koodi ega tehnilist seadistust teie poolt ei nõuta.

<Aside type="tip">
Teil on vaja kahte asja GA4-st: **Measurement ID** ja **Measurement Protocol API secret**. Measurement ID juhib sirvimisprotsessi külalise brauseris; API secret võimaldab Winkil salvestada lõpetatud broneeringud (`purchase`) **serveripoolselt**, nii et müük ei lähe kunagi kaduma, kui külaline suunatakse maksepakkuja juurde ja tagasi.
</Aside>

---

## Kuidas see töötab

```
Sisestate oma Measurement ID (G-XXXXXXXXXX) ja API secret Wink portaali
       ↓
Sirvimissündmused (vaated, ostukorv, kassasse minek) voogavad brauserist teie GA4 kontole
Lõpetatud broneeringud (purchase) saadetakse serveripoolselt — makse suunamise ülekäik säilib
       ↓
Logite sisse analytics.google.com ja näete kogu oma broneeringute torujuhtme
```

---

## Mida peate tegema

<Steps>

1. **Loo GA4 konto**

   Minge aadressile [analytics.google.com](https://analytics.google.com): Admin → Create Property. Määrake oma ajavöönd ja valuuta vastavalt oma turule.

2. **Loo veebandmevoog**

   Admin → Data Streams → Add Stream → Web. Sisestage URL-iks `wink.travel`. See genereerib teie **Measurement ID** (`G-XXXXXXXXXX`). Kopeerige see.

3. **Loo Measurement Protocol API secret**

   Avage sama veebandmevoog → kerige alla **Measurement Protocol API secrets** → **Create**. Andke sellele hüüdnimi (nt "Wink") ja kopeerige genereeritud **secret value**. See secret võimaldab Winkil salvestada lõpetatud broneeringud serveripoolselt, nii et müük ei lähe makse suunamise ajal kaduma.

4. **Sisestage oma Measurement ID ja API secret Wink portaali**

   Logige sisse [app.wink.travel](https://app.wink.travel), valige oma konto ja minge vahekaardile **Customizations**. Kleepige oma Measurement ID ja API secret **GA4** väljadele ning salvestage. See on kõik — teie GA4 integratsioon on nüüd aktiivne.

   <Aside type="note">
   API secret on **ainult kirjutamiseks**: pärast salvestamist seda enam ei kuvata. Tulevikus, kui muudate, jätke secret väli tühjaks, et säilitada juba salvestatud väärtus.
   </Aside>

5. **Märgistage `purchase` võtmesündmuseks**

   Tagasi oma GA4 kontol: Admin → Events → leidke `purchase` → lülitage sisse **Mark as key event**. See muudab lõpetatud broneeringud nähtavaks teie Konversioonide aruandes.

6. **Vaadake oma andmeid**

   Logige sisse [analytics.google.com](https://analytics.google.com) ja näete oma broneeringuid, tulu ja külaliste torujuhet — kõik automaatselt Wink kaudu jälgitud.

</Steps>

<Aside type="note">
Selle integratsiooni jaoks ei ole vaja oma veebisaidile paigaldada ühtegi jälgimiskoodi. Kõike haldab Wink. Teie Measurement ID on sihtkoht, kuhu broneeringuandmed saadetakse, ja teie API secret võimaldab Winkil kinnitada lõpetatud broneeringud serveripoolselt.
</Aside>

<Aside type="tip">
**GA4 ja GTM saab kasutada koos.** Kui kasutate ka Google Tag Manageri konteinerit (näiteks Sojern konteinerit), saate mõlemad korraga seadistada — need ei ole enam üksteist välistavad. Vaadake [GTM Analytics Integration](/et/guides/developers/gtm-dual-tagging).
</Aside>

## Mida saate jälgida

Kui ühendus on loodud, saab teie GA4 konto täieliku komplekti Enhanced E-commerce sündmusi teie kinnisvara kohta:

### Avastamine

| Sündmus | Tähendus |
|---|---|
| `view_item_list` | Külaline nägi teie kinnisvara otsingus või kategooria nimekirjas |
| `select_item` | Külaline klõpsas teie kinnisvaral nimekirjas |
| `view_item` | Külaline vaatas teie hotelli detaillehte |

### Kaalu-mine

| Sündmus | Tähendus |
|---|---|
| `view_promotion` | Külaline nägi teie kinnisvara reklaampakkumist |
| `select_promotion` | Külaline klõpsas reklaampakkumisel |
| `add_to_wishlist` | Külaline lisas teie kinnisvara soovinimekirja |

### Broneeringute torujuhe

| Sündmus | Tähendus |
|---|---|
| `add_to_cart` | Külaline valis toa või paketi |
| `view_cart` | Külaline vaatas oma broneeringu kokkuvõtet |
| `remove_from_cart` | Külaline eemaldas toa või paketi |
| `begin_checkout` | Külaline alustas kassasse minekut |
| `add_payment_info` | Külaline sisestas makseandmed |
| `add_shipping_info` | Külaline sisestas oma andmed |
| `purchase` | Külaline lõpetas broneeringu |
| `refund` | Broneering tühistati ja tagastati |

Kõik sündmused sisaldavad asjakohaseid mõõtmeid nagu tulu, valuuta, toaliik ja broneeringu väärtus — andes teile täieliku ülevaate külalise teekonnast esimesest muljest kuni lõpetatud broneeringuni. Täiendavate kinnisvara- ja toatasemeliste mõõtmete nagu `city_name`, `cancellation_policy`, `bed_type` ja teiste avamiseks vaadake [Custom Dimensions in GA4](/et/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4).

## Ristdomeeni jälgimine (edasijõudnutele)

Ülaltoodud standardne integratsioon jälgib kõike, mis toimub Winkis. Kui soovite aga jälgida külalisi kogu tee oma veebisaidilt kuni Winkis broneeringu lõpuleviimiseni — ja õigesti omistada algne liikluse allikas (Google Ads, e-posti kampaaniad, orgaaniline otsing jne) — on vaja teha veel üks samm mõlemal poolel.

<Aside type="caution">
See jaotis kehtib ainult siis, kui teil on GA4 paigaldatud oma veebisaidile. Kui te ei kasuta GA4 oma saidil, piisab ülaltoodud standardintegratsioonist.
</Aside>

### Miks see oluline on

Ilma ristdomeeni jälgimiseta kuvatakse GA4-s külaline, kes esmalt külastab teie veebisaiti ja seejärel broneerib Winkis, kui **Direct** sessioon ilma varasema külastusega seotuseta. Kõik Google Adsi klõpsud, e-posti kampaaniad või orgaanilised otsingud, mis broneeringuni viisid, ei saa krediiti.

Ristdomeeni jälgimise seadistamisel näete kogu külalise teekonda:

```
google.com (tasuline reklaam)
       ↓
teie veebisait (külaline sirvib tube)
       ↓
wink.travel (külaline valib toa ja broneerib)
       ↓
ost omistatakse õigesti algsele Google Adsi klõpsule
```

### Tegevus: Teie

Seadistage oma GA4 konto nii, et `wink.travel` oleks teie domeeni osa, mitte väline viide. See ütleb GA4-le, et ühendada kaks sessiooni üheks pidevaks külalisteekonnaks.

<Steps>
1. GA4 Admin → Data Streams → teie voog
2. Konfigureerige sildiseaded → **Configure your domains**
3. Lisage `wink.travel` lingitud domeenina
4. Salvestage
</Steps>

### Tegevus: Wink

Võtke ühendust [Wink Support](https://app.wink.travel) ja andke oma veebisaidi domeen (nt `yourhotel.com`). Wink lisab teie domeeni Wink GA4 konto viidete välistamise nimekirja. See takistab teie veebisaiti registreerimast viitena, mis muidu kirjutaks külalise algse omistuse üle ja alustaks uut sessiooni.

<Aside type="tip">
Ülaltoodud standardintegratsioon on enamiku kinnisvarade jaoks piisav ja annab teile kohese ülevaate broneeringutest ja tulust Winkis. Ristdomeeni jälgimine on edasijõudnutele mõeldud valik, mida tasub seadistada, kui olete oma GA4 andmetega mugav ja soovite sügavamat omistuse ülevaadet.
</Aside>
