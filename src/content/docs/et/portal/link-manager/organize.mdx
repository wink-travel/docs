WinkLinksi siltide haldamiseks mine põhimenüüs `WinkLinks` sektsiooni, klõpsa vahekaardil `Design` ja kerige alla `Manage categories`.

Kui su sisu kasvab, tahad hakata seda organiseerima. Selleks lõime `sildid`. Saad grupeerida sisu nii paljude siltidega kui soovid.

## Loo silt

<Steps>
1. Loo uus silt, klõpsates nuppu `Add a new tag`.
2. Sisesta oma uue sildi nimi. *nt Top kohvikud Berliinis*
3. Klõpsa lingil `Save`.
</Steps>

## Uuenda silti

<Steps>
1. Alusta, klõpsates silti, mida soovid muuta, kõrval olevat linki `Edit`.
2. Uuenda oma sildi nime. *nt Parimad kohvikud Berliinis*
3. Klõpsa lingil `Save`.
</Steps>

## Eemalda silt

:::note
Sildi eemaldamisel eemaldad selle ka kogu seotud sisust.
:::

<Steps>
1. Klõpsa silti, mida soovid eemaldada, kõrval olevat linki `Remove`.
</Steps>

## API

Arendajad, kes soovivad hallata `WinkLinks`i, saavad minna [Developers > API > WinkLinks](/et/api).
