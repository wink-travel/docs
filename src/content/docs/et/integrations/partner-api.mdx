Winki **Partneri API** on autentitud, suurema läbilaskevõimega viis integratsioonide jaoks pärida broneeritavat reisivarustust — sama pakkumine, mis toidab meie manustatavaid vidinaid ja avalikke sirvimisliideseid, esitatud esmaklassilise programmeeritava liidesena. Kus tasuta veebikomponendid ja avalikud sirvimisliidesed on mõeldud kergekaaluliseks, inimeste suunatud manustamiseks, on Partneri API loodud süsteemidele, mis otsivad, hindavad ja broneerivad mahus. Juurdepääs on autentitud iga integratsiooni kohta ja arveldatakse kasutuse alusel, nii et maksate ainult tegelikult saadetud liikluse eest.

Kaks OpenAPI liidest teenindavad broneeritavat varustust ja need vastavad ülaltoodud kahele tasemele:

- **Tasuta — Tarbija / Broneerimismootori API** (`/api/public/**`): anonüümne, brauseri- ja vidina suunatud. [Sirvi Broneerimismootori viidet →](/et/api/booking-engine/)

## Kuidas kasutus ja piirangud toimivad

### Tasuta tase

Tasuta tase on loodud selleks, et saaksite ehitada, testida ja käivitada mõõdukat tooteliiklust ilma kuludeta.

- **Päringupiirang — 30 päringut minutis, 60 päringu lühiajaline tõus.** Lühikesed tipud üle püsiva määra kompenseeritakse lühiajalise tõusu lubatud mahuga. Kui seda ületate, vastab API **HTTP 429 (liiga palju päringuid)** ja rakendab **5-minutilise pausi**, enne kui teie võti jätkab liikluse teenindamist. Pärast pausi akent tehke paus ja proovige uuesti, ärge koormake lõpp-punkti.
- **Kuu kvant — 10 000 päringut kalendrikuus.** Kui jõuate kuu limiidini, tagastab API **HTTP 429 kogu kuu lõpuni** — lõplik peatus — koos sõnumiga, mis kutsub teid tellima tasulise taseme, et jätkata. Loendur lähtestatakse järgmise kalendrikuuga.

Tasuta tase ei sisalda teenusetaseme lepingut ega prioriteetset tuge.

### Tasuline tase

Tasuline tase eemaldab kuu limiidi ja päringupiirangu pausid ning arveldab ainult tegeliku kasutuse eest.

- **Arveldatavad päringud — 1,00 $ 1 000 päringu kohta.** Kuu päringute limiiti ega päringupiiranguid tavakasutuse korral ei ole; arveldatakse tegeliku mahu alusel.
- **Ülevaatamise tasu — 2,00 $ 1 000 ületatud vaatamise kohta.** Pakkumise tervise hoidmiseks mõõdame otsingute ("vaatamiste") ja kinnitatud broneeringute suhet. Teil on õigus **5 000 vaatamisele ühe broneeringu kohta** enne ülevaatamise tasu rakendumist. Ületatud vaatamised arvutatakse järgmiselt:

  `üle = max(0, vaatamised − broneeringud × 5 000)`

  Ülevaatamise tasu on **2,00 $ 1 000 ületatud vaatamise kohta**. Hästi konverteerivad integratsioonid ei tekita tavaliselt ülevaatamise tasu; see kehtib ainult liiklusele, mis otsib palju rohkem kui broneerib.

Tasuline tase sisaldab allpool kirjeldatud teenusetaseme lepingut — 99,9% tööaja lubadust ja P95 vastuseaja eesmärki alla 500 ms — ning prioriteetset, tõsidusel põhinevat tuge.

## Teenusetaseme leping

_Jõustumiskuupäev: 5. juuli 2026 · Versioon 1.0_

See teenusetaseme leping ("SLA") sätestab kättesaadavuse lubaduse, teenusekrediidid ja tugieesmärgid, mida Wink ("Wink", "meie") pakub kliendile ("Klient", "teie") autentitud Wink Partneri API ("Partneri API" või "Teenuse") puhul tasemetel, kus SLA kehtib. See SLA on osa ja reguleeritud teie ja Winki vahelise lepinguga, mille alusel pääsete Partneri API-le ligi ("Leping"), ning kehtib seni, kuni teil on aktiivne, tasuline Partneri API tellimus heas seisukorras. Suurtähtedega terminid, mida siin ei defineerita, omavad tähendust, mis on neile antud Lepingus.

### 1. Mõisted

1. **"Tööaeg"** tähendab perioode, mil Partneri API on kättesaadav vastu võtma ja edukalt vastama korrektselt vormistatud, autentitud päringutele.
2. **"Seisakuaeg"** tähendab iga minutit mõõdetud perioodi, mil Partneri API ei suuda edukalt vastata korrektselt vormistatud, autentitud päringutele, välja arvatud sektsioonis 4 toodud erandid. Üksikud vead, mis mõjutavad ebaolulist osa päringutest, ei ole iseenesest seisakuaeg.
3. **"Kuu tööaja protsent"** tähendab antud kalendrikuus kogu minutite arvu sellest kuust miinus seisaku minutid, jagatud kogu minutite arvuga samas kuus, väljendatuna protsendina.
4. **"Planeeritud hooldus"** tähendab teenuse planeeritud hooldust, mille kohta Wink on eelnevalt teavitanud vastavalt sektsioonile 4.
5. **"Teenusekrediit"** tähendab krediiti, mis arvutatakse protsendina teie poolt Partneri API eest mõjutatud kalendrikuus makstud või makstavast tasust ning mida rakendatakse tulevaste Partneri API tasude vastu kui ainus ja eksklusiivne vahend tööaja lubaduse mittetäitmise korral.
6. **"Vastuse aeg"** tähendab aega Winkilt korrektselt vormistatud, autentitud päringu vastuvõtmisest Wink teenuse piiril kuni vastuse tagastamise alguseni, välja arvatud võrgutransiit ja kliendi poolne aeg väljaspool Winki kontrolli.

### 2. Kättesaadavuse ja jõudluse lubadus

Wink kasutab äriliselt mõistlikke jõupingutusi, et teha Partneri API kättesaadavaks **kuu tööaja protsendiga vähemalt 99,9%** iga kalendrikuus (edaspidi "Tööaja lubadus"). Tööaja lubadust mõõdetakse Winki teenuse piiril ja see ei hõlma Winki mõistliku kontrolli alt väljuvaid tegureid, sealhulgas sektsioonis 4 kirjeldatud olukordi. Winki jälgimissüsteemid on autoriteetne allikas kuu tööaja protsendi ja vastuseaja mõõtmiseks.

Wink seab sihiks ka **95. protsentiili (P95) vastuseaja alla 500 millisekundi** edukatele, korrektselt vormistatud, autentitud päringutele, mõõdetuna Winki teenuse piiril iga kalendrikuus (edaspidi "Jõudluse eesmärk"). Jõudluse eesmärk ei hõlma sektsioonis 4 kirjeldatud tegureid, päringuid, mis tagastavad rakendustaseme vigu päringu enda tõttu, ega ebatavaliselt suuri või keerukaid partiipäringuid. Jõudluse eesmärk on teenuse eesmärk; sektsioonis 3 toodud teenusekrediidid kehtivad tööaja lubaduse mittetäitmise korral ja on ainus ning eksklusiivne vahend kättesaadavuse puuduste korral.

### 3. Teenusekrediidid

Kui kuu tööaja protsent langeb alla tööaja lubaduse mõnel kalendrikuul, võite olla õigustatud teenusekrediidile, mis arvutatakse protsendina teie selle kuu eest makstud või makstavast Partneri API tasust vastavalt allolevale skaalale:

| Kuu tööaja protsent | Teenusekrediit |
|---|---|
| Alla 99,9%, kuid vähemalt 99,0% | 10% |
| Alla 99,0%, kuid vähemalt 95,0% | 25% |
| Alla 95,0% | 50% |

1. **Krediidi nõudmine.** Teenusekrediidi saamiseks peate esitama Winkle kirjaliku nõude hiljemalt **kolmekümne (30) päeva jooksul** pärast kalendrikuud, mil puudujääk toimus. Nõudele tuleb lisada iga seisaku kuupäevad ja kellaajad ning kõik mõistlikult kättesaadavad logid või tõendid. Hiljem esitatud nõuded ei ole õigustatud.
2. **Krediidi vorm.** Kinnitatud teenusekrediidid rakendatakse tulevaste Partneri API tasude vastu ega oma sularahaväärtust. Need ei ole tagasimaksed ega maksta välja, välja arvatud kohaldatava seaduse nõudel.
3. **Maksimaalne krediit.** Ühe kalendrikuuga antud teenusekrediidide kogusumma ei ületa 50% teie selle kuu eest makstud või makstavast Partneri API tasust.
4. **Ainus ja eksklusiivne vahend.** Teenusekrediidid on teie **ainus ja eksklusiivne vahend** Winkilt tööaja lubaduse või muu Partneri API kättesaadavuse puuduse mittetäitmise korral.

### 4. Erandid

Tööaja lubadus ja sellest tulenevad teenusekrediidid ei kehti ning seisakuaeg ei hõlma ühtegi kättesaamatust, peatamist, halvenemist või jõudlusprobleemi, mis tuleneb või on seotud:

1. **Planeeritud hooldus**, mille kohta Wink on eelnevalt teavitanud, tingimusel, et teavitus on antud mõistliku etteteatamisajaga kanalil, mida Wink tavaliselt kasutab klientidega suhtlemiseks;
2. **Force majeure** sündmused või muud põhjused, mis on Winki mõistlikust kontrollist väljas, sealhulgas loodusõnnetused, valitsuse tegevused, võrgu- või kommunaalteenuste tõrked ning teenuse keelamise või muud pahatahtlikud rünnakud;
3. probleemid, mis on põhjustatud **teie** tegudest või tegematajätmistest, teie seadmetest, tarkvarast või võrgust või mis tahes **kolmanda osapoole** teenusest, tootest või pakkujast, kes ei ole Wink'i otsese kontrolli all;
4. teie **teenuse väärkasutus** või **lepingu, selle SLA, kasutustingimuste või kehtivate päringupiirangute rikkumine**, sealhulgas liiklus, mida Wink mõistlikult peab liigseks, automatiseeritud väärkasutus või pettus; ning
5. mis tahes **juurdepääsu peatamine või lõpetamine**, mis on korrektselt teostatud vastavalt lepingule, sealhulgas peatamine maksmata jätmise tõttu.

### 5. Tugi ja vastuseesmärgid

Wink pakub Partneri API jaoks tuge tavapärastel tööaegadel, välja arvatud kohalikud riigipühad. Wink kasutab äriliselt mõistlikke jõupingutusi, et kinnitada korrektselt esitatud tugipäringud järgmiste sihtvastuse aegade jooksul, tuginedes teie määratud ja Winki mõistlikult kinnitatud tõsidusele:

| Tõsidus | Kirjeldus | Sihtvastuse aeg esialgseks vastuseks |
|---|---|---|
| **Sev 1 — Kriitiline** | Partneri API on tootmises maas või kasutuskõlbmatu ilma lahenduseta. | 4 tundi |
| **Sev 2 — Suur** | Oluline funktsioon on kahjustatud või halvenenud; lahendus on olemas. | 1 tööpäev |
| **Sev 3 — Väike** | Üldised küsimused, väiksemad probleemid või funktsioonisoovid. | 2 tööpäeva |

Sihtvastuse ajad kirjeldavad, millal Wink püüab teha **esialgse kontakti**; need ei ole lahenduse garantii. Prioriteetne tugi ja tõsidusel põhinevad eesmärgid kehtivad tasemetel, kus need on märgitud kaasatuks.

### 6. Andmed ja turvalisus

Wink rakendab äriliselt mõistlikke haldus-, tehnilisi ja organisatsioonilisi meetmeid, mis on mõeldud kaitsmaks Partneri API kaudu töödeldavate andmete konfidentsiaalsust, terviklikkust ja kättesaadavust ning vaatab neid meetmeid perioodiliselt üle. Winki isikuandmete töötlemist reguleerib [Privaatsuspoliitika](/et/privacy) ja kõik andmetöötlustingimused lepingus. Te vastutate oma API volituste turvalisuse eest, kõigi andmete seadusliku kasutamise eest ning koheselt teavitamise eest Wink'i, kui kahtlustate volituste kompromiteerimist.

### 7. Vastutuse piiramine

Teenusekrediidid on **ainus ja eksklusiivne vahend** mis tahes kättesaamatuse või tööaja lubaduse mittetäitmise korral ning neid pakutakse kõigi muude vastutuste asemel, mis tulenevad sellisest mittetäitmisest. Välja arvatud käesolevas SLA-s selgesõnaliselt sätestatud, pakutakse Partneri API-d "nagu on" alusel. Maksimaalses ulatuses, mida kohaldatav seadus lubab, on Winki koguvastutus Teenuse osas piiratud lepingus sätestatuga ning Wink ei vastuta ühegi kaudse, juhusliku, erilise, tagajärjelise või karistusliku kahju eest ega kasumi, tulu, andmete või heasoovlikkuse kaotuse eest, isegi kui on teavitatud selliste kahjude võimalikkusest.

### 8. Kehtivusaeg, muudatused ja lõpetamine

See SLA kehtib seni, kuni teil on aktiivne Partneri API tellimus tasemel, kus SLA on märgitud kehtivaks. Wink võib seda SLA-d aeg-ajalt uuendada; olulised muudatused edastatakse kanalite kaudu, mida Wink tavaliselt kasutab klientidega suhtlemiseks, ning Partneri API jätkuv kasutamine pärast uuenduse jõustumist tähendab uuendatud SLA aktsepteerimist. See SLA lõpeb automaatselt lepingu või teie Partneri API tellimuse lõpetamisel või aegumisel. Lõpetamisele vaatamata jäävad kehtima lõigud, mis oma olemuselt peaksid kehtima ka pärast lõpetamist — sealhulgas kogunenud, kuid nõudmata teenusekrediidi õigused, vastutuse piirang ja mõisted.
