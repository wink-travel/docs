Winki **Partneri API** on autentitud, suurema läbilaskevõimega viis integratsioonide jaoks pärida broneeritavat reisivarustust — sama pakkumine, mis toidab meie manustatavaid vidinaid ja avalikke sirvimisliideseid, esitatud esmaklassilise programmeeritava liidesena. Kus tasuta veebikomponendid ja avalikud sirvimisliidesed on mõeldud kergekaaluliseks, inimeste suunatud manustamiseks, on Partneri API loodud süsteemidele, mis otsivad, hindavad ja broneerivad mahus. Juurdepääs on autentitud iga integratsiooni kohta ja arveldatakse kasutuse alusel, nii et maksate ainult tegelikult saadetud liikluse eest.

## Plaanid ja hinnakujundus

Üks API kõne = üks päring. Kasutust mõõdetakse ja arveldatakse 1 000 päringu kaupa.

| | Tasuta | Tasuline | Ettevõtte |
|---|---|---|---|
| **Hind** | 0 $ | Kasutusepõhine | Võtke meiega ühendust |
| **Parim kasutus** | Hindamine ja madala mahuga integratsioonid | Skaalal tasu vastavalt kasutusele | Kohandatud maht ja läbiräägitud tingimused |
| Päringud minutis | 30 (60 lühiajaline tõus) | Piiramatu | Piiramatu |
| Päringud kuus | 10 000 | Piiramatu | Piiramatu |
| API vastuse aeg (P95) | — | Alla 500 ms | Alla 500 ms |

| Ülevaatamise tasu (1 000 ületavat otsingut üle 5 000:1) | — | 2,00 $ | Kohandatud |
| Päringupiirangu vastus | 429 (paus / kuupõhine lõplik peatus) | Puudub | Puudub |

## API viide

Kaks liidest teenindavad broneeritavat varustust ja need vastavad ülaltoodud kahele tasemele:

- **Tasuta — Tarbija / Broneerimismootori API** (REST, `/api/public/**`): anonüümne, brauseri- ja vidinapõhine. [Sirvi Broneerimismootori viidet →](/et/api/booking-engine/)
- **Tasuline — Partneri integratsiooni API** (**gRPC**, `wink.partner.v1`): autentitud, kasutust mõõtev, loodud serveritevaheliseks integratsiooniks mahus. [Sirvi Integratsiooni viidet →](/et/partner-api/partner/)

Partneri integratsiooni API on gRPC, mitte REST. Seda kutsutakse genereeritud kliendiga üle HTTP/2 aadressil
`partner.wink.travel:443`, edastades kandjatokeni ja konto, mille nimel päring tehakse:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

Ülaltoodud viideteleht dokumenteerib iga teenuse, sõnumi ja veastatuse ning skeem on saadaval ka jooksvalt serveri peegeldamise kaudu, nii et `grpcurl`, Postman ja Insomnia leiavad selle ilma allalaadimiseta.

## Kuidas kasutus ja piirangud toimivad

### Tasuta tase

Tasuta tase on loodud võimaldama teil ehitada, testida ja käitada mõõdukat tooteliiklust ilma kuludeta.

- **Päringupiirang — 30 päringut minutis, 60 päringut lühiajaline tõus.** Lühikesed ületused püsivast kiirusest neelab lühiajaline tõus. Kui seda ületate, vastab API **HTTP 429 (liiga palju päringuid)** ja rakendab **5-minutilise pausi**, enne kui teie võti jätkab liikluse teenindamist. Pärast pausi ärge jätkake päringute pommitamist, vaid proovige uuesti.
- **Kuu kvota — 10 000 päringut kalendrikuu kohta.** Kui jõuate kuu limiidini, tagastab API **HTTP 429 kogu kuu lõpuni** — lõplik peatus — koos sõnumiga, mis kutsub teid tasulisele tasemele üle minema. Loendur lähtestatakse järgmise kalendrikuu alguses.

Tasuta tase ei sisalda teenusetaseme lepingut ega prioriteetset tuge.

### Tasuline tase

Tasuline tase eemaldab kuu limiidi ja päringupiirangu pausid ning arveldab ainult tegeliku kasutuse eest.

- **Mõõdetud päringud — 1,00 $ 1 000 päringu kohta.** Kuupõhist limiiti ega päringupiiranguid tavakasutuse korral ei ole; arveldatakse tegeliku mahu alusel.
- **Ülevaatamise tasu — 2,00 $ 1 000 ületava otsingu kohta.** Pakkumise tervise hoidmiseks mõõdame otsingute ("vaatamiste") ja kinnitatud broneeringute suhet. Teil on õigus **5 000 vaatamisele ühe broneeringu kohta** enne ülevaatamise tasu rakendumist. Ületavad vaatamised arvutatakse järgmiselt:

  `üle = max(0, vaatamised − broneeringud × 5 000)`

  Ülevaatamise tasu on **2,00 $ 1 000 ületava vaatamise kohta**. Hästi konverteerivad integratsioonid ei tekita tavaliselt ülevaatamise tasu; see kehtib ainult liikluse kohta, mis otsib palju rohkem kui broneerib.

Tasuline tase sisaldab allpool kirjeldatud teenusetaseme lepingut — 99,9% tööaja lubadust ja P95 vastuseaja sihti alla 500 ms — ning prioriteetset, tõsidusel põhinevat tuge.

## Teenusetaseme leping

_Jõustumiskuupäev: 5. juuli 2026 · Versioon 1.0_

See teenusetaseme leping (edaspidi "SLA") sätestab kättesaadavuse lubaduse, teenusekrediidid ja tugieesmärgid, mida Wink ("Wink", "meie") pakub kliendile ("Klient", "teie") autentitud Wink Partneri API (edaspidi "Partneri API" või "Teenuse") puhul tasemetel, kus SLA kehtib. See SLA on osa ja reguleeritud teie ja Winki vahelise lepinguga, mille alusel te Partneri API-le juurdepääsu saate (edaspidi "Leping"), ning kehtib seni, kuni teil on aktiivne, tasuline Partneri API tellimus heas seisukorras. Suurtähtedega mõisted, mida siin ei defineerita, on määratletud Lepingus.

### 1. Mõisted

1. **"Tööaeg"** tähendab perioode, mil Partneri API on kättesaadav vastu võtma ja edukalt vastama korrektselt vormistatud, autentitud päringutele.
2. **"Seisakuaeg"** tähendab iga minutit mõõdetud perioodi, mil Partneri API ei suuda edukalt vastata korrektselt vormistatud, autentitud päringutele, välja arvatud jaotises 4 sätestatud erandid. Üksikud vead, mis mõjutavad ebaolulist osa päringutest, ei ole iseenesest seisakuaeg.
3. **"Kuu tööaja protsent"** tähendab antud kalendrikuu kogu minutite arvu miinus seisaku minutid, jagatud kuu kogu minutite arvuga, väljendatuna protsendina.
4. **"Planeeritud hooldus"** tähendab teenuse planeeritud hooldust, mille kohta Wink on eelnevalt teavitanud vastavalt jaotisele 4.
5. **"Teenusekrediit"** tähendab krediiti, mis arvutatakse protsendina teie poolt Partneri API eest mõjutatud kalendrikuu jooksul makstud või makstavast tasust ning mida rakendatakse tulevaste Partneri API tasude vastu ainsa ja eranditult hüvitisena tööaja lubaduse mittetäitmise eest.
6. **"Vastuse aeg"** tähendab aega Winkilt korrektselt vormistatud, autentitud päringu vastuvõtmisest Wink teenuse piiril kuni vastuse tagastamise alguseni, välja arvatud võrgutransiit ja kliendi poolne aeg väljaspool Winki kontrolli.

### 2. Kättesaadavuse ja jõudluse lubadus

Wink kasutab äriliselt mõistlikke jõupingutusi, et tagada Partneri API kättesaadavus **kuu tööaja protsendiga vähemalt 99,9%** iga kalendrikuu jooksul (edaspidi "Tööaja lubadus"). Tööaja lubadust mõõdetakse Winki teenuse piiril ja see ei hõlma Winki mõistliku kontrolli alt väljuvaid tegureid, sealhulgas jaotises 4 kirjeldatud juhtumeid. Winki jälgimissüsteemid on autoriteetne allikas kuu tööaja protsendi ja vastuseaja mõõtmiseks.

Wink seab sihiks **95. protsentiili (P95) vastuseaja alla 500 millisekundi** edukatele, korrektselt vormistatud, autentitud päringutele, mõõdetuna Winki teenuse piiril iga kalendrikuu jooksul (edaspidi "Jõudluse siht"). Jõudluse siht ei hõlma jaotises 4 kirjeldatud tegureid, päringuid, mis tagastavad rakendustaseme vigu päringu enda tõttu, ega ebatavaliselt suuri või keerukaid partiipäringuid. Jõudluse siht on teenuse eesmärk; jaotises 3 toodud teenusekrediidid kehtivad tööaja lubaduse mittetäitmise korral ja on ainsad ja eranditult hüvitised kättesaadavuse puudujääkide eest.

### 3. Teenusekrediidid

Kui kuu tööaja protsent langeb alla tööaja lubaduse mõnel kalendrikuu jooksul, võite olla õigustatud teenusekrediidile, mis arvutatakse protsendina teie selle kuu jooksul makstud või makstavast Partneri API tasust vastavalt alljärgnevale skaalale:

| Kuu tööaja protsent | Teenusekrediit |
|---|---|
| Alla 99,9%, kuid vähemalt 99,0% | 10% |
| Alla 99,0%, kuid vähemalt 95,0% | 25% |
| Alla 95,0% | 50% |

1. **Krediidi nõudmine.** Teenusekrediidi saamiseks peate esitama Winkle kirjaliku nõude **kolmekümne (30) päeva jooksul** pärast kalendrikuu lõppu, mil puudujääk toimus. Nõudele tuleb lisada iga seisaku kuupäev ja kellaaeg ning kõik asjakohased logid või tõendid, mis teil mõistlikult olemas on. Hiljem esitatud nõuded ei ole õigustatud.
2. **Krediidi vorm.** Kinnitatud teenusekrediidid rakendatakse tulevaste Partneri API tasude vastu ega oma rahalist väärtust. Need ei ole tagasimaksed ega maksta välja, välja arvatud kohaldatava seaduse nõudel.
3. **Maksimaalne krediit.** Ühe kalendrikuu jooksul antud teenusekrediidide kogusumma ei ületa 50% teie selle kuu jooksul makstud või makstavast Partneri API tasust.
4. **Ainuke ja eranditult hüvitis.** Teenusekrediidid on teie **ainus ja eranditult hüvitis** Winkilt tööaja lubaduse mittetäitmise või muu Partneri API kättesaadavuse puudujäägi eest.

### 4. Erandid

Tööaja lubadus ja sellest tulenevad teenusekrediidid ei kehti ning seisakuaeg ei hõlma ühtegi kättesaamatust, peatamist, halvenemist või jõudlusprobleemi, mis tuleneb või on seotud:

1. **Planeeritud hooldus**, mille kohta Wink on eelnevalt teavitanud, tingimusel, et teavitus on antud mõistliku etteteatamisajaga tavapärase suhtluskanali kaudu;
2. **Force majeure** sündmused või muud põhjused, mis on Winki mõistlikust kontrollist väljas, sealhulgas loodusõnnetused, valitsuse tegevused, võrgu- või kommunaalteenuste tõrked ning teenuse keelamise või muud pahatahtlikud rünnakud;
3. probleemid, mis on põhjustatud **teie** tegevusest või tegevusetusest, teie seadmetest, tarkvarast või võrgust või mis tahes **kolmanda osapoole** teenusest, tootest või pakkujast, mis ei ole Winki otsese kontrolli all;
4. teie **teenuse väärkasutus** või **lepingu, selle SLA, kasutustingimuste või kehtivate päringupiirangute rikkumine**, sealhulgas liiklus, mida Wink mõistlikult peab liigseks, automatiseeritud väärkasutus või pettus; ning
5. mis tahes **juurdepääsu peatamine või lõpetamine**, mis on õiguspäraselt teostatud vastavalt Lepingule, sealhulgas peatamine maksmata jätmise tõttu.

### 5. Tugi ja vastuse eesmärgid

Wink pakub Partneri API jaoks tuge tavapärastel tööaegadel, välja arvatud kohalikud riigipühad. Wink kasutab äriliselt mõistlikke jõupingutusi, et tunnustada korrektselt esitatud tugipäringuid järgmiste sihtvastuse aegade jooksul, lähtudes teie määratud tõsidusest ja Winki mõistlikust kinnitamisest:

| Tõsidus | Kirjeldus | Esialgne sihtvastus |
|---|---|---|
| **Sev 1 — Kriitiline** | Partneri API on tootmises maas või kasutuskõlbmatu ilma lahenduseta. | 4 tundi |
| **Sev 2 — Suur** | Oluline funktsioon on kahjustatud või halvenenud; lahendus on olemas. | 1 tööpäev |
| **Sev 3 — Väike** | Üldküsimused, väiksemad probleemid või funktsioonisoovid. | 2 tööpäeva |

Sihtvastuse ajad kirjeldavad, millal Wink püüab teha **esialgse kontakti**; need ei ole lahenduse garantii. Prioriteetne tugi ja tõsidusel põhinevad eesmärgid kehtivad tasemetel, kus need on lubatud.

### 6. Andmed ja turvalisus

Wink rakendab äriliselt mõistlikke haldus-, tehnilisi ja organisatsioonilisi meetmeid, mis on mõeldud kaitsmaks Partneri API kaudu töödeldavate andmete konfidentsiaalsust, terviklikkust ja kättesaadavust ning vaatab neid meetmeid perioodiliselt üle. Winki isikuandmete töötlemist reguleerib [Privaatsuspoliitika](/et/privacy) ja kõik andmetöötlustingimused Lepingus. Teie vastutate oma API volituste turvalisuse eest, kõigi andmete seadusliku kasutamise eest ning viivitamatu teavitamise eest Winkile, kui kahtlustate volituste kompromiteerimist.

### 7. Vastutuse piiramine

Teenusekrediidid on **ainus ja eranditult hüvitis** mis tahes kättesaamatuse või tööaja lubaduse mittetäitmise eest ning neid pakutakse kõigi muude vastutuste asemel, mis tulenevad sellisest mittetäitmisest. Välja arvatud käesolevas SLA-s selgesõnaliselt sätestatud, pakutakse Partneri API-d "nagu on" alusel. Maksimaalses ulatuses, mida kohaldatav seadus lubab, on Winki koguvastutus Teenuse osas piiratud vastavalt Lepingule ning Wink ei vastuta kaudsete, juhuslike, erakorraliste, tagajärjel tekkivate või karistuslike kahjude eest ega kasumi, tulu, andmete või hea tahte kaotuse eest, isegi kui on teavitatud selliste kahjude võimalikkusest.

### 8. Kehtivusaeg, muudatused ja lõpetamine

See SLA kehtib seni, kuni teil on aktiivne Partneri API tellimus tasemel, kus SLA kehtib. Wink võib seda SLA-d aeg-ajalt uuendada; olulised muudatused teatatakse tavapärase suhtluskanali kaudu, mida Wink kasutab klientidega suhtlemiseks, ning Partneri API jätkuv kasutamine pärast uuenduse jõustumist tähendab uuendatud SLA aktsepteerimist. See SLA lõpeb automaatselt Lepingust või teie Partneri API tellimusest loobumise või aegumise korral. Lõpetamisele vaatamata jäävad kehtima lõigud, mis oma olemuselt peaksid kehtima ka pärast lõpetamist — sealhulgas kogunenud, kuid nõudmata teenusekrediidi õigused, vastutuse piiramine ja mõisted.
