Wink **Partneri API** on autentitud, suurema läbilaskevõimega viis integratsioonide jaoks pärida broneeritavat reisivarustust — sama pakkumine, mis toidab meie manustatavaid vidinaid ja avalikke sirvimisliideseid, esitatud esmaklassilise programmeeritava liidesena. Kus tasuta veebikomponendid ja avalikud sirvimisliidesed on mõeldud kergekaaluliseks, inimeste suunaleks manustamiseks, on Partneri API loodud süsteemidele, mis otsivad, hindavad ja broneerivad mahus. Juurdepääs on autentitud iga integratsiooni kohta ja arveldatakse kasutuse alusel, nii et maksate ainult tegelikult saadetud liikluse eest.

## API viide

Kaks liidest teenindavad broneeritavat varustust ja need vastavad ülaltoodud kahele tasemele:

- **Tasuta — Tarbija / Broneerimismootori API** (REST, `/api/public/**`): anonüümne, brauseri- ja vidina suunaline. [Sirvi Broneerimismootori viidet →](/et/api/booking-engine/)
- **Tasuline — Partneri integratsiooni API** (**gRPC**, `wink.partner.v1`): autentitud, kasutuspõhine, loodud serveritevaheliseks integratsiooniks mahus. [Sirvi Integratsiooni viidet →](/et/partner-api/partner/)

Partneri integratsiooni API on gRPC, mitte REST. Seda kutsutakse genereeritud kliendiga üle HTTP/2 aadressil
`partner.wink.travel:443`, edastades kandjatokeni ja konto, mille nimel päring tehakse:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

Ülaltoodud viideteleht dokumenteerib iga teenuse, sõnumi ja veastatuse ning skeem on saadaval ka jooksvalt serveri peegeldamise kaudu, nii et `grpcurl`, Postman ja Insomnia leiavad selle ilma allalaadimiseta.

Kui soovite kliendi eelnevalt genereerida, on `.proto` lähtefailid avaldatud aadressil
[github.com/wink-travel/partner-api-proto](https://github.com/wink-travel/partner-api-proto).

## Kuidas kasutus ja piirangud toimivad

### Tasuta tase

Tasuta tase on loodud selleks, et võimaldada teil ehitada, testida ja käivitada mõõdukat tooteliiklust ilma kuludeta.

- **Päringupiirang — 30 päringut minutis, 60 päringu lühiajaline tõus.** Lühikesed tipud üle pideva määra neelab lühiajaline tõus. Kui seda ületate, vastab API **HTTP 429 (liiga palju päringuid)** ja rakendab **5-minutilise pausi**, enne kui teie võti jätkab liikluse teenindamist. Pärast pausi ärge ründake lõpp-punkti, vaid proovige uuesti.
- **Kuu kvota — 10 000 päringut kalendrikuu kohta.** Kui jõuate kuu limiidini, tagastab API **HTTP 429 kogu kuu lõpuni** — lõplik peatus — koos sõnumiga, mis kutsub teid tasulisele tasemele üle minema. Loendur lähtestatakse järgmise kalendrikuu alguses.

Tasuta tase ei sisalda teenusetaseme lepingut ega prioriteetset tuge.

### Tasuline tase

Tasuline tase eemaldab kuu limiidi ja päringupiirangu pausid ning arveldab ainult tegeliku kasutuse eest.

- **Arveldatavad päringud — 1,00 $ 1000 päringu kohta.** Kuupõhist limiiti ega päringupiiranguid tavakasutuse korral ei ole; arveldatakse tegeliku mahu alusel.
- **Ülevaatamise tasu — 2,00 $ 1000 ületava otsingu kohta.** Pakkumise tervise hoidmiseks mõõdame otsingute ("vaatamiste") ja kinnitatud broneeringute suhet. Teil on õigus **5000 vaatamisele ühe broneeringu kohta** enne ülevaatamise tasu rakendumist. Ületavad vaatamised arvutatakse järgmiselt:

  `üle = max(0, vaatamised − broneeringud × 5000)`

  Ülevaatamise tasu on **2,00 $ 1000 ületava vaatamise kohta**. Hästi konverteerivad integratsioonid harva ülevaatamist tekitavad; tasu kehtib ainult liiklusele, mis otsib palju rohkem kui broneerib.

Tasuline tase sisaldab allpool kirjeldatud teenusetaseme lepingut — 99,9% tööaja lubadust ja P95 vastuseaja sihti alla 500 ms — ning prioriteetset, raskusastmepõhist tuge.

## Teenusetaseme leping

_Jõustumiskuupäev: 5. juuli 2026 · Versioon 1.0_

See teenusetaseme leping ("SLA") sätestab Wink'i ("Wink", "meie") kättesaadavuse lubaduse, teenusekrediidid ja tugieesmärgid, mida pakutakse kliendile ("Klient", "teie") autentitud Wink Partneri API ("Partneri API" või "Teenuse") puhul tasemetel, kus SLA kehtib. See SLA on osa ja reguleeritud teie ja Wink'i vahelise lepinguga, mille alusel pääsete Partneri API-le ligi ("Leping"), ning kehtib seni, kuni teil on aktiivne, tasuline Partneri API tellimus heas seisukorras. Suurtähtedega mõisted, mida siin ei defineerita, on määratletud Lepingus.

### 1. Mõisted

1. **"Tööaeg"** tähendab perioode, mil Partneri API on kättesaadav korrektselt vormistatud, autentitud päringute vastuvõtmiseks ja edukaks vastamiseks.
2. **"Seisakuaeg"** tähendab iga minutit, mil Partneri API ei suuda edukalt vastata korrektselt vormistatud, autentitud päringutele, välja arvatud punktis 4 toodud erandid. Üksikud vead, mis mõjutavad ebaolulist osa päringutest, ei ole iseenesest seisakuaeg.
3. **"Kuu tööaja protsent"** tähendab antud kalendrikuu kogu minutite arvu miinus seisaku minutid, jagatud kuu minutite koguarvuga, väljendatuna protsendina.
4. **"Planeeritud hooldus"** tähendab teenuse planeeritud hooldust, mille kohta Wink on eelnevalt teavitanud vastavalt punktile 4.
5. **"Teenusekrediit"** tähendab krediiti, mis arvutatakse protsendina teie poolt Partneri API eest mõjutatud kalendrikuu jooksul makstud või makstavast tasust ning mida rakendatakse tulevaste Partneri API tasude vastu kui ainus ja eksklusiivne vahend tööaja lubaduse mittetäitmise korral.
6. **"Vastuse aeg"** tähendab aega Wink'i teenusepiiril korrektselt vormistatud, autentitud päringu vastuvõtmisest kuni vastuse tagastamise alguseni, välja arvatud võrgutransiit ja kliendi poolne aeg, mis ei ole Wink'i kontrolli all.

### 2. Kättesaadavuse ja jõudluse lubadus

Wink kasutab äriliselt mõistlikke jõupingutusi, et tagada Partneri API kättesaadavus **kui vähemalt 99,9% kuu tööajast** iga kalendrikuu jooksul (edaspidi "Tööaja lubadus"). Tööaja lubadust mõõdetakse Wink'i teenusepiiril ja see ei hõlma tegureid, mis on väljaspool Wink'i mõistlikku kontrolli, sealhulgas punktis 4 kirjeldatud olukordi. Wink'i jälgimissüsteemid on autoriteetne allikas kuu tööaja protsendi ja vastuseaja mõõtmiseks.

Wink seab sihiks **95. protsentiili (P95) vastuseaja alla 500 millisekundi** edukate, korrektselt vormistatud, autentitud päringute puhul, mõõdetuna Wink'i teenusepiiril iga kalendrikuu jooksul (edaspidi "Jõudluse sihtmärk"). Jõudluse sihtmärk ei hõlma punktis 4 kirjeldatud tegureid, päringuid, mis tagastavad rakendustaseme vigu, mis on põhjustatud päringust endast, ega ebatavaliselt suuri või keerukaid partiipäringuid. Jõudluse sihtmärk on teenuse eesmärk; punktis 3 toodud teenusekrediidid kehtivad ainult tööaja lubaduse mittetäitmise korral ja on ainus ning eksklusiivne vahend kättesaadavuse puuduste korral.

### 3. Teenusekrediidid

Kui kuu tööaja protsent langeb alla tööaja lubaduse, võite olla õigustatud teenusekrediidile, mis arvutatakse protsendina teie selle kuu jooksul makstud või makstavast Partneri API tasust vastavalt alljärgnevale skaalale:

| Kuu tööaja protsent | Teenusekrediit |
|---|---|
| Alla 99,9%, kuid vähemalt 99,0% | 10% |
| Alla 99,0%, kuid vähemalt 95,0% | 25% |
| Alla 95,0% | 50% |

1. **Krediidi nõudmine.** Teenusekrediidi saamiseks peate esitama Wink'ile kirjaliku nõude hiljemalt **kolmekümne (30) päeva jooksul** pärast kalendrikuu lõppu, mil puudujääk toimus. Nõudel peavad olema kirjas iga seisaku kuupäevad ja kellaajad ning kõik asjakohased logid või tõendid, mis teil mõistlikult olemas on. Hiljem esitatud nõuded ei ole õigustatud.
2. **Krediidi vorm.** Kinnitatud teenusekrediidid rakendatakse tulevaste Partneri API tasude vastu ega oma rahalist väärtust. Need ei ole tagasimaksed ega maksta välja, välja arvatud juhul, kui kohaldatav seadus seda nõuab.
3. **Maksimaalne krediit.** Ühe kalendrikuu jooksul antud teenusekrediidide kogusumma ei ületa 50% teie selle kuu jooksul makstud või makstavast Partneri API tasust.
4. **Ainus ja eksklusiivne vahend.** Teenusekrediidid on teie **ainus ja eksklusiivne vahend** Wink'i tööaja lubaduse mittetäitmise või muu Partneri API kättesaadavuse puuduse korral.

### 4. Erandid

Tööaja lubadus ja sellest tulenevad teenusekrediidid ei kehti ning seisakuaeg ei hõlma ühtegi kättesaamatust, peatamist, halvenemist või jõudlusprobleemi, mis tuleneb või on seotud:

1. **Planeeritud hooldus**, mille kohta Wink on eelnevalt teavitanud, tingimusel, et teavitus on antud mõistliku etteteatamisajaga kanalil, mida Wink tavaliselt kasutab klientidega suhtlemiseks;
2. **Jõuolukorrad** või muud Wink'i mõistlikust kontrollist väljaspool olevad põhjused, sealhulgas loodusõnnetused, valitsuse tegevused, võrgu- või kommunaalteenuste tõrked ning teenuse keelamise või muud pahatahtlikud rünnakud;
3. probleemid, mis on põhjustatud **teie** tegudest või tegematajätmistest, teie seadmetest, tarkvarast või võrgust või mis tahes **kolmanda osapoole** teenusest, tootest või pakkujast, mis ei ole Wink'i otsese kontrolli all;
4. teie **teenuse väärkasutus** või **lepingu, selle SLA, kasutustingimuste või kehtivate päringupiirangute rikkumine**, sealhulgas liiklus, mida Wink mõistlikult peab liigseks, automatiseeritud väärkasutus või pettus; ning
5. mis tahes **juurdepääsu peatamine või lõpetamine**, mis on korrektselt teostatud vastavalt Lepingule, sealhulgas peatamine maksmata jätmise tõttu.

### 5. Tugi ja vastuse eesmärgid

Wink pakub Partneri API jaoks tuge tavapärastel tööaegadel, välja arvatud kohalikud riigipühad. Wink kasutab äriliselt mõistlikke jõupingutusi, et tunnustada korrektselt esitatud tugipäringuid järgmiste sihtvastuse aegade jooksul, tuginedes teie määratud raskusastmele, mida Wink mõistlikult kinnitab:

| Raskusaste | Kirjeldus | Sihtvastuse aeg esialgseks vastuseks |
|---|---|---|
| **Sev 1 — Kriitiline** | Partneri API on tootmises maas või kasutuskõlbmatu ilma lahenduseta. | 4 tundi |
| **Sev 2 — Suur** | Oluline funktsioon on kahjustatud või halvenenud; lahendus on olemas. | 1 tööpäev |
| **Sev 3 — Väike** | Üldised küsimused, väiksemad probleemid või funktsioonisoovid. | 2 tööpäeva |

Sihtvastuse ajad kirjeldavad, millal Wink püüab teha **esialgse kontakti**; need ei ole lahenduse garantii. Prioriteetne tugi ja raskusastmepõhised eesmärgid kehtivad tasemetel, kus need on lubatud.

### 6. Andmed ja turvalisus

Wink rakendab äriliselt mõistlikke haldus-, tehnilisi ja organisatsioonilisi meetmeid, mis on mõeldud kaitsmaks Partneri API kaudu töödeldavate andmete konfidentsiaalsust, terviklikkust ja kättesaadavust ning vaatab neid meetmeid perioodiliselt üle. Wink'i isikuandmete töötlemist reguleerib [Privaatsuspoliitika](/et/privacy) ja kõik andmetöötlustingimused Lepingus. Teie vastutate oma API volituste turvalisuse eest, kõigi andmete seadusliku kasutamise eest ning Wink'i viivitamatu teavitamise eest, kui kahtlustate volituste kompromiteerimist.

### 7. Vastutuse piiramine

Teenusekrediidid on **ainus ja eksklusiivne vahend** mis tahes kättesaamatuse või tööaja lubaduse mittetäitmise korral ning neid pakutakse kõigi muude vastutuste asemel. Välja arvatud käesolevas SLA-s selgesõnaliselt sätestatud, pakutakse Partneri API-d "nagu on" alusel. Maksimaalses seadusega lubatud ulatuses on Wink'i koguvastutus Teenuse osas piiratud Lepingus sätestatuga ning Wink ei vastuta kaudsete, juhuslike, erakorraliste, tagajärjel tekkivate või karistuslike kahjude, kasumi, tulu, andmete või hea tahte kaotuse eest, isegi kui on teavitatud selliste kahjude võimalikkusest.

### 8. Kehtivusaeg, muudatused ja lõpetamine

See SLA kehtib seni, kuni teil on aktiivne Partneri API tellimus tasemel, kus SLA kehtib. Wink võib seda SLA-d aeg-ajalt uuendada; olulised muudatused teatatakse kanalil, mida Wink tavaliselt kasutab klientidega suhtlemiseks, ning Partneri API jätkuv kasutamine pärast uuenduse jõustumist tähendab uuendatud SLA aktsepteerimist. See SLA lõpeb automaatselt Lepingust või teie Partneri API tellimusest loobumise või aegumise korral. Lõpetamisele vaatamata jäävad kehtima lõigud, mis oma olemuselt peaksid kehtima ka pärast lõpetamist — sealhulgas kogunenud, kuid nõudmata teenusekrediidi õigused, vastutuse piirang ja mõisted.
