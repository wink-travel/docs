Wink kasutaja võib valida, et annaks teile õiguse hallata ühte oma kinnisvara-, sidusettevõtte- või reisibüroo kontot. Kui see juhtub, saate kutse taotlusega e-kirja.

import { Steps } from '@astrojs/starlight/components';

Praeguste Wink kutsete nägemiseks järgige neid samme:

<Steps>
 1. Logige sisse aadressil [app.wink.travel](https://app.wink.travel).
 2. Klõpsake vasakpoolses külgribas `Invites`.
 3. Näete kõigi praeguste kutsete nimekirja.
 4. See jaotis kuvab kõik teie taotlused.
 5. Valige kutse `Accept` või `Reject`.
 6. Kui aktsepteerisite kutse, kuvatakse konto jaotises `Accounts`.
</Steps>
