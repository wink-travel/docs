Esta página lista todos los eventos webhook a los que puedes suscribirte en Wink. Para instrucciones de configuración, consulta la [Guía de Integración Webhook](/es/guides/developers/webhook-integration) o la [página de gestión de Webhooks](/es/portal/settings/webhooks).

## Cómo suscribirse

1. Navega a **Aplicaciones > Webhooks** en tu portal.
2. Crea un webhook y selecciona los eventos que deseas recibir.
3. Wink envía un HTTP POST a tu endpoint cada vez que ocurre el evento.

Para pasos completos de configuración y mejores prácticas, consulta [Integración Webhook](/es/guides/developers/webhook-integration).
