La **API para socios** de Wink es la forma autenticada y de mayor rendimiento para que los integradores consulten inventario de viajes reservable — el mismo suministro que alimenta nuestros widgets embebibles y los endpoints públicos de navegación, expuesto como una interfaz programática de primera clase. Mientras que los Web Components gratuitos y los endpoints públicos de navegación están pensados para integraciones ligeras orientadas a usuarios, la API para socios está diseñada para sistemas que buscan, cotizan y reservan a gran escala. El acceso se autentica por integrador y se factura por uso, por lo que solo pagas por el tráfico que realmente envías.

## Referencia de la API

Dos superficies OpenAPI sirven inventario reservable, y corresponden a los dos niveles anteriores:

- **Gratis — API de consumidor / motor de reservas** (`/api/public/**`): anónima, orientada a navegador y widgets. [Consulta la referencia del motor de reservas →](/es/api/booking-engine/)
- **De pago — API para integradores socios** (`/api/partner/**`): autenticada, con uso medido, diseñada para integración servidor a servidor a gran escala. [Consulta la referencia para integradores →](/es/integrations-api/integrator/)

## Cómo funcionan el uso y los límites

### Nivel gratuito

El nivel gratuito está diseñado para que puedas construir, probar y manejar un tráfico de producción modesto sin costo.

- **Límite de tasa — 30 solicitudes por minuto, con una ráfaga de 60 solicitudes.** Picos cortos por encima de la tasa sostenida se absorben con la ráfaga. Si la excedes, la API responde con **HTTP 429 (Demasiadas solicitudes)** y aplica una **pausa de 5 minutos** antes de que tu clave reanude el servicio. Retrocede y reintenta después de la pausa en lugar de saturar el endpoint.
- **Cuota mensual — 10,000 solicitudes por mes calendario.** Al alcanzar el límite mensual, la API devuelve **HTTP 429 por el resto del mes** — una parada estricta — junto con un mensaje invitándote a suscribirte al nivel de pago para continuar. El contador se reinicia al inicio del siguiente mes calendario.

El nivel gratuito no incluye Acuerdo de Nivel de Servicio ni soporte prioritario.

### Nivel de pago

El nivel de pago elimina el límite mensual y las pausas por límite de tasa, y te factura solo por lo que usas.

- **Solicitudes medidas — $1.00 por cada 1,000 solicitudes.** No hay límite mensual ni restricción por límite de tasa en uso normal; se factura según el volumen real.
- **Exceso look-to-book — $2.00 por cada 1,000 búsquedas en exceso.** Para mantener saludable el suministro, medimos la proporción de búsquedas ("looks") a reservas confirmadas. Tienes derecho a **5,000 búsquedas por reserva** antes de que se aplique el exceso. Las búsquedas en exceso se calculan como:

  `excess = max(0, looks − bookings × 5,000)`

  El exceso se factura a **$2.00 por cada 1,000 búsquedas en exceso**. Las integraciones con buena conversión rara vez incurren en exceso; el cargo solo aplica al tráfico que busca mucho más de lo que reserva.

El nivel de pago incluye el Acuerdo de Nivel de Servicio descrito a continuación — un compromiso de disponibilidad del 99.9% y un objetivo de tiempo de respuesta P95 menor a 500 ms — y soporte prioritario basado en severidad.

## Acuerdo de Nivel de Servicio

_Fecha de vigencia: 5 de julio de 2026 · Versión 1.0_

Este Acuerdo de Nivel de Servicio (el "SLA") establece el compromiso de disponibilidad, créditos de servicio y objetivos de soporte que Wink ("Wink", "nosotros") ofrece a un cliente ("Cliente", "usted") para la API autenticada de socios de Wink (la "API para socios" o el "Servicio") en los niveles donde se indica que aplica un SLA. Este SLA está incorporado y regido por el acuerdo entre usted y Wink bajo el cual accede a la API para socios (el "Acuerdo"), y aplica mientras mantenga una suscripción activa y pagada de la API para socios en buen estado. Los términos en mayúscula no definidos aquí tienen el significado que se les da en el Acuerdo.

### 1. Definiciones

1. **"Disponibilidad"** significa los períodos durante los cuales la API para socios está disponible para aceptar y responder con éxito a solicitudes correctamente formadas y autenticadas.
2. **"Indisponibilidad"** significa cualquier período, medido en minutos, durante el cual la API para socios no responde con éxito a solicitudes correctamente formadas y autenticadas, excluyendo cualquier período dentro de las Exclusiones indicadas en la Sección 4. Errores aislados que afectan una fracción insignificante de solicitudes no constituyen, por sí solos, Indisponibilidad.
3. **"Porcentaje mensual de disponibilidad"** significa, para un mes calendario dado, el total de minutos en ese mes menos los minutos de Indisponibilidad, dividido por el total de minutos en ese mes, expresado como porcentaje.
4. **"Mantenimiento programado"** significa mantenimiento planificado del Servicio para el cual Wink ha proporcionado aviso previo conforme a la Sección 4.
5. **"Crédito de servicio"** significa un crédito, calculado como un porcentaje de las tarifas pagadas o pagaderas por usted para la API para socios en el mes calendario afectado, que se aplica contra futuras tarifas de la API para socios como el único y exclusivo remedio por incumplimiento del compromiso de disponibilidad.
6. **"Tiempo de respuesta"** significa el tiempo transcurrido entre la recepción por parte de Wink de una solicitud correctamente formada y autenticada en el límite del servicio de Wink y el momento en que Wink comienza a devolver la respuesta, excluyendo el tránsito de red y cualquier tiempo del lado del cliente fuera del control de Wink.

### 2. Compromiso de disponibilidad y rendimiento

Wink hará esfuerzos comercialmente razonables para mantener la API para socios disponible con un **Porcentaje mensual de disponibilidad de al menos 99.9%** durante cada mes calendario del plazo (el "Compromiso de disponibilidad"). El Compromiso de disponibilidad se mide en el límite del servicio de Wink y excluye factores fuera del control razonable de Wink, incluidos los descritos en la Sección 4. Los sistemas de monitoreo de Wink son la fuente autorizada para medir el Porcentaje mensual de disponibilidad y el Tiempo de respuesta.

Además, Wink apunta a un **Tiempo de respuesta en el percentil 95 (P95) menor a 500 milisegundos** para solicitudes exitosas, correctamente formadas y autenticadas, medido en el límite del servicio de Wink durante cada mes calendario (el "Objetivo de rendimiento"). El Objetivo de rendimiento excluye los factores descritos en la Sección 4, solicitudes que devuelven errores a nivel de aplicación causados por la propia solicitud, y solicitudes por lotes inusualmente grandes o complejas. El Objetivo de rendimiento es un objetivo de servicio; los Créditos de servicio en la Sección 3 aplican a incumplimientos del **Compromiso de disponibilidad** y son el único y exclusivo remedio por deficiencias de disponibilidad.

### 3. Créditos de servicio

Si el Porcentaje mensual de disponibilidad cae por debajo del Compromiso de disponibilidad en cualquier mes calendario, usted puede ser elegible para un Crédito de servicio calculado como un porcentaje de las tarifas de la API para socios pagadas o pagaderas por usted para ese mes, según la siguiente tabla:

| Porcentaje mensual de disponibilidad | Crédito de servicio |
|---|---|
| Por debajo de 99.9% pero igual o superior a 99.0% | 10% |
| Por debajo de 99.0% pero igual o superior a 95.0% | 25% |
| Por debajo de 95.0% | 50% |

1. **Reclamar un crédito.** Para recibir un Crédito de servicio debe enviar una reclamación por escrito a Wink dentro de los **treinta (30) días** posteriores al final del mes calendario en que ocurrió la deficiencia. La reclamación debe incluir las fechas y horas de cada incidente de Indisponibilidad que reclama y cualquier registro o evidencia razonablemente disponible. Reclamos presentados fuera de este plazo no son elegibles.
2. **Forma del crédito.** Los Créditos de servicio aprobados se aplican contra futuras tarifas de la API para socios y no tienen valor en efectivo. No son reembolsos y no se pagarán excepto cuando lo exija la ley aplicable.
3. **Crédito máximo.** El total de Créditos de servicio otorgados por cualquier mes calendario no excederá el 50% de las tarifas de la API para socios pagadas o pagaderas por usted para ese mes.
4. **Remedio único y exclusivo.** Los Créditos de servicio son su **único y exclusivo remedio** por cualquier incumplimiento de Wink del Compromiso de disponibilidad o cualquier otra deficiencia de disponibilidad de la API para socios.

### 4. Exclusiones

El Compromiso de disponibilidad y cualquier Crédito de servicio resultante no aplican, y la Indisponibilidad no incluye, ninguna indisponibilidad, suspensión, degradación o problema de rendimiento que surja o esté relacionado con:

1. **Mantenimiento programado** para el cual Wink haya dado aviso previo, siempre que dicho aviso se haya dado con un período razonable de anticipación a través de un canal que Wink normalmente usa para comunicarse con los clientes;
2. eventos de **fuerza mayor** u otras causas fuera del control razonable de Wink, incluyendo desastres naturales, actos gubernamentales, fallas de red o servicios públicos, y ataques de denegación de servicio u otros ataques maliciosos;
3. problemas causados por actos u omisiones de **usted**, su equipo, software o red, o por cualquier servicio, producto o proveedor **tercero** no bajo control directo de Wink;
4. su **uso indebido del Servicio** o **incumplimiento del Acuerdo**, este SLA, los términos de uso aceptable o los límites de tasa aplicables, incluyendo tráfico que Wink determine razonablemente como excesivo, abuso automatizado o fraudulento; y
5. cualquier **suspensión o terminación** de su acceso debidamente efectuada bajo el Acuerdo, incluyendo suspensión por falta de pago.

### 5. Soporte y objetivos de respuesta

Wink proporciona soporte para la API para socios durante horas hábiles estándar, excluyendo feriados locales. Wink hará esfuerzos comercialmente razonables para reconocer solicitudes de soporte correctamente enviadas dentro de los siguientes tiempos objetivo de respuesta, basados en la severidad que usted asigne y que Wink confirme razonablemente:

| Severidad | Descripción | Tiempo objetivo de respuesta inicial |
|---|---|---|
| **Sev 1 — Crítico** | La API para socios está caída o inutilizable en producción sin solución alternativa. | 4 horas |
| **Sev 2 — Mayor** | Funcionalidad significativa afectada o degradada; existe solución alternativa. | 1 día hábil |
| **Sev 3 — Menor** | Preguntas generales, problemas menores o solicitudes de funciones. | 2 días hábiles |

Los tiempos objetivo de respuesta describen cuándo Wink pretende hacer **contacto inicial**; no garantizan tiempos de resolución. El soporte prioritario y los objetivos basados en severidad aplican en los niveles donde se indica que están incluidos.

### 6. Datos y seguridad

Wink mantiene medidas administrativas, técnicas y organizativas comercialmente razonables diseñadas para proteger la confidencialidad, integridad y disponibilidad de los datos procesados a través de la API para socios, y revisa esas medidas periódicamente. El procesamiento de datos personales por parte de Wink está regido por la [Política de privacidad](/es/privacy) y cualquier término de procesamiento de datos en el Acuerdo. Usted sigue siendo responsable de asegurar sus propias credenciales API, del uso legal de cualquier dato que recupere y de notificar prontamente a Wink sobre cualquier sospecha de compromiso de credenciales.

### 7. Limitación de responsabilidad

Los Créditos de servicio son el **único y exclusivo remedio** por cualquier indisponibilidad o incumplimiento del Compromiso de disponibilidad, y se proporcionan en lugar de cualquier otra responsabilidad derivada de dicho incumplimiento. Salvo lo expresamente indicado en este SLA, la API para socios se proporciona "tal cual está disponible". En la máxima medida permitida por la ley aplicable, la responsabilidad agregada de Wink derivada o relacionada con el Servicio está limitada según lo establecido en el Acuerdo, y Wink no es responsable por daños indirectos, incidentales, especiales, consecuentes o punitivos, ni por pérdida de beneficios, ingresos, datos o buena voluntad, incluso si se le ha advertido de la posibilidad de tales daños.

### 8. Vigencia, cambios y terminación

Este SLA aplica mientras tenga una suscripción activa a la API para socios en un nivel donde se indique que aplica el SLA. Wink puede actualizar este SLA ocasionalmente; los cambios materiales se comunicarán a través de un canal que Wink normalmente usa para llegar a los clientes, y el uso continuado de la API para socios después de que una actualización entre en vigor constituye aceptación del SLA actualizado. Este SLA termina automáticamente al terminar o expirar el Acuerdo o su suscripción a la API para socios. Las secciones que por su naturaleza deben sobrevivir a la terminación — incluyendo la elegibilidad acumulada pero no reclamada para Créditos de servicio, limitación de responsabilidad y definiciones — sobreviven.
