Booking Engine se puede incrustar en cualquier lugar. Elige tu framework o CMS y sigue su guía; los Web Components subyacentes son los mismos en todas partes.

## Enfoques principales

- [Web Components](/es/integrations/web-components/) — los elementos embebibles que usa toda integración.
- [npm package](/es/integrations/npm/) — instala en una build de JavaScript.
- [Headless CMS](/es/integrations/headless/) — renderiza desde cualquier backend de contenido.
- [Partner API](/es/integrations/partner-api/) — integración programática completa.
