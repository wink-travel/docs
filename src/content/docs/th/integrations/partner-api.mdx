Wink **Partner API** คือวิธีการที่มีการยืนยันตัวตนและรองรับการส่งข้อมูลจำนวนมากสำหรับผู้รวมระบบในการค้นหาสินค้าท่องเที่ยวที่สามารถจองได้ — ซัพพลายเดียวกับที่ขับเคลื่อนวิดเจ็ตฝังตัวและจุดเชื่อมต่อสาธารณะสำหรับการเรียกดู ซึ่งเปิดเผยในรูปแบบอินเทอร์เฟซโปรแกรมมิ่งระดับชั้นหนึ่ง ในขณะที่ Web Components ฟรีและจุดเชื่อมต่อสาธารณะสำหรับการเรียกดูเหมาะสำหรับการฝังที่เบาและมุ่งเน้นผู้ใช้ทั่วไป Partner API ถูกสร้างขึ้นสำหรับระบบที่ค้นหา กำหนดราคา และจองในระดับใหญ่ การเข้าถึงมีการยืนยันตัวตนแยกตามผู้รวมระบบและคิดค่าบริการตามการใช้งานจริง ดังนั้นคุณจึงจ่ายเฉพาะปริมาณข้อมูลที่คุณส่งจริงเท่านั้น

## เอกสารอ้างอิง API

มีสองส่วนที่ให้บริการสินค้าท่องเที่ยวที่สามารถจองได้ และสอดคล้องกับสองระดับข้างต้น:

- **ฟรี — Consumer / Booking Engine API** (REST, `/api/public/**`): ไม่ระบุตัวตน, สำหรับเบราว์เซอร์และวิดเจ็ต [เรียกดูเอกสาร Booking Engine →](/th/api/booking-engine/)
- **จ่ายเงิน — Partner Integrator API** (**gRPC**, `wink.partner.v1`): มีการยืนยันตัวตน, วัดปริมาณการใช้งาน, สร้างขึ้นสำหรับการรวมระบบเซิร์ฟเวอร์ต่อเซิร์ฟเวอร์ในระดับใหญ่ [เรียกดูเอกสาร Integrator →](/th/partner-api/partner/)

Partner Integrator API เป็น gRPC ไม่ใช่ REST คุณเรียกใช้งานด้วยไคลเอนต์ที่สร้างขึ้นผ่าน HTTP/2 ที่
`partner.wink.travel:443` โดยส่งโทเค็น Bearer และบัญชีที่คุณเรียกใช้งาน:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

หน้ารายละเอียดอ้างอิงข้างต้นจะอธิบายทุกบริการ ข้อความ และสถานะข้อผิดพลาด และสคีมาจะพร้อมใช้งานในเวลารันไทม์ผ่านการสะท้อนเซิร์ฟเวอร์ ดังนั้น `grpcurl`, Postman และ Insomnia จึงค้นพบได้โดยไม่ต้องดาวน์โหลดอะไรเพิ่มเติม

## วิธีการทำงานของการใช้งานและข้อจำกัด

### ระดับฟรี

ระดับฟรีออกแบบมาเพื่อให้คุณสร้าง ทดสอบ และใช้งานในระดับการจราจรที่ไม่สูงมากโดยไม่มีค่าใช้จ่าย

- **ข้อจำกัดอัตรา — 30 คำขอต่อนาที พร้อมระเบิด 60 คำขอ** ช่วงเวลาสั้น ๆ ที่เกินอัตราคงที่จะถูกดูดซับโดยการระเบิด หากเกินจะได้รับการตอบกลับด้วย **HTTP 429 (คำขอมากเกินไป)** และมีการ **หยุดชั่วคราว 5 นาที** ก่อนที่คีย์ของคุณจะเริ่มให้บริการอีกครั้ง หลีกเลี่ยงการส่งคำขอซ้ำในช่วงหยุดชั่วคราว
- **โควต้ารายเดือน — 10,000 คำขอต่อเดือนปฏิทิน** เมื่อถึงเพดานรายเดือน API จะส่งกลับ **HTTP 429 ตลอดช่วงเวลาที่เหลือของเดือน** — หยุดถาวร — พร้อมข้อความเชิญชวนให้สมัครใช้ระดับจ่ายเงินเพื่อใช้งานต่อ ตัวนับจะรีเซ็ตเมื่อเริ่มเดือนปฏิทินถัดไป

ระดับฟรีไม่มีข้อตกลงระดับการให้บริการหรือการสนับสนุนลำดับความสำคัญ

### ระดับจ่ายเงิน

ระดับจ่ายเงินจะไม่มีเพดานรายเดือนและไม่มีการหยุดชั่วคราวจากข้อจำกัดอัตรา และคิดค่าบริการเฉพาะที่คุณใช้งานจริง

- **คำขอที่วัดปริมาณ — $1.00 ต่อ 1,000 คำขอ** ไม่มีเพดานคำขอรายเดือนและไม่มีการจำกัดอัตราในสภาวะปกติ คุณจะถูกคิดค่าบริการตามปริมาณจริง
- **ค่าปรับ Look-to-book — $2.00 ต่อ 1,000 การค้นหาที่เกิน** เพื่อรักษาความสมดุลของซัพพลาย เราจะวัดอัตราส่วนของการค้นหา ("looks") ต่อการจองที่ยืนยัน คุณจะได้รับสิทธิ์ **5,000 การค้นหาต่อการจองหนึ่งครั้ง** ก่อนที่จะมีการคิดค่าปรับ การค้นหาที่เกินคำนวณได้ดังนี้:

  `excess = max(0, looks − bookings × 5,000)`

  ค่าปรับจะคิดที่ **$2.00 ต่อ 1,000 การค้นหาที่เกิน** การรวมระบบที่มีอัตราการแปลงดีมักจะไม่ถูกคิดค่าปรับ ค่าบริการนี้จะใช้กับการจราจรที่ค้นหามากกว่าการจองอย่างมากเท่านั้น

ระดับจ่ายเงินรวมข้อตกลงระดับการให้บริการที่อธิบายไว้ด้านล่าง — การรับประกันเวลาทำงาน 99.9% และเป้าหมายเวลาตอบสนอง P95 ต่ำกว่า 500 มิลลิวินาที — รวมถึงการสนับสนุนลำดับความสำคัญตามความรุนแรง

## ข้อตกลงระดับการให้บริการ

_วันที่มีผล: 5 กรกฎาคม 2026 · เวอร์ชัน 1.0_

ข้อตกลงระดับการให้บริการนี้ ("SLA") กำหนดความมุ่งมั่นด้านความพร้อมใช้งาน เครดิตบริการ และเป้าหมายการสนับสนุนที่ Wink ("Wink", "เรา", "พวกเรา") มอบให้กับลูกค้า ("ลูกค้า", "คุณ") สำหรับ Wink Partner API ที่มีการยืนยันตัวตน ("Partner API" หรือ "บริการ") ในระดับที่ระบุว่าใช้ SLA นี้ ข้อตกลงนี้ถูกรวมเข้าและถูกควบคุมโดยข้อตกลงระหว่างคุณกับ Wink ซึ่งคุณเข้าถึง Partner API ("ข้อตกลง") และใช้ได้ตราบเท่าที่คุณมีการสมัครสมาชิก Partner API ที่ชำระเงินและอยู่ในสถานะดี คำศัพท์ที่ใช้ตัวพิมพ์ใหญ่ซึ่งไม่ได้กำหนดไว้ที่นี่มีความหมายตามที่ระบุในข้อตกลง

### 1. คำจำกัดความ

1. **"เวลาทำงาน"** หมายถึงช่วงเวลาที่ Partner API พร้อมให้บริการรับและตอบสนองคำขอที่ถูกต้องและยืนยันตัวตนสำเร็จ
2. **"เวลาหยุดทำงาน"** หมายถึงช่วงเวลาที่วัดเป็นนาทีซึ่ง Partner API ไม่สามารถตอบสนองคำขอที่ถูกต้องและยืนยันตัวตนได้สำเร็จ โดยไม่รวมช่วงเวลาที่ตกอยู่ในข้อยกเว้นตามมาตรา 4 ข้อผิดพลาดที่เกิดขึ้นแยกส่วนและส่งผลกระทบต่อคำขอเพียงส่วนน้อยไม่ถือเป็นเวลาหยุดทำงาน
3. **"เปอร์เซ็นต์เวลาทำงานรายเดือน"** หมายถึงจำนวนรวมของนาทีในเดือนปฏิทินนั้นลบด้วยเวลาหยุดทำงานทั้งหมด หารด้วยจำนวนรวมของนาทีในเดือนนั้น แสดงเป็นเปอร์เซ็นต์
4. **"การบำรุงรักษาที่กำหนดไว้ล่วงหน้า"** หมายถึงการบำรุงรักษาบริการที่ Wink แจ้งล่วงหน้าตามมาตรา 4
5. **"เครดิตบริการ"** หมายถึงเครดิตที่คำนวณเป็นเปอร์เซ็นต์ของค่าธรรมเนียมที่คุณจ่ายหรือค้างชำระสำหรับ Partner API ในเดือนปฏิทินที่ได้รับผลกระทบ ซึ่งใช้เป็นการเยียวยาเดียวและเฉพาะสำหรับการไม่ปฏิบัติตามความมุ่งมั่นเวลาทำงาน
6. **"เวลาตอบสนอง"** หมายถึงเวลาที่ผ่านไปตั้งแต่ Wink รับคำขอที่ถูกต้องและยืนยันตัวตนที่ขอบเขตบริการของ Wink จนถึงจุดที่ Wink เริ่มส่งกลับการตอบสนอง โดยไม่รวมเวลาขนส่งเครือข่ายและเวลาฝั่งไคลเอนต์ที่อยู่นอกการควบคุมของ Wink

### 2. ความมุ่งมั่นด้านความพร้อมใช้งานและประสิทธิภาพ

Wink จะใช้ความพยายามอย่างสมเหตุสมผลในเชิงพาณิชย์เพื่อให้ Partner API พร้อมใช้งานที่ **เปอร์เซ็นต์เวลาทำงานรายเดือนอย่างน้อย 99.9%** ในแต่ละเดือนปฏิทินของระยะเวลาสัญญา ("ความมุ่งมั่นเวลาทำงาน") ความมุ่งมั่นเวลาทำงานนี้วัดที่ขอบเขตบริการของ Wink และไม่รวมปัจจัยที่อยู่นอกการควบคุมอย่างสมเหตุสมผลของ Wink รวมถึงที่ระบุในมาตรา 4 ระบบตรวจสอบของ Wink เป็นแหล่งข้อมูลที่เชื่อถือได้สำหรับการวัดเปอร์เซ็นต์เวลาทำงานรายเดือนและเวลาตอบสนอง

Wink ยังตั้งเป้า **เวลาตอบสนองเปอร์เซ็นไทล์ที่ 95 (P95) ต่ำกว่า 500 มิลลิวินาที** สำหรับคำขอที่ถูกต้องและยืนยันตัวตนสำเร็จ วัดที่ขอบเขตบริการของ Wink ในแต่ละเดือนปฏิทิน ("เป้าหมายประสิทธิภาพ") เป้าหมายประสิทธิภาพไม่รวมปัจจัยที่ระบุในมาตรา 4 คำขอที่ส่งกลับข้อผิดพลาดระดับแอปพลิเคชันที่เกิดจากคำขอเอง และคำขอแบบแบตช์ที่มีขนาดใหญ่หรือซับซ้อนผิดปกติ เป้าหมายประสิทธิภาพเป็นวัตถุประสงค์ของบริการ เครดิตบริการในมาตรา 3 จะใช้กับความล้มเหลวในการปฏิบัติตาม **ความมุ่งมั่นเวลาทำงาน** และเป็นการเยียวยาเดียวและเฉพาะสำหรับปัญหาความพร้อมใช้งาน

### 3. เครดิตบริการ

หากเปอร์เซ็นต์เวลาทำงานรายเดือนต่ำกว่าความมุ่งมั่นเวลาทำงานในเดือนปฏิทินใด ๆ คุณอาจมีสิทธิ์ได้รับเครดิตบริการซึ่งคำนวณเป็นเปอร์เซ็นต์ของค่าธรรมเนียม Partner API ที่คุณจ่ายหรือค้างชำระสำหรับเดือนนั้น ตามระดับดังนี้:

| เปอร์เซ็นต์เวลาทำงานรายเดือน | เครดิตบริการ |
|---|---|
| ต่ำกว่า 99.9% แต่ไม่ต่ำกว่า 99.0% | 10% |
| ต่ำกว่า 99.0% แต่ไม่ต่ำกว่า 95.0% | 25% |
| ต่ำกว่า 95.0% | 50% |

1. **การเรียกร้องเครดิต** เพื่อรับเครดิตบริการ คุณต้องส่งคำร้องเป็นลายลักษณ์อักษรถึง Wink ภายใน **สามสิบ (30) วัน** หลังสิ้นเดือนปฏิทินที่เกิดปัญหา คำร้องต้องระบุวันที่และเวลาของแต่ละเหตุการณ์เวลาหยุดทำงานที่คุณเรียกร้อง พร้อมบันทึกหรือหลักฐานสนับสนุนที่คุณมีอยู่ตามสมควร คำร้องที่ส่งหลังช่วงเวลานี้จะไม่ได้รับสิทธิ์
2. **รูปแบบเครดิต** เครดิตบริการที่ได้รับการอนุมัติจะถูกนำไปหักลบกับค่าธรรมเนียม Partner API ในอนาคตและไม่มีมูลค่าเป็นเงินสด ไม่ใช่การคืนเงินและจะไม่จ่ายเป็นเงินสดเว้นแต่กฎหมายที่ใช้บังคับกำหนด
3. **เครดิตสูงสุด** เครดิตบริการรวมสูงสุดสำหรับเดือนปฏิทินใด ๆ จะไม่เกิน 50% ของค่าธรรมเนียม Partner API ที่คุณจ่ายหรือค้างชำระสำหรับเดือนนั้น
4. **การเยียวยาเดียวและเฉพาะ** เครดิตบริการเป็น **การเยียวยาเดียวและเฉพาะ** สำหรับความล้มเหลวใด ๆ ของ Wink ในการปฏิบัติตามความมุ่งมั่นเวลาทำงานหรือปัญหาความพร้อมใช้งานอื่น ๆ ของ Partner API

### 4. ข้อยกเว้น

ความมุ่งมั่นเวลาทำงานและเครดิตบริการที่เกิดขึ้นไม่ครอบคลุม และเวลาหยุดทำงานไม่รวมถึง ความไม่พร้อมใช้งาน การระงับ การเสื่อมสภาพ หรือปัญหาประสิทธิภาพที่เกิดจากหรือเกี่ยวข้องกับ:

1. **การบำรุงรักษาที่กำหนดไว้ล่วงหน้า** ที่ Wink แจ้งล่วงหน้าตามช่องทางที่ Wink ใช้สื่อสารกับลูกค้าเป็นประจำ
2. เหตุการณ์ **เหตุสุดวิสัย** หรือสาเหตุอื่นที่อยู่นอกการควบคุมอย่างสมเหตุสมผลของ Wink รวมถึงภัยธรรมชาติ การกระทำของรัฐบาล ความล้มเหลวของเครือข่ายหรือสาธารณูปโภค และการโจมตีแบบปฏิเสธการให้บริการหรือการโจมตีที่เป็นอันตรายอื่น ๆ
3. ปัญหาที่เกิดจากการกระทำหรือการละเลยของ **คุณ** อุปกรณ์ ซอฟต์แวร์ หรือเครือข่ายของคุณ หรือบริการ ผลิตภัณฑ์ หรือผู้ให้บริการ **บุคคลที่สาม** ที่ไม่อยู่ภายใต้การควบคุมโดยตรงของ Wink
4. การ **ละเมิดการใช้บริการ** หรือ **การฝ่าฝืนข้อตกลง** นี้ SLA ข้อกำหนดการใช้งานที่ยอมรับได้ หรือข้อจำกัดอัตราที่ใช้บังคับ รวมถึงการจราจรที่ Wink เห็นว่าเกินความเหมาะสม การละเมิดอัตโนมัติ หรือการฉ้อโกง
5. การ **ระงับหรือยกเลิก** การเข้าถึงของคุณที่ดำเนินการอย่างถูกต้องตามข้อตกลง รวมถึงการระงับเนื่องจากไม่ชำระเงิน

### 5. การสนับสนุนและเป้าหมายการตอบสนอง

Wink ให้การสนับสนุนสำหรับ Partner API ในช่วงเวลาทำการปกติ ไม่รวมวันหยุดราชการท้องถิ่น Wink จะใช้ความพยายามอย่างสมเหตุสมผลในเชิงพาณิชย์เพื่อตอบรับคำขอสนับสนุนที่ส่งมาอย่างถูกต้องภายในเวลาตอบสนองเป้าหมายต่อไปนี้ ตามความรุนแรงที่คุณกำหนดและ Wink ยืนยันอย่างสมเหตุสมผล:

| ความรุนแรง | คำอธิบาย | เป้าหมายการตอบสนองเริ่มต้น |
|---|---|---|
| **Sev 1 — รุนแรงมาก** | Partner API หยุดทำงานหรือใช้งานไม่ได้ในระบบจริงโดยไม่มีวิธีแก้ไขชั่วคราว | 4 ชั่วโมง |
| **Sev 2 — รุนแรงปานกลาง** | ฟีเจอร์สำคัญทำงานผิดปกติหรือเสื่อมสภาพ มีวิธีแก้ไขชั่วคราว | 1 วันทำการ |
| **Sev 3 — เล็กน้อย** | คำถามทั่วไป ปัญหาเล็กน้อย หรือคำขอฟีเจอร์ | 2 วันทำการ |

เวลาตอบสนองเป้าหมายหมายถึงเวลาที่ Wink ตั้งใจจะติดต่อ **ครั้งแรก** ไม่ใช่เวลารับประกันการแก้ไข การสนับสนุนลำดับความสำคัญและเป้าหมายตามความรุนแรงใช้กับระดับที่ระบุว่าได้รับบริการนี้

### 6. ข้อมูลและความปลอดภัย

Wink รักษามาตรการบริหารจัดการ เทคนิค และองค์กรที่สมเหตุสมผลในเชิงพาณิชย์เพื่อปกป้องความลับ ความสมบูรณ์ และความพร้อมใช้งานของข้อมูลที่ประมวลผลผ่าน Partner API และทบทวนมาตรการเหล่านี้เป็นระยะ Wink การประมวลผลข้อมูลส่วนบุคคลถูกควบคุมโดย [นโยบายความเป็นส่วนตัว](/th/privacy) และข้อกำหนดการประมวลผลข้อมูลในข้อตกลง คุณยังคงรับผิดชอบในการรักษาความปลอดภัยข้อมูลรับรอง API ของคุณ การใช้งานข้อมูลที่ถูกกฎหมาย และการแจ้ง Wink อย่างรวดเร็วหากสงสัยว่าข้อมูลรับรองถูกละเมิด

### 7. ข้อจำกัดความรับผิดชอบ

เครดิตบริการเป็น **การเยียวยาเดียวและเฉพาะ** สำหรับความไม่พร้อมใช้งานหรือความล้มเหลวในการปฏิบัติตามความมุ่งมั่นเวลาทำงาน และให้แทนความรับผิดชอบอื่นใดที่เกิดจากความล้มเหลวดังกล่าว เว้นแต่จะระบุไว้อย่างชัดเจนใน SLA นี้ Partner API ให้บริการในสภาพ "ตามที่มี" ในขอบเขตสูงสุดที่กฎหมายใช้บังคับ ความรับผิดชอบรวมของ Wink ที่เกิดขึ้นจากหรือเกี่ยวข้องกับบริการถูกจำกัดตามที่ระบุในข้อตกลง และ Wink จะไม่รับผิดชอบต่อความเสียหายทางอ้อม เหตุการณ์พิเศษ ผลที่ตามมา หรือค่าปรับ หรือความเสียหายจากกำไร รายได้ ข้อมูล หรือชื่อเสียงที่สูญหาย แม้จะได้รับแจ้งถึงความเป็นไปได้ของความเสียหายดังกล่าวแล้วก็ตาม

### 8. ระยะเวลา การเปลี่ยนแปลง และการยกเลิก

SLA นี้ใช้ได้ตราบเท่าที่คุณมีการสมัครสมาชิก Partner API ที่ใช้งานอยู่ในระดับที่ระบุว่าใช้ SLA นี้ Wink อาจปรับปรุง SLA นี้เป็นครั้งคราว การเปลี่ยนแปลงที่สำคัญจะสื่อสารผ่านช่องทางที่ Wink ใช้สื่อสารกับลูกค้าเป็นประจำ และการใช้งาน Partner API ต่อหลังจากการอัปเดตมีผลถือเป็นการยอมรับ SLA ที่อัปเดตแล้ว SLA นี้จะสิ้นสุดโดยอัตโนมัติเมื่อข้อตกลงหรือการสมัครสมาชิก Partner API ของคุณสิ้นสุดหรือหมดอายุ ส่วนที่โดยธรรมชาติควรคงอยู่หลังการยกเลิก — รวมถึงสิทธิ์เครดิตบริการที่ยังไม่ได้เรียกร้อง ข้อจำกัดความรับผิดชอบ และคำจำกัดความ — จะยังคงมีผลต่อไป
