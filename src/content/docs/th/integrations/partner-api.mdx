Wink **Partner API** คือวิธีการที่ได้รับการยืนยันตัวตนและมีความสามารถในการประมวลผลสูงสำหรับผู้รวมระบบในการค้นหาสินค้าคงคลังการเดินทางที่สามารถจองได้ — ซึ่งเป็นซัพพลายเดียวกับที่ขับเคลื่อนวิดเจ็ตฝังตัวและจุดเชื่อมต่อการเรียกดูสาธารณะ โดยเปิดเผยในรูปแบบอินเทอร์เฟซโปรแกรมมิ่งระดับชั้นหนึ่ง ในขณะที่ Web Components ฟรีและจุดเชื่อมต่อการเรียกดูสาธารณะเหมาะสำหรับการฝังที่เบาและมุ่งเน้นผู้ใช้ทั่วไป Partner API ถูกสร้างขึ้นสำหรับระบบที่ค้นหา กำหนดราคา และจองในระดับขนาดใหญ่ การเข้าถึงได้รับการยืนยันตัวตนตามผู้รวมระบบและคิดค่าบริการตามการใช้งาน ดังนั้นคุณจึงจ่ายเฉพาะปริมาณการใช้งานที่คุณส่งจริงเท่านั้น

## แผนและราคา

การใช้งานถูกวัดเป็น **คืนโรงแรม**: โรงแรมหนึ่งแห่งที่กำหนดราคาสำหรับการเข้าพักหนึ่งคืน — *ไม่ใช่* การเรียก API หนึ่งครั้ง การค้นหาที่ส่งคืนโรงแรม 20 แห่งสำหรับการเข้าพัก 3 คืนจะเท่ากับ 60 คืนโรงแรมจากคำขอเดียว การเรียก Content และ Lookup (การค้นหาปลายทางและการเติมข้อความอัตโนมัติ) เป็นข้อยกเว้น: แต่ละคำขอคิดเป็นหนึ่งหน่วยต่อการเรียก ไม่ว่าจะส่งคืนข้อมูลเท่าใด จุดเชื่อมต่อบัญชีฟรี [ราคาค่าใช้จ่าย](/th/pricing/) เป็นแหล่งข้อมูลที่ถูกต้องสำหรับอัตรา

| | ฟรี | จ่ายเงิน | องค์กร |
|---|---|---|---|
| **ราคา** | $0 | คิดตามการใช้งาน | ติดต่อเรา |
| **เหมาะสำหรับ** | การประเมิน & การรวมระบบปริมาณต่ำ | การจ่ายตามการใช้งานในระดับขนาดใหญ่ | ปริมาณที่กำหนดเอง & เงื่อนไขที่เจรจาได้ |
| หน่วยต่อเดือน | 10,000 | ไม่จำกัด | ไม่จำกัด |
| เวลาตอบสนอง API (P95) | — | ต่ำกว่า 500 มิลลิวินาที | ต่ำกว่า 500 มิลลิวินาที |

## เอกสารอ้างอิง API

มีสองส่วนที่ให้บริการสินค้าคงคลังที่สามารถจองได้ และสอดคล้องกับสองระดับข้างต้น:

- **ฟรี — Consumer / Booking Engine API** (REST, `/api/public/**`): ไม่ระบุตัวตน เหมาะสำหรับเบราว์เซอร์และวิดเจ็ต [เรียกดูเอกสาร Booking Engine →](/th/api/booking-engine/)
- **จ่ายเงิน — Partner Integrator API** (**gRPC**, `wink.partner.v1`): มีการยืนยันตัวตน วัดการใช้งาน สร้างขึ้นสำหรับการรวมระบบเซิร์ฟเวอร์ต่อเซิร์ฟเวอร์ในระดับขนาดใหญ่ [เรียกดูเอกสาร Integrator →](/th/partner-api/partner/)

Partner Integrator API เป็น gRPC ไม่ใช่ REST คุณเรียกใช้ด้วยไคลเอนต์ที่สร้างขึ้นผ่าน HTTP/2 ที่
`partner.wink.travel:443` โดยส่งโทเค็น Bearer และบัญชีที่คุณเรียกใช้:

```bash
grpcurl -H "authorization: Bearer $WINK_TOKEN" partner.wink.travel:443 list
```

หน้าการอ้างอิงข้างต้นมีเอกสารทุกบริการ ข้อความ และสถานะข้อผิดพลาด และสคีมานี้ยังสามารถเข้าถึงได้ในเวลารันผ่านการสะท้อนเซิร์ฟเวอร์ ดังนั้น `grpcurl`, Postman และ Insomnia จึงค้นพบได้โดยไม่ต้องดาวน์โหลดอะไร

หากคุณต้องการสร้างไคลเอนต์ล่วงหน้า ไฟล์ต้นฉบับ `.proto` เผยแพร่ที่
[github.com/wink-travel/partner-api-proto](https://github.com/wink-travel/partner-api-proto)

## วิธีการทำงานของการใช้งานและข้อจำกัด

### ระดับฟรี

ระดับฟรีออกแบบมาเพื่อให้คุณสร้าง ทดสอบ และใช้งานการจราจรในระดับการผลิตที่ไม่สูงโดยไม่มีค่าใช้จ่าย

- **ไม่มีข้อจำกัดต่อชั่วโมงที่เผยแพร่** Wink ตรวจสอบอัตราการร้องขอและอาจใช้ข้อจำกัดการใช้งานที่เป็นธรรมเพื่อปกป้องบริการ หากคุณได้รับ **HTTP 429 (Too Many Requests)** ให้รอจำนวนวินาทีที่ระบุในส่วนหัว `Retry-After` ก่อนลองใหม่
- **โควตารายเดือน — 10,000 หน่วยต่อเดือนปฏิทิน** โควตานี้ให้ต่อบัญชีและรีเซ็ตในวันที่ 1 ของทุกเดือน (UTC) เมื่อถึงโควตา บัญชีที่ไม่ได้สมัครใช้การคิดค่าบริการตามการใช้งานจะได้รับ **HTTP 429 จนถึงวันที่ 1 ของเดือนถัดไป** — หยุดการใช้งานอย่างเด็ดขาด พร้อมส่วนหัว `Retry-After` และข้อความเชิญชวนให้สมัครแผนจ่ายเงิน บัญชีที่สมัครแล้วจะทำงานต่อและถูกคิดเงินตามการใช้งานเกินโควตา

ระดับฟรีไม่มีข้อตกลงระดับการให้บริการหรือการสนับสนุนลำดับความสำคัญ

### ระดับจ่ายเงิน

ระดับจ่ายเงินจะลบเพดานรายเดือนและคิดเงินเฉพาะที่คุณใช้จริง

- **คืนโรงแรมที่วัดได้ — $0.0001 ต่อคืนโรงแรม** ไม่มีเพดานรายเดือน คุณถูกคิดเงินตามปริมาณจริง Wink อาจยังใช้ข้อจำกัดการใช้งานที่เป็นธรรมเพื่อปกป้องบริการ การค้นหาและการเรียกดูสินค้าคงคลังคิดเงินตามคืนโรงแรมที่กำหนดราคา; การเรียก Content และ Lookup คิดเงินหนึ่งหน่วยต่อคำขอ ดังนั้นการรวมคำขอจะช่วยลดค่าใช้จ่าย

ระดับจ่ายเงินรวมข้อตกลงระดับการให้บริการที่อธิบายไว้ด้านล่าง — การรับประกันความพร้อมใช้งาน 99.9% และเป้าหมายเวลาตอบสนอง P95 ต่ำกว่า 500 มิลลิวินาที — และการสนับสนุนลำดับความสำคัญตามความรุนแรง

## ข้อตกลงระดับการให้บริการ

_วันที่มีผล: 5 กรกฎาคม 2026 · เวอร์ชัน 1.0_

ข้อตกลงระดับการให้บริการนี้ ("SLA") กำหนดความมุ่งมั่นด้านความพร้อมใช้งาน เครดิตบริการ และเป้าหมายการสนับสนุนที่ Wink ("Wink", "เรา", "พวกเรา") มอบให้กับลูกค้า ("ลูกค้า", "คุณ") สำหรับ Wink Partner API ที่มีการยืนยันตัวตน ("Partner API" หรือ "บริการ") ในระดับที่ระบุว่าใช้ SLA ข้อตกลงนี้ถูกรวมเข้าและควบคุมโดยข้อตกลงระหว่างคุณกับ Wink ซึ่งคุณเข้าถึง Partner API ("ข้อตกลง") และใช้ได้ตราบเท่าที่คุณรักษาการสมัครสมาชิก Partner API ที่ชำระเงินและมีสถานะดี คำศัพท์ที่ใช้ตัวพิมพ์ใหญ่ซึ่งไม่ได้กำหนดไว้ที่นี่มีความหมายตามที่ระบุในข้อตกลง

### 1. คำจำกัดความ

1. **"เวลาทำงาน"** หมายถึงช่วงเวลาที่ Partner API พร้อมใช้งานเพื่อรับและตอบสนองคำขอที่ถูกต้องและได้รับการยืนยันตัวตนอย่างสำเร็จ
2. **"เวลาหยุดทำงาน"** หมายถึงช่วงเวลาที่วัดเป็นนาทีซึ่ง Partner API ไม่สามารถตอบสนองคำขอที่ถูกต้องและได้รับการยืนยันตัวตนอย่างสำเร็จ ยกเว้นช่วงเวลาที่อยู่ในข้อยกเว้นตามมาตรา 4 ข้อผิดพลาดที่เกิดขึ้นแยกกันซึ่งส่งผลกระทบต่อคำขอเพียงส่วนน้อยไม่ถือเป็นเวลาหยุดทำงานโดยตัวมันเอง
3. **"เปอร์เซ็นต์เวลาทำงานรายเดือน"** หมายถึงสำหรับเดือนปฏิทินใด ๆ จำนวนเวลาทำงานทั้งหมดในเดือนนั้นลบด้วยเวลาหยุดทำงานทั้งหมด หารด้วยจำนวนเวลาทั้งหมดในเดือนนั้น แสดงเป็นเปอร์เซ็นต์
4. **"การบำรุงรักษาที่กำหนดเวลา"** หมายถึงการบำรุงรักษาบริการที่วางแผนไว้ซึ่ง Wink ได้แจ้งล่วงหน้าตามมาตรา 4
5. **"เครดิตบริการ"** หมายถึงเครดิตที่คำนวณเป็นเปอร์เซ็นต์ของค่าธรรมเนียมที่คุณจ่ายหรือค้างชำระสำหรับ Partner API ในเดือนปฏิทินที่ได้รับผลกระทบ ซึ่งใช้เป็นการเยียวยาเดียวและเฉพาะสำหรับความล้มเหลวในการปฏิบัติตามความมุ่งมั่นเวลาทำงาน
6. **"เวลาตอบสนอง"** หมายถึงเวลาที่ผ่านไประหว่าง Wink รับคำขอที่ถูกต้องและได้รับการยืนยันตัวตนที่ขอบเขตบริการของ Wink จนถึงจุดที่ Wink เริ่มส่งคืนการตอบสนอง ไม่รวมเวลาขนส่งเครือข่ายและเวลาฝั่งไคลเอนต์ที่อยู่นอกการควบคุมของ Wink

### 2. ความมุ่งมั่นด้านความพร้อมใช้งานและประสิทธิภาพ

Wink จะใช้ความพยายามอย่างสมเหตุสมผลในเชิงพาณิชย์เพื่อให้ Partner API พร้อมใช้งานที่ **เปอร์เซ็นต์เวลาทำงานรายเดือนอย่างน้อย 99.9%** ในแต่ละเดือนปฏิทินของระยะเวลาสัญญา ("ความมุ่งมั่นเวลาทำงาน") ความมุ่งมั่นเวลาทำงานถูกวัดที่ขอบเขตบริการของ Wink และไม่รวมปัจจัยที่อยู่นอกการควบคุมอย่างสมเหตุสมผลของ Wink รวมถึงที่ระบุในมาตรา 4 ระบบตรวจสอบของ Wink เป็นแหล่งข้อมูลที่เชื่อถือได้สำหรับการวัดเปอร์เซ็นต์เวลาทำงานรายเดือนและเวลาตอบสนอง

Wink ยังตั้งเป้า **เวลาตอบสนองเปอร์เซ็นไทล์ที่ 95 (P95) ต่ำกว่า 500 มิลลิวินาที** สำหรับคำขอที่ถูกต้องและได้รับการยืนยันตัวตนที่สำเร็จ วัดที่ขอบเขตบริการของ Wink ในแต่ละเดือนปฏิทิน ("เป้าหมายประสิทธิภาพ") เป้าหมายประสิทธิภาพไม่รวมปัจจัยที่ระบุในมาตรา 4 คำขอที่ส่งคืนข้อผิดพลาดระดับแอปพลิเคชันที่เกิดจากคำขอเอง และคำขอแบบกลุ่มที่มีขนาดใหญ่หรือซับซ้อนผิดปกติ เป้าหมายประสิทธิภาพเป็นวัตถุประสงค์ของบริการ เครดิตบริการในมาตรา 3 ใช้กับความล้มเหลวในการปฏิบัติตาม **ความมุ่งมั่นเวลาทำงาน** และเป็นการเยียวยาเดียวและเฉพาะสำหรับความล้มเหลวด้านความพร้อมใช้งาน

### 3. เครดิตบริการ

หากเปอร์เซ็นต์เวลาทำงานรายเดือนต่ำกว่าความมุ่งมั่นเวลาทำงานในเดือนปฏิทินใด ๆ คุณอาจมีสิทธิ์ได้รับเครดิตบริการซึ่งคำนวณเป็นเปอร์เซ็นต์ของค่าธรรมเนียม Partner API ที่คุณจ่ายหรือค้างชำระสำหรับเดือนนั้น ตามระดับดังนี้:

| เปอร์เซ็นต์เวลาทำงานรายเดือน | เครดิตบริการ |
|---|---|
| ต่ำกว่า 99.9% แต่ไม่ต่ำกว่า 99.0% | 10% |
| ต่ำกว่า 99.0% แต่ไม่ต่ำกว่า 95.0% | 25% |
| ต่ำกว่า 95.0% | 50% |

1. **การเรียกร้องเครดิต** เพื่อรับเครดิตบริการ คุณต้องส่งคำร้องเป็นลายลักษณ์อักษรถึง Wink ภายใน **สามสิบ (30) วัน** หลังสิ้นเดือนปฏิทินที่เกิดความล้มเหลว คำร้องต้องระบุวันที่และเวลาของแต่ละเหตุการณ์เวลาหยุดทำงานที่คุณเรียกร้อง พร้อมบันทึกหรือหลักฐานสนับสนุนที่คุณมีอยู่ตามสมควร คำร้องที่ส่งหลังช่วงเวลานี้จะไม่ได้รับสิทธิ์
2. **รูปแบบเครดิต** เครดิตบริการที่ได้รับการอนุมัติจะถูกนำไปหักลบกับค่าธรรมเนียม Partner API ในอนาคตและไม่มีมูลค่าเป็นเงินสด ไม่ใช่การคืนเงินและจะไม่จ่ายเป็นเงินสดเว้นแต่กฎหมายที่ใช้บังคับกำหนด
3. **เครดิตสูงสุด** เครดิตบริการรวมสูงสุดสำหรับเดือนปฏิทินใด ๆ จะไม่เกิน 50% ของค่าธรรมเนียม Partner API ที่คุณจ่ายหรือค้างชำระสำหรับเดือนนั้น
4. **การเยียวยาเดียวและเฉพาะ** เครดิตบริการเป็น **การเยียวยาเดียวและเฉพาะ** สำหรับความล้มเหลวใด ๆ ของ Wink ในการปฏิบัติตามความมุ่งมั่นเวลาทำงานหรือความล้มเหลวด้านความพร้อมใช้งานอื่น ๆ ของ Partner API

### 4. ข้อยกเว้น

ความมุ่งมั่นเวลาทำงานและเครดิตบริการที่เกิดขึ้นไม่ใช้กับ และเวลาหยุดทำงานไม่รวมถึง ความไม่พร้อมใช้งาน การระงับ การเสื่อมสภาพ หรือปัญหาด้านประสิทธิภาพที่เกิดจากหรือเกี่ยวข้องกับ:

1. **การบำรุงรักษาที่กำหนดเวลา** ที่ Wink ได้แจ้งล่วงหน้า โดยแจ้งล่วงหน้าในช่วงเวลาที่เหมาะสมผ่านช่องทางที่ Wink ใช้สื่อสารกับลูกค้าเป็นประจำ;
2. เหตุการณ์ **เหตุสุดวิสัย** หรือสาเหตุอื่นที่อยู่นอกการควบคุมอย่างสมเหตุสมผลของ Wink รวมถึงภัยธรรมชาติ การกระทำของรัฐบาล ความล้มเหลวของเครือข่ายหรือสาธารณูปโภค และการโจมตีแบบปฏิเสธการให้บริการหรือการโจมตีที่เป็นอันตรายอื่น ๆ;
3. ปัญหาที่เกิดจากการกระทำหรือการละเลยของ **คุณ** อุปกรณ์ ซอฟต์แวร์ หรือเครือข่ายของคุณ หรือโดยบริการ ผลิตภัณฑ์ หรือผู้ให้บริการ **บุคคลที่สาม** ที่ไม่อยู่ภายใต้การควบคุมโดยตรงของ Wink;
4. การ **ละเมิดการใช้บริการ** หรือ **การฝ่าฝืนข้อตกลง** นี้ SLA ข้อกำหนดการใช้งานที่ยอมรับได้ หรือข้อจำกัดอัตราที่ใช้บังคับ รวมถึงการจราจรที่ Wink เห็นว่าเกินความเหมาะสม การละเมิดอัตโนมัติ หรือการฉ้อโกง; และ
5. การ **ระงับหรือยุติ** การเข้าถึงของคุณที่ดำเนินการอย่างถูกต้องตามข้อตกลง รวมถึงการระงับเนื่องจากไม่ชำระเงิน

### 5. การสนับสนุนและเป้าหมายการตอบสนอง

Wink ให้การสนับสนุนสำหรับ Partner API ในช่วงเวลาทำการปกติ ยกเว้นวันหยุดราชการท้องถิ่น Wink จะใช้ความพยายามอย่างสมเหตุสมผลในเชิงพาณิชย์เพื่อตอบรับคำขอสนับสนุนที่ส่งอย่างถูกต้องภายในเวลาตอบสนองเป้าหมายต่อไปนี้ โดยอิงตามความรุนแรงที่คุณกำหนดและ Wink ยืนยันอย่างสมเหตุสมผล:

| ความรุนแรง | คำอธิบาย | เป้าหมายการตอบสนองเริ่มต้น |
|---|---|---|
| **Sev 1 — รุนแรงมาก** | Partner API หยุดทำงานหรือใช้งานไม่ได้ในสภาพแวดล้อมการผลิตโดยไม่มีวิธีแก้ไขชั่วคราว | 4 ชั่วโมง |
| **Sev 2 — รุนแรงปานกลาง** | ฟีเจอร์สำคัญทำงานผิดปกติหรือเสื่อมสภาพ มีวิธีแก้ไขชั่วคราว | 1 วันทำการ |
| **Sev 3 — เล็กน้อย** | คำถามทั่วไป ปัญหาเล็กน้อย หรือคำขอฟีเจอร์ | 2 วันทำการ |

เวลาตอบสนองเป้าหมายระบุเวลาที่ Wink ตั้งใจจะติดต่อ **ครั้งแรก**; ไม่ใช่การรับประกันเวลาการแก้ไข การสนับสนุนลำดับความสำคัญและเป้าหมายตามความรุนแรงใช้กับระดับที่ระบุว่ารวมอยู่

### 6. ข้อมูลและความปลอดภัย

Wink รักษามาตรการบริหารจัดการ เทคนิค และองค์กรที่สมเหตุสมผลในเชิงพาณิชย์เพื่อปกป้องความลับ ความสมบูรณ์ และความพร้อมใช้งานของข้อมูลที่ประมวลผลผ่าน Partner API และทบทวนมาตรการเหล่านั้นเป็นระยะ Wink การประมวลผลข้อมูลส่วนบุคคลถูกควบคุมโดย [นโยบายความเป็นส่วนตัว](/th/privacy) และข้อกำหนดการประมวลผลข้อมูลในข้อตกลง คุณยังคงรับผิดชอบในการรักษาความปลอดภัยข้อมูลรับรอง API ของคุณ การใช้งานข้อมูลที่ถูกกฎหมาย และการแจ้ง Wink อย่างรวดเร็วหากสงสัยว่าข้อมูลรับรองถูกละเมิด

### 7. ข้อจำกัดความรับผิด

เครดิตบริการเป็น **การเยียวยาเดียวและเฉพาะ** สำหรับความไม่พร้อมใช้งานหรือความล้มเหลวในการปฏิบัติตามความมุ่งมั่นเวลาทำงาน และให้แทนความรับผิดใด ๆ ที่เกิดจากความล้มเหลวดังกล่าว นอกจากที่ระบุไว้อย่างชัดเจนใน SLA นี้ Partner API ให้บริการในสถานะ "ตามที่มี" ในขอบเขตสูงสุดที่กฎหมายใช้บังคับได้ ความรับผิดรวมของ Wink ที่เกิดขึ้นจากหรือเกี่ยวข้องกับบริการถูกจำกัดตามที่ระบุในข้อตกลง และ Wink จะไม่รับผิดชอบต่อความเสียหายทางอ้อม บังเอิญ พิเศษ ตามมา หรือการลงโทษ หรือความเสียหายจากกำไร รายได้ ข้อมูล หรือชื่อเสียงที่สูญหาย แม้จะได้รับแจ้งถึงความเป็นไปได้ของความเสียหายดังกล่าว

### 8. ระยะเวลา การเปลี่ยนแปลง และการยุติ

SLA นี้ใช้ได้ตราบเท่าที่คุณมีการสมัครสมาชิก Partner API ที่ใช้งานอยู่ในระดับที่ระบุว่าใช้ SLA Wink อาจปรับปรุง SLA นี้เป็นครั้งคราว การเปลี่ยนแปลงที่สำคัญจะสื่อสารผ่านช่องทางที่ Wink ใช้สื่อสารกับลูกค้าเป็นประจำ และการใช้งาน Partner API ต่อหลังจากการอัปเดตมีผลถือเป็นการยอมรับ SLA ที่อัปเดตแล้ว SLA นี้จะสิ้นสุดโดยอัตโนมัติเมื่อข้อตกลงหรือการสมัครสมาชิก Partner API ของคุณสิ้นสุดหรือหมดอายุ ส่วนที่โดยธรรมชาติควรคงอยู่หลังการยุติ — รวมถึงสิทธิ์เครดิตบริการที่สะสมแต่ยังไม่ได้เรียกร้อง ข้อจำกัดความรับผิด และคำจำกัดความ — จะยังคงมีผลต่อไป
