Booking Engine สามารถฝังได้ทุกที่ เลือกเฟรมเวิร์กหรือ CMS ของคุณและทำตามคำแนะนำ; Web Components พื้นฐานเหมือนกันทุกที่

## วิธีการหลัก

- [Web Components](/th/integrations/web-components/) — องค์ประกอบที่ฝังได้ซึ่งใช้ในทุกการผสานรวม
- [npm package](/th/integrations/npm/) — ติดตั้งในโปรเจกต์ JavaScript
- [Headless CMS](/th/integrations/headless/) — แสดงผลจากแบ็กเอนด์เนื้อหาใดก็ได้
- [Partner API](/th/integrations/partner-api/) — การผสานรวมแบบโปรแกรมเต็มรูปแบบ
