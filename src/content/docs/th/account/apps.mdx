แท็บ **Apps** ที่ [iam.wink.travel/my-account/apps](https://iam.wink.travel/my-account/apps) จะแสดงรายชื่อแอป OAuth2 ทุกแอปที่คุณได้ให้สิทธิ์เข้าถึงบัญชี Wink ของคุณ พร้อมวิธีการเพิกถอนสิทธินั้น

## วิธีที่แอปมาอยู่ที่นี่

เมื่อคุณคลิก `Authorize` บนเครื่องมือของบุคคลที่สามที่เชื่อมต่อกับ Wink (หรือแอปของ Wink เอง) กระบวนการยินยอมจะบันทึกการอนุญาตนั้น จากนั้นแอปนั้นจะสามารถทำงานแทนคุณภายในขอบเขตที่คุณอนุมัติไว้

## การตรวจสอบการเข้าถึง

แต่ละรายการจะแสดง:

- **ชื่อแอป** และคำอธิบายสั้น ๆ
- **ขอบเขต** ที่แอปสามารถเข้าถึงได้ แบ่งตามส่วนงาน (เช่น "Bookings: `booking.read`") —  
  ซึ่งเป็นแคตตาล็อกเดียวกับที่ใช้ในฟอร์มสร้างแอปในแท็บ [Applications](/th/account/applications#choosing-scopes)
- **การใช้งานครั้งล่าสุด** — เมื่อแอปเรียกใช้ Wink API แทนคุณครั้งล่าสุด

## การเพิกถอนแอป

คลิก `Revoke` ข้างรายการใดก็ได้ โทเค็นของแอปจะถูกยกเลิกทันที และงานเบื้องหลังที่แอปทำกับบัญชีของคุณจะเริ่มล้มเหลวด้วยข้อผิดพลาด 401

:::tip
การเพิกถอนไม่ทำให้ข้อมูลเสียหาย — คุณสามารถอนุญาตแอปนั้นใหม่ได้ทุกเมื่อโดยผ่านกระบวนการยินยอมอีกครั้ง ใช้เมื่อต้องการจัดการแอปที่ทำงานผิดพลาด, หมุนเวียนข้อมูลรับรอง หรือเมื่อคุณไม่ใช้การเชื่อมต่อนั้นอีกต่อไป
:::

## แอป OAuth ที่คุณสร้างเอง

หากคุณต้องการ *สร้าง* แอป OAuth (ไม่ใช่แค่อนุญาตแอป) นั่นเป็นฟีเจอร์สำหรับบัญชีองค์กร — ดูที่ [Settings → Applications](/th/account/applications)
