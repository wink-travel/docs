หน้าการเรียกเก็บเงินคือที่ที่คุณเปิดใช้งานระบบจ่ายตามการใช้งาน เลือกว่าบัญชีใดบ้างที่จะถูกคิดค่าบริการ และติดตามการใช้จ่ายของคุณ

คุณไม่จำเป็นต้องมาที่นี่เพื่อเริ่มต้น ทุกบัญชีจะได้รับสิทธิ์ใช้งานฟรีรายเดือนสำหรับฟีเจอร์ที่คิดค่าบริการตามการใช้งานโดยไม่ต้องทำอะไรเลย หน้านี้ใช้สำหรับการใช้งานเกินกว่าสิทธิ์ฟรีเท่านั้น ดู [Pricing](/th/getting-started/pricing) เพื่อดูว่าฟีเจอร์ใดฟรี ฟีเจอร์ใดคิดค่าบริการ และค่าใช้จ่ายเท่าไร

## การเปิดใช้งานระบบจ่ายตามการใช้งาน

เปิดระบบจ่ายตามการใช้งานและเลือกวิธีการชำระเงินที่คุณต้องการ:

- **บัตรเครดิต** — เราจะเรียกเก็บเงินจากบัตรที่บันทึกไว้โดยอัตโนมัติเมื่อออกใบแจ้งหนี้
- **ใบแจ้งหนี้** — เราจะส่งใบแจ้งหนี้ให้คุณและคุณชำระเงินเอง

คุณสามารถสลับระหว่างสองวิธีนี้ได้ตลอดเวลา

:::note
มีเพียง **เจ้าของ** บัญชีเท่านั้นที่สามารถเปิดใช้งานระบบจ่ายตามการใช้งานสำหรับบัญชีนั้นได้ การมีสิทธิ์จัดการบัญชีของผู้อื่นไม่เพียงพอ เพราะใบแจ้งหนี้จะส่งถึงเจ้าของ — เราจะไม่อนุญาตให้ใครคนอื่นเรียกเก็บเงินจากบัตรของคุณ
:::

## การเลือกบัญชีของคุณ

หากคุณเป็นเจ้าของมากกว่าหนึ่งบัญชี คุณสามารถเลือกได้ทีละบัญชีว่าจะเปิดใช้งานระบบจ่ายตามการใช้งานหรือไม่ บัญชีที่คุณปิดใช้งานจะหยุดที่สิทธิ์ใช้งานฟรีในแต่ละเดือน

การใช้งานจากทุกบัญชีที่เปิดใช้งานจะถูกรวมเป็น **ใบแจ้งหนี้เดียวต่อเดือน** ดังนั้นคุณจะได้รับบิลเพียงใบเดียวแทนที่จะเป็นใบแจ้งหนี้แยกตามแต่ละที่พัก

## วิธีการชำระเงิน

เพิ่มบัตรเครดิตและเราจะเก็บข้อมูลอย่างปลอดภัยกับผู้ให้บริการชำระเงิน เราจะแสดงเพียงยี่ห้อบัตร สี่หลักสุดท้าย และวันหมดอายุเท่านั้น — Wink จะไม่เห็นหรือเก็บหมายเลขบัตรเต็มของคุณ หากธนาคารของคุณออกบัตรทดแทน รายละเอียดจะอัปเดตโดยอัตโนมัติ

## การใช้งาน

ติดตามการใช้งานของคุณในเดือนนี้ แยกตามฟีเจอร์และบัญชี พร้อมกับสิทธิ์ใช้งานฟรีสำหรับแต่ละบัญชี นี่คือจำนวนที่ควรเฝ้าดูหากคุณต้องการควบคุมค่าใช้จ่ายให้คาดเดาได้ — โดยเฉพาะสำหรับ Social จำนวนโพสต์รายเดือนของคุณคืองบประมาณของคุณ

สิทธิ์ใช้งานฟรีจะรีเซ็ตในวันที่ 1 ของทุกเดือน

## ใบแจ้งหนี้

ประวัติใบแจ้งหนี้ของคุณจะแสดงหมายเลขเดือน ระยะเวลาการเรียกเก็บเงิน จำนวนเงิน สกุลเงิน และสถานะ พร้อมลิงก์เพื่อดูใบแจ้งหนี้ออนไลน์หรือดาวน์โหลดเป็น PDF

## สถานะการเรียกเก็บเงิน

| สถานะ | ความหมาย |
| -- | -- |
| สถานะดี | ทุกอย่างทำงานตามปกติ |
| ค้างชำระ | การชำระเงินล้มเหลวและกำลังพยายามใหม่ ฟีเจอร์ของคุณยังคงใช้งานได้ในขณะที่เราพยายามใหม่ |
| ระงับ | ใบแจ้งหนี้ไม่ได้รับการชำระจนถึงกำหนด ฟีเจอร์ที่คิดค่าบริการตามการใช้งานจะถูกบล็อกจนกว่าจะชำระ — ฟีเจอร์ฟรียังคงใช้งานได้ตามปกติ |
