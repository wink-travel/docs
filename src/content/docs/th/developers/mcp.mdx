เครื่องมือ MCP ของ Wink ถูกเผยแพร่เป็น **ชุดเครื่องมือ** — จุดเชื่อมต่อที่เน้นงานเฉพาะแต่ละงาน คุณเชื่อมต่อไคลเอนต์ AI ของคุณกับหนึ่งหรือสองชุดที่ตรงกับงานของคุณ ไม่ใช่ทั้งหมด

ทุกจุดเชื่อมต่อใช้ **การเข้าสู่ระบบ OAuth2 แบบโต้ตอบ** (PKCE authorization code flow): เอเจนต์ AI ของคุณจะเปิดแท็บเบราว์เซอร์ คุณลงชื่อเข้าใช้ด้วยบัญชี Wink ของคุณ และเท่านี้ก็เสร็จ ไม่มีความลับของไคลเอนต์ให้จัดการ

```bash title="ผู้รวมระบบจัดการช่องทางเชื่อมต่อกับจุดเชื่อมต่อหนึ่งจุด"
claude mcp add wink-channel-manager https://integrations.wink.travel/mcp/channel-manager --transport http
```

```bash title="ผู้จัดการโรงแรมที่จัดการอัตราของตนเองเชื่อมต่อกับอีกจุดเชื่อมต่อหนึ่ง"
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

## ทำไมเครื่องมือจึงถูกแยกเป็นหลายจุดเชื่อมต่อ

Wink มีเครื่องมือประมาณ 500 รายการ การส่งมอบทั้งหมดให้เอเจนต์ในครั้งเดียวเป็นไปได้ทางเทคนิค — แต่เป็นความคิดที่ไม่ดี

**คำจำกัดความของเครื่องมือใช้บริบท** เครื่องมือแต่ละรายการที่เซิร์ฟเวอร์ MCP โฆษณาจะถูกโหลดเข้าไปในหน้าต่างบริบทของโมเดลก่อนทำงาน พร้อมคำอธิบายและโครงสร้างพารามิเตอร์เต็มรูปแบบ เครื่องมือห้าร้อยรายการเหล่านี้ใช้ส่วนใหญ่ของงบประมาณที่งานจริงของคุณต้องการ ในทุกคำขอ

**คุณภาพการเลือกลดลงเมื่อรายการยาวขึ้น** เอเจนต์ที่เลือกจากเครื่องมือ 500 รายการที่มีชื่อคล้ายกันจะเลือกได้แย่กว่าเอเจนต์ที่เลือกจาก 40 รายการ หากคุณรวมระบบจัดการช่องทาง ประมาณยี่สิบเครื่องมือจะเกี่ยวข้องกับคุณ ส่วนที่เหลือ 480 เป็นเสียงรบกวนที่ทำให้เครื่องมือที่ถูกต้องหายากขึ้น

**งานแยกจากกันได้จริง** คนที่ซิงค์ความพร้อมใช้งานจาก PMS กับคนที่ดูแลหน้าแอฟฟิลิเอตแทบจะไม่มีเครื่องมือร่วมกัน การแยกตามงานหมายความว่าการเชื่อมต่อแต่ละรายการมีคำศัพท์ของงานหนึ่งงาน

<Aside type="caution" title="ชุดเครื่องมือไม่ใช่สิทธิ์">
การเลือกชุดเครื่องมือแคบ **ไม่ได้** จำกัดสิ่งที่บัญชีของคุณทำได้ และการเลือกชุดกว้างไม่ได้ให้สิทธิ์เพิ่มเติม เครื่องมือทุกตัวบังคับใช้สิทธิ์บัญชีเดียวกับพอร์ทัลเว็บ ภายใต้ตัวตนที่คุณลงชื่อเข้าใช้ หากบัญชีของคุณไม่สามารถยกเลิกการจองใน Wink Portal ได้ เอเจนต์ก็ไม่สามารถทำได้เช่นกัน — ไม่ว่าจุดเชื่อมต่อที่เชื่อมต่อจะเป็นอะไร

เลือกชุดเครื่องมือเพื่อ **ความเน้น** ไม่ใช่เพื่อความปลอดภัย
</Aside>

### `https://integrations.wink.travel` — การรวมระบบจัดการช่องทาง

มีจุดเชื่อมต่อเดียว เพราะโฮสต์นี้มีไว้สำหรับงานเดียว

| จุดเชื่อมต่อ | จำนวนเครื่องมือ | ครอบคลุมอะไร |
|---|---:|---|
| `/mcp/channel-manager` | ~9 | การเชื่อมต่อและยืนยันระบบจัดการช่องทาง, PMS หรือการรวม CRS |

<Aside type="note" title="การรวมระบบจัดการช่องทาง vs. การจัดการอัตราของคุณเอง">
นี่คืองานที่แตกต่างกันสำหรับคนที่แตกต่างกัน และไม่มีการแชร์จุดเชื่อมต่อกัน

**ผู้ขายระบบจัดการช่องทาง, PMS หรือ CRS** รวมระบบครั้งเดียวผ่าน `integrations.wink.travel/mcp/channel-manager` และจากนั้นแลกเปลี่ยนข้อมูลทรัพย์สิน, อัตรา, ความพร้อมใช้งาน และการจองผ่านการรวมระบบนั้น จุดเชื่อมต่อเดียวนี้คือพื้นผิวทั้งหมด

**ผู้จัดการโรงแรมที่เปลี่ยนอัตราของตนเองด้วยมือ** ใช้ชุดเครื่องมือ extranet บน `api.wink.travel` — `/mcp/extranet/rates` และชุดที่เกี่ยวข้อง ชุดเหล่านี้ไม่ใช่ส่วนหนึ่งของการรวมระบบจัดการช่องทาง และผู้รวมระบบไม่มีเหตุผลที่จะเชื่อมต่อกับชุดเหล่านี้

การบริหารบัญชียังอยู่บน `api.wink.travel` ที่ `/mcp/settings` ไม่มี `/mcp/settings` บนโฮสต์ integrations
</Aside>

ทุกจุดเชื่อมต่อยังมีเครื่องมือ `ping` เพื่อให้คุณยืนยันได้ว่าการเชื่อมต่อยังใช้งานได้ก่อนขอให้ทำงานจริง

## วิธีการทำงานของการตรวจสอบสิทธิ์

เซิร์ฟเวอร์ MCP ของ Wink ใช้ **OAuth2 Authorization Code + PKCE** และรองรับ **Dynamic Client Registration (RFC 7591)** นี่คือสิ่งที่จะเกิดขึ้นเมื่อคุณเชื่อมต่อครั้งแรก:

1. ไคลเอนต์ AI ของคุณค้นหาเซิร์ฟเวอร์อนุญาตจากเมตาดาต้า `/.well-known/oauth-protected-resource` ของจุดเชื่อมต่อ MCP
2. ไคลเอนต์ลงทะเบียนตัวเองผ่าน **Dynamic Client Registration** — ไม่ต้องตั้งค่าแอปพลิเคชันด้วยตนเอง
3. ไคลเอนต์เปิด **แท็บเบราว์เซอร์** ไปที่ `https://iam.wink.travel` คุณลงชื่อเข้าใช้ด้วยบัญชี Wink และอนุมัติสิทธิ์ที่ร้องขอบนหน้าจออนุญาต
4. Wink ออก **โทเค็นเข้าถึง** ที่มีขอบเขตกับบัญชีของคุณและเชื่อมโยงกับตัวตนของคุณ
5. ไคลเอนต์ AI แนบโทเค็นกับทุกคำขอ MCP ผลลัพธ์เครื่องมือทั้งหมดจะถูกจำกัดขอบเขตตามหน่วยงานผู้จัดการของคุณโดยอัตโนมัติ
6. โทเค็นหมดอายุหลัง 3 ชั่วโมง ไคลเอนต์ AI ของคุณจะรีเฟรชโทเค็นเงียบๆ ในเบื้องหลังโดยไม่ต้องขออนุมัติอีกครั้ง

การเรียกใช้เครื่องมือทุกครั้งทำงาน **ภายใต้ตัวตนของคุณ** — กฎ ACL เดียวกับที่ปกป้องพอร์ทัลเว็บจะใช้กับเอเจนต์ AI

## เชื่อมต่อไคลเอนต์ AI ของคุณ

  <TabItem label="Claude Code">

<Steps>
1. ตรวจสอบให้แน่ใจว่า Claude Code เป็นเวอร์ชันล่าสุด:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. เลือกชุดเครื่องมือจาก [ไดเรกทอรีด้านบน](#endpoint-directory) และเพิ่มเข้าไป เช่น ราคาและความพร้อมใช้งาน:
   ```bash
   claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
   ```

## ขอบเขตสิทธิ์

เมื่อคุณอนุมัติหน้าจออนุญาต คุณจะเห็นรายละเอียดสิ่งที่เอเจนต์ร้องขอ MCP
ไคลเอนต์ใช้คำศัพท์สิทธิ์เดียวกับแพลตฟอร์มทั้งหมด — ดู
[เอกสารอ้างอิงขอบเขตสิทธิ์ในหน้าการตรวจสอบสิทธิ์](/th/developers/authentication#scopes)

สองสิ่งที่เฉพาะเจาะจงสำหรับ MCP:

- **ขอบเขต `mcp.read` `mcp.write` `mcp.remove` จำเป็นเพิ่มเติม** เพื่อเปิดการขนส่ง MCP ไคลเอนต์ที่มีขอบเขต `mcp.*` จะได้รับอนุญาตเข้าถึงจุดเชื่อมต่อ MCP ใดก็ได้ของ Wink แต่เครื่องมือที่เรียกใช้จะยังคงบังคับใช้ขอบเขตของส่วนที่จุดเชื่อมต่อห่อหุ้ม (เช่น `booking.read`)
- **ไคลเอนต์ AI ขอเฉพาะขอบเขตที่ต้องการเท่านั้น** คุณสามารถปฏิเสธสิทธิ์แต่ละรายการบนหน้าจออนุญาต — เครื่องมือที่ต้องการขอบเขตที่ถูกปฏิเสธจะส่งคืนข้อผิดพลาดเมื่อเรียกใช้

**ชุดเครื่องมือไม่เปลี่ยนแปลงสิ่งนี้** จุดเชื่อมต่อที่คุณเชื่อมต่อกำหนดว่าเครื่องมือใด *แสดง* ไม่ใช่สิ่งที่อนุญาตให้ทำ เชื่อมต่อกับ `/mcp/payment` ไม่ได้ให้สิทธิ์ทางการเงินที่คุณไม่มี และเชื่อมต่อกับ `/mcp/reference` ก็ไม่หยุดเครื่องมือที่นั่นจากการบังคับใช้ขอบเขตของตัวเอง การอนุญาตตัดสินใจตามการเรียกใช้เครื่องมือแต่ละครั้ง จากโทเค็นของคุณและสิทธิ์บัญชีของคุณ

## การแก้ไขปัญหา

**แท็บเบราว์เซอร์ไม่เปิด**

ไคลเอนต์ AI ของคุณอาจยังไม่รองรับการไหล PKCE แบบโต้ตอบ ตรวจสอบให้แน่ใจว่าคุณใช้เวอร์ชันล่าสุด:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** อัปเดตจากตัวอัปเดตในแอป

**`401 Unauthorized` หลังจากลงชื่อเข้าใช้**

โทเค็นที่แคชอาจหมดอายุ ลบและเพิ่มเซิร์ฟเวอร์ใหม่เพื่อเริ่มการลงชื่อเข้าใช้ใหม่:

```bash
# Claude Code
claude mcp remove wink-rates
claude mcp add wink-rates https://api.wink.travel/mcp/extranet/rates --transport http
```

สำหรับ Claude Desktop และ ChatGPT ให้ลบรายการเซิร์ฟเวอร์จากการตั้งค่า รีสตาร์ทแอป แล้วเพิ่มใหม่

**`403 Forbidden` เมื่อเรียกใช้เครื่องมือเฉพาะ**

เครื่องมือต้องการขอบเขตที่คุณไม่อนุมัติบนหน้าจออนุญาต หรือสิทธิ์ที่บัญชีของคุณไม่มี เชื่อมต่อเซิร์ฟเวอร์ใหม่ — หน้าจออนุญาตจะปรากฏอีกครั้งและคุณสามารถอนุมัติสิทธิ์ที่ขาดได้ หากยังล้มเหลว เครื่องมือต้องการสิทธิ์บัญชีที่คุณไม่มี; การเชื่อมต่อกับชุดเครื่องมืออื่นจะไม่ช่วย เพราะชุดเครื่องมือไม่ให้สิทธิ์

**เครื่องมือที่ต้องการไม่อยู่ในรายการ**

คุณอาจเชื่อมต่อกับชุดเครื่องมือที่ไม่ครอบคลุมงานนั้น ตรวจสอบ [ไดเรกทอรีจุดเชื่อมต่อ](#endpoint-directory) และเพิ่มชุดเครื่องมือที่ครอบคลุม — การเชื่อมต่อแต่ละรายการเป็นอิสระ การเพิ่มชุดหนึ่งไม่เปลี่ยนแปลงชุดอื่น หากไม่แน่ใจว่าเครื่องมืออยู่ในชุดใด เชื่อมต่อกับ `https://api.wink.travel/mcp` ชั่วคราว ค้นหาเครื่องมือ แล้วดูว่าชุดเครื่องมือใดมีเครื่องมือนั้น

**`404 Not Found` บนจุดเชื่อมต่อชุดเครื่องมือ**

ตรวจสอบเส้นทางอย่างละเอียด — ชุดเครื่องมือที่ซ้อนมีสองส่วน (`/mcp/extranet/rates` ไม่ใช่ `/mcp/extranet-rates`) และชุดเครื่องมือแบบแบนมีหนึ่งส่วน (`/mcp/link-manager`) โปรดทราบว่าคำขอที่ *ไม่ได้รับการตรวจสอบสิทธิ์* ไปยังเส้นทางใดๆ ภายใต้ `/mcp` จะส่งคืน `401` ไม่ใช่ `404` ดังนั้น `401` เพียงอย่างเดียวไม่บอกว่าจุดเชื่อมต่อมีอยู่หรือไม่

**ฉันเชื่อมต่อกับ `api.wink.travel/mcp/channel-manager` แล้วไม่ได้อะไร**

จุดเชื่อมต่อนั้นไม่มีอยู่จริง การรวมระบบจัดการช่องทางให้บริการจาก `https://integrations.wink.travel/mcp/channel-manager` เท่านั้น หากคุณต้องการอ่านหรือเขียนอัตราของทรัพย์สินด้วยมือ นั่นเป็นงานแยกบนจุดเชื่อมต่อแยกต่างหาก — ดู `/mcp/extranet/rates`

**เซิร์ฟเวอร์ปรากฏแต่การเรียกเครื่องมือส่งคืน "account not found"**

คุณลงชื่อเข้าใช้บัญชี Wink ที่ไม่มีหน่วยงานผู้จัดการ ไปที่ [Wink Portal](https://app.wink.travel) และตรวจสอบให้แน่ใจว่าบัญชีของคุณถูกตั้งค่าก่อนใช้เซิร์ฟเวอร์ MCP

**โทเค็นหมดอายุระหว่างเซสชัน**

โทเค็นมีอายุ 3 ชั่วโมง Claude Code และ Claude Desktop รีเฟรชโทเค็นเงียบๆ โดยไม่ขัดจังหวะเซสชัน หากคุณเห็นข้อผิดพลาดการตรวจสอบสิทธิ์หลังช่วงเวลาว่างนาน พิมพ์ข้อความใหม่ — ไคลเอนต์จะตรวจสอบสิทธิ์ใหม่โดยอัตโนมัติ

**Codex CLI แสดง "MCP server unreachable"**

ตรวจสอบว่าไฟล์ `~/.codex/config.json` เป็น JSON ที่ถูกต้อง (ไม่มีลูกน้ำท้าย) และ `"type": "http"` ถูกตั้งค่า Codex ต้องการการขนส่ง HTTP สำหรับเซิร์ฟเวอร์ระยะไกล; การขนส่ง stdio สำหรับไบนารีในเครื่องเท่านั้น

**เมนู "Connectors" ของ ChatGPT หายไป**

การรองรับ MCP ต้องใช้แอป ChatGPT บนเดสก์ท็อปเวอร์ชัน **1.2024.352** ขึ้นไป และสมัครสมาชิก Plus, Pro, Team หรือ Enterprise อัปเดตแอปและตรวจสอบแผนใน Settings → Account

**เซิร์ฟเวอร์ Cursor แสดงสีแดง / "Failed to connect"**

ตรวจสอบว่าไฟล์ `~/.cursor/mcp.json` เป็น JSON ที่ถูกต้องและมี `"type": "http"` จากนั้นไปที่ **Settings → Cursor Settings → MCP** และคลิก **Refresh** หากยังมีข้อผิดพลาด รีสตาร์ท Cursor อย่างสมบูรณ์ — การเปลี่ยนแปลงคอนฟิกบางครั้งไม่ถูกนำมาใช้หากไม่รีสตาร์ท

**เซิร์ฟเวอร์ MCP ของ Windsurf ไม่แสดงในการตั้งค่า**

Windsurf ต้องรีสตาร์ทเต็มรูปแบบ (ไม่ใช่แค่โหลดหน้าต่างใหม่) เพื่อรับการเปลี่ยนแปลงใน `mcp_config.json` ใช้ **File → Quit** แล้วเปิดใหม่ หากเซิร์ฟเวอร์ยังไม่แสดง ให้ตรวจสอบว่าใช้ Windsurf **1.4+** ผ่าน **Help → About Windsurf**

**ตัวเลือก "Add Server" ของ Cline ไม่ปรากฏ**

ตัวจัดการเซิร์ฟเวอร์ MCP ต้องใช้ Cline **2.0** ขึ้นไป เปิดแผงส่วนขยาย VS Code ค้นหา Cline และคลิก **Update** หากมีอัปเดต หลังอัปเดต โหลด VS Code ใหม่ (`Ctrl+Shift+P` → "Developer: Reload Window")
