Wink มีเซิร์ฟเวอร์ MCP ที่ผ่านการรับรองตัวตนสองตัว ทั้งสองใช้ **การเข้าสู่ระบบ OAuth2 แบบโต้ตอบ** (PKCE authorization code flow) — เอเจนต์ AI ของคุณจะเปิดแท็บเบราว์เซอร์เพื่อให้คุณลงชื่อเข้าใช้ด้วยบัญชี Wink ของคุณ ไม่มีความลับของไคลเอนต์ให้จัดการ

| เซิร์ฟเวอร์ | URL | ฟังก์ชัน |
|--------|-----|--------------|
| **Inventory API** | `https://api.wink.travel/mcp` | สินค้าคงคลัง, การจอง, อัตรา, ช่องทางการขาย, การวิเคราะห์ และการดำเนินการทั้งหมดบนแพลตฟอร์ม |
| **Integrations** | `https://integrations.wink.travel/mcp` | การผสานรวมผู้จัดการช่องทาง — ซิงค์ที่พัก, อัตรา และความพร้อมใช้งานกับ OTA |

---

## วิธีการทำงานของการรับรองตัวตน

เซิร์ฟเวอร์ MCP ของ Wink ใช้โฟลว์ **OAuth2 Authorization Code + PKCE** และรองรับ **Dynamic Client Registration (RFC 7591)** นี่คือสิ่งที่จะเกิดขึ้นเมื่อคุณเชื่อมต่อครั้งแรก:

1. ไคลเอนต์ AI ของคุณค้นหาเซิร์ฟเวอร์การอนุญาตจากเมตาดาต้า `/.well-known/oauth-protected-resource` ของจุดสิ้นสุด MCP
2. ไคลเอนต์ลงทะเบียนตัวเองผ่าน **Dynamic Client Registration** — ไม่ต้องตั้งค่าแอปพลิเคชันด้วยตนเอง
3. ไคลเอนต์เปิด **แท็บเบราว์เซอร์** ไปที่ `https://iam.wink.travel` คุณลงชื่อเข้าใช้ด้วยบัญชี Wink และอนุมัติสิทธิ์ที่ร้องขอบนหน้าจอการยินยอม
4. Wink ออก **access token** ที่มีขอบเขตสำหรับบัญชีของคุณและเชื่อมโยงกับตัวตนของคุณ
5. ไคลเอนต์ AI แนบโทเค็นกับทุกคำขอ MCP ผลลัพธ์ของเครื่องมือทั้งหมดจะถูกจำกัดขอบเขตตามหน่วยงานที่คุณจัดการโดยอัตโนมัติ
6. โทเค็นหมดอายุหลัง 3 ชั่วโมง ไคลเอนต์ AI ของคุณจะรีเฟรชโทเค็นอย่างเงียบๆ ในเบื้องหลังโดยไม่ต้องแจ้งเตือนอีกครั้ง

ทุกคำขอเครื่องมือทำงาน **ภายใต้ตัวตนของคุณ** — กฎ ACL เดียวกับที่ปกป้องเว็บพอร์ทัลจะใช้กับเอเจนต์ AI ด้วย

## เชื่อมต่อไคลเอนต์ AI ของคุณ

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. ตรวจสอบให้แน่ใจว่า Claude Code เป็นเวอร์ชันล่าสุด:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. เพิ่มเซิร์ฟเวอร์ Wink Inventory MCP:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. Claude Code ติดต่อเซิร์ฟเวอร์ ค้นหาเซิร์ฟเวอร์การอนุญาต และเปิดเบราว์เซอร์เริ่มต้นของคุณ

4. **ลงชื่อเข้าใช้ Wink** และอนุมัติคำขอสิทธิ์บนหน้าจอการยินยอม

5. Claude Code ยืนยันการเชื่อมต่อ พิมพ์ `/mcp` เพื่อตรวจสอบว่าเซิร์ฟเวอร์ปรากฏและเครื่องมือโหลดเรียบร้อยแล้ว
</Steps>

หากต้องการเพิ่มเซิร์ฟเวอร์ Integrations ด้วย:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[แชร์กับทีมของคุณ]
เพิ่ม `--scope project` ในคำสั่ง `claude mcp add` แล้ว Claude Code จะเขียน URL เซิร์ฟเวอร์ลงใน `.mcp.json` ที่โฟลเดอร์รากของรีโป ให้คอมมิตไฟล์นั้น — สมาชิกทีมแต่ละคนจะทำการลงชื่อเข้าใช้ผ่านเบราว์เซอร์ครั้งแรกที่เชื่อมต่อ
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. แก้ไขไฟล์ config ของ Claude Desktop:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. เพิ่มรายการเซิร์ฟเวอร์ MCP:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **ออกจากโปรแกรม Claude Desktop ให้หมดและเปิดใหม่** (ใช้ Quit จากเมนูบาร์ — ปิดหน้าต่างอย่างเดียวไม่พอ)

4. Claude Desktop จะเปิดแท็บเบราว์เซอร์สำหรับแต่ละเซิร์ฟเวอร์ใหม่ ลงชื่อเข้าใช้ Wink และอนุมัติสิทธิ์

5. ไอคอนปลั๊กที่แถบเครื่องมือด้านล่างจะแสดงสถานะเชื่อมต่อของทั้งสองเซิร์ฟเวอร์
</Steps>

  <TabItem label="ChatGPT">

การรองรับเซิร์ฟเวอร์ MCP มีใน **แอป ChatGPT บนเดสก์ท็อป** สำหรับผู้สมัครสมาชิก Plus, Pro, Team และ Enterprise

<Steps>
1. ดาวน์โหลดและติดตั้ง [แอป ChatGPT บนเดสก์ท็อป](https://openai.com/chatgpt/download/) หากยังไม่ได้ติดตั้ง

2. เปิดแอปและคลิก **ไอคอนโปรไฟล์ของคุณ** ที่มุมขวาบน จากนั้นเลือก **Settings**

3. ไปที่ **Connectors** (หรือ **MCP Servers** ขึ้นกับเวอร์ชันแอปของคุณ) แล้วคลิก **Add**

4. ใส่ URL เซิร์ฟเวอร์ Wink Inventory:
   ```
   https://api.wink.travel/mcp
   ```
   แล้วคลิก **Connect**

5. ChatGPT จะเปิดแท็บเบราว์เซอร์ไปที่ `https://iam.wink.travel` **ลงชื่อเข้าใช้ Wink** และอนุมัติสิทธิ์

6. ทำซ้ำขั้นตอนที่ 4–5 สำหรับเซิร์ฟเวอร์ Integrations:
   ```
   https://integrations.wink.travel/mcp
   ```

7. ทั้งสองเซิร์ฟเวอร์จะปรากฏในรายการ Connectors ของคุณ เริ่มแชทใหม่ — เครื่องมือ Wink จะพร้อมใช้งานโดยอัตโนมัติ
</Steps>

:::note[ข้อจำกัดของเว็บแอป]
เซิร์ฟเวอร์ MCP สามารถตั้งค่าได้เฉพาะใน **แอปเดสก์ท็อป** เท่านั้น ส่วนอินเทอร์เฟซเว็บของ ChatGPT ที่ chatgpt.com ไม่รองรับเซิร์ฟเวอร์ MCP แบบกำหนดเอง
:::

## การอ้างอิงขอบเขต (Scope)

เมื่อคุณอนุมัติหน้าจอการยินยอม คุณจะเห็นรายละเอียดของสิ่งที่เอเจนต์ร้องขอ Wink จัดกลุ่มสิทธิ์ตามพื้นที่การทำงาน:

| กลุ่มขอบเขต | ขอบเขต | สิ่งที่ปลดล็อก |
|-------------|--------|-----------------|
| **MCP transport** | `mcp.read` `mcp.write` `mcp.remove` | จำเป็นสำหรับการเชื่อมต่อกับเซิร์ฟเวอร์ MCP ใดๆ |
| **Account** | `account.read` `account.write` `account.remove` | หน่วยงานที่จัดการ, สมาชิกทีม, การตั้งค่า, แอปพลิเคชัน |
| **Booking** | `booking.read` `booking.write` `booking.remove` | ค้นหา, ดู, สร้าง, ยกเลิก และคืนเงินการจอง |
| **Inventory** | `inventory.read` `inventory.write` `inventory.remove` | ที่พัก, ห้องพัก, อัตรา, สิ่งอำนวยความสะดวก, ความพร้อมใช้งาน |
| **Analytics** | `analytics.read` | การวิเคราะห์การจอง, รายงานรายได้, กระดานผู้นำ |
| **Marketing** | `marketing.read` `marketing.write` `marketing.remove` | โพสต์โซเชียล, แคมเปญ, ช่องทางการขาย, โปรโมชั่น |
| **Content** | `content.read` `content.write` `content.remove` | สื่อมัลติมีเดีย, URL ย่อ, รายการที่สามารถเผยแพร่ซ้ำ, แผนที่ |
| **Payment** | `payment.read` `payment.write` | สมุดบัญชี, การจ่ายเงิน, รายละเอียดทางการเงิน, การถอนเงิน |

ไคลเอนต์ AI จะร้องขอเฉพาะขอบเขตที่ต้องการเท่านั้น คุณสามารถปฏิเสธสิทธิ์แต่ละรายการบนหน้าจอการยินยอม — เครื่องมือที่ต้องการขอบเขตที่ถูกปฏิเสธจะส่งคืนข้อผิดพลาดเมื่อเรียกใช้งาน

## การแก้ไขปัญหา

**แท็บเบราว์เซอร์ไม่เปิด**

ไคลเอนต์ AI ของคุณอาจยังไม่รองรับโฟลว์ PKCE แบบโต้ตอบ ตรวจสอบให้แน่ใจว่าคุณใช้เวอร์ชันล่าสุด:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT desktop:** อัปเดตจากตัวอัปเดตในแอป

**`401 Unauthorized` หลังจากลงชื่อเข้าใช้**

โทเค็นที่แคชไว้อาจหมดอายุ ลบและเพิ่มเซิร์ฟเวอร์ใหม่เพื่อเริ่มการลงชื่อเข้าใช้ใหม่:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

สำหรับ Claude Desktop และ ChatGPT ให้ลบรายการเซิร์ฟเวอร์จากการตั้งค่า รีสตาร์ทแอป แล้วเพิ่มใหม่อีกครั้ง

**`403 Forbidden` เมื่อเรียกใช้เครื่องมือเฉพาะ**

เครื่องมือต้องการขอบเขตที่คุณไม่ได้อนุมัติบนหน้าจอการยินยอม เชื่อมต่อเซิร์ฟเวอร์ใหม่ — หน้าจอการยินยอมจะปรากฏอีกครั้งและคุณสามารถอนุมัติสิทธิ์ที่ขาดหายไป

**เซิร์ฟเวอร์ปรากฏแต่การเรียกเครื่องมือส่งคืน "account not found"**

คุณลงชื่อเข้าใช้บัญชี Wink ที่ไม่มีหน่วยงานที่จัดการ ไปที่ [Wink Portal](https://app.wink.travel) และตรวจสอบให้แน่ใจว่าบัญชีของคุณตั้งค่าเรียบร้อยก่อนใช้เซิร์ฟเวอร์ MCP

**โทเค็นหมดอายุระหว่างเซสชัน**

โทเค็นมีอายุ 3 ชั่วโมง Claude Code และ Claude Desktop จะรีเฟรชโทเค็นอย่างเงียบๆ โดยไม่รบกวนเซสชัน หากคุณเห็นข้อผิดพลาดการรับรองตัวตนหลังจากไม่ได้ใช้งานนาน ให้พิมพ์ข้อความใหม่ — ไคลเอนต์จะทำการรับรองตัวตนอัตโนมัติ

**Codex CLI แสดง "MCP server unreachable"**

ตรวจสอบว่าไฟล์ `~/.codex/config.json` เป็น JSON ที่ถูกต้อง (ไม่มีเครื่องหมายจุลภาคท้าย) และ `"type": "http"` ถูกตั้งค่า Codex ต้องการการขนส่ง HTTP สำหรับเซิร์ฟเวอร์ระยะไกล; การขนส่ง stdio ใช้สำหรับไบนารีในเครื่องเท่านั้น

**เมนู "Connectors" ของ ChatGPT หายไป**

การรองรับ MCP ต้องใช้แอป ChatGPT บนเดสก์ท็อปเวอร์ชัน **1.2024.352** ขึ้นไป และต้องสมัครสมาชิก Plus, Pro, Team หรือ Enterprise อัปเดตแอปและตรวจสอบแผนของคุณใน Settings → Account

**เซิร์ฟเวอร์ Cursor แสดงสีแดง / "Failed to connect"**

ตรวจสอบว่าไฟล์ `~/.cursor/mcp.json` เป็น JSON ที่ถูกต้องและมี `"type": "http"` จากนั้นไปที่ **Settings → Cursor Settings → MCP** และคลิก **Refresh** หากยังมีข้อผิดพลาด ให้รีสตาร์ท Cursor ใหม่ — การเปลี่ยนแปลง config บางครั้งต้องรีสตาร์ทเพื่อให้ระบบรับรู้

**เซิร์ฟเวอร์ MCP ของ Windsurf ไม่แสดงในการตั้งค่า**

Windsurf ต้องรีสตาร์ทเต็มรูปแบบ (ไม่ใช่แค่โหลดหน้าต่างใหม่) เพื่อรับการเปลี่ยนแปลงใน `mcp_config.json` ใช้ **File → Quit** แล้วเปิดใหม่ หากเซิร์ฟเวอร์ยังไม่แสดง ให้ตรวจสอบว่าใช้ Windsurf **1.4+** ผ่าน **Help → About Windsurf**

**ตัวเลือก "Add Server" ของ Cline ไม่แสดง**

ตัวจัดการเซิร์ฟเวอร์ MCP ต้องใช้ Cline **2.0** ขึ้นไป เปิดแผงส่วนขยาย VS Code ค้นหา Cline และคลิก **Update** หากมีอัปเดต หลังอัปเดตให้โหลด VS Code ใหม่ (`Ctrl+Shift+P` → "Developer: Reload Window")
