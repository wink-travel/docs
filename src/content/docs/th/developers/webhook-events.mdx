หน้านี้แสดงรายการเหตุการณ์ webhook ทั้งหมดที่คุณสามารถสมัครรับบน Wink สำหรับคำแนะนำการตั้งค่า ดูที่ [Webhook Integration Guide](/th/guides/developers/webhook-integration) หรือ [หน้า Webhooks management](/th/portal/settings/webhooks)

## วิธีการสมัครรับ

1. ไปที่ **Applications > Webhooks** ในพอร์ทัลของคุณ
2. สร้าง webhook และเลือกเหตุการณ์ที่คุณต้องการรับ
3. Wink จะส่ง HTTP POST ไปยัง endpoint ของคุณทุกครั้งที่เกิดเหตุการณ์นั้น

สำหรับขั้นตอนการตั้งค่าเต็มรูปแบบและแนวทางปฏิบัติที่ดีที่สุด ดูที่ [Webhook Integration](/th/guides/developers/webhook-integration)

## การจัดการเหตุการณ์ของเอนทิตี

เหตุการณ์สำหรับการจัดการเอนทิตี (ทรัพย์สิน, บริษัทในเครือ, บริษัท) และการบริหารจัดการของพวกเขา

### วงจรชีวิต

| เหตุการณ์ | คีย์ | คำอธิบาย |
|---|---|---|
| สร้างเอนทิตี | `managing_entity.created` | มีการสร้างเอนทิตีใหม่ |
| ลบเอนทิตี | `managing_entity.deleted` | มีการลบเอนทิตี |
| อัปเดตสถานะ | `managing_entity.status.updated` | สถานะของเอนทิตีเปลี่ยนแปลง |
| อยู่ระหว่างตรวจสอบ | `account.under_review` | บัญชีเอนทิตีกำลังรอตรวจสอบ |

### การสมัครรับ

| เหตุการณ์ | คีย์ | คำอธิบาย |
|---|---|---|
| การสมัครรับถูกจัดเตรียม | `managing_entity.subscription.provisioned` | มีการจัดเตรียมการสมัครรับใหม่ |
| การสมัครรับเปลี่ยนแปลง | `managing_entity.subscription.changed` | แผนการสมัครรับถูกเปลี่ยนแปลง |
| ใบแจ้งหนี้การสมัครรับเปลี่ยนแปลง | `managing_entity.subscription.invoice.changed` | ใบแจ้งหนี้การสมัครรับได้รับการอัปเดต |

### วงจรชีวิตของผู้จัดการ

| เหตุการณ์ | คีย์ | คำอธิบาย |
|---|---|---|
| เพิ่มผู้จัดการ | `managing_entity.manager.added` | มีการเพิ่มผู้จัดการใหม่ |

| ลบผู้จัดการ | `managing_entity.manager.removed` | มีการลบผู้จัดการ |
| ผู้จัดการยอมรับ | `managing_entity.manager.accepted` | คำเชิญผู้จัดการได้รับการยอมรับ |

| ตั้งเจ้าของ | `managing_entity.manager.owner.set` | การโอนกรรมสิทธิ์เอนทิตีเสร็จสมบูรณ์ |

## เหตุการณ์การจอง

เหตุการณ์สำหรับวงจรชีวิตการจองบน Wink ตั้งแต่การสร้างจนถึงการคืนเงินและการจ่ายเงิน

### การจองหลัก

| เหตุการณ์ | คีย์ | คำอธิบาย |
|---|---|---|
| สร้างการจอง | `booking.create` | มีการสร้างการจองใหม่ |
| ยกเลิกการจอง | `booking.cancelled` | การจองถูกยกเลิก |
| การจองล้มเหลว | `booking.failed` | ความพยายามจองล้มเหลว |
| กำลังดำเนินการจอง | `booking.processing` | กำลังดำเนินการชำระเงินการจอง |
| ขอเริ่มต้นการจอง | `booking.initialize.request` | มีการร้องขอเริ่มต้นการจอง |
| เริ่มต้นการจองเสร็จสมบูรณ์ | `booking.initialize.complete` | การเริ่มต้นการจองเสร็จสมบูรณ์ |

### การคืนเงิน

| เหตุการณ์ | คีย์ | คำอธิบาย |
|---|---|---|
| ขอคืนเงิน | `booking.refund.request` | มีการส่งคำขอคืนเงิน |
| ข้อผิดพลาดคืนเงิน | `booking.refund.error` | เกิดข้อผิดพลาดขณะดำเนินการคืนเงิน |
| คืนเงินบางส่วน | `booking.refund.partial` | มีการคืนเงินบางส่วน |
| คืนเงินเต็มจำนวน | `booking.refund.full` | มีการคืนเงินเต็มจำนวน |

### การจ่ายเงิน

| เหตุการณ์ | คีย์ | คำอธิบาย |
|---|---|---|
| สร้างการจ่ายเงิน | `booking.payout.create` | มีการสร้างการจ่ายเงินสำหรับการจอง |
| การจ่ายเงินเสร็จสมบูรณ์ | `booking.payout.complete` | การจ่ายเงินเสร็จสมบูรณ์ |
| เงินพร้อมใช้ | `booking.funds.available` | เงินจากการจองพร้อมสำหรับการชำระบัญชี |
| เงินถูกบันทึกในบัญชีแยกประเภท | `booking.funds.ledgered` | เงินจากการจองถูกบันทึกในบัญชีแยกประเภท |

### รีวิว

| เหตุการณ์ | คีย์ | คำอธิบาย |
|---|---|---|
| ส่งรีวิว | `booking.review.created` | แขกได้ส่งรีวิวสำหรับการจอง |
| ตอบรีวิว | `booking.review.responded` | ทรัพย์สินได้ตอบรีวิวการจอง |

## เหตุการณ์ทรัพย์สิน

เหตุการณ์สำหรับโปรไฟล์และเนื้อหาของทรัพย์สิน ส่งไปยังผู้สมัครรับ webhook ของทรัพย์สินนั้น

| เหตุการณ์ | คีย์ | คำอธิบาย |
|---|---|---|
| สร้างทรัพย์สิน | `property.created` | มีการสร้างทรัพย์สินใหม่ |
| อัปเดตทรัพย์สิน | `property.updated` | รายละเอียดทรัพย์สินได้รับการอัปเดต |
| ลบทรัพย์สิน | `property.deleted` | มีการลบทรัพย์สิน |
| ลงทะเบียนทรัพย์สิน | `property.registered` | ทรัพย์สินได้ลงทะเบียนเสร็จสมบูรณ์ |
| อัปเดตสถานะ | `property.status.updated` | สถานะภายนอกของทรัพย์สินเปลี่ยนแปลง |
| อัปเดตชื่อ | `property.name.updated` | ชื่อทรัพย์สินเปลี่ยนแปลง |
| อัปเดตที่อยู่ | `property.address.updated` | ที่อยู่ของทรัพย์สินได้รับการอัปเดต |
| อัปเดตตำแหน่งทางภูมิศาสตร์ | `property.geolocation.updated` | ตำแหน่งทางภูมิศาสตร์ของทรัพย์สินได้รับการอัปเดต |
| อัปเดตโปรไฟล์ | `property.profile.updated` | เนื้อหาโปรไฟล์ของทรัพย์สินเปลี่ยนแปลง |
| อัปเดตบริการ | `property.services.updated` | รายการบริการ/สิ่งอำนวยความสะดวกของทรัพย์สินเปลี่ยนแปลง |
| อัปเดตข้อความต้อนรับ | `property.welcome_text.updated` | ข้อความต้อนรับของทรัพย์สินเปลี่ยนแปลง |
| สร้างนโยบาย | `property.policy.created` | มีการสร้างนโยบายทรัพย์สินใหม่ |
| อัปเดตนโยบาย | `property.policy.updated` | นโยบายทรัพย์สินได้รับการอัปเดต |
