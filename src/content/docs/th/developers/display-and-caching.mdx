ข้อตกลงพันธมิตรความต้องการไม่อนุญาตให้เปรียบเทียบราคากับซัพพลายของ Wink "นอกเหนือจากที่ได้รับอนุญาตอย่างชัดเจน" (ข้อ 11.3) หน้านี้อธิบายว่า Wink ให้สิทธิ์อนุญาตนั้นสำหรับการแสดงผลการค้นหาอย่างไร และกฎที่การแสดงผลของคุณต้องปฏิบัติตามเมื่อคุณได้รับสิทธิ์นั้นแล้ว

## ความหมายของการแสดงผลการค้นหา

**การแสดงผลการค้นหา** คือการแสดงโรงแรมจาก Partner API เพื่อตอบสนองการค้นหาของผู้ใช้ ร่วมกับข้อเสนอโรงแรมอื่น ๆ รวมถึงทางเลือกที่ไม่มีค่าใช้จ่ายจากแหล่งอื่น ๆ โดยมีการคลิกออกที่เปิด Wink Booking Engine ของโรงแรมที่เลือกภายใต้บัญชีพันธมิตรของคุณ

ครอบคลุมเฉพาะการค้นหา เนื้อหา และการคลิกออกเท่านั้น การสร้าง เปลี่ยนแปลง หรือยกเลิกการจองผ่าน Partner API ต้องได้รับการอนุมัติเป็นลายลักษณ์อักษรแยกต่างหากจาก Wink

## กฎสำหรับการแสดงผลทุกครั้ง

- **อัตราราคาสด** อัตราและความพร้อมต้องสะท้อนข้อมูลสดในเวลาที่แสดงผล (ข้อ 8.2)
- **อัตราไม่เปลี่ยนแปลง** แสดงอัตราแต่ละรายการตามที่ Partner API ส่งมาโดยตรงโดยไม่มีการบวกเพิ่ม ค่าธรรมเนียม หรือการเปลี่ยนแปลง โรงแรมเป็นผู้กำหนดและควบคุมอัตรา
- **การนำเสนอที่ถูกต้อง** แสดงราคาสิ่งที่รวมและนโยบายการยกเลิกอย่างถูกต้องและไม่เปลี่ยนความหมาย (ข้อ 6.1)
- **ไม่แสดง Wink เป็นผู้ขาย** ผลิตภัณฑ์ของคุณต้องแยกออกจาก Wink อย่างชัดเจนทั้งในแง่ภาพและโครงสร้าง ไม่แสดงตัวเองเป็น Wink และไม่แสดง Wink เป็นตัวแทนท่องเที่ยวออนไลน์แยกต่างหากหรือผู้ขาย (ข้อ 7.4) สัญญาการเข้าพักเป็นระหว่างผู้เดินทางกับโรงแรม
- **การเปิดเผย** เปิดเผยความสัมพันธ์ทางการค้าของคุณกับ Wink เมื่อกฎหมายกำหนด (ข้อ 6.2)
- **ห้ามใช้ต่อ** ห้ามให้สิทธิ์ใช้งานต่อ โอน หรือเปิดเผยข้อมูลหรือเนื้อหาซัพพลายของ Wink แก่ผู้อื่น (ข้อ 11.3)

## การแสดงผลชั่วคราว

Wink ไม่กำหนดเวลาจำกัดว่าคุณจะเก็บผลการค้นหาได้นานเท่าใด เพราะไม่มีใครรู้ว่าเมื่อไหร่ราคาจะเปลี่ยน: โรงแรมอาจเปลี่ยนราคาในอีกห้าวินาทีข้างหน้าหรืออีกหนึ่งปีข้างหน้า สิ่งที่สำคัญคืออัตราและความพร้อมที่คุณแสดงต้องตรงกับข้อมูลสดในเวลาที่แสดงผล (ข้อ 8.2) ดึงข้อมูลใหม่จาก Partner API ทุกครั้งที่แผนการเดินทางเปลี่ยน และก่อนที่คุณจะแสดงผลที่คุณไม่แน่ใจว่ายังเป็นปัจจุบัน

การแสดงผลที่ปฏิบัติตามกฎเหล่านี้ไม่ถือเป็น "สำเนาเนื้อหาคงที่" ตามข้อ 7.5 และไม่ใช่การแคชอัตราที่ล้าสมัยตามข้อ 8.2

## การแคชเนื้อหาโรงแรม

เนื้อหาโรงแรม (ชื่อ คำอธิบาย รูปภาพ สิ่งอำนวยความสะดวก และนโยบาย) ไม่มีเวลาจำกัดในการแคช ใช้ `lastUpdate` ของแต่ละโรงแรมจาก Partner API เป็นกุญแจแคชของคุณ และรีเฟรชเนื้อหาโรงแรมเมื่อมีการเปลี่ยนแปลง

## ตัวระบุที่คุณอาจเก็บไว้

คุณอาจเก็บได้เฉพาะสิ่งเหล่านี้เท่านั้น:

- รหัสโรงแรม Wink และ `urlName` ของโรงแรม
- หมายเลขอ้างอิงการจองที่ระบุว่าเป็นของคุณ
- รหัสการอ้างอิงของคุณเอง รหัสลูกค้า และรหัสการตั้งค่า พร้อมวันที่คลิกและวันที่จองที่เกี่ยวข้อง

ใช้ข้อมูลเหล่านี้เฉพาะเพื่อกำจัดรายการโรงแรมซ้ำจากหลายแหล่ง และสำหรับการอ้างอิง รายงาน และการกระทบยอดค่าคอมมิชชั่น ห้ามเก็บอัตรา ความพร้อม หรือเนื้อหาโรงแรมเกินกว่ากฎข้างต้น และห้ามใช้ข้อมูลใด ๆ จาก Wink รวมถึงตัวระบุเหล่านี้ เพื่อฝึก ปรับแต่ง หรือประเมินโมเดล หรือเพื่อสร้างหรือปรับปรุงฐานข้อมูลซัพพลาย (ข้อ 7.5 และ 10.6)

## วิธีขออนุญาต

การแสดงผลการค้นหาต้องได้รับอนุญาตเป็นลายลักษณ์อักษรอย่างชัดเจนจาก Wink ซึ่งให้เป็นจดหมายแนบท้ายข้อตกลงพันธมิตรความต้องการของคุณ การอนุญาตจะมีผลเมื่อทั้งจดหมายและข้อตกลงได้รับการยอมรับ และ Wink สามารถถอนสิทธิ์ได้โดยแจ้งล่วงหน้าหรือทันทีหากกฎข้างต้นถูกละเมิด

หากต้องการขออนุญาต ส่งอีเมลไปที่ [legal@wink.travel](mailto:legal@wink.travel) พร้อมข้อมูลดังนี้:

- ชื่อผลิตภัณฑ์ของคุณ
- URL ของผลิตภัณฑ์ หากเปิดใช้งานแล้ว
- วิธีที่คุณวางแผนจะใช้ซัพพลายของ Wink: จะแสดงอะไร ที่ไหน และร่วมกับอะไรบ้าง
