ทุกฟีเจอร์ของแพลตฟอร์มสามารถเรียกใช้งานจากภายนอกได้ ส่วนนี้ครอบคลุมการตรวจสอบสิทธิ์, พื้นที่ API, การส่งเหตุการณ์ และข้อมูลอ้างอิงเบื้องหลัง

## เริ่มที่นี่

- [เริ่มต้นอย่างรวดเร็ว](/th/developers/quickstart/) — จากศูนย์สู่ราคาห้องพักสดและการจองทดสอบครั้งแรกในสเตจจิ้ง
- [สร้างบน Wink](/th/developers/build-on-wink/) — สิ่งที่คุณสามารถสร้างและ API ใดที่เหมาะสม
- [การตั้งค่า](/th/developers/setup/) — สร้างแอปพลิเคชันและรับข้อมูลรับรอง
- [การตรวจสอบสิทธิ์](/th/developers/authentication/) — เซสชัน OAuth2 และขอบเขต

## พื้นที่ API

- [REST และ gRPC](/th/developers/rest-and-grpc/) — สองช่องทางการส่งข้อมูลและเมื่อใดควรใช้แต่ละแบบ
- [การระบุตำแหน่งทางภูมิศาสตร์](/th/developers/geolocation/) — การค้นหาพื้นที่สำหรับสินค้าคงคลังที่จองได้
- [การจัดหมวดหมู่](/th/developers/taxonomy/) — รหัส OTA, ภาษาที่รองรับ และสกุลเงิน

## เหตุการณ์และการซิงโครไนซ์

- [การรวมเว็บฮุค](/th/developers/webhook-integration/) — สมัครรับเหตุการณ์ของแพลตฟอร์ม
- [แคตตาล็อกเหตุการณ์เว็บฮุค](/th/developers/webhook-events/) — เหตุการณ์ทั้งหมดที่แพลตฟอร์มส่งออก
- [การซิงค์การจอง](/th/developers/booking-sync/) — รักษาการจองให้สอดคล้องกับ PMS หรือผู้จัดการช่องทาง

## ตัวแทน AI

- [เซิร์ฟเวอร์ MCP](/th/developers/mcp/) — อ่านสัญญา API สดจากไคลเอนต์ AI
- [การชำระเงินแบบ Agentic](/th/developers/agentic-payments/) — เชื่อมต่อเอเจนต์ของคุณ, ลงชื่อเข้าใช้, ค้นหาห้องพัก และอนุมัติการชำระเงิน
- [ทักษะ AI](/th/developers/ai-skills/) — สิ่งที่เอเจนต์ที่ได้รับอนุมัติสามารถทำได้บนแพลตฟอร์ม
