## ซัพพลายโดยตรงเทียบกับซัพพลายที่ขายต่อ

เนื้อหาโรงแรมส่วนใหญ่ที่เอเจนซี่ได้รับมักผ่านหลายขั้นตอน: โรงแรม → ผู้จัดการช่องทาง → ผู้ค้าส่งหรือ bed bank → เอเจนซี่ ทุกขั้นตอนเพิ่มความล่าช้า, กำไรขั้นต้น และความแตกต่างระหว่างสิ่งที่เอเจนซี่เห็นกับสิ่งที่โรงแรมมีจริง

อาการที่พบได้บ่อยคือ: อัตราที่ล้าสมัยเมื่อถึงเวลาลูกค้าตัดสินใจ, ความพร้อมใช้งานที่ล้มเหลวตอนยืนยัน, คำอธิบายห้องที่ไม่ตรงกัน และไม่มีทางถามโรงแรมเกี่ยวกับการจองที่ไม่ได้ทำกับพวกเขา

การจองโดยตรงตัดขั้นตอนเหล่านี้ออก อัตราคือของโรงแรม, ความพร้อมใช้งานเป็นแบบสด และการจองจะลงในระบบของโรงแรมโดยมีเอเจนซี่ของคุณแนบอยู่

| | ผู้ค้าส่ง / bed bank | ซัพพลายโรงแรมโดยตรง |
|---|---|---|
| แหล่งที่มาของอัตรา | โควตาที่ทำสัญญาไว้ มักเป็นแบบคงที่ | อัตราแบบสดของโรงแรม |
| ความพร้อมใช้งาน | แคชไว้ อาจล้มเหลวตอนยืนยัน | สดจากโรงแรม |
| โครงสร้างกำไร | กำไรแฝงในอัตรา | ค่าคอมมิชชั่นโปร่งใส |
| การเป็นเจ้าของลูกค้า | แบ่งปันหรือไม่ชัดเจน | เอเจนซี่รักษาลูกค้าไว้ |
| ความสัมพันธ์กับโรงแรม | ทางอ้อม | โดยตรงกับโรงแรม |
| คำขอพิเศษ | ส่งผ่านหลายขั้นตอน | ติดต่อโรงแรมได้พร้อมการจอง |

## สิ่งที่เอเจนซี่ต้องมีเพื่อจองโดยตรง

- **เข้าถึงซัพพลายที่มีสิทธิ์** — โรงแรม, ห้องพัก และอัตราที่เปิดให้เอเจนซี่ของคุณใช้ได้ ซึ่งกำหนดโดยโรงแรม
- **วิธีนำเสนอที่พร้อมสำหรับลูกค้า** — รายการโรงแรมที่คัดสรร, แพ็กเกจ, แผนที่ หรือหน้าร้านสำหรับข้อเสนอหรือแผนการเดินทาง
- **เส้นทางการจองที่รักษาแหล่งที่มา** เพื่อให้ค่าคอมมิชชั่นถูกระบุโดยไม่ต้องตามหา
- **เงื่อนไขการชำระเงินที่ชัดเจน** — ใครเป็นผู้เก็บเงิน, ใครเป็นผู้ค้าหลัก, และเมื่อใดที่ค่าคอมมิชชั่นจะถูกชำระ
- **การยืนยันและการจัดการแก้ไข** ที่ส่งถึงโรงแรมจริง

## สองวิธีที่การชำระเงินสามารถทำงานได้

**โรงแรมเป็นผู้เก็บเงิน** การชำระเงินถูกเก็บสำหรับโรงแรมซึ่งยังคงเป็นผู้ค้าหลัก เอเจนซี่ได้รับค่าคอมมิชชั่นจากการจองที่ระบุไว้และไม่มีความรับผิดชอบในฐานะผู้ค้า นี่คือค่าเริ่มต้นและไม่ต้องมีใบอนุญาต

**เอเจนซี่เป็นผู้เก็บเงิน** เอเจนซี่ที่มีใบอนุญาตท่องเที่ยวในภูมิภาคที่เหมาะสมสามารถรับชำระเงินจากลูกค้าเองและจ่ายให้โรงแรมโดยตรง Wink จะคิดค่าธรรมเนียม **1.5% สำหรับการประมวลผลเท่านั้น** เรียกเก็บรายเดือน เพราะไม่ได้จัดการเงินสด ใบอนุญาตที่ใช้ขึ้นอยู่กับพื้นที่ที่คุณดำเนินการ — โปรดยืนยันในพื้นที่ก่อนเลือกวิธีนี้

## ค่าคอมมิชชั่น และการคำนวณ

ค่าเริ่มต้นคือ **10%** คำนวณหลังจากหักค่าธรรมเนียมแพลตฟอร์ม 1.5% ของโรงแรมและค่าธรรมเนียมบัตรเครดิต ไม่ใช่จากยอดรวม ในการจองมูลค่า $2,000 จะประมาณ **$189** การระบุแหล่งที่มาจะอยู่ได้นาน **6 เดือนต่อการคลิก** ซึ่งสำคัญสำหรับงานเอเจนซี่ที่ข้อเสนออาจอยู่กับลูกค้านานเป็นสัปดาห์

## การจองกลุ่ม, งานอีเวนต์ และ MICE

ซัพพลายโดยตรงมีคุณค่ามากที่สุดในจุดที่ผู้ค้าส่งอ่อนแอที่สุด: การจองห้องเป็นกลุ่มสำหรับงานแต่งงาน, การประชุม, การพักผ่อน และแรงจูงใจ เหล่านี้ต้องการการสนทนากับโรงแรมเกี่ยวกับอัตรา, การจองสำรอง และวันหมดเขต — ซึ่งเป็นไปได้เมื่อการจองเป็นของคุณและโรงแรมรู้จักคุณ

หน้าร้านหรือหน้ากิจกรรมที่สร้างจากซัพพลายที่มีสิทธิ์จะให้ลิงก์จองแก่ผู้เข้าร่วมในขณะที่ยังคงรักษาการจองกลุ่ม, การระบุแหล่งที่มา และรายงานกับเอเจนซี่

## ข้อผิดพลาดที่พบบ่อย

- **เปรียบเทียบอัตราผู้ค้าส่งแบบเน็ตกับอัตราโดยตรงที่มีค่าคอมมิชชั่น** โดยไม่ปรับสำหรับกำไรที่แฝงอยู่ในอัตราเน็ต
- **ส่ง PDF ให้ลูกค้า** ข้อเสนอที่ไม่สามารถจองได้จะเสียโอกาสให้กับผู้ที่ทำให้ข้อเสนอของตนจองได้
- **ใช้ลิงก์เดียวกันสำหรับลูกค้าทุกคน** การระบุแหล่งที่มาและรายงานจะกลายเป็นการเดา
- **คิดว่าต้องมีใบอนุญาตเพื่อรับค่าคอมมิชชั่น** จริง ๆ แล้วไม่ต้อง — ต้องมีเฉพาะกรณีที่ต้องการเก็บเงินเอง
- **ไม่สนใจเงื่อนไขการยกเลิก** ของการจองกลุ่มจนกว่าลูกค้าจะถาม
