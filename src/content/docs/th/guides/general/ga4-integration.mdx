โดยการเชื่อมต่อทรัพย์สิน Google Analytics 4 ของคุณกับ Wink เหตุการณ์การจองของคุณ — ตั้งแต่การดูห้องจนถึงการจองที่เสร็จสมบูรณ์ — จะถูกส่งต่อไปยังแดชบอร์ด GA4 ของคุณโดยอัตโนมัติพร้อมกับการวิเคราะห์ของ Wink เอง โดยไม่ต้องเขียนโค้ดหรือการตั้งค่าทางเทคนิคใดๆ จากฝั่งคุณ

<Aside type="tip">
คุณต้องมีสิ่งเดียวจาก GA4: **Measurement ID** (`G-XXXXXXXXXX`) Wink จะโหลดมันในเบราว์เซอร์ของแขกและสตรีมช่องทางการจองทั้งหมดของคุณ — รวมถึงการจองที่เสร็จสมบูรณ์ (`purchase`) — ไปยังทรัพย์สิน GA4 ของคุณโดยตรง ไม่มีความลับ API ที่ต้องสร้างและไม่ต้องติดตั้งอะไรบนเว็บไซต์ของคุณเอง
</Aside>

## วิธีการทำงาน

```
คุณป้อน Measurement ID (G-XXXXXXXXXX) ในพอร์ทัล Wink
       ↓
Wink โหลด GA4 ของคุณในเบราว์เซอร์ของแขกและสตรีมเหตุการณ์การจอง
(การดู, ตะกร้า, ชำระเงิน) ไปยังทรัพย์สิน GA4 ของคุณแบบเรียลไทม์
       ↓
ในหน้าขอบคุณ เหตุการณ์การจองที่เสร็จสมบูรณ์ (purchase) จะทำงานในเบราว์เซอร์ —
Wink เชื่อมต่อเซสชัน GA4 ที่ถูกขัดจังหวะโดยการเปลี่ยนเส้นทางการชำระเงินใหม่
ดังนั้นยอดขายยังคงนับรวมกับการเยี่ยมชมเดิมของแขก
       ↓
คุณเข้าสู่ระบบที่ analytics.google.com และดูช่องทางการจองทั้งหมดของคุณ
```

## สิ่งที่คุณต้องทำ

<Steps>

1. **สร้างทรัพย์สิน GA4**

   ไปที่ [analytics.google.com](https://analytics.google.com): Admin → Create Property ตั้งค่าโซนเวลาและสกุลเงินให้ตรงกับตลาดของคุณ

2. **สร้าง Web Data Stream**

   Admin → Data Streams → Add Stream → Web ป้อน `wink.travel` เป็น URL ระบบจะสร้าง **Measurement ID** (`G-XXXXXXXXXX`) ให้คุณ คัดลอกไว้

3. **ป้อน Measurement ID ของคุณในพอร์ทัล Wink**

   เข้าสู่ระบบที่ [app.wink.travel](https://app.wink.travel) เลือกบัญชีของคุณและเปิดการตั้งค่าการปรับแต่ง ในส่วน **Analytics & integrations** วาง Measurement ID ของคุณในช่อง **GA4 Measurement ID** แล้วบันทึก เพียงเท่านี้การผสานรวม GA4 ของคุณก็พร้อมใช้งานแล้ว

4. **ตั้งค่า `purchase` เป็นเหตุการณ์สำคัญ**

   กลับไปที่ทรัพย์สิน GA4 ของคุณ: Admin → Events → หา `purchase` → สลับเปิด **Mark as key event** เหตุการณ์นี้จะทำให้การจองที่เสร็จสมบูรณ์ปรากฏในรายงาน Conversions ของคุณ

5. **ดูข้อมูลของคุณ**

   เข้าสู่ระบบที่ [analytics.google.com](https://analytics.google.com) แล้วคุณจะเห็นการจอง รายได้ และช่องทางของแขก — ทั้งหมดถูกติดตามโดยอัตโนมัติผ่าน Wink

</Steps>

<Aside type="note">
คุณไม่จำเป็นต้องติดตั้งโค้ดติดตามใดๆ บนเว็บไซต์ของคุณสำหรับการผสานรวมนี้ Wink จะจัดการทุกอย่าง — Measurement ID ของคุณเป็นเพียงจุดหมายปลายทางที่ข้อมูลการจองของคุณถูกส่งไป
</Aside>

<Aside type="tip">
**GA4 และ GTM สามารถใช้ร่วมกันได้** หากคุณใช้ Google Tag Manager container (เช่น container ของ Sojern) คุณสามารถตั้งค่าทั้งสองพร้อมกันได้ — ไม่ขัดแย้งกัน ดู [GTM Analytics Integration](/th/guides/general/gtm-integration)
</Aside>

## วิธีที่ Wink ใช้ Measurement ID ของคุณในระบบจอง

ทุกอย่างเกิดขึ้น **ในเบราว์เซอร์ของแขก** — ไม่มีการส่งข้อมูลระหว่างเซิร์ฟเวอร์และไม่มีความลับ API ที่เกี่ยวข้อง

- **GA4 ของคุณจะโหลดบนหน้าการจองของคุณ** เมื่อใดก็ตามที่แขกดูทรัพย์สินของคุณในระบบจอง Wink จะโหลด Measurement ID ของคุณในเบราว์เซอร์ของพวกเขาควบคู่กับการวิเคราะห์ของ Wink โดยอ่านจากข้อมูลที่ใช้ร่วมกันเดียวกัน เหตุการณ์การเรียกดู — การค้นหา, การดูห้อง, ตะกร้า, ชำระเงิน — จะสตรีมไปยังทรัพย์สิน GA4 ของคุณแบบเรียลไทม์
- **การจองที่เสร็จสมบูรณ์จะทำงานในหน้าขอบคุณ** เมื่อแขกชำระเงินเสร็จและไปยังหน้าการยืนยัน เหตุการณ์ `purchase` จะทำงานที่ฝั่งไคลเอนต์ พร้อมข้อมูลมูลค่าการจองเต็มจำนวน สกุลเงิน และรายละเอียดห้อง
- **การเปลี่ยนเส้นทางการชำระเงินจะไม่ทำให้ยอดขายหายไป** การชำระเงินด้วยบัตรจะส่งเบราว์เซอร์ของแขกไปยังผู้ให้บริการชำระเงินและกลับมา ซึ่งโดยปกติจะทำให้เซสชัน GA4 ในเบราว์เซอร์ขาดตอนและทำให้การจองดูเหมือนเป็นการเยี่ยมชม "Direct" ใหม่ เพื่อป้องกันปัญหานี้ Wink จะนำตัวระบุเซสชัน GA4 ของคุณผ่าน URL การกลับมาและ **เชื่อมต่อเซสชันเดิม** ในหน้าขอบคุณ *ก่อน* ที่เหตุการณ์ `purchase` จะทำงาน ดังนั้นการจองที่เสร็จสมบูรณ์จึงถูกนับรวมกับการเยี่ยมชมเดิมที่แขกเริ่มต้น — ไม่ถูกนับเป็นเซสชันแยกต่างหาก

<Aside type="note">
Wink จะลบการนับซ้ำของเหตุการณ์ `purchase` ต่อการจองหนึ่งครั้ง ดังนั้นการรีเฟรชหน้า หรือการเปลี่ยนเส้นทางอัตโนมัติไปยังรายละเอียดการจองจะไม่ทำให้ยอดขายถูกนับซ้ำ
</Aside>

## สิ่งที่คุณสามารถติดตามได้

เมื่อเชื่อมต่อแล้ว ทรัพย์สิน GA4 ของคุณจะได้รับชุดเหตุการณ์ Enhanced E-commerce เต็มรูปแบบสำหรับทรัพย์สินของคุณ:

### Discovery

| เหตุการณ์ | ความหมาย |
|---|---|
| `view_item_list` | แขกเห็นทรัพย์สินของคุณในผลการค้นหาหรือรายการหมวดหมู่ |
| `select_item` | แขกคลิกที่ทรัพย์สินของคุณจากรายการ |
| `view_item` | แขกดูหน้ารายละเอียดโรงแรมของคุณ |

### Consideration

| เหตุการณ์ | ความหมาย |
|---|---|
| `view_promotion` | แขกเห็นข้อเสนอโปรโมชั่นสำหรับทรัพย์สินของคุณ |
| `select_promotion` | แขกคลิกที่ข้อเสนอโปรโมชั่น |
| `add_to_wishlist` | แขกบันทึกทรัพย์สินของคุณลงในรายการโปรด |

### Booking Funnel

| เหตุการณ์ | ความหมาย |
|---|---|
| `add_to_cart` | แขกเลือกห้องหรือแพ็กเกจ |
| `view_cart` | แขกดูสรุปการจองของตน |
| `remove_from_cart` | แขกลบห้องหรือแพ็กเกจออก |
| `begin_checkout` | แขกเริ่มกระบวนการชำระเงิน |
| `add_payment_info` | แขกป้อนข้อมูลการชำระเงิน |
| `add_shipping_info` | แขกป้อนข้อมูลแขก |
| `purchase` | แขกทำการจองเสร็จสมบูรณ์ |
| `refund` | การจองถูกยกเลิกและคืนเงิน |

เหตุการณ์ทั้งหมดรวมมิติที่เกี่ยวข้อง เช่น รายได้ สกุลเงิน ประเภทห้อง และมูลค่าการจอง — ให้ภาพรวมเส้นทางของแขกตั้งแต่การรับรู้ครั้งแรกจนถึงการจองที่เสร็จสมบูรณ์ เพื่อปลดล็อกมิติระดับทรัพย์สินและห้องเพิ่มเติม เช่น `city_name`, `cancellation_policy`, `bed_type` และอื่นๆ ดู [Custom Dimensions in GA4](/th/guides/general/gtm-integration#custom-dimensions-in-ga4)

## การติดตามข้ามโดเมน (ขั้นสูง)

การผสานรวมมาตรฐานข้างต้นติดตามทุกอย่างที่เกิดขึ้นภายใน Wink อย่างไรก็ตาม หากคุณต้องการติดตามแขกตั้งแต่เว็บไซต์ของคุณเองจนถึงการจองที่เสร็จสมบูรณ์บน Wink — และระบุแหล่งที่มาของการเข้าชมเดิมอย่างถูกต้อง (Google Ads, แคมเปญอีเมล, การค้นหาแบบออร์แกนิก ฯลฯ) — จะต้องมีขั้นตอนเพิ่มเติมในแต่ละฝั่ง

<Aside type="caution">
ส่วนนี้ใช้ได้เฉพาะถ้าคุณติดตั้ง GA4 บนเว็บไซต์ของคุณเองเท่านั้น หากคุณไม่ได้ใช้ GA4 บนเว็บไซต์ของคุณ การผสานรวมมาตรฐานข้างต้นก็เพียงพอแล้ว
</Aside>

### ทำไมเรื่องนี้จึงสำคัญ

หากไม่มีการติดตามข้ามโดเมน แขกที่เยี่ยมชมเว็บไซต์ของคุณก่อนแล้วจึงจองบน Wink จะปรากฏใน GA4 ของคุณเป็นเซสชัน **Direct** โดยไม่มีการเชื่อมโยงกับการเยี่ยมชมก่อนหน้า การคลิก Google Ads แคมเปญอีเมล หรือการเยี่ยมชมแบบออร์แกนิกที่นำไปสู่การจองจะไม่ได้รับเครดิตใดๆ

เมื่อกำหนดค่าการติดตามข้ามโดเมน คุณจะเห็นเส้นทางของแขกอย่างครบถ้วน:

```
google.com (โฆษณาที่ชำระเงิน)
       ↓
เว็บไซต์ของคุณ (แขกเรียกดูห้อง)
       ↓
wink.travel (แขกเลือกห้องและจอง)
       ↓
การจองถูกนับรวมอย่างถูกต้องกับการคลิก Google Ads เดิม
```

### สิ่งที่คุณต้องทำ: คุณ

กำหนดค่าทรัพย์สิน GA4 ของคุณให้รู้จัก `wink.travel` เป็นส่วนหนึ่งของโดเมนของคุณเอง ไม่ใช่การอ้างอิงภายนอก ซึ่งจะบอก GA4 ให้เชื่อมต่อเซสชันทั้งสองเข้าด้วยกันเป็นเส้นทางของแขกที่ต่อเนื่อง

<Steps>
1. GA4 Admin → Data Streams → เลือกสตรีมของคุณ
2. ตั้งค่าป้ายกำกับ → **Configure your domains**
3. เพิ่ม `wink.travel` เป็นโดเมนที่เชื่อมโยง
4. บันทึก
</Steps>

### สิ่งที่คุณต้องทำ: Wink

ติดต่อ [Wink Support](https://app.wink.travel) และแจ้งโดเมนเว็บไซต์ของคุณ (เช่น `yourhotel.com`) Wink จะเพิ่มโดเมนของคุณในรายการยกเว้นการอ้างอิงในทรัพย์สิน GA4 ของ Wink ซึ่งจะป้องกันไม่ให้เว็บไซต์ของคุณถูกบันทึกเป็นแหล่งอ้างอิง ซึ่งอาจทำให้การนับแหล่งที่มาของแขกเปลี่ยนแปลงและเริ่มเซสชันใหม่

<Aside type="tip">
การผสานรวมมาตรฐานข้างต้นเพียงพอสำหรับทรัพย์สินส่วนใหญ่และให้คุณเห็นข้อมูลการจองและรายได้บน Wink ได้ทันที การติดตามข้ามโดเมนเป็นตัวเลือกขั้นสูงที่ควรตั้งค่าหลังจากที่คุณคุ้นเคยกับข้อมูล GA4 ของคุณและต้องการข้อมูลการระบุแหล่งที่มาที่ลึกขึ้น
</Aside>
