คำแนะนำนี้จะพาตัวแทนท่องเที่ยวตั้งแต่การลงทะเบียนจนถึงการจองลูกค้ารายแรก นอกจากนี้ยังอธิบายสองวิธีที่ตัวแทนสามารถทำงานบน Wink เพื่อให้คุณเลือกวิธีที่เหมาะสมก่อนเริ่มต้น

## ก่อนเริ่มต้น

คุณจะต้องมี:

- รายละเอียดบริษัทของคุณ
- หมายเลขทะเบียนตัวแทนท่องเที่ยว หรือรหัส IATA หากมี
- บัญชีธนาคารสำหรับรับค่าคอมมิชชั่นของคุณ

## เลือกวิธีการทำงานของคุณ

| | มาตรฐาน (ตัวแทนส่วนใหญ่) | การเก็บเงินโดยตัวแทน |
|---|---|---|
| วิธีการจอง | ในพอร์ทัล Wink หรือผ่าน Partner API | ผ่าน [Partner API](/th/integrations/partner-api/) จากระบบของคุณเอง |
| ใครเป็นผู้รับเงินลูกค้า | เก็บเงินให้โรงแรม ซึ่งยังคงเป็นผู้ค้ารายการ คุณกรอกบัตรของลูกค้าในขั้นตอนชำระเงิน | คุณเป็นผู้รับเงินในฐานะผู้ค้ารายการ |
| สิ่งที่คุณได้รับ | **ค่าคอมมิชชั่นเริ่มต้น 10%** จากแต่ละการจอง | ค่าคอมมิชชั่นตามข้อตกลงของคุณกับแต่ละโรงแรม |
| สิ่งที่คุณจ่ายให้ Wink | ไม่มี | **ค่าธรรมเนียมการจอง 1.5%** ของมูลค่าการจองแต่ละครั้ง เรียกเก็บรายเดือน พร้อมค่าการใช้งาน Partner API เกินโควตาฟรี |
| การจ่ายเงินให้โรงแรม | Wink จัดการให้ | คุณจ่ายเงินให้แต่ละโรงแรมโดยตรง ตามข้อตกลงของคุณกับโรงแรมนั้น |
| การคืนเงิน, การเรียกเก็บเงินซ้ำ, การปฏิบัติตามข้อกำหนดการชำระเงิน | Wink จัดการให้ | เป็นความรับผิดชอบของคุณ |
| การอนุมัติ | การลงทะเบียนของคุณจะถูกตรวจสอบก่อนจองได้ | การลงทะเบียนของคุณจะถูกตรวจสอบ พร้อมการอนุมัติเป็นลายลักษณ์อักษรจาก Wink สำหรับเส้นทางนี้ พร้อมวงเงินเครดิต |

Wink ตรวจสอบการลงทะเบียนตัวแทนท่องเที่ยวทุกแห่ง ตัวแทนส่วนใหญ่จะใช้เส้นทางมาตรฐาน การเก็บเงินโดยตัวแทนเหมาะสำหรับ **พันธมิตร API เท่านั้น**: ตัวแทนที่จองผ่าน Partner API จากระบบของตนเอง เก็บเงินลูกค้าภายใต้ใบอนุญาตของตนเอง และทำสัญญาโดยตรงกับโรงแรม

## ขั้นตอนที่ 1: ลงทะเบียนตัวแทนของคุณ

<Steps>
1. ไปที่ [app.wink.travel](https://app.wink.travel) คลิก `Sign-In / Register` และลงทะเบียน

2. คลิก `Accounts` ในแถบด้านข้างซ้าย จากนั้นคลิก `Create` และเลือก **I am a Travel Agent**

3. กรอกรายละเอียดตัวแทนของคุณ เลือก **Company** เป็นประเภทนิติบุคคล: ซึ่งจะกำหนดวิธีการจ่ายเงิน ดูที่ [Create Account](/th/portal/create-account/)

4. หากคุณจะเก็บเงินเองผ่าน Partner API ให้เลือกเส้นทางนี้ในขั้นตอนลงทะเบียน นี่เป็นการขอ ไม่ใช่การอนุมัติ ดูที่ [ขั้นตอนที่ 6](#step-6-collect-payment-yourself-api-partners-only)

5. Wink ตรวจสอบการลงทะเบียนตัวแทนท่องเที่ยวทุกแห่ง เราจะส่งอีเมลไปยังที่อยู่ที่ลงทะเบียนและขอเอกสารของคุณ: รายละเอียดบริษัทและหมายเลขทะเบียนตัวแทนท่องเที่ยวหรือรหัส IATA คุณสามารถจองได้เมื่อการลงทะเบียนได้รับการอนุมัติ
</Steps>

## ขั้นตอนที่ 2: เพิ่มบัญชีธนาคารของคุณ

ไปที่ `Account > Bank Accounts` เพิ่มบัญชีของตัวแทนและตั้งเป็น **Primary** ค่าคอมมิชชั่นจะถูกจ่ายผ่านการโอนเงินผ่านธนาคาร Wink ส่งเงินผ่าน Revolut ดังนั้นบัญชีธุรกิจ Revolut จะสะดวกที่สุด แต่บัญชีธนาคารใดก็ได้ใช้ได้ ดูที่ [Bank Accounts](/th/portal/settings/payouts/)

## ขั้นตอนที่ 3: ค้นหาโรงแรมสำหรับลูกค้าของคุณ

<Steps>
1. คลิก `Browse > Hotels` ในแถบเมนูหลัก

2. ค้นหาตามจุดหมาย วันที่ และจำนวนผู้เข้าพัก และกรองจนกว่าจะได้ตัวเลือกที่เหมาะสมสำหรับลูกค้า

3. บันทึกรายการโปรดลงใน [curated list](/th/portal/studio/curated-lists/) หากคุณกำลังเปรียบเทียบตัวเลือกกับลูกค้า
</Steps>

ราคาที่คุณเห็นเป็นราคาของโรงแรมโดยตรง Wink ส่งต่อราคาโดยไม่ปรับเพิ่ม: คุณจะได้รายได้จากค่าคอมมิชชั่น ดูที่ [Search](/th/portal/studio/search/)

## ขั้นตอนที่ 4: จองสำหรับลูกค้าของคุณ

<Steps>
1. เลือกห้องและราคา และกรอกชื่อและข้อมูลติดต่อของลูกค้าในฐานะผู้เดินทาง

2. ในขั้นตอนชำระเงิน กรอกบัตรที่ลูกค้าให้สำหรับการจองนี้ การชำระเงินจะถูกเก็บให้โรงแรม และโรงแรมยังคงเป็นผู้ค้ารายการ

3. ยืนยัน คุณ ผู้เดินทาง และโรงแรมจะได้รับอีเมลยืนยัน รหัสการจองจะขึ้นต้นด้วย `WNK`
</Steps>

:::caution[จัดการบัตรของลูกค้าของคุณอย่างระมัดระวัง]
ขอใช้บัตรเฉพาะสำหรับการจองที่คุณกำลังทำ และกรอกบัตรโดยตรงในขั้นตอนชำระเงิน อย่าจดบันทึก ส่งอีเมล หรือเก็บไว้ในบันทึกของคุณเอง
:::

## ขั้นตอนที่ 5: จัดการการจองและรับเงิน

- **การจอง:** คลิก `Bookings` ในแถบเมนูหลักเพื่อดูการจองทั้งหมด กรอง ส่งออกเป็น CSV ส่งอีเมลยืนยันซ้ำ หรือยกเลิกภายใต้นโยบายการยกเลิกของโรงแรม ดูที่ [Bookings](/th/portal/travel-agent/bookings/)
- **ค่าคอมมิชชั่น:** เริ่มต้นที่ 10% เมื่อคุณทำงานกับโรงแรมเป็นประจำ คุณสามารถขอ [การเชื่อมต่อโดยตรง](/th/portal/studio/network/) และตกลงค่าคอมมิชชั่นที่แตกต่างได้
- **เวลาที่ได้รับเงิน:** ค่าคอมมิชชั่นจะพร้อมใช้ภายใน 24 ชั่วโมงหลังจากผู้เข้าพักเช็คอิน และจะถูกโอนไปยังบัญชีธนาคารหลักของคุณ ค่าธรรมเนียมการโอนจ่ายตามต้นทุน ดูที่ [Pricing](/th/getting-started/pricing/)

## ขั้นตอนที่ 6: เก็บเงินเอง (สำหรับพันธมิตร API เท่านั้น)

ข้ามขั้นตอนนี้หากคุณจองในพอร์ทัล หรือพอใจกับเส้นทางมาตรฐาน

<Steps>
1. รวมระบบกับ [Partner API](/th/integrations/partner-api/) เส้นทางนี้ใช้ได้เฉพาะผ่าน API จากระบบจองของคุณเอง ไม่ใช่ในพอร์ทัล

2. เลือกเส้นทางนี้ในขั้นตอนลงทะเบียน (ขั้นตอนที่ 1)

3. Wink ประเมินพร้อมเอกสารลงทะเบียนของคุณ เช่น สถานะทางการเงินและสถานะการกำกับดูแล และยืนยันเป็นลายลักษณ์อักษร การอนุมัติจะมาพร้อมกับ **วงเงินเครดิต**: จำนวนสูงสุดที่คุณสามารถถือครองในการจองที่ยังไม่ชำระเงินได้ในแต่ละครั้ง

4. จนกว่าจะได้รับการอนุมัติ คุณสามารถจองผ่านเส้นทางมาตรฐานได้
</Steps>

เมื่อได้รับการอนุมัติ คุณจะเก็บเงินลูกค้าเองและจ่ายเงินให้แต่ละโรงแรมโดยตรง สำหรับแต่ละการจอง คุณจะหักค่าธรรมเนียม Wink 1.5% และค่าคอมมิชชั่นของคุณตามลำดับ ส่วนที่เหลือจะจ่ายให้โรงแรม:

| สำหรับการจองมูลค่า USD 1,000.00 พร้อมค่าคอมมิชชั่น 10% | |
|---|---|
| มูลค่าการจอง | USD 1,000.00 |
| หักค่าธรรมเนียม Wink (1.5% ของมูลค่าการจอง) | USD 15.00 |
| ยอดรวมย่อย | USD 985.00 |
| หักค่าคอมมิชชั่นของคุณ (10% ของยอดรวมย่อย) | USD 98.50 |
| **ยอดที่ต้องจ่ายให้โรงแรม** | **USD 886.50** |

Wink จะออกใบแจ้งหนี้ค่าธรรมเนียมการจอง 1.5% รายเดือน เป็นสกุลเงิน USD ชำระภายใน 15 วัน พร้อมค่าการใช้งาน Partner API เกินโควตาฟรี คุณรับผิดชอบเรื่องการคืนเงิน การเรียกเก็บเงินซ้ำ ความปลอดภัยการชำระเงิน (PCI-DSS) และใบอนุญาตที่ประเทศของคุณกำหนดสำหรับการเก็บเงิน เอกสารข้อกำหนดทั้งหมดอยู่ใน [Travel Agent Agreement](/th/legal/platform-agreements/)

## เชื่อมต่อระบบของคุณเอง

ตัวแทนที่มีเครื่องมือจองของตนเองสามารถค้นหาและจองผ่าน [Partner API](/th/integrations/partner-api/) บัญชืตัวแทนท่องเที่ยวสามารถสร้างการจองโดยตรงผ่าน API และนี่เป็นวิธีเดียวที่ใช้เส้นทางเก็บเงินโดยตัวแทน ดูที่ [Partner API reference](/th/partner-api/partner/)
