นี่คือวิธีที่เราจัดแบ่งความรับผิดชอบใน Wink:

- [Extranet](/th/portal/extranet/what-is-extranet) ดูแลผู้ให้บริการที่จัดการสินค้าคงคลัง
- [Studio](/th/portal/studio/what-is-studio) ดูแลพันธมิตรที่จัดการเนื้อหา
- `Booking Engine` ดูแลการสร้างเนื้อหาจาก `Studio` ที่อิงจากสินค้าคงคลังที่สร้างใน `Extranet` และทำให้สามารถจองได้
- [Payment](/th/payment/what-is-trip-pay) ดูแลการเรียกเก็บเงิน / คืนเงินนักเดินทางที่จอง [ผ่านแพลตฟอร์มอย่าง Wink] และจ่ายเงินให้ผู้ขาย

booking engine คือหัวใจหลักของแพลตฟอร์มของเรา

ความรับผิดชอบของมันรวมถึง:

- จัดการสกุลเงินและอัปเดตอัตราแลกเปลี่ยนให้ทันสมัย
- ให้ผู้ให้บริการอัตราราคาส่งข้อมูลอัตราแก่เรา
- จัดการข้อมูลอ้างอิง *เช่น ภูมิภาค ประเทศ จุดหมายปลายทาง ที่พัก ฯลฯ*
- จัดการภาษา
- สร้างการวิเคราะห์จากการโต้ตอบของผู้ใช้ เหตุการณ์ และการเรียก API
- ให้บริการสินค้าคงคลังที่จองได้ในรูปแบบ ภาษา และสกุลเงินที่ต้องการ เช่น:
    - [ลิงก์ที่แชร์ได้](/th/portal/studio/shareable-links) บน Facebook
    - หน้าแลนดิ้งของโรงแรมบน https://book.wink.travel ที่มีสินค้าคงคลังของโรงแรมนั้น
    - [การ์ด](/th/portal/studio/cards) ที่มีสินค้าคงคลังของพันธมิตร
    - [แผนที่](/th/portal/studio/maps) บนบัญชี [WinkLinks](/th/portal/link-manager/wink-links) ของคุณ
    - [การเรียก API](/th/api) จากระบบตัวแทนท่องเที่ยวระยะไกล
- ให้ผู้เดินทางมีวิธีการ:
    - ค้นหาสินค้าคงคลังการเดินทาง
    - จองสินค้าคงคลังที่มีอยู่
    - จัดการ [การจองและรีวิว](/th/booking-engine/bookings) ของตน
    - จัดการ [รายการสิ่งที่อยากจอง](/th/booking-engine/bucket-list) สำหรับอนาคต
    - จัดการ [โปรไฟล์การเดินทาง](/th/booking-engine/travel-preferences) ของตน *เช่น ภูมิแพ้ ผู้ติดต่อฉุกเฉิน ฯลฯ*

booking engine คือชุดฟังก์ชันที่นำกลับมาใช้ใหม่ได้ซึ่งเราเปิดเผยผ่าน https://book.wink.travel; เว็บไซต์ที่ปรับแต่งได้สูงสำหรับโรงแรมและพันธมิตรในการขายสินค้าของตนให้กับนักเดินทาง

ผู้รวมระบบที่ต้องการอิสระมากขึ้น สามารถเข้าถึงฟีเจอร์ทั้งหมดผ่าน [ปลั๊กอิน WordPress](/th/integrations/wordpress/), [Web Components](/th/integrations/web-components) และ [APIs](/th/api)

อ่านต่อในส่วนถัดไปเพื่อเรียนรู้เพิ่มเติมเกี่ยวกับสิ่งที่ booking engine มีให้

## อ่านเพิ่มเติม

- อ่านเกี่ยวกับ [ปลั๊กอิน WordPress](/th/integrations/wordpress/)
- อ่านเกี่ยวกับ [Web Components](/th/integrations/web-components)
- อ่านเกี่ยวกับ [APIs](/th/api)
