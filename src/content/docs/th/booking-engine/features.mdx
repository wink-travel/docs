เครื่องมือจองคือที่ที่สินค้าคงคลังกลายเป็นสิ่งที่สามารถจองได้ ที่พักจะลงรายการสินค้าคงคลังของตนใน [Portal](/th/portal/overview) และพันธมิตรจะเปลี่ยนมันเป็นเนื้อหาที่แชร์ได้ที่นั่นด้วย — จากนั้นเครื่องมือจองจะให้บริการเนื้อหานั้นแก่ผู้เดินทางในภาษาที่เหมาะสม สกุลเงิน และแบรนด์ และรับการจอง

มันถูกเปิดเผยในรูปแบบเว็บไซต์ที่ `https://book.wink.travel` และฟังก์ชันเดียวกันนี้สามารถเข้าถึงได้สำหรับผู้รวมระบบผ่าน [Web Components](/th/integrations/web-components), [ปลั๊กอิน WordPress](/th/integrations/wordpress) และ [API](/th/api/overview/)

## เครื่องมือเดียว ปรับแต่งให้เหมาะสม

มีเครื่องมือจองเพียงหนึ่งเดียว และมันอยู่ที่ `https://book.wink.travel`

<LinkButton href="https://book.wink.travel/home" variant="secondary" icon="external" target="_blank">
  เปิดเครื่องมือจอง
</LinkButton>

มันปรับตัวให้เหมาะกับผู้ที่ขายผ่านระบบนี้ พันธมิตรที่มีที่พักหลายแห่งจะได้หน้าแรกที่สร้างขึ้นเพื่อการเรียกดูและเปรียบเทียบ โรงแรมเดียวจะได้หน้าที่นำตรงไปยังสินค้าคงคลังของตน บริษัทบริหารจัดการที่พักจะได้ [ที่พักที่พวกเขาเป็นตัวแทน](/th/portal/settings/agency-representation) สิ่งเหล่านี้ไม่ใช่เว็บไซต์แยกหรือผลิตภัณฑ์แยก — แต่เป็น [การปรับแต่ง](/th/portal/settings/branding) ของคุณที่บอกเครื่องมือเดียวกันนี้ว่าจะนำเสนออย่างไร

## สิ่งที่นักเดินทางสามารถทำได้

### ค้นหาสิ่งที่ต้องการจอง

- **ค้นหาตามจุดหมายปลายทาง** ค้นหาชื่อเมือง เกาะ ประเทศ หรือที่พัก ร้านอาหาร สปา ห้องประชุม กิจกรรม สถานที่ท่องเที่ยว หรือสถานที่เฉพาะ
- **เรียกดูคอลเลกชันที่จัดอันดับ** สำรวจสินค้าคงคลังที่จัดเรียงตามอัตราสมาชิก ราคา ความนิยม คะแนนสิ่งแวดล้อม ประสบการณ์ สิทธิพิเศษ ความภักดี หรือสิ่งเสริม — ทั้งทั่วโลกหรือจำกัดเฉพาะเมือง เกาะ หรือประเทศ
- **กรองผลลัพธ์** ตามชื่อ รัศมี ไลฟ์สไตล์ คะแนนดาว และสินค้าคงคลังที่จองตรงเท่านั้น
- **ตั้งแผนการเดินทาง** — วันที่เช็คอินและเช็คเอาต์ จำนวนผู้ใหญ่ เด็กพร้อมอายุ หลายห้องพร้อมกัน และรหัสโปรโมชั่น ราคาบนตารางจะอัปเดตแบบเรียลไทม์

อ่านเพิ่มเติมใน [การค้นหา](/th/booking-engine/search)

### ประเมินที่พัก

ที่พักแต่ละแห่งจะมีหน้าแลนดิ้งเพจของตัวเองพร้อมแกลเลอรีภาพ คำอธิบายที่แปลเป็นภาษาท้องถิ่น แผนที่ สิ่งอำนวยความสะดวก คะแนนดาว และคะแนนจากผู้เข้าพัก คะแนนสิ่งแวดล้อม Greendex รีวิวจากผู้เข้าพัก รวมถึงร้านอาหาร สปา กิจกรรม สถานที่ท่องเที่ยว ห้องประชุม และคำแนะนำการเดินทางของที่พักนั้น

อ่านเพิ่มเติมใน [รายละเอียดที่พัก](/th/booking-engine/property-detail)

### สร้างการเข้าพักและจอง

- **เลือกห้องและแผนราคา** พร้อมตัวเลือกที่คืนเงินได้และไม่ได้คืนเงินที่ระบุอย่างชัดเจน
- **ดูสิทธิพิเศษ** ที่แนบมากับแต่ละราคา — ทั้งที่รับประกันและตามความพร้อม
- **เพิ่มหลายห้อง** ในการจองเดียวและปรับจำนวนได้
- **เพิ่มสิ่งเสริมและแพ็กเกจของโรงแรม** รวมถึงสิ่งเสริมที่กำหนดเวลาไว้ตามวันที่และเวลา
- **ดูยอดรวมอัปเดตแบบเรียลไทม์** พร้อมรายละเอียดราคาต่อห้องและการประหยัดเมื่อเทียบกับราคาสาธารณะ
- **ชำระเงินและเช็คเอาต์** ผ่านวิดเจ็ตชำระเงินที่ฝังอยู่ในระบบอย่างปลอดภัย รองรับบัตร กระเป๋าเงิน และวิธีชำระเงินท้องถิ่นตามที่บัญชีรับชำระเงินของที่พักรองรับ

อ่านเพิ่มเติมใน [การชำระเงิน](/th/booking-engine/checkout)

### จัดการการจองหลังจากนั้น

- **ดูการยืนยัน** พร้อมรหัสการจอง ทันทีและทางอีเมล
- **เปิดการจองโดยไม่ต้องเข้าสู่ระบบ** — ลิงก์การจองที่ส่งทางอีเมลใช้ได้กับผู้เข้าพักที่ไม่เคยสร้างบัญชี
- **ตรวจสอบการจองทั้งหมด**: นโยบายการยกเลิก สถานะการชำระเงิน สิ่งที่ชำระและวิธีชำระ ค่าธรรมเนียมเพิ่มเติม และรายละเอียดติดต่อของที่พัก
- **ดำเนินการ**: คัดลอกรหัสการจอง แชร์การจอง เพิ่มลงในปฏิทิน พิมพ์ ดาวน์โหลดใบเสร็จ ยกเลิกพร้อมเหตุผล หรือขอคืนเงินนอกช่วงเวลายกเลิก
- **เขียนรีวิว** เมื่อการเข้าพักมีคุณสมบัติ
- **ดูทริปที่จัดกลุ่ม** เมื่อทริปเดียวสร้างการจองหลายรายการ

อ่านเพิ่มเติมใน [การจอง](/th/booking-engine/bookings) และ [การยืนยันการจอง](/th/booking-engine/confirmation)

### ทำให้เป็นส่วนตัว

- **เปลี่ยนภาษาและสกุลเงิน** ได้ทุกเวลาจากส่วนหัว — มากกว่า 40 ภาษาและ 160 สกุลเงิน
- **เข้าสู่ระบบครั้งเดียว** ผ่านระบบ single sign-on ของ Wink การกลับมาหลังจากเข้าสู่ระบบจะพาผู้เดินทางกลับไปยังจุดที่ค้างไว้ รวมถึงระหว่างขั้นตอนชำระเงิน
- **เก็บโปรไฟล์การเดินทาง** — ความชอบด้านภาษา ผู้ติดต่อฉุกเฉิน ภูมิแพ้ สัตว์เลี้ยง ความต้องการการเข้าถึง และความชอบเกี่ยวกับโรงแรม ห้องพัก อาหาร และส่วนตัว — และเลือกว่าจะแชร์กับที่พักที่จองหรือไม่
- **แชร์ที่พัก** ผ่านลิงก์หรือ QR โค้ดไปยังเครือข่ายสังคมและแอปส่งข้อความสิบห้าแห่ง

อ่านเพิ่มเติมใน [ความชอบการเดินทาง](/th/booking-engine/travel-preferences)

## วิธีที่นักเดินทางเข้าถึงเครื่องมือจอง

ส่วนใหญ่ไม่จำเป็นต้องลิงก์ไปยังเครื่องมือจองโดยตรง ทุกอย่างที่คุณสร้างใน [Portal](/th/portal/overview) — ลิงก์ การ์ด ตาราง และแผนที่ — พร้อมกับสิ่งที่คุณเผยแพร่บน [WinkLinks](/th/portal/link-manager/wink-links) จะมีรหัสลูกค้า รหัสพันธมิตร และแบรนด์ของคุณฝังอยู่แล้ว และพาผู้เดินทางไปยังหน้าที่ถูกต้องพร้อมแผนการเดินทางที่กรอกไว้แล้ว

| สิ่งที่คุณแชร์ | ที่ที่พาผู้เดินทางไป |
| --- | --- |
| [ลิงก์ที่แชร์ได้](/th/portal/studio/shareable-links) | URL สั้น `trvl.as` ที่ขยายเป็นหน้าแลนดิ้งเพจที่มีแบรนด์ของที่พัก พร้อมแผนการเดินทาง สกุลเงิน และภาษาที่ตั้งไว้ล่วงหน้า ใช้ได้เป็นโพสต์บน Facebook, X, WhatsApp หรือที่ใดก็ได้ที่ใช้ URL |
| [การ์ด](/th/portal/studio/cards) | ผู้ให้บริการหรือสินค้าคงคลังที่จองได้เพียงรายการเดียว — โรงแรม ประเภทห้อง สปา ร้านอาหาร `จอง` เปิดขั้นตอนการจอง; `ข้อเสนอที่ดีที่สุด` และ `รายละเอียดโรงแรม` นำไปยังหน้าที่พัก |
| [ตาราง](/th/portal/studio/grids) | ชุดการ์ดที่แบ่งหน้า สร้างจากรายการที่คัดสรร การค้นหาที่บันทึก หรือการค้นหาที่จัดอันดับแบบสด การ์ดแต่ละใบจองได้เหมือนกัน |
| [แผนที่](/th/portal/studio/maps) | แผนที่โต้ตอบที่เครื่องหมายเปิดเป็นการ์ดที่จองได้ |
| [WinkLinks](/th/portal/link-manager/wink-links) | หน้า link-in-bio ของคุณที่โฮสต์ส่วนผสมใด ๆ ข้างต้น อินสตาแกรมถึงการจองในสองคลิก |
| [ปุ่มจองตอนนี้](/th/guides/hoteliers/the-book-now-button) | ปุ่มของเว็บไซต์คุณเอง ชี้ไปยังลิงก์ที่พักที่สร้างอัตโนมัติพร้อมวันที่ การตั้งค่าห้อง ภาษา สกุลเงิน และรหัสโปรโมชั่นเป็นพารามิเตอร์ URL |
| [Web Components](/th/integrations/web-components) | ฝังการ์ด ตาราง แผนที่ การค้นหา และตัวเลือกแผนการเดินทางโดยตรงในหน้าของคุณ การจองจะส่งต่อไปยังเครื่องมือจองหรือเปิดในโมดอล เลือกได้ |
| [ปลั๊กอิน WordPress](/th/integrations/wordpress) | คอมโพเนนต์เดียวกันในรูปแบบ shortcode สำหรับ Gutenberg, Elementor, Avada และ WPBakery |
| [API](/th/api/overview/) | การรวมระบบโดยตรงสำหรับระบบตัวแทนท่องเที่ยวระยะไกลและผู้จัดการช่องทาง |

ไม่ว่าจะเส้นทางใดที่นักเดินทางเลือก พันธมิตรที่ส่งพวกเขาจะถูกบันทึกเพื่อการอ้างอิง — และการอ้างอิงนั้นจะคงอยู่ 180 วัน ดังนั้นการจองที่ทำในครั้งหลังยังคงให้เครดิตพันธมิตรที่แนะนำ

## การทำ Whitelabel

เครื่องมือจองถูกสร้างขึ้นเพื่อซ่อนอยู่เบื้องหลังแบรนด์ของคุณ

ในระดับเบา การ [ปรับแต่ง](/th/portal/settings/branding) จะปรับสไตล์เครื่องมือให้ดูเหมือนของคุณ: ชื่อของคุณ โลโก้ของคุณ สีของคุณ และแบบอักษรของคุณ นักเดินทางยังคงเข้าถึงที่ `book.wink.travel`

ในระดับลึกที่สุด, **พันธมิตรสามารถรันเครื่องมือจองบนโดเมนของตนเองได้** ชี้โดเมนของคุณไปยังเครื่องมือจองและมันจะโหลดการปรับแต่งของคุณโดยอัตโนมัติจากชื่อโฮสต์ — ไม่มีรหัสลูกค้าหรือรหัสการตั้งค่าใน URL ไม่มีโดเมน Wink ในแถบที่อยู่ นักเดินทางจะเห็น `book.yourbrand.com` ตั้งแต่การค้นหาจนถึงการยืนยัน

:::note[การตั้งค่าโดเมนของคุณเอง]
โดเมนที่กำหนดเองจะตั้งค่าด้วยความช่วยเหลือจากเรา ไม่ใช่แบบบริการตนเอง [ติดต่อเรา](/th/contact) พร้อมโดเมนที่คุณต้องการใช้ และเราจะตั้งค่าและเชื่อมต่อกับการปรับแต่งของคุณ
:::

## การปรับแต่ง

ทุกอย่างด้านล่างตั้งค่าต่อการปรับแต่ง และคุณสามารถเก็บหลายรายการ — หนึ่งรายการต่อตลาด ต่อแคมเปญ หรือแต่ละที่พัก

**ตัวตน**

- ชื่อแสดงและแท็กไลน์ที่ต่อท้ายชื่อหน้า
- โลโก้ รวมถึงโลโก้แยกสำหรับอีเมลการจอง

**รูปลักษณ์และความรู้สึก**

- พาเลตสี 11 โทน: หลัก รอง สำเร็จ อันตราย เตือน ข้อมูล สว่าง มืด ตัวเนื้อหา เบาบาง และขาว
- แบบอักษร เลือกจากแบบอักษรที่คัดสรร 20 แบบ
- เค้าโครงหน้า — ข้อมูลหรือธุรกรรม — ซึ่งปรับเปลี่ยนหน้าแรก ส่วนหัว และหน้าที่พัก
- เค้าโครงการ์ด — ตารางแนวตั้งหรือรายการแนวนอน
- สวิตช์สำหรับแถบค้นหา ป้ายอันดับ และการ์ดที่พักที่ไม่พร้อมใช้งาน

ทดสอบการปรับแต่งธีมของคุณในแซนด์บ็อกซ์สำหรับนักพัฒนาของเราด้านล่าง

<LinkButton href="https://developer.wink.travel/web-component" variant="secondary" icon="external" target="_blank">
  ธีม
</LinkButton>

**ค่าปริยายที่นักเดินทางจะเจอ**

- ภาษาและสกุลเงินเริ่มต้น
- แผนการเดินทางที่ตั้งไว้ล่วงหน้า — วันที่คงที่หรือช่วงเวลาที่เลื่อนตาม เช่น "30 วันข้างหน้า 2 คืน"
- การตั้งค่าห้องและรหัสโปรโมชั่นเริ่มต้น
- เมืองเริ่มต้นสำหรับตัวเลือกจุดหมายปลายทาง

**การวัดผลและการรวมระบบ**

- รหัสวัดผล Google Analytics 4 ของคุณเอง คอนเทนเนอร์ Google Tag Manager และพิกเซลติดตาม ทำงานควบคู่กับของ Wink
- กุญแจ API Google Maps ของคุณเอง
- ควบคุมว่าอีเมลแจ้งเตือนการจองจะส่งไปยังที่พัก ผู้จอง และผู้จัดการช่องทางหรือไม่
- ว่าปุ่ม `จอง` ของคอมโพเนนต์ฝังจะส่งต่อไปยังเครื่องมือจองหรือเปิดในโมดอล

สำหรับคำแนะนำทีละช่อง ดูที่ [การปรับแต่ง](/th/portal/settings/branding) และ [การปรับแต่งประสบการณ์การจองของคุณ](/th/guides/general/customizing-your-booking-experience)

## การลิงก์โดยตรง

ถ้าคุณต้องการลิงก์ไปยังเครื่องมือจองด้วยตนเอง ให้เพิ่มรหัสลูกค้าและรหัสการปรับแต่งใน URL เป็นพารามิเตอร์ ทั้งสองอยู่ใน [Portal](/th/portal/overview) บัญชีที่คุณกำลังใช้งาน — ไม่ว่าจะเป็นบัญชีที่พัก บริษัทบริหาร หรือพันธมิตร

### ค้นหารหัสลูกค้าของคุณ

<Steps>
1. เลือกบัญชีที่คุณต้องการทำงานด้วยจาก [Accounts](https://app.wink.travel)
2. คลิกที่ `Actions` ที่ด้านล่างของการ์ดบัญชีและเลือก `Manage account`
3. คลิกแท็บ `Applications` ในหน้าถัดไป
4. คัดลอกรหัสลูกค้าจากแอปพลิเคชันที่คุณต้องการใช้และวางใน URL เป็นพารามิเตอร์คำขอ ตัวอย่าง: ?client-id=MY_CLIENT_ID
</Steps>

ดูเพิ่มเติมที่ [Applications](/th/account/applications) สำหรับการสร้างและจัดการแอปพลิเคชัน

### ค้นหารหัสการปรับแต่งของคุณ

<Steps>
1. เลือกบัญชีที่คุณต้องการทำงานด้วยจาก [Accounts](https://app.wink.travel)
2. คลิกที่ `Actions` ที่ด้านล่างของการ์ดบัญชีและเลือก `Manage account`
3. คลิกแท็บ `Customizations` ในหน้าถัดไป
4. คัดลอกรหัสการปรับแต่งจากการปรับแต่งที่คุณต้องการใช้และวางใน URL เป็นพารามิเตอร์คำขอ ตัวอย่าง: ?configuration-id=MY_CUSTOMIZATION_ID
</Steps>

ดูที่ [การปรับแต่ง](/th/portal/settings/branding) สำหรับรายการเต็มของสิ่งที่การปรับแต่งควบคุม

### รวมกัน

เมื่อลิงก์ไปยังหน้าแรก คุณจะได้ URL ที่มีลักษณะดังนี้:

https://book.wink.travel?client-id=MY_CLIENT_ID&configuration-id=MY_CUSTOMIZATION_ID

หน้าแรกจะแสดงแบรนด์ของคุณและแสดงสินค้าคงคลังที่บัญชีของคุณเป็นตัวแทน — ที่พักของคุณเอง ที่พักที่คุณบริหาร หรือแคตตาล็อกพันธมิตรทั้งหมดของคุณ

ถ้าต้องการส่งผู้เดินทางตรงไปยังที่พักเฉพาะ ให้ลิงก์ไปยังหน้าแลนดิ้งเพจของที่พักแทน:

https://book.wink.travel/hotel/hotel-x?client-id=MY_CLIENT_ID&configuration-id=MY_CUSTOMIZATION_ID

:::note
ถ้าคุณไม่ใส่รหัสลูกค้าหรือรหัสการปรับแต่ง เครื่องมือจองยังโหลดได้ แต่จะใช้การตั้งค่าเริ่มต้น — ดังนั้นผู้เดินทางจะเห็นแบรนด์เริ่มต้นและการจองจะไม่ถูกอ้างอิงถึงคุณ โปรดใส่ทั้งสองอย่างเสมอ
:::
