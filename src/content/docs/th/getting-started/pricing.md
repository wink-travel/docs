Wink ไม่มีการสมัครสมาชิก ไม่มีที่นั่ง และไม่มีค่าธรรมเนียมการตั้งค่า แพลตฟอร์มส่วนใหญ่ใช้งานได้ฟรี และมีเพียงสองอย่างที่คุณจะต้องจ่ายเงิน:

1. **ค่าธรรมเนียมแพลตฟอร์มต่อการจอง รวมถึงค่าธรรมเนียมการประมวลผลบัตรตามต้นทุน** — เฉพาะเมื่อมีการจองเท่านั้น
2. **ค่าธรรมเนียมการใช้งานแบบจ่ายตามการใช้** — สำหรับฟีเจอร์พรีเมียมบางอย่างที่มีค่าใช้จ่ายทุกครั้งที่ใช้งาน โดยแต่ละฟีเจอร์มีโควต้าฟรีรายเดือน

## สิ่งที่ใช้ฟรี

สิ่งเหล่านี้ไม่มีค่าใช้จ่ายตลอดไป ไม่มีโควต้าและไม่มีการวัดการใช้งาน:

- **เครื่องมือจอง** — บนเว็บไซต์ของคุณเอง ในหน้า WinkLinks ของคุณ หรือที่ใดก็ตามที่คุณฝังไว้
- **การจัดการทรัพย์สิน** — เนื้อหา รูปภาพ อัตราค่าบริการ แผนราคา ความพร้อมใช้งาน โปรโมชั่น และนโยบาย
- **เครื่องมือพันธมิตร** — ลิงก์ที่แชร์ได้ รายการที่คัดสรร ตาราง แผนที่ การ์ด และวิดเจ็ตที่ฝังได้
- **เครื่องมือสำหรับตัวแทนท่องเที่ยว** — การค้นหา อัตราพิเศษ และการจองแทนลูกค้าของคุณ
- **WinkLinks** — จดทะเบียน URL ส่วนตัว สร้างหน้า และเผยแพร่ได้บ่อยเท่าที่ต้องการ
- **โพสต์โซเชียลด้วยตนเอง** — ทุกอย่างที่คุณเขียนเอง บนเครือข่ายที่เชื่อมต่อใด ๆ
- **การวิเคราะห์ กระดานผู้นำ การเรียกร้อง การตั้งค่า** และการจัดการบัญชี
- **API สำหรับผู้บริโภคและเครื่องมือจอง** รวมถึงจุดสิ้นสุดสำหรับการค้นหาและเติมข้อความอัตโนมัติ

## การจอง

Wink รองรับสองรูปแบบ: Wink รับชำระเงินแทนโรงแรม และตัวแทนท่องเที่ยวที่ได้รับอนุญาตทำหน้าที่เป็นผู้ค้ารายงาน

### รูปแบบที่ 1 — Wink รับชำระเงินแทนโรงแรม

Wink รับชำระเงินจากแขกในฐานะตัวแทนเก็บเงินจำกัดของโรงแรม โรงแรมเป็นผู้ค้ารายงาน และชื่อโรงแรมจะปรากฏบนใบแจ้งยอดบัตรของแขก
รูปแบบนี้ใช้กับการจอง 95% ของทั้งหมด

#### รายละเอียด

:::note[ค่าธรรมเนียมแพลตฟอร์ม]
Wink เรียกเก็บค่าธรรมเนียมแพลตฟอร์ม 1.5% ต่อการจอง ค่านี้ครอบคลุมการบำรุงรักษาแพลตฟอร์มและทำให้เราสามารถให้บริการฟรีตามที่กล่าวมาข้างต้น ไม่คิดค่าธรรมเนียมสำหรับการจองที่ถูกยกเลิก
:::

:::note[ค่าประมวลผลบัตร]
ค่าธรรมเนียมการประมวลผลการชำระเงินที่เรียกเก็บเพื่อรับเงินจากแขกจะถูกส่งต่อให้โรงแรมตามต้นทุนจริงโดยไม่มีการบวกกำไร ค่าธรรมเนียมนี้ขึ้นอยู่กับบัตรและวิธีการชำระเงินของแขก จำนวนที่แน่นอนจะแสดงในส่วนบัญชีของแต่ละการจอง หากการจองถูกยกเลิกหรือคืนเงิน ค่าธรรมเนียมที่ผู้ประมวลผลเก็บไว้จะยังคงถูกเรียกเก็บ หากไม่มีการเรียกเก็บค่าธรรมเนียม เราก็ไม่คิดค่าธรรมเนียมเช่นกัน
:::

:::note[การโอนเงิน]
มีค่าธรรมเนียมที่เกี่ยวข้องกับการโอนเงินเข้าบัญชีของคุณ ขึ้นอยู่กับวิธีการโอนที่คุณเลือก ปัจจุบันเรารองรับ:

- **การโอนเงินผ่านธนาคาร** — ค่าใช้จ่ายขึ้นอยู่กับประเทศที่คุณอยู่ ต้นทางของเงิน และการแปลงสกุลเงินใด ๆ ที่เกิดขึ้นระหว่างทาง ค่าธรรมเนียมการจ่ายเงินและค่าแปลงสกุลเงินใด ๆ จะถูกจ่ายโดยผู้รับเงินตามต้นทุน เรามีเครื่องมือคำนวณราคาให้คุณใช้เมื่อมีเงินในบัญชีของคุณ

หากคุณต้องการให้เรารองรับวิธีการจ่ายเงินอื่น โปรดส่งอีเมลหาเรา
:::

### รูปแบบที่ 2 — ตัวแทนท่องเที่ยวเป็นผู้ค้ารายงาน

รูปแบบนี้ใช้ได้เฉพาะกับตัวแทนท่องเที่ยวที่มีใบอนุญาตตัวแทนท่องเที่ยวในภูมิภาคของตนและต้องการเป็นผู้ค้ารายงาน ตัวแทนท่องเที่ยวที่ลงทะเบียนบางรายต้องการรับผิดชอบในการจัดการการชำระเงินและการโอนเงินให้โรงแรม ภายใต้รูปแบบนี้ พวกเขารับผิดชอบเงินและมีใบอนุญาตที่จำเป็นในการดำเนินงานในประเทศของตน

#### รายละเอียด

:::note[ค่าธรรมเนียมแพลตฟอร์ม]
Wink เรียกเก็บค่าธรรมเนียมแพลตฟอร์ม 1.5% ต่อการจอง ค่านี้ครอบคลุมการบำรุงรักษาแพลตฟอร์มและทำให้เราสามารถให้บริการฟรีตามที่กล่าวมาข้างต้น
:::

ในรูปแบบนี้ ตัวแทนท่องเที่ยวจ่ายเฉพาะค่าธรรมเนียมแพลตฟอร์มของ Wink เท่านั้น และ Wink จะออกใบแจ้งหนี้ให้ตัวแทนท่องเที่ยวเป็นรายเดือน

## การใช้งาน (จ่ายตามการใช้)

ฟีเจอร์บางอย่างมีค่าใช้จ่ายทุกครั้งที่ใช้งาน — เช่น AI สร้างสรรค์, API โซเชียลของบุคคลที่สาม และการให้บริการราคาสดในระดับใหญ่ แทนที่จะรวมไว้ในแผนรายเดือนที่คุณอาจไม่ได้ใช้ คุณจ่ายเฉพาะสิ่งที่ใช้จริง และหลังจากใช้โควต้าฟรีรายเดือนหมดแล้วเท่านั้น

### วิธีการคิดราคาโพสต์

โพสต์จะคิดราคาตามเนื้อหาภายใน เพราะนั่นคือสิ่งที่มีค่าใช้จ่ายสำหรับเรา รูปภาพนิ่งราคาถูก วิดีโอราคาแพงกว่า และสื่อที่สร้างด้วย AI มีต้นทุนสูงกว่ารูปภาพที่คุณจัดหาเองอย่างมีนัยสำคัญ

- **โควต้าฟรีครอบคลุมเฉพาะโพสต์รูปภาพมาตรฐานเท่านั้น** คุณจะได้รับหนึ่งโพสต์ต่อบัญชีต่อเดือน โพสต์วิดีโอและสื่อที่สร้างด้วย AI จะถูกคิดเงินตั้งแต่โพสต์แรก — ไม่มีโควต้าฟรีในระดับนี้ ดังนั้นทรัพย์สินที่โพสต์วิดีโอควรคาดหวังค่าธรรมเนียมในเดือนแรก
- **วิดีโอมีสิทธิ์เหนือกว่า** หากโพสต์มีวิดีโอแม้เพียงเล็กน้อย โพสต์ทั้งหมดจะถูกคิดราคาตามอัตราวิดีโอ โพสต์ที่ผสมรูปภาพและวิดีโอถือเป็นโพสต์วิดีโอ
- **แหล่งที่มาของ AI กำหนดระดับราคา** สื่อที่คุณจัดหาเอง — รูปภาพและวิดีโอของคุณ หรือสื่อใด ๆ จากคลังเนื้อหาของ Wink — จะคิดราคาตามอัตรามาตรฐาน สื่อที่เราสร้างให้คุณจะคิดราคาตามอัตรา AI

### สิ่งที่ถูกและไม่ถูกวัดการใช้งาน

- เฉพาะโพสต์ที่ **สร้างขึ้นโดย AI** และเผยแพร่ไปยังเครือข่ายบุคคลที่สาม (Facebook, Instagram) เท่านั้นที่คิดเงิน โพสต์ที่คุณเขียนเองฟรีไม่ว่าจะแพร่ภาพที่ไหน
- **การเผยแพร่ไปยัง WinkLinks ฟรีเสมอ** ไม่ว่าจะสร้างโดย AI หรือไม่ก็ตาม
- คุณถูกเรียกเก็บเงิน **เมื่อเผยแพร่** ไม่ใช่ต่อความพยายาม การสร้างร่างใหม่จนกว่าจะพอใจไม่เพิ่มค่าใช้จ่าย — คุณจ่ายครั้งเดียวสำหรับโพสต์ที่เผยแพร่จริง ความพยายามไม่ใช่ไม่จำกัด: แต่ละโพสต์อนุญาตให้สร้างใหม่ประมาณ 10 ครั้งสำหรับรูปภาพ และ 3 ครั้งสำหรับวิดีโอ ซึ่งสะท้อนต้นทุนการผลิต คุณจะเห็นจำนวนที่เหลือขณะทำงาน
- สำหรับ API พันธมิตร, **โรงแรม-วัน** หมายถึงโรงแรมหนึ่งแห่งที่มีราคาสำหรับการเข้าพักหนึ่งคืน — *ไม่ใช่* การเรียก API หนึ่งครั้ง การค้นหาที่คืนผลลัพธ์ 20 โรงแรมสำหรับการเข้าพัก 3 คืน คือ 60 โรงแรม-วันจากคำขอเดียว จุดสิ้นสุดการค้นหาและเติมข้อความอัตโนมัติฟรีและไม่ถูกวัด

### การเปิดใช้งาน

การใช้งานแบบจ่ายตามการใช้ถูกปิดโดยค่าเริ่มต้น ทุกคนได้รับโควต้าฟรีโดยไม่ต้องทำอะไร

เพื่อใช้เกินโควต้า **เจ้าของ** บัญชีต้องเปิดใช้งานการใช้งานแบบจ่ายตามการใช้และเลือกบัญชีที่ต้องการวัดการใช้งาน การใช้งานจากบัญชีที่เปิดใช้งานทั้งหมดจะถูกรวมใน **ใบแจ้งหนี้รายเดือนฉบับเดียว** ซึ่งคุณสามารถชำระเงินอัตโนมัติด้วยบัตรหรือรับใบแจ้งหนี้เพื่อชำระเอง

เมื่อเปิดใช้งาน การใช้งานของคุณจะถูกวัดแต่ **ไม่ถูกจำกัดความเร็ว** — คุณจะไม่ถูกจำกัดอัตราการใช้จ่ายกับเรา

:::note[ถ้าคุณไม่เปิดใช้งาน]
ไม่มีอะไรเสียหายและไม่มีการเรียกเก็บเงิน คุณจะหยุดที่โควต้าฟรีของเดือนนั้น: โพสต์ที่สร้างโดย AI จะไม่เผยแพร่ และการเรียก API พันธมิตรจะคืนค่า `429` จนกว่าโควต้าจะรีเซ็ต
:::

## ผลกระทบของแพลตฟอร์ม

สุดท้าย เมื่อเราเติบโตทั้งในขนาดและจำนวนการจอง เราต้องการแบ่งปันผลกระทบบางส่วนของแพลตฟอร์มกับคุณ การจองที่มากขึ้นนำไปสู่โอกาสในการรับส่วนลดปริมาณจากผู้ประมวลผลการชำระเงิน เนื่องจากค่าธรรมเนียมการประมวลผลบัตรถูกส่งต่อโดยตรงตามต้นทุน การประหยัดใด ๆ ที่เราต่อรองได้จะถูกส่งต่อไปยังโรงแรมโดยตรง

เข้าร่วม Wink วันนี้และค้นพบวิธีใหม่ที่ทำกำไรได้ในการทำธุรกิจในอุตสาหกรรมการบริการ!
