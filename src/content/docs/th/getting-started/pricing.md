Wink ไม่มีการสมัครสมาชิก ไม่มีที่นั่ง และไม่มีค่าติดตั้ง แพลตฟอร์มส่วนใหญ่ใช้ฟรี และมีเพียงสองอย่างที่คุณจะต้องจ่ายเงิน:

1. **ค่าธรรมเนียมแพลตฟอร์มต่อการจอง รวมถึงค่าธรรมเนียมการประมวลผลบัตรตามต้นทุน** — เฉพาะเมื่อมีการจองเท่านั้น
2. **ค่าธรรมเนียมการใช้งานแบบจ่ายตามจริง** — สำหรับฟีเจอร์พรีเมียมบางอย่างที่มีค่าใช้จ่ายทุกครั้งที่ใช้งาน โดยแต่ละฟีเจอร์มีโควต้าฟรีรายเดือน

## สิ่งที่ใช้ฟรี

สิ่งเหล่านี้ไม่มีค่าใช้จ่ายตลอดไป ไม่มีโควต้าและไม่มีการวัดการใช้งาน:

- **เครื่องมือจอง** — บนเว็บไซต์ของคุณเอง ในหน้าของ WinkLinks หรือที่ใดก็ตามที่คุณฝังไว้
- **การจัดการทรัพย์สิน** — เนื้อหา รูปภาพ ราคา แผนราคา ความพร้อมใช้งาน โปรโมชั่น และนโยบาย
- **เครื่องมือพันธมิตร** — ลิงก์ที่แชร์ได้ รายการคัดสรร ตาราง แผนที่ การ์ด และวิดเจ็ตฝังได้
- **เครื่องมือสำหรับตัวแทนท่องเที่ยว** — การค้นหา ราคาเฉพาะ และการจองแทนลูกค้าของคุณ
- **WinkLinks** — จดทะเบียน URL ส่วนตัว สร้างหน้า และเผยแพร่ได้บ่อยเท่าที่ต้องการ
- **โพสต์โซเชียลด้วยตนเอง** — ทุกอย่างที่คุณเขียนเอง บนเครือข่ายที่เชื่อมต่อใดๆ
- **การวิเคราะห์ กระดานผู้นำ การเรียกร้อง การตั้งค่า** และการจัดการบัญชี
- **API สำหรับผู้บริโภคและเครื่องมือจอง** รวมถึงจุดสิ้นสุดการค้นหาและเติมข้อความอัตโนมัติ สำหรับ **Partner API** การเรียก Lookup และ Content จะถูกวัดเป็นหน่วยละหนึ่ง (ดู [การใช้งาน](#what-is-and-isnt-metered) ด้านล่าง)

## การจอง

Wink รองรับสองรูปแบบ: Wink รับชำระเงินสำหรับโรงแรม และตัวแทนท่องเที่ยวที่ได้รับอนุญาตทำหน้าที่เป็นผู้ค้ารายการ

### รูปแบบที่ 1 — Wink รับชำระเงินแทนโรงแรม

Wink รับชำระเงินจากแขกในฐานะตัวแทนเก็บเงินจำกัดของโรงแรม โรงแรมเป็นผู้ค้ารายการ และชื่อโรงแรมจะปรากฏบนใบแจ้งยอดบัตรของแขก
รูปแบบนี้ใช้กับการจอง 95% ของทั้งหมด

#### รายละเอียด

:::note[ค่าธรรมเนียมแพลตฟอร์ม]
Wink เรียกเก็บค่าธรรมเนียมแพลตฟอร์ม 1.5% ต่อการจอง ค่านี้ครอบคลุมการบำรุงรักษาแพลตฟอร์มและทำให้เราสามารถให้บริการฟรีตามที่ระบุไว้ข้างต้น ไม่คิดค่าธรรมเนียมสำหรับการจองที่ถูกยกเลิก
:::

:::note[ค่าประมวลผลบัตร]
ค่าธรรมเนียมการประมวลผลการชำระเงินที่เรียกเก็บเพื่อรับเงินจากแขกจะถูกส่งต่อให้โรงแรมตามต้นทุนโดยไม่มีการบวกกำไร ค่าธรรมเนียมนี้ขึ้นอยู่กับบัตรและวิธีการชำระเงินของแขก จำนวนที่แน่นอนจะแสดงในส่วนบัญชีของแต่ละการจอง หากการจองถูกยกเลิกหรือคืนเงิน ค่าธรรมเนียมที่ผู้ประมวลผลเก็บไว้จะยังคงถูกเรียกเก็บ หากไม่มีการเรียกเก็บค่าธรรมเนียม เราก็ไม่คิดค่าธรรมเนียมเช่นกัน
:::

:::note[การโอนเงิน]
มีค่าธรรมเนียมที่เกี่ยวข้องกับการโอนเงินเข้าบัญชีของคุณ ขึ้นอยู่กับวิธีการโอนที่คุณเลือก ปัจจุบันเรารองรับ:

- **การโอนเงินผ่านธนาคาร** — ค่าใช้จ่ายขึ้นอยู่กับประเทศที่คุณอยู่ ต้นทางของเงิน และการแปลงสกุลเงินที่อาจเกิดขึ้น ค่าธรรมเนียมการจ่ายเงินและค่าแปลงสกุลเงินจ่ายโดยผู้รับเงินตามต้นทุน เรามีเครื่องมือคำนวณราคาให้ใช้เมื่อคุณมีเงินในบัญชี

หากคุณต้องการให้เรารองรับวิธีการจ่ายเงินอื่น โปรดส่งอีเมลหาเรา
:::

### รูปแบบที่ 2 — ตัวแทนท่องเที่ยวเป็นผู้ค้ารายการ

รูปแบบนี้ใช้ได้เฉพาะกับตัวแทนท่องเที่ยวที่มีใบอนุญาตตัวแทนท่องเที่ยวในภูมิภาคของตนและต้องการเป็นผู้ค้ารายการ ใช้ได้เฉพาะกับพันธมิตร API ที่จองผ่าน [Partner API](/th/integrations/partner-api/) และต้องได้รับการอนุมัติเป็นลายลักษณ์อักษรจาก Wink ตัวแทนท่องเที่ยวที่ลงทะเบียนบางรายต้องการรับผิดชอบการจัดการชำระเงินและการจ่ายเงินให้โรงแรม ภายใต้รูปแบบนี้ พวกเขารับผิดชอบเงินและมีใบอนุญาตที่จำเป็นในการดำเนินงานในประเทศของตน

#### รายละเอียด

:::note[ค่าธรรมเนียมแพลตฟอร์ม]
Wink เรียกเก็บค่าธรรมเนียมแพลตฟอร์ม 1.5% ต่อการจอง ค่านี้ครอบคลุมการบำรุงรักษาแพลตฟอร์มและทำให้เราสามารถให้บริการฟรีตามที่ระบุไว้ข้างต้น
:::

ในรูปแบบนี้ ตัวแทนท่องเที่ยวจ่ายค่าธรรมเนียม 1.5% ของ Wink รวมถึงค่าการใช้งาน Partner API ที่เกินโควต้าฟรี โดยจะออกใบแจ้งหนี้รายเดือน

## สิ่งที่พันธมิตรต้องจ่าย

สำหรับพันธมิตรที่ส่งการจอง: ผู้สร้าง, พันธมิตร, แพลตฟอร์ม, นักพัฒนา และตัวแทนท่องเที่ยว ความร่วมมือไม่ผูกขาด ไม่มีเขตพื้นที่

| | รับชำระเงินสำหรับโรงแรม (พันธมิตรส่วนใหญ่) | คุณเป็นผู้ค้ารายการ (พันธมิตร API เท่านั้น) |
|---|---|---|
| ค่าลิขสิทธิ์หรือค่าพื้นที่ | ไม่มี | ไม่มี |
| ค่าติดตั้ง | ไม่มี | ไม่มี |
| ค่าสมาชิกหรือค่ารายเดือน | ไม่มี | ไม่มี |
| ข้อผูกมัดขั้นต่ำหรือระยะเวลา | ไม่มี | ไม่มี มีวงเงินเครดิต |
| การเข้าถึง Partner API | 10,000 คืนโรงแรมต่อเดือนฟรี จากนั้น $0.0001 ต่อคืนโรงแรม จ่ายตามการใช้งานปิดโดยค่าเริ่มต้น; เมื่อถึงโควต้าฟรี การเรียกจะคืน `429` | เหมือนกัน |
| ค่าธรรมเนียมธุรกรรม | ไม่มี คุณได้รับค่าคอมมิชชั่น (10% เริ่มต้น) | ค่าธรรมเนียมการจอง 1.5% ของมูลค่าการจอง ออกใบแจ้งหนี้รายเดือนเป็น USD ชำระภายใน 15 วัน หากเปิดใช้งานจ่ายตามการใช้งาน การใช้งาน Partner API จะออกใบแจ้งหนี้แยกรายเดือน |
| ค่าบริการสนับสนุน | ไม่มี | ไม่มี |
| ค่าธรรมเนียมอื่นๆ | ค่าธรรมเนียมการโอนจ่ายตามต้นทุน | อาจมีการชำระเงินล่วงหน้าหรือเงินมัดจำเมื่ออนุมัติ ดอกเบี้ย 1.5% ต่อเดือนสำหรับใบแจ้งหนี้ค้างชำระเท่านั้น |
| เมื่อค่าธรรมเนียมเปลี่ยนแปลง | แจ้งล่วงหน้า 30 วัน; ใช้กับการจองที่ทำหลังการเปลี่ยนแปลงเท่านั้น | เหมือนกัน Wink อาจปรับวงเงินเครดิตของคุณโดยแจ้งล่วงหน้า |

เส้นทางผู้ค้ารายการต้องได้รับการอนุมัติเป็นลายลักษณ์อักษรจาก Wink ดู [รูปแบบที่ 2](#model-2--travel-agent-as-merchant-of-record) ข้างต้นและหน้า [Partner API](/th/integrations/partner-api/)

## การใช้งาน (จ่ายตามจริง)

ฟีเจอร์บางอย่างมีค่าใช้จ่ายทุกครั้งที่ใช้งาน — AI สร้างเนื้อหา, API โซเชียลของบุคคลที่สาม และการให้บริการราคาสดในระดับใหญ่ แทนที่จะรวมไว้ในแผนรายเดือนที่คุณอาจไม่ใช้ คุณจ่ายเฉพาะสิ่งที่ใช้จริง และหลังจากใช้โควต้าฟรีรายเดือนหมดแล้วเท่านั้น

| ฟีเจอร์ | ฟรีต่อเดือน | จากนั้น | หน่วยคิดเงิน |
| -- | -- | -- | -- |
| โพสต์โซเชียล — รูปภาพ | 1 | $1.50 | โพสต์ที่เผยแพร่หนึ่งโพสต์ |
| โพสต์โซเชียล — รูปภาพที่สร้างโดย AI | 0 | $2.50 | โพสต์ที่เผยแพร่หนึ่งโพสต์ |
| โพสต์โซเชียล — วิดีโอที่ปรับปรุงโดย AI | 0 | $4.00 | โพสต์ที่เผยแพร่หนึ่งโพสต์ |
| โพสต์โซเชียล — วิดีโอที่สร้างโดย AI | 0 | $14.00 | โพสต์ที่เผยแพร่หนึ่งโพสต์ |
| ตอบกลับด้วย AI ต่อคอมเมนต์หรือ DM | 5 | $0.05 | การตอบกลับหนึ่งครั้ง |

### วิธีคิดราคาโพสต์

โพสต์คิดราคาตามเนื้อหาภายใน เพราะนั่นคือสิ่งที่มีค่าใช้จ่ายสำหรับเราที่จะสร้าง รูปภาพนิ่งราคาถูก วิดีโอราคาแพงกว่า และสื่อที่สร้างด้วย AI มีค่าใช้จ่ายมากกว่ารูปภาพที่คุณจัดหาเองอย่างมีนัยสำคัญ

- **โควต้าฟรีครอบคลุมเฉพาะโพสต์รูปภาพมาตรฐานเท่านั้น** คุณจะได้รับหนึ่งโพสต์ต่อบัญชีต่อเดือน โพสต์วิดีโอและสื่อที่สร้างด้วย AI จะถูกคิดเงินตั้งแต่โพสต์แรก — ไม่มีโควต้าฟรีในระดับนี้ ดังนั้นทรัพย์สินที่โพสต์วิดีโอควรคาดว่าจะมีค่าใช้จ่ายในเดือนแรก
- **วิดีโอมีสิทธิ์เหนือกว่า** หากโพสต์มีวิดีโอแม้เพียงเล็กน้อย โพสต์ทั้งหมดจะถูกคิดราคาตามอัตราวิดีโอ โพสต์ที่ผสมรูปภาพและวิดีโอถือเป็นโพสต์วิดีโอ
- **แหล่งที่มาของ AI กำหนดระดับราคา** สื่อที่คุณจัดหาเอง — รูปภาพและวิดีโอของคุณ หรือสื่อจากคลังเนื้อหาของ Wink — คิดราคาตามอัตรามาตรฐาน สื่อที่เราสร้างให้คุณคิดราคาตามอัตรา AI

### สิ่งที่ถูกและไม่ถูกวัด

- เฉพาะโพสต์ที่ **สร้างขึ้น** และเผยแพร่ไปยังเครือข่ายบุคคลที่สาม (Facebook, Instagram) เท่านั้นที่คิดเงิน โพสต์ที่คุณเขียนเองฟรี ไม่ว่าจะเผยแพร่ที่ไหน
- **การเผยแพร่ไปยัง WinkLinks ฟรีเสมอ** ไม่ว่าจะสร้างขึ้นหรือไม่
- คุณถูกเรียกเก็บเงิน **เมื่อเผยแพร่** ไม่ใช่ต่อความพยายาม การสร้างร่างซ้ำจนกว่าจะพอใจไม่เพิ่มค่าใช้จ่าย — คุณจ่ายครั้งเดียวสำหรับโพสต์ที่เผยแพร่จริง ความพยายามไม่จำกัด แต่ละโพสต์อนุญาตให้สร้างซ้ำประมาณ 10 ครั้งสำหรับรูปภาพ และ 3 ครั้งสำหรับวิดีโอ ซึ่งสะท้อนต้นทุนการผลิต คุณจะเห็นจำนวนที่เหลือขณะทำงาน
- บน Partner API, **คืนโรงแรม** หมายถึงโรงแรมหนึ่งแห่งที่มีราคาสำหรับการเข้าพักหนึ่งคืน — *ไม่ใช่* การเรียก API หนึ่งครั้ง การค้นหาที่คืนผลลัพธ์ 20 โรงแรมสำหรับการเข้าพัก 3 คืน คือ 60 คืนโรงแรมจากคำขอเดียว การเรียก Content และ Lookup (การค้นหาปลายทางและเติมข้อความอัตโนมัติ) คิดเป็นหนึ่งหน่วยต่อการเรียก ไม่ว่าจะคืนข้อมูลเท่าใด จุดสิ้นสุดบัญชีฟรี

### การเปิดใช้งาน

การใช้งานแบบจ่ายตามจริงปิดโดยค่าเริ่มต้น ทุกคนได้รับโควต้าฟรีโดยไม่ต้องทำอะไร

เพื่อใช้เกินโควต้า **เจ้าของ** บัญชีต้องเปิดใช้งานการใช้งานแบบจ่ายตามจริงและเลือกบัญชีที่ต้องการวัดการใช้งาน การใช้งานจากบัญชีที่เปิดใช้งานทั้งหมดจะถูกรวมใน **ใบแจ้งหนี้รายเดือนฉบับเดียว** ซึ่งคุณสามารถชำระอัตโนมัติด้วยบัตรหรือรับใบแจ้งหนี้ไปชำระเอง

เมื่อเปิดใช้งาน การใช้งานของคุณจะถูกวัดแต่ **ไม่ถูกจำกัดความเร็ว** — คุณจะไม่ถูกจำกัดอัตราการใช้จ่ายกับเรา

:::note[ถ้าคุณไม่เปิดใช้งาน]
ไม่มีอะไรเสียหายและไม่มีการเรียกเก็บเงิน คุณจะหยุดที่โควต้าฟรีของเดือนนั้น: โพสต์ที่สร้างขึ้นจะไม่เผยแพร่ และการเรียก Partner API จะคืน `429` จนกว่าโควต้าจะรีเซ็ต
:::

### สถานะการเรียกเก็บเงิน

| สถานะ | ความหมาย |
| -- | -- |
| สถานะดี | ทุกอย่างทำงานปกติ |
| ค้างชำระ | การชำระเงินล้มเหลวและกำลังพยายามใหม่ ฟีเจอร์ของคุณยังทำงานในช่วงนี้ |
| ระงับ | ใบแจ้งหนี้ไม่ได้ชำระจนหมด การดำเนินการที่ต้องเรียกเก็บเงินถูกบล็อกจนกว่าจะชำระ ฟีเจอร์ฟรียังทำงานตามปกติ |

:::tip[ราคาสด]
ราคาต่อหน่วยและโควต้าฟรีจะแสดงใน Portal โดยตรงจากระบบเรียกเก็บเงินของเรา เพื่อให้คุณตรวจสอบก่อนตัดสินใจ ดู [Billing](/th/portal/plan) เพื่อเปิดใช้งานจ่ายตามจริง เลือกบัญชี และติดตามการใช้งานและใบแจ้งหนี้รายเดือน ดู [Social](/th/portal/social/what-is-social) เพื่อดูว่าปริมาณโพสต์ส่งผลต่อค่าใช้จ่ายอย่างไร
:::

## ผลกระทบของแพลตฟอร์ม

สุดท้าย เมื่อเราเติบโตทั้งในขนาดและจำนวนการจอง เราต้องการแบ่งปันผลกระทบบางส่วนของแพลตฟอร์มกับคุณ การจองที่มากขึ้นนำไปสู่โอกาสในการรับส่วนลดปริมาณจากผู้ประมวลผลการชำระเงิน เนื่องจากค่าธรรมเนียมการประมวลผลบัตรถูกส่งต่อโดยตรงตามต้นทุน การประหยัดใดๆ ที่เราต่อรองได้จะถูกส่งต่อไปยังโรงแรมโดยตรง

เข้าร่วม Wink วันนี้และค้นพบวิธีใหม่ที่ทำกำไรได้ในการทำธุรกิจในอุตสาหกรรมการบริการ!
