Wink ไม่มีการสมัครสมาชิก ไม่มีที่นั่ง และไม่มีค่าธรรมเนียมการตั้งค่า แพลตฟอร์มส่วนใหญ่ใช้ฟรี และมีเพียงสองสิ่งที่คุณจะต้องจ่ายเท่านั้น:

1. **เปอร์เซ็นต์เล็กน้อยต่อการจอง** — เฉพาะเมื่อคุณทำเงินได้จริงเท่านั้น
2. **ค่าธรรมเนียมการใช้งานแบบจ่ายตามจริง** — สำหรับฟีเจอร์พรีเมียมบางอย่างที่มีค่าใช้จ่ายทุกครั้งที่ใช้งาน โดยแต่ละฟีเจอร์มีโควต้าใช้ฟรีรายเดือน

## สิ่งที่ใช้ฟรี

สิ่งเหล่านี้ไม่มีค่าใช้จ่ายตลอดไป ไม่มีโควต้าและไม่มีการวัดการใช้งาน:

- **เครื่องมือจอง** — บนเว็บไซต์ของคุณเอง ในหน้า WinkLinks ของคุณ หรือที่ใดก็ตามที่คุณฝังมันไว้
- **การจัดการทรัพย์สิน** — เนื้อหา รูปภาพ อัตราค่าบริการ แผนราคา ความพร้อมใช้งาน โปรโมชั่น และนโยบายต่างๆ
- **เครื่องมือพันธมิตร** — ลิงก์ที่แชร์ได้ รายการที่คัดสรร ตาราง แผนที่ การ์ด และวิดเจ็ตที่ฝังได้
- **เครื่องมือสำหรับตัวแทนท่องเที่ยว** — การค้นหา อัตราพิเศษ และการจองแทนลูกค้าของคุณ
- **WinkLinks** — ขอรับ URL ส่วนตัว สร้างหน้า และเผยแพร่ได้บ่อยเท่าที่ต้องการ
- **โพสต์โซเชียลด้วยตนเอง** — ทุกอย่างที่คุณเขียนเอง บนเครือข่ายที่เชื่อมต่อใดๆ
- **การวิเคราะห์ กระดานผู้นำ การเรียกร้อง การตั้งค่า** และการจัดการบัญชี
- **API สำหรับผู้บริโภคและเครื่องมือจอง** รวมถึงจุดสิ้นสุดสำหรับการค้นหาและเติมข้อความอัตโนมัติ

## การจอง

Wink รองรับทั้งโมเดลผู้ค้าและตัวแทน

### โมเดล 1

Wink เป็นผู้ค้ารายงานในเวลาที่เกิดการจอง Wink รับผิดชอบเงินทุนและถือใบอนุญาตทั้งหมดที่จำเป็นในการดำเนินการเป็นตัวแทนท่องเที่ยว
โมเดลนี้ใช้กับ 95% ของการจองทั้งหมด

Wink เรียกเก็บค่าธรรมเนียม `5.5% ต่อการจอง` เพื่อดูแลแพลตฟอร์ม
ส่วนใหญ่ของค่านี้ไปยังเกตเวย์การชำระเงิน (Visa, MasterCard ฯลฯ) การจองเฉลี่ยมีค่าใช้จ่าย `2.95%` สำหรับเรา บางครั้งสูงถึง `3.6%` การคืนเงินบางส่วนทำให้เราต้องเสียค่าใช้จ่ายเพิ่มเพราะเกตเวย์การชำระเงินมองว่าเป็นการเรียกเก็บเงินใหม่
เราต้องการความโปร่งใสเกี่ยวกับราคาตั้งแต่ตอนนี้เพื่อประหยัดเวลาทุกคนก่อนที่จะพยายามเจรจาส่วนลดเพิ่มเติมก่อนใช้ Wink ราคาของเราเป็นธรรมมากและเราก็ต้องทำมาหากินด้วยเช่นกัน

#### การแจกแจง

:::note[ค่าธรรมเนียมการประมวลผล]
Wink เรียกเก็บค่าธรรมเนียมการประมวลผล 1.5% ต่อการจอง ค่านี้ครอบคลุมการดูแลแพลตฟอร์มและเป็นเหตุผลที่เราสามารถให้บริการฟรีตามที่กล่าวไว้ข้างต้น
:::

:::note[ค่าธรรมเนียมการชำระเงิน]
TripPay เรียกเก็บค่าธรรมเนียมการชำระเงิน 4.0% ต่อการจอง ค่านี้ครอบคลุมการรับเงินจากนักเดินทาง
:::

:::note[การโอนเงิน]
มีค่าธรรมเนียมที่เกี่ยวข้องกับการโอนเงินเข้าบัญชีของคุณ ขึ้นอยู่กับวิธีการโอนที่คุณเลือก ปัจจุบันเรารองรับ:

- **การโอนเงินผ่านธนาคาร** ค่าใช้จ่ายขึ้นอยู่กับประเทศที่คุณอยู่และที่มาของเงิน เรามีเครื่องมือคำนวณราคาให้คุณใช้เมื่อมีเงินในบัญชีของคุณ

หากคุณต้องการให้เรารองรับวิธีการจ่ายเงินอื่น โปรดส่งอีเมลหาเรา
:::

### โมเดล 2

โมเดลนี้ใช้ได้เฉพาะกับตัวแทนท่องเที่ยวที่มีใบอนุญาตตัวแทนท่องเที่ยวในภูมิภาคของตนและต้องการเป็นผู้ค้ารายงาน ตัวแทนท่องเที่ยวที่ลงทะเบียนบางรายต้องการรับผิดชอบการจัดการการชำระเงินและการโอนเงินให้กับโรงแรม ภายใต้โมเดลนี้ พวกเขารับผิดชอบเงินทุนและถือใบอนุญาตที่จำเป็นในการดำเนินงานในประเทศของตน

#### การแจกแจง

:::note[ค่าธรรมเนียมการประมวลผล]
Wink เรียกเก็บค่าธรรมเนียมการประมวลผล 1.5% ต่อการจอง ค่านี้ครอบคลุมการดูแลแพลตฟอร์มและเป็นเหตุผลที่เราสามารถให้บริการฟรีตามที่กล่าวไว้ข้างต้น
:::

ในโมเดลนี้ ตัวแทนท่องเที่ยวจะจ่ายเฉพาะค่าธรรมเนียมการประมวลผลของ Wink เท่านั้น และ Wink จะออกใบแจ้งหนี้ให้ตัวแทนท่องเที่ยวเป็นรายเดือน

## การใช้งาน (จ่ายตามจริง)

### วิธีการคิดราคาโพสต์

โพสต์คิดราคาตามเนื้อหาภายใน เพราะนั่นคือสิ่งที่มีค่าใช้จ่ายสำหรับเรา รูปภาพนิ่งราคาถูก วิดีโอราคาแพงกว่า และสื่อที่สร้างโดย AI มีต้นทุนสูงกว่ารูปภาพที่คุณจัดหาเองอย่างมีนัยสำคัญ

- **โควต้าฟรีครอบคลุมเฉพาะโพสต์รูปภาพมาตรฐานเท่านั้น** คุณจะได้รับหนึ่งโพสต์ต่อบัญชีต่อเดือน โพสต์วิดีโอและสื่อที่สร้างโดย AI จะถูกคิดเงินตั้งแต่โพสต์แรก — ไม่มีโควต้าฟรีในระดับนี้ ดังนั้นทรัพย์สินที่โพสต์วิดีโอควรคาดว่าจะมีค่าใช้จ่ายในเดือนแรก
- **วิดีโอมีสิทธิ์เหนือกว่า** หากโพสต์มีวิดีโอแม้เพียงเล็กน้อย โพสต์ทั้งหมดจะถูกคิดราคาตามอัตราวิดีโอ โพสต์ที่ผสมรูปภาพและวิดีโอถือเป็นโพสต์วิดีโอ
- **แหล่งที่มาของ AI กำหนดระดับราคา** สื่อที่คุณจัดหาเอง — รูปภาพและวิดีโอของคุณ หรือสื่อจากไลบรารีเนื้อหาของ Wink — จะคิดราคาตามอัตรามาตรฐาน สื่อที่เราสร้างให้คุณจะคิดราคาตามอัตรา AI

### สิ่งที่ถูกและไม่ถูกวัดการใช้งาน

- เฉพาะโพสต์ที่ **สร้างโดย AI** และเผยแพร่ไปยังเครือข่ายบุคคลที่สาม (Facebook, Instagram) เท่านั้นที่ถูกคิดเงิน โพสต์ที่คุณเขียนเองฟรีไม่ว่าที่ใดก็ตาม
- **การเผยแพร่ไปยัง WinkLinks ฟรีเสมอ** ไม่ว่าจะสร้างโดย AI หรือไม่ก็ตาม
- คุณถูกคิดเงิน **เมื่อเผยแพร่** ไม่ใช่ต่อความพยายาม การสร้างร่างซ้ำจนกว่าจะพอใจไม่เพิ่มค่าใช้จ่าย — คุณจ่ายครั้งเดียวสำหรับโพสต์ที่เผยแพร่จริง ความพยายามไม่จำกัด แต่ละโพสต์อนุญาตให้สร้างซ้ำประมาณ 10 ครั้งสำหรับรูปภาพ และ 3 ครั้งสำหรับวิดีโอ ซึ่งสะท้อนต้นทุนการผลิต คุณจะเห็นจำนวนที่เหลือขณะทำงาน
- ใน API พันธมิตร หน่วยคือ **โรงแรม-วัน** คือโรงแรมหนึ่งแห่งที่มีราคาสำหรับคืนหนึ่งคืน — *ไม่ใช่* การเรียก API หนึ่งครั้ง การค้นหาที่คืนผลลัพธ์ 20 โรงแรมสำหรับการเข้าพัก 3 คืน คือ 60 โรงแรม-วันจากคำขอเดียว จุดสิ้นสุดการค้นหาและเติมข้อความอัตโนมัติฟรีและไม่ถูกวัด
- ใน **API สื่อพันธมิตร** หน่วยคือโรงแรมหนึ่งแห่งที่ส่งสื่อกลับมาให้คุณ ไม่ว่าจะเป็นรูปภาพหรือวิดีโอจำนวนเท่าใดก็ตาม คำขอแบบกลุ่มสำหรับ 50 โรงแรมคือ 50 หน่วย — และถ้าโรงแรมบางแห่งไม่มีสื่อที่คุณมีสิทธิ์ดู คุณจะถูกคิดเงินเฉพาะโรงแรมที่ส่งสื่อกลับมาเท่านั้น

### ตัวอย่าง: OTA ที่เก็บข้อมูลราคาล่วงหน้า 90 วัน

สมมติว่าคุณเป็น OTA เว็บไซต์เมตาเสิร์ช หรือผู้ประกอบการทัวร์ และต้องการราคาล่วงหน้า 90 วันสำหรับ **1,000 โรงแรม** แต่ละแห่งมี **4 อัตราหลัก**

**การรีเฟรชข้อมูลทั้งหมดครั้งหนึ่งคือ 90,000 โรงแรม-วัน — $9.00**

นั่นคือ 1,000 โรงแรม × 90 วัน อัตรา 4 แผนราคาไม่คิดเงินเพิ่ม: คำขอเดียวคืนทุกแผนราคาที่โรงแรมเผยแพร่ในช่วงเวลานั้น ดังนั้นจำนวนแผนราคาที่ทรัพย์สินมีไม่ใช่มิติการคิดเงิน และไม่ว่าคุณจะแบ่งคำขออย่างไร — คำขอช่วงเวลาครอบคลุมสูงสุด 30 วัน ดังนั้นคุณจะทำ 3 คำขอต่อโรงแรม และ 3 × 30 วัน คิดเงินเท่ากับคำขอ 90 วันคำเดียว คุณถูกคิดเงินตามราคาที่ขอ ไม่ใช่ตามวิธีการขอ

ดังนั้นสิ่งที่คุณจ่ายต่อเดือนขึ้นอยู่กับคำถามเดียว: คุณรีเฟรชบ่อยแค่ไหน?

| ความถี่รีเฟรช | โรงแรม-วัน / เดือน | หลังโควต้าฟรี 10,000 | ค่าใช้จ่ายรายเดือน |
| -- | -- | -- | -- |
| เดือนละครั้ง | 90,000 | 80,000 | **$8.00** |
| สัปดาห์ละครั้ง | 360,000 | 350,000 | **$35.00** |
| วันละครั้ง | 2,700,000 | 2,690,000 | **$269.00** |
| วันละสองครั้ง | 5,400,000 | 5,390,000 | **$539.00** |

การรีเฟรชโรงแรมทั้ง 1,000 แห่งทุกวันคือ 3,000 คำขอต่อวัน และคิดเป็นประมาณ $9.00 ต่อวัน โควต้าฟรีเพียงอย่างเดียว — 10,000 โรงแรม-วันต่อเดือน — เพียงพอที่จะตั้งราคาประมาณ 110 โรงแรมสำหรับ 90 วันเต็ม หรือสร้างและทดสอบการรวมระบบทั้งหมดโดยไม่ต้องจ่ายเงิน

#### ปัจจัยที่ทำให้ตัวเลขเปลี่ยนแปลง

- **การขอแผนราคาแยกทีละแผน** คำขอช่วงเวลาคืนราคาที่ดีที่สุดต่อประเภทห้องพักในทุกแผนราคาในครั้งเดียว หากคุณกรองให้แสดงแผนราคาแผนเดียวต่อคำขอเพื่อดูทั้งสี่แยกกัน คุณจะทำคำขอสี่เท่าและจ่ายสี่เท่า
- **จำนวนผู้เข้าพัก สกุลเงิน หรือภาษาเพิ่มเติม** ราคาสำหรับผู้ใหญ่ 1 คนและราคาสำหรับผู้ใหญ่ 2 คนเป็นคำถามที่ต่างกัน และแต่ละคำถามถูกคิดเงิน เช่นเดียวกับสกุลเงินหรือภาษาที่แสดงเพิ่มเติม
- **ความสดใหม่ที่คุณไม่ต้องการ** ไม่มีอะไรบอกว่าทุก 90 วันต้องรีเฟรชบ่อยเท่ากัน รีเฟรช 14 วันถัดไปทุกวัน และวันที่ 15–90 ทุกสัปดาห์ โรงแรม 1,000 แห่งเดียวกันจะมีค่าใช้จ่าย **$71.40** ต่อเดือนแทนที่จะเป็น $269.00 — วันที่ใกล้เคียงที่ราคาขยับจริงๆ จะสดใหม่

### การเปิดใช้งาน

การใช้งานแบบจ่ายตามจริงปิดโดยค่าเริ่มต้น ทุกคนได้รับโควต้าฟรีโดยไม่ต้องทำอะไร

เพื่อใช้เกินโควต้า **เจ้าของ** บัญชีจะเปิดใช้งานการใช้งานแบบจ่ายตามจริงและเลือกบัญชีที่ต้องการวัดการใช้งาน การใช้งานจากบัญชีที่เปิดใช้งานทั้งหมดจะถูกรวมใน **ใบแจ้งหนี้รายเดือนฉบับเดียว** ซึ่งคุณสามารถชำระโดยอัตโนมัติผ่านบัตร หรือรับใบแจ้งหนี้เพื่อชำระเอง

เมื่อเปิดใช้งาน การใช้งานของคุณจะถูกวัดแต่ **ไม่ถูกจำกัดความเร็ว** — คุณจะไม่ถูกจำกัดอัตราการใช้จ่ายกับเรา

:::note[ถ้าคุณไม่เปิดใช้งาน]
ไม่มีอะไรเสียหายและไม่มีการคิดเงิน คุณจะหยุดที่โควต้าฟรีของเดือนนั้น: โพสต์ที่สร้างโดย AI จะไม่เผยแพร่ และการเรียก API พันธมิตรจะคืนค่า `429` จนกว่าโควต้าจะรีเซ็ต
:::

### สถานะการเรียกเก็บเงิน

| สถานะ | ความหมาย |
| -- | -- |
| สถานะดี | ทุกอย่างทำงานปกติ |
| ค้างชำระ | การชำระเงินล้มเหลวและกำลังพยายามใหม่ ฟีเจอร์ของคุณยังทำงานในช่วงนี้ |
| ระงับ | ใบแจ้งหนี้ไม่ได้ชำระจนหมด การดำเนินการที่ต้องชำระเงินถูกบล็อกจนกว่าจะชำระ; ฟีเจอร์ฟรียังทำงานตามปกติ |

:::tip[ราคาสด]
ราคาต่อหน่วยและโควต้าฟรีจะแสดงใน Portal โดยตรงจากระบบเรียกเก็บเงินของเรา เพื่อให้คุณตรวจสอบก่อนตัดสินใจ ดูที่ [Billing](/th/account/subscription) เพื่อเปิดใช้งานจ่ายตามจริง เลือกบัญชี และติดตามการใช้งานและใบแจ้งหนี้รายเดือน ดูที่ [Social](/th/portal/social/what-is-social) เพื่อดูว่าปริมาณโพสต์ส่งผลต่อค่าใช้จ่ายอย่างไร
:::

## ผลกระทบของแพลตฟอร์ม

เข้าร่วม Wink วันนี้และค้นพบวิธีใหม่ที่ทำกำไรในการทำธุรกิจในอุตสาหกรรมการบริการ!
