Wink คือโครงสร้างพื้นฐานสำหรับการค้าการท่องเที่ยว โรงแรมสามารถควบคุมซัพพลายของตนเองและขายตรงผ่านเว็บไซต์ ช่องทางพันธมิตรและครีเอเตอร์ การค้นพบของผู้บริโภค และเอเจนต์ AI — พร้อมทั้งรักษาความสัมพันธ์กับแขกผู้เข้าพัก

ส่วนนี้เป็นการปูพื้นฐาน อ่านตามลำดับหากคุณเป็นมือใหม่ หรือข้ามไปยังส่วนที่คุณต้องการ

## เริ่มที่นี่

- [แนะนำ Wink](/th/getting-started/how-to-use/) — แพลตฟอร์มทำอะไรได้บ้างและส่วนประกอบต่างๆ ทำงานร่วมกันอย่างไร
- [คุณสมบัติหลัก](/th/getting-started/key-features/) — ความสามารถที่มีให้สำหรับโรงแรม, พันธมิตร และนักพัฒนา
- [สมัครสมาชิก](/th/getting-started/sign-up/) — สร้างบัญชีและเลือกประเภทบัญชีที่เหมาะสม
- [การตั้งราคา](/th/getting-started/pricing/) — ค่าใช้จ่ายของ Wink และสิ่งที่ให้ใช้ฟรี

- [ลูกค้า](/th/getting-started/customers/) — ใครใช้ Wink และเพื่อวัตถุประสงค์อะไร
