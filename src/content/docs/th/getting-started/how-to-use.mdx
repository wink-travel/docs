ยินดีต้อนรับสู่ Wink ไม่ว่าคุณจะเป็นเจ้าของโรงแรม โปรโมตการท่องเที่ยวให้กับกลุ่มเป้าหมาย จองแทนลูกค้า หรือพัฒนาซอฟต์แวร์สำหรับงานเหล่านี้ — คุณมาถูกที่แล้ว

Wink ถูกสร้างขึ้นมาเพื่อทำให้การขายสินค้าการท่องเที่ยวกลับมาน่าตื่นเต้นอีกครั้ง และเพื่อให้เข้าถึงได้ง่ายขึ้นสำหรับคนจำนวนมากกว่ากลุ่มผู้เล่นใหญ่ไม่กี่รายที่เคยควบคุมตลาดนี้ เอกสารนี้จะพาคุณผ่านทุกส่วนของแพลตฟอร์ม ตั้งแต่การสร้างบัญชีแรกจนถึงการใช้งานจริงด้วยการเชื่อมต่อ API ขั้นสูง คุณไม่จำเป็นต้องอ่านตามลำดับ ให้ไปยังส่วนที่ตรงกับสิ่งที่คุณต้องการทำ — และถ้าคุณรู้แล้วว่าต้องการอะไร ช่องค้นหาที่ขับเคลื่อนด้วย AI ด้านบนของหน้านี้จะพาคุณไปยังจุดนั้นได้ทันที

บัญชีบน Wink ช่วยให้คุณ:

- สร้างและจัดการที่พัก และขายได้ทุกที่ที่นักเดินทางมีโอกาสเข้าถึง
- สร้างและจัดการบัญชีพันธมิตร และรับค่าคอมมิชชั่นจากการจองที่คุณช่วยอำนวยความสะดวก
- สร้างและจัดการบัญชีตัวแทนท่องเที่ยว และจองแทนลูกค้าของคุณ
- รับลิงก์ WinkLinks ส่วนตัวของคุณ (*เช่น https://i.trvl.as/bob*) และใช้เป็น `Link-in-Bio URL`
- จองวันหยุดครั้งต่อไปและประหยัดค่าใช้จ่าย
- ทำทุกอย่างข้างต้นในฐานะนักพัฒนาโดยการเชื่อมต่อกับ Wink

## เกี่ยวกับ Wink

`The Wink Travel Platform` คือแพลตฟอร์มท่องเที่ยวใหม่ที่ปฏิวัติวงการ ออกแบบตั้งแต่ต้นเพื่อเสริมพลังให้กับโรงแรม ผู้ให้บริการประสบการณ์ ผู้มีอิทธิพล และพันธมิตร ด้วยการผสานเครื่องมือที่ล้ำสมัยเข้ากับอินเทอร์เฟซที่ใช้งานง่าย Wink เปลี่ยนแปลงอุตสาหกรรมการบริการให้เชื่อมต่อ เติบโต และประสบความสำเร็จได้ง่ายกว่าที่เคย

ทุกสิ่งที่คุณทำในฐานะธุรกิจตอนนี้อยู่ในที่เดียว — **Portal** พร้อมกับ
**booking engine** ซึ่งเป็นที่ที่การจองทั้งหมดเกิดขึ้น และ
**developer tools** สำหรับทีมที่ต้องการสร้างบนแพลตฟอร์มของเรา เลือกส่วนที่เหมาะกับคุณด้านล่างและเริ่มต้นได้เลย

## ค่าใช้จ่าย

ส่วนใหญ่ของสิ่งที่ Wink มีให้นั้นฟรี การลงประกาศและจัดการที่พัก การสร้างเครือข่ายพันธมิตร การใช้ booking engine การเผยแพร่หน้า WinkLinks การเขียนโพสต์โซเชียลของคุณเอง การวิเคราะห์ — ไม่มีค่าใช้จ่าย ไม่มีค่าสมาชิก และไม่มีค่าติดตั้ง

เมื่อมีการจองเกิดขึ้น Wink จะเก็บเปอร์เซ็นต์เล็กน้อยเพื่อรักษาการดำเนินงาน และฟีเจอร์พรีเมียมบางอย่างที่มีค่าใช้จ่ายจริงทุกครั้งที่คุณใช้ — โพสต์โซเชียลที่สร้างด้วย AI การตอบกลับอัตโนมัติ การเข้าถึง API ปริมาณสูง — จะถูกคิดเป็น **ค่าบริการตามการใช้งาน** ในอัตราที่เราคิดว่าคุณจะพบว่าคุ้มค่า ฟีเจอร์เหล่านี้มาพร้อมกับโควต้าใช้ฟรีรายเดือน เพื่อให้คุณได้ลองก่อนจ่ายเงิน

## แนวคิดหลัก

> คุณเห็นหนึ่ง... คุณเห็นทั้งหมด

เมื่อคุณทำความคุ้นเคยกับฟีเจอร์ทั้งหมดของ Wink จะพบว่ามีความซ้ำซ้อนในวิธีการทำงาน การเข้าใจแนวคิดหลักจะช่วยให้คุณคุ้นเคยและมั่นใจมากขึ้นเมื่อใช้งานฟีเจอร์ต่างๆ

เริ่มกันเลย:

- ทุกส่วนมักจะมีวิธีการแสดงรายการ เพิ่ม แก้ไข และลบข้อมูล
- เมื่อคุณแก้ไขข้อมูล เครื่องหมายดอกจันสีแดง <Badge text="*" variant="danger" size="large" /> บนช่องฟอร์มหมายความว่าจำเป็นต้องกรอก
- หากช่องฟอร์มใดไม่ถูกต้อง จะมีกรอบสีแดงและข้อความสีแดงอธิบายปัญหาใต้ช่องฟอร์มนั้น
- คุณจะสามารถ `บันทึก` ฟอร์มได้ก็ต่อเมื่อฟอร์มถูกต้องและมีการเปลี่ยนแปลงบางอย่าง
- ฟอร์มบางแบบมีหลายแท็บ เช่น ฟอร์มห้องพักแขก
- ทุกแท็บต้องถูกต้องก่อนจึงจะดำเนินการต่อได้
- แท็บที่มีข้อมูลฟอร์มหายไปหรือไม่ถูกต้องจะแสดงสามเหลี่ยมสีเหลือง <Badge text="⚠️" variant="caution" size="large" /> ข้างชื่อแท็บ
- เมื่อส่งฟอร์ม ฟอร์มส่วนใหญ่จะแสดงกล่องโต้ตอบ `ยืนยัน` ถามว่าคุณต้องการดำเนินการต่อหรือไม่

## Portal

[Portal](https://app.wink.travel) คือแอปเดียวที่รวบรวมทุกสิ่งที่คุณทำในฐานะธุรกิจ ไม่ว่าคุณจะมีบัญชีประเภทใด นี่คือจุดเริ่มต้นของคุณ:

- **Property** — ลงประกาศโรงแรมของคุณ จัดการราคา เนื้อหา และความพร้อมใช้งาน พร้อมกับมีเครือข่ายพันธมิตรช่วยขายให้คุณ
- **Affiliate** — สร้างรายได้จากกลุ่มเป้าหมายของคุณและรับค่าคอมมิชชั่นจากทุกการจองที่คุณส่งมา
- **Travel agent** — ค้นหาราคาพิเศษและสินค้าคงคลังโดยตรงจากซัพพลายเออร์และจองแทนลูกค้าของคุณ
- **Payment** — ติดตามรายได้และถอนเงินของคุณ โดยใช้บริการ TripPay
- **Social** — ให้ AI ช่วยดูแลช่องทางโซเชียลของคุณให้มีชีวิตชีวาและสร้างยอดขาย
- **Link Manager** — สร้างและเผยแพร่หน้า WinkLinks ของคุณ
- **Settings** — การตั้งค่าแบรนด์ ผู้จัดการ แอปพลิเคชัน เว็บฮุก และการจ่ายเงิน แยกตามบัญชี

คุณสามารถจัดการบัญชีได้หลายบัญชีจากการเข้าสู่ระบบเพียงครั้งเดียว และระบบ Corporate กำลังจะมาเร็วๆ นี้
