ก่อนอื่น คุณต้องสร้างบัญชีผู้ใช้บน Wink

<Aside type="note" title="คุณกำลังจองทริปใช่ไหม?">
คำแนะนำนี้สำหรับมืออาชีพที่ต้องการทำงานกับสินค้าท่องเที่ยวของ Wink — เจ้าของโรงแรม ตัวแทนท่องเที่ยว ผู้ร่วมงาน และพันธมิตรอื่นๆ ที่จัดการการจอง ที่พัก และการกระจายสินค้า หากคุณเป็นนักเดินทาง คุณไม่จำเป็นต้องมีบัญชีล่วงหน้า: คุณจะสร้างบัญชีในขั้นตอนการชำระเงินเมื่อทำการจอง
</Aside>

ทำตามขั้นตอนเหล่านี้:

<Steps>
1. ไปที่ [app.wink.travel](https://app.wink.travel)
2. คลิกที่ `Sign-In / Register` ที่มุมขวาบน
3. คุณจะถูกนำไปยังแบบฟอร์มเข้าสู่ระบบ คลิกที่ลิงก์ `Register` ด้านล่างช่องกรอกข้อมูล
4. กรอกแบบฟอร์มลงทะเบียนให้ครบถ้วนแล้วคลิก `Register` คุณจะถูกเปลี่ยนเส้นทางไปยังหน้าล็อกอิน
5. เมื่อเข้าสู่ระบบแล้ว คุณจะถูกเปลี่ยนเส้นทางไปยัง [Portal](/th/portal/create-account) ของเรา ที่ซึ่งคุณสามารถสร้างบัญชีแรกของคุณได้
</Steps>

การสร้างบัญชีผู้ใช้ Wink จะทำให้คุณเข้าถึงฟีเจอร์ทั้งหมดบนแพลตฟอร์มได้ คุณสามารถสร้างที่พักและบัญชีพันธมิตรได้ไม่จำกัดจำนวน
