โดยการสร้าง [บัญชีพันธมิตร](/th/portal/studio/what-is-studio) คุณจะมี WinkLinks vanity URL แล้ว ฟีเจอร์ผู้เผยแพร่ WinkLinks มีอยู่ในแอป Studio ของเรา พร้อมกับฟีเจอร์พันธมิตรอื่นๆ

### ตัวอย่าง

ถ้าชื่อบัญชีของคุณคือ Queen Bee WinkLinks vanity URL ของคุณจะเป็น:

<h4 align="center">https://i.trvl.as/queen-bee</h4>

ส่วนที่อยู่หลัง `i.trvl.as/` เรียกว่า slug ซึ่งเริ่มต้นจากชื่อบัญชีของคุณ และคุณสามารถแก้ไขได้ภายหลัง Slug จะถูกจัดสรรตามลำดับ `มาก่อนได้ก่อน` — รีบคว้า URL เฉพาะตัวของคุณก่อนใคร!
