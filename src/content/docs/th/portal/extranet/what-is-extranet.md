Extranet คือฝั่งของที่พักใน [Portal](/th/portal/overview) แอปเดียวของเราที่ [app.wink.travel](https://app.wink.travel) ซึ่งออกแบบมาสำหรับโรงแรม เครือโรงแรม แบรนด์ และบริษัทบริหารโรงแรม เพื่อสร้างและจัดการโปรไฟล์ดิจิทัลของที่พักบนแพลตฟอร์ม Wink

ไม่มีอะไรแยกต่างหากให้สมัคร และไม่มีที่อื่นให้ล็อกอิน — เพียงเลือกบัญชีที่พักใน Portal และฟีเจอร์ Extranet ที่อธิบายในส่วนนี้ก็พร้อมใช้งานทันที

Extranet ถูกออกแบบมาอย่างรอบคอบให้เรียบง่ายที่สุดเท่าที่จะเป็นไปได้ แต่ยังคงรองรับฟีเจอร์ทั้งหมดที่ผู้ใช้ขั้นสูงคาดหวังจากพอร์ทัลที่พักขั้นสูง ตัวอย่างเช่น:

1. ความเรียบง่าย: ใช้เวิร์กโฟลว์การเริ่มต้นใช้งานอัจฉริยะของเราเพื่อเริ่มต้นที่พักของคุณและเปิดใช้งาน LIVE ในเวลาไม่ถึงชั่วโมง
2. ขั้นสูง: Wink รองรับนโยบายการยกเลิกได้ถึง 8500 รูปแบบที่แตกต่างกัน
3. เจ๋ง: ให้ส่วนลด 10% กับคนเพียงคนเดียวบนโลกนี้โดยที่ผู้ใช้ไม่ต้องล็อกอินหรือพิมพ์รหัสโปรโมชั่น

ให้ผู้ช่วยของเรานำทางคุณตลอดกระบวนการทั้งหมด เมื่อคุณรู้สึกมั่นใจพอ... ก็ลองทำด้วยตัวเอง

Wink คือระบบจัดการเนื้อหาขั้นสูงสำหรับที่พักและผู้ให้บริการประสบการณ์ ทุกอย่างที่คุณทำได้ใน Portal คุณก็สามารถทำผ่าน API ได้ ซึ่งช่วยให้คุณผสานรวมกับ Wink อย่างลึกซึ้งจนสามารถขายผ่าน Wink ได้โดยไม่ต้องล็อกอินเลย

:::tip[เคล็ดลับมือโปร]
คุณกำลังจ่ายค่าบริการโฮสติ้งสื่อราคาแพงผ่าน Leonardo International อยู่หรือเปล่า? คุณสามารถทำสิ่งเดียวกันนี้ผ่าน Wink ได้ และยังมีตัวเลือกมากมายให้ปรับแต่งและปรับแต่งภาพและวิดีโอของคุณได้อย่างละเอียด
:::

ฟีเจอร์ทั้งหมดนี้ไม่มีค่าใช้จ่ายสำหรับคุณ เราจะเก็บค่าธรรมเนียมเล็กน้อยก็ต่อเมื่อคุณมีการจองเท่านั้น ไม่มีอะไรต้องเสีย — มีแต่ได้กับได้
