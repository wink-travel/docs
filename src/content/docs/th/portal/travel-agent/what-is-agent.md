ตัวแทนท่องเที่ยวที่ลงทะเบียนใช้พอร์ทัลเดียวกับทุกคนที่ [app.wink.travel](https://app.wink.travel) โดยใช้บัญชี Travel Agent ตัวแทนจะค้นหาและจองแทนลูกค้าของตนและได้รับค่าคอมมิชชั่นจากการจองแต่ละครั้ง ในการตั้งค่าบัญชี ให้ทำตาม [เริ่มต้นใช้งานในฐานะตัวแทนท่องเที่ยว](/th/guides/travel-agents/getting-started/)

เอเจนซี่ที่ได้รับอนุมัติให้เก็บเงินเองจะทำหน้าที่เป็นผู้ค้ารายการและจัดการการชำระเงินนอกแพลตฟอร์ม Wink เอเจนซี่ที่มีระบบของตนเองสามารถเชื่อมต่อผ่าน [Partner API](/th/integrations/partner-api/)

ตัวแทนท่องเที่ยวมีฟีเจอร์บางส่วนของพอร์ทัลเดียวกับ [Studio](/th/portal/studio/what-is-studio) ดังนั้นเราจะไม่กล่าวถึงซ้ำที่นี่

## ค้นหา

ไปที่ [Search](/th/portal/studio/search) เพื่อเรียนรู้วิธีค้นหาและจองโรงแรม

หากไม่ใช่ ให้ดำเนินการต่อไปยังส่วนถัดไป

## API

เอเจนซี่สามารถค้นหาและจองผ่าน [Partner API](/th/partner-api/partner/) ซึ่งมาแทนที่ Travel Agent REST endpoints รุ่นเก่า
