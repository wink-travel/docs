รายการที่คัดสรรเป็นฟีเจอร์ที่ช่วยให้คุณจัดกลุ่มและจัดเรียงสินค้าคงคลังที่คุณเลือกจากสิ่งที่คุณพบขณะค้นหาสินค้าคงคลังการเดินทาง
เมื่อสร้างแล้ว คุณสามารถแสดงรายการให้ผู้ใช้ของคุณเห็นโดยการเปิดให้ขายในรูปแบบ [grid](/th/portal/studio/grids) หรือ [map](/th/portal/studio/maps) ผ่าน [WinkLinks](/th/portal/link-manager/wink-links), ปลั๊กอิน [WordPress](/th/integrations/wordpress/) ของเรา หรือโดยการฝังหนึ่งใน [Web Components](/th/integrations/web-components) ของเราในเว็บไซต์ของคุณ

โดยค่าเริ่มต้น บัญชีพันธมิตรทุกบัญชีจะเริ่มต้นด้วยรายการ `Favorites` ที่คุณสามารถใช้ได้ทันที `Favorites` เป็นรายการพิเศษและไม่สามารถลบได้
รายการที่คัดสรรทั้งหมดอนุญาตให้คุณทำสิ่งต่อไปนี้:

- จากแดชบอร์ด คลิก `Lists > Curated` ในแถบนำทาง
- สร้างรายการที่คัดสรรใหม่โดยคลิกปุ่ม `Make a new list`
- คุณจะถูกขอให้ตั้งชื่อรายการของคุณ *ตัวอย่าง: Top 3 NYC Picks*
- คลิกปุ่ม `Save`

## เพิ่มรายการในลิสต์

คุณสามารถเพิ่มรายการในลิสต์ใดก็ได้จากผลการค้นหา

- ไปที่ [Search](/th/portal/studio/search)
- ค้นหาสิ่งที่คุณต้องการเพิ่มในรายการของคุณ
- เมื่อเจอแล้ว คลิกลิงก์ `Actions` ที่มุมล่างซ้ายของการ์ดผลการค้นหา
- คลิก `Add to...` แล้วเลือกรายการที่คัดสรรที่คุณต้องการเพิ่มสินค้านี้เข้าไป
- กลับไปที่หน้ารายการที่คัดสรรเพื่อตรวจสอบว่าสินค้าได้ถูกเพิ่มในรายการของคุณแล้ว

- แปลงรายการเป็น [map](/th/portal/studio/maps)
- แปลงรายการเป็น [grid](/th/portal/studio/grids)
- ลบรายการ (*ยกเว้น Favorites*)

## API

นักพัฒนาที่ต้องการจัดการรายการที่คัดสรรสามารถไปที่ [Developers > API > Browse](/th/api)

- อ่านเกี่ยวกับฟีเจอร์ [map](/th/portal/studio/maps) ของเรา
