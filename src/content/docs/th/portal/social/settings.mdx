# การตั้งค่า

เมื่อคุณเริ่มต้นใช้งาน Social เราจะถามคุณว่าต้องการให้เราสร้างเนื้อหาอย่างไร ตัวเลือกเหล่านี้พร้อมใช้งานตลอดเวลาเพื่อให้คุณสามารถเปลี่ยนแปลงได้อย่างง่ายดายในภายหลัง

ไปที่ `Settings` จากแถบด้านข้างเพื่อจัดการการตั้งค่าของคุณ

ส่วนความชอบประกอบด้วยการตั้งค่าพื้นฐานสำหรับการสร้างเนื้อหาของคุณ:

1. **การปรับแต่งที่ต้องการ** เลือกการปรับแต่งที่ใช้เมื่อสร้างเนื้อหา การปรับแต่งควบคุมสีธีม แผนการเดินทางเริ่มต้น สกุลเงิน ภาษา และอื่นๆ คุณสามารถสร้างการปรับแต่งได้ภายใต้บัญชีของคุณที่ [app.wink.travel](https://app.wink.travel)
2. **อนุมัติอัตโนมัติ** เมื่อเปิดใช้งาน โพสต์ที่สร้างขึ้นจะถูกเผยแพร่อัตโนมัติโดยไม่ต้องรอการอนุมัติของคุณ เปิดใช้งานนี้เมื่อคุณมั่นใจในคุณภาพของเนื้อหาที่เราสร้างให้คุณ
3. **ชื่อผู้อนุมัติ** ชื่อของบุคคลหรือทีมที่จะได้รับอีเมลคำขออนุมัติ
4. **อีเมลผู้อนุมัติ** ที่อยู่อีเมลที่คำขออนุมัติสำหรับโพสต์ที่จะมาถึงจะถูกส่งไป

## ผู้สร้างเนื้อหา

<figure>
<CldImage

  alt="Social content creators"

  <figcaption>*รูปที่ 2 - ผู้สร้างเนื้อหา*</figcaption>

Social มาพร้อมกับผู้สร้างเนื้อหาหลายแบบให้เลือก แต่ละผู้สร้างเน้นวิธีเฉพาะในการสร้างเนื้อหาเฉพาะตัวสำหรับที่พักของคุณโดยใช้ AI ผู้สร้างเนื้อหาทุกคนมีคุณสมบัติ **น้ำหนัก** — น้ำหนักที่สูงกว่าจะเพิ่มโอกาสที่ผู้สร้างคนนั้นจะถูกเลือกเมื่อสร้างโพสต์

นี่คือผู้สร้างเนื้อหาทั้งหมดที่มีให้:

| ผู้สร้าง | คำอธิบาย |
| -- | -- |
| **ปลายทาง** | ใช้ตำแหน่งของคุณเพื่อสร้างข้อความที่เป็นประโยชน์เกี่ยวกับพื้นที่ |
| **ประเภทห้อง** | สร้างโพสต์ที่จองได้โดยมีข้อความที่สร้างด้วย AI และภาพของประเภทห้องของคุณ |
| **กิจกรรม** | สร้างโพสต์ที่จองได้โดยมีหนึ่งในกิจกรรมของคุณ |
| **สิ่งเสริม** | สร้างโพสต์ที่จองได้โดยมีหนึ่งในสิ่งเสริมของคุณ |
| **สถานที่ท่องเที่ยว** | สร้างโพสต์ที่จองได้โดยมีหนึ่งในสถานที่ท่องเที่ยวของคุณ |
| **สถานที่** | สร้างโพสต์ที่จองได้โดยมีหนึ่งในสถานที่ของคุณ |
| **ห้องประชุม** | สร้างโพสต์ที่จองได้โดยมีหนึ่งในห้องประชุมของคุณ |
| **ร้านอาหาร** | สร้างโพสต์ที่จองได้โดยมีหนึ่งในร้านอาหารของคุณ |
| **สปา** | สร้างโพสต์ที่จองได้โดยมีหนึ่งในสปาของคุณ |
| **ที่พัก** | สร้างโพสต์ที่จองได้โดยมีห้องราคาดีที่สุดของคุณพร้อมข้อความที่สร้างด้วย AI และภาพของที่พัก |
| **ความรู้สึกของผู้ใช้** | รวบรวมรีวิวจากแขกทั่วเว็บเป็นโพสต์ที่ขับเคลื่อนด้วยความรู้สึกที่เน้นสิ่งที่แขกชื่นชอบเกี่ยวกับที่พักของคุณ |
| **ตลก** | สร้างโพสต์เบาสมองและสนุกสนานเพื่อให้ฟีดของคุณน่าสนใจ |

:::tip[เคล็ดลับมือโปร]
ตรวจสอบให้แน่ใจว่าคุณมีประเภทสินค้าคงคลังที่จำเป็นสำหรับผู้สร้างเนื้อหาที่คุณเลือก เช่น หากคุณเลือก "ร้านอาหาร" คุณต้องมีร้านอาหารอย่างน้อยหนึ่งแห่งในที่พักของคุณ
:::

## น้ำเสียง

<figure>
<CldImage

น้ำเสียงกำหนดสไตล์ภาษาที่ AI ใช้เมื่อสร้างเนื้อหา เลือกน้ำเสียงที่ตรงกับบุคลิกแบรนด์ของคุณ เช่นเดียวกับผู้สร้างเนื้อหา แต่ละน้ำเสียงมี **น้ำหนัก** เพื่อควบคุมความถี่ในการใช้งาน

นี่คือน้ำเสียงที่มีให้เลือก:

| น้ำเสียง | สไตล์ |
| -- | -- |
| **เป็นกลาง** | สงบ น่าเชื่อถือ มีข้อเท็จจริง ไม่มีการโอ้อวด ไม่มีมุกตลก — เพียงความรู้ที่เชื่อถือได้และมีโครงสร้างดี |
| **เป็นมิตร** | อบอุ่น เข้าถึงง่าย มีพลังรอยยิ้มผ่านข้อความ ใช้คำย่อแบบไม่เป็นทางการและอีโมจิเป็นครั้งคราว |
| **หรูหรา** | ซับซ้อน เรียบหรู ใช้คำเช่น "ประณีต" และ "สั่งทำพิเศษ" ที่ทำให้ผู้อ่านรู้สึกพิเศษ |
| **คนรักอาหาร** | คำบรรยายที่เร้าใจและชวนให้น้ำลายไหล ภาษาอาหารที่ทำให้ผู้อ่านหิว |
| **ผจญภัย** | กล้าหาญ ไม่กลัว สำรวจ ใช้คำบรรยายที่ชัดเจนและมีชีวิตชีวาที่ทำให้ทุกอย่างดูยิ่งใหญ่ |
| **ครอบครัว** | สนุกสนาน เหมาะสำหรับเด็ก มีพลังอบอุ่นแบบพ่อแม่เกี่ยวกับประสบการณ์ที่ปลอดภัยและสนุกสนาน |
| **โรแมนติก** | กวี มีความคิดถึง หัวใจเต้นแรง พระอาทิตย์ตก ภาษาอ่อนโยนและความรัก |
| **ตลกขบขัน** | เสียดสี มุกสั้น ฉลาด อ่านเหมือนการแสดงสแตนด์อัพ |
| **รักษ์โลก** | จริงใจและถูกต้องทางศีลธรรม ชื่นชมทางเลือกสีเขียวและความยั่งยืน |
| **คนในท้องถิ่น** | อ้างอิงท้องถิ่นเฉพาะเจาะจง เตือนให้หลีกเลี่ยงกับดักนักท่องเที่ยว ใช้สแลงท้องถิ่น |
| **ครอบคลุม** | ต้อนรับ ฉลอง และยืนยัน ทำให้ทุกคนรู้สึกเห็นและมีคุณค่า |
| **ลึกลับ** | ลึกลับ จิตวิญญาณ ความจริงจักรวาล เชิญชวนอย่างอ่อนโยนให้มองเข้าไปข้างใน |
| **อนาคต** | เรียบหรู มองไปข้างหน้า ชอบคำเช่น "การเปลี่ยนแปลงรูปแบบ" และวิสัยทัศน์อนาคตที่มองโลกในแง่ดี |
| **ประหยัด** | ขยัน ประหยัดอย่างภาคภูมิใจ ชื่นชมการค้นหาที่คุ้มค่าและประสบการณ์ฟรี |

## ประเภทโพสต์

ประเภทโพสต์กำหนดเป้าหมายและโครงสร้างของเนื้อหาที่สร้างขึ้น ประเภทโพสต์แต่ละประเภทมี **น้ำหนัก** เพื่อควบคุมความถี่ในการใช้งาน

| ประเภทโพสต์ | คำอธิบาย |
| -- | -- |
| **เชิงธุรกรรม** | ชัดเจน กระชับ เน้นการแปลงยอด ขับเคลื่อนการจองและการดำเนินการโดยตรงด้วยข้อเท็จจริง ราคา และขั้นตอนถัดไป |
| **การรับรู้** | เนื้อหาสร้างแบรนด์ที่ออกแบบมาเพื่อแนะนำที่พักของคุณและเพิ่มการมองเห็นในกลุ่มแขกเป้าหมาย |
| **ความรู้สึก** | เนื้อหาที่สร้างความรู้สึกเชิงบวกและสร้างความสัมพันธ์ทางอารมณ์กับผู้ชมของคุณ |
