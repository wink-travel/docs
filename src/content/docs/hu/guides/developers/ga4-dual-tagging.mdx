A Google Analytics 4 tulajdonod Winkhez való csatlakoztatásával a foglalási eseményeid — a szobamegjelenítésektől a befejezett foglalásokig — automatikusan továbbítódnak a saját GA4 irányítópultodra a Wink saját elemzései mellett. Nincs szükség kódolásra vagy technikai beállításra a te részedről.

<Aside type="tip">
Két dologra van szükséged a GA4-ből: egy **Mérési azonosítóra** és egy **Measurement Protocol API titokra**. A Mérési azonosító működteti a böngészési tölcsért a vendég böngészőjében; az API titok lehetővé teszi, hogy a Wink **szerveroldalon** rögzítse a befejezett foglalásokat (`purchase`), így egy eladás sem vész el, amikor a vendéget átirányítják a fizetési szolgáltatóhoz és vissza.
</Aside>

---

## Hogyan Működik

```
Beírod a Mérési azonosítódat (G-XXXXXXXXXX) és az API titkot a Wink portálon
       ↓
Böngészési események (megtekintések, kosár, fizetés) a böngészőből folyamatosan érkeznek a GA4 tulajdonodba
A befejezett foglalások (purchase) szerveroldalon érkeznek — túlélve a fizetési átirányítást
       ↓
Bejelentkezel az analytics.google.com oldalra, és látod a teljes foglalási tölcséred
```

## Mit Kell Tenned

<Steps>

1. **Hozz létre egy GA4 tulajdont**

   Látogass el a [analytics.google.com](https://analytics.google.com) oldalra: Admin → Tulajdon létrehozása. Állítsd be az időzónádat és a pénznemet a piacodnak megfelelően.

2. **Hozz létre egy Web adatfolyamot**

   Admin → Adatfolyamok → Adatfolyam hozzáadása → Web. Írd be a `wink.travel` URL-t. Ez létrehozza a **Mérési azonosítódat** (`G-XXXXXXXXXX`). Másold ki.

3. **Hozz létre egy Measurement Protocol API titkot**

   Nyisd meg ugyanazt a Web adatfolyamot → görgess le a **Measurement Protocol API titkok** részhez → **Létrehozás**. Adj neki egy becenevet (pl. "Wink") és másold ki a generált **titkos értéket**. Ez a titok teszi lehetővé, hogy a Wink szerveroldalon rögzítse a befejezett foglalásokat, így egy eladás sem vész el a fizetési átirányítás során.

4. **Írd be a Mérési azonosítódat és az API titkot a Wink portálon**

   Jelentkezz be a [app.wink.travel](https://app.wink.travel) oldalra, válaszd ki a fiókodat, és menj a **Testreszabások** fülre. Illeszd be a Mérési azonosítót és az API titkot a **GA4** mezőkbe, majd mentsd el. Ennyi — a GA4 integrációd most aktív.

   <Aside type="note">
   Az API titok **csak írásra szolgál**: egyszer mentve soha többé nem jelenik meg. Későbbi szerkesztéseknél hagyd üresen a titok mezőt, hogy megőrizd a már tárolt értéket.
   </Aside>

5. **Jelöld meg a `purchase` eseményt kulcsfontosságú eseményként**

   Térj vissza a GA4 tulajdonodba: Admin → Események → keresd meg a `purchase` eseményt → kapcsold be a **Kulcsfontosságú eseményként jelölés** opciót. Ezáltal a befejezett foglalások megjelennek a Konverziók jelentésedben.

6. **Nézd meg az adataidat**

   Jelentkezz be az [analytics.google.com](https://analytics.google.com) oldalra, és látni fogod a foglalásaidat, bevételeidet és a vendégtölcsért — mind automatikusan követve a Wink által.

</Steps>

<Aside type="note">
Ehhez az integrációhoz nem kell semmilyen követőkódot telepítened a saját weboldaladra. A Wink mindent kezel. A Mérési azonosítód az a célpont, ahová a foglalási adataid érkeznek, az API titok pedig lehetővé teszi, hogy a Wink szerveroldalon megerősítse a befejezett foglalásokat.
</Aside>

<Aside type="tip">
**A GA4 és a GTM együtt is használható.** Ha Google Tag Manager konténert is futtatsz (például Sojern konténert), mindkettőt egyszerre konfigurálhatod — már nem kizárólagosak egymás mellett. Lásd a [GTM Analytics Integráció](/hu/guides/developers/gtm-dual-tagging) részt.
</Aside>

## Mit Követhetsz Nyomon

Csatlakozás után a GA4 tulajdonod megkapja a teljes Enhanced E-commerce eseménykészletet a szálláshelyedhez:

### Felfedezés

| Esemény | Jelentése |
|---|---|
| `view_item_list` | Egy vendég látta a szálláshelyed keresési vagy kategória listában |
| `select_item` | Egy vendég rákattintott a szálláshelyedre egy listából |
| `view_item` | Egy vendég megtekintette a szállodád részletes oldalát |

### Megfontolás

| Esemény | Jelentése |
|---|---|
| `view_promotion` | Egy vendég látta a szálláshelyed promóciós ajánlatát |
| `select_promotion` | Egy vendég rákattintott egy promóciós ajánlatra |
| `add_to_wishlist` | Egy vendég elmentette a szálláshelyed a kívánságlistájára |

### Foglalási tölcsér

| Esemény | Jelentése |
|---|---|
| `add_to_cart` | Egy vendég kiválasztott egy szobát vagy csomagot |
| `view_cart` | Egy vendég megtekintette a foglalási összefoglalóját |
| `remove_from_cart` | Egy vendég eltávolított egy szobát vagy csomagot |
| `begin_checkout` | Egy vendég elkezdte a fizetési folyamatot |
| `add_payment_info` | Egy vendég megadta a fizetési adatait |
| `add_shipping_info` | Egy vendég megadta a vendégadatait |
| `purchase` | Egy vendég befejezte a foglalást |
| `refund` | Egy foglalást töröltek és visszatérítettek |

Minden esemény tartalmaz releváns dimenziókat, mint például bevétel, pénznem, szobatípus és foglalási érték — így teljes képet kapsz a vendégút első benyomásától a befejezett foglalásig. További szálláshely- és szobaszintű dimenziók (például `city_name`, `cancellation_policy`, `bed_type` és még sok más) feloldásához lásd a [Egyedi dimenziók GA4-ben](/hu/guides/developers/gtm-dual-tagging#custom-dimensions-in-ga4) részt.

## Kereszt-domain követés (Haladó)

A fenti alapértelmezett integráció mindent követ, ami a Winkben történik. Ha azonban azt szeretnéd, hogy a vendégek az első látogatástól a foglalás befejezéséig a saját weboldaladon keresztül is követve legyenek — és helyesen legyen hozzárendelve az eredeti forgalmi forrás (Google Ads, e-mail kampányok, organikus keresés stb.) — akkor mindkét oldalon egy további lépés szükséges.

<Aside type="caution">
Ez a rész csak akkor vonatkozik rád, ha GA4-et használsz a saját weboldaladon. Ha nem futtatod a GA4-et a weboldaladon, a fenti alapértelmezett integráció elegendő.
</Aside>

### Miért Fontos Ez

Kereszt-domain követés nélkül egy vendég, aki először a weboldaladat látogatja meg, majd a Winknél foglal, a GA4-ben **Közvetlen** munkamenetként jelenik meg, amely nem kapcsolódik a korábbi látogatásához. Az összes Google Ads kattintás, e-mail kampány vagy organikus keresés, amely a foglaláshoz vezetett, nem kap hitelt.

Kereszt-domain követéssel a teljes vendégutat látod:

```
google.com (fizetett hirdetés)
       ↓
a te weboldalad (vendég böngészi a szobákat)
       ↓
wink.travel (vendég kiválasztja a szobát és foglal)
       ↓
a vásárlás helyesen a Google Ads eredeti kattintásához van rendelve
```

### Teendő: Te

Állítsd be a GA4 tulajdonodat úgy, hogy a `wink.travel` a saját domain részeként legyen kezelve, ne külső hivatkozásként. Ez megmondja a GA4-nek, hogy a két munkamenetet egy folyamatos vendégúttá fűzze össze.

<Steps>
1. GA4 Admin → Adatfolyamok → a te adatfolyamod
2. Címke beállítások konfigurálása → **Domainjeid konfigurálása**
3. Add hozzá a `wink.travel`-t mint összekapcsolt domaint
4. Mentsd el
</Steps>

### Teendő: Wink

Lépj kapcsolatba a [Wink Supporttal](https://app.wink.travel) és add meg a weboldalad domainjét (pl. `yourhotel.com`). A Wink hozzáadja a domainedet a hivatkozás kizárási listához a Wink GA4 tulajdonban. Ez megakadályozza, hogy a weboldalad hivatkozási forrásként legyen rögzítve, ami egyébként felülírná a vendég eredeti hozzárendelését és új munkamenetet indítana.

<Aside type="tip">
A fenti alapértelmezett integráció a legtöbb szálláshely számára elegendő, és azonnali betekintést nyújt a Wink foglalásaiba és bevételeibe. A kereszt-domain követés egy haladó opció, amelyet érdemes beállítani, ha már kényelmes vagy a GA4 adataiddal, és mélyebb hozzárendelési betekintést szeretnél.
</Aside>
