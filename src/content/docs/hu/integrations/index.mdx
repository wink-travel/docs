A Booking Engine bárhol beágyazható. Válassza ki a keretrendszerét vagy CMS-ét, és kövesse annak útmutatóját; az alapul szolgáló Web Components mindenhol ugyanazok.

## Alapproblémák

- [Web Components](/hu/integrations/web-components/) — az integrációk által használt beágyazható elemek.
- [npm package](/hu/integrations/npm/) — telepítés JavaScript buildbe.
- [Headless CMS](/hu/integrations/headless/) — bármilyen tartalom backendből történő megjelenítés.
- [Partner API](/hu/integrations/partner-api/) — teljes programozott integráció.
