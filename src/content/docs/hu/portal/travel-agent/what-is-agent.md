A regisztrált utazási ügynökök számára készült megoldásunk a [Wink Agent](https://agent.wink.travel). Ez egy önkiszolgáló portál, amelyet az ügynökök használhatnak ügyfeleik nevében történő keresésre és foglalásra, és minden foglalás után jutalékot szerezhetnek maguknak.

A fejlettebb utazási ügynökök választhatják az API szintű integrációt is, hogy a fizetések és kifizetések kezelését a Wink platformon kívül intézhessék.

Az utazási ügynökök a portál [Studio](/hu/portal/studio/what-is-studio) funkcióinak egy részhalmazát használhatják, ezért ezeket itt nem ismertetjük újra.

## Keresés

Látogasson el a [Keresés](/hu/portal/studio/search) oldalra, hogy megtanulja, hogyan keressen és foglaljon szállodákat.

Egyébként folytassa a következő szakaszra.

## API

A fejlesztők, akik kezelni szeretnék a `Travel Agent` funkciót, látogassanak el a [Fejlesztők > API > Travel Agent](/hu/api/overview/) oldalra.
