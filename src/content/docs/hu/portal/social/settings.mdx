# Beállítások

Amikor először kezded el használni a Social-t, megkérdezzük, hogyan szeretnéd, hogy elkészítsük a tartalmaidat. Ezek az opciók mindig elérhetők számodra, így később könnyedén módosíthatod őket.

Navigálj a `Preferences` menüponthoz az oldalsávból a beállításaid kezeléséhez.

A preferences szekció tartalmazza az alapvető tartalomgenerálási beállításaidat:

1. **Preferred customization** Válaszd ki, mely testreszabást szeretnéd használni a tartalom generálásakor. A testreszabások szabályozzák a témaszíneket, az alapértelmezett útitervet, a pénznemet, a nyelvet és még sok mást. Testreszabásokat a fiókod alatt hozhatsz létre az [app.wink.travel](https://app.wink.travel) oldalon.
2. **Auto-approve** Ha engedélyezve van, a generált bejegyzések automatikusan közzé lesznek téve, jóváhagyásod nélkül. Ezt akkor kapcsold be, ha már megbízol a számunkra előállított tartalom minőségében.
3. **Approver name** Az a személy vagy csapat neve, aki megkapja a jóváhagyási kérelmeket tartalmazó e-maileket.
4. **Approver e-mail** Az az e-mail cím, ahová a közelgő bejegyzések jóváhagyási kérelmei érkeznek.

## Tartalomkészítők

<figure>
<CldImage
  src="academy/social_content_creators"

  <figcaption>*2. ábra - Tartalomkészítők*</figcaption>

A Social számos tartalomkészítőt kínál, amelyek közül választhatsz. Minden készítő egy adott módra fókuszál, hogy egyedi tartalmat hozzon létre az ingatlanod számára AI segítségével. Minden tartalomkészítő rendelkezik egy **Weight** attribútummal — a magasabb súly növeli annak esélyét, hogy az adott készítő legyen kiválasztva a bejegyzések generálásakor.

Íme az összes elérhető tartalomkészítő:

| Készítő | Leírás |
| -- | -- |
| **Destination** | A helyszíned alapján készít hasznos szöveget a környékről |
| **Room type** | Foglalható bejegyzést hoz létre az egyik szobatípusodról AI által generált szöveggel és a szobatípus képeivel |
| **Activity** | Foglalható bejegyzést készít az egyik tevékenységedről |
| **Add-On** | Foglalható bejegyzést készít az egyik kiegészítő szolgáltatásodról |
| **Attraction** | Foglalható bejegyzést készít az egyik látványosságodról |
| **Place** | Foglalható bejegyzést készít az egyik helyszínedről |
| **Meeting room** | Foglalható bejegyzést készít az egyik tárgyalótermedről |
| **Restaurant** | Foglalható bejegyzést készít az egyik éttermedről |
| **Spa** | Foglalható bejegyzést készít az egyik wellness részlegedről |
| **Property** | Foglalható bejegyzést készít a legjobb árú szobádról AI által generált szöveggel és az ingatlan képeivel |
| **User sentiment** | Összegyűjti a vendégértékeléseket a weben, és egy érzelmi alapú bejegyzést készít, amely kiemeli, mit szeretnek a vendégek az ingatlanodban |
| **Funny** | Könnyed, szórakoztató bejegyzéseket készít, hogy a hírfolyamod érdekes maradjon |

:::tip[Pro tipp]
Győződj meg róla, hogy rendelkezel a kiválasztott tartalomkészítők által igényelt készlettípussal. Például, ha a "Restaurant" opciót választod, legalább egy éttermet kell szerepeltetned az ingatlanodban.
:::

A hangnem határozza meg azt a nyelvi stílust, amelyet az AI használ a tartalom generálásakor. Válaszd ki azokat a hangnemeket, amelyek illenek a márkád személyiségéhez. Ahogy a tartalomkészítőknél, itt is minden hangnemhez tartozik egy **Weight**, amely szabályozza, milyen gyakran használódik.

Az elérhető hangnemek:

| Hangnem | Stílus |
| -- | -- |
| **Neutral** | Nyugodt, tekintélyes, tényszerű. Nincs túlzás, nincs viccelődés — csak megbízható, jól strukturált tudás |
| **Friendly** | Meleg, közvetlen, mosolygós hangvétel, laza rövidítésekkel és időnként emojikkal |
| **Luxury** | Elegáns, kifinomult. Olyan szavak, mint az „exkluzív” és „egyedi”, amelyek különlegessé teszik az olvasót |
| **Foodie** | Érzéki, étvágygerjesztő leírások. „Food porn” nyelvezet, amely éhesvé teszi az olvasót |
| **Adventurous** | Merész, bátor, felfedező energia. Élénk érzéki leírások, amelyek mindent epikussá tesznek |
| **Family** | Egészséges, gyerekbarát izgalom. Meleg szülői energia a biztonságos és szórakoztató élményekről |
| **Romantic** | Költői, vágyakozó, szívet melengető. Naplementék, lágy nyelvezet és szerelem |
| **Humorous** | Szarkasztikus, gyors poénok, szellemes szóviccek. Olyan, mint egy stand-up előadás |
| **Eco** | Komoly és igazságos. Ünnepli a zöld alternatívákat és a fenntartható választásokat |
| **Local insider** | Nagyon specifikus helyi utalások, figyelmeztet a turistacsapdákra, helyi szleng használata |
| **Inclusive** | Befogadó, ünneplő és megerősítő. Mindenkit láthatónak és értékeltnek éreztet |
| **Mystical** | Éteri, spirituális, kozmikus igazságok. Gyengéd meghívások a belső szemlélődésre |
| **Futuristic** | Letisztult, előrelátó. Szereti az olyan kifejezéseket, mint a „paradigmaváltás” és az optimista jövőkép |
| **Budget** | Fürge, leleményes, büszkén takarékos. Ünnepli a megfizethető találatokat és az ingyenes élményeket |

## Bejegyzéstípusok

A bejegyzéstípusok határozzák meg a generált tartalom célját és szerkezetét. Minden bejegyzéstípushoz tartozik egy **Weight**, amely szabályozza, milyen gyakran használódik.

| Bejegyzéstípus | Leírás |
| -- | -- |
| **Transactional** | Egyértelmű, tömör, konverzióközpontú. Foglalásokat és közvetlen lépéseket ösztönöz tényekkel, árakkal és következő lépésekkel |
| **Awareness** | Márkaépítő tartalom, amely bemutatja az ingatlanodat és növeli a láthatóságot a potenciális vendégek körében |
| **Sentiment** | Érzelmileg rezonáló tartalom, amely pozitív asszociációkat teremt és érzelmi kapcsolatot épít a közönségeddel |

Lehet, hogy egy adott nyelvre és régióra szeretnéd fókuszálni a marketing tevékenységedet. Mondd meg nekünk, mely nyelveken szeretnél tartalmat készíteni, és melyik időzónában érdekel, mi pedig elvégezzük a többit. A bejegyzések a kiválasztott időzónában ütemezett időpontban jelennek meg.

*Az ingatlanok többsége egyetlen nyelvet használ, és alapértelmezettként a helyi nyelvét választja.*
