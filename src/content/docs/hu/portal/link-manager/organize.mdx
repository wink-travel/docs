A WinkLinks címkék kezeléséhez navigálj a fő navigációs sávban a `WinkLinks` menüpontra, kattints a `Design` fülre, majd görgess le a `Manage categories` részhez.

Ahogy nő a tartalmad, szeretnéd majd elkezdeni annak rendszerezését. Erre hoztuk létre a `címkéket`. Tetszőleges számú címkével csoportosíthatod a tartalmakat.

## Címke létrehozása

<Steps>
1. Hozz létre egy új címkét a `Add a new tag` gombra kattintva.
2. Írd be az új címke nevét. *pl. Top kávézók Berlinben*
3. Kattints a `Save` linkre.
</Steps>

## Címke frissítése

<Steps>
1. Kezdd azzal, hogy a módosítani kívánt címke mellett a `Edit` linkre kattintasz.
2. Frissítsd a címke nevét. *pl. Legjobb kávézók Berlinben*
3. Kattints a `Save` linkre.
</Steps>

## Címke eltávolítása

:::note
Címke eltávolításakor az az összes hozzá kapcsolódó tartalomból is törlődik.
:::

<Steps>
1. Kattints a `Remove` linkre a törölni kívánt címke mellett.
</Steps>

## API

A fejlesztők, akik kezelni szeretnék a `WinkLinks`-et, látogassanak el a [Developers > API > WinkLinks](/hu/api) oldalra.
