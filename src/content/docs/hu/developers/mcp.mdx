A Wink két autentikált MCP szervert kínál. Mindkettő **interaktív OAuth2 bejelentkezést** használ (PKCE engedélyezési kód folyamat) — az AI ügynöke megnyit egy böngészőfület, így bejelentkezhet Wink fiókjával. Nincs szükség kliens titkok kezelésére.

| Szerver | URL | Mit csinál |
|--------|-----|------------|
| **Inventory API** | `https://api.wink.travel/mcp` | Készlet, foglalások, árak, értékesítési csatornák, elemzések és az összes platform művelet |
| **Integrations** | `https://integrations.wink.travel/mcp` | Csatornamenedzser integrációk — ingatlanok, árak és elérhetőség szinkronizálása OTA-kkal |

---

## Hogyan működik az autentikáció

A Wink MCP szerverek a **OAuth2 Authorization Code + PKCE** folyamatot használják, és támogatják a **Dynamic Client Registration (RFC 7591)**-t. Így történik az első csatlakozáskor:

1. Az AI kliens felfedezi az engedélyező szervert az MCP végpont `/.well-known/oauth-protected-resource` metaadataiból.
2. A kliens önmagát regisztrálja a **Dynamic Client Registration** segítségével — nincs szükség kézi alkalmazásbeállításra.
3. A kliens megnyit egy **böngészőfület** a `https://iam.wink.travel` címen. Bejelentkezik Wink fiókjával, és jóváhagyja a kért engedélyeket a hozzájárulási képernyőn.
4. A Wink kiad egy **hozzáférési tokent**, amely a fiókjához van kötve és azonosítójához kapcsolódik.
5. Az AI kliens minden MCP kéréshez csatolja a tokent. Minden eszköz eredménye automatikusan a kezelő entitásához van kötve.
6. A tokenek 3 óra után lejárnak. Az AI kliens csendben frissíti őket a háttérben, újabb kérés nélkül.

Minden eszközhívás **az Ön azonosítója alatt fut** — ugyanazok az ACL szabályok érvényesek, amelyek a webportált védik az AI ügynökre is.

## Csatlakoztassa AI kliensét

<Tabs>
  <TabItem label="Claude Code">

<Steps>
1. Győződjön meg róla, hogy a Claude Code naprakész:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. Adja hozzá a Wink Inventory MCP szervert:
   ```bash
   claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
   ```

3. A Claude Code kapcsolatba lép a szerverrel, felfedezi az engedélyező szervert, és megnyitja az alapértelmezett böngészőt.

4. **Jelentkezzen be Wink fiókjával** és hagyja jóvá az engedélykérést a hozzájárulási képernyőn.

5. A Claude Code megerősíti a kapcsolatot. Írja be a `/mcp` parancsot, hogy ellenőrizze, megjelenik-e a szerver és betöltődtek-e az eszközök.
</Steps>

Az Integrations szerver hozzáadásához:
```bash
claude mcp add wink-integrations https://integrations.wink.travel/mcp --transport http
```

:::tip[Ossza meg csapatával]
Adja hozzá a `--scope project` opciót a `claude mcp add` parancshoz, és a Claude Code a szerver URL-jét a `.mcp.json` fájlba írja a projekt gyökérkönyvtárában. Kötelezze el ezt a fájlt — minden csapattag az első csatlakozáskor saját böngészős bejelentkezést végez.
:::

  </TabItem>
  <TabItem label="Claude Desktop">

<Steps>
1. Szerkessze a Claude Desktop konfigurációs fájlt:
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`

2. Adja hozzá az MCP szerver bejegyzéseket:

   ```json title="claude_desktop_config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

3. **Teljesen zárja be és indítsa újra** a Claude Desktopot (a menüsorban a Kilépés használatával — az ablak bezárása nem elég).

4. A Claude Desktop minden új szerverhez megnyit egy böngészőfület. Jelentkezzen be Wink fiókjával és hagyja jóvá az engedélyeket.

5. Az alsó eszköztáron a dugó ikon mindkét szervert csatlakoztatottnak mutatja.
</Steps>

  </TabItem>
  <TabItem label="OpenAI Codex">

<Steps>
1. Győződjön meg róla, hogy a Codex CLI telepítve van:
   ```bash
   npm install -g @openai/codex
   ```

2. Nyissa meg (vagy hozza létre) a Codex konfigurációs fájlt:
   - **macOS / Linux:** `~/.codex/config.json`
   - **Windows:** `%USERPROFILE%\.codex\config.json`

3. Adja hozzá a Wink MCP szerver bejegyzéseket:

   ```json title="~/.codex/config.json"
   {
     "mcpServers": {
       "wink-inventory": {
         "type": "http",
         "url": "https://api.wink.travel/mcp"
       },
       "wink-integrations": {
         "type": "http",
         "url": "https://integrations.wink.travel/mcp"
       }
     }
   }
   ```

4. Indítsa el a Codexet. Első használatkor a Codex megnyit egy böngészőfület a `https://iam.wink.travel` címen.

5. **Jelentkezzen be Wink fiókjával** és hagyja jóvá a kért engedélyeket.

6. A Codex megerősíti a kapcsolatot. Futtassa a `codex` parancsot, és kérje az elérhető eszközök listáját, hogy ellenőrizze a Wink szerverek aktívak-e.
</Steps>

:::note
A Codex CLI MCP támogatásához a **1.0** vagy újabb verzió szükséges. Ellenőrizze a `codex --version` paranccsal, és frissítsen a `npm install -g @openai/codex` paranccsal.
:::

  </TabItem>
  <TabItem label="ChatGPT">

Az MCP szerver támogatás elérhető a **ChatGPT asztali alkalmazásban** Plus, Pro, Team és Enterprise előfizetők számára.

<Steps>
1. Töltse le és telepítse a [ChatGPT asztali alkalmazást](https://openai.com/chatgpt/download/), ha még nem tette meg.

2. Nyissa meg az alkalmazást, kattintson a **profil ikonra** a jobb felső sarokban, majd válassza a **Beállítások** menüpontot.

3. Menjen a **Csatlakozók** (vagy **MCP szerverek** az alkalmazás verziójától függően) részhez, és kattintson a **Hozzáadás** gombra.

4. Adja meg a Wink Inventory szerver URL-jét:
   ```
   https://api.wink.travel/mcp
   ```
   Ezután kattintson a **Csatlakozás** gombra.

5. A ChatGPT megnyit egy böngészőfület a `https://iam.wink.travel` címen. **Jelentkezzen be Wink fiókjával** és hagyja jóvá az engedélyeket.

6. Ismételje meg a 4–5. lépéseket az Integrations szerverrel:
   ```
   https://integrations.wink.travel/mcp
   ```

7. Mindkét szerver megjelenik a Csatlakozók listájában. Indítson új beszélgetést — a Wink eszközök automatikusan elérhetők.
</Steps>

:::note[Webes alkalmazás korlátozás]
Az MCP szerverek csak a **asztali alkalmazásban** konfigurálhatók. A ChatGPT webes felülete a chatgpt.com címen nem támogatja az egyedi MCP szervereket.
:::

## Jogosultsági körök (scope) áttekintése

A hozzájárulási képernyőn látható lesz, hogy az ügynök milyen jogosultságokat kér. A Wink funkcionális területek szerint csoportosítja az engedélyeket:

| Jogosultsági csoport | Jogosultságok | Mit engedélyeznek |
|----------------------|---------------|-------------------|
| **MCP transport** | `mcp.read` `mcp.write` `mcp.remove` | Szükséges bármely MCP szerverhez való csatlakozáshoz |
| **Fiók** | `account.read` `account.write` `account.remove` | Kezelő entitások, csapattagok, beállítások, alkalmazások |
| **Foglalás** | `booking.read` `booking.write` `booking.remove` | Foglalások keresése, megtekintése, létrehozása, törlése és visszatérítése |
| **Készlet** | `inventory.read` `inventory.write` `inventory.remove` | Ingatlanok, szobák, árak, szolgáltatások, elérhetőség |
| **Elemzés** | `analytics.read` | Foglalási elemzések, bevételi jelentések, ranglisták |
| **Marketing** | `marketing.read` `marketing.write` `marketing.remove` | Közösségi posztok, kampányok, értékesítési csatornák, promóciók |
| **Tartalom** | `content.read` `content.write` `content.remove` | Multimédia, rövidített URL-ek, szindikálható elemek, térképek |
| **Fizetés** | `payment.read` `payment.write` | Főkönyv, kifizetések, pénzügyi bontások, kifizetések |

Az AI kliens csak a szükséges jogosultságokat kéri. Egyéni engedélyeket megtagadhat a hozzájárulási képernyőn — az eszközök, amelyekhez megtagadott jogosultság szükséges, hibát adnak vissza híváskor.

## Hibakeresés

**Nem nyílik meg a böngészőfül**

Lehet, hogy az AI kliens még nem támogatja az interaktív PKCE folyamatot. Ellenőrizze, hogy a legfrissebb verziót használja:
- **Claude Code:** `npm install -g @anthropic-ai/claude-code`
- **Codex CLI:** `npm install -g @openai/codex`
- **Claude Desktop / ChatGPT asztali:** frissítse az alkalmazás beépített frissítőjével

**`401 Unauthorized` bejelentkezés után**

A gyorsítótárazott token lejárt. Távolítsa el, majd adja hozzá újra a szervert, hogy friss bejelentkezést indítson:

```bash
# Claude Code
claude mcp remove wink-inventory
claude mcp add wink-inventory https://api.wink.travel/mcp --transport http
```

Claude Desktop és ChatGPT esetén távolítsa el a szerver bejegyzést a beállításokból, indítsa újra az alkalmazást, majd adja hozzá újra.

**`403 Forbidden` egy adott eszköz hívásakor**

Az eszköz olyan jogosultságot igényel, amelyet nem hagyott jóvá a hozzájárulási képernyőn. Csatlakoztassa újra a szervert — a hozzájárulási képernyő újra megjelenik, és jóváhagyhatja a hiányzó engedélyt.

**A szerver megjelenik, de az eszköz hívások "account not found" hibát adnak**

Olyan Wink fiókkal van bejelentkezve, amelyhez nincs kezelő entitás rendelve. Látogasson el a [Wink Portálra](https://app.wink.travel), és győződjön meg róla, hogy a fiókja megfelelően be van állítva az MCP szerver használata előtt.

**A token lejár a munkamenet közben**

A tokenek 3 óráig érvényesek. A Claude Code és Claude Desktop csendben frissíti a tokeneket megszakítás nélkül. Ha hosszú tétlenség után hitelesítési hibákat tapasztal, írjon be egy új üzenetet — a kliens automatikusan újra hitelesít.

**Codex CLI "MCP server unreachable" hibát jelez**

Ellenőrizze, hogy a `~/.codex/config.json` érvényes JSON (nincs utolsó vessző), és hogy a `"type": "http"` beállítás szerepel. A Codex távoli szerverekhez HTTP transportot igényel; a stdio transport csak helyi binárisokhoz használható.

**ChatGPT "Csatlakozók" menü hiányzik**

Az MCP támogatáshoz a ChatGPT asztali alkalmazás **1.2024.352** vagy újabb verziója szükséges, valamint aktív Plus, Pro, Team vagy Enterprise előfizetés. Frissítse az alkalmazást, és ellenőrizze előfizetését a Beállítások → Fiók menüpontban.

**Cursor szerver piros / "Csatlakozás sikertelen"**

Ellenőrizze, hogy a `~/.cursor/mcp.json` érvényes JSON és tartalmazza a `"type": "http"` beállítást. Ezután menjen a **Beállítások → Cursor beállítások → MCP** részhez, és kattintson a **Frissítés** gombra. Ha a hiba továbbra is fennáll, indítsa újra teljesen a Cursor-t — a konfigurációs változtatásokat nem mindig veszi észre újraindítás nélkül.

**Windsurf MCP szerverek nem jelennek meg a beállításokban**

A Windsurf teljes újraindítást igényel (nem elég az ablak újratöltése) az `mcp_config.json` változások észleléséhez. Használja a **Fájl → Kilépés** menüpontot, majd indítsa újra. Ha a szerverek még mindig nem jelennek meg, ellenőrizze, hogy Windsurf **1.4+** verziót használ a **Súgó → A Windsurf névjegye** menüpontban.

**Cline "Szerver hozzáadása" opció nem látható**

Az MCP szerver kezelőhöz Cline **2.0** vagy újabb verzió szükséges. Nyissa meg a VS Code Kiterjesztések panelt, keresse meg a Cline-t, és kattintson a **Frissítés** gombra, ha elérhető. Frissítés után töltse újra a VS Code-ot (`Ctrl+Shift+P` → "Developer: Reload Window").
