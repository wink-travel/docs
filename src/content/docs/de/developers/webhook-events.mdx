Diese Seite listet alle Webhook-Ereignisse auf, für die Sie sich bei Wink anmelden können. Für Einrichtungshinweise siehe den [Webhook-Integrationsleitfaden](/de/developers/webhook-integration) oder die [Webhook-Verwaltungsseite](/de/portal/settings/webhooks).

## So abonnieren Sie

1. Navigieren Sie im Portal zu **Anwendungen > Webhooks**.
2. Erstellen Sie einen Webhook und wählen Sie die Ereignisse aus, die Sie erhalten möchten.
3. Wink sendet bei jedem Auftreten des Ereignisses eine HTTP POST-Anfrage an Ihren Endpunkt.

Für vollständige Einrichtungsschritte und bewährte Verfahren siehe [Webhook-Integration](/de/developers/webhook-integration).
