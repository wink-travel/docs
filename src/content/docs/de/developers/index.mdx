Jede Plattformfunktion ist extern aufrufbar. Dieser Abschnitt behandelt Authentifizierung, die API-Oberfläche, Ereignisübermittlung und die dahinterliegenden Referenzdaten.

## Hier starten

- [Quickstart](/de/developers/quickstart/) — von null zu Live-Hotelpreisen und Ihrer ersten Testbuchung in der Staging-Umgebung.
- [Build on Wink](/de/developers/build-on-wink/) — was Sie bauen können und welche API passt.
- [Setup](/de/developers/setup/) — erstellen Sie eine Anwendung und erhalten Sie Zugangsdaten.
- [Authentication](/de/developers/authentication/) — OAuth2-Sitzungen und Berechtigungen.

## Die API-Oberfläche

- [REST and gRPC](/de/developers/rest-and-grpc/) — die zwei Transportarten und wann welche zu verwenden ist.
- [Geolocation](/de/developers/geolocation/) — räumliche Suche über buchbare Bestände.
- [Taxonomy](/de/developers/taxonomy/) — OTA-Codes, unterstützte Sprachen und Währungen.

## Ereignisse und Synchronisation

- [Webhook Integration](/de/developers/webhook-integration/) — abonnieren Sie Plattformereignisse.
- [Webhook Events Catalog](/de/developers/webhook-events/) — jedes Ereignis, das die Plattform aussendet.
- [Booking Sync](/de/developers/booking-sync/) — halten Sie Buchungen mit einem PMS oder Channel Manager synchron.

- [MCP Servers](/de/developers/mcp/) — lesen Sie die Live-API-Verträge von einem KI-Client.
