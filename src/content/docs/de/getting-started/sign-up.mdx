Bevor Sie irgendetwas tun, müssen Sie ein Benutzerkonto bei Wink erstellen.

<Aside type="note" title="Buchen Sie eine Reise?">
Dieser Leitfaden richtet sich an Fachleute, die mit dem Reiseinventar von Wink arbeiten möchten – Hoteliers, Reisebüros, Partner und andere, die Buchungen, Unterkünfte und Vertrieb verwalten. Wenn Sie Reisender sind, benötigen Sie zunächst kein Konto: Sie erstellen eines im Rahmen des Buchungsvorgangs.
</Aside>

Folgen Sie diesen Schritten:

<Steps>
1. Gehen Sie zu [app.wink.travel](https://app.wink.travel)
2. Klicken Sie oben rechts auf `Anmelden / Registrieren`
3. Sie gelangen zu einem Login-Formular. Klicken Sie auf den Link `Registrieren` unter den Formularfeldern.
4. Füllen Sie das Registrierungsformular aus und klicken Sie auf `Registrieren`. Sie werden zur Anmeldeseite weitergeleitet.
5. Nach der Anmeldung werden Sie zu unserem [Portal](/de/portal/create-account) weitergeleitet, wo Sie Ihr erstes Konto erstellen können.
</Steps>

Die Erstellung eines Wink-Benutzerkontos gibt Ihnen Zugriff auf alle Funktionen der Plattform. Sie können unbegrenzt viele Unterkünfte und Partnerkonten anlegen.
