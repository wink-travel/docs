## Warum QR-Codes für Hotels wichtig sind

Ein Hotel ist voller Offline-Momente mit hoher Buchungsabsicht. Ein Gast, der eine Spa-Karte liest, ein Gast, der eine Mahlzeit beendet, ein Teilnehmer bei einer Hochzeit, ein Reisender mit einer Schlüsselkarte — jeder Moment ist eine Chance, eine Buchung, ein Zusatzangebot oder einen Folgeaufenthalt zu generieren. QR-Codes verbinden diese Momente mit einem digitalen, buchbaren nächsten Schritt.

Die Technologie ist trivial; jede Handykamera scannt einen Code. Der Unterschied zwischen einem funktionierenden QR-Code und einem ignorierten ist **wohin er führt**. Zu viele Hotel-QR-Codes öffnen ein statisches PDF, eine Startseite oder eine Speisekarte ohne Handlungsoption. Die Chance besteht darin, den Scan **buchbar und messbar** zu machen.

## Wo Hotels QR-Codes platzieren können

| Platzierung | Der buchbare Moment |
|---|---|
| Gästezimmer & Schlüsselkarte | Aufenthalt verlängern, Rückkehr buchen, Spa oder Gastronomie hinzufügen. |
| Restaurants & Bars | Tisch reservieren, Chef-Erlebnis buchen, zukünftigen Aufenthalt planen. |
| Spa & Wellness | Behandlungen und Wellness-Pakete buchen. |
| Rezeption & Lobby | Upgrades, Early Check-in, Late Checkout, Erlebnisse verkaufen. |
| Events & Hochzeiten | Teilnehmern Zimmerkontingente oder Storefronts anbieten. |
| Gedruckte Werbematerialien | Broschüren, Flyer, Beschilderung, Visitenkarten und Willkommensbücher. |
| Außenwerbung & lokale Partner | Plakate, Partner-Locations und Destination-Platzierungen. |

Jede Platzierung sollte auf eine **konkrete Absicht** ausgerichtet sein — ein Spa-QR sollte den Gast nicht in einen reinen Zimmerbuchungsprozess führen.

## Wohin ein QR-Code führen sollte

Ein Scan sollte auf ein Ziel führen, das zum Moment passt und eine Aktion ermöglicht:

- Ein **buchbares Angebot** — das genaue Zimmer, Paket, Tisch, Behandlung oder Erlebnis.
- Ein **Storefront** — wenn ein Code mehrere Angebote präsentieren soll (Event-Hotels, eine Destination-Kollektion, das vollständige buchbare Angebot der Unterkunft).
- Eine **mobil-optimierte** Seite — QR-Traffic erfolgt fast ausschließlich über das Handy.
- Eine **messbare** Route — damit das Hotel weiß, welche Platzierung die Buchung ausgelöst hat.

## Wie es auf Wink funktioniert

Wink macht aus einem QR-Code einen echten Kanal, keinen statischen Link.

- **[Studio](/de/products/studio/) generiert die Codes.** Erstelle einen buchbaren Shareable Link oder ein Asset und lade einen gebrandeten **QR-Code als PNG oder SVG** für Druck, Beschilderung und Platzierungen im Hotel herunter.
- **[WinkLinks](/de/products/winklinks/) hostet das Ziel.** Wenn ein Code mehr als ein Angebot enthalten soll, leite ihn auf ein mobil-optimiertes Travel Storefront — buchbare Hotelkarten, Angebote, Listen und Karten unter einem `i.trvl.as/dein-name` Link.
- **[Booking Engine](/de/products/booking-engine/) erfüllt die Buchung.** Ein Tipp führt zum Checkout — das richtige Zimmer, Tarif und Extras, Zahlung, Bestätigung — und die gesamte Buchung, nicht nur das Zimmer.
- **Attribution bleibt erhalten.** Die Buchung bleibt mit der Kampagne, Platzierung oder dem Partner hinter dem Code verbunden, sodass das Hotel sehen kann, welche QR-Codes tatsächlich Nachfrage erzeugen.

Dies ist derselbe geschlossene Kreislauf wie beim [Hotel Social Commerce](/de/resources/hotel-social-commerce/) — der QR-Code ist nur ein offline Einstiegspunkt.

## Ein praktisches QR-Handbuch

### 1 — Wähle den Moment und die Absicht

Entscheide, was jede Platzierung verkaufen soll. Ein Tischaufsteller im Restaurant und ein Hochzeitsbanner haben unterschiedliche Aufgaben.

### 2 — Baue das Ziel zuerst auf

Erstelle das buchbare Angebot oder Storefront, bevor du etwas druckst. Das Ziel ist die Kampagne; der Code ist nur die Tür.

### 3 — Generiere und brand den Code

Nutze Studio, um den QR-Code zu erstellen und lade ihn als PNG oder SVG herunter, damit er bei jeder Druckgröße scharf bleibt.

### 4 — Gestalte für den Scan

Füge neben dem Code einen klaren Handlungsaufruf hinzu („Scannen, um das Spa-Paket zu buchen“) und stelle sicher, dass die Landingpage auf Mobilgeräten schnell lädt.

### 5 — Messen und optimieren

Verfolge Scans-zu-Buchungen nach Platzierung. Verschiebe Codes, die nicht konvertieren, und setze verstärkt auf die, die es tun.

## Häufige Fehler

- **QR-Codes, die ein PDF oder eine Startseite öffnen.** Der Scan muss zu etwas Buchbarem führen.
- **Ein generischer Code überall.** Passe den Code an den Moment und die Absicht an.
- **Keine Attribution.** Wenn du nicht sagen kannst, welche Platzierung die Buchung ausgelöst hat, kannst du sie nicht verbessern.
- **Landingpages im Desktop-Format.** QR-Traffic ist mobil — gestalte entsprechend.
- **Drucken vor dem Aufbau.** Baue das Ziel zuerst auf, dann drucke.
