Das Dashboard ist das Erste, was Sie sehen, wenn Sie [Portal](https://app.wink.travel) öffnen – das Kommandozentrum Ihres Kontos. Jeder Kontotyp sieht dieselben zwei Abschnitte; nur die zugrunde liegenden Daten unterscheiden sich je nachdem, ob Sie eine Unterkunft oder ein Affiliate-Konto (Studio, Reisebüro, Unternehmen) verwalten.

## Aktivität

Ein schneller Überblick über Ihre Buchungsgesundheit, mit Karten, die zeigen:

- Gesamtbuchungen
- Durchschnittlicher Verkaufswert
- Gesamtumsatz

Ein Link führt Sie direkt zu Ihrer vollständigen Buchungsliste für weitere Details.

## Analysen

Ein Diagramm, das Ihre Verkäufe im Zeitverlauf verfolgt, mit einem Link zu Ihren vollständigen Analysen für tiefere Filterungen und Zeiträume.
