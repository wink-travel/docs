Um Ihre WinkLinks-Tags zu verwalten, navigieren Sie in der Hauptnavigationsleiste zu `WinkLinks`, klicken Sie auf den Reiter `Design` und scrollen Sie zu `Kategorien verwalten`.

Mit wachsendem Inhalt möchten Sie diesen wahrscheinlich organisieren. Dafür haben wir `Tags` erstellt. Sie können Inhalte mit beliebig vielen Tags gruppieren.

## Tag erstellen

<Steps>
1. Erstellen Sie ein neues Tag, indem Sie auf die Schaltfläche `Neues Tag hinzufügen` klicken.
2. Geben Sie den Namen Ihres neuen Tags ein. *z. B. Beste Coffeeshops in Berlin*
3. Klicken Sie auf den Link `Speichern`.
</Steps>

## Tag aktualisieren

<Steps>
1. Klicken Sie zunächst auf den Link `Bearbeiten` neben dem Tag, das Sie ändern möchten.
2. Aktualisieren Sie den Namen Ihres Tags. *z. B. Beste Coffeeshops in Berlin*
3. Klicken Sie auf den Link `Speichern`.
</Steps>

## Tag entfernen

:::note
Wenn Sie ein Tag entfernen, wird es auch aus allen zugehörigen Inhalten entfernt.
:::

<Steps>
1. Klicken Sie auf den Link `Entfernen` neben dem Tag, das Sie löschen möchten.
</Steps>

## API

Entwickler, die `WinkLinks` verwalten möchten, können zu [Entwickler > API > WinkLinks](/de/api) wechseln.
