Ihre Inhalte finden Sie unter dem Reiter `Entries`.

Wir unterstützen drei Haupttypen von Inhalten:

- Öffentlich zugängliche URLs, die auf Webseiten verlinken.
- Dateien, die über WinkLinks hochgeladen wurden.
- Textinhalte, die über unsere Funktion `Quotes` erstellt wurden.

## Inhalt hinzufügen

So fügen Sie Inhalte zu WinkLinks hinzu. Klicken Sie unter dem Reiter `Entries` zunächst auf die Schaltfläche `Add entry`.

### Normaler Link

:::tip
Der Link muss auf eine Webseite führen. Zum Beispiel können Sie nicht direkt auf eine PDF verlinken. Wenn Sie eine PDF teilen möchten, müssen Sie die Funktion `Upload file` verwenden.
:::

So fügen Sie einen normalen Link hinzu:

<Steps>
1. Geben Sie den Link ein, den Sie teilen möchten. *z. B. https://trvl.as/3xWCH*
2. Sobald Sie den Link eingegeben haben, sucht Wink nach Details zu dieser Webseite und füllt das folgende Formular aus.
3. Sie können einige der Daten ändern, wie z. B. den Seitennamen, Titel und Beschreibung.
4. Sie können auch ein benutzerdefiniertes Bild hochladen.
5. Klicken Sie auf die Schaltfläche `Save`, wenn Sie bereit sind, fortzufahren.
</Steps>

### Datei hochladen

:::caution[Anforderungen]
- Bilder dürfen 10 MB nicht überschreiten.
- Videos dürfen 50 MB nicht überschreiten.
- Wir unterstützen alle anerkannten Bild- und Videoformate, einschließlich PDF.
:::

:::note[Empfehlungen]
- 2560w x 1440h (16:9 Seitenverhältnis) für Ihr Titelbild.
- 2560w x 1920h (4:3 Seitenverhältnis) für alle anderen Bilder.
- Die Bildgröße sollte 5 MB nicht überschreiten. Bitte komprimieren Sie Ihre Bilder vor dem Hochladen auf Wink.
:::

So fügen Sie eine Datei hinzu:

<Steps>
1. Medien können hinzugefügt werden:
    - Indem Sie Bilder von Ihrem Computer in das Fenster ziehen oder auf `Browse` klicken.
    - Indem Sie eine externe URL einfügen, die auf ein Bild verweist.
    - Mit der Kamera Ihres Laptops.
    - Von Ihrem Google Drive-Konto.
    - Von Ihrem Dropbox-Konto.
    - Von Shutterstock
    - Von gettyimages
    - Von iStock
    - Von Unsplash
2. Sobald der Upload abgeschlossen ist, können Sie weitere Metadaten hinzufügen, um Ihre Datei zu beschreiben, z. B. Titel und Beschreibung.
3. Klicken Sie auf die Schaltfläche `Save`, wenn Sie bereit sind, fortzufahren.
</Steps>

### Ein Zitat schreiben

:::tip
Ein Zitat ist eine großartige Möglichkeit, eine lange Liste zu unterbrechen [...und es lässt Sie auch klug und kenntnisreich wirken 😉].
:::

So schreiben Sie ein Zitat:

<Steps>
1. Geben Sie das Zitat ein *z. B. Rosen sind rot. Veilchen sind blau...*.
2. Geben Sie den Namen des ursprünglichen Autors ein. *z. B. Edmund Spenser*
3. Geben Sie den Namen der Seite ein, von der Sie das Zitat haben. *z. B. Daily Quotes*
4. Klicken Sie auf die Schaltfläche `Save`, wenn Sie bereit sind, fortzufahren.
</Steps>

## Inhalt aktualisieren

Alle Inhalte können einfach bearbeitet werden, indem Sie auf den Link `Actions` klicken und `Update` auswählen. Inhalte können auf ähnliche Weise entfernt werden, indem Sie auf die Schaltfläche `Remove` klicken.

## Inhalt entfernen

Alle Inhalte können einfach bearbeitet werden, indem Sie `Update` auswählen. Inhalte können auf ähnliche Weise entfernt werden, indem Sie zuerst auf den Link `Actions` klicken und dann die Schaltfläche `Remove` auswählen.

## Inhalte sortieren

Sie können Ihre Inhalte sortieren, indem Sie auf das Symbol unten links bei jedem Eintrag klicken und es an die gewünschte Position ziehen.

## Inhalte gruppieren

:::tip
Erstellen Sie Ihre Tags, bevor Sie Ihre Einträge erstellen. Andernfalls verlieren Sie Ihren Fortschritt und müssen von vorne beginnen.
:::

Beim Bearbeiten eines Eintrags haben Sie die Möglichkeit, einen oder mehrere Tags zur Gruppierung hinzuzufügen. Scrollen Sie zum Ende des Formulars, um das Feld `Tags` zu finden.

Nutzer, die Ihre WinkLinks-Seite besuchen, können wählen, wie sie Ihre Inhalte konsumieren möchten (entweder Liste oder Raster) und können einen oder mehrere Tags auswählen, um Ihre Inhalte weiter zu filtern.

## API

Entwickler, die `WinkLinks` verwalten möchten, können sich unter [Developers > API > WinkLinks](/de/api/overview/) informieren.
